一、内核与版本动态

1.1 主仓库 RT-Smart POSIX 兼容批次双 PR 合入，共 13 笔提交

日期：2026-08-30（20:49-20:55 北京时间合并）　来源：PR #11732、PR #11733

昨日日报判断主仓库”特性间歇期延续”，当晚即被打破。创始人 BernardXiong 连续合入两个 RT-Smart（RT-Thread Smart，POSIX/Linux 兼容模式）相关 PR，共 13 笔提交：

  • PR #11732「Extend Smart POSIX filesystem and syscall compatibility」（20:49 合并，10 笔提交）：DFS POSIX 记录锁（record locks）与 utest 覆盖、fchmod、tmpfs setattr 与元数据修正、Linux 兼容 procfs 进程/系统文件字段、libc epoll 在 OOM 时唤醒等待者、LWP 系统调用拷贝修复、EFAULT 与 tmpfs 属性位修复、virtio 网卡改为依赖 LWIP、clang-format 对齐。
  • PR #11733「Harden RT-Smart serial ioctl arguments」（20:55 合并，3 笔提交）：RT-Smart 串口 ioctl 参数硬化，termios 声明格式化并落实评审意见。

这是主仓库自 08-28 玄铁 C908 rt-smart BSP 之后最大的一笔合入，方向明确：RT-Smart 的 POSIX 文件系统与系统调用兼容层持续向 Linux 语义对齐（记录锁、多用户 procfs、epoll），串口 ioctl 进入参数级硬化阶段。

1.2 ENV WebUI TypeScript 化落地，并修复 BSP 同步失败

日期：2026-08-31（00:56 合并 PR；11:00 追加修复提交）　来源：RT-Thread/env PR #291

ENV 工具 PR #291「feature/webui typescript」合并，三项改动：WebUI 前端由 JavaScript 迁移为 TypeScript；插件启动 WebUI 时自动跳转到对应插件的 WebUI 页面；更新 RT-Thread Env logo。随后 08-31 11:00 追加一笔修复提交「Fix WebUI module import error causing BSP package synchronization failure」，修复 WebUI 模块导入错误导致 BSP 软件包同步失败的问题。

延续昨日 PR #290（SDK 管理与本地工具链配置）之后，ENV WebUI 化进入工程化阶段，创始人连续第三日亲笔迭代，官方开发工具链现代化节奏未停。

三、生态与厂商适配

3.1 packages：AI Agent 软件包新增音频框架

日期：2026-08-31（11:04 合并）　来源：RT-Thread/packages PR #2029

社区开发者 CXSforHPU 提交的 PR #2029 合并，ai/Agent/Kconfig 新增「Agent Driver」菜单与 PKG_AGENT_DRIVER_AUDIO 开关，启用后自动选择 wavplayer（含录音支持）与 BSP 音频——AI Agent 软件包由此获得音频驱动通路，为语音交互类智能体应用提供硬件接入点。该包 08-24 刚加多模态支持与聊天记录裁剪（PR #2022），本次补齐音频侧，端侧 AI 能力拼图继续完善。改动为 Kconfig 配置层，实际驱动逻辑在 wavplayer/BSP 侧，运行效果待实机验证。

3.2 packages：optparse 恢复 v1.0.0 版本条目，修复破坏性接口变更

日期：2026-08-31（11:02 合并）　来源：RT-Thread/packages PR #2028

optparse 软件包因接口破坏性变更（optparse_init 由 2 参数改为 3 参数、新增 argc）导致 wavplayer v0.2.0 等既有包编译失败（”too few arguments to function ‘optparse_init’“），而包索引此前仅收录 latest 版本，用户无法回退、只能手动改第三方包源码。PR #2028 由 Leeee-wx 提交，为 optparse 恢复 v1.0.0 版本条目（package.json + Kconfig），恢复回退能力，RT-Thread Studio 用户可直接回滚。软件包索引治理向”版本回退兼容”方向演进。

3.3 生态参考：h120d-protocol 逆向文档更新

日期：2026-08-30（12:43）　来源：H4ck3rTR/h120d-protocol
