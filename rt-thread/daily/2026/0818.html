RT-Thread 每日动态报告（2026-08-18）

2026-08-18 苦芽科技

调研窗口：过去 24 小时（2026-08-17 11:18 ~ 2026-08-18 11:18 北京时间） 信源：RT-Thread 官方新闻 API、GitHub（org: RT-Thread / topic: rt-thread / 主仓库 commits）、Google News 聚合（zh-CN，经代理）、HN 等（详见附录）

一、内核与版本动态

1.1 内核新增原生 AF_UNIX 本地套接字实现（8 月 17 日合入，本窗口最大内核事件）

日期：2026-08-17 17:15（北京时间合入）　来源：rt-thread PR #11681

创始人熊谱翔（BernardXiong）提交、维护者 Rbb666 合入主仓库的 PR #11681「Add AF_UNIX sockets implementation」，共 36 个文件、净增约 5700 行，是本窗口规模最大的内核合入。核心内容：

  • SAL 新增本地协议族注册表：此前 SAL 要求 socket 协议提供方必须挂接网络设备，该模型不适用于本地 IPC；本次引入独立于 netdev 的本地协议族机制，原有网络设备型 socket 行为保持不变；
  • DFSv2 支持 S_IFSOCK 节点：tmpfs 与 devtmpfs 可承载套接字文件节点，为 /dev/log 这类路径型套接字铺路；
  • SCM_RIGHTS 描述符传递：新增 DFS 文件引用计数助手，支持跨进程传递文件描述符（sendmsg/recvmsg 辅助数据）；
  • LWP socket 系统调用转换扩展：补充 sockaddr_un、musl msghdr、ancillary data 与 MSG_CTRUNC 的转换支持，打通 rt-smart 用户态进程使用 AF_UNIX 的路径；
  • 新增可选组件 components/net/af_unix：支持 SOCK_DGRAM 与 SOCK_STREAM、基于路径名的 bind/connect、socketpair、阻塞/非阻塞 IO、收发超时、poll/select 就绪、shutdown 与对端关闭处理、SCM_RIGHTS 描述符传递；
  • 配套：Kconfig 选项、SCons 集成、组件文档（README）、7 组 utest 用例（common/ipc/namespace/node/poll/rights 等约 1800 行测试）。

动机与意义：BusyBox syslogd/logger 等应用依赖基于路径名的 AF_UNIX 套接字（典型如 /dev/log）。此前 RT-Thread 无法原生提供，只能借助网络栈模拟。本次合入后 RT-Thread（含 rt-smart）获得不依赖网卡的本地进程间通信通道，是继 8 月 17 日 rt-smart 打通 ROS 2 交叉编译后，向”用户态进程模型 + 标准 POSIX IPC”方向补上的又一块关键基础设施，对机器人/具身智能场景的多进程协作与系统日志链路有直接价值。

1.2 wlan 修复 wifi 命令静默失败问题（8 月 17 日）

日期：2026-08-17 14:34（北京时间合入）　来源：rt-thread PR #11696

kaidegit 提交的修复：当设备模式未绑定到 AP 时执行 wifi ap 命令会无任何报错地直接失败，用户难以排查；本次增加模式检查并在失败时给出明确日志提示。验证环境为 hpm + esp hosted 板。属可用性小修复，配合前日合入的 WLAN 安全模式标志（WPA3/企业级/WAPI/OWE/DPP），WLAN 框架层近期处于密集完善期。

三、生态与工具链

3.1 ENV 工具链新增可选在线插件市场（8 月 18 日凌晨合入）

日期：2026-08-18 00:17（北京时间合入）　来源：RT-Thread/env PR #288

BernardXiong 主导的 PR #288「Add optional online plugin market」合入 ENV 工具链（RT-Thread Studio 的命令行后端）：

  • CLI 能力：新增 rt-env plugin market / market set / market clear 命令，支持 ENV_PLUGIN_MARKET_URL 环境变量覆盖配置文件中的市场地址；
  • WebUI 集成：配置市场后 WebUI 显示在线插件目录，由本机 Host API 代理市场目录、详情与 prepare 流程；下载制品后通过一次性 upload id 交给本机安装器完成安装；
  • 安全与兼容设计：未配置市场时行为与现状完全一致，”在线插件”页隐藏、相关 API 返回 404；ENV 不会按插件 ID 或任意 URL 直接安装（下载后校验再安装）；
  • 质量：29 项单元测试通过（test_market / test_env_cli / test_webui_server）。

意义：这是 RT-Thread 官方工具链首次具备插件分发渠道。结合 8 月 14 日合入的 epack 交互式脚手架（epack init 向导）与 8 月 13 日插件生命周期文档，ENV 已形成”开发（epack）→ 发布/获取（插件市场）→ 安装（一次性 upload id 安全安装）”的插件闭环。工具链侧连续第五天有合入（8/14 epack 向导 → 8/15 Buildroot 包导入 → 8/16 插件命令并发 → 8/17 smart-build ROS 2 → 8/18 插件市场），生态基建节奏密集。

四、行业应用专章（机器人 / 具身智能 / 工业）

  1. 本地 IPC 基建补齐，机器人多进程架构受益：AF_UNIX 合入使 rt-smart 用户态进程间通信不再依赖网络栈，配合 SCM_RIGHTS 描述符传递，可支撑机器人系统中”主控进程 + 传感器/执行器服务进程”的经典分解架构，也与前日 ROS 2 交叉编译支持形成呼应——ROS 2 的 DDS 走网络域、本地辅助 IPC 走 AF_UNIX 的分工在 RT-Thread 上成为可能。
  2. AIoT 大赛收官，AI 项目是主旋律：2026 RT-Thread AIoT 大赛排名公布，参赛作品以 AI 项目为主，反映了社区开发者从”裸机/传统 RTOS 应用”向”端侧 AI 应用”迁移的持续趋势；完整名单与获奖项目详情待官方公告。
  3. 工业主线不变：8 月 27 日上海「睿擎工业平台 Workshop：EtherCAT 实时控制与工业方案实战」倒计时 9 天，窗口内无新增预热信息；睿擎工业平台与 ENV 插件市场（工控场景插件化部署）的协同值得关注。

五、总结与趋势观察

  1. 内核侧：本地 IPC 从”无”到”有”：AF_UNIX 原生实现（SAL 本地协议族 + DFSv2 S_IFSOCK + SCM_RIGHTS）是本窗口最大技术事件，标志着 RT-Thread 在 POSIX 兼容与进程间通信能力上迈出实质一步，与 rt-smart 用户态路线直接咬合。
  2. 工具链侧：官方插件分发渠道从 0 到 1：ENV 在线插件市场合入，配合 epack 脚手架形成开发-分发-安装闭环；未来 Studio 插件生态的供给方式可能发生变化。
  3. 官方信息出口滞后依旧，媒体侧核查恢复正常：官方新闻 API 仍滞后约 2 个月，AIoT 大赛排名这类事件仅靠第三方媒体可查；本窗口 Google News 经代理恢复可达（昨日超时），媒体核查完整度较昨日提升。
  4. 机器人方向连续动作保持：8/17 ROS 2 交叉编译 → 8/18 AF_UNIX 本地 IPC，两天内两笔与机器人/多进程架构直接相关的基础设施合入，官方下半年主攻方向进一步明朗。
  5. 版本面平稳：v5.2.2 不变，内核大功能（AF_UNIX）以合入 master 方式先行，预计随下个版本发布。
