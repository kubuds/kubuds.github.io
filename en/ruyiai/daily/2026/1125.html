Today’s Highlights: FlagGems 59 linear algebra operators merged into triton-riscv (11-24)

Source: PR #134.

#134 “Port/flaggems linalg” was merged on 11-24 at 17:13, changing 121 files, adding 2,457 lines and deleting 35 lines.

The PR adds 59 FlagGems linear algebra operators at once, each paired with a test, and all exported uniformly from the example package’s export table. LU, Cholesky, triangular solve, and QR each retain one kernel, shared by operators of the same algorithm.

The tests do not require LAPACK. RISC-V’s PyTorch build lacks LAPACK, so instead of calling torch.linalg, the tests reconstruct results via matmul identities for validation.

The same batch fixes the CPU backend’s affine_grid_generator. It is changed so that each output element has a program load its own theta, keeping the kernel within the batch allocation.

This code was previously under review as examples. The 11-23 report noted two example PRs not yet merged; they have now landed.

Today’s Highlights: openRuyi packages Triton 3.9.0, switches to Buddy toolchain and removes old package (11-24)

Source: python-triton upgrade commit.

The openRuyi packaging repo changed three things at once on 11-24 at 15:14. python-triton was upgraded to 3.9.0 and switched to the Buddy toolchain, the buddy-mlir package was upgraded to 0.1.4, and the old package python-triton-ruyiai was removed.

Sources are taken from three places: the v3.9.0 release package from triton-lang, and commit f346011a of llvm-project from RuyiAI-Stack.

The third is commit 9ded1d4c of triton-riscv from RuyiAI-Stack. All three versions are pinned in the spec.

Build dependencies include buddy-mlir 0.1.4, buddy-mlir-llvm 0.1.4, and clang 22, among others. The spec states that the CPU backend uses Buddy’s LLVM tools, while AMD GPU uses a self-built LLVM from the same source.

This change folds RuyiAI’s Triton from a standalone package into the distribution’s mainline. With the old package name removed, triton installed via ruyi has only one source.

Note the version lag. Upstream buddy-mlir has already reached 0.1.8, while the distribution still locks 0.1.4.

I. RuyiAI Stack Progress (PyTorch / Triton / TileLang RISC-V Adaptation)

1.1 triton-riscv official tag points to deps commit; FlagGems merge lands after the tag (11-24)

Source: release/20261124-4be260f.

The tag was published on 11-24 at 15:44, pointing to commit 4be260f, i.e. “Bump triton buddy and llvm” (#123). That commit landed at 10:45.

Both assets are abi3 wheels of triton-3.9.0. The x86_64 package is 310,984,269 bytes; the riscv64 package is 312,550,917 bytes, the latter built against manylinux_2_39. The release notes are empty.

The FlagGems linear algebra work was merged at 17:13, after the tag. This release does not include those 59 operators.

1.2 Five commits in the triton-riscv window, with examples and tests landing together (11-24)

Source: main branch commit list.

The five commits are, in order: dependency upgrade, affine_grid_generator fix, linear algebra operators, removal of the per-file export table, and examples plus tests.

The dependency upgrade commit carries two engineering changes. First, setup.sh must re-apply patches after resetting the Triton source tree, otherwise the next build loses the compatibility code. Second, the patch script now fails outright on patches that do not apply, instead of silently skipping them.

The same commit also deletes six patches written for older Triton versions. The integration test trigger condition had previously been commented out, so every PR ran as an empty job; this is cleaned up as well.

The repo’s review queue remains long. Three example PRs — #130, #131, #132 — are unmerged, and #135’s backend unification change is also under review.

4.3 Seven Commits in the Window, VIR Scheduling Chain Takes Shape (11-24 to 11-25)

Source: buddy-mlir commit list.

The seven commits fall into two groups. The morning of 11-24 covers packaging and the frontend: the LLVM and Buddy tar packages switch to zstd, and DeepSeek tokenization is split out of the chat template.

The evening of 11-24 through the early hours of 11-25 covers four vector-side commits. First, value-class operations in VIR are marked Pure, enabling CSE merging and scheduling across memory accesses.

Next, -vir-schedule is added to reorder operations by vir.set_vl ranges to reduce register pressure. Then RVV semantics are refined: broadcasts used only as scalar operands no longer occupy vector registers, the maximum live count for MoE top-8 merging is corrected from 10 to 4, and the required grouping is corrected from 9 to 3.

The final commit moves scheduling ahead of -lower-vir-to-vector.

There is also an approximate-math pass. RVV has no vector math library, so math.exp and similar previously degraded to per-lane libm calls. The new pass switches to polynomial approximation and uses custom patterns for log, log2, sin, cos, atan2, and cbrt to avoid upstream errors on subnormals and large magnitudes.

VI. Trend Observations

6.1 FlagGems Porting Shifts to Daily Batches

On the same day the 59 linear algebra operators were merged, batches B12, B13, and B14 opened with over 96 operators combined. Single PRs run tens of thousands of lines, and the cadence has compressed from weekly to daily.

The porting conventions are also unified: one test per operator, package exports centralized in the init file, and tests bypassing LAPACK. This approach can be reused directly for subsequent batches.

6.2 The Distro Begins to Take Over Triton Builds

openRuyi pins triton 3.9.0 and the triton-riscv commit into the spec, switches the build to the Buddy toolchain, and removes the old package. RuyiAI’s Triton is now delivered from the distro mainline.

This step turns “community forks producing wheels” into “the distro producing packages.” Future version cadence will be decided by the packaging side, not by repo tags.

6.3 Upstream Release Cadence Diverges from Packaged Versions

Buddy shipped three releases in three days, while the distro remains pinned at 0.1.4. New capabilities like zstd packaging and VIR scheduling won’t reach the distro in the short term.

If the packaging side doesn’t catch up, Triton’s build baseline will continue to drift from upstream.
