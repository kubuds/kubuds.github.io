Today’s Highlight: LLVM fork completes riscv branch baseline rebuild — BOSC AME instruction update merged, patch stack replayed onto new upstream baseline

Date: 2026-09-29 ~ 2026-09-30　Source: riscv branch commit list, PR #29, SyncBots integration commit 697305d1

At 14:07 Beijing time on 09-29, the llvm-project repo (RuyiAI-Stack organization) merged PR #29 “BOSC: bosc-ame-instruction-update” (Yranger, opened 09-24) — the latest update in the BOSC AME instruction series. BOSC is the abbreviation for Beijing Institute of Open Source Chip; AME (Attached Matrix Extension) is a RISC-V matrix extension direction for AI computing, with its standardization advancing within the RISC-V International (RVI) framework.

From 23:00 that night to 01:47 on 09-30, the repo’s riscv branch (default branch) underwent a full rebuild: the local RISC-V patch stack was replayed in its entirety with new committer timestamps, tracing back to the April MLIR-JIT and vector semantics fixes (#1, #3, #4), followed in order by the IME/AME migration, the BOSC AME instruction and builtin series (#14, #16, #18), the Buckyball vendor extension and alignment with the Pebble core ISA (#20, #23), the BOSCAME backend design updates (#24, #27), and finally #29 merged within the window; CI jobs (riscv64 job, OpenMP checks) and multiple SyncBots automated sync integration commits were interspersed throughout. The rebuild session concluded with the integration commit “[SyncBots] Integrate LLVM at b3b5e33,” advancing the sync point to the LLVM upstream commit of 09-29. This rebuild was primarily a replay, with the only new content in the window being the single merge of #29.

Sync impact: the update timestamps of three open PRs on the branch were all refreshed to 01:47 that night — #22 “RVI AME (standard, pre-approved stage) backend support” (13 discussion threads, opened in July), #25 “BOSCAME FPGA backend,” and #28 “xboscame FPGA.” That is, both the standard AME backend and the FPGA-side follow-up paths are in the queue, awaiting review progress under the new baseline.

Key takeaways: this branch carries the entirety of RuyiAI’s RISC-V compiler work (matrix extensions, custom instructions, CI, and upstream sync automation); this rebuild advances the patch stack’s sync point with upstream LLVM to the same-day commit, establishing a new baseline for subsequent review of the matrix extension PR series.
