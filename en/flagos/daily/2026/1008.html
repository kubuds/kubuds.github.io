Today’s Highlight: FlagQuantum Lands 23 Merges in This Window — Distributed MPS Training Promoted to Release Certified (10-07 ~ 10-08)

Date: 2026-10-07 ~ 2026-10-08　Source: FlagQuantum #587, #590, #591, #595

In the first window after the holiday, FlagQuantum (the FlagOS quantum simulation and training component) became the largest increment within the organization: 76 commits and 23 merged PRs in the window, advancing continuously from the morning of 10-07 to the morning of 10-08, covering five tracks — release certification, performance dispatch, gradients and geometric quantities, error-correction decoding, and native entropy export:

  • Release certification landed (#587, merged 10-08 07:16): The distributed MPS release campaign concluded — the two_node_mps_training capability row was promoted from production_supported to release_certified (the only capability row promoted in this window), with certification built on two signed, measured production run payloads that passed the release gate; at the same time, the unsatisfiability of the tensor network (TN) capacity precondition on the current revision was recorded with measured justification, and all output-side defects found by the inspection process were fixed (28 non-merge commits since the self-merge baseline c7bba053). This campaign continues the distributed MPS / tensor network release work opened by #535.
  • Performance dispatch batch (#576 / #581 / #582 / #583): Public statevector dispatch was extended to SV-014 (SWAP), SV-010 (diagonal), and bounded SV-011 (Pauli rotations), and bounded Pauli rotation dispatch recertification was completed — continuing the SV series’ item-by-item “implementation + evidence” approach.
  • Gradients and geometric quantities (#562 / #568 / #575 / #585 / #564 / #565): Added fq.jacobian / fq.jvp / fq.vjp (multi-output programs); second-order derivatives (Hessian) reuse first-order rules via parameter shifting; added the Fubini-Study metric tensor (central-difference implementation, with a counterexample table explaining why operator-shift rules are not reused); N3-9 finalized the 30-pair matrix of “gradient method × execution mode” into a contract and re-tested it at the gate.
  • QEC and entropy export (#590 / #591 / #592 / #589): Added a sliding-window decoder (flagquantum/qec/sliding_window.py, 772 new lines, reading the detector error model per window and decoding window by window); fq.vn_entropy promoted von Neumann entropy to a native Stable Core export (root export budget 37 → 38); the four-row QEC alignment items converged; Quafu remote submission now fails closed when credentials are missing.
  • Quality closeout (#595 / #597): #595 backfilled 16 undeclared dispatch revisions; #597 (open) fixes a CI concurrency group defect — two consecutive merges cancel the entire previous validation batch (the cancellation of #590’s 23/23 checks was an instance of this mechanism).

Assessment: FlagQuantum’s dual track of “release certification + contractualized governance” is taking shape — capabilities are documented as contract files and re-verified through gates and measured payloads, and its engineering discipline is isomorphic to the FlagOS mainline release system; the window straddles the tail of the holiday and the first day back, making this repo a development line that maintained high intensity throughout the long break.

I. Open-Source Project Progress (GitHub Activity)

1.1 FlagQuantum: Distributed MPS Release Certification Lands — Two-Node Training Promoted to release_certified (10-08)

Date: 2026-10-08　Source: FlagQuantum #587, #535

  • Certification content: two_node_mps_training was promoted from production_supported to release_certified, the only changed row in the capability table; certification is based on two signed measured_production_run measured production run payloads accepted by the release gate.
  • Capacity record: The tensor-network capacity precondition is recorded as “unsatisfiable on the current revision” with measured justification — making the capacity boundary explicitly documented rather than left as an implicit constraint.
  • Engineering scope: Since merge baseline c7bba053, includes 28 non-merge commits and 2 mainline merges; all output-side defects found by the repo’s self-check process were fixed in the same pass.
  • Lineage: The campaign was opened by #535 (merged 10-06); this completes it and delivers the first distributed capability row to the repository’s release certification system (release_certified tier).

1.2 FlagQuantum: statevector and Kernel Dispatch Performance Batch — SV-010 / 011 / 014 and SWAP Fusion (10-07)

Date: 2026-10-07　Source: #576, #581, #582, #583, #566, #571, #574, #572

  • Public dispatch (SV series): #576 enables SV-014 public SWAP dispatch; #581 enables SV-010 diagonal dispatch; #582 adds bounded SV-011 Pauli rotations; #583 re-certifies the existing bounded Pauli rotation dispatch.
  • Gate batch (#566 / #571): Bounded reversible three-qubit gate dispatch (#566), dense local two-qubit matrix dispatch (#571) — local gate dispatch coverage continues to densify.
  • Kernel fusion and sampling (#574 / #572): Bounded SWAP sequence fusion (#574); MPS sampling collapse kernel dispatch (#572) — performance work now covers both the statevector and tensor-network simulation paths.
  • Implication: The performance batch advances from “in-kernel optimization” to “dispatch-layer semantics” — the same operation is routed to specialized kernels by matrix form and boundedness, with evidence recorded item by item.

1.3 FlagQuantum: Gradients and Geometric Quantities — jacobian / jvp / vjp, Fubini-Study Metric, and Second-Order Derivatives (10-07)

Date: 2026-10-07　Source: #562, #568, #564, #565, #575, #585

  • Differentiation interface surface (#562 / #568): Adds fq.jacobian / fq.jvp / fq.vjp for multi-output programs; native gradient capabilities are now centrally registered (single-point registration).
  • Contractualized measurement (#564 / #565): N3-9 codifies the 30-pair matrix of “gradient method × execution mode” as contracts/gradient-methods-contract.toml (30 unit cells + 30 noisy cells) and re-tests it in the gate; N3-11 measures every differentiable instruction × execution mode item by item.
  • Geometric quantities and second-order derivatives (#575 / #585): #575 makes second-order derivatives (parameter-shift Hessian) reuse first-order rules; #585 adds the Fubini-Study metric tensor (fq.gradients.metric_tensor) — implemented via central differences, with a counterexample table explaining why operator-shift rules are not reused (differentiating with respect to a state and with respect to an expectation value are different objects).

1.4 FlagQuantum: QEC and Native Entropy Export — Sliding-Window Decoder and von Neumann Entropy (10-08)

Date: 2026-10-08　Source: #590, #591, #592, #589

  • Sliding-window decoder (#590, merged 09:06): Adds flagquantum/qec/sliding_window.py (772 lines) — builds the decoding graph by window, decodes the detection event stream window by window, commits corrections, and advances by a fixed stride; also unblocks three block-level projections previously reserved for it.
  • Native entropy export (#591, merged 09:06): fq.vn_entropy becomes a native Stable Core export (root export budget 37 → 38) — fq.run(circuit, outputs=fq.vn_entropy([0])) returns the entropy value directly and supports log_base; the numerical implementation lives in simulation/entropy.py, with the runtime responsible only for dispatch.
  • Alignment convergence and fail-closed (#592 / #589): The four QEC alignment items converge on their respective targets (#592); Quafu remote submission switches to fail-closed when credentials are missing (#589, the earliest merge in the window).

1.5 FlagQuantum: Evidence and CI Closeout — Dispatch Revision Backfill and Concurrency Defect Fix (10-07 ~ 10-08)

Date: 2026-10-07 ~ 2026-10-08　Source: #595, #593, #573, #597, #579
