1.3 New Public Repository Trident: Experimental MLIR/LLVM Compilation Bridge (10-12)

Date: 2026-10-12　Source: flagos-ai/Trident · README · commit history

  • Positioning: Trident is an experimental compilation bridge—it compiles Python functions containing Triton/Torch-style computation into MLIR/LLVM, then executes via tvm_ffi; the core is C++/MLIR (CMake build, LLVM/MLIR pulled in as an external project), with Python-side entry points trident.jit and trident.compile, examples covering ATen operator lowering such as add / attn / mm / softmax, depending on apache-tvm-ffi and torch>=2.10.
  • Timeline: The repository was created and made public within the org on 10-12 16:47 (Beijing time); master branch commit history traces back to mid-May, 274 commits cumulative; 2 within the window—”refactor: unify FX and Triton imports around TVM FFI” (10-12 23:10) and “test: reorganize coverage and check e2e CUDA memory leaks” (10-13 00:50).
  • Observation: The project completed its migration from torch-mlir imports to direct FX-to-TVM-FFI connection in July; in form it is an exploration of a “frontend compilation bridge” for unified multi-chip onboarding, echoing FlagTree’s unified compiler route; its future direction (whether it converges with the TLE / FlagMega lines) is worth tracking.
