Today’s Focus: SpacemiT and XiangShan Jointly Release Server-Class CPU V100, the Industry’s First Chip Fully Compliant with the RISC-V Server Specification

Date: 2026-10-19　Sources: EETrend: SpacemiT Releases Server-Class CPU V100 (10-19), Shenzhen News: SpacemiT Releases Server-Class CPU V100 (10-19), Phoronix: SpacemiT Announces The V100 Server-Class RISC-V Processor (10-19), 21st Century Business Herald: First Chip Fully Compliant with the RISC-V Server Specification Released (10-19)

On the second day of the 6th RISC-V China Summit (10-19), SpacemiT and the XiangShan team jointly released the server-class CPU V100, alongside three categories of complete servers: compute, AI compute, and storage. The company calls it the industry’s first general-purpose compute chip fully compliant with the RISC-V server specification.

  • Specification coverage: The server specification is implemented across three layers—chip, firmware, and operating system—covering five specifications: RVA23, server SoC, server platform, Boot and Runtime Services (BRS), and security model. The BRS specification tests pass in full, and the chip supports direct installation, boot, and operation of mainstream Linux distributions including openEuler, openRuyi, openKylin, Debian, Ubuntu, Fedora, Red Hat, and Rocky, eliminating the need for a separately customized OS for each chip.
  • Microarchitecture: A 46-core hybrid design—6 XiangShan Kunminghu V2R2 cores plus 40 in-house X100 cores, with a maximum clock of 2.4 GHz and dual-socket coherent interconnect scaling up to 92 cores; a single chip provides 8-channel DDR5-4800 and 52 PCIe 5.0 lanes. Process and power (per overseas media) are 12nm and 120W TDP, with support for UEFI, ACPI, and SMBIOS.
  • Essentials for the data center: Supports the H extension, AIA, and IOMMU, with hardware virtualization of CPU, memory, interrupts, and I/O; the virtualization extensions are natively supported upstream in Linux, requiring no custom kernel. It integrates a hardware root of trust on-die and supports RISC-V native TEE, plus the RERI RAS specification. For cloud Agent applications, it offers a lightweight virtual machine approach that achieves VM-level isolation at resource overhead close to that of containers.
  • Complete systems and ecosystem: C2201 compute server, G5201 AI compute server, and S5236 storage server; the G5201 supports 8 full-height, full-length, double-width accelerator cards, has validated domestic accelerators such as Kunlunxin M100, and supports high-speed RDMA networking. Companion motherboards, firmware, BMC management, and hardware reference designs are open to external parties.
  • Statement: Founder and CEO Chen Zhijian said, “V100 is not only an important step for SpacemiT from edge to cloud, but also represents RISC-V moving toward a truly deployable, scalable data center market.”

I. Open Source Community and Software Ecosystem

1.1 Linux 7.3 Officially Released: RISC-V Adds RVA23 Detection, Counter Delegation, and KVM Extensions

Date: 2026-10-18 (media coverage 10-19)　Source: Phoronix: Linux 7.3 Released (10-18), Kernel Newbies: Linux 7.3 changelog

Linux 7.3 was released on schedule on October 18. On the RISC-V side, this release includes: hwprobe now exposes the RVA23U64 base behavior, allowing user space to directly determine whether a machine is RVA23-compliant; support for counter delegation-related extensions (Smcdeleg/Ssccfg/Smcntrpmf) and resctrl support for Ssqosid and CBQRI; KVM adds FWFT support for Svadu, Zicfiss, and Zicfilp; shutdown and reboot now use EFI runtime services; arm64 and RISC-V both gain crashkernel CMA reservation support; alternative section boundaries are statically computed to fix vDSO compatibility, and xip support is further removed. On the platform side, an initial device tree for StarFive JHB100 and support for Canaan K230 (a 64-bit RISC-V AI SoC) are added; detection and enumeration are also added for extensions including Smcsrind/Sscsrind, Zicclsm, Ziccamoa, Ziccif, Ziccrse, and Za64rs. For distributions, RVA23 detectability is a key step from “guessing via Kconfig” to “determining at runtime.”

1.2 XiangShan: XSCache Merges Coupled L2 Banked SRAM and Prefetch Admission Throttling

Date: 2026-10-19　Source: XSCache PR #36 (10-19), XiangShan PR #6738 (10-19), GEM5 PR #1241 (10-19)

The main XiangShan repo (kunminghu-v3) had 1 commit in the window: #6738 bumps the XSCache submodule version. On the cache side, XSCache #36 is a substantive performance commit—it splits CoupledL2’s L2 SRAM by set and bank and throttles prefetch admission, targeting two issues: last-level cache bandwidth contention and prefetch pollution. On the simulation side, GEM5 (xs-dev) #1241 fixes the out-of-order model: when store and AMO sends fail, it skips the replay flag in the load pipeline, avoiding incorrect replay accounting. The reference model NEMU and the difftest main branch had no new commits in the window (the most recent was the CRC check overhead optimization on 10-16).

1.3 openRuyi: dpdk Backports RISC-V lpm and fib Lookup Optimizations, spdk Upgraded to 26.09

Date: 2026-10-19　Source: openRuyi main repo commit log (10-19), openRuyi official news page

The openRuyi main repo had 15 commits in the window, with two performance-related ones most worth noting: dpdk backports RISC-V lpm and fib lookup optimizations, directly affecting the virtual switching and routing forwarding paths; spdk is upgraded to 26.09, following the upstream storage stack version. On the packaging side, the Rust ecosystem continues to be filled in as a group: rust-brotli-7, brotli-decompressor-4, botan-0.10, alloc-stdlib-2, alloc-no-stdlib-2, winreg-0.52, sequoia-man-0.3, and self-replace-1 are added, while rust-regex is upgraded to 1.13.1, regex-automata to 0.4.18, and regex-syntax to 0.8.11; go-gopkg-h2non-gock is upgraded to 1.2.0 and duplicate providers are cleaned up. During the same period, lookout, kiwi-image, and TakoPack within the organization also had pushes. The latest version on the official news page remains 2026.09 (released September 30; this version improves RVA23 support, expands the cloud and storage software stack, and upgrades the Go 1.27 build environment), with no new version announcement in the window.

II. Product and Ecosystem Updates

2.1 ZTE Microelectronics’ subsidiary Lirui Micro unveils Zhifeng 200, a RISC-V CPU for intelligent computing centers

Date: 2026-10-19　Source: 21st Century Business Herald (STAR Market Daily): ZTE Micro’s subsidiary Lirui Micro debuts high-performance RISC-V chip for intelligent computing centers (10-19), NetEase: Lirui Micro’s RISC-V chip debuts (10-19)

During the 6th RISC-V China Summit, Lirui Micro, a subsidiary of ZTE Microelectronics, publicly showcased for the first time Zhifeng 200, a high-performance RISC-V CPU chip built for intelligent computing centers. The company describes it as the industry’s first RISC-V CPU chip targeting intelligent computing center scenarios, focusing on three use cases: Agent clusters, inference super-node hosts, and enterprise-grade hybrid intelligent computing inference. It natively features RISC-V AI instruction acceleration and is optimized for KV Cache and long-context LLM inference. On the hardware side, it integrates multiple acceleration engines for Matrix, Vector, compression, and encryption, supports high-speed interconnect interfaces including DDR5, PCIe, and CXL, and can accommodate a “RISC-V native AI + GPU accelerator card” MoE hybrid inference solution. Detailed product specifications will be officially released at the end of this year; this issue only confirms the direction and scenarios, with performance data not yet disclosed.

2.2 Tenstorrent closes $1.5B Series E at a $6.2B post-money valuation

Date: 2026-10-19　Source: Tenstorrent press release: Tenstorrent Announces a $1.5B Series E at a $6.2B valuation (10-19), Dealroom: Tenstorrent raises $1.5B Series E (10-19), Quartz: Tenstorrent raised $1.5 billion (10-19)

Tenstorrent announced on October 19 that it had closed a $1.5 billion Series E at a $6.2 billion post-money valuation, more than double its valuation of roughly $2.6 billion in 2024, making it one of the largest Series E rounds for a U.S. semiconductor company. The round was co-led by newly formed Trace Capital (founder Ben Mahdavi) and Innovation X, with participation from Fidelity, T. Rowe Price, Morgan Stanley, Sandisk, Tether Investments, Cadence Ventures, ARK Invest, Agostinelli Group, and others. Tenstorrent, led by Jim Keller, is a leading company in high-performance RISC-V AI acceleration and IP.

2.3 UltraRISC’s UR-CP400 processor core debuts: RVA23, 8-wide out-of-order, SPECint above 22 points per GHz

Date: 2026-10-19　Source: Sohu (90 Says Tech): UltraRISC appears at the 2026 RISC-V China Summit (10-19)

UltraRISC showcased its UR series high-performance RISC-V processor cores and multi-scenario system-level solutions based on UR-DP1000 in the summit’s core exhibition area. The highlight of this generation is UR-CP400: it complies with the RVA23 specification, supports RVV 1.0, adopts an out-of-order, 8-wide, 14-stage pipeline microarchitecture, and achieves SPECint_base2006 above 22 points per GHz under an FPGA emulation configuration; it adds virtualization enhancements for multi-tenant cloud environments and targeted hardware optimizations for Agentic AI, with an FPGA prototype system demonstrated on site. The UR-CP400 IP is scheduled for delivery in Q1 2027. The company also presented a layered product lineup spanning processor core IP, multi-core CPU chips, and AI edge, multi-node cluster, and virtualization applications. CTO Jiang Jiang gave a technical talk at the data center and high-performance computing sub-forum.

IV. Special Chapter on Embodied Intelligence and Robotics

4.1 Ubitium Closes $14M Seed Round: Reconfigurable RISC-V Array Targets Physical AI

Date: 2026-10-13 (reported by Chinese media on 10-19)　Sources: Ubitium press release (10-13), Evertiq: Ubitium raises $14M (10-16), Zhidx: Ubitium raises $14M (10-19)

German Düsseldorf-based startup Ubitium announced the close of a $14 million new seed round, led by Ibex Investors with participation from OpenOcean, and follow-on investment from existing shareholders KBC Focus Fund, Runa Capital, and Inflection, bringing cumulative seed funding to $18 million. The company is building a reconfigurable RISC-V array (CGRA approach): a set of programmable processing units dynamically allocates three workload classes—signal processing, AI inference, and real-time control—according to software configuration, replacing the multi-chip stack of “DSP + NPU + CPU” with unified memory and a standard RISC-V toolchain, targeting physical AI scenarios in drones, robots, vehicles, and industrial equipment. The first validation chip, UB108, is built on Samsung 8nm with 256 processing units and has demonstrated all three compute classes running on the same array; the first commercial chip, UB410, is planned with 4096 processing units, with evaluation samples scheduled for delivery in 2027. This direction stands in contrast to the domestic “automotive-grade + embodied” dedicated SoC approach: one pursues specialization, the other reconfigurable generalization.

Date: 2026-10-19　Source: spacemit-robotics/perception PR #10 (10-19)

V. Summary and Trend Observations

  • Server specifications move from “document” to “product”: V100 lands five specifications—RVA23, server SoC, server platform, BRS, and security model—across the chip, firmware, and OS layers in one go, with all BRS tests passing and mainstream distributions directly installable. This means RISC-V servers are beginning to shed the embedded inertia of “one chip, one system” and move toward the x86-style general-purpose platform model—the most structural step this issue.
  • Open-source cores enter commercial server chips for the first time: 6 of V100’s 46 cores are XiangShan Kunminghu V2R2. Open-source high-performance cores are no longer merely academic and validation objects but are entering sellable data-center products as IP, giving the XiangShan “open source → product” path a verifiable sample.
  • Intelligent computing centers become a new competitive front: Zhufeng 200 explicitly targets Agent clusters, inference super-node Hosts, and hybrid inference; G5201 has validated the Kunlunxin M100 and supports RDMA networking; plus Sophgo’s teased RISC-V intelligent computing server—all three are pushing the “CPU + domestic accelerator card” combination toward inference clusters rather than point-to-point competition with general-purpose servers.
  • Base software simultaneously fills in determinability: Linux 7.3 makes RVA23 determinable at runtime via hwprobe and completes counter delegation, QoS identifiers, and KVM’s Svadu and shadow stack extensions; openRuyi backports RISC-V lpm/fib lookup optimizations into dpdk. The former solves “how do I know I’m RVA23,” the latter “once I know, can the performance be delivered.”
  • Capital remains polarized: Tenstorrent closed a $1.5 billion Series E at a $6.2 billion valuation and explicitly refused to sell, in stark contrast to the domestic Xinji Wuxian’s tens-of-millions-of-yuan Pre-A; but both direct funds toward “mass production and scenario deployment” rather than architecture validation. XuanTie’s 6 billion units shipped and E908A’s dual ASIL automotive certification offer another path—trading scale for ecosystem.
  • Limitations: V100’s 12nm/120W process and power figures come from overseas media reports; the official Chinese release does not list these two items. Zhufeng 200 has only disclosed scenarios and interfaces; specifications and performance are subject to its year-end launch. The summit lightning talks by Sophgo and the Beijing Institute of Open Source Chip are agenda arrangements; specific product specifications have not been confirmed by public materials. Ubitium’s funding was announced on 10-13; inclusion in this issue is based on Chinese media reports on 10-19. Changes detected in the member website inspection are all routine homepage updates by universities and institutions; no substantive product, funding, or architecture announcements were found.
