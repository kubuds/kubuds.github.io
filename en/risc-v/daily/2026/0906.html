I. Open-Source Community and Software Ecosystem

1.1 Trend Retrospective: GCC 17 Native -mcpu/-mtune=native Support Merged for RISC-V (09-03)

Date: 2026-09-03　Source: Phoronix

A significant milestone on the RISC-V toolchain side: GCC 17 now supports -mtune=native/-mcpu=native on RISC-V targets, allowing the compiler to automatically detect host processor features and generate more optimized code, giving the RISC-V platform a native compilation experience on par with x86/AArch64. This item was covered in detail in the 09-04 report; here it is only a trend retrospective over the past three days and will not be expanded upon again.

1.2 Trend Retrospective: PoCL 7.2 Achieves Official OpenCL 3.0 Conformance, Covering RISC-V (09-04)

Date: 2026-09-04　Source: Phoronix

The portable computing language project PoCL 7.2 has become a Khronos-certified official OpenCL 3.0 conformant implementation, covering RISC-V (RV64GC and RVA22) and x86_64 — the first time an open parallel computing standard has received official conformance endorsement on general-purpose RISC-V processors. This was covered in detail in the 09-05 report; the trend retrospective is omitted here.

Date: 2026-09-02~04　Source: GitHub openxiangshan/XiangShan commits, openxiangshan/XSAI

The engineering progress of the open-source core along both the vector extension and AI feature lines is the most stable active signal in the open-source community over the past three days.

1.4 Window Observation: OpenSBI Routine Development Commits, No Version Release (09-03~05)

Date: 2026-09-03~05　Source: GitHub riscv-software-src/opensbi commits

During the window, riscv-software-src/opensbi had routine development commits: sbi_pmu counter/event error codes aligned with the SBI v3.0 specification, raw event matching fixes, scounteren time emulation, FP state save fixes, and sbi_domain code renaming, among others — all part of the daily maintenance rhythm, with no version release (the latest official version remains v1.9 from 2026-07-01). The Lingrui Zhixin P100 core has continued to dominate domestic RISC-V server narratives: China’s first commercialized dynamic SMT4 (real-time switching of 1–4 threads per core under load) server-class RISC-V core, with a 20+ stage out-of-order pipeline, 8-decode/10-issue, and a P100-based test chip that taped out on a domestic advanced process line in mid-to-late August (roughly three months from April kickoff to tape-out). Biren Technology participated in its Pre-A round and jointly optimizes CPU+GPU compute scheduling; a 128-core server CPU is planned for tape-out in 2027.
