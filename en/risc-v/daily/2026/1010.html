Today’s Highlights: ESWIN Computing breaks issue price on debut, closes down 0.97% with total market cap of approximately HK$33.8 billion

Date: 2026-10-09　Sources: Sina Finance (The Paper): ESWIN Computing slips 0.97% on first day of trading (10-09), 21jingji.com: “First RISC-V stock” makes debut, rebounds after breaking issue price (10-09), TechNode: RISC-V chipmaker ESWIN Computing lists in Hong Kong (10-09)

The “first RISC-V stock” ESWIN Computing (01256.HK) listed on the Main Board of the Hong Kong Stock Exchange on 10-09, with a volatile first day: it opened at HK$1.54, immediately breaking its issue price (issue price HK$1.55), rebounded at one point during the session (up about 3% at midday), touched a low of HK$1.365, and closed at HK$1.535, down 0.97%, with a total market cap of approximately HK$33.83 billion. The global offering comprised approximately 1.617 billion H shares, raising gross proceeds of HK$2.5 billion and net proceeds of approximately HK$2.386 billion; approximately 35% of the proceeds will be used for chip product development and iteration, and 30% will be invested in the RISAA (RISC-V and AI) software and hardware platform.

I. Open-Source Community and Software Ecosystem

1.1 Canonical: Ubuntu 26.10 Debuts Official RISC-V Desktop Images

Date: 2026-10-09　Source: 9to5Linux: Canonical Announces Official Ubuntu Desktop Images for RISC-V (10-09), Phoronix: Ubuntu 26.10 To Include Desktop Images For RISC-V (10-09)

Canonical announced that Ubuntu Desktop now officially offers RISC-V images, launching alongside Ubuntu 26.10 (Stonking Stingray) on October 15; an experimental Xubuntu Minimal image is also available (not yet officially supported, recommended for testing in a VM). Official testing is recommended on the SpacemiT K3 (Pico-ITX), which gains official support starting with 26.10; the full desktop experience targets RVA23-class hardware, including Milk-V Jupiter 2, DeepComputing DC-ROMA, and SiFive HiFive Unmatched. Booting on real hardware requires manually supplying first-stage boot (e.g., U-Boot) and device tree.

1.2 LLVM/RISC-V: Branch-Free Code Still Compiled into Branches on RV32, Zicond as the Fix

Date: 2026-10-09　Source: Frank Denis: Branches in branch-free code (10-09), Hacker News discussion

Testing revealed that clang 23 compiles deliberately branch-free constant-time code on RISC-V (128-bit addition carry propagation, mask selection, etc.) into conditional branches (beq/beqz), present on both RV32 and RV64, constituting a potential side channel; Zig and Rust are similarly affected. Enabling the Zicond extension (part of the RVA23 profile, providing czero.eqz/nez) restores branch-free code in all cases, but timing guarantees still require the Zkt extension; GCC 16.1 produces branch-free code for some formulations but still introduces branches for comparison-mask formulations. Conclusion: after compiler version or flag changes, constant-time code must be re-audited at the machine-code level.

1.3 riscv-unified-db: New RVA23.1/RVB23.1 Profiles Added

Date: 2026-10-09　Source: riscv-unified-db commit log (10-09)

The machine-readable specification database riscv-unified-db saw 7 commits in the window: added RVA23.1 and RVB23.1 profiles (#2721), added 8/16-bit atomic RMW paths for the Zabha extension (#2566), added Sspmp/Sspmpen/Smpmpdeleg extension definitions (#1817), completed Smcdeleg and Ssccfg dependencies (#2718), and fixed fcvt floating-point conversion metadata and cleaned up VSEI/VSSI interrupt parameters. The specification database continues to track the latest ratified profiles.

1.4 openRuyi: 13 More Go Ecosystem Packages Added

Date: 2026-10-09　Source: openRuyi commit log: SPECS second batch (10-09), lookout commit log (10-09)

Following the first batch of 20-plus items, the openRuyi main repository merged 13 more SPECS commits in the window: added package definitions for Go ecosystem components including franz-go, OpenTelemetry profiling, Jaeger IDL, the Datadog series, ghinstallation, Alibaba Cloud OpenAPI, and chroma, plus buf-protovalidate and cloudfoundry-clock. The organization’s version inspection tool lookout merged 20-plus commits the same day (release version dropdown selection, batch dependency upgrades, and CI cache optimization). A check of the official news page shows no new release announcements after the 2026.09 version.

1.5 XiangShan: FMA Early Wakeup, MMU ptehelper Support, and Four Other Merges

Date: 2026-10-09　Source: XiangShan commit log (kunminghu-v3 branch, 10-09), PR #6679, PR #6687

The XiangShan main repository saw 6 merges in the window: #6679 adds early wakeup for FMA from FMA and load (src2 path), #6687 fixes aes64ks1i failing to trigger an illegal instruction exception when rnum>10, #6580 corrects interrupt-related comments, #6636 enables performance reporting for workload_list, plus two MMU commits (adding ptehelper support and a spelling fix). Frontend decode, floating-point issue, and MMU paths are being closed out in sync.

1.6 XiangShan Simulation Chain: difftest Supports 2-Slot ROB Architecture Events, GEM5 Aligns with V3 RTL

Date: 2026-10-09　Source: difftest PR #979: 2-slot ROB entry architecture events (10-09), difftest PR #954: UVHS GBus host interface, GEM5 commit log (10-09), NEMU commit log (10-09)

The simulation chain advanced on multiple fronts: difftest merged #979 (crob supports archEvent and storeEvent for 2-slot ROB entries) and #954 (adds UVHS GBus host interface for FPGA verification); GEM5 fixed UARTLite fast builds and added Clang coverage (#1209), and aligned SBuffer store miss handling with Kunminghu V3 RTL; NEMU’s ZSTD checkpoint format error handling was merged into the main branch.

2.1 Sophgo: sophon-demo Adds YOLO26 Depth and Pose Estimation Samples

Date: 2026-10-09　Source: sophon-demo commit log (10-09), sophon-tools commit log (10-09)

Sophgo’s sophon-demo added two new samples—YOLO26 monocular depth estimation and pose estimation (YOLO26_depth/YOLO26_pose)—completing the example matrix for the new-generation detection model on the Sophgo TPU platform; sophon-tools changed the EC20 module self-healing timer to be triggered by udev upon module detection (period adjusted from 60s to 90s), and fixed psewriter test compilation on 32-bit platforms. Eight repositories in the sophgo organization were batch-pushed in the window (including libsophon, LLM-TPU, osdrv, etc.).

2.2 Sipeed: SLogic Adds sigrok-cli Forwarding Plugin

Date: 2026-10-09　Source: SLogic commit log (10-09), slogic16u3-tools commit log (10-09)

Sipeed logic analyzer ecosystem updates: the SLogic repository added sigrok-cli-slogic-plugin—a cross-platform thin-wrapper forwarder for the sigrok command-line toolchain, with wiki documentation (Chinese and English) aligned accordingly; slogic16u3-tools exposed OTA application image flashing tuning to product.toml (the [ota] config section), enhancing toolchain configurability.

III. Deep Dive into Domestic Teams

3.1 ESWIN Computing: Turbulent Trading on Debut, Net Proceeds HK$2.386 Billion

Date: 2026-10-09　Source: Sohu (ChipInsights): First RISC-V Stock! ESWIN Computing Breaks Issue Price on Debut (10-09), EE Times China: ESWIN Computing Lists on HKEX, Wang Dongsheng Reaps Third IPO (10-09)

Supplementing the debut-day coverage (see “Today’s Highlights”): intraday high of approximately HK$1.60 and low of HK$1.365; issuance fees of approximately HK$121 million. The company was co-founded by former BOE Chairman Wang Dongsheng, with cumulative funding of over RMB 9 billion across four rounds (IDG Capital is the largest external institutional shareholder); revenue for 2023–2025 was RMB 1.752/2.025/2.431 billion, with net losses of RMB 1.837/1.547/1.516 billion. The prospectus discloses that its strategy for coping with competition includes “trading price for volume,” and further losses remain possible.

3.2 ESWIN Group: First Batch of Equipment for Wuhan Silicon Materials Base to Arrive This Month

Date: 2026-10-09　Source: Hubei Provincial Department of Economy and Information Technology: First Batch of Equipment for ESWIN Wuhan Silicon Materials Base to Arrive This Month (10-09)

The silicon materials segment of ESWIN Group (Xi’an ESWIN, listed on the STAR Market) is accelerating construction of its Wuhan base: covering approximately 310 mu, with total investment of approximately RMB 12.5 billion, the first batch of equipment arriving this month and production commencing in Q2 next year, with annual output value expected to exceed RMB 3.5 billion at full capacity. As of end-June this year, Xi’an ESWIN’s total capacity exceeded 1 million wafers/month, with global shipment market share of approximately 7.7% (ranking first domestically and sixth globally in 12-inch wafers). The base fills a gap in Wuhan’s 12-inch wafer segment and complements the local memory and wafer fabrication cluster.

3.3 SpacemiT: spine-triton Refines Build and Release Pipeline

Date: 2026-10-09　Source: spine-triton commit log (10-09), docs-buildroot commit log (10-09)

SpacemiT’s spine-triton (the Triton compilation stack for K3) saw over 10 commits during the window focused on refining the release pipeline: renaming the smt_rvisa module and adding GitHub CI to build riscv64 wheels per Python version; extracting vendoring logic into a shared script (scripts/common.sh), along with routine version bumps and build workflow updates. On the documentation side, docs-buildroot added an English translation of the K3 Secure Boot guide and v1.0.8/v1.0.9 release notes, while docs-ros corrected several K3 documentation issues.

3.4 Espressif: esp-sr Adds wakenet10 Wake Word Model Support, esp-idf Multi-Chip Fixes Merged

Date: 2026-10-09　Source: esp-sr commit log (10-09), esp-idf commit log (10-09)

Espressif maintained steady progress during the window: the esp-sr speech framework added support for the wakenet10 wake word model (including PT model files), upgrading the voice interaction stack; esp-idf merged a batch of fixes — C61 monitoring clock now set via PVT functions, SDMMC msync timeout mask, TEE anti-rollback, S31 DAC preparation, and BLE Audio address signing. The Espressif organization pushed to over 30 repositories during the window, reflecting a dense maintenance cadence on the device side (including the RISC-V chip line).

IV. Embodied Intelligence and Robotics Special Section

4.1 SpacemiT Robotics: ros2_humanoid Adds WebSocket Direct-Connect ASR Action Control

Date: 2026-10-09　Source: ros2_humanoid commit log (10-09)

SpacemiT Robotics’ ros2_humanoid merged direct WebSocket ASR (speech recognition) action control during the window: recognition results can directly trigger humanoid robot actions via WebSocket. The repository had previously migrated ROS control to the operator socket API and maintained ASR capture during audio prompts — the control chain continues to evolve toward direct connection and decoupling across “voice—operator—actuator.”

V. Summary and Trend Observations

  • A milestone for desktop distributions: Ubuntu 26.10 ships the first official RISC-V desktop image (recommending SpacemiT K3, targeting RVA23-class hardware), marking RISC-V desktop usability’s transition from “experimental images” to “official support.”
  • Capital debut tests market patience: ESWIN Computing opened below its issue price on day one and closed down 0.97%, with a total market cap of approximately HK$33.8 billion; amid the coexistence of high growth and high losses, the execution pace of the “trading price for volume” strategy and RISAA ecosystem investment becomes a key focus going forward.
  • Toolchain and specification layers tighten up details: LLVM compiles branchless code into branches on RISC-V (Zicond/RVA23 as the solution), riscv-unified-db adds RVA23.1/RVB23.1 profiles — the software and specification layers continue to be refined at the margins.
  • XiangShan ecosystem and community repositories remain high-frequency: XiangShan FMA/MMU fixes advance in sync with difftest, GEM5, and NEMU simulation chains; openRuyi Go packages, Espressif esp-sr, Sipeed SLogic, and Sophgo example matrices all saw substantive commits.
  • To watch: ESWIN’s post-IPO trajectory and lock-up expiration cadence; actual installation feedback for the RISC-V image after Ubuntu 26.10’s official release on October 15; the release cadence of SpacemiT spine-triton’s riscv64 wheels.
