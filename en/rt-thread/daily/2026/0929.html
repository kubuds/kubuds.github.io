I. Kernel and Version Updates

1.1 Mainline merges three PRs in one evening: ESP32-C6 and CH32V003 BSPs, IAR template fix (09-28)

Date: 2026-09-28 22:19–22:22 (Beijing time, merge time)　Source: PR #11836, PR #11838, PR #11843

Maintainer Rbb666 completed three merges within roughly three minutes. First (#11836), Espressif ESP32-C6-DevKitC-1 board support (9 commits, 40 files, +9598/-50) officially entered mainline: it includes the complete bsp/ESP/ESP32_C6 board project (build configuration, IDF adaptation layer idf_port, linker scripts and certificate bundle), adaptation updates to the shared ESP drivers and Kconfig, and CI wiring; the proposal was submitted in the early hours of 09-25 and merged about four days later, and this merge also folded in a CH32V203 SConstruct adjustment. Second (#11838), WCH CH32V003F4P6-EVT board support (5 commits, 47 files, +9258) was merged: RISC-V core RV32EC, 48MHz, 16KB Flash, with UART1 entering msh by default; it had entered review on 09-25. Third (#11843) fixed the IAR project templates for 5 BSPs: the template ewp’s linker configuration file previously pointed to absolute paths on another development machine, and was uniformly changed to $PROJ_DIR$ relative paths (+7/-7, covering boards such as asm9260t, mm32f3270-100ask-pitaya, and stm32f103-100ask-mini).

1.2 ESP32-S3-DevKitM-1 BSP proposal enters review: package dependencies still need to be completed (09-28 ~ 09-29)

Date: 2026-09-28 19:04 (created) ~ 09-29 10:18 (last updated)　Source: PR #11844, PR #11816

The same contributor (cms19859230182-lang) submitted a brand-new BSP proposal (#11844) for the Espressif ESP32-S3-DevKitM-1 within the window: 6 commits, 44 files, +6862/-31, adding bsp/ESP/ESP32_S3 and libcpu/xtensa/esp32s3, single-core image, UART0 (GPIO43/44) entering msh, Flash 8MB DIO 80MHz; the proposal notes that this board uses the Xtensa LX7 architecture, not RISC-V, so it cannot reuse the ESP32-C3 toolchain and interrupt wiring, and the configured toolchain is xtensa-esp32s3-elf GCC 12.2.0. During review, the maintainer pointed out that compilation and package dependency issues remain (09-28 22:18), and the submitter responded on the morning of 09-29 and began revisions. Separately, the ESP32-C3 Windows build fix proposal (#11816, submitted 09-21) received a follow-up comment from the submitter on the morning of 09-29 and remains under review.

1.3 RT-Thread Env tool fixes Unicode and invalid path handling (09-28)

Date: 2026-09-28 21:07 ~ 21:10 (commit and merge time)　Source: RT-Thread/env PR #298

env (the Windows-side development tool) merged fix #298 within the window: it removes the ASCII-only BSP path validation, allowing Env commands to work normally in Unicode working directories such as Chinese ones; it also fixes path handling for the Explorer right-click menu at disk root, terminates startup directly when the selected path does not exist, and adds regression tests (including Unicode path cases). Submitted and merged by project founder Bernard Xiong, it is the first update to the env repository since 09-16.

The latest entry date in the archive returned by the official news API (rt_org category) remains 2026-06-17, with no additions within the window and no updates for the fourth consecutive day; product and event information continues to be first released via the WeChat official account, community forum, and GitHub channels.

2.2 Forum tutorial “MCU linker script ‘upgrade’” updated: summary and appendices added (09-29)

Date: 2026-09-29 09:39 (update time)　Source: Forum article 54cb40d33610387a

Community author “大目熊”’s advanced linker script tutorial was updated again on the morning of 09-29 (the article had already been indexed on 09-28): the end of the article now provides a full summary—recommending enabling “orphan section” warnings in engineering practice and writing linker scripts rigorously to eliminate hidden risks in advance—and adds two appendices: a reference for key linker flags (–warn-orphan, –orphan-handling=error, -Map=output.map) and a quick reference for common readelf commands (-S/-l/-s), concluding the tutorial.

III. Ecosystem and Vendor Adaptation

3.1 GD32 downstream repository merges driver update: USART/I2C/SPI GPIO initialization switched to the new version (09-28)

Date: 2026-09-28 16:20 (merge time)　Source: GD32-MCU-IOT/gd32_rt-thread PR #71

The RT-Thread downstream repository maintained by GigaDevice merged a driver update within the window (#71, with the commit description stating that the GPIO initialization of the USART, I2C, and SPI drivers was updated to the new version): it involves six files—drv_hard_i2c, drv_spi, and drv_usart—with a net removal of 797 lines relative to the previous version (mainly retracting the old implementation, while driver files are retained and implementations converge). The repository’s chip adaptation and driver maintenance cadence continued this month (an F20x I2C DMA update was merged on 09-18).

3.2 Espressif esp-idf package C6 source proposal closed by submitter (09-29)

Date: 2026-09-29 08:28 (close time)　Source: RT-Thread-packages/esp-idf PR #17

The proposal to add ESP32-C6 scons build sources to the esp-idf package (#17, submitted 09-25) was closed by the submitter on the morning of 09-29 without being merged; the package repository has had no new pushes since November 2023. Mainline ESP32-C6 board support has been merged (see 1.1), and there is no further public information on the corresponding package-side form.
