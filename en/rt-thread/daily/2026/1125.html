I. New Architecture: RH850 Enters the Mainline

1.1 Renesas RH850/U2C8 Port Merged, 52 Files, 4,122 Lines (11-24)

Date: 2026-11-24 15:01 (merged). Source: #11998.

The proposal was opened on November 6 and merged on November 24, with review taking 18 days. The author is parthitce, and the commit is signed by Parthiban Nallathambi of Linumiz.

The merge landed four commits on the main branch at once: kernel architecture layer, board support library, QEMU board, and CI. In total, 52 files with 4,122 lines added and zero deletions.

The kernel layer lives in libcpu/rh850. Thread switching goes through TRAP0, with support for nested interrupts, FPU context, and fault dumps. The board library includes startup code, the INTC interrupt controller, the OSTM timer, and the RLIN3 serial port.

The QEMU board is named qemu-rh850-u2c, with the serial port on RLIN311, and it drops straight into msh on boot. The libcpu directory now holds 21 entries, with rh850 being the new addition.

Assessment: This is an architecture-level port, not just another dev board. The basis is that the changes land in libcpu, bsp, and CI simultaneously, and come with their own toolchain and emulator.

1.2 Serial Port Only Supports V1, Toolchain Uses v850-elf (11-24)

Date: 2026-11-24 15:01 (merged). Source: #11998 description.

The serial driver implements only V1. In Kconfig, BSP_USING_UART depends on RT_USING_SERIAL_V1, so the newer serial framework is not yet selectable.

The toolchain is v850-elf-gcc. tools/ci/toolchain_bsp.yml classifies this board under v850-elf-gcc. The download source points to v1.2.0 of linumiz/rh850-gcc-toolchain.

That toolchain is GCC 14.3 plus picolibc. The emulator comes from rh850-v1.2.0 of linumiz/qemu-rh850. CI downloads both archives, verifies SHA-256, then extracts.

Assessment: Reusing the v850 toolchain lineage shows the priority here is getting it running first. The basis is that RH850 and V850 both belong to Renesas’s 32-bit MCU instruction set lineage, and the repo already has libcpu/v850 and the bm3803 board.

1.3 CI Matrix Adds RH850 Alongside ARM, AArch64, RISC-V (11-24)

Date: 2026-11-24 15:01 (merged). Source: utest_auto_run.yml.

utest_auto_run.yml adds a row to the platform matrix for RH850, machine rh850-u2c, standard kernel, no SD card. Three test suites are attached: kernel_basic, mem, cpp11.

The third verifies C++ global constructors. The trigger path adds bsp/renesas/rh850.

bsp/README.md adds the RH850 architecture series, with maintenance level marked as “basic support” and the serial column marked as supported.

The author listed verification results in the proposal. Hard-float and soft-float builds pass, scons –dist passes. In msh, list thread and free work normally, and kernel_basic passes all 22 items. clang-format and cppcheck are clean.

Assessment: Getting into CI is worth more than getting into the mainline. The basis is that an emulator plus test suites means any future kernel change must pass this gate.

II. Kernel and Driver Hardening: Six Proposals from the Same Source Cleared

2.1 Six Security Proposals from the Same Author Merged Within Five Minutes (11-24)

Date: 2026-11-24 15:11 to 15:16 (merged). Source: #11820, #11821, #11823, #11824, #11825, #11826.

All six come from manyangshen, with an author date of September 22, held for two months.

Three on the driver side. I2C serializes bus control and transfers; block devices constrain partition I/O to relative sectors; virtio rejects invalid input offsets to avoid overflow.

Two on the kernel and IPC side. The message queue path sizes by terminating NUL; power management restores devices by the mode at suspend time rather than always defaulting.

One on the board side. STM32 OpenAMP’s receive ring state becomes bounded with added synchronization, fixing wraparound. All six changes are small, most in the range of a dozen to a few dozen lines.

Assessment: This is a batched release. The basis is that all six share one author, merged within the same minute range, with identical author dates, indicating review completed in a single round.

2.2 Five Existing Issues Closed Alongside the Merge (11-24)

Date: 2026-11-24 15:14 to 15:48 (closed). Source: issue list.

#10379 and #10380 are out-of-bounds write and read in the virtio_input driver. #11299 is an out-of-bounds write in the OpenAMP virtual serial RX ring on stm32mp157a-st-ev1.

#11292 is mq_open and mq_unlink using rt_sprintf to concatenate queue names into a fixed buffer, with the prefix /dev/mqueue/. #11854 is a feature request for STM32F103C6, closed with the board merge.

New issues opened in the window: zero.

Assessment: The common thread across these issues is buffer boundaries and concurrency timing. The basis is that all five stem from the same round of fixes and none involve new features.

III. Chip and Development Board Adaptation

3.1 GD32H77D GinoPi board support merged, 107 files, 26,700 lines (11-24)

Date: 2026-11-24 15:20 (merged). Source: #11829.

Proposed by CYFS3 on September 23. At merge: 107 files, 26,711 lines added, 907 lines deleted.

The new board directory is bsp/gd32/arm/gd32h77d-ginopi. Main controller GD32H77DIW, Cortex-M7, 600MHz.

Onboard 8MiB GD25Q64 QSPI Flash, 32MiB 16-bit SDRAM, plus a GD32VW553 AT Wi-Fi module on uart4.

Drivers include LCD, OV7670 camera, GT911 touch, QSPI Flash filesystem, ENET1 RMII, and USB high-speed port. The default .config enables only serial and PIN; the rest are enabled via menuconfig as needed.

Gino Pi is the first GD32H77D ecosystem development board jointly launched by RT-Thread and GigaDevice; its official product page went live on September 8. The board defaults to a 600MHz clock, and the sample program toggles PC4 every 500ms.

Assessment: This is a flagship board co-built by the vendor and the community, not a third-party port. The basis: the board product page is hosted on the RT-Thread official site, and the BSP provides both GCC and MDK5 project sets.

3.2 STM32F103C6 added to blue-pill board support (11-24)

Date: 2026-11-24 21:41 (merged). Source: #11850.

STM32F103C6 is the smaller variant of the C8, with 32KB Flash and 10KB RAM. The change extends Kconfig, the linker script, and rtconfig.py so the same blue-pill board can select the small-capacity chip.

Total 8 files, 138 lines added, 25 lines deleted. The same batch also fixed an incorrect LED pin in the README: PB2 should be PC13.

Assessment: This brings a low-cost board into the mainline. The basis: the same BSP now covers both C6 and C8 capacities.

3.3 SWM341 CAN receive truncates to classic frame length (11-24)

Date: 2026-11-24 15:04 (merged). Source: #12076.

The driver copies data directly by the DLC field, so a DLC greater than 8 overruns the 8-byte buffer. The change clamps the length to the classic frame limit.

Two files, 8 lines added. Author cms19859230182-lang, also the submitter of the Allwinner V861 five-PR proposal.

Assessment: This is a read-side boundary fix that does not change message semantics. The basis: only the length is clamped; the DLC field itself is untouched.

3.4 Four small fixes: x86 toolchain, AF_NETLINK, ROMFS alignment, macOS docs (11-24)

Date: 2026-11-24 15:05 to 21:24 (merged). Source: commit list.

The x86 board README swapped the toolchain download URL, a one-line change.

The netdev AF_NETLINK path had a build error fixed, about three lines each in two files. The ROMFS generator in tools now aligns binary entries after UTF-8 filenames, 41 lines added, 15 lines deleted.

The macOS QEMU quick-start doc fixed PATH expansion and the restart script, author bernard.

Assessment: All four are reproducibility issues. The basis: each can be hit directly in a fresh environment and is unrelated to functionality.

IV. Toolchain and SDK: Env Pilot enters the plugin marketplace

4.1 Env Pilot 0.1.2 released as a plugin package (11-24)

Date: 2026-11-24 18:54 (released). Source: Release.

Package name org.rt-thread.env-pilot-0.1.2-py3-none-any.epack, 1,551,793 bytes. 3 downloads as of this report’s verification.

The plugin describes itself as an orchestration and execution workbench for local Claude Code, targeting Windows and Linux. It declares three capabilities: commands, service, webui.

Compatibility is stated as env 2.0.2 up to before 3.0, Python 3.7 and up. The package carries a SHA-256, and the index stores the same value.

Assessment: Env is starting to ship incremental features as plugins rather than stuffing them into the main body. The basis: the plugin package goes through its own Release, with versioning decoupled from the Env main body.

4.2 Plugin directory grows from one entry to two (11-24)

Date: 2026-11-24 18:56 to 19:07 (commit and merge). Source: sdk commit, plugin index.

The index array in env-plugins/index.json adds org.rt-thread.env-pilot. The entry sits alongside the existing org.rt-thread.kconfig.

The kconfig plugin remains at 0.1.34, released November 5. The README states that the marketplace reads this directory by default and that plugin packages just need to be placed in a GitHub Release, with no marketplace server required.

Assessment: This is the second iteration of a serverless plugin marketplace. The basis: the index lists only directory names, while the actual download URLs and checksums live in each plugin’s own index.json.

Assessment: The blocker has shifted from DTB generation to build matrix registration. The basis: this round’s comments landed on a different point, but both point to the same thing: a clean checkout must compile on its own.

VI. Industry Application Observations: Automotive-Grade and HMI Tracks

6.1 The QEMU-first automotive-grade path (11-24)

Date: 2026-11-24 (this publication’s assessment). Source: Renesas RH850/U2C product page.

RH850/U2C is a Renesas 28nm automotive-grade MCU. The G4KH core runs up to 320MHz, configurable for dual-core lockstep, with safety level up to ASIL D.

Official applications listed are chassis, body management, battery management, and motor control. RT-Thread this time only goes as far as QEMU simulation, with the board named qemu-rh850-u2c and no real hardware record. Serial support is also V1 only.

Assessment: This stakes out an entry point first, not a production-grade port. The basis: both the toolchain and the emulator are provided by the same external company, and there is no vendor co-maintenance marker on the repo side.

6.2 GinoPi points to graphical interaction (11-24)

Date: 2026-11-24 (this publication’s assessment). Source: Gino Pi product page.

GD32H77D has MIPI DSI, LCD-TFT, camera interface, and an image accelerator. The board drivers include all three of LCD, OV7670, and GT911, plus SDRAM and a QSPI Flash filesystem.

This combination targets HMI panels, handheld devices, and vision capture, not low-power sensor nodes.

Assessment: The mainline is filling in mid-to-high-end graphical boards. The basis: display and capture dominate this board’s driver list, while the default config enables only serial.

VII. Summary and Trend Observations

7.1 16 merges in a single day, more than triple the previous day

6 on November 23, 16 on November 24, 22 over the two days. The six security proposals were authored on September 22 and sat for two months before merging.

7.2 New architectures bring long-term maintenance cost

RH850 entered three places: libcpu, bsp, and CI, so future kernel changes will be gated by this pipeline once. The author also submitted two upstream fixes, to picolibc and mem.cfg, showing that the porting process in turn fixed shared code.

7.3 Security hardening centers on buffer boundaries

Four of the six proposals relate to lengths, offsets, and terminators. This matches the five issues closed in the same period, with a highly consistent defect type.

7.4 Env shifts toward pluginization

Env Pilot is the second plugin and the first with a webui. Plugin packages and the Env main body release separately, so subsequent features can iterate independently.

7.5 The news side stays silent

The official news API’s latest entry is still November 6, and the official site’s news center’s latest is November 3. The Google News three-day window has only 4 generic CSDN tech pieces, none with RT-Thread in the title. All information in this issue comes from code and releases.

Limitations note: RH850 has only QEMU verification records; no real hardware testing was seen. The official news API returns only 5 entries, with no new ones in the window. Google News matching for RT-Thread is unreliable; the 4 results in the Chinese three-day window were all generic embedded pieces and have been excluded.
