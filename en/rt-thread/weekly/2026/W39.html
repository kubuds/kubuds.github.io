RT-Thread Weekly Report (2026-09-21 ~ 2026-09-25)

2026-09-25 Kubuds

Reporting period: Monday, September 21, 2026 to Friday, September 25, 2026 — 5 working days, 5 publication days Sources: The daily RT-Thread intelligence briefings for this period (09-21, 09-22, 09-23, 09-24, 09-25; 5 issues total); additionally includes a GitHub organization window check through the morning of 09-26 Editorial note: This period covers five dimensions — the RT-Thread kernel and releases, toolchain, ecosystem vendor adaptation, community activities, and industry applications. All items come from verified sources in the daily briefings for the period.

1. This Week’s Highlights

  • Gino Pi ecosystem full-stack integration completed in one week (09-21 ~ 09-23): The mainline BSP for the GD32H77D development board Gino Pi entered review as a series of proposals (19 commits, 142 files, ~26,000 net lines added, covering board-level skeleton, full peripheral suite, and demo projects); on the same day, the device support package added GD32H77x_78x support across two repos, and the AT component gained Wi-Fi and TCP socket support for the onboard GD32VW553 module. Previously, the Studio SDK side had already added J-Link dependencies and link script fixes. The board’s transition from “Studio and vendor downstream” to “mainline maintainable” marks the most substantive step this week in the GigaDevice–RT-Thread collaboration.
  • Three RISC-V board support additions in one day (09-24 ~ 09-25): The WCH CH32V203C8T6 BSP was merged into mainline (Qingke V4B core, ~2 days from proposal to merge); the Espressif ESP32-C6-DevKitC-1 BSP proposal entered review, with esp-idf package C6 build sources submitted in parallel; the community released an RT-Thread Nano IDF-free port project (ESP32-S31 dual-core RISC-V, 320 MHz). Three RISC-V chips appearing simultaneously in the board support chain signals RISC-V’s growing share in the RT-Thread board ecosystem.
  • 13 merges into mainline throughout the week: Monday morning batch of nine (network AT channel hostname validation tightened, SDIO double memory leak fix, STM32H7 UART4 receive DMA, GD32 USART pin correction, Rust target selection and QEMU documentation, etc.), Monday afternoon two (Infineon PWM macro mismatch, CherryUSB N32H4x USBFS support), Wednesday CI pipeline adjustment (clang-format commits no longer skip the pipeline), Thursday CH32V203 BSP — all landed.
  • 22 new proposals and 2 defect reports in the review queue this week (09-21 ~ 09-24): Including a seven-part hardening series for legacy defects (bus mutex, power management, USB host, IPC, block device, OpenAMP, virtio), Nations Technology N32H timer completion (39 files, ~4,000 lines), lwip-nat port allocation and lwip-dhcpd missing header fixes, rt_vsnprintf width semantics defect fix, etc. Quality and fix contributions form the bulk.
  • Three package index merges (09-24): CanopenNode v1.2.0 completed nine Kconfig refactors (CiA 401 device switches consolidated into a general device profile system), a new “virtual sensor” package added (simulated data generation, optional MQTT reporting), and the AI Agent package gained MQTT tools and automatic rt_vsnprintf capability detection.
  • Renesas Titan Mini edge vision dual advancement (09-22, 09-24): The OpenMV project first completed SDRAM timing and memory pool optimization (Tiny YOLOv2 INT8 single-frame inference reduced from 156.10 ms to 58.49 ms; YOLOv8n 256×256 reduced from 186.54 ms to 38.33 ms), then connected the onboard 800×480 RGB screen, adding LCD display and color block tracking examples; industry media followed up with coverage in the same period.
  • Toolchain and supporting ecosystem updates across multiple points (09-18 ~ 09-22): RT-Thread Studio companion switched to v5.3.0 kernel, J-Link debugger upgraded to V9.76a (cross-year update); STM32H7 device package and HAL driver package dual release (v1.10.7 / v1.11.6); third-party GDB debugging framework GDR released 2026.03.
  • Official channels silent for the 32nd to 36th day; events focused on the Industry Expo and industry-education: Industry Expo Workshop details announced (October 13 Shanghai special session, 25 smart car teaching kits), Lingang “Scenario Express” RT-Thread closed-door matchmaking session supplementary registration, RSOC26 summer camp tutorial systemization launched; no new additions to the official news feed all week.

II. Kernel and Release Dynamics

Releases and Mainline

  • No new releases: The latest official release remains v5.3.0, published on 09-10; this cycle is the normal post-release digestion period, with work focused on the review queue and supporting follow-ups.
  • Merge cadence: 13 merges over the week followed a “front-loaded peak, low-frequency throughout” pattern — nine merges on Monday morning and two in the afternoon formed the peak, with one each on Wednesday and Thursday, while the mainline was silent the rest of the time.
  • Supporting follow-up (09-20): RT-Thread Studio’s SDK index and bundled kernel source were switched to v5.3.0, and the debugger component upgraded J-Link to V9.76a (the previous version was V8.48 from July 2025); the supporting follow-up was completed ten days after the v5.3.0 kernel release.
  • Toolchain status: No new commits or releases in the Env toolchain window (latest is v2.0.2 from 09-16); the package index repository saw no activity apart from three merges on 09-24.

Mainline Fixes Merged This Week (chronological)

  • Network AT channel hostname validation tightened: overly long hostnames resembling numbers are now rejected outright, eliminating a stack buffer overflow write risk (09-21, #11782)
  • Two SDIO memory leak fixes: temporary memory in the CIS tuple branch was not freed (09-21, #11780), and the driver deregistration node leak was closed out (09-21, #11806)
  • STM32H7 general-purpose DMA gained the missing UART4 receive-side channel definition (09-21, #11808)
  • Block device partition component log format specifiers and argument types corrected (09-21, #11809)
  • GD32 series USART TX/RX pin initialization corrected — TX switched to alternate-function push-pull, RX to pull-up input — covering E50x through F30x (09-21, #11804)
  • Rust toolchain Cortex-M33 hard-float target detection corrected (09-21, #11811)
  • Two items: QEMU Linux quick-start guide and removal of high-risk commands from documentation (09-21, #11790 / #11793)
  • Infineon PWM macro mismatch fix closed on the mainline, sharing the same root cause as the evaluation board BSP fix (09-21, #11802)
  • CherryUSB added device-side USBFS support for Nations Technology’s N32H4x series (09-21, #11764)
  • clang-format auto-commits no longer skip continuous integration; formatting results are now part of the build verification pipeline (09-23, #11830)
  • WCH CH32V203C8T6-EVT-R0 BSP merged, including the D6 vector table, 64KB/20KB linker scripts, and two shared driver fixes (09-24, #11827)

Security and Defects

  • rt_vsnprintf width semantics defect and fix (09-24): minimum width was mistakenly treated as maximum width for truncation (e.g. %3s truncated “abcdef” to “abc”; left-aligned and asterisk-width variants were affected as well); the defect report and fix proposal were submitted the same day, with the fix covering both the standard and tiny implementations plus unit tests (3 files), currently under review.
  • Seven-fold hardening of legacy defects (submitted 09-22, under review): a single contributor submitted seven fixes at once, covering two-wire serial bus control and transfer mutual exclusion, power management paired restore by suspend mode, USB host interface count bounds, IPC message queue path terminator bounds, block device logical partition out-of-bounds read/write, STM32 OpenAMP receive bounds and ring wraparound, and virtio input offset validation; all reference defect reports filed months earlier and include GCC 16.1 build and boundary-case verification.
  • bluepill BSP documentation defect report (#11818): the quick-start guide lacks the step to regenerate the MDK project, so following the documentation does not compile.
  • Four security-related issues from the previous Thursday (tmpfs, message queue, pread, finsh): no corresponding per-item fix commits appear in the public record, and there were no updates this cycle.

Review Queue Observations

  • Two batches of single-night concentrated submissions formed the bulk of new additions: eight items in the early hours of 09-21 to 09-22 (N32H timer completion spanning 39 files and roughly four thousand lines, STM32 Ethernet ops adaptation and adcv2 log levels, lwip macro switchover, RA6W1 resource allocation, ESP32-C3 Windows build, unit test performance case clock dependency, bluepill documentation, etc.); eight items on the night of 09-22 (the seven-item defect hardening series plus the CH32V203 BSP).
  • Network stack fixes concentrated: lwip-nat port allocation defect and lwIP 2.1 adaptation (#11831), lwip-dhcpd missing string.h header (#11835), netdev AF_NETLINK build fix (#11828).
  • Large proposals remain pending review: the GD32H77D GinoPi peripheral series (#11829, 142 files), the network protocol stack upgrade (lwip 2.2.1) on a long wait, and the N32H timer completion.
  • Build and cleanup items: ipc SConscript redundant macro cleanup (#11832), bluepill documentation fix (#11817); plus an ESP32-C6 board-level proposal (#11836, see Chapter III).
  • Old proposal revived: #10689 (created in September 2025) resumed discussion at the end of the window.

III. Ecosystem and Vendor Adaptation

Vendor BSPs

  • GigaDevice (GD32H77D / Gino Pi): The mainline BSP series proposal has entered review — 19 commits, 142 files, ~26,000 net lines added, covering the board-level skeleton (project, linker script, rtconfig), a full peripheral suite (Ethernet, USB host and device, SDRAM, hardware I2C, SPI3, PWM, SDIO and filesystem, RTC and alarm, watchdog, CAN and CAN FD, OSPI Flash, MIPI LCD, GT911 touch, OV7670 camera, LVGL) and demo projects; UART4 AT communication and MAC query for the onboard GD32VW553 wireless module have been verified, while Wi-Fi association remains pending (disabled by default).
  • GigaDevice (device packs and networking components): The dual repos gd32-arm-cmsis and gd32-arm-series add GD32H77x_78x support (CMSIS device layer and new peripheral library); at_device adds GD32VW553 Wi-Fi device and TCP socket support.
  • Renesas (RA8P1 Titan Mini): The OpenMV project completed external SDRAM timing/clock configuration and expanded the on-chip SRAM main garbage collection pool (1344 KiB to 1472 KiB), with measured inference time reductions across three models (up to ~4.9x); subsequently added an RGB interface 800×480 screen driver (RGB565) with LCD basic display, camera preview, and red color-block tracking examples (17 files, ~1200 lines).
  • WCH (CH32V203): BSP merged into mainline (see Chapter II), accompanied by fixes to drv_usbd’s USBFS DMA timing and the drv_iwdt watchdog shared driver; the D6 variant has only 64KB Flash / 20KB SRAM, so USB and other peripherals must be traded off by capacity.
  • Espressif (ESP32-C6 / ESP32-S31): The ESP32-C6-DevKitC-1 BSP proposal (40 files, +9492 lines) and the esp-idf software package C6 build source proposal were submitted for review in parallel (the same contributor as the CH32V203 submission); the community ESP32-S31 IDF-free port project has undergone reproducible build verification (89 tracked files, byte-for-byte identical image).
  • Infineon (PSoC6): The PWM macro mismatch fix has been closed in mainline; the evaluation board BSP has also completed cross-project corrections.
  • GD32 downstream repo: PR #71 driver update branch refreshed and entered review interaction (GPIO initialization version updates for USART, SPI, and two-wire serial bus drivers), not yet merged back to mainline.

Software Packages and Middleware

  • Triple package index merge (09-24): CanopenNode v1.2.0 (nine Kconfig refactors, generic device profile system, logical device registry and transport contract), the new “virtual sensor” package (simulated data generation, optional MQTT reporting), and the AI Agent package (MQTT tools, automatic detection of rt_vsnprintf capability by kernel symbol to avoid duplicate definitions in 4.1.x kernels); three proposals backlogged for about two weeks were merged on the same day.
  • STM32H7 device pack and HAL driver pack dual release (09-18): Device pack v1.10.7 (added TIM23 / TIM24 instances, fixed GPIO bit definition typo), HAL pack v1.11.6 (incorporated ~20 upstream syncs, covering USB zero-length packets, Ethernet 10M speed, SDMMC clock, I2C deadlock, AES-GCM/CCM, FDCAN filtering, DMA callbacks, etc.).
  • GDR 2026.03 (09-22): The third-party GDB debugging framework adds an RT-Thread object summary command and a git-style structured help system, and fixes the issue where initialization policy validation failure terminates the session; supports RT-Thread 3.1.x / 4.0.x / 4.1.x, with Cortex-A9 and RV64 targets verified end-to-end.

  • Items already covered at the end of the previous period (media-perspective roundup, CIIF Workshop recruitment post) are not re-listed as entries this period, and are only presented incrementally when information updates.
  • The merge form of the Gino Pi mainline proposal (whether split, peripheral trade-offs) is subject to the review conclusion; GD32VW553’s Wi-Fi association and TCP / MQTT traffic have not yet been verified (per the commit description).

IV. Official and Community Activities

  • CIIF Workshop details announced (09-22): The 26th China International Industry Fair is scheduled for October 12–16 at the National Exhibition and Convention Center (Shanghai). RT-Thread’s “AI Edge Smart Car Hands-on Workshop” will hold a dedicated session on October 13 from 13:00 to 17:00, with 25 smart car teaching kits, two people per group, covering hardware detection, SLAM mapping, autonomous navigation through to AR comprehensive exercises; the site will also display industrial control equipment, mobile robots, embodied intelligence, and flight control units.
  • Lingang “Scenario Express” Second Session (held 09-18, reported 09-20): RT-Thread’s closed-door demand matchmaking meeting conducted targeted negotiations in a “chain leader poses the problem, enterprises solve it” model, focusing on AI large models and agents entering factories, demonstrating its continued participation in Lingang’s industrial and smart manufacturing ecosystem scenario matchmaking.
  • RSOC26 Summer Camp tutorial systematization (09-23): Updated “Chapter 1: Development Environment, BSP Configuration, and Device Model,” using the Spark-1 (STM32F407ZG) to walk through Studio environment deployment, project structure and device model, and GPIO and FinSH verification.
  • Forum content: The MCU low-level series updated a long-form article on GNU linker scripts (09-22, the third installment following probe-rs debugging and C runtime startup); older competition and application posts remain editorially maintained.
  • Official news API: No additions for the thirty-second through thirty-sixth consecutive days (zero updates all week); the official website news list page still returns a loading failure and cannot be directly verified, with information first released via the forum, store, and industry media channels.

V. Industry Applications and Business Trends

  • Community RK3576 heterogeneous AMP networking practice (09-21): Stripped one A53 from the Linux side and handed it to RT-Thread, which took over the GMAC1 Ethernet controller entirely for independent send/receive; the author identified and fixed three root causes — MDIO clock calculation, PHY reference clock timing, and a crash from sustained ping heap — offering direct reference value for real-time-side independent networking and edge gateway directions.
  • CIIF exhibit lineup: Physical exhibits such as industrial control equipment, mobile robots, embodied intelligence, and flight control units constitute the most recent industry-side activity this period, forming a “from low-level system to AI application” display loop with the Workshop.
  • Gino Pi sales operations: The official store sales post was updated, clarifying the purchase channel and the first-batch user cashback review campaign.
  • Deployment cases: No new mass-production, commercial, or partnership deployment case reports this period; no new deployment news in the robotics and embodied intelligence direction, consistent with the previous week’s pace.

VI. Trend Observations

  • RISC-V becomes the main driver of board-level additions: Within one week, WCH CH32V203 merged, Espressif ESP32-C6 submitted for review, and ESP32-S31 IDF-free port appeared in succession, plus GigaDevice GD32VW553 wireless module support — nearly all new board-level link activity falls on RISC-V chips.
  • The “vendor release to mainline” path takes shape: Gino Pi went from Studio SDK index, debug chain completion, and device pack groundwork to a mainline BSP proposal within one week; chip-vendor-led submissions with parallel Studio and mainline efforts are becoming a replicable dev-board landing cadence.
  • Quality-oriented fixes become the mainstay of review: Seven consecutive hardening fixes for legacy defects, rt_vsnprintf width semantics, lwip port allocation, and missing headers were all proactively submitted by the community; low mainline frequency (13 merges) coexists with high review frequency (22 new proposals), as the codebase enters a digestion and refinement phase.
  • Edge vision moves from performance to functionality: After completing inference speedup, Titan Mini OpenMV immediately connected screens and vision examples, shifting the demo form from “benchmarking” to “screen-equipped and interactive,” with follow-up from industry media.
  • Tools and supporting ecosystem follow steadily: Studio syncs with v5.3.0, J-Link upgrades across years, GDR releases a new version — the toolchain and debugging ecosystem around the major version remains active.
  • Official communication silence continues: The official news API has been silent all week (days thirty-two through thirty-six), with external information continuing to be first released via GitHub, the forum, the store, and industry media, creating a clear contrast between engineering-side activity and official channels.
