RISC-V 위클리 리포트 (2026-08-29 ~ 2026-08-31)

2026-08-31 Kubuds

병합 범위: 8월 29일(토), 8월 30일(일), 8월 31일(월) 3일 데일리 리포트 정리 날짜: 2026-08-31

합계: 23건(중복 제거 후)

1. 오픈소스 커뮤니티와 소프트웨어 생태계(6건)

  • [08-29] 1.1 Espressif esp-nn 1.3.1 릴리스, RISC-V 커널 완전연결층 벡터화 최적화
  • [08-30] 1.1 오픈아톰(OpenAtom) Zijin 존 OPC 인큐베이션 액션 플랜 출범, RISC-V 오픈소스 칩 산업 혁신 센터 쑤저우 시범 착수
  • [08-30] 1.2 OpenTitan 오픈소스 보안 칩, 스페인어권 기술 매체 특집 보도, 프로덕션 배포 배경 회고
  • [08-31] 1.1 Linux 7.3-rc1 릴리스: RISC-V 인터럽트 컨트롤러 코드 리팩터링, 범용 ACPI IRQ 프레임워크로 편입
  • [08-31] 1.2 openKylin 3.0 정식 릴리스: 4대 아키텍처 동일 소스, RISC-V 적응 범위 최대, RVA23 및 RVV 최적화 지원
  • [08-31] 1.3 오픈소스 프로젝트 2건: ClickDOOM, ClickHouse SQL로 RISC-V 시뮬레이션하여 1993 DOOM 구동; LabWired Core 펌웨어 결정론적 시뮬레이터

2. 제품과 생태계 동향(5건)

  • [08-29] 2.1 SiFive BigSky 납품 단계 진입: 첫 시스템이 이미 선도 고객사에서 워크로드 구동, Futurum 애널리스트 해석
  • [08-30] 2.1 StarFive FangTianshu-100 정식 납품: 중국 내 최초로 납품 가능 상태에 도달한 서버급 RISC-V CPU IP
  • [08-31] 2.1 XCENA MX1: Hot Chips 2026에서 수천 개 RISC-V 코어의 CXL 컴퓨팅 스토리지 디바이스 상세 해설
  • [08-31] 2.2 인도 Aheesa Vihaan 1차 테이프아웃 점등: 64비트 RISC-V 네트워크 SoC, 첫 하드웨어 검증 통과
  • [08-31] 2.3 Radxa Linkr 생태계 참고: USB 메모리 크기 IP KVM, 메인 컨트롤러에 RISC-V 코프로세서 포함

3. 국내 팀 동향과 심층 분석(7건)

  • [08-29] 3.1 XiangShan: 68건 이상 커밋, 월 경계 개발 성과 대규모 병합(ZICBO, Zvknha/Zvbb, 벡터 유닛 리팩터링, AMOCAS)
  • [08-29] 3.2 SpacemiT: 모델 라이브러리 문서 도구 신규 저장소 model-zoo-file2md 0.1.1 릴리스
  • [08-30] 3.1 Nuclei 신삼판 혁신층 상장(875127): 중국 RISC-V CPU IP 선두주자 자본시장 진입
  • [08-30] 3.2 SOPHGO sophon-tools 릴리스 전 보안 강화, SophLiteOS v2.2.6 등 다수 수정 병합
  • [08-30] 3.3 XiangShan: Ftq 프리페치 성능 튜닝, KunminghuV2 CI 옵션 및 Deterload 도구 H/V 확장 지원
  • [08-30] 3.4 SpacemiT P3 PMIC 데이터시트 문서 반영; Revyos SG2044 펌웨어 업데이트(브리핑)
  • [08-31] 3.1 국내 팀 GitHub 동향 점검: 모니터링 기간 전반적으로 조용, SOPHGO/SpacemiT만 소폭 반복 개선

4. 체화 지능과 로봇 특별 챕터(5건)

  • [08-29] 4.1 모니터링 기간 내 RISC-V 체화 지능 신제품 없음; Hugging Face 생태계 Microduck 이족 보행 로봇 출시(RK3566/ARM, 생태계 참고)
  • [08-30] 4.1 Kaihong M-Robots OS 3.0 Beta 출시: 오픈소스 OpenHarmony 로봇 OS, 중심을 군집 지능으로 전환
  • [08-30] 4.2 글로벌 체화 지능 로봇 산업 엑스포 폐막, 3일간 39억 위안 성사 의향 달성
  • [08-30] 4.3 모니터링 기간 내 여전히 RISC-V 체화 지능 하드웨어 신제품 없음(구도 지속)
  • [08-31] 4.1 모니터링 기간 내 RISC-V 체화 지능 하드웨어 신제품 없음; 소프트웨어 측 openKylin 3.0 휴머노이드 로봇 등 적응 완료
