RISC-V 위클리 리포트 (2026-08-12)

2026-08-12 Kubuds

데이터 출처: 로컬 데일리 리포트(8/11, 8/12) 집계 + GitHub 조직 커밋 추가 수집(8/6-8/10 모니터링 기간, XUANTIE-RV / OpenXiangShan / Nuclei-Software / sophgo / spacemit-com 등) + 교차 모니터링 기간 보도 추가 기록. 설명: 로컬 데일리 리포트 시스템은 8월 11일 K3 머신에서 이전되었으며, 8/6-8/10에는 일별 데일리 리포트가 없어 해당 구간은 GitHub 커밋과 8/10-8/11의 교차 모니터링 기간 보도를 기준으로 했고, 중복 제거 및 병합을 최대한 반영했습니다.

1. 오픈소스 커뮤니티 및 커널/규격 동향

1.1 RVA23.1 및 RVB23.1 Profile 공개 리뷰 공식 시작

날짜: 2026-08-11　출처: HN / RISC-V isa-dev 메일링 리스트

RISC-V 국제 재단이 RVA23.1 및 RVB23.1 Profile 공개 리뷰를 시작하고 전 커뮤니티를 대상으로 피드백을 모집합니다. 이는 RVA23/RVB23 시리즈 규격 발표 이후 첫 유지보수성 반복 버전으로, A류 애플리케이션과 B류 기준 Profile의 세부 개정 및 정오표 업데이트를 포함하며, 툴체인, 커널, 컴파일러 생태계의 적응 속도에 직접적인 지침을 제공합니다.

1.2 QEMU 11.1 릴리스: RISC-V 빅엔디언 지원 및 K230 보드 레벨 에뮬레이션 추가

날짜: 2026-08-12(릴리스 08-11 16:11 UTC)　출처: Linuxiac 미러 검증

QEMU 11.1의 최대 특징은 RISC-V 빅엔디언(big-endian) 타깃 지원으로, 이는 RISC-V 런타임에서 제어 가능한 엔디언 능력의 실현에 해당합니다(Codethink가 앞서 이 주제로 연구를 진행한 바 있습니다). RISC-V 측 동시 강화: Kanzhi K230 개발 보드 지원 추가, OpenSBI 1.8.1로 업그레이드, Tenstorrent mvendorid 지원 추가, 그리고 대량의 IOMMU, 인터럽트 처리, 페이지 테이블 순회 및 벡터 명령어 문제를 수정했습니다. RISC-V 커널/배포판 개발자는 에뮬레이터에서 빅엔디언 소프트웨어 스택을 우선 검증할 수 있습니다.

1.3 XiangShan: 일주일간 타이밍 및 정확성 수정 시리즈

날짜: 2026-08-06 ~ 08-10　출처: GitHub OpenXiangShan/XiangShan

XiangShan은 이번 주 여러 수정을 병합했습니다: FTQ/ICache meta 읽기 포트 타이밍(#6281), Phr의 s1/s3 기간 업데이트 타이밍(#6263), vbop 핸드셰이크 로직 정리(#6163), WriteBuffer 동일 항목 읽기/쓰기 충돌(#6315), IFU 예외 시 s1_instrCount 계산(#6301), StoreUnit이 이중 TLB 히트 시에만 UnalignQueue로 paddr 전송(#6332). 또한 XiangShanLab 저장소에 RISC-V spec/gap 스킬 도구가 추가되었습니다(8/10). 엔지니어링 측은 지속적으로 추진 중이며, 아키텍처 업그레이드(3.2 KaixinHong 참조)를 지원합니다.

1.4 RISC-V 규격 인프라 저장소 활발

날짜: 2026-08-11/12　출처: riscv-unified-db / riscv-arch-test

riscv-unified-db(규격 기계 판독 가능 데이터베이스)에 여러 의존성 유지보수 커밋이 병합되었고, riscv-arch-test는 Ubuntu 24.04 Docker 이미지를 업데이트했습니다. 규격 엔지니어링의 정규 리듬에 속하며, RVA23.1 리뷰와 함께 추진됩니다.

1.5 커뮤니티 회고 글 《RISC-V: They Should Have Known Better》 화제

날짜: 2026-08 상순　출처: HN / dmitry.gr

베테랑 임베디드 개발자 Dmitry.GR가 장문을 발표하여 RISC-V의 인터럽트 지연, 명령어 밀도, 주소 지정 모드 등 저수준 설계상의 결함을 비판하며, 일부 임베디드 지표가 수십 년 전 아키텍처보다 못하다고 주장했습니다. 이 글은 HN/Reddit에서 광범위한 논의를 일으켰고 Sina 등 중국어 매체에서도 전재되었으며, 이번 주 커뮤니티 차원에서 가장 중요한 견해성 사건입니다(의견 글에 속하며 공식 입장이 아닙니다).

1.6 labwired-core: ESP32-C3(RISC-V) 펌웨어 에뮬레이션 기능 강화

날짜: 2026-08-12　출처: GitHub w1ne/labwired-core

Rust로 작성된 결정론적 펌웨어 시뮬레이터 labwired-core(59 stars)가 15개의 커밋을 머지: ATmega328P Nano 트윈 추가, ESP32-C3(RISC-V)의 DHT 단일 버스 타이밍 수정, 리소스 메트릭 기능 추가. RISC-V MCU의 “펌웨어 수준 시뮬레이션/가상 하드웨어” 툴체인 내 적용 범위가 확대되고 있다.

2. 제품 및 생태계 동향

2.1 Comu: 6달러 USB 포트형 RISC-V 개발 보드

날짜: 2026-08-10　출처: CNX Software

친헝(CH32V203, RISC-V 코어 MCU) 기반의 초소형 개발 보드 Comu는 전체 보드가 USB 인터페이스 안에 내장될 수 있으며(USB 메모리 형태), 가격은 약 6달러로 RISC-V MCU 진입 장벽을 크게 낮추었고 HN에서 논의되었다.

2.2 Dabao(Baochip-1x, DEF CON 34 배지 칩) 생태계 빠르게 형성

날짜: 2026-08-10　출처: Adafruit Blog

DEF CON 34 배지에 탑재된 Baochip-1x RISC-V SoC에 MicroPython 실험적 포팅이 이루어졌다. GitHub에는 이미 mainline Linux 부팅 시도(baochip-linux), 베어메탈 DOOM 포팅(baochip-doom), 베어메탈 C SDK(dabao-sdk)가 등장했다. 일주일 만에 “Linux 부팅 + DOOM 실행 + SDK 출시”가 집중된 것은 RISC-V 오픈소스 하드웨어 커뮤니티 활성도의 전형적인 샘플이다.

2.3 Zunjie V800 스마트 시트에 ESWIN RISC-V 차량용 AI MCU 탑재

날짜: 2026-08-10　출처: KuaiKeJi / Phoenix Net

HarmonyOS Smart Mobility의 Zunjie V800이 공개되었으며, 완전 능동형 자기적응 스마트 시트의 핵심 연산은 ESWIN EAM2011이 담당한다. 이는 중국 최초로 경량 AI 애플리케이션을 지원하는 차량용 MCU로, 자체 개발한 32비트 RISC-V 코어를 탑재해 전 과정 현지화 연구개발 및 양산을 완료했다. 이는 중국산 RISC-V 차량용 칩의 규모 있는 차량 탑재를 보여주는 상징적 사례다.

2.4 제5회 디수이후 중국 RISC-V 산업 포럼 사전 공지(8월 13일 개최)

날짜: 2026-08-07(공지)　출처: Sina Finance

제5회 디수이후 중국 RISC-V 산업 포럼이 8월 13일 개최될 예정이며, 10종의 중국산 첨단 칩이 집중 공개된다(구체적 성과는 다음 주 위클리 리포트에서 다룬다).

3. 국내 팀 동향

3.1 Nuclei: 자본화 추진 + 디버그 툴체인 생태계 + Hummingbird FPGA 수정

날짜: 2026-08-06 ~ 08-11　출처: Sina Finance / Nuclei-Software GitHub

세 가지 축이 병행된다. 8월 10일 전국중소기업주식거래시스템에 신삼판 혁신층 상장을 신청하고 4,200만 위안을 사모 모집했다. 8월 11일 lauterbach-startup 저장소(Lauterbach TRACE32 디버거 시작 스크립트, 국제 디버그 툴체인 적응)를 추가했다. e603_hbird(Hummingbird E203 관련)에 DDR 클록 계층 및 bitstream 등 FPGA 수정이 머지되었다(8/6-8/7). “IP 선두 기업의 자본화”와 “생태계 툴체인”이 두 축으로 동시에 진행되고 있다.

3.2 카이신홍(샹산 IP 상용화 주체): 1억 위안 초과 시드 라운드, 국유자본+선도 산업투자 공동 지원

날짜: 2026-08-11/12　출처: 관점망 / 신징보

카이신홍이 1억 위안 초과 시드 라운드 자금 조달을 완료했으며, 자금은 샹산 IP 코어 아키텍처 업그레이드에 투입된다. 투자자 명단은 이후 공개되었다: 궈카이창신, 청퉁창신, 중커창싱, 중관춘과학성, 치항펀드, 궈타이창투 등 국유자본 및 선도 산업투자 기관. 샹산 IP 상용화는 동시에 국가급 정책 자본과 지역 산업 자본의 보증을 받았다(이번 주 이틀 연속 보도, 하나로 통합).

3.3 이쓰웨이컴퓨팅: 차규격 탑재 + 소비자급 AI 프라이빗 클라우드 양 라인 동시 실현

날짜: 2026-08-10　출처: 콰이커지 / 왕이(집계) / 후베이경신청(집계)

이쓰웨이컴퓨팅은 이번 주 여러 동향이 겹쳤다: 차규격 측 EAM2011이 Zunjie V800 스마트 시트에 적용되었고(2.3), 소비자 측에서는 지공간(ZSpace)과 협력하여 국산 AI 프라이빗 클라우드 NAS를 개발, 이미지 소재의 AI 처리가 전부 로컬에서 실행된다. 그룹 소재 사업(이쓰웨이소재)은 65억 위안을 모집하여 12인치 웨이퍼 확장에 투입할 계획이다(2027년 1기 생산 개시). “RISC-V+AI”가 차규격과 소비자 양단에서 동시에 실현되고 있다.

3.4 쑤안넝(SOPHGO): SophLiteOS AI Agent 추가 + 툴체인 집중 수정

날짜: 2026-08-09 ~ 08-12　출처: GitHub sophgo/sophon-tools / zsbl

sophon-tools 모니터링 기간 내 다수 병합: SophLiteOS AI Agent 기능 추가(pbmssm LLM 포워딩, picoclaw-web-chat 내장 포함), LLM Agent 상호작용 능력을 엣지 시스템 툴체인으로 하향 이전 — K230/SG 시리즈 RISC-V SoC와 결합하여 “RISC-V 엣지 + LLM Agent”의 직접적 엔지니어링 진전에 해당; 그 외 pota_update/pmemory_edit 보안 수정, Docker 3개 이미지를 단일 이미지로 병합(용량 약 10GB) 등. zsbl 빌드 시스템 최적화: Linux-kernel 의존성 분리, 내장 dtb 증분 재빌드 수정.

3.5 진뎨시공(SpaceMiT): K3 생태 문서 및 엣지 AI 가속 추진

날짜: 2026-08-06 ~ 08-10　출처: GitHub spacemit-com

docs-ros는 K3 로봇 매니퓰레이터 ONNX 배포 가이드를 업데이트했고(#200), docs-buildroot는 K3 Secure Boot 가이드를 추가했으며, model-zoo-vision은 eigen-spacemit + OpenBLAS로 YOLOv8-Seg mask GEMM을 가속했다(#64). K3의 로봇/보안 부팅/엣지 AI 문서 스택이 8월 첫째 주에 집중적으로 보완되었다(참고: K3 플래그십 SoC는 8/13 디수이후 포럼에서 정식 발표 예정).

3.6 핑터우거(XUANTIE-RV): damo-rv-priv-ats 업데이트

날짜: 2026-08-06　출처: GitHub XUANTIE-RV/damo-rv-priv-ats

쉬안톄 DAMO(동적 메모리 할당 및 보호?) RV Priv ATS 저장소 업데이트: config 디렉터리 구조 조정(#21), CSR 인코딩을 사용하도록 테스트 업데이트(#22, 8/11). 쉬안톄 생태의 권한 및 주소 변환 측 지속적 반복에 해당.

4. 구현 지능 및 로봇

모니터링 기간 내 중대한 독립 뉴스는 없습니다. 인접 신호: ESWIN EAM2011의 Zunjie V800 탑재 인체 자세 인식 애플리케이션(센서 인식 + 동적 적응 기술 스택은 로봇 제어와 공용); SophGo SophLiteOS AI Agent가 RISC-V 로봇 두뇌에 더 가벼운 소프트웨어 기반을 제공; SpacemiT K3 로봇 매니퓰레이터 ONNX 배포 문서 업데이트. 8/13 Dishui Lake 포럼에서 임바디드 AI 관련 칩 신제품 발표가 예상되며, 회의 후 추적할 가치가 있습니다.

5. 요약 및 트렌드 관찰

  1. 규격 측면 검토 기간 진입: RVA23.1/RVB23.1 공개 검토 개시, QEMU 11.1에 RISC-V 빅엔디언 지원 반영, 규격에서 툴체인까지의 적응 경로가 폐쇄 루프를 형성 중.
  2. 중국산 RISC-V 자본화 가속: Nuclei NEEQ 혁신층 신고(모금 4200만 위안), Kaixin Hong 억 위안 초과 시드 라운드에 국유자본 참여, ESWIN 그룹 65억 위안 증산——IP/칩 업체들이 1차 및 2차 시장에 밀집 접촉.
  3. RISC-V 차량규격 및 엣지 AI 규모화 착지: EAM2011 Zunjie V800 탑재, SophLiteOS 내장 AI Agent, ESWIN AI 프라이빗 클라우드, 중국산 RISC-V가 “AI 착지” 방향에서 다방면으로 개화.
  4. 커뮤니티 생태계 활기 유지: 6달러 USB 개발 보드, DEF CON 배지 칩의 Linux/DOOM/SDK 생태계, Dmitry.GR의 RISC-V 성찰 장문이 업계 논의를 촉발——낮은 진입장벽 하드웨어가 가져온 신선한 인력과 아키텍처 저층에 대한 진지한 검토가 공존.
  5. 전망: 8/13 제5회 Dishui Lake 포럼(10종 중국산 칩 집중 공개, SpacemiT K3, Lanxin LX500 서버 CPU, Topus EA6530 등 포함)이 다음 주기 가장 중요한 산업 관찰 창구.
