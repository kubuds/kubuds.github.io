1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 NVIDIA, CUDA를 RISC-V 호스트 CPU로 이식하기 위한 명확한 요구사항 공개, SiFive 협력 시연 임박

날짜: 2026-08-23(Hot Chips 2026 튜토리얼 강연) / 09-01(ServeTheHome과 Chips and Cheese 심층 보도)　출처: ServeTheHome, Chips and Cheese(Chester Lam), Hot Chips 2026 의제(NVIDIA 공식)

NVIDIA는 Hot Chips 2026(스탠퍼드, 08-23~08-25) 일요일 튜토리얼 세션에서 Frans Sijstermans가 “RISC-V Profile and Platform for Interoperability With NVIDIA GPUs”라는 제목으로 강연을 진행하며, CUDA를 RISC-V 호스트 CPU로 확장하기 위한 로드맵과 요구사항 목록을 체계적으로 공개했다. 핵심 요점:

  • CUDA 현황: 2006년부터 이어진 병렬 컴퓨팅 플랫폼으로, 호스트 측은 현재 x86-64와 aarch64만 지원한다. 애플리케이션은 CPU와 GPU 모듈 사이에서 분할되고, 호스트 소프트웨어 스택은 복잡하며 이기종이다.
  • RISC-V 호스트 CPU에 대한 강제 요구 사항: RVA23 profile, RISC-V server SoC 및 server platform 규격 준수(RAS, 전용 보안 프로세서 등 기준선 포함), ACPI(UEFI Forum 2025-05가 ACPI 6.6에 RISC-V를 추가, RISC-V BRS 부팅 및 런타임 서비스 규격 2025-08 도입), PCIe 하드웨어 수준 I/O 일관성, PCIe peer-to-peer 통신. NVIDIA는 소프트웨어 바이너리 호환이 핵심 목표라고 강조하며 “최소 공통 분모” 문제를 피하고자 한다(벡터 확장의 프레디케이트 지원을 예로 듦).
  • NVLink Fusion 측면: 커스텀 CPU(RISC-V일 수 있음)가 NVLink C2C(약 88개 PCIe lane, CHI 일관성)를 통해 NVIDIA AI 플랫폼에 접속하며, 추가로 DOCA, NCCL 소프트웨어 스택과 NVIDIA의 심층 협력이 요구된다. SiFive가 RISC-V 측 NVLink Fusion CPU 파트너로 지목되었으며, Hot Chips 현장에서 CUDA를 실행하는 고코어 수 서버 시스템을 시연할 계획이다.
  • 논평: ServeTheHome은 RISC-V가 서버 CPU 시장에서 x86, Arm 외에 진정한 세 번째 선택지가 되고 있지만 대규모 배포까지는 약 두 세대가 남았다고 본다. Chips and Cheese는 기존 RISC-V 소비자급 하드웨어가 거의 전부 요구 사항을 충족하지 못하며(ACPI가 최대 약점), 단기적으로 CUDA on RISC-V는 기업급 서버 플랫폼에만 등장할 것이라고 지적한다. 이는 모니터링 기간 내 RISC-V 소프트웨어 생태계에 대한 가장 무게 있는 상업적 지지 신호다.

1.2 ab-riscv-interpreter 0.2: RISC-V ACT 인증 테스트를 통과한 Rust 컴파일 타임 인터프리터

날짜: 2026-08-31(블로그 게시) / 09-01(Hacker News 인기 글)　출처: Project Abundance 블로그, Hacker News, crates.io

Project Abundance가 ab-riscv-interpreter와 ab-riscv-primitives 0.2 버전을 발표했다. 특징: 완전 모듈화와 제네릭화, panic-free, no_std에 제로 할당, const fn으로 컴파일 타임 실행 가능, RISC-V 규격을 엄격히 준수한 구현(블록체인 용도 지향), RISC-V Architectural Certification Tests(ACT) 아키텍처 인증 테스트 통과. 디코더는 독립 crate로 분리되어 단독 사용 가능하며, 명령어 실행 코드는 매크로로 생성된다(단일 구현이 약 1900행으로 전개됨). 성능은 CoreMark 약 1600(컴팩트 match 루프) / 2950(indirect threading). 대가는 약 30개의 nightly Rust 기능(const 제네릭, 보장된 꼬리 호출 등)에 의존한다는 점이다. 저자는 확장이 임의의 RISC-V 유사 ISA(예: Parity의 PolkaVM)로 일반화될 수 있다고 말한다. 블록체인/형식 검증 시나리오를 겨냥한 RISC-V 소프트웨어 스택에 또 하나의 엄격한 구현 옵션이 추가되었다.

1.3 Raven-RiscV: RV32IMF 어셈블리 학습 시뮬레이터와 IDE가 커뮤니티 주목

날짜: 2026-09-02(모니터링 기간 내 push)　출처: GitHub Gaok1/Raven-RiscV

Rust로 작성된 RISC-V 교육용 시뮬레이터 Raven-RiscV가 모니터링 기간 내 업데이트되었고(09-02 00:01 UTC) 커뮤니티 인기를 유지하고 있다(111 stars). RV32IMF 지원, 단계별 디버거, 캐시와 파이프라인 시각화를 갖추었으며 “어셈블리를 배우는 시뮬레이터 + IDE”를 표방한다. 저장소는 2025-03에 생성되었고 최근 기능 완성도 향상으로 RISC-V 주제 저장소 인기 구간에 진입했다. 교육용 도구는 계속해서 RISC-V 어셈블리 입문 생태계를 채우며 강좌/경진대회 시나리오와 맞물린다.

2. 제품과 생태계 동향

2.1 Qualcomm Dragonwing Q-2390 / IQ-2390: ARM 메인 코어 + RISC-V 실시간 코어로 Zephyr 실행

날짜: 2026-09-01　출처: CNX Software, Qualcomm 보도자료

Qualcomm, Dragonwing Q2 시리즈 AIoT 프로세서 발표: Q-2390(상용/소비자: 리테일, 스마트홈, 스마트 디스플레이, 엔터프라이즈 엣지 디바이스)과 IQ-2390(산업용: 산업 자동화, 머신 비전, 빌딩 관리, 에너지 시스템). 메인 컴퓨팅 코어는 쿼드코어 Cortex-A78/A55(ARM)이며, Android, Yocto Linux, Ubuntu를 지원한다. 일부 모델에는 RISC-V 실시간 코어가 탑재되며, 이 코어는 Zephyr RTOS를 지원한다. SoM은 IFA 2026에서 전시될 예정이며, 평가 키트는 2027년 Q1에 제공될 예정이다. 이는 Qualcomm AIoT 제품 라인이 “ARM 애플리케이션 코어 + RISC-V 실시간/관리 코프로세서” 조합을 이어가는 또 하나의 사례로, 엣지 디바이스에서 RISC-V의 역할이 계속 자리 잡고 있음을 보여준다. 다만 메인 컴퓨팅은 여전히 ARM이 담당한다는 점에 유의해야 한다.

2.2 GigaDevice와 Rutronik 계약 체결: GD32(RISC-V 아키텍처 MCU 포함) EMEA 및 동남아시아 유통 확대

날짜: 2026-08-31(공고) / 09-01(Evertiq, Bisinfotech 보도)　출처: GigaDevice 공식 뉴스, Evertiq, Bisinfotech

GigaDevice가 독일의 전통 있는 유통업체 Rutronik Elektronische Bauelemente와 전략적 프랜차이즈(franchise) 협력을 체결하여 EMEA와 동남아시아(인도 포함)를 커버한다. 협력의 핵심은 GD32 시리즈 마이크로컨트롤러로, 공식적으로 이 제품군은 Arm Cortex-M과 RISC-V 듀얼 아키텍처 기반이며, 엔트리급부터 고성능 실시간 애플리케이션까지 포괄한다. 목표 시장은 산업, 자동차, 에너지, 통신, 소비자 가전 및 IoT이다. Rutronik은 2025 회계연도 매출 약 10억 유로, 4만 명 이상의 고객 서비스, 전 세계 80개 이상의 사무소를 보유하고 있어 GigaDevice의 해외 채널을 보완하는 중요한 축이다. 중국산 RISC-V MCU가 유럽 유통 체계를 통해 해외로 나아가는 또 하나의 진전이다.

3. 국내 팀 동향 및 심층 분석

3.1 SpacemiT: K3 UEFI 펌웨어 외부 개발자 수정, P3 데이터시트 공개, AI 문서 영문화

날짜: 2026-09-01　출처: spacemit-com/edk2-platforms commits, spacemit-com/docs-chip commits, spacemit-com/docs-ai

모니터링 기간 동안 SpacemiT(spacemit-com)의 세 저장소에서 실질적인 업데이트가 있었다:

  • edk2-platforms(UEFI 펌웨어): 외부 기여자 vhaudiquet의 K3 수정 PR 2건 병합 — 펌웨어 네트워크 문제 및 부팅 진행 코드(progress codes) 문제. 이는 커뮤니티 외부 개발자가 K3 UEFI 펌웨어 개발에 직접 참여한 최초의 신호 중 하나로, K3 플랫폼 펌웨어 생태계가 외부 기여에 개방되기 시작했음을 보여준다.
  • docs-chip: P3 칩 데이터시트 추가(BUCK DVS 예약 비트 수정 포함), 데이터시트 도표의 영문 번역 지속 진행으로 해외 개발자가 확보할 수 있는 영문 자료가 보완되고 있다.
  • docs-ai: 영문판 솔루션 문서 동기화.

어제 RevyOS가 K1/K3를 위해 커널 설정(linuxboot, K3 DC/UFS)을 추가한 것과 결합하면, SpacemiT K3 플랫폼은 펌웨어, 문서에서 배포판 커널에 이르기까지 소프트웨어 스택이 전반적으로 추진되고 있다.

3.2 SOPHGO: sophon-tools CV84X6 memory_edit 수정 마무리

날짜: 2026-09-01　출처: sophgo/sophon-tools commits

SOPHGO sophon-tools가 수정 한 건을 병합했다(zetao.zhang): CV84X6 -p 출력 상한과 검증 불일치(2M 초과 보고)(#181)로, v26.08.31 릴리스 배치의 마무리 작업에 해당한다. 릴리스급 신규 동향은 없다.

3.3 Sipeed: NanoKVM H264 비디오 스트림 동시성 최적화

날짜: 2026-09-01　출처: sipeed/NanoKVM commits

Sipeed NanoKVM(RISC-V 아키텍처 IP-KVM)이 커밋 두 건을 병합했다: H264 구독자 격리, H264 캡처 프레임 공유로 다중 클라이언트 동시 시청 시 비디오 스트림 성능과 메모리 점유를 개선했다. 소규모 유지보수 항목이다.

중국 팀 점검 결론: T-Head(XUANTIE-RV), ESWIN Computing(eswincomputing), revyos는 모니터링 기간 내 push가 없었다; Espressif(espressif)는 esp-idf, arduino-esp32 등 정규 진행으로 릴리스급 동향은 없다; Nuclei의 nuclei-linux-sdk는 저장소 push가 있었으나 메인 브랜치에 새 커밋이 보이지 않는다(브랜치/태그 작업으로 추정); gnews 중국어 쿼리(샹산/T-Head/쉬안톄, Nuclei/ESWIN, Espressif, T-Head, SOPHGO, StarFive when:7d) 전부 제로 히트로, 중국 팀 정보는 계속 GitHub 점검에 의존한다.

4. Embodied AI와 로봇 특별 챕터

4.1 모니터링 기간 내 로봇 특별 뉴스 없음; 최근 3일 트렌드와 기회 창

날짜: 2026-09-02　출처: gnews embodied AI when:3d 제로 히트(점검은 부록 참조)

모니터링 기간 내 embodied AI/로봇 방향의 특별 뉴스 히트는 없었다(gnews 중국어와 영어 쿼리 모두 제로). 최근 3일 트렌드 참조: MicroDuck 오픈소스 이족 보행 로봇(09-01 이미 보도, 메인 컨트롤러는 Rockchip RK3566, ARM 플랫폼)이 첫날 예약 구매 250만 달러를 넘겨 “저가 오픈소스 로봇 + 강화학습 소프트웨어 스택” 수요가 강력함을 입증했다; RISC-V 측면에서 기회 창은 여전히 9월 중국 로봇 전시회 시즌과 각 사 SoC의 로봇 SKU 양산 확대에 있다. 이번 호 해당 챕터는 조용한 관찰을 유지한다.

5. 요약과 트렌드 관찰

  1. CUDA 공식 로드맵이 RISC-V 호스트 CPU를 지목: NVIDIA가 Hot Chips 2026에서 처음으로 포팅 요구 사항 목록(RVA23, 서버 SoC/플랫폼 규격, ACPI, PCIe 일관성, P2P)을 공개하고, SiFive를 NVLink Fusion의 RISC-V 협력사로 지목했으며, CUDA를 실행하는 시스템을 현장 시연할 계획이다. 이는 RISC-V 서버 생태계에 대한지금까지 가장 강력한 상업적 지지 중 하나이다; 그러나 ACPI 등 하드웨어 관문은 기준을 충족하는 하드웨어에 여전히 수년이 걸린다는 것을 의미하며, 단기적으로는 엔터프라이즈급 서버에서만 등장할 것이다.
  2. RISC-V 실시간 코어가 주류 AIoT SoC에 계속 침투: Qualcomm Dragonwing Q2 시리즈의 “ARM 애플리케이션 코어 + RISC-V 실시간 코어(Zephyr)”는 이 조합이 이미 엣지 AI 칩의 주류 방식임을 재차 입증한다.
  3. 중국산 RISC-V MCU 해외 채널 강화: GigaDevice GD32(RISC-V 아키텍처 포함)가 Rutronik 채널을 통해 EMEA와 동남아시아로 확장하며 산업/자동차/에너지 등 시장을 커버한다.
  4. 중국 팀은 정규 이터레이션 기간: T-Head K3 UEFI 펌웨어가 외부 기여자의 수정을 받고, P3 데이터시트가 온라인에 공개되며, AI 문서 영문화가 모니터링 기간 내 가장 실질적인 진전이다; SOPHGO, Sipeed는 유지보수성 커밋이다; 일곱 점검 조직 중 릴리스급 신제품은 없다.
  5. 오픈소스 툴체인 심층 확장: Rust 컴파일 타임 RISC-V 인터프리터가 ACT 인증 테스트를 통과하고, RV32IMF 교육용 시뮬레이터가 스타를 받으며, 교육 및 검증류 소프트웨어 생태계가 계속 자리를 채우고 있다.
  6. 한계 설명: Google News 중국어 출처는 중국 팀에 대해 제로 히트로, 중국 부분은 GitHub 커밋 점검에 의존한다; Qualcomm 모델급 RISC-V 실시간 코어 세부 사항은 CNX 전달을 기준으로 한다; Hot Chips 발표는 08-23에 열렸으며, 이번 호는 심층 보도 보충 기록이다(ServeTheHome 09-01 게시).
