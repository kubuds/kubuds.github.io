오늘의 핵심: ESWIN Computing, 홍콩거래소 상장 청문 통과…홍콩증시 ‘RISC-V 제1호 상장사’ 유력

날짜: 2026-09-21　출처: CBN 《ESWIN Computing, 홍콩거래소 상장 청문 통과》, Sina Finance／Guandian Net 《ESWIN Computing, 홍콩거래소 상장 청문 통과…2025년 매출 24억 3100만 위안》, NetEase Hao 《ESWIN Computing, 홍콩거래소 청문 통과…RISC-V 트랙 ‘제1호 상장사’ 유력》

홍콩거래소 문서에 따르면, 베이징 ESWIN Computing Technology Co., Ltd.는 09-21 홍콩거래소 메인보드 상장 청문을 통과했으며, 공동 주관사는 CITIC Securities와 CITIC Securities International이다(회사는 2026-07-31 세 번째로 상장 신청서를 제출했다). 이후 발행이 순조롭게 진행되면 홍콩증시 ‘RISC-V 제1호 상장사’가 되어 RISC-V 칩 트랙의 상장 표적 공백을 메우게 된다.

경영 데이터 측면에서: 회사는 Fabless 모델을 채택하고 RISC-V를 기술 기반으로 삼으며, 제품은 인간-컴퓨터 상호작용 및 멀티미디어 처리 칩, 상호연결 및 컴퓨팅 칩을 아우르고, 스마트 단말과 임바디드 인텔리전스 두 가지 시나리오에 집중한다. 2023~2025년 매출은 각각 17억 5200만 위안, 20억 2500만 위안, 24억 3100만 위안이었고, 2025년 순손실은 15억 1600만 위안이다. 2026년 1분기 매출은 4억 9400만 위안(전년 대비 18.4% 증가), 순손실 3억 7500만 위안, 매출총이익률 14.8%다. 2026년 3월 31일 기준으로 150종 이상의 소프트웨어·하드웨어 협업 제품을 출시했고 전 세계 220여 개 고객을 서비스하고 있다. 컴퓨팅 제품 매출은 2023년 37만 5000 위안에서 2025년 3억 2000만 위안으로 증가했고, 2026년 1분기에는 2억 2300만 위안에 달했으며, 제품은 자동차, 산업 등 핵심 트랙에 진입했다. 2025년 매출 기준으로 회사는 국내 최대 스마트 단말 인간-컴퓨터 상호작용 칩 제공업체다.

업계 데이터도 함께 공개됐다. Frost & Sullivan 통계에 따르면 중국 RISC-V 메인 컨트롤 칩 시장 규모는 2021년 11억 위안에서 2025년 377억 위안으로 성장했으며(연평균 성장률 139.5%), 2030년에는 2194억 위안까지 확대될 전망이다. 유지해야 할 경계는 청문 통과가 공식 발행 및 가격 책정까지는 여전히 절차가 남아 있다는 점이며, 회사의 순손실과 컴퓨팅 제품 라인의 양산 리듬이 상장 후 가장 직접적인 검증 지표가 될 것이다. 같은 날, 회사 GitHub 측에는 이에 맞춘 릴리스 작업이 있었다(3.1 참조).

1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 openRuyi: 커널 듀얼 트랙 7.2.6 및 6.18.52로 업그레이드, 보안 수정 대량 반영

날짜: 2026-09-21　출처: openRuyi 커밋: linux 7.2.6으로 업그레이드, kernel-team-tools: TAG v7.2.6-1로 상향, openRuyi 공식 웹사이트 뉴스 페이지

openRuyi 롤링 릴리스 모니터링 기간 내 20건 이상 커밋되었으며, 주된 흐름은 커널 듀얼 트랙 업그레이드와 업스트림 추종이다: linux는 7.2.6으로, linux-lts는 6.18.52로 업그레이드되었고(모두 patchset 및 config 갱신 포함); kernel-team-tools는 네 개 커널 시리즈의 빌드 태그(6.18.52-1／7.0.14-5／7.1.13-1／7.2.6-1)를 동기화했으며, 커널 설정에서 ULTRARISC, VFIO_IOMMU_TYPE1, ARCH_ANLOGIC 등의 옵션을 활성화했다; openRuyi-Project/linux의 ruyi/6.18.y, 7.0.y, 7.1.y, 7.2.y 네 개 유지보수 브랜치도 당일 동기화 푸시되었다.

빌드 체계 측면: openruyi-linux-build 컴포넌트가 새로 추가되었고(각 플레이버 변형에 통합 linux 패키지 제공), linux／linux-lts／linux-lts-kmhv2 세 가지 spec은 rpm 매크로를 통한 통합 유지보수로 전환되었으며; glibc 2.44는 업스트림 스냅샷을 따라갔다. 보안 및 패키지 업데이트가 대량 반영되었다: python-pytorch-lightning 2.6.6, python-datasets 5.0.1, python-ujson 6.0.0, ImageMagick 7.1.2.31, pcre2 10.48(커밋 모두 security-fixes 표기); 클라우드 네이티브 측에는 k8s konnectivity-client와 kms, Datadog dd-trace-go, VictoriaMetrics 등 Go 패키지가 새로 추가되었다. 공식 웹사이트 뉴스 페이지 모니터링 기간 내 신규 공지 없음, 9월 릴리스는 아직 미발행(최신은 2026.08, 08-27 릴리스).

1.2 XiangShan: Kunminghu V3 브랜치 CBO 및 프리페치 경로 수정, NEMU는 mseccfg를 설정 가능으로 변경

날짜: 2026-09-21　출처: XiangShan 커밋: LoadUnit prefetch.i 리타이어 경로 유지(#6230), NEMU 커밋: mseccfg를 Kconfig 선택 항목으로 변경(#1221)

XiangShan 메인 저장소의 모니터링 기간 내 5건 커밋은 kunminghu-v3 브랜치에 있다: LoadUnit은 prefetch.i에 대해 S1 단계에서 제거하는 대신 정상 리타이어로 변경(#6230); CBO(Cache Block Operation) 명령어 두 가지 수정 — decode 단계에서 numWb를 2로 변경, Load-Store Queue의 StoreQueue credits가 CBO lane을 넘어갈 때 올바르게 유지되도록 수정; docker 기본 이미지를 xs-env:stable로 전환(#6577); CI 측 ckpt_select.py 개선 및 nightly fuzz 추가(#6604). NEMU 측 두 가지: mseccfg를 Kconfig 설정 가능 항목으로 변경(#1221), 가상화 supervisor 타이머는 nemu_timer 활성화 시에만 비활성화.

GEM5 브랜치 수준 개발도 활발하다: feat-ywl-pfbuffer 브랜치에 PDB(프리페치 데이터 버퍼) 모델이 새로 추가되었고, 그 리플레이 정리와 프리페치 허용 로직이 수정되었다; 모니터링 기간 내 Hybrid_CROB, calibrate-rvv-iq 등 개발 브랜치도 새로 열렸다(각각 하이브리드 CROB와 RVV 명령어 큐 캘리브레이션을 지향). difftest와 XSCache 메인 브랜치는 모니터링 기간 내 신규 커밋 없음; 메인라인 병합 동향은 여전히 관찰이 필요하다.

1.3 Bluespec 오픈소스 하드웨어 IP 라이브러리 Tape-Out(FukuzSoC) 다수 신규 저장소 개설

날짜: 2026-09-21　출처: GitHub 조직 Tape-Out(FukuzSoC)

FukuzSoC라는 오픈소스 하드웨어 IP 라이브러리가 09-21에 다수의 신규 저장소를 개설했다. 여기에는 세 가지 참조 SoC(soc-mcu／soc-linux／soc-smp)와 PLIC 인터럽트 컨트롤러 등이 포함된다. 해당 조직은 스스로를 “Bluespec으로 구축하고 XiRang 패키지 관리자로 조립하는 오픈소스 하드웨어 IP 라이브러리”라고 설명한다. 각 IP 저장소에는 ip.yaml(설정 항목, 계약 및 실측 면적), regmap.yaml(레지스터 매핑), Bluespec 소스 코드와 전체 설정 매트릭스를 커버하는 동작 테스트가 포함되며, 자체 개발 툴체인 xirang이 파싱, 생성, 테스트와 “가격 책정”을 담당하고 spec이 파일 의미를 정의한다.

IP 계보는 hart 프로세서 코어, cache, NPU／GPGPU／YOLO 가속기, ACLINT／PLIC／IMSIC 등 RISC-V 인터럽트 체계 부품, UART／SPI／I2C 등 주변장치와 이더넷 스위치／라우팅 모듈을 포괄한다. 성숙도는 planned／simulated／fpga-proven／asic-ready／silicon-proven의 다섯 단계로 나뉘며 각 저장소에 배지로 표시된다. 참조 SoC는 명시적으로 “자체 RTL을 포함하지 않으며” 전부 IP 조합으로 조립된다. 이러한 “패키지 관리자 + IP 라이브러리” 구성 방식은 중국에서 흔한 RTL 단일 저장소 모델과 다르므로 그 성숙도 진전은 추적할 가치가 있다. (주: 최근 공개된 프로젝트로 아직 공개된 테이프아웃 기록과 커뮤니티 논의는 보이지 않는다.)

1.4 simdjson에 RVV 벡터 백엔드 실험 저장소 등장

날짜: 2026-09-21　출처: MA-Gustave/Simdjson-rvv-vla

개발자가 simdjson의 RISC-V 벡터(RVV 1.0) 실험 백엔드를 오픈소스로 공개했다. 벡터 길이 무관(VLA) 방식으로 작성되었으며 GCC／Clang 검증, 런타임 디스패치, 업스트림 인수 테스트와 재현 가능한 성능 벤치마크를 갖추고 있다. 저장소는 09-21에 생성되어 당일 연속으로 커밋이 푸시되었다. simdjson은 널리 쓰이는 고성능 JSON 파싱 라이브러리로, RVV 백엔드가 업스트림에 수용된다면 RISC-V 플랫폼에서 이 라이브러리의 벡터 가속 경로가 보완될 것이다. 주: 현재 개인 실험 저장소로 초기 단계이며 성능과 업스트림 수용 진척은 검증이 필요하다.

1.5 오픈소스 생태계 단신: GNOME Flatpak riscv64 빌드, Exercism 트랙과 AG32 오픈소스 툴체인

날짜: 2026-09-21　출처: nico359/gnome-flatpak-riscv64, Exercism RISC-V 트랙, bbenchoff/AGaMEMnon

세 가지 경량 소식: 첫째, 개발자가 GNOME Flatpak Platform／SDK의 riscv64 비공식 빌드 저장소를 유지 관리한다(09-11 저장소 생성, 모니터링 기간 내 지속 업데이트). 이것이 완성되면 RISC-V 데스크톱의 컨테이너화된 애플리케이션 배포 여건이 개선될 것이다. 둘째, Exercism 프로그래밍 학습 플랫폼이 RISC-V 트랙을 개설했다(독립 test-runner 포함, 09-21 푸시). RISC-V가 해당 플랫폼의 언어 목록에 들어온 것이다. 셋째, AG32(AGM 반도체의 RISC-V MCU, AGRV2K FPGA 로직 내장)의 오픈소스 SDK와 툴체인 프로젝트 AGaMEMnon(48 스타, yosys／nextpnr 기반 오픈소스 플로우)이 모니터링 기간 내 활발하며, 이 “MCU + FPGA” 하이브리드 칩에 대한 오픈소스 도구 지원을 계속 추진하고 있다.

4.1 SpacemiT spacemit-robotics: 휴머노이드 로봇 관절 설정 수정 및 원격 제어 수신기 컴포넌트 저장소 반영

날짜: 2026-09-21　출처: humanoid_linglong PR #13: 고관절 설정 수정, peripherals-rc_receiver: 이벤트 기반 콜백 라이프사이클, manifest: RC 수신기 컴포넌트 추가

spacemit-robotics 조직은 모니터링 기간에 세 가지로 진전했다: 첫째, 휴머노이드 로봇 프로젝트 humanoid_linglong이 고관절 관련 수정을 병합했으며(고관절 모터 설정 수정, 구버전 정책의 고관절 댐핑 유지), 이는 실기 디버깅에서의 관절 캘리브레이션 문제를 가리킨다. 둘째, 새로운 원격 제어 수신기 외부 컴포넌트 peripherals-rc_receiver가 이벤트 기반 콜백 라이프사이클 정렬을 커밋했고, manifest를 통해 공식적으로 로봇 컴포넌트 빌드 체계에 편입되었다(이전 모니터링 기간에도 manifest가 지속적으로 확장되는 것이 확인됨). 셋째, 비주얼 매핑 프로젝트 linksee가 불필요한 점유 그리드 노드를 정리했다(#25). ORB-SLAM3 실행 저장소, ros2_humanoid부터 이번 모니터링 기간의 관절과 원격 제어 외부장치에 이르기까지, 로봇 소프트웨어 스택은 여전히 ‘컴포넌트화 + manifest 조립’의 리듬에 따라 조각조각 채워지고 있다.

4.2 2026 글로벌 AI 칩 서밋: SpacemiT, ‘대뇌·소뇌 융합 칩’ 계획 공개

날짜: 2026-09-21　출처: Hipoint 《AI 칩의 다음 방향이 궁금한가? 상하이 서밋에 오지 못한 사람이라면, 이 글 하나면 충분하다》

Hipoint 09-21 보도에 따르면, 2026 글로벌 AI 칩 서밋(상하이, 이틀간)이 막을 내렸으며, 60여 명의 연사와 100여 개 이상의 AI 칩 생태계 기업이 참가했다. RISC-V 관련 관전 포인트는 SpacemiT에 집중되었다: 칩 제품 총괄 천젠둥(Chen Jiandong)은 RISC-V 기반으로 ‘동형 융합 컴퓨팅’을 추진한다고 소개했다 — 통일 아키텍처, 통일 메모리, 통일 소프트웨어 시스템으로 CPU 연산력, AI 연산력, 실시간 연산력을 수요에 따라 할당하는 것이다. 두 세대의 칩이 이미 양산되었으며, K1은 1세대(AI 연산력 2T), K3는 8코어 CPU(주파수 2.4GHz, AI 연산력 60T, 30B 모델 배포 지원)이고, 이후 더 높은 연산력 플랫폼의 ‘대뇌·소뇌 융합 칩’을 개발할 예정이다. 전시 측면에서는 Nuclei, Imagination, SpacemiT 등 기업이 제품 솔루션을 전시했으며, 체화 지능 칩 포럼에서 Weifan Intelligence는 체화 시나리오를 위한 BiGPU 바이오닉 뉴로모픽 아키텍처를 제안했다. 서밋은 ‘TOPS에서 Token으로’를 메인 라인으로 삼아, 업계의 관심이 피크 연산력에서 추론 시나리오의 소프트웨어·하드웨어 협업으로 이동하고 있음을 반영했다.

5. 요약과 트렌드 관찰

  • 자본시장이 제시한 「RISC-V 제1주」: 이스위 계산(ESWIN Computing)이 홍콩거래소 청문을 통과했으며, 2025년 매출 24.31억 위안, 컴퓨팅 제품 라인 수익은 2023년 37.5만 위안에서 2025년 3.20억 위안으로 성장——상장 서사보다 더 검증 의미가 있는 것은 컴퓨팅 칩 수익 곡선의 기울기이며, 같은 날 EIC7X 릴리스 브랜치와 예제 저장소가 자리 잡아 자본 움직임과 엔지니어링 딜리버리가 처음으로 같은 주 안에 대조를 이뤘다.
  • 차량용 RISC-V가 「논의」에서 「양산 리스트」로 진입: DF30은 2026년 규모 양산, 연말 첫 탑재차 출하 계획이며, 누클레이(Nuclei) 코어 팀은 약 500명으로 확대되었고, 인피니언(Infineon, 자동차 MCU 점유율 36%)은 차세대 차량용 MCU를 전면 RISC-V로 전환한다. 국내 완성차 기업과 국제 대기업이 같은 타임라인에서 교차하며, 2026~2028년은 전자전기 아키텍처 전환의 핵심 3년으로 여겨진다.
  • 오픈소스 생태계의 「공급 측」이 계속 두터워짐: openRuyi 커널 이중 라인 업그레이드와 보안 배치, 샹산 쿤밍후 V3와 GEM5의 브랜치급 수정, Bluespec 오픈소스 IP 라이브러리 Tape-Out 등장, simdjson의 RVV 백엔드 실험——배포판, 프로세서에서 구체적 라이브러리까지 벡터화 경로가 모두 추진되고 있으며, RVV는 플래그십 프로젝트에서 일반 라이브러리의 일상적 최적화 대상으로 하향 확산 중이다.
  • 엠바디드 인텔리전스가 국내 RISC-V 벤더의 공통 서사로: 진뎨스공간(SpacemiT)이 AI 칩 서밋에서 「대뇌·소뇌 융합 칩」 계획을 공개했고, spacemit-robotics는 원격 수신기를 컴포넌트 체계에 편입시켰다. 이전 몇 기의 ORB-SLAM3, ros2_humanoid와 쑤안넝(SOPHGO) π0.5 이식에 더해, 로봇 방향의 RISC-V 소프트웨어 스택이 계속 두터워지고 있다.
  • 한계 설명: 이번 기 데이터는 공개 웹페이지와 GitHub 공개 커밋에서 가져왔으며, 어떠한 비공개 채널도 사용하지 않았다. GitHub 비인증 API가 수집 기간 중 한도에 도달했고(잔여 할당량 0), 일부 커밋 상세는 Atom 피드와 이벤트 인터페이스로 교차 검증했다. 회원 공식 사이트 점검에서 70곳 크롤링 실패(국내 사이트와 안티 크롤링 사이트 위주)가 있었다. 회의류 정보(스마트 자동차 칩 생태계 대회, IC WORLD 포럼, AI 칩 서밋)는 여러 매체에서 가져왔으며 회의 날짜를 표기했다. EE Times China 《항공우주 산업이 점차 RISC-V를 표준으로 삼고 있다》는 2026 유럽 RISC-V 서밋 내용(원문 7월)의 최근 재게재로, 당일 항목으로 수록하지 않았다.
  • 다음 기 관전 포인트: openRuyi 2026.09 버전 릴리스 여부, 이스위 계산 상장 가격 책정과 EIC7X의 릴리스 리듬, 샹산 쿤밍후 V3와 GEM5 PDB 브랜치의 병합 동향, Tape-Out IP 라이브러리의 성숙도 진전과 커뮤니티 반응, 다모원 쉬안티에(XuanTie)·누클레이·Radxa Linkr 등 저장소의 푸시 재개 시점.
