날짜: 2026-10-09　출처: Sina Finance (The Paper): ESWIN Computing 상장 첫날 소폭 하락 0.97% (10-09), 21 Jingji: “RISC-V 제1주” 데뷔, 공모가 하회 후 반등 (10-09), TechNode: RISC-V chipmaker ESWIN Computing lists in Hong Kong (10-09)

“RISC-V 제1주” ESWIN Computing (01256.HK)이 10-09 홍콩거래소 메인보드에 상장, 첫날 등락이 거듭됐다: 개장가 1.54 홍콩달러로 즉시 공모가 하회 (공모가 1.55 홍콩달러), 장중 한때 반등 (점심 무렵 최고 약 3% 상승), 저가 1.365 홍콩달러, 종가 1.535 홍콩달러, 0.97% 하락, 총 시가총액 약 338.3억 홍콩달러. 이번 글로벌 공모 약 16.17억 주 H주, 조달 총액 25억 홍콩달러, 순액 약 23.86억 홍콩달러; 조달 자금 약 35%는 칩 제품 개발 반복에, 30%는 RISAA (RISC-V와 AI) 소프트웨어·하드웨어 플랫폼에 투입.

1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 Canonical: Ubuntu 26.10 최초 공식 RISC-V 데스크톱 이미지

날짜: 2026-10-09　출처: 9to5Linux: Canonical Announces Official Ubuntu Desktop Images for RISC-V(10-09), Phoronix: Ubuntu 26.10 To Include Desktop Images For RISC-V(10-09)

Canonical이 Ubuntu Desktop의 공식 RISC-V 이미지 제공을 발표했으며, 10월 15일 출시되는 Ubuntu 26.10(Stonking Stingray)과 함께 선보인다. 별도로 실험적인 Xubuntu Minimal 이미지도 있는데(아직 공식 지원은 불가, 가상 머신에서의 시험 사용을 권장). 공식적으로는 SpacemiT K3(Pico-ITX)에서의 테스트를 권장하며, 26.10부터 해당 플랫폼에 대한 공식 지원을 제공한다. 완전한 데스크톱 경험은 RVA23급 하드웨어를 대상으로 하며, Milk-V Jupiter 2, DeepComputing DC-ROMA, SiFive HiFive Unmatched가 포함된다. 실기기 부팅을 위해서는 1차 부트로더(예: U-Boot)와 디바이스 트리를 직접 넣어야 한다.

1.2 LLVM/RISC-V: 분기 없는 코드가 RV32에서 여전히 분기로 컴파일되어, Zicond가 해법으로

날짜: 2026-10-09　출처: Frank Denis: Branches in branch-free code(10-09), Hacker News 토론

실측 결과: clang 23은 RISC-V에서 의도적으로 분기 없이 작성한 상수 시간 코드(128비트 덧셈 캐리 전파, 마스크 선택 등)를 조건 분기(beq/beqz)로 컴파일하며, RV32와 RV64 모두에서 발생해 잠재적 사이드 채널을 구성한다. Zig, Rust도 마찬가지로 영향을 받는다. Zicond 확장(RVA23 구성의 일부로, czero.eqz/nez 제공)을 활성화하면 모든 사례가 분기 없는 형태로 복원되지만, 타이밍 특성은 여전히 Zkt 확장이 함께 적용되어야 보장된다. GCC 16.1은 일부 작성 방식에서는 분기 없이 생성하지만, 비교 마스크 작성 방식에 대해서는 여전히 분기를 도입한다. 결론: 컴파일러 버전이나 파라미터가 변경된 후에는 상수 시간 코드의 기계어를 다시 감사해야 한다.

1.3 riscv-unified-db: RVA23.1/RVB23.1 프로파일 추가

날짜: 2026-10-09　출처: riscv-unified-db 커밋 기록(10-09)

명세 기계 판독 데이터베이스 riscv-unified-db는 모니터링 기간 내 7건의 커밋이 있었다: RVA23.1 및 RVB23.1 프로파일 추가(#2721), Zabha 확장을 위한 8/16비트 원자적 RMW 경로 보완(#2566), Sspmp/Sspmpen/Smpmpdeleg 확장 정의 추가(#1817), Smcdeleg 및 Ssccfg 의존성 완성(#2718), 그리고 fcvt 부동소수점 변환 메타데이터 수정과 VSEI/VSSI 인터럽트 파라미터 정리. 명세 데이터베이스는 최신 ratified 구성을 지속적으로 반영하고 있다.

1.4 openRuyi: Go 생태계 소프트웨어 패키지 13건 추가 등록

날짜: 2026-10-09　출처: openRuyi 커밋 기록: SPECS 2차분(10-09), lookout 커밋 기록(10-09)

1차분 20여 건에 이어, openRuyi 메인 저장소는 모니터링 기간 내 13건의 SPECS 커밋을 추가로 병합했다: franz-go, OpenTelemetry profiling, Jaeger IDL, Datadog 시리즈, ghinstallation, 알리바바 클라우드 OpenAPI, chroma 등 Go 생태계 컴포넌트 패키지 정의를 추가하고, buf-protovalidate와 cloudfoundry-clock도 보완했다. 같은 조직의 버전 점검 도구 lookout은 같은 날 20여 건을 병합했다(릴리스 버전 드롭다운 선택, 의존성 일괄 업그레이드 및 CI 캐시 최적화). 공식 웹사이트 뉴스 페이지 확인 결과 2026.09 버전 이후 새로운 릴리스 공지는 없다.

1.5 XiangShan: FMA 조기 웨이크업, MMU ptehelper 지원 등 6건 병합

날짜: 2026-10-09　출처: XiangShan 커밋 기록(kunminghu-v3 브랜치, 10-09), PR #6679, PR #6687

XiangShan 메인 저장소 모니터링 기간 내 6건 머지: #6679는 FMA와 load로부터의 사전 웨이크업(src2 경로)을 FMA에 추가, #6687은 aes64ks1i가 rnum>10일 때 불법 명령어 예외를 트리거하지 않던 문제를 수정, #6580은 인터럽트 관련 주석을 정정, #6636은 workload_list의 성능 리포트를 활성화, 그 외 2건의 MMU 커밋(ptehelper 지원 추가 및 맞춤법 수정). 프런트엔드 디코드, 부동소수점 발행 및 MMU 경로가 동시에 마무리되었다.

1.6 XiangShan 시뮬레이션 체인: difftest가 2슬롯 ROB 아키텍처 이벤트 지원, GEM5가 V3 RTL에 정렬

날짜: 2026-10-09　출처: difftest PR #979: 2슬롯 ROB 항목 아키텍처 이벤트(10-09), difftest PR #954: UVHS GBus 호스트 인터페이스, GEM5 커밋 기록(10-09), NEMU 커밋 기록(10-09)

시뮬레이션 체인이 여러 방향으로 추진: difftest는 #979(crob가 2슬롯 ROB 항목의 archEvent와 storeEvent 지원)와 #954(FPGA 검증 방향에 UVHS GBus 호스트 인터페이스 추가)를 머지; GEM5는 UARTLite 빠른 빌드를 수정하고 Clang 커버리지를 추가(#1209)했으며 SBuffer store miss 처리를 쿤밍후 V3 RTL과 정렬; NEMU의 ZSTD 체크포인트 형식 오류 처리가 메인 브랜치에 머지되었다.

2. 제품 및 생태계 동향

2.1 Sophgo: sophon-demo에 YOLO26 깊이 및 자세 추정 샘플 추가

날짜: 2026-10-09　출처: sophon-demo 커밋 기록(10-09), sophon-tools 커밋 기록(10-09)

Sophgo sophon-demo에 YOLO26 단안 깊이 추정과 자세 추정 두 샘플(YOLO26_depth／YOLO26_pose)이 추가되어, 차세대 검출 모델의 Sophgo TPU 플랫폼 예제 매트릭스를 보강했다; sophon-tools는 EC20 모듈 자가 복구 timer를 udev가 모듈을 감지할 때 트리거하도록 변경(주기 60s에서 90s로 조정)하고 psewriter의 32비트 플랫폼 테스트 컴파일을 수정했다. sophgo 조직은 모니터링 기간 내 8개 저장소를 일괄 푸시(libsophon, LLM-TPU, osdrv 등 포함).

2.2 Sipeed: SLogic에 sigrok-cli 포워딩 플러그인 추가

날짜: 2026-10-09　출처: SLogic 커밋 기록(10-09), slogic16u3-tools 커밋 기록(10-09)

Sipeed 로직 분석기 생태계 업데이트: SLogic 저장소에 sigrok-cli-slogic-plugin이 추가됨—sigrok 명령줄 툴체인을 위한 크로스 플랫폼 슬림 래퍼 포워더로, wiki 문서(중영문)도 동시에 정렬; slogic16u3-tools는 OTA 애플리케이션 이미지 플래싱 튜닝을 product.toml([ota] 설정 섹션)에 노출하여 툴체인 구성 가능성이 강화되었다.

3.1 ESWIN Computing: 상장 첫날 등락 거듭, 순조달 자금 23.86억 홍콩달러

날짜: 2026-10-09　출처: Sohu (Xinzhi Xun): RISC-V 첫 주식! Yisiwei Computing 상장 첫날 공모가 하회 (10-09), EE Times China: Yisiwei Computing 홍콩거래소 상장, Wang Dongsheng 세 번째 IPO 달성 (10-09)

상장 첫날(자세한 내용은 「오늘의 중점」 참조) 관련 보충: 장중 고가 약 1.60 홍콩달러, 저가 1.365 홍콩달러; 발행 비용 약 1.21억 홍콩달러. 이 회사는 전 BOE 회장 Wang Dongsheng이 공동 창업에 참여했으며, 누적 4라운드 펀딩으로 90억 위안을 초과 조달했고(IDG Capital이 최대 외부 기관 주주), 2023년부터 2025년까지 매출은 17.52억 / 20.25억 / 24.31억 위안, 순손실은 18.37억 / 15.47억 / 15.16억 위안이었다. 공모 설명서에 따르면 경쟁 대응 전략으로 「가격을 낮춰 물량을 확보하는 방식」을 포함하고 있으며, 향후에도 지속적인 손실이 발생할 가능성이 있다.

3.2 Yisiwei Group: 우한 실리콘 소재 기지 첫 장비 이달 반입

날짜: 2026-10-09　출처: 후베이성 경제정보화청: Yisiwei 우한 실리콘 소재 기지 첫 장비 이달 반입 (10-09)

같은 Yisiwei Group 산하의 실리콘 소재 부문(Xi’an Yicai, 커촹반 상장) 우한 기지 건설이 가속화되고 있다: 부지 약 310무, 총 투자 약 125억 위안, 첫 장비 이달 반입, 내년 2분기 양산 예정이며, 전면 양산 달성 시 연간 생산액 35억 위안 초과가 예상된다. 올해 6월 말 기준 Xi’an Yicai의 총 생산능력은 100만 장/월을 돌파했고, 출하량 기준 글로벌 시장 점유율 약 7.7%(12인치 실리콘 웨이퍼 중국 내 1위, 글로벌 6위)를 기록했다. 이 기지는 우한의 12인치 실리콘 웨이퍼 공정 공백을 메우고, 현지 메모리 및 웨이퍼 제조 클러스터와의 연계를 형성한다.

3.3 SpacemiT: spine-triton 빌드 릴리스 파이프라인 개선

날짜: 2026-10-09　출처: spine-triton 커밋 기록 (10-09), docs-buildroot 커밋 기록 (10-09)

SpacemiT의 spine-triton(K3의 Triton 컴파일 스택)은 모니터링 기간 내 10여 건의 커밋이 릴리스 파이프라인 개선에 집중되었다: smt_rvisa 모듈 이름을 변경하고, GitHub CI가 각 Python 버전별로 riscv64 wheel을 빌드하도록 추가했으며, vendoring 로직을 공유 스크립트(scripts/common.sh)로 추출하고 버전 번호와 빌드 워크플로를 정기적으로 업데이트했다. 문서 측면에서는 docs-buildroot에 K3 Secure Boot 가이드의 영문 번역과 v1.0.8 / v1.0.9 릴리스 노트를 추가했고, docs-ros는 K3 문서의 여러 부분을 수정했다.

3.4 Espressif: esp-sr wakenet10 웨이크업 모델 지원, esp-idf 다중 칩 수정 사항 병합

날짜: 2026-10-09　출처: esp-sr 커밋 기록 (10-09), esp-idf 커밋 기록 (10-09)

Espressif는 모니터링 기간 내 꾸준히 진행했다: esp-sr 음성 프레임워크에 wakenet10 웨이크업 모델 지원(PT 모델 파일 포함)을 추가하여 음성 인터랙션 스택을 업그레이드했고, esp-idf에는 일련의 수정 사항을 병합했다——C61 모니터링 클록을 PVT 함수로 설정하도록 변경, SDMMC msync 타임아웃 마스크, TEE 롤백 방지, S31 DAC 준비 및 BLE Audio 주소 서명 등. Espressif 조직은 모니터링 기간 내 30개 이상의 저장소에 푸시했으며, 엣지 디바이스(RISC-V 칩 라인 포함) 유지보수 리듬이 밀도 높게 이어지고 있다.

4. 임바디드 인텔리전스 및 로보틱스 특별 장

4.1 SpacemiT Robotics: ros2_humanoid에 WebSocket 직접 연결 ASR 동작 제어 추가

날짜: 2026-10-09　출처: ros2_humanoid 커밋 기록 (10-09)

SpacemiT Robotics 조직의 ros2_humanoid는 모니터링 기간 내 WebSocket 직접 연결 ASR(음성 인식) 동작 제어를 병합했다: 인식 결과가 WebSocket을 통해 휴머노이드 로봇 동작을 직접 트리거할 수 있다. 이전에 해당 저장소는 ROS 제어를 오퍼레이터 socket API로 마이그레이션하고 오디오 알림 동안 ASR 수집을 유지했으며——제어 체인은 지속적으로 「음성—오퍼레이터—액추에이터」의 직접 연결과 디커플링 방향으로 진화하고 있다.

5. 요약 및 트렌드 관찰

  • 배포판 데스크톱 측 이정표 달성: Ubuntu 26.10이 공식 RISC-V 데스크톱 이미지를 최초 출시(SpacemiT K3 권장, RVA23급 하드웨어 대상), RISC-V 데스크톱 사용성이 「실험 이미지」에서 「공식 지원」으로 전환.
  • 자본 첫 선을 통한 시장 인내 검증: ESWIN Computing이 첫날 시초가 하락, 0.97% 하락 마감, 총 시가총액 약 338억 홍콩달러; 고성장과 고손실이 공존하는 가운데 「가격 대비 물량」 전략과 RISAA 생태계 투자의 실현 속도가 향후 관찰 포인트로 부상.
  • 툴체인과 규격 계층 세부 사항 마무리: LLVM이 RISC-V에서 분기 없는 코드를 분기로 컴파일(Zicond/RVA23이 해결책), riscv-unified-db에 RVA23.1/RVB23.1 프로파일 추가, 소프트웨어와 규격 계층은 여전히 세부 사항에서 지속적인 개선 중.
  • XiangShan 계열과 생태계 저장소 일상 고빈도: XiangShan FMA/MMU 수정과 difftest, GEM5, NEMU 시뮬레이션 체인 동시 추진; openRuyi Go 패키지, Espressif esp-sr, SiSpeed SLogic, Sophon 예제 매트릭스 각 라인에서 실질적인 커밋 존재.
  • 관찰 필요: ESWIN 상장 후 주가 흐름과 락업 해제 속도; Ubuntu 26.10이 10월 15일 정식 출시된 후 RISC-V 이미지의 실제 설치 피드백; SpacemiT spine-triton의 riscv64 wheel 릴리스 속도.
