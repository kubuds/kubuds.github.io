1. 오픈소스 커뮤니티와 소프트웨어 생태계 동향

1.1 USENIX Security 26 논문: Spectre, 상용 비순차 RISC-V 실리콘에서 전면 성립 (오늘의 헤드라인 중 하나)

날짜: 2026-08-12 (논문 채택 및 블로그 게시, 08-12~13 미디어 확산)　출처: Lukas Gerlach 블로그 (논문 단편) / The Register / SC Media

독일 연구자 Lukas Gerlach 등의 논문 《Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors》가 USENIX Security 26에 채택되어 공개되었다. 연구는 구매 가능한 상용 비순차 RISC-V 프로세서 — T-Head XuanTie C910/C920과 SiFive P550 — 에서 체계적으로 검증했다: 이전에 x86에서 성립한 Spectre 각 변종이 RISC-V에서도 동일하게 가능하다 (일부는 추가 기술 필요). 핵심 발견: 첫째, Spectre-BTB (v2)의 악용 가능 여부는 펌웨어가 간접 분기 예측기를 활성화했는지에 달려 있다 — C910/P550은 출하 시 비활성화, C920은 활성화 상태이며, 활성화 후 공격은 성공하지만 간헐적 기계 충돌이 발생하여 하드웨어 결함 존재를 시사한다; 둘째, 연구자들은 BPF 프로브를 통해 임의 파일을 읽는 실제 공격 체인을 구축했다: RISC-V BPF JIT는 커널이 삽입한 BPF_NOSPEC 배리어에 대해 어떤 명령어도 생성하지 않으며, 검증기는 프로그램이 보호된다고 판단하지만 생성된 코드에는 실제로 배리어가 없어 “추측 유형 혼동” 가젯을 형성한다; 셋째, 시험 대상 코어는 BTB를 사용자 모드와 커널 모드 간에 분리하여 전통적인 커널 Spectre 악용 경로를 어렵게 만든다. 논문은 동시에 방어 권고안을 제시한다. 이는 2023년 T-Head 보안 공지 이후 “RISC-V는 Spectre에 면역”이라는 신화에 대한 공개적 체계적 반증이며, RISC-V의 서버/클라우드 인프라 진입에서 신뢰 구축에 중요한 경고가 된다.

1.2 XiangShan: satp 플러시 후 첫 명령어 페치 오류 수정 (#6014)

날짜: 2026-08-14 (07:02 UTC 커밋, 베이징 15:02)　출처: OpenXiangShan/XiangShan GitHub

XiangShan 오픈소스 고성능 RISC-V 프로세서 (7191 스타)가 모니터링 기간 내 fix(csr): fix first fetch fault after satp flush (#6014)를 병합하여, satp (페이지 테이블 베이스 레지스터) 플러시 후 첫 명령어 페치 오류를 수정했다 — 이는 주소 변환/페이지 테이블 전환 경로의 경계 조건 결함 수정으로, 가상 메모리 전환 정확성과 직접적으로 관련된다. 모니터링 기간 내 difftest/XSCache/GEM5/NEMU 등 주변 저장소의 지속적 푸시 (15시간 내 모두 업데이트)와 결합하여, XiangShan 프로젝트팀은 풀스택 고빈도 반복 개발 리듬을 유지하고 있다. 이전 08-13의 BERTi 성능 강화, elaboration 파라미터 캐시 가속은 어제 리포트에 수록되었다.

1.3 QEMU 11.1 릴리스: RISC-V 빅엔디언 지원 추가 (최근 3일 트렌드)

날짜: 2026-08-11/12　출처: Linuxiac / Phoronix 집계

QEMU 11.1이 릴리스되어 RISC-V 빅엔디언(big-endian) 지원과 ARM 중첩 가상화, UFS 에뮬레이션 등 여러 개선 사항이 추가되었다. RISC-V 빅엔디언 지원은 이기종/특수 워크로드의 에뮬레이션 검증에 의미가 있으며, RISC-V 가상화 툴체인의 지속적인 완성에 해당한다. 릴리스 시점이 모니터링 기간 하루 전이므로 최근 3일 트렌드로 분류한다.

1.4 Tenstorrent Ascalon XG 코어 GCC 패치 + 오픈소스 프로젝트 관찰

날짜: 2026-08-12 (Phoronix 보도)　출처: Phoronix 집계

Tenstorrent가 Ascalon XG 코어(자사의 RISC-V 서버 CPU 제품 라인 핵심)를 위한 GCC 컴파일러 패치를 제출하여, 해당 코어의 GNU 툴체인 측 정식 지원을 추진했다——이는 RISC-V 고성능 서버 코어 소프트웨어 생태계 구축의 또 하나의 고리이다(최근 3일 트렌드, 어제 전망에서 Tenstorrent 수출 모델 분화를 이미 언급). 또한 GitHub 활발 프로젝트 관찰(topic:risc-v, 24시간 내 푸시): riscv/riscv-unified-db(209 스타, RISC-V 통합 데이터베이스, 08-14 업데이트), bbenchoff/AGaMEMnon(37 스타, AGM AG32 RISC-V MCU 오픈소스 SDK 및 임베디드 AGRV2K FPGA 툴체인, 08-15 생성), w1ne/labwired-core(59 스타, ARM/RISC-V 결정론적 펌웨어 시뮬레이터) 등, 커뮤니티 측 소규모 프로젝트가 지속적으로 등장하고 있다.

2. 제품 및 생태계 동향

2.1 제5회 디수이후 중국 RISC-V 산업 포럼: 40여 종 소개, 양산률 90% 초과, 출하 360억 개 (오늘 헤드라인)

날짜: 2026-08-13 개막, 08-13~14 집중 보도　출처: 국제전자상정 / eet-china / Sina Finance / JiWei

어제 전망한 제5회 디수이후 중국 RISC-V 산업 포럼(상하이 링강, 8월 13일 개막)의 성과가 집중적으로 landing되어 오늘 산업 측 최대 이벤트가 되었다. VeriSilicon의 Dai Weimin은 네 차례 포럼에서 누적 40종의 중국산 RISC-V 칩을 소개했고 양산률이 90%를 초과한다고 밝혔다. 이번 포럼이 전한 산업 신호는——RISC-V 칩 누적 출하 360억 개, 시장 점유율 30% 돌파, 침투율 25% 달성이다. 포럼에서는 10종의 자국산 RISC-V 칩 신제품이 발표되어 AI 서버, 로봇 운동 제어, 자동차 전자, 지능형 비전, 네트워크 인터페이스 등의 방향을 커버했다(자세한 내용은 2.2~2.4 및 제3장 참조). 상하이 당국은 글로벌 RISC-V 산업 고지를 조속히 구축하겠다는 입장을 밝혔다. 국제전자상정은 “열 개의 칩으로 보는 RISC-V의 주력화 경로”라는 제목으로 정리했다: 임바디드 로봇, AI 서버, 자동차 전자라는 세 대전장을 모두 커버하며, 중국산 RISC-V가 “사용 가능”에서 “주력”으로 전환하는 산업 서사가 형성되었음을 표시한다.

2.2 Lanxin Computing LX500: 세계 최초 RISC-V 양산 서버 CPU (48코어 75 TOPS)

날짜: 2026-08-13 (디수이후 포럼 공개)　출처: eet-china / EDN China / Xinzhi Xun

Lanxin Computing은 디수이후 포럼에서 LX500을 발표하며 “세계 최초 RISC-V 양산 서버 CPU”라고 주장했다: 48코어, 75 TOPS AI 연산력, “지능-컴퓨팅 융합”(CPU와 AI 가속 융합) 아키텍처를 채택했으며 연산력 활용률을 주력으로 내세워 “CPU+가속 카드” 분리 아키텍처 서사를 종결시켰다. 이 회사는 이전에 Lenovo와 RISC-V+AI 지능-컴퓨팅 융합 CPU 공동 혁신 연구소를 설립했으며, Lenovo는 세계 최초 오픈소스 아키텍처 AI 서버를 출시했다(7월 보도). Lanxin Computing은 Pre-B 라운드에서 Longqiu Capital로부터 3억 위안 이상의 단독 투자를 유치했다(7월 1일). 만약 “양산 서버 CPU”가 사실이라면, 이는 RISC-V가 데이터센터 주 연산 노드를 공략하는 상징적 이정표이며, 어제의 StarFive BMC가 데이터센터 관리 측면에 진입한 것과 함께 “컴퓨팅+관리” 이중 라인 호응을 형성한다.

2.3 StarFive JH-B100 시리즈: RISC-V BMC 칩, 국산 대체 가속화 (어제 보도 후속, 모델명 구체화)

날짜: 2026-08-13/14　출처: EDN China / eet-china / Sohu

어제 “StarFive, AI 데이터센터 BMC에 베팅”이라는 산업 소식이 오늘 구체적 제품으로 실현되었다: StarFive JH-B100 시리즈 RISC-V BMC 칩(이전 “Fang·Jinghong-B100”이 2026 중국 IC 설계 성취상에 참가한 바 있음)이 여러 중국 매체에 의해 “지능형 컴퓨팅 센터의 보이지 않는 생명선, 글로벌 독점 타파”라는 제목으로 보도되었으며, 지능형 컴퓨팅 센터의 BMC 수요 폭발에 대응하여 국산 대체를 가속화한다고 지적했다. BMC 시장은 오랫동안 Aspeed가 주도해왔으며, RISC-V 솔루션이 서버 대역 외 관리를 공략하는 것은 생태계가 데이터센터에 진입하는 저비용 고가치 경로다.

2.4 Allwinner V861과 Timesintelli PT153S: 비전 엣지 및 네트워크 카드 칩

  • Timesintelli PT153S: 전 국산화 USB 기가비트 네트워크 카드 칩, RISC-V 기반, 3개월 만에 출하 100만 장 초과를 주장하며 “엣지 AI에서 고속 인터페이스까지” 경로로 네트워크 카드 칩 국산 대체를 촉진한다——RISC-V가 네트워크 인터페이스 컨트롤러 세분 시장에 진입.

2.5 ESP32-C6 홈 오토메이션 키트 (LinuxGizmos)

날짜: 2026-08-14 (04:03 UTC)　출처: LinuxGizmos

LinuxGizmos는 ESP32-C6 (Espressif RISC-V 코어 MCU) 기반 홈 오토메이션 키트를 보도했다: ESPHome과 모듈식 센서를 통합하여 스마트 홈 DIY 시나리오를 겨냥한다. ESP32-C 시리즈 RISC-V 생태계의 일상적인 신제품으로, Espressif RISC-V MCU가 소비자/홈 시장에서 지속적으로 확대되고 있음을 뒷받침한다.

3. 국내 팀 동향과 심층 분석

3.1 SpacemiT: K3, 네 가지 세계 최초 달성, RVA23 도입, 로봇 모션 제어 + DeepSeek harness 문서

날짜: 2026-08-13 (보도 발표) ~ 08-14 (GitHub 문서 업데이트)　출처: EDN China / eet-china / JiWei / docs-ai GitHub

SpacemiT K3는 디수이후 포럼에서 가장 주목받는 신제품이 되었다: 여러 중국 매체가 “네 가지 세계 최초 달성” (RVA23 표준 도입, 온디바이스 AI 연산력 등 측면)을 보도했으며, eet-china는 “RVA23 표준 도입부터 로봇 모션 제어 실전까지”라는 제목으로, EDN은 “CPU 2.0 시대 개막”이라는 제목으로 보도했다 — K3는 RISC-V 온디바이스 AI 플래그십 SoC로 포지셔닝되며, 로봇 모션 제어(모션 컨트롤)는 주요 적용 시나리오 중 하나이다. 소프트웨어 측면에서도 동시에 추진 중이다: spacemit-com/docs-ai는 08-14 20:57 (베이징 시간)에 DeepSeek 추론 harness 중국어 문서(ds-harness, PR #157/#158)를 머지했으며, ai-sdk는 매일 정례적으로 vision 서브모듈을 업데이트하고 있다 (08-14 18:16 베이징 시간 최신). K3 온디바이스 대규모 모델 추론 (DeepSeek 계열) 툴체인 문서화 속도가 빨라지고 있다. 앞서 FlagGems-RACE K1 백엔드 90+ 연산자 매트릭스(어제 리포트)와 결합하면, SpacemiT의 “칩 + 연산자 라이브러리 + 추론 문서” 삼위일체 온디바이스 AI 스택이 형성되고 있다.

3.2 ESWIN Computing EAI8800: RISC-V 차량용 전자 사이드미러(CMS) 전용 칩

날짜: 2026-08-13　출처: SEMI 대반도체산업망 / eet-china / EDN China

ESWIN Computing의 Guo Guangkuo는 디수이후 포럼에서 EAI8800을 발표했다: RISC-V 아키텍처로 차량용 전자 사이드미러(CMS) 칩 솔루션을 재구성하여 낮은 지연과 원가 절감을 주력으로 하며, DDR 가격 상승을 두려워하지 않는다고 주장한다(아키텍처/메모리 솔루션 최적화를 통해). CMS(Camera Monitor System)는 스마트 자동차가 전통적인 광학 사이드미러를 대체하는 새로운 분야이다. ESWIN Computing은 최근 홍콩 증시 IPO 절차를 동시에 진행 중이며(“RISC-V 아키텍처 제1호 상장사” 서사, 홍콩거래소 3차 도전, 3년 누적 적자 49억 위안, 8/10-14 다수 보도), 그 차량용 AI MCU(EAM2011)는 이미 Zunjie 스마트 시트 공급망에 진입했으며, 자동차 전자는 이 회사의 상용화 주력 라인이다.

3.3 거연반도체: 500나노초 전류 루프, 단일 칩으로 25 자유도 구동——RISC-V 로봇 운동 제어 기반

날짜: 2026-08-13　출처: eet-china

거연반도체가 디수이후 포럼에서 RISC-V 로봇 운동 제어 솔루션을 선보였다: 500나노초 전류 루프(전류 루프 제어 주기), 단일 칩으로 25개 자유도 구동, 실시간 제어 DSP 노선을 주력으로 한다(자사의 GS32 시리즈 DSP는 이미 6월에 ASIL-B 제품 인증을 획득, 고급 실시간 제어를 겨냥). 이는 RISC-V가 체화 지능 ‘운동 제어 기반’ 계층에서 국산 대체 솔루션을 제공하는 것이다——자세한 내용은 제4장 전용 장을 참조.

3.4 카이신훙, 억 위안 초과 시드 라운드 완료: 자금은 샹산 IP 코어 아키텍처 업그레이드에 투입

날짜: 2026-08-11(최근 3일 추세)　출처: 관점망

카이신훙이 억 위안을 초과하는 시드 라운드 투자를 완료했으며, 자금은 명확히 샹산 IP 코어(XiangShan) 아키텍처 업그레이드에 투입된다——샹산 오픈소스 고성능 코어의 상용화 주체가 초기 자본 지원을 확보한 것으로, 샹산 프로젝트팀의 최근 풀스택 반복(1.2 참조)과 호응을 이룬다. 이는 8월 11일 뉴스로, 모니터링 기간 경계에 위치하여 최근 3일 추세에 포함한다.

4. 중점 방향 전용 장: 체화 지능과 로봇

4.1 디수이후 포럼, 로봇 신호 집중 방출: 운동 제어 칩이 국산 RISC-V의 새 전장으로

디수이후 포럼의 여러 신제품이 체화 지능을 겨냥한다: 거연반도체의 단일 칩으로 25 자유도 구동, 500나노초 전류 루프의 로봇 운동 제어 솔루션(3.3 참조)은 모니터링 기간 내 가장 구체적인 운동 제어급 제품 신호다——전류 루프 주기는 운동 제어 실시간성의 핵심 지표이며, 500나노초 수준은 고급 서보 제어에 대응한다; 진디시공 K3는 로봇 운동 제어를 주력 시나리오 중 하나로 꼽으며(3.1 참조), spacemit-robotics의 LeRobot(SmolVLA/ACT 엣지 배포), 휴머노이드 로봇(humanoid_unitree_g1) 방향의 기존 포석을 이어간다; 국제전자상정 “10개 칩으로 보는 RISC-V의 주력 경로”와 신랑 8/14 종합 “서버, AI 그리고 로봇: 중국 RISC-V의 다음 역” 모두 로봇을 RISC-V 3대 주력 시장 중 하나로 꼽는다. 운동 제어(실시간 제어 DSP/MCU)와 엣지 AI(VLA 모델 추론)는 RISC-V 체화 지능의 두 병행 주선을 구성하며, 전자는 이번 주 실질적 신제품이 출시되었다.

4.2 생태계 측면 수용

샹산/진디 등 고성능 코어와 연산자 라이브러리 진전(1.2, 3.1 참조)은 계속 로봇 엣지 추론에 기반을 제공한다; 거연 GS32 시리즈는 이미 ASIL-B 인증을 획득했으며(6월), 차량급 실시간 제어 칩은 로봇 관절 제어 재사용에 인증 기반을 제공한다.

5. 요약 및 추세 관찰

  1. 중국산 RISC-V, ‘주력 서사’ 단계 진입: 디수이후 포럼의 “출하량 360억 개, 시장 점유율 30% 초과, 양산율 90% 초과”라는 산업 데이터와 10종 신제품(서버 CPU, 로봇 운동 제어, 차량용 CMS, 비전 엣지, 네트워크 카드, BMC)이 집중적으로 공개되며 AI 서버, 임베디드 로봇, 자동차 전자라는 세 가지 전장을 아우렀다. 중국산 RISC-V가 ‘사용 가능’에서 ‘주력’으로 전환한다는 서사가 이번 주에 형성되었다. 이는 어제의 SiFive SKL 오픈소스(소프트웨어 커널 라이브러리 군비 경쟁)와 함께 RISC-V 하드웨어 생태계가 이미 충분히 풍부해졌으며, 경쟁 중심이 소프트웨어 스택과 산업 현장 적용으로 이동하고 있음을 보여준다.
  2. RISC-V 서버 경로에 양산급 노드 등장: 란신 LX500(48코어 75 TOPS, 세계 최초 RISC-V 양산 서버 CPU라고 주장)과 사이팡 JH-B100 BMC가 같은 날 주목받으며 ‘주 연산력+대역 외 관리’의 이중 라인으로 데이터센터에 진입하는 태세를 형성했다. 전자가 양산 실현이 사실이라면 Tenstorrent Ascalon, 핑터우거 슈안톄 서버 코어(이전 보도)와 같은 무대에서 경쟁하게 된다.
  3. 보안 신뢰 구축이 새로운 의제로 부상: USENIX Security 26 논문이 상용 비순차 RISC-V 실리콘(중국산 C910/C920 포함)에서 Spectre가 성립함을 공개 검증했고, BPF JIT의 배리어 부재라는 구체적인 소프트웨어 결함도 지적했다. RISC-V가 서버/클라우드 신뢰 경계에 진입하려면 보안 감사와 강화(예측 배리어, 펌웨어 기본 구성, JIT 수정)가 성능 서사와 병행되어야 하며, 관련 방어 작업은 지속적으로 추적할 가치가 있다.
  4. 임베디드 지능 운동 제어 계층에 중국산 솔루션 등장: 거젠 반도체의 500나노초 전류 루프/25 자유도 운동 제어 칩과 진디에 K3 로봇 운동 제어 포지셔닝은 RISC-V가 로봇 ‘운동 제어 기반’(이전에는 주로 DSP/전용 MCU가 차지)에서 돌파구를 열었음을 의미하며, 엣지 AI 추론(LeRobot 적응)과 함께 완전한 현장 적용 경로를 구성한다.
  5. 오픈소스 고성능 코어 상용화 가속: 카이신홍이 초과 1억 위안 시드 라운드를 샹산 IP 코어 아키텍처 업그레이드에 투자했고, XiangShan은 모니터링 기간 내에 정확성 수정(satp flush 명령어 페치 오류)을 지속적으로 병합하며 오픈소스 코어의 ‘커뮤니티 반복+상용 기업 승계’ 모델이 더욱 명확해졌다.

한계 설명: 디수이후 포럼 신제품은 대부분 발표 기준이며, 구체적 파라미터는 제조사 공식 데이터를 기준으로 한다(LX500 ‘양산’ 일정, K3 ‘네 가지 1위’ 구체적 차원은 공식 백서 필요). eet-china/EDN 등 원사이트는 크롤링 방지가 적용되어 있어 본문 세부 사항은 주로 제목과 다중 출처 교차에 근거한다. 왕이리가 육성한 베이징 칩 스타트업이 20억 위안 초과 B 라운드 투자를 완료했으나(36kr/즈둥시, 8/14) 명령어 세트 방향을 확인할 수 없어 산업 자본 동향 참고로만 기록하고 본문에는 포함하지 않았다. 본 보고서의 GitHub 데이터는 미인증 API 기반이다(60 req/h 속도 제한 내 완료).
