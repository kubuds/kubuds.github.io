1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 샹산: 새로운 벡터 백엔드에 VIDiv 지원 병합, 저장 큐 수정 및 검증 저장소 배치 푸시 (09-08)

날짜: 2026-09-08 (15:47~19:30 베이징 시간 배치)　출처: GitHub openxiangshan/XiangShan commits

샹산 오픈소스 고성능 코어 (쿤밍후) 새로운 벡터 백엔드 기능 보완 지속: 09-08 배치에서 feat(VIDiv) “support VIDiv” 병합, 벡터 실행 경로에 정수 나눗셈 명령어 지원 추가; 동일 배치에서 fix(StoreQueue) 벡터 비활성 요소 (vector inactive element)로 인한 예기치 않은 uncacheMove (#6474) 수정. 09-06 전체 레지스터 이동, 09-07 vfma/vfmac 부동소수점 곱셈-덧셈 및 widen 명령어 배치와 결합하여, 새로운 벡터 백엔드가 “레지스터 이동—부동소수점 곱셈-덧셈—정수 나눗셈—후속 행렬/리덕션 연산” 순서로 명령어 범위를 빠르게 확장 중임을 판단할 수 있음. 같은 날 openxiangshan 조직 하에 검증 및 도구 저장소 배치 푸시: NEMU (16:27), XSAI (00:26 전후 배치, 16:26 UTC 푸시), difftest (15:27), gsim, XSCache, XiangShan-Dashboard (23:42), GEM5 등 모두 pushed 신호 있으며, 이는 지원 검증 환경의 정기 이터레이션이며 릴리스는 없음. 샹산 엔지니어링 측은 이미 벡터 서브시스템 고빈도 개발기에 진입했으며, 새로운 벡터 백엔드 병합 리듬을 지속 추적할 것을 권장.

1.2 오픈소스 하드웨어 데모: Baochip-1x, FPU 없이 온칩에서 완전한 GPT 훈련 달성하여 HN 등재 (09-08)

날짜: 2026-09-08 (HN 등재 21:49 베이징 시간; 원문 09-04)　출처: Hacker News, rvembedded 원문, GitHub AI-from-Scratch-in-C

임베디드 엔지니어 Armstrong Subero가 데모를 발표했다: 자신의 Rovari 교육 플랫폼 생태계 내에서 자체 개발한 “AI from Scratch in C” 과정 원고의 GPT 훈련 프로그램을 bunnie Huang이 설계한 오픈소스 칩 Baochip-1x(Dabao 평가 보드, Crowd Supply 출하)로 완전히 이식하여 구동에 성공했다. Baochip-1x는 22nm “mostly open” RISC-V SoC이다: 350 MHz RV32IMAC 코어, FPU 없음(F 확장 없음), Flash 없음, 4 MB ReRAM 실행 코드 + 2 MB SRAM. 데모 모델은 27,680 파라미터의 decoder-only transformer(어휘 28, d_model 32, 2층, 4헤드, context 64)로, 완전한 역전파, Adam 옵티마이저, 그래디언트 체크를 포함하며, 전체 패키지와 소프트웨어 부동소수점 런타임 코드가 단 37 KB이고, 훈련 워킹셋은 약 1 MB(활성화 캐시가 426 KB 차지), 온칩에서 무작위 가중치로부터 훈련에 약 1시간이 걸리며, 가중치는 최종적으로 ReRAM에 기록된다. 각 부동소수점 곱셈-누산은 소프트웨어 부동소수점 시뮬레이션으로 완료된다(매 단계 약 460만 회). 이 글은 세 가지를 보여준다: FPU 없는 MCU 단말 측 훈련으로 “최소 실행 가능 GPT”가 가능하다는 것, ReRAM이 22nm에서 Flash 대체품으로 이미 실제 상용화되었다는 것, 오픈소스 칩과 오픈소스 교재의 조합으로 최전선 개념을 재현할 수 있다는 것. HN 09-08 저녁에 순위에 올랐으며(약한 화제성), 내용의 교육적 가치가 높아 오픈소스 하드웨어 및 엣지 AI 교육 방향 관찰로 수록한다.

2. 제품 및 생태계 동향

2.1 Midea가 Shanghai HiSilicon과 함께 “Jingwei A²MCU” 단말 측 AI 스마트 냉장고 출시: 자체 개발 RISC-V 코어 백색가전 적용 (09-08)

날짜: 2026-09-08(Kuaikeji 18:48 보도)　출처: Kuaikeji, HiSilicon 공식 홈페이지 Hi3066M 제품 페이지

HiSilicon은 09-08 Midea와 공동으로 구축한 단말 측 AI 스마트 냉장고 기술 방안을 대외 공개했다: “Jingwei A²MCU” 시리즈 칩을 탑재하여 단말 측 AI 강화학습으로 종합 절전 9.6%를 달성하며, 6월에 새로 시행된 냉장고 에너지 효율 국가 표준(500L 양문형 1등급 에너지 효율 일일 소비전력이 0.92도에서 0.55도로 감소, 진입 장벽 30%~40% 상향)에 따라 산정하면 단일 제품이 1년에 약 19.3도 전력을 절약할 수 있다. Jingwei A²MCU는 HiSilicon이 에어컨·냉장고·세탁기·주방 백색가전 시나리오를 중심으로 한 시리즈형 MCU로, 자체 개발 RISC-V 코어 기반이다(HiSilicon 공식 홈페이지 판매 중 Hi3065H/Hi3066M 등 모델: 200 MHz 32비트 RISC-V + FPU, 내장 eAI 엔진, 512 KB Flash / 64 KB SRAM). eAI 엔진은 단말 측 절전 알고리즘 연산자에 특화 최적화되어 강화학습 정책이 냉장고 메인 컨트롤러와 동일 칩에서 실시간 실행되도록 한다. 방안은 “단말-클라우드 협업 + 순수 단말 측” 이중 트랙(오프라인 사전 훈련 + 온라인 적응 미세조정)과 “AI 메인 컨트롤 + PID 백업” 이중 트랙 보호를 채택한다. 500만 대 온라인 냉장고 기준으로 연간 약 8.8만 톤 탄소를 감축한다. 의의: HiSilicon RISC-V MCU + 단말 측 AI가 선두 백색가전 브랜드의 플래그십 에너지 효율 시나리오에서 규모 있게 적용된 사례로, “RISC-V의 가전 진입”이 메인 컨트롤러 대체에서 단말 측 지능화로 나아가는 벤치마크 사례이며, 6월 신국가표준이 이끄는 백색가전 에너지 효율 업그레이드 창과 공명한다.

3. 국내 팀 동향 및 심층 분석

3.1 Shanghai Jiao Tong University IPADS 주도 SPMP 메모리 보호 확장이 RISC-V 국제 표준에 공식 병합, 국내 최초로 완전 주도한 ISA 기능 (뉴스 09-08, 승인 08-31)

날짜: 2026-09-08(Wenhui/Shangguang 등 집중 보도; 표준 승인 08-31)　출처: Shangguang News/Wenhui Bao, Sina Finance 전재

국내 주류 매체가 09-08 표준 이정표를 집중 보도했다: 2026-08-31, Shanghai Jiao Tong University 컴퓨터과학대학 IPADS(병렬 및 분산 시스템 연구소, Chen Haibo 교수 팀)가 주도 추진한 SPMP(특권 모드 물리 메모리 보호) 명령어 집합 표준이 RISC-V 국제 재단 이사회(BoD) 심의를 공식 통과하여 RISC-V 명령어 집합 아키텍처(ISA) 표준에 병합되었다. 이는 RISC-V 국제 재단이 2015년 설립된 이래 최초로 중국 본토 팀이 처음부터 자체적으로 발의하고 완전히 주도한 ISA 표준 기능이다: 2019-09-23 팀이 커뮤니티에 아키텍처 초안을 제출했고, 약 7년(2500여 일)의 기술 심사와 방안 수정을 거쳤으며, 승인 시 워킹 그룹 의장은 IPADS 박사 Yang Bicheng이었다. SPMP는 프로세서에 특권 모드의 물리 메모리 보호와 격리 기능을 제공하여 RISC-V의 보안 아키텍처약점을 보완한다. 의의: 이는 국내 기관이 처음으로 RISC-V 확장 표준 제정에서 “제안부터 최종안까지”의 완전한 주도권을 확보한 것으로, 중국 팀이 수동적 규칙 추종에서 규칙 정의 참여로 전환했음을 상징하며, 향후 국산 RISC-V 보안 기능(각종 격리/기밀 컴퓨팅 확장 등)이 국제 표준에 진입하기 위한 패러다임 경험을 축적했다. 본 리포트는 이 사건을 이전에 수록하지 않았으며(승인일 08-31 전후 모니터링 기간 누락), 이번에 주류 매체 보도에 따라 추가 수록한다.

3.2 기술 일보가 티베트 최초의 RISC-V 천 카드 컴퓨팅 파워 클러스터 보도를 게재: 시무 컴퓨팅 STCP950L이 671B급 모델 지원 (보도 09-08, 클러스터 2026-04 납품)

날짜: 2026-09-08 (기술 일보 게재; 클러스터 실제 납품 운영은 2026-04)　출처: 기술 일보/중국과학기술망, 티베트 자치구 정부망 (2026-04-08 최초 발표)

기술 일보 09-08 게재: 차이나 모바일 티베트 법인과 시무 컴퓨팅이 라싸에서 티베트 최초의 천 카드 RISC-V 아키텍처 컴퓨팅 파워 클러스터를 성공적으로 납품하고 정식 운영을 시작했다. 이는 고원 지역 국산 RISC-V 하이엔드 컴퓨팅 파워의 공백을 메우는 것으로, 차이나 모바일 티베트 법인이 자치구의 “컴퓨팅 파워 에베레스트” 전략을 이행한 실천 사례이다. 클러스터는 시무 컴퓨팅이 자체 개발한 STCP950L NPU AI 컴퓨팅 파워 카드를 기반으로 구축되었으며, 출하부터 배치 점등, 테스트 검수까지 단 20일이 걸렸고 30일 시범 운영 동안 안정적으로 작동하여 70억에서 6,710억 파라미터 대형 모델의 배치를 지원하고 있으며, 배치 추론, 실시간 AI 서비스 및 대형 모델 지능형 에이전트 시나리오에 전면적으로 적응한다. 중점 서비스 분야는 스마트 정무(“일망통판” 가속화), 산업 디지털화(특색 농업, 문화관광) 및 민생 서비스(원격 의료, 스마트 교육) 세 가지이다. 명시할 사항: 추적 결과, 이 클러스터의 납품 운영 정보는 최초로 티베트 일보가 2026-04-08에 보도했으며(본 리포트 시스템 당시 미수록), 이번에는 기술 일보가 재게재하면서 모니터링 기간에 진입한 것으로, 이미 착수된 프로젝트에 대한 권위 매체의 재진술이며, 핵심 증분은 “초고원 극한 환경에서의 장기 안정 운영” 검증 결론이다. 의의: 고고도, 저기압, 큰 일교차 환경은 컴퓨팅 파워 하드웨어 안정성에 엄격한 요구를 하며, 천 카드급 국산 RISC-V AI 컴퓨팅 파워가 이러한 특수 시나리오에서 규모화 착지한 것은 RISC-V가 지능형 컴퓨팅 인프라에 진입하는 데 극한 환경 실증을 제공한다.

날짜: 2026-09-08　출처: XUANTIE-RV/damo-rv-priv-ats commits, sophgo/zsbl, spacemit-com/docs-ai, sipeed/maix_ax620e_sdk 등 commits API

국내 팀의 GitHub 측은 수요일 전야까지 모두 일상적 개발로, 릴리스급 동향은 없었다: 다모원 쉬안티에 공개 저장소 damo-rv-priv-ats는 09-08 11:29에 “add sail in github action” (#28)을 병합하여 sail(RISC-V 형식 의미 시뮬레이터)을 GitHub Actions에 연동했으며, 09-07에 추가된 Hypervisor Za* 테스트의 검증 체계 보강 리듬을 이어가는 것으로, 규범 테스트 인프라 구축에 해당한다. Sophgo의 zsbl과 sophgo-edk2는 각각 14:19, 20:20 전후에 푸시되었으며 UEFI/부팅 툴체인의 일상적 반복이다. Spacemit(docs-ai 19:13, docs-chip 10:28)과 llama.cpp fork(11:14, 업스트림 동기화 성격)에 푸시가 있었으며 모두 문서 또는 동기화 업데이트이다. Sipeed의 maix_ax620e_sdk 및 그 kernel/msp, MaixCDK는 11:54~12:10에 배치 푸시되었으며 AX620E 관련 SDK의 일상적 진화이다. Nuclei-Software, eswincomputing, revyos는 모니터링 기간 내 침묵했다. 결론: 국내 팀의 뉴스 측에는 새로운 증분이 없으며, 실질적 동향은 위 GitHub 커밋이 주를 이루고, 내일 IICIE 전시회 모니터링 기간에 진입하면 뜨거워질 것으로 예상된다.

4. 체화 지능 및 로봇 특별 장

4.1 모니터링 기간 관찰: 오늘 선전 IICIE 개막, RISC-V 산업 생태 혁신 대회와 체화 지능 산업 대회 오늘 오후 개최 (09-09)

날짜: 2026-09-09 (오늘 개막; 본 모니터링 기간은 08:18 기준 개최 첫날 즉시 보도 없음)　출처: IICIE 회의 일람, IICIE 공식 의제 페이지

어제 보고서에서 예고한 선전 IICIE(국제 집적회로 혁신 박람회)가 오늘(09-09~11) 선전 국제 컨벤션 센터(바오안)에서 개막했으며, CIOE 중국 광박람회, elexcon 선전 국제 전자전과 세 전시회가 동시기에 같은 장소에서 연동 개최된다. 총 전시 면적은 32만 제곱미터, 참가 기업은 5000개사를 넘는다. RISC-V 관련 일정은 오늘 오후에 집중된다: 14호관 2층 14C “2026 RISC-V 산업 생태 혁신 대회”와 15호관 내 회의실 “2026 엠바디드 인텔리전스 산업 대회——컴퓨팅에서 실행까지, 엠바디드 인텔리전스 시스템 구축”이 동시에 개최된다; Damo Academy XuanTie, SopHgo, T-Head, ZTE Microelectronics, Ingenic 등이 공식 참가 명단에 있으며, 전시 구역에는 “RISC-V 생태 응용 전시 구역”과 AI+ 특색 전시 구역이 마련된다. 어제 보고서에서는 이미 “XuanTie/SopHgo/T-Head 참가, 오늘부터 국내 RISC-V x 엠바디드 동향 실현 관찰 창구에 진입”을 예고했다; 이번 모니터링 기간(오늘 08:18 기준) 내에는 아직 개막 첫날의 현장 보도와 신제품 발표 정보가 없으며, 대회 성과는 내일 보고서에서 중점적으로 후속 추적할 것이다.

5. 요약 및 트렌드 관찰

이번 보고서 모니터링 기간은 이벤트 밀도가 회복되기 전야에 해당한다: 뉴스 측에서는 국제 표준 이정표 1건과 컴퓨팅 실현 보도 2건이 나타났고, 오픈소스 커뮤니티와 국내 팀 GitHub는 일상적 반복 개발을 이어갔으며, 엠바디드 방향은 오늘 개막한 선전 전시회 실현 창구에 진입했다. 요점을 정리하면 다음과 같다:

첫째, 표준 주도권에서 “제로의 돌파”를 실현했다. 상하이 자오퉁대 IPADS가 주도한 SPMP 메모리 보호 확장이 08-31 RISC-V 국제 재단 이사회 심의를 통과해 ISA 표준에 통합되었으며, 이는 국내 최초로 제안부터 최종안까지 완전히 주도한 ISA 특성이다(2019년 제출, 약 7년간 난관 공략). 09-08 Wenhui/Shangguang 등 주류 매체의 집중 보도를 받았다. 보안 체계 아키텍처와 “규칙 정의” 발언권 서사가 동시에 고조되고 있으며, 더 많은 국내 보안/격리류 확장 제안이 국제 표준으로 가속화될 것으로 예상된다.

둘째, RISC-V 컴퓨팅 실현에서 “고급 컴퓨팅+엔드사이드 백색가전”이라는 양극단 사례가 나타났다. Seamicro STCP950L 천 카드 클러스터가 티베트 초고원 환경에서 장기간 안정적으로 운용되었으며(과기일보 09-08 재게재, 671B급 모델 지원), RISC-V 지능형 컴퓨팅 인프라의 극한 환경 신뢰성을 검증했다; HiSilicon Jingwei A²MCU는 자체 개발 RISC-V 코어+eAI 엔진으로 Midea 냉장고 엔드사이드 절전 시나리오에 진입했으며(종합 절전 9.6%), 6월 신국가표준 창구를 활용해 “RISC-V+엔드사이드 AI”를 선두 백색가전에서 규모화하여 실현했다.

셋째, 오픈소스 프로세서 엔지니어링 리듬이 지속되었다. XiangShan 새 벡터 백엔드가 이틀 연속 vfma/widen(09-07)과 VIDiv, StoreQueue 수정(09-08)을 추진하며, 벡터 서브시스템은 고빈도 기능 보완기에 진입했다; Damo Academy XuanTie priv-ats가 sail 형식화 의미 테스트를 CI에 연결하며 검증 체계를 지속 강화했다; CVA6, OpenSBI 등 해외 오픈소스 코어는 모니터링 기간 내 기본적으로 침묵했으며, XiangShan/XuanTie가 현재 가장 활발한 오픈소스 측 신호원을 구성한다.

넷째, 이벤트 창구가 열렸다. 오늘 IICIE 선전이 개막했고, RISC-V 산업 생태 혁신 대회와 엠바디드 인텔리전스 산업 대회가 오늘 오후에 개최되며, Damo Academy XuanTie/SopHgo/T-Head가 집중 참가한다. 이번 주 중반 국내 RISC-V x 엠바디드 인텔리전스 동향은 밀집 발표기에 진입하며, 내일 보고서는 개막 첫날 발표와 연설 요점을 중점적으로 후속 추적할 것이다.

한계 설명: GitHub 미인증 API 속도 제한 하에서 org 검증은 pushed_at 정렬로 최근 활발한 저장소를 표본 점검했으며, 기본 브랜치가 아닌 푸시와 저활동 저장소는 누락될 수 있다; cva6는 09-08 23:10에 pushed 신호가 있었으나 기본 브랜치 모니터링 기간 내에 새 커밋이 없어 브랜치 또는 태그 푸시로 의심되며 본문에 포함하지 않았다; XiangShan/XuanTie 커밋 내용은 commit message만으로 판단했다; 티베트 클러스터 항목의 사건 본체는 2026-04에 발생했으며, 이번은 매체 재게재 후속 추적으로 본문에 명기했다; SPMP 승인일(08-31)은 이번 보고서 모니터링 기간보다 앞서므로 “주류 매체 보도일 09-08” 기준으로 수록하고 출처를 추적했다.
