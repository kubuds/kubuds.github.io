오늘의 중점: ESWIN Computing, 홍콩 증시 공모 공식 개시, 10월 9일 상장 예정

날짜: 2026-09-28　출처: RTHK 《ESWIN Computing 상장 최대 약 25억 위안 조달, ‘RISC-V 제1호 상장사’ 될 수도》(09-28), 경제참고망 《ESWIN Computing 홍콩 증시 공모 개시》(09-28), 홍콩상보 《RISC-V 칩 기업 ESWIN Computing(01256) 오늘 공모, 약 15.7억 주 글로벌 발행 계획》(09-28)

9월 28일, 베이징 ESWIN Computing(01256.HK)이 홍콩 증시 글로벌 발행을 공식 개시했다. 약 15.7억 주 H주(그중 약 10%는 홍콩 공개 발행)를 발행할 예정이며, 발행가 범위는 주당 1.48~1.59 홍콩달러, 1lot 2000주, 입장료 약 3212 홍콩달러, 상한 기준 총 조달액은 최대 약 24.97억 홍콩달러(약 25억 홍콩달러, 약 3.2억 달러)다. 공모는 10월 6일 청약 마감되며, 10월 9일 홍콩거래소 메인보드 상장이 예상된다. 공동 스폰서는 CITIC Securities와 CITIC Securities International이다.

회사는 CITIC Asset Management Hong Kong, 일본 Orix, 허페이건설투자, GBAHIL(광둥-홍콩-마카오 그레이터베이 지역 공동 고향 투자) 등 전략적 투자자를 유치했으며, 합계 약 11.61억 홍콩달러를 청약했다. 조달 자금은 주로 인간-컴퓨터 상호작용 및 멀티미디어 처리 칩, 상호연결 및 컴퓨팅 칩의 제품 개발과 소프트웨어·하드웨어 기술 플랫폼 구축, 잠재적 전략적 인수합병 등에 사용될 예정이다. 공모서 데이터에 따르면 2026년 3월 말 기준 회사는 150개 이상의 소프트웨어·하드웨어 협업 제품을 출시했고 전 세계 220여 개 고객에 서비스를 제공하며, 620여 개 IP 모듈과 20여 개 시리즈화된 RISC-V 코어를 축적했다. 발행이 순조롭게 진행되면 홍콩 증시 최초로 RISC-V를 주력으로 하는 칩 상장사가 된다(홍콩은 이미 2026-27 회계연도 예산안에서 RISC-V를 중점 육성 7대 신흥 산업 중 하나로 지정했다). 본지는 공모가 확정과 상장 시점에서 계속 추적할 것이다.

1.1 샹산: bosc IOMMU와 DMAC/IOPMP 통합 반영, 메인 저장소 4건 머지

날짜: 2026-09-28　출처: XiangShan 커밋: bosc IOMMU와 DMAC, IOPMP 통합(#6560)(09-28), XiangShan 커밋: ckpt_select에 랜덤 시드 전달(#6637)(09-28), difftest PR #976: MinimalMatrixConfig 검사기 호환성 수정(09-28)

XiangShan 메인 저장소의 기본 브랜치(kunminghu-v3)는 모니터링 기간 내 4건이 머지되었으며, 핵심은 bosc IOMMU와 DMAC, IOPMP의 시뮬레이션 통합(#6560)이다: 변경 사항은 OpenIOMMU 서브모듈, 시뮬레이션 최상위 및 디바이스 구성, IOMMU 테스트 케이스(Iommu.scala / SimMMIO / SimTop) 등을 포함하며, IOMMU 방향의 시스템 수준 접속이 한 단계 더 진전되었다(difftest 측에는 이전에 이미 OpenIOMMU 시뮬레이션 파일 목록 접속이 있었음, #974 참조). 나머지는 엔지니어링 측면이다: ckpt_select가 랜덤 시드 전달을 지원(#6637), CI가 dependabot 설정을 무시(#6612), kunminghu-v2에 dependabot 활성화(#6611). difftest는 09-28에 fix-ame-minimal 브랜치를 새로 생성하고 PR #976(MinimalMatrixConfig 검사기 호환성 수정)을 열었다.

1.2 XiangShan 시뮬레이션 체인: GEM5 프리페치 실험이 BDP 파라미터화 조정을 계속 추진, NEMU는 AME 검사 비활성화

날짜: 2026-09-28　출처: GEM5 커밋: 파라미터화된 BDP 증분 깊이 제어(09-28), GEM5 커밋: G12 예측형 스트림 깊이 컨트롤러 유지(09-28), NEMU 커밋: AME MS 도메인 검사 일시 비활성화(#1236)(09-28)

GEM5 프리페치 브랜치 feat-ywl-pfbuffer는 모니터링 기간 내 2건이 진행되었다: 파라미터화된 BDP(대역폭 지연곱) 증분 깊이 제어를 새로 추가하고 G12 버전 예측형 스트림 깊이 컨트롤러를 유지했다——지난 기간 31건 실험 이후의 파라미터 조정 마무리를 이어간다. NEMU는 #1236을 머지했다: AME(행렬 확장) MS 도메인의 검사 로직을 일시적으로 비활성화했으며, 이는 행렬 확장 시뮬레이션 경로의 일상적 조정에 해당한다(09-25에 v2026.09.r18을 막 릴리스했다).

1.3 rv32emu: 시스템 시뮬레이션 배치 머지, JIT와 메모리 풀 최적화 약 20건

날짜: 2026-09-28　출처: rv32emu 머지: bench 브랜치 PR #783(09-28), rv32emu 커밋: 시스템 시뮬레이션에 tier-1 JIT 선택(09-28), rv32emu 커밋: T2C 캐시 유지 관리를 핫 패스에서 제거(09-28)

교육용 RV32 시뮬레이터 rv32emu는 모니터링 기간 내 bench 브랜치 배치(PR #783, 약 20건)를 머지하며 시스템 시뮬레이션 능력을 집중 강화했다: 시스템 시뮬레이션 시나리오를 tier-1 JIT로 전환, T2C(번역 캐시) 유지 관리를 핫 패스에서 제거, 번역 코드가 guest 능동 새로고침 시 퇴역, 시뮬레이터 스레드만 메모리 풀 사용, 그리고 guest OS 하의 브랜치 샘플링 분석과 듀얼 호스트 벤치마크 기록을 새로 추가했다. 도구 측은 스크롤하여 더 많은 사전 빌드 버전을 볼 수 있도록 지원한다. 지난 기간 Linux 이미지 빌드(#786)를 수록한 이후, 이 프로젝트의 “시스템을 돌릴 수 있다, 빠르게 돌릴 수 있다” 두 축을 계속 강화하고 있다.

1.4 felix86: 온라인 코어 수 위조, Wine int 0x2d 수정

날짜: 2026-09-28　출처: felix86 커밋: 온라인 CPU 코어 수 위조 (#799) (09-28), felix86 커밋: Wine 환경에서 int 0x2d 처리 수정 (#800) (09-28)

RISC-V Linux에서 x86 게임을 실행하는 바이너리 번역 프로젝트 felix86의 모니터링 기간 내에 2건이 추가로 병합되었다: 애플리케이션에 보고되는 온라인 CPU 코어 수 위조(일부 프로그램의 코어 수에 대한 하드코딩된 가정 회피), 그리고 Wine 환경에서 int 0x2d(FPU 에뮬레이션 관련 인터럽트) 처리 수정이다. 9월 중순 이후 이 프로젝트는 높은 빈도의 호환성 개선 리듬을 유지하고 있으며, 일주일 누적 커밋 수는 이미 10여 건에 달한다.

2. 제품 및 생태계 동향

2.1 Efinix, Sapphire RV64 출시: 64비트 RISC-V FPGA 소프트 코어 SoC

날짜: 2026-09-28　출처: Business Wire《Efinix Brings 64-Bit RISC-V Performance to Embedded FPGA Designs With New Sapphire RV64 SoC》(09-28), Efinix Sapphire RV64 사용자 가이드 (공식 문서)

FPGA 제조사 Efinix, Sapphire RV64 SoC 출시: Sapphire 소프트 코어 시리즈를 32비트에서 64비트 RISC-V로 확장——7단 파이프라인, 선택적 A／F／D／C 및 Zba／Zbb／Zbs／Zicbom 확장 지원; 온칩 4~512KB RAM, 다중 L1 명령어／데이터 캐시, 선택적 L2 캐시(64~512KB, 8-way), 분기 예측기 및 하드웨어·소프트웨어 프리페치; DDR／LPDDR4 메모리 컨트롤러와 결합하여 1~4개의 64비트 코어 구성 가능, 주파수 20~400MHz. 제품은 「애플리케이션이 32비트 코어의 주소 지정, 캐시 및 I/O 상한을 초과한」 엣지 AI 및 임베디드 Linux 시나리오를 겨냥하며, 모든 Titanium／Topaz FPGA와 Trion(T20 이상) 디바이스에 사용 가능하고 Efinity IP Manager 그래픽 구성 도구를 제공한다. 공식 문서에 따르면 이 코어는 오픈소스 VexiiRiscv와 유사하며 자사 디바이스에 맞게 최적화되었다.

2.2 Xcena MX1, EE Times 상세 분석: CXL 메모리에 1000개 이상의 RISC-V 코어 통합

날짜: 2026-09-28　출처: EE Times《Xcena Cuts Data Movement to Address Memory Bottlenecks》(09-28), IndexBox《Xcena MX1: CXL Near-Memory Processing with 2TB DDR5 and 1,000+ RISC-V Cores》(09-28)

EE Times와 IndexBox는 09-28 한국 반도체 기업 Xcena의 MX1 컴퓨팅형 CXL 메모리 디바이스(금년 여름 Hot Chips 2026 발표)를 상세 분석하는 기사를 게재했다: 단일 카드에 최대 2TB DDR5(4채널, CXL 3.2 ／ PCIe 6.0) 통합, SSD는 InfiniteMemory를 통해 바이트 주소 지정 메모리 형태로 노출되며, 1000개 이상의 자체 개발 1.4GHz RISC-V 코어로 구성된 근접 메모리 컴퓨팅 유닛(기술 매체 보도에서는 3072개, 24개 서브시스템이 128MB L3 공유)과 약 3 TFLOPS FP32/FP16 벡터 엔진을 통합; 공식 기준으로 데이터 분석 워크로드에서 CXL을 통해 접근하는 호스트 CPU 대비 최대 4.7배 처리량, 18.7배 에너지 효율을 달성한다. 개발자는 LLVM 툴체인을 통해 C／C++／Rust로 프로그래밍하며, 2026년 말 양산, 2027년부터 매출 발생을 계획하고 있다. RISC-V 코어의 「메모리 월」 시나리오에서의 규모화된 도입이 이번 보도들의 핵심 포인트이다.
