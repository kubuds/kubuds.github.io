오늘의 중점: Damo Academy XuanTie C950, 독립 가속기 없이 27B 대규모 모델 구동 성공, 성과가 RISC-V 국제 재단 공식 웹사이트에 소개됨

날짜: 2026-10-15　출처: riscv.org: V Questions with… DAMO Academy’s Dr. Jianyi Meng (10-15)

RISC-V 국제 재단 공식 웹사이트 ‘V Questions’ 칼럼에 Damo Academy XuanTie 수석 과학자이자 RISC-V 중국 서밋 2026 부의장인 Meng Jianyi와의 인터뷰가 게재되어, XuanTie의 최근 대표적 성과를 체계적으로 소개하고 10-18 선전 서밋을 예열했다. 요점:

  • 마일스톤 데이터: XuanTie 팀이 64코어 C950 목표 구성에서 Qwen3.8-27B(270억 파라미터) 를 네이티브로 구동했으며, 독립 GPU／NPU 없이 디코딩 속도가 30 tokens／초 초과(약 20–22 단어／초, 자연 실시간 대화 수준 도달); 이 워크로드는 약 400 GB／s 의 메모리 데이터 이동 능력이 필요하며, 인터뷰에서는 「양자화, 행렬 명령어, 온칩 메모리, 대역폭과 연산자 최적화가 반드시 단일 시스템으로协同 설계되어야 한다」고 강조했다.
  • C950 과 AME: C950 은 서버급 64비트 슈퍼스칼라 프로세서로, RVA23 프로파일(RVV 1.0 포함) 을 범용 컴퓨팅 기준선으로 삼는다; XuanTie 자체 개발 행렬 확장은 실리콘 검증 후 Qualcomm, IBM, VRULL, ISCAS, BOSC 등 멤버와 공동으로 AME(Attached Matrix Extension) 태스크 그룹을 발기했으며, 현재 규격의 공식 승인 및 산업 적용을 추진하고 있다.
  • 설계 트레이드오프: AME는 벡터 레지스터를 재사용하지 않고 독립 tile 레지스터를 채택——행렬 부하가 RVV 레지스터 스택을 잠식하는 것을 방지하고, 스필과 캐시 교란을 줄이며, 혼합 정밀도 누적(INT4／INT8→INT32, FP4／FP8／FP16／BF16→FP32)을 네이티브로 지원한다; 행렬 상태는 필요 시에만 활성화되며, 필요할 때만 저장／복원된다.
  • 생태계 호소: Meng Jianyi는 세 가지 기대를 제시했다——고성능 데이터센터 소프트웨어 스택의 지속적 보완(Java 런타임 적응 성과는 이미 커뮤니티에 기여), 완전한 AI 소프트웨어 체인(최적화 연산자 라이브러리, 컴파일러 업데이트, xPU로서의 RISC-V 완전한 스택), 그리고 ISA 개방성을 활용한 새로운 확장과 컴퓨팅 패러다임 탐구.

1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 openRuyi: Ruyi Firmware 20261015 연속 릴리스; K3 펌웨어와 UEFI 라인 모니터링 기간 내 여러 건 진전

날짜: 2026-10-15　출처: Ruyi Firmware 20261015 Release(10-15), ruyifirmware 커밋 기록(10-15), edk2-ruyi 커밋 기록(10-15), openRuyi 메인 저장소 커밋 기록(10-15)

openRuyi 펌웨어 라인은 연속 3일째 새 버전 「Ruyi Firmware 20261015」를 릴리스했으며, K3 플랫폼이 여전히 반복의 중심이다. 펌웨어 측 모니터링 기간 내 8건의 커밋: raw SPI 플래싱 설치 문서, A100-only 모드 인터럽트 라우팅 수정, System Information 페이지와 DRAM 목록, 그래픽 콘솔 초기화, IMG GPU 클럭 디바이스 트리 수정, 「선택 가능한 UEFI 드라이버 에뮬레이션」 패키징; 함께 edk2-ruyi 6건——K3 시스템 정보 페이지, SMBIOS DRAM 구성 보고, GOP 초기화 후 그래픽 콘솔 연결, 플랫폼 설정 그룹화와 SPI-backed 에뮬레이션 옵션. 메인 저장소 측 8건의 SPECS 업데이트는 보안 유지보수가 주를 이루었다(cups, python-nltk(CVE-2026-81726), capstone 5.0.9, llama-cpp 0.4.1, multipath-tools 0.15.1의 백포트와 업그레이드, spdk bdevperf 설치 등). openRuyi 공식 웹사이트 뉴스 페이지에는 이번 기간 새 버전 공지가 없다(최신은 여전히 2026.09).

1.2 RevyOS: 7.3 커널 브랜치에서 K3／ESWIN EIC7700 등 플랫폼 구성 일괄 활성화

날짜: 2026-10-15　출처: revyos/linux revyos/7.3.y 커밋 기록(10-15)

RevyOS는 7.3 커널 브랜치(revyos/7.3.y) 모니터링 기간 내 20건의 일괄 구성 커밋을 병합했다: 부팅 체인 측에 linuxboot 구성과 크로스／네이티브 빌드 CI 추가; 플랫폼 측에서 한 번에 활성화——SpacemiT K3(UFS／DC)와 K1(Banana F3 USB2), ESWIN EIC7700(ARCH_ESWIN／DWMAC／PINCTRL), TH1520 USB 모듈(RESET_GPIO 포함), USB Type-C 와 디스플레이 체인(TCPM／UCSI／DP_ALTMODE／PHY_SPACEMIT), DRM_AST, ERRATA_PICOHEART 등 수십 항목, 그리고 8250 시리얼 런타임 포트 수를 6으로 조정. 이 배치는 RevyOS가 7.3 커널 라인을 위해 다수 벤더 플랫폼 지원 범위를 통일적으로 집약하고 있음을 보여준다.

1.3 openKylin, OSS EU 2026 참가: RVV 최적화로 ONNX Runtime FP32 추론 2–5배 향상

날짜: 2026-10-15(회의 10-07~09)　출처: MarkTechPost: openKylin Outlines Its Vision for Reimagining Linux in the AI Era at OSS EU 2026(10-15), openKylin 공식 웹사이트

MarkTechPost는 openKylin이 Open Source Summit Europe 2026(프라하)에 참가한 내용을 정리해 보도했다: 이사장 Min Liu는 메인 무대 기조연설에서 통합 AI 런타임 KART와 시스템 수준 Agent 실행 환경을 소개했으며(「자원 관리」에서 「의도 관리」로 나아가는 3계층 아키텍처: KART 런타임 계층／Agent 실행 계층／역량 계층), 기술위원회 위원 Jianfeng Li는 《Building an AI-Ready Linux Desktop on RISC-V》 라이트닝 토크를 진행했다. RISC-V 측 핵심 요점: RVV 커널 최적화로 ONNX Runtime FP32 추론이 2–5배 빨라졌으며, 관련 커널 최적화와 추론 프레임워크 적응 작업은 업스트림에 기여할 계획이다; AI 스택은 SpacemiT K3에서 vLLM으로 CPU 추론을 수행하는 것을 지원하며, 제공 형태에는 .deb, Python wheel, Conda, Docker가 포함된다. 서밋 현장에서 SpacemiT는 openKylin 3.0이 사전 설치된 K3 노트북을 전시했다.

2. 제품 및 생태계 동향

2.1 HPMicro HPM5100 시리즈 RISC-V 혼합신호 MCU 양산 돌입: 아날로그 및 모터 제어에 주력

날짜: 2026-10-15　출처: CNX Software: HPMicro HPM5100 RISC-V MCU integrates four 16-bit ADCs, four op-amps(10-15)

상하이 HPMicro의 HPM5100 시리즈 32비트 RISC-V 혼합신호 MCU가 해외 매체에 보도되었다: 첫 출시 부품 HPM5151은 400 MHz RISC-V 코어, 416 KB SRAM＋1 MB Flash를 갖추고 4채널 16비트 ADC, 4채널 연산증폭기, 4채널 아날로그 비교기를 통합하여 아날로그 센싱 및 모터 제어 시나리오를 겨냥한다; 인터페이스로는 USB 2.0 OTG(PHY 내장), CAN FD, 다채널 UART／SPI／I2C와 32채널 PWM을 포함하며 하드웨어 부동소수점과 DSP 명령어를 지원한다. 시리즈는 이미 양산 중이다: QFN48／QFN68／LQFP100 패키지 가격은 15.60／16.90／19.50 위안, EVK 개발 보드는 258 위안; SDK 1.13.0(9월)에 지원이 추가되었으며 SEGGER Embedded Studio for RISC-V가 함께 제공된다.

2.2 Orange Pi O1 출시: SOPHGO BM1688(RISC-V 코프로세서 포함) 탑재, 16 TOPS 온디바이스 AI에 주력

날짜: 2026-10-15　출처: CNX Software: Orange Pi O1 SBC features 16 TOPS SOPHGO BM1688 AI SoC(10-15), OrangePi O1 제품 페이지

OrangePi가 OrangePi O1 싱글 보드 컴퓨터를 발표했으며, SOPHGO BM1688 SoC 기반: 8코어 Arm Cortex-A53 @1.65 GHz + RISC-V C906 코프로세서 @1.2 GHz, 내장 16 TOPS@INT8 신경망 가속 엔진, 16채널 1080p 비디오 디코딩/10채널 인코딩 지원; 8/16 GB LPDDR4X, M.2 NVMe, 듀얼 기가비트 이더넷 포트, Wi-Fi 6E/BT 5.3, 2×USB 3.0 및 4G/5G 모듈 확장 제공. 가격 195달러(8 GB)/325달러(16 GB)(별도 7.9달러 쿨러); Ubuntu 이미지와 Linux 소스 코드는 추후 제공 예정. SOPHGO BM1688 생태계(이전에는 주로 모듈과 서버 형태)가 범용 SBC 채널로 하향 확장되기 시작.

2.3 Espressif ESP32-S31 Linux BSP에 ‘플래시 레이아웃 구성 가능’ 추가; 커뮤니티 포팅 버전 v0.3.1 릴리스

날짜: 2026-10-15　출처: espressif/esp-linux-bsp(10-15 업데이트), esp32-s31-linux: v0.3.1 Release(10-15)

‘Linux on ESP32-S31‘를 둘러싼 두 가지 새로운 진전: 첫째, Espressif ESP32-S31 Linux BSP(esp-linux-bsp)가 모니터링 기간 내 ‘esp32s31: 플래시 레이아웃 구성 가능화’ 커밋을 병합——해당 저장소는 Buildroot 이미지 레이아웃과 패키징 도구를 담당하며(post-image 훅이 U-Boot SPL을 Espressif 이미지 형식으로 패키징하고 SPL, U-Boot FIT, Linux 디바이스 트리, XIP 커널과 cramfs 루트 파일시스템을 s31_full_flash.bin으로 병합), 현재 개발자 프리뷰 브랜치에서 유지보수 중. 둘째, 커뮤니티 프로젝트 esp32-s31-linux가 v0.3.1 릴리스(Linux 7.2 + OpenSBI 1.9가 ESP32-S31-Korvo-1에서 실행, 16 MiB PSRAM을 메모리로 사용), 블루투스와 802.15.4 RCP 지원을 추가하고 릴리스 노트를 개선. ESP32-S31(듀얼 RV32 코어 @320 MHz)이 ‘Linux를 위해 태어나지 않은’ MCU에서 공식과 커뮤니티 두 가지 오픈소스 시스템 경로를 갖춘 실험 플랫폼으로 변모.

2.4 RVSC2026 카운트다운: 개막 전 마지막 일정과 연사 업데이트; 서밋 공식 웹사이트 소스 코드 13건 커밋

날짜: 2026-10-15　출처: 제6회 RISC-V 중국 서밋 공식 웹사이트 일정 페이지(10-15 업데이트), summit-website 저장소 커밋 기록(10-15)

제6회 RISC-V 중국 서밋(10-18 개막, 선전 컨벤션 센터(푸톈))이 개막 전 마무리 단계에 진입: 공식 웹사이트 대회 일정 페이지가 모니터링 기간 내 업데이트——10-20 RAG 세션 발표 제목이 《클라우드 컴퓨팅 AI 해제: RISC-V CPU를 사용한 RAG 워크로드 가속》(알리바바 다모아카데미 저우윈페이, 뤼이저)으로 확정, 샹산 HPC 세션에 공동 연사 추가, DiffTest-H 발표 제목이 ‘30 MHz’로 업데이트, 메인 페이지 중영문 히어로 이미지 교체; 서밋 공식 웹사이트 소스 코드 저장소에 모니터링 기간 내 13건 커밋(영문 참가업체 요약 페이지 신규 추가 포함). 개막 전 자료가 개막에 맞춰 기본적으로 준비 완료.

2.5 The Next Platform, zeroRISC 인터뷰 게재: 오픈소스 실리콘 10년

날짜: 2026-10-15　출처: The Next Platform: A Decade In, zeroRISC Sees A Bright Future For Open Silicon(10-15)

The Next Platform이 zeroRISC 창립자 Dominic Rizzo(OpenTitan 초기 책임자)와의 장문 인터뷰를 게재, 오픈소스 실리콘 10년과 상업적 경로를 회고. 핵심 논점 중 하나는 RISC-V의 개방성이 ‘오픈소스 구현’에 라이선스를 부여했다——’오픈소스 ISA가 있는데 왜 구현을 개방하지 않는가’; zeroRISC는 현재 OpenTitan 보안 루트(RISC-V 기반)를 기반으로 데이터센터, ICS/OT와 IoT를 대상으로 실리콘+소프트웨어+클라우드 관리의 완전한 솔루션을 제공하며, 오픈소스 실리콘이 공급망 신뢰에서 차지하는 위치를 논의. 이 글은 오픈 하드웨어와 보안 루트 시장의 진화를 관찰하는 하나의 시각.

3. 국내 팀 심층 분석

3.1 다모아카데미 XuanTie: 확장 사양 저장소 3건 병합; 프리빌리지 테스트 스위트 Sail 0.15로 업그레이드

날짜: 2026-10-15　출처: thead-extension-spec 커밋 기록(10-15), damo-rv-priv-ats 커밋 기록(10-15)

공식 웹사이트 인터뷰 외에(오늘의 중점 참조), XuanTie GitHub 조직 모니터링 기간 내 움직임은 규격과 테스트 두 축에 집중되었다: thead-extension-spec은 3건을 병합했다——codex/fix-rv32-lwud 수정(PR #80), 사용자 PR #78 및 README 정기 업데이트(#72)로 확장 규격 문서를 지속적으로 다듬었다. damo-rv-priv-ats는 테스트 스위트의 Sail 형식 모델 의존성을 0.15로 업그레이드(PR #38)하여 특권 아키텍처 테스트의 재현성을 향상시켰다. 자체 개발 테스트 스위트 damo-rv-ats는 모니터링 기간 내 신규 추가가 없었다.

3.2 샹산: GEM5 5건 커밋으로 명령어 인출 및 BTB 최적화; NEMU/difftest 수정 지속 추진

날짜: 2026-10-15　출처: GEM5 xs-dev 커밋 기록(10-15), NEMU 커밋 기록(10-15), difftest 커밋 기록(10-15), XiangShan-doc 커밋 기록(10-15)

샹산 검증 체인(GEM5 브랜치 xs-dev)은 모니터링 기간 내 5건 커밋: MLP 인식 명령어 인출 전략 도입 및 BlockStall 인출 로직 재구성, 프라이빗 MBTB victim cache 기본 활성화(#1235) 및 그 공유 MBTB 쓰기 하의 프라이빗 VC 무효화 수정(#1236), 주간 이상적 BTB SPEC 벤치마크 추가(#1233), PR에 따라 만료된 Quick Check 실행 취소(#1237). 백엔드 수정: NEMU는 페이지 경계를 넘는 저장 페이지 폴트 시 첫 페이지 쓰기 보존 수정(#1240, RVV); difftest는 trace 업데이트를 핸드셰이크에 게이팅(#990). 메인 저장소 kunminghu-v3는 모니터링 기간 내 신규 병합 없음(브랜치 레벨 푸시 위주, kunminghu-v2는 ChiselAIA 백프레셔 수정 1건); 주변 저장소도 동시에 활발했다——XiangShan-doc RVSC2026 문서 수정 2건, AME_gem5 softmax 연산자 예제 추가(#7).

3.3 Sophgo: SG2042 SDK v20261015 릴리스; tpu-mlir/sophon-sail 업데이트

날짜: 2026-10-15　출처: sophgo/bootloader-riscv 커밋 기록(10-15), sophgo/tpu-mlir 커밋 기록(10-15), sophgo/sophon-sail 커밋 기록(10-15)

Sophgo는 세 축으로 추진했다: bootloader-riscv는 SG2042 SDK v20261015 릴리스 노트를 발표(서버 플랫폼 부팅 펌웨어의 버전별 주기 업데이트 지속); tpu-mlir(TPU 컴파일러, 998 스타)는 「백엔드 업데이트」 커밋을 병합; sophon-sail(추론 인터페이스 계층)은 rawstream 모듈 임시 FBC bm_image의 수명 주기 문제를 수정(PR #17). 신제품 측면(2.2 샹청파이 O1의 BM1688 채택 참조)과 결합하면, Sophgo의 「칩＋컴파일러＋추론 런타임＋완제품 채널」 엣지 AI 조합이 모니터링 기간 내 여러 지점에서 개화했다.

3.4 SpacemiT: 에이전트 역량 배포 인프라 구축——APM, Agent Hub 및 Bianbu Skills 이미지가 같은 날 실질적 내용 확보

날짜: 2026-10-15　출처: spacemit-com/agent-power-manager, spacemit-com/bibit-agenthub-plugin, spacemit-com/bianbu-skill, model-zoo-vision 커밋 기록 (10-15)

10-13에 집중적으로 개설된 「Agent 시스템 소프트웨어」 저장소 그룹이 이번 모니터링 기간에 첫 실질적 콘텐츠를 구현하며, 엣지 디바이스 Agent의 역량 배포 인프라를 지향한다:

  • APM(agent-power-manager): Go로 작성된 커맨드라인 도구로, Skill/Plugin/MCP/Expert 네 가지 「Power」의 검색, 설치, 업그레이드, 제거, 커밋을 동일한 명령 체계로 통합한다. Agent Power Cloud(APC)에서 메타데이터를 동기화하고, 버전별 설치, 트랜잭션 복구 가능, bibit 등 대상 Agent를 지원하며, Apache-2.0 오픈소스이다.
  • Bibit Agent Hub(bibit-agenthub-plugin): Bibit 내장 「역량 센터」——프론트엔드 플러그인(TypeScript/React) + 순수 표준 라이브러리 Go CLI Provider. 설치된 목록, APC 전체 마켓 브라우징, 원클릭 업그레이드 및 사용자 정의 리소스 업로드를 제공하며, riscv64 빌드를 지원한다.
  • Bianbu Skills(bianbu-skill): APC 공개 배포 Skill의 읽기 전용 미러 저장소로, 첫 회에 11개 Skill을 수록한다(K3 미디어 파이프라인, VPU/CoreMark 벤치마크, RISC-V 이식 어시스턴트, 문서-Markdown 변환, 오프라인 HTML 앱 생성 등). APC 디렉터리 스냅샷 그대로 아카이빙한다.
  • 부속 업데이트: model-zoo-vision 2건 수정(OC-SORT 칼만 추적 및 메모리 안전 #100, 비전 인터페이스 계약 및 수치 안전 #101), ai-sdk 두 번째 vision 서브모듈 업데이트, llama.cpp(mtmd-backend) 업스트림 동기화(PR #46) 및 SMT 경로 수정, lxqt-schedule에 LXQt 일정 관리 및 데스크톱 알림 도입.

지난 데일리 리포트에서 설명한 Bianbu AgentOS 컴포넌트 집중 오픈소스화 이후, SpacemiT가 채운 것은 바로 「역량 배포와 버전 거버넌스」라는 퍼즐 조각이다.

3.5 Sipeed: SLogic 브라우저 내 펌웨어 업그레이드 추가, MaixPy 3건 커밋

날짜: 2026-10-15　출처: sipeed/SLogic 커밋 기록 (10-15), sipeed/MaixPy 커밋 기록 (10-15)

Sipeed의 로직 분석기 소프트웨어 SLogic은 계속해서 고빈도 반복 개발을 진행한다. 모니터링 기간 내 웹 펌웨어 업그레이드를 추가했으며(브라우저 내에서 SLogic16U3/32U3에 OTA 푸시), 기반 라이브러리는 800 MHz 클럭 기준으로 전환하고 ngscope ADC 관련 문제를 수정했다(ALL-LOGIC 동일 배치 반영). MaixPy 메인라인은 3건을 병합했다(RVV 문서 내비게이션 및 예제 개선 등). SLogic v2.3.0(10-14) 릴리스 이후, 툴체인과 펌웨어 업그레이드 경험은 여전히 빠르게 다듬어지고 있다.

4. 임바디드 인텔리전스와 로보틱스 특별 장

4.1 SpacemiT ROS2 시뮬레이션: 휴머노이드 로봇 humanoid_mujoco에 RGBD 시뮬레이션 실행 명령 추가

날짜: 2026-10-15　출처: ros2_simulation 커밋 기록 (10-15)

spacemit-robotics 조직의 이번 모니터링 기간 유일한 푸시는 ros2_simulation에 있었다. humanoid_mujoco 패키지(휴머노이드 로봇 RL과 MuJoCo 동일 인스턴스 시뮬레이션, 「LingLong」 전용 설정 포함)에 RGBD 시뮬레이션 실행 명령 hmi_runtime을 새로 추가했다(3D LiDAR/RGBD 카메라, 포인트 클라우드 및 TF 퍼블리시, RTAB-Map/Nav2 연동 포함). 해당 저장소의 빌드 대상은 k3-com260-kit-humanoid-linglong이다. 「휴머노이드 로봇 시뮬레이션 훈련(MuJoCo+RL) → K3 로봇 키트」 경로가 소프트웨어 측면에서 한층 보완되었다. 이번 모니터링 기간 Agent 역량 배포 인프라의 구현(3.4)과 결합하면, SpacemiT의 「칩—AgentOS—시뮬레이션/RL 툴체인」 3계층 조합 윤곽이 더욱 명확해진다. 로봇 측면은 현재까지 시뮬레이션과 운동 제어가 주를 이루며, 모니터링 기간 내 새로운 하드웨어 발표는 없었다.

5. 요약 및 트렌드 관찰

  • XuanTie 고성능 서사, 국제 채널로 진출: C950 단일 장비에서 27B 대규모 모델 실행 성과가 RISC-V 국제 재단 공식 웹사이트 인터뷰를 통해 확산(10-22 베이징 세미나 및 10-20 서밋 AME 세미나와 중첩)되며 서밋 주간을 예열; AME는 「자체 개발 매트릭스 확장」에서 「Qualcomm／IBM 등을 이끌어 공동 추진하는 표준 제안」으로 업그레이드되었으며, 이는 가장 주목할 만한 추적 단서다.
  • 오픈소스 배포판과 펌웨어의 「플랫폼 커버리지 겨루기」: openRuyi 펌웨어 연속 일일 업데이트(K3 라인 8건＋UEFI 6건), RevyOS 7.3 커널이 K3／EIC7700 등 플랫폼 설정을 대량 통합——RISC-V 배포판의 경쟁 초점이 「부팅 가능」에서 「플랫폼 breadth＋UEFI 경험＋보안 유지보수」로 전환되고 있다.
  • 엣지 Agent 인프라, 컴포넌트에서 배포로 이동: ESWIN APM／Agent Hub／Skills 이미지가 「릴리스—검색—설치—버전 거버넌스」 폐쇄 루프를 형성하며, RISC-V 엣지 Agent 생태계에 지원 엔지니어링 툴체인이 등장하기 시작했다.
  • 세 개의 세분화 제품 라인 동일 기간 신제품 출시: HPMicro HPM5100(혼합 신호 MCU 양산), Orange Pi O1(엣지 AI SBC), Espressif ESP32-S31 Linux BSP 반복＋커뮤니티 v0.3.1——MCU, AI 박스, Linux-on-MCU 세 방향 각각에 새로운 공급이 있다.
  • 서밋 주간 개막 임박: RVSC2026이 일요일(10-18) 선전에서 개막하며, 다음 호에서는 개막식, 메인 포럼 및 각 주제 분과 포럼 첫날 내용을 중점 관찰한다.
  • 한계 설명: openKylin 항목은 10-15 보도를 근거로 하며(회의는 10-07~09), 세부 사항은 공식 후속 자료를 기준으로 한다; 커뮤니티 ESP32-S31 Linux 프로젝트는 애호가 프로젝트로, 성숙도는 해당 릴리스 노트를 기준으로 한다; 일부 저장소는 모니터링 기간 내 브랜치 수준 푸시만 있었으며, 출처 검증표에 명시하였다.
