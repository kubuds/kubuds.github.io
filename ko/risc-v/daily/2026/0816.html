1.1 RISC-V 공식 고보증 암호학(HAC) 규격 집중 업데이트: ML-KEM/ML-DSA 포스트 양자 암호 설명 세분화 (오늘의 헤드라인 중 하나)

날짜: 2026-08-15 (11:34~23:25 UTC 약 20건 커밋)　출처: riscv/riscv-high-assurance-cryptography GitHub

RISC-V 인터내셔널 재단 고보증 암호학(HAC) 규격 저장소에 모니터링 기간 동안 약 20건의 커밋이 집중되었다. 주로 포스트 양자 암호와 고보증 구현을 둘러싼 내용으로, ML-KEM(Kyber 포스트 양자 키 캡슐화)과 ML-DSA(Dilithium 포스트 양자 서명)의 명령어 집합 설명 개정, ACE-ISA-unpriv 규격 문구 통일 (“must”를 “shall”로 변경), OCB3 구조 간소화, CR 표현과 용량 상한 명확화 등을 포함하며, 리뷰 의견(review1.md) 처리와 AsciiDoc 조판 수정도 이루어졌다. HAC는 RISC-V가 FIPS 140-3급 고보증 암호 구현(상수 시간, 부채널 방어)을 지향하는 확장 규격으로, ML-KEM/ML-DSA 등 포스트 양자 명령어 집합 설명이 집중 개정 단계에 들어간 것은 RISC-V 암호 확장이 실용화·표준화로 수렴하고 있음을 보여준다. 이는 RISC-V가 금융/정부/클라우드 신뢰 경계로 진입하는 데 직접적인 의미가 있으며, 이번 주 Spectre 논문이 촉발한 보안 신뢰 논의와도 호응한다.

4. 중점 방향 특별 챕터: 임바디드 AI와 로보틱스

4.1 듀얼코어 RISC-V RT-MCU: 모션 제어 기반의 “이기종 분업” 내러티브 형성

이번 모니터링 기간 가장 방향성 있는 신호는 EE Times China의 특집 《듀얼코어 RISC-V RT-MCU가 어떻게 임바디드 로봇의 모션 제어 기반을 지탱하는가?》(08-15): 듀얼코어 아키텍처(실시간 코어가 모터/관절 제어 루프 실행 + 애플리케이션 코어가 통신/인지/엣지 AI 실행)가 임바디드 로봇 모션 제어 기반의 주류 설계 사상이 되고 있으며, 대표 제품인 Fengfan FU75XX 시리즈(32비트 RISC-V 듀얼코어, 듀얼 모터 드라이브)는 2025-11부터 “미래 로봇을 위해 태어나다”라는 포지셔닝을 취하고 있다. 이는 디수이후 포럼(08-13)의 모션 제어 신호와 완전히 동일 주파수다: Gejian 반도체 500나노초 전류 루프/단일 칩 25 자유도(어제 보고서 3.3), HPMicro HPM53M1 휴머노이드 로봇 관절 제어, SpacemiT K3 로봇 모션 제어 포지셔닝 — 국산 RISC-V 모션 제어 솔루션은 “단일코어 실시간 DSP/MCU”에서 “듀얼코어 이기종(실시간+지능)”으로 진화하고 있으며, 모션 제어 계층의 국산 대체 경로가 더욱 구체화되고 있다.

4.2 온디바이스 AI 추론의 NPU화: SPERT 전체 그래프 커널 경로

SpacemiT llama.cpp 브랜치의 SPERT 전체 그래프 커널 경로(3.1)와 Sophgo YOLOv8-pose 실전급 수정(3.2)은 함께 임바디드 AI 소프트웨어 스택의 성숙화를 가리킨다: 전자는 LLM/VLA 추론을 온디바이스 NPU 엔진으로 내려보내고(저전력 실시간성), 후자는 비전 인지 예제의 엔지니어링 결함을 지속적으로 보수한다. 어제의 LeRobot(SmolVLA/ACT) 온디바이스 배포와 휴머노이드 로봇 적응과 결합하면, RISC-V 임바디드 AI의 “인지(비전) — 결정(온디바이스 LLM/VLA) — 운동(듀얼코어 RT-MCU 모션 제어)” 3계층 국산화 경로가 점차 명확해지고 있다.

5. 요약 및 트렌드 관찰

  1. 포스트 양자 암호가 RISC-V 규격 핫이슈로 부상: RISC-V 공식 HAC 규격 모니터링 기간 내 약 20건의 커밋이 ML-KEM/ML-DSA 등 포스트 양자 암호 명령어 설명을 세분화하고 있으며, 암호 확장이 FIPS급 고보증 구현으로 수렴 — 이번 주 Spectre-on-RISC-V 논문이 촉발한 보안 신뢰 논의와 같은 방향으로, 보안/암호가 RISC-V 생태계의 공식 우선순위 의제가 되고 있다.
  2. 모션 제어 계층 “듀얼코어 이기종” 내러티브 형성: EE Times China 특집(듀얼코어 RISC-V RT-MCU) + Fengfan FU75XX + 디수이후 포럼 모션 제어 신제품(Gejian/HPMicro/K3)이 동일 주파수로, 임바디드 로봇 모션 제어 기반의 국산 RISC-V 솔루션이 “단일코어 실시간”에서 “실시간 코어+애플리케이션 코어” 듀얼코어 분업으로 나아가고 있다.
  3. 온디바이스 LLM 추론 가속이 NPU로 하강: SpacemiT llama.cpp에 SPERT 전체 그래프 커널 경로 머지, 온디바이스 대형 모델 추론이 “CPU 구동”에서 “NPU 전체 그래프 가속”으로 나아가며, 연산자 라이브러리(FlagGems-RACE), 추론 문서(docs-ai)와 완전한 체인을 구성한다.
  4. ESWIN IPO가 “상장 전야”에 진입: 홍콩증시 “RISC-V 아키텍처 제1주” 내러티브가 상장 임박까지 진전, 3년간 누적 적자 49억 위안이지만 차량용 MCU/CMS 제품 라인과 국산 RISC-V 주력 내러티브가 이를 뒷받침한다.
  5. 검증 인프라 지속 강화: OpenXiangShan difftest에 검증기 백프레셔 제어와 배치 검증 추가(처리량 향상), macOS arm64 호스트 지원 신규 추가, 오픈소스 고성능 코어의 검증 효율이 경쟁력 초점이 되고 있다.

한계 설명: EE Times China 원사이트(eet-china)는 안티 크롤링으로 접근할 수 없어, 2.1 특집 본문 세부 내용은 제목과 기존 제품 라인(Fengta FU75XX 등)을 교차 추론한 것이며, 구체적 기종 표현은 원문을 기준으로 한다. Japan Today 개요(2.3)는 본문을 크롤링할 수 없어(gnews 리다이렉트 빈 페이지), 제목과 집계 검색 정보만으로 생태계 배경으로 수록했다. 9to5Linux가 보도한 Advantech AOM-2721 보드 Ubuntu 인증(08-15)은 원사이트 403이고 제조사 페이지에 RISC-V 증거 단어가 없어 플랫폼을 확인할 수 없으므로 본문에 수록하지 않았다. “RISC-V 첫 주식” 등의 표현은 매체 용어이다. GitHub 데이터는 미인증 API(60 req/h 속도 제한 내 완료)를 기반으로 한다.
