오늘의 핵심: UPC 연구: XuanTie C910과 온칩 성능 카운터로 RISC-V 칩이 마이크로아키텍처 공격을 “자가 검출”, 검출 정밀도 99%

날짜: 2026-09-24　출처: Scienmag《Machine Learning Turns RISC-V Chips Into Their Own Hardware Attack Detectors》, 논문: Pou, Otero, Robledo, Pajuelo & Canal, RISC-V hardware attack detection using on-chip hardware performance counters, Cybersecurity 9(1) Article 222, HARPY-V 데이터셋(CORA 연구 데이터 저장소)

9월 24일, Scienmag는 스페인 카탈루냐 공과대학(UPC) 팀의 연구를 보도했다: 연구진은 머신러닝 탐지기를 RISC-V 칩 자체의 하드웨어 성능 카운터(HPC)에 “내장”하여 칩 내부에서 마이크로아키텍처 공격을 실시간으로 탐지하는 데 성공했으며, 논문은 저널 Cybersecurity(9(1) 제222편)에 게재되었다. 실험은 실제 상용 실리콘에서 완료되었다——다모원 XuanTie C910(64비트 아웃오브오더 코어, RV64GCV)이 Sipeed LicheePi 4A 개발 보드에 탑재되어 Debian 13을 구동했다; 팀은 데이터셋 HARPY-V를 구축하고 공개했다: 약 6만 4천 개의 레이블링된 샘플로, 16종의 마이크로아키텍처 공격(Flush+Reload, Flush+Flush, Evict+Reload, Spectre V1/V2/RSB, 타이밍 드리프트, TLB 및 페이지 테이블 워크류 공격, 그리고 GhostWrite 등)과 16개의 양성 프로그램을 포함하며, 양성 집합은 공격과 하드웨어 구조를 공유하는 워크로드를 의도적으로 선택하여 분류 문제를 실제 난이도에 가깝게 만들었다.

결과와 엔지니어링 세부사항: 이진 탐지(공격/양성) 정밀도는 99%에 달하며, 다중 분류(구체적 공격 유형 구분)는 약 95%; “leave-one-attack-out” 제로데이 시뮬레이션에서 랜덤 포레스트와 mRMR 특징 선택, 결정 트리와 RFECV의 조합은 여전히 높은 탐지율을 유지했으며, “올바른 카운터를 고르는 것”이 “더 많은 카운터를 쌓는 것”보다 더 중요했다. 팀은 또한 두 가지 귀중한 실측 경험을 공개했다: C910에서 perf가 여러 카운터를 동시에 모니터링하면 서로 간섭하며(일부 판독값이 3배 이상 증폭됨), 반드시 카운터별로 개별 수집해야 한다; 그리고 C910의 perf 이벤트 설명은 대부분 부정확하므로 공식 매뉴얼의 카운터 매핑을 기준으로 해야 한다.

의의와 한계: 이는 상용 RISC-V 실리콘(FPGA 소프트 코어나 시뮬레이터가 아닌)을 플랫폼으로 삼고 재현 가능한 데이터셋을 공개한 최초의 마이크로아키텍처 공격 탐지 연구 중 하나이며, “칩 자체 카운터와 경량 모델로 능동 탐지를 수행하는” 것은 실리콘을 변경할 필요도, 커널 패치가 필요하지도 않은 저비용 강화 경로로, RISC-V 개방형 생태계의 보안 서사와 호응한다; 동시에 한계에 유의해야 한다——실험은 단일 코어 모델만을 대상으로 하며, 카운터 패턴은 마이크로아키텍처와 강하게 연관되어 칩 간에는 재학습이 필요하다; 지도 학습은 레이블링된 공격 데이터에 의존하므로 완전히 새로운 공격 유형에 대한 일반화는 여전히 검증이 필요하다.

2.1 Espressif ESP32-S31의 Linux 이식 가열: 마이크로컨트롤러에서 SBC 형태로

날짜: 2026-09-24　출처: XDA《The newest ESP32 can actually run Linux, and it’s getting uncomfortably close to a Raspberry Pi》, CNX Software: ESP32-S31 Linux BSP 개발자 프리뷰(08-22)

XDA가 Espressif ESP32-S31에 대한 특집을 게재: 듀얼 코어 32비트 RISC-V 메인 코어(최대 320 MHz, 별도 40 MHz 저전력 코어)에 더해 최초로 Sv32 MMU를 내장한 ESP32이며, 하드웨어적으로 기가비트 이더넷 MAC(RGMII), USB 2.0 High-Speed OTG 호스트, 듀얼 슬롯 SDIO, DVP 카메라 입력 및 병렬 LCD 컨트롤러를 갖춰 — 주변장치 조합이 이미 현대 단일 보드 컴퓨터에 근접. 공식적으로 8월에 Linux BSP 개발자 프리뷰를 발표(Buildroot 2025.02 + U-Boot + Linux 6.18 브랜치, 전체 이미지 약 13.7MB); 커뮤니티 이식도 동시 진행: GrieferPig의 Linux 6.12 supervisor 모드 이식(약 15MB 가용 메모리, CoreMark 약 1059), 그리고 Linux 7.1 + OpenSBI 1.9 기반, 800x480 LCD 콘솔 구동 가능한 또 다른 이식. XDA의 판단: S31의 주변장치, 대역폭 및 CPU 특권 모델은 모두 “SBC에 근접”했으나, Linux 지원은 여전히 실험적 성격이라 단기간 내 프로덕션 사용은 권장하지 않음.

2.2 SOPHGO BM1688 신규 단일 보드 OrangePi O1 공개: 16 TOPS TPU에 RISC-V C906 코프로세서

날짜: 2026-09-24　출처: LinuxGizmos《16-TOPS AI SBC with SATA 3.0 runs on octa-core Sophgo BM1688》

LinuxGizmos가 OrangePi O1 단일 보드(90×70mm) 상세를 게재: SOPHGO BM1688 비전 컴퓨팅 프로세서 기반 — 8코어 Arm Cortex-A53(최대 1.65GHz)에 RISC-V C906 코프로세서(최대 1.2GHz), 내장 TPU가 INT8 16 TOPS/INT4 32 TOPS/FP16-BF16 약 4 TFLOPS 제공, Caffe, PyTorch, TensorFlow, ONNX, MXNet 지원, 엣지 측 대형 모델 및 비전 모델 추론 지향. 보드 구성: 8/16GB LPDDR4X, eMMC(16-128GB 옵션), M.2 NVMe(PCIe 3.0), SATA 3.0, 듀얼 기가비트 이더넷 포트, Wi-Fi 6E/블루투스 5.3, 선택형 4G/5G 모듈, HDMI 2.0 4K60, 듀얼 MIPI-CSI 및 6채널 비디오 입력; 16채널 1080p30 디코딩 지원.
