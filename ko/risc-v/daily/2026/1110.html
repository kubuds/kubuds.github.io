오늘의 핵심: Nuclei, VME 매트릭스 확장을 최초 지원하는 RISC-V 범용 AI 연산 코어 NI1000 출시 (11-09)

Nuclei Technology는 11월 9일 NI1000 RISC-V CPU IP를 출시했으며, 공식 발표에 따르면 이는 Vector Matrix Extension(VME)을 지원하는 첫 번째 고성능 범용 AI 프로세서 IP다. NI 시리즈는 AI 애플리케이션을 겨냥한 Nuclei의 단일 제품 라인으로, 900 또는 1000 시리즈로 구성할 수 있다. RVV 1.0 벡터 유닛(VPU)의 VLEN은 512, 1024, 2048 또는 4096비트로 설정할 수 있으며, 클러스터 내 각 코어는 자체 VPU를 독립적으로 구성할 수 있다. 코어 간에는 IOCP(IO Coherent Port)를 통해 NPU 가속기와 긴밀하게 결합되어 캐시 일관성을 유지하며, NICE／VNICE 인터페이스는 사용자 정의 스칼라 및 벡터 명령을 허용하고 NICE는 NPU와의 긴밀한 결합 상호작용에도 사용할 수 있다.

기술적 핵심은 VME의 구현 방식에 있다. VME는 CPU, RVV와 동일 코어 내에서 긴밀하게 결합되며, 소스 오퍼랜드는 RVV의 벡터 레지스터 그룹을 직접 재사용하고 연산 유닛도 RVV의 실행 유닛을 재사용하며, 추가로 Matrix Tiles의 면적만 늘어난다. 새로 추가된 네이티브 매트릭스 명령은 외적 결과를 전용 N×N 누산기에 누적하며, 네 세트의 독립 Matrix Tiles가 핑퐁 병렬로 처리되어 처리량을 높이고, FP8 데이터 타입에 대한 네이티브 지원도 새로 추가했다. Nuclei가 제시한 데이터는 다음과 같다. NI1020(VLEN 1024)에서 32×32 FP32 매트릭스 곱셈을 실행할 때 전체 면적은 15%만 증가하며(주로 Matrix Tiles), 매트릭스 곱셈 성능은 2.5배 향상된다.

포지셔닝은 비교적 절제되어 있다. 공식적으로 NI 시리즈는 NPU, GPU 등 가속기 IP를 대체할 계획이 없으며, 오히려 그것들과 결합하여 AI SoC 상의 가속기를 더 잘 지원하는 것이라고 명확히 밝히고 있다. 이 점은 VME의 선택과 일치한다. IME와 비교하면 독립적인 행렬 누산 하드웨어가 있어 행렬 연산 에너지 효율이 더 높고, AME와 비교하면 완전한 독립 행렬 레지스터 파일과 하드웨어 행렬 가속기를 생략한다. VME는 중간에 서서 감당 가능한 하드웨어 오버헤드로 행렬 연산 능력을 확보하며, 그 대가는 전용 행렬 유닛만큼의 피크 에너지 효율은 나오지 않는다는 점이다. Nuclei는 동시에 VME가 완전히 RVV를 기반으로 하여 소프트웨어 생태계를 재사용할 수 있음을 강조하며, VME가 가장 먼저 표준화될 RISC-V 행렬 확장이 될 것으로 판단한다.

이 소식을 이번 달의 좌표에 놓고 보면, 그것이 보완하는 것은 “범용 연산 코어”라는 계층이다. 직전 주의 뉴스는 차량용 MCU(Infineon AURIX RC1), 엣지 비전 SoC(Virgl VS815V), 보안 코어(AMD의 RISC-V TEE)에 집중되어 있었으며, 모두 RISC-V를 특정 기능 유닛에 넣는 것이었다. NI1000이 마주하는 것은 AI 칩 안의 “무엇이든 조금씩 해야 하는” 범용 코어다. 스칼라 제어를 실행해야 하고, 벡터 연산자를 실행해야 하며, 일반적인 규모의 행렬 곱셈도 감당한 후 NPU와 분업해야 한다. 국내 AI 칩 회사들은 오랫동안 이 계층에서 양자택일을 해왔다. 고성능 애플리케이션 코어를 외부에서 사거나, 자체 개발하되 소프트웨어 스택 부담을 지는 것이다. VME가 RVV를 재사용하는 노선은 실질적으로 이 선택의 비용을 낮추는 것이며, 고객이 받아들일 수 있을지는 툴체인과 연산자 라이브러리가 따라오느냐에 달려 있다.

openRuyi 메인 저장소 하루 20건: wlroots 0.20.2, wget2 2.3.0 및 LLVM 22~24의 Python 바인딩 수정 (11-09/11-10)

openRuyi 메인 저장소는 모니터링 기간 내에 20건의 SPECS 커밋을 반영했으며, 그 리듬은 전형적인 “롤링 릴리스 일상”이지 집중 릴리스가 아니다. 데스크톱 스택은 wlroots를 0.20.2로 올렸고, 네트워크 도구는 wget2를 2.3.0으로 올렸으며, Python 쪽은 한 번에 httpx2와 httpcore2를 2.13.0으로, idna를 3.20으로, langgraph-sdk를 0.4.11로 업데이트하고 python-pymongo가 BSON을 메인 패키지에 포함하도록 했다. 또 몇 건은 패키징 정확성 수정이다. llvm22, llvm23, llvm24 세 패키지는 sed로 clang의 Python 바인딩을 libclang 링크로 변경했고, openruyi-linux-build는 devel 파일 충돌을 수정하고 버전 번호가 붙은 문서를 설치했다.

기록할 만한 것은 llvm 세 건이다. LLVM 각 버전의 Python 바인딩은 오랫동안 동적 라이브러리 경로 추론에 의존해 왔으며, 배포판 패키징 시 clang의 Python 모듈이 정적 라이브러리나 잘못된 soname을 가리키면 사용자가 RISC-V에서 llvmlite, triton 같은 의존성을 설치할 때 임포트 단계에서 실패한다. 세 버전을 동시에 명시적 libclang 링크로 변경한 것은 “설치는 되지만 사용할 수 없는” 유형의 문제에 대한 근본 원인 수정으로, RISC-V AI 스택을 만드는 팀에게는 버전 번호 자체보다 더 의미가 있다.

CORE-V CVW 11건 병합: 16550 UART의 LSR 오류 비트, SPI 빈 RX 0 반환 및 록스텝 비정렬 면제 (11-09/11-10)

CORE-V CVW는 모니터링 기간 내에 11건을 병합했으며, 주된 흐름은 여전히 마이크로아키텍처를 바꾸는 것이 아니라 “주변 장치와 검증 환경을 견고하게 만드는” 것이다. 16550 UART는 LSR(라인 상태 레지스터)의 오류 비트 동작을 보완했고, SPI는 수신 FIFO가 비어 있을 때 0을 반환하며, 분기 예측 리다이렉트의 커버리지 통계에 제외 항목을 추가했고, 록스텝(lockstep) 모드에서는 비정렬 접근에 대한 면제 규칙을 제공했으며, 그 외에 예제와 스크립트 정리 작업이 있었다. SHA의 Questa 스크립트 삭제, Docker 빌드와 회귀 스크립트 제거, ruff와 uv의 스크립트 진입점 통일 등이다.

이 커밋들은 지난주 “두 세트의 로컬 분기 예측기 삭제, RV32GC CoreMark/MHz 4.33 공개”와 같은 마무리 작업의 양면이다. 지난주는 성능과 면적을 건드렸고, 이번 주는 검증 가능성을 건드린다. UART의 오류 비트와 SPI의 빈 읽기 의미는 모두 “프로토콜에 규정되어 있지만 구현에서 놓치기 쉬운” 세부 사항이며, 놓쳐도 코어가 동작하지 않는 것은 아니지만 드라이버가 오류 경로에서 멈추게 만든다. 록스텝 면제와 커버리지 제외는 검증 보고서가 납품 증거로 사용될 수 있는지를 직접 결정한다. CVW를 차량용이나 산업용 평가에 사용하는 팀에게 이런 커밋은 수백 MHz 더 높은 것보다 더 가치 있다.

날짜: 2026-11-09 ~ 2026-11-10　출처: openhwfoundation/cvw

M9B, Tang Nano 9K에서 RISC-V 컴퓨터를 구현하고 5종의 DOS 시대 게임을 36MHz 소프트코어에서 구동 (11-09)

개발자 Mika Tammi의 m9b 프로젝트가 Hacker News에 등장했다: 약 20달러짜리 Sipeed Tang Nano 9K(Gowin GW1NR-9) 한 장에 VexiiRiscv 소프트코어로 완전한 소형 컴퓨터를 구현했다——36MHz, 캐시 탑재, 온보드 8MB PSRAM을 메모리로 사용, 720×480 HDMI 영상, 48kHz 오디오, USB 2포트로 키보드·마우스 연결, SD 카드에 프로그램 저장. 부팅하면 SD 카드의 프로그램 목록이 나타나는 인터페이스로 진입하며, 5종의 DOS 시대 게임을 모두 음향 효과와 음악과 함께 구동할 수 있다: Doom(셰어웨어, timedemo 약 22 fps), Descent(약 10 fps), Tyrian 2.1(최고 속도 35 fps), System Shock(약 7 fps), Ultima VII(두 가지 엔진, 7~13 fps).

이런 프로젝트의 가치는 “게임을 할 수 있다”는 데 있지 않고, “컴퓨터 한 대에 최소한 무엇이 필요한가”라는 선을 그어낸다는 데 있다. 9K의 로직 자원으로는 비순차 코어를 담을 수 없고 Linux 수준의 메모리 관리도 담을 수 없어, 트레이드오프가 매우 구체적으로 드러난다: HDMI를 원하면 캐시를 잘라야 하고, 음향 효과를 원하면 음악을 미리 렌더링해 스트림으로 카드에서 읽어야 한다. 이 프로젝트는 SoC, 런타임, 5종 게임 이식, SD 카드 이미지를 각각 독립 저장소로 분리해 전부 오픈소스로 공개했으며, 각 저장소마다 업스트림에서 어디를 수정했는지 명시했다——RISC-V 교육 보드와 FPGA 입문을 담당하는 팀에게 이는 곧바로 재사용 가능한 엔지니어링 계층화 샘플이다.

날짜: 2026-11-09　출처: m9b-system 저장소, Hacker News 토론

RISC-V Day Tokyo 2026 Autumn 내일 개막, Tenstorrent와 AIST 참석 (11-11)

RISC-V 협회(일본)가 11월 11일 도쿄대학교 혼고 캠퍼스에서 RISC-V Day Tokyo 2026 Autumn을 개최하며, 약 400명이 참가할 것으로 예상된다. 오전 일정은 칩 설계 튜토리얼, 오후는 기술 발표와 부스로 구성된다: Tenstorrent는 물리적 AI와 Open Chiplet Atlas를 발표하고, 산업기술종합연구소(AIST)는 2nm 엣지 AI를 발표하며, Andes Technology는 현장 데모를 진행한다. 행사장에는 별도로 Chip Museum 특별전이 마련되어 Google TPU v3의 하드웨어 사양과 소프트웨어 개요를 전시한다.

M5Stack Core Matrix, ESP32-C61에 16×16 LED 매트릭스 탑재하고 29.99달러에 출시 (11-09)

M5Stack이 Core Matrix를 출시했다. 이 보드의 의미는 “디스플레이”를 화면에서 도트 매트릭스로 바꾼 데 있다. Infineon AURIX RC1의 RISC-V 코어, MIPS IP에서 유래해 GlobalFoundries에서 생산된다는 주장 (11-09)

Design And Reuse는 11월 9일 jonpeddie.com의 분석을 전재하며, Infineon AURIX RC1이 MIPS의 프로세서 IP를 채택하고 GlobalFoundries에서 생산된다고 지적했으며, 이를 MIPS와 GlobalFoundries가 RISC-V에서 거둔 중요한 설계 승리라고 평가했다. 기사는 동시에 RISC-V가 결국 Infineon 자체의 TriCore 아키텍처를 대체할 것인가라는 질문을 제기했다. 앞서 11월 4일 Infineon이 RC1을 발표했을 때 공식 입장은 “RISC-V 기반 최초의 차량용 MCU 플랫폼, TriCore 시리즈는 계속 공급”이었으며 IP 출처에 대해서는 밝히지 않았다.

이 보도는 공급망 차원의 공백을 메운다. 차량용 칩 발표는 통상 플랫폼과 생태계만 이야기할 뿐 코어가 어디서 왔는지는 말하지 않는다. 그러나 국산 차량용 RISC-V를 만드는 팀에게 코어의 출처는 두 가지를 직접 결정한다. 기능 안전 증거 체인을 누가 제공하는가(ISO 26262 ASIL D의 IP 수준 증거는 완성차 업체가 스스로 보완할 수 없다), 그리고 생산 능력과 공정이 어느 파운드리에 속하는가이다. MIPS는 GlobalFoundries에 인수된 후 노선을 전면 RISC-V로 전환했으며, 이번에 정말로 RC1의 코어 공급사라면 “RISC-V 차량용 코어” 시장에 파운드리 배경을 가진 플레이어가 하나 늘어난 셈이다. 국내 IP 업체에게 이는 정면으로 비교해야 할 경쟁자이지, 먼 곳의 개념이 아니다.

3. 국내 팀 심층 분석

T-Head, 2027년 홍콩 IPO 추진, 20억~30억 달러 조달 계획 (11-09)

여러 매체가 11월 9일 로이터 통신 보도를 인용해, Alibaba 산하 칩 회사인 T-Head Semiconductor가 2027년 홍콩거래소 상장을 계획하고 있으며 목표 조달액은 20억~30억 달러(약 156억~234억 홍콩달러)라고 전했다. 공개 정보에 따르면 T-Head는 2018년 10월 Zhongtian Micro와 DAMO Academy 칩 팀이 통합되어 설립되었으며, 제품은 AI 가속 칩(TrueNorth 시리즈), Arm 서버 CPU(Yitian 시리즈), RISC-V 프로세서 IP(XuanTie 시리즈), 스토리지 컨트롤러 등을 아우른다. 2026년 3월 Alibaba CEO Wu Yongming은 실적 발표 콘퍼런스콜에서 T-Head 칩 누적 출하량이 47만 개를 넘고 연환산 매출이 100억 위안을 초과한다고 밝혔으며, 8월에는 TrueNorth 시리즈가 650개 이상 고객에게 서비스되었고 외부 유료 고객 비중이 60%를 넘는다고 공개했다. 9월 Yunqi 컨퍼런스에서 발표된 TrueNorth V900은 216GB 메모리와 1200GB/s 칩 간 대역폭을 표방하며 2027년 1분기 양산을 계획하고 있다.

기준을 명확히 할 필요가 있다. 보도는 XuanTie 시리즈 RISC-V 프로세서 IP를 T-Head의 제품 라인에 포함시켰지만, XuanTie 팀은 2024년 이미 DAMO Academy로 옮겨 RISC-V 프로세서(C950 등)에 전념하고 있으며, T-Head 자체의 제품 중심은 PPU(AI 가속 카드)와 Yitian(Arm CPU)이다. “XuanTie 누적 출하 60억 개”는 그룹 차원의 역사적 누적 기준이며 현재 T-Head가 운영하는 것과 같지 않다. 상장 주체가 최종적으로 자산을 어떻게 분할하고 XuanTie IP 귀속이 이에 따라 조정될지는 현재 공개되지 않았으며, 이것이 이 소식에서 가장 추적해야 할 부분이다.

RISC-V 산업에 있어 IPO 자체는 기술 노선을 바꾸지 않지만, 자본이 이 분야를 가격 책정하는 방식을 바꾼다. 지난 2년간 국내 RISC-V 기업의 가치 평가 기준은 “대체 공간”이었다. T-Head가 100억 위안급 연환산 매출과 60% 외부 고객이라는 정체성으로 상장한다면 기준은 “이미 상용화된 컴퓨팅 파워 공급자”로 바뀐다. 이는 자금 조달 중인 RISC-V 서버, AI 칩, IP 기업에게 양방향 영향을 미친다. 비교 가능 기업이 명확해지지만, 자본 시장도 동일한 매출과 마진 기준으로 이들을 평가할 것이다.

XUANTIE-RV 조직의 최근 푸시는 여전히 11월 4일(damo-rv-priv-ats와 torq-tile)에 멈춰 있으며, llvm-project와 bcc는 각각 10월 하순에 멈춰 있다. ESWIN의 eswincomputing 최근 푸시는 10월 19일이다. 두 곳 모두 24시간 모니터링 기간 내에 확인 가능한 새로운 개발 성과가 없다.

이는 제품 라인이 조용하다는 것을 의미하지 않는다. XuanTie의 고성능 코어(C950 시리즈)와 차량용 E908A 진전은 이미 10월의 각 기 보고서에 수록되었으며, ESWIN의 RISAA 생태계 플랫폼과 RDI 연맹 행보는 10월 RISC-V 중국 정상회의 기간에 집중되었다. 모니터링 기간 내의 공개 정보는 주로 핑터우거 IPO 보도에서 XuanTie 출하량을 인용한 것으로, 그룹 차원의 역사적 데이터에 해당하며 새로운 기술 진전을 구성하지 않는다. 이번 호에서는 중복 수록하지 않는다.

4. 임베디드 지능 및 로봇 특별 장

MIPS Actus, 두 개의 Atlas M8500 실시간 RISC-V 코어로 로봇 관절 구현, TSN 및 포스트 양자 보안 탑재 (11-09)

MIPS(GlobalFoundries에 인수됨)는 11월 9일 electronica 2026을 앞두고 Actus 참조 플랫폼의 진전을 발표했다: 컴팩트 로봇 관절을 겨냥한 칩으로, 결정론적 모터 제어, 로봇 체내 네트워크, 엣지 추론을 단일 die에 통합했으며 GlobalFoundries의 FDX FD-SOI 공정을 기반으로 한다. 핵심은 두 개의 MIPS Atlas M8500 실시간 RISC-V 프로세서로, 하드웨어 멀티스레딩을 통해 인터럽트 서비스 시의 컨텍스트 스위칭 오버헤드를 제거한다; 전용 삼각함수 가속은 자기장 방향 제어(FOC) 알고리즘에서 표준 삼각함수 라이브러리보다 16배 이상 빠르다; 100피코초급 고해상도 PWM과 sigma-delta ADC를 갖춰 대전류 모터를 구동하며, 추가로 ARC VPX 512비트 벡터 유닛으로 동일 칩에서 센서 융합과 예측 유지보수 모델을 실행한다.

시스템 측면도 충분히 갖췄다: 3포트 시간 민감 네트워크(TSN) 기가비트 이더넷에 CAN-FD와 시리얼을 더해 각 관절 컨트롤러와 중앙 컨트롤러가 위치와 토크 데이터를 교환하도록 한다; 온칩 하드웨어 보안 모듈은 포스트 양자 암호를 지원하며 기능 안전도 지원한다. Actus는 Acies(추론 네이티브 플랫폼), Aegis(보안 네이티브 CPU 플랫폼)와 함께 MIPS의 피지컬 AI 제품 라인을 구성한다.

이 항목의 무게는 “관절”이라는 위치에 있다. 휴머노이드 로봇의 연산 서사는 오랫동안 대뇌(누구의 NPU, 몇 TOPS)에 집중되었지만, 실제로 양산을 가로막는 것은 팔꿈치부터 손끝까지의 구간이다: 공간, 전력, 방열이 모두 극히 빡빡하지만 부드러운 인간형 운동과 결정론적 타이밍을 요구한다. 듀얼 실시간 코어, 모터 제어 주변장치, TSN, 보안 모듈을 하나의 관절 칩에 집어넣는 것은 “대뇌가 명령을 내리고 관절이 스스로 폐루프를 구성한다”는 분산 아키텍처를 구매 가능한 부품으로 만드는 것과 같다. 국내에서 로봇 관절과 실시간 제어를 하는 팀에게 이는 “MCU에 외장 드라이버” 노선과 정면으로 비교되는 방안이며, 핵심 차이는 연산력이 아니라 하드 실시간과 네트워크 결정성에 있다.

spacemit-robotics: unitree-go2, smallcore 모터 통신 지원, perception은 추론 런타임을 las2에 패키징 (11-09)

spacemit-robotics의 unitree-go2 저장소가 #6을 병합하여 smallcore 모터 통신 지원을 추가했으며(feat/smallcore-motor-tra… 브랜치); perception 저장소에는 las2를 둘러싼 두 건의 수정이 있다: 일치하는 추론 런타임을 릴리스물에 패키징하고(#14), 그에 앞서 소스 저장소에 패키징된 모델 파일을 먼저 제거했다(#13).

두 가지 모두 “전달 형태”를 가리킨다. unitree-go2는 Unitree Go2 사족 로봇을 K3 플랫폼에 포팅한 프로젝트로, 이전에 이미 IMU 스냅샷 읽기, 지형 보행 정책, 모델 다운로드를 완료했다; smallcore 모터 통신을 보완한다는 것은 제어 링크가 서로 다른 배치의 관절 드라이버 보드에 대응할 수 있어야 한다는 뜻이며, 이는 demo를 재현 가능한 프로젝트로 만들기 위해 반드시 넘어야 할 관문이다. perception의 #13과 #14는 한 쌍이다: 먼저 대형 모델 파일을 소스 저장소에서 분리하고(저장소 비대화 방지), 이어서 추론 런타임을 릴리스물과 함께 패키징한다(사용자가 직접 의존성을 찾지 않도록) — 하나 빼고 하나 더하는 것은 이 인지 스택이 “스크립트 더미”가 아니라 “설치 가능한 소프트웨어 패키지”로 조직되기 시작했음을 보여준다.

5. 요약 및 트렌드 관찰

1. AI 칩의 ‘범용 코어’ 계층에 전용 제품이 등장하기 시작했다. Xinlai NI1000은 VME를 사용해 행렬 능력을 RVV에 접목했으며, 면적은 15%만 증가하고 행렬 곱셈은 2.5배 빨라졌다. 포지셔닝은 NPU를 대체하는 것이 아니라 NPU와 분업하는 것이다. 이는 지난 2년간의 “누구의 NPU 피크가 더 높은가”라는 서사와 다르다. AI SoC의 범용 코어는 오랫동안 외부 구매 애플리케이션 코어나 자체 개발 대형 코어로 해결해 왔는데, 이제 세 번째 길이 나타났다. 즉, 벡터를 기반으로 필요에 따라 행렬을 추가하는 방식이다. 진정한 장벽은 IP가 아니라 연산자 라이브러리와 컴파일러가 VME를 활용할 수 있느냐에 있다.

2. 로봇 관절이 RISC-V 실시간 코어의 새로운 전장이 되었고, 노선이 분기되기 시작했다. MIPS Actus는 두 개의 Atlas M8500에 TSN과 포스트 양자 보안을 더해 관절급 단일 칩을 만들고, 중국의 spacemit-robotics는 K3에서 사족 보행 이식과 제어 링크 적응을 계속하고 있다. 전자는 디바이스와 실시간성 보장을 판매하고, 후자는 재현 가능한 엔지니어링과 생태계를 축적한다. 두 길 모두 한 가지를 보여준다. 구현 지능의 컴퓨팅 경쟁이 ‘대뇌’에서 ‘소뇌와 관절’로 내려가고 있으며, 이 계층의 평가 기준은 TOPS가 아니라 확정성과 전력 소비라는 것이다.

3. 중국 측 자본 시장 움직임이 기술 서사에 영향을 미치기 시작했다. 핑터우거(PingTouGe)가 2027년 홍콩 IPO를 추진하여 20억~30억 달러를 조달할 계획이며, 만약 성사된다면 RISC-V와 중국 AI 칩 기업이 처음으로 ‘이미 상용화되고, 외부 고객이 있으며, 매출이 있는’ 비교 대상 지표를 갖게 된다. 다만 한 가지 냉정함이 필요하다. 보도는 XuanTie IP를 핑터우거 제품 라인에 포함시켰지만, XuanTie 팀은 2024년에 이미 다모아카데미(DAMO Academy)로 이동했으며, 상장 주체의 자산 경계는 아직 공개되지 않았다. 산업 관찰자에게 다음에 볼 것은 밸류에이션이 아니라, 공모 자료에서 외부 고객 수익과 관련 거래의 분할 방식이다.

4. 소프트웨어 측 진전은 ‘설치 가능하고 사용 가능한’ 세부 사항에 집중된다. openRuyi의 하루 20건 중 llvm22~24의 Python 바인딩을 명시적 libclang 링크로 변경한 것이 가장 대표적인 사례이다. 이는 어떤 지표도 향상시키지 않지만, RISC-V에서 llvmlite와 triton을 정상적으로 설치할 수 있는지를 결정한다. CORE-V CVW가 이번 주 병합한 UART LSR 오류 비트, SPI 빈 읽기 0 반환, 록스텝 예외도 “벤치마크에는 영향 없고, 납품 가능성에는 영향 있는” 범주에 속한다. SuanNeng이 bootloader의 두 세대 플랫폼 빌드 체인을 수렴한 것, Jindie가 디지털 휴먼 파이프라인을 Bianbu 브랜드로 편입한 것 모두 데모에서 유지보수로 나아가는 움직임이다.

5. 조용한 뉴스 면과 조용하지 않은 저장소 면. 이번 기간 Google News 측 유효 신규는 Xinlai NI1000, MIPS Actus, M5Stack Core Matrix, Infineon AURIX의 IP 출처 네 건뿐이며, 추가로 Weijing VS815V, AMD RISC-V TEE, Openchip BER10 세 건은 구뉴스 재전파로 이전 보고서에 수록되어 이번 기간에는 반복하지 않는다. 이는 지난주 리듬과 일치한다. 대기업 발표는 드물지만 GitHub 측 커밋 밀도는 상승하고 있다. Jindie, SuanNeng, Xinlai, openRuyi, CORE-V가 같은 24시간 안에 합계 60여 건의 검증 가능한 커밋을 기록했다.

한계 설명: 본 기기의 익명 GitHub API 접근이 수집 시간대에 시간당 60회 속도 제한에 걸렸으며, 조직 및 저장소 활성도는 GitHub 조직 페이지 내장 데이터와 각 저장소 Atom 커밋 피드로 대체 수집하여 API 할당량을 소모하지 않았다. 따라서 ‘모니터링 기간 내 푸시 있음’ 판정은 기본 브랜치 커밋 시간을 기준으로 하며, 비기본 브랜치 푸시(예: Jindie의 wip 브랜치)는 과소평가될 수 있다. 다모아카데미 XuanTie와 Yisivei의 ‘제로 푸시’ 결론도 같은 방법론 제약을 받으며, 기본 브랜치가 모니터링 기간 내 커밋이 없음을 의미할 뿐이다. Google News의 중국어 쿼리에는 여전히 도박 및 주식 기사 노이즈가 있으며, 제목 의미에 따라 제거했다. RISC-V 멤버 공식 사이트 점검의 108개 ‘변화’는 모두 홈페이지 마케팅 순환 또는 보안 차단 페이지였으며, 실질적인 제품 및 아키텍처 릴리스는 발견되지 않았다.
