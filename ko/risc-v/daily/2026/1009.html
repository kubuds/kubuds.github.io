날짜: 2026-10-08　출처: Sina Finance(Gelonghui): ESSENCORE 컴퓨팅 홍콩 공모 9.09배 초과 청약, 10월 9일 상장(10-08), HSTong: 암시장 마감, ESSENCORE 컴퓨팅 1.6% 상승 마감(10-08), Phoenix Net(Ryan Capital): “RISC-V 제1호 주식” 10월 9일 홍콩 상장 예정(10-08)

“RISC-V 제1호 주식” ESSENCORE 컴퓨팅(01256.HK)이 10-08 저녁 배정 결과를 발표했다: 글로벌 공모 약 16.17억 주 H주, 주당 1.55 홍콩달러 가격 결정(범위 1.48~1.59 홍콩달러), 순조달금액 약 23.86억 홍콩달러; 홍콩 공모 부분 9.09배 초과 청약, 국제 공모 부분 1.95배 초과 청약, 1수 배정 확률 약 10%. 9개 코너스톤 투자자가 합계 약 11.61억 홍콩달러를 청약했다. 암시장 거래는 높은 변동성을 보였다——개장 직후 약 17% 하락했으나 장 마감에 1.61% 상승한 1.57 홍콩달러/주로 마감, 대응 총시가 약 346.4억 홍콩달러. 회사는 오늘(10-09) 홍콩거래소 메인보드에 상장하며, 조달 자금 약 35%는 칩 제품 개발 반복에, 30%는 RISAA(RISC-V와 AI) 소프트웨어·하드웨어 플랫폼에 투입된다.

1. 오픈소스 커뮤니티와 소프트웨어 생태계

1.1 SpacemiT: Linux 7.4 디바이스 트리 업데이트, K3 주파수 조절·온도 제어·팬 제어 활성화

날짜: 2026-10-08　출처: Phoronix “SpacemiT RISC-V SoCs To See More Improvements With Linux 7.4” (10-08)

업스트림 커널의 SpacemiT K3／K1 디바이스 트리 업데이트 pull request가 10-08에 발송되었다(Linux 7.4 진입 예정): K3의 CPU 주파수 조절 지원이 더 많은 하드웨어로 확대되고 RFKILL 노드가 활성화되었으며, 온도 제어와 팬 제어가 새로 추가되었다—K3 CoM260 시스템 모듈의 CTF2301 센서 칩을 대상으로 한다; K3 기반 Muse Pi Pro, Orange Pi R2S, Orange Pi RV2 개발 보드 모두 이번 배치와 함께 CPU 주파수 조절이 활성화된다. K1 측은 온보드 EEPROM 지원을 활성화하고 EEPROM 데이터로부터 MAC 주소 설정을 지원한다. K3는 첫 양산 RVA23 칩 중 하나로서 업스트림 지원이 지속적으로 마무리되고 있다.

1.2 RevyOS: 커널 설정 대량 반영, K1／K3와 EIC7700 플랫폼 추진

날짜: 2026-10-08　출처: revyos/linux 커밋 기록 (revyos/7.3.y 브랜치, 10-08)

RevyOS 커널 저장소(revyos/linux)는 모니터링 기간 내 한 번에 20여 건의 설정 커밋을 푸시했다: dp1000과 K1／K3 전용 설정 추가(K3 디스플레이 DC, K3 UFS, Banana F3의 K1 USB2); ESWIN EIC7700 아키텍처와 DWMAC, PINCTRL 드라이버, TH1520 GPU 전원 시퀀싱, RTC／RESET_GPIO 등 일련의 상용 드라이버 활성화; USB-C 측은 Type-C 역할 전환, TCPM, UCSI, FUSB301과 DP 대체 모드 활성화. CI 측은 크로스／네이티브 빌드 작업과 linuxboot 설정을 추가했다. 다중 플랫폼(TH1520／K1／K3／EIC7700)을 위한 배포판 커널 설정이 연휴 후 첫 모니터링 기간에 집중적으로 펼쳐졌다.

1.3 openRuyi: SPECS 대량 확장, go-github 시리즈 20여 건 일괄 등록

날짜: 2026-10-08　출처: openRuyi 커밋 기록 (10-08), openRuyi 커밋: cgctl이 현재 cilium-ebpf API 지원

openRuyi 메인 저장소는 모니터링 기간 내 한 번에 20여 건의 SPECS 커밋을 병합했다: go-github-* 시리즈 패키지 정의(gopsutil, gokrb5, nats.go, cassandra-gocql, aliyun-credentials-go, google-cel-go 등)를 대량 추가하고, cgctl을 현재 cilium-ebpf API에 적응시키며 jcmturner-gokrb5-v8의 Go 빌드를 수정했다. 공식 웹사이트 뉴스 페이지 확인 결과—2026.09 릴리스 이후 새로운 릴리스 공지는 없음; 이번 확장은 릴리스 후 소프트웨어 소스 일상 보충 패키지로 보이며, 클라우드 네이티브와 관측성 관련 Go 생태계 의존성을 커버한다.

1.4 XiangShan: FEX0 두 건의 백엔드 수정 마무리, 메인 브랜치에 병합

날짜: 2026-10-08　출처: XiangShan PR #6649: x0 변환을 위한 FEX0 출력 슬롯 보존 (09-29 개시, 10-08 병합), XiangShan PR #6651: FEX0에서 사용되지 않는 F2vCfg 정리 (09-29 개시, 10-08 병합)

09-29 데일리 리포트에 기록된 XiangShan 백엔드 수정이 모니터링 기간 내 공식 마무리되었다: #6649(x0 변환을 위한 FEX0 출력 슬롯 보존)와 #6651(FEX0에서 사용되지 않는 F2vCfg 설정 제거)가 차례로 메인 브랜치에 병합되었으며, 두 건 모두 부동소수점 실행 유닛 FEX0의 발사와 리소스 관리 경로에 위치한다. 앞서 같은 배치로 개시된 #6652, #6653(벡터 발사와 정렬 수정)은 이번 모니터링 기간의 병합 기록에서 보이지 않아 리뷰 향방을 추적할 필요가 있다.

1.5 XiangShan 시뮬레이션 체인: NEMU 다수 PR 연이어 개시, difftest 독립 가속기 클럭 지원

날짜: 2026-10-08　출처: difftest PR #977: 독립 가속기 클록 지원(10-08), NEMU PR #1242: SIP 쓰기가 래치 타이머 인터럽트를 방지, NEMU PR #1243: difftest 유도 메모리 관측, NEMU PR #1244: CHECKPOINT_HERE 체크포인트 모드, NEMU PR #1245: ZSTD 체크포인트 포맷 오류 처리

모니터링 기간 내 시뮬레이션 체인이 여러 갈래로 추진되었다: difftest #977 머지——독립 가속기 클록을 지원하여 다중 클록 도메인 비교 시뮬레이션의 길을 열었다; NEMU는 여러 PR을 연이어 열었다——#1241(RVV 크로스 페이지 저장 시 페이지 폴트 발생 시 첫 페이지 쓰기 보존, 모니터링 기간 경계), #1242(SIP 쓰기가 래치 타이머 인터럽트를 방지), #1243(difftest 유도 메모리 관측), #1244(CHECKPOINT_HERE 체크포인트 모드 도입, nemu_trap 0x105 기반), #1245(ZSTD 체크포인트 포맷 오류 처리 개선), 그리고 feat-matrix-mem-profiling 기능 브랜치를 푸시했다. 체크포인트 메커니즘과 CPU 동작 수정이 병행되면서 시뮬레이션 인프라가 다음 라운드 마이크로아키텍처 반복을 위한 힘을 축적하고 있다.

1.6 생태계 단신: Chipyard가 PMU 라이브러리를 머지, riscv-unified-db에 Zkr／Sdext 항목 추가

날짜: 2026-10-08　출처: Chipyard PR #2387: PMU 라이브러리 머지 및 BOOM v3에 PMU 구성 추가(10-08), riscv-unified-db 커밋 기록(10-08)

오픈소스 SoC 프레임워크 Chipyard(UC Berkeley)는 모니터링 기간 내 #2387을 머지했다: PMU(성능 모니터링 유닛) 라이브러리를 제너레이터 서브모듈로 도입하고, BOOM v3에 PMU 구성을 추가했으며, 서브모듈 포인터도 동기화하여 업데이트했다——비순차 코어의 하드웨어 성능 분석을 위한 인프라를 보강한 것이다. riscv-unified-db(규격 기계 판독 가능 데이터베이스)는 Zkr 시드 CSR(C++ 백엔드 엔트로피 소스 지원 포함), Sdext 확장 설명 및 불법 명령어 처리 등의 항목을 새로 추가하여 규격 데이터베이스의 확장 범위가 계속 넓어지고 있다.

2. 제품 및 생태계 동향

2.1 Vayavya Labs와 Tenstorrent 협력: SystemC 가상 플랫폼으로 RISC-V 소프트웨어·하드웨어 개발 가속

날짜: 2026-10-07　출처: Tenstorrent 뉴스룸: Vayavya Labs 협력 발표(10-08), PR Newswire 기사(10-07)

Vayavya Labs는 Tenstorrent의 가상 플랫폼 파트너가 되었다고 발표했다: 자사의 TvastaaVP 플랫폼을 기반으로 Tenstorrent의 보안 및 시스템 관리 IP를 위한 SystemC 가상 플랫폼을 구축하여, 소프트웨어가 테이프아웃 전에 더 일찍 개발 및 검증을 진행하고 통합 리스크를 낮출 수 있게 한다. 양측은 이 협력이 단발성 모델링에서 다년간 파트너십으로 격상되었으며, Tenstorrent가 벵갈루루에서 개최하는 RISC-V 생태계 행사 「The Open Frontier」(10-08)에서 함께 발표할 것이라고 밝혔다. 설계 좌측 이동(shift-left)은 RISC-V 고성능 칩의 경쟁 요소가 되고 있다.

2.2 Sophgo: SG2044가 SDK v20261008 릴리스 커밋을 머지, 보드 레벨 코드명 SRM31로 변경

날짜: 2026-10-08　출처: bootloader-riscv 커밋 기록(10-08)

Sophon bootloader-riscv 모니터링 기간 내 SG2044 시리즈 3건의 커밋 완료: 보드 레벨 코드명 SRM3-C0 → SRM31 명칭 변경, 릴리스 스크립트 신규 추가(release script), 그리고 SDK v20261008 릴리스 커밋 병합——64코어 RISC-V 서버 플랫폼 SG2044의 펌웨어와 SDK가 새로운 버전화 납품 단계에 진입. 같은 기간 sophgo-edk2, edk2-platforms 등 저장소에서도 유지보수성 푸시가 있었음(SRM/cv 시리즈의 UEFI 지원 라인).

2.3 Radxa Linkr v1.5.2 릴리스: FN 더블 클릭으로 핫스팟 전환, Q8B 해상도 전환 수정

날짜: 2026-10-08　출처: Radxa Linkr v1.5.2 릴리스(10-08)

  • 생태계가 설계의 좌우 양단으로 확장: 좌측에서는 Tenstorrent가 가상 플랫폼 협력으로 IP 개발을 가속하고 Chipyard가 PMU 인프라를 보강했으며; 우측에서는 엣지 제품이 계속 등장(Upbeat 드론 비행 제어, Q8botOne 사족 로봇)하여 RISC-V가 안전 필수 실시간 시스템과 로봇 시나리오에서 끊임없이 착점하고 있다.
