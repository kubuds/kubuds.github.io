2. 제품 및 생태계 동향

2.1 Waveshare, ESP32-C5 Pico 보드 출시: 듀얼밴드 Wi-Fi 6 RISC-V 마이크로 보드가 라즈베리 파이 Pico 폼팩터 채택 (09-09)

날짜: 2026-09-09　출처: CNX Software, Open Source For You, Waveshare 문서 사이트, GitHub waveshareteam/ESP32-C5-Pico

Waveshare가 ESP32-C5 Pico 보드를 출시하며, Espressif ESP32-C5 듀얼밴드 Wi-Fi 6 SoC를 라즈베리 파이 Pico 폼팩터(약 51~56.85 x 21 mm)에 도입했다. 핵심 사양: ESP32-C5-MINI-1/1U 모듈(ESP32-C5HF4, 단일 코어 32비트 RISC-V 최대 240 MHz에 48 MHz 저전력 RISC-V 코어 추가, 384 KB SRAM, 320 KB ROM, 4 MB SPI flash), 무선은 듀얼밴드 2.4/5 GHz 802.11ax Wi-Fi 6 및 Wi-Fi 4 하위 호환, 블루투스 5.0 LE(Mesh 포함), 802.15.4(Zigbee 3.0 / Thread 1.3 / Matter)를 지원한다. 온보드 USB-C(전원 공급, 플래싱, 충전), 2x20 pin Pico 호환 헤더(최대 26개 GPIO, 20개 PWM, 추가 6개는 TCA9554PWR 확장), 리셋 및 BOOT 버튼, RGB LED와 리튬 배터리 충방전 회로를 갖췄다. 네 가지 버전(온보드 PCB 안테나 또는 IPEX 외장 안테나, 헤더 사전 납땜 또는 미납땜)을 제공하며, 소프트웨어는 Arduino IDE와 ESP-IDF를 지원하고, 예제 코드는 공식 웹사이트에서 GitHub로 이전했다(보드 정보, RGB, I/O 확장, 듀얼밴드 Wi-Fi, UART, 1.83인치 터치스크린, MCP2515 SPI CAN 등). 의의: ESP32-C5가 2025년 4월 양산된 이후, 그 “듀얼밴드 Wi-Fi 6 + RISC-V” 역량이 Pico 호환 폼팩터를 따라 하위 시장으로 확산되고 있으며, 서드파티 보드 생태계(Waveshare는 선전 소재 업체)가 Espressif RISC-V 무선 MCU 정착의 직접적인 증폭기가 되고 있다.

2.2 GigaDevice 팟캐스트에서 RISC-V, 로봇, 엣지 AI 논하다: GD32 듀얼 아키텍처 노선과 EtherCAT 분산 제어 (09-09)

날짜: 2026-09-09　출처: Electropages, GigaDevice 휴머노이드 로봇 솔루션 페이지, GigaDevice GD32V 출시 공고

Electropages 팟캐스트(Robin Mitchell과 GigaDevice 사업 개발 매니저 Kevin Jones의 대화)는 이 회사의 MCU 노선을 체계적으로 다뤘다. RISC-V 측면에서 GigaDevice는 비교적 이른 주류 채택자로, 2019년에 GD32VF103(코어는 Nuclei가 제공, 양측 공개 협력)을 출시했으며, 현재 무선 제품 라인도 RISC-V를 채택했고, 공식 측은 아키텍처 유연성이 칩 업체로 하여금 특정 애플리케이션과 워크로드에 맞춰 프로세서를 커스터마이즈할 수 있게 한다고 강조한다. 로봇 측면에서 산업용 로봇의 다중 모터와 복잡한 운동은 컨트롤러 간 통신의 결정성 요구를 높이고 있으며, GD32H7 시리즈는 EtherCAT을 지원해 분산 MCU가 각각 단일 모터와 국부 서브시스템을 제어함으로써 모든 결정을 중앙 프로세서로 되돌려 보내는 의존성을 줄일 수 있다. 엣지 AI 측면에서 모터 이상 감지, 인체 감지 등 로컬 추론 작업은 고급 AI 프로세서에 의존할 필요가 없으며, Cortex-M7/M33이 모델 경량화 후 이미 감당할 수 있어 비용 민감 시나리오의 클라우드 의존도를 낮추는 데 유리하다. GigaDevice 휴머노이드 로봇 솔루션 페이지(“인지—결정—제어—실행” 아키텍처, MCU, 메모리, 아날로그 칩 조합으로 로봇 손, 관절 모듈, IMU, 전원 관리 등을 커버)와 결합해 보면, 그 “Arm + RISC-V 듀얼 아키텍처 + 로봇/엣지 AI”의 중국산 MCU 포지셔닝을 확인할 수 있다. 이 항목은 인터뷰성 내용으로 신제품 출시는 없으며, 전략 관찰로 수록한다.

3. 국내 팀 동향과 심층 분석

3.1 SpacemiT: 차세대 일관성 상호연결 버스 N200 개발 완료, 범용 컴퓨팅+지능 컴퓨팅+상호연결 3대 섹터 형성 (09-07 발표, 이번 추가 수록)

날짜: 2026-09-07(회사 발표, 이전 두 모니터링 기간에서 누락, 이번 추가 수록)　출처: SpacemiT 공식 웹사이트 뉴스, GitHub spacemit-com/model_zoo_rl, spacemit-com/ai-sdk

Zhendie Shikong은 공식 웹사이트에서 회사의 차세대 자체 개발 고성능 일관성 인터커넥트 버스 N200이 공식적으로 개발을 완료했다고 밝혔다. 범용 컴퓨팅 CPU 코어(X60/X100/X200)와 지능형 컴퓨팅 AI 코어(A60/A100/A200)를 배치한 데 이어, N200의 마무리는 “범용 컴퓨팅, 지능형 컴퓨팅, 컴퓨팅 인터커넥트”라는 3대 핵심 기술 분야의 배치를 완성했음을 의미한다. N200은 범용 컴퓨팅 코어 X200, 지능형 컴퓨팅 코어 A200과 함께 차세대 컴퓨팅 칩에 사용될 예정이며, 2027년 공식 양산이 예상된다. 이는 K3(전 세계 최초로 RVA23 규격을 준수하며 양산된 RISC-V AI CPU, 60 TOPS, 300억~800억 파라미터의 온디바이스 추론 지원) 이후의 아키텍처 심화 움직임이다. 자체 개발 인터커넥트 버스는 차세대 칩이 “기성 NoC 채택”에서 전스택 자체 개발로 전환하여 멀티코어 일관성과 AI 코어 협업 대역폭을 직접 지원한다는 것을 의미한다. 모니터링 기간 내 GitHub 측면에서 Zhendie Shikong(spacemit-com)의 온디바이스 AI 툴체인은 지속적으로 반복되었다. ai-sdk는 09-09 14:01과 17:45, 다음 날 00:22(베이징 시간)에 rl/vision 서브모듈을 여러 차례 업데이트했다. model_zoo_rl은 09-09 20:19에 feat(rl): support inference cancellation and YAML provider selection(#11)을 병합했다. model-zoo-vision, docs-ai, linux도 푸시가 있었다. RL 모델 라이브러리와 추론 취소, YAML provider 선택 등의 기능은 로봇 및 임바디드 시나리오의 중단 가능한 추론과 다중 백엔드 전환에 대한 실제 수요에 대응한다. (참고: 회사 뉴스 페이지의 같은 배치에는 K3의 DeepSeek Harness 실행, GIS 2026 참가 등의 항목도 나열되어 있으나, 해당 이벤트는 모두 이전 모니터링 기간에 해당하므로 중복 수록하지 않는다.)

3.2 Nuclei: 영국 매체, Quintauris RISC-V 생태계 협력 정리, Nuclei 차량 규격 IP RT-Europa에 정렬(영문 매체 09-08~09 정리, 협력 본체는 2026년 상반기)

날짜: 2026-09-08(Electronics World 정리 기사, New Electronics 09-09 동일 주제 보도)　출처: Electronics World, Automotive World, Quintauris 뉴스룸, Nuclei 공지(2026-06-16)

영국 매체 Electronics World는 09-08에 정리 기사를 게재했고, New Electronics는 09-09에 동일 주제로 보도했다. Quintauris는 지속적인 협력을 통해 RISC-V 생태계를 확장하고 있으며, 2026년 상반기에 4건의 협력을 추가했다. Elektrobit(04-21, 자동차 소프트웨어, 소프트웨어 정의 자동차 서비스), Nuclei(06-16, 차량 규격 RISC-V 프로세서 IP를 Quintauris RT-Europa 실시간 플랫폼 규격에 정렬), Ashling(디버그 및 개발 도구), 그리고 EM-Altair Profile 규격으로, 소프트웨어, 하드웨어, 툴체인을 아우른다. 그중 Nuclei 부분의 핵심은 다음과 같다. RT-Europa는 자동차 실시간 RISC-V 프로세서를 위한 최초의 플랫폼 규격(결정론적 메모리 접근, 인터럽트 처리, 특권 모드, 물리 메모리 보호, 디버그 인터페이스 및 SoC 통합 요구사항 정의)이며, Nuclei는 양산 검증된 NA 시리즈로 이에 정렬한다. Nuclei NA 시리즈는 세계 최초로 ISO 26262 ASIL-D 인증을 통과한 RISC-V 프로세서 IP로, ASIL-A부터 ASIL-D까지 커버하며, 고객사는 이미 300개를 넘었고, 라이다, 밀리미터파 레이더, 도메인 컨트롤러, 차량 규격 MCU, 차량 이더넷 및 SoC 안전 아일랜드에 적용된다. 명확히 해야 할 점은, 본 항목은 기존 협력에 대한 영문 매체의 정리형 재보도이며, 협력 본체는 모두 2026년 상반기에 발생한 것(이번 모니터링 기간의 신규 이벤트가 아님)이고, 수록 가치는 “중국 RISC-V IP가 국제 차량 규격 참조 플랫폼에 진입”이라는 산업 신호를 다시 확대한다는 데 있다. 모니터링 기간 내 Nuclei-Software의 GitHub 조직 42개 저장소에는 푸시가 없었고, 자체 개발 동향도 없었다.

5. 요약과 트렌드 관찰

본 보고서 모니터링 기간은 뉴스 측면이 약하고 오픈소스 측면이 활발했으며, 국내는 전시회 첫날 “의제 구체화, 실황 공개 대기”의 과도기 상태에 진입했다. 요점을 정리하면 다음과 같다:

첫째, 오픈소스 코어가 구조 재편기에 진입했다. 샹산은 3일 연속 새로운 벡터 백엔드 명령면(전체 레지스터 이동, vfma/widen, VIDiv)을 전개한 후, 09-09에 VFAlu/VFMA 래퍼 계층을 제거하고 설정 직접 생성으로 전환했으며, XiangShan-Dashboard 1.0.0 릴리스, difftest FPGA 프로브 수정, XiangShanLab에 Zicfilp 템플릿 추가와 함께 검증 및 툴체인 지원이 동기적으로 추진되었다. 담마원 쉬안톄는 Hypervisor 원자 클래스 명령 테스트를 통계 스크립트에 통합하여 테스트 기준선을 지속적으로 강화했다. 오픈소스 측면의 신호 품질이 뉴스 측면보다 높다.

둘째, RISC-V 디바이스 측에서 “무선 연결 + 로봇 제어” 이중 라인 제품 서사가 형성되었다. ESP32-C5(듀얼 밴드 Wi-Fi 6 RISC-V SoC)는 웨이쉐 보드를 통해 Pico 호환 형태로 확산되어 개발자 진입 장벽을 낮춘다. 자오이촹신은 GD32의 Arm+RISC-V 듀얼 아키텍처에 EtherCAT 결정론적 제어와 Cortex-M7/M33 엣지 추론을 결합하여 RISC-V를 로봇/산업 제어 제품 매트릭스에 편입시켰다.

셋째, 국내 팀의 아키텍처 심화가 추진되었다. 진디에스페이스 N200 자체 개발 일관성 인터커넥트 버스가연구개발를 완료하여 “범용 컴퓨팅 코어 + 지능형 컴퓨팅 코어 + 인터커넥트 버스” 3대 핵심 영역을 완성했으며, 2027년 양산을 목표로 하는 차세대 칩의 풀스택 자체 개발을 지향한다. GitHub 측에서는 RL 모델 라이브러리와 중단 가능 추론, 다중 백엔드 선택 등의 기능이 반복 개선되어 임베디드 인텔리전스 시나리오 요구에 직접 대응한다. 신라이커지 차량 규격 IP가 다시 국제 미디어 정리에서 언급되어, 중국 RISC-V IP가 국제 차량 규격 참조 플랫폼에 지속적으로 편입되고 있음을 반영한다(협력 본체는 2026년 상반기, 새로운 사건은 아님).

넷째, 전시회 창구는 열렸지만 실황은 아직 도래하지 않았다. 선전 IICIE 첫날, RISC-V 산업 생태 혁신 대회 의제(칭신즈옌, 궈신커지, 산넝커지, 쭌잔커지, 진디에스페이스, 신지무한, 중더공예 7개 연설)와 “임베디드 인텔리전스 산업 대회”가 같은 시기에 개최되었으며, 담마원 쉬안톄, 산넝커지, 진디에스페이스 등이 집중 참가했다. 첫날 현장 보도와 발표 내용은 본 모니터링 기간 내 검색 채널에 의해 아직 인덱스되지 않았으며, 후속 추적 가치가 높다.
