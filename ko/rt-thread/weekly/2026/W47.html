RT-Thread 위클리 리포트 (2026-11-21)

2026-11-21 Kubuds

이번 주 메인 저장소에 9건이 머지되었고, 소프트웨어 패키지 인덱스 7건, Windows 도구 저장소 2건이 반영되었습니다. 11-19와 11-20은 연속으로 머지가 없었으며, 미종료 제안은 144건에서 138건으로 줄었다가 다시 142건으로 돌아왔습니다. 버전은 여전히 09-10의 v5.3.0에 머물러 있고, 메인 브랜치는 자체적으로 5.4.0을 표방합니다.

  • RT-Smart 경계 정리 네 건: ptyfs 등록 해제 누수, ivshmem 윈도 검증, 블록 디바이스 파티션 ioctl, FinSH 경로 완성. 네 건 모두 11-16과 11-17에 머지되었습니다. ptyfs는 2만 회 열고 닫기를 실측하여 매회 약 369바이트가 누수됨을 확인했습니다.
  • 메일박스 핸들로 권한 우회 읽기/쓰기 가능: 이슈 #11960에서 전체 PoC를 제시하여 임의의 커널 qword를 변경할 수 있습니다. 수정 제안 #12015는 10개 파일을 변경하며 +1440/-126 규모이나 아직 머지되지 않았습니다.
  • 디바이스 명령 전면 재인코딩: #11881이 아홉 개의 범용 명령을 0x2001에서 0x2009로 이동시켰습니다. 저장소 내 14개 파일만 동기화되었고 호환 매크로가 없어, 저장소 외 BSP는 자체 점검이 필요합니다.
  • 세 건의 오래된 이슈에 CVE 번호 부여: 11-16에 CVE-2026-38160, 50961, 106729가 보완되었습니다. 같은 날 CherryUSB는 1.7.0 미만의 경계를 확정했습니다.
  • D213 보드 패키지 사흘 만에 머지: 30개 파일, +1783줄, 11-14 제안 후 11-17 머지. 제출자는 지난주 부동소수점 수정과 동일 인물입니다.
  • 테스트 설정에서 조용히 케이스 누락: mem.cfg에서 MEMHEAP이 선택되지 않아 memheap 케이스 전체가 컴파일되지 않았습니다. 빌드와 테스트 모두 통과로 표시되어 리포트상으로는 이상이 보이지 않습니다.
  • 에코시스템이 커널보다 분주: 패키지 인덱스 7건으로, Agent 설정화 두 건, Wi-Fi 블루투스 호스트 드라이버, ms-probe가 포함됩니다. Windows Env는 CI의 clang-format과 Arm GNU에 맞춰졌습니다.
  • 공식 채널 2주간 침묵: 뉴스 인터페이스는 열 차례 연속 신규 항목이 없습니다. 12월 12일 베이징, 12월 19일 선전 양도시 살롱이 확정되었고, AI Kit가 현장에서 첫 공개됩니다.

이번 주 판단: 실제로 다운스트림의 판단을 바꾸는 것은 명령 재인코딩과 메일박스 권한 우회입니다. 전자는 구 값을 하드코딩한 BSP에 영향을 주고, 후자는 LWP 객체 테이블이 우회될 수 있음을 보여줍니다. 보안 수정은 여전히 정적 대조 위주이며, ptyfs만 정량적 검증을 제공했습니다.
