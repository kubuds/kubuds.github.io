1. 커널 및 버전 동향

1.1 공식 Env 툴체인, WebUI 플러그인 상태 유지 (keep_alive) 메커니즘 머지

날짜: 2026-09-05 (머지 09-05 00:08 베이징 시간)　출처: RT-Thread/env PR #294 (머지 커밋)

RT-Thread 공식 개발 보조 도구 Env (저장소 RT-Thread/env)가 창립자 BernardXiong이 제출한 PR #294 “Add opt-in state retention for plugin WebUI pages”를 머지했습니다. 핵심 변경 사항: 플러그인 manifest.webui에 선택적 keep_alive 필드 추가 (기본값 false), 활성화 시 플러그인 WebUI의 iframe이 플러그인 페이지, 설정 페이지, 플러그인 센터 간 탐색 전환 시 마운트 상태를 유지하여 매번 재로드되지 않음 (비활성화 플러그인은 기존 재로드 동작 유지); 동시에 WebUI 상단 바를 제거하고 ‘WebUI 종료’ 작업을 사이드바 하단으로 이동, 플러그인별 정적 리소스 격리, 샌드박스화된 WebUI 페이지에 선택적 백엔드 HTTP/WebSocket 컨텍스트 개방. 이 PR은 09-02부터 env 브랜치에서 진행된 일련의 WebUI 개편 (플러그인별 iframe 수명 주기 유지, 플러그인 리소스 토큰 및 CSP 경계, doctor 요청 세대 검증 등, feature/ws 브랜치)을 이어받았으며, 이번 머지는 Env의 WebUI 플러그인 시스템이 ‘전환 시 재로드’에서 ‘페이지 상태 필요 시 유지’로 업그레이드되었음을 의미하며, 공식 툴체인 경험 반복 개선에 해당하고 이 모니터링 기간 org 내 유일한 머지입니다.

1.2 메인 저장소 모니터링 기간 내 머지 제로, 신규 PR 제로, 축적기 지속; CAN 리팩터링 PR #11779 새로운 진전 없음

날짜: 2026-09-05　출처: org:RT-Thread 저장소 목록 (commits / pulls 인터페이스)

메인 저장소 rt-thread는 두 번째 모니터링 기간 연속 신규 커밋 머지 없음 (최근 머지는 여전히 09-03 아침 #11776, 어제 이미 수록), 모니터링 기간 내 신규 PR 생성도 없음, release는 여전히 v5.2.2 (2025-10-31). 리뷰 큐 상태는 어제와 동일: CAN 프레임워크 리팩터링 PR #11779 (wdfk-prog, 2 commits, +2902/-1308)의 마지막 코멘트는 여전히 메인테이너 CYFS3가 09-03 17:47 (베이징 시간)에 표명한 입장—별도의 CAN_V2 프레임워크를 유지하는 것을 권장하지 않으며 개발자들이 함께 머지를 추진하기를 희망—모니터링 기간 내 신규 코멘트 및 커밋 없음; #11775 ([bsp][c908] rt-smart 및 MMU Sv39/48 지원), #11772 (힙 런타임 AddressSanitizer), #11774 (sal SIOCGIFCONF 오버플로 수정), #11689 (stm32 SPI BDMA) 등은 모두 open 상태로 변동 없음. 커널 측은 머지 후 통상적인 축적기에 진입했습니다.

2. 공식 및 커뮤니티 활동

2.1 공식 뉴스 API 16일 연속 신규 없음, elexcon 2026 카운트다운 4일

날짜: 2026-09-05　출처: RT-Thread 공식 뉴스 API

공식 뉴스 API(rt_org 분류)는 여전히 오래된 5개 항목이며, 최신 항목은 2026-06-17 아부다비 투자 포럼 보도로, 16일 연속 신규 항목이 없습니다. 다음 대외 창구는 9월 9-11일 선전 elexcon 2026(Ruisaide 전시 참가, 8-30 예고 이미 수록)이며, 카운트다운 4일입니다. 중국어 출처 측 gnews 3일 모니터링 기간 재점검: OSChina에 이미 수록된 기획 보도(09-03) 외에, EE Times China 콘텐츠 두 건이 추가로 확인되었으며(3.2, 3.3 참조), 이는 커뮤니티와 제조사 측 콘텐츠 생산이 여전히 지속되고 있음을 보여주며, 침묵은 공식 뉴스 채널 자체에만 국한됩니다.

3. 생태계 및 제조사 적응

3.1 canopennode-rtt에 CiA402 주기 동기 모드 CSP/CSV/CST 추가, 모션 제어 모드 범위 보완

날짜: 2026-09-05(11:08 베이징 시간 push)　출처: wdfk-prog/canopennode-rtt

topic:rt-thread 생태계 저장소 canopennode-rtt 기본 브랜치 모니터링 기간 내 신규 커밋 「feat: support CiA 402 CSP CSV and CST modes」, CiA402(DS402 모션 제어 프로파일)에 주기 동기 위치(CSP), 주기 동기 속도(CSV), 주기 동기 토크(CST) 세 가지 주기 동기 모드를 추가했습니다. 09-03/09-04에 병합된 다축 디바이스 프로파일 및 PP/PV/Homing 위치/속도/원점 복귀 모드와 연결되어, DS402 지원이 비주기 모드에서 주기 동기 폐루프 모드로 확장되었으며 모션 제어 기능 범위가 보완되었습니다. 해당 작성자가 동시에 메인 저장소에서 Generic CAN 프레임워크 리팩터링(#11779)을 추진하고 있는 점을 고려하면, 「애플리케이션 계층(CANopenNode 확장) + 프레임워크 계층(CAN 리팩터링)」의 이중 트랙 병행 태세가 지속되고 있으며, CAN/모션 제어는 여전히 현재 커뮤니티에서 가장 활발한 추진 주선입니다.

3.2 EE Times China 칼럼에서 커뮤니티 작품 공유: FRDM-MCXN947 USB 모니터 보조 화면

날짜: 2026-09-04(17:30 베이징 시간)　출처: EE Times China a522648(RT-Thread 포럼 원작)

EE Times China 「오픈소스 프로젝트 공유」 칼럼이 09-04에 NXP FRDM-MCXN947 개발 보드 기반 USB Monitor 프로젝트 실습을 소개하는 글을 게재했습니다: RT-Thread 운영체제 + LVGL 그래픽 라이브러리 + CherryUSB 프로토콜 스택을 통해 PC 측 CPU, GPU 등의 실행 상태를 보조 화면에 실시간으로 표시하는 구현입니다. 이 작품은 RT-Thread 포럼 「24 임베디드 설계 대회」의 「USB 일선 통 모니터 보조 화면」 프로젝트에서 비롯되었으며, 커뮤니티 작품이 업계 미디어를 통해 재전파되는 전형적인 사례이자, RT-Thread가 NXP 신규 플랫폼(MCXN947, 듀얼코어 Cortex-M33)에서 LVGL/CherryUSB 생태계와 함께 즉시 활용 가능한 수준임을 보여줍니다. EET 원문 사이트 본문은 직접 접근할 수 없어 링크로 증빙합니다.

3.3 Geehy 「Geehy Chip Talk EP.87」: RTT-Studio 환경에서 APM32 주변장치 드라이버 사용 가이드

날짜: 2026-09-03(11:30 베이징 시간; 오늘 3일 모니터링 기간 재점검 추가 수록, 어제 zh 검색에서 미확인)　출처: EE Times China a522255

Geehy Semiconductor(Geehy) 개발자 커뮤니티 「Geehy Chip Talk」 시리즈 제87회(EE Times China 09-03 게재): RTT-Studio 환경에서의 APM32 주변장치 드라이버 사용 가이드. 이 글은 RT-Thread Studio에서 APM32 프로젝트를 생성한 후 adc, dac, hwtimer, uart 등 주변장치 드라이버의 사용 방법을 설명하며, APM32의 RT-Thread 주변장치 드라이버가 하위 핀 초기화와 주변장치 클럭 활성화를 이미 드라이버 내부에 캡슐화하여 개발자가 디바이스 모델 인터페이스로 직접 호출할 수 있음을 지적합니다. 칩 원제조사가 RT-Thread 생태계를 대상으로 지속적으로 튜토리얼을 제공하는 사례(해당 시리즈는 이전에 APM32 시리즈 RT-Thread BSP 이식, LwIP, LVGL, CherryUSB 등의 주제를 이미 다룸)로, APM32 사용자와 Studio 입문자에게 직접적인 참고 가치가 있습니다.

3.4 생태계 참고: H120D 드론 RT-Thread 내부 메커니즘 리버싱 문서 프로젝트 업데이트

날짜: 2026-09-05(07:31 베이징 시간 push)　출처: H4ck3rTR/h120d-protocol

서드파티 리버스 엔지니어링 문서 프로젝트 h120d-protocol(stars 4)이 모니터링 기간 내에 업데이트되었습니다: Holy Stone H120D 항공 촬영 드론 WiFi 프로토콜 리버스 엔지니어링 데이터 패킷, RT-Thread 내부 메커니즘 설명 및 부속 제어 도구를 정리했습니다. 이 프로젝트는 독립 애호가의 리버스 문서 작업(비공식)으로, 소비자급 드론 펌웨어에 담긴 RT-Thread의 내부 메커니즘(스레드/메시지 등)과 사설 WiFi 프로토콜을 함께 문서화하여, RT-Thread가 소비자 전자/드론 제품에서 실제로 구현되는 형태를 연구하는 데 일정한 참고 가치가 있으며, 생태계 참고 자료로 수록합니다.

4. 요약 및 트렌드 관찰

  • 툴체인 측: 공식 Env 도구에 PR #294 병합——WebUI 플러그인 시스템에 opt-in 상태 유지(keep_alive), 플러그인별 리소스 격리 및 샌드박스 컨텍스트를 도입했으며, 창립자 BernardXiong이 직접 병합하여 공식 개발자 도구 경험 반복 속도가 빨라졌습니다.
  • 커널 측: 메인 저장소가 두 번째 모니터링 기간 연속 제로 병합, 제로 신규 PR(최근 #11776은 09-03), CAN 프레임워크 리팩터링 #11779는 리뷰에 새로운 진전 없음(CYFS3 09-03 입장 표명 후 커뮤니티 응답 대기), 축적기 지속, release는 여전히 v5.2.2.
  • 생태계 측: canopennode-rtt가 이틀 만에 CiA402를 다축 + PP/PV/Homing에서 주기 동기 CSP/CSV/CST 전면 커버리지로 끌어올리며, 모션 컨트롤 메인라인이 활발합니다. 중국어 생태계 콘텐츠 측에서는 EE Times China가 RT-Thread 관련 작품 공유(FRDM-MCXN947 USB 모니터 보조 화면)와 칩 원제조사 튜토리얼(GeekHai EP.87)을 지속적으로 제작하고 있습니다.
  • 공식 측: 공식 뉴스 API가 16일 연속 침묵, elexcon 2026(9/9-11 선전) 카운트다운 4일, 회의 전 침묵은 예상된 리듬입니다.
  • 최근 3일 트렌드(09-03 ~ 09-05): 메인 저장소 #11776 병합, CiA402 다축 및 PP/PV/Homing, CAN 리팩터링 리뷰에서 의견 차이가 발생하고 메인테이너의 「CAN_V2를 만들지 않겠다」는 입장 표명 확보(09-03) → env WebUI 개편 진행, EET 커뮤니티 작품 전재, 공식 침묵 15일차(09-04) → env PR #294 병합, CiA402 주기 동기 모드 구현, 공식 침묵 16일차(09-05). 현재 추진 메인라인은 「공식 툴체인 WebUI 경험 반복 + CAN/모션 컨트롤 생태계 양대 라인」이며, 공식 대외 활동은 elexcon까지 침묵하며 역량을 축적 중입니다.
