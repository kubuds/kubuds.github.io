1. 커널 및 버전 동향

1.1 메인 저장소 [utest][rtc] 병합: RTC 시간 및 알람 테스트 케이스 추가

날짜: 2026-09-01 (13:36 베이징 시간 병합)　출처: PR #11755 (병합 커밋 b1e8365, 메인테이너 Rbb666 병합)

어제 4개 PR의 견고성 배치 (MPU 권한 / net sal 해제 / PWM utest / Renesas CAN FD) 이후, 메인 저장소 모니터링 기간 내 유일한 병합은 본 테스트 커버리지 보완 건: components/drivers/rtc/utest/ 디렉토리 하위에 RTC 시간 테스트 (rtc_time_tc.c)와 알람 테스트 (rtc_alarm_tc.c) 두 그룹의 테스트 케이스를 추가하고, RTC 드라이버의 Kconfig / SConscript 및 components/utilities/utest 전체 설정에 연결하여 활성화했다. RTC 드라이버는 이전까지 utest 체계 내에 전용 테스트 케이스가 없었으나, 본 건으로 시간 및 알람 기능에 자동화 회귀 능력을 갖추게 되었으며, 최근 “테스트 커버리지 보완”이라는 커널 측 메인 라인을 이어갔다. 모니터링 기간 내 대규모 기능 병합은 없었다.

2. 공식 및 커뮤니티 활동

2.1 공식 뉴스 API 13일 연속 신규 없음, elexcon 2026 카운트다운 진입

날짜: 2026-09-02　출처: RT-Thread 공식 뉴스 API

공식 뉴스 API (rt_org 카테고리)는 여전히 5건의 기존 항목이며, 최신 항목은 2026-06-17 아부다비 투자 포럼 보도로, 13일 연속 신규가 없다. gnews 다중 보충 조회 (RT-Thread when:3d 중영문, RT-Thread 睿赛德 when:3d, 睿擎派 OR 睿擎 when:3d): 영문 조회는 여전히 Rotten Tomatoes 평점 / SCALR AI 등 “RT” 분절 노이즈이며; 중문 조회는 오늘 수록된 EET-China 튜토리얼 항목만 적중; Ruiqing 조회는 결과 없음. 공식 측 차기 대외 창구는 9월 9-11일 선전 elexcon 2026 (RT-Thread RealThread 참가, AI 하드웨어 “풀 라인업” 전시, 8-30 예고 이미 수록)으로, 개막 일주일 전이며, 조용한 기간 연장은 예상 범위 내이다.

3. 에코시스템 및 벤더 적응

3.1 packages: Fudan Microelectronics FM33LG0xx FL Library 소프트웨어 패키지 인덱스 등록, 동반 BSP는 아직 병합 대기 중

날짜: 2026-09-01 (11:40 병합)　출처: RT-Thread/packages PR #2030

Fudan Microelectronics의 FM33LG0xx 시리즈 MCU 공식 FL 드라이버 라이브러리 소프트웨어 패키지 fm33lg0xx_fl_library가 새로 추가되었으며, 인덱스 버전은 v2.3.5 / latest 중 선택 가능하고 peripherals/hal-sdk/fm33/ 경로에 배치되어 기존 국산 제조사 HAL 드라이버 패키지(hal-sdk 디렉터리) 체계와 일관된다. PR 설명에 따르면 rt-thread/bsp/fm33lg026과 함께 사용되도록 지원하며, 해당 BSP는 이 패키지에 의존하도록 변경될 예정이나 대응 BSP PR(#11729, 08-21 생성)은 현재도 open 상태로, 즉 “소프트웨어 패키지가 먼저 인덱스에 진입하고 BSP는 메인 저장소 병합을 대기” 중이다. 국산 저전력 MCU 제조사(Fudan Microelectronics FM33 시리즈는 Cortex-M0+ 저전력 제품 라인)의 HAL 드라이버가 공식 소프트웨어 패키지 체계에 진입한 또 하나의 사례이다.

3.2 packages: CANopenNode 포팅 패키지 공식 소프트웨어 패키지 인덱스에 정식 진입

날짜: 2026-09-01(16:45 병합)　출처: RT-Thread/packages PR #2033, github.com/wdfk-prog/canopennode-rtt

어제 리포트에서 커뮤니티 저장소 canopennode-rtt가 “공식 packages 인덱스와 독립적이며, 향후 공식 소프트웨어 패키지 체계 진입 여부를 주시한다”고 언급했는데, 오늘 그 결과가 나왔다: wdfk-prog가 제출한 CANopenNode RT-Thread 포팅 패키지가 공식 인덱스에 정식으로 추가되어, 사용자는 Env/menuconfig를 통해 직접 설정, 다운로드 및 사용할 수 있다(PR 설명). CANopenNode는 국제적으로 잘 알려진 오픈소스 CANopen 프로토콜 스택으로, 이 패키지는 산업/차량용 CANopen 통신 시나리오를 대상으로 한다. 소스 저장소는 모니터링 기간 내 지속적으로 활발했다: 09-02 11:02 co_rtt_mainline_deadline_min을 extern으로 조정하여 메인라인 스케줄링에 대응, 09-01 15:14 임시 테스트 명칭 제거 및 문서 갱신(이벤트 기반 메인라인 스케줄링 08:54는 어제 이미 수록). 커뮤니티 프로젝트의 공식 인덱스 전환은 커뮤니티→공식 소프트웨어 패키지 경로가 원활함을 검증한다.

3.3 진행 중: Tencent IoT SDK 패키지 설정 업데이트 PR 리뷰 대기

날짜: 2026-09-02(10:17 생성, open)　출처: RT-Thread/packages PR #2034

packages 인덱스에 새 PR #2034가 열렸다: Tencent IoT SDK(Tencent IoT SDK) 소프트웨어 패키지 설정을 업데이트하며, 현재 open 상태로 병합 대기 중이다. Tencent Cloud IoT 접속은 IoT 시나리오에서 자주 쓰이는 소프트웨어 패키지로, 설정 업데이트 세부 사항은 병합 후 관찰 예정이며 진행 중 동향으로 수록한다.

4. 산업 응용

4.1 EET-China 기고: Ethos-U55 NPU에 YOLO-Fastest 배포 실전 노트

날짜: 2026-09-01(17:30 게시)　출처: Google News 집계(원문 사이트 eet-china.com/mp/a521750.html, 원문 사이트 현재 접속 불가, 세부 사항은 제목과 요약 기준)

EE Times China “기술 집결” 칼럼에 실전 노트가 게재되어, AI 얼굴 인식 알고리즘을 훈련 환경(PyTorch / TensorFlow)에서 Arm Ethos-U55 microNPU 플랫폼(Renesas RA8P1 등 Ethos-U55 탑재 MCU 대상, Renesas AI 챌린지 단골 주제)으로 엔드투엔드 이식한 내용을 다룬다. 핵심 작업은 모델 양자화, 정밀도 캘리브레이션 및 추론 배포 체인을 포함한다. 이 글은 EET-China의 RT-Thread 태그가 달려 있고 RT-Thread 관련 검색어로 검출되었으며, RT-Thread 생태계 엣지 AI 배포 튜토리얼류 콘텐츠에 속한다. 모니터링 기간 내 미디어 측 유일한 신규 항목이다. 엣지 단 NPU 추론 배포 주제는 최근의 높은 관심(최근 RT-Thread AI 하드웨어 방향과 일치)을 이어가고 있으며, 튜토리얼류 콘텐츠는 개발자 생태계에 직접적 가치가 있다.

5. 요약 및 트렌드 관찰

  • 커널 측: 메인 저장소 모니터링 기간 내 단일 병합([utest][rtc] RTC 시간/알람 테스트 보완, 09-01 13:36), 어제의 견고성 배치 이후 테스트 커버리지 주선을 이어갔으며, 평일 병합 리듬은 안정적이고 대형 기능은 보이지 않음.
  • 생태계 측: 소프트웨어 패키지 인덱스가 연속 세 번째 활동일——푸단웨이 FM33LG0xx FL 라이브러리 인덱스 등록(국산 MCU HAL 드라이버 확장), CANopenNode 이식 패키지가 커뮤니티 프로젝트에서 공식 인덱스로 전환(어제 예측 실현), Tencent IoT SDK 설정 업데이트 진행 중; “소프트웨어 패키지 생태계 거버넌스와 확장”이 현재 가장 명확한 추진 주선.
  • 공식 측: 공식 뉴스 API 13일 연속 신규 없음; 다음 대외 창구는 9월 9-11일 선전 elexcon 2026, 카운트다운 일주일 진입.
  • 미디어 측: 모니터링 기간 내 유일한 신규 항목은 EET-China의 Ethos-U55 + YOLO-Fastest 배포 튜토리얼, 엣지 AI 배포 주제 지속; Google News의 “RT-Thread” 단어 분리 노이즈는 여전히 심각, 미디어 출처는 공식 API와 GitHub를 기준으로 함.
  • 최근 3일 추세(08-31 ~ 09-02): RT-Smart POSIX 호환 배치와 optparse 이중 버전 거버넌스(08-31) → 커널 견고성 4 PR, CANopenNode 이벤트 기반 스케줄링(09-01 오전) → RTC utest, 두 소프트웨어 패키지 인덱스 등록, CANopenNode 공식 전환(09-01 오후 ~ 09-02). 주선은 커널 테스트 커버리지 보완 + 소프트웨어 패키지 인덱스 확장 + 산업 통신(CANopen)과 엣지 AI 생태계 추진이며, 뉴스량이 적은 날은 GitHub 저장소 동향이 중심.
