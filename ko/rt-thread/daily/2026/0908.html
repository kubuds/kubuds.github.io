1. 커널 및 버전 동향

1.1 sal 계층 SIOCGIFCONF 버퍼 오버플로 수정 메인 저장소 병합 (#11774)

날짜: 2026-09-07 (14:53 베이징 시간 병합, 즉 06:53:10Z)　출처: RT-Thread/rt-thread commits (PR #11774)

어제 리포트에서 리뷰 큐에 포함되었던 #11774 [components][sal] Fix SIOCGIFCONF buffer overflow (Huoyanlifusu 제출)가 09-07 오후 master에 정식 병합되었다. 해당 PR은 09-07 아침 Rbb666의 CHANGES_REQUESTED 반려 의견을 받았고, 작성자는 당일 수정 버전을 재푸시했으며(어제 수집됨), 이번 병합으로 「반려—재푸시—병합」 라운드가 완료되었음을 의미한다. 이 수정은 sal 계층 SIOCGIFCONF(인터페이스 주소 목록 조회) ioctl 처리에서의 버퍼 오버플로 위험을 대상으로 하며, 네트워크 컴포넌트 메모리 안전성 계열 수정에 해당한다. 병합 시점은 어제 아침 4건 PR 배치 이후이며, 모니터링 기간 내 유일한 신규 병합이다. release는 여전히 v5.2.2 (2025-10-31)이며 신규 버전 릴리스 동작은 없었다.

1.2 Env (Windows 버전) 도구 v2.1.0 릴리스, 2년여 만의 첫 버전 점프

날짜: 2026-09-08 (11:04 베이징 시간, 즉 03:04:16Z, tag v2.1.0 동시 생성)　출처: RT-Thread/env-windows (commit fc857c5, tag v2.1.0)

RT-Thread Env 도구 Windows 버전 저장소(ConEmu shell 환경의 Env 도구)가 오늘 오전 v2.1.0을 릴리스했다. 단일 커밋 “Update Env to version 2.1.0”으로, packages 소프트웨어 패키지 인덱스 업데이트, tools/bin/env-init.bat 및 tools/scripts 조정을 포함한다. 이 버전은 이전 정식 버전 v2.0.0 (2024-07-10)으로부터 2년 이상 지난 것으로, env-windows 저장소가 2024-07 이후 처음으로 버전 점프를 한 것이다(그 사이 2025-06에 DTC 도구 기능 커밋 1건만 추가됨). GitHub Releases 페이지에는 아직 v2.1.0 release 객체가 생성되지 않았고 현재는 tag만 반영된 상태이며, 정식 릴리스 노트는 공지/위챗 채널을 통해 공개될 것으로 예상된다. env 메인 저장소가 09-04에 병합한 WebUI 플러그인 유지보수 반복(#294, 수집됨)과 연결되며, Env 툴체인(메뉴 구성/소프트웨어 패키지 관리/WebUI 플러그인)의 최근 반복 속도가 빨라지고 있어 elexcon 2026 전후 툴체인 통합 작업의 일부일 가능성이 있다.

1.4 OSPP 2026 이슈 제안: RISC-V Lazy FP/RVV 컨텍스트 스위치 (#11786)

날짜: 2026-09-07 (23:49 베이징 시간 생성, 즉 15:49:05Z)　출처: RT-Thread/rt-thread issue #11786

외부 기여자 PiyushPatle26가 메인 저장소에 OSPP 2026 이슈 제안(issue #11786)을 제출: RISC-V 이식은 현재 매 컨텍스트 스위치마다 스레드가 부동소수점을 전혀 사용하지 않더라도 무조건 전체 FPU 상태를 저장/복원함; 동시에 커널은 벡터 확장(RVV)을 전혀 지원하지 않음——벡터 레지스터가 스레드 컨텍스트에 없어, V 명령을 사용하는 모든 스레드의 상태는 컨텍스트 스위치로 조용히 파괴됨. 하드웨어가 이미 제공하는 mstatus.FS / mstatus.VS dirty 비트를 활용해 확장 상태 저장/복원을 무조건 수행하는 대신 지연(lazy) 모드로 전환할 것을 제안. 해당 이슈는 초기 issue #10722(RISC-V 벡터 지원 공백)와 연관됨. 이 제안이 채택되면 커널 RISC-V 이식의 부동소수점/벡터 확장 컨텍스트 관리에 대한 구조적 개선이 될 것이며, #11775(C908 rt-smart/MMU)와 함께 커널 측 RISC-V 메인라인 추진에 속함. 모니터링 기간 내 별도로 두 건의 pin_api_attach_irq legacy 경로 IRQ 파라미터 문제 issue(#11783 종료됨, #11784 추적 중, 09-07 15:14/16:57 생성)가 있었으며, 동일한 드라이버 등록 문제에 대한 후속 보고임.

2. 공식 및 커뮤니티 활동

2.1 공식 뉴스 API 19일 연속 신규 없음; elexcon 2026 내일 개막

날짜: 2026-09-08　출처: RT-Thread 공식 뉴스 API

공식 뉴스 API(rt_org 분류)는 여전히 5건의 이전 항목이며, 최신 항목은 여전히 2026-06-17 아부다비 투자 포럼 보도로, 19일 연속 신규 항목이 없습니다. elexcon 2026 선전 국제 전자전 겸 임베디드 전(09-09 ~ 09-11, 선전 국제 컨벤션센터 바오안 신관, Ruiside 참가, 「AI 하드웨어 풀 패키지」 예고 08-30 기수록)이 내일 개막하며, 공식 대외 콘텐츠는 전시회와 함께 집중적으로 공개될 것으로 예상됩니다. 중국어 미디어 측(Google News 프록시 경유 검증 “RT-Thread” when:3d, Ruiside when:7d, Ruiqingpai OR Ruiqing when:7d) 모니터링 기간 내 아래 보충 항목 외 신규 항목 없음; 영어 측(“RT-Thread” when:2d / “RT-Thread Studio” when:7d) 적중 없음, 전시회 전 정적 상태 지속.

2.2 공식 위챗 공개 계정 「Gino Pi 플래그십 메이커 플랫폼」 신제품 첫 공개 카운트다운 예고

날짜: 2026-09-06 저녁 ~ 09-07(gnews 수록; 위챗 공개 계정 미러 페이지 09-07 표기)　출처: EE Times China·RT-Thread 공식 미러 계정 《미스터리 신제품 첫 공개 카운트다운｜Gino Pi 플래그십 메이커 플랫폼》

RT-Thread 공식 위챗 공개 계정(EE Times China EET-China 플랫폼 미러 계정 「RTThread사물인터넷운영체제」를 통해 게시)이 《미스터리 신제품 첫 공개 카운트다운｜Gino Pi 플래그십 메이커 플랫폼》 예고를 게시하며, Gino Pi라는 이름의 플래그십 메이커 플랫폼 신제품을 출시할 것이라고 발표했습니다. 해당 글은 전문을 읽으려면 로그인이 필요하며, 구체적인 하드웨어 사양, 칩 플랫폼(RISC-V 여부), 출시 시기는 모두 공개되지 않았습니다; 게시 시점이 elexcon 2026 개막 전(09-09)과 맞물려, Ruiside 전시회 「AI 하드웨어 풀 패키지」 사전 예열(08-30 기수록) 타임라인과 일치하여, 전시회 첫 공개 신제품 예고일 가능성이 높다고 판단되며, 내일 전시회 정보 검증 후 후속 추적 예정입니다. 이 항목은 09-06 gnews에 수록되었으나 어제 리포트 모니터링 기간 내 적중하지 못한(gnews 인덱스 지연) 보충 항목입니다.

3. 생태계 및 제조사 적응

3.1 생태계 측 모니터링 기간 내 특별 동향 없음: packages 인덱스와 canopennode-rtt 모두 신규 커밋 없음

날짜: 2026-09-08　출처: RT-Thread/packages, wdfk-prog/canopennode-rtt

packages 소프트웨어 패키지 인덱스 저장소는 모니터링 기간 내 커밋 없음(최종 업데이트 09-01 CANopenNode 인덱스, 기수록); topic:rt-thread 생태계 저장소는 09-06 이후 신규 push 없음; 외부 브랜치 저장소 canopennode-rtt는 신규 커밋 없음(최종 09-06 아침 CiA401 관련, 기수록). 주목할 점은 wdfk-prog(canopennode-rtt 작성자)가 이번 주 공식 저장소 CAN 프레임워크 리팩터링 #11779에 집중하고 있다는 것(오늘 아침 11:10에도 업데이트 있음, 1.3 참조), 「외부 생태계 이식 + 공식 프레임워크 기여」 두 축 중 공식 측이 지속적으로 활발합니다. fetch 모니터링 기간 내 적중한 zlgopen/awtk(09-08 02:50 push)는 검증 결과 combo_box 상호작용 개선 및 sdl3 Windows 빌드 수정 등 범용 GUI 커밋으로 RT-Thread 전용과 직접적 관련이 없어 제외하고 수록하지 않습니다.

4. 산업 응용

신규 항목 없음. 모니터링 기간 내 신규 산업 응용/적용 사례 보도 없음, 산업 측 정적 상태 지속. 내일 개막하는 elexcon 2026(산업/로봇/자동차 전자 부문)과 Ruiside 부스 동향이 다음 산업 콘텐츠 모니터링 기간이 될 것입니다.

5. 요약 및 트렌드 관찰
