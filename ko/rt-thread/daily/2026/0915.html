1. 커널 및 버전 동향

1.1 RISC-V 지연 FP/RVV 컨텍스트 스위칭 제안, 커널 메인테이너로부터 긍정적 반응 확보 (#11786) (09-15)

날짜: 2026-09-07 제안 제출, 2026-09-15 10:23 메인테이너 답변 (베이징 시간)　출처: Issue #11786

해당 이슈는 OSPP 2026 주제 형식으로 제안되었으며, 기존 RISC-V 포팅 레이어에 두 가지 구조적 결함이 존재함을 지적한다: 첫째, 매 컨텍스트 스위칭 시 스레드가 부동소수점 유닛을 사용한 적이 없음에도 불구하고 무조건 전체 FPU 상태를 저장 및 복원한다; 둘째, 벡터 확장 RVV를 전혀 지원하지 않아 벡터 레지스터가 스레드 컨텍스트에 포함되지 않으며, 벡터 명령어를 사용하는 모든 스레드의 상태가 컨텍스트 스위칭에 의해 조용히 손상된다. 두 가지 모두 기존 이슈 #10722에 기록되어 있다. 제안은 확장 상태를 지연 저장 및 복원 방식으로 변경할 것을 권고한다, 즉 실제 사용 시에만 상태를 반영하는 것이다. 메인테이너 Rbb666은 모니터링 기간 내 답변에서 이는 훌륭한 성능 최적화 제안이라며 PR 제출을 환영한다고 밝혔다. 해당 이슈의 레이블은 enhancement, Kernel, Arch: RISC-V이며, 모니터링 기간 내 유일한 아키텍처급 방향성 입장 표명이다.

1.2 리뷰 큐 관찰 (1): STM32N657 Nucleo BSP 하루 네 번 강제 푸시로 CI 수정 (#11799) (09-14)

날짜: 2026-09-14 13:21 / 13:24 / 15:06 / 16:44 (베이징 시간)　출처: PR #11799

STMicroelectronics STM32N657 시리즈의 stm32n657-st-nucleo BSP (84개 파일, 약 15,340줄 추가)가 모니터링 기간 내 작성자에 의해 연속 네 번 강제 푸시되었다 (09-14 13:21, 13:24, 15:06, 16:44). 이는 메인테이너의 “CI 문제를 수정해야 합니다”라는 리뷰 의견에 직접 대응한 것이다. 해당 PR은 09-11에 리뷰 요청되었으며, 리뷰어로 Liang1795, hamburger-os, wdfk-prog가 지정되었다. 서드파티 메모리 비교 도구가 발행한 보고서에서 해당 보드는 아직 비교 대상에 포함되지 않았다. 하루 고빈도 재푸시는 CI와 리뷰 의견 피드백 루프가 여전히 진행 중이며 아직 병합 단계에 진입하지 않았음을 보여준다.

1.3 리뷰 큐 관찰 (2): GigaDevice N32H 3개 시리즈 드라이버 확장, 리뷰 반영 후 재푸시 (#11800) (09-14)

날짜: 2026-09-14 16:48 (베이징 시간, 강제 푸시)　출처: PR #11800

해당 PR은 bsp/n32/n32hxxx 아래에 N32H47x_48x, N32H49x, N32H7xx 세 시리즈 드라이버를 확장하며, n32h487zgl7-evb, n32h497zgl7-evb, n32h760zil7-stb 세 보드를 포괄한다. 공용 드라이버 계층에 ADC, DAC, I2C, SPI 설정 헤더 파일을 추가하고, drv_adc, drv_dac, drv_eth, drv_gpio, drv_hard_i2c, drv_nand, drv_qspi, drv_sdram, drv_spi, drv_usart, drv_wdt 등 29개 파일을 확장했다. 두 evb에는 추가로 FEMC 타이밍 테이블, ETH PHY 리셋 및 CherryUSB 설정이 추가되었다. 모니터링 기간 내 작성자는 다시 강제 푸시했으며, 리뷰 스레드에서 자동 리뷰가 제기한 문제에 대해 항목별로 답변했다. 여기에는 I2C DMA 타임아웃 처리를 독립 변경 사항으로 설명하고, N32H7xx의 전송 중단 로직을 확장한 것 등이 포함된다. 국산 MCU 원제조사 드라이버 보강은 여전히 리뷰 큐의 주요 구성 요소이다.

1.4 리뷰 큐 관찰 (3): lwip 2.2.1 지원 브랜치 재차 재푸시, 서드파티 메모리 비교 변화 없음 (#11797) (09-15)

날짜: 2026-09-15 11:19 (베이징 시간, 강제 푸시)　출처: PR #11797

해당 PR은 #11588을 수정하기 위해 lwip 2.2.1 지원을 도입했으며, 검증용 BSP는 bsp/nxp/imx/imxrt/imxrt1180-nxp-evk/m7이고 BSP_USING_ETH, RT_USING_SAL, RT_USING_NETDEV, RT_USING_LWIP를 활성화했다. 모니터링 기간 내 작성자는 다시 강제 푸시했으며(commit 04a4e19b), 같은 기간 서드파티 메모리 비교 도구(MemBrowse)가 해당 PR에 대해 보고서를 제출하여 메모리 점유 변화가 도입되지 않았다고 판정했다. 리뷰 레이블은 components, 리뷰어는 Maihuanyi. 프로토콜 스택 버전 업그레이드는 산업 및 게이트웨이 시나리오에서 흔히 쓰이는 경로이며, 이번 기수는 리뷰 반복 단계에 있어 아직 메인라인에 머지되지 않았다.

2. 공식 및 커뮤니티 활동

2.1 Ruiside의 산업 지능화를 위한 풀스택 역량 기고문이 업계 미디어를 통해 게시됨 (09-14)

날짜: 2026-09-14 11:50 (베이징 시간, 집계 시간)　출처: EE Times China (집계)

업계 미디어가 「OS 뿌리에서 AI 구현까지: RT-Thread Ruiside 풀스택 역량이 산업 지능화 업그레이드를 겨냥하다」를 게시했다. 주제는 회사가 실시간 운영체제 커널을 뿌리로 삼아 산업 시나리오 AI 역량으로 확장하는 기술 경로이다. 이 방향에 대응하는 제품은 Ruiqing 산업용 하드웨어·소프트웨어 일체형 개발 플랫폼이다. 공식 입장에 따르면 자체 개발한 실시간 제어 기술을 기반으로 마이크로초급 실시간 응답(일부 시나리오에서 1마이크로초 미만)을 구현하고, 주요 산업 통신 프로토콜 스택, 그래픽 인터페이스 컴포넌트 및 다양한 미들웨어를 깊이 통합하여 하위 커널부터 상위 애플리케이션까지 완전한 공업 제어 소프트웨어 기반을 형성함으로써, 산업 제어 연구개발에서 시스템 복잡성이 높고 소프트웨어 반복 주기가 길며 자주적 통제 필요성이 절박하다는 세 가지 문제점에 대응한다. 원문 페이지는 네트워크 접근이 제한되어 여기서는 집계 링크를 인용한다.

2.2 Lingang 자동차 소프트웨어 얼라이언스 제5기 기술 살롱 예고 발표 (09-15)

날짜: 2026-09-15 08:57 (베이징 시간, 집계 시간)　출처: EE Times China (집계)

Lingang 자동차 소프트웨어 얼라이언스 제5기 기술 살롱이 활동 예고를 발표했으며, Horizon Robotics 등 기업이 참여하여 AI 연산력, 모델 배포, 운영체제 기반, 툴체인 등 다양한 각도에서 접근한다. 얼라이언스는 Lingang 신구역 관리위원회의 지도로 결성되었으며, Ruiside는 초기 멤버로서 지난 살롱에서 AI로 운영체제와 차량용 기반 소프트웨어 의제에 대해 공유한 바 있다. Ruiside의 차량용 방향 대응 제품은 Chengxuan 차량 기반 소프트웨어 OS로, AUTOSAR 표준에 부합하는 코드 생성 툴체인과 보안 인증 전 과정 지원을 제공한다. 원문 예고 페이지는 네트워크 접근이 제한되어 여기서는 집계 링크를 인용한다.

2.3 공식 뉴스 API 연속 26일째 신규 없음 (09-15)

날짜: 2026-09-15 11:18 (확인 시간)　출처: RT-Thread 공식 뉴스 인터페이스

공식 뉴스 인터페이스의 최신 항목 날짜는 여전히 2026-06-17이며, 모니터링 기간 내 신규 기록이 없어 연속 26일째 업데이트가 중단되었다. 이와 대조적으로 이번 기수에서 가장 비중 있는 제품 움직임(Gino Pi 정식 판매)은 공식 위챗 채널에서 나왔으며, 이는 회사의 대외 발표 중심이 뉴미디어로 이동했음을 보여준다. 외부 관찰은 위챗 집계 출처와 GitHub 저장소 상태를 교차 검증해야 한다. 커뮤니티 포럼 글 목록 인터페이스는 이번 기수에 비정상 상태를 반환하여 포럼 내용은 이번 기수에 포함되지 않았으며, 포럼 측에 신규 기술 글이 있는지 확인할 수 없었다.

3. 생태계 및 벤더 적응

3.1 RT-Thread, GigaDevice와 손잡고 Gino Pi 개발 보드 정식 출시, 첫 출시 혜택 80위안 (09-15)

날짜: 2026-09-15 08:00 (베이징 시간, 집계 시간)　출처: EE Times China (집계)

RT-Thread의 RealThread가 GigaDevice와 손잡고 Gino Pi 개발 보드를 정식 출시했으며, 첫 출시 혜택은 80위안이고 같은 시기 Gino Pi 신제품 해설도 발표되었다. 해당 보드는 이전에 09-11에 RT-Thread Studio SDK 인덱스에 진입했으며(GD32H77D-Gino BSP v1.0.0, 패키지 138 MB), 이번 기간에 “다운로드 가능한 BSP”에서 “공개 판매”로 진전했다. 이는 GigaDevice와 RealThread의 전략적 협력(GD32 전 시리즈를 포괄하며 GD32F5, GD32VW553, GD32H7 세 제품 라인을 중점 심화)이 개발 보드 차원에서 결실을 맺은 첫 번째 하드웨어이다. 원문 페이지는 네트워크 접근이 제한되어 있으며, 가격과 할인 폭은 집계 요약을 기준으로 하며 공식 페이지의 2차 확인은 받지 못했다.

3.2 Gino Pi 하드웨어 사양과 기술적 실체: Studio BSP SDK 저장소 공개 자료 (09-10)

날짜: 2026-09-10 (SDK 마무리 커밋)　출처: sdk-bsp-gd32h77d-realthread-ginopi

Studio BSP SDK 저장소를 통해 보드의 실제 형태를 확인할 수 있다. 코어는 GD32H77DIW(Arm Cortex-M7, 최대 600 MHz)이고, 25 MHz 크리스털, 콘솔 UART1(PA2/PA3, 115200-8-N-1), 동작 표시등 PC4가 500밀리초마다 토글된다. 외부 확장으로 32 MiB SDRAM(0xC0000000에 매핑)과 온보드 8 MiB GD25Q64E QSPI Flash가 있으며, 디스플레이는 720×720 MIPI DSI 화면(FL7707N, RGB565)이고 터치는 GT911이 I2C3를 사용한다. 카메라는 OV7670(QVGA RGB565, DCI 및 DMA)이고, 이더넷은 ENET1 RMII이며, Wi-Fi는 GD32VW553 AT 모듈이 UART4를 통해 제공한다. 다운로드 및 디버깅은 SWD(Studio 측 DAP-Link / PyOCD, MDK 측 CMSIS-DAP)를 사용한다. SDK는 RT-Thread 5.3.0을 기반으로 하며 16개의 주변장치 및 애플리케이션 예제 프로젝트를 포함하고, UART, I2C, SPI, QSPI Flash, SD 카드, CAN, PWM, RTC, SDRAM, USB 디바이스 및 호스트, LVGL 디스플레이 및 터치, Wi-Fi, 이더넷, 카메라, MQTT 그리고 출하 시 종합 데모를 포괄하며, Studio와 MDK5 두 가지 프로젝트 세트를 제공한다. 전체적으로 H7급 그래픽 인터랙션 및 네트워킹 평가 플랫폼으로 자리매김하며, 인간-기계 인터페이스와 멀티미디어 애플리케이션에 뚜렷하게 치우쳐 있다.

3.3 소프트웨어 패키지 인덱스: STM32N657xx FSBL 인덱스 커밋이 메인 인덱스에 병합됨 (09-14)

날짜: 2026-09-14 12:35 (베이징 시간, 병합 시간; 작성자 커밋 날짜 09-10)　출처: commit d9b53de7

지난 기간에 심사를 올린 hal_sdk 디렉터리의 STM32N657xx FSBL 소프트웨어 패키지 인덱스(소프트웨어 패키지 인덱스 저장소 PR #2041에 해당)가 모니터링 기간 내에 병합되었으며, 커밋은 peripherals/hal-sdk/stm32/stm32n657xx_fsbl/Kconfig와 package.json 두 파일을 추가하고 stm32 디렉터리 Kconfig를 동기화 갱신하여 새 항목을 마운트했다. 이 소프트웨어 패키지는 메인 저장소에서 심사 중인 stm32n657-st-nucleo BSP와 짝을 이루며, 이는 STM32N6 시리즈 FSBL(1단계 보안 부팅 로더) 단계의 자원이 소프트웨어 패키지 측에서 먼저 자리를 잡았음을 의미하므로 개발자는 패키지 관리자에서 직접 얻을 수 있다. 소프트웨어 패키지 인덱스와 메인 저장소 BSP 심사의 선후 협력은 최근 STM32 신시리즈 도입의 고정된 리듬이다.

4. 산업 응용

4.1 모니터링 기간 내 신규 적용 사례 없음; 산업 품질 검사 대회 문제와 린강 살롱 예고는 기존 및 전향적 움직임 (09-14 ~ 09-15)

날짜: 2026-09-14 ~ 2026-09-15　출처: RT-Thread 공식 뉴스 인터페이스, EE Times China(집계)

모니터링 기간 내에 새로운 양산 또는 상용화 사례는 공개되지 않았으며, 공식 뉴스 인터페이스에도 사례 유형의 새로운 기사가 없었습니다. 추적 가능한 전향적 단서는 두 가지입니다. 첫째, 09-11에 공개된 “모든 개발자가 할 수 있는 산업 품질 검사 AI” 주제(2026 오픈소스 대회, 총 상금 100만 위안)는 여전히 접수 기간 중이며, 방향은 RT-Thread가 오랫동안 운영해 온 산업 품질 검사 시나리오입니다. 둘째, 09-15의 링강 자동차 소프트웨어 얼라이언스 제5기 기술 살롱 예고는 AI 연산력, 모델 배포, 운영체제 기반과 툴체인에 초점을 맞추며 차량용 소프트웨어 생태계의 협력을 지향합니다. 로봇 및 구현형 지능 방향은 모니터링 기간 내에 새로운 움직임이 없었으며, 지난주 흐름과 일치합니다.

5. 요약 및 트렌드 관찰

5.1 최근 3일 트렌드(09-12 ~ 09-15)

  • 제품 측 폐쇄 루프: Gino Pi가 SDK 인덱스 마운트(09-11)에서 정식 판매(09-15)까지 이어진 것은 이번 주 가장 실질적인 의미를 지닌 움직임입니다. GD32H7 플랫폼은 RuisiDe의 고성능 그래픽 인터랙션 보드에서 두 번째 제품 라인이 되었으며, 이전에는 이 위치를 STM32H7 플랫폼의 ART-Pi 시리즈가 담당했습니다. 칩 공급망의 국산화 선택이 더 명확해졌습니다.
  • 커널 측 아키텍처급 의제로 전환: RISC-V 지연 FP/RVV 컨텍스트 스위치 제안이 메인테이너의 긍정적 응답을 받았고, 여기에 XuanTie C908의 QEMU rt-smart 지원이 지속적으로 추진되면서 RISC-V 방향의 메인라인 커널 내 투자 가시성이 높아졌습니다. 이러한 변경은 실시간 성능과 벡터 시나리오 사용성에 직접 영향을 미치므로 후속 PR 추적이 가치 있습니다.
  • 리뷰 측은 여전히 BSP와 드라이버: STM32N657 Nucleo BSP와 국민기술 N32H 3개 시리즈 드라이버 확장이 리뷰 큐의 주체를 구성하며, 두 칩 원제조사와 생태계 개발자가 집중적으로 재푸시하고 리뷰에 항목별로 응답하고 있습니다. 머지 속도는 CI와 리뷰 의견 폐쇄 속도에 달려 있습니다.
  • 생태계 측 안정적 마무리: STM32N657xx FSBL 소프트웨어 패키지 인덱스가 머지되었고, 메인 저장소 BSP 제출과 함께 구성되어 STM32N6 시리즈가 패키지 관리자에서 먼저 사용 가능해졌습니다.
  • 전파 측 채널 이동: 공식 뉴스 인터페이스는 06-17부터 업데이트가 중단된 지 26일이 지났으며, 제품과 활동 정보는 주로 위챗 공식 계정 채널을 통해 집중 발표됩니다. 외부 검색은 집계 소스와 GitHub 상태를 함께 활용해야 하며, 공식 인터페이스만으로는 중대한 제품 움직임을 놓칠 수 있습니다.

5.2 한계와 중복 제거 설명

  • 이번 기간 주요 뉴스의 세 원본 페이지(Gino Pi 판매, 산업 지능화 업그레이드 기사, 링강 살롱 예고)는 네트워크 접근이 제한되어, 본문 세부 사항은 집계 요약과 RT-Thread Studio BSP SDK 저장소의 공개 기술 자료를 교차 확인한 것입니다. Gino Pi의 “첫 출시 할인 80위안”은 집계 요약을 기준으로 하며, 공식 페이지에서 2차 확인을 받지 못했습니다.
  • 중복 제거 설명: Gino Pi의 BSP 인덱스 마운트(09-11), STM32 SPI BDMA 지원 메인라인 머지(머지 시각 09-14 09:59, 이번 기간 윈도 시작 시점 11:18보다 이전), lely-canopen-rtt와 h120d-protocol 등 생태계 저장소 관찰은 모두 2026-09-14 리포트에 수록되었으므로 이번 기간에는 중복 보도하지 않습니다. 이번 기간 새로 추가된 내용은 판매 움직임 자체, 보드 하드웨어 사양, 그리고 소프트웨어 패키지 인덱스의 머지 상태 변화입니다.
  • 커뮤니티 포럼 글 목록 인터페이스가 이번 기간 비정상 상태 코드를 반환하여 포럼 내용은 포함되지 않았으며, 포럼 측에 수록되지 않은 기술 글이 존재할 가능성을 배제할 수 없습니다.
  • 공식 뉴스 인터페이스는 신규 항목이 없으며, 최신 항목 날짜는 2026-06-17입니다.
