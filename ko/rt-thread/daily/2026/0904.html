1. 커널 및 버전 동향

1.1 진행 중: CAN 프레임워크 리팩터링 PR #11779 리뷰 논의 진입, 메인테이너는 CAN_V2 별도 구축 불가 입장 표명

날짜: 2026-09-03 (리뷰 논의 집중일; 스레드는 09-02부터 지속)　출처: PR #11779

어제 수록된 Generic CAN 프레임워크 구조적 리팩터링 PR(wdfk-prog 제출, 2 commits, +2902/-1308)이 모니터링 기간 내 실질 리뷰에 진입: 메인테이너 CYFS3가 09-02 22:10에 “다른 BSP도 can 재적응이 필요한가”라고 질문했고, 작성자는 09-03 08:26에 불필요하다고 응답 — STM32 bxCAN 변경은 RT_CAN_CMD_ABORT_TX 지원을 위한 것뿐이고 나머지는 CI 포맷팅과 최적화이며 프레임워크 설계는 이미 호환 처리를 해두었다는 것; 09-03 16:39 리뷰에서 “Request changes” 의견 제시, 핵심은 현재 구현이 Generic CAN과 모든 BSP 간의 런타임 계약을 변경했으면서 STM32 bxCAN만 마이그레이션했으므로 “다른 BSP 적응 불필요”라는 호환성 약속을 아직 충족하지 못한다는 것; 이어서 17:47 CYFS3가 명확히 표명: CAN_V2 프레임워크를 별도로 유지하는 것은 권장하지 않음(유지 비용 과다), 관심 있는 개발자들이 함께 참여하여 본 PR 머지를 추진해주기를 희망. 현재 댓글 8개, PR은 여전히 open, 머지 전략은 아직 협의 중이나 리팩터링 방향 자체는 의문이 제기되지 않았고 메인테이너의 지지를 받음.

1.2 메인 저장소 모니터링 기간 내 신규 머지 없음, 리뷰 대기열 다수 PR 활발 유지

날짜: 2026-09-04　출처: org:RT-Thread 저장소 목록 (commits / pulls 인터페이스)

모니터링 기간 내 메인 저장소에 신규 커밋 머지 없음(09-03 아침 #11776 이후 정체), release는 여전히 v5.2.2 (2025-10-31). 리뷰 대기열에서 주목할 만한 오픈소스 PR: #11775 ([bsp][c908] QEMU c908에 rt-smart 및 MMU Sv39/48 지원 추가, 09-04 11:21 베이징 시간 업데이트 활동 있음), #11772 ([components][asan] 힙 런타임 AddressSanitizer), #11774 ([sal] SIOCGIFCONF 버퍼 오버플로 수정), #11689 ([stm32] SPI에 BDMA 지원 추가). 모두 open 상태로 머지 대기 중이며, 모니터링 기간 내 신규 PR 생성은 없었고 리뷰 처리량의 통상적 축적기에 해당.

2. 공식 및 커뮤니티 활동

2.1 Ruisi De 2026 상하이 오픈소스 소프트웨어 애플리케이션 혁신 대회 과제 발표: 산업 품질 검사 AI를 위한 Ruiiing 플랫폼 툴체인

날짜: 2026-09-03　출처: OSChina 뉴스 (접수 링크 oschina.net/os2026)

RT-Thread 데일리 리포트(2026-09-04) 중 2/3 블록

Ruisaide가 “2026 상하이 오픈소스 소프트웨어 응용 혁신 대회” AI+산업 소프트웨어 트랙에서 《루이칭 산업 개발 플랫폼 기반 사전학습 비전 모델 경량화 적응 및 로우코드 배포 최적화》라는 과제를 제안했다. 이 과제는 산업 품질 검사 배포의 “마지막 1킬로미터”를 정조준한다. 루이칭 산업 플랫폼은 고실시간성 산업용 커널과 NCNN 추론 프레임워크(YOLOv3 범용 객체 검출 기본 지원)를 내장하고 있지만, 현장 데이터 수집 및 샘플 라벨링 기능이 없고, 사용자 정의 산업용 사전학습 모델 가져오기를 지원하지 않으며, 배포가 수작업 코드 작성에 의존한다. 대회 과제는 플랫폼 실시간 커널을 개조하지 않는 전제 아래 네 단계 툴체인을 경량화하여 보완할 것을 요구한다. 즉 데이터 수집과 정규화, 결함 샘플 온라인 라벨링, 사용자 정의 모델 양자화와 연산자 호환 적응, 로우코드 원클릭 배포이며, 실행 가능한 Demo를 제출하고 툴 완전성/플랫폼 적응성/모델 최적화 효과/사용 편의성 네 가지 차원으로 심사한다. 접수 마감은 10월 11일, 결선은 10월 24일 상하이에서 개최되며, 수상 프로젝트는 100만 위안 상금 풀(현금, Token, 대규모 모델 API 등)을 나누고 상하이시 오픈소스 프로젝트 육성 사업에 선정될 기회도 얻는다. 이는 공식 뉴스 침묵기 중 드물게 나온 실질적 대외 움직임으로, Ruisaide가 지역 오픈소스 대회를 빌려 루이칭 산업 플랫폼 생태계와 개발자 모집을 추진하고 있음을 반영한다.

2.2 공식 뉴스 API 15일 연속 신규 없음, elexcon 2026 카운트다운 5일

날짜: 2026-09-04　출처: RT-Thread 공식 뉴스 API

공식 뉴스 API(rt_org 분류)는 여전히 5건의 오래된 항목이며, 최신은 여전히 2026-06-17 아부다비 투자 포럼 보도로 15일 연속 신규가 없다. gnews 다중 보충 조회("RT-Thread" when:2d 영어, RT-Thread RTOS when:2d 영어, 睿擎 OR 睿赛德 when:3d 중국어): 영어 쿼리는 0건 적중, 중국어는 OSChina 과제 보도(2.1에 이미 수록)와 Phoenix Net의 “저우라오빙, 휴머노이드 로봇 데이터 트레이닝 센터 방문”만 적중했다. 후자는 본문이 실제로 베이징 Shougang Park Ruilman 트레이닝 센터 방문 보도로, “루이얼만/루이사이드” 문자열 퍼지 매칭 노이즈이므로 제외했다. 다음 대외 창구는 9월 9-11일 선전 elexcon 2026(Ruisaide 참가, 8-30 예고 이미 수록)이며 카운트다운 5일, 회의 전 침묵기 지속은 예상된 리듬이다.

3. 생태계 및 벤더 적응

3.1 canopennode-rtt 메인라인에 CiA402 다축 및 PP/PV/Homing 지원 추가, 모션 제어 기능면 확대

날짜: 2026-09-04(09:41 베이징 push, 직전 09-03 11:25 베이징)　출처: wdfk-prog/canopennode-rtt

topic:rt-thread 생태계 저장소 canopennode-rtt 기본 브랜치 모니터링 기간 내에 두 건의 CiA402(DS402 모션 제어 profile) 커밋이 추가되었다. 09-03 11:25 “add multi-axis device profile support”(다축 디바이스 profile 지원, 9c8da59), 09-04 09:41 “add PP PV and homing mode support”(Profile Position / Profile Velocity 위치결정 및 속도 모드와 원점 복귀 모드, 7f143ec). 이는 이전의 이벤트 구동 메인라인 스케줄링(09-01), LSS 런타임 보드레이트 활성화(08-27)와 이어지며, 어제 관측된 ds402/A04 기능 브랜치 진화가 메인라인에 합류하여 모션 제어 기능면이 단축에서 다축 및 대표적인 위치결정/속도/원점 복귀 모드로 확장되었다. 해당 저장소 작성자는 동시에 메인 저장소에서 CAN 프레임워크 리팩터링을 추진하고 있으며(1.1 참조), “응용 계층(CANopenNode 소프트웨어 패키지 확장) → 프레임워크 계층(Generic CAN 리팩터링)”이 쌍선으로 병진하고 있어 CAN은 여전히 현재 커뮤니티에서 가장 활발하게 추진되는 메인라인이다.

4. 요약 및 트렌드 관찰

  • 공식/대회 측: Ruiside가 2026 상하이 오픈소스 소프트웨어 응용 혁신 대회 AI+산업 소프트웨어 트랙에서 과제를 발표(루이칭 플랫폼이 데이터 수집-라벨링-모델 적응-로우코드 배포 툴체인을 보완, 접수 마감 10-11, 상금 풀 100만, 10-24 상하이 결선), 이는 공식 뉴스 침묵 기간 내의 실질적 대외 행보; 공식 뉴스 API는 연속 15일째 신규 없음, elexcon 2026(9/9-11 선전) 카운트다운 5일.
  • 커널 측: 모니터링 기간 내 제로 머지, 제로 신규 PR(#11776 이후 축적기); CAN 프레임워크 리팩터링 PR #11779가 리뷰 논의에 진입, “Request changes” 의견 등장(STM32만 마이그레이션하는 크로스 BSP 호환성 논란에 국한), 메인테이너 CYFS3는 CAN_V2 프레임워크를 별도로 만들지 않겠다고 명확히 하고 커뮤니티의 공동 추진을 촉구 — 리팩터링 방향이 메인테이너의 지지를 얻어 머지 경로가 명확해지는 추세.
  • 생태계 측: canopennode-rtt 메인라인에 CiA402 다축 + PP/PV/Homing 두 건의 커밋 착륙(09-03/09-04), DS402 모션 제어 역량 범위 확대, 메인 저장소 프레임워크 리팩터링과 함께 “응용 계층 + 프레임워크 계층”의 이중 라인 구성.
  • 최근 3일 추세(09-02 ~ 09-04): Tencent IoT SDK 설정 PR, CAN 프레임워크 리팩터링 PR 제안(09-02) → CPPPATH 위생 머지 #11776, 대회 과제 발표, CiA402 다축 커밋, CAN 리팩터링 PR 리뷰 개시(09-03) → CiA402 PP/PV/Homing 커밋, CAN 리팩터링 PR 메인테이너 지지 획득, 공식 침묵 15일째(09-04). 현재 추진 메인라인은 “CAN 생태계 심층 추진(응용 계층 확장 + 프레임워크 계층 리팩터링) + 공식 대회 개발자 운영”.
