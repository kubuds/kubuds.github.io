1. 커널 및 버전 동향

메인 저장소는 기간 내 9건의 머지와 1건의 RISC-V 리팩터링 커밋을 완료하여 근 일주일 중 가장 밀집된 머지 배치를 기록했다. 리뷰 측면에서는 8건의 심사 중 제안과 다수의 결함 티켓이 동시에 갱신되었다.

1.1 Next RISC-V 제안 신규 커밋: RISC-V 아키텍처 이식 리팩터링, RV32/RV64 공통 레이어 통합 (10-15)

날짜: 2026-10-15 11:51 (커밋 시간)　출처: PR #10320, 리팩터링 커밋 6bf3686

RISC-V 대규모 리팩터링 제안 (#10320)은 기간 내 대형 리팩터링 커밋 「[libcpu][risc-v] Refactor the RISC-V architecture port」를 푸시했다: 선택적 RISC-V 통합 공통 레이어 (RV32/RV64)를 도입하고, ARCH_RISCV와 ARCH_CPU_64BIT로 아키텍처와 XLEN 선택을 완료하며, context, trap, MMU, cache, timer, SBI, SMP 및 ISA 처리를 통합하고, PLIC, CLIC, ACLINT, APLIC 및 IMSIC 지원을 추가했으며, 물리 HART ID에서 논리 CPU ID로의 매핑 테이블을 구축했다. T-Head 벤더 오버라이드 브랜치는 유지된다. qemu-virt64-riscv가 새로운 공통 레이어에 최초로 접속한 BSP가 되었으며 (동일 디렉터리에서 RV32와 RV64 S-mode 지원), RT_USING_RISCV_NEW_COMMON 매크로를 선택하지 않은 기존 BSP는 legacy_common / common64 경로를 계속 사용한다. 커밋 후 자동 프로세스 재실행 (형식 알림, 리뷰 할당, membrowse 메모리 리포트); RISC-V 조정 추적 티켓 #11246 동시 갱신 (11:52). 제안은 열린 상태 유지.

1.2 네트워크 스택 수정 배치 머지: ping 통계 제로 나눗셈 및 마지막 패킷 지연 두 건 연이어 적용 (10-14 ~ 10-15)

날짜: 2026-10-14 09:33 ~ 2026-10-15 09:10 (머지 시간)　출처: PR #11853, PR #11866

netdev 컴포넌트 모니터링 기간 내 ping 관련 수정 2건이 병합되었습니다. 첫 번째(#11853, 10-14 병합)는 목적지 도달 불가 시 ping 통계의 0으로 나누기로 인해 shell이 크래시되는 문제를 수정한 것으로, 관련 결함 티켓 #11852가 같은 날 종료되었습니다. 두 번째(#11866, 10-15 오전 병합)는 마지막 패킷 지연 로직을 수정한 것입니다. 기존 루프 판정이 항상 거짓이어서 마지막 패킷 이후에도 지연이 추가되었고, 지연이 0일 때도 rt_thread_delay(0)을 호출하여 잘못된 인자를 반환하는 문제가 있었습니다. 이를 실제 소요 시간을 기록하고, 마지막 패킷이 아니면서 지연이 0보다 클 때만 호출하도록 변경했으며, 관련 결함 티켓 #11865가 같은 날 종료되었습니다. 같은 방향의 초기 제안 #11862는 병합되지 않고 종료되었습니다.

1.3 커널 및 USB 수정 배치 병합: calloc 오버플로 및 USB host 인터페이스 수 검증 강화(10-14)

날짜: 2026-10-14 09:28 ~ 10:17(병합 시간)　출처: PR #11848, PR #11822

커널 측에서는 calloc 정수 오버플로 문제를 수정했습니다(#11848). 커뮤니티 기여자가 제출하고 병합했습니다. USB 측에서는 legacy USB host 강화를 완료했습니다(#11822). “host가 장치가 보고한 인터페이스 수를 직접 신뢰하여 범위를 벗어난 접근이 발생할 수 있다”는 결함 티켓(#11288)에 대해 인터페이스 수 상한 판정과 인터페이스 열거, 정리 경로의 경계 처리를 추가했으며, 두 건의 커밋(인터페이스 수 검증 명확화, 열거 및 정리 마무리)이 동시에 병합되고 결함 티켓이 같은 날 종료되었습니다.

1.4 다수 벤더 BSP 및 드라이버 배치 병합: ra6w1, ESP32-C3, STM32H723, RISC-V 벡터 복원 등(10-14)

날짜: 2026-10-14 09:13 ~ 09:44(병합 시간)　출처: PR #11814, PR #11847, PR #11851, PR #11861, PR #11855

메인테이너가 여러 벤더 BSP 및 드라이버 업데이트를 집중 병합했습니다. Renesas ra6w1은 시스템 리소스 할당을 최적화했습니다(메인 스레드 스택을 4096으로 조정, RC 커밋, #11814). Espressif ESP32-C3는 Windows 경로에서 IRAM 와일드카드 매칭과 블루투스 링커 스크립트 오매칭 문제를 수정했습니다(#11847). STM32H723-DM-MC02는 SPI6 BDMA 지원을 추가했습니다(#11851). RISC-V 벡터 유닛은 설정 후 vstart 상태 복원을 수정했습니다(#11861). components/drivers reset 프레임워크는 ulog와 동시 활성화 시의 빌드 오류를 수정했습니다(#11855).

1.5 심사 중 제안 집중 메인테이너 리뷰: lwip 매크로 제어, ESP32-S3 BSP, rt_kprintf 수정, STM32 이더넷 ops(10-14 ~ 10-15)

날짜: 2026-10-14 10:13 ~ 2026-10-15 09:22(리뷰 시간)　출처: PR #11815, PR #11844, PR #11864, PR #11819

메인테이너는 모니터링 기간 내 심사 중인 제안 4건에 리뷰를 제시했습니다. lwip 섹션 매크로 제어 제안(#11815)은 10-15 오전 수정 요청을 받았습니다(이전에 작성자는 10-14에 변경 사항을 다시 푸시했습니다). ESP32-S3 보드 지원 제안(#11844)은 작성자가 10-14에 리뷰 지적에 대응하여 수정한 후, 10-15 오전 메인테이너의 라인 단위 코멘트가 포함된 재심사를 받았습니다. rt_kprintf 암시적 선언 수정 제안(#11864)은 수정 요청을 받았습니다. 이 제안은 IAR 환경에서 선언을 포함하지 않았을 때 %f 로그 출력이 비정상인 문제를 수정하기 위한 것입니다. STM32 신규 이더넷 드라이버 ops 계층 적응 제안(#11819)은 수정 요청을 받았습니다. 네 건 모두 열린 상태로 유지되었습니다.

1.6 기타 심사 중 제안 동향: clang-format 추가 커밋, N32 타이머 제안 재개, ASan 제안 추가 테스트(10-14)

날짜: 2026-10-14 09:46 ~ 12:27 (업데이트 시간)　출처: PR #11859, PR #11812, PR #11772

clang-format 규범 세분화 제안(#11859)에 두 건의 커밋이 추가되었다: 스타일 규칙 미세 조정(정렬, 괄호 줄바꿈 및 간격) 및 thread.c로 실제 효과 시연; N32 시리즈 타이머 보완 제안(#11812)이 메인테이너에 의해 재개됨——해당 안건은 N32H47x/48x와 H49x에 공용 드라이버 브랜치를 보완하고 ci-attach 항목을 함께 구성함; 힙 메모리 ASan 제안(#11772) 작성자가 추가 설명을 보충함: rt_memcpy, rt_memset 및 rt_memmove의 범위 검사와 선택적 libc 인터페이스 래핑을 추가하고, 범위 초과, 해제 후 접근, 제로 길이 등 경계 테스트를 보완했으며, 최신 CI 전부 통과를 보고함.

1.7 오래된 결함 티켓에 새로운 논의: at_gethostbyname 오버플로 처리 방향 명확화 필요 (10-14)

날짜: 2026-10-14 16:26 (댓글 시간)　출처: Issue #5913

2022년에 생성된 힙 버퍼 오버플로 보고 티켓(#5913)이 모니터링 기간 내 새로운 댓글을 획득함: at_gethostbyname에서 ip_str 처리 관련 오버플로 위험 논의가 2년 넘게 방치되어 아직 결론이 나지 않았음을 지적하며, 커뮤니티에 처리 방향을 명확히 할 것을 제안——복사 길이 제한 또는 초과 호스트명 거부, 그리고 수정 담당자 지정; 만약 다른 커밋에서 이미 해결되었다면 커밋 번호를 보충하여 해당 티켓을 닫을 수 있음.

1.8 공식 뉴스 인터페이스 연속 56일째 신규 없음 (10-15)

날짜: 2026-10-15 (확인 시간)　출처: RT-Thread 공식 뉴스 인터페이스

공식 뉴스 인터페이스(rt_org 분류)가 반환한 아카이브 원고의 최신 항목은 여전히 2026-06-17이며, 모니터링 기간 내 신규 없음, 연속 56일째 업데이트 중단; 제품 및 활동 정보는 계속해서 위챗 공식 계정, 커뮤니티 포럼과 GitHub 채널에서 최초 공개됨. 공식 웹사이트 뉴스 목록 페이지는 프런트엔드 동적 렌더링으로, 이번 기간에는 직접 확인 불가.

2.1 공업박람회 AI 스마트카 Workshop 복기 기사 게재: 엣지 AI 실현의 새로운 사례 (10-15)

날짜: 2026-10-15 11:50 (기사 발행)　출처: EE Times China

EE Times China가 Ruiside 공업박람회 AI 엣지 지능 스마트카 Workshop 복기를 게재: 10-13 현장 실습은 2인 1조, 수십 세트의 스마트카 교구로 진행되었으며, 참가자들은 하드웨어 검사, 시스템 부팅, 주변장치 디버깅, 실시간 제어, SLAM 매핑, 자율 주행, 카메라 캘리브레이션, 멀티모달 비전 추적, AR 종합 훈련 전 과정을 완주했고, 현장에서 라이다, IMU와 뎁스 카메라를 디버깅함; 기사는 동시에 그 AIOS 하이브리드 배포 이념을 설명——AI 추론은 Linux 측에서 실행, 고신뢰성 실시간 제어는 RT-Thread 커널에 위임, 두 영역은 상호 간섭하지 않음; 현장에서는 로봇, 드론, 산업 제어 장비 등 동일 기반 제품을 전시했으며, 기사 말미에 솔루션 연락 채널을 제시함. 기사에서 누적 설치량 25억 대 초과를 인용함.

2.2 〖2026 임베디드 대회〗「슈헝즈양」AI 비전 경혈 물리치료 로봇팔 작품 게시물 발표 (10-15)

날짜: 2026-10-15 08:32 (발표 시간)　출처: 포럼 게시물 a2a82aa707bc2966

2026 임베디드 대회 작품 게시물 「슈헝즈양 · 자적응 다중 모드 물리치료 로봇팔」 발표: 하위 기기는 GigaDevice GD32H759I-EVAL(Cortex-M7, 600MHz)을 메인 컨트롤러로 사용하고 RT-Thread를 실행하여 다중 주변장치 동시 통신과 실시간 모션 제어를 완료함; K230 비전 측에서 실시간으로 인체 17개 골격 키포인트를 추출하고 내관, 천돌, 중완, 곡지 등의 경혈 3차원 좌표를 산출하며, 메인 컨트롤러가 역기구학 해석을 완료한 후 4자유도 버스 서보 로봇팔을 구동하여 생체 모방 추나 점압을 수행하고, 인체 미세 움직임 자적응 추적을 지원함; 로컬 Taojingchi 터치스크린과 클라우드 Web, Qt PC, Android 다중 단말 이중 경로 제어, 클라우드에는 SpringBoot 서비스를 구성하고 DeepSeek 지능 문진을 연동함; 각도 제한, 파라미터 검증, 상태 머신 관리와 비상 정지 등 안전 메커니즘을 갖춤.

3. 생태계 및 제조사 적응

3.1 packages 인덱스: hpm_sdk v1.13.0 소프트웨어 패키지 인덱스 병합 (10-14)

날짜: 2026-10-14 18:41 (병합 시간)　출처: PR #2045(RT-Thread/packages)

소프트웨어 패키지 인덱스 저장소(RT-Thread/packages) 모니터링 기간 내 hpm_sdk v1.13.0 인덱스 제안(#2045)이 병합됨: PKG_USING_HPM_SDK_V113 설정 및 다운로드 항목이 추가됨(기본 버전은 v1.10.0 유지, 명시적 선택 필요), 인덱스는 업스트림에서 10-13에 릴리스된 v1.13.0 태그에 대응함(HPM5100 시리즈 지원 추가). 해당 안건은 10-13에 개설된 후 다음 날 병합이 완료되었으며, 인덱스 저장소의 반달 만의 첫 번째 병합이다.

3.2 N32 표준 주변장치 드라이버 저장소 수정 커밋: FEMC ECC 상수 사용 수정(10-14)

날짜: 2026-10-14 09:45(커밋 시간)　출처: 수정 커밋 9983259

RT-Thread-packages/n32h7xx_std_driver 저장소 모니터링 기간 내 수정 커밋이 병합됨: FEMC 드라이버의 ECC 상태 읽기 인터페이스가 표준 상수 그룹(FEMC_ECC_LAST_*)을 사용하도록 변경되었으며, 이는 N32H7 시리즈 표준 주변장치 라이브러리의 지속적 유지보수에 해당하며, 동시기 메인라인 N32 타이머 보완 제안(1.6 참조)과 함께 국산 N32 플랫폼 지원 밀도가 향상되고 있음을 반영한다.

기타 생태계 채널은 모니터링 기간 내 계속 조용함: env 도구 저장소(최근 커밋 10-10), Studio SDK 인덱스(최근 업데이트 10-10), GD32 벤더 다운스트림 gd32_rt-thread(메인 브랜치 최신 병합 09-28) 모두 모니터링 기간 내 푸시가 없었다.

4. 산업 응용

모니터링 기간 내 산업 응용 측에는 새로 수록된 항목이 없으며, 관련 방향의 동향은 커뮤니티 작품과 미디어 복기(2장 참조)에 집중되었다. 단말-엣지 협동 정교 로봇암 시스템 기술 공유(10-12)와 6개 도시 순회 오프라인 행사(10-10)는 이미 이전 기간에 수록되었다.

5. 요약 및 트렌드 관찰

5.1 최근 하루 트렌드(10-14 ~ 10-15)

  • RISC-V 리팩터링 가속: #10320이 libcpu급 리팩터링 커밋을 완료(공통 레이어 통합, 인터럽트 컨트롤러 확장, HART 매핑), RISC-V 조정 추적 티켓 동기 갱신; 여기에 10-14에 병합된 벡터 vstart 수정이 더해져, RISC-V 아키텍처 스택이 집중 착지기에 진입했다.
  • 메인테이너 집중 병합이 이번 주 최다: 10-14 오전부터 하루 만에 9건의 PR이 메인 브랜치에 병합됨—네트워크 ping 2건, 커널 calloc, USB host 강화 및 5건의 벤더 BSP 업데이트로, 이전 기간의 약 45시간 병합 공백을 해소했다.
  • 네트워크 스택 견고성 메인라인 완결: ping 0 나눗셈과 마지막 패킷 지연 2건이 결함 티켓에서 수정 병합까지 당일 완결되었고, 동종 초기 제안 종료와 함께 netdev 안정성이 마무리되었다.
  • 리뷰 대기열 전면 활성화: 8건의 심사 중 제안이 모니터링 기간 내 움직임이 있었으며, lwip 매크로 제어와 ESP32-S3 BSP가 수동 리뷰 단계에 진입했고, rt_kprintf와 STM32 이더넷 ops 2건도 수정 요청을 받았다.
  • 생태계와 커뮤니티 양축 출력: packages가 hpm_sdk 인덱스 병합을 완료했고; 공업박람회 Workshop 복기 글과 대회 물리치료 로봇암 작품 게시글이 계속 출력되어, 로봇 및 건강돌봄 방향의 콘텐츠 밀도가 상승했다.

5.2 한계 및 중복 제거 설명

  • 재실행 설명: 당일은 장애 재실행—당일 정규 실행(08:00)과 수동 재실행(09:51)이 연이어 모델 서비스 장애로 중단되었고, 이번은 서비스 복구 후 실행으로, 수집 기간은 이전 기간 마감점(10-14 08:00)부터 생성 시점(약 29시간)까지를 포함하며, 서두에 사실대로 명기했다.

  • “Muyu Xinsheng” 게시글(10-12 게시)의 타임스탬프가 다시 갱신되었으며(10-14 08:43), 이전 기간에 수록된 항목에 해당하여 중복 전개하지 않는다.
  • Google News 중국어 측: 공업박람회 복기 글이 유효 신규(2.1 참조); 9월 월간 보고서(10-11), 로봇암 기술 공유(10-12), 6개 도시 순회(10-10)는 이전 기간에 수록됨; “Bokente 공업박람회 신제품 최초 공개” 글은 검토 결과 RT-Thread 실질 내용이 없어(검색 텍스트 오매칭) 수록하지 않음; “Ruiqing” 관련 조회는 이번 기간 제로 히트. 영어 측 제로 히트.
  • HN 4건 히트는 모두 주제와 무관(프로그래밍 수필, 기타 제품 출시 등)하여 수록하지 않음; topic:rt-thread 최근 1주 5건 중, 모니터링 기간 내 2건(awtk, h120d-protocol)은 모두 전문 주제에 해당하지 않아 수록하지 않음.
