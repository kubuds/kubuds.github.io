1. 커널 및 버전 동향

1.1 메인 저장소 제로 머지 세 번째 기간으로 연장, 신규 PR #11780 SDIO CIS 메타데이터 메모리 누수 수정

날짜: 2026-09-05 (PR 생성 16:59 베이징 시간)　출처: RT-Thread/rt-thread PR #11780 (관련 issue #11724)

메인 저장소 rt-thread는 이번 기간 제로 머지, 제로 신규 issue이며, 최근 머지는 여전히 09-03의 #11776(세 번째 기간 연장), 릴리스는 여전히 v5.2.2(2025-10-31)이다. 기간 내 유일한 신규는 커뮤니티 개발자 Huoyanlifusu가 제출한 PR #11780 “[components][sdio] Fix CIS tuple memory leak”이다. #11724에서 지적한 문제를 수정한다. sdio_read_cis()가 CISTPL_FUNCE와 CISTPL_VERS_1 등의 일부 CIS tuple을 처리할 때 메모리를 할당하지만 처리 완료 후 해제하지 않아, SDIO 장치를 반복적으로 초기화/해제하면 메모리 누수가 발생한다. 수정 방안은 위 두 분기 처리가 완료된 후 임시 tuple을 해제하고, 알 수 없는 tuple은 여전히 func->tuples 연결 리스트에서 관리하며 sdio_free_cis()가 일괄 해제하도록 하는 것이다. 파일 1개 변경, 순증 2줄이며, 작성자는 qemu-vexpress-a9 BSP에서 검증을 완료했다. 이 PR은 작성자의 연속 세 번째 컴포넌트급 수정이다(#11756 netdev ping 널 포인터 크래시 수정은 08-26 머지 완료, #11774 sal SIOCGIFCONF 범위 초과 수정은 여전히 리뷰 중). “컴포넌트급 메모리 안전 수정”이라는 기여 주류를 이어간다. 리뷰 큐의 나머지 항목은 어제와 동일하다. #11779 CAN 프레임워크 리팩터링은 메인테이너 CYFS3가 09-03 입장을 표명한 이후 새로운 코멘트가 없으며, #11775(c908 rt-smart), #11772(힙 ASan), #11689(stm32 SPI BDMA) 등은 모두 open 상태로 움직이지 않았다.

2. 공식 및 커뮤니티 활동

2.1 공식 뉴스 API 17일 연속 신규 없음, elexcon 2026 3일 카운트다운

날짜: 2026-09-06　출처: RT-Thread 공식 뉴스 API

공식 뉴스 API(rt_org 분류)는 여전히 5건의 오래된 항목이며, 최신은 여전히 2026-06-17 아부다비 투자 포럼 보도로, 17일 연속 신규가 없다. 다음 대외 창구는 9월 9-11일 선전 elexcon 2026(루이사이드 참가, “AI 하드웨어 풀 세트” 예고는 08-30에 이미수록)이며, 오늘은 개막 전 마지막 주말로 카운트다운 3일이다. 중문 및 영문 매체 측(Google News 프록시 경유 검증 1d/2d/3d 기간) 모두 기간 내 신규 RT-Thread 보도가 없으며, 최신 매체 콘텐츠는 여전히 09-04 EE Times China의 커뮤니티 작품 공유(어제 이미수록)로, 공식 채널 침묵 기간에도 커뮤니티와 매체 콘텐츠 생산 리듬은 영향을 받지 않았다.

3. 생태계 및 벤더 이식

3.1 canopennode-rtt: CiA402 컨트롤러 측 및 진단/EMCY 보완, CiA401 범용 I/O profile 브랜치 시작

날짜: 2026-09-05 ~ 09-06(14:08 ~ 다음 날 10:06 베이징 시간, 6건 커밋)　출처: wdfk-prog/canopennode-rtt(CIA401 브랜치)

어제 11:08에 CSP/CSV/CST 주기 동기화 모드를 수록한 이후, 해당 저장소의 개발은 멈추지 않았다. 기본 브랜치에 「CiA402 device diagnostics and EMCY bridge」(장치 진단 및 EMCY 비상 메시지 브리징, 09-05 14:08), 「CiA402 컨트롤러 지원 및 관련 테스트 추가」(16:13, CiA402 적용 범위가 슬레이브 측에서 컨트롤러 측으로 확장), 그리고 문서 정리 및 리팩터링(16:36)이 추가되었다. 이어서 새 브랜치 CIA401을 열고, 09-05 21:53부터 연속으로 「generic I/O device profile core」「digital event and output fail-safe support」및 09-06 10:06의 「아날로그 입출력 이벤트 및 페일세이프 기능 지원」을 착지시켰다. 이로써 해당 CANopenNode 이식은 09-03 이후 일주일 내에 양축 확장을 완료했다. 모션 컨트롤 profile(CiA402: 다축, PP/PV/Homing, CSP/CSV/CST, 진단 및 EMCY, 컨트롤러 측)과 범용 I/O 디바이스 profile(CiA401: 디지털/아날로그 이벤트 및 페일세이프)이며, CAN/산업용 필드버스 방향의 생태계 추진 주력은 전 커뮤니티에서 가장 활발한 위치를 유지하고 있다. 해당 작성자가 동시에 메인 저장소에서 Generic CAN 프레임워크 리팩터링(#11779)을 추진하고 있는 점을 감안하면, 「프레임워크 계층 + 애플리케이션 계층」양축 병진의 태세는 변함이 없다.

3.2 생태계 참고: gdr GDB 디버깅 프레임워크 FreeRTOS 적응 마무리, RT-Thread는 여전히 최우선 지원

날짜: 2026-09-05(17:39 베이징 시간 마무리 커밋)　출처: flespark/gdr

topic:rt-thread 저장소 flespark/gdr(GDB Python 환경에서의 RTOS 디버깅 보조 프레임워크로, rtt threads/rtt timers 등의 RTOS 명령 트리, 커널 객체 pretty-printer 및 편의 함수를 제공)는 모니터링 기간 내에 「refactor(freertos): wrapup of new rtos support, code and docs quality enhance」를 커밋하여 FreeRTOS 두 번째 어댑터를 마무리했다. 해당 README에 따르면, RT-Thread(3.1.x / 4.0.x / 4.1.x, Cortex-A9 전 계열 검증, RV64는 4.0.4부터)는 여전히 최우선 지원 대상이며, 모니터링 기간 내에 완성된 FreeRTOS 채널(V10.3.0 ~ V11.3.x)은 QEMU에서 64비트 RISC-V lane과 MPS2-AN521 듀얼코어 SMP 검증을 보강했다. 이는 범용 프레임워크 확장으로 RT-Thread 전용 커밋은 아니지만, RT-Thread 사용자(RISC-V 타깃 포함)에게 GDB 디버깅 도구 측면에서 긍정적인 참조가 되므로 생태계 참고로 수록한다.

4. 산업 응용

신규 항목 없음. 모니터링 기간 내에 새로운 산업 응용/착지 사례 보도는 없었으며, 최근 3일(09-04 ~ 09-06) 동안 산업 측도 침묵을 유지했다. 최근 수록된 산업 콘텐츠는 08-27 말레이시아 도시 IoT 사례와 08-24 RISC-V+AI 양축 정상회담 보도(EE Times China)이다. RT-Thread의 임베디드 인공지능(린강 디수이즈후이), 산업(루이칭 산업 플랫폼) 등의 방향에서의 최신 대외 동향은 09-09 개막하는 elexcon 2026을 통해 집중적으로 공개될 것으로 예상된다.

5. 요약 및 트렌드 관찰

  • 커널 측: 메인 저장소는 세 번째 모니터링 기간에 무병합 진입(최근 병합 #11776, 09-03), 신규 PR은 #11780 단 하나——SDIO CIS tuple 메모리 누수 수정(1개 파일 +2줄, qemu-vexpress-a9 검증), 작성자는 연속 세 번째 컴포넌트 수준 수정, 리뷰 큐에 다른 변화 없음, release는 여전히 v5.2.2, 축적기 지속.
  • 생태계 측: canopennode-rtt는 일주일 내에 CANopenNode 포팅을 모션 컨트롤(CiA402 전 모드)에서 범용 I/O profile(CiA401)과 컨트롤러 측 지원으로 진전시켰으며, 현재 커뮤니티에서 가장 활발한 개발 메인라인이다; GDB 디버깅 보조 프레임워크 gdr는 FreeRTOS 두 번째 어댑터 마무리를 완료했고, RT-Thread 지원(RV64 포함)은 최우선 기능으로 유지되고 있다.
  • 공식/미디어 측: 공식 뉴스 API는 연속 17일째 침묵; 미디어 측 24h 모니터링 기간 내 신규 보도 0건(프록시와 소스 점검 정상); elexcon 2026(09-09~11 선전) 카운트다운 3일, 회의 전 침묵은 예상된 리듬.
  • 최근 3일 트렌드(09-04 ~ 09-06): CiA402 다축과 PP/PV/Homing, EET가 커뮤니티 USB 모니터링 보조 화면 작품 전재, 공식 침묵 15일째(09-04) → env에 WebUI keep_alive 병합(#294), CiA402 주기 동기 CSP/CSV/CST 적용, 공식 침묵 16일째(09-05) → sdio CIS 누수 수정 PR #11780, CiA402 진단/EMCY/컨트롤러 측과 CiA401 I/O profile 브랜치 시작, 공식 침묵 17일째(09-06). 현재 추진 메인라인은 「공식 툴체인 WebUI 경험 반복 개선 + CANopenNode 이중 profile 생태계 확장」이며, 대외 활동은 elexcon 2026까지 역량 축적 중.
