3.2 Horizon Robotics: BPU 연산자 라이브러리를 사용 가능하게 수정, 체인 실행으로 4회 디스패치를 0.673밀리초로 단축 (11-04)

날짜: 2026-11-04　출처: Torch-FL PR #721 · Torch-FL PR #726

  • 세 가지 심각한 고장: #721은 BPU의 eager 경로가 실제로는 모든 연산자가 CPU에서 실행된다는 것을 밝혀냈습니다. 연산자 버킷 계단이 512 lane을 넘지 않고, 이중 입력 artifact가 단일 텐서 설명자로 제출되어 조용히 잘못된 값을 내며, hbdk4가 box64 아래에서 numpy를 임포트할 수 없어 x86 툴체인이 사용 불가능했습니다. 수정 후 Run을 C ABI로 노출하여 eager 경로가 aten dispatcher를 우회하게 하고, 매 호출의 고정 작업을 핫 경로 밖으로 이동했습니다.

3.3 Hygon: FP32 flash attention 전방 구현, 추가로 FP32 최적화 9건 접수 (11-04)

날짜: 2026-11-04　출처: FlagGems PR #7388 · FlagGems PR #8404 · FlagGems PR #8451 · FlagGems-vllm PR #1066 · build-infra PR #1628

  • FP32 순전파: #7388은 _flash_attention_forward의 Hygon 구현에 명시적으로 지원되는 FP32 경로를 추가하면서 ATen의 5출력 스키마와 기존 FP16/BF16 동작을 유지한다. 지원 범위는 매우 좁게 명시되어 있다: 고정 길이, 연속 4D BSHD, 정방형 MHA이면서 Q/K/V가 동일 형상, head dim이 64 또는 128, dropout이 0, window/alibi/seqused/varlen 없음. 지원되지 않는 조합은 검증되지 않은 경로를 타는 대신 즉시 오류를 낸다.
  • 구현 요점: QK와 PV는 IEEE FP32 점곱을 사용한다. 온라인 softmax의 최댓값은 -inf로 초기화하여 -1e30보다 낮은 유효 logit이 삼켜지지 않도록 한다. 긴 시퀀스는 exp2/log2를 사용하고, 짧은 시퀀스는 자연 지수를 유지한다. head dim과 시퀀스 길이에 따라 세 가지 정적 tile을 선택한다. 저정밀도 경로는 컴파일 시점에 이와 격리된다.
  • 동측 최적화: luojung의 열 건의 오픈 PR은 rsqrt, floor, nonzero, FP32 전차원 리덕션, masked_fill, nan_to_num, neg, masked_select, aminmax를 모두 “연속 FP32”로 한정하여 커버한다. 이는 먼저 하나의 경로를 올바르게 만든 뒤 성능을 논하는 전형적인 순서다.
  • 버전과 플러그인: DTK 26.10의 base와 runtime은 오늘 2.3.0으로 기록된다(1.2 참조). FlagGems-vllm #1066은 Hygon에 CUDA PDL 내장이 없을 때의 임포트를 수정한다. FlagBLAS는 Hygon collection을 수정한다. FlagTrain의 mixed_gemm은 Hygon을 커버한다.
