1.3 신규 공개 저장소 Trident: 실험적 MLIR/LLVM 컴파일 브리지(10-12)

날짜: 2026-10-12　출처: flagos-ai/Trident · README · 커밋 기록

  • 포지셔닝: Trident는 실험적 컴파일 브리지——Triton/Torch 스타일 연산을 포함한 Python 함수를 MLIR/LLVM으로 컴파일한 뒤 tvm_ffi를 통해 실행; 핵심은 C++/MLIR(CMake 빌드, LLVM/MLIR을 외부 프로젝트로 도입)이며, Python 측은 trident.jit과 trident.compile 진입점을 제공, 예제는 add / attn / mm / softmax 등 ATen 연산자 하강을 포괄, apache-tvm-ffi와 torch>=2.10에 의존.

  • 타임라인: 저장소는 10-12 16:47(베이징 시간)에 조직 내에서 생성되어 공개되었고, master 브랜치 커밋 이력은 5월 중순까지 거슬러 올라가며 누적 274건; 모니터링 기간 내 2건——「refactor: unify FX and Triton imports around TVM FFI」(10-12 23:10)와 「test: reorganize coverage and check e2e CUDA memory leaks」(10-13 00:50).

  • 관찰: 프로젝트는 7월에 torch-mlir 임포트에서 FX 직결 TVM FFI로의 마이그레이션을 완료했으며, 형태상 멀티칩 통합 접속을 지향하는 “프런트엔드 컴파일 브리지” 탐색에 속하고, FlagTree의 통합 컴파일러 노선과 호응; 향후 방향(TLE / FlagMega 라인과 합류 여부)은 추적할 가치가 있음.

3. vLLM 0.28 적응 배치가 안착기에 진입: Iluvatar CoreX / Ascend 첫 머지, Moore Threads(#575 크로스데이 고빈도 업데이트), XuanTie(#574), Enflame S60(#582) 심사 중——지난 호 “다섯 라인 여전히 심사 중” 관찰점이 하루 만에 두 라인이 실현되었고, 나머지 라인은 여전히 이동 상태; 이 적응 배치가 완료되면 각 벤더 추론 스택이 0.28 베이스라인으로 통일되어 대회 기간 엔드투엔드 데모에 버전 기반을 제공하게 됨.

4. 개발 라인 “신규 국면 개시” 신호 밀집: FlagGems 5.5 개발 라인 개시(v5.5.0.dev0), FlagTree Iluvatar CoreX 빌드 라인 0.7.1a1로 상승, 조직에 Trident 컴파일 브릿지 저장소 추가——세 가지가 24시간 내 동일 창에 출현, 여기에 FlagMega의 BI-V150 토큰 수준 양자화 최적화와 TileIR 13.4 업그레이드(#1352) 심사 중이 겹쳐, 컴파일 및 연산자 스택이 “직전 납품 주기 마무리 + 차기 주기 배치”의 중첩 상태에 있음.
