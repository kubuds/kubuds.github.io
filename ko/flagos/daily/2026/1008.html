오늘의 중점: FlagQuantum 기간 내 23건 머지 — 분산 MPS 트레이닝 릴리스 인증으로 승격 (10-07 ~ 10-08)

날짜: 2026-10-07 ~ 2026-10-08　출처: FlagQuantum #587, #590, #591, #595

연휴 이후 첫 회차 기간에 FlagQuantum(FlagOS 양자 시뮬레이션 및 트레이닝 컴포넌트)이 조직 내 최대 증분을 기록했다: 기간 내 76건 커밋, 23건 PR 머지로, 10-07 오전부터 10-08 오전까지 연속적으로 추진되었으며, 릴리스 인증, 성능 디스패치, 그래디언트 및 기하량, 오류 정정 디코딩, 네이티브 엔트로피 도출의 다섯 가지 라인을 커버한다:

  • 릴리스 인증 완료(#587, 10-08 07:16 병합): 분산 MPS 릴리스 캠페인 종결 — two_node_mps_training 역량 행이 production_supported에서 release_certified로 승격(이 모니터링 기간 유일한 승격 역량 행), 인증은 릴리스 게이트를 통과한 서명된 실측 프로덕션 실행 페이로드 2건에 기반함. 동시에 텐서 네트워크(TN) 용량 전제가 현재 리비전에서 충족 불가능함을 실측 사유로 기록하고, 점검 절차에서 발견된 모든 산출 측 결함을 수정함(자체 병합 기준 c7bba053부터 비병합 커밋 28건 포함). 이 캠페인은 #535로 시작된 분산 MPS / 텐서 네트워크 릴리스 작업을 이어받음.
  • 성능 디스패치 배치(#576 / #581 / #582 / #583): statevector 공개 디스패치가 SV-014(SWAP), SV-010(대각) 및 유계 SV-011(Pauli 회전)로 확장되었고, 유계 Pauli 회전 디스패치 재인증을 완료 — SV 시리즈의 항목별 「구현 + 증거」 추진 방식이 지속됨.
  • 그래디언트와 기하량(#562 / #568 / #575 / #585 / #564 / #565): fq.jacobian / fq.jvp / fq.vjp(다중 출력 프로그램) 신규 추가; 2계 도함수(Hessian)는 파라미터 이동으로 1계 규칙을 재사용; Fubini-Study 계량 텐서 신규 추가(중심 차분 구현, 연산자 시프트 규칙을 재사용하지 않는 이유를 반증 표로 설명); N3-9는 「그래디언트 방법 × 실행 모드」의 30쌍 행렬을 계약으로 확정하고 게이트에서 재검증.
  • QEC와 엔트로피 내보내기(#590 / #591 / #592 / #589): 슬라이딩 윈도 디코더 신규 추가(flagquantum/qec/sliding_window.py, 772행 추가, 윈도별로 검출기 오류 모델을 읽어 윈도 단위로 디코딩); fq.vn_entropy는 von Neumann 엔트로피를 네이티브 Stable Core 내보내기로 승격(루트 내보내기 예산 37 → 38); 4행 QEC 정렬 항목 수렴; Quafu 원격 제출은 자격 증명 부재 시 fail-closed로 변경.
  • 품질 마감(#595 / #597): #595는 선언되지 않은 디스패치 리비전 16건을 추가 기록; #597(오픈)은 CI 동시성 그룹 결함을 수정 — 연속 두 번의 병합이 이전 검증 전체를 취소함(#590의 23/23 검사가 취소된 것이 바로 이 메커니즘에 해당).

판단: FlagQuantum의 「릴리스 인증 + 계약화 거버넌스」 이중 트랙이 형성되고 있음 — 역량은 계약 파일로 문서화되고, 게이트와 실측 페이로드로 재검증되며, 그 엔지니어링 규율은 FlagOS 메인라인 릴리스 체계와 동형임; 모니터링 기간이 마침 연휴 말미와 연휴 후 첫날에 걸쳐 있는데, 이 저장소는 장기 연휴 기간에도 높은 강도를 유지한 개발 라인임.

1. 오픈소스 프로젝트 진행(GitHub 동향)

1.1 FlagQuantum: 분산 MPS 릴리스 인증 완료 — 2노드 훈련이 release_certified로 승격(10-08)

날짜: 2026-10-08　출처: FlagQuantum #587, #535

  • 인증 내용: two_node_mps_training이 production_supported에서 release_certified로 승격, 역량 표에서 유일하게 변동된 행; 인증은 릴리스 게이트(release gate)를 통과하여 수용된 서명된 measured_production_run 실측 프로덕션 실행 페이로드 2건에 기반함.
  • 용량 기록: 텐서 네트워크 용량 전제는 실측 사유에 따라 「현재 리비전에서 충족 불가능」으로 기록 — 용량 경계를 암묵적 제약으로 남겨두지 않고 명시적으로 문서화함.
  • 엔지니어링 범위: 자체 병합 기준 c7bba053부터 비병합 커밋 28건과 메인라인 병합 2건 포함; 동시에 이 저장소의 자체 점검 절차에서 발견된 모든 산출 측 결함을 수정.
  • 연계 관계: 캠페인은 #535(10-06 병합)로 시작되었으며, 이번에 완료되어 저장소의 릴리스 인증 체계(release_certified 등급)에 첫 분산 역량 행을 전달함.

1.2 FlagQuantum: statevector와 커널 디스패치 성능 배치 — SV-010 / 011 / 014와 SWAP 융합(10-07)

날짜: 2026-10-07　출처: #576, #581, #582, #583, #566, #571, #574, #572

  • 공개 디스패치(SV 시리즈): #576에서 SV-014 공개 SWAP 디스패치를 활성화했고, #581에서 SV-010 대각 디스패치를 활성화했으며, #582에서 유계 SV-011 Pauli 회전을 새로 추가했고, #583에서 기존 유계 Pauli 회전 디스패치에 대한 재인증을 수행했다.
  • 게이트 배치(#566 / #571): 유계 가역 3큐비트 게이트 디스패치(#566), 밀집 국소 2큐비트 행렬 디스패치(#571) — 국소 게이트 디스패치 적용 범위가 계속 촘촘해지고 있다.
  • 커널 융합과 샘플링(#574 / #572): 유계 SWAP 시퀀스 융합(#574), MPS 샘플링 붕괴 커널 디스패치(#572) — 성능 작업이 상태 벡터와 텐서 네트워크 두 시뮬레이션 경로를 동시에 커버한다.
  • 의미: 성능 배치가 「커널 내부 최적화」에서 「디스패치 계층 시맨틱」으로 나아갔다 — 동일한 연산이 행렬 형태와 유계성에 따라 전용 커널로 분기되며, 항목별로 증거를 남긴다.

1.3 FlagQuantum: 그래디언트와 기하량 — jacobian / jvp / vjp, Fubini-Study 계량과 2차 도함수(10-07)

날짜: 2026-10-07　출처: #562, #568, #564, #565, #575, #585

  • 미분 인터페이스 면(#562 / #568): 다중 출력 프로그램을 위해 fq.jacobian / fq.jvp / fq.vjp를 새로 추가했고, 네이티브 그래디언트 기능을 중앙 등록(단일 지점 등록) 방식으로 변경했다.
  • 계약화 측정(#564 / #565): N3-9에서 「그래디언트 방법 × 실행 모드」 30쌍 행렬을 contracts/gradient-methods-contract.toml로 문서화했으며(30개 단위 + 30개 노이즈 단위), 게이트에서 재검증했다. N3-11에서는 모든 미분 가능 명령 × 실행 모드를 항목별로 측정했다.
  • 기하량과 2차 도함수(#575 / #585): #575에서 2차 도함수(파라미터 시프트 Hessian)가 1차 규칙을 재사용하도록 했고, #585에서 Fubini-Study 계량 텐서(fq.gradients.metric_tensor)를 새로 추가했다 — 중심 차분으로 구현했으며, 연산자 시프트 규칙을 재사용하지 않는 이유를 반증 표로 설명했다(상태에 대한 미분과 기댓값에 대한 미분은 서로 다른 대상에 속한다).

1.4 FlagQuantum: QEC와 네이티브 엔트로피 도출 — 슬라이딩 윈도우 디코더와 von Neumann 엔트로피(10-08)

날짜: 2026-10-08　출처: #590, #591, #592, #589

  • 슬라이딩 윈도 디코더(#590, 09:06 머지): flagquantum/qec/sliding_window.py(772줄) 신규 추가 — 윈도별로 디코딩 그래프를 구성하고, 검출 이벤트 스트림을 윈도 단위로 디코딩하며, 수정을 커밋하고 고정 스트라이드로 전진한다. 동시에 이전에 이를 위해 보류했던 세 개의 블록 수준 프로젝션을 해제했다.
  • 네이티브 엔트로피 내보내기(#591, 09:06 머지): fq.vn_entropy가 네이티브 Stable Core 내보내기가 되었다(루트 내보내기 예산 37 → 38) — fq.run(circuit, outputs=fq.vn_entropy([0]))가 엔트로피 값을 직접 반환하며 log_base를 지원한다. 수치 구현은 simulation/entropy.py에 배치되고, 런타임은 디스패치만 담당한다.
  • 정렬 수렴 및 fail-closed(#592 / #589): 네 줄의 QEC 정렬 항목이 각자의 목표에서 수렴했다(#592). Quafu 원격 제출은 자격 증명이 없을 때 fail-closed로 변경되었다(#589, 모니터링 기간 가장 이른 머지).

1.5 FlagQuantum: 증거와 CI 마감 — 디스패치 수정 소급 기록 및 동시성 결함 수정(10-07 ~ 10-08)

날짜: 2026-10-07 ~ 2026-10-08　출처: #595, #593, #573, #597, #579

  • 증거 소급 기록(#595): 선언되지 않은 디스패치 수정 16건을 한 번에 선언하여 품질 전수 조사 기준을 바로잡았다.
  • 문서 및 벤치마크(#593 / #573): CircuitIR.global_phase 승인과 버전 마이그레이션 비용을 기록했다(#593). 벤치마크 앵커는 “어느 채널이 해당 판독값을 산출했는지”를 공개하고 인증된 채널을 통해 판독한다(#573).
  • CI 동시성 결함(#597, 오픈): “초록불 PR이 빨간불 main에 머지됨” 메커니즘을 규명했다 — ci.yml / pre-commit.yaml이 github.ref를 동시성 그룹으로 사용하고 cancel-in-progress가 설정되어 있어, 연속 두 번의 머지 시 이전 검증이 전부 취소된다(#590의 23/23 검사가 취소된 것이 바로 이 원인). 수정은 리비전별로 판독하고 강제 실행하도록 하는 것이다.
  • 정리: 또한 후속 머지로 대체된 잔여 PR 13건이 10-07 오후에 집중적으로 닫혔고, 머지 후 브랜치 삭제 16회가 완료되었다.
  • 용어 마이그레이션: qubit 용어 마이그레이션 배치(WQ-4 런타임 구간, WQ-5 알고리즘 구간)가 이번 모니터링 기간에 진행되었으며, api-changes 기록이 함께 제공되었다.

4. 요약 및 트렌드 관찰

  1. 연휴 후 첫날은 코드 측에서 재시동, FlagQuantum 단일 저장소가 주요 증분을 담당 — 모니터링 기간 내 조직은 총 24건의 PR이 머지되었고(FlagQuantum 23건 + vllm-plugin-FL 1건), 77건의 커밋이 있었으며, 그중 FlagQuantum은 연휴 말미와 복귀 아침에 걸쳐 연속적으로 추진되었다. 나머지 저장소는 아침에 새로 열린 PR로 재시동되었다(FlagTree 2건, vllm-plugin-FL 2건, docs 1건, build-infra 1건).
  2. FlagQuantum의 「릴리스 인증 + 계약 거버넌스」 이중 트랙 형성 — two_node_mps_training이 release_certified로 승격되었고 인증은 이미 서명된 실측 페이로드 위에 구축되었다. 루트 내보내기 예산 37 → 38, 「그래디언트 방법 × 실행 모드」 30쌍 계약, 메트릭 텐서 반증표 등이 역량으로서 계약 파일로 문서화되고 게이트 재검증으로 관리된다.
  3. 성능 작업이 「커널 최적화」에서 「디스패치 계층 시맨틱」으로 진전 — SV 시리즈 공개 디스패치가 SV-010 / 011 / 014로 확장되었고, MPS 샘플링 붕괴, SWAP 융합, 로컬 2비트 행렬 등의 커널이 동일한 증거 체계에 진입했다.
  4. 멀티칩 적응은 조용한 가운데 움직임이 있음 — 하이광(Hygon, bmm / baddbmm / addmm / index_copy), 쿤룬신(Kunlunxin, P800 업그레이드와 XPU3 수정), 다모아카데미 슈안톄(Damo Academy Xuantie, PPU 베이스라인 워크플로), 무어 스레즈(Moore Threads, 벤치마크와 별칭), ascende(Ascend, W8A8 INT8)가 각각 배치 처리를 진행했다. 신규 파트너 시왕(Sunrise) PTPU 그래프 모드 연결이 vllm-plugin-FL에 진입했다(#569).
  5. 빌드 및 품질 인프라 동시 수정 — vllm-plugin-FL CI 자가 치유 메커니즘(#559: 실패/취소 작업 정밀 재실행, 벤더 이미지 사전 빌드)과 FlagQuantum CI 동시성 그룹 결함(#597 머지 대기)이 함께 나타나, 복귀 첫날은 「인프라의 날」 특징을 보였다.
  6. 다음 관찰 지점: FlagQuantum #597 머지와 분산 릴리스 전역 후속(#535 → #587 라인), vllm-plugin-FL #561 / #569 리뷰 결과, FlagTree PPU / hcu 워크플로 머지, 조직 각 라인의 연휴 후 첫 완전한 업무 주간 리듬 회복 상황.
