오늘의 핵심: Torch-FL이 FlagGems의 Python 제출 경로를 네이티브 host로 컴파일, Qwen3-0.6B 핫 스타트 오버헤드가 벤더 PyTorch의 1.17배로 감소 (11-14~11-16)

날짜: 2026-11-14 ~ 2026-11-16　출처: Torch-FL #824 · Torch-FL #839 · Torch-FL #822(요구 사항 이슈) · Project 14

  • 결과: #824는 FlagGems의 Python 측 host 로직—메타데이터, 메모리 할당, 휴리스틱 및 Triton 발사 준비—을 가드가 있는 네이티브 host 프로그램으로 컴파일하면서 기존 디바이스 커널은 유지한다. 전체 Qwen3-0.6B 추론에서 prefill/decode의 핫 스타트 CPU 제출 소요 시간이 211.51/203.92밀리초에서 28.46/27.15밀리초로 감소했다. 벤더 PyTorch는 24.43/22.96밀리초이며, 환산 지연 비율은 1.17과 1.18이다.
  • 검수 기준: #822는 국산 가속기에서 벤더 PyTorch와 동일 물리 카드, 동일 워크로드로 비교하여 처리량 비율이 0.80 이상이거나 지연 비율이 1.25 이하에 도달할 것을 요구한다. 엔비디아 측은 이미 기준에 진입했으나 국산 카드 측은 아직 공개 데이터가 없다. #824는 자체적으로 실험적 엔비디아 추론 구현이라고 밝히며, 기본 모드 전환이 아니고 전체 연산자 커버리지를 선언하는 것도 아니다.
  • 연속성: 11-15부터 11-16 새벽까지 여섯 건을 연속 병합했다—#826은 FlagGems 소스 코드와 모델 host를 컴파일하고, #835는 네이티브 host 레지스트리를 전량 등록하며, #836은 schema 타입이 있는 eager 항목을 생성하고, #837은 소스 코드 호출 브리지를 생성하며, #838은 스칼라 의미를 보존하고, #839는 공유 host 오버헤드를 낮춘다(+2388/-55, 15개 파일). 이 라인은 “단일 모델 동작, 레지스트리 보완, 오버헤드 억제” 순서로 추진되며, 산발적인 성능 패치가 아니다.
  • 설계 방향: #823의 설계 초안은 구현 전에 노선을 정했으며, 결론은 상한을 결정하는 것이 커널 발사가 아니라 메모리 할당이라는 것이므로 1단계에서 할당자로부터 직접 메모리를 가져온다. #824와 #826 병합 후 계획은 메인테이너의 승인을 받았고, #829와 #830이 후속을 이어받는다.
  • 의미: FlagGems의 eager 경로는 항상 “Python 세금” 계층을 지니고 있었다—매 호출마다 Python에서 메타데이터, 할당 및 발사 준비를 해야 한다. 이 계층을 컴파일해 없앤 후, 크로스 칩 추론의 격차는 “커널을 얼마나 잘 작성했는가”에서 “host 경로를 어떻게 조직하는가”로 확장되었으며, 2.3의 추론 성능 검수 기준은 host 측 베이스라인을 동시에 명시해야 한다.

4. 요약 및 동향 관찰

  • 2.3 rc 직전 단계에 진입: 11-13 FEP 병합 마감이 지났고, 다음 관문은 11-30 기능 동결과 rc0이다. 모니터링 기간 내 build-infra가 910C, ROCm 7.2.4, PPU 2.1.0, MUSA 5.3.0 네 백엔드의 2.3.0 버전 데이터를 보완했으며, 마감 단위는 여전히 「백엔드 하나당 PR 하나」이다.

  • 융합 연산자는 추론 측의 주 전장: Hygon MegaMoE, NVIDIA MegaPreAttention, Ascend A5의 KDA와 인과 컨볼루션 모두 통신, 프로젝션, 정규화, KV 업데이트를 하나의 퍼시스턴트 커널에 묶는다. 이런 작업이 바꾸는 것은 단일 포인트 연산력이 아니라 멀티카드 가용성이다.
  • 테스트와 CI의 비중 상승: FlagGems 62건 정합, 82개 플랫폼 pytest 패키지(#9118), FlagGems-vllm의 CI 자체 포함(#1202), gendoc 5건 강화는 모두 같은 점을 가리킨다——2.3의 병목이 「코드 작성」에서 「검증과 추적 가능성」으로 이동하고 있다.
  • 주말도 멈추지 않음: 11-13 하루 180건 병합, 125건 커밋, 11-14와 11-15에는 각각 15건과 27건 병합. 평일 동안 쌓인 리뷰가 주말에 정리되었고, 실제 신규 개발은 여전히 11-13 낮에 집중되었다.
  • 뉴스 면과 코드 면의 괴리 지속: gnews 컴포넌트 쿼리는 연속 제로 히트였고, 이번 기간 유일하게 정보 가치가 있는 외부 보도는 Horizon Robotics Sunrise 칩의 임베디드 툴 적응과 Enflame의 인사 변동으로, 모두 배경 수준이다. 데일리 리포트의 판단 기준은 여전히 커밋, PR, 패키징 매트릭스의 1차 데이터이다.
