날짜: 2026-09-28 ~ 2026-09-29　출처: community #116, #121, #123, FlagGems v5.4.0, FlagScale v2.1.0, release-info 포털

09-28은 2.2의 GA일이며(직전 데일리 리포트 모니터링 기간은 당일 10:00에 마감), 이번 모니터링 기간은 릴리스물의 대외 저장소 반영 과정을 완전히 포괄했다——태그, Release, wheel, 이미지, 포털의 다섯 가지 유형 아티팩트가 동일 모니터링 기간 내에 모두 공개되었다:

  • 릴리스 규모: 모니터링 기간 내 21개 저장소에서 총 25개 태그/Release가 저장소에 반영되었다(4개의 FlagTree 변형 태그와 vllm-plugin-FL 듀얼 버전 라인, 목록 외 동일 모니터링 기간에 릴리스된 FlagAudio v0.3.0 포함). 2.2 공식 목록(community release-2.2.yaml, L0 / L1 / L2 세 계층 총 24개 항목) 중 21개 항목이 모니터링 기간 내에 릴리스를 완료했다——Torch-FL이 유일한 미릴리스 항목이며(버전 번호는 v2.10.0으로 확정), FlagTree triton3.5 / 3.3 두 변형은 기존 태그를 유지했다.
  • 세 차례 추진: 1차(09-28 17시 전후)——FlagGems v5.4.0(17:23), Megatron-LM-FL v0.3.0(17:23), flagcx v0.14.0(17:53), FlagScale v2.1.0과 TransformerEngine-FL v0.3.0(17:53), FlagTree enflame / sunrise 변형(17:05 / 17:15); 2차(20:16 ~ 22:15)——SGLang-Plugin-FL v0.2.0(20:16), flagtree-cpu v0.1.0, FlagGems-vllm v0.2.0, FlagGems-sglang v0.1.0, vllm-plugin-FL v0.3.0 + v0.2.2, KernelGen v2.2.0, KernelGenBench v0.2.0, FlagOS-Compressor v0.1.0 등이 20:27 ~ 20:28에 집중적으로 저장소에 반영되었다; 3차(09-29 01:12 ~ 01:13)——6개 L1 연산자 라이브러리(FlagFFT / FlagSparse / FlagDNN / FlagBLAS / FlagTensor / FlagAttention)가 소스 수정 병합(#123) 후 최종 릴리스를 완료했다.
  • 수정 폐쇄 루프: 6개 연산자 라이브러리의 소스는 “메인 브랜치 메인라인에서 2026-09-28 09:00 이전의 마지막 커밋”(FlagDNN / FlagBLAS는 master 브랜치)을 기준점 스냅샷으로 사용하도록 변경되었다——수정 병합(01:12)과 6개 라이브러리 재릴리스(01:12 ~ 01:13)가 동일 분 단위 모니터링 기간에 연결되어, 릴리스물이 드리프트 불가능한 기준점으로 버전이 고정되었다.
  • 아티팩트 동기화: 6개 순수 Python 연산자 라이브러리 wheel(FlagAttention 0.4.0, FlagSparse / FlagBLAS / FlagAudio 0.3.0, FlagFFT / FlagGems-vllm 0.2.0)이 내부 PyPI에 등록되었다(build-infra #1250, CI run 36425218655, pip download 모두 정상 수신 가능); vLLM 0.24.0 애플리케이션 이미지가 2.2.0-0.3.0 태그로 11개 플랫폼 패밀리 약 20개 레코드에 걸쳐 일괄 저장소에 반영되었다(1.3 / 3.1 참조); release-info 포털은 모니터링 기간 내 20회 자동 배포되었다.

판단: 직전 모니터링 기간의 “언제든 릴리스 가능” 상태가 이번 모니터링 기간에 “릴리스 완료”로 실현되었다——릴리스 규율(느려도 틀리지 않기, 수정 후 재릴리스, 기준점 버전 고정)이 전 과정에 걸쳐 관철되었다; Torch-FL이 유일한 공백이며, 대외 공식 서사 노드는 10-17 대회에 고정된다(2.2 참조).

2.3 Hygon×중커룽안: EngineerAI 컴퓨팅 일체형 머신 발표——DCU 산업 시나리오 진입(09-28)

날짜: 2026-09-28　출처: Sina Finance(ZOL), Ifeng

4. 요약 및 트렌드 관찰

  1. 릴리스 안착: 2.2가 「목록」에서 「저장소」로 진입——21개 저장소, 25개 태그/Release가 12시간 내 저장소에 반영; 6개 wheel이 내부 PyPI에 등록, 애플리케이션 이미지 일괄 재기록, 포털 20회 배포——「태그 + Release + wheel + 이미지 + 포털」 다섯 가지가 모두 갖춰져 2.2가 재현 가능한 설치 상태에 진입.
  2. 수정 클로즈드 루프로 릴리스 규율 입증——6개 연산자 라이브러리 소스 수정(#123)과 재릴리스가 동일 분 내에 연결; 목록 기준이 「RC2 HEAD」에서 「메인라인 스냅샷 시점」으로 변경——릴리스물은 드리프트하지 않는 커밋에 고정, 「기준을 조정할지언정 움직이는 소스를 쫓지 않는다」.
  3. Torch-FL이 유일한 공백——v2.10.0 버전 라인과 벤더 명명 패키징 규범(wheel 의존성 명시적 선언)은 이미 갖춰졌고, 태그 저장소 반영만을 대기 중——릴리스 규율의 이면: 기준 미달 시 통과 불가.
  4. 개발 라인과 릴리스 라인의 명확한 분리——FlagGems-vllm 0.3.0-dev1, FlagSparse / FlagBLAS / FlagAudio 0.4.0-dev1, FlagFFT 0.3.0-dev1 등 dev 버전 번호가 일제히 상향; NCIC 협업 라인(FlagSparse) 지속 활발——2.3 주기와 2.2 마무리가 병행 추진.
  5. 대외 서사 노드는 10-17 대회에 고정——메인 포럼에서 「FlagOS 2.2 버전 릴리스」 세션을 선보일 예정; 뉴스 측은 22번째 연속 조용한 모니터링 기간으로, 외부 산업 포석(Hygon×Zhongke Soft 일체형 기기)과 대비——일상은 코드 측이 주도하고, 릴리스와 회의 노드가 대외 서사를 담당.
  6. 멀티 플랫폼 커버리지가 연내 최대 도달——애플리케이션 이미지 매트릭스가 11개 플랫폼 패밀리 커버, 양자화 커널 배치가 8개 벤더에 걸침——「한 번 개발, 여러 칩에서 실행」의 딜리버리 면이 릴리스 주간에 정점 도달, 다음 관찰 포인트는 Torch-FL 저장소 반영과 2.3 개발 라인 합류.
