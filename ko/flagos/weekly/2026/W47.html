FlagOS 위클리 리포트 (2026-11-16 ~ 2026-11-20)

2026-11-20 Kubuds

보고 주기: 2026년 11월 16일(월)부터 11월 20일(금)까지. 5영업일, 5회 데일리 리포트. 11-16 회차는 주말을 걸친 72시간 모니터링 기간으로, 11-13 06:00부터 11-16 06:00까지이다. 나머지 네 회차는 각각 24시간이며 앞뒤가 맞물린다. 행위 사실 구간은 11-13 06:00부터 11-20 06:00까지이다. 발행일(11월 21일)에는 org 푸시, 병합 검색과 네 개의 릴리스 태그에 대해 추가 점검을 실시한다.

1부 · 브리핑

이 절은 이번 주 주요 사항을 선별한 것으로, 기본 800자 이내(이번 회차 740자)이다. 전체 항목, 건별 목록과 출처는 2부 아카이브를 참조하라.

이번 주 65개 저장소 중 19~20개 저장소에 푸시가 있었다. 다섯 회차 합계 커밋 787건, 병합 875건. 심사 대기 재고는 261~318건 사이를 오갔으며, 기말 261건이다.

  • FlagTree 0.7.1 정식 라인, 네 개 백엔드 보완: 11-17과 11-18에 각각 태그 하나씩 생성. 정식 버전은 ascend3.5, xpu3.6, ppu3.6, enflame3.6을 커버한다. 프리릴리스 측은 여전히 a1과 a2가 병존한다.
  • 2.3.0 기반, 일주일 만에 여섯 개 SDK 라인 교체: MetaX는 maca3.10.1.11로 교체, Enflame 두 개 tops 라인 첫 납품, Cambricon 4.7.6 3계층 적용, Moore Threads musa4.3.6 정리. build-infra 병합 125건, 신규 기능 없음.
  • vLLM 0.32.0 애플리케이션 계층, 다섯 백엔드 동일 날 개시: 이미지 태그 네 개 기록됨. Ascend는 V2 샘플링 심볼 세 개 누락, Pingtouge는 플러그인 하드 import에서 막힘.
  • host 경로가 새로운 격전지로: Torch-FL은 Qwen3-0.6B 핫 스타트 커밋을 211밀리초에서 28밀리초로 단축. 지연 비율은 벤더 PyTorch 대비 1.17과 1.18.
  • 세 곳 네이티브 호스트 동일 날 병합: MetaX 83.68%로 문턱 통과. Hygon 단문 시퀀스 1.264배, Enflame decode 78.60%, 모두 기준 미달.
  • 연산자 생산과 검수 탈동기화: FlagGems 전 네 회차 병합 261건. 11-20 단일 일 83건 커밋 중 43건이 KernelGen 생성. 심사 대기 261~318건.
  • A5, 스캐폴드에서 실측으로: 950DT 첫 연산자가 4096 토큰을 약 250마이크로초에서 55마이크로초로 단축.
  • 상용 측 첫 완전한 라인 등장: 11-17 Zhiyuan과 Qingmao Intelligence가 FlagOS 기반 상용 Token 공장 출시. 11-19 BIS 신규 규정 발효, Enflame 하한가, 다섯 회원 단위 동일 날 급락.

이번 주 판단: 2.3의 병목이 코드 작성에서 플랫폼 목록과 검수로 이동했다. rc0까지 단 열흘 남았고, vLLM 0.32가 여섯 곳을 동기화 동작으로 묶었다. 어느 한 곳이라도 심볼 계약이 정렬되지 않으면 전체 칸이 비어 있게 된다.

2부 · 아카이브

아래는 이번 주 전체 본문으로, 구조와 기준은 지난 위클리 리포트와 동일하다. 브리핑의 각 판단은 여기서 건별 근거와 출처를 확인할 수 있다.

자료 출처: 본 데일리 FlagOS 동향 리포트 5회, 날짜는 11-16, 11-17, 11-18, 11-19, 11-20. GitHub 측은 flagos-ai 조직 64~65개 저장소를 커버한다. 다섯 회차 합계 기본 브랜치 커밋 787건, 병합 PR 875건. 심사 대기 PR 재고는 261~318건 사이. 발행일 재확인은 org 저장소 목록, 병합 PR 검색과 태그 원출처를 사용했다.

편성 설명: 여섯 차원으로 구성한다: 주간 주요 뉴스, 버전과 릴리스, 컴포넌트와 코드 공동 기여, 회원 단위와 벤더 적응, 생태계와 커뮤니티, 추세 관찰. 병합 기준은 병합 PR 검색을 준거로 한다. 발행일 11-13 06:00부터 11-20 06:00까지 재계산 결과도 875건으로 동일하다. 조직 저장소 수는 11-19에 64에서 65로 증가했다. 따라서 “65개 저장소”라는 표현은 마지막 두 회차에서만 성립한다.

1. 이번 주 주요 뉴스

  • FlagTree 0.7.1 정식 라인, 일주일 만에 네 개 백엔드 보완(11-17~11-18): 11-17 18:23에 0.7.1+ppu3.6 생성. 11-18 01:16에 0.7.1+enflame3.6 생성. GitHub 측에는 태그만 있고 Release 본문은 없다. Pingtouge는 이전에 0.7.1.dev1+ppu3.6에, Enflame은 0.7.0+enflame3.6에 머물러 있었다. 정식 버전은 이로써 ascend3.5, xpu3.6, ppu3.6, enflame3.6 네 개 백엔드를 커버한다. 프리릴리스 측은 여전히 a1과 a2가 병존하며, a2는 Moore Threads와 Iluvatar CoreX를 커버한다.

  • 2.3.0 기반, 일주일 만에 여섯 개 SDK 라인 교체(11-16~11-19): 이번 주 순차적으로 Hygon dtk26.10 버전 조합 확정. Enflame 두 개 tops 라인 세대 교체 및 최초 납품. MetaX는 maca3.10.1.11로 교체. Cambricon Neuware 4.7.6 3계층 적용. Moore Threads musa4.3.6 전 체인 정리. build-infra는 닷새간 125건 병합, 순서대로 39, 13, 36, 20, 17이며 신규 기능은 한 건도 없다. 커뮤니티 일정의 rc0(11-30)까지 단 열흘 남았다.

  • vLLM 0.32.0 애플리케이션 레이어 5개 백엔드 동시 개시(11-17): #1851에서 5개 라인에 deps_app.vllm0.32.0을 추가했다. 5개 라인은 nvidia-cuda13.3, amd-rocm7.2.4, ascend-cann9.2.1, iluvatar-corex5.0.1, thead-ppu2.1.0이다. 애플리케이션 이미지 태그는 2.3.0-0.5.0.dev0_g814b6d3.d20261117로 통일했다. 4개 백엔드는 bot이 이미 changelog에 기록했고, Ascend는 차단 기록만 있다. Ascend는 v2_apply_penalties 등 3개의 V2 샘플링 심볼이 없으며, 이들은 FlagGems-vllm #1234 브랜치에만 있다. T-Head는 플러그인 측에서 flash_attn_3._C를 하드 import하는 부분에서 막혔다. 두 지점 모두 FlagOS 자체 코드에는 없다.

  • Torch-FL, ‘Python 세금’을 컴파일로 제거(11-14~11-19): #824에서 FlagGems의 Python 측 host 로직을 가드가 붙은 네이티브 host 프로그램으로 컴파일했다. Qwen3-0.6B의 prefill/decode 핫 스타트 CPU 제출 시간이 211.51/203.92밀리초에서 28.46/27.15밀리초로 줄었다. 벤더 PyTorch는 24.43/22.96밀리초이며, 지연 비율은 1.17과 1.18이다. 11-19에 MetaX, Hygon, Enflame 세 곳의 네이티브 호스트가 같은 날 병합되었다. MetaX는 86,907,392개 logits가 모두 일치했고, 처리량은 벤더의 83.68%였다. Hygon은 190,831,616개 logit 요소가 비트 단위로 일치했으며, 짧은 시퀀스에서는 여전히 1.264와 1.260배였다. Enflame은 두 라운드 병합이 81.38%와 78.60%였고, decode는 80% 기준을 넘지 못했다.

  • Zhiyuan·Qingmao Intelligence, 상용 Token 공장 출시(11-17): 발표는 2026 Qingmao AI 파트너 콘퍼런스 겸 Token 공장 연례회의에서 이루어졌다. 생태 기준은 21개 반도체 기업, 86개 생태 파트너, 35종 AI 반도체다. 9대 연산자 라이브러리에 누적 1454개 이상의 Triton 연산자가 축적되었다. 그중 약 800개가 최소 5종의 중국산 반도체에서 네이티브 연산자 대비 80% 이상 성능을 달성했다. 910C에서 GLM-5.3의 Prefill 웨이브 처리량은 3.41% 향상되었고, 256K 입력에서 TTFT p50은 4.94% 감소했다.

  • Ascend A5, 스캐폴드에서 실측으로(11-16~11-19): 11-16 FlagGems-vllm #1245에서 950DT용 BNSD FlashAttention 전방 연산을 추가했다. 11-19 FlagGems #9543에서 아키텍처 탐지와 빈 a5/ 패키지를 보완했다. 같은 날 FlagGems-vllm #1338에서 ascend/a5/ops/에 topk_softplus_sqrt를 병합했다. 256 전문가, bf16, topk=6 조건에서 4096 token이 약 250마이크로초에서 55마이크로초로 줄었다. A5는 Ascend950DT와 Ascend950PR에 대응하며, NpuArch는 DAV_3510이다.

  • BIS 신규 규정 발효 당일 5개 회원사 주가 급락(11-19): 11-16에 발표된 《선진 반도체 원격 접근 대응》 임시 최종 규정이 11-19에 발효되었다. Enflame은 20% 하한가로 마감해 364.33위안을 기록했다. 당일 거래대금은 19.62억 위안, 회전율은 28.35%였다. MetaX, Moore Threads, Hygon, Centec과 홍콩 상장 Iluvatar CoreX도 같은 날 하락했다. FlagOS 컴포넌트 코드에는 당일 대응 변화가 없었다.

2. 버전 및 릴리스 동향

Moore Threads mthreads-musa5.3.0은 #1792부터 총 10여 건을 처리했다. 같은 회차에서 Iluvatar 애플리케이션 레이어의 corex4.4.0을 삭제했고(#1771), iluvatar의 LLVM을 v0.7.0으로 고정했다(#1819).

  • 11-19호 (11-18) 20건: MetaX 라인 교체 여섯 건이 연속으로 이어짐. #1894는 base 레이어 교체, #1895는 runtime 변경 기록 보완, #1896은 ompi 라이브러리 경로 수정, #1897과 #1899는 날짜 보완 기록, #1900은 오래된 주석 삭제. Moore Threads 두 건: #1902는 base 레이어의 musa4.3.6을 퇴역시키고, #1904는 애플리케이션 레이어에서 해당 행을 삭제. #1905의 flagcx 행은 여전히 검토 중.

  • 11-20호 (11-19) 17건: Cambricon Neuware 4.7.6 3개 레이어 반영(#1906 base, #1907 FlagCX 빌드 행, #1909 runtime). Hygon은 amdsmi==7.0.2 보완(#1917). 910C 세 행은 dispatch를 통해 FILE_STORE로 변경(#1921). #1925는 8.5.0과 9.0.0 두 행의 runtime을 내부 PyPI로 지정, 여전히 검토 중. 동일 배치에서 Enflame 벤더 페이지의 세 가지 표현 수정(#1916, 대응 issue #1915).

FlagTree 0.7.1: 정식 라인 네 개 백엔드, 사전 릴리스는 여전히 a1과 a2 병존

출처: https://github.com/flagos-ai/FlagTree/releases/tag/0.7.1%2Bppu3.6.

6. 트렌드 관찰

  • 기반 계층이 「버전 보충」에서 「라인 교체와 정리 퇴출」로 전환: 이번 주 여섯 개 SDK 라인이 세대 교체, 한 곳 정리 퇴출, 한 곳 신규 진입했습니다. build-infra에 병합된 125건 중 신규 기능은 한 건도 없습니다. 작업 형태는 「한 라인당 한 카드」이며, 리듬은 base 먼저落地, runtime 후속, 인덱스 보충 후 휠 보충으로 통일되었습니다. rc0까지 열흘 남은 상황에서 이 리듬은 Cambricon 4.7.6이大概率 2.3.0 기본 매트릭스에 맞추지 못할 것임을 의미합니다.

  • 성능 서사가 host 경로와 컨텍스트 재사용으로 이동: Torch-FL은 웜 스타트 CPU 커밋을 벤더 PyTorch의 1.17배와 1.18배로 압축하여 #822의 80% 기준선에 진입했습니다. Ascend MegaMHC는 컨텍스트를 사전 바인딩하지 않은 Eager가 0.648배에 불과하여, 이득이 순수 내부 연산이 아니라 시작과 워크스페이스 재사용에서 온다는 것을 보여줍니다. 이제 크로스칩 비교에는 host 기준선을 함께 제시해야 하며, 그렇지 않으면 숫자는 비교 불가능합니다.

  • 검증 측이 병목: KernelGen은 하루에 43개 연산자를 생성했고, 같은 날 40건의 커밋이 각 벤더 백엔드의 정밀도와 타임아웃을 수정했습니다. 심사 대기열은 261~318건이며, Kunlunxin의 「287 ops fix」는 단일 건에 203개 파일, +53022줄입니다. 연산자 보충이 정렬보다 빠르며, 리뷰 처리량이 2.3의 커버리지를 결정합니다.

  • 업스트림 버전이 다운스트림을 동기화 작업으로 묶음: vLLM 0.32는 다섯 곳이 같은 날 개시, 여섯 곳이 심사 중이며, SGLang 0.5.18은 다섯 곳이 같은 주에 마무리했습니다. 두 곳의 블로킹 모두 FlagOS 자체 코드가 아니라 심볼 계약입니다. 예로는 v2_apply_penalties 같은 익스포트 누락, flash_attn_3._C 같은 하드 임포트, ECCL의 64비트 dtype 경계가 있습니다. 이런 문제는 매트릭스에 명시적으로 기록해야 하며, 재시도로 덮어서는 안 됩니다.

  • 신규 하드웨어가 세대별 디렉토리로 분화, 컴파일러 인터페이스 교체 중: Ascend는 「하나의 백엔드」에서 _ascend/a5 같은 세대별 디렉토리로 변했으며, A5는 950DT와 950PR에 대응합니다. 동시에 TLE pipeline 이터레이터가 철회되고, FlagGems, FlagGems-vllm, FlagAttention 세 라이브러리가 같은 날 tl.range로 변경되었습니다. 상위 연산자가 컴파일러 인터페이스를 따라가야 하는 것은 이제 상시 상태입니다.

  • 뉴스면과 코드면의 괴리 지속, 하지만 이번 주 산업 서사에는 실질 내용: 컴포넌트명 쿼리는 연속 다섯 모니터링 기간 제로 히트이며, 공개 보도는 여전히 멤버 기관의 자본과 제품 소식이 공급합니다. Token 공장은 이번 주 유일하게 완전한 기술 수치를 갖춘 산업 이벤트입니다. BIS 신규 규칙은 외부 환경을 바꾼 유일한 이벤트입니다. 데일리 리포트의 판단 기준은 여전히 커밋, PR, 패키징 매트릭스의 일차 데이터입니다.
