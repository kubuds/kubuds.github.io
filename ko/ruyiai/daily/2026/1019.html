오늘의 중점: BUDDY MLIR 0.1.1 릴리스——RISC-V 서버 측 크로스 컴파일 및 모델 릴리스 파이프라인 구축

날짜: 2026-10-18　출처: BUDDY MLIR 0.1.1 릴리스 페이지, 0.1.0 대비 0.1.1 차이, PR #989 RISC-V 서버 측 크로스 컴파일, PR #925 모델 릴리스 워크플로

Buddy Compiler 메인 저장소 buddy-mlir는 10-18 06:26(베이징 시간)에 BUDDY MLIR 0.1.1을 릴리스했으며, 0.1.0(10-16 00:53)으로부터 약 이틀 만으로, 이 프로젝트의 이틀 내 두 번째 정식 버전이다. 0.1.0 대비 0.1.1은 변경 2건, 파일 24개, 약 +896/-54줄에 불과하며, 방향은 모두 “전달 가능성”을 향한다.

첫째는 #989 “buddy-server에 RISC-V 서버 측 크로스 컴파일 추가”: buddy-server에 riscv64 대상 크로스 컴파일 경로를 보강하고, 동시에 런타임 의존성 목록의 핸들 구현(RaxDependenciesHandle, 단위 테스트와 테스트 플러그인 포함), 플러그인 발견의 의사 구현과 전사 테스트를 추가하여 런타임 의존성을 목록에 따라 해석한다. 이와 함께 buddy-cli를 간소화(순감 40줄)하고 RVV 환경 문서를 갱신했다. 둘째는 #925 “publish-models 워크플로 신규 추가”: GitHub Actions 릴리스 파이프라인과 Hugging Face 모델 릴리스 스크립트(약 313줄)를 추가하여 모델 아티팩트를 CI에서 직접 푸시·릴리스할 수 있게 했다. 두 변경을 합치면, 0.1.1이 해결한 것은 “서버가 RISC-V 머신에 진입하고, 모델 아티팩트가 CI에서 나온다”는 양 끝이다.

다운스트림은 당일 바로 반응했다: triton-riscv는 10-17 22:41에 #87을 병합하여 Buddy MLIR v0.1.0을 고정했고, 10-18 08:57에 자동 버전 추종 #88로 v0.1.1 야간 버전으로 올렸다. tilelang-riscv는 10-16에 Buddy MLIR 릴리스 CI를 신규 추가하고 해당 CI에서 Python 확장을 빌드했다(상세는 1.3, 1.4, 4.1 참조).

Buddy MLIR이 0.1.0에서 0.1.1까지 약 이틀밖에 걸리지 않았으며, 0.1.1의 두 변경 모두 전달 가능성을 겨냥했다. 서버 측 크로스 컴파일로 buddy-server가 RISC-V 머신에 진입할 수 있게 했고, 모델 릴리스 워크플로로 모델 아티팩트가 CI에서 나올 수 있게 했다. 다운스트림 대응 역시 일 단위로 이루어졌다. triton-riscv는 10-17에 #87을 병합하여 0.1.0을 고정했고, 10-18 오전 자동 추종으로 0.1.1 야간 버전으로 올라갔다. tilelang-riscv는 10-16에 Buddy MLIR 릴리스 CI를 자체 파이프라인에 포함했다. 세 저장소가 동일한 LLVM 백엔드를 둘러싼 버전 결합이 강화되고 있으며, 관찰 포인트는 통일된 릴리스 윈도우와 회귀 기준선이 형성되는지 여부다.

6.2 두 fork 유지보수 라인의 계속 분화: PyTorch 병합과 리플레이 병행, LLVM 엿새간 정적

PyTorch의 riscv 브랜치는 모니터링 기간 내 143건을 병합했으며(업스트림 동기화 위주), 일괄 리플레이로 로컬 패치 스택을 유지하는 한편 약 5주 만에 첫 PR 병합(#51 riscv64 로컬 이미지)이 나타났다. 반면 LLVM의 riscv 브랜치는 10-12부터 엿새간 커밋이 없었으며, 두 건의 FPGA 백엔드 PR이 10-12에 멈춰 있다. 모두 “업스트림 fork + 로컬 패치 스택”이지만, 한쪽은 일 단위로 진행되는 파이프라인이고 다른 쪽은 리뷰를 기다리는 정적 브랜치로, 유지보수 투입의 차이가 이전 모니터링 기간보다 더 뚜렷하다. 관찰 포인트: LLVM 리플레이가 새 업스트림 기준선에 따라 재시작되는지, 그리고 FPGA 백엔드 PR이 리뷰에 들어가는지 여부다.

6.3 RuyiSDK 3개 라인 병진: 커널 탐지 보완, 배포판 확장, 툴체인 버전 윈도우 대기

커널 측은 RVA23 관련 원자성 및 명령어 페치 원자성 프로파일 확장을 cpufeature와 hwprobe에 병합했고, 사설 확장 ID를 업스트림과 정렬했다. 배포판 측은 Rust 임베디드 6개 패키지를 추가하여 Rust 베어메탈 개발의 기본 의존성을 소프트웨어 소스에 포함했다. 툴체인 측은 0.54.0을 10월 말로 확정했으며, ABI 호환성 검사와 K1/K3 적응이 계속 추진 중이다. 펌웨어 라인은 3연속 릴리스 후 일시 중지되었다. 전체적으로 “커널 탐지 보완, 배포판 확장, 툴체인 버전 윈도우 대기”의 리듬을 보이고 있으며, 다음 단계는 0.54.0이 예정대로 릴리스되는지, 그리고 서밋 이후 방안이 실행되는지를 지켜보는 것이다.
