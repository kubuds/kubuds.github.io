RuyiAI 위클리 리포트 (2026-09-30 ~ 2026-10-07)

2026-10-07 Kubuds

보고 기간: 2026년 9월 30일(수) ~ 10월 7일(수), 총 8일; 국경절 연휴 특별 집계 기간(10월 1일~7일은 연휴로 데일리 리포트 중단) 자료 출처: 본 간행물의 일일 RuyiAI 동향 리포트(2026-09-30 1회, 모니터링 기간 09-29 04:30 ~ 09-30 04:30; 10-01 ~ 10-07 연휴로 데일리 리포트 자료 없음); 그 외 조직 저장소 216시간 모니터링 기간 점검, 커뮤니티 이중 출처 재검증 및 기술 정보 저장소 전 기간 스캔(10-08 아침까지 포함) 편성 설명: 이번 주기는 국경절 연휴에 걸쳐 진행됨——코드 병합은 연휴 기간 저생산 모드로 전환되었으나 리뷰 큐, 정보 저장소 및 커뮤니티 채널은 계속 운영됨; 모든 기술적 사실은 코드 저장소, 릴리스물 및 커뮤니티 포럼의 실측 검증에서 비롯됨

1. 주간 주요 뉴스

  • openRuyi 2026.09 정식 릴리스: RVA23 완성도 향상, 클라우드 및 스토리지 소프트웨어 스택 확장, 저장소 GPG 검증 활성화(09-30): 릴리스 공지는 이번 주기 첫날 게시됨(09-30 데일리 리포트 모니터링 기간 내에는 아직 보이지 않았으며, 이번 기수 점검에서 새로 발견된 항목). 요점: GCC 16 BCLR 코드 생성 수정 사항 백포트——DPDK rte_softrss() 행 및 Mesa ACO 스케줄러 오컴파일 제거; DPDK 25.07에서 RVA23 기반 RVV 조회 경로 활성화(lpm / fib / acl / node); OpenJDK에 15개의 RISC-V 패치 병합(Zbs / Zfa 명령어 생성, RVV vset 최적화, CRC32C intrinsic); 컨테이너 측 riscv_hwprobe 허용 후 Sophgo V100에서 OpenSSL의 Zvkned / Zvknhb 벡터 암호 확장 활성화, zlib-ng의 Zbc 기반 crc32 가속 활성화 실측; 커널 7.2.6 / 6.18.54; Cloudpods 4.0.3 멀티클라우드 플랫폼, SPDK 25.09(io_uring / RBD bdev / SMA) 및 Ceph 21.3.0 스냅샷 추가; 설치 경로에서 기본적으로 GPG 서명 검증 활성화; 보안 업데이트 일괄 적용(expat / jq / vim / pcre2 / runc 등); Server / Container / Desktop / Zero 4개 버전 및 실험적 RVA20 버전 제공. 출처: openRuyi 2026.09 릴리스

  • 《PyTorch RISC-V CI 실천》블로그 게시: RuyiAI 커뮤니티, XuanTie 및 RISE와 공동으로 실기 CI 체계 공개(10-08 새벽 게시): 블로그는 PyTorch RISC-V 지속적 통합의 전모를 공개——RuyiAI(중국과학원 소프트웨어연구소)가 XuanTie 팀, RISE AI/ML 워킹 그룹과 공동 구축: Debian Trixie / Python 3.13 / GCC 14 / OpenBLAS 0.3.33 기반라인 채택, “한 번 빌드, 다중 머신 테스트”; Jenkins 병렬 분할(핵심 테스트 약 3시간, 전체 약 5시간); 과거 소요 시간에 따른 동적 분할; 통합 blocklist를 수동 분류로 관리; 실패 로그 중앙 집중 아카이빙(community-ci.openruyi.cn); SyncBots가 지속적으로 업스트림 main을 RISC-V 작업 브랜치에 동기화하고 핵심 테스트를 자동 트리거——현재 RISC-V 핵심 테스트 스위트는 지속적으로 안정적으로 통과 중. 작업은 XuanTie 팀의 RFC(pytorch#171659)와 tracking issue(#180975)에서 시작됨; 소프트웨어연구소는 RISE 멤버이며, RuyiAI 멤버가 RISE AI/ML WG 공동 의장을 맡고 있음. 출처: 블로그(중영문 이중 언어), RFC #171659, tracking #180975

  • PyTorch fork, 무소식 종료: riscv 브랜치 일일 동기화 재개, 10-08 새벽 전면 재빌드 완료 (09-30 ~ 10-08): riscv 브랜치는 이전에 09-21부터 조용했으나, 09-30 오전 유지관리자 푸시가 재개됨——이후 기본적으로 매일 1회(09-30부터 10-07까지 총 7회); 10-08 새벽(베이징 시간)에 전면 재빌드 1회 완료——로컬 패치 스택을 순서대로 재적용(#1 RISC-V Blocklist부터 총 23건, #44 bytes_to_scalar 수정, #50 inductor blocklist, #42 ULP 허용 오차 등 포함), SyncBots 통합 커밋으로 업스트림 동기화 지점을 e188cec로 전진; 8건의 오픈 PR(#23 / #35 / #36 / #38 / #43 / #46 / #48 / #51)의 베이스라인을 일괄 갱신——RVV 2건(#46 ATen RVV 지원, #48 RVV CPU capability)과 CI 로컬 미러(#51)가 포함됨. 출처: riscv 브랜치 커밋, PR 목록

  • llvm-project riscv 브랜치: T-Head A100 시리즈 3건 병합 (10-03); 야간 재빌드 리듬이 연휴 내내 지속 (10-01 ~ 10-07): #30은 IME intrinsics를 A100 점적 연산으로 lowering, #32는 A100 pack/unpack intrinsic lowering 및 스케줄링 추가, #31은 A100 HP/SP 및 pack/unpack lowering을 보완하고 스케줄 모델을 교정——3건이 10-03에 연이어 병합됨; 해당 브랜치는 매일 야간(베이징 시간 새벽) 재빌드를 유지하며, 모니터링 기간 마지막 재빌드 헤드는 03e4e494. 표준 AME 사전 승인 백엔드 PR #22(7월 개설, 토론 7건)는 10-02에 종료(미병합); FPGA 2건(#25 / #28)은 여전히 리뷰 중이며 베이스라인 갱신됨. 출처: PR #30, PR #31, PR #32, PR #22

  • riscv-gcc P 확장 2건 PR 병합 (10-02); Ztt 초안 툴체인 작업 라인 개시 (09-30부터): #20(abs / pabs 계열을 헤더 파일 연산자 lowering으로 변경 및 테스트 수정)과 #21(잘못된 동일 채널 PAS/PSA combine 모드 제거)이 10-02에 병합(작성자 TelGome); 같은 시기 riscv-gcc와 riscv-binutils에 ztt-dev 브랜치를 새로 열어 Ztt 초안 확장을 위한 레지스터 피연산자, 명령어 인코딩 및 CSR 지원을 추가, 연휴 기간 내내 커밋 지속(코드 생성 최적화 포함, 최신은 10-08 아침까지); riscv-gnu-toolchain에는 ame-experimental 브랜치 추가. 출처: PR #20, PR #21, ztt-dev 브랜치

  • 행렬 확장 작업 라인 구축: AME-operator 저장소 오픈소스화, 공식 AME 규격 저장소 fork 완료(09-30): ruyisdk 조직이 AME-operator 저장소를 신설——RISC-V AME/Ztt GEMM 및 GEMV 커널, 독립 수치 참조 및 DejaGNU/Spike 검증 스위트(INT8 / UINT8 / INT32 / FP32 / BF16, T=4~128; 스모크 테스트 16개 ELF, 32회 실행 전부 통과); 같은 날 RISC-V 공식 attached-matrix-extension(AME 태스크 그룹 관리 저장소)을 fork. 이로써 행렬 방향은 「LLVM(BOSC AME / A100) - GCC/Binutils(Ztt) - 연산자 및 검증(AME-operator)」 3개 라인 구도가 형성됨. 출처: AME-operator 저장소, attached-matrix-extension fork

  • 국경절 연휴 「정보와 리뷰 두 라인 무중단」: ruyiai-daily 9회 연속 업데이트, openRuyi 리뷰 큐 활발, 커뮤니티 강좌 신규 업로드(09-30 ~ 10-08): 기술 정보 저장소 ruyiai-daily가 연휴 기간 9회 연속 발행(09-30~10-08회차, 매일 이른 아침 게시), PyTorch 생태계 / LLVM-MLIR / Triton 및 TileLang / RISC-V / AI 업계 5장 구조 유지; 오픈 PR 측에서는 openRuyi 큐가 audit의 RISC-V 지원 활성화(#1399), go-github-chewxy-math32 RISC-V 테스트 수정(#1398), moby 29.8.1(#1395) 등을 집중 리뷰; 커뮤니티 포럼에서는 《RISC-V Linux 실습 과정》 제01장 「환경과 툴체인」 강의 자료와 실습(10-04, 10-06) 및 개발 보드 예제 저장소 자료 게시물(09-30)을 게시. 출처: ruyiai-daily, 포럼 #2885

  • triton-riscv: Nightly 2026-10-04 빌드 릴리스; softmax 및 matmul 최적화 PR 생성(10-05, 10-08): 야간 빌드는 주간 리듬 유지——Nightly 2026-10-04-12c2f6a가 10-05에 릴리스(CPython 3.12~3.14의 x86_64 및 riscv64 wheel 커버); 10-08 아침 PR #85「softmax 및 matmul 최적화」(커뮤니티 기여자) 신규 생성. 출처: Nightly 2026-10-04, PR #85

2. RuyiAI 스택 진척(PyTorch / Triton / TileLang RISC-V 적응)

모니터링 기간 개요: RuyiAI-Stack 조직(18개 저장소)은 이번 주기에 llvm-project(A100 시리즈 병합, 매일 밤 재빌드), pytorch(매일 동기화, 전체 재빌드 및 PR 갱신), triton-riscv(매주 빌드, 신규 PR), ruyiai-daily(9회) 및 사이트 블로그에 작업이 집중됨; tilelang-riscv, mxnet, caffe, FBGEMM, cpuinfo, VecIntrinBench, IntrinTrans, torq-tile, dsh-osc, pytorch-ci 등은 커밋 없음; harness는 커밋은 없으나 PR 측에서 리뷰 활동 있음.

PyTorch fork: 「조용한 마무리」에서 「매일 동기화 + 전체 재빌드」로

  • 휴일 동기화(09-30 ~ 10-07): riscv 브랜치는 09-30 오전에 푸시를 재개했으며(이전에는 09-21부터 침묵), 이후 거의 매일 한 번씩 유지보수 푸시를 진행했습니다(09-30, 10-01, 10-02, 10-04, 10-05, 10-06, 10-07 총 7회). 브랜치 유지관리자가 수행했으며, 이는 재구성형 동기화(패치 스택을 더 새로운 업스트림 기준선으로 재적용)에 해당합니다. main 브랜치의 정례 업스트림 동기화는 지속되었습니다(MPS, ROCm, inductor 등 일반 커밋은 필터링 규칙에 따라 수록하지 않음).

  • 전체 재구성(10-08 새벽): 브랜치가 모니터링 기간의 마지막 전체 재구성을 완료했습니다. 패치 스택 23건을 순서대로 재적용했으며(가장 이른 것은 4월의 RISC-V Blocklist #1과 CI 구축 #6~#12까지 거슬러 올라감), SyncBots 통합 커밋(e188cec)이 최상단에 배치되었습니다. 8건의 오픈 PR 기준선 상태가 동기화되어 갱신되었고, 업데이트 시간은 10-08로 통일되었습니다.

  • RVV 심사 대기열: 두 건의 벡터 패치(#46 ATen RVV 지원, #48 RVV CPU capability)가 계속 대기 중이며, 이번 기간 업데이트는 재구성으로 인해 발생했습니다. CI 로컬 미러 PR #51(네이티브 riscv64 하드웨어 요구)도 같은 대기열에 있습니다.

  • 배경 연관성: 이번 재구성은 《PyTorch RISC-V CI 실천》 블로그 글과 호응합니다. SyncBots가 업스트림 main을 지속적으로 동기화하고 핵심 테스트를 자동 트리거하는 것은 「업스트림 추적에서 실기 회귀까지」의 폐쇄 루프가 운영되는 모습입니다(자세한 내용은 이번 주 주요 뉴스 참조).

컴파일러 라인(llvm-project): A100 시리즈 병합, 매일 밤 재구성, AME 노선 수렴

  • A100 시리즈(10-03 병합): #30 「Lower IME intrinsics to SpacemiT A100 dot instructions」— IME intrinsics를 SpacemiT A100의 점곱 명령어로 낮춥니다. #32 「Add A100 pack/unpack intrinsic lowering and scheduling」, #31 「Add A100 HP/SP and pack/unpack lowering with calibrated scheduling」— 세 건이 하루 만에 연이어 병합되어 A100 플랫폼의 LLVM 측 명령어 lowering 및 스케줄링 기반을 구성했습니다.

  • 매일 밤 재구성(10-01 ~ 10-07 매일 밤): riscv 브랜치는 휴일 기간에도 매일 밤(베이징 시간 새벽) 재구성 리듬을 유지했습니다. 10-03 밤부터 A100 시리즈 변경이 포함되었고, 모니터링 기간의 마지막 재구성은 동기화 지점을 기간 말 업스트림 커밋(헤드 03e4e494)까지 전진시켰으며, 심사 중인 PR 3건의 상태도 이에 따라 갱신되었습니다.

  • AME 노선 변화: 표준 AME(RVI, 사전 승인 단계) 백엔드 PR #22가 10-02에 닫혔습니다(병합되지 않음, 개설 이후 7건의 논의). BOSC AME 스캔 라인(#29 및 이전 시리즈)과 FPGA 두 건(#25 / #28)이 현재 저장소에서 활성 경로입니다.

triton-riscv: 주간 빌드 리듬 유지, 신규 최적화 PR 개설

  • Nightly 2026-10-04-12c2f6a(10-05 릴리스): 주 1회 빌드 리듬을 유지했습니다(이전 회차 09-27). wheel은 CPython 3.12부터 3.14까지, x86_64와 riscv64 듀얼 아키텍처를 지원합니다.

  • PR #85 「softmax 및 matmul 최적화」: 10-08 아침 커뮤니티 기여자가 개설했습니다(심사 중). 이전에 renovate 의존성 PR #84가 열린 상태로 유지되고 있습니다.

  • 메인 브랜치의 최근 커밋은 여전히 09-14에 멈춰 있습니다(휴일 기간 기능성 커밋 없음).

TileLang 및 기타 대상 저장소: 전 기간 침묵

  • tilelang-riscv(최근 커밋 07-16), FBGEMM(07-13), cpuinfo(05-20), torq-tile(04-09), dsh-osc(09-15), pytorch-ci(커밋 기록 없음)는 휴일 기간 모두 움직임이 없었습니다. mxnet과 caffe 두 저장소는 커밋이 없습니다(이전에 개설된 PR 대기열은 기간 내 업데이트가 없었음).
