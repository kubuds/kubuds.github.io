一、开源社区与软件生态

1.1 NVIDIA 公布 CUDA 移植 RISC-V 主机 CPU 的明确要求，SiFive 合作演示在即

日期：2026-08-23（Hot Chips 2026 教程演讲）/ 09-01（ServeTheHome 与 Chips and Cheese 深度报道）　来源：ServeTheHome、Chips and Cheese（Chester Lam）、Hot Chips 2026 议程（NVIDIA 官方）

NVIDIA 在 Hot Chips 2026（斯坦福，08-23 至 08-25）周日的教程场次上，由 Frans Sijstermans 做了题为 “RISC-V Profile and Platform for Interoperability With NVIDIA GPUs” 的演讲，系统公开了把 CUDA 扩展到 RISC-V 主机 CPU 的路线与要求清单。要点：

  • CUDA 现状：自 2006 年以来的并行计算平台，主机侧目前仅支持 x86-64 与 aarch64；应用在 CPU 与 GPU 模块间切分，主机软件栈复杂且异构。
  • 对 RISC-V 主机 CPU 的硬性要求：RVA23 profile；遵循 RISC-V server SoC 与 server platform 规范（含 RAS、专用安全处理器等基线）；ACPI（UEFI Forum 2025-05 在 ACPI 6.6 中加入 RISC-V，RISC-V BRS 引导与运行时服务规范 2025-08 落地）；PCIe 硬件级 I/O 一致性；PCIe peer-to-peer 通信。NVIDIA 强调软件二进制兼容是核心目标，避免”最低公分母”问题（以向量扩展的谓词支持为例）。
  • NVLink Fusion 侧：自定义 CPU（可以是 RISC-V）经 NVLink C2C（约 88 条 PCIe lane、CHI 一致性）接入 NVIDIA AI 平台，额外要求 DOCA、NCCL 软件栈与 NVIDIA 深度合作。SiFive 被点名是 RISC-V 侧 NVLink Fusion CPU 合作伙伴，并计划在 Hot Chips 现场演示一台运行 CUDA 的高核数服务器系统。
  • 点评：ServeTheHome 认为 RISC-V 正成为服务器 CPU 市场 x86、Arm 之外真正的第三选项，但距大规模部署仍约两代；Chips and Cheese 则提醒，现有 RISC-V 消费级硬件几乎全部不满足要求（ACPI 是最大短板），短期内 CUDA on RISC-V 只会出现在企业级服务器平台。这是窗口内对 RISC-V 软件生态最具分量的商业背书信号。

1.2 ab-riscv-interpreter 0.2：通过 RISC-V ACT 认证测试的 Rust 编译期解释器

日期：2026-08-31（博客发布）/ 09-01（Hacker News 热帖）　来源：Project Abundance 博客、Hacker News、crates.io

Project Abundance 发布 ab-riscv-interpreter 与 ab-riscv-primitives 0.2 版本。特性：完全模块化与泛型化、panic-free、no_std 且零分配、可作 const fn 在编译期执行、严格按 RISC-V 规范实现（面向区块链用途）、通过 RISC-V Architectural Certification Tests（ACT）架构认证测试。解码器独立成 crate 可单独使用；指令执行代码由宏生成（单个实现展开约 1900 行）；性能 CoreMark 约 1600（紧凑 match 循环）/ 2950（indirect threading）。代价是依赖约 30 个 nightly Rust 特性（const 泛型、保证尾调用等）。作者称扩展可泛化到任意 RISC-V 类 ISA（如 Parity 的 PolkaVM）。面向区块链/形式化验证场景的 RISC-V 软件栈又添一个严格实现选项。

1.3 Raven-RiscV：RV32IMF 汇编学习模拟器与 IDE 获社区关注

日期：2026-09-02（窗口内 push）　来源：GitHub Gaok1/Raven-RiscV

Rust 编写的 RISC-V 教学模拟器 Raven-RiscV 在窗口内更新（09-02 00:01 UTC）并保持社区热度（111 stars）：支持 RV32IMF、逐步调试器、缓存与流水线可视化，定位是”学汇编的模拟器 + IDE”。仓库创建于 2025-03，近期因功能完善进入 RISC-V 主题仓库热门区间。教育类工具持续填补 RISC-V 汇编入门生态，与课程/竞赛场景契合。

二、产品与生态动态

2.1 高通 Dragonwing Q-2390 / IQ-2390：ARM 主核 + RISC-V 实时核运行 Zephyr

日期：2026-09-01　来源：CNX Software、Qualcomm 新闻稿

高通发布 Dragonwing Q2 系列 AIoT 处理器：Q-2390（商用/消费：零售、智能家居、智能显示、企业边缘设备）与 IQ-2390（工业：工业自动化、机器视觉、楼宇管理、能源系统）。主计算核为四核 Cortex-A78/A55（ARM），支持 Android、Yocto Linux、Ubuntu；部分型号带 RISC-V 实时核，该核支持 Zephyr RTOS。SoM 将在 IFA 2026 展示，评估套件预计 2027 年 Q1 提供。这是高通 AIoT 产品线延续”ARM 应用核 + RISC-V 实时/管理协核”组合的又一实例，RISC-V 在边缘设备中的角色继续坐实；但需注意主计算仍由 ARM 承担。

2.2 兆易创新与 Rutronik 签约：GD32（含 RISC-V 架构 MCU）拓展 EMEA 与东南亚分销

日期：2026-08-31（公告）/ 09-01（Evertiq、Bisinfotech 报道）　来源：GigaDevice 官网新闻、Evertiq、Bisinfotech

兆易创新（GigaDevice）与德国老牌分销商 Rutronik Elektronische Bauelemente 达成战略特许（franchise）合作，覆盖 EMEA 与东南亚（含印度）。合作核心是 GD32 系列微控制器——官方明确该产品家族基于 Arm Cortex-M 与 RISC-V 双架构，涵盖入门级到高性能实时应用。目标市场：工业、汽车、能源、通信、消费电子与 IoT。Rutronik 2025 财年营收约 10 亿欧元、服务超 4 万客户、全球 80+ 办公室，是兆易创新海外渠道的重要补充。国产 RISC-V MCU 借助欧洲分销体系出海的又一步。

窗口内进迭时空（spacemit-com）三个仓库有实质更新：

五、总结与趋势观察

  1. CUDA 官方路线图指向 RISC-V 主机 CPU：NVIDIA 在 Hot Chips 2026 首次公开移植要求清单（RVA23、服务器 SoC/平台规范、ACPI、PCIe 一致性、P2P），并点名 SiFive 为 NVLink Fusion 的 RISC-V 合作方、计划现场演示跑 CUDA 的系统。这是 RISC-V 服务器生态迄今最强的商业背书之一；但 ACPI 等硬门槛意味着达标硬件仍需数年，短期只会在企业级服务器出现。
  2. RISC-V 实时核继续渗透主流 AIoT SoC：高通 Dragonwing Q2 系列”ARM 应用核 + RISC-V 实时核（Zephyr）”再证这一组合已成为边缘 AI 芯片主流做法。
  3. 国产 RISC-V MCU 出海渠道加码：兆易创新 GD32（含 RISC-V 架构）借 Rutronik 渠道拓展 EMEA 与东南亚，覆盖工业/汽车/能源等市场。
  4. 国内团队处常规迭代期：进迭 K3 UEFI 固件获外部贡献者修复、P3 数据手册上线、AI 文档英文化是窗口内最实质进展；算能、矽速为维护性提交；七家核查组织中无发布级新品。
  5. 开源工具链纵深拓宽：Rust 编译期 RISC-V 解释器通过 ACT 认证测试、RV32IMF 教学模拟器获星，教育与验证类软件生态继续补位。
  6. 局限说明：Google News 中文源对国内团队零命中，国内部分依赖 GitHub 提交核查；Qualcomm 型号级 RISC-V 实时核细节以 CNX 转述为准；Hot Chips 演讲于 08-23 举行，本期为深度报道补录（ServeTheHome 09-01 发文）。
