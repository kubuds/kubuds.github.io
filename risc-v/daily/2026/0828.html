一、开源社区与软件生态

1.1 RISC-V International 批量发布 World RISC-V Days 2026 全球活动回顾

日期：2026-08-28（北京时间，UTC 08-27 18:32）　来源：riscv.org 博客（都灵）、格拉茨、特拉维夫、波士顿 等

RISC-V International 于窗口内一次性发布 10 篇 World RISC-V Days 2026 活动回顾报告，覆盖意大利都灵、奥地利格拉茨、以色列特拉维夫、美国波士顿、印度古吉拉特、肯尼亚内罗毕、阿根廷布宜诺斯艾利斯、孟加拉（Mymensingh、Dhaka）与希腊伊拉克利翁等全球 10 城。要点：都灵站（2 月 26 日，都灵理工大学，225 余名注册参会者）聚焦基准对比、全开源芯片开发与 FLOW PPU 等新兴技术；格拉茨站（2 月 24 日，格拉茨工业大学，近 100 人）覆盖 CHERI 安全、可重构可扩展 SoC、硬件加速器、CPU 设计与基准测试，并讨论 NXP 的 RISC-V 参与及欧洲 RISC-V 未来；波士顿站（2 月 27 日，Red Hat）在暴风雪中举办，包含 Fedora 与 AI 实操体验。该批回顾表明 RISC-V 社区日活动已形成覆盖六大洲的常态化布局。

二、产品与生态动态

2.1 USB-C Deskradar：基于 ESP32-C3（RISC-V）的开源 ADS-B 飞行追踪器

日期：2026-08-27　来源：CNX Software

CNX Software 报道开源项目 USB-C Deskradar：基于乐鑫 ESP32-C3FH4（单核 32 位 RISC-V，最高 160 MHz，400KB SRAM、4MB Flash）的桌面 ADS-B 飞行追踪器，1.28 英寸 240×240 圆形 TFT 屏以声呐式雷达界面实时显示周边航班（航向、速度、呼号、高度、机型），数据来自 adsb.fi 或 OpenSky Network 开放 API，支持 Wi-Fi 配网门户、机场跑道图层与 3D 打印外壳（STL 开源）。项目已在 GitHub 开源（arvis91/deskradar、MatixYo/ESP32-Plane-Radar），并被中国商家搬上 AliExpress 成廉价桌面小设备。属创客硬件与 RISC-V MCU 应用案例，体现 RISC-V 在低成本物联网终端的渗透。

三、国内团队动态与深挖

3.1 算能：CV84X6 官方规格落地，工具链密集合入

日期：2026-08-27　来源：sophgo/sophon-tools、sophgo/sophon-demo

算能 sophon-tools 窗口内合入约 15 笔提交，核心事件为 CV84X6 官方规格落地（PR #152，bmssm 2.3.4 / sophliteos 2.2.3）：算力规格 64T/32/2、显示名定为 CV84X6、CPU 规格主频按官方规格表由 2.5GHz 修正为 2.6GHz（v2.2.4）。结合昨日日报报道的 CV84X2 大规模适配（get_info v1.5 补齐 19 项指标等），可确认 CV84X 家族存在多款型号，官方规格正陆续固化进工具链。同期配套：CV84X2 适配工具版本号补齐、版本号单一权威化改造（根 release 禁止传版本号）、bmssm 新增 Prometheus 指标转发（默认关闭、token 鉴权，v2.2.2）、reasonix 嵌入前自动 strip 去 debug 信息并默认内嵌 deb 包、sophliteos agent WebSocket 改同源寻址；sophon-demo 新增 ResNet 示例适配 BM1684X2（SE13-64 单板）。算能正为 CV84X 系列新品铺平监控运维与示例软件栈。

3.2 香山：66 笔提交，微架构性能优化与验证分析并行

日期：2026-08-27　来源：OpenXiangShan org 提交检索

OpenXiangShan 窗口内约 66 笔提交，性能优化与验证分析两条线并行。优化侧：新增 RVV 字符串微基准（rvv-string-bench #85）；IFU/ICache 指令对齐路径优化（#6220）；MMU 对齐 CSR 变更引发的 TLB flush 延迟（#6421）；cpu-o3 避免冗余 ROB 扫描与 FTQ 拷贝（#1067）；fcmp 将 FLTQ/FLEQ 按 quiet 比较处理（qNaN 不置 NV）；codegen 对单维数组赋值生成块拷贝（#125）。验证分析侧：dcache bank 冲突分析场景与代码落地、4636 号分析收尾、difftest 补齐 XSTileDiffTop/NoCDiffTop 的 KMHV3、csrc 改为从 Opcodes.scala 生成 C++ 操作码编码、NEMU 引用与 ready-to-run 同步更新、nix 依赖例行升级。延续”研究分析沉淀 + 微架构打磨”型活跃节奏，未出现新架构级改动。

3.3 进迭时空：K3 AVL 文档化与 RL 基准工具打磨

日期：2026-08-27　来源：spacemit-com/docs-chip、spacemit-com/model_zoo_rl、spacemit-com/ai-sdk

进迭时空窗口内 4 笔提交：docs-chip 仓库重构硬件资源文档结构，新增 K3 AVL（Allowable Voltage Limits，电压裕量）文档并标准化 AVL 术语；model_zoo_rl 修复强化学习基准计时不真实的问题（#9）；ai-sdk 同步更新 rl 子模块。结合昨日 K3 BSP v1.0.7 的 OPP 表 efuse 校准优化，AVL 文档化是 K3 功耗电压管理配套工作的一部分。当日动态量小，属文档与工具链持续打磨。

四、具身智能与机器人专章

4.1 MIPS 成为 RISC-V International 顶级会员，领衔物理 AI 开放标准

日期：2026-08-27　来源：Business Wire（Yahoo Finance 转载）

MIPS（现为 GlobalFoundries 旗下 “MIPS, by GF”）宣布晋升为 RISC-V International Premier Member（顶级会员），其 SVP 兼 CTO Yankin Tanurhan 出任 RISC-V International 董事会副主席。公司将在航空航天、AI、汽车、工业与智能边缘等物理 AI 平台的开放标准与半导体技术中发挥牵头作用；MIPS 目前活跃于 Automotive、Functional Safety、Crypto、Vector、Documentation 等多个 SIG 与工作组，将 RISC-V 标准工作与其差异化微架构、定制硅方案对接。RISC-V International CEO Andrea Gallo 表示欢迎其在高吞吐实时平台上的持续贡献。该事件将”物理 AI 开放标准”与 RISC-V 治理层直接绑定，是本窗口具身智能方向最重要的生态信号。

本窗口（08-27 08:18 ~ 08-28 08:18）其余具身智能方向无新增硬件/产品事件：2026 世界机器人大会（8 月 19 至 24 日）闭幕后的媒体消化期延续，昨日日报已覆盖天工 Omni 双冠与上半年人形机器人出货报告；8 月 27 日 MERICS 发布中国主题分析”人形机器人 + 脱碳 + 平台经济”（政策视角，未涉及 RISC-V，仅作产业背景参考，不收录正文）。

五、总结与趋势观察

  1. 本窗口为”组织治理 + 国内团队交付”型行情：国际侧最大事件是 MIPS 晋升 RISC-V International 顶级会员并出任董事会副主席，把物理 AI 开放标准议程抬上治理层；社区侧 RISC-V International 批量发布 10 城 World RISC-V Days 回顾，印证社区日活动的全球化常态。
  2. 算能 CV84X6 官方规格落地（64T/32/2 算力、2.6GHz CPU）与昨日 CV84X2 适配报道衔接，CV84X 家族产品轮廓逐步清晰；配套 Prometheus 指标转发、reasonix 去 debug、版本单一权威化等运维工程化动作表明新品已进入量产前工具链收尾阶段。
  3. 香山以 66 笔提交保持高活跃，方向从验证分析转向”验证分析 + 微架构性能优化”并重（TLB flush 延迟、IFU/ICache 对齐、cpu-o3 冗余扫描、RVV 字符串基准），研究向工程收敛的信号明显。
  4. 进迭时空当日为文档打磨日（K3 AVL 文档化），结合昨日 BSP v1.0.7 发布，整体处于月度迭代节奏中的平静段。
  5. 局限性说明：本窗口 gnews 中文团队查询（平头哥/香山/芯来/算能/奕斯伟）全部为空或为噪音（香山命中均为北京香山论坛，与香山处理器无关），国内团队信息以 GitHub 提交为准；futu 一篇英文标题将 301536（星宸科技 SigmaStar）误标为 “StarFive Technology”，经东方财富数据页核验剔除，未收录。
