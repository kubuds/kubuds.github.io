一、开源社区与软件生态

1.1 Linux 7.3-rc1 发布：RISC-V 中断控制器代码重构入通用 ACPI IRQ 框架

日期：2026-08-31　来源：9to5Linux、LKML（Linus 发布邮件）、Phoronix：Linux 7.3 新增多个新 RISC-V 扩展、Phoronix：KVM Chainsaw 清理合入

Linus Torvalds 于 08-30（北京时间 08-31 凌晨）发布 Linux 7.3 首个候选版 7.3-rc1，为期两周的合并窗口正式关闭。Linus 表示本次 rc1”提交数规模名列前茅”，主要驱动是 AMD DCN6 寄存器头文件的大批量更新。与 RISC-V 直接相关的变化：irqchip/ACPI 代码重构将 RISC-V 中断控制器管理代码抽取出通用部分并入公共 ACPI IRQ 代码，以支持 ARM 侧 GICv5 IWB 的 ACPI 探测顺序（该重构亦为 RISC-V 后续 ACPI 中断支持铺路）；合并窗口期间已合入对若干较新 RISC-V 扩展的支持（Phoronix 08-24 报道）。KVM 侧本周期以修复与清理为主：”KVM Chainsaw”（拆分 kvm_mmu 巨型数据结构）合并落地，AMD SEV/SEV-ES 的 ENCRYPT/DECRYPT 改为整页分配以修复 PSP 固件页指派导致的数据损坏问题，SEV-SNP population ioctl 加固。按每周日 rc 节奏，Linux 7.3 正式版预计 10 月 18 日或 25 日发布。该条目为窗口内内核侧最重要事件。

1.2 openKylin 3.0 正式发布：四大架构同源，RISC-V 适配最广、支持 RVA23 与 RVV 优化

日期：2026-08-28/29　来源：CSDN/开放原子、凤凰网科技、新浪科技/IT之家

开放原子 openKylin 3.0 于 08-28 正式发布。内核从 Linux 6.6 跨代升级至 7.0，GCC 15、glibc 2.42、LLVM 22、JDK 25 等 180 余个核心组件同步迭代。与 RISC-V 生态最相关的三点：（1）同源支持 x86、ARM、RISC-V、LoongArch 四大架构，官方称 openKylin 是”RISC-V 架构适配最广、成熟度最高的操作系统之一”，已支持最新 RVA23 标准，各架构硬件兼容清单在 Gitee 发布；（2）RISC-V 平台上 AI 推理经 RVV 指令优化，FP32 场景提速 2 至 5 倍、FP16 场景最高 36.5 倍；（3）场景覆盖延伸至”灵龙”人形机器人、AI 无人小车、AI 机械臂等具身智能适配与多架构工业硬件平台。安全侧集成 NIST 三大后量子密码标准（ML-KEM/ML-DSA/SLH-DSA）并经 openHiTLS 提供系统级调用，支持 Rust For Linux 内核驱动开发。智能体侧构建开放底座：KylinBot 与 OpenClaw 等主流智能体经 MCP 协议直调桌面能力。作为 RISC-V 软件生态的国产 OS 关键一环，openKylin 3.0 的 RVA23/RVV 适配进度值得持续跟踪。

1.3 开源项目两则：ClickDOOM 用 ClickHouse SQL 模拟 RISC-V 跑 1993 DOOM；LabWired Core 固件确定性模拟器

日期：2026-08-31　来源：MarcusKainth/ClickDOOM、w1ne/labwired-core

两个新晋活跃开源项目（窗口内由 GitHub API 检出）：ClickDOOM 将 1993 年 id Software 的 DOOM 引擎 C 源码经 doomgeneric 移植层原样编译为裸机 RV32IM 二进制，再逐指令跑在”完全由 ClickHouse SQL 实现的 RISC-V CPU 模拟器”上（fetch/decode/execute、寄存器、RAM、MMIO 全在 SQL 内），demo3 第 220 帧在 2.2 亿条指令后与参考模拟器输出哈希一致，验证了模拟正确性；其前身为 Click-V（SQL 内 RISC-V CPU），Apache-2.0/GPL-2.0 双许可，属”把严肃 ISA 模拟玩成 SQL 极限挑战”的趣味硬核项目。LabWired Core 是 Rust 编写的固件模拟器：加载固件 ELF 后在建模的芯片（CPU、总线、外设、传感器）上确定性执行，同一 ELF + 板卡清单在任何机器产生相同 trace，可作 CI 门禁（pass/fail 退出码），支持 ARM Cortex-M 与 RISC-V，61 stars。二者共同体现 RISC-V 工具链/模拟生态在”仿真即测试”方向上的活跃度。

二、产品与生态动态

2.1 XCENA MX1：Hot Chips 2026 详解数千 RISC-V 核的 CXL 计算存储器件

日期：2026-08-26（Hot Chips 演讲）/08-28（报道）　来源：HPCwire、ServeTheHome、StorageNewsletter

XCENA 在 Hot Chips 2026 Memory 分会场（08-26，与三星联合演讲）详解其 CXL Type 3 计算存储器件 MX1 架构与实测性能：3072 颗定制 1.4GHz RISC-V 核组成 Memory Acceleration Unit 就近执行访存密集型负载；四条 DDR5-8400 通道最高扩展 2TB 内存，SSD 经根端口以字节寻址 CXL 内存形态呈现；集成向量引擎提供约 3 TFLOPS FP32/FP16 点积吞吐（面向向量检索、KV-cache 评分）。开发者以标准 C/C++ 或 Rust 编程，经 LLVM 工具链 + PXL 运行时（共享虚拟地址空间）调度数千核。实测相对宿主机 CPU 经 CXL 访问：单 MX1 吞吐最高 4.7 倍、能效 18.7 倍；相对本地 DDR5：吞吐 2.0 倍、能效 6.2 倍。该器件是”RISC-V 大规模近存计算 + CXL 内存池化”路线的代表，与三星机架级 CXL 内存方案搭配，值得关注其对 AI 内存墙叙事的实际影响。

2.2 印度 Aheesa Vihaan 一版流片点亮：64 位 RISC-V 网络 SoC 通过首轮硬件验证

日期：2026-08-30　来源：SDxCentral、The Hans India、Aheesa 官网

金奈初创 Aheesa Digital Innovations 宣布其 Vihaan 系列一版流片（first-pass silicon）成功，首轮硬件验证确认了性能指标。Vihaan 是 64 位 RISC-V 驱动的网络 SoC，面向宽带接入场景：高性能路由器、托管交换机与统一威胁管理（UTM）设备；另有边缘版本面向 IoT 网关与工业自动化（本地低延迟处理）。该公司 2021 年成立，高管来自 Wipro、Microchip、AMI，CEO Sridharan Mani 曾任亚马逊高级软件开发经理；受印度电子与信息技术部（MeitY）设计关联激励（DLI）计划资助，融资约 419 万美元（含泰米尔纳德邦基础设施基金 TNIFMC）。节奏：2026 年 1 月首轮流片，量产流片目标 2027 年。MeitY 声明称其进展”表明印度半导体设计正走出实验室”。这是印度 RISC-V 主权芯片路线（继 IIT Madras 系 Shakti 之后）在商用网络硅片方向上的标志性进展。

2.3 Radxa Linkr 生态参考：U 盘大小 IP KVM，主控含 RISC-V 协处理器

日期：2026-08-30　来源：CNX Software、Radxa 产品页

CNX Software 拆解评测 Radxa 新品 Linkr：U 盘大小的 IP KVM（70×22×12mm），经 HDMI 采集目标机画面 + USB 模拟键鼠，支持 USB-C 直连、以太网与 Wi-Fi 6（AIC8800）远程控制，浏览器即可操作，免装 App，支持 Tailscale VPN、双因素认证及 OpenClaw/Hermes 等 AI agent 接管。主控为 Rockchip RV1106G3（Arm Cortex-A7 @1.2GHz + 集成 RISC-V 协处理器），1 TOPS NPU，256MB 片上内存 + 可选 16GB eMMC。与 RISC-V 的关联点：RV1106 内嵌 RISC-V 协处理器（同类产品 JetKVM 亦采用），且 Radxa 本身是 RISC-V 单板主力厂商；但 Linkr 主算力侧仍为 Arm，属生态参考条目而非 RISC-V 原生产品。售价 59 美元起，四渠道暂缺货。

三、国内团队动态与深挖

3.1 国内团队 GitHub 动态核查：窗口内整体平静，仅算能/进迭有小步迭代

日期：2026-08-30/31　来源：sophgo/sophon-tools、spacemit-com/openocd、GitHub orgs API（XUANTIE-RV/sophgo/Nuclei-Software/spacemit-com/eswincomputing/revyos/sipeed）

对七家国内团队的 GitHub 组织活跃度做窗口核查（orgs repos API pushed_at 过滤）：平头哥（XUANTIE-RV，72 仓库）、芯来（Nuclei-Software，42 仓库）、奕斯伟计算（eswincomputing，16 仓库）、矽速（sipeed）窗口内均无 push，整体处于发布后平静期；算能（sophgo）仅 sophon-tools 一笔 push（08-30 上午，即昨日已报发版前安全加固批次的合入落定）；进迭时空（spacemit-com）两笔 push 分别为 docs-chip（昨日已报 P3 PMIC 文档）与 openocd 仓库（上游镜像只读同步，无自主开发）；Revyos 组织 7 仓库 push 均为 SG204x 固件链同步（fsbl.bin/EDK2 交叉编译器，昨日已报）。结论：国内团队窗口内无架构级或产品级新动态，符合大版本发布后的常规平静期特征；下一关注窗口为各团队 9 月发布节奏（算能 CV84X 量产配套、芯来挂牌后首轮动作、香山 KunminghuV2 后续）。

四、具身智能与机器人专章

4.1 窗口内无 RISC-V 具身智能硬件新品；软件侧 openKylin 3.0 完成人形机器人等适配

日期：2026-08-31　来源：本期各条目汇总（详见附录）

本窗口未发现新的 RISC-V 具身智能硬件新品发布，格局延续近一周判断：RISC-V 在具身智能侧的进展集中于软件与平台适配层。本期最相关的信号来自 openKylin 3.0（见 1.2）：其场景覆盖明确纳入”灵龙”人形机器人、AI 无人小车、AI 机械臂等具身智能适配，并支持 RISC-V 等多架构工业硬件平台——即国产 OS 阵营正把 RISC-V 具身智能纳入默认适配矩阵；同时 RISC-V 上 RVV 优化的 AI 推理性能（FP16 最高 36.5 倍提速）为端侧模型部署提供了实测依据。此外 eeNews Europe 技术综述（08-25，生态参考）指出欧洲 EPAC 1.0 加速器以 RISC-V 控制核 + 领域 AI tile 实现 12 TOPS/W，印证开放 ISA 在机器人与自主系统的功耗约束下的适用性。硬件新品窗口建议关注 9 月国内机器人展会季与各家 SoC 的机器人 SKU 发布节奏。

五、总结与趋势观察

  1. 内核主线推进：Linux 7.3-rc1 发布，合并窗口合入多个新 RISC-V 扩展，RISC-V 中断控制器代码重构入通用 ACPI IRQ 框架，为 RISC-V ACPI 中断支持铺路；KVM 侧以 SEV 修复与 kvm_mmu 巨型结构拆分为主。
  2. 国产 OS 的 RISC-V 适配加速：openKylin 3.0 四大架构同源发布，自评”RISC-V 适配最广、成熟度最高”，RVA23 支持 + RVV 推理优化（FP16 最高 36.5 倍）+ 具身智能场景覆盖，软件栈就绪度持续提升。
  3. RISC-V 向数据中心纵深：XCENA MX1 以 3072 核 RISC-V 近存计算 + CXL 3.2 池化切入 AI 内存墙问题，实测吞吐/能效相对宿主 CPU 大幅领先（最高 4.7 倍/18.7 倍），与 SiFive BigSky 服务器交付（08-29 已报）形成互补。
  4. 全球主权芯片路线多点开花：印度 Aheesa Vihaan（DLI 计划资助）一版流片点亮，继 Shakti 之后在商用网络硅片方向落子，2027 年量产流片目标明确。
  5. 国内团队进入发布后平静期：七家主要组织 GitHub 窗口内无架构级动态，属大版本发布后常规节奏；下一观察点为 9 月各家发布窗口。
  6. 局限说明：Google News 中文源对国内团队直采有限（平头哥/香山等词条被同名噪音污染），国内部分依赖 GitHub 提交核查；Radxa Linkr 主控为 Arm + RISC-V 协处理器，收录为生态参考；gnews 跳转页不可直读，正文均以原站为准。
