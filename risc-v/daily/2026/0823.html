一、开源社区与软件生态

1.1 乐鑫发布 ESP32-S31 Linux BSP 开发者预览版：带 MMU 的 RISC-V 微处理器正式支持 Linux（08-22）

日期：2026-08-22（CNX Software 报道 12:26 北京；HN 讨论 20:50 北京）　来源：CNX Software、HN 讨论帖、espressif/esp-linux-bsp

乐鑫正式发布 ESP32-S31 官方 Linux BSP 开发者预览版，这是 ESP32 家族首个官方支持 Linux 的 RISC-V 产品线：ESP32-S31 为双核 RISC-V 微处理器（集成 MMU 内存管理单元），3 月首次亮相、5 月推出两款开发板、数周前刚宣布量产；开发板带 16MB PSRAM，可承载最小 Linux 镜像。要点：

  • 官方 BSP 构成（三仓库分工）：esp-linux-bsp（镜像布局与打包工具，integration/v1.0-esp32s31 分支）＋ esp-buildroot-external（Buildroot 2025.02 的 NOR 启动栈与根文件系统，含构建烧录指引）＋ espressif/linux（Linux 6.18 内核 fork，integration/v6.18-esp32s31 分支）；Buildroot 打包把 U-Boot SPL、FIT、设备树、XIP 内核与 cramfs rootfs 合并为单文件 s31_full_flash.bin，esptool >= 5.3.0 直刷即可启动 Linux console（115200 波特）；
  • 发布状态：开发者预览、不推荐生产使用——官方明示”无固定更新节奏、可能随时破坏性变更、功能接受有限、bug 按尽力而为修复”，仅面向早期采用者做技术验证与反馈收集；已实现功能边界（如 WiFi 是否可用）尚未完全明确；
  • 社区移植同步活跃：GrieferPig 的 esp32-s31-linux 把 MMU RV32 Linux 6.12 原生跑在 ESP32-S31 上（Buildroot rootfs 与 reboot 稳定，poweroff 未实现，WiFi/蓝牙双模/双核尚为实验性）；Marco（annoyedmilk）的移植则带来 Linux 7.1 + OpenSBI 1.9（LCD/微 SD/USB host/WLAN 之外的外设未启用）。

意义：乐鑫此前以 ESP-IDF/RTOS 生态著称，Linux BSP 使”带 MMU 的 RISC-V 微处理器”以官方渠道进入 Linux 世界，叠加量产后价格优势，有望把完整 Linux 开发体验下放到数十美元级嵌入式器件——与香山/进迭等高性能路线互补，构成”RISC-V 向低端渗透 Linux”的另一极。

五、总结与趋势观察

  1. “Linux 下放到 MCU 级 RISC-V”官方化：乐鑫 ESP32-S31 发布 Linux BSP 开发者预览（Linux 6.18 fork + Buildroot 2025.02 集成），带 MMU 的 RISC-V 微处理器以官方渠道进入 Linux 生态，叠加量产与价格优势，与高性能路线（香山/进迭/赛昉）互补，构成 RISC-V 生态”高端追性能、低端扩应用”的双向渗透；
  2. 社区移植与官方并行：官方 BSP 之外，GrieferPig（Linux 6.12 MMU RV32）与 Marco（Linux 7.1 + OpenSBI 1.9）两个社区移植已在 Korvo-1 板上跑通——乐鑫器件的社区活跃度是 ESP32 生态传统优势，Linux 化后延续；
  3. 国内团队节奏继续分化：乐鑫（Linux BSP 三仓库、活跃）、香山（5 笔例行）、算能（agent 工具链发版）有动作；进迭时空 0 笔（昨日 YOLO26 后休整）、平头哥/芯来/奕斯伟/赛昉静默；
  4. 产品线平静：窗口内无新产品发布，KEO / K230 为昨日事件转载；ESP32-S31 量产节奏与 Linux 侧 WiFi/蓝牙支持进度是后续观察点；
  5. 平静日说明：gnews 英文窗口内新增仅 ESP32-S31 一条；厂商英文查询（SiFive/Milk-V/SpacemiT/SOPHGO/StarFive/Andes）全部命中旧闻或噪音；中文区域查询窗口内为空，国内动态以 GitHub 组织检索捕捉（见附录核查表）。

局限性说明：ESP32-S31 Linux BSP 处于开发者预览阶段，已实现功能边界（WiFi/蓝牙在 Linux 侧的状态）官方未完整披露，本文以 CNX Software 实测与仓库 README 为准；社区移植项目（GrieferPig/Marco）状态以各自 GitHub 仓库声明为准，属非官方支持；香山/算能提交按 committer 时间归类，个别提交的 author 日期可能早于窗口。
