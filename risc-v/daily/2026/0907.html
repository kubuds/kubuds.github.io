二、产品与生态动态

2.1 OrcSDR：基于 ESP32-P4（RISC-V）的掌上全功能 SDR 开源项目（09-06）

日期：2026-09-06　来源：Notebookcheck、OrcSDR GitHub 仓库

开源项目 OrcSDR 将 M5Stack Tab5（5 英寸手持平板，搭载双核 RISC-V 的乐鑫 ESP32-P4）与廉价 RTL-SDR USB 接收棒组合，构成无需 PC 的掌上软件无线电设备：ESP32 承担原始射频流处理、音频解调与触摸屏频谱/瀑布图实时渲染。实测场景包括 ADS-B 空中应答机实时跟踪、Meshtastic/LoRa 离网覆盖核查、2.4GHz Wi-Fi 信道拥塞审计与 P25 数字应急通信解调，经 M5Burner 浏览器工具一键烧录预编译镜像即可部署。报道称其填补了数十美元电脑电视棒与 650 美元商用数字扫描器（如 Uniden SDS100）之间的价位空档，面向现场运维、搜救与无线电爱好者。该项目是 RISC-V 应用处理器在实时信号处理场景的又一落地案例，也延续了 ESP32-P4 作为”无 Linux 也能干重活”的高性能 MCU 类处理器的生态叙事。
