FlagOS周报（2026-09-21 ~ 2026-09-25）

2026-09-25 苦芽科技

报告周期：2026 年 9 月 21 日（周一）至 9 月 25 日（周五），共 5 个工作日 素材来源：本刊每日 FlagOS 动态报告（09-21、09-22、09-23、09-24、09-25 五期，窗口逐日衔接、无空档）；全部条目来自当期已核验信源，编制时另经 GitHub 复核补充 编制说明：本周为 FlagOS 2.2 GA（09-28）前的最后一个完整工作周，主线是发布收口——「标签、清单、范围」三层校验相继完成；同时覆盖组件与代码共建、新芯片伙伴接入、成员单位与生态四个维度。五期日报窗口提交命中合计 916 条（163 / 224 / 143 / 211 / 175），各期活跃仓库 22 / 19 / 24 / 23 / 24 个，合计覆盖 org 内约 30 个仓库

一、本周要闻

  • 2.2 发布物冻结：十组件正式版本标签批量落库（09-24）：09-24 凌晨 01:49 ~ 01:50，十个 L1 模块的正式版本标签（裸版本号、无 rc / post 后缀）一次性打出——flaggems v5.4.0、flagfft v0.2.0、flagsparse v0.3.0、flagdnn v0.3.0、flagblas v0.3.0、flagtensor v0.3.0、flagaudio v0.3.0、flagattention v0.4.0、flaggems-vllm v0.2.0、flaggems-sglang v0.1.0；每个标签打在对应模块 rc2 分支 HEAD 并逐条回读核对，配套 PR（community #114）把「官方标签 ← rc2 基线」映射补入官方清单，截至编制仍在审。
  • rc2 通道收口 + 范围审计启动（09-24）：community #113 把 rc2 清单 13 个模块统一 bump 到最新已验证 post 标签（flaggems rc2.post4 等），rc2 稳定期按排期 09-24 截止、之后仅接受 hotfix；同日 community #115 开出「2.2 FEP 范围审计」——18 项 Implemented FEP 保留、FEP 0019 / 0069 / 0081 / 0084 / 0093 / 0100 六项推迟至 2.3，保留项仅限「已实现的接口 + 已验证的配置」。发布校验从「代码冻结」「发布物冻结」推进到「范围与声明冻结」。
  • 发布信息门户重建、平台矩阵快速增密（09-22 ~ 09-25）：Release Info 门户 09-23 重建（20 平台行 base / runtime + vLLM 两套矩阵 + Megatron + sglang 应用镜像）；Megatron 应用镜像 2.2.0-0.2.3 覆盖 14 个平台行，megatron_rl 矩阵解除阻塞并开放全部 18 个后端；sglang 应用页单夜七连发（昆仑芯 / 昇腾 / 燧原 / 海光 / 摩尔线程 / 天数 / generic 七平台），达摩院玄铁 thead-ppu2.1.0 应用页同日进入门户。
  • 新芯片伙伴密集接入（09-24 ~ 09-25）：壁仞（Biren）SUPA 后端以「FlagGems 算子库 + vllm-plugin-FL 推理插件」双层同日进线（#6367 / #530）；曦望（Sunrise）把 PTPU 的 0.2.1 补丁集移植到 vLLM 0.24 主线（#555）；清微 FlagTree 平台标签齐备——「算子库 + 推理插件 + 编译器」三层同构接入成为外部芯片进入 FlagOS 的标准路径。
  • FlagFFT 补齐海光后端，单窗口 102 笔横跨三线（09-21 ~ 09-22）：海光 BW1000（HCU）适配器进入 dev，README 后端清单扩为 CUDA / MUSA / PPU / IX / MACA / NPU / HCU 七项；同窗口 MACA（沐曦）性能收口与 NPU（昇腾）Stockham 批次并行，打包三件套（#12 / #18 / #22）同步合入——新后端 + 性能收口 + 分发打包三件事同窗完成。
  • 达摩院玄铁双线推进：真武 V900 发布 + PPU 进入 FlagOS 矩阵（09-22 ~ 09-25）：云栖大会（09-22）发布新一代训推一体 AI 芯片真武 V900（216GB 显存、片间互联 1200GB/s、原生 FP8 / FP4、单芯性能为上代 M890 三倍、2027 年 Q1 量产）；软件侧 PPU 以真实身位进入构建与应用矩阵——FlagTree 0.7.0+ppu3.6 标签、sglang thead-ppu 应用页、TE-FL PPU CI；SAIL 软件栈宣布扩大开源、GitHub 开发分支将成为研发主线。
  • 910C 强化学习链路端到端就绪（09-24 ~ 09-25）：昇腾 910C 两种配置（CANN 9.0.0 + torch 2.10 / CANN 8.5.0 + torch 2.9）以单步安装完成 megatron-core[rl] GRPO 端到端验证（退出码 0），wheel 内置 packed_seq 门控等三项 RL 修复；配套解决 Ascend-Docker-Runtime 导致的 NPU 不可见问题——为 2.2 在 RL 场景的昇腾声明提供可复现证据链。
  • 产业与生态事件密集（09-21 ~ 09-25）：AICC2026 在京举行（FlagOS 两场报告、「可靠AI」测评体系 20 余家单位启动）；沐曦 MXMACA 以「上游优先」合入 LMCache 主线、官宣 39 个主流模型 Day 0 适配；摩尔线程 RLinf 官方 CI 接入 MTT S5000、Protenix-v2 全链路推理提速约 26%；龙芯发布加速计算平台首个版本；Open3D-PIMC 报道矩阵扩至新浪财经。
