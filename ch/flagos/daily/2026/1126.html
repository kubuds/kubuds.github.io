今日重点：Xing4.1-Preview 八芯 Day0 适配，英伟达平台每 Token 耗时最高降 20.9%（11-25）

日期：2026-11-25　来源：FlagOS 专栏。

  • 模型：中电信人工智能科技有限公司开源星辰大模型 Xing4.1-Preview。
  • 规格：总参数 285B，每 Token 激活约 17B，原生支持 1M 上下文。
  • 结构：45 层 Transformer 主干，其中 42 层为 MoE。
  • 路由：每 Token 从 256 个专家中选 8 个，另有 1 个共享专家。
  • 注意力：MLA 压缩 KV 表示，配合 DSA 稀疏注意力。
  • 适配范围：平头哥、英伟达、摩尔线程、昇腾、沐曦、海光、天数智芯、昆仑芯 8 家。
  • 交付物：W8A8 与 BF16 两套版本，已上架魔搭与 Hugging Face。
  • 评测口径：英伟达单机 8 卡、64 并发，基线为同精度原生方案。
  • 4K 输入：输出吞吐由 1862.10 升至 1988.23 tokens/s，提升 6.8%。
  • 4K 时延：平均每 Token 耗时由 30.23 降至 27.63 ms，降 8.6%。
  • 16K 输入：吞吐提升 4.1%，每 Token 耗时降 18.7%。
  • 32K 输入：吞吐提升 1.7%，每 Token 耗时降 20.9%。
  • 代价：三档输入的平均首 Token 时延分别增加 11.8%、21.5% 和 6.0%。
  • 精度：MATH-500、GPQA Diamond、MMLU 三项与英伟达原生对齐。
  • 国产平台：部分场景单位算力吞吐达到英伟达原生的七成以上，最高 181.5%。
  • 算子：4K 场景启用 54 个 FlagGems 算子。
  • 组件：部署链路使用 FlagGems、FlagTree 与 vLLM-plugin-FL。
  • 框架：英伟达、平头哥、沐曦、海光、天数智芯、昆仑芯采用 vLLM 0.24.0。
  • 框架续：昇腾与摩尔线程采用 SGLang 0.5.18。
  • 观察：这是 FlagOS 本周第一条带完整性能数据的 Day0 适配。
  • 观察续：国产平台的对比指标是单位算力吞吐，不是绝对吞吐。
