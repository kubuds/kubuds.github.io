今日重点：距 2.2 GA（09-28）4 天——官方清单开始收录 L1 算子库：十组件正式版本标签批量落库

日期：2026-09-24　来源：community #114、community #113、release-2.2-rc2.yaml、官方清单 release-2.2.yaml

rc2 稳定期进入最后一天（官方排期 09-24 截止、GA 定 09-28），发布工程在 09-24 凌晨完成两件事。

其一，官方发布清单开始收录 L1 算子库。09-24 01:49 ~ 01:50，十个 L1 模块的正式版本标签（裸版本号、无 rc / post 后缀）批量打出：

  • flaggems v5.4.0、flagfft v0.2.0、flagsparse v0.3.0、flagdnn v0.3.0、flagblas v0.3.0、flagtensor v0.3.0、flagaudio v0.3.0、flagattention v0.4.0、flaggems-vllm v0.2.0、flaggems-sglang v0.1.0。

每个正式标签都打在对应模块 rc2 分支 HEAD（即最新已验证 post 标签提交）上，且推送后已与远端逐条回读核对。配套 PR（community #114「add L1 operator libraries to the 2.2 official manifest」）于 01:51 开出：向官方清单 release-2.2/release-2.2.yaml 补入十条「官方标签 ← rc2 基线」映射（flaggems v5.4.0 ← post4；flagattention v0.4.0 ← post1；flaggems-vllm v0.2.0 ← post1；flaggems-sglang v0.1.0 ← post1；其余各条 ← post2），该 PR 仍在审（waiting merge）。官方清单此前仅有 sglang-plugin-fl v0.2.0 一条（09-22 落库），本 PR 是 L1 层的首批批量收录。

其二，rc2 通道以 13 模块 post 标签收口（09-24 00:42，community #113）：把 release-2.2-rc2.yaml 中 13 个模块版本字段统一 bump 到各自 rc2 分支 HEAD 的最新已验证标签——flaggems rc2.post4；flagfft / flagdnn / flagblas / flagtensor / flagaudio rc2.post2（内容为 Debian / RPM 打包与 Nexus 发布链、flagaudio 增益恒等修复）；flagtree 三线 0.7.0rc2.post2；vllm-plugin-fl 双线 post3；transformerengine-fl post2；flagscale post2。全部标签推送前均与远端核对。

同日范围侧另有一笔收缩记录：community #112（FEP-0085）指出 rc2 测试在 FlagCX 0.14.0-rc2 与 FlagTree 0.7.0-rc2-triton3.6 中均未发现 GEMM+ReduceScatter 的实现（参 FlagCX#620），经与开发线商定将该算子移出 2.2 范围，FEP 文档、测试计划与实现历史同步修订（该 PR 仍在审）。

判断：正式标签批量落库 + rc2 清单收口 + 范围收缩三件事在同一个窗口出现，说明 2.2 的发布面已从「代码冻结」转入「发布物冻结」——清单、标签、范围三者开始互为校验。接下来四天的观察点是 #114 的合并与 L2 / L3 批次（vllm-plugin-FL、TE-FL、FlagScale、KernelGen 等）的收录顺序。
