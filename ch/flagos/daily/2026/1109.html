3.1 平头哥（T-Head）：SDK 只随 PAI-DSW 镜像分发，FlagTune 代价模型已开（11-06）

日期：2026-11-06　来源：厂商文档 thead · FlagGems #6497 · FlagAttention #127

四、总结与趋势观察

  • 平台面从”有键”走到”可交付”：平头哥 ZW810E PPU 在两天内完成后端键、base 镜像、runtime changelog 与状态矩阵四处对齐，2.3.0 是该后端第一次有 runtime 交付。设备只在阿里云 PAI-DSW 镜像里可取、runner 无 GitHub 出口，这两条约束决定了它的交付形态与其他后端不同，短期内 app 层仍是空白。
  • 算子生产已进入批量节奏：单日 123 笔 FlagGems 合入、其中 87 个昇腾算子由一人一小时内落库，另有 20 个海光专用算子排队待审。KernelGen 把”写算子”变成了”审核生成结果”，瓶颈从实现转到评审与验收——这解释了为什么在审 PR 数（269 笔）持续高于合入数。
  • 分发层在收敛：TransformerEngine-FL 用一份纯 Python wheel 供给所有非 NVIDIA 厂商，FlagTree 的 deb 改为一后端一包、rpm 直接取已发布 wheel，两条动作指向同一目标——减少逐芯片重复构建，把差异留在配置里。
  • 框架适配呈波浪形：vLLM 0.32.0 与 SGLang 0.5.18 的适配在窗口内集中出现，覆盖平头哥、天数、MUSA、昆仑芯、昇腾五家，但绝大多数仍在审。能否在 11-30 的 rc0 前合入，是 2.3 能否按矩阵交付的关键变量。
  • 2.3 进入收口倒计时：社区 2.3 时间表为 FEP 合入截止 11-13、特性冻结与 rc0 11-30、rc1 12-07、rc2 12-14、代码锁 12-25、GA 12-30。本期无新 FEP 提交，11-06 那批六份（0164 至 0168、0170）仍为 Provisional Draft 且自述未跑 GPU 验收，收口压力集中在下周。
  • 风险与观察点：平头哥 app 层未接、海光 20 个算子全在审、天数四条 CI 三处在审、竞赛提交只入库未出成绩——四项都属于”已有动作、未到验收”，下周重点看合入率而非新增量。
