今日重点：智源与清昴智能联合发布 Token 工厂端到端方案，商用国产 Token 工厂按 FlagOS 上线（11-17~11-18）

日期：2026-11-17 ~ 2026-11-18　来源：雷峰网 · 环球网科技 · 投资家网

  • 事件：11 月 17 日，「国芯国模 自主生态」2026 清昴 AI 伙伴大会暨 Token 工厂年会上，北京智源人工智能研究院与清昴智能联合发布「国产 Token 工厂端到端推理优化方案」，基于众智 FlagOS 上线商用 Token 工厂。雷峰网在 11-18 13:31 刊出报道，环球网与投资家网同日跟进。
  • 生态口径：报道称 FlagOS 生态已汇聚 21 家芯片企业、86 家生态伙伴，覆盖 35 款 AI 芯片。9 大算子库累计沉淀 1454 个以上开源 Triton 算子，其中近八百个在至少 5 款国产芯片上达到原生算子 80% 以上性能。单个代码仓库覆盖 20 家厂商后端，过去半年多次做到新模型发布当天 12 款芯片跑通。
  • 昇腾 910C 的账：针对智谱 GLM-5.3 与 GLM-5.3-Flash，Prefill 侧在 81920 输入、16 并发下波次吞吐提升 3.41%，256K 输入下 TTFT p50 下降 4.94%。Decode 侧用 LI 量化写回把动态量化、尺度转换与 HBM 缓存写回合并进同一内核，910C 微基准从 18.03 微秒压到 2.04 微秒。端到端 ITL 下降超过 10%，TPOT 降低 8% 以上。
  • 存量 910B：BAAI Token Hub 把 48 张 910B 组成 Prefill 与 Decode 分离的集群，32 张卡分 4 个 Prefill 域、16 张卡分 8 个 Decode 域，跑 1M 上下文的 GLM-5.3-Flash 服务，已连续稳定两周，TTFT P50 约 2.3 秒、TPOT P50 为 22 毫秒。跨 Prefill 域的 Prefix Cache 复用把命中率从 82.65% 提到 94.15%，复用阶段首字时延中位数从 16.63 秒降到 3.10 秒。
  • 横向对比：平头哥 810E 上 FlagOS 2.2 让 DeepSeek-V4.1-Flash 提升 77% 至 82%，16 路并发可用、最高 80 并发，单请求解码 136.2 tok/s。海光 BW1100 上 GLM-5.3-Flash 提升 25% 以上，多并发下单路吞吐突破 80 TPS。
  • 口径提示：环球网版本另称 910C 上 GLM-5.3-Flash 整体输出从二十多 TPS 升到五十多 TPS，逻辑服务吞吐为优化前 2.04 倍，单位算力成本比商业 API 计费低 19.4% 至 27.6%，并称自动调优器把搜索效率提高 298 倍。这些数字出自厂商与媒体口径，未见第三方复现。

3.1 摩尔线程：Kimi K3.1 Pro 训练适配，双机 16 卡 400 步收敛（11-17~11-18）

日期：2026-11-17 ~ 2026-11-18　来源：第一财经 · 中国经营报转载 · 与非网技术稿

  • 事件：月之暗面开源 2.8 万亿参数的 Kimi K3.1 Pro 后，摩尔线程基于 MTT S5000 智算卡与 MUSA 软件栈完成训练适配。构建了原生 FSDP2 多模态训练路径，打通模型加载、分片调度到梯度同步的全链路。第一财经与每经在 11-17 晚间首发，中国经营报 11-18 补充技术细节。
  • 验证配置：裁剪训练方案为 13 层语言主干、16 专家（top-8 路由）与完整 27 层视觉塔，双机共 16 张 MTT S5000，用 MedPix-VQA 图文数据从随机初始化开训。16 个进程连续完成 400 次优化器更新，训练 Loss 从 8.9365 收敛到 2.1802，验证集 Loss 从 6.5297 降至 4.6873，显存峰值 44.80 GiB。
  • 工程要点：补齐新增算子的前向与梯度实现，把专家分发与归并接入统一计算图；并行上采用 FSDP2 与 EP 混合，配参数预取与梯度通信调度；损失侧用 Chunk Loss 分块（块长 256）控制大词表显存。
  • 口径边界：中国经营报明确指出训练适配不等于该模型在该芯片上预训练，二者需分开表述。摩尔线程此前已完成 021 科学基础模型（2360 亿参数）的从零训练，并联合智源完成具身大脑模型 RoboBrain 2.5 的全流程训练。
  • 观察：这条消息的技术含量在「训练适配」而非「推理可用」，且验证规模是裁剪配置。它说明国产卡在万亿级模型上的工程量在推进，但离完整规模预训练仍有距离。

3.2 沐曦与燧原：两条换线背后的芯片与 SDK 口径（11-18）

日期：2026-11-18　来源：base 层变更记录目录 · metax-maca3.10.1.11 · enflame-tops4.1.6

  • 芯片对应：沐曦新线对 C550，燧原两条线分别对紫霄 C200（S60）与 L600。此前燧原两条退役线在 11-17 已被换成成交接线，当日是新建线首次交付，属同一轮换代的收尾。
  • 驱动策略：沐曦把驱动做成仅用户态安装，容器内不装内核模块。这与 NVIDIA 的做法一致，好处是镜像可无卡构建，代价是宿主机驱动版本必须与镜像匹配。
  • SDK 组件面：燧原两条线的组件清单完全一致，说明两条线的差异只在芯片与栈版本，不在能力范围。Triton GCU 均为 1.0.20261116，即 11 月 16 日的构建。
  • 目录收敛：base 层与 runtime 层的 maca3.7.2.1 镜像目录已删除，只留历史变更记录；燧原旧线的目录同样不在树中。这种「删目录、留记录」的做法让构建矩阵保持干净，同时保住可追溯性。
  • 观察：底座层的换代口径是「一条线对应一张卡」。三家在同一天完成这件事，说明 2.3 周期的平台清单已基本定型，接下来是 rc0 前的验收。

四、总结

  • 底座层是当日主线：FlagOS 2.3 的 base 与 runtime 层一天内完成沐曦换线、燧原双线首交、摩尔线程旧线清退，二十笔合入没有一笔新功能。距 rc0 的 11-30 还有十二天，平台清单正在收敛。
  • 算子层在做两件事：FlagAttention 一次进四个注意力变体，FlagGems-vllm 把融合算子按后端逐个铺开。前者扩能力边界，后者补覆盖密度。
  • 编译器接口在换代：TLE pipeline 迭代器被移除，FlagGems、FlagGems-vllm、FlagAttention 三个库同一天改到 tl.range。这是一次跨仓库的接口对齐。
  • 量子线占比升高：FlagQuantum 与 FlagQAI 合计 34 笔，接近当日合入量的四分之一。纠错侧在工程化，研究侧在界面化。
  • 公开报道只有一条主线：智源与清昴智能的 Token 工厂方案是唯一有实质内容的产业新闻，其余为伙伴侧回顾与旧闻转载。组件级的版本消息仍只走 GitHub。
  • 待观察：摩尔线程旧线的 flagcx 行仍有一笔在审；海光 BW 上 FlagGems-vllm 0.2.0 基线启用时禁用一个用例；2.3 的 GA 定在 12-30，中途还有 rc0、rc1、rc2 三个节点。
