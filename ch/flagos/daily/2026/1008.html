今日重点：FlagQuantum 窗口 23 笔合入——分布式 MPS 训练升入发布认证（10-07 ~ 10-08）

日期：2026-10-07 ~ 2026-10-08　来源：FlagQuantum #587、#590、#591、#595

节后首期窗口，FlagQuantum（FlagOS 量子模拟与训练组件）成为组织内最大增量：窗口内 76 笔提交、23 笔 PR 合入，从 10-07 上午连续推进至 10-08 上午，覆盖发布认证、性能派发、梯度与几何量、纠错解码、原生熵导出五条线：

  • 发布认证落地（#587，10-08 07:16 合入）：分布式 MPS 发布战役收官——two_node_mps_training 能力行由 production_supported 升至 release_certified（本窗口唯一升格的能力行），认证建立在两份通过发布门禁的已签署实测生产运行载荷之上；同时以实测理由记录张量网络（TN）容量前提在当前修订上的不可满足性，并修复检查流程发现的全部产出侧缺陷（自合并基准 c7bba053 起含 28 笔非合并提交）。该战役接续 #535 开启的分布式 MPS / 张量网络发布工作。
  • 性能派发批（#576 / #581 / #582 / #583）：statevector 公开派发扩展至 SV-014（SWAP）、SV-010（对角）与有界 SV-011（Pauli 旋转），并完成有界 Pauli 旋转派发重认证——SV 系列逐项「实现 + 证据」的推进方式延续。
  • 梯度与几何量（#562 / #568 / #575 / #585 / #564 / #565）：新增 fq.jacobian / fq.jvp / fq.vjp（多输出程序）；二阶导（Hessian）以参数平移复用一阶规则；新增 Fubini-Study 度规张量（中心差分实现，附反证表说明为何不复用算符移位规则）；N3-9 将「梯度方法 × 执行模式」的 30 对矩阵落成契约并在门禁复测。
  • QEC 与熵导出（#590 / #591 / #592 / #589）：新增滑动窗口解码器（flagquantum/qec/sliding_window.py，新增 772 行，按窗口读取检测器错误模型并逐窗解码）；fq.vn_entropy 将 von Neumann 熵升为原生 Stable Core 导出（根导出预算 37 → 38）；四行 QEC 对齐项收敛；Quafu 远程提交在缺少凭据时改为 fail-closed。
  • 质量收口（#595 / #597）：#595 补录 16 笔未声明的派发修订；#597（开放）修复 CI 并发组缺陷——两次连续合入会整批取消前一次校验（#590 的 23/23 检查曾被取消即属该机制）。

判断：FlagQuantum 的「发布认证 + 契约化治理」双轨正在成型——能力以契约文件落档、以门禁与实测载荷复证，其工程纪律与 FlagOS 主线发布体系同构；窗口恰跨假期尾段与节后首日，该仓是长假期间仍保持高强度的开发线。

日期：2026-10-08　来源：FlagQuantum #587、#535

  • 认证内容：two_node_mps_training 由 production_supported 升至 release_certified，为能力表中唯一变动行；认证基于两份通过发布门禁（release gate）接受的已签署 measured_production_run 实测生产运行载荷。

  2. FlagQuantum 的「发布认证 + 契约治理」双轨成型——two_node_mps_training 升入 release_certified 且认证建立在已签署实测载荷上；根导出预算 37 → 38、「梯度方法 × 执行模式」30 对契约、度规张量反证表等，能力以契约文件落档、以门禁复测。
  3. 性能工作从「核优化」推进到「派发层语义」——SV 系列公开派发扩展至 SV-010 / 011 / 014，MPS 采样坍缩、SWAP 融合、局部双比特矩阵等核进入同一证据体系。
  4. 多芯片适配静中有动——海光（bmm / baddbmm / addmm / index_copy）、昆仑芯（P800 升级与 XPU3 修复）、达摩院玄铁（PPU 基线工作流）、摩尔线程（基准与别名）、昇腾（W8A8 INT8）各有批处理；新伙伴曦望（Sunrise）PTPU 图模式接线进入 vllm-plugin-FL（#569）。
  5. 构建与质量基建同步修复——vllm-plugin-FL CI 自愈机制（#559：失败/取消岗位精确重跑、厂商镜像预烤）与 FlagQuantum CI 并发组缺陷（#597 待合入）并现，复工首日呈现「基础设施日」特征。
  6. 下一观察点：FlagQuantum #597 合入与分布式发布战役后续（#535 → #587 线）；vllm-plugin-FL #561 / #569 评审结果；FlagTree PPU / hcu 工作流合入；组织各线在节后首个完整工作周的节奏恢复情况。
