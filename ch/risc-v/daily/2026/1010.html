一、开源社区与软件生态

1.1 Canonical：Ubuntu 26.10 首发官方 RISC-V 桌面镜像

日期：2026-10-09　来源：9to5Linux：Canonical Announces Official Ubuntu Desktop Images for RISC-V（10-09）、Phoronix：Ubuntu 26.10 To Include Desktop Images For RISC-V（10-09）

Canonical 宣布 Ubuntu Desktop 正式提供 RISC-V 镜像，随 10 月 15 日发布的 Ubuntu 26.10（Stonking Stingray）一同推出；另有实验性的 Xubuntu Minimal 镜像（暂无法官方支持，建议虚拟机试用）。官方推荐在 SpacemiT K3（Pico-ITX）上测试，26.10 起为该平台提供官方支持；完整桌面体验面向 RVA23 级硬件，包括 Milk-V Jupiter 2、DeepComputing DC-ROMA 与 SiFive HiFive Unmatched。真机启动需自行放入首级引导（如 U-Boot）与设备树。

1.2 LLVM／RISC-V：无分支代码在 RV32 上仍被编译出分支，Zicond 成解法

日期：2026-10-09　来源：Frank Denis：Branches in branch-free code（10-09）、Hacker News 讨论

实测发现：clang 23 会把 RISC-V 上刻意写成无分支的常量时间代码（128 位加法进位传播、掩码选择等）编译出条件分支（beq／beqz），RV32 与 RV64 均存在，构成潜在侧信道；Zig、Rust 同样受影响。启用 Zicond 扩展（RVA23 配置的一部分，提供 czero.eqz／nez）后全部案例恢复无分支，但计时特性仍需 Zkt 扩展配合才有保证；GCC 16.1 在部分写法下无分支、对比较掩码写法仍会引入分支。结论：编译器版本或参数变更后，常量时间代码需重新审计机器码。

1.3 riscv-unified-db：新增 RVA23.1／RVB23.1 配置文件

日期：2026-10-09　来源：riscv-unified-db 提交记录（10-09）

规范机器可读数据库 riscv-unified-db 窗口内 7 笔提交：新增 RVA23.1 与 RVB23.1 配置文件（#2721）、为 Zabha 扩展补充 8／16 位原子 RMW 路径（#2566）、新增 Sspmp／Sspmpen／Smpmpdeleg 扩展定义（#1817）、补全 Smcdeleg 与 Ssccfg 依赖（#2718），并修正 fcvt 浮点转换元数据、清理 VSEI／VSSI 中断参数。规范数据库持续跟进最新 ratified 配置。

1.4 openRuyi：Go 生态软件包再入库 13 项

日期：2026-10-09　来源：openRuyi 提交记录：SPECS 第二批（10-09）、lookout 提交记录（10-09）

继首批 20 余项之后，openRuyi 主仓库窗口内再合入 13 笔 SPECS 提交：新增 franz-go、OpenTelemetry profiling、Jaeger IDL、Datadog 系列、ghinstallation、阿里云 OpenAPI、chroma 等 Go 生态组件包定义，并补入 buf-protovalidate 与 cloudfoundry-clock。同组织的版本巡检工具 lookout 同日合入 20 余笔（发布版本下拉选择、依赖批量升级与 CI 缓存优化）。官网新闻页核查显示 2026.09 版本之后暂无新发布公告。

1.5 香山：FMA 提前唤醒、MMU ptehelper 支持等六笔合入

日期：2026-10-09　来源：XiangShan 提交记录（kunminghu-v3 分支，10-09）、PR #6679、PR #6687

香山主仓窗口内 6 笔合入：#6679 为 FMA 增加来自 FMA 与 load 的提前唤醒（src2 通路），#6687 修复 aes64ks1i 在 rnum>10 时未触发非法指令异常的问题，#6580 修正中断相关注释，#6636 启用 workload_list 的性能报告，另有两笔 MMU 提交（新增 ptehelper 支持与拼写修复）。前端解码、浮点发射与 MMU 路径同步收口。

1.6 香山仿真链：difftest 支持 2 槽 ROB 架构事件，GEM5 对齐 V3 RTL

日期：2026-10-09　来源：difftest PR #979：2 槽 ROB 项架构事件（10-09）、difftest PR #954：UVHS GBus 主机接口、GEM5 提交记录（10-09）、NEMU 提交记录（10-09）

仿真链多线推进：difftest 合入 #979（crob 支持 2 槽 ROB 项的 archEvent 与 storeEvent）与 #954（FPGA 验证方向新增 UVHS GBus 主机接口）；GEM5 修复 UARTLite 快速构建并加入 Clang 覆盖率（#1209）、将 SBuffer store miss 处理与昆明湖 V3 RTL 对齐；NEMU 的 ZSTD 检查点格式错误处理合入主分支。

四、具身智能与机器人专章

4.1 进迭时空机器人：ros2_humanoid 新增 WebSocket 直连 ASR 动作控制

日期：2026-10-09　来源：ros2_humanoid 提交记录（10-09）

进迭时空机器人组织的 ros2_humanoid 窗口内合入直连 WebSocket 的 ASR（语音识别）动作控制：识别结果可经 WebSocket 直接触发人形机器人动作。此前该仓已把 ROS 控制迁移至操作员 socket API、并在音频提示期间保持 ASR 采集——控制链持续向「语音—操作员—执行器」的直连与解耦方向演进。

五、总结与趋势观察

  • 发行版桌面侧迎里程碑：Ubuntu 26.10 首发官方 RISC-V 桌面镜像（推荐 SpacemiT K3、面向 RVA23 级硬件），RISC-V 桌面可用性从「实验镜像」走向「官方支持」。

  • 香山系与生态仓库日常高频：香山 FMA／MMU 修复与 difftest、GEM5、NEMU 仿真链同步推进；openRuyi Go 包、乐鑫 esp-sr、矽速 SLogic、算能示例矩阵各线均有实质提交。
  • 待观察：奕斯伟上市后的走势与解禁节奏；Ubuntu 26.10 于 10 月 15 日正式发布后 RISC-V 镜像的实际装机反馈；进迭时空 spine-triton 的 riscv64 wheel 发布节奏。
