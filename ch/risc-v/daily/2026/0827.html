一、开源社区与软件生态

1.1 GCC 补丁为 RISC-V 添加 -mcpu=native / -mtune=native 支持

日期：2026-08-26　来源：Phoronix / GCC 补丁列表

SiFive 工程师 Kito Cheng 向 GCC 提交补丁系列，为 RISC-V 后端添加 -mcpu=native 与 -mtune=native 支持，使编译器能自动探测本机 CPU 核并据此选择指令集扩展与调优参数，与其他架构对齐。该特性被寄望于并入明年的 GCC 17 发布；当前局限是不支持 RISC-V 混合/非对称大小核设计。补丁同时改进 GCC 对 SiFive P550 / P870-D / U74 与进迭时空 Spacemit X60 / X100 / A100 等核心的识别。RISC-V 长期缺乏”本机原生调优”选项的短板正在补齐。

1.2 arXiv：CTTE 开源双协议 RISC-V 追踪编码器

日期：2026-08-26　来源：arXiv:2608.18170 / Hacker News

论文发布开源 RISC-V 处理器追踪编码器 CTTE（SystemVerilog 实现）：采用协议无关前端加可选后端设计，同时支持 RISC-V 两种标准化追踪格式 N-Trace（Nexus）与 E-Trace，实现 N-Trace 1.0 程序追踪消息集、参数化地址宽度，并遵循 RISC-V Trace Control Interface 规范。据作者称，截至 2026 年 8 月尚无公开可综合的 N-Trace 编码器，也无单前端双后端开源实现。CTTE 已与 5 家供应商的 6 款 RISC-V 内核完成集成验证，为调试与可观测性工具链提供开放底座。

1.3 LLVM/Clang 23.1 发布，通用编译器栈更新

日期：2026-08-25　来源：Phoronix

LLVM 23.1 按计划发布，为 LLVM 23 系列首个稳定版（2026 下半年更新），本期主要亮点为 AMD Zen 6 与 NVIDIA Rigel 支持及部分 C++26 特性。作为 RISC-V 生态主流通用编译器之一，LLVM 版本更新对依赖其后端的工具链与芯片厂商（含国内团队）具有同步跟进意义，本期无 RISC-V 专项大改披露。

二、产品与生态动态

2.1 Armbian 26.8 发布：重写安装器与 UEFI ISO

日期：2026-08-26　来源：Armbian 官方博客 / 9to5Linux

面向 ARM 与 RISC-V 单板机的发行版 Armbian 26.8 发布：全树升级 Linux 7.1 内核，安装器从独立脚本重写为 armbian-config 模块（支持 SPI/MTD 目标、eMMC 与 NVMe 分离流程、独立刷引导程序并上报失败），Armbian Imager 升级至 2.0，新增可引导 UEFI ISO 镜像构建（image-output-iso 扩展），便于 IPMI 虚拟光驱与云环境直接部署。对 RISC-V 单板用户而言，UEFI ISO 与安装器重写降低入门门槛。

2.2 趋势条目：SiFive BigSky 服务器媒体持续发酵

日期：2026-08-26　来源：Electronics Weekly（gnews）、thestack.technology（gnews）、XenoSpectrum（gnews）

SiFive BigSky SF-2U870 企业级 RISC-V 服务器发布持续发酵：Electronics Weekly、thestack.technology、XenoSpectrum、Technetbook 等欧美媒体 8 月 26 日密集跟进，标题普遍强调”全球首款机架式 2U RISC-V 数据中心服务器”与 32 核开发服务器定位。主事件已于 8 月 25 日日报报道，本条为后续传播观察，不再展开。

2.3 Adafruit 实测 ESP32 深睡功耗：S3 vs C3 vs C6

日期：2026-08-26　来源：Adafruit Blog（gnews）

Adafruit 发布 ESP32 三款 SoC 深度睡眠功耗实测对比（S3 vs C3 vs C6），其中 ESP32-C3 与 C6 均为 RISC-V 内核，实测数据显示其低功耗表现与 Xtensa 内核的 S3 同台竞技，佐证 RISC-V MCU 在电池供电物联网场景的竞争力。属嵌入式社区内容，供低功耗选型参考。

三、国内团队动态与深挖

3.1 进迭时空：K3 BSP v1.0.7 与 Bianbu V4.0.6 同日发布

日期：2026-08-26　来源：docs-buildroot 发布说明 / docs-bianbu 发布说明 / esos org

进迭时空 8 月 26 日同日发布 K3 芯片 Buildroot BSP v1.0.7 与 Bianbu V4.0.6 发行版更新。BSP 主要更新：支持 RISC-V64 加密加速、支持读取 K3 chipid、优化 OPP 表（采用 efuse 校准值作热温参考），并修复 PCIe 唤醒链路训练失败、MIPI DSI 面板未切换、UFS 读写混合序列化、fastboot 大偏移截断等一批底层缺陷。Bianbu V4.0.6 聚焦 LXQt 桌面与基础组件修复（快照快门、背光插件、wlroots 休眠黑屏、网络列表冗余等）。配套 esos 仓库同期批量合入 K3 挂起到磁盘（hibernation）支持、audio pmdomain 状态修复等提交，文档侧 MUSE Pi Pro 用户指南新增 JTAG 调试接口章节与 TF 卡调试扩展板文档。版本节奏保持约月度更新。

3.2 算能：sophon-tools 大规模适配 CV84X2/SE13

日期：2026-08-26~27　来源：sophgo/sophon-tools

算能 sophon-tools 工具链窗口内合入约 25 笔提交，集中适配 CV84X2（疑似 CV 系列新一代芯片）与 SE13 单板：get_info 升级至 v1.5.0/1.5.1（补齐 CV84X2 剩余 19 项空值指标、dts 探测跟随符号链接、CHIP_SN 改按 BM1688 方案读取）、bmssm 监控指标对齐 get_info、sophliteos 构建/部署三处坑修复（CV84X2 真机验证）、psoph_phytool 硬件探测、pota_update 网络解析兜底等。提交信息含 MYS-753/754 等内部缺陷跟踪号并标注真机验证，表明算能正为 CV84X2 新品铺平工具链与运维配套。

3.3 香山：模拟器工具链密集更新，研究分析沉淀为主

日期：2026-08-26　来源：OpenXiangShan org 提交检索

OpenXiangShan 组织窗口内约 40 笔提交，集中在一众模拟/验证工具链：gsim 重构 CI（新增 arm64 构建、clang 升级、jemalloc、dependabot 跟踪、–threads 解析线程数参数）；XiangShanLab 新增 prefetch 指令 MMIO 非对齐分析报告（含波形）与指令生命周期分析（#4724 分析报告）；difftest 重写 StoreRecorder 校验逻辑、FPGA 差分调试字段过滤；GEM5 修复 arch-riscv MUL 符号溢出、禁用方向 TLB probe 跳过等；NEMU 支持向量 exp2 指令；XSAICache 同步 coupledL2 矩阵数据。延续”研究分析沉淀 + 基建维护”型活跃，未见新架构改动。

3.4 平头哥：thead-extension-spec 修复 xtheadfmv 文档编码错误

日期：2026-08-26　来源：XUANTIE-RV/thead-extension-spec PR #75

平头哥玄铁扩展规范仓库合入 PR #75（外部贡献者 majin2020）：修正 xtheadfmv 扩展文档中 th.fmv.hw.x 与 th.fmv.x.hw 两条指令互换的 funct7 编码（0x60/0x50），使其与硬件实际规格一致；同期修复 CI 的 wavedrom npm 参数问题。属规范文档勘误，动态量小，体现玄铁扩展规范仓库持续接受外部修订。
