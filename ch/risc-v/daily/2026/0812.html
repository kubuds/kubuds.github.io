RISC-V 全球动态日报（2026-08-12）

2026-08-12 苦芽科技

调研窗口：过去 24 小时（2026-08-11 15:46 ~ 2026-08-12 08:50 北京时间） 信源：HN、Google News 聚合、CNX Software、Linuxiac、快科技、新京报、GitHub API 等（详见附录）

一、开源社区与内核/版本动态

1.1 QEMU 11.1 发布：新增 RISC-V 大端支持与 K230 板级模拟

日期：2026-08-12（发布 08-11 16:11 UTC）　来源：Linuxiac（经 vmvirtualmachine 镜像核实） / Google News 聚合

QEMU 11.1 作为 11.x 系列首个维护版本发布，头号特性是 RISC-V 大端（big-endian）目标支持——对应 RISC-V 规范中运行时可控端序（runtime-controllable endianness）能力的落地，Codethink 此前即以此为主题开展”在小端架构上模拟大端”的研究并以 QEMU 为测试底座。RISC-V 侧同步增强：新增勘智 K230 开发板支持（Canaan K230 为 RISC-V 双核 AI 视觉 SoC，常用于端侧视觉与机器人场景）、OpenSBI 升级至 1.8.1、新增 Tenstorrent mvendorid 支持，并修复大批 IOMMU、中断处理、页表遍历与向量指令等底层问题。对 RISC-V 内核/发行版开发者而言，11.1 的大端支持意味着可在模拟器中先行验证大端软件栈。

1.2 RISC-V 官方规范仓库自动化维护更新

日期：2026-08-12　来源：riscv-unified-db / riscv-arch-test

RISC-V 官方规范侧基础设施仓库保持更新：riscv-unified-db（规范机器可读数据库）窗口内合入 4 笔依赖维护提交（prek、mise、jetty 版本升级与锁文件维护），riscv-arch-test（架构一致性测试 ACT）更新 Ubuntu 24.04 Docker 镜像 digest。两者均为自动化维护型提交，属规范工程常规节奏；值得留意的信号是 RVA23.1/RVB23.1 公开评审（昨日已报）正在推进，后续统一数据库内容会随之更新。

1.3 labwired-core：ESP32-C3（RISC-V）固件仿真能力持续增强

日期：2026-08-12　来源：GitHub w1ne/labwired-core

Rust 编写的确定性固件仿真器 labwired-core（支持 ARM Cortex-M 与 RISC-V，提供 MCU 数字孪生与 MCP server 接口，59 stars）窗口内合入 15 笔提交：新增 ATmega328P Nano 孪生（CPU + Timer0/USART）、ESP32-C3（RISC-V 内核）侧修复 DHT 单总线在 C3 孪生上的时序、为各 BLE Pong 实验分配独立信道以消除测试抖动，并新增资源度量（访问计数 + PC 采样）功能。其 ESP32-C3 相关工作量占比提升，反映 RISC-V MCU 在”固件级仿真/虚拟硬件”工具链中的覆盖度在扩大。

二、产品与生态动态

2.1 尊界 V800 智能座椅搭载奕斯伟 RISC-V 车规级 AI MCU（近 3 天趋势）

日期：2026-08-10　来源：快科技 / 凤凰网 / 新浪

鸿蒙智行尊界 V800 正式亮相，其全主动自适应智能座椅成为亮点：通过精准的人体姿态识别与动态适配调整驾乘体验，核心算力与 AI 算法方案由奕斯伟计算提供的 RISC-V 车规级 AI MCU EAM2011 承载。EAM2011 是国内首颗支持轻量级 AI 应用的车规级 MCU，搭载自研 32 位 RISC-V 内核、采用国内成熟工艺制程，并完成从核心 IP、芯片设计到生产平台的全链路本土化研发与量产体系搭建。该事件虽落在昨日窗口末端（08-10 报道，昨日报告未收录），但作为国产 RISC-V 车规芯片规模化上车的标志性案例，值得在今日报告中补录。此前该系列芯片已见于智能座舱轻量化 AI 部署场景。

三、国内团队动态与深挖

3.1 开芯红（香山 IP 商业化主体）：种子轮投资方阵容披露，国资+头部产投共同加持

日期：2026-08-11/12　来源：新京报 / Google News 聚合（搜狐转载，08-12 窗口内）

昨日已报开芯红完成超亿元种子轮融资（资金投向香山 IP 核架构升级），今日投资方阵容进一步披露：本轮汇聚国开科创、诚通科创、中科创星、中关村科学城、启航基金及国泰创投等头部产投机构（新京报 8 月 11 日报道，搜狐 8 月 12 日凌晨转载进入本窗口）。国开科创与诚通科创均为国资背景创投平台，加上中科创星（硬科技）、中关村科学城（北京属地）的组合，表明香山 IP 商业化同时获得国家级政策资本与属地产业资本背书。GitHub 侧香山生态仓库组（XiangShan 主仓库、difftest、NEMU、GEM5、env-scripts、XSAI 等 11 个仓库）8 月 11 日批量更新，配套工具链保持同步演进，为”架构升级”路线提供工程侧支撑。

3.2 奕斯伟计算：车规 MCU 上车 + 消费级 AI 私有云落地

日期：2026-08-10　来源：快科技 / Google News 聚合（网易） / Google News 聚合（湖北省经信厅）

奕斯伟计算本周多条动态叠加，形成”车规 + 消费电子”双线落地图景（均为近 3 天事件，昨日报告未收录）：

  • 车规：EAM2011（自研 32 位 RISC-V 内核车规级 AI MCU）进入尊界 V800 智能座椅，详见 2.1；
  • 消费：极空间（ZSpace）即将上线的国产 AI 私有云 NAS 与奕斯伟合作打造，图片素材 AI 处理全部本地运行、无需上传云端，隐私优先定位的端侧 AI 场景；
  • 集团层面：奕斯伟材料（西安奕材）拟对武汉奕材增资，总募资 65 亿元投向 12 英寸硅片扩产（湖北省经信厅披露），拟 2027 年首期产能投产——属集团材料业务资本动作，与计算芯片业务相互独立但印证集团整体扩产节奏。

3.3 算能（SOPHGO）：SophLiteOS 新增 AI Agent 功能

日期：2026-08-12（提交时间 08-11 21:03 / 08-12 07:15 北京时间）　来源：GitHub sophgo/sophon-tools

算能官方工具仓库 sophon-tools 窗口内合入 5 笔提交，核心变更：SophLiteOS 新增 AI Agent 功能（含 pbmssm LLM 转发），并将 picoclaw-web-chat 作为 AI Agent 页内嵌实现（MYS-149 需求），另修复 SophLiteOS 概览页内存指标命名。SophLiteOS 是算能面向 RISC-V 端侧芯片的轻量操作系统，本次合入把 LLM Agent 交互能力下沉到端侧系统工具链中，配合其 K230/SG 系列 RISC-V SoC，属于”RISC-V 端侧 + LLM Agent”方向的直接工程进展。

四、具身智能与机器人专章

窗口内无重大动态。 过去 24 小时英文检索（”risc-v” robot when:3d）无窗口内命中，中文检索（RISC-V 机器人/具身智能 when:3d）仅命中车规与工业综述类条目，未发现具身智能/机器人方向的 RISC-V 强相关新闻。

近 3 天趋势观察：该方向与上周保持一致的渐进节奏。值得关注的邻近信号有二：一是奕斯伟 EAM2011 车规级 AI MCU 在尊界 V800 智能座椅上的姿态识别应用（2.1），此类”传感器感知 + 动态适配”正是机器人控制与智能座舱共用的技术栈，国产 RISC-V 车规芯片的落地路径可作为具身智能芯片的参照；二是算能 SophLiteOS AI Agent 功能落地（3.3），端侧 LLM Agent 能力为 RISC-V 机器人大脑提供更轻的软件基座。进迭时空（spacemit-robotics）、乐鑫（esp32-c 系列）机器人相关产品线未见新的公开里程碑。明日（8 月 13 日）第五届滴水湖中国 RISC-V 产业论坛召开，10 款国产芯片集中亮相，具身智能相关芯片新品值得会后跟踪。

五、总结与趋势观察

  1. 模拟器层加速跟进 RISC-V 新特性：QEMU 11.1 落地 RISC-V 大端支持并新增 K230 板级模拟、OpenSBI 1.8.1，配合 Codethink 的端序研究，RISC-V 运行时可控端序从规范走向可验证的工具链路径正在闭环。
  2. 国产 RISC-V 车规芯片规模化上车：奕斯伟 EAM2011 进入尊界 V800 智能座椅，叠加极空间 AI 私有云，奕斯伟系在车规与消费电子两端同时兑现”RISC-V+AI”产品化。
  3. RISC-V 端侧 OS 开始内建 LLM Agent：算能 SophLiteOS 合入 AI Agent 与 LLM 转发功能，端侧大模型应用栈向 RISC-V 生态渗透。
  4. 香山 IP 商业化获政策资本背书：开芯红种子轮投资方披露国开科创、诚通科创等国资机构，一级市场对国产高性能 RISC-V IP 的认可度持续提升。
  5. 局限性说明：24 小时窗口内国际重磅新闻偏少（以 QEMU 11.1 为最显著），国内动态多依赖 GitHub 提交与转载媒体；极空间、武汉奕材等条目仅能引用 Google News 聚合链接（原站正文不可直接抓取），尊界 V800 细节以快科技/凤凰网/新浪多源交叉核实。具身智能专章窗口内无直接新闻，相关判断基于邻近方向推断。
