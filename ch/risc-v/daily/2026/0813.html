RISC-V 全球动态日报（2026-08-13）

2026-08-13 苦芽科技

调研窗口：过去 24 小时（2026-08-12 08:50 ~ 2026-08-13 08:24 北京时间） 信源：HN、Google News 聚合、CNX Software、Phoronix、The Register、电子工程专辑、新浪财经、IT之家、GitHub API 等（详见附录）

一、开源社区与内核/版本动态

1.1 USENIX 论文：商用乱序 RISC-V 芯片对全部 Spectre 变体易感，含国产玄铁 C910/C920（今日头条）

日期：2026-08-13（报道 08-12 20:42 UTC）　来源：The Register

比利时与德国高校学者完成论文《Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors》，已被第 35 届 USENIX Security Symposium 录用。研究结论直指此前”RISC-V 架构太简单、不受 Spectre 影响”的流行假设是错的：商用乱序执行 RISC-V 处理器（SiFive P550、平头哥玄铁 C910/C920）对所有主要 Spectre 变体均易感；而顺序执行内核（SiFive U74、玄铁 C906/C908）未见漏洞。研究者在两块芯片上实现了 Spectre-PHT/BTB/RSB/STL 四类 PoC 攻击，召回率达 100%、精度超 97%，并在玄铁 C910 上以 338 B/s 的速度泄露任意 Linux 内核内存。研究者强调：x86/ARM 的软件缓解手段不能直接迁移（RISC-V 缺少微架构自省接口，且生态碎片化导致难以统一缓解），需从架构原语、硬件透明性与生态工具链层面系统性补课。相关补丁已合入主线上游 Linux 3 个、另有 2 个在审；SiFive 已处理 P550 专项问题。对国产 RISC-V 服务器与云场景，这是安全基线的直接提示。

1.2 RISC-V 官方模拟器与测试套件维护更新

日期：2026-08-12（21:36/21:59 北京时间）　来源：riscv-isa-sim / riscv-tests / sail-riscv-tests

RISC-V 软件生态基础设施仓库窗口内例行更新：官方 ISA 模拟器 Spike（riscv-isa-sim）合入构建系统清理（Boost 检测上移至顶层 configure，修复重复链接告警与 C99 设计符告警，PR #2365/#2363/#2362）；riscv-tests 的 debug 测试新增”接受 GDB 主线程标识符”兼容修复（#657）；sail-riscv-tests 预编译测试套件同步更新。均为低信号维护型提交，属规范工程常规节奏，与 RVA23 公开评审及统一数据库更新（riscv-unified-db）保持同步。

二、产品与生态动态

2.1 Tenstorrent 提交 Ascalon XG GCC 补丁：疑为面向出口市场的去加密型号

日期：2026-08-13（08-12 16:14 EDT）　来源：Phoronix

Tenstorrent 工程师向 GCC 邮件列表提交补丁，首次公开新内核型号 Ascalon XG——这是高性能乱序 RISC-V RVA23 内核 Ascalon X 的新变体，目标是进入开源 GCC 上游支持。补丁中明确标注其为 “the global version of Ascalon X”：与 Ascalon X 的唯一差异是去掉 zvkng 向量密码学扩展，其余（rva23s64、zfbfmin、zfh、zvbc、zvfh、zvl256b、smaia、ssaia 等）保持完整，编译器目标标识为 tt-ascalon-xg。去掉密码学扩展、降低吞吐定位，业界普遍解读为面向中国市场等出口管制场景的合规型号。这是 Tenstorrent Ascalon 系列在 RISC-V 高性能 CPU 路线上的又一布局信号，也侧面印证出口管制正在影响 RISC-V 高性能核的型号分化。

2.2 Apollo 发布 40 美元 ESPHome 官方入门套件，搭载 RISC-V 芯片 ESP32-C6

日期：2026-08-12（18:55 北京时间）　来源：CNX Software

Apollo Automation 与 Open Home Foundation 合作推出首款官方 ESPHome 入门套件，售价 40 美元。主控板为 ESPHome C6 Board，搭载 ESP32-C6-MINI-1 模组（乐鑫 RISC-V 内核 MCU，支持 2.4GHz Wi-Fi 6、BLE、Thread/Zigbee），通过两条 14-pin FPC 接口连接四款模块：MH-SR602 PIR 人体感应、AHT20F 温湿度、RGB LED+蜂鸣器通知模块与按键模块，USB-C 供电可选锂电池。套件主打零门槛：配合 ESPHome Device Builder 桌面可视化编辑器即可配置，无需写 YAML，可独立运行或接入 Home Assistant。ESP32-C6（RISC-V）成为智能家居官方入门硬件的事实选择之一，是 RISC-V MCU 在消费级生态渗透的又一实例。

（说明：QEMU 11.1 发布及其 RISC-V 大端支持、K230 板级模拟已在昨日报告收录，今日不重复。）

三、国内团队动态与深挖

3.1 平头哥：真武 AI 芯片累计出货 56 万片，阿里云称产能持续提升

日期：2026-08-12（19:30 北京时间）　来源：电子工程专辑

电子工程专辑报道，截至今年 4 月平头哥真武 AI 芯片累计出货 56 万片。阿里云全球数据中心总经理王朝阳在公开场合表示：平头哥产能正在逐渐提升，”未来非常确定性的是，国产自有芯片的产能会持续提升、占比越来越高，而产能提升时间大概不需要三年”。这是阿里云侧对国产自研芯片产能节奏的罕见量化表态。深挖：平头哥为阿里全资半导体主体，产品线覆盖数据中心 AI 芯片（含光/真武）、服务器 CPU（倚天 710/730）与 RISC-V 处理器 IP（玄铁系列），其中玄铁 RISC-V 生态（XUANTIE-RV 组织）本周持续活跃——窗口内 zero_stage_boot 仓库（C 语言零级启动引导）更新（08-12 19:18）、damo-rv-priv-ats 与 opensbi 同步推进，显示其 RISC-V 内核与生态工程与 AI 芯片业务并行投入。

3.2 希奥端计算：数亿元 A 轮融资交割，总部迁至南京江北新区，兆易创新参投

日期：2026-08-12（18:01 北京时间）　来源：IT之家 / 投资界 / Google News 聚合（新浪财经）

服务器 CPU 研发企业希奥端计算（成立于 2022 年 7 月）宣布于 2026 年 7 月完成数亿元人民币 A 轮融资交割，并同步将总部迁至南京江北新区。本轮由铭哲资本、现象资本联合一家头部 VC 领投，中信建投资本、中银国际、兆易创新、智宸资本、卓源亚洲、守正资本、鼎心资本等跟投——其中兆易创新是国内 RISC-V MCU（GD32V 系列）主力厂商，其参投印证产业资本对服务器 CPU 国产化的押注。公司战略为双路线并行：一方面基于 ARM v9 指令集 Neoverse V3 核构建第一代产品 BlueDot V1（强化向量运算、乱序流水线与内存互联带宽，面向云端与边缘 AI 推理）；另一方面前瞻布局 RISC-V CPU 架构。募资将投入 BlueDot V1 回片验证与 2026 年底小批量试产。国产推理服务器 CPU 赛道再添新玩家。

3.3 奕斯伟计算：三冲港交所，”RISC-V 第一股”连续减员引发关注

日期：2026-08-12（18:58 北京时间）　来源：Google News 聚合（新浪财经）

新浪财经刊发长文分析奕斯伟计算（ESWIN Computing）第三次递表港交所背后的经营细节：作为”RISC-V 架构第一股”候选，公司营收持续增长但三年累计亏损约 49 亿元，客户高度集中，且员工人数连续缩减成为市场关注点。结合此前已披露信息（8 月 7-8 日启动三冲港股、母公司西安奕材 65 亿元增资武汉 12 英寸硅片基地），奕斯伟集团正以”材料扩产 + 计算芯片 IPO”双线推进资本运作。员工规模变化与研发投入节奏的关系、以及 RISC-V 车规 MCU（EAM2011 上车尊界 V800）的放量进度，将是后续跟踪重点。

3.4 进迭时空：AI SDK 集中更新，机器人学习框架 LeRobot 适配 K3 持续推进

日期：2026-08-12（20:32 北京时间）　来源：spacemit-com/ai-sdk / spacemit-robotics/lerobot / spacemit-com/docs-ros

进迭时空（SpacemiT）GitHub 组织窗口内多条仓库集中更新：AI SDK（面向 K 系列芯片的 AI 能力集合，以 Git submodule 组织）更新计算机视觉、语音（VAD/ASR/TTS）、LLM 与多模态 VLM 组件（08-12 20:32），model-zoo-vision 视觉模型仓库同步更新（19:49）；docs-chip/docs-buildroot 文档更新（15:41/16:23）。机器人侧（spacemit-robotics）：LeRobot 仓库 08-10 合入 “harden SmolVLA K3 runtime” ONNX 加固提交，此前已落地 ACT（Action Chunking with Transformers）FP16 部署示例与 ONNX 推理机器人测试；docs-ros（ROS 文档）与 Robot SDK IMU 驱动（peripherals-imu）同日更新。K3（RISC-V 8 核 AI SoC）在机器人学习框架与 ROS 生态上的适配面在扩大，详情见第四章。

3.5 算能（SOPHGO）：引导链组件集中更新

日期：2026-08-12（14:41~14:47 北京时间）　来源：sophgo/zsbl / sophgo/sophgo-edk2 / sophgo/bootloader-riscv / sophgo/sophon-tools

算能 RISC-V 芯片引导链组件窗口内集中更新：zsbl（RISC-V Zero Stage BootLoader，08-12 14:47）、sophgo-edk2（UEFI 固件，14:41）、bootloader-riscv（08-11 13:59）、linux_5.10 内核分支（08-11 16:40）相继有提交；sophon-tools 今日（08-13 07:05）继续更新（SophLiteOS AI Agent 功能昨日已报）。引导链（ZSBL→UEFI→内核）的成体系推进，通常对应新芯片平台的固件就绪阶段，可视为算能新平台量产准备的工程信号。

3.6 芯来科技：申报新三板创新层，定向募资 4200 万元（近 3 天趋势）

日期：2026-08-10　来源：Google News 聚合（新浪财经）

国内 RISC-V CPU IP 龙头芯来科技（Nuclei）申报新三板创新层，计划定向募资 4200 万元（新浪财经 8 月 10 日报道，落于本窗口之前，作近 3 天趋势收录）。资本侧动态与研发侧同步：GitHub 侧 Nuclei-Software 组织近期更新 Lauterbach TRACE32 调试脚本仓库（lauterbach-startup，08-11）、RV64GC Linux 能力内核 e603_hbird（08-07）与 nuclei-ai-models（08-07），显示其从 IP 核到调试工具链与 AI 模型库的完整布局仍在扩张。

四、具身智能与机器人专章

窗口内最大看点：进迭时空（SpacemiT）在机器人学习框架上的持续落地。

  1. LeRobot 适配进展（spacemit-robotics/lerobot，08-10 16:20 提交）：合入 “fix(onnx): harden SmolVLA K3 runtime”（#17）——SmolVLA 是轻量视觉-语言-动作（VLA）模型，进迭时空在其 K3 RISC-V SoC 上以 ONNX 运行时部署并加固；此前已落地 ACT（Action Chunking with Transformers）的 SpineTorch FP16 部署示例（#16）与 ONNX 推理机器人测试（#14）。加上 6 月以来的 SmolVLA ONNX pipeline（#12/#13），K3 已形成”VLA + ACT 双路线”的机器人学习模型端侧部署矩阵。其组织内另有 humanoid_unitree_g1/go1（宇树）、humanoid_tiangong（天工）、reachy_mini 等仿人机器人适配仓库与 Robot SDK 电机/IMU 外设驱动，构成完整的机器人软件栈。
  2. ROS 生态：docs-ros 文档仓库更新（08-10），与 AI SDK 的 ROS 示例配套。
  3. 滴水湖论坛今日开幕：第五届滴水湖中国 RISC-V 产业论坛于今日（8 月 13 日）召开，此前预告”10 款国产芯片新品集中亮相”（新浪财经 8 月 8 日报道），具身智能相关芯片新品值得会后跟踪；截至本报告采集时点（08:24）尚无开幕当日成果报道。
  4. 邻近信号：奕斯伟 EAM2011 车规级 AI MCU 在尊界 V800 智能座椅的姿态识别应用（昨日已报），其”感知 + 动态适配”技术栈与机器人控制共用，可作为具身智能芯片国产化路径参照。

五、总结与趋势观察

  1. 安全基线敲响警钟：USENIX 论文证实商用乱序 RISC-V 芯片（含国产玄铁 C910/C920）对全部 Spectre 变体易感，且 x86/ARM 软件缓解不可直接迁移。RISC-V 在高性能计算与云场景的规模化进程中，微架构安全原语与生态级防御工具链的建设将成关键竞争维度，国产乱序核（玄铁、香山等）尤需重视。
  2. 出口管制重塑产品线：Tenstorrent Ascalon XG”去加密出口型号”公开亮相，叠加美国会推动收紧 AI 芯片流向管制，RISC-V 高性能核的”国内版/国际版”分化可能成为常态，国产替代窗口与合规压力并存。
  3. 国产服务器 CPU 融资活跃：希奥端 A 轮（兆易创新参投、BlueDot V1 年底试产）、芯来新三板募资、奕斯伟三冲港股，资本正密集涌入国产 CPU/RISC-V IP 赛道，ARM 与 RISC-V 双路线成为新一代创业公司标配。
  4. 机器人方向稳步推进：进迭时空 LeRobot 的 SmolVLA/ACT 端侧部署与 ROS 适配是本周最具体的 RISC-V 具身智能进展；滴水湖论坛今日开幕，会后芯片新品信息值得持续跟踪。
  5. 生态基础设施节奏正常：Spike/riscv-tests 维护更新、玄铁 zero_stage_boot 等提交显示规范工程与厂商工程均按常规节奏推进。
