今日重点：奕斯伟计算通过港交所上市聆讯，有望成为港股「RISC-V 第一股」

日期：2026-09-21　来源：第一财经《奕斯伟计算通过港交所上市聆讯》、新浪财经／观点网《奕斯伟计算通过港交所上市聆讯 2025年营收24.31亿元》、网易号《奕斯伟计算通过港交所聆讯，RISC-V赛道有望迎来「第一股」》

据港交所文件，北京奕斯伟计算技术股份有限公司于 09-21 通过港交所主板上市聆讯，联席保荐人为中信证券与中信建投国际（公司于 2026-07-31 第三次递交招股书）。若后续发行顺利，将成为港股「RISC-V 第一股」，填补 RISC-V 芯片赛道的上市标的空白。

经营数据方面：公司采用 Fabless 模式，以 RISC-V 为技术底座，产品覆盖人机交互及多媒体处理芯片、互连及计算芯片，聚焦智能终端与具身智能两大场景；2023 至 2025 年营收分别为 17.52 亿元、20.25 亿元、24.31 亿元，2025 年净亏损 15.16 亿元；2026 年一季度营收 4.94 亿元（同比增长 18.4%）、净亏损 3.75 亿元、毛利率 14.8%。截至 2026 年 3 月 31 日，已推出超 150 款软硬件协同产品、服务全球 220 余家客户；计算产品收入从 2023 年的 37.5 万元增至 2025 年的 3.20 亿元，2026 年一季度达 2.23 亿元，产品切入汽车、工业等核心赛道。以 2025 年营收口径统计，公司为国内最大的智能终端人机交互芯片提供商。

行业面数据一并释出：据弗若斯特沙利文统计，中国 RISC-V 主控芯片市场规模由 2021 年的 11 亿元增长至 2025 年的 377 亿元（年复合增长率 139.5%），预计 2030 年扩大至 2194 亿元。需要保留的边界是：聆讯通过距正式发行与定价仍有流程要走，公司的净亏损与计算产品线的放量节奏将是上市后最直接的检验指标。同日，公司 GitHub 侧有配套发布动作（见 3.1）。

一、开源社区与软件生态

1.1 openRuyi：内核双线升级至 7.2.6 与 6.18.52，安全修复批量落地

日期：2026-09-21　来源：openRuyi 提交：linux 升级 7.2.6、kernel-team-tools：TAG 升至 v7.2.6-1、openRuyi 官网新闻页

openRuyi 滚动发行版窗口内提交 20 项以上，主线是内核双线升级与上游跟进：linux 升级至 7.2.6、linux-lts 升级至 6.18.52（均含 patchset 与 config 刷新）；kernel-team-tools 同步更新四个内核系列的构建标签（6.18.52-1／7.0.14-5／7.1.13-1／7.2.6-1），并在内核配置中启用 ULTRARISC、VFIO_IOMMU_TYPE1、ARCH_ANLOGIC 等选项；openRuyi-Project/linux 的 ruyi/6.18.y、7.0.y、7.1.y、7.2.y 四个维护分支当日同步推送。

构建体系侧：新增 openruyi-linux-build 组件（为各风味变体提供统一的 linux 包），linux／linux-lts／linux-lts-kmhv2 三份 spec 改用 rpm 宏统一维护；glibc 2.44 跟上上游快照。安全与包更新批量落地：python-pytorch-lightning 2.6.6、python-datasets 5.0.1、python-ujson 6.0.0、ImageMagick 7.1.2.31、pcre2 10.48（提交均标注 security-fixes）；云原生侧新增 k8s konnectivity-client 与 kms、Datadog dd-trace-go、VictoriaMetrics 等 Go 包。官网新闻页窗口内无新公告，9 月版本尚未发布（最新为 2026.08，08-27 发布）。

1.2 香山：昆明湖 V3 分支修复 CBO 与预取路径，NEMU 将 mseccfg 改为可配置

日期：2026-09-21　来源：XiangShan 提交：LoadUnit 保留 prefetch.i 退休路径（#6230）、NEMU 提交：mseccfg 改为 Kconfig 可选项（#1221）

香山主仓库窗口内 5 项提交落在 kunminghu-v3 分支：LoadUnit 对 prefetch.i 改为正常退休而非在 S1 阶段清除（#6230）；CBO（Cache Block Operation）指令两项修复——decode 阶段 numWb 改为 2、Load-Store Queue 的 StoreQueue credits 在跨 CBO lane 时正确保持；docker 基础镜像切换为 xs-env:stable（#6577）；CI 侧改进 ckpt_select.py 并加入 nightly fuzz（#6604）。NEMU 侧两项：把 mseccfg 改为 Kconfig 可配置项（#1221）、虚拟化 supervisor 计时器仅在 nemu_timer 启用时关闭。

GEM5 分支级开发同样活跃：feat-ywl-pfbuffer 分支新增 PDB（预取数据缓冲）模型，并修复其重放清理与预取准入逻辑；窗口内另新开 Hybrid_CROB、calibrate-rvv-iq 等开发分支（分别指向混合 CROB 与 RVV 指令队列校准）。difftest 与 XSCache 主分支窗口内无新提交；主干合并动向仍待观察。

1.3 Bluespec 开源硬件 IP 库 Tape-Out（FukuzSoC）批量新开仓库

日期：2026-09-21　来源：GitHub 组织 Tape-Out（FukuzSoC）

一个名为 FukuzSoC 的开源硬件 IP 库 09-21 批量新开仓库，包括三套参考 SoC（soc-mcu／soc-linux／soc-smp）与 PLIC 中断控制器等。其组织自述为「用 Bluespec 构建、由 XiRang 包管理器装配的开源硬件 IP 库」：每个 IP 仓库包含 ip.yaml（配置项、契约与实测面积）、regmap.yaml（寄存器映射）、Bluespec 源码与覆盖全配置矩阵的行为测试；自研工具链 xirang 负责解析、生成、测试与「定价」，spec 定义文件语义。

IP 谱系涵盖 hart 处理器核、cache、NPU／GPGPU／YOLO 加速器，ACLINT／PLIC／IMSIC 等 RISC-V 中断体系部件，UART／SPI／I2C 等外设与以太网交换／路由模块；成熟度分 planned／simulated／fpga-proven／asic-ready／silicon-proven 五级，并在每个仓库以徽章展示。参考 SoC 明确「不含自有 RTL」，全部由 IP 组合装配——这种「包管理器 + IP 库」的组织方式与国内常见的 RTL 单仓模式不同，其成熟度推进值得跟踪。（注：为新近公开项目，尚未见公开的流片记录与社区讨论。）

1.4 simdjson 出现 RVV 向量后端实验仓库

日期：2026-09-21　来源：MA-Gustave/Simdjson-rvv-vla

开发者开源 simdjson 的 RISC-V 向量（RVV 1.0）实验后端，采用向量长度无关（VLA）写法，配套 GCC／Clang 验证、运行时分发、上游验收测试与可复现性能基准，仓库 09-21 创建并当日连续推送提交。simdjson 是应用广泛的高性能 JSON 解析库，RVV 后端若被上游接纳，将补齐 RISC-V 平台在该库上的向量加速路径。注：目前为个人实验仓库，尚处早期阶段，性能与上游接纳进度待验证。

二、产品与生态动态

2.1 印度 Aheesa 发布 VIHAAN-I：本土自研 RISC-V 宽带网络 SoC 完成流片

日期：2026-09-21　来源：EE Times《Fabless Startup Aheesa Tapes Out First Indian RISC-V Network SoC》、Machine Maker《Aheesa Advances India’s Semiconductor Ambitions with Indigenous VIHAAN Broadband Networking Chip》

印度金奈的 Fabless 初创 Aheesa Digital Innovations 在 SEMICON India 2026 期间展示其自研 RISC-V 宽带网络 SoC VIHAAN-I（厂商称其为印度首款本土设计的 RISC-V 宽带网络芯片）。该芯片为 28nm 工艺，单芯片集成计算、宽带接入与系统控制，面向 GPON／EPON 光纤接入与电信基础设施，目标是替代印度电信与网络领域的进口半导体。公司已完成 VIHAAN-I 流片，计划进入多项目晶圆（MPW）制造，商用时间目标 2027 年一季度；项目获印度 MeitY 设计链接激励（DLI）计划认可，并获泰米尔纳德邦新兴行业种子基金投资。意义与边界：这是印度「国产芯片」议程在电信基础设施方向落下的第一个 RISC-V SoC 载体，但产品尚未量产，工艺与性能细节均来自厂商及展会报道口径。

2.2 智能汽车芯片生态大会续报：DF30 计划 2026 年规模量产，英飞凌下一代车规 MCU 全面转向 RISC-V

日期：2026-09-21（会议 09-16）　来源：凤凰网转网通社《2026第六届智能汽车芯片生态大会召开，东风、长安、上汽及英飞凌等企业讨论RISC-V架构应用》、凤凰网转网通社《英飞凌宣布下一代汽车MCU全面转向RISC-V架构》

网通社 09-21 就 2026 第六届智能汽车芯片生态大会发布两项后续报道，补足了此前未覆盖的细节。其一，东风汽车披露其 RISC-V 车规芯片进度的量化坐标：与中国信科联合研发、武汉二进制半导体参与的 DF30 基于 RISC-V 多核架构、国产 40nm 车规工艺、功能安全达 ASIL-D，2024 年 11 月发布后已在东风奕派 007、猛士 M817、风神皓瀚等车型完成验证，首搭发动机 ECU，计划 2026 年规模量产、年底首批搭载量产车下线；为其提供 CPU 内核的芯来科技团队从二十余人扩至约五百人，芯片先后完成六百多项测试。

其二，英飞凌汽车业务高管在大会上阐述「下一代汽车 MCU 全面转向 RISC-V」的布局：新品纳入 AURIX 家族（与 TriCore、Arm 产品线并存），其汽车 MCU 份额已从 2025 年的 32.1% 提升至 36%；2026 年 3 月发布 DRIVECORE 虚拟原型评估包，国内部分主机厂与 Tier1 已用于前期评估；AUTOSAR 侧联合 Vector、东软睿驰、普华适配，开源侧推进 FreeRTOS／Zephyr／NuttX；并作为核心成员加入中国汽车芯片标准检测认证联盟（CACC）的汽车 RISC-V 工作组。行业口径：RISC-V 在汽车领域的渗透率预计从 2025 至 2026 年的约 10% 升至 2031 年的 31%；Mobileye EyeQ Ultra 已集成 12 颗 RISC-V 核进入量产窗口，地平线征程 6 亦部分采用 RISC-V 内核量产。

2.3 IC WORLD 大会 RISC-V 开放算力论坛：电信「北海」平台、算能服务器 CPU 与 openKylin 适配进展

日期：2026-09-21 报道（会议 09-16 至 09-18）　来源：中国科技网（科技日报）《2026北京微电子国际研讨会暨IC WORLD大会在亦庄举办》、赛迪网《助推RISC-V从「可用」走向「好用」，RISC-V开放算力论坛在京成功举办》、OSChina《openKylin亮相2026 IC WORLD大会，共探RISC-V算力生态建设》

2026 北京微电子国际研讨会暨 IC WORLD 大会（09-16 至 09-18，亦庄）的「RISC-V 开放算力论坛：具身智能·大模型·数据中心」细节在窗口内进一步披露（OSChina 09-21 刊出 openKylin 参会稿）。论坛由北京集成电路学会与 RDI 聚力联盟主办、北京 RDI 创新中心承办：奕斯伟计算副总裁刘帅称 RISC-V 出货增速已超过 x86 和 Arm，公司持续打造 RISC-V 核心部件与方案；中国电信研究院介绍「北海」RISC-V 智算平台建设成果，同时点出软件生态适配难、大规模集群验证不足两个瓶颈；武汉元石智算提出优先从存储、管理场景切入、实现跨架构算力统一调度；openKylin 社区介绍其在硬件适配、AI 能力融合、云原生支持及具身智能场景的进展；北京算能展示量产 RISC-V 服务器 CPU 在智算中心、政务云等场景的落地案例；青岛国实信息分享 RISC-V 支撑海洋可信数据空间的建设方案；北京 RDI 创新中心表示下一步将打造 RISC-V 智算底座验证体系，并布局具身智能端边控制器。

3.1 奕斯伟计算：EIC7X 发布分支与 eic7700_sample 新仓落地

日期：2026-09-21　来源：eswincomputing/u-boot 新建 release-EIC7X-2026.06 分支、eswincomputing/linux-stable 同名分支、eic7700_sample 首次提交

与港交所聆讯同日，奕斯伟计算 GitHub 侧有三项动作：u-boot 与 linux-stable 仓库分别新建 release-EIC7X-2026.06 发布分支（linux-stable 分支近期提交含 ESWIN ISP 媒体子系统一批修复——帧率恢复、isp 重启、imx415 与 dvp2axi 修正——以及 RISC-V DTS 补充；u-boot 分支含内核阶段 HDMI 显示修复、emmc 分区与板级信息修正），并新开 eic7700_sample 仓库（当日首次提交）。EIC7X（对应 EIC7700 系列边缘计算 SoC）发布分支的建立通常意味着版本冻结与对客户发布准备，与聆讯时点相互印证——资本动作与工程交付在同一周内并行动作，是其从「IP 与芯片供应商」转向量产交付节奏的信号。

3.2 算能：sophon-tools 修复批量与 Qwen3 系列 CV84X6 bmodel

日期：2026-09-21　来源：sophon-tools #200：VPSS 使用率抓取（v1.6.0）、LLM-TPU：Qwen3 系列 CV84X6 bmodel、sophon-demo：Qwen3.5 prefix cache 修复

算能三条线同步推进：sophon-tools 窗口内 6 项提交／合并——get_info 新增 bm1688／cv186ah／cv84x6 的 VPSS 各部件使用率抓取（v1.6.0）、修复 CV84X2 网口名判定（按寄存器基址升序区分 WAN/LAN）、修复 bm1684 内嵌打包链的 RECOVERY f2fs 守卫失效、socbak/bmssm 三份同源副本逐字节对齐 v1.5.8、性能历史导出按 web 勾选过滤并给图表横坐标补日期；LLM-TPU 为 CV84X6 补充 Qwen3-Embedding 与 Qwen3-TTS 的 bmodel；sophon-demo 修复 Qwen3.5 的 prefix cache 问题（准确率下降约 3 个百分点与非确定性，三项修复）。工具链、模型资产与示例库三条线的修复密度显示其新一代封装形态（CV84X6／SE13-64）的软件配套仍在快速补全。

3.3 进迭时空：model-zoo-vision 的 RVV 预处理融合优化与 mpp 更新

日期：2026-09-21　来源：model-zoo-vision #86：RVV 加速融合 CPU pack、mpp：流包按 VB 引用传递、ai-sdk 子模块更新

进迭时空视觉模型库 model-zoo-vision 一天内合入 4 个优化 PR，主线是用 RISC-V 向量扩展（RVV）加速图像预处理：先以 RVV 加速融合 CPU pack（#86），再把 face／clip 模型迁移到融合 pack（#87），随后把 tracking pack 与 RVV OCR 识别融合（#88），最后抽出共享的 RVV u8c3 pack 辅助函数完成重构（#89）。同窗口 mpp（多媒体处理平台）在 feat 分支新增「流包按 VB 引用传递」并补齐测试与 cpplint 风格修正；ai-sdk 两次更新 vision 子模块。预处理是 CV 流水线中典型的 CPU 密集段，这一组提交延续了其「把算子从 CPU 通用路径迁到 RVV」的优化惯性。

4.2 2026 全球 AI 芯片峰会：进迭时空披露「大小脑融合芯片」规划

日期：2026-09-21　来源：芯东西《想看AI芯片下一步往哪里走？没来上海峰会的人，看这篇就够了》

据芯东西 09-21 报道，2026 全球 AI 芯片峰会（上海，为期两天）落幕，超 60 位嘉宾、逾百家 AI 芯片生态企业参会。RISC-V 相关看点集中在进迭时空：其芯片产品总监陈俭东介绍基于 RISC-V 推进「同构融合计算」——以统一架构、统一内存与统一软件系统，实现 CPU 算力、AI 算力与实时算力的按需分配；两代芯片已量产，K1 为第一代（AI 算力 2T），K3 为八核 CPU（主频 2.4GHz、AI 算力 60T、支持部署 30B 模型），后续将开发更高算力平台的「大小脑融合芯片」。展会侧，芯来科技、Imagination、进迭时空等企业展出产品方案；具身智能芯片论坛上，维泛智能提出面向具身场景的 BiGPU 仿生类脑架构。峰会以「从 TOPS 到 Token」为主线，反映行业关注点正从峰值算力转向推理场景的软硬协同。

五、总结与趋势观察

  • 资本市场给出「RISC-V 第一股」：奕斯伟计算通过港交所聆讯，2025 年营收 24.31 亿元，计算产品线收入从 2023 年的 37.5 万元增长至 2025 年的 3.20 亿元——比上市叙事更具检验意义的是计算芯片收入曲线的斜率；同日其 EIC7X 发布分支与示例仓库落地，资本动作与工程交付首次在同一周内形成对照。
  • 车规 RISC-V 从「讨论」进入「量产清单」：DF30 计划 2026 年规模量产、年底首批搭载车下线，芯来内核团队扩至约五百人；英飞凌（汽车 MCU 份额 36%）把下一代车规 MCU 全面转向 RISC-V。国内车企与国际大厂在同一时间表上交汇，2026 至 2028 年被视为电子电气架构切换的关键三年。
  • 开源生态的「供给侧」继续加厚：openRuyi 内核双线升级与安全批量、香山昆明湖 V3 与 GEM5 的分支级修复、Bluespec 开源 IP 库 Tape-Out 亮相、simdjson 的 RVV 后端实验——从发行版、处理器到具体库的向量化路径都在推进，RVV 正从旗舰项目下沉为通用库的常规优化目标。
  • 具身智能成为国内 RISC-V 厂商的共同叙事：进迭时空在 AI 芯片峰会披露「大小脑融合芯片」规划，spacemit-robotics 把遥控接收器纳入组件体系；叠加前几期的 ORB-SLAM3、ros2_humanoid 与算能 π0.5 移植，机器人方向的 RISC-V 软件栈在持续增厚。
