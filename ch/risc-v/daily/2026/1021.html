今日重点：蓝芯算力发布智通融合超节点，RISC-V AI 算力从单芯片走向集群

日期：2026-10-19 发布（10-20 集中报道）　来源：经济参考网：蓝芯算力发布智通融合超节点（10-20）、证券日报网：蓝芯算力发布智通融合超节点（10-20）、36 氪：蓝芯算力发布智通融合超节点 RISC-V 加速拓展 AI 推理新场景（10-20）、投资界：蓝芯算力发布智通融合超节点（10-20）

第六届 RISC-V 中国峰会第三日（10-19），蓝芯算力（深圳） 发布智通融合超节点，把基于 RISC-V 的 AI 计算能力从单芯片、服务器推进到集群化算力基础设施。当日 CTO 贾新霞以「LX500：解锁 AI 推理新路径」为题发表演讲。

  • 架构主张：传统「CPU + 独立加速卡」方案要靠 PCIe 在不同内存空间之间搬数据，大模型推理的长上下文与首 Token 延迟被带宽和功耗放大。智通融合把通用计算与 AI 计算集成在同一芯片，并以统一内存架构减少搬运，超节点是这条路线向更大规模系统的延伸。
  • 芯片规格：LX500 集成 48 个 RISC-V 核（32 性能核 + 16 能效核），同时集成 AI Vector 与 Matrix 计算引擎，AI 算力 75 TOPS INT8，支持 INT4 至 FP32 多种精度；共享 DDR5 内存资源，支持 CXL 扩展。
  • 产品节奏：2026 年 2 月芯片点亮，4 月首次公开亮相，5 月发布一体机原型，7 月搭载 LX500 的联想问天 WR5219 G5 服务器亮相，8 月起向多家行业客户送样并进入小批量部署测试。至此形成 LX500 芯片、WR5219 G5 服务器、LX5000 智通融合一体机、智通融合超节点四级产品矩阵。
  • 软件与场景：已围绕 Qwen、DeepSeek、Kimi 等大模型开展适配，覆盖不同参数规模、不同精度与长上下文场景；落地方向为企业私有知识库 RAG、Agent 办公助手、金融合规推理、政府离线问答与工业现场检测。

3.3 乐鑫 esp-emu 0.50.0：P4／S31 融合乘加提速约 3 倍，P4 显存窗口跟随 MMU

日期：2026-10-20　来源：espressif/esp-emulator: esp-emu 0.50.0（10-20）

乐鑫开源仿真器 esp-emu 0.50.0 于 10-20 发布，RISC-V 侧改动集中在 ESP32-P4／S31／C3：

  • 性能：P4 与 S31 的单精度融合乘加改走宿主直通路径，约 3 倍加速，sinf、expf、powf 等数学函数随之受益，结果与标志位保持一致。
  • 内存模型：P4 的 PSRAM 窗口改为跟随 PSRAM MMU，运行时重映射外部内存窗口的固件不再读到全零，也不会在非法指令处 trap。
  • 缺陷修复：C3 与 S3 的 BLE 发射功率 API 在控制器使能后不再触发 Load access fault；P4 针对 rev 0.x／1.x 固件的启动在仿真器侧提前拒绝，并给出改用对应 ROM 或重新编译的两种修法。

仿真器与硅片行为对齐得越细，RISC-V 端侧固件的 CI 才越有替代真机的可能——这也是乐鑫持续投入这条工具链的实际价值。

五、总结与趋势观察

  • RISC-V 的 AI 叙事从「芯片」升级为「系统」：蓝芯算力把智通融合从单芯片推到超节点，睿芯用数据流架构吃 35B 模型的本地推理，中科通量直接给出工作站 + 一体机 + 加速卡的三件套。三家不约而同绕开「对标通用 CPU」，转而按推理场景组织算力——这是本期最清晰的产业信号。
  • 国产团队的差异化在架构层，不在制程层：数据流（睿芯、中科通量）、统一内存与 CXL（蓝芯）、SMT 与 AME 矩阵扩展（达摩院）——在先进制程受限的前提下，这些是能靠设计拿回来的性能。达摩院给出的 C950A 五倍目标，本质也是同一逻辑的延伸。
  • 软件栈的补齐从工具链转向服务端中间件：openRuyi 单日 40 笔提交里，minio、Prometheus、sarama、uwsgi 这类云原生组件占了大头；乐鑫则把仿真器的硅片一致性做到单条指令级。前者决定 RISC-V 服务器能不能承接真实业务，后者决定端侧固件的迭代速度。
  • 资本与产品开始同频：进迭时空 10-19 发布 V100、10-20 完成 B+ 轮，间隔一天；智元以 47 笔投资把本体与上游芯片绑在一起。相比前两年「先融资再找场景」，今年的顺序更像「先出产品再补弹药」。
  • 具身智能的政策底座正在成型：工信部给出全年 10 万台的量级预期，并明确要发布 2026 版标准体系建设指南、建设人形机器人开源社区。对 RISC-V 而言，这是把芯片、中间件与场景接口一并写进规范的时间窗口。
  • 局限说明：蓝芯算力超节点的节点内芯片数量、互联方式与交付时间未公开，现有报道只有方向性表述；睿芯「全球首款量产 RISC-V 数据流物理 AI 芯片」与「Intel 全球采购认可」均为公司口径，未见 Intel 侧公开确认；中科通量产品规格来自厂商在峰会现场的公开介绍，缺少第三方实测；工信部数据发布于 10-19，本期收录依据为其发布会实录与 10-20 的集中报道；会员官网巡检检出的变化均为高校与机构首页例行更新，未发现实质产品、融资或架构发布；香山系仓库组织侧 pushed_at 显示有推送，但默认分支 atom 复核窗口内无新提交，判断为非默认分支活动。
