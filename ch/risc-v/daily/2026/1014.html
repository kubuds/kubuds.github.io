今日重点：蓝芯算力完成近 20 亿元 B 轮系列融资，RISC-V+AI 服务器芯片冲刺量产

日期：2026-10-12（中文媒体首发）／2026-10-13（英文媒体跟进）　来源：凤凰网·投资界：首发｜蓝芯算力完成 B 轮系列近 20 亿融资（10-12）、东方财富（财联社）：蓝芯算力完成近 20 亿元 B 轮融资（10-12）、搜狐（大河财立方）：蓝芯算力完成近 20 亿元 B 轮融资（10-12）、DIGITIMES：China’s Blue Core Computing secures nearly US$300 million（10-13）

深圳 RISC-V 芯片公司蓝芯算力（深圳）科技有限公司完成 B 轮系列融资，合计规模近 20 亿元人民币（约合 2.99 亿美元）：深创投、华控基金、隆湫资本等老股东继续追加，苏国投、苏创投、兆易创新、同创伟业、建银国际、粤科金融、九坤创投等国资、产业资本与头部创投进场。资金将用于 RISC-V CPU 芯片量产落地、AI 异构处理器迭代，以及面向电信运营商、金融机构和云服务商的通用算力解决方案拓展。要点：

  • 产品：核心产品 LX500 为全球首款 RISC-V 通用计算与 AI 智算单芯片原生融合的服务器 CPU——48 核异构设计（32 性能核＋16 能效核），片内集成 75 TOPS（INT8）AI 引擎，支持 RVV 1.0 向量扩展与 RVA23 标准，原生兼容 PCIe 5.0 与 CXL 2.0 内存扩展。
  • 落地：2026 年 2 月流片点亮；7 月搭载 LX500 的联想问天 WR5219 G5 服务器在合肥联宝工厂量产下线；已适配中国移动 BC-LINUX 操作系统，并完成 Kimi K2.6、Qwen3.6-35B 等大模型推理验证。
  • 团队：创始人兼 CEO 卢山为前字节跳动服务器芯片研发负责人（曾任职英特尔、高通），CTO 贾新霞拥有 21 年芯片设计经验。

在 Agentic AI 算力需求与 RISC-V 服务器化两条叙事交汇下，这是 2026 年国内 RISC-V 领域规模最大的融资之一，也标志国产 RISC-V 服务器芯片从”点亮”进入”规模落地”阶段。

一、开源社区与软件生态

1.1 Asterinas 0.19.0：引入 X.Org／DRM 初支持并新增 AArch64 目标

日期：2026-10-13　来源：Phoronix：Asterinas 0.19.0 Brings Up X.Org & Other Improvements To This Rust-Written OS（10-13）

Rust 编写的内存安全内核 Asterinas 发布 0.19.0：首次引入初始 DRM 子系统，在 modesetting 驱动与 Mesa LLVMpipe 之上跑通 X.Org 图形栈，替代此前的传统帧缓冲体验；新增 AArch64 架构支持，与既有的 x86_64、RISC-V、LoongArch64 目标并列；同时推进安全容器、Rust 原生设备模型、自举（self-hosting）与 AI 代码审查模式。该项目以 Linux 软件兼容与内存安全为卖点，是 RISC-V 平台系统软件多样化的观察样本。

1.2 openRuyi：固件线发布「Ruyi Firmware 20261013」，K3 Pico-ITX 全套 UEFI 支持

日期：2026-10-13　来源：ruyifirmware Release 20261013（10-13）、edk2-ruyi 提交记录（10-13）、openRuyi 提交记录（10-13）

openRuyi 项目固件线（ruyifirmware／edk2-ruyi）窗口内集中合入进迭时空 K3 Pico-ITX 平台支持：GOP 图形输出与 EDID 模式、PCI 选项 ROM、RTL8127 有线网卡驱动、引导选择与控制台热键策略、Fastboot 更新校验等；并发布 「Ruyi Firmware 20261013」，提供含 x64 模拟（x64emu）与不含两个固件变体（x64emu 下已验证 AMD Radeon RX 6400）。主仓同步进行 Go 生态软件包（OpenTelemetry 采集器等）SPECS 更新；kiwi-image 新增 riscv64 镜像的 GitHub Action 构建脚本。openRuyi 官网新闻页暂无新版本发布（最新仍为 2026.09 版本）。

1.3 riscv.org 博客：ISA Explorer 学员实践——ISA 配置构建器与扩展沙盒

日期：2026-10-13　来源：RISC-V International：My RISC-V Mentorship: The Problems Nobody Assigned Me（10-13）

riscv.org 刊出 LFX 导师计划学员 Rohit Sharma（印度 JECRC 大学）的实践总结：在 RISC-V ISA Explorer 项目中，除完成既定里程碑外，自主设计并上线两个工具——ISA Configuration Builder（按需勾选核心配置、自动解析依赖、生成工具链可用的配置串并校验冲突）与 Extension Sandbox（新指令设计时即时检查与既有编码的冲突）；同步管线重写为三遍路由，使 1,867 条指令按 83 个 ISA 子集自动归类。工具用于降低自研核配置与自定义扩展的出错成本，是社区教育与工具链建设的样例。

二、产品与生态动态

2.1 Ubitium：1400 万美元种子融资，可重配置 RISC-V「通用处理器」面向物理 AI

日期：2026-10-13　来源：Ubitium 官网新闻稿：UBITIUM RAISES $14 MILLION TO BUILD THE FIRST UNIVERSAL PROCESSOR FOR PHYSICAL AI（10-13）、EE Times：Ubitium Tapes Out First ‘Universal’ RISC-V Chip（背景）

德国杜塞尔多夫半导体初创公司 Ubitium（RISC-V International 会员）宣布 1400 万美元新种子轮：Ibex Investors 领投，OpenOcean、KBC Focus Fund、Runa Capital、Inflection 等参投，累计融资达 1800 万美元。公司主张用一颗可重配置 RISC-V 处理阵列取代”DSP＋NPU＋CPU”的拼凑栈——阵列按运行时需求在信号处理、AI 推理与实时控制三类负载间分配资源。首颗芯片 UB108（256 个处理单元，三星 8nm）已流片并在同一阵列上验证三类负载；首款商用芯片 UB410（4,096 个处理单元）计划于 2027 年交付评估单元，首批客户聚焦雷达与音频等”感知层”应用。

三、国内团队深挖

日期：2026-10-13　来源：llama.cpp Release v0.2.2（10-13）、llama.cpp PR #44：Fix ggml-spacemit op kernels garbling Qwen3.5-2B output on K1（10-13）

接续上一期（独立 ggml-spacemit 后端引入与 v0.2.1），进迭时空 llama.cpp 分支窗口内再发 v0.2.2：合入 Qwen3.5-2B 在 K1 上输出乱码的算子内核修复（#44），并将新后端启用方式完整文档化——须同时设置环境变量 GGML_SPACEMIT_BACKEND 与参数 –device SPACEMIT0 才启用（单独设环境变量不生效）；多模态模型走 –media-backend smt 路径，基准测试用 llama-bench –dev SPACEMIT0。分支保持约 1~3 周的版本迭代节奏，端侧推理可用性持续收敛。

3.2 进迭时空生态：K3 全国产化 mini COM-E 模块推出；Agent 软件线集中建仓

日期：2026-10-12／2026-10-13　来源：CSDN：众达科技推出 SMSM_K3_A 进迭时空 K3 全国产化 mini COM-E 模块（10-12）、GitHub：spacemit-com 组织新建仓库（10-13）、model-zoo-vision 提交记录（10-13）

两条生态动态：其一，众达科技基于进迭时空 K3 推出 SMSM_K3_A 全国产化 mini COM-E（Type 10）模块——16 核同构融合架构、60 TOPS AI 算力、32GB LPDDR5 内存、16MB NOR＋128GB UFS 存储，元器件 100% 国产；支持 Bianbu／Buildroot／银河麒麟 V10，工业级 -40~70℃、典型功耗 13W；AI 侧提供 llama.cpp（GGUF/GGML，可跑 Qwen3-30B 等）与 YOLO、VLM、ASR/TTS 支持，面向 AI 边缘网关、工业服务器与具身机器人等场景。其二，GitHub 侧，进迭时空于 10-13 傍晚集中建仓一批新仓库（bibit 系列、bianbu-agent 系列、agent-power-manager、bianbu-agenic、bianbu-skill 等，目前均为空仓库），指向端侧 AI Agent 系统软件方向的布局；软件侧 model-zoo-vision 新增 CosPlace 视觉位置识别模型，mpp 合入 vdec/venc/RTSP 多项修复，docs-buildroot 更新 K1/K3 屏幕适配文档。

3.3 香山：存储队列修复合入主分支；仿真验证链密集迭代

日期：2026-10-13　来源：XiangShan PR #6693：fix forward older store data（10-13）、NEMU 提交记录（10-13）、difftest 提交记录（10-13）、GEM5 提交记录（10-13）

香山主线（kunminghu-v3）合入存储队列前递旧存储数据修复（#6693）；验证与仿真基础设施多点开花：difftest 新增 MCSim 时序后端（与 DRAMSim3 并列）、mcsr/mcfg 的 delta 编码、面向 FPGA 的 CRC-64 存储队列哈希校验及 PLDM 流程修复；NEMU 加速 AME 矩阵哈希计算、引入 CRC-64 存储队列哈希校验与重复存储日志恢复修复；GEM5 增加 Zimop 指令支持（含 RV64 回归）与 TRACERTL/NEMU 轨迹格式支持。昆明湖平台在正确性验证基建上的推进本窗口较为显著。

3.4 乐鑫：安全自检库 ESP-BIST 发布 v1.1.0，工具链补齐 S31 支持

日期：2026-10-13　来源：esp-bist Release v1.1.0（10-13）、esptool 提交记录（10-13）、esp-video-components 提交记录（10-13）

乐鑫内建自检（BIST）库 esp-bist 发布 v1.1.0——该库对 CPU 寄存器、CSR、中断处理、易失／非易失存储、堆栈与时钟源等硬件做完整性自检，面向 IEC 60730 Class B 等安全关键场景，支持列表覆盖 ESP32-C3／C5／C6／C61 与 H2／H4／P4（均为 RISC-V 内核）；esptool 合入 ESP32-S31 的 ADC 权重 eFuse 字段与 ESP32-H2 芯片变体识别；esp-video-components 修复 OV5647 传感器非连续时钟模式。乐鑫组织窗口内 46 个仓库推送，端侧（含 RISC-V 芯片线）维护节奏密集。

3.5 矽速：逻辑分析仪软件 SLogic 发布 v2.2.0

日期：2026-10-13　来源：SLogic Release release-2.2.0（10-13）、SLogic 提交记录（10-13）、sipeed_wiki 提交记录（10-13）

矽速逻辑分析仪软件 SLogic 在 v2.1.0 后继续发布 v2.2.0：聚焦 arm64（macOS）下捕获长度问题与 ngscopeclient 深存储重新整形不再卡死；同步修复 ALL-LOGIC 在 arm64 下采样深度变量未初始化问题；sipeed_wiki 更新 NanoKVM 多屏镜像文档、修复文档链接，并将站顶提示切至 SLogic32U3 的 Kickstarter 众筹入口。

四、具身智能与机器人专章

4.1 燕心科技：把「符号＋行为＋连接」融入 RISC-V 芯片，做即插即用机器人大脑

日期：2026-10-13　来源：36 氪：大模型能写诗，却走不出工厂围栏——燕心科技把「符号＋行为＋连接」三条路线融进 RISC-V 芯片（10-13，Google News 链接）、英文版（36Kr Europe 同文）

36 氪报道北京初创燕心科技（2025 年 1 月成立）：针对大模型”走不出厂房围栏”的场景泛化痛点，将符号主义、行为主义、连接主义三条技术路线融合为一套「通用具身智能大脑」系统，预封装固化进 RISC-V 芯片，面向机器人厂商提供即插即用的”行业具身智能大脑”，主张支持出厂后持续学习与人机交互示教、纯端侧部署。需要留意：公司仍处早期验证阶段——公开信息显示其注册资本 100 万元、尚在融资路演期，报道亦提示具体技术实现细节、性能指标与量产进度均未公开。可视作 RISC-V×具身智能交叉赛道持续吸引早期创业的又一例证。

4.2 窗口观察：具身智能侧的三条线索

本窗口具身智能与机器人侧呈”两端升温、组合交付”侧影：其一，国际新玩家以差异化架构入局——Ubitium 用可重配置 RISC-V 阵列统一感知、推理与实时控制，获 1400 万美元种子融资（见 2.1）；其二，国内早期创业把”机器人大脑”押注在 RISC-V 芯片化封装（燕心科技，见 4.1）；其三，成熟厂商侧，进迭时空 K3 持续向机器人与边缘场景输送”芯片—模块—软件栈”完整链路（K3 COM-E 模块与 llama.cpp／模型库软件线，见 3.2），其机器人专项组织 spacemit-robotics 窗口内无新推送。三条线索共同指向：RISC-V 在具身智能的竞争正从”单点芯片”转向”芯片＋大脑软件＋场景封装”的组合交付。

五、总结与趋势观察

  • 资本与产品双线共振：蓝芯算力近 20 亿元 B 轮与 Ubitium 1400 万美元种子轮同期落地，高性能／物理 AI 方向的 RISC-V 芯片成为全球资本集中加注的赛道；国内 RISC-V 服务器芯片进入”量产验证”阶段（LX500＋联想整机量产＋运营商操作系统适配）。
  • 产业日程临近：第六届 RISC-V 中国峰会 10 月 18-20 日深圳举行，达摩院玄铁、奕斯伟、蓝芯、进迭等集中亮相；叠加 Ubuntu 26.10（10 月 15 日发布）首次提供官方 RISC-V 桌面镜像，下周为观察窗口。
