今日重点：LPC26 归来——RVA23u64 内核 profile 位推进，8 枚补丁已入 riscv/for-next

日期：2026-10-11　来源：微信公众号「Docular嘚吧嘚」：LPC26 参会记（10-11）、LPC26 演讲材料（slides）、作者主页：Docular

RVA23 内核工作主要推动者徐国栋（Docular，现就职高通）发布 Linux Plumbers Conference 2026（LPC26，布拉格）参会记：其主导的 Linux 内核 rva23u64 profile 位系列正推进至 v9（在途），10 月 9 日 v8 的 11 个 patch 中前 8 个已被 RISC-V 内核维护者 Paul Walmsley 收入 riscv/for-next（等下一合并窗进主线），其余 3 枚核心 patch 将吸收 LPC 现场意见后随 v9 提交。

  • 要解决的问题：RVA23 profile 1.0（2024-10 批准，39 必选 + 15 可选扩展）需要内核与用户态低成本回答「这台硬件是不是 RVA23」——现状只能逐 bit 查询，glibc、GCC 各算各的，Ubuntu 侧的检测工具也只能给出 “probably RVA23”。方案是内核启动时算出 “RVA23 compliant” 位放入 vDSO，用户态经 hwprobe UAPI 一读即得。
  • LPC26 四个 Ask 的结论：① v8 位形态获维护者认可，v9 将补充 RVA22 / RVA20 分级位（便于 glibc 逐级回退）并写明不继承 IMA 位的历史遗留行为；② glibc 将改为按 profile 构建 + glibc-hwcaps 自动选库（hwcaps 来源即内核位；ifunc 留给微架构级选择），GCC 维护者 Jeff Law 在 GNU Tools Cauldron 的 RISC-V BoF 同向推进；③ 用户态动态关闭 V 扩展的接口将废弃——LPC 次日 Samuel Holland（SiFive）即发出 3-patch 系列（cover letter：RISE 与 LPC26 已形成共识，create more trouble than benefits）；④ 未来带寄存器状态的扩展（如 matrix）不会再引入同类开关。
  • 外溢效应：该系列直接或间接带动不少于 5 个主线系列——两块搁置两年的旧补丁（扩展名大小写统一、Zicclsm）被吸收，字节跳动 Qingwei Hu 贡献 Zic64b 支持，另有 do not report disabled extensions（6 patch 系列）、cpufeature BUNDLE 到 SUPERSET 精简、V-off 废弃系列同期发出。
  • 补充：本届 LPC 的 RISC-V MC 共 10 场 talk，高通占 3 场；该 talk 的 slides 已公开（见参考链接）。

一、开源社区与软件生态

1.1 Phoronix／LPC26：内核自动向量化取得积极结果，LZ4 最高提升约 15%

日期：2026-10-11　来源：Phoronix：Auto Vectorizing The RISC-V Linux Kernel Shows Promising Results（10-11）、LPC26 演讲页：Optimizing the kernel with vector、Hacker News 讨论

RISC-V 内核构建目前尚未启用 V（向量）扩展。Andy Chiu 在 LPC26（10 月 5-7 日，布拉格）演讲「Optimizing the kernel with vector」，介绍以编译器自动向量化优化内核的做法：针对 crypto、RAID、XOR、用户拷贝等内核场景的实验显示——LZ4 最大提升约 15%、Btrfs 约 8.4%、XFS 约 5%、Nginx 场景约 2%；代价是向量上下文管理带来的时间与内存开销上升，内核态使用向量单元仍有既有约束。Phoronix 评价该方向「前景可观」（promising results），演讲材料已随会议公开。

1.2 RevyOS：内核同步 6.17.11 配置，启用 Rust／PowerVR／NTSYNC 等特性

日期：2026-10-11　来源：revyos/linux 提交记录（10-11）

RevyOS（面向多平台的 RISC-V Debian 发行版）内核仓库窗口内 50 笔提交：将内核配置批量同步至 6.17.11 基线，新增 K1/K3、DP1000、SG2042/SG2044、TH1520 等平台配置，启用 Rust、PowerVR DRM、NTSYNC、K3 显示控制器与 UFS、SPACEMIT PM 域、FUSB301 Type-C 控制器等；设备树为 K3 Pico ITX 启用 GPU 与 USB3 端口、为 Milk-V Meles 启用 USB；CI 新增交叉/原生构建。K3 等平台的显示、USB、存储与 GPU 支持在发行版内核侧密集补齐。

1.3 openRuyi：SPECS 更新 Go 1.27.2 与 OpenSSL 3.6.5，docker-cli 独立打包

日期：2026-10-10　来源：openRuyi 提交记录（10-10）、lookout 提交记录（10-11）、openRuyi 官网新闻页（10-12 核查）

openRuyi 仓库窗口内 5 笔 SPECS 更新：Go 升级至 1.27.2、OpenSSL 升级至 3.6.5、新增 docker-cli 独立包（moby 的 Provides 迁移至 docker-cli）；PR 模板修正链接。同组织版本巡检工具 lookout 窗口内 10 笔提交，推进 Go 组件从可信来源标签自动发现、精确 Go 版本跟踪与 NVD 安全身份核验等能力。官网新闻页核查：最新发布仍为 2026.09 版，无新版本公告。

M5Stack 推出防水型工业 IoT 控制器 ToughC5（2021 年 M5Stack TOUGH 的升级款）：基于 ESP32-C5（单核 RISC-V @240MHz + 低功耗 RISC-V 核），双频 Wi-Fi 6、BLE 5、802.15.4（Zigbee 3.0／Thread 1.3）、8MB Octal PSRAM、16MB 闪存、2.0 英寸 320×240 触摸屏（最高 853 尼特）、RS485 与 4 路 HY2.0-4P 扩展、RX8130CE RTC（独立纽扣电池）、6-24V 供电；防水外壳内置 USB-C 与 4-pin 扩展口，配 M12 走线。面向工业现场控制、户外边缘采集与智能楼宇，售价 49.9 美元。

2.3 产业观察：高通诉 Arm 庭审就 RISC-V 数据中心成熟度展开攻防

日期：2026-10-11　来源：Wccftech：Even Court Judges Are Now Declaring That RISC-V Is Basically Worthless（10-11）

围绕高通诉 Arm 的许可纠纷庭审（特拉华州联邦法院），RISC-V 意外成为庭上话题：Arm 专家证人 Timothy Simcoe 称 RISC-V 与 x86 构成「长期竞争压力」；主审法官 Noreika 追问 RISC-V 当下可用性，证人承认其企业数据中心部署尚处早期、相关设计主要来自中国企业（如阿里玄铁），主审法官随后未再深究。该报道以夸张标题流传引发社区热议；讨论焦点为企业数据中心场景，与 RISC-V 在嵌入式与边缘的既有落地进展无直接矛盾。

2.4 行业分析：x86／Arm／RISC-V 在工业边缘「正面相遇」

日期：2026-10-10　来源：36 氪：《x86、Arm、RISC-V 在工业边缘正面相遇》（10-10）

边缘 AI 爆发让三条架构在工业场景正面竞争：《半导体产业纵横》（36 氪授权发布）梳理——x86 靠生态（英特尔 Open Edge Platform、AMD 锐龙 AI 嵌入式 X100 最高 80 TOPS，巡检机器人已落地）；Arm 靠能效与异构（瑞芯微 RK3572 集成 RISC-V 核、RK182X 协处理器内置多核 RISC-V，已导入数百客户项目）；RISC-V 靠开放可定制（玄铁 C950、芯来 NA900 通过 ASIL-D、奕斯伟 R500A 通过 ASIL-B 认证）。文中判断 2030 年 RISC-V 在工业边缘芯片出货占比或从不足 7% 升至 24% 以上，竞争关键在工具链、RTOS 与认证体系；并预告 10-12 起上海工博会国芯展设「RISC-V 能否啃下工业边缘的硬骨头」论坛。

三、国内团队深挖

3.1 香山：压缩 ROB（crob）架构特性合入，MMU 与运算单元修补

日期：2026-10-10/11　来源：XiangShan 提交记录（10-10/11）、PR #6695：MMU 忽略 PTE G 位、PR #6689：窄移位偏置

香山主仓窗口内 10 笔合入：压缩 ROB（crob）架构特性落地——实现压缩 ROB 并集成 CSR 状态跟踪，配套重构压缩状态与时限路径、为 ArchEvent 携带事件位置、以条目偏移保持有序存储检查、修复 scommit 位宽并扩充条目数；另修复 MMU（V=0 时忽略 PTE 的 G 位，#6695）、运算单元窄移位偏置按输出格式选择（#6689）与 CI 性能报告（#6702、#6705）。

3.2 香山仿真链：difftest 新增并行存储哈希校验，NEMU／GEM5 特性分支推进

乐鑫多仓库持续维护：esp-vision 新增 nano track 目标跟踪支持与传感器 IPA 统计接口（10-11）；esp-sr 更新预编译库（10-10）；esp-idf 合入 BLE 命令 IRAM 占用削减、ESP32 TWAI 随机接收数据错位勘误修复、PSRAM 速率 DFS 与 H4 ECO2 晶振依赖等修复（10-10）。乐鑫组织窗口内 25 个仓库推送，端侧（含 RISC-V 芯片线）维护节奏密集。

五、总结与趋势观察

  • 内核底层两线并进：LPC26 后 RVA23u64 profile 位已有 8 枚进入 riscv/for-next（glibc 将按 profile 构建分发、用户态动态关闭 V 扩展的接口将废弃）；内核自动向量化实验给出 LZ4 约 15% 级收益，「内核态用向量」这一长期禁区正被重新评估。
  • 发行版配置升级：RevyOS 内核同步 6.17.11 并为 K3／TH1520／SG2042 等平台启用 Rust、PowerVR、NTSYNC 等特性；openRuyi 更新 Go／OpenSSL 并拆分 docker-cli，lookout 巡检能力增强。
  • 边缘竞争叙事成型：36 氪长文与高通诉 Arm 庭审讨论指向同一判断——RISC-V 在嵌入式／边缘已具「参赛资格」，数据中心仍需时间；第 26 届中国工博会国芯展今日（10-12）起在上海举行。
  • 端侧与国内团队落地：乐鑫（esp-vision 跟踪与 IPA 统计）、算能（zsbl v3.2.1、LLM-TPU 模型适配）、矽速（SLogic v2.1.0）、进迭时空（机器人外设库、文档术语统一）均有实质提交。
  • 待观察：Ubuntu 26.10（10-15 发布）RISC-V 桌面镜像的实测反馈；RVA23 系列 v9 提交与内核向量化讨论走向；香山压缩 ROB 的后续性能验证。
