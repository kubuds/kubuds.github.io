今日重点：进迭时空 llama.cpp 分支引入独立 ggml-spacemit 后端，发布 v0.2.1

日期：2026-10-12　来源：spacemit-com/llama.cpp PR #43：Add standalone ggml-spacemit backend（10-12）、llama.cpp 分支 Release v0.2.1（10-12）

进迭时空的 llama.cpp 分支仓库合入 PR #43，引入独立的 ggml-spacemit 后端，与既有 CPU 路径实现双后端共存：

  • 独立后端为显式启用：未启用时设备注册表报告零设备、默认行为保持不变（仍走传统 CPU 路径）；启用须设置环境变量
    GGML_SPACEMIT_BACKEND 为 1，使用者通过 --device SPACEMIT0 选择该后端。
  • 构建修复：调整 libggml-cpu 与 libggml-spacemit 两个库的构建方式，修复两者之间的符号插入（symbol interposition）冲突。
  • 同日发布 v0.2.1（上一版 v0.2.0 于 09-24 发布）——分支版本号保持约 2~3 周的迭代节奏。

叠加本窗口其他进迭时空更新（xslim 静态量化支持忽略算子、模型库新增 RT-DETR 与 MNN 后端，见 3.6）以及 Ubuntu 26.10 对 K3 的官方支持临近（见 1.1），K3／K1 端侧 AI 推理与桌面上层生态链路在公司内外同步完善。

一、开源社区与软件生态

1.1 Ubuntu：26.10 RISC-V 桌面镜像进入发布前测试周

日期：2026-10-12　来源：NeoTeo：Ubuntu 26.10 RISC-V desktop images: what to test（10-12）、新浪财经：Ubuntu 计划推出适配 RISC-V 指令集的官方 26.10 桌面镜像（10-12）、Canonical Discourse：Announcing Ubuntu Desktop Images for RISC-V（10-09，背景）

Ubuntu 26.10（Stonking Stingray）定于 10 月 15 日发布，riscv64 桌面镜像进入发布前最后一周的集中测试期。本窗口测试侧跟进：NeoTeo 发布「测什么」测试指引（10-12），新浪财经等中文媒体跟进报道（10-12）。此前已报道的要点：Ubuntu Desktop 首次提供 RISC-V 官方镜像，另有实验性 Xubuntu Minimal 镜像（建议虚拟机试用）；官方推荐在 SpacemiT K3（Pico-ITX）上测试（26.10 起为该平台提供官方支持）；完整桌面体验面向 RVA23 级硬件（Milk-V Jupiter 2、DeepComputing DC-ROMA、SiFive HiFive Unmatched）；真机启动需自行放入首级引导（U-Boot）与设备树；缺陷报告走 Launchpad。

1.2 RevyOS：内核配置批量扩充——新增奕斯伟 EIC7700 与 linuxboot、Type-C 栈支持

日期：2026-10-12　来源：revyos/linux 提交记录（10-12）

RevyOS 内核仓库窗口内 20 笔提交，对配置进行第二轮批量扩充（此前 10-11 的一轮为基线同步）：新增奕斯伟（ESWIN）EIC7700 平台支持（ARCH_ESWIN、DWMAC_EIC7700 网卡、PINCTRL_EIC7700，并启用 DRM_AST 显示）与 DP1000 平台配置；为 K3 启用显示控制器与 UFS；为 K1（Banana F3） 启用 USB2；启用 Type-C 协议栈（TYPEC／TCPM／UCSI／FUSB301／DP_ALTMODE／PHY_SPACEMIT）与 RTC_DRV_EFI、PWM 风扇传感器等；新增 linuxboot 配置；CI 增加交叉与原生构建。发行版侧对国产 SoC（K1／K3／EIC7700）与 TH1520 的平台化支持持续走深。

1.3 openRuyi：KDE Plasma 桌面栈升级至 6.7.5，lookout 发布 v0.2.5

日期：2026-10-12　来源：openRuyi SPECS 提交记录（10-12）、lookout Release v0.2.5（10-12）、lookout 提交记录（10-12）

openRuyi 发行版仓库窗口内 20 笔提交：将 KDE Plasma 桌面栈批量升级至 6.7.5（plasma-workspace／plasma-desktop／powerdevil／plasma-nm／systemsettings／sddm-kcm 等 19 个包），并加入面向 AI 编码代理的说明文件 AGENTS.md。配套工具 lookout 发布 v0.2.5：修复搜索结果受筛选条件影响的问题、发布任务显示计算版本、CI 集成覆盖率（Cobertura）报告并补充测试。另有 kernel-team-tools、homepage 等仓库推送；官网新闻页最新仍为 2026.09 版本（本期无新发布）。

1.4 技术社区：RVBNA（批量归一化算法）解析文章发布

日期：2026-10-11（10-12 经 Hacker News 传播）　来源：FProx：RISC-V Bulk Normalization Algorithm (RVBNA)（10-11）、Hacker News 讨论（10-12）

社区作者 FProx 撰文解析 RVBNA（RISC-V Bulk Normalization Algorithm）——一种可扩展的点积（dot product）近似计算方案：以定点累加器为核心，乘积与累加两个阶段均采用 round-to-odd 舍入，牺牲少量精度换取实现成本与延时的可伸缩性（累加器 guard 位数随累积项数扩展）。RVBNA 已写入 RISC-V ISA 手册草案（5 月并入），当前集成于两个扩展项目：向量矩阵扩展 VME 的 Zvt 家族（riscv-isa-manual PR #2997）与大批量点积扩展 Zvdota／Zvbdota（PR #2618）。文章系统比较了 FP MUL+ADD、FMA、Kulisch 精确累加等方案的精度—成本权衡，并开源了误差评估器（rvbna-explorer）。

二、产品与生态动态

2.1 元（Meta）：开源 Muse Gadgets SDK，官方 Home Link 硬件基于 ESP32-C5

日期：2026-10-12　来源：CNX Software：Facebook releases Muse Gadgets SDK for ESP32 and Raspberry Pi/Linux-based devices（10-12）、facebookincubator/muse-gadget-sdk（GitHub）

Meta 发布开源 Muse Gadgets SDK（Apache-2.0），让自制硬件接入其个人 AI 助手 Muse：含 ESP32 设备 SDK（显示图像、音频输入输出、传感器/执行器接口，支持多款 ESP32 开发板，覆盖 ESP32-C5／C6 等 RISC-V 芯片型号）与 Linux 设备 SDK（树莓派等，提供 system.run、file.read/write 等指令）；另含第三方设备技能目录（智能家居、打印机、3D 打印机等）。Meta 自制 五千台 Muse Home Link 面向美国订阅用户免费发放，硬件基于 ESP32-C5（双频 Wi-Fi 6、BLE、802.15.4）。这是 RISC-V 无线 MCU 进入大厂消费级硬件的最新案例，也显示 ESP32 生态正被用作个人 AI 代理的硬件底座。

2.2 行业分析：AI 负载加速 RISC-V 采用，SHD 预测 2031 年 SoC 出货 359 亿颗

日期：2026-10-12　来源：Bisinfotech：Why AI workloads are accelerating RISC-V adoption（10-12）

行业媒体 Bisinfotech 刊文分析 AI 与边缘计算如何重塑 SoC 设计取向：性能瓶颈从主频转向数据搬运、内存层次与互连效率；异构 SoC 中 RISC-V 适合承担控制与系统管理角色，并为矩阵／张量运算等定制扩展留出空间。文章引用 SHD Group《2026 RISC-V 市场报告》：预计 2031 年 RISC-V SoC 出货量达 359 亿颗、CAGR 约 31.7%，并强调软硬件协同（编译器/运行时对自定义指令的支持）与 pre-silicon 验证（FPGA 原型）对定制 RISC-V SoC 落地的重要性。

三、国内团队深挖

3.1 香山：MBTB 全相联 vBTB 合入主分支；NEMU 发布 v2026.10.r3

日期：2026-10-12　来源：XiangShan PR #6587：implement a fully associative vbtb（10-12）、NEMU 提交记录（10-12）、NEMU Release v2026.10.r3（10-12）

香山主分支（kunminghu-v3）窗口内合入 PR #6587：为 MBTB（主分支目标缓冲）实现全相联 vBTB（虚拟分支目标缓冲）。仿真基础设施同步推进：NEMU 将 AME 矩阵扩展的指令分发与物理内存（PMEM）访问解耦重构（#1249），并发布 v2026.10.r3 版本。difftest／GEM5／XSCache 窗口内推送集中在特性分支（主分支无窗口内提交）。这是继上期压缩 ROB（crob）合入之后，香山在乱序前端结构与矩阵扩展仿真两条线上的连续投入。

3.2 达摩院玄铁：合规测试框架引入 T-SBI，测试套件迁移至 S 模式执行

日期：2026-10-12　来源：damo-rv-priv-ats PR #37（10-12）、damo-rv-priv-ats 仓库

达摩院玄铁（XUANTIE-RV）组织下的 damo-rv-priv-ats 合规测试框架（覆盖 RISC-V 特权级规范 90 余个扩展、以裸机程序直接运行于 QEMU／Sail／Spike／FPGA）合入 PR #37：引入 T-SBI（Test Supervisor Binary Interface）协议层，并将全部测试套件迁移到 S 模式常规执行模型——启动阶段完成仅 M 模式的初始化后，在 main() 之前降至 S(HS) 模式执行。动机是原先把测试体跑在 M 模式下无法建模 S/HS 视角下的寄存器行为（例如 Smstateen 门控 CSR 在 HS 模式读取时应陷入）；迁移后测试运行位置与规范判定场景一致。该组织窗口内 73 个仓库仅此一仓推送。

3.3 算能：SG2042 平台软件包集中发布——SDK v20261012 与 EDK2 v1.5.0

日期：2026-10-12　来源：bootloader-riscv 提交记录（10-12）、edk2-platforms Releases（10-12）、LLM-TPU 提交记录（10-12）

算能（SOPHGO）SG2042（64 核 RISC-V 服务器芯片）平台软件包窗口内集中发布：bootloader-riscv 发布 SG2042 SDK v20261012（含新增发布脚本），edk2-platforms 发布 SG2042 EDK2 v1.5.0，edk2／edk2-non-osi／sophgo-edk2 等仓库同步推送。AI 侧：LLM-TPU 新增 MiniCPM5-2B（20 亿参数）Python 演示（面向 BM1684X／CV84X6 平台），并将 bge-reranker-v2-m3 重排序、MinerU2.5-Pro 文档解析的适配提交完成并入。SG2042 固件与 SDK 侧保持持续迭代。

3.4 乐鑫：ESP-GMF 多媒体框架发布 v1.1，esp-vision 增加 LCD 触摸支持

日期：2026-10-12　来源：esp-gmf Release v1.1（10-12）、esp-vision 提交记录（10-12）、esp-idf 提交记录（10-12）

乐鑫多媒体框架 ESP-GMF 发布 v1.1（上一版 v1.0 于 6 月发布）：新增 Reverb 与 Delay 音频效果、ALC 过渡时间控制、配置读取接口与 bypass 支持，改进蓝牙音频、播放与多路 sink 采集，扩展多媒体管线运行时控制能力。设备侧：esp-vision 合入 LCD 触摸驱动支持；esp-idf 主分支合入 RISC-V 追踪（trace）快照重构、BLE 日志控制台文档与 CI 目标测试等改动。乐鑫组织窗口内 38 个仓库推送，为当日最活跃关注组织。

3.5 矽速：SLogic 新增 SLogic16U3 型号适配与 USB 链路速率自检

日期：2026-10-12　来源：SLogic 提交记录（10-12）、ALL-LOGIC 提交记录（10-12）

矽速逻辑分析仪软件 SLogic（v2.1.0 于 10-10 发布）窗口内继续修进：回归自检自动识别型号并新增 SLogic16U3 支持；新增 Windows 下 USB 链路速率探测（10G／5G）；吞吐测量改为从首字节起算（排除冷启动干扰）；将「首个 32 位丢弃」改为按型号的独立 quirk 并同步全部代码副本；补充逐步回归检查清单文档。ALL-LOGIC 仓库同步 libslogic 变更。矽速组织窗口内 6 个仓库推送。
