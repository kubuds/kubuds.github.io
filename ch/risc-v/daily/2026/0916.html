今日重点：RISC-V 产业化的政策与资本双信号

日期：2026-09-15　来源：观点网《两部门：推进 RISC-V 产业化》、观察者网《加强开源鸿蒙等国产操作系统搭载，推进 RISC-V 研发与产业化》、新浪财经《电子信息制造业发展”十五五”规划》、北京商报《欲冲击北交所 IPO！芯来科技启动上市辅导》

9 月 15 日，工业和信息化部与国家发展改革委联合印发《电子信息制造业发展”十五五”规划》。规划第 9 条”推进软硬协同和电子系统设备突破”中明确写入：推进第五代精简指令集（RISC-V）研发与产业化，支持 RISC-V 芯片在人工智能、嵌入式系统等领域应用。同条还提出”强化开源开放与协同共建，加强开源鸿蒙等国产操作系统搭载，打造基于计算的人工智能软硬件全栈生态，健全配套软硬件协同适配工具”，以及”深化芯模协同创新，加强算法与硬件架构协同设计优化”。

这一表述的分量在于三点。其一，层级：这是工信部与发改委两部委联署的五年期产业规划，而非地方规划或行业倡议——9 月初北京市”十五五”数字经济规划曾点名 RISC-V 智算指令集与众智（FlagOS）开源生态，此番是国家部委层面的同类定调，形成”中央加地方”的政策叠层。其二，写法：RISC-V 被写入”软硬协同”条目且与开源鸿蒙并列，指向的是”开放指令集加国产操作系统”的组合路径，而非单点芯片攻关；”支持在人工智能、嵌入式系统等领域应用”则给出了明确的应用牵引方向，与国内产业界”端侧推理是 RISC-V 最佳切入点”的共识一致。其三，时点：该规划发布正值 RISC-V 在数据中心侧出现上游软件突破（同日 SiFive 与 AMD 宣布 ROCm 适配，见 2.1）与国内 CPU IP 龙头启动资本化（芯来科技，见 3.1），政策、技术、资本三条线在同一周交汇。

资本面的对应信号：同日前后披露的芯来科技北交所上市辅导，是”政策定调”在资本市场侧的直接映射。辅导备案报告显示，这家 2018 年成立、胡振波创办的上海 RISC-V CPU IP 公司已于 9 月 8 日与招商证券签署辅导协议，9 月 9 日向上海证监局提交备案材料，9 月 11 日完成备案；公司此前已于 8 月 28 日挂牌新三板创新层，并计划在挂牌后 12 个月内提交北交所发行上市申请文件。若顺利推进，将成为 A 股市场首家以 RISC-V 商业 CPU IP 为主业的上市公司。详细财务与股权分析见第三章 3.1。

判断与边界：政策条目本身是”规划语言”，不构成具体资金或项目安排，其兑现取决于后续配套细则、地方承接与产业界的实际投入；本报告按公开规划文本如实收录，不做过度的落地预期推导。需要持续跟踪的是三个观察点：是否有配套的专项资金或首台套政策跟进、是否有面向 RISC-V 的国家级测试认证体系建立、”开源鸿蒙加 RISC-V”的组合是否出现规模化的整机落地案例。

一、开源社区与软件生态

1.1 香山：CommonHR 与取指异常两处修复合入

日期：2026-09-15　来源：OpenXiangShan/XiangShan 提交记录

开源高性能 RISC-V 处理器香山在窗口内共 2 次提交，延续前一交易日”分支预测收敛后转正确性打磨”的节奏。其一是 #6557，修正 CommonHR（共用历史寄存器）在 s2_override 之后 s0_commonHR 使用不正确的问题——CommonHR 是香山用于在分支预测器中共享历史信息的结构，s2 级覆写后若 s0 级仍读旧值会导致预测历史与真实执行路径不一致，属典型的多级流水共享状态正确性修复。其二是 #6207，把 IFU 的异常支持收窄为仅 fb(1) 一种形式，即只保留取指缓冲层面的单类异常通路，属对异常分类与触发条件的收敛。两处均为小改动、边界类修复，未见新特性级推进；前一交易日（09-14）已集中合入的 ITTAGE useful 计数器掩码、IFU/FTQ 自修改代码分支训练、向量 VMove 浮点 boxing 等条目本报告不重复收录。

1.2 香山仿真链 NEMU：页表读取与 MMU 身份地址缓存提速，矩阵访存加可见性检查

日期：2026-09-15　来源：OpenXiangShan/NEMU 提交记录

香山参考模拟器 NEMU 在窗口内 5 次提交，主线是性能优化而非功能扩展。#1138 精简 riscv64 通用页表读取路径，减少常用路径上的重复判断；#1011 为 riscv64 MMU 缓存”身份映射有效地址”状态，即在已知虚拟地址等于物理地址时跳过翻译查表——这两项都直接作用于内存访问这一仿真热点。#1137 为逐基本块的性能剖析增加”非活跃时关闭”的门控，避免 profiling 开销污染基准数据；#1210 抑制 clang-18 及以上版本的配置告警。最值得关注的是 #1212（feat(ame)）：在矩阵加载之前检查标量与向量的存储可见性——AME 是香山面向矩阵扩展的仿真支持，此项修复针对的是”矩阵单元读取数据时，此前由标量/向量指令写入的数据是否已可见”这一内存模型一致性问题，属矩阵扩展仿真在正确性层面的补强。整体看，NEMU 正同时向”跑得快”（页表/MMU 缓存、profiling 门控）与”仿得准”（AME 可见性）两端推进。

1.3 香山仿真链 GEM5：cbo.zero 经 O3 存储缓冲实现，ROB 排空后处理挂起中断

日期：2026-09-15　来源：OpenXiangShan/GEM5 提交记录

香山配套的 GEM5 仿真模型在窗口内 5 次有效提交，集中在 RISC-V 架构语义与乱序核时序两处。#1153 让 cbo.zero（缓存块清零指令，RVA23 相关的基础设施指令）通过乱序核的存储缓冲执行——这意味着该指令不再需要单独的特殊通路，可直接复用存储流水线，既简化实现也让清零操作获得与普通存储一致的排序语义。#1149 处理 ROB（重定序缓冲）排空之后的挂起中断：ROB 排空是精确异常与中断投递的关键时机，此前在排空瞬间到达的中断可能被遗漏，此项修复补上了该窗口。#1154 改进香山 SE（系统调用仿真）模式支持，#1157 把测试断言换成受支持的写法。这批改动显示香山在 GEM5 上的仿真保真度正从”功能可跑”进入”时序与异常语义对齐真实硬件”的阶段。

1.4 CORE-V：CVW 修 U 模式缺失时 mstatus.MPP 复位值非法问题

日期：2026-09-15　来源：openhwgroup/cvw 提交记录

CORE-V 生态中的 CVW（Wally 教学与验证处理器）在窗口内提交 #1870，修复”不支持 U 模式时 mstatus.MPP 复位值非法”的问题。mstatus 的 MPP 字段记录上一次特权级，便于 mret 返回到正确层级；当核心配置为不支持用户态（仅 M 模式）时，MPP 若复位为表示 U 模式的值即构成非法状态，会在特权级切换与异常返回时引发未定义行为。这与前一交易日已收录的 #1864（U 模式缺失时 mcounteren 非法访问）属同一批次的特权态边界清理——即团队在系统性地梳理”精简配置下（无 U 模式）特权寄存器复位值与访问权限”的一致性。配套的 CVA6 仓库窗口内无新提交（最近一次为 09-13 的 HLVX 执行权限修复）。

1.5 revyos：K3/K1 内核配置批量合入，新增 LinuxBoot 与交叉构建 CI

日期：2026-09-15　来源：revyos/linux 提交记录

面向进迭时空平台（K1/K3）的 revyos 发行版内核仓库在窗口内一次批次合入 8 次提交，作者日期跨度从 2026-04-03 至 2026-09-15，属典型的积压批次落地（按合入时间计）。内容几乎全部是内核配置项：为 K3 开启 UFS 与 DC（显示控制器）、为 Banana Pi F3 开启 K1 USB2、开启 SENSORS_LM63 温度传感器、开启 CONFIG_ERRATA_PICOHEART 勘误处理、开启 RESET_GPIO，并新增 LinuxBoot 配置与”交叉编译加原生编译”的 CI 流程。同日 revyos 生态下的固件栈（firmware-sg204x、sophgo-edk2、edk2-platforms、edk2）四仓在同分钟内推送，属 EDK2/UEFI 固件同步更新。信号意义在于：K3 的显示与存储（UFS）通路正在被逐项打通，LinuxBoot 与 CI 的引入说明该发行版的构建与引导链路趋于工程化，而非停留在单板调试阶段。

二、产品与生态动态

2.1 SiFive 与 AMD 合作在 RISC-V 数据中心服务器上优化 ROCm

日期：2026-09-15　来源：SiFive 官方新闻稿、Business Wire 原始发布、Yahoo Finance 转载

RISC-V 创始公司 SiFive 与 AMD 联合宣布，双方正合作把 AMD 的开源软件生态 ROCm 移植优化到 RISC-V 数据中心服务器平台，并在 SiFive 的 BigSky 数据中心开发平台上完成演示。演示硬件为 BigSky SF-2U870：32 颗 P870-D 核心运行于 2.0 GHz、256 GB DDR5-5600 内存、4 路 PCIe Gen5 x16（共 64 lane）加 PCIe Gen3 x4、2 块 7.68 TB U.2 NVMe 固态盘、10/25 Gb OCP 3.0 网卡，平台现已可订购。现场演示于 9 月 15 日至 17 日在美国圣克拉拉会议中心举行的 AI Infra Summit 上进行，展位位于 RISC-V International 展区内的 SiFive 展台。

双方表态的分寸值得注意。SiFive 数据中心高级副总裁 Matt Langman 称，把 ROCm 开源软件生态带到 BigSky 平台，”让超大规模厂商与开发者能够在 RISC-V 上无缝运行先进 AI 负载”，并称之为加速 RISC-V 进入数据中心”又一个关键里程碑”。AMD 方则由 AI 软件产品管理企业副总裁 Ramine Roane 定性为”早期一步“（early step）——即演示的意义在于”让开发者开始探索基于 ROCm 的 AI 加速在 RISC-V 宿主平台上”的可行性，而非宣称生产可用。两家公司表示将继续评估在 RISC-V 服务器上优化 ROCm，目标是加快处理速度、支持更多加速场景与更大模型。

为何值得关注：这是 RISC-V 数据中心路线在软件栈上的一个关键节点。此前 RISC-V 进入数据中心的公开叙事多围绕 CPU 核性能与 IP 授权（SiFive P870-D、Ventana、Tenstorrent 等），而 AI 服务器真正的准入门槛在加速器软件生态：ROCm 若能在 RISC-V 宿主上跑通，意味着”RISC-V CPU 加 AMD GPU”可以构成一条不依赖 x86 的算力组合。呼应关系上，中科院软件所此前已公开完成 ROCm 对 RISC-V 架构的适配并称大模型推理性能有数量级提升，此次是 AMD 官方首次以合作方身份背书该方向。边界同样清楚：演示不等于产品化，ROCm 在 RISC-V 上的算子覆盖度、性能成熟度与长期维护承诺均待验证，AMD 措辞中的”early step”也提示不宜过度解读为战略转向。

2.2 奥维领芯 RV9000 系列异构 SoC 流片点亮，模块化可配置架构完成硅上验证

日期：2026-09-15　来源：界面新闻《奥维领芯 RV9000 流片点亮 RISC-V 模块化可配置异构平台实现工程化落地》、36 氪项目库：奥维领芯

深圳奥维领芯科技有限公司（成立于 2023 年 4 月，专注 RISC-V 高性能处理器芯片与 CPU IP）宣布，自研 RV9000 系列异构 SoC 芯片完成流片封装，芯片上电启动正常，核心基础模块测试一次性通过，运行符合设计预期。本次点亮的具体型号为 RV9311，标志着该公司的模块化可配置异构计算架构完成硅上实物验证。公司称研发团队已启动完整功能调测、性能验证、SDK 与操作系统移植适配，同步推进可靠性摸底测试与 Alpha 客户样片评估。

架构层面，RV9000 采用 RISC-V 与 DSA（领域专用架构）相结合的模块化可配置众核异构设计，通过 NoC 片上网络实现计算核心间低延迟互联；提供 4 核、8 核两种通用核心配置，部分型号额外集成 16 颗 SDPA（软件定义处理加速器）专用处理核，异构算力组合最高可达 24 核，用户还可按需选配 HNA（硬件网络处理加速器）。产品定位网络通信、网络安全、边缘计算、控制面板处理、分布式存储等领域，面向通讯设备、工业机器人、AI PC、电力设备、存储设备等硬件，强调面向国产化场景的体系化适配。公司资方包括深创投、国新国证投资、创东方投资、力合资本等，2025 年 12 月完成超亿元人民币 Pre-A 轮。

为何值得关注：本条与前一交易日的苏州睿芯”高光 D35”形成国内 RISC-V 芯片”架构路线分化”的第二例。睿芯走的是”RISC-V 加数据流架构”，奥维领芯走的是”RISC-V 加 DSA 加 NoC 众核”，两家都在通用 CPU 之外叠加专用计算单元，且都强调网络与工业场景。奥维领芯的差异化在”同一颗 Die 通过配置衍生多规格型号”的积木式思路——4 核、8 核、加 16 颗 SDPA、加 HNA 的组合，本质是用软件定义的可配置性替代多款芯片的并行开发，这与 InCore 等厂商的 SoC 生成器思路同源。需要注意的边界：官网与转载稿均未披露具体性能指标（TOPS、能效比、主频）、SDK 开放程度与量产时间表，”一次点亮”仍属研发里程碑而非商用产品，且该稿源标注为广告转载，本报告按厂商口径收录并标注。

五、总结与趋势观察

本期最显著的特征是 RISC-V 在”政策与资本”两个非技术维度同时获得进展。 工信部与国家发展改革委的《电子信息制造业发展”十五五”规划》首次在国家级五年产业规划中写入”推进 RISC-V 研发与产业化，支持 RISC-V 芯片在人工智能、嵌入式系统等领域应用”，且与”加强开源鸿蒙等国产操作系统搭载”并列表述，给出的是”开放指令集加国产操作系统”的组合路径；同日前后，国内最早的商用 RISC-V CPU IP 公司芯来科技完成北交所上市辅导备案，若成行将成为 A 股首家以 RISC-V 商业 CPU IP 为主业的上市公司。政策定调与资本定价在同一周出现，是 RISC-V 在中国从生态叙事走向产业计价的标志性节点。

技术侧本期以”修修补补”为主，但修补的位置值得注意。 香山的 2 次提交均为流水线共享状态与异常分类的边界修复；NEMU 的 5 次提交里 4 项是性能优化（页表读取、MMU 身份地址缓存、profiling 门控）、1 项是矩阵扩展的内存可见性正确性检查；GEM5 让 cbo.zero 走乱序核的存储缓冲、补上 ROB 排空瞬间的中断投递窗口。三个仓库共同指向同一件事：香山体系的仿真与参考模型正从”功能跑通”进入”时序与内存模型对齐真实硬件”的阶段，而这类工作通常发生在流片或性能对标之前。

国际侧的关键信息是数据中心软件栈的松动。 SiFive 与 AMD 宣布在 RISC-V 服务器上优化 ROCm，虽然 AMD 明确称之为”early step”，但这是 AMD 官方首次以合作方身份为 RISC-V 宿主平台背书。若 ROCm 在 RISC-V 上的算子覆盖度与维护承诺能够持续，”RISC-V CPU 加 AMD GPU”将成为一条独立于 x86 的 AI 服务器组合路径，其战略含义大于单点技术进展。

国内芯片侧，架构路线分化已成事实。 继苏州睿芯”RISC-V 加数据流架构”之后，本期奥维领芯 RV9000 以”RISC-V 加 DSA 加 NoC 众核、同一 Die 配置衍生多规格”的形态完成流片点亮。两家公司都在通用 CPU 之外叠加专用计算单元，并都把网络与工业（含机器人）作为首选场景，说明国内 RISC-V 厂商已不再尝试在通用算力上与 ARM/x86 正面竞争，而是以”可配置异构”切入细分市场。这一路线能否成立，取决于 SDK 开放程度与真实客户案例，本期两家均未披露量化性能与量产时间表，后续需持续跟踪。

待跟踪的三个观察点：其一，”十五五”规划中 RISC-V 条目的配套细则与专项资金是否跟进，以及”开源鸿蒙加 RISC-V”组合是否出现规模化整机落地（深圳物联网产业协会 09-15 的沙龙与深圳 8 月 AI 服务器行动计划已在地方层面推进）；其二，ROCm 在 RISC-V 上的算子覆盖与性能数据何时公开，中科院软件所与 SiFive 两条线的进展是否收敛；其三，芯来科技从辅导备案到正式申报的推进节奏，以及其亏损收窄路径——这将是判断国产 RISC-V IP 商业模式是否成立的重要样本。
