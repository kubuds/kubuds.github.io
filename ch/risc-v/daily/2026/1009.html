一、开源社区与软件生态

1.1 SpacemiT：Linux 7.4 设备树更新，K3 调频、温控与风扇控制启用

日期：2026-10-08　来源：Phoronix《SpacemiT RISC-V SoCs To See More Improvements With Linux 7.4》（10-08）

上游内核针对 SpacemiT K3／K1 的设备树更新 pull request 于 10-08 发出（拟进入 Linux 7.4）：K3 的 CPU 调频支持扩大到更多硬件、RFKILL 节点启用，并新增温控与风扇控制——针对 K3 CoM260 系统模块上的 CTF2301 传感器芯片；基于 K3 的 Muse Pi Pro、Orange Pi R2S、Orange Pi RV2 开发板均随此批启用 CPU 调频。K1 侧则启用板载 EEPROM 支持，并支持从 EEPROM 数据设置 MAC 地址。K3 作为首批量产 RVA23 芯片之一，上游支持持续收口。

1.2 RevyOS：内核配置批量落地，K1／K3 与 EIC7700 平台推进

日期：2026-10-08　来源：revyos/linux 提交记录（revyos/7.3.y 分支，10-08）

RevyOS 内核仓库（revyos/linux）窗口内一次推送 20 余笔配置提交：新增 dp1000 与 K1／K3 专项配置（K3 显示 DC、K3 UFS、Banana F3 的 K1 USB2）；启用 ESWIN EIC7700 架构与 DWMAC、PINCTRL 驱动、TH1520 GPU 电源时序、RTC／RESET_GPIO 等一批常用驱动；USB-C 侧启用 Type-C 角色切换、TCPM、UCSI、FUSB301 与 DP 交替模式。CI 侧新增交叉／原生构建任务与 linuxboot 配置。面向多平台（TH1520／K1／K3／EIC7700）的发行版内核配置在节后首个窗口集中铺开。

1.3 openRuyi：SPECS 批量扩包，go-github 系列 20 余项一次入库

openRuyi 主仓库窗口内一次合入 20 余笔 SPECS 提交：批量新增 go-github-* 系列软件包定义（gopsutil、gokrb5、nats.go、cassandra-gocql、aliyun-credentials-go、google-cel-go 等），并对 cgctl 适配当前 cilium-ebpf API、修复 jcmturner-gokrb5-v8 的 Go 构建。结合其官网新闻页核查——2026.09 版本之后暂无新发布公告；本批扩包应属发布后的软件源日常补包，覆盖云原生与可观测性相关 Go 生态依赖。

开源 SoC 框架 Chipyard（UC Berkeley）窗口内合入 #2387：将 PMU（性能监控单元）库作为生成器子模块引入，并为 BOOM v3 增加 PMU 配置、同步更新子模块指针——为乱序核的硬件性能分析补齐基础设施。riscv-unified-db（规范机器可读数据库）则新增 Zkr 种子 CSR（含 C++ 后端熵源支持）、Sdext 扩展描述与非法指令处理等条目，规范数据库的扩展覆盖面继续扩大。

4.3 ZeroWire：Q8botOne 掌心四足机器人开启众筹预热

日期：2026-10-08　来源：CNX Software：Q8botOne 报道（10-08）、Crowd Supply 众筹页

ZeroWire Robotics 的 Q8botOne 掌心级开源四足机器人进入众筹上线前预热（Crowd Supply）：ESP32-C3-MINI-N4（RISC-V）主控、8 个 DYNAMIXEL XL 系列智能舵机、并联腿结构与无排线一体化 PCB 设计，重约 250 克，可小跑、跳跃并承载约两倍自重；硬件（Altium 原理图、Gerber、BOM、3D CAD）与固件、Python 控制软件将全部开源，附预配对无线手柄。相较同尺寸 PWM 舵机方案，智能舵机支持关节反馈与 PID 调参，面向创客与教研场景。

五、总结与趋势观察

  • 资本与量产双里程碑同日到来：奕斯伟计算今日港交所挂牌（定价 1.55 港元、公开发售 9.09 倍认购），紫荆半导体车规 RISC-V 芯片出货突破千万颗——RISC-V 在资本市场与汽车量产两端的可见度同步抬升。
  • 节后内核与发行版侧恢复满速：SpacemiT K3／K1 上游设备树支持收口（拟进 Linux 7.4），RevyOS 一次铺开 20 余笔内核配置（含 ESWIN EIC7700、linuxboot），openRuyi 批量扩充 Go 生态软件包。
  • 香山系仿真与修复双线推进：FEX0 两笔后端修复正式合入；NEMU 同日连开多笔 PR（检查点机制、SIP／RVV 修复、difftest 引导式观测），difftest 支持独立加速器时钟，为下一轮微架构迭代与多时钟域验证蓄力。
  • 生态向设计左右两端扩展：左端 Tenstorrent 以虚拟平台合作为 IP 开发提速、Chipyard 补齐 PMU 基础设施；右端端侧产品持续涌现（Upbeat 无人机飞控、Q8botOne 四足机器人），RISC-V 在安全关键实时系统与机器人场景不断落子。
  • 待观察：奕斯伟挂牌首日表现；香山 #6652／#6653 等评审队列走向；矽速 AE350 Linux 仓库后续提交；进迭时空 ai-gateway 0.2.0 的组件化落地节奏。
