二、产品与生态动态

2.1 微雪 Waveshare 推出 ESP32-C5 Pico 板卡：双频 Wi-Fi 6 RISC-V 微板卡采用树莓派 Pico 外形（09-09）

日期：2026-09-09　来源：CNX Software、Open Source For You、Waveshare 文档站、GitHub waveshareteam/ESP32-C5-Pico

微雪（Waveshare）发布 ESP32-C5 Pico 板卡，把乐鑫 ESP32-C5 双频 Wi-Fi 6 SoC 引入树莓派 Pico 外形（约 51 至 56.85 x 21 mm）。核心规格：ESP32-C5-MINI-1/1U 模块（ESP32-C5HF4，单核 32 位 RISC-V 最高 240 MHz 加一颗 48 MHz 低功耗 RISC-V 核，384 KB SRAM、320 KB ROM、4 MB SPI flash），无线支持双频 2.4/5 GHz 802.11ax Wi-Fi 6 及 Wi-Fi 4 向下兼容、蓝牙 5.0 LE（含 Mesh）、802.15.4（Zigbee 3.0 / Thread 1.3 / Matter）。板载 USB-C（供电、烧录、充电）、2x20 pin Pico 兼容排针（最多 26 路 GPIO、20 路 PWM，另 6 路经 TCA9554PWR 扩展）、复位与 BOOT 按键、RGB LED 与锂电充放电电路；提供四个版本（板载 PCB 天线或 IPEX 外置天线，排针预焊或未焊），软件支持 Arduino IDE 与 ESP-IDF，示例代码自官网迁移至 GitHub（板卡信息、RGB、I/O 扩展、双频 Wi-Fi、UART、1.83 英寸触摸屏、MCP2515 SPI CAN 等）。意义：ESP32-C5 于 2025 年 4 月量产后，其”双频 Wi-Fi 6 + RISC-V”能力正沿 Pico 兼容形态向下沉市场扩散，第三方板卡生态（微雪为深圳厂商）成为乐鑫 RISC-V 无线 MCU 落地的直接放大器。

2.2 兆易创新播客谈 RISC-V、机器人与边缘 AI：GD32 双架构路线与 EtherCAT 分布式控制（09-09）

日期：2026-09-09　来源：Electropages、GigaDevice 人形机器人方案页、GigaDevice GD32V 发布公告

Electropages 播客（Robin Mitchell 对话兆易创新业务发展经理 Kevin Jones）系统谈及该公司 MCU 路线：RISC-V 方面，兆易创新是较早的主流采用者，2019 年即推出 GD32VF103（内核由芯来科技提供，双方公开合作），当前无线产品线亦采用 RISC-V，官方强调架构灵活性可让芯片厂商围绕特定应用与负载定制处理器；机器人方面，工业机器人多电机与复杂运动对控制器间通信的确定性要求提高，GD32H7 系列支持 EtherCAT，可通过分布式 MCU 各自控制单个电机与局部子系统，减少把全部决策回传中央处理器的依赖；边缘 AI 方面，电机异常检测、人体检测等本地推理任务不必依赖高端 AI 处理器，Cortex-M7/M33 在模型裁剪后已可承担，有利于降低成本敏感场景对云端的依赖。结合兆易创新人形机器人方案页（”感知—决策—控制—执行”架构，MCU、存储、模拟芯片组合覆盖灵巧手、关节模组、IMU、电源管理等），可见其”Arm + RISC-V 双架构 + 机器人/边缘 AI”的国产 MCU 定位。本条为访谈类内容，无新品发布，作为战略观察收录。

三、国内团队动态与深挖

3.1 进迭时空：新一代一致性互联总线 N200 研发完成，形成通算+智算+互联三大板块（09-07 发布，本次补录）

日期：2026-09-07（公司发布；此前两个窗口遗漏，本次补录）　来源：进迭时空官网新闻、GitHub spacemit-com/model_zoo_rl、spacemit-com/ai-sdk

进迭时空在官网披露，公司新一代自研高性能一致性互联总线 N200 正式完成研发。继布局通用计算 CPU 核（X60/X100/X200）与智能计算 AI 核（A60/A100/A200）后，N200 的收官标志其完成”通用计算、智能计算、计算互联”三大核心技术板块布局；N200 将与通算核 X200、智算核 A200 一同用于下一代计算芯片，预计 2027 年正式量产。这是继 K3（全球首颗符合 RVA23 规范量产的 RISC-V AI CPU，60 TOPS、支持 300 亿至 800 亿参数端侧推理）之后的架构纵深动作：自研互联总线意味着其下一代芯片将从”采用现成 NoC”转向全栈自研，直接支撑多核一致性与 AI 核协同带宽。窗口内 GitHub 侧，进迭时空（spacemit-com）端侧 AI 工具链持续迭代：ai-sdk 于 09-09 14:01 与 17:45、次日 00:22（北京时间）多次更新 rl/vision 子模块；model_zoo_rl 于 09-09 20:19 合入 feat(rl): support inference cancellation and YAML provider selection（#11）；model-zoo-vision、docs-ai、linux 亦有推送。RL 模型库与推理取消、YAML provider 选择等功能，对应机器人与具身场景对可中断推理与多后端切换的实际需求。（注：公司新闻页同批还列出 K3 跑通 DeepSeek Harness、GIS 2026 参展等条目，对应事件均在早前窗口，不重复收录。）

3.2 芯来科技：英媒盘点 Quintauris RISC-V 生态合作，芯来车规 IP 对齐 RT-Europa（英文媒体 09-08~09 盘点，合作本体为 2026 上半年）

日期：2026-09-08（Electronics World 盘点文；New Electronics 09-09 同题报道）　来源：Electronics World、Automotive World、Quintauris 新闻室、芯来科技公告（2026-06-16）

英国媒体 Electronics World 于 09-08 刊出盘点稿，New Electronics 09-09 同题：Quintauris 通过持续合作扩展其 RISC-V 生态，2026 上半年新增四项合作——Elektrobit（04-21，汽车软件，服务软件定义汽车）、芯来科技 Nuclei（06-16，车规级 RISC-V 处理器 IP 对齐 Quintauris RT-Europa 实时平台规范）、Ashling（调试与开发工具）、以及 EM-Altair Profile 规范，覆盖软件、硬件与工具链。其中芯来部分的核心是：RT-Europa 为首个面向汽车实时 RISC-V 处理器的平台规范（定义确定性内存访问、中断处理、特权模式、物理内存保护、调试接口与 SoC 集成要求），芯来以量产验证的 NA 系列与之对齐；芯来 NA 系列为全球首个通过 ISO 26262 ASIL-D 认证的 RISC-V 处理器 IP，覆盖 ASIL-A 至 ASIL-D，客户已超 300 家，应用于激光雷达、毫米波雷达、域控制器、车规 MCU、车载以太网与 SoC 安全岛。须明确：本条为英文媒体对既有合作的盘点式再报道，合作本体均发生于 2026 年上半年（非本窗口新事件），收录价值在于其把”中国 RISC-V IP 进入国际车规参考平台”的产业信号再度放大；窗口内 Nuclei-Software 的 GitHub 组织 42 个仓库无推送，无自主开发动态。

五、总结与趋势观察

本报告窗口新闻侧偏弱、开源侧活跃，国内进入到展会首日”议程落地、实况待释放”的过渡状态。要点归纳如下：

其一，开源核进入结构重构期。香山在连续三日铺开新向量后端指令面（整寄存器移动、vfma/widen、VIDiv）后，于 09-09 移除 VFAlu/VFMA 包装层改用配置直接生成，配合 XiangShan-Dashboard 1.0.0 发布、difftest FPGA 探针修复与 XiangShanLab 新增 Zicfilp 模板，验证与工具链配套同步推进；达摩院玄铁将 Hypervisor 原子类指令测试并入统计脚本，测试基线持续夯实。开源侧的信号质量高于新闻侧。

其二，RISC-V 端侧形成”无线连接 + 机器人控制”双线产品叙事。ESP32-C5（双频 Wi-Fi 6 RISC-V SoC）经微雪板卡向 Pico 兼容形态扩散，降低开发者入门门槛；兆易创新以 GD32 的 Arm+RISC-V 双架构叠加 EtherCAT 确定性控制与 Cortex-M7/M33 边缘推理，把 RISC-V 纳入机器人/工业控制产品矩阵。
