今日重点:包云岗谈 RISC-V 与开源 IP——”开源 IP 斩杀线”正在形成

来源:开芯院公众号《【大咖观点】包云岗:浅谈北京市人民政府印发〈北京市”十五五”时期高精尖产业发展规划〉》(https://mp.weixin.qq.com/s/tUq67S2OF_yor_jD60HSHw)

北京市人民政府印发《北京市”十五五”时期高精尖产业发展规划》,提出加快第五代精简指令集架构(RISC-V)、芯粒、光电融合等创新平台建设,持续推进存算一体等新型架构产品迭代升级,聚力培育自主计算产业生态。中国科学院计算技术研究所副所长、北京开源芯片研究院(开芯院)首席科学家包云岗就此分享了几点认识:

一是”森林论”:RISC-V 生态好比一片森林,既需要参天大树(高性能 RISC-V 芯片),也需要灌木草丛(海量嵌入式 MCU)。培育参天大树,ARM 模式已不再适用,必须探索新模式,而开源 IP 将是成功概率最高的路径;培育灌木草丛面向海量定制化长尾需求,犹如”义乌模式”——小商品、大市场,可借鉴嘉立创模式以低成本、敏捷开发体系应对。

二是 RISC-V+AI 将成为 AI 时代主流:不同 AI 场景、模型与部署形态对硬件提出高度差异化要求,RISC-V 的开放性与可扩展性比 x86 和 ARM 更易适配 AI 定制化需求,近期 Meta、OpenAI 自研 AI 芯片的背后都有 RISC-V 的身影。

三是软件生态壁垒需要刷新认知:跨指令集迁移软件成本高,长期以来是 CPU 生态竞争的核心壁垒;但随着 AI Agent 快速发展,代码迁移、适配、调试与优化成本出现数量级下降,未来软件生态将不再是壁垒。

四是”开源 IP 斩杀线”:全球 ARM 生态仅一家 IP 供应商、全年收入约 30 亿美元,RISC-V IP 价格须低于 ARM 才有机会替代,市场总盘子很难超过 30 亿美元;但指令集开放意味着多家 IP 供应方并存、单家营业额都做不大,难以维持高昂研发成本(近期 Andes 关闭 2023 年在美国德州成立的高性能 RISC-V IP 子公司即为例证)。破解思路是将高性能 RISC-V IP 作为产业公共品以开源模式提供,把授权费从几千万元、上亿元降低 1-2 个数量级——正如 DeepSeek 等中国大模型通过开源将 AI 应用扩散到各行各业。开源模式存在可持续商业模式:当系统足够复杂,就产生专业服务空间(“Linux + RedHat”“安卓 + 中科创达”)。

五是香山的六年实践:香山于 2020 年 6 月启动,2021 年 12 月开芯院成立支撑其持续发展;开芯院作为非营利机构(NPO)不需追求估值与利润,只需每年筹集覆盖运营成本的经费(约 1.5 亿元/年)即可长期运转。香山已基本解决资金筹集、工业级质量(充分验证)与持续迭代演进(每年发布一代)三大挑战——“有信心、有底气让香山活 30 年”。由此形成一条冷酷的”开源 IP 斩杀线”:若性价比不能高于这条线,自研高性能 IP 的逻辑将难以成立(类比 1991 年 Linux 诞生后私有 Unix 的消亡)。积极拥抱开源 IP 的芯片企业将成为受益者——”香山”研发团队已成为整个芯片产业的公共资产。

点评:这是继 8 月滴水湖论坛、RISC-V 中国峰会之后,国内 RISC-V 政策与产业路线的又一重要表态:北京市”十五五”规划把 RISC-V 列入高精尖产业重点平台建设,包云岗则从产业组织方式层面论证了”开源高性能 IP”路线的必要性与可持续性,对国内 RISC-V 芯片企业(自研 IP 与拥抱开源 IP)的路线选择具有风向标意义。

二、产品与生态动态

2.1 NextSilicon 首次公开 Arbel：自研乱序超标量 RISC-V 核，双核 2.4 GHz 一致性测试芯片跑通 Linux/Ubuntu（09-10）

日期：2026-09-10（公司博客；HN 收录 09-10 17:18 UTC）　来源：NextSilicon 博客（Yiftach Gilad 署名）、Hacker News 讨论

NextSilicon 公布其自研高性能 RISC-V CPU 核 Arbel 的完整历程。作者 Yiftach Gilad 自述在 Intel 做了 18 年处理器，最初认为”自建 CPU 核”近乎不可能。Arbel 的起点并非独立产品，而是为该公司 Maverick 数据流加速器配套的串行执行单元：第一代是集成在加速器内的乱序、超标量、纯整数 RISC-V 核，跑通 Linux 与 BusyBox 以验证路线；其后逐步补齐向量能力、缓存一致性、更强存储结构与更宽的发射。关键节点是双核、一致性、2.4 GHz 的测试芯片，集成 PCIe Gen5、CXL 与基于 CHI 的片上网络，外接通用 CXL DDR 与 PCIe 组件组成”迷你 PC”，可直接运行 Linux/Ubuntu 与开箱可用的 GCC/LLVM 并跑分。量产路线为 64 核、服务器级、面向数据中心的 chiplet，覆盖虚拟化、安全、可靠性、可调试性与高带宽 IO。架构上公司强调前端不依赖昂贵的 micro-op cache、虚拟 L1 缓存结构降低 load-to-use 延迟并处理别名与标签管理、原子化 L1 fill/evict 流水线等细节选择。意义：在 HPC 与智能体 AI 场景下，公司认为瓶颈正从数学引擎转向编排、内存搬运、调度与软件执行，因此”加速器旁的 CPU”重新变得关键；Arbel 是继 SiFive、Ventana、Rivos 之后又一家公开服务器级 RISC-V 核进展的创业公司，且以真实硅片而非路线图对外发声。

2.2 riscv.org 刊发 MIPS 首席执行官专稿：汽车行业的 RISC-V 意义在于选择自由（09-10）

日期：2026-09-10　来源：riscv.org 博客（Viewpoints）

RISC-V International 官网观点栏目刊发 MIPS 首席执行官 Sameer Wasson 专稿（作者身份标注为 MIPS, by GF——即被 GlobalFoundries 收购后的 MIPS）。核心论点：汽车整车平台的生命周期以十年计，软件需维护到最后一辆车报废，因此指令集架构（ISA）的选择是战略决策，OEM 与一级供应商需要的”经济控制”不是自研一切，而是拥有供应商选择权、议价能力、跨车型软件复用能力，以及不必绑定某家厂商路线图即可演进硬件。文章认为开放架构恰恰扩大竞争：半导体厂商仍可在实现层差异化，IP 厂商可在架构之上创新，软件生态可跨系统复用，而 OEM 可保持架构一致性并自由评估方案。作者同时强调”开放不等于同质化”（openness should not mean commoditization），并指出随着车辆内 AI 无处不在（感知、ADAS、安全、预测性维护、座舱），架构需要为尚不可预见的工作负载预留余量，而 RISC-V 提供的价值在于”软件底座保持一致、实现层随负载演进”。意义：MIPS 转向 RISC-V 并以”汽车经济控制”为叙事主线，是继 09-08 前后 GlobalFoundries 发布 MIPS Acies 边缘 AI 推理平台报道之后，该阵营在行业话语层的延续动作，也反映 RISC-V 在汽车领域的推广重心从”性能对标”转向”长期成本与供应链自主”。

2.3 埃因霍温理工大学 CONVOLVE 项目发布 Chimera 芯片：RISC-V 处理核与内存中心/神经形态加速器跨层协同（09-08 发布，09-10 英文媒体续报）

日期：2026-09-08（校方发布）/ 09-10（Bits&Chips 等英文媒体续报进入本窗口）　来源：TU/e 官方新闻、Bits&Chips、CONVOLVE 项目站

欧盟资助、埃因霍温理工大学（TU/e）主导的 CONVOLVE 项目公布其流片验证成果——代号 Chimera 的边缘 AI 芯片原型，并在 ESSERC 会议（西班牙）向产业界宣讲。方法论上的关键在于”跨层设计”：不再把 AI 算法、处理器架构、存储系统与电路设计分层独立开发，而是联合优化，从而在设计早期即平衡精度、可编程性、处理速度、硅面积与能耗。架构上，Chimera 把可编程 RISC-V 处理器与专用 AI 加速器组合使用，后者涵盖内存中心（memory-centric）计算与神经形态计算技术，目标是从设计源头压低数据搬运带来的能耗。项目组强调验证基于已流片的原型芯片而非仿真，用真实 AI 工作负载实测能效、吞吐、延迟、面积与精度并与既有设计对比。团队由 Manil Dev Gomony、Henk Corporaal、Sander Stuijk、Marc Geilen 等领衔，合作方分布在鲁汶、代尔夫特、苏黎世。项目动因是 GenAI 负载推高数据中心能耗与用水，端侧本地推理可同时降低能耗、延迟与对远端基础设施的依赖，作者定位为”欧洲在边缘智能处理器上的自主方案”。意义：本条补录了欧洲学术阵营在 RISC-V + 新型 AI 加速（内存中心/神经形态）方向的具体硅片级进展，与产业侧 RISC-V AI 芯片形成对照。

三、国内团队动态与深挖

3.1 芯来科技启动北交所上市辅导备案：RISC-V CPU IP 第一梯队冲刺资本市场（09-10）

日期：2026-09-10（公司公告披露日）　来源：同壁财经（新浪财经转载）、扑克财经

芯来智融半导体科技（上海）股份有限公司（证券简称”芯来科技”，证券代码 875127）于 09-10 披露《申请公开发行股票并在北交所上市辅导备案及其进展公告》：公司已于 09-08 与招商证券签署北交所上市辅导协议，09-09 向上海证监局提交辅导备案申请材料，北交所上市进程正式启动。公司成立于 2018 年 9 月，总部位于上海浦东，主营 RISC-V CPU IP 授权、SoC 子系统平台授权及芯片定制，系国家级重点专精特新”小巨人”企业、中国 RISC-V 产业联盟副理事长单位，创始人胡振波合计控制 42.50% 表决权。产品体系为 N/U/NX/UX 四大通用 CPU IP 产品线加 NS（安全）、NA（车规）、NI（智能计算）三个专用线，其中 UX1030H 为全球较早支持 RVA23 规范的高性能 RISC-V CPU IP，NA900 为全球首个通过 ISO 26262 ASIL-D 车规认证的 RISC-V CPU IP；累计取得境内授权专利 93 项（发明专利 92 项）。按 The SHD Group 2026 年 3 月报告的内核出货量口径，芯来位列全球 RISC-V CPU IP 市场前四的第一梯队，国内外正式授权客户超 300 家，覆盖兆易创新、芯原股份、恒玄科技、晶晨半导体等上市公司及央国企。财务方面：2024/2025 年营收 7399.87 万元 / 8294.11 万元，2026 年上半年 3687.45 万元；2024/2025 年归母净利润分别为 -8646.73 万元 / -9593.78 万元，剔除股份支付影响后亏损由 2023 年的 -1722.73 万元收窄至 2025 年的 -958.63 万元；最近两年研发投入累计占营收比例达 124.48%。公司已于 2026-08-28 挂牌新三板创新层，同步定向发行募资约 4200 万元用于 RISC-V 芯片定制平台研发项目，认购方含黑龙江振兴先进制造产业私募股权基金、中芯熙诚（北京）数字科技基金等产业资本，并按规划拟于挂牌后 12 个月内向北交所提交发行上市申请文件。行业数据方面，公告援引 SHD Group：2025 年全球 RISC-V SoC 出货量约 69 亿颗，预计 2031 年增至约 360 亿颗，复合年增长率 31.7%。深挖视角：芯来是国内少数以纯 CPU IP 授权为主业并冲刺公开资本市场的 RISC-V 企业，其”车规 ASIL-D 认证 + RVA23 高性能核 + 300 家授权客户”的组合，是观察国内 RISC-V IP 商业化成熟度的关键样本；此前日报持续跟踪的芯来 GitHub 组织（Nuclei-Software，42 仓库）在窗口内无专项 push，本次动态为资本市场而非代码侧。（财务与市场数据源自公司公告与第三方报告转述，以正式披露文件为准。）

五、总结与趋势观察

  1. 高性能 RISC-V 核的”真实硅片”叙事升温：NextSilicon 公开 Arbel（双核 2.4 GHz、CXL/PCIe Gen5/CHI NoC、跑通 Linux/Ubuntu 与 GCC/LLVM，路线图为 64 核服务器级 chiplet），且明确以”智能体 AI 时代 CPU 重新关键”为立论基石。与既有 SiFive、Ventana、Rivos 路线相比，Arbel 的特殊性在于它是从加速器配套需求”长出来”的 CPU，说明数据中心 RISC-V 的驱动力正从”替代通用 CPU”扩展到”主机-加速器协同的系统完整性”。
  2. 开源核阵营进入结构收敛期：香山在连续一周的向量指令功能合入（整寄存器移动、vfmac/widen、VIDiv）之后，09-09 至 09-10 连续做包装层移除（VFAlu/VFMA）与控制信号清理（VPUCtrlSignals）并修复 vxsat 写使能传播，属典型的”功能铺开后结构整理”，通常是下一阶段（矩阵/规约运算或性能调优）的前置动作。
  3. 国内 RISC-V IP 商业化进入资本验证阶段：芯来科技启动北交所上市辅导备案，是继奕斯伟计算冲击港股后国内 RISC-V 企业资本化的又一动作，且两者商业模式不同（芯来为 CPU IP 授权、奕斯伟为芯片产品），可互为对照；芯来”车规 ASIL-D + RVA23 高性能核 + 300 家授权客户”是其差异化基础，但两年研发投入占营收 124.48%、剔除股份支付后仍亏损，说明 IP 授权模式的盈利拐点尚未到来。
  4. RISC-V 在汽车的推广重心转向”长期经济性”：riscv.org 刊发 MIPS 首席执行官专稿，把汽车 RISC-V 的卖点从性能对标转向”平台生命周期十年以上的选择自由与软件复用”，与前一天 GlobalFoundries/MIPS 发布 Acies 边缘 AI 推理平台的产业动作呼应，显示该阵营正以”经济控制”叙事进攻车规市场。
  5. 端侧 AI 加速与 RISC-V 的学术侧合流：TU/e 的 CONVOLVE/Chimera 用 RISC-V 可编程核 + 内存中心/神经形态加速器的跨层设计，把”降低数据搬运能耗”作为首要目标并完成了原型芯片实测；玄铁同步在开源侧补齐 RVV 量化算子微内核库（torq-tile），一端是体系结构创新、一端是算子工程落地，共同支撑 RISC-V 在端侧 AI 的实际可用性。
  6. 当日国内厂商代码侧以收敛性维护为主：算能 SG2044 固件补 4GB 以下地址分配兼容性、进迭时空合并 K1 引导分支并更新 ROS 机器人文档，均为稳定性与文档质量类工作，无发布级新动态；玄铁 torq-tile 的 RVV 量化算子批次（09-07 合入）为本窗口发现的新增内容。

局限性说明：NextSilicon Arbel 的性能描述（2.4 GHz 双核测试芯片、64 核量产规划、微架构选择）均来自公司博客自述，尚无第三方评测或 SPEC 级数据佐证，其”服务器级”定位需以实际量产硅片为准；MIPS 专稿为观点文章（Viewpoints），观点归属作者与 MIPS 公司，不代表 RISC-V International 立场；TU/e Chimera 的具体能效数字需以 ESSERC 论文与项目公开材料为准，本条依据校方新闻与项目站描述；芯来科技财务与市场数据源自公司公告及 The SHD Group 报告转述，投资相关内容不构成建议；香山、玄铁、算能、进迭时空的代码动态以 commit message 与仓库 pushed 时间为准，未做微架构级验证；torq-tile 的窗口内推送未见新提交（疑为分支/元数据操作），其表述以 09-07 合入批次为准。
