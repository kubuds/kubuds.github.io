一、开源社区与软件生态动态

1.1 RISC-V 官方高保证密码学（HAC）规范密集更新：ML-KEM/ML-DSA 后量子密码描述细化（今日头条之一）

日期：2026-08-15（11:34~23:25 UTC 约 20 笔提交）　来源：riscv/riscv-high-assurance-cryptography GitHub

RISC-V 国际基金会高保证密码学（HAC）规范仓库窗口内密集提交约 20 笔，主要围绕后量子密码与高保证实现：ML-KEM（Kyber 后量子密钥封装）与 ML-DSA（Dilithium 后量子签名）的指令集描述修订、ACE-ISA-unpriv 规范措辞统一（”must” 改 “shall”）、OCB3 结构精简、CR 表示与容量上限澄清等，并处理评审意见（review1.md）与 AsciiDoc 排版修正。HAC 是 RISC-V 面向 FIPS 140-3 级高保证密码实现（恒定时间、侧信道防护）的扩展规范，其 ML-KEM/ML-DSA 等后量子指令集描述进入密集修订阶段，标志 RISC-V 密码扩展向实用化、标准化收敛——对 RISC-V 进入金融/政务/云信任边界有直接意义，与本周 Spectre 论文引发的安全信任讨论形成呼应。

1.2 香山 difftest 验证框架增强：mma 验证器背压可配置 + 批量验证 + macOS arm64 主机支持

日期：2026-08-15（06:00/16:08 UTC 提交，北京 14:00/08-16 00:08）　来源：OpenXiangShan/difftest GitHub

香山配套的 difftest（差分协同验证框架）窗口内合入三项改进：feat(mma): add configurable verifier backpressure (#923)（mma 验证器背压可配置）、feat(mma): batch contiguous verification requests (#920)（连续验证请求批量合并，提升验证吞吐）、fix(runtime): support Darwin arm64 hosts (#930)（新增 macOS Apple Silicon 主机支持）。其中 Darwin arm64 支持对本地开发验证流程友好。窗口内 XiangShan 主仓库 08-15 18:07 UTC 推送（主分支最近合入仍为 08-14 satp 修复 #6014，当日为分支/CI 动态），XSCache（08-15 18:55 UTC）、difftest、NEMU、CoupledL2、GEM5、env-scripts、circt 等周边仓库同步活跃，香山全栈持续高频迭代。

1.3 RISC-V P 扩展规范同步工具链版本（#322）

日期：2026-08-15（09:28 UTC，北京 17:28）　来源：riscv/riscv-p-spec GitHub

RISC-V P 扩展（Packed SIMD）规范仓库合入 Sync gcc, binutils, QEMU version and links (#322)，同步更新 GCC/Binutils/QEMU 支持版本与链接——P 扩展工具链支持状态维护。P 扩展（定长 SIMD，对标 DSP 类工作负载）在嵌入式与 AI 边缘场景有应用潜力，规范侧保持低频稳定推进。另有 riscv-unified-db（RISC-V 统一数据库）例行依赖更新（renovate 自动 PR）。

日期：2026-08-14（18:19 UTC 推送，近三日趋势）　来源：sipeed/picoclaw GitHub

矽速（Sipeed）开源项目 PicoClaw 近期快速增长（当前 29.8k 星，2026-02 创建）：以 Go 编写、面向 $10 级硬件/10MB 内存/毫秒级启动的超轻量 AI 助手，架构徽章明示支持 x86_64/ARM64/MIPS/RISC-V/LoongArch，定位”随处可部署的极简 AI”。该项目将轻量 AI 助手带到 RISC-V 等低资源架构，属端侧 AI 软件生态的活跃新力量（推送时间略早于窗口起点，列近三日趋势）。

二、产品与生态动态

2.1 电子工程专辑专题：双核 RISC-V RT-MCU 如何撑起具身机器人运动控制基座

日期：2026-08-15（09:00 CST）　来源：gnews 链接（电子工程专辑）

电子工程专辑刊发专题，探讨双核 RISC-V RT-MCU（实时控制 MCU）在具身机器人运动控制基座中的角色：实时核负责电机/关节控制环路（电流环、位置环），应用核承担通信/感知/边缘 AI，双核分工契合机器人”实时控制+智能决策”异构需求。代表性产品为峰岹科技 FU75XX 系列（第 2 代 ME+32 位 RISC-V 双核 MCU，2025-11 发布时即以”为未来机器人而生”定位，双电机驱动型号 FU7512L 曾参评 2026 中国 IC 设计成就奖）。该专题与本窗口前滴水湖论坛的运控芯片信号（格见 500 纳秒电流环、先楫 HPM53M1 关节控制、进迭 K3 运控定位）构成同一叙事：RISC-V 运控 MCU 从”单核实时”走向”双核异构”，详见第四章专章。

四、重点方向专章：具身智能与机器人

4.1 双核 RISC-V RT-MCU：运控基座的”异构分工”叙事成形

本窗口最具方向性信号是电子工程专辑的专题《双核 RISC-V RT-MCU 如何撑起具身机器人的运动控制基座？》（08-15）：双核架构（实时核跑电机/关节控制环路 + 应用核跑通信/感知/边缘 AI）成为具身机器人运动控制基座的主流设计思路，代表性产品峰岹 FU75XX 系列（32 位 RISC-V 双核、双电机驱动）自 2025-11 起即以”为未来机器人而生”定位。这与滴水湖论坛（08-13）的运控信号完全同频：格见半导体 500 纳秒电流环/单芯片 25 自由度（昨日报告 3.3）、先楫 HPM53M1 人形机器人关节控制、进迭时空 K3 机器人运控定位——国产 RISC-V 运控方案正从”单核实时 DSP/MCU”向”双核异构（实时+智能）”演进，运控层国产替代路径进一步具体化。

4.2 端侧 AI 推理 NPU 化：SPERT 整图内核路径

进迭时空 llama.cpp 分支的 SPERT 整图内核路径（3.1）与算能 YOLOv8-pose 实战级修复（3.2）共同指向具身智能软件栈的成熟化：前者将 LLM/VLA 推理下沉至端侧 NPU 引擎（低功耗实时性），后者持续修补视觉感知示例的工程缺陷。结合昨日 LeRobot（SmolVLA/ACT）端侧部署与仿人机器人适配，RISC-V 具身智能”感知（视觉）— 决策（端侧 LLM/VLA）— 运动（双核 RT-MCU 运控）”三层国产化路径逐步清晰。

五、总结与趋势观察

  1. 后量子密码成为 RISC-V 规范热点：RISC-V 官方 HAC 规范窗口内约 20 笔提交细化 ML-KEM/ML-DSA 等后量子密码指令描述，密码扩展向 FIPS 级高保证实现收敛——与本周 Spectre-on-RISC-V 论文引发的安全信任讨论同向，安全/密码正成为 RISC-V 生态的官方优先级议题。
  2. 运控层”双核异构”叙事成形：电子工程专辑专题（双核 RISC-V RT-MCU）+ 峰岹 FU75XX + 滴水湖论坛运控新品（格见/先楫/K3）同频，具身机器人运动控制基座的国产 RISC-V 方案从”单核实时”走向”实时核+应用核”双核分工。
  3. 端侧 LLM 推理加速下沉 NPU：进迭时空 llama.cpp 合入 SPERT 整图内核路径，端侧大模型推理从”CPU 跑通”迈向”NPU 整图加速”，与算子库（FlagGems-RACE）、推理文档（docs-ai）构成完整链条。
  4. 奕斯伟 IPO 进入”上市前夜”：港股”RISC-V 架构第一股”叙事推进至临近挂牌，虽三年累亏 49 亿，但车规 MCU/CMS 产品线与国产 RISC-V 主力叙事为其背书。
  5. 验证基础设施持续加码：香山 difftest 增加验证器背压控制与批量验证（提升吞吐）、新增 macOS arm64 主机支持，开源高性能核的验证效率成为竞争力焦点。

局限性说明：电子工程专辑原站（eet-china）反爬不可达，2.1 专题正文细节依据标题与既有产品线（峰岹 FU75XX 等）交叉推断，具体机型表述以原文为准；Japan Today 综述（2.3）正文无法抓取（gnews 跳转空壳页），仅以标题与聚合命中信息收录为生态背景；9to5Linux 报道的 Advantech AOM-2721 板卡 Ubuntu 认证（08-15）因原站 403 且厂商页无 RISC-V 证据词，无法确认平台，未收录正文；”RISC-V 第一股”等表述为媒体口径；GitHub 数据基于未认证 API（60 req/h 限速内完成）。
