一、开源社区与软件生态动态

1.1 RISC-V 架构大辩论持续升温：Grinberg 批评长文引发多方回应（今日头条）

日期：2026-08-14 原文首发（HN 376 分），本窗口内 08-16 两篇重磅回应　来源：Grinberg 原文（dmitry.gr） / rvembedded 回应文 / The Chip Letter 综述

独立嵌入式开发者 Dmitry Grinberg 的长文《RISC-V: They Should Have Known Better》08-14 登上 HN 首页（376 分，250+ 评论），成为近期对 RISC-V 架构最系统的一次批评。其核心观点：一、单一 ISA 无法同时通吃廉价 MCU 与高性能计算两端，”高端 CPU 的需求与低成本 MCU 的需求本质上对立”；二、压缩指令编码”荒谬”（如 S 型存储指令 16 位编码偏移量仅 0-3）、立即数在指令中散乱分布（对比 MIPS/ARM）、Zicsr 等扩展本应内置；三、结论是”我 100% 确定 RISC-V 终将拿下廉价一次性 MCU 市场——但不是因为 ISA 设计得好，而是尽管它设计得一般”，靠的是免费与低价；高端桌面/手机市场则”不看好”。

本窗口内的新进展是两篇高热度回应（08-16）：

  • rvembedded.com《A Third World Embedded Engineer Responds》（HN 353 分，170+ 评论）：特立尼达和多巴哥的嵌入式工程师（已把整套 STM32/ARM 栈迁移到 RISC-V，代表作 CH32V003 教材）从”全球南方”视角反驳——对发展中国家的工程师与学生，10 美分与 1 美元的芯片差价、运费与海关壁垒远比 ISA 优雅性重要；他桌上恰好摆着三个证据：10 美分 RV32EC 的 CH32V003（正是 Grinberg 亲手推导出的那类核）与 400 MHz 双核 CH32H417 同属一个 ISA 家族，直接反驳”单一 ISA 不能通吃”；同时诚实承认 Grinberg 部分批评合理（压缩存储偏移、Zicsr 独立成扩展）。
  • The Chip Letter《RISC-V: What Really Matters》（08-16）：综合评述认为 RISC-V 因”免费、主流工具链支持、可扩展”而注定成功——引 Raspberry Pi Pico 2 的 Hazard3 开源核设计者 Luke Wren：”满足我对 ISA 的两个要求：主流 LLVM/GCC 支持、不需要律师”；Meta MTIA 加速器团队成员：”我们在 AI 加速器上用 RISC-V 大获成功”；但高性能桌面/手机市场地位仍存疑，厂商或更倾向 ARM 授权路线。

意义：这是继本周 Spectre-on-RISC-V 论文后第二个生态级话题，标志 RISC-V 舆论从”技术新星”叙事进入”被严肃审视与反思”阶段；争论双方反而在一点上高度一致——廉价嵌入式/端侧市场 RISC-V 势在必得（靠价格与开放，而非架构完美）。

1.2 RISC-V 官方高保证密码学（HAC）规范连续第二日密集修订（约 12 笔提交）

日期：2026-08-16（00:48~23:37 UTC）　来源：riscv/riscv-high-assurance-cryptography GitHub

HAC 规范仓库窗口内再合入约 12 笔提交，延续昨日 ML-KEM/ML-DSA 后量子主线：Allow ace.restrict instructions in any state（允许 ace.restrictl/h/v 在任何 CR 状态下执行，替代原先的异常路径）、SCProtection 层级与 ace.restrictv 保留值范围（3-5、6-7）明确化、CSK 术语统一（清理遗留的 RCSK 引用）、异常行为与零化（zeroization）规则澄清、ace.setst 使用控制修复、删除 ace-examples.adoc 并持续处理评审意见（review1.md）。连续两日密集修订表明该面向 FIPS 140-3 级高保证密码实现的扩展规范进入评审收敛冲刺期，与本周安全信任议题（Spectre 论文、密码扩展）构成同一条主线：RISC-V 正系统性补课安全与密码基础设施。

1.4 AROS（开源 Amiga 兼容 OS）推进 riscv64 平台：一次性平台定时器合入

日期：2026-08-16（17:53/17:55 UTC，北京 08-17 01:53）　来源：aros-development-team/AROS GitHub

AROS（开源 Amiga 兼容操作系统）窗口内为 riscv64 平台合入两项关键提交：riscv64-opensbi: expose a one-shot platform timer to timer.device（新增 KATTR_PlatformTimer 平台定时器接口）与 microsecond-precision timer.device（以一次性定时器替代通用 tick 驱动，微秒级精度）。同日还合入 SMP 压力/回归测试集（PR #1000，pin 多核 worker、信号竞争测试）。AROS 的 riscv64 移植持续推进（此前已完成 OpenSBI 引导与内核基础），是 RISC-V 桌面 OS 生态活跃度的旁证。

1.5 开源项目观察

  • felix86（661★，08-16 推送）：开源 x86/x86-64 游戏运行层（二进制翻译），目标”在 RISC-V Linux 上跑 x86 游戏”，是 RISC-V 桌面生态补强信号，与本章 1.1 的”高端市场存疑”争论形成对照——生态补位正在发生。

二、产品与生态动态

2.1 印度 VIHAAN 宽带芯片流片一次成功：VEGA（C-DAC RISC-V）内核，2027 量产（今日头条之一）

日期：2026-08-16 报道（里程碑为 08-15 独立日）　来源：Indianweb2 原站 / Swarajya（gnews 链接）

印度金奈（Chennai）fabless 初创 Aheesa Digital Innovations 宣布其光纤宽带网络 SoC「VIHAAN」流片一次成功：芯片于 2026 年共和日（01-26）完成流片，独立日（08-15）验证通过首次硅验证，目标 2027 年量产流片。核心亮点：处理器内核采用 VEGA 微处理器（C-DAC 在 MeitY 支持下开发的 RISC-V 架构处理器），28nm 工艺，面向光纤接入网最后一公里（家庭/办公宽带），集成计算、宽带接入与系统控制功能。项目获印度 DLI（Design Linked Incentive）计划支持——该计划下印度已完成 30+ 次芯片流片；Aheesa 2026 年初经 TNIFMC/TNESSF 与私人投资者融资 4000 万卢比。VIHAAN 是印度”国产芯片 + RISC-V 架构”叙事的又一落地案例，与 VEGA/Shakti 生态、DLI 政策构成完整链条，2027 量产目标值得跟踪。

四、重点方向专章：具身智能与机器人

4.1 本窗口具身智能方向平静：运控主线仍是”双核异构 + 成本敏感”

本窗口内具身智能/机器人方向无新发布，回看近三日趋势（08-15 滴水湖论坛与电子工程专辑专题）：国产 RISC-V 运控方案正从”单核实时”走向”实时核+应用核”双核异构（峰岹 FU75XX、格见 500 纳秒电流环、先楫 HPM53M1、进迭 K3 运控定位），端侧感知—决策—运控三层国产化路径成形（进迭 SPERT NPU 推理、算能视觉示例库修补）。

4.2 架构之争与具身智能的交点：争论双方都承认”廉价嵌入式 RISC-V 势在必得”

今日头条的架构大辩论（1.1）与具身智能方向形成有趣呼应：Grinberg 批评长文的结论恰恰是”RISC-V 将 100% 拿下廉价一次性 MCU 市场，靠的是价格与开放而非架构完美”——而具身机器人运动控制基座（关节电机控制、传感器融合）正是典型的成本敏感、实时性优先场景。争论双方（批评者与辩护者）在这一点上罕见一致，从侧面印证：在机器人运控这一国产 RISC-V 的核心增量市场，RISC-V 的生态位不因架构争议而动摇。运控芯片的国产替代路径与”全球南方”嵌入式工程师的生态叙事（10 美分部件改变教育与实践的边界）同构：开放 + 低价是 RISC-V 在嵌入式/端侧取胜的根本逻辑。

五、总结与趋势观察

  1. 架构之争成为本周生态第二热点：Grinberg 长文（08-14，HN 376 分）引发”全球南方”工程师回应（rvembedded，08-16，HN 353 分）与 The Chip Letter 综述（08-16）——RISC-V 舆论从”技术新星”进入”被严肃审视”阶段；争论双方一致认同廉价嵌入式/端侧市场 RISC-V 靠”开放+低价”胜出。
  2. 印度 RISC-V 商业化落地加速：VIHAAN（VEGA 内核）宽带 SoC 流片一次成功、2027 量产目标明确，DLI 计划下印度 30+ 次流片、6.8 万人设计人才培训——印度”国产芯片”叙事正以 RISC-V 为底座落地。
  3. 安全/密码仍是 RISC-V 官方优先级：HAC 规范连续两日密集修订（ace.restrict 任意状态、SCProtection 层级、CSK 术语、零化规则），与本周 Spectre 论文议题同向；SPMP 冻结后首次维护。
  4. 国内团队窗口内平静：香山主分支无新合入（周边例行），平头哥/进迭/算能/芯来/奕斯伟无新增，深度动态集中在 08-15；乐鑫安全供应链基础设施（NVD 镜像/SBOM/安全看板）持续加码。
  5. 开源桌面/OS 生态活跃：AROS riscv64 平台定时器落地、felix86 x86 游戏翻译层活跃——与”高端市场存疑”的辩论形成张力，生态补位正在发生。
