一、开源社区与软件生态

1.1 乐鑫 esp-nn 1.3.1 发布，RISC-V 内核全连接层向量化优化

日期：2026-08-28　来源：espressif/esp-nn 提交记录

乐鑫神经网络库 esp-nn 发布 1.3.1（合入时间 08-28 23:44 北京时间）。本次核心性能改进为全连接层（fully_connected）per-channel offset 校正的向量化：RISC-V 路径（riscv_pie 优化内核变体，面向 ESP32-C 系列）与 Xtensa S3 路径同步优化，S3 侧在短行场景优先使用汇编；README 性能数字同步刷新。esp-nn 的 riscv_pie 内核族覆盖激活函数、基础数学、全连接等算子，是乐鑫持续为 RISC-V MCU 提供 DSP 级优化算子的例行迭代，无架构级变化。

二、产品与生态动态

2.1 SiFive BigSky 进入交付阶段：首批系统已在领先客户运行负载，Futurum 分析师解读

日期：2026-08-28　来源：The Futurum Group 分析稿（发布日 2026-08-28）

Futurum Group 分析师 Brendan Burke 于 08-28 发表 BigSky 专题解读，标题直言”SiFive BigSky 出货首款 RISC-V 服务器”。新增事实要点：（1）BigSky SF-2U870 完整符合 RVA23 profile，开箱即用支持 Ubuntu 26.04 LTS 与 RHEL 10；（2）CUDA 可在其 P870-D 核心上运行，作为 NVIDIA GPU 的 LLM 工作负载 head node（控制节点）；（3）SiFive 称领先客户（含超大规模云厂商、软件与主要 SoC 厂商）已在已部署的 BigSky 系统上运行工作负载。分析师判断：BigSky 本质是”出售时间”的移植载体——压缩超大规模厂商定制 SoC 项目多年代软件阶段；RISC-V 服务器当前所处位置相当于 Arm 约 2018 年（RVA23 与服务器平台规范已定稿、企业级 Linux 就绪、首批可运行该软件栈的硅片到达客户），制约 RISC-V 数据中心落地的已从硅片转为软件，BigSky 正是为按期弥合该缺口而生。同时指出 SiFive 未随平台公布 SPEC/性能、功耗与定价数据，商务竞争力验证留待后续。本窗口为该事件自 08-24 发布、08-25 至 08-27 媒体发酵后的”交付/部署进展 + 分析师定调”阶段，属实质性新信息。

三、国内团队动态与深挖

3.1 香山：68+ 笔提交，跨月开发成果大规模合入（ZICBO、Zvknha/Zvbb、向量单元重构、AMOCAS）

日期：2026-08-28　来源：OpenXiangShan/XiangShan 提交检索、XiangShanLab

OpenXiangShan 组织窗口内约 84 笔提交（XiangShan 主仓库 68 笔），核心事件是 08-28 16:44 一批跨月开发成果的大规模合入（author 日期跨度 2025-11 至 2026-08-26，属批量合入收尾而非当日新开发）。要点：（1）ZICBO 扩展：新增 ZICBO 支持并将缓存块操作（cbo）opcode 经 LSUOpType 统一（author 08-26）；（2）密码学向量扩展：Zvknha（NIST AES 向量密码学）initial version（author 2026-02）、Zvbb（向量位操作）初始化支持（author 2026-02）；（3）向量单元重构：vector 新初始提交（author 08-06）、vstart 传入 VectorDecodeChannel、immType 加入 vector fu config、vl value wakeup 禁用、VTypeGen 时序断链等一批重构与时序优化；（4）AMOCAS d/w/q 支持（author 08-19）与 AMOCAS src select 逻辑修正；（5）指令集侧从 riscv_opcodes 仓库导入生成指令列表（author 2025-11）、load event 差异化 opcode（formLoadEventOpcode，author 08-20）。同期 XiangShanLab 活跃：4636 号分析程序落地、difftest-tracer skill、chisel 教学程序基础库与 issue 工作流改造，教学与实验工具建设持续推进。本次合入使香山在向量扩展覆盖、原子指令与缓存块操作指令支持上明显补强。

3.2 进迭时空：模型库文档工具新仓库 model-zoo-file2md 发布 0.1.1

日期：2026-08-28　来源：spacemit-com/model-zoo-file2md

进迭时空窗口内 3 笔提交（新仓库 model-zoo-file2md）：新增 document to markdown 组件（feat(file2md)）、恢复可读的 0.1.1 发布说明、移除本地 benchmark 报告脚本。该仓库定位为模型库文档转 Markdown 工具链，服务进迭 model zoo 系列仓库（model_zoo_rl 等）的文档标准化。结合前日 docs-chip 仓库 AVL 文档化工作，进迭时空正持续强化模型库与硬件文档的工程化沉淀，当日动态量小，属工具链打磨。

四、具身智能与机器人专章

4.1 窗口内无 RISC-V 具身智能新品；Hugging Face 生态 Microduck 双足机器人发布（RK3566/ARM，生态参考）

日期：2026-08-28　来源：CNX Software、pollen-robotics/microduck

Pollen Robotics 与 Hugging Face 发布 Microduck：25 cm 高双足机器人，15 个电机（腿/头/颈自由度）、相机 + 深度传感器 + 双 IMU + 8×8 ToF LiDAR、可抓取物件的铰接喙，399 美元预售，2026 年圣诞前发货，限北美与欧洲。其主控为 Rockchip RK3566（四核 Cortex-A55，非 RISC-V），软件栈（Rust 编写的 50 Hz 伺服控制守护进程、Python 强化学习训练工具、Hugging Face 在线模拟器）全开源。本窗口 RISC-V 侧无具身智能硬件新品；该条作为生态参考收录——物理 AI 硬件浪潮（Hugging Face 开源机器人生态）仍在加速，但终端主控主流仍选 ARM 平台，RISC-V 在具身智能领域的渗透依旧呈现”标准与治理层先行（MIPS 晋升顶级会员，昨日已报）、终端落地待观察”的格局。

五、总结与趋势观察

  1. 本窗口核心事件是 SiFive BigSky 从”发布”走向”交付”：Futurum 分析师确认首批系统已在超大规模云厂商等领先客户部署运行负载，RVA23 完整合规 + Ubuntu 26.04 LTS/RHEL 10 开箱即用，CUDA 在 P870-D 上承担 NVIDIA GPU head node 角色；分析对标”RISC-V 服务器处于 Arm 2018 年位置”，软件就绪度已成数据中心落地的主要矛盾。未公布性能与定价数据，商务验证仍待观察。
  2. 香山完成一批跨月开发成果的大规模合入：向量单元重构 + Zvknha/Zvbb 密码学向量扩展 + ZICBO 缓存块操作扩展 + AMOCAS 原子指令支持，指令覆盖与安全特性显著补强；XiangShanLab 教学实验工具（4636 程序、difftest-tracer）同步推进，研究向工程转化节奏稳定。
  3. 国内团队动态分化：进迭时空发布文档工具新仓库 model-zoo-file2md 0.1.1；算能、平头哥（XUANTIE-RV）、芯来、奕斯伟计算窗口内均无提交——算能昨日刚完成 CV84X6 官方规格落地，属正常节奏轮换。
  4. 具身智能：窗口内无 RISC-V 硬件新品；Hugging Face 生态 Microduck 双足机器人选用 RK3566（ARM），物理 AI 终端主控仍以 ARM 为主，RISC-V 在该领域的落地节奏慢于治理层信号。
  5. 局限性说明：gnews 中文团队查询（平头哥/香山/算能/进迭/芯来/奕斯伟）为空或噪音（香山命中均为北京香山论坛同名新闻）；”Milk-V” 查询被 gnews 分词拆解为牛奶类内容严重污染；StarFive 命中 301536.SZ（星宸科技，非赛昉）半年报误标；国内团队信息以 GitHub 提交为准。
