一、开源社区与软件生态

1.1 PoCL 7.2 发布，OpenCL 3.0 官方一致性落地 RISC-V 与 x86_64

日期：2026-09-04　来源：Phoronix

可移植计算语言项目 PoCL 发布 7.2 版，成为经 Khronos Group 认证的官方 OpenCL 3.0 一致性实现，覆盖 RISC-V（RV64GC 与 RVA22 级硬件）与 x86_64（AVX-512 路径，以 AMD Ryzen 9 9900X 验证）两类 CPU 平台。新版本同时支持 LLVM 22（含 CUDA 与 Level Zero 设备后端）及最高 LLVM 23 的 CPU 设备目标，并跟进 cl_khr_extended_bit_ops、cl_khr_integer_dot_product、cl_khr_kernel_clock、cl_khr_spirv_linkonce_odr 等一批新 OpenCL 扩展。对 RISC-V 生态而言，这是开放并行计算标准首次在 RISC-V 通用处理器上获得官方一致性背书，标志着 RISC-V 在桌面与服务器侧异构计算软件栈的成熟度再进一步。

1.2 回声条目：ServeTheHome 补发 Hot Chips 2026 SiFive 标准与采纳演讲实录

日期：2026-09-04　来源：ServeTheHome

ServeTheHome 补发其在 Hot Chips 2026 期间记录的 SiFive《RISC-V 标准与采纳》演讲实录。昨日（09-03）报告已收录 SiFive 官方博客的同主题补录，本篇属同源媒体回声，实质内容无新增，按去重口径不再单列详述；仅补强一处信号——演讲收尾称首批 RVA23 服务器芯片将于今年落地，标准工作正转化为真实硬件，与 SiFive 服务器平台规范（RVA23 + AIA 中断 + UEFI/ACPI + MCTP/Redfish 管理）的推进相互印证。

二、产品与生态动态

2.1 XenoSpectrum 分析：中国服务器市场仍 74% x86，北京缘何押注 RISC-V

日期：2026-09-04　来源：XenoSpectrum（译自日文原创）

日媒 XenoSpectrum 刊发长文，从市场数据与政策逻辑两端分析中国 RISC-V 战略：一方面服务器市场约 74% 份额仍由 x86 把持，现实与”RISC-V 已铺开”的观感存在落差；另一方面北京通过信创名录、国资云与采购补贴等组合拳持续押注。文章批评业内流传的”RISC-V 出货占比”数字常被剥离时间点与产品品类语境反复引用，造成扩散性夸大；并以 RISC-V E203（0.145mW）较 Arm Cortex-M0（0.17mW）省电约 15% 的研究为例，指出此类孤例结论不宜泛化。该文对评估国内 RISC-V 服务器叙事的”预期与现实的落差”具有参考价值，可视为近期”中国 RISC-V 政策热”报道的祛魅式补充。

三、国内团队动态与深挖

3.1 中科昊芯完成 B 轮融资，押注 AI 边缘端 RISC-V DSP

日期：2026-09-03/04　来源：科创板日报（经东方财富转载）、投资界

北京中科昊芯（中国科学院自动化研究所成果转化企业，基于 RISC-V 架构的数字信号处理器专业供应商）近日完成 B 轮融资，投资方为悦湖资本，资金重点投向 AI 边缘端芯片产品与行业定制化解决方案研发。公司自研 Haawking HX2000 系列 DSP 已实现规模化应用，覆盖 AI 智慧家电、工业控制、新能源汽车、光伏储能及具身智能等领域，主打高端 DSP 国产化替代；其团队自 2016 年起投入 RISC-V 处理器研究，构建了从内核、架构到自主工具链（Haawking IDE）的全链条自研体系。值得关注的是赛道热度：同赛道六岳微电子 2026 年 7 月刚完成 5 亿元 A 轮融资（粤科金融、广州工控等十余家机构参与），资本正加速涌入 RISC-V DSP 这一”国产替代 + 具身智能”交叉赛道。

3.2 乐鑫 ESP32-S31 开发板上手：双核 RISC-V 320MHz + Wi-Fi 6

日期：2026-09-04　来源：Geeky Gadgets（Google News 聚合）、Espressif 官方产品页

Geeky Gadgets 发布乐鑫 ESP32-S31 开发板（40-pin 排针 + 双 USB-C）上手评测。ESP32-S31 是乐鑫 S 系列中采用 RISC-V 的双核 32 位 SoC：主频 320MHz、一核带 128 位宽数据通路与 SIMD 指令，配 MMU、512KB SRAM 与 250MHz 8-bit DDR PSRAM（支持与 flash 并发访问），最多 60 GPIO；无线侧集成 2.4GHz Wi-Fi 6、蓝牙 5.4（LE Audio/测向/Mesh 1.1）与 IEEE 802.15.4（Thread/Zigbee），对 Matter 协议提供 Wi-Fi 与 Thread 双路径支持。官方称已进入量产并可购买，由 ESP-IDF、ESP-Matter、ESP-GMF 全栈支持，也可经 ESP-Hosted/ESP-AT 作连接协处理器，目标场景为智能家居中枢、智能音箱、边缘 AI 与工业自动化。继 C 系列（C2/C3/C5/C6/C61，RISC-V）与 P4 之后，乐鑫将 RISC-V 主控进一步引入 S 系列产品线；需注意 S31 与此前 Xtensa 内核的 S2/S3 架构不同，报道勿混为一谈。

3.3 国内团队 GitHub 综合核查：整体平静

日期：2026-09-04/05　来源：GitHub org 检索（XUANTIE-RV、Nuclei-Software、sophgo、spacemit-com、eswincomputing、espressif、revyos、sipeed）

窗口内国内团队开源侧整体平静，无重大新发布：

  • 达摩院玄铁（XUANTIE-RV，72 仓库）、奕斯伟计算（eswincomputing，16 仓库）：窗口内无推送。
  • 芯来科技（Nuclei-Software）：nuclei-sdk、nuclei-linux-sdk 与 opensbi 仓库有例行同步推送，提交内容为常规维护。
  • 算能（sophgo）：sophon-demo 修复 Qwen3.5 系列在 BM1684X2 上图片输入输出异常，属演示套件维护。
  • 进迭时空（spacemit-com）：ai-sdk 更新 RL 子模块引用，model_zoo_rl 新增”导出原始策略动作以支持行为跟踪”功能（#10），端侧机器人强化学习工具链持续迭代。
  • 矽速（sipeed）：NanoKVM（RISC-V IP-KVM）改进终端启动登录 shell 与 SSH 提示，体验性更新。

四、具身智能与机器人专章

4.1 窗口观察：无重大机器人新品，RISC-V 具身叙事由融资与 RL 工具链承接

日期：2026-09-04/05

窗口内未见新的 RISC-V 机器人整机或具身专用芯片发布。周边关联动态两条：其一，中科昊芯 B 轮融资明确将”具身智能”列为 HX2000 DSP 规模化应用场景之一（见 3.1），资金投向 AI 边缘端芯片，说明工业控制类 RISC-V 处理器正借助具身智能扩大叙事半径；其二，进迭时空 model_zoo_rl 新增原始策略动作导出接口（见 3.3），延续其在机器人强化学习模型工具链上的投入。另注：CNX Software 报道的 Petoi Quaddle 迷你机器狗（众筹）主控为 ESP32-S3（Xtensa 内核），非 RISC-V 平台，按报道口径剔除。行业主线仍延续昨日引述的”人形机器人计算走向中央与分布式混合架构”讨论与”具身智能量产元年”的产业叙事。

五、总结与趋势观察

  1. 软件生态：PoCL 7.2 让 RISC-V CPU 首次拿下 OpenCL 3.0 官方一致性认证，开放并行计算标准与 RISC-V 的结合再获实质性背书，利好桌面/服务器侧异构计算栈。
  2. 资本面：中科昊芯 B 轮落地（悦湖资本），叠加六岳微电子 7 月 5 亿元 A 轮，RISC-V DSP 在”高端国产替代 + AI 边缘 + 具身智能”叙事下成为资本密集赛道。
  3. 产品面：乐鑫 ESP32-S31（双核 RISC-V 320MHz + Wi-Fi 6 + 802.15.4）开发板开始铺开上手评测，量产可用且 ESP-IDF/Matter/语音生态同步就绪，RISC-V 在消费级 AIoT 主控的渗透加深。
  4. 叙事面：XenoSpectrum 长文提示”RISC-V 服务器占比”类数字常被脱离时间与品类语境引用；”首批 RVA23 服务器年内落地”的信号与”服务器市场仍 74% x86”的现实并存，高端市场放量仍需时间验证。
  5. 平静日说明：国内团队 GitHub 侧仅常规维护，机器人方向无窗口内新品；本期以软件生态里程碑与融资事件为主。

局限性说明：本日早间 Google News 补充查询通道经多次超时，已改用 Tavily 检索与直连原站复核兜底，并据 GitHub org 扫描交叉验证国内团队动态；覆盖面以英文技术媒体、中文财经媒体与 GitHub 为主，未发现窗口内遗漏的重大事件，但不排除个别中文自媒体信源未被覆盖。
