一、开源社区与软件生态

1.1 香山：昆明湖 V3 将 ROB 扩大至 160 项；GEM5 增加两线程 SpMT 资源划分

日期：2026-10-16　来源：XiangShan PR #6730（10-16）、GEM5 xs-dev #1231（10-16）、NEMU PR #1246（10-16）、NEMU PR #1252（10-16）

香山主仓（kunminghu-v3）合入 #6730：将重排序缓冲（ROB）容量扩大至 160 项，属乱序执行窗口的参数级性能调整，直接扩大可同时在飞的指令数量。仿真侧 GEM5（xs-dev 分支）合入 #1231：为两线程 SpMT 增加中间端（middle end）资源划分，指向多线程共享前端／重命名资源时的隔离与配额。验证侧同窗口两笔：NEMU #1246 新增昆明湖 V2（kmhv2）配置并对齐 V2 与 V3 的公共修复，使参考模型同时覆盖两代微架构；#1252 降低 DiffTest 存储 CRC 校验开销。窗口内 difftest、XSCache 主分支无新增。

1.2 openRuyi：主仓一次合入 6 个 Rust 生态软件包，补齐裸机与驱动开发组件

日期：2026-10-16　来源：openRuyi 主仓提交记录（10-16）

openRuyi 主仓由维护者 luojia65 一次性提交 6 个 SPECS 包：rust-riscv 0.16、rust-riscv-macros 0.4、rust-riscv-types 0.1、rust-embedded-hal 1、rust-volatile-register 0.2、rust-vcell 0.1。该组软件包覆盖 RISC-V 裸机运行时、嵌入式 HAL 抽象与底层寄存器访问，是 Rust 在 RISC-V 裸机与驱动场景落地的底层依赖；对发行版而言，意味着 Rust 的支持范围从编译器本身扩展到运行期组件成组进入打包体系。官网新闻页本期无新版本公告（最新仍为 2026.09）。

1.3 meta-riscv：linux-mainline 升至 7.2.11，riscv-common 改为优先主线内核与 U-Boot

日期：2026-10-16~10-19　来源：riscv/meta-riscv 提交记录（10-16~10-19）

Yocto 层 meta-riscv 窗口内 14 笔提交：linux-mainline 由 7.2.10 升至 7.2.11；riscv-common 调整为首选主线 Linux 与 U-Boot，减少对厂商 BSP 分支的依赖；文档侧补齐进迭时空 K3 Pico-ITX、K3 COM260 与 LicheePi-4A 的启动与 UART 说明，并为 freedom-u540 设定 KERNEL_IMAGETYPE=Image。发行版构建层向主线收敛，与 openRuyi、RevyOS 近期的平台收拢动作同向。

二、产品与生态动态

2.1 Tenstorrent 据报同时与 Intel、Qualcomm 洽谈出售，估值或超 50 亿美元

日期：2026-10-17　来源：Startup Fortune：Intel and Qualcomm Both Court Jim Keller’s AI Chip Startup Tenstorrent（10-17）

据 Bloomberg 报道（Startup Fortune 转述），RISC-V AI 芯片公司 Tenstorrent 正分别与 Intel、Qualcomm 就潜在出售进行谈判，并已聘请投行评估，交易估值可能超过 50 亿美元；消息传出后 Intel 股价盘中一度上涨 6.4%。Intel、Qualcomm 与 Tenstorrent 均拒绝置评。Tenstorrent 由 Jim Keller 执掌，是 RISC-V 高性能 AI 加速与 IP 的代表性公司；今年 6 月曾传出 Qualcomm 以 80–100 亿美元洽购，Keller 当时予以否认。该事项仍处媒体报道阶段，未获任何一方确认。

2.2 AI 智能体完成 RISC-V 加密 SoC 全流程设计：算力成本约 2000 美元、功耗 20 mW

日期：2026-10-16（原始报道 10-15）　来源：腾讯新闻（快科技）：门槛崩塌！AI 耗资 1.4 万就能设计出 RISC-V 芯片（10-16）

半导体博主 @bubbleboi 使用 Meta 的 Muse AI 智能体，完成一款 RISC-V 加密专用 SoC 从逻辑设计到布局布线的全流程：消耗约 1 亿 token、算力成本约 2000 美元；借助 OpenROAD 完成布局布线并生成可送厂的 GDSII 版图。设计含约 61590 个逻辑单元、100 MHz、功耗 20 mW、时序余量 4.5 ns，通过 DRC 检查与 150 万条 Berkeley TestFloat 向量校验。作者正寻找多项目晶圆（MPW）共享流片机会。该结果尚未经硅验证，属个人实验，但为「AI 参与芯片设计」的成本曲线提供了可复核样本。

三、国内团队深挖

3.1 睿思芯科完成战略融资：任君资本、水木基金入股，继续加码 RISC-V 服务器 CPU

日期：2026-10-16　来源：搜狐（大河财立方）：睿思芯科完成战略融资（10-16）

睿思芯科（深圳）完成新一轮战略融资，投资方包括任君资本、水木基金，金额未披露。公司由谭章熹创立，团队出自加州大学伯克利分校 RISC-V 原创项目组，曾推出国内首款全自研 RISC-V 服务器处理器「灵羽」，此前完成由深重投国资领投的 B 轮。本轮资金将用于 RISC-V 服务器级高性能处理器与云原生 CPU 研发。谭章熹同时担任 RISC-V 国际开源实验室（RIOS）联合主任，今日峰会开幕式亦由其致辞。

3.2 奕斯伟计算上市后首周：市值 338 亿港元，人机交互仍占收入 76%

日期：2026-10-17　来源：新浪财经（中国经营报）：奕斯伟计算上市即破发 RISC-V 仍待规模化商用（10-17）

10-09 在港交所挂牌的奕斯伟计算（01256.HK）首份上市后市场评估出炉：首日收报 1.535 港元、跌 0.97%，市值约 338 亿港元；2023–2025 年营收 17.52／20.25／24.31 亿元，经调整净利润分别为 −17.05／−14.40／−11.61 亿元，毛利率在 14%–18% 区间；人机交互芯片仍占收入基本盘 76%，单价由 20.9 元降至 11.6 元。按 2025 年营收计，其在中国 RISC-V 主控芯片市场排名第五、国产厂商第三，份额 1.2%（前五合计 22.5%）。

3.3 进迭时空 llama.cpp 分支发布 v0.2.3：合入 K3 decode 状态优化并同步上游

日期：2026-10-16　来源：llama.cpp v0.2.3 Release（10-16）、PR #48：perf/k3-decode-state（10-16）

spacemit-com/llama.cpp 的 mtmd-backend 分支发布 v0.2.3：合入 #48（K3 decode 阶段状态复用优化）与 #47（同步上游 20261014 版本），并更新版本号。该分支维持约 1–3 周一版的节奏（v0.2.2 于 10-13 发布），持续收敛 K1／K3 端侧推理的可用性与性能。

3.4 算能 zsbl：将各 cpusys 拆分为独立应用子目录

日期：2026-10-16　来源：sophgo/zsbl 提交记录（10-16）

算能 zsbl（ZScale Boot Loader）窗口内 1 笔结构调整：将每个 cpusys 拆分为独立的应用子目录，便于不同芯片平台分别维护引导代码。属引导固件侧的工程重构，未涉及功能变更；同期 sophon-tools 亦有推送。

四、具身智能与机器人专章

4.1 智元机器人战略入股芯际无限：RISC-V 人形机器人算力走向专用底座

日期：2026-10-18　来源：搜狐（半导体产业纵横）：智元战略投资芯际无限！加码清华系 RISC-V 具身智能算力赛道（10-18）

智元机器人战略入股清华系 RISC-V AI 芯片公司芯际无限。芯际无限是清华大学唯一技术转化并持股的 RISC-V AI 芯片企业，团队自 2016 年起从事 RISC-V 研究；2026 年清华华控技术转移以核心 RISC-V 知识产权作价入股。产品侧：

  • XC64AE（小脑芯片）：12 核 RISC-V 内核＋自研 NPU，兼顾运动控制与中端环境感知，首款已流片回片并推出标准化开发方案；V1000（大脑芯片）基于 2.5D Chiplet，标称 1000 TOPS；关节控制芯片已量产，2027 年第二代 XC64AE 全系列计划流片。
  • 车规 XC32 系列：XC32MC 车身电机控制 MCU 已批量上车，累计订单超 500 万颗；XC32LS 符合 ASIL-D，已流片点亮、计划 2027 年量产；XC32DC 中央域控预计 2028 年定点量产。
  • 意义：在特斯拉自研 FSD 与英伟达 Jetson 通用平台之外，芯际无限选择「全栈自研 RISC-V＋可裁剪指令扩展＋Chiplet」的第三条路线；智元带来整机场景与实测数据，加速芯片从样品走向量产验证。

4.2 峰会机器人议题：10-20 设汽车电子、工业与机器人分论坛，具身智能渗透率预期升至 28.2%

日期：2026-10-17~10-19　来源：第六届 RISC-V 中国峰会官网议程、证券时报：RISC-V 重磅峰会将举办，产业空间有望超 2000 亿元（10-17）

峰会 10-20 设「汽车电子、工业与机器人」分论坛（联合主席：赛昉科技徐滔、沁恒微杨勇），主论坛亦安排零次方机器人分享 RISC-V 架构在具身智能领域的应用。市场侧，弗若斯特沙利文数据显示：RISC-V 在中国具身智能芯片的渗透率预计由 2025 年 10.7% 升至 2030 年 28.2%，智能终端由 6.9% 升至 26.7%；中国 RISC-V 主控芯片市场由 2025 年约 377 亿元增至 2030 年约 2194 亿元。

五、总结与趋势观察

  • 峰会进入「议程兑现」阶段：会前两周的议程、参展商与讲者预热已结束，10-19 主论坛与 10-20 七场分论坛是检验「生态成熟度」叙事的第一手材料；AI 与数据中心两条主线（达摩院 AME、奕斯伟 RISC-V＋AI、蓝芯 LX500）集中在主论坛下午场。
  • 资本冷热分化明显：一级市场持续加注（智元入股芯际无限、睿思芯科完成战投），二级市场则给出「理性偏冷」定价（奕斯伟上市首日破发、A 股 RISC-V 概念股年内平均回撤）。产业长期空间（2030 年 2194 亿元）与短期盈利兑现之间的错位，仍是估值主线。
  • 软件栈三条推进线：微架构侧香山以 ROB 扩容与 NEMU 双版本配置提升性能与验证覆盖面；发行版侧 openRuyi 补 Rust 运行期组件、meta-riscv 向主线内核／U-Boot 收敛；端侧推理侧进迭时空 llama.cpp 保持 1–3 周一版迭代。
  • 具身智能成为 RISC-V 差异化战场：从芯际无限的专用 SoC＋Chiplet，到峰会机器人分论坛与 28.2% 渗透率预期，RISC-V 在机器人算力上的叙事已从「可用」转向「专用底座＋场景数据闭环」。
  • 局限说明：峰会主论坛讲者与顺序依据会前公布材料，官网对 10-19 仍标注「详细议程即将公布」，以现场为准；Tenstorrent 出售事项为媒体报道、三方未确认；AI 设计 RISC-V SoC 为个人实验、尚未流片，数据以作者公开描述为准；会员官网巡检的变化多为营销页刷新，未检出实质产品发布。
