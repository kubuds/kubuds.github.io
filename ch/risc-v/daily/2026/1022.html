今日重点：Qualcomm 收购 RISC-V 服务器 IP 公司 Akeana，美系大厂加速收拢架构资产

日期：2026-10-21　来源：Dealroom：Qualcomm buys RISC-V startup Akeana to push into AI and data-center chips（10-21）、Sammy Fans：Qualcomm acquires Samsung foundry partner Akeana to expand AI chip business（10-21）

据 10-21 报道，Qualcomm 已完成对 RISC-V 处理器 IP 初创公司 Akeana 的收购，交易金额未披露。Akeana 创始人兼 CEO Rabin Sugumar 已在职业社交平台确认，Akeana 的 IP 与团队「已成为 Qualcomm 的一部分」，其本人加入 Qualcomm 出任工程副总裁。

  • 公司背景：Akeana 成立于 2021 年，核心团队出自 Marvell／Cavium 的 ThunderX 服务器处理器团队；2024 年 8 月走出隐身状态并披露融资超过 1 亿美元（Kleiner Perkins、Mayfield、Fidelity 等参投），IP 覆盖 Akeana 100／1000／5000 三档（MCU 级 32 位核、带 MMU 的 64 位核、面向笔记本与数据中心的超高性能核），并提供 AI 矩阵计算引擎与安全、调试、RAS、遥测等系统 IP。
  • 产业侧线索：Akeana 与三星代工合作推进 4nm 服务器芯片，2025 年 12 月双方完成代号 Alpine 的服务器测试芯片设计，这是本条与「三星代工生态」直接相关的地方。
  • Qualcomm 的连续动作：2025 年 12 月 Qualcomm 收购 RISC-V 服务器 CPU IP 公司 Ventana Micro Systems；此后完成对 Alphawave 的 24 亿美元收购，并与 Amazon 公布定制 AI 推理合作。加上本次 Akeana，Qualcomm 在 10 个月内收进两家 RISC-V 服务器 IP 团队。
  • 解读边界：交易金额、客户承诺与产品时间表均未公开，Akeana 的 IP 线是否并入 Qualcomm 自有 CPU 路线（Oryon）还是独立产品线，目前没有官方说明；本条只做事实层面的并购确认，商业回报尚待观察。

与国内路线的对照：同一周内，进迭时空联合香山发布服务器级 CPU V100（6 个香山昆明湖 V2R2 核 + 40 个自研 X100 核，46 核），走的是「开源核＋自研核混合」的产品化路径。海外是 IP 团队向大厂集中，国内是开源核向商用芯片渗透，两条路径都在回答同一个问题：服务器级 RISC-V 的 IP 供给从哪里来。

1.1 RISE 发布首个基于 RVA23 的 Android 17 开源版本

日期：2026-10-20　来源：RISE：Android 17 Available on RVA23 with RISE（10-20）、RISE android_manifest：android-17-v1.0（10-20）

RISE 项目宣布交付首个运行在 RVA23 硬件上的 Android 17 构建，以开源形式发布，支持 SpacemiT K3 Pico-ITX 与阿里巴巴 A210 EVB 两块板卡。该项目编号 RP024，由 RISE 出资并牵头，成员单位 进迭时空与阿里达摩院提供平台经验与硬件，BayLibre 承担工程实现，建立在其此前 SpacemiT K1 的 Android 移植基础上。

  • 发布内容：android-17-v1.0 提供两块板卡的二进制镜像、锁定版本的源码 manifest、校验和、烧写工具与重建说明，源码历史与作者信息完整保留，可复现、可扩展。
  • 开放程度：采用 U-Boot + OpenSBI 的开源启动链，图形栈基于上游 Imagination 内核驱动与 Mesa；官方明确这是面向开发者的开源版本，不是量产或认证版本。
  • 下一阶段：RP024 第二阶段将把构建、硬件测试与发布流程自动化，先在 RISE Board Farm 已有的 A210 系统上跑测试，数周内加入 K3；RISE 还预告后续 RFP 将覆盖 Bionic、BoringSSL、ART、V8、Chrome 与多媒体库，并推动厂商把平台支持回灌 Linux 内核、U-Boot 与 OpenSBI。

RVA23 是 RISC-V 应用处理器的规范分水岭，Android 17 在其上跑通并开源，意味着「移动操作系统 + 应用处理器规范」这条最苛刻的组合第一次有了可复现的公共基线。

1.2 Linux 7.4 加密库：RISC-V 与 x86 的 AES 优化实现并入 lib/crypto

日期：2026-10-21　来源：Phoronix：Linux 7.4 Kernel Crypto Library Enjoying Optimized AES Implementations On x86 & RISC-V（10-21）

Google 内核工程师 Eric Biggers 的加密子系统性能工作已合入 Linux 7.4：把 x86／x86_64 与 RISC-V 的 AES 各模式优化实现迁移进 lib/crypto 内核加密库。

  • 覆盖模式：ECB、CBC、CBC-CTS、CTR、XCTR、XTS 六种；迁移后库 API 在这些架构上直接获得加速，crypto_skcipher 一侧的使用同样继续受益。
  • x86 侧：走 AVX 优化代码与 AES-NI 指令；RISC-V 侧为基于向量与加密扩展的加速实现。
  • 附带收益：清理掉大量重复的胶水代码，减少维护面。同批更新还包括开发者 Stian Halseth 为 SPARC64 编写的 AES-XTS 优化实现。

对 RISC-V 而言，这条的价值不在「又一个优化提交」，而在落点：加速实现从架构私有目录搬进通用库，内核内其它消费者（文件系统加密、IPsec、dm-crypt 等）无需改动即可受益，属于基础设施层的可复用收益。

1.3 openRuyi：20 笔 SPECS 提交，uv 的 Rust 依赖成批入库

日期：2026-10-22　来源：openRuyi 主仓提交记录（10-22）、openRuyi 官网新闻页

openRuyi 主仓在窗口内录得 20 笔提交，集中在 10-22 凌晨的一批 SPECS 入库，全部为 rust-uv-* 0.0.96 系列包：pep440、pep508、platform-tags、pypi-types、options-metadata、normalize、toml、version、small-str、globfilter、git-types、fs、errors、logging、macros、redacted、static、preview、warnings、windows。

这批包是 uv（Rust 编写的 Python 包与项目管理器）的依赖组件。上一期日报记录的 40 笔提交集中在 minio、Prometheus、sarama 等 Go 云原生组件，本期转向 Python 工具链，两天连起来看，openRuyi 正在把「数据中心常用服务」与「Python 开发工具链」两类软件补齐到 RISC-V 发行版里。官网新闻页最新公告仍为 2026.09 版本，窗口内无新版本发布。

2.1 乐鑫 ESP-Mosaico 开售：ESP32-S31 模块化 AI 硬件套件，59 美元起

日期：2026-10-21　来源：CNX Software：ESP-Mosaico — An ESP32-S31-based modular development platform for AI-assisted hardware creation（10-21）、Mosaico 商店

乐鑫推出 ESP-Mosaico：一块以 ESP32-S31 为核心的模块化开发平台，主打「AI 与硬件结合」，面向磁吸扩展玩具、运动感知、方形触控 HMI 与边缘语音／多媒体场景。

  • 核心板：ESP32-S31NRV16（320MHz RV32IMAFCP 高性能核＋低功耗 MCU 核，512KB SRAM＋32KB 低功耗 SRAM＋16MB PSRAM），Wi-Fi 6、蓝牙 5.4（含 LE Audio、方向查找、Mesh 1.1 与 Classic）、802.15.4；128MB SPI NAND＋16MB SPI NOR。
  • 人机与外设：2.16 英寸 480×480 QSPI 触摸屏（CO5300＋CST9220）、NS4150B 功放与 ES8311 编解码、双 BMM150 磁力计、BMI270 六轴、振动马达、USB-C 供电与烧写；底板通过 60 针板对板连接器扩展，含扬声器与 3.7V／65mAh 电池。
  • 模块化：已推出摄像头模块（OV3640 3.2MP 或 SC101IOT）与多功能交互模块（光敏、PIR、红外 LED、6 颗 WS2812、机械键／电容触摸焊盘）。
  • 开发方式：官方给出两条路径——通过 ESP-Claw 的自然语言「对话式编码」，以及通过 ESP-ZeroCode AI 的「氛围编程」，由 AI 代理承担实现、部署、真机测试与迭代。
  • 价格与状态：含摄像头与交互模块的完整套件 59 美元，电池模块 15 美元；此前已在淘宝与第三方渠道销售数月，现由官方商店正式开售。

ESP32-S31 从「预览器件」走向成品套件只用了约两个月（10-14 才出现首款第三方开发板），而这一代产品把开发体验本身当成卖点：自然语言生成固件、AI 代理跑真机测试，这是 RISC-V MCU 在端侧与 ARM 生态竞争时少见的差异化切口。

三、国内团队深挖

3.1 达摩院玄铁开出 CubeSandbox RISC-V 支持分支：CubeShim 对接 KVM／AIA VMM 后端

日期：2026-10-21　来源：XUANTIE-RV/CubeSandbox：add_riscv_support 分支（10-21）、TencentCloud/CubeSandbox 上游仓库

达摩院玄铁（XUANTIE-RV）在 GitHub 上维护的 CubeSandbox 分支 add_riscv_support 窗口内有新提交：注册 riscv64-control-plane-demo.yml 工作流供手动触发。CubeSandbox 是腾讯云开源的 AI Agent 沙箱服务（Apache 2.0，硬件级隔离、毫秒级启动、兼容 E2B 接口，已进入 CNCF Landscape），玄铁分支在做的正是把它移植到 RISC-V。

  • 构建路径：make all-riscv64 可交叉编译架构无关的控制面、guest 工具、Cubelet 与 CubeVS／eBPF，交叉构建镜像自动生成；guest 内核用 make guest-kernel KERNEL_TARGET_ARCH=riscv64 单独构建。
  • 冷启动：CubeShim 已改为对接实验性的 RISC-V KVM／AIA VMM 后端，支持直接内核冷启动。
  • 现状边界：RISC-V 侧快照／恢复仍关闭，需等 vAIA 状态迁移实现；官方未提供发布镜像与受支持的部署路径，属开发者预览阶段。

AI Agent 的代码执行沙箱是今年增长最快的一类基础设施，其底层依赖虚拟化与特权指令的完整度。玄铁把这条栈搬上 RISC-V，指向的是「RISC-V 服务器能不能承载 Agent 工作负载」这一具体命题，也是 RISC-V 在 AIA（高级中断架构）落地后最直接的应用侧验证。

3.2 奕斯伟计算与 SiFive 签署黄金合作伙伴联盟 MOU，合作从边缘 AI 扩展到 Agentic AI

日期：2026-10-21　来源：网易（华商韬略）：奕斯伟计算与 SiFive 签署黄金合作伙伴联盟 MOU（10-21）、观点网：奕斯伟计算与 SiFive 签署黄金合作伙伴联盟 MOU 深化 RISC-V+AI 合作（10-21）

奕斯伟计算与 RISC-V 处理器 IP 企业 SiFive 正式签署黄金合作伙伴联盟备忘录（Gold Partner Alliance MOU）。这是奕斯伟计算 10-09 在港交所上市后推进的一项国际产业合作。

  • 合作基础：奕斯伟计算的 EIC7700 SoC 已用于 SiFive 旗舰开发板 HiFive Premier P550，面向全球开发者提供高性能 RISC-V 硬件平台并已规模化上市，双方技术协同已有可核验的产品。
  • 升级方向：合作从边缘 AI 扩展到 Agentic AI 等应用，共同挖掘低功耗、高性能 AI 方案需求，并按客户集成诉求探索多层级 RISC-V 产品形态。
  • 双方定位：SiFive 由 RISC-V 指令集创始团队成员创立，强在架构与内核 IP；奕斯伟计算强在产品落地与商业化，公司口径为国内领先的 RISC-V 主控芯片提供商之一。

值得注意的是合作的时间点：奕斯伟上市后第一笔公开的国际合作不是产能或代工，而是与 IP 供应商的联盟升级。对照同期 Qualcomm 直接收购 IP 团队的做法，国内厂商选择了「自研核＋外部 IP 联盟」的混合路线。

3.3 算能 sophon-demo 完成 CV84X6 适配：新增 MiniCPM4、InternVL3 与 MiniCPMV 样例

日期：2026-10-21　来源：sophgo/sophon-demo 提交记录（10-21）

算能（Sophgo）示例仓库 sophon-demo 在 release 分支合入提交「CV84X6 适配：MiniCPM4 + InternVL3 + MiniCPMV」，为 CV84X6 平台补上三个多模态／端侧大模型样例。

  • 模型覆盖：MiniCPM4（端侧小参数语言模型）、InternVL3（多模态视觉语言模型）、MiniCPMV（面壁智能的多模态端侧模型）——三者都属端侧部署取向，与算能 SoC 的边缘推理定位一致。
  • 仓库节奏：近期同仓还有 PaddleOCR-VL、SAM3、SAM2、BLIP、MP_SENet、YOLO_world 的 C++ 样例新增，示例库正从 Python 参考实现向 C++ 工程化样例扩展。
  • 同窗口其他提交：zsbl 主分支 1 笔，把应用选择上移到 SoC 级 Kconfig，属启动固件的结构性整理。

端侧芯片的竞争力越来越取决于「模型到了能不能跑、跑得动不动」——把当年最热的多模态模型在自家平台上补齐样例，比赛道宣传更实际。

四、具身智能与机器人专章

4.1 峰会汽车电子、工业与机器人分论坛：紫荆 M100 量产上车，IAR 与芯来补齐工具链与 IP

日期：2026-10-21　来源：人民网（北青网）：开源架构的黄金时刻——2026 RISC-V 中国峰会分论坛传递产业新信号（10-21）

第六届 RISC-V 中国峰会七大平行分论坛（10-20）的回顾报道，把汽车电子、工业与机器人方向的具体进展摊开：

  • 紫荆半导体：长城汽车孵化的芯片公司，其 紫荆 M100 已成为量产上车的 RISC-V 车规芯片。整车厂内部孵化的 RISC-V 车规产品从样片走到量产，是这一轮「上车」叙事里最硬的证据。
  • IAR：从工具链视角提出 RISC-V 在汽车、工业与机器人领域的三大挑战，并推出 RISC-V 开发工具，主打安全关键场景的合规开发。

  • 兆松科技：参与实时控制与车规 MCU 架构落地议题；同分论坛还有阿里达摩院介绍车规路线图。

分论坛的整体口径是「RISC-V 已从能不能用进入好用、商用阶段」，但落到工程细节，讨论的仍是安全认证、实时控制、工具链合规这三件难事——恰恰是机器人关节控制与车规底盘域控的共同门槛。

4.2 机器人算力侧由融资叙事转入量产验证：关节控制芯片已量产，大脑芯片仍处流片阶段

日期：2026-10-21　来源：人民网（北青网）：2026 RISC-V 中国峰会分论坛传递产业新信号（10-21）、东方财富：智元机器人 47 次出手投了什么（10-20）

24 小时窗口内，具身智能方向没有新的独立融资或整机发布，可核验的进展集中在产能与验证环节：

  • 量产侧：芯际无限的机器人关节控制芯片已量产，面向中端算力的 XC64AE 已启动与头部具身智能企业的量产验证，首款小脑芯片完成流片回片；车规侧智能电机控制 MCU 出货突破 100 万颗，2026 年新签订单 520 万颗。
  • 未落地部分：定位大脑的 V1000（2.5D Chiplet，设计算力 1000 TOPS）仍处流片阶段，第二代 XC64AE 全系列计划 2027 年流片。
  • 资本侧：智元机器人入股芯际无限（Pre-A 轮）后，其投资版图已覆盖本体、关键零部件与底层算力芯片；本体厂商以资本锁定上游，使指令集选择在早期就被绑定。

这条线索的意义在于节奏差：小脑与关节控制这类实时、低算力、强认证的环节已进入量产，而大算力的「大脑」芯片仍在流片与对标阶段。RISC-V 在机器人上的第一波真实出货，很可能来自关节与运动控制，而不是通用 AI 算力。

五、总结与趋势观察

  • 服务器 IP 的归属正在集中：Qualcomm 十个月内收进 Ventana 与 Akeana 两家 RISC-V 服务器 IP 团队，独立 IP 供应商的数量在减少；国内则把开源核（香山昆明湖 V2R2）装进商用服务器芯片（V100）。同一周的两件事，说明服务器级 RISC-V 的 IP 供给正在分化为「大厂内部资产」与「开源核产品化」两条路。
  • Android on RVA23 是平台化节点，不是又一次移植：RISE 这次给的是锁定 manifest、校验和、烧写工具与重建路径，加第二阶段的全自动构建与 Board Farm 测试。可复现、可回归，才是应用处理器生态真正的门槛。
  • 性能工作从架构私有走向通用复用：Linux 7.4 把 RISC-V 与 x86 的 AES 各模式实现搬进 lib/crypto，删掉重复胶水代码。这类改动不显眼，但让加密、存储、网络等上层消费者自动受益。
  • 发行版补齐的层次在上移：openRuyi 前一天批量入库 Go 云原生组件，这一天把 uv 的 20 个 Rust 依赖打包进 SPECS。从内核、工具链到 Python 开发工具，RISC-V 发行版的「可日常使用」正在被逐层填满。
  • 端侧竞争转向开发体验：ESP-Mosaico 以 59 美元套件、自然语言生成固件、AI 代理跑真机测试作为卖点。当芯片规格趋同，谁能把「从想法到硬件」的路径缩短，谁就更容易拿到开发者。
  • 车规与机器人仍是国内落地主线：紫荆 M100 量产上车、芯际无限关节控制芯片量产、奕斯伟与 SiFive 的 IP 联盟，三条线分别对应整车、机器人与通用 IP 供给。峰会口径乐观，但认证、实时性与工具链仍是决定性变量。
  • 局限说明：Qualcomm 收购 Akeana 的交易金额、客户承诺与产品整合方案均未披露，现有信息来自 Dealroom 与 Sammy Fans 的报道及当事人社交平台确认，未见 Qualcomm 官方新闻稿；RISE 的 Android 17 属开发者版本，明确不适用于量产；Linux 7.4 加密库条目依据 Phoronix 报道，未逐条核对补丁；openRuyi 的 uv 依赖入库仅从提交标题判断用途，未见发行版公告；Radxa Linkr v1.6.0 未附变动清单；峰会分论坛内容来自媒体回顾报道，厂商口径未必经第三方验证；会员官网巡检检出的变化均为高校、机构与厂商官网的例行更新，未发现实质产品、融资或架构发布；香山系与部分重点仓库 pushed_at 显示有推送，默认分支复核窗口内无新提交，判断为非默认分支或 PR 头分支活动。
