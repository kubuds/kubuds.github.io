本期提要：当日最重的一条在标准层。达摩院玄铁以 RISC-V Unified Database 的 YAML 格式，提交了名为 Zvfc 的复数向量扩展提案。提案含 18 条指令，版本 0.1.0，状态标为 development。发行版侧，openRuyi 一夜 35 笔，nodejs 升到 26.13.1，并修了 RISC-V 返回地址偏移。固件侧配套 11 笔，EDK II 基线升到 edk2-stable202611。机器人侧，进迭把 SONIC 规划器接到 G1，Go2 加了学到的自翻正与舞蹈策略。媒体侧当日无 RISC-V 新品发布。

今日重点：达摩院玄铁提交 Zvfc 复数向量扩展提案，18 条指令（11-23）

11 月 23 日，达摩院玄铁在 XUANTIE-RV/zvfx-proposal 仓库提交一份扩展提案。提案名为 Zvfc，全称 Vector Floating-Point Complex Arithmetic。该仓库是 riscv-unified-db 的镜像分支，提案按 UDB 的 YAML 结构写进 spec/std/isa 下的标准扩展位。提交共 21 个文件，含 1 份扩展定义、18 条指令定义与 2 处金样本更新。

Zvfc 定义 18 条指令。vfcjadd.vv 与 vfcjsub.vv 是带 j 旋转的加减，只有向量-向量形态。vfcmul、vfcmacc、vfcnmul、vfcnmsac 四组各有实部（r）与虚部（i）形式，每组都有 .vv 与 .vs 两种形态。复数按相邻元素对存放，偶数索引放实部，奇数索引放虚部。

扩展依赖 Zve32f，版本号 0.1.0，状态标为 development。乘累加按融合运算处理，分量乘积不先舍入。寄存器组须能容纳一组完整复数对，否则指令保留。奇数 vl 可用，奇数 vstart 保留。实现可在 vl 为奇数时多读一个源元素，只有活动输出元素产生浮点异常标志。文件头版权署名为 Alibaba Damo Academy。

日期：2026-11-23　来源：https://github.com/XUANTIE-RV/zvfx-proposal 。

RISC-V 100 榜单动态

灵晟条目改题为 TOP500 第一，分数口径补齐（11-21）

riscv100.top 巡检今天报出显著变化，复核后是站点把 11 月 21 日那条公告改了标题。原题是 LineShine LX2: SPEC CPU2017 Rate on One Node (256 copies)。现题是 TOP500 #1 LineShine: Single-Node SPECrate 422/452。公告 slug 未变，仍是 2026-11-21-lineshine-lx2-spec17-rate。

榜单记录本身与上期一致。日期 11 月 19 日，编译器 LLVM 23.1.0，平台 LineShine-LX2，整数 272.258、浮点 291.613，状态 completed。新标题里的 422 与 452 是未按主频归一的原始分。422 除以 1.55GHz 得 272.258，452 除以 1.55GHz 得 291.613。

灵晟（LineShine）是深圳国家超算中心的 CPU-only 超算，LX2 为 Armv9 平台。该记录进的是跨架构对照榜，作用是为 RISC-V 平台提供同榜基线。它不构成 RISC-V 成绩。RISC-V 频道六张榜单本期无新增，委员会成员无增删。

日期：2026-11-21　来源：https://riscv100.top/cross-arch/spec17/ 。

一、开源社区与软件生态

openRuyi 35 笔：nodejs 升 26.13.1，修 RISC-V 返回地址偏移（11-23）

11 月 23 日，openRuyi 主仓在窗口内落地 35 笔 SPECS 提交。nodejs 升到 26.13.1，其中一笔专门修 Wasm 帧代码查找与 RISC-V 返回地址偏移。同批把 nodejs 切到 LLD、系统 Abseil 与共享 Temporal，并按 OpenSSL 4 调整测试预期。

其余改动分布在图形与语言栈。mesa 升到 26.3.1，opencv 升到 5.1.0，linux 与 linux-lts 刷新补丁集与配置。Rust 侧一次补进 ICU4X 相关的 20 余个包，含 icu-calendar、icu-locale、diplomat、tzif、ixdtf 与 temporal-rs。另有 spdk-mcp 的 RPC schema 修复，python-mcp 恢复 pyjwt crypto extra。

日期：2026-11-23　来源：https://github.com/openRuyi-Project/openRuyi 。

ruyifirmware：EDK II 升到 edk2-stable202611，SG2042 改用 SBI 存运行变量（11-23）

同日，配套固件仓 ruyifirmware 落了 7 笔。EDK II 基线更新到 edk2-stable202611，固件版本号改为从 EDK II checkout 推导。SG2042 平台的持久运行变量改走 SBI 调用，不再依赖平台自有存储路径。

CI 侧同时换底。一笔在 Debian 13 里构建固件，另一笔改用 Ubuntu 26.04 的 GCC，并从 coreboot 中去掉 libgcc。K3 的 PCIe 驱动另有一笔针对 GCC 16 的适配。

edk2-ruyi 仓同步 4 笔。改动要求 RISC-V EFI 内存映射使用恒等映射，把 SG2042 的运行变量与高地址 MMIO 解耦，并在 DSC 里写入固件标识。Spacemit 平台包把 PCIe 子设备的初始化提到端口校验之前。

日期：2026-11-23　来源：https://github.com/openRuyi-Project/ruyifirmware 。

香山 GEM5 把 RVWMO litmus 测试纳入周回归（11-23）

香山的 GEM5 仓当日 5 笔。最新一笔把 RVWMO 的 litmus 测试挂进每周回归。另一笔修 RISC-V 下 CSR 纯读的写副作用与 SATP squash，还有一笔放宽只读 CSR 指令的排序约束。同批含 cpu-o3 的取指块 trace 数据库，以及一处 o3 提交阶段 bad address 的 panic 修复。

日期：2026-11-23　来源：https://github.com/OpenXiangShan/GEM5 。

CVA6 与 CVW：向量模式基址对 256 字节对齐，浮点向量跑 Verilator（11-23）

openhwfoundation 侧，CVA6 合入一笔基址对齐，向量模式下把 stvec 与 vstvec 的 BASE 对齐到 256 字节。CVW 把 TestFloat 与 cover-float 的向量搬到 Verilator 上跑，逐个向量比对。

同日 core-v-mcu 修 uDMA 的 QSPI 四线 LSB-first 接收与摄像头 VSYNC 极性，cvfpu-uvm 补上测试计划与功能覆盖率模型。

日期：2026-11-23　来源：https://github.com/openhwfoundation/cva6 。

libRPMI 七笔：时钟树资源释放与时钟组测试补齐（11-23）

riscv-software-src 的 libRPMI 当日 7 笔。核心两处是时钟树销毁时释放全部资源，以及时钟组线性区间的速率计数处理修正。测试侧补了时钟组线性范围与 set rate 的 round down、auto 模式用例，README 与 logo 一并更新。

日期：2026-11-23　来源：https://github.com/riscv-software-src/librpmi 。

二、产品与生态动态

乐鑫 esp-riscv-trace 加指令语义解码器与故障窗口（11-23）

乐鑫的 esp-riscv-trace 仓当日 6 笔，两条特性线合入 master。解码侧新增指令语义解码器，并把 RV32 的共享编码规则抽到 encoding.py。分析侧新增寄存器来源回溯的故障窗口，并给进入未跟踪代码的调用补上被调方名字。

五、总结与趋势观察

  • 标准层：玄铁的 Zvfc 把复数运算做成 RVV 的扩展提案，直接写进 UDB 的数据结构。国内厂商以标准格式提交 ISA 扩展，此前不常见。
  • 固件层：ruyifirmware 与 edk2-ruyi 同日推进。EDK II 基线、SBI 运行变量、K3 PCIe 与 SG2042 解耦四件事一起做。
  • 机器人层：进迭两个仓同步接 SONIC 规划器。公共层给接口，机型层给参数。

把三条放在一起看，当日没有发布会，也没有新跑分。可核查的进展都落在结构里：ISA 定义文件、固件调用路径、规划器接口。这类工作不出新闻，却决定后面的平台能否复用。媒体侧当日最接近的几条是 RISC-V Club 的后续转载与平头哥的资本叙事。前者已在 11 月 23 日一期收录，后者主体是 PPU 与倚天线，不属 RISC-V。
