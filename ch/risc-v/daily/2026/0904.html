一、开源社区与软件生态

1.1 GCC 17 合入 RISC-V 原生的 -mcpu/-mtune=native 支持

日期：2026-09-03　来源：Phoronix

GCC 在 RISC-V 后端长期缺失的 “本机自动调优” 能力终于补齐：此前讨论的 -mcpu=native / -mtune=native 支持补丁已合入 GCC 主线，将随 GCC 17.1（2027 年初发布）落地。过去 RISC-V 用户若想按本机 CPU 优化代码生成，必须手写具体型号名（如 sifive-p550、spacemit-x100），与 x86/Arm 的 native 行为不一致。本次补丁来自 SiFive 的 Kito Cheng（RISC-V 工具链核心维护者之一）。当前已知限制：对多核异构 SoC（如 SpacemiT A100 与 X100 混搭平台），GCC 只能按编译进程实际运行所在的核心类型选 CPU 目标，暂无法感知全芯片异构拓扑。这是 RISC-V 工具链”服务器化/易用化”的又一小步，与 RVA23 服务器硅片今年落地（见 1.2）形成配套。

1.2 SiFive 详解 RISC-V 标准体系与未来演进：Hot Chips 2026 演讲实录补录

日期：2026-09-02 发布 / 09-03 被 HN 与 Google News 收录（本窗口补录）　来源：ServeTheHome（Patrick Kennedy 现场记录）、Hacker News

ServeTheHome 补发其 Hot Chips 2026（8 月下旬，斯坦福）现场记录——SiFive 的 RISC-V 标准与采用进展演讲。该演讲与 09-02 已报的 NVIDIA CUDA-on-RISC-V 教程同属本届 Hot Chips”RISC-V 服务器化”叙事，本期为两条线索中较”标准科普”的一条。要点：

  • 标准体系全景：以 RISC-V 十六周年（2010-05-18 生日）为引，重申”开放标准非单家公司命运绑定”；四类基础 ISA（RV32I/RV64I/RV32E/RV64E）已批准，CHERI 能力安全变体与未来 RV128（128 位地址空间）正在开发；
  • Profile 机制细化：RVA20/RVA22/RVA23 三代演进（RVA23 于 2024-10 批准，强制向量与 hypervisor），明确大版本加强制功能、小版本只增 option 的兼容模型，保证新软件在旧硬件上可运行；RVB23（Yocto/OpenEmbedded 定制构建场景）独立演进；
  • AI 与安全：矩阵扩展给出 AME/IME/VME + 向量 fast-track 的”1+3”并行路线；强调 RISC-V 是唯一能同时扮演 AI 主机 ISA（CUDA 移植）、加速器设备 ISA 与端侧自托管 ISA 的架构；安全特性清单含 PMP、RISC-V Worlds 总线级隔离、面向机密计算的 supervisor domains、指针屏蔽，进行中项目含 CHERI、推测屏障、内存标签与内存加密上下文；
  • 破除流言：逐一回应”变长指令是弱点”“RISC-V 需要指令融合才有竞争力”“RISC-V 性能不行”等说法（gnews 上”SiFive RISC-V requires Fusion”“has too many extensions”等惊悚标题均出自该文小节）。作者结语：首个 RVA23 服务器今年出货，是标准工作落地硬件的实际信号。

二、产品与生态动态

2.1 趋势条目：CUDA-on-RISC-V 媒体回声延续：BigSky 定位”移植验证平台”，NVLink Fusion 芯片最早 2027

日期：2026-09-03　来源：igor’sLAB（德媒，英文版）

德媒 igor’sLAB 于 09-03 刊出 SiFive BigSky SF-2U870 的跟进解读（主事件 08-25 已报，本期不重复展开），口径可作为生态节奏的第三方确认：BigSky（32 核 P870-D @ 2.0GHz、RVA23、Ubuntu 26.04 LTS / RHEL 10）定位是面向超大规模云厂商、芯片公司与软件开发者的移植验证平台，而非对标 EPYC/Xeon 的量产服务器；CUDA 已在其上运行——RISC-V 核担任主机跑操作系统与控制任务，CUDA 内核实际在 NVIDIA GPU 上执行，据 RISC-V International 周报，该演示为 RISC-V 主机 + NVIDIA Blackwell GPU 组合。文中重申：SiFive 与 NVIDIA 正推进 NVLink Fusion 集成，首批集成 NVLink Fusion 的 RISC-V 定制芯片最早 2027 年才可能问世，BigSky 的意义在于先把软件栈在真实硬件上备好。结合 09-02 已报 NVIDIA 的要求清单（RVA23/ACPI/一致性），”CUDA 上 RISC-V”的落地节奏判断不变：软件先行、硅片在后。

三、国内团队动态与深挖

3.1 香山主仓与 XSAI：向量/浮点单元重构推进，AI 分支持续同步

日期：2026-09-03/04　来源：openxiangshan/XiangShan commits、openxiangshan/XSAI、openxiangshan 组织

中科院计算所主导的开源高性能核 XiangShan 窗口内合入 6 笔提交（较昨日 10+ 笔节奏放缓，属正常波动），集中在向量/浮点执行与流水线优化：

  • refactor(VCVT)：浮点与向量类型转换单元（VCVT）开始重构，引入新的 VCVTWrapper 结构（初始支持）；
  • perf(LoadQueueReplay)：优化 LoadQueueReplay 延迟（#6422）；
  • refactor(VIMac)：向量整数乘加单元初始化支持；fix(vector,exu)：向量执行源操作数不应总走 bypass 数据；
  • config(isa)：ISA 扩展字符串与实现对齐（#6463）；ready-to-run 同步 bump NEMU 引用。

深挖：XSAI——香山 AI 分支并行推进。openxiangshan 组织下存在一个自述为 “A fork of Xiangshan for AI” 的仓库 XSAI（2023-12 建仓），窗口内持续合入：difftest 子模块对齐 mrelease retirement 语义（#121）、nightly regression checkpoint 池更新（#120）；回溯可见其 08-31 批量同步昆明湖（kunminghu-v2）bug 修复（#115）、并引入 Palladium 仿真环境的 commit-stall 看门狗（#119）——说明香山团队在通用核（昆明湖）之外维护着一条面向 AI 负载的处理器变体线，且与主线的正确性修复保持同步；另一仓库 YunSuan（云算）为香山功能单元的独立单元测试工程（Verilator 仿真），属验证基建。整体看，香山系”处理器+模拟器+AI 变体+功能单元测试”的开发闭环仍在全速运转，向量/浮点与可靠性打磨是当前主题。

3.2 HICOOL 2026 RISC-V+AI 协同创新挑战赛收官

日期：2026-09-03（决赛颁奖）　来源：国际科技创新中心网络服务平台（北京亦庄官微转载）、赛事主页 rdi.hicool.com、经济参考网（复赛报道，08-21）

国内首个聚焦 RISC-V 与 AI 融合创新的专项赛事——HICOOL 2026 全球创业大赛”集成电路前沿技术：RISC-V+AI 协同创新挑战赛”在中国国际展览中心完成决赛路演与颁奖，十强队伍角逐全部奖项后圆满落幕：

  • 一等奖花落”基于 RISC-V 与 OpenHarmony 的智能视频监控（NVR）端侧 AI 分析系统”；另有 3 个二等奖、6 个三等奖，获奖项目覆盖端侧 AI 分析、国产芯片工业适配、边缘计算终端、教育场景解决方案、工业数据流处理等方向；
  • 赛事由北京市人才工作局指导、北京海外高层次人才协会主办，北京 RISC-V 数字基础设施创新中心与北京奕斯伟计算（ESWIN Computing）联合承办，RDI 聚力联盟等协办，四大赛道为 AI 驱动芯片设计、算力底座与 CLI 创新、RISC-V+AI 场景应用、OPC 超级个体轻量化 AI；
  • 获奖权益设计颇能反映北京亦庄的生态打法：可申请每年最高 2000 万元算力券、经开区”科创二十条/人才十条”与集成电路专项政策、免费使用 ACT（RISC-V 架构符合性测试）工具并获 RISC-V 测试认证、奕斯伟计算生态背书与开发者生态对接、免费加入 RDI 聚力联盟。

与 08-21 复赛（70 余项目晋级、近百位创业者）相比，决赛聚焦十强，标志着该赛事从”项目征集”走完”落地孵化”第一程。对国内 RISC-V 生态而言，这是继”香山开源、奕斯伟商业、亦庄产业政策”之后，“开源内核 + 头部商业公司 + 区域产业带”三方合力的又一显性动作；NVR 端侧 AI 一等奖项目同时命中 RISC-V 与 OpenHarmony 两个开源底座，值得跟踪其后续产业化。

四、具身智能与机器人专章

4.1 人形机器人计算走向”中央+分布式”混合架构，安全复杂度高于自动驾驶

日期：2026-09-03（Liz Allan 文）　来源：Semiconductor Engineering、Jon Peddie Research 分析（09-03）

Semiconductor Engineering 刊发行业圆桌综述，讨论人形机器人算力架构与安全设计。核心判断与 RISC-V 生态强相关：

  • 架构共识：混合制。英飞凌人形机器人系统架构师 Ronald Stärz 提出”中央强算力 + 指端/关节级分布式预处理”的混合模型，明确类比汽车从集中 ECU 到 zone 架构的迁移（延迟、带宽、容错驱动）；MIPI Alliance Physical AI BoF 主席 Edo Cohen 补充手部局部实时推理（毫秒级抓握力调节）与中央任务规划的职责切分，但也提示集中式架构在 BOM、功耗与软件复杂度上可能更优。TI 则主张”哑传感器 + 中央融合”路线以省功耗。共同点是：安全绝不能只交给 AI 模型，必须有独立认证的硬件组件兜底；
  • 安全威胁模型升级：Secure-IC（Cadence 旗下，RISC-V 安全 IP 重要供应商）CTO 指出人形机器人与自动驾驶的本质差异——物理亲近性（家庭、医院、学校），使中间人攻击、LLM 操纵弱势群体等场景成为现实风险；功能安全与网络安全的融合成为刚需；
  • RISC-V 角度：MIPS（GF 旗下，全面转向 RISC-V）市场负责人 James Prior 的表述被单独引用——”客户问的不是何时采用 RISC-V，而是如何转向 RISC-V（找谁合作、走什么路径）”，并强调机器人行业（汽车/工业同源）风险厌恶，需要”软件优先、开放标准、生态活力”的供应叙事。这与昨日 MIPS 三平台（Acies/Actus/Aegis）发布、Jon Peddie Research 09-04 跟进分析（”MIPS gives physical AI three ways to think”）相互印证：RISC-V 在具身智能的竞争正从”芯片规格”转向”架构话语权 + 安全认证 + 生态服务”。

五、总结与趋势观察

  1. 工具链与标准双线”服务器化”收口：GCC 17 补上 RISC-V 原生 -mcpu/-mtune=native（Kito Cheng/SiFive），SiFive 在 Hot Chips 系统化阐述 RVA/RVB profile、安全与矩阵扩展路线——编译、profile、OS 三层都在为首个 RVA23 服务器硅片（今年出货）做准备；本周 Hot Chips 两条 RISC-V 演讲报道（NVIDIA CUDA 要求清单 09-02 已报、SiFive 标准演进今日补录）至此集齐。
  2. CUDA-on-RISC-V 节奏清晰化：第三方媒体（igor’sLAB）与 RISC-V International 周报共同确认 BigSky 的”移植验证平台”定位与 RISC-V 主机 + Blackwell GPU 演示事实；NVLink Fusion 定制芯片最早 2027——软件栈先行、硅片在后的判断不变，短期内不宜高估 RISC-V 服务器出货量。
  3. 国内开源侧唯香山系活跃：昆明湖主仓向量/浮点重构（VCVT、VIMac、LoadQueueReplay）与 AI fork XSAI 的同步修复并进，开发闭环完整；平头哥/芯来/算能/进迭等仍处发布后平静期。
  4. 生态动作看亦庄：HICOOL RISC-V+AI 挑战赛收官（一等奖为 RISC-V+OpenHarmony NVR 端侧 AI），奕斯伟计算与北京 RISC-V 数字基础设施创新中心联合承办、ACT 免费开放——国内 RISC-V+AI 的”产业带孵化”模式初显。
  5. 局限说明：今日无重大新品发布级事件，属标准/工具链/生态会议类信息为主的”轻量日”；BigSky、MIPS 相关报道均为已报主事件的媒体回声，本期只作趋势条目不重复展开；Google News 中文源对国内团队零命中，国内部分依赖 GitHub 提交核查与亦庄官方渠道。
