今日重点：奕斯伟集成电路产业基地落地北京亦庄（11-25）

11 月 25 日，北京经济技术开发区管理委员会与北京奕斯伟科技集团签署经济发展合作协议，奕斯伟集团集成电路产业基地项目落地北京亦庄。

项目以芯片设计为核心，协同算力基础设施建设、硅基与新材料研发、半导体装备等板块。规划说法是纵向打通「芯片—板卡—服务器—算力集群」，覆盖云边智能、具身智能与端侧智能三类场景。

签约双方的定位是 RISC-V 全栈算力产业集群。奕斯伟集团董事长王东升表示，将加大研发投入，推进 RISC-V 计算架构芯片与算力系统的规模化落地。

奕斯伟计算以 RISC-V+AI 为底座，产品分端侧智能、具身智能、云边智能三条线。11 月 19 日的 ICCAD-Expo 2026 上，公司披露已积累 620+ 项 IP、20+ 系列 RISC-V 内核。

北京经开区现有集成电路相关企业超 400 家，覆盖设计、制造、封测、装备、材料与零部件。今年前三季度，该区集成电路产值超 1600 亿元。

日期：2026-11-25 来源：https://www.ncsti.gov.cn/kjdt/scyq/bjjjjskfq/jkdt/202611/t20261125_265445.html。另见：https://www.eswin.com/news/newsinfo/179.html。

RISC-V 100 榜单动态

进迭 V100 首次进入 RISC-V SPEC CPU2006 榜（11-24）

11 月 24 日，riscv100.top 的 What’s New 上线一条记录：SpacemiT V100 XSCC 1.1 SPEC CPU2006 Speed。

公告给出的绝对分数是 int 17.879、fp 15.297。模式为 Speed/Base，输入为 ref，29 项整数与浮点测试全部完成。榜单记录的日期为 2026-10-10，早于本次巡检日，属补录上榜，不是当日新测。

榜单按 Ratio/GHz 显示，对应记录为 int 8.127、fp 6.953。

V100 是进迭时空的 RISC-V 服务器处理器，支持 RVA23。官方产品页列出每颗 46 核：6 个香山昆明湖 V2R2 核，40 个进迭 X100 核。

测试在一台双路 V100 节点上运行，操作系统是 openRuyi Creek，只使用了 X100 核。

对照榜单现状，RISC-V 频道 SPEC CPU2006 的榜首仍是香山 KMHv3 配 XSCC 2.0。该记录日期为 2026-10-17，int 22.802、fp 25.649，同为 Ratio/GHz。

日期：2026-11-24 来源：https://riscv100.top/whats-new/2026-11-24-v100-xscc11-spec06-speed。另见：https://riscv100.top/riscv/spec06/。

openRuyi 20 笔：17 个 rust-* 包与 eza 入库，clamav 升到 1.5.5（11-25）

另有 node-exporter 新增，clamav 升到 1.5.5。当日没有版本发布，工作集中在打包面。

日期：2026-11-25 来源：https://github.com/openRuyi-Project/openRuyi/commits/main。

内核标签推进：manifest 增加 7.3.6-2、7.0.14-21、6.18.65-2（11-25）

openRuyi 的 kernel-team-tools 当日 3 笔。晚间一笔在 manifest 里增加 7.3.6-2、7.0.14-21、6.18.65-2 三个内核标签。

另两笔把 linux 与 linux-lts 的配置改为内建 MOTORCOMM_PHY。同一仓库在 25 日凌晨已把 linux 配置升到 v7.3.6-1、linux-lts 升到 v6.18.65-1，这几笔在本次窗口之前。

RevyOS 内核 20 笔配置批量合入，覆盖六家厂商 SoC（11-25）

RevyOS 的 linux 仓（revyos/7.3.y）当日合入 20 笔，提交时间集中在 19:41。

新增的 SoC 配置包括知合 A210、奕斯伟 EIC7700、UltraRISC DP1000、进迭 K1 与 K3、玄铁 TH1520、算能 SG2042 与 SG2044。

同日打开 ARM SCMI，把 EFI framebuffer 换成 efidrm 并启用 drm_panic。还增加了 linuxboot 配置与 debian_defconfig。

另有一笔 K3 的 errata：用 WRS.STO 替代 WRS.NTO。还有一笔为奕斯伟 starpro64 打开风扇控制。

这批提交的作者日期从 2025-12 到 2026-11-20，属长期配置分支的一次性合入，不是当日新写。

日期：2026-11-25 来源：https://github.com/revyos/linux/commits/revyos/7.3.y。

五、总结与趋势观察

  • 产业签约：当日唯一实签在亦庄。奕斯伟把基地落到北京经开区，方向是 RISC-V 芯片设计与全栈算力集群。签约方给出的链条是芯片、板卡、服务器到算力集群。
  • 榜单新平台：进迭 V100 首次进入 RISC-V SPEC CPU2006。机器的构成值得注意：每颗 46 核里，6 个是香山昆明湖 V2R2，40 个是进迭 X100。本次只用 X100 核测，榜单分数为 Ratio/GHz 8.127（int）。
  • 发行版承接服务器验证：该次测试跑的是 openRuyi Creek。同一日 openRuyi 主仓合入 20 笔打包改动，kernel-team-tools 推进内核标签。软件栈与硬件验证开始对得上。
  • 配置批量合入：RevyOS 一次合入 20 笔，覆盖知合、奕斯伟、UltraRISC、进迭、玄铁、算能六家厂商的 SoC。作者日期跨约一年，说明这是长期配置分支的收口，不是新增开发。
  • 从能跑到能调：机器人栈的 11 笔集中在 SLAM 方差、按需编码、串口角色映射与碰撞体。这类改动不出现在发布说明里，但决定真机能不能稳定跑。
  • 近一日趋势：产业侧在签地，软件侧在打包，硬件侧在上榜。三条线各自推进，交集是 openRuyi 与进迭的 V100 节点。
