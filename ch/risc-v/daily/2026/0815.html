一、开源社区与软件生态动态

1.1 USENIX Security 26 论文：Spectre 在商业乱序 RISC-V 硅片上全线成立（今日头条之一）

日期：2026-08-12（论文接收与博客发布，08-12~13 媒体扩散）　来源：Lukas Gerlach 博客（论文短版） / The Register / SC Media

德国研究者 Lukas Gerlach 等的论文《Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors》被 USENIX Security 26 接收并公开。研究在可购得的商业乱序 RISC-V 处理器——平头哥玄铁 C910/C920 与 SiFive P550 上系统验证：此前在 x86 上成立的 Spectre 各变体在 RISC-V 上同样可行（部分需额外技巧）。关键发现：其一，Spectre-BTB（v2）是否可利用取决于固件是否启用间接分支预测器——C910/P550 出厂禁用、C920 启用，启用后攻击成功但偶发机器崩溃，暗示存在硬件缺陷；其二，研究者构建了经 BPF 探针读取任意文件的实际利用链：RISC-V BPF JIT 对内核插入的 BPF_NOSPEC 屏障不生成任何指令，验证器认为程序受保护而生成代码实际无屏障，形成”投机类型混淆”gadget；其三，被测核心将 BTB 在用户态与内核态间分离，使传统内核 Spectre 利用路径变难。论文同时给出防御建议。这是继 2023 年 T-Head 安全公告后，对”RISC-V 免疫 Spectre”迷思的公开系统证伪，对 RISC-V 进入服务器/云基础设施的信任建立构成重要提醒。

1.2 香山 XiangShan：修复 satp 刷新后首条取指错误（#6014）

日期：2026-08-14（07:02 UTC 提交，北京 15:02）　来源：OpenXiangShan/XiangShan GitHub

香山开源高性能 RISC-V 处理器（7191 星）窗口内合入 fix(csr): fix first fetch fault after satp flush (#6014)，修复 satp（页表基址寄存器）刷新后首次取指错误——属地址翻译/页表切换路径的边界条件缺陷修复，与虚拟内存切换正确性直接相关。结合窗口内 difftest/XSCache/GEM5/NEMU 等周边仓库持续推送（15h 内均有更新），香山项目组保持全栈高频迭代节奏。此前 08-13 的 BERTi 性能增强、elaboration 参数缓存加速已在昨日报告收录。

四、重点方向专章：具身智能与机器人

4.1 滴水湖论坛密集释放机器人信号：运控芯片成国产 RISC-V 新战场

滴水湖论坛多款新品指向具身智能：格见半导体单芯片驱动 25 自由度、500 纳秒电流环的机器人运动控制方案（见 3.3），是窗口内最具体的运控级产品信号——电流环周期是运控实时性的核心指标，500 纳秒级别对标高端伺服控制；进迭时空 K3 将机器人运控列为主打场景之一（见 3.1），延续 spacemit-robotics 在 LeRobot（SmolVLA/ACT 端侧部署）、仿人机器人（humanoid_unitree_g1）方向的既有布局；国际电子商情”从十颗芯片看 RISC-V 的主力之路”与新浪 8/14 综述”服务器、AI 和机器人：中国 RISC-V 的下一站”均将机器人列为 RISC-V 三大主力市场之一。运控（实时控制 DSP/MCU）与端侧 AI（VLA 模型推理）构成 RISC-V 具身智能的两条并行主线，前者本周有实质新品落地。

4.2 生态侧承接

香山/进迭等高性能核与算子库进展（见 1.2、3.1）继续为机器人端侧推理提供底座；格见 GS32 系列已获 ASIL-B 认证（6 月），车规级实时控制芯片亦为机器人关节控制复用提供认证基础。

五、总结与趋势观察

  1. 国产 RISC-V 进入”主力叙事”阶段：滴水湖论坛”出货 360 亿颗、市占超 30%、量产率超 90%”的产业数据与 10 款新品（服务器 CPU、机器人运控、车规 CMS、视觉边端、网卡、BMC）集中亮相，覆盖 AI 服务器、具身机器人、汽车电子三大战场，国产 RISC-V 从”可用”向”主力”过渡的叙事在本周成型。这与昨日 SiFive SKL 开源（软件内核库军备）共同指向：RISC-V 硬件生态已足够丰富，竞争重心正在向软件栈与行业落地迁移。
  2. RISC-V 服务器之路出现量产级节点：蓝芯 LX500（48 核 75 TOPS，宣称全球首款 RISC-V 量产服务器 CPU）与赛昉 JH-B100 BMC 同日聚焦，形成”主算力+带外管理”双线进入数据中心的态势；前者若量产落地属实，将与 Tenstorrent Ascalon、平头哥玄铁服务器核（此前报道）同台竞技。
  3. 安全信任建设成为新议题：USENIX Security 26 论文公开验证 Spectre 在商业乱序 RISC-V 硅片（含国产 C910/C920）成立，且指出 BPF JIT 缺屏障这一具体软件缺陷。RISC-V 要进入服务器/云信任边界，安全审计与加固（预测屏障、固件默认配置、JIT 修复）需与性能叙事并行，相关防御工作值得持续跟踪。
  4. 具身智能运控层迎来国产方案：格见半导体 500 纳秒电流环/25 自由度运控芯片与进迭 K3 机器人运控定位，标志 RISC-V 在机器人”运动控制基座”（此前多由 DSP/专用 MCU 占据）打开缺口，与端侧 AI 推理（LeRobot 适配）构成完整落地路径。
  5. 开源高性能核商业化提速：开芯红超亿元种子轮投向香山 IP 核架构升级，XiangShan 窗口内持续合入正确性修复（satp flush 取指错误），开源核”社区迭代+商业公司承接”的模式进一步清晰。
