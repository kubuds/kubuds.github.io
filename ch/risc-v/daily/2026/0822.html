一、开源社区与软件生态

1.1 Ferrite Engineering 发布 EDACrux：RISC-V 芯片验证工具免费化（08-21）

日期：2026-08-21（riscv.org 官方博客发布，21:03 北京）　来源：RISC-V International Blog

RISC-V 老将 Martin Fink（前 HPE CTO，2017 年促成西部数据”每年十亿核转向 RISC-V”的关键人物）二次退休后再度出山，创办新成员组织 Ferrite Engineering，并发布首个产品 EDACrux——一套四件免费 RISC-V 芯片设计验证工具：WaveCrux（波形查看器，内置 RVFI Commit Inspector）、NetCrux（RTL 原理图浏览器）、LintCrux（lint 检查仪表盘）、SimCrux（回归测试管理器），四者共享工作区并可交叉探查，帮助工程师定位”薛定谔指令”（被取指后究竟正常退役、被 squash 还是触发 trap）。

核心亮点：

  • RVFI Commit Inspector：基于 RISC-V Formal Interface（源于 Clifford Wolf 的 riscv-formal，生态广泛采用）把仿真中的退役指令流还原成可读记录，并自动跑六项一致性检查、对照 RISC-V ISA 规范标记偏离——兼容 Ibex、CVA6、PicoRV32、SERV、VeeR 家族及多数 riscv-formal 测试平台；
  • 开源策略明确：”技术上已被开源解决、商业上未被充分服务的 EDA 环节，做精品化集成产品，核心开源、商业增强收费”——公测期（10 月初结束）全功能免费，公测结束后每件工具核心以 Apache 2.0 开源（含源码、测试、构建脚本、波形引擎与 CXP 协议），Pro 版卖”深度与速度”（cycle-by-cycle 会计、分支预测分析、兼容性仪表盘）；
  • 对生态的意义：Fink 直言”告诉你核心违反规范的工具不应该放在许可证后面”。目前多数 RISC-V 芯片仍用商业 EDA 工具设计，EDACrux 免费化降低了学术界与预算有限团队的芯片验证门槛，与 OpenHW CORE-V、CHIPS Alliance VeeR 等开源核形成”开源核 + 开源验证工具”闭环。

二、产品与生态动态

2.1 印度卡纳塔克邦发布 KEO AI PC：RISC-V 处理器 + 边缘 LLM（08-21）

日期：2026-08-21（发布与集中报道，YourStory 23:38 / Moneycontrol 次日 00:22 北京）　来源：The Economic Times、YourStory、ETV Bharat、The Hindu

印度卡纳塔克邦政府（IT-BT 部长 Priyank Kharge）与邦属电子企业 KEONICS 正式发布 KEO（Knowledge-driven, Economical and Open-source）AI PC：基于开源 RISC-V 处理器 + Linux 操作系统，面向公立学校与社区学习场景，主打弥合数字鸿沟。要点：

  • 硬件：RISC-V 处理器、内置 BUDDH AI agent；接口齐全（4G、Wi-Fi、以太网、USB-A/USB-C、HDMI、音频口）；配套演示的”Small AI PC”变体重不足 250 克、开放硬件设计；
  • 落地节奏：KEONICS 已收到 1,500 台预订单，首批部署目标为农村图书馆与学校；预装学习、编程与办公软件；
  • 官方口径：KEONICS 主席 Sharath Kumar Bache Gowda 称这是”全球首个在边缘设备部署 LLM”的案例（注：该表述属官方宣传口径，未披露所用处理器型号与模型规格，RISC-V 端侧大模型已有平头哥 C950 等更早先例）；
  • 背景意义：这是继 IIT Madras 香提（Shakti）、印度 C2S 芯片计划之后，印度邦政府级 RISC-V 终端规模化采购的又一落点，与国内”信创”逻辑同构——政府订单驱动开源 CPU 生态落地，同时降低对 x86/ARM 的依赖。

2.2 LILYGO T-Display K230 Kit：K230 双核 RISC-V 手持终端（08-21）

日期：2026-08-21（LinuxGizmos 报道 12:52 北京）　来源：LinuxGizmos

LILYGO 更新其 T-Display K230 手持开发平台，装入紧凑外壳并增加可拆卸物理键盘：基于嘉楠（Canaan）Kendryte K230 SoC（双核 64 位 RISC-V，1.6GHz + 800MHz，集成 KPU/DPU/GPU/VPU，AI 加速 + 多媒体齐全），4.1 英寸 AMOLED 触屏（568×1232）、2MP 旋转摄像头（1080p）、HDMI 输出（1080p30）、LoRa（SX1262，868/915/923MHz）、2.4G Wi-Fi、以太网、nRF52840 伴生 MCU、1GB LPDDR4。固件侧提供 CanMV / RT-Smart（RT-Thread 智能操作系统）双方案，LILYGO GitHub 仓库 V1.3 增加 LR2021、电池、GPS、LTE-M、风扇、扬声器支持。售价：LoRa CoreSet 约 150 美元、键盘 71~113 美元。这是 K230（国产 RISC-V 视觉 SoC）在”口袋级 Linux/AI 开发终端”形态上的又一产品化尝试，LoRa+键盘组合指向应急通信、离线教学等场景。
