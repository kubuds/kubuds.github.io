一、开源社区与软件生态

1.1 香山：RVV 向量除法指令合入，Smmtt 扩展解码重开，Bpu/FMA/CSR 多路修复

日期：2026-09-11 ~ 2026-09-13　来源：OpenXiangShan/XiangShan 提交记录

窗口内香山主仓共 9 次提交，节奏延续”向量通路重构后转收敛”的判断。功能新增方面：zhaozukang 于 09-12 合入 feat(vector): support vector divide instruction，向量除法指令落地；Xuan Hu 于 09-11 提交 feat(decode): add back conditional Smmtt extension support，将被移除的 Smmtt（Supervisor 域与可信执行环境内存管理）扩展支持以条件 decode 方式重新加入，并同步重构 pass extensions to decode fields 的解码参数传递；HuSipeng 于 09-11 新增分支预测单元 s2_override。缺陷修复集中在浮点与 CSR：Guanghui Cheng 于 09-11 修正 FMA 加数的 NaN-boxing 判断（#6532），并修复 CSR 读改写过程中 LCOFIP 位丢失（#6522）；Zhihao Xu 于 09-11 修复 ICache 两取指 replacer 的 touch 行为（#6416）。清理侧，Xuan Hu 于 09-13 移除后端过时的 VL 非零状态并清理向量无用类与方法。配套仓库方面，XSAI（面向 AI 的香山分支）09-11 提交 difftest 子模块升级（#128）；XSCache（开源 L2/LLC 缓存）与 YunSuan（功能单元库）窗口内无新提交（最近分别为 08-31、09-10）。

1.2 CVA6：窗口内八次提交，PMP 与触发器规则、Zcmp IDLE 门控、xRET 修复集中落地

日期：2026-09-11 ~ 2026-09-13　来源：openhwgroup/cva6 提交记录

开源六发射应用级 RISC-V 核 CVA6 在窗口内共 8 次提交，以特权态与调试正确性为主：Maanvi212006 于 09-13 要求 HLVX 访问必须具备执行权限（#3413，修正 PMP 与 Hypervisor 访存权限组合）；Flavien Solt 于 09-11 集中修复调试触发器语义，包括 NAPOT 地址匹配（#3488）、dmode 触发器写入规则（#3487）与 LoadAddr 触发器动作保留（#3491）；Keerthivasan Palani 于 09-11 修复无 RVH 时 xRET 的 MPRV 处理（#3551）、单步执行下 WFI 停顿（#3525），并将 Zcmp 的 IDLE 状态迁移改为以 issue 应答为门控（#3543）；Téo Biton 于 09-11 为分支预测结构补充有效位（#3550）。整体看，本周提交集中在”特权/调试边界条件正确性”，属典型的功能验证驱动推进；CVA6 亦被 riscv.org 列为性能模型驱动的超标量开源核案例。

2.2 英飞凌在 Hot Chips 2026 讲 RISC-V 汽车：新一代车规 MCU 走 RISC-V 路线，胜负手在车规工具链

日期：2026-09-13　来源：ServeTheHome

英飞凌在 Hot Chips 2026 的演讲实录于窗口内刊发，核心是车规 MCU 的计算需求与 RISC-V 的定位。英飞凌给出的需求画像为：底盘、动力总成与 ADAS 合流要求实时低延迟、高能效与安全性共存，并叠加最高完整性等级与功能安全；其中电机控制一类快控制环需要 10 毫秒内截止、中断延迟在数十纳秒量级，而整车管理类策略功能可容忍数秒与 10 毫秒级中断延迟。英飞凌强调，RISC-V 规定的是指令集架构而非实现细节，指令延迟、存储层次、缓存一致性与锁步、错误追踪等功能安全特性仍由芯片设计方决定，这正是汽车差异化的所在；在 MCU 场景，真正决定胜负的属性是存储器、连接性、专用硬件、供货与最终 BOM 成本，而”是否有车规认证工具链”决定谁能胜出。结论层面，英飞凌把 RISC-V 与区域控制器（zonal controller）角色直接绑定：RISC-V 可加速区域控制单元落地，但应用适配与成本由 SoC 架构、生态推动与部署便利性共同决定，长期采用取决于标准化的软硬件接口与工具链支持。该厂商此前已明确新一代 AURIX 车规 MCU 基于 RISC-V。

2.3 乐鑫 ESP32-P4 跑起《古墓丽影》：双核 400 MHz RISC-V 软渲染 30 FPS，25 美元级开发板

日期：2026-09-13　来源：Tom’s Hardware、GitHub openlara_esp32p4

开发者 alexkid77 将开源引擎 OpenLara（初代《古墓丽影》引擎重实现）移植到乐鑫 ESP32-P4：该 SoC 为双核 400 MHz RISC-V（带 AI 指令扩展），配 16 MB Flash、32 MB PSRAM，工程以 320x240 软件渲染配合芯片内置像素处理加速器（PPA）硬件放大到 1024x600 显示，实现 30 FPS，并接入 I2S 加 ES8311 音频、USB HID 键盘、GT911 触摸与 microSD 存储，另支持 MP3/OGG 解码与在屏 FPS 计数。硬件平台为 ESP32-P4-Function-EV-Board，整板价位在 25 美元级、功耗约 1 瓦。技术意义不在游戏本身，而在展示 RISC-V 应用级 MCU 的算力与显示/音视频外设整合能力：以往需精细预算资源的单片机，如今已能承载上世纪游戏主机量级的实时软渲染负载。该条为研发趣味型产品动态，可作为 RISC-V 端侧算力上行的直观注脚。

三、国内团队动态与深挖

3.1 上海交大 SPMP 标准后续：交大官网刊发深度稿，确认已在香山与芯来芯片部署

日期：2026-09-11（标准获批 08-31）　来源：上海交通大学新闻网、上海教育传媒网

本条为标准事件的续报（2026-08-31 获批、09-08 起主流媒体报道，本刊 09-09 期已收录事件本体）。交大官网于 09-10 至 09-11 刊发深度稿，补充了国内首次”从零起步、完整主导”的具体分量与落地证据：一是技术定位，SPMP（特权态物理内存保护）面向 AI 芯片、车载芯片、智能终端、工业控制器一类”固定布局”场景，用特权态物理内存隔离替代多级页表，避免层层查表带来的高延迟与页表硬件面积/功耗开销；二是落地情况，SPMP 已在香山（中科院开源高性能 RISC-V 处理器）与芯来（国产 RISC-V IP 厂商）等国产芯片上获得部署与应用；三是社区履历，SPMP 入选 RISC-V 国际基金会 2021 年度安全亮点特性，并被 Linux 基金会列为 2023 年度四大 RISC-V 安全进展、为当年我国唯一入选项目；四是评价，RISC-V 国际基金会董事会成员、中科院计算所副所长包云岗致贺，称这是中国机构首次从零起步、自主发起并完整主导 RISC-V 扩展标准的制定，既完善了 RISC-V 安全体系架构，也为国内机构参与国际标准制定树立范例。团队方面，工作由 IPADS（杜冬冬、杨璧丞、夏虞斌、陈海波等）主导，2019-09-23 提交架构初稿，历时近七年，获批时 SPMP 工作组主席为 IPADS 博士杨璧丞。对国内生态的直接含义是：香山与芯来已具备该隔离能力的可实现路径，国产 RISC-V 安全特性的”标准—实现”闭环初步成形。

3.2 芯来科技 IPO 后续：九成营收来自 RISC-V IP 授权，招商证券辅导，上半年营收增 41% 未盈利

日期：2026-09-12 ~ 2026-09-13　来源：凤凰网财经、东方财富

芯来科技北交所上市辅导备案的续报（辅导备案事件本刊 09-10 期已收录）。窗口内媒体补充了三项财务与业务细节：一是收入结构，公司九成营收来自 RISC-V IP 授权，是国内少数以纯 RISC-V CPU IP 授权为主业的厂商，与 ARM 模式下的 IP 授权业务可直接对照；二是辅导机构为招商证券；三是业绩概况，上半年营收同比增长约 41%，但尚未盈利。结合此前信息，芯来已于 09-10 前后启动北交所上市辅导备案，若顺利推进将成为国内 RISC-V IP 第一梯队中率先进入资本市场的企业。对行业的观察价值在于两点：其一，纯 IP 授权在 RISC-V 语境下的盈利模型仍未跑通（高增长、未盈利），与包云岗此前”开源 IP 斩杀线”的论证互为印证；其二，若北交所路径打通，可能为国内 RISC-V IP 与工具链企业提供新的融资范式参考。

3.3 算能 SG2044：UEFI 固件调整引导项排序，sophgo-edk2 同步跟进

日期：2026-09-11　来源：sophgo/edk2-platforms、sophgo/sophgo-edk2

算能（SOPHGO）在窗口内推进 SG2044 平台的 UEFI 固件：Chao Wei 于 09-11 提交 Sophgo/SG2044: Order freshly enumerated boot options ahead of inherited ones，将新枚举的引导项排在继承项之前，修正多启动项的优先级顺序，属典型的多启动介质（NVMe/SD/USB/PXE）场景体验修复；sophgo-edk2 主仓同日同步更新 edk2 与 edk2-platforms 子模块，并在 08:56 至 09:27 间集中推送了 edk2、edk2-platforms、MultiArchUefiPkg 与 sophgo-edk2 四个仓库。结合本刊 09-11 期收录的”MultiArchUefiPkg 内存分配策略调整”，可以看出算能正围绕 SG2044 持续完善 RISC-V 服务器的标准固件启动链路，这是其数据中心方向产品化程度的直接指标。

进迭时空（SpacemiT）在窗口内集中推进端侧 AI 与 OpenHarmony 文档两条线。视觉模型库 model-zoo-vision 于 09-11 合并 #81，新增 RF-DETR COCO 目标检测模型（RF-DETR 为当前实时检测方向的热门方案），并提交 #80 将 SigLIP2 视觉语言模型默认切换到自研的 SpaceMITExecutionProvider 执行后端，意味着其推理栈从复用通用后端转向自有优化路径；ai-sdk 主仓于同一日两次更新 vision 子模块。文档侧，docs-openharmony 于 09-11 合并 #66、#67，新增 OpenHarmony WebView 相关文档并修复缺陷；docs-ai 同日提交英文 File2MD 指南、修正 vLLM 占位文档并对齐侧边栏层级。整体看，进迭时空在”自研执行后端加模型库扩充加文档补齐”三线并行，端侧多模态推理与其 K1/K3 系列芯片的落地配套在持续加密。

4.1 进迭时空 spacemit-robotics：MuJoCo 仿真新增无头模式，机器人仿真走向 CI 化

日期：2026-09-11　来源：spacemit-robotics/simulation_mujoco

进迭时空机器人软件栈（spacemit-robotics）在窗口内继续推进：simulation_mujoco 于 09-11 合并 #8，新增 headless（无头）仿真模式。该仓库为其机器人 SDK 的 MuJoCo 仿真环境，无头模式是仿真从”人工在图形界面里看”转向”服务器端批量/自动运行”的关键能力，通常用于回归测试、参数扫描与持续集成（CI）。结合该组织 09-08 至 09-09 在 IMU 与电机驱动（peripherals-imu、peripherals-motor）、整机控制（control_whole_body）、玲珑人形（humanoid_linglong）、ROS 2 人形（ros2_humanoid）与感知（perception）等仓库的成批推送，其机器人 SDK 已形成”外设驱动—整机控制—仿真—感知”的完整分层，且在持续补齐工程化能力而非仅做演示。这条线索与进迭时空在主芯片侧推进自研推理后端、视觉模型库的节奏一致，指向 RISC-V 平台上的具身智能软件栈正在从”能跑”走向”可测、可交付”。

4.2 深开鸿 M-Robots OS 3.0 Beta：机器人操作系统数字底座适配 ARM/RISC-V/LoongArch/x86 四架构

日期：2026-08-28 发布，2026-09-13 媒体转载　来源：深开鸿官网、凤凰网转载快科技

深开鸿（深圳开鸿数字产业发展）在 2026 中国国际大数据产业博览会（贵阳，8 月 28 日开幕）上发布 M-Robots OS 3.0 Beta，媒体转载落在本窗口内，故一并收录并注明原始发布时间。该系统以开源鸿蒙（OpenHarmony）为底座，是面向多形态机器人的分布式异构多机协同操作系统，1.0（2025-04）解决多硬件形态兼容与低时延通信，2.0（2026-05）补齐积木式框架、混合部署、M-DDS 低延时协同等六大能力，3.0 Beta 重心从单机能力转向群体智能，围绕安全（VAA 统一数字身份、KGSI 安全启动、群体安全状态共享）、实时（自研单芯多内核混合部署，中断响应与任务切换时延小于等于 1 微秒，关键业务 2 秒恢复、整机 4 秒恢复）、群体智能（Agent Native 框架与 M-Claw 分布式自治集群）、数字底座四条主线升级。与本刊主题直接相关的是数字底座一项：其明确适配 ARM、RISC-V、LoongArch、x86 四大架构，并兼容 ROS、Dora-rs、OpenHarmony 三大生态，覆盖 CPU/NPU/GPU/BPU 四类算力。 会上同时演示无人零售、园区巡检、水质检测三个群体协同场景，并联合数字华夏发布基于该系统的全国产人形机器人星行侠 P02。项目已于 2025 年 11 月捐赠开放原子开源基金会，2026 年 6 月社区启动运营，设 13 个 SIG 技术组与独立 PMC。对 RISC-V 生态的含义是：国内头部机器人操作系统在架构层面把 RISC-V 与 ARM 并列为一级支持目标，为 RISC-V 芯片进入具身智能整机提供了上层软件入口。

五、总结与趋势观察

  • 国内 9 月进入 RISC-V 产业活动密集期。9 月 9 日至 11 日 IICIE 深圳落幕并设 RISC-V 产业生态创新大会与生态应用展示区，9 月 16 日至 18 日 IC WORLD 北京设”RISC-V 开放算力论坛：具身智能·大模型·数据中心”专题，议程覆盖 IP、运营商、智算存储、行业数据、操作系统社区与芯片厂商，RISC-V 的议题重心明显从”芯片/指令集”移向”AI 算力与端边协同”。

  • 标准与资本的”双线突破”进入续报阶段。上海交大 SPMP 作为国内首个从零起步完整主导的 ISA 特性，其落地证据被补足到具体芯片（香山、芯来），”标准—实现”闭环初步成形；同期芯来科技冲刺北交所，九成营收来自 RISC-V IP 授权但尚未盈利，与包云岗”开源 IP 斩杀线”的判断形成现实对照，纯 IP 授权的盈利模型仍是国内待解课题。

  • 开源核的功能验证进入深水区。香山窗口内合入向量除法指令并重开 Smmtt（可信执行环境内存管理）条件支持，CVA6 八次提交集中在 PMP、调试触发器、Zcmp 与 xRET 等特权态边界条件——两家高性能开源核的推进重心都落在”安全与特权正确性”，与 SPMP 所代表的国产安全特性主线相互呼应。

  • 端侧算力上行继续被硬件事实佐证。乐鑫 ESP32-P4 以双核 400 MHz RISC-V 加内置像素处理加速器，在 25 美元级、约 1 瓦的开发板上实现《古墓丽影》引擎 30 FPS 软渲染，说明 RISC-V 应用级 MCU 的能力边界已越过传统单片机范畴，对机器人、工业与消费端侧的本地化算力方案有直接提示。

  • 具身智能软件栈在向工程化收敛。进迭时空 spacemit-robotics 为 MuJoCo 仿真补上无头模式，使其具备服务器端批量回归与 CI 能力；深开鸿 M-Robots OS 3.0 Beta 把 RISC-V 与 ARM 并列为数字底座四大支持架构之一。二者分别从”可测”与”可承载”两个方向，为 RISC-V 进入具身智能整机铺路。
