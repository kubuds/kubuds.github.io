今日重点：进迭时空联合香山发布服务器级 CPU V100，业内首颗完整符合 RISC-V 服务器规范

日期：2026-10-19　来源：电子创新网：进迭时空发布服务器级 CPU V100（10-19）、深圳新闻网：进迭时空发布服务器级 CPU V100（10-19）、Phoronix：SpacemiT Announces The V100 Server-Class RISC-V Processor（10-19）、21 经济网：首颗完整符合 RISC-V 服务器规范的芯片发布（10-19）

第六届 RISC-V 中国峰会第二日（10-19），进迭时空（SpacemiT）与香山团队联合发布服务器级 CPU V100，并同步推出计算、智算、存储三类服务器整机。公司称其为业内首颗完整符合 RISC-V 服务器规范的通用计算芯片。

  • 规范覆盖：把服务器规范落到芯片、固件与操作系统三层，覆盖 RVA23、服务器 SoC、服务器平台、启动与运行时服务（BRS）、安全模型五项规范；其中 BRS 规范测试全项通过，支持 openEuler、openRuyi、openKylin、Debian、Ubuntu、Fedora、Red Hat、Rocky 等主流 Linux 发行版直接安装、启动与运行，不再需要为每颗芯片单独定制系统。
  • 微架构：46 核混合设计——6 个香山昆明湖 V2R2 核 + 40 个自研 X100 核，最高主频 2.4 GHz，双路一致性互联最高扩展至 92 核；单芯片 8 通道 DDR5-4800、52 条 PCIe 5.0 通道。工艺与功耗侧（海外媒体口径）为 12nm、120W TDP，并支持 UEFI、ACPI、SMBIOS。
  • 数据中心的必要件：支持 H 扩展、AIA 与 IOMMU，具备 CPU、内存、中断与 I/O 的硬件虚拟化能力，虚拟化扩展已获上游 Linux 原生支持、无需定制内核；片上集成硬件信任根并支持 RISC-V 原生 TEE；支持 RERI RAS 规范。面向云端 Agent 应用提供轻量级虚拟机方案，以接近容器的资源开销取得虚拟机级隔离。
  • 整机与生态：C2201 计算服务器、G5201 智算服务器、S5236 存储服务器；其中 G5201 支持 8 张全高全长双宽加速卡，已验证昆仑芯 M100 等国产加速卡，支持高速 RDMA 组网；配套主板、固件、BMC 管理与硬件参考设计对外开放。
  • 表态：创始人兼 CEO 陈志坚称「V100 不仅是进迭时空从端到云的重要一步，更代表 RISC-V 正在迈向真正可部署、可规模化应用的数据中心市场」。

一、开源社区与软件生态

1.1 Linux 7.3 正式发布：RISC-V 补齐 RVA23 识别、计数器委派与 KVM 扩展

日期：2026-10-18（媒体报道 10-19）　来源：Phoronix：Linux 7.3 Released（10-18）、Kernel Newbies：Linux 7.3 变更清单

Linux 7.3 于 10 月 18 日按期发布。RISC-V 侧本版落地的内容包括：hwprobe 暴露 RVA23U64 基础行为，让用户态可以直接判断机器是否符合 RVA23；新增计数器委派相关扩展支持（Smcdeleg／Ssccfg／Smcntrpmf）及 Ssqosid 与 CBQRI 的 resctrl 支持；KVM 增加 Svadu、Zicfiss、Zicfilp 的 FWFT 支持；改用 EFI 运行时服务完成关机与重启；arm64 与 RISC-V 共同获得 crashkernel CMA 预留支持；静态计算 alternative 段边界以修补兼容 vDSO，并进一步移除 xip 支持。平台侧新增 StarFive JHB100 初始设备树与Canaan K230（64 位 RISC-V AI SoC）支持；此外补齐 Smcsrind／Sscsrind、Zicclsm、Ziccamoa、Ziccif、Ziccrse、Za64rs 等扩展的识别与枚举。对发行版而言，RVA23 的可探测性是从「靠 Kconfig 猜」转向「运行时可判定」的关键一步。

1.2 香山：XSCache 合入耦合 L2 分 bank SRAM 与预取准入限流

日期：2026-10-19　来源：XSCache PR #36（10-19）、XiangShan PR #6738（10-19）、GEM5 PR #1241（10-19）

香山主仓（kunminghu-v3）窗口内 1 笔：#6738 提升 XSCache 子模块版本。缓存侧 XSCache #36 为实质性性能提交——把 CoupledL2 的 L2 SRAM 按 set 与 bank 拆分，并对预取准入（prefetch admission）做限流，指向末级缓存带宽争用与预取污染两类问题。仿真侧 GEM5（xs-dev）#1241 修正乱序模型：在 store 与 AMO 发送失败时跳过 load 流水线的 replay 标记，避免错误的重放记账。参考模型 NEMU 与 difftest 主分支窗口内无新增（最近一次为 10-16 的 CRC 校验开销优化）。

1.3 openRuyi：dpdk 回移 RISC-V lpm 与 fib 查找优化，spdk 升至 26.09

日期：2026-10-19　来源：openRuyi 主仓提交记录（10-19）、openRuyi 官网新闻页

openRuyi 主仓窗口内 15 笔提交，性能侧两笔最值得记录：dpdk 回移 RISC-V 的 lpm 与 fib 查找优化，直接作用于虚拟交换与路由转发路径；spdk 升至 26.09，跟进上游存储栈版本。打包侧继续成组补 Rust 生态：新增 rust-brotli-7、brotli-decompressor-4、botan-0.10、alloc-stdlib-2、alloc-no-stdlib-2、winreg-0.52、sequoia-man-0.3、self-replace-1，并把 rust-regex 升至 1.13.1、regex-automata 升至 0.4.18、regex-syntax 升至 0.8.11；go-gopkg-h2non-gock 升级至 1.2.0 并清理重复提供者。同期组织内 lookout、kiwi-image、TakoPack 亦有推送。官网新闻页最新版本仍为 2026.09（9 月 30 日发布，本版改进 RVA23 支持、扩充云与存储软件栈、升级 Go 1.27 构建环境），窗口内无新版本公告。

4.1 Ubitium 完成 1400 万美元种子轮：可重构 RISC-V 阵列面向物理 AI

日期：2026-10-13（中文媒体 10-19 报道）　来源：Ubitium 新闻稿（10-13）、Evertiq：Ubitium raises $14M（10-16）、至顶网：Ubitium 获 1400 万美元融资（10-19）

德国杜塞尔多夫初创公司 Ubitium 宣布完成 1400 万美元新种子轮，由 Ibex Investors 领投，OpenOcean 参与，老股东 KBC Focus Fund、Runa Capital、Inflection 跟投，累计种子轮融资 1800 万美元。公司做的是可重构 RISC-V 阵列（CGRA 路线）：用一组可编程处理单元按软件配置动态分配信号处理、AI 推理与实时控制三类负载，以统一内存与标准 RISC-V 工具链替代「DSP + NPU + CPU」的多芯片堆栈，主打无人机、机器人、车辆与工业设备的物理 AI 场景。首颗验证芯片 UB108 采用三星 8nm、256 个处理单元，已演示三类计算在同一阵列上运行；首颗商用芯片 UB410 规划 4096 个处理单元，评估样片计划 2027 年交付。该方向与国内「车规 + 具身」专用 SoC 路线互为对照：一方做专用化，一方做可重构通用化。

4.3 进迭时空机器人感知栈：平面重建在 VDEC 不可用时回退 CPU 图像解码

日期：2026-10-19　来源：spacemit-robotics/perception PR #10（10-19）

spacemit-robotics 组织窗口内 1 笔推送：perception #10「planar 流程在 VDEC 不可用时回退到 CPU JPEG 解码」。该仓库承载机器人视觉的平面重建（planar）流程，此前数周连续调整特征检测参数作用域、ONNX Runtime 链接与模型下载健壮性，本期补上硬件视频解码缺失时的降级路径——对以 K3 等端侧芯片为算力底座的机器人整机而言，属于「没有硬解码也能跑起来」的可用性修补，而非性能优化。同组织其余仓库窗口内无推送。

五、总结与趋势观察

  • 服务器规范从「文档」变成「产品」：V100 把 RVA23、服务器 SoC、服务器平台、BRS 与安全模型五项规范一次性落到芯片、固件与操作系统三层，且 BRS 测试全项通过、主流发行版可直接安装。这意味着 RISC-V 服务器开始摆脱「一芯一系统」的嵌入式惯性，向 x86 式的通用平台模式靠拢——这是本期最具结构性的一步。
  • 开源核第一次进入商用服务器芯片：V100 的 46 核里有 6 个香山昆明湖 V2R2。开源高性能核不再只是学术与验证对象，而是以 IP 形式进入可销售的数据中心产品，香山「开源→产品」的路径由此得到一次可核验的样本。
  • 智算中心成为新的竞争面：珠峰200 明确以 Agent 集群、推理超节点 Host 与混合推理为场景，G5201 已验证昆仑芯 M100 并支持 RDMA 组网，加上算能预告的 RISC-V 智算服务器——三方都在把「CPU + 国产加速卡」的组合推向推理集群，而不是单点对标通用服务器。
  • 基础软件侧同步补齐可判定性：Linux 7.3 让 RVA23 可通过 hwprobe 在运行时判定，并把计数器委派、QoS 标识、KVM 的 Svadu 与影子栈扩展补齐；openRuyi 则把 RISC-V 的 lpm／fib 查找优化回移进 dpdk。前者解决「怎么知道自己是 RVA23」，后者解决「知道之后性能能否兑现」。
  • 资本冷热仍分化：Tenstorrent 以 62 亿美元估值完成 15 亿美元 E 轮、明确拒绝出售，与国内芯际无限数千万元 Pre-A 形成量级对照；但两者共同点是资金都指向「量产与场景落地」，而非架构验证。玄铁 60 亿颗出货与 E908A 的车规双 ASIL 认证，则提供了另一条以规模换生态的路径。
  • 局限说明：V100 的 12nm／120W 工艺与功耗数据来自海外媒体报道，官方中文稿未列该两项；珠峰200 仅公布场景与接口，规格与性能以年底发布为准；算能与北京开源芯片研究院的峰会闪电演讲内容为议程安排，具体产品规格未获公开材料确认；Ubitium 融资发布于 10-13，本期收录依据为 10-19 中文媒体报道；会员官网巡检的变化均为高校与机构首页例行更新，未检出实质产品、融资或架构发布。
