今日重点：奕行智能完成近 20 亿元新一轮融资，投后估值近 150 亿元

日期：2026-09-18　来源：猎云网 via 腾讯新闻《奕行智能完成新一轮近20亿元融资，投后估值接近150亿元》、36Kr 英文《Yixing Intelligence Secures 2 Billion Yuan New Financing》

RISC-V 云端 AI 算力芯片企业奕行智能（EVAS Intelligence）于 09-18 经多家媒体确认完成新一轮融资：金额近 20 亿元（约合 2.95 亿美元），投后估值接近 150 亿元。本轮投资方超过 20 家，包括华泰创新、钟鼎资本、中芯聚源、九安医疗、通富微电、赛意产业基金、和利资本、芯鑫租赁等，其中芯鑫租赁为国家集成电路产业投资基金一期（大基金一期）子基金。这是继今年上半年 15 亿元 B 轮融资与中国移动战略投资后，公司在数月内再度获得的大额资金，也是目前国内 RISC-V 方向披露的最大单笔融资。

产品与商业侧信息一并释出：第一代 Epoch 云端算力芯片已实现规模化量产交付，原生支持分块量化 FP8；今年 7 月 WAIC 期间发布的业界首个 RISC-V AI 算力超节点（64 节点正交无背板、E200-L 液冷 OAM 模组、芯片间百纳秒级互联）已在河北石家庄运营商数据中心完成集群部署，验证了万卡级部署路径；新一代云端芯片已完成流片，公司给出的迭代节奏为”一年一代”。生态侧，公司推进 VISA 虚拟指令集开源，软件栈原生兼容 PyTorch、TensorFlow、JAX、ONNX，并与 vLLM、Triton 及 FlagOS 等社区联动。

政策背景值得对照：工信部与国家发展改革委近期联合印发《电子信息制造业发展”十五五”规划》，在软硬协同部分提出”推进第五代精简指令集（RISC-V）研发与产业化，支持 RISC-V 芯片在人工智能、嵌入式系统等领域应用”。资本市场在本轮给出的估值，与政策指向、以及公司”首个量产级 RISC-V 云端算力”的定位直接相关。需要保留的边界是：估值接近 150 亿元不等于业绩兑现，公司成立四年、首代芯片刚进入规模交付，后续订单与营收兑现节奏是更硬的检验。

一、开源社区与软件生态

1.1 香山 NEMU/difftest：AME 矩阵扩展一批修复与适配

日期：2026-09-18 ~ 09-20　来源：NEMU PR #1224、NEMU PR #1217、difftest PR #962

NEMU 在窗口内合入 5 项提交，AME（矩阵扩展）方向两项：检测对未定义 tile 寄存器区域的读取（#1224，09-20）、把矩阵 load 的比较范围限定在活跃区域（#1217，09-18）；差分测试方向两项：为 SHARE REF 场景标记 CSR 脏位（#1220，09-20）、改用 memmove 导出 GCC 寄存器提升导出性能（#1219，09-18）；虚拟化方向一项：riscv64 保留 RVH 最终 TLB refill 路径、不再强制故障（#1218，09-18）。difftest 侧配套两项：#962 让 AME 打包事件适配 NEMU ABI（09-18），#971 关闭 elfloader 调试打印（09-20）。

这组提交由同一开发者连续推进，主线是让矩阵扩展在 NEMU、difftest 与 RTL 之间行为一致——包括”未定义寄存器区域的读取行为”这类边界语义的明确化。AME 相关支持在香山验证链中的密集落地，说明矩阵计算是其当前指令集扩展工作的重点方向之一。

1.2 香山仓库群：store prefetch 与 CHI 集成等分支级开发活跃，主干无新合并

日期：2026-09-18 ~ 09-20 核查　来源：XiangShan 分支活动、GEM5 分支活动、XSCache 分支活动

窗口内香山主仓、GEM5、XSCache 的 master 均无新合并提交，但分支级推送密集，主要动向可归纳为四条：一是 store prefetch 优化系列在 XSCache 与 XiangShan 同步推进（size8、size4-shadow-dedup 等多个变体分支，属访存预取策略的探索）；二是 GEM5 侧建立 CHI 集成 rebase 分支（feature/chi-dev-v2-rebase-xs-dev-20260920）、cacheline 置换拆分（split-store-perm）与 I-prefetch 对齐分支，对应一致性总线集成与取指优化；三是 XiangShan 主仓出现 TAGE 分支冲突修复（fix-tage-bank-conflict）、RAS 测试（test-ras-1）、快速中断（fast-interrupt）与昆明湖 V3（kunminghu-v3）分支更新；四是部分批量性能实验分支（codex/perf-128-*）。分支活跃、主干待合，属并行开发期的正常形态，本期记录里程碑、待合并后跟踪。

1.3 openRuyi：SPECS 包提交约 20 项，云原生与工具链更新密集；9 月版本未发布

日期：2026-09-19 ~ 09-21　来源：openRuyi 提交记录、openRuyi 官网新闻页

openRuyi 滚动发行版仓库窗口内落地约 20 项 SPECS 提交：新增 cloudpods 与 cloudpods-operator（多云管理平台）、vkmark、assimp、glm、kes 等软件包；更新 go 1.27.1、jemalloc 5.4.0、iptables 1.8.13、flashrom 1.8.0、libjaylink 0.5.0。容器栈方向跟进上游仓库迁移（podman、buildah、composefs、containers-common 的地址更新），并在默认 seccomp profile 中放行 riscv_hwprobe 系统调用——该改动允许容器内程序探测 RISC-V 硬件特性，对云原生负载的可移植性有实际意义。整体看，发行版正在”服务器与云原生”方向持续堆包：云平台、容器、固件工具三类组件同时推进。

官网新闻页核查：最新条目仍为”openRuyi 2026.08 发布”（08-27），2026.09 版本尚未发布。按该发行版月度节奏（每月下旬发布），9 月版本已进入发布窗口，下一期需重点跟踪。

1.4 openRuyi ceph-ci：Ceph RISC-V 移植持续推进，precommit-hooks 新仓落地

日期：2026-09-18　来源：ceph-ci 提交记录、openruyi-precommit-hooks 提交记录

openRuyi 的 Ceph 移植 CI 仓库窗口内落地 8 项提交：为从 GitHub 拉取源码引入 token 认证，解决 CI 拉取失败；对 rocksdb v9.11.2 打 GCC 16 兼容补丁（强制包含 cstdint 头）；rgw 侧 lancedb 升级至 0.39.0，并在 riscv64 上默认关闭 lancedb；CI 流程改为用 dnf 把构建出的 rpm 安装进干净基础镜像做验证，替代此前的手工检查。另有 openruyi-precommit-hooks 新仓库建立，首个钩子为 SPDX 许可证头检查，用于统一软件包提交的许可声明规范。

Ceph 是分布式存储的主力组件，其 RISC-V 移植与 CI 化意味着该发行版在”存储底座可复现构建”上又进一步。GCC 16 兼容补丁这类提交也提示：openRuyi 已开始跟随下一代工具链的预适配节奏。

二、产品与生态动态

2.1 2026 半导体生态发展大会：RISC-V 国际标准时间表与蓝芯 LX500 商业进展

日期：会议 2026-09-17 ~ 09-19（上海）；报道 09-20 进入窗口　来源：财联社／科创板日报 via 东方财富《聚焦2026半导体生态发展大会：产业转向多元技术突围 天基计算、三维封装与RISC-V多点开花》

在上海举行的 2026 半导体生态发展大会（主题”AI 驱动新质创芯”）上，RISC-V 成为独立议题板块，两条产业信息值得记录。

标准时间表：超睿科技（上海）执行总裁兼首席技术官蒋江指出，AI 产业算子库重复投入、生态割裂的痛点，根源在于芯片底层指令集与微架构不统一；RISC-V 的开放标准、软硬件解耦、开源生态是其成为 AI 芯片创新底层范式的三大优势。就 RISC-V 成为国际标准的时间表，他给出”最乐观预计 2027 年底获批，客观来看可能需要 2 至 3 年甚至更长时间”的判断，同时强调这是”不可逆转的大趋势”。

商业进展：蓝芯算力（深圳）首席技术官贾新霞披露，公司今年 2 月点亮首款基于 RISC-V 的”智通融合”一体 CPU 蓝芯 LX500，并基于该芯片推出面向 AI 原生场景的智能体一体机；产品已完成 Qwen 3.5 35B（BF16 精度）与 Kimi K2.6 万亿参数大模型的适配，Kimi K3 128K 超长上下文版本适配推进中。客户侧已落地头部运营商、央国企集团、云服务厂商、金融机构、高校及工业领域，2026 年以来收获国内外批量订单并启动交付，部分国际集群项目在建。

2.2 SEMICON India 2026 闭幕：DIR-V 大赛揭晓，C-DAC 发布 AI 与量子平台

日期：2026-09-19 ~ 09-20　来源：thepublicworld《SEMICON India 2026 Wraps up with 15 New Announcements on Chips, AI and Quantum Tech》、fintechbiznews《Digital India RISC-V Grand Challenge Won By 3 Teams》（Google News 聚合）

SEMICON India 2026 闭幕，15 项新公告中 RISC-V 相关内容占据重要位置：Digital India RISC-V（DIR-V）Grand Challenge 结果揭晓——赛事由 Maker Village 在 MeitY 的 Chips to Startup（C2S）计划下组织，共吸引 1,236 支团队、5,000 余名参与者，三支团队的方案分享 60 万卢比奖金：第一名 SASTRA 大学基于 IIT Madras SHAKTI 处理器的自主水面清洁机器人，第二名来自特里凡得琅的数字听诊器（运行于 C-DAC VEGA 处理器），第三名 IISc 班加罗尔的森林监测系统。参赛作品均基于印度自主 RISC-V 处理器（SHAKTI、VEGA），显示其国产处理器生态开始支撑实际应用创新。

同场其他发布：C-DAC 与 NLC India、Bharat Electronics 分别签署合作（能源行业数据中心；高性能计算、AI 与主权数据中心方案），并发布 PARAM Vidya（面向高校与初创的即插即用 AI 实验平台）与 PARAM Shavak-QS（紧凑型量子模拟平台）。市场侧，EY 与 ISEA 的联合报告预计印度半导体市场将从 2026 年约 640 亿美元增长至 2035 年 2,000 亿美元。

2.3 Openchip：欧洲主权 RISC-V 芯片 BER10 的两年流片路径

日期：2026-09-17（窗口首日）　来源：RISC-V International《V Questions with… Openchip’s Cesc Guim and Marc Fernández》

RISC-V 国际基金会刊发对巴塞罗那 Openchip 两位负责人的访谈。BER10 是欧洲基于开放标准自研的高性能 RISC-V 应用处理器：团队 2024 年初从零组建，350 余名员工分布西班牙、意大利、波兰、比利时、法国、德国、爱尔兰，不到两年时间完成流片，且一次成功、无需重流片。芯片为 64 位、可运行 Linux，集成向量单元、一致性 fabric、存储与互连子系统以及独立管理 tile。资金方面依托欧盟 NextGenerationEU 计划下 IPCEI 微电子项目的 1.11 亿欧元支持。

访谈中的三个要点：其一，芯片回片约三周后成功启动操作系统，团队称下一个”传统节目”是跑 DOOM；其二，公司定位强调”交付系统”而非只交付芯片——集成、认证、支持与生产级软件栈是商业化前提；其三，正与欧洲多方讨论基于 seL4 的主权系统栈，把”每一层都可验证”作为欧洲主权计算的目标形态。该案例是欧洲 Chips Act 框架下 RISC-V 路线最具代表性的样本之一。

2.4 Nordic 发布 nRF54LC10A：Cortex-M33 加 RISC-V 协处理器的多协议 SoC

日期：2026-09-17 发布，09-18 进入窗口　来源：LinuxGizmos《nRF54LC10A SoC features Cortex-M33, RISC-V coprocessor, Bluetooth LE, Thread and Zigbee》

Nordic Semiconductor 扩展 nRF54L 系列，新增入门级多协议 SoC nRF54LC10A：128MHz Arm Cortex-M33 主核（带 FPU、DSP、MPU 与 TrustZone）+ 128MHz RISC-V 协处理器，后者用于软件定义外设与时间关键任务的卸载；1MB NVM、192KB RAM；2.4GHz 无线电支持蓝牙 LE（含 Channel Sounding）、Thread、Zigbee、Matter 与专有模式（最高 4Mbps）；提供 CSP29、CSP39（约 1.93 × 2.29mm）与 QFN48 三种封装。当前为项目制早期送样，量产预计 2027 年二季度。

这是 RISC-V 作为”内部控制核/协处理器”进入国际大厂主流 IoT 产品线的又一实例：跟随主核存在、不对外暴露编程模型，但出货规模可观——与 NVIDIA GPU 内置 RISC-V 控制器属同一渗透路径的不同环节。

三、国内团队深挖

3.1 达摩院玄铁：zero_stage_boot 发布 XuanTie_V1.4.0 稳定版

日期：2026-09-18　来源：zero_stage_boot 发布页、damo-rv-priv-ats PR #32

达摩院玄铁开源的零阶段引导项目 zero_stage_boot 在 09-18 晚发布 XuanTie_V1.4.0 稳定版（此前经过 rc1、rc2、rc3 三轮预发布）。发布产物为成套预编译包：zsb 固件本身、OpenSBI 0.9 与 1.7、Linux 5.10 与 6.6 内核，覆盖 32ilp32、64ilp32、64lp64 三种 ABI 组合（6.6 附 debug 变体）——面向下游 SoC 厂商与板卡伙伴的启动链集成，开箱即可在对应玄铁 CPU 上跑通”零阶段引导—OpenSBI—Linux”链路。opensbi 仓库在同一批次同步推送。

同组织其它动静：特权态测试仓库 damo-rv-priv-ats 在 09-18 更新测试计划、把测试项与规范条款建立链接（PR #32），延续其”测试对齐规范”的工作方式；其余 70 余个公开仓库窗口内无推送，符合其近期以启动链与安全测试为主线的节奏。

4.1 苏州睿芯×启元机器人：高光 D35 数据流物理 AI 芯片进入人形机器人生态

日期：2026-09-20（量产消息 09-14）　来源：上海证券报 via 新浪财经《睿芯RISC-V数据流物理AI芯片牵手启元机器人》、极客公园《启元机器人发布 Q1/T1 双新品 官宣苏州睿芯为算力生态合作伙伴》、苏州工业园区《RISC-V数据流物理AI芯片量产！》

上纬新材（688585）旗下消费级具身智能品牌启元机器人 09-20 在上海发布 Q1、T1 两款个人机器人（19999 元起），并官宣苏州睿芯集成电路为算力生态合作伙伴：双方将围绕具身智能端侧算力需求展开技术合作，推进数据流架构 AI 芯片在人形机器人场景的落地。

苏州睿芯成立于 2020 年，走”RISC-V 指令集 + 数据流架构”的差异化路线：拥有 80 余项数据流专利，核心团队来自中科院计算所、中科院自动化所、IBM、Intel 等机构，研究成果获 ISCA 2026 最佳论文提名；其全自研 RISC-V CPU 内核 IP 已通过国际半导体巨头技术认证并进入全球采购体系。旗舰产品高光 D35 定位”全球首款 RISC-V 数据流物理 AI 芯片”——以数据到达触发计算，减少数据搬运的能耗与延迟，主打边缘端推理，单芯片最高支持 128GB 高速显存，采用 Chiplet 先进封装与全栈软件工具链，已于 9 月中旬由苏州工业园区宣布量产。发布会在生态展区展示了 D35 芯片实物与控制器模组。

意义与边界：这是国产 RISC-V 芯片首次以”算力生态伙伴”身份进入消费级人形机器人发布会的舞台；但合作目前处于”技术合作与落地探索”阶段，D35 在启元产品中的实际装机形态与量产节奏仍待后续披露，报道中的芯片参数均引自厂商口径。

五、总结与趋势观察

  • 资本侧出现国内 RISC-V 最大单笔融资：奕行智能近 20 亿元、投后估值近 150 亿元，叠加苏州睿芯高光 D35 量产并牵手启元机器人、蓝芯算力 LX500 客户落地——云端算力与具身智能两条高价值赛道同时拿到”商业化证据”。与半年前”技术验证”叙事相比，接下来的关键变量是交付与订单兑现，估值给出的信任票需要用营收来还。
  • 标准与生态节奏并行：超睿科技给出 RISC-V 国际标准”2027 年底最乐观”的时间表，与前几期国内汽车 QC/T 标准启动编制互为呼应；标准周期以年计，而产品发布以月计，两条线的节奏差是理解产业预期的关键。
  • 开源软件侧的”服务器化”稳步推进：openRuyi 的 cloudpods、容器栈 seccomp 放行 riscv_hwprobe、Ceph 移植 CI 等提交，都是把服务器级工作负载搬上 RISC-V 的基础工作；openRuyi 9 月版本已进入发布窗口，下期重点跟踪。
  • 香山生态本周技术含量集中在 AME 矩阵扩展：NEMU/difftest 连续落地矩阵扩展边界行为与差分适配，配合分支级的 store prefetch 优化队列，矩阵计算与访存优化是其近期主轴。
  • 国内厂商工程主线各有侧重：达摩院玄铁发布 ZSB 成套固件（启动链）；算能快速迭代 ZSBL 与烧写工具（交付可靠性）；矽速重构 SLogic 软件栈（工具平台化）；进迭时空批量同步 K3 分支并深耕机器人软件栈（ORB-SLAM3、人机接口）；Radxa Linkr 以插件体系转向平台产品。
  • 局限性说明：本期数据来自公开网页与 GitHub 公开提交，未使用任何非公开渠道。GitHub 未认证 API 在采集期内接近速率上限，部分仓库的提交明细经 Atom 源与事件接口交叉核验；RISC-V 国际基金会会员官网巡检有 70 家抓取失败（以国内站点与反爬站点为主）；会议类信息（半导体生态发展大会、SEMICON India）来自聚合渠道，已标注会议日期。
  • 下一期关注点：openRuyi 2026.09 版本是否发布（含容器与云原生栈更新）；奕行智能新一代芯片与超节点的交付节奏；苏州睿芯与启元机器人合作的具体落地形态；香山各优化分支的合并动向；达摩院玄铁工具链与内核仓库是否恢复推送。
