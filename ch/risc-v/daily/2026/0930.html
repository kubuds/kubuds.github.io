今日重点：RevyOS 上架知合计算 A210（Melon Pi）内核支持，一批补丁就位

日期：2026-09-29　来源：revyos/linux 提交：MAINTAINERS 新增知合 A210 支持（09-29）、提交：A210 温控与看门狗设备树（09-29）、提交：PWM 复用 TH1520 驱动支持 A210（09-29）、提交：Melon Pi V2 音频走线（09-29）

9 月 29 日早间，RevyOS 内核仓库（revyos/linux）在 rv/a210-upstream-local 分支批量推送一批补丁（窗口内可见 14 笔），为知合计算（Zhihe Computing）「阿基米德」A210 SoC 及其 Melon Pi V2 开发板补齐内核支持。A210 为搭载达摩院玄铁 C920 与 C908 的八核 RISC-V「通推一体」芯片（12 TOPS@INT8），面向边缘服务器与具身智能等场景。本批补丁覆盖：MAINTAINERS 与 defconfig 条目；设备树（温控与看门狗、PWM、ADC、Melon Pi V2 音频走线）；驱动侧包括 PWM 复用 TH1520 驱动、IIO ADC 单次转换、ASoC 的 A210 I2S 控制器与 Everest ES8156 立体声编解码；另含一笔 [NOT-FOR-UPSTREAM] 的 deb-pkg DTB 安装调整。多数以 dt-bindings 与驱动、设备树的规范化形态提交，延续 RevyOS 对新硬件的快速跟进节奏。

二、产品与生态动态

2.1 GF 旗下 MIPS：完成 ARC 整合锚定 RISC-V Physical AI，与 Xcelsa 合作加速定制硅

日期：2026-09-29　来源：digitimes《GF’s MIPS bets on RISC-V physical AI, expands into autos and data centers》（09-29，Google News 聚合链接）、Industry Events 转载摘要（09-29）、Business Wire《MIPS and Xcelsa Collaborate to Accelerate Verified, Workload-Optimized Custom Silicon》（09-29）

digitimes 09-29 报道：GlobalFoundries 旗下 MIPS 称已完成对 Synopsys ARC 处理器 IP 业务的整合，以 RISC-V 为底座锚定 Physical AI，并从 AIoT 扩展到汽车与数据中心应用；其称该合并已使 GF 与 MIPS 成为全球第二大处理器 IP 供应商。同日 Business Wire 消息：MIPS 与 Xcelsa Labs 达成战略合作——以 Xcelsa 的 Apex 设计优化平台（形式等价保证）加速基于 MIPS IP 的定制芯片开发，覆盖 AI、汽车、工业、机器人与边缘场景。此前 9 月初，MIPS 已发布 Acies／Actus／Aegis 三个工作负载原生平台。

2.2 Nuvacore：公布「Core First」开发模式，ISA 选择保持开放

日期：2026-09-29　来源：Notebookcheck《Apple Silicon and Nuvia veterans reveal unusual CPU core that keeps its ISA options open》（09-29）、Tom’s Hardware《Legendary Qualcomm, Apple, and Nuvia alumni form new CPU startup》（背景）

由 Gerard Williams III、John Bruno、Ram Srinivasan（Apple／Nuvia／Qualcomm 背景）创立的 CPU 新创 Nuvacore 公开首款通用核 WarpCore 的「Core First」模式：先构建与 ISA 解耦的微架构基础，之后再按目标系统选择指令集；其招聘材料将 RISC-V、Arm64 与 x86 并列，被解读为 ISA 选项保持开放——媒体指出 RISC-V 因无需 Arm 式架构授权而路径最直接，而译码、特权级、内存序与软件兼容仍是最终 ISA 的决定性约束。公司尚未披露 ISA 选择、工艺与流片计划。

2.3 SignOff：以 RISC-V「Kaveri」软 IP 展示定制芯片全流程能力

日期：2026-09-29　来源：Electronics For You《SignOff Builds Toward a Bigger Role in Custom Silicon》（09-28／29）

印度设计服务公司 SignOff Semiconductor 正从 VLSI 设计服务扩展到 turnkey 定制芯片：其在自研的 RISC-V「Kaveri」平台上以软 IP 形式展示可定制 RTL 与围绕应用的外围功能，并将其定位为「能力证明」而非产品线——面向希望单一合作伙伴包办从架构到硅实现的客户群。公司称已用该平台完成多项应用演示，正结合代工厂与 OSAT 生态、EDA 投入承接端到端项目。

五、总结与趋势观察

  • 新硬件与发行版跟进的正循环：知合计算 A210 获 RevyOS 内核支持批次（含多项 dt-bindings 与驱动的规范化提交）；openRuyi 发布 K3 固件 20260929 并滚动升级 linux-lts 至 6.18.54。
  • RISC-V 在处理器 IP 层的商业位次上升：GF 与 MIPS 称完成 ARC 整合后成为全球第二大处理器 IP 供应商，并以 Xcelsa 合作补全「工作负载到定制硅」链路；汽车与数据中心为明确扩张方向。
  • 「ISA 开放性」再获顶级团队关注：Nuvacore 的 Core First 模式把 ISA 选择后置，RISC-V 因授权成本成为直接受益选项。
  • 国内厂商工具链进入版本化与教学化阶段：矽速 SLogic 2.0.0 与 slogic16u3-tools 双发版、进迭时空 K3 Triton 教程成型、乐鑫多语言语音模型——从「能用」走向「可学、可发版」。
  • 香山系维持高频分支级开发：主仓库四笔后端修复 PR 集中于发射与定序路径，difftest 铺 CROB 对比线，仿真链与实现链同步推进。
  • 待观察：奕斯伟定价与挂牌（10 月 9 日）、openRuyi 2026.09 版本、香山四笔 PR 的评审走向；达摩院玄铁、芯来、Radxa Linkr 等窗口内静默。
