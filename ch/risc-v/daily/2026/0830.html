一、开源社区与软件生态

1.1 开放原子紫金专区 OPC 孵化行动计划启动，RISC-V 开源芯片产业创新中心落地苏州试点

日期：2026-08-28　来源：人民网江苏频道、新华报业网、名城苏州

8 月 28 日，以”开源聚势·智能共生”为主题的 2026 开源创新生态大会在苏州举办，正式发布开放原子紫金专区 OPC 孵化行动计划：以 JSopen 为核心数字基座，依托”苏州吴中+南京雨花”双中心联动，打造全国首个人工智能 OPC 专业开源孵化社区。现场完成 OPC 项目孵化中心揭牌与 16 家首批入驻项目签约（覆盖 AI 大模型、具身智能、医疗科技）；启动紫金开源 OPC 创新投资者联盟并揭牌江苏云途开元创业投资基金（规划总规模不低于 10 亿元的 OPC 产业基金矩阵，联合南京雨花台区设立 3000 万元 AI 微种子基金）。与 RISC-V 直接相关的是：RISC-V 开源芯片产业创新中心作为五大省级开源生态创新平台苏州试点之一正式启动，另有开源鸿蒙应用创新中心、紫金开源 AI 赋能中心等同步落地；科沃斯八界开源智创空间、博云 BoHub 社区、三所高校开源创新实验室揭牌，第八届全球校园人工智能算法精英大赛（AI+开源）同步启动。该事件为 08-28 当日落地、08-30 早间被多家媒体转载，属江苏开源产业政策与 RISC-V 生态平台建设的重要信号。

1.2 OpenTitan 开源安全芯片获西语科技媒体专题报道，生产部署背景回顾

日期：2026-08-29　来源：Desde Linux、lowRISC OpenTitan News、Google Open Source Blog

西语科技媒体 Desde Linux 于 08-29 发表 Google OpenTitan 专题文章，介绍这一全球最活跃的开源硅片项目（基于 RISC-V Ibex 内核的开源安全信任根 RoT 芯片）。该文属科普向，但背景信息值得记录：OpenTitan 已于 2025-02 由 Nuvoton 量产并在 Chromebook 中首次生产部署，是首个支持后量子密码（SLH-DSA PQC 安全启动）的开源 RoT；2026 年内 Real Intent、Cadence 先后以工具合作伙伴身份加入，强化开源硅片签核与验证链路，社区总提交量超 3.3 万笔。窗口内无 OpenTitan 新版本/新事件，作为开源硅片生态持续渗透的参考收录。

二、产品与生态动态

2.1 赛昉昉·天枢-100 正式交付：国内率先达到可交付状态的服务器级 RISC-V CPU IP

日期：2026-08-27（补收录）　来源：新浪科技/快科技、腾讯新闻、赛昉科技官网

快科技 8 月 27 日消息：赛昉科技宣布服务器级 RISC-V HPC CPU 内核设计昉·天枢-100（Dubhe-100）正式交付——这是国内率先达到可交付状态的服务器级 RISC-V CPU IP，已获客户采用并进入服务器芯片开发阶段，填补国产 RISC-V 高性能计算 IP 空白。核心规格：性能对标 Arm Cortex-A78，整数 IPC 达 SPECint2006 15/GHz；深度乱序执行、15 级流水线、6 发射宽度、256 条指令乱序窗口；严格遵循 RVA23 规范，率先实现业界领先的乱序执行向量单元（RVV）；支持单核/双核/四核集群与 TileLink、AXI、ACE、CHI 互连，可对接自研 NoC IP 昉·星路-700（StarNoC-700）扩展至 256 核；已完成 Type 1/Type 2 Hypervisor 完整支持，Linux 与 KVM 虚拟化方案稳定运行；同步推出 AIA 高级中断架构与 IOMMU 等服务器级基础设施 IP。商用落地方面，希奥端计算（LECARC）已确定采用天枢-100 开发面向智能边缘的新一代服务器 CPU（双方 06-29 官宣合作）。说明：天枢-100 首发（08-19）本报已收录；”正式交付”为其后续里程碑，因前两日 gnews 赛昉查询被 301536.SZ 星宸科技半年报误标污染而漏检，今日补收录。

三、国内团队动态与深挖

3.1 芯来科技新三板创新层挂牌（875127）：国内 RISC-V CPU IP 龙头登陆资本市场

日期：2026-08-28　来源：同壁财经/新浪财经、同花顺、亿欧数据/网易

芯来智融半导体科技（上海）股份有限公司（证券简称：芯来科技，代码 875127）挂牌申请获批，于 8 月 28 日在新三板创新层正式挂牌，主办券商招商证券。该公司成立于 2018 年，创始人胡振波（国内第一颗开源 RISC-V 处理器核蜂鸟 E203 作者），是国内首批商用 RISC-V CPU IP 供应商：产品覆盖 N 系列低功耗嵌入式、UX 系列高能效、NA 系列车规（全球首个 ISO 26262 ASIL-D 认证 RISC-V CPU IP）、NI 系列 AI 计算（全球较早支持 VLEN 1024 比特）；授权客户超 300 家（含兆易创新、恒玄科技、晶晨、裕太微等上市公司），按 SHD Group 2026-03 报告以出货量计居全球 RISC-V CPU IP 前四。财务与融资：2024/2025 营收 7,399.87 万元/8,294.11 万元，剔除股份支付影响后亏损逐期收窄（-1722.73 万/-958.63 万/-377.56 万元），2025 经营性现金流转正（792.03 万元）；挂牌同时定向发行约 8.21 万股、募资约 4,200 万元（认购方为黑龙江振兴先进制造产业基金、中芯熙诚北京数字科技基金），募资投向 RISC-V 芯片定制平台研发。股东阵容含小米长江产业基金、君联资本、中电科基金、芯原股份等（前十大股东合计持股 73.01%）。背景：2025-08 芯原股份曾筹划收购芯来科技 97% 股权，同年 12 月宣布终止（标的诉求与市场环境、政策要求存在偏差），芯来随后转向独立挂牌；本次挂牌为公司从 IP 授权向芯片定制、Chiplet 及服务器 CPU 四阶段战略升级提供资金通道。同日亿欧数据将其归入”制造领域投融资日报”上市类目（估算融资总额约 3 亿元，含未披露口径）。

3.2 算能 sophon-tools 发版前安全加固，SophLiteOS v2.2.6 等多项修复合入

日期：2026-08-29　来源：sophgo/sophon-tools 提交记录

算能窗口内 5 笔提交（sophgo/sophon-tools，均为 08-29 晚间合入），主题为发版前安全检查与加固：其一，/agent/ws 服务同源校验与限流加固、CV84X2 设备树（dts）兜底查找（#160）；其二，P1/P2 级安全加固批次——注册流程拒绝临时 token、防火墙保护端口守卫收紧、软件包名/引号/退出码/jwt/超时/指标 token 等细节修复（#161）；其三，SophLiteOS 的 agent 双回复问题修复——history 按 kind 归一化去重，随 v2.2.6 发布（#157）；其四，OTA 预检拦截残缺刷机包、防止 OTA 死循环（#158）；其五，psocbak 备份排除外置数据盘挂载点并同步 ota_update md5（#159）。sophon-tools 是算能 SophOS/刷机与 OTA 工具链，本批提交属发布前夕的系统性安全与稳定性收敛，为 CV84X 系列（昨日已报官方规格落地）量产支撑工具的工程化补强。

3.3 香山：Ftq 预取性能调优、KunminghuV2 CI 选项与 Deterload 工具 H/V 扩展支持

四、具身智能与机器人专章

4.1 深开鸿发布 M-Robots OS 3.0 Beta：开源鸿蒙机器人 OS 重心转向群体智能

日期：2026-08-29　来源：新浪科技/IT之家、深开鸿官网

在贵阳 2026 中国国际大数据产业博览会上，深开鸿高级副总裁王皓正式发布 M-Robots OS 3.0 Beta 版。M-Robots OS 是全国首个基于开源鸿蒙（OpenHarmony）的分布式异构多机协同机器人操作系统，3.0 Beta 将重心从”单机能力”转向”群体智能”，围绕安全、实时、群体智能、数字底座四大方向系统性升级：安全侧构筑”组网可信、接入可控、运行可防”立体防护。深开鸿 06-26 刚启动 M-Robots 社区共建（首个开源鸿蒙机器人操作系统社区），并持续参与开源鸿蒙/RISC-V 生态赛事与硬件适配。本窗口 RISC-V 侧无具身智能硬件新品；该条作为开源鸿蒙机器人生态动态收录——与昨日 Microduck（Hugging Face 生态双足机器人）同属”终端主控仍以 ARM/既有生态为主、RISC-V 在具身智能领域以标准与治理层先行”格局的佐证，但开源鸿蒙机器人 OS 的硬件适配面已覆盖 RISC-V 开发板，是值得跟踪的潜在渗透通道。

五、总结与趋势观察

  1. 资本市场里程碑：芯来科技（875127）8 月 28 日新三板创新层挂牌，成为国内首家登陆资本市场的商用 RISC-V CPU IP 企业（芯原 2025 年底终止并购后独立挂牌），定向发行募资约 4,200 万元投向 RISC-V 芯片定制平台研发；叠加 8 月中旬杰理科技北交所上市，国产 RISC-V/芯片设计公司正加速对接多层次资本市场。
  2. 服务器赛道再进一步：赛昉天枢-100 由”发布”走向”正式交付”（国内率先达到可交付状态的服务器级 RISC-V CPU IP），希奥端计算确认采用；与 SiFive BigSky 交付（昨日已报）相呼应，RISC-V 服务器 CPU IP 的国际国内两条线都在从硅片设计走向客户项目落地。

  4. 开源生态政策面：开放原子紫金专区 OPC 孵化行动计划落地苏州，RISC-V 开源芯片产业创新中心列入五大省级平台试点，配套 10 亿元级 OPC 产业基金矩阵与 3000 万元 AI 微种子基金，开源芯片孵化获得地方政策与资本双重加持。
  5. 具身智能：窗口内无 RISC-V 硬件新品；M-Robots OS 3.0 Beta（开源鸿蒙机器人 OS）转向群体智能，深圳具身智能博览会 3 天 39 亿元成交意向——产业放量进行时，RISC-V 渗透仍以生态与中间层先行。
