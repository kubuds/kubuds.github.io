今日重点：芯来发布 NI1000，首款支持 VME 矩阵扩展的 RISC-V 通用 AI 算力核（11-09）

芯来科技 11 月 9 日发布 NI1000 RISC-V CPU IP，官方称这是其第一款支持 Vector Matrix Extension（VME）的高性能通用 AI 处理器 IP。NI 系列是芯来面向 AI 应用的单列产品线，可配置为 900 或 1000 系列；RVV 1.0 向量单元（VPU）的 VLEN 可设为 512、1024、2048 或 4096 位，且集群内每个核可以独立配置自己的 VPU。核间通过 IOCP（IO Coherent Port）与 NPU 加速器紧耦合并保持缓存一致性，NICE／VNICE 接口则允许用户自定义标量与向量指令，NICE 还能用于与 NPU 的紧耦合交互。

技术要点在 VME 的实现方式。VME 与 CPU、RVV 在同一个核内紧耦合，源操作数直接复用 RVV 的向量寄存器组，运算单元也复用 RVV 的执行单元，只额外增加 Matrix Tiles 的面积；新增的原生矩阵指令把外积结果累加进专用的 N×N 累加器，四套独立 Matrix Tiles 做乒乓并行以提升吞吐，并新增对 FP8 数据类型的原生支持。芯来给出的数据是：在 NI1020（VLEN 1024）上执行 32×32 的 FP32 矩阵乘法，整体面积只增加 15%（主要是 Matrix Tiles），矩阵乘法性能提升 2.5 倍。

定位讲得比较克制。官方明确写着 NI 系列不打算取代 NPU、GPU 等加速器 IP，而是与之结合、更好地服务 AI SoC 上的加速器。这一点与 VME 的取舍一致：对比 IME 有独立矩阵累加硬件、矩阵运算能效更高，对比 AME 省去完整独立矩阵寄存器堆与硬件矩阵加速器；VME 站在中间，用可控的硬件开销换矩阵算力，代价是峰值能效不如专用矩阵单元。芯来同时强调 VME 完全以 RVV 为基座，软件生态可复用，并判断 VME 会成为最早标准化的 RISC-V 矩阵扩展。

把这条放进本月的坐标里看，它补的是「通用算力核」这一层。此前一周的新闻集中在车规 MCU（英飞凌 AURIX RC1）、端侧视觉 SoC（为旌 VS815V）与安全核（AMD 的 RISC-V TEE），都是把 RISC-V 放进特定功能单元；NI1000 面对的是 AI 芯片里那颗「什么都要干一点」的通用核——要跑标量控制、要跑向量算子、还要能承接一般规模的矩阵乘，然后与 NPU 分工。国内 AI 芯片公司长期在这层二选一：要么外购高性能应用核，要么自研但背软件栈。VME 复用 RVV 的路子，实质是把这道选择题的成本压低，能不能被客户接受，取决于工具链与算子库跟不跟得上。

一、开源社区与软件生态

openRuyi 主仓单日 20 笔：wlroots 0.20.2、wget2 2.3.0 与 LLVM 22 至 24 的 Python 绑定修正（11-09／11-10）

openRuyi 主仓在窗口内落地 20 笔 SPECS 提交，节奏是典型的「滚动发行版日常」而非集中发布：桌面栈把 wlroots 升到 0.20.2，网络工具把 wget2 升到 2.3.0，Python 侧一口气更新了 httpx2 与 httpcore2 到 2.13.0、idna 到 3.20、langgraph-sdk 到 0.4.11，并让 python-pymongo 把 BSON 打进主包。另有几笔是打包正确性修复：llvm22、llvm23、llvm24 三个包用 sed 把 clang 的 Python 绑定改为链接 libclang，openruyi-linux-build 修掉 devel 文件冲突并安装带版本号的文档。

值得记一笔的是 llvm 那三笔。LLVM 各版本的 Python 绑定长期靠动态库路径推断，发行版打包时若把 clang 的 Python 模块指向静态库或错误的 soname，用户在 RISC-V 上装 llvmlite、triton 这类依赖就会在导入阶段失败。三个版本同步改成显式链接 libclang，属于「装得上但用不了」这一类问题的根因修复，对做 RISC-V AI 栈的团队比版本号本身更有意义。

CORE-V CVW 合并 11 笔：16550 UART 的 LSR 错误位、SPI 空 RX 归零与锁步非对齐豁免（11-09／11-10）

CORE-V CVW 在窗口内合并 11 笔，主线仍是「把外设与验证环境做扎实」而不是改微架构：16550 UART 补上 LSR（线路状态寄存器）的错误位行为，SPI 在接收 FIFO 为空时读回零，分支预测重定向的覆盖率统计加上排除项，锁步（lockstep）模式对非对齐访问给出豁免规则，另有一批示例与脚本整理——删除 SHA 的 Questa 脚本、移除 Docker 构建与回归脚本、统一 ruff 与 uv 的脚本入口。

这组提交与上周「删两套局部分支预测器、公开 RV32GC CoreMark/MHz 4.33」是同一轮收口的两半。上周动的是性能与面积，这周动的是可验证性：UART 的错误位与 SPI 的空读语义都属于「协议规定了、实现里容易漏」的细节，漏了不会让核跑不起来，但会让驱动在错误路径上挂死；锁步豁免与覆盖率排除则直接决定验证报告能不能作为交付证据。对拿 CVW 做车规或工业评估的团队，这类提交比多跑几百 MHz 更值钱。

M9B 在 Tang Nano 9K 上搭出 RISC-V 电脑，五款 DOS 时代游戏跑进 36MHz 软核（11-09）

开发者 Mika Tammi 的 m9b 项目在 Hacker News 上出现：在一块售价约二十美元的 Sipeed Tang Nano 9K（Gowin GW1NR-9）上，用 VexiiRiscv 软核搭出一台完整的小电脑——36MHz、带缓存、用板载 8MB PSRAM 作内存、720×480 HDMI 视频、48kHz 音频、两个 USB 口接键鼠、SD 卡存程序。开机进一个列出 SD 卡程序的界面，能跑五款 DOS 时代游戏，且都带音效与音乐：Doom（shareware，timedemo 约 22 fps）、Descent（约 10 fps）、Tyrian 2.1（满速 35 fps）、System Shock（约 7 fps）、Ultima VII（两套引擎，7 至 13 fps）。

这类项目的价值不在「能玩游戏」，而在把「一台电脑最少需要什么」这条线画出来。9K 的逻辑资源装不下乱序核，也装不下 Linux 级别的内存管理，于是取舍变得非常具体：要 HDMI 就得砍缓存，要音效就得把音乐预先渲染成流从卡里读。项目把 SoC、运行时、五套游戏移植与 SD 卡镜像拆成独立仓库并全部开源，每个仓库都写明改动了上游哪里——对做 RISC-V 教学板与 FPGA 上手的团队，这是一份可直接复用的工程分层样本。

二、产品与生态动态

M5Stack Core Matrix 用 ESP32-C61 加 16×16 LED 矩阵，29.99 美元开卖（11-09）

M5Stack 推出 Core Matrix，一颗基于 ESP32-C61 的 IoT 控制器：SoC 为 ESP32-C61HR8，单核 32 位 RISC-V 最高 160MHz，320KB SRAM 加 8MB PSRAM、16MB QSPI flash，2.4GHz Wi-Fi 6 与蓝牙 LE 5.0；正面是 16×16 白光 LED 矩阵（256 颗，TM1680 驱动），配 Bosch BMI270 六轴 IMU、microSD、无源蜂鸣器、三个用户按键与电源键，扩展走 30 pin M5-Bus 与 Grove I2C，支持 USB 或 3.7V 外接电池供电，尺寸 54×54×11.6mm，售价 29.99 美元。软件侧支持 Arduino IDE 与 UIFlow2，提供 M5Unified、M5GFX 与电源管理芯片的驱动库。

这块板的意义是把「显示」从屏幕换成点阵。ESP32-C61 是乐鑫面向低成本 Wi-Fi 6 的 RISC-V 型号，算力与内存都不足以驱动 LCD，但足以驱动 256 颗单色 LED 并跑状态机与联网逻辑；用点阵做图标、动画与通知，等于在「没有屏幕」与「有屏幕」之间补了一档。对做桌面状态灯、机房指示器与低成本交互设备的团队，这是一个现成的参考形态，价格也落在可以批量铺开的区间。

英飞凌 AURIX RC1 的 RISC-V 核被指来自 MIPS IP、由格芯代工（11-09）

Design And Reuse 11 月 9 日转载 jonpeddie.com 的分析，指出英飞凌 AURIX RC1 采用的是 MIPS 的处理器 IP，由 GlobalFoundries 代工，并称这是 MIPS 与格芯在 RISC-V 上的一笔重要设计胜利。文章同时提出一个问题：RISC-V 是否会最终取代英飞凌自有的 TriCore 架构。此前 11 月 4 日英飞凌发布 RC1 时，官方口径是「首条基于 RISC-V 的车规 MCU 平台、TriCore 系列继续供货」，未展开 IP 来源。

这条补的是供应链层的空白。车规芯片公告通常只讲平台与生态，不讲核从哪来；而对做国产车规 RISC-V 的团队，核的来源直接决定两件事——功能安全证据链由谁提供（ISO 26262 ASIL D 的 IP 级证据不是整机厂能自己补的），以及产能与制程落在哪家代工厂。MIPS 在被格芯收购后把路线整体转到 RISC-V，这次若确为 RC1 的核供应商，等于「RISC-V 车规核」这个市场多了一个有代工厂背景的玩家；对国内 IP 厂商，这是一个需要正面对比的竞争者，而不是远处的概念。

三、国内团队深挖

平头哥拟 2027 年赴港 IPO，募资 20 亿至 30 亿美元（11-09）

多家媒体 11 月 9 日援引路透社报道，阿里巴巴旗下芯片公司平头哥半导体计划于 2027 年在香港交易所上市，目标募资 20 亿至 30 亿美元（约 156 亿至 234 亿港元）。公开信息显示，平头哥 2018 年 10 月由中天微与达摩院芯片团队整合成立，产品覆盖 AI 加速芯片（真武系列）、Arm 服务器 CPU（倚天系列）、RISC-V 处理器 IP（玄铁系列）与存储主控等；2026 年 3 月阿里 CEO 吴泳铭在财报电话会上披露，平头哥芯片累计出货超过 47 万片、年化营收超过百亿元，8 月披露真武系列已服务超过 650 家客户、外部付费客户占比超过六成。9 月云栖大会发布的真武 V900 标称 216GB 显存、1200GB/s 片间带宽，计划 2027 年第一季度量产。

需要把口径分清楚：报道把玄铁系列 RISC-V 处理器 IP 计入平头哥的产品线，而玄铁团队 2024 年已转入达摩院、专做 RISC-V 处理器（C950 一类），平头哥自身的产品重心是 PPU（AI 加速卡）与倚天（Arm CPU）；「玄铁累计出货 60 亿颗」是集团层面的历史累计口径，不等于当前由平头哥经营。上市主体最终如何切分资产、玄铁 IP 归属是否随之调整，目前没有披露，这也是这条消息最需要跟踪的部分。

对 RISC-V 产业，IPO 本身不改变技术路线，但会改变资本对这条赛道的定价方式。过去两年国内 RISC-V 公司的估值锚是「替代空间」，平头哥若以百亿元级年化营收、六成外部客户的身份上市，锚就换成「已商业化的算力供应商」；这对正在融资的 RISC-V 服务器、AI 芯片与 IP 公司是双向影响——可比公司变清晰了，但资本市场也会用同一套营收与毛利标准来要求它们。

进迭时空：ggml-spacemit 单日四笔，门控 delta 网络用 RVV 与 TCM 重写（11-09）

spacemit-com 的 llama.cpp fork（mtmd-backend 分支）在窗口内合并四笔 ggml-spacemit 后端提交：用 RVV 与 TCM 优化循环版门控 delta 网络（#54）、按 head size 对门控 delta 网络做展开特化（#59）、优化 MoE 矩阵乘并新增稠密 Q4_0 与 F16 的 GEMM（#53），以及修掉 softplus 缺少 log1p 项的实现错误（#57）。

四笔凑在一起，指向的是同一类模型结构。门控 delta 网络（GDN）是线性注意力一系的循环层，推理时每步只做小规模矩阵运算，瓶颈不在算力而在访存与状态驻留——这正是 TCM（紧耦合内存）该用的地方；把 head size 作为特化维度展开，则是为了消掉内层循环的分支与索引开销。MoE 矩阵乘与 Q4_0／F16 GEMM 是另一条线：K3 的向量单元要同时伺候稀疏专家路由与低比特稠密层，缺一条都会让整机吞吐掉到下一个档。softplus 那笔最不起眼，但 log1p 缺失属于数值稳定性问题，长序列推理会累积成可见偏差。

进迭时空：数字人管线改名 bianbu-avatar，对齐 K3 的 EP 核分配（11-09）

spacemit-com/model-zoo-avatar 仓库在窗口内提交九笔，围绕一条数字人（avatar）推理管线：新增 FeatherHuBERT 与 UNet 两个推理组件，把资源下载路径统一到 model_zoo/avatar，去掉仓库里的通用测试音频改为按人设下载，修掉原生贴回（paste-back）路径下人脸替换的问题，并把项目名从 FeatherTalk 改为 bianbu-avatar。其中一笔提交明确写着「匹配 K3 上 bianbu-avatar 的 EP 核分配」。

这组提交透露的是端侧数字人的部署形态：语音侧用 HuBERT 一类模型做特征，视觉侧用 UNet 做生成，两段都要落在同一颗 SoC 的不同计算单元上，于是「EP 核分配」（哪个核跑哪个子图）成了必须显式对齐的参数。改名同样有信息量——从第三方模型名收回到自有发行版品牌（Bianbu），说明这条管线已经从「跑通某个开源项目」进入「作为发行版组件维护」的阶段。

四、具身智能与机器人专章

MIPS Actus 用双颗 Atlas M8500 实时 RISC-V 核做机器人关节，带 TSN 与后量子安全（11-09）

MIPS（已被格芯收购）11 月 9 日在 electronica 2026 前发布 Actus 参考平台的进展：一颗面向紧凑机器人关节的芯片，把确定性电机控制、机器人体内网络与边缘推理放在同一颗 die 上，基于格芯的 FDX FD-SOI 工艺。核心是两颗 MIPS Atlas M8500 实时 RISC-V 处理器，用硬件多线程消除中断服务时的上下文切换开销；专用三角函数加速在磁场定向控制（FOC）算法上比标准三角函数库快 16 倍以上；配 100 皮秒级高分辨率 PWM 与 sigma-delta ADC 驱动大电流电机，另用 ARC VPX 512 位向量单元在同一颗芯片上跑传感器融合与预测性维护模型。

系统侧同样给足了：三端口时间敏感网络（TSN）千兆以太网加 CAN-FD 与串口，让各关节控制器与中央控制器交换位置与力矩数据；片内硬件安全模块支持后量子密码，并对功能安全提供支持。Actus 与 Acies（推理原生平台）、Aegis（安全原生 CPU 平台）共同构成 MIPS 的物理 AI 产品线。

这条的分量在「关节」这个位置。人形机器人的算力叙事长期集中在大脑（谁家的 NPU、多少 TOPS），而真正卡量产的是从肘到指尖这一段：空间、功耗、散热都极紧，却要求平滑的人形运动与确定性时序。把双实时核、电机控制外设、TSN 与安全模块塞进一颗关节芯片，等于把「大脑给指令、关节自己闭环」这套分布式架构做成可采购的器件。对国内做机器人关节与实时控制的团队，这是与「MCU 加外置驱动」路线正面对比的一种方案，关键差异在硬实时与网络确定性，而不在算力。

日期：2026-11-09　来源：MIPS 新闻稿

spacemit-robotics：unitree-go2 支持 smallcore 电机通信，perception 把推理运行时打包进 las2（11-09）

spacemit-robotics 的 unitree-go2 仓库合并 #6，新增对 smallcore 电机通信的支持（feat/smallcore-motor-tra… 分支）；perception 仓库有两笔围绕 las2 的修正：把匹配的推理运行时打包进发布物（#14），并在此之前先把打包进源码仓库的模型文件移除（#13）。

两件事都指向「交付形态」。unitree-go2 是宇树 Go2 四足机器人在 K3 平台上的移植工程，此前已经做完 IMU 快照读取、地形行走策略与模型下载；补 smallcore 电机通信，意味着控制链路要能对接不同批次的关节驱动板，这是把 demo 变成可复现工程必须过的一关。perception 的 #13 与 #14 是一对：先把大模型文件从源码仓库剥离（避免仓库膨胀），再把推理运行时随发布物一起打包（避免用户自己找依赖）——一减一加，说明这套感知栈开始按「可安装的软件包」而不是「一堆脚本」来组织。

五、总结与趋势观察

一、AI 芯片的「通用核」这一层开始有专用产品。 芯来 NI1000 用 VME 把矩阵能力嫁接到 RVV 上，面积只加 15%、矩阵乘法快 2.5 倍，定位是与 NPU 分工而不是取代。这与过去两年「谁的 NPU 峰值高」的叙事不同：AI SoC 里那颗通用核长期靠外购应用核或自研大核解决，现在出现了第三条路——以向量为基座、按需加矩阵。真正的门槛不在 IP，而在算子库与编译器能否把 VME 用起来。

二、机器人关节成了 RISC-V 实时核的新战场，且路线开始分叉。 MIPS Actus 用双颗 Atlas M8500 加 TSN 与后量子安全做关节级单芯片，国内 spacemit-robotics 则继续在 K3 上做四足移植与控制链路适配。前者卖的是器件与实时性保证，后者攒的是可复现的工程与生态；两条路都说明一件事：具身智能的算力竞争正从「大脑」下沉到「小脑与关节」，而这一层的评价标准是确定性与功耗，不是 TOPS。

三、国内侧的资本市场动作开始影响技术叙事。 平头哥拟 2027 年赴港 IPO、募资 20 亿至 30 亿美元，若成行，RISC-V 与国产 AI 芯片公司第一次有了「已商业化、有外部客户、有营收」的可比标的。需要留一分清醒：报道把玄铁 IP 计入平头哥产品线，而玄铁团队 2024 年已转入达摩院，上市主体的资产边界尚未披露；对产业观察者，接下来要看的不是估值，而是招股材料里外部客户收入与关联交易的切分方式。

四、软件侧的进展集中在「装得上、用得了」这类细节。 openRuyi 单日 20 笔里，llvm22 至 24 的 Python 绑定改为显式链接 libclang 是最有代表性的一笔——它不提升任何指标，却决定 RISC-V 上能不能正常装 llvmlite 与 triton；CORE-V CVW 这一周合并的 UART LSR 错误位、SPI 空读归零与锁步豁免，同属「不影响跑分、影响能不能交付」的类别；算能把 bootloader 的两代平台构建链收敛、进迭把数字人管线收进 Bianbu 品牌，也都是从 demo 走向维护的动作。

五、平静的新闻面与不平静的仓库面。 本期 Google News 侧的有效新增只有芯来 NI1000、MIPS Actus、M5Stack Core Matrix 与英飞凌 AURIX 的 IP 来源四条，另有为旌 VS815V、AMD RISC-V TEE、Openchip BER10 三条属旧闻二次传播，已在此前报告收录，本期不重复。这与上周的节奏一致：大厂发布稀疏，但 GitHub 侧的提交密度在上升——进迭、算能、芯来、openRuyi 与 CORE-V 在同一个 24 小时里合计有 60 余笔可核对的提交。

局限性说明：本机匿名访问 GitHub API 在采集时段触发每小时 60 次的限流，组织与仓库活跃度改由 GitHub 组织页嵌入数据与各仓库 Atom 提交流获取，不消耗 API 额度；因此「窗口内有推送」的判定以默认分支提交时间为准，非默认分支的推送（如进迭的 wip 分支）可能被低估。达摩院玄铁与奕斯伟的「零推送」结论同样受此方法约束，仅表示默认分支在窗口内无提交。Google News 的中文查询仍有博彩与股市稿噪音，已按标题语义剔除；RISC-V 会员官网巡检的 108 项「变化」均为首页营销轮换或安全拦截页，未发现实质产品与架构发布。
