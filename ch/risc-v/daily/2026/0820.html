一、开源社区与内核/版本动态

日期：2026-08-19（09:45 ~ 20:33 北京时间）　来源：OpenXiangShan/XiangShan GitHub

香山组织窗口内 12 个仓库有推送，主分支（XiangShan）与 AI 加速器（XSAI）各落数笔实质提交：

  • 访存正确性：fix(StoreUnit): kill younger cross-page unalign head store (#6382)（08-19 13:56 北京，当日新提交）——修复跨页非对齐头部 store 与更年轻访存指令的乱序执行冲突；
  • 前端时序：timing(ibuffer): shorten valid paths for partial-drain output、fix(ibuffer): make deqEntries valid/bits consistent, fix VTypeGen input（08-19 10:42 北京合入，作者 08-18）——指令缓冲器部分排空路径的时序优化与 VTypeGen 输入修复，同批还合入 feat: use PNR ptr to judge for 2-pre/fetch (#6378)（08-19 10:10 北京）；
  • AI 加速器：XSAI 合入 fix(matrix): bump CUTE for MLCT,MSCT fixes (#106)（08-19 09:45 北京）——矩阵加速器随 CUTE（CUDA Tensor Engine 式矩阵库）更新 MLCT/MSCT 修复。
  • 其余活跃仓库：GEM5、llvm-project、XSCache、NEMU、XiangShan-doc、XiangShanLab、workshop、workload-builder、nexus-am、xs-env（均为常规配套迭代）。

连续第三日主分支批量合入，且本轮以”前端 IBuffer 时序 + 访存乱序正确性 + 矩阵加速器”三线并进，开发节奏保持高强度。

1.2 社区辩论：Dmitry Grinberg 批评 RISC-V 嵌入式 ISA，多方回应（08-19）

日期：2026-08-19（Adafruit 转载 02:37 北京时间）　来源：Adafruit Blog、dmitry.gr 原文

嵌入式开发者 Dmitry Grinberg 撰长文《RISC-V: They Should Have Known Better》，批评 RISC-V 嵌入式核心的指令集取舍，Adafruit Blog 于 08-19 转载引发社区热议。核心论点：RISC-V 嵌入式指令集（以 RV32E 为参照）缺少 aarch64 式的位域指令（BFC/BFI），他统计同一内核镜像中位域插入/提取指令出现 6,284/8,881 次，认为”唯一的目的——嵌入式内核——RISC-V 反而比现有竞品更差”，并批评代码密度与上下文切换设计。社区回应亦迅速：

  • rvembedded.com《A Third World Embedded Engineer Responds》以实机案例反驳：CH32V003 十美分的 RV32EC 核心（16 寄存器、无乘除、仅 M 模式）即可支撑其两款量产产品，工具链数小时可上手，”有 ISA 手册和 C 编译器就够”；
  • Reddit r/RISCV 讨论多持正面立场：”RISC-V 设计良好、将是未来主导 ISA、无性能天花板，向量扩展优于 ARM”；
  • HN 同步发酵（回应帖 5 分 2 评）。

这是一场”嵌入式 ISA 设计取舍”的公开辩论，双方围绕位域指令、代码密度、成本与工具链成熟度交锋——标志着 RISC-V 已进入”可以被严肃批评、也有实机证据回应”的生态成熟期。

1.3 开源项目观察：labwired-core——ARM/RISC-V 确定性固件模拟器（08-20）

日期：2026-08-20（08:13 北京时间）　来源：github.com/w1ne/labwired-core（59 stars）

w1ne 发布 labwired-core：面向 ARM Cortex-M 与 RISC-V 的确定性固件模拟器，主打”经硬件验证的并行外设仿真”（hardware-validated parallel peripherals），用于固件在环测试。属嵌入式/固件测试方向的新工具，RISC-V 侧覆盖值得关注（当日新建、星级尚低，仅作生态观察）。

二、产品与生态动态

2.1 头条：赛昉科技发布 Dubhe-100——RVA23 合规的服务器/HPC RISC-V CPU IP（08-19）

日期：2026-08-19（官方 X 官宣 13:19 北京；CNX 报道 08-20 08:00 北京）　来源：CNX Software、StarFive 产品页

赛昉科技（StarFive）官方发布 Dubhe 家族新旗舰 Dubhe-100——面向服务器与 HPC 的 64 位 RVA23 合规商用级 RISC-V CPU IP，官方 X 称其为”commercial-grade RISC-V CPU IP for servers and HPC”。核心规格：

  • ISA/微架构：RV64GCBVH（含 B/V/H 扩展）、15 级流水线、6 发射超标量、深度乱序执行、支持指令融合与多核缓存一致性、AIA 1.0 中断架构；
  • 性能：SPECint2006 15/GHz、Dhrystone v2.2 10.0 DMIPS/MHz（官方宣称值）；
  • 向量与密码：支持 RISC-V Vector（RVV）与 Vector Crypto 全套扩展；
  • 安全与调试：PMP/PMA（可配 16/32/64 区域、最小 4096 字节粒度）、Svpbmt、符合 RISC-V Debug/Trace 规范的调试与跟踪接口、HPM 硬件性能计数器；
  • 目标应用：服务器/HPC、LLM 推理、AI agent、视觉分析（计算机视觉）、基础设施芯片（Smart NIC 控制器、分布式存储控制器）；
  • 首个客户：LECARC（希奥端计算，2026-06-29 官宣合作）正基于 Dubhe-100 设计智能边缘服务器 SoC；
  • 软件生态：开发走 StarFive StarStudio IDE，Dubhe SDK 尚未开放下载（预计商用 SoC 落地后放出到 starfive-tech GitHub）。

定位评述：Dubhe-100 使赛昉进入”RVA23 高端核心”竞争圈，与平头哥 C950（64 核、RVA23、矩阵加速）正面同场；RISC-V International CEO Andrea Gallo 同期评价”2026 年就是高性能 RISC-V 应用处理器之年”，Dubhe-100 官宣是最新注脚（详见 3.1 深挖与第四章）。

2.2 Pine64 暂停 Linux 设备生产：DRAM/eMMC 缺货涨价（08-19）

日期：2026-08-19（CNX 报道 18:29 北京时间）　来源：CNX Software、Hackster.io

Pine64 官方（社区 Mastodon）宣布：因 DRAM 与 eMMC 缺货且价格高企，即日起暂停 Linux 设备生产，”生产是否恢复取决于 2027 年年中之后的存储价格走势”。要点：

  • 断货时间表：PineNote 与 PineTab2 预计约 3 个月内售罄；RISC-V 相关的 Star64（JH7110，StarFive 双 A55 类核心）同属受影响 Linux 产品线；
  • MCU 产品不受影响：PineTime 手表、Pinecil 烙铁、PinePower 电源等 MCU 产品线继续生产并扩张（存储成本占比低）；
  • 行业信号：AI 需求挤压 DRAM/eMMC 产能导致价格暴涨，低成本 Linux/RISC-V 单板机厂商首当其冲——对”平价 RISC-V 入门硬件”供给是负面扰动，社区入门平台（Star64 等）短期供应承压。

三、国内团队动态与深挖

3.1 平头哥：C950 性能数字的批判性复盘——SHL 软件栈与测量局限（08-19）

日期：2026-08-19（13:36 北京时间）　来源：XenoSpectrum

昨日头条（C950 原生运行 Qwen-3.8 27B）今日迎来行业媒体的批判性复盘：XenoSpectrum 刊发长文拆解”30 tok/s / TTFT 1.9s”数字背后的软件栈与测量边界：

  • 数字来源：出自 08-18 技术观察者 tphuang 转发的 XUANTIE 标签幻灯片，非独立复测结果；幻灯片另列出 Qwen3.8-2.4T-A95B 在 C950 上的 decode 7.2 tok/s / TTFT 8.5s；
  • 性能来源：核心是平头哥 SHL（Heterogeneous Neural Network Library）异构神经网络库——按精度与计算形状选择 MatMul/Linear 矩阵算子、Softmax/RMSNorm 专用实现，配合算子融合、缓冲区复用、格式转换削减；官方仓库公开支持 8/16/f16 位、对称/非对称量化与异构调度；
  • C950 定位：服务器级 RISC-V 处理器 IP（云/数据中心、AI agent 服务器、高性能机器人），8 指令解码、乱序执行、向量计算、Matrix AI 加速、RVA23 Profile 与 CoVE；Qwen3.8-27B 权重 08-12~14 上传，C950 材料 08-18 即出，Day 0 适配属实；
  • 测量局限（原文重点）：精度、量化、批大小、提示长度、内存带宽、功耗均未披露，无法与 GPU/Mac 同口径对比；C950 是 IP，64 核 target configuration 不等于量产芯片出货；TSMC 5nm 工艺（Nikkei 报道”5nm 验证”）未经阿里证实。
  • 另：XUANTIE-RV/opensbi 仓库 08-19 07:56 UTC 有推送（默认分支无新提交，疑为 tag/分支级更新；此前 08-07 已打 XuanTie_V1.4.0-rc2-c9502 标签，C950 启动固件迭代持续）。

评述：这篇复盘把叙事从”官宣里程碑”拉回”可复现基准”层面——RISC-V 跑 27B 大模型的方向性验证成立，但距离可对标的效率数据仍需厂商披露测量条件。这与昨日报告”以媒体口径为准”的局限说明互相印证。

3.2 赛昉 StarFive：Dubhe-100 深挖——家族演进与生态节奏（08-19）

日期：2026-08-19　来源：StarFive 官网、CNX Software

Dubhe 家族演进脉络：Dubhe（2021-12 首曝，12nm、2 GHz、对标 P550）→ Dubhe-90/80（2023-08 发布，Max Performance / Efficiency Performance 两系列）→ Dubhe-83（2024-12，跟随 RVA23 Profile、RVV 1.0 + Vector Crypto）→ Dubhe-100（2026-08，RVA23 合规、SPECint2006 15/GHz）。

  • 战略位置：赛昉此前以 VisionFive 系列 SBC（JH-7110）与数据中心 BMC 芯片为市场抓手（08-13 已报道 BMC 布局），Dubhe-100 将产品线明确推向”服务器级 IP + AI 基础设施”，是 08-14 报告”RISC-V 向数据中心基础设施渗透”判断的又一落子。

四、重点方向专章：具身智能与机器人

4.1 RISC-V 高端算力叙事集体转向 AI agent 与机器人（08-19）

本周两条国内重磅（C950 与 Dubhe-100）在产品定位上高度同向——都把”AI agent 服务器 / 高性能机器人 / 具身智能”写进核心应用场景：

  • 平头哥 C950：官方口径明确覆盖”AI agent 服务器与高性能机器人”，SHL 软件栈 + 64 核 RVV 跑通 27B 级模型（30 tok/s），为端侧/边缘大模型推理提供基线数据；
  • 赛昉 Dubhe-100：目标应用含 LLM 推理、AI agent 与视觉分析，首客户 LECARC 做”智能边缘服务器”，官方宣传语即”Agentic AI 时代”；
  • 香山 XSAI：矩阵加速器（CUTE）持续迭代，RISC-V 开源侧的高性能 AI 计算底座同步推进。

对具身智能的意义：VLA（视觉-语言-动作）模型上机依赖”端侧可负担的大模型推理”，C950 的 30 tok/s 基线说明 RISC-V 多核+向量路线在该方向已越过”演示”门槛；而 Dubhe-100 的 15/GHz 整数性能与 Vector Crypto 则指向”机器人算力底座 + 安全”的更高一档定位。风险面同步出现：DRAM/eMMC 涨价使低成本机器人/边缘硬件的整机成本承压（见 2.2），供应链波动可能延缓平价具身平台的铺开。

五、总结与趋势观察

  1. 赛昉 Dubhe-100 官宣：中国服务器级 RISC-V IP 再添一员——RVA23 合规、SPECint2006 15/GHz、Vector Crypto，与平头哥 C950 正面同场，RISC-V 高端核心竞赛进入”中国双雄”阶段；
  2. C950 性能数字迎来批判性复盘：XenoSpectrum 拆解出 SHL 软件栈是关键（算子融合/量化/缓冲区复用），同时指出测量条件未披露、”IP ≠ 量产芯片”——”RISC-V 跑大模型”叙事进入理性讨论期；
  3. 香山连续第三日高强度迭代（12 仓库）：前端 IBuffer 时序、访存乱序正确性、矩阵加速器 CUTE 三线并进，开源高性能核研发节奏不减；
  4. 社区辩论升温：Dmitry Grinberg 对嵌入式 ISA 的批评与实机回应（CH32V003 案例）同屏出现，RISC-V 生态进入”可批评、有反驳”的成熟期；
  5. 供应链阴云：Pine64 因 DRAM/eMMC 缺货暂停 Linux 设备生产（Star64 等 RISC-V SBC 受影响），AI 需求挤压存储产能的传导开始波及平价 RISC-V 硬件。

局限性说明：Dubhe-100 规格以 CNX 转述与 StarFive 官方产品页为准，SPECint2006 15/GHz 为 IP 级厂商宣称值、未经独立第三方复测；C950 性能数字为厂商幻灯片口径（XenoSpectrum 亦强调非独立复测）；XUANTIE-RV/opensbi 08-19 推送未核实到具体提交内容（默认分支无新提交）；gnews 中文查询（zh-CN 区域）窗口内为空、英文正常，国内厂商中文报道可能存在漏报；本周厂商英文查询（SiFive/Milk-V 等）空命中，未见海外头部厂商新品。
