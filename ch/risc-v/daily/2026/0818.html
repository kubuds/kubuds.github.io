1.3 riscv-unified-db 合入三笔指令语义修复：zalrsc 符号扩展、sstateen 定长、c.sdsp 索引

日期：2026-08-18 05:22 ~ 05:36（北京时间）　来源：riscv/riscv-unified-db GitHub

RISC-V 官方统一指令数据库（unified-db，UDB 项目）窗口内合入三笔指令语义级修复：

  • fix(zalrsc): sign-extend the lr.w result on RV64 (#2460)——Zalrsc 扩展 lr.w 在 RV64 上的结果需符号扩展；
  • fix(csr): sstateen0-3 take the stateen family's fixed length of 64 (#2395)——sstateen0-3 CSR 固定 64 位长度；
  • fix(isa): c.sdsp must use its full 5-bit register index (#2419)——压缩指令 c.sdsp 必须使用完整 5 位寄存器索引。

UDB 是 RISC-V 官方 spec/软件工具链的机器可读指令语义单一来源（riscv-arch-test、Sail 等均消费该库），此类低级语义修复直接影响测试与仿真工具的正确性，属”规范基础设施”级维护。
