RISC-V周报（2026-09-21 ~ 2026-09-25）

2026-09-25 苦芽科技

报告周期：2026 年 9 月 21 日（周一）至 9 月 25 日（周五），共 5 个工作日、5 期日报素材 素材来源：每日 RISC-V 全球动态日报（09-21、09-22、09-23、09-24、09-25 五期；09-21 期为三天窗口，含上一周末动态）；另经 GitHub 组织与重点仓库 168 小时窗口复核、openRuyi 双源核查与会员企业官网巡检补强 编制说明：本周期覆盖指令集与架构生态、操作系统与发行版、芯片与硬件、开源社区与产业活动四个主题维度；五期日报核心条目按主题聚合，事实、版本号与日期均来自当期已核验信源与本周期实测核查，厂商、园区与媒体单方口径已在正文标注

一、本周要闻

  • 奕斯伟计算通过港交所上市聆讯，有望成为港股「RISC-V 第一股」（09-21）：据港交所文件，北京奕斯伟计算技术股份有限公司于 09-21 通过港交所主板上市聆讯（联席保荐人中信证券与中信建投国际），若发行顺利将填补 RISC-V 芯片赛道的上市标的空白。公司以 RISC-V 为技术底座，产品覆盖人机交互及多媒体处理芯片、互连及计算芯片，聚焦智能终端与具身智能；2023 至 2025 年营收 17.52／20.25／24.31 亿元，2025 年净亏损 15.16 亿元，2026 年一季度营收 4.94 亿元（同比增 18.4%）；计算产品收入由 2023 年的 37.5 万元增至 2025 年的 3.20 亿元。据弗若斯特沙利文，中国 RISC-V 主控芯片市场规模由 2021 年的 11 亿元增至 2025 年的 377 亿元，预计 2030 年扩大至 2194 亿元。同日公司 GitHub 侧新建 release-EIC7X-2026.06 发布分支并落地 eic7700_sample 仓库（见第四节）。边界：聆讯距正式发行与定价仍有流程要走，净亏损收窄与计算产品放量节奏是最直接的检验指标。来源：第一财经、新浪财经／观点网

  • 奕行智能完成近 20 亿元融资，为国内 RISC-V 方向披露的最大单笔（09-18 消息，本周期日报收录）：RISC-V 云端 AI 算力芯片企业奕行智能（EVAS Intelligence）完成近 20 亿元（约 2.95 亿美元）新一轮融资、投后估值接近 150 亿元，投资方超过 20 家（含国家大基金一期子基金芯鑫租赁、华泰创新、钟鼎资本、中芯聚源等）。产品侧：第一代 Epoch 芯片规模化量产交付、原生支持分块量化 FP8；业界首个 RISC-V AI 算力超节点（64 节点、E200-L 液冷 OAM 模组）已在石家庄运营商数据中心完成集群部署；新一代云端芯片已流片，迭代节奏为「一年一代」；公司推进 VISA 虚拟指令集开源，软件栈兼容 PyTorch、TensorFlow、JAX、ONNX，并与 vLLM、Triton 及 FlagOS 社区联动。边界：估值接近 150 亿元不等于业绩兑现，后续订单与营收节奏是更硬的检验。来源：猎云网 via 腾讯新闻、36Kr 英文

  • Monte Cimone v3：算能 SG2044 获得第三方 HPC 能效坐标（09-23）：RISC-V 国际基金会官网博客发布博洛尼亚大学、意大利 Cineca 超算中心与 E4 Computer Engineering 联合完成的第三代 RISC-V HPC 测试床（MCv3）评测：基于算能 Sophon SG2044 构建集群，以 HPL 与 STREAM 基准同步测量功耗，与 Intel Xeon Platinum 8480+（Sapphire Rapids）、NVIDIA Grace CPU Superchip 对标。数据：SG2044 单核性能较上代 SG2042 提升一倍以上；能效达 3.08 GFLOPs/W（约为第一代测试床的 10 倍），峰值能效点性能达 Sapphire Rapids 的 46%、Grace CPU Superchip 的 91%。意义与边界：首次有第三方学术团队把国产 RISC-V 服务器芯片放入与国际服务器平台同一基准框架给出能效对照；性能总量仍有差距，现实切入点仍是能效敏感与开放可定制场景。来源：RISC-V International 博客

  • UPC 研究：用玄铁 C910 与片上性能计数器让 RISC-V 芯片「自检」微架构攻击，检出精度 99%（09-24）：西班牙加泰罗尼亚理工大学（UPC）团队在真实商用硅片上完成实验——达摩院玄铁 C910（RV64GCV）搭载于矽速 LicheePi 4A、运行 Debian 13——用硬件性能计数器配合机器学习做微架构攻击实时检测，论文发表于期刊 Cybersecurity，并公开数据集 HARPY-V（约 6.4 万条标注样本、16 种微架构攻击含 GhostWrite 与 16 个良性程序）；二元检测精度 99%、多分类约 95%。团队同时披露实测经验：C910 上同时监控多个 perf 计数器会相互干扰（部分读数被放大 3 倍以上）、须逐计数器单独采集，且 perf 事件描述多不准确、须以官方手册的计数器映射为准。意义与边界：首批以商用 RISC-V 硅片加公开可复现数据集完成的研究之一；仅覆盖单一核心型号、跨芯片需重训练，对全新攻击类型的泛化仍待验证。来源：Scienmag、论文

  • 云栖大会：达摩院玄铁团队发布真武 V900 AI 芯片，首次公布倚天 720／730／750 CPU 路线图（09-22）：真武 V900 采用自研并行计算架构、216GB 显存、片间互联带宽 1200GB/s、单芯片性能为上一代真武 M890 的三倍，原生支持 FP8／FP4，2027 年一季度量产并在阿里云数据中心规模化部署，配套磐久超节点与自研 ICN Switch（单集群最多连接 50 万颗）；倚天 720（192 核、96 条 PCIe）与倚天 730（首次基于全自研微架构、支持 SMT、单核 SPECint2017／GHz 最高为倚天 710 的 1.4 倍）定档 2027 年三季度，倚天 750 将采用第二代自研核并原生支持 ICN 互联。边界与背景：真武与倚天均非 RISC-V 产品（倚天沿用 Arm 指令集），按「国内核心团队」口径收录；达摩院玄铁是 RISC-V 生态核心团队，其 RISC-V 线（玄铁 C 系列 IP、无剑联盟与开源香山联合研发）本周同期有新动作（见第二、三节）。来源：IT之家、快科技、TrendForce

  • 汽车 RISC-V 进入「量产清单」：东风 DF30 定档 2026 年规模量产，英飞凌下一代车规 MCU 全面转向（09-21 ~ 09-23）：东风披露 DF30（与中国信科联合研发、国产 40nm 车规工艺、功能安全达 ASIL-D、芯来内核）已在东风奕派 007、猛士 M817、风神皓瀚等车型完成验证、首搭发动机 ECU，计划 2026 年规模量产、年底首批搭载量产车下线；芯来内核团队已扩至约 500 人、芯片完成 600 多项测试。英飞凌宣布下一代汽车 MCU 全面转向 RISC-V（纳入 AURIX 家族），其汽车 MCU 份额升至 36%，并联合 Vector、东软睿驰、普华适配 AUTOSAR、推进 FreeRTOS／Zephyr／NuttX。盖世汽车系列终篇补上「成本账」与节奏判断：商用 RISC-V 内核授权费约为 Arm 的十分之一，但商用 IP、工具与验证环境均需付费、生态投入是主要门槛（英飞凌提前 2 至 3 年投入）；汽车领域渗透率预计从 2025 至 2026 年的约 10% 升至 2031 年的约 31%，路径为「边缘到中心」。来源：凤凰网（网通社）、凤凰网（网通社）、Gasgoo

  • 香山处理器：向量浮点指令合入默认分支，缓存子系统「Oceanus」L2 并行推进（09-22 ~ 09-24）：09-22 主仓库合入「向量浮点指令支持」（为昆明湖向量单元增加浮点向量运算路径）并把 Zicbop 指令补入 decode 的 uopTable；09-23 XSCache「Oceanus」新一代 L2 开发分支推进 20 项提交（L2 端口参数化、AMBA CHI 端口暴露、StashShared／StashUnique 事务支持与多项一致性问题修复）；09-23 主仓库修复跨 16 字节对齐加载／存储的 pingpong 卡死（#6590）、09-24 默认分支合入 uBTB 命中检查时序与 CommonHR 重定向历史维护修复；09-25 向量、TAGE 分支预测、自由列表重构、load-to-use 时序等多分支并行修复与调优。仿真与验证链（NEMU／GEM5／difftest）同步跟进（详见第二节）。来源：XiangShan 提交记录、XSCache 提交记录

  • 奥维领芯完成超 2 亿元 Pre-A+ 轮融资（09-23）：深圳奥维领芯宣布 Pre-A+ 轮全部资金交割、金额超 2 亿元，引入苏创投、国新国证、普华中小二期、成都沛坤等国资背景机构与星宸科技、聚合资本、深产投等产业资本，老股东跟投；Pre-A 系列合计超 3 亿元，资金投向新一代芯片研发、团队扩充与商业化落地。技术路径为「RISC-V 底座＋DSA 模块化可配置异构架构」，自研 RV9000 系列（异构算力最高 24 核、内置国密安全引擎）已于 09-15 流片点亮（上一期周报刊登）。边界：融资额与用途为公司官宣口径，芯片尚无第三方性能数据与量产时间表。来源：投资界

二、指令集与架构生态

香山处理器：向量浮点合入默认分支，缓存与前端多线并行

  • 向量浮点进入主分支：09-22 主仓库合入 feat(vector): support vector-float instructions，为昆明湖向量单元增加浮点向量运算路径并整理 vecRegion 连接；decode 侧把缺失的 Zicbop 指令补进 uopTable（#6586）。向量开发分支（0923）持续修复六项——新存储路径的向量存储掩码支持、向量加载 VL 依赖跟踪、vle 异常处理、vldSNMergeInfo 初值修正、写回时合并旧 vd、物理存储队列外的 vstd uop 取消，属向量访存路径的收尾打磨。
  • 默认分支合入与缓存子系统：09-23 主仓库修复跨 16 字节对齐加载／存储的 pingpong 卡死（#6590）；09-24 默认分支合入 uBTB 命中检查时序（#6489）与 CommonHR 重定向历史维护修复。XSCache「Oceanus」L2 分支 09-23 推进 20 项提交：L2 端口参数化（兼容多 D-Cache bank 组合）、以 AMBA CHI 接口对外暴露端口、CHI 语义 StashShared／StashUnique 事务支持，以及 EVT 提交、peer 元数据写入、ReplRd 返回 I 态等一致性修复——内存系统向多核与一致性互连方向演进。
  • 前端与微架构调优线：TAGE 分支预测修复 bank 冲突与 CommonHR 维护错误；自由列表重构分支以位图入队计数轮转重填 bank（性能）；ECC RERI 特性分支提交；load-to-use 时序分支修复 specMiss 时序；09-22 主仓把 docker 基础镜像切换为 xs-env:stable（#6577）、CI 加入 nightly fuzz 并改进 ckpt_select.py（#6604）。整体呈「向量访存收尾＋前端预测与缓存微架构调优」双线节奏。来源：XiangShan、XSCache

仿真与验证链：NEMU、GEM5、difftest 的矩阵扩展、预取与多核收敛

  • NEMU：把 mseccfg 改为 Kconfig 可配置项（#1221）、虚拟化 supervisor 计时器仅在 nemu_timer 启用时关闭（09-21）；NutShell 未实现 CSR 改为省略（#1222）、无 Zicntr 时保持 CY／TM／IR 可写（#1223）（09-22）；发布 v2026.09.r17（09-23）；完成 CUTE AMU 回调并优化 share-ctrl 控制器（09-24）。窗口早期（09-18 ~ 09-20）另有一批 AME 矩阵扩展工作：未定义 tile 寄存器区域读取检测（#1224）、矩阵 load 比较范围限定活跃区域（#1217）、SHARE REF 标记 CSR 脏位（#1220）、memmove 加速 GCC 寄存器导出（#1219）。
  • GEM5（香山分支）：PDB（预取数据缓冲）模型与重放清理、预取准入修复；mem-cache 修复 probeHit 边界后启用 hit-under-block（#1164）；cpu-o3 修复 pflush vset（#1135）；SMT 增加按 IQ 的安全水位策略（#1175）；FP 除法延迟跨格式对齐（#1167）；KMHV3 向量计算发射队列对齐（#1179）；L2 低精度 offload 可配置（#1183）、H2P 页表默认启用；每周性能覆盖刷新（#1188）与 Hybrid ROB、MaskRAT 建模等分支推进。
  • difftest：AME 打包事件适配 NEMU ABI（#962）、iotrace 保留 EOF 处最后一个 zstd 分块（#972）、OpenIOMMU 文件清单改为条件化追加（#974）、AME MinimalMatrixConfig 校验器兼容性修复。
  • 合并观察：矩阵扩展（AME）边界语义、预取机制与多核算力对齐是本周仿真链的三条主线；香山验证基础设施继续做「仿得更准、跑得更快」两件事。来源：NEMU、GEM5、difftest

编译器、工具链与生态库：二进制翻译、向量后端与开源 IP 工具体系

  • felix86（在 RISC-V Linux 上运行 x86／x86-64 程序）：09-23 五笔提交——x87 运算后更新 RIP、futex 加锁前信号竞态修复、VK_AMD_buffer_marker 图形 thunk、MSVC 字符串查找优化；09-24 四笔——MOV+SHUFPS 组合优化为 PSHUFD、REPL 回归修复、fork 前后信号量加解锁、Zydis 解码优化，游戏与工作负载兼容性持续打磨。
  • 模拟器与规范工具：RVVM 合入五项浮点修复（fcvt 动态舍入模式、fcsr 保留位与 frm 澄清、NaN 与 sqrt 结果规范化，涉及 #259、#260、#280）；qtrvsim 修复 WebAssembly 构建的窗口尺寸与模态事件循环问题、旧 SUSE 发行版打包改用 GCC-13；riscv-unified-db（机器可读规范库）新增 WFI 超时与 U-Mode 支持参数（#2526）。
  • 向量后端与库生态：simdjson 出现 RVV（RVV 1.0）长度无关（VLA）实验后端，配套 GCC／Clang 验证、运行时分发与可复现基准（个人实验仓库，上游接纳进度待验证）；矽速 SLogic 工具链把驱动从私有实现迁移到共享 libslogic 库、发布 slogic16u3-tools v0.1.3（烧录校验日志细化）。
  • 开源 IP 与构建层：Bluespec 开源硬件 IP 库 Tape-Out（FukuzSoC）批量新开仓库——三套参考 SoC（MCU／Linux／SMP）与 PLIC 等部件，每 IP 含 ip.yaml（含实测面积）、regmap.yaml 与全配置矩阵行为测试，配自研 xirang 包管理器、成熟度分五级徽章展示；Tiny-Vedas 发布 arxiv-v0 快照（RV32IM 核＋8x8 int8 GEMM 加速器＋PyTorch JIT 到 RV32 ELF 完整链路，进入论文版）；GNOME Flatpak riscv64 非官方构建持续更新；Exercism 编程平台开设 RISC-V 赛道；AG32（RISC-V MCU＋FPGA 混合芯片）开源 SDK 工具链 AGaMEMnon 持续活跃。来源：felix86、RVVM、Tape-Out、Tiny-Vedas、simdjson RVV

六、趋势观察

  • RISC-V 从社区叙事进入资本市场定价，检验指标转向交付与营收：一周之内，奕斯伟计算通过港交所聆讯、奕行智能完成近 20 亿元融资（国内最大单笔）、奥维领芯超 2 亿元 Pre-A+ 交割，叠加芯来科技北交所辅导备案与「十五五」规划点名（上一周期），资本对 RISC-V 的定价窗口已经打开；与估值同周出现的产业动作（EIC7X 发布分支、EIC7700 示例仓库、RV9000 流片）互为印证，接下来的关键变量是产品交付与订单兑现。
