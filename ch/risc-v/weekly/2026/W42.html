RISC-V周报（2026-10-12 ~ 2026-10-16）

2026-10-16 苦芽科技

报告周期：2026 年 10 月 12 日（周一）至 10 月 16 日（周五），共 5 个工作日、5 期日报素材。

素材来源：每日 RISC-V 全球动态日报（10-12、10-13、10-14、10-15、10-16 五期；10-12 期为 44 小时窗口，自上一期国庆调休补报截点 10-10 09:20 起算）；另经 GitHub 关注组织与重点仓库 168 小时窗口复核、openRuyi 双源核查、riscv.org 与 RISC-V 国际基金会会员官网巡检补强，Ubuntu 26.10 发布镜像经官方 cdimage 站点实测核对。

编制说明：五期日报核心条目按「指令集与架构生态 / 操作系统与发行版 / 芯片与硬件 / 社区与产业活动」四个维度聚合，同一线索跨日进展合并叙述；事实、版本号与日期均取自当期已核验信源或本周期实测核查，单一媒体口径与厂商自述已在正文标注。

一、本周要闻

  • 达摩院玄铁 C950 在 64 核目标配置上无独立加速器跑通 27B 大模型，成果经 RISC-V 国际基金会官网专访传播（10-15）：RISC-V 国际基金会「V Questions」专栏刊出对玄铁首席科学家、RISC-V 中国峰会 2026 副主席孟建熠的专访，披露玄铁团队在 64 核 C950 配置上原生跑通 Qwen3.8-27B（270 亿参数），不依赖独立 GPU／NPU，解码速度超过 30 tokens／秒（约合 20 至 22 词／秒，达到自然实时对话水平）；该负载需约 400 GB／s 的内存数据搬运能力，访谈强调量化、矩阵指令、片上内存、带宽与算子优化必须作单一系统协同设计。C950 为服务器级 64 位超标量处理器，以 RVA23 档案（含 RVV 1.0） 为通用计算基线；玄铁自研矩阵扩展经硅验证后，与 Qualcomm、IBM、VRULL、ISCAS、BOSC 等成员共同发起 AME（Attached Matrix Extension）任务组，正推动规范走向正式批准。设计上 AME 采用独立 tile 寄存器而非复用向量寄存器，原生支持 INT4／INT8→INT32、FP4／FP8／FP16／BF16→FP32 混合精度累加。边界：解码速度为公司团队口径，未附第三方基准与整机功耗数据。来源：riscv.org

  • 蓝芯算力完成近 20 亿元 B 轮系列融资，RISC-V＋AI 服务器芯片进入量产验证（10-12 中文首发／10-13 英文跟进）：深圳蓝芯算力完成 B 轮系列融资合计近 20 亿元人民币（约合 2.99 亿美元），深创投、华控基金、隆湫资本等老股东追加，苏国投、苏创投、兆易创新、同创伟业、建银国际、粤科金融、九坤创投等进场；资金投向 RISC-V CPU 量产、AI 异构处理器迭代与运营商／金融／云服务商通用算力方案。核心产品 LX500 为 48 核异构（32 性能核＋16 能效核）服务器 CPU，片内集成 75 TOPS（INT8） AI 引擎，支持 RVV 1.0 与 RVA23，原生兼容 PCIe 5.0 与 CXL 2.0；2026 年 2 月流片点亮，7 月搭载该芯片的联想问天 WR5219 G5 在合肥联宝量产下线，已适配中国移动 BC-LINUX 并完成 Kimi K2.6、Qwen3.6-35B 推理验证。边界：融资规模为中文媒体与 DIGITIMES 口径，芯片尚无第三方性能评测。来源：凤凰网·投资界、DIGITIMES

  • RVA23 从「规范」变成「可判定事实」：内核 profile 位 8 枚补丁进入 riscv/for-next，单次查询能力获 Phoronix 报道（10-11／10-14）：LPC26 参会记披露，Linux 内核 rva23u64 profile 位系列已推进至 v9（在途），v8 的 11 枚 patch 中前 8 枚于 10-09 被 RISC-V 内核维护者 Paul Walmsley 收入 riscv/for-next，其余 3 枚将吸收 LPC 现场意见后随 v9 提交。LPC26 的四个结论：v9 将补充 RVA22／RVA20 分级位便于 glibc 逐级回退；glibc 改为按 profile 构建并由 glibc-hwcaps 自动选库（hwcaps 来源即内核位，ifunc 留给微架构级）；用户态动态关闭 V 扩展的接口将废弃，Samuel Holland（SiFive）已在次日发出 3-patch 系列；未来带寄存器状态的扩展（如矩阵）不再引入同类开关。该系列外溢带动不少于 5 个主线系列，包括搁置两年的扩展名大小写统一与 Zicclsm、字节跳动 Qingwei Hu 的 Zic64b 支持。10-14 Phoronix 跟进报道「单次查询系统是否 RVA23 合规」的补丁（方案即 riscv_hwprobe 单比特 KEY_BASE_BEHAVIOR：IMA RVA23U64），此前 Ubuntu 侧工具只能给出「probably RVA23」。来源：LPC26 参会记、Phoronix、LPC26 演讲材料

  • Ubuntu 26.10 正式发布，首个官方 RISC-V 桌面镜像随版落地，基线明确为 RVA23（10-15）：Ubuntu 26.10（Stonking Stingray）于 10 月 15 日发布，官方 cdimage 站点已提供 ubuntu-26.10-desktop-riscv64.iso（4.0 GB），标注为「面向 64 位 RISC-V RVA23 及以上处理器」；同批 riscv64 镜像还包括 live-server（1.6 GB）、netboot tarball 与 preinstalled-server（1.3 GB）。这是 Ubuntu 首次提供带桌面环境的 RISC-V 官方镜像（此前 riscv64 仅有服务器／CLI 版），Canonical 同时为 SpacemiT K3 Pico-ITX 提供官方支持与安装文档；实验性 Xubuntu Minimal 镜像面向 QEMU 环境（GNOME 在纯模拟下加载需 30 分钟以上）。发布前一周（10-12）社区已发布「测什么」的测试指引与中文媒体报道。意义：桌面镜像是 RVA23 基线第一次落到消费可下载的成品上，与本周内核 profile 位进展形成「规范—内核—发行版」闭环。来源：Ubuntu cdimage 26.10、Canonical Discourse

  • openRuyi 固件线连续三日发布，K3 平台支持成主线（10-13／10-14／10-15）：openRuyi 项目在窗口内连发 「Ruyi Firmware 20261013」「20261014」「20261015」 三个版本，重心均为进迭时空 K3：13 日版本落地 K3 Pico-ITX 的 GOP 图形输出与 EDID 模式、PCI 选项 ROM、RTL8127 有线网卡驱动、引导选择与控制台热键，并提供含／不含 x64 模拟（x64emu）两个固件变体（x64emu 下已验证 AMD Radeon RX 6400）；14 日版本新增 K3 双簇 CPU 模式选择——UEFI Setup 提供 X100 only（默认，8 核、RVV VLEN 256、保留 H 扩展）／X100＋A100（16 核）／A100 only（8 核、VLEN 1024） 三档，设置持久化到 SPI 专用扇区，由 coreboot 在 OpenSBI 启动前读取，A100-only 引导经 SBI HSM 将 SEC 从 hart 0 移交 hart 8，设备树根兼容串同步反映模式；15 日版本补 raw SPI 烧录安装文档、A100-only 模式中断路由修复、System Information 页与 DRAM 清单、IMG GPU 时钟设备树修正。同周主仓（openRuyi）完成 Go 1.27.2／OpenSSL 3.6.5／docker-cli 拆包、KDE Plasma 6.7.5 全套升级（19 个包）、Mesa 26.2.4 与 PowerVR 回移，以及 cups、python-nltk（CVE-2026-81726）、capstone 5.0.9、llama-cpp 0.4.1、multipath-tools 0.15.1 的安全维护批次。来源：20261013、20261014、20261015

  • 进迭时空把端侧 Agent 全栈整体公开：Bianbu AgentOS 组件集中开源，llama.cpp 独立后端两连发（10-12 ~ 10-15）：10-13 晚间集中建仓后，进迭时空在 10-14 将端侧 Agent 系统软件栈（Bianbu AgentOS）推向公开：桌面端 BiBit GUI 与离线语音 Bibit Voice 发布 1.0Beta1，同时开源 Agent 运行时（bianbu-agent-runtime，YAML 配置驱动、会话即事件流、securityd 签名清单与 Tool 审批、生产模式 fail-closed，当前仅支持 K3／Bianbu 4.0）、本地优先记忆服务（bianbu-agent-memory，L1 会话事件／L2 工作摘要／L3 长期记忆三层，SQLCipher 加密与命名空间隔离）、意图路由与文件搜索等组件；10-15 补齐 能力分发基建——APM（agent-power-manager，把 Skill／Plugin／MCP／Expert 四类 Power 的检索安装升级收敛到统一命令，Apache-2.0）、Bibit Agent Hub（能力中心前端插件＋Go CLI Provider，支持 riscv64 构建）与 Bianbu Skills 只读镜像（首期 11 个 Skill）。AI 推理侧同步：llama.cpp 分支引入独立 ggml-spacemit 后端（PR #43，需同时设设备后端环境变量与 --device SPACEMIT0 才启用）并连发 v0.2.1／v0.2.2（后者修复 K1 上 Qwen3.5-2B 输出乱码）。边界：全部组件以 K3 单平台先行验证，跨平台可移植性待观察。来源：bibit 1.0Beta1、bianbu-agent-runtime、llama.cpp v0.2.2

  • RISE 发布 SpeexDSP 的 RVV 向量优化成果：重采样最高加速 4.88 倍（10-13）：RISE 项目刊出 RP020 结项成果——为实时音频基础库 SpeexDSP（被 VLC、Firefox、Wireshark、PulseAudio、Mumble 等广泛使用）引入手写 RVV 汇编：浮点重采样内核对比编译器自动向量化 C 加速 3.71 倍（Clang 18）／3.59 倍（GCC 13），定点内核 **2.69 倍（Clang 18）／4.88 倍（GCC 13，GCC 未能自动向量化）。得益于 RVV 长度无关特性，同一份汇编在 SpacemiT K1（VLEN=256）与 Canaan K230（VLEN=128）两类物理平台均有效；配套 Meson＋Checkasm 校验顺带发现并修复了 SSE2 内核一个历时 8 年的数据依赖缺陷。项目由 Google 工程师与 RISE 合作推进，RISE 资助 4 万美元。来源：RISE Project

二、指令集与架构生态

RVA23 与内核：profile 位入树、自动向量化实验与「合规可查」

  • profile 位进入合并流程：v8 的 11 枚 patch 中 8 枚已进 riscv/for-next（10-09），余 3 枚随 v9 提交；v9 将补 RVA22／RVA20 分级位便于 glibc 逐级回退，并写明不继承 IMA 位的历史遗留行为。glibc 侧改为按 profile 构建 + glibc-hwcaps 自动选库，GCC 维护者 Jeff Law 在 GNU Tools Cauldron 的 RISC-V BoF 同向推进；用户态动态关闭 V 扩展的接口将废弃（SiFive 的 Samuel Holland 已发 3-patch 系列），未来带寄存器状态的扩展不再引入同类开关。
  • 外溢系列：该系列直接或间接带动不少于 5 个主线系列——搁置两年的扩展名大小写统一与 Zicclsm 被吸收、字节跳动 Qingwei Hu 贡献 Zic64b、do not report disabled extensions（6 patch）、cpufeature BUNDLE 到 SUPERSET 精简、V-off 废弃系列。本届 LPC 的 RISC-V MC 共 10 场 talk，高通占 3 场。
  • 内核自动向量化：Andy Chiu 在 LPC26 介绍以编译器自动向量化优化内核的实践——LZ4 最大提升约 15%、Btrfs 约 8.4%、XFS 约 5%、Nginx 场景约 2%，代价是向量上下文管理的时间与内存开销上升。RISC-V 内核构建目前仍未启用 V 扩展，该结果使「内核态用向量」这一长期禁区被重新评估。
  • 查询接口：10-14 Phoronix 报道单比特查询方案（KEY_BASE_BEHAVIOR：IMA RVA23U64，开机从完整 ISA 位图一次性计算），由 Andrew Jones 发起 RFC、徐国栋推进；配套《RVA23 in practice》演讲材料已在 LPC 网站公开。来源：Phoronix 自动向量化、LPC26 向量演讲

香山：压缩 ROB、全相联 vBTB 与 L2 访存延迟三线推进

  • 前端与乱序结构：主仓（kunminghu-v3）窗口内落地压缩 ROB（crob）架构特性——实现压缩 ROB 并集成 CSR 状态跟踪，重构压缩状态与时限路径、为 ArchEvent 携带事件位置、以条目偏移保持有序存储检查、修复 scommit 位宽并扩充条目数；随后合入 MBTB（主分支目标缓冲）全相联 vBTB（#6587）、修复 MMU 在 V=0 时忽略 PTE G 位（#6695）、运算单元窄移位偏置按输出格式选择（#6689）、存储队列前递旧存储数据修复（#6693）。
  • 访存与缓存：10-14 合入 降低 L2 load-to-use 延迟（#6713），并修复 ICache 异常传递与取指块末偏移在数据 ECC 场景下的 bank 选择，支持 Zimop（MOP）指令解码。周期末（10-15）主仓无新合入，分支级推送为主（kunminghu-v2 有 1 笔 ChiselAIA 回压修复）。
  • 仿真与验证链：NEMU 将 AME 矩阵扩展的指令分发与 PMEM 访问解耦（#1249）、加速 AME 矩阵哈希、修复 AME 矩阵存储回滚记录（#1251）与跨页存储缺页的首页写入保留（#1240），并发布 v2026.10.r3；difftest 新增 MCSim 时序后端（与 DRAMSim3 并列）、mcsr／mcfg 的 delta 编码、lane 并行 CRC-64 存储哈希校验、GBD1 frozen-bank DMA drain 与 trace 握手门控（#990）；GEM5 分支（xs-dev）增加 Zimop 指令支持与 TRACERTL／NEMU 轨迹格式，恢复 macOS 构建并新增手工冒烟 CI（#1228），10-15 再合入 MLP 感知取指策略、私有 MBTB victim cache 默认启用（#1235）及其共享写入下的失效修复（#1236）、每周理想 BTB SPEC 基准（#1233）。
  • 判断：本周香山的投入呈「前端结构（crob／vBTB）＋访存延迟＋验证基建（时序后端、哈希校验）」三线并行，验证链的工程化程度提升快于核本体性能数据的公开。来源：XiangShan、NEMU、GEM5、difftest

架构测试与工具链：玄铁 ATS 补 BF16 向量、奕斯伟开源 AME 测试向量、openKylin 的 RVV 收益

  • 达摩院玄铁：damo-rv-priv-ats 特权架构测试框架合入 PR #37，引入 T-SBI（Test Supervisor Binary Interface）协议层并把全部测试套件迁移到 S 模式常规执行模型——启动阶段完成仅 M 模式初始化后在 main() 之前降至 S(HS) 模式，以正确建模 Smstateen 门控 CSR 等 HS 视角行为；damo-rv-ats 合入 Zvfbfmin 与 Zvfbfwma（BF16 向量）指令测试（vfncvtbf16／vfwcvtbf16 与 vfwmaccbf16.vf／.vv 用例及构建脚本），并补充公共基础设施、整型向量、浮点向量、向量密码四份框架文档；damo-rv-priv-ats 另将 Sail 形式化模型依赖升级至 0.15；thead-extension-spec 合入 3 笔（RV32 LWUD 修复 #80、用户 PR #78、README 更新 #72）。
  • 奕斯伟计算：开源 riscv-matrix-gemm-vectors 仓库，面向 RISC-V 矩阵扩展（AME）规范提案 v0.6.0 提供 BF16×BF16→FP32 矩阵乘累加测试向量集——每个用例为裸机自校验程序，随附与实现无关的参考值及检查器，判据采用标准舍入误差界（ Ĉ−C* ≤ γ(G)·Σ a·b ）而非逐位比对，以适配规范允许的无序求和实现差异；另提供两个「所有合规实现结果位相同」的用例以检出错误舍入。该套件不依赖具体指令集，可复用于其他矩阵扩展实现。
  • openKylin：在 Open Source Summit Europe 2026（布拉格，10-07 至 10-09）披露 RISC-V 侧进展——RVV 内核优化使 ONNX Runtime FP32 推理提速 2 至 5 倍，相关内核优化与推理框架适配计划回馈上游；AI 栈支持在进迭时空 K3 上以 vLLM 做 CPU 推理，交付形态含 deb、Python wheel、Conda 与 Docker；现场展出预装 openKylin 3.0 的 K3 笔记本。
  • 架构提案讨论：社区作者 FProx 撰文解析 RVBNA（RISC-V Bulk Normalization Algorithm）——以定点累加器为核心、乘积与累加两阶段均用 round-to-odd 舍入的可扩展点积近似方案，已写入 ISA 手册草案（5 月并入），当前集成于向量矩阵扩展 VME 的 Zvt 家族与大批量点积扩展 Zvdota／Zvbdota，并开源误差评估器。来源：damo-rv-priv-ats、AME 测试向量库、MarkTechPost

开源核与生态项目：OpenHW 持续推进，仿真与工具小生态活跃

  • OpenHW 基金会：168 小时核查显示 cvw、cva6、cv-hpdcache、cv32e40p、uap 五个仓库窗口内有推送（cva6 与 cvw 在周期末至核查时仍活跃），延续 CORE-V 系列的设计与验证节奏；组织仓库已由 openhwgroup 迁至 openhwfoundation。
  • 其他：Rust 编写的内存安全内核 Asterinas 0.19.0 首次引入初始 DRM 子系统并在 modesetting 驱动与 Mesa LLVMpipe 之上跑通 X.Org，同时新增 AArch64 目标（与既有 x86_64、RISC-V、LoongArch64 并列）；riscv.org 刊出 LFX 导师计划学员实践，其自主开发的 ISA Configuration Builder 与 Extension Sandbox 把 1,867 条指令按 83 个 ISA 子集自动归类，用于降低自研核配置与自定义扩展的出错成本。来源：openhwfoundation、Phoronix Asterinas、riscv.org 博客

三、操作系统与发行版

六、趋势观察

  • RVA23 从「规范文本」变成「可判定事实」，三环闭环本周成形：内核 profile 位已有 8 枚进入 riscv/for-next（v9 在途）、单次查询接口获主流媒体报道、Ubuntu 26.10 直接以 RVA23 为镜像基线并写明「RVA23 及以上」。这意味着「这台机器是不是 RVA23」将从逐项比对变成一次系统调用，glibc 按 profile 构建 + hwcaps 自动选库是下一个关键落点。若该链条按期走通，RISC-V 软件分发的二进制碎片化问题将首次有系统性答案。

  • 高性能叙事分成两条路线，且都在本周拿到阶段性证据：一条是「CPU 本身承载 AI」——玄铁 C950 在 64 核配置上无独立加速器跑 27B、解码超 30 tokens／秒，靠的是量化、矩阵指令、片上内存与带宽的系统级协同；另一条是「CPU＋片内 AI 引擎」——蓝芯 LX500 以 48 核＋75 TOPS 单芯片融合冲刺量产。前者证明可行性上限，后者证明商业路径，但两者都缺少第三方基准与整机功耗数据，这是下一阶段最该补的证据。

  • 发行版竞争焦点从「能启动」转向「平台广度＋固件体验＋安全维护」：openRuyi 把固件做成了日更节奏（K3 双簇 CPU 模式选择已下到 SPI 持久化与 coreboot 读取层），RevyOS 两周内把 K1／K3／EIC7700／TH1520／SG2042／SG2044 的平台配置一次收拢，Ubuntu 则用官方桌面镜像＋K3 官方支持直接参与。三家同周把 K3 当首要验证平台，说明国产 SoC 的发行版支持面已从「补丁式适配」进入「产品化交付」。

  • 端侧 Agent 栈成为 RISC-V 软件栈的新赛道，但仍是单平台先行：进迭时空一周内从「集中建仓」走到「全栈开源 + 能力分发闭环」（GUI／运行时／记忆／离线语音／安全 + APM／Agent Hub／Skills 镜像），并把人形机器人 MuJoCo 仿真补上 RGBD 启动命令。这套组合在 RISC-V 上尚属首例；风险在于全部组件当前只支持 K3 与 Bianbu 4.x，跨芯片可移植性与社区外贡献者规模是后续观察点。

  • 资本与量产在同一周出现，但「融资额」与「性能兑现」仍需分开看：蓝芯近 20 亿元 B 轮与 Ubitium 1400 万美元种子轮同期落地，前者已有整机量产与运营商系统适配，后者仍在流片验证与 2027 年评估样片阶段。国内 RISC-V 服务器芯片正从「点亮」进入「量产验证」，接下来的硬指标是订单、第三方性能评测与软件栈成熟度，而非估值。

  • 生态活动密度达到年内高点，峰会周之后应有一批技术披露：RVSC2026（10-18 至 20）叠加进迭开发者大会（10-17）、龙蜥 RISC-V 分论坛（10-18）、香山生态大会（10-20）、AME 矩阵扩展研讨会（10-20）与玄铁北京站（10-22），一周内五场活动覆盖编译器、矩阵扩展、车规工具链与端侧 Agent 四条主线。下一期周报应以峰会现场材料为主线重做一次事实核对，尤其是 AME 规范的推进状态与各厂商的芯片时间表。
