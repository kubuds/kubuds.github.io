RISC-V周报（2026-08-12）

2026-08-12 苦芽科技

数据来源:本机每日日报(8/11、8/12)汇总 + GitHub 组织提交补采(8/6-8/10 窗口,XUANTIE-RV / OpenXiangShan / Nuclei-Software / sophgo / spacemit-com 等)+ 跨窗口报道补录。 说明:本机日报系统 8 月 11 日由 K3 机器迁移而来,8/6-8/10 无逐日日报,该区间以 GitHub 提交与 8/10-8/11 的跨窗口报道为准,已尽量去重合并。

一、开源社区与内核/规范动态

1.1 RVA23.1 与 RVB23.1 Profile 公开评审正式启动

日期:2026-08-11　来源:HN / RISC-V isa-dev 邮件组

RISC-V 国际基金会启动 RVA23.1 与 RVB23.1 Profile 公开评审,面向全社区征集反馈。这是 RVA23/RVB23 系列规范发布后的首个维护性迭代版本,涉及 A 类应用与 B 类基准 Profile 的细则修订与勘误更新,对工具链、内核与编译器生态的适配节奏有直接指引意义。

1.2 QEMU 11.1 发布:新增 RISC-V 大端支持与 K230 板级模拟

日期:2026-08-12(发布 08-11 16:11 UTC)　来源:Linuxiac 经镜像核实

QEMU 11.1 的头号特性是 RISC-V 大端(big-endian)目标支持,对应 RISC-V 运行时可控端序能力的落地(Codethink 此前以此为主题开展研究)。RISC-V 侧同步增强:新增勘智 K230 开发板支持、OpenSBI 升级至 1.8.1、新增 Tenstorrent mvendorid 支持,并修复大批 IOMMU、中断处理、页表遍历与向量指令问题。RISC-V 内核/发行版开发者可在模拟器中先行验证大端软件栈。

1.3 香山 XiangShan:一周时序与正确性修复系列

日期:2026-08-06 ~ 08-10　来源:GitHub OpenXiangShan/XiangShan

香山本周合入多笔修复:FTQ/ICache meta 读端口时序(#6281)、Phr 在 s1/s3 期间的更新时序(#6263)、vbop 握手逻辑整理(#6163)、WriteBuffer 同条目读写冲突(#6315)、IFU 异常时 s1_instrCount 计算(#6301)、StoreUnit 仅双 TLB 命中时向 UnalignQueue 发送 paddr(#6332)。另 XiangShanLab 仓库新增 RISC-V spec/gap 技能工具(8/10)。工程侧持续推进,为架构升级(见 3.2 开芯红)提供支撑。

1.4 RISC-V 规范基础设施仓库活跃

日期:2026-08-11/12　来源:riscv-unified-db / riscv-arch-test

riscv-unified-db(规范机器可读数据库)合入多笔依赖维护提交,riscv-arch-test 更新 Ubuntu 24.04 Docker 镜像。属规范工程常规节奏,与 RVA23.1 评审配套推进。

1.5 社区反思文章《RISC-V: They Should Have Known Better》引热议

日期:2026-08 上旬　来源:HN / dmitry.gr

资深嵌入式开发者 Dmitry.GR 发布长文,批评 RISC-V 在中断延迟、指令密度、寻址模式等底层设计上的缺陷,称部分嵌入式指标不如几十年前架构。文章在 HN/Reddit 引发广泛讨论,新浪等中文媒体亦有转载,是本周社区层面最重要的观点性事件(属观点文,非官方立场)。

1.6 labwired-core:ESP32-C3(RISC-V)固件仿真能力增强

日期:2026-08-12　来源:GitHub w1ne/labwired-core

Rust 编写的确定性固件仿真器 labwired-core(59 stars)合入 15 笔提交:新增 ATmega328P Nano 孪生、修复 ESP32-C3(RISC-V)上 DHT 单总线时序、新增资源度量功能。RISC-V MCU 在”固件级仿真/虚拟硬件”工具链中的覆盖度在扩大。

二、产品与生态动态

2.1 Comu:6 美元 USB 口 RISC-V 开发板

日期:2026-08-10　来源:CNX Software

基于沁恒 CH32V203(RISC-V 内核 MCU)的微型开发板 Comu,整板可嵌入 USB 接口内(U 盘形态),售价约 6 美元,显著降低 RISC-V MCU 入门门槛,在 HN 上获讨论。

2.2 Dabao(Baochip-1x,DEF CON 34 徽章芯片)生态快速成形

日期:2026-08-10　来源:Adafruit Blog

DEF CON 34 徽章搭载的 Baochip-1x RISC-V SoC 获得 MicroPython 实验性移植;GitHub 上已出现 mainline Linux 启动尝试(baochip-linux)、裸机 DOOM 移植(baochip-doom)与裸机 C SDK(dabao-sdk)。一周内聚集”移植 Linux + 跑 DOOM + 出 SDK”,是 RISC-V 开源硬件社区活跃度的典型样本。

2.3 尊界 V800 智能座椅搭载奕斯伟 RISC-V 车规级 AI MCU

日期:2026-08-10　来源:快科技 / 凤凰网

鸿蒙智行尊界 V800 亮相,其全主动自适应智能座椅核心算力由奕斯伟计算 EAM2011 承载——国内首颗支持轻量级 AI 应用的车规级 MCU,搭载自研 32 位 RISC-V 内核,完成全链路本土化研发与量产。这是国产 RISC-V 车规芯片规模化上车的标志性案例。

2.4 第五届滴水湖中国 RISC-V 产业论坛预告(8 月 13 日举行)

日期:2026-08-07(公告)　来源:新浪财经

第五届滴水湖中国 RISC-V 产业论坛定于 8 月 13 日举行,10 款国产先进芯片集中亮相(具体成果见下期周报)。

三、国内团队动态

3.1 芯来科技:资本化推进 + 调试工具链生态 + 蜂鸟 FPGA 修复

日期:2026-08-06 ~ 08-11　来源:新浪财经 / Nuclei-Software GitHub

三条线并进:8 月 10 日向全国股转系统申报新三板创新层并定向募资 4200 万元;8 月 11 日新增 lauterbach-startup 仓库(Lauterbach TRACE32 调试器启动脚本,国际调试工具链适配);e603_hbird(蜂鸟 E203 相关)合入 DDR 时钟层次与 bitstream 等 FPGA 修复(8/6-8/7)。”IP 龙头资本化”与”生态工具链”双线同步。

3.2 开芯红(香山 IP 商业化主体):超亿元种子轮,国资+头部产投共同加持

日期:2026-08-11/12　来源:观点网 / 新京报

开芯红完成超亿元种子轮融资,资金投向香山 IP 核架构升级;投资方阵容随后披露:国开科创、诚通科创、中科创星、中关村科学城、启航基金、国泰创投等国资与头部产投机构。香山 IP 商业化同时获得国家级政策资本与属地产业资本背书(本周两日连续报道,合并为一条)。

3.3 奕斯伟计算:车规上车 + 消费级 AI 私有云双线落地

日期:2026-08-10　来源:快科技 / 网易(聚合) / 湖北经信厅(聚合)

奕斯伟本周多条动态叠加:车规侧 EAM2011 进入尊界 V800 智能座椅(2.3);消费侧与极空间(ZSpace)合作国产 AI 私有云 NAS,图片素材 AI 处理全部本地运行;集团材料业务(奕斯伟材料)拟募资 65 亿元投向 12 英寸硅片扩产(2027 年首期投产)。”RISC-V+AI”在车规与消费两端同时兑现。

3.4 算能(SOPHGO):SophLiteOS 新增 AI Agent + 工具链密集修复

日期:2026-08-09 ~ 08-12　来源:GitHub sophgo/sophon-tools / zsbl

sophon-tools 窗口内多笔合入:SophLiteOS 新增 AI Agent 功能(含 pbmssm LLM 转发、picoclaw-web-chat 内嵌),把 LLM Agent 交互能力下沉到端侧系统工具链——配合 K230/SG 系列 RISC-V SoC,属”RISC-V 端侧 + LLM Agent”直接工程进展;另有 pota_update/pmemory_edit 安全修复、Docker 三镜像合并为单镜像(体积约 10GB)等。zsbl 构建系统优化:剥离 Linux-kernel 依赖、修复内置 dtb 增量重建。

3.5 进迭时空(SpaceMiT):K3 生态文档与端侧 AI 加速推进

日期:2026-08-06 ~ 08-10　来源:GitHub spacemit-com

docs-ros 更新 K3 机器人机械臂 ONNX 部署指南(#200);docs-buildroot 新增 K3 Secure Boot 指南;model-zoo-vision 用 eigen-spacemit + OpenBLAS 加速 YOLOv8-Seg mask GEMM(#64)。K3 的机器人/安全启动/端侧 AI 文档栈在 8 月第一周密集补全(注:K3 旗舰 SoC 将于 8/13 滴水湖论坛正式发布)。

3.6 平头哥(XUANTIE-RV):damo-rv-priv-ats 更新

日期:2026-08-06　来源:GitHub XUANTIE-RV/damo-rv-priv-ats

玄铁 DAMO(动态内存分配与保护?)RV Priv ATS 仓库更新:调整 config 目录结构(#21)、更新测试以使用 CSR 编码(#22,8/11)。属玄铁生态的权限与地址翻译侧持续迭代。

四、具身智能与机器人

窗口内无重大独立新闻。 邻近信号:奕斯伟 EAM2011 在尊界 V800 上的人体姿态识别应用(传感器感知+动态适配技术栈与机器人控制共用);算能 SophLiteOS AI Agent 为 RISC-V 机器人大脑提供更轻的软件基座;进迭时空 K3 机器人机械臂 ONNX 部署文档更新。8/13 滴水湖论坛预计有具身智能相关芯片新品发布,值得会后跟踪。

五、总结与趋势观察

  1. 规范侧进入评审窗口:RVA23.1/RVB23.1 公开评审启动,QEMU 11.1 落地 RISC-V 大端支持,规范到工具链的适配路径正在闭环。
  2. 国产 RISC-V 资本化加速:芯来申报新三板创新层(募资 4200 万)、开芯红超亿元种子轮获国资加持、奕斯伟集团 65 亿扩产——IP/芯片厂商密集对接一级与二级市场。
  3. RISC-V 车规与端侧 AI 规模化落地:EAM2011 上车尊界 V800、SophLiteOS 内建 AI Agent、奕斯伟 AI 私有云,国产 RISC-V 在”AI 落地”方向多点开花。
  4. 社区生态活跃度不减:6 美元 USB 开发板、DEF CON 徽章芯片的 Linux/DOOM/SDK 生态、Dmitry.GR 的 RISC-V 反思长文引发行业讨论——既有低门槛硬件带来的新鲜血液,也有对架构底层的严肃审视。
  5. 前瞻:8/13 第五届滴水湖论坛(10 款国产芯片集中亮相,含进迭 K3、蓝芯 LX500 服务器 CPU、特普斯 EA6530 等)是下周期最重要的产业观察窗口。
