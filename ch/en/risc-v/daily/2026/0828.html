I. Open-Source Community and Software Ecosystem

1.1 RISC-V International Publishes Batch of World RISC-V Days 2026 Global Event Recaps

Date: 2026-08-28 (Beijing Time, UTC 08-27 18:32)　Source: riscv.org blog (Turin), Graz, Tel Aviv, Boston, etc.

RISC-V International published 10 World RISC-V Days 2026 event recap reports in a single batch within the window, covering 10 cities worldwide including Turin, Italy; Graz, Austria; Tel Aviv, Israel; Boston, USA; Gujarat, India; Nairobi, Kenya; Buenos Aires, Argentina; Bangladesh (Mymensingh, Dhaka); and Heraklion, Greece. Key points: The Turin stop (February 26, Politecnico di Torino, over 225 registered attendees) focused on benchmark comparisons, fully open-source chip development, and emerging technologies such as FLOW PPU; the Graz stop (February 24, Graz University of Technology, nearly 100 attendees) covered CHERI security, reconfigurable and scalable SoCs, hardware accelerators, CPU design and benchmarking, and discussed NXP’s RISC-V involvement and the future of RISC-V in Europe; the Boston stop (February 27, Red Hat) was held during a blizzard and included hands-on Fedora and AI sessions. This batch of recaps demonstrates that RISC-V community day events have become a regular fixture spanning six continents.

II. Product and Ecosystem News

2.1 USB-C Deskradar: An Open-Source ADS-B Flight Tracker Based on ESP32-C3 (RISC-V)

Date: 2026-08-27　Source: CNX Software

CNX Software reported on the open-source project USB-C Deskradar: a desktop ADS-B flight tracker based on the Espressif ESP32-C3FH4 (single-core 32-bit RISC-V, up to 160 MHz, 400KB SRAM, 4MB Flash), featuring a 1.28-inch 240×240 round TFT display that shows nearby flights (heading, speed, callsign, altitude, aircraft type) in real time via a sonar-style radar interface. Data comes from the adsb.fi or OpenSky Network open APIs, and it supports a Wi-Fi provisioning portal, airport runway overlays, and a 3D-printed enclosure (STL open-sourced). The project is open-sourced on GitHub (arvis91/deskradar, MatixYo/ESP32-Plane-Radar) and has been picked up by Chinese vendors on AliExpress as a cheap desktop gadget. This is a maker hardware and RISC-V MCU application case, reflecting RISC-V’s penetration into low-cost IoT terminals.

III. Domestic Team Updates and Deep Dives

3.1 Sophgo: CV84X6 Official Specs Land, Toolchain Densely Merged

Date: 2026-08-27　Source: sophgo/sophon-tools, sophgo/sophon-demo

The Sophgo sophon-tools window merged roughly 15 commits, with the core event being the landing of official CV84X6 specs (PR #152, bmssm 2.3.4 / sophliteos 2.2.3): compute specs 64T/32/2, display name set to CV84X6, and CPU spec clock frequency corrected from 2.5GHz to 2.6GHz per the official spec table (v2.2.4). Combined with yesterday’s daily report on large-scale CV84X2 adaptation (get_info v1.5 filling in 19 metrics, etc.), this confirms that the CV84X family has multiple models, with official specs gradually being solidified into the toolchain. Accompanying changes in the same period: CV84X2 adaptation tool version numbers completed, single-source-of-truth version numbering refactor (root release prohibited from passing version numbers), bmssm added Prometheus metric forwarding (disabled by default, token authentication, v2.2.2), reasonix automatically strips debug info before embedding and embeds deb packages by default, sophliteos agent WebSocket switched to same-origin addressing; sophon-demo added a ResNet example adapted for BM1684X2 (SE13-64 single board). Sophgo is paving the way for monitoring, operations, and example software stacks for the new CV84X series.

3.2 XiangShan: 66 Commits, Microarchitectural Performance Optimization and Verification Analysis in Parallel

Date: 2026-08-27　Source: OpenXiangShan org commit search

OpenXiangShan had roughly 66 commits in the window, with performance optimization and verification analysis proceeding on two parallel tracks. On the optimization side: added RVV string microbenchmarks (rvv-string-bench #85); IFU/ICache instruction alignment path optimization (#6220); MMU alignment of TLB flush latency caused by CSR changes (#6421); cpu-o3 avoids redundant ROB scans and FTQ copies (#1067); fcmp treats FLTQ/FLEQ as quiet comparisons (qNaN does not set NV); codegen generates block copies for single-dimensional array assignments (#125). On the verification analysis side: dcache bank conflict analysis scenarios and code landed, analysis No. 4636 wrapped up, difftest filled in KMHV3 for XSTileDiffTop/NoCDiffTop, csrc switched to generating C++ opcode encodings from Opcodes.scala, NEMU references and ready-to-run synchronized updates, and routine nix dependency upgrades. The “research analysis accumulation + microarchitectural polishing” pattern of activity continues, with no new architecture-level changes.

3.3 SpacemiT: K3 AVL Documentation and RL Benchmark Tooling Polish

Date: 2026-08-27　Source: spacemit-com/docs-chip, spacemit-com/model_zoo_rl, spacemit-com/ai-sdk

Combined with yesterday’s K3 BSP v1.0.7 OPP table efuse calibration optimization, the AVL documentation is part of the supporting work for K3 power and voltage management. Activity volume was low for the day, consisting of ongoing documentation and toolchain polish.

IV. Embodied Intelligence and Robotics Special Section

4.1 MIPS Becomes RISC-V International Premier Member, Leading Open Standards for Physical AI

Date: 2026-08-27　Source: Business Wire (republished by Yahoo Finance)

MIPS (now “MIPS, by GF” under GlobalFoundries) announced its promotion to RISC-V International Premier Member, with its SVP and CTO Yankin Tanurhan appointed Vice Chair of the RISC-V International Board of Directors. The company will play a leading role in open standards and semiconductor technologies for physical AI platforms spanning aerospace, AI, automotive, industrial, and intelligent edge; MIPS is currently active in multiple SIGs and working groups including Automotive, Functional Safety, Crypto, Vector, and Documentation, aligning RISC-V standards work with its differentiated microarchitecture and custom silicon solutions. RISC-V International CEO Andrea Gallo welcomed its continued contributions on high-throughput real-time platforms. This event directly binds “physical AI open standards” to the RISC-V governance layer and is the most important ecosystem signal in the embodied intelligence direction for this window.

No other new hardware/product events occurred in the embodied intelligence direction during this window (08-27 08:18 ~ 08-28 08:18): the media digestion period following the close of the 2026 World Robot Conference (August 19–24) continues, and yesterday’s daily report already covered Tiangong Omni’s double championship and the H1 humanoid robot shipment report; on August 27, MERICS published a China-themed analysis on “humanoid robots + decarbonization + platform economy” (policy perspective, not involving RISC-V, included only as industry background reference, not covered in the main text).
