II. Product and Ecosystem Developments

2.1 OrcSDR: Handheld full-featured SDR open-source project based on ESP32-P4 (RISC-V) (09-06)

Date: 2026-09-06　Source: Notebookcheck, OrcSDR GitHub repository

The open-source project OrcSDR combines the M5Stack Tab5 (a 5-inch handheld tablet powered by the dual-core RISC-V Espressif ESP32-P4) with an inexpensive RTL-SDR USB receiver dongle to form a PC-free handheld software-defined radio device: the ESP32 handles raw RF stream processing, audio demodulation, and real-time rendering of spectrum/waterfall displays on the touchscreen. Tested scenarios include real-time ADS-B aircraft transponder tracking, Meshtastic/LoRa off-grid coverage verification, 2.4GHz Wi-Fi channel congestion auditing, and P25 digital emergency communications demodulation; deployment is via one-click flashing of a precompiled image using the M5Burner browser tool. The report notes it fills the price gap between tens-of-dollars computer TV dongles and $650 commercial digital scanners (such as the Uniden SDS100), targeting field operations, search and rescue, and radio enthusiasts. The project is another landing case for RISC-V application processors in real-time signal processing scenarios, and continues the ecosystem narrative of the ESP32-P4 as a high-performance MCU-class processor that can “do heavy lifting without Linux.”
