一、内核与版本动态

1.1 网络栈安全修复：DHCP 服务器选项边界检查合入，#11323 关闭（10-10）

日期：2026-10-10 17:20（合入时间）　来源：PR #11858、Issue #11323

DHCP 服务器选项解析的缓冲区边界检查提案（#11858，单文件 +63/-33、两笔提交——边界检查与 clang-format 整理）由维护者合入主线，缺陷单 #11323（解析选项时对数据包缓冲区越界读取，由安全研究者上报）随之关闭。修复在选项解析前增加边界校验，消除越界读取路径；该案 10-08 开出、经节后队列消化后进入合入位，为窗口内网络侧首笔安全类修复。

1.2 STM32 全系 BSP 栈 8 字节对齐修正合入（10-10）

日期：2026-10-10 17:20（合入时间）　来源：PR #11841、Issue #7527

全系 STM32 BSP 栈对齐修正合入（#11841，作者 avm1234567，110 文件 +220/-220）：各 BSP 链接脚本与模板的 .stack 段由 ALIGN(4) 统一改为 ALIGN(8)，满足 ARM AAPCS 对公共函数边界处栈指针对齐的要求。修正援引 2023 年 5 月开出的缺陷单 #7527（全系 STM32 链接脚本问题；该单目前仍为开放状态，未随本次合入自动关闭）。

1.3 C++ 全局构造兼容修复合入：cplusplus_system_init 补走 .init_array（10-11）

日期：2026-10-11 16:11（合入时间）　来源：PR #11856、Issue #11778

C++ 运行时兼容修复合入（#11856，作者 cms19859230182-lang，4 文件 +60/-6）：新版 GCC 将 C++ 全局构造函数放入 .init_array 段，而既有初始化流程仅扫描 ctors_start/ctors_end 区间，导致未合并该段的部分 BSP 漏跑构造；修复补走 __init_array_start/__init_array_end（弱符号声明），并跳过已落入 ctors 区间的重复条目。关联缺陷单 #11778（多 BSP 的 C++ 自动构造支持异常）关闭。

1.4 USB CDC VCOM 环形缓冲别名缺陷修复合入，#11739 关闭（10-11）

日期：2026-10-11 17:37（合入时间）　来源：PR #11770、Issue #11739

USB CDC 虚拟串口修复合入（#11770，作者 Finder16，单文件 +47/-6、两笔提交）：旧实现将内嵌环形缓冲直接挂到 serial_rx，Serial V2 按串口 FIFO 结构解释该指针——因环形缓冲恰为首成员而表面上可用，但 rx_cpt、rx_timeout 等字段实际错位；修复改为规范挂接并补充 VCOM 轮询接收支持。该案 08-29 开出、经多轮评审后合入主线，缺陷单 #11739 关闭。

1.5 utest 性能测试时钟依赖修复合入（10-11）

日期：2026-10-11 15:59（合入时间）　来源：PR #11813

测试框架修复合入（#11813，作者 CYFS3，2 文件 +8/-1）：修复 utest 性能测试对固定时钟计时的依赖，并加固测试构建守卫，降低不同板级与仿真环境下的误报。

1.6 RISC-V 向量：vstart 恢复顺序修正提案进入评审（10-10 ~ 10-11）

日期：2026-10-10 13:37 ~ 10-11 17:15（创建与更新）　来源：PR #11861、Issue #11786

RISC-V 向量上下文修正提案进入评审（#11861，作者 PiyushPatle26，4 文件 +187/-5）：RESTORE_VECTOR 此前在 vsetvl 之前恢复 vstart，而向量配置指令会将其清零、导致重启索引丢失；修复把恢复动作移到配置指令之后，并在 qemu-virt64-riscv 增加覆盖零/非零 vstart 与 vl、vtype、vcsr 的回归用例（汇编探针 + C 用例）。维护者 10-11 评审确认修法正确、建议先解决测试并发问题并补验证证据，作者当日已推送修正提交。同作者推动的 OSPP 2026 议题「RISC-V 惰性 FP/RVV 上下文切换」（#11786）窗口内同步更新实现计划。

1.7 netdev ping 统计除零缺陷获认领，修复提案新开（10-11）

日期：2026-10-11 22:10 ~ 23:05（认领与提案时间）　来源：Issue #11852、PR #11862、PR #11853

netdev ping 缺陷的修复脉络在窗口内明显推进：缺陷单 #11852（10-05 上报；目标不可达时 received 为 0，平均值除法触发 x86 SIGFPE / Cortex-M 除零，杀死 shell 线程）于 10-11 晚间由贡献者 ymj0440 评论认领、随即开出提案 #11862（单文件 +1/-1）；此前同类提案 #11853（作者 r3wretrhy，10-06 开出）已于 10-07 获评审通过（LGTM）但尚未合入。两案并行，待维护者择一。

1.8 Next RISC-V 大重构提案窗口内再次刷新（10-10）

日期：2026-10-10 19:18（最新提交时间）　来源：PR #10320

大重构提案「Next RISC-V」（#10320，作者 GuEe-GUI，166 文件 +15175/-2614）窗口内再次刷新：头部提交更新为「[libcpu][risc-v] Refactor the RISC-V architecture port」，为 10-08 变基后的又一次推送。提案累计评论已满百条，集成范围覆盖 S-mode RT-Thread / RT-Smart、Sv32~Sv64 MMU、AIA / CLIC / PLIC 中断控制器与 T-Head 平台合并等，仍在开放评审。
