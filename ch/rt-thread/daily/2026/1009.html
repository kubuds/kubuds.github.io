一、内核与版本动态

1.1 节后开发恢复：主仓库单日下午密集开出四条新提案（10-08）

日期：2026-10-08 12:51 ~ 17:23（北京时间，创建时间）　来源：PR #11855、PR #11856、PR #11857、PR #11858

节后首个开发日下午，社区在主仓库集中开出四条修复提案，均附测试说明、处于评审：其一（#11855，12:51，单文件 +3/-0）修复重置组件与日志组件同时启用时的构建错误——日志兼容宏将 assert 无条件下定义为 ASSERT，重置控制器结构体中的同名成员被宏展开导致编译失败，方案为在使用处取消该宏；其二（#11856，15:36，单文件 +40/-4）修复 C++ 全局构造缺失——新版 GCC 将 C++ 全局构造函数移入 .init_array，而系统初始化仅遍历旧构造区间，方案为补跑 .init_array 区间并做重叠去重，已在模拟器平台完成构建验证（关联需求 #11778）；其三（#11857，16:32，两提交，单文件 +64/-41）调整带颜色日志的复位顺序，避免颜色控制码落到下一行、shell 提示符配色错乱（关联需求 #11296）；其四（#11858，17:23，单文件 +63/-33）为 DHCP 服务器选项解析补充缓冲区边界检查，修复畸形报文越界读风险（关联需求 #11323）。四条中三条出自同一位节前活跃贡献者（近期有 ESP32-C6、CH32V003 等 BSP 合入记录），当日均触发格式化与内存对比流水线。

1.2 评审队列观察：老提案复核确认主线已含同类修复（10-08）

日期：2026-10-08 14:22（北京时间，复核评论）　来源：PR #11499

主仓库窗口内无新合入（主线上一次合入仍为 10-03 12:59 的网络协议栈），存量提案有两处动态：6 月开出的内核同步链表日志防护提案（#11499）作者复核指出，冲突源于上游提交（超时唤醒归属修复）已在同一位置补充空指针判断，主线已包含该修复，提案后续处置待维护者评估；DHCP 报文头文件补充提案（#11835）触发一次自动化内存对比复查，无实质推进。此外，RISC-V 大重构提案（#10320）窗口内无新增评论，最近动作仍为 10-08 上午的变基刷新（已见假期周报）。

二、官方与社区活动

2.1 〖2026嵌入式大赛〗烟雾火灾报警监测系统作品发布（10-08）

日期：2026-10-08 17:21（发布时间）　来源：论坛文章 0e815ddfc029ea9c

2026 嵌入式大赛窗口内再添一份完整作品：基于恩智浦 FRDM-MCXA346 与内核 5.2.2 的烟雾火灾报警监测系统。系统以 MQ-2 采集烟雾浓度（ADC）、DHT22 采集温湿度（单总线），实现 OLED 三页显示切换、蜂鸣器与继电器联动、长按消音、回差阈值防抖与自动恢复，并提供多条 MSH 调试命令与电脑端仪表盘（实时曲线、CSV 记录、远程测试控制）。方案采用硬件抽象、业务与显示三层结构及告警状态机设计，开发环境为 Keil MDK-ARM。该帖延续节末以来大赛作品密集发布的节奏——同期已有智能实验室管理终端、GD32H759 电机控制与 Edgi-Talk 显示配置指南等作品（已由假期周报收录）。

三、生态与厂商适配

3.1 env 工具合入 #300：离线 SDK 软件包跳过 Git 更新（10-08）

日期：2026-10-08 20:10（合并时间）　来源：env PR #300

工具仓库 env 窗口内合入一笔打包管理修复（#300，单文件 +7/-0）：SDK 内手动管理的离线软件包没有独立 .git 目录，包更新时 Git 命令会在父仓库误执行；修复为在仓库校验前检查软件包目录的 .git 并跳过离线源码，同时兼容以 .git 文件形式存在的 worktree 与子模块。该笔由社区贡献者提交、创始人当晚合并，是工具链仓库节后的首笔合入（上一笔为 10-04 合入的 #299，WebUI 与插件工作流增强）。

3.2 RT-Thread Studio：Gino Pi SDK 提交五笔，补齐 LVGL 8/9 双版本支持（10-08）

日期：2026-10-08 16:30 ~ 17:31（提交时间）　来源：Gino Pi 板级支持包仓库

RT-Thread Studio 的 Gino Pi 板级支持包（兆易创新 GD32H77D，Cortex-M7 最高 600MHz，32MiB SDRAM、720×720 MIPI DSI 屏，基于内核 5.3.0，内置 17 个外设与应用工程）在窗口内集中提交五笔：显示框架扩展为 LVGL 8/9 双版本（按版本宏选择包）、新增独立 LVGL 8.3.11 示例、修正版本宏解析顺序、将随板 GD32 SDK 库标记为非托管（避免被包管理器误更新），并同步英文文档、补充 MDK 工程生成步骤。该板卡为 10-01 商城发售的联合产品，SDK 侧在发售窗口后快速补齐显示与文档能力。

3.3 软件包：esp-idf 适配仓库恢复合入，补齐 ESP32-C6 scons 编译源码（10-08）

日期：2026-10-08 17:28（合并时间）　来源：esp-idf PR #17

芯片适配包仓库 esp-idf 窗口内完成一次实质合入（#17，4 提交、332 文件、+48463/-5146）：补齐 ESP32-C6 所需的 scons 编译源码，贡献者在 ESP32-C6-DevKitC-1 实机编译烧录后进入 msh 验证；该笔合入 rtt-dev 开发分支，为此仓库自 2023 年末以来首度恢复合入。合入后维护者在评论中提议跟进更新 ESP-IDF 版本，贡献者回应计划升级至 6.1。乐鑫 C6 支持链路（BSP 合入、SPI 按需编译提案在审、scons 编译源码、包索引版本提案 #2043 在审）在节前节后连续推进，多个层面同时展开。

3.4 厂商下游：GD32 仓库新开 GD32G553 DMA 支持提案 #72（10-08）

日期：2026-10-08 10:44（创建时间）　来源：GD32 下游仓库 PR #72

兆易创新 GD32 板级支持仓库窗口内开出新提案（#72，单提交、16 文件、+2571/-50）：为 GD32G553 补齐 SPI、I2C 与 UART 的完整 DMA 支持，含 I2C2 的 DMAMUX 配置、UART0 ~ 5 全量通道、SPI G5x3 兼容性与 Keil 编译器兼容修正；作者以 GCC 与 Keil 零告警编译、I2C-AT24C02 EEPROM DMA 实测通过，测试板为 GD32G553Q-EVAL。提交当日编译机器人报告有 BSP（gd32_arm）编译失败，待修复与评审；该仓库此前一笔合入为 09-28（PR #71）。

四、行业应用

4.1 「知手同行」手语教学机器人开源发布：MaixCAM2 + Titan Mini + AmazingHand（10-09）

日期：2026-10-09 00:10（北京时间，项目材料发布提交）　来源：开源仓库 asungod/amazinghand

topic:rt-thread 生态新增一个手语入门教学机器人开源项目「知手同行」，教学应用与项目材料于窗口内发布。系统由三部分组成：MaixCAM2 视觉节点完成手部关键点获取与手型、课程步骤判定；Titan Mini 控制板（瑞萨 RA8P1 平台，运行 RT-Thread 固件）承担通信与机械动作执行，固件含总线舵机驱动、动作安全门控与语音关键词识别模块；AmazingHand 机械手执行实体示范。课程共 13 项（初级 3、中级 4、高级 6），配套浏览器练习界面、分步反馈、练习记录与文字沟通卡，随附技术报告、验证材料与竞赛讲解材料；项目内部文档同时披露当前推进边界（视觉节点串口链路已真机跑通、控制板固件已完成编译，两板联调与舵机闭环等仍在推进）。该板卡方向的同类社区项目此前有端侧声学事件检测（09-30 日报收录）。
