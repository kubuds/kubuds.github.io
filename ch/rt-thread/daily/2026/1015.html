一、内核与版本动态

主仓库窗口内完成 9 笔合入与 1 笔 RISC-V 重构提交，为近一周最密集的合入批次；评审侧 8 笔在审提案与多条缺陷单同步更新。

1.1 Next RISC-V 提案新提交：RISC-V 架构移植重构、统一 RV32/RV64 公共层（10-15）

日期：2026-10-15 11:51（提交时间）　来源：PR #10320、重构提交 6bf3686

RISC-V 大重构提案（#10320）窗口内推送一枚大型重构提交「[libcpu][risc-v] Refactor the RISC-V architecture port」：引入可选的 RISC-V 统一公共层（RV32/RV64），以 ARCH_RISCV 与 ARCH_CPU_64BIT 完成架构与 XLEN 选择，统一 context、trap、MMU、cache、timer、SBI、SMP 与 ISA 处理，新增 PLIC、CLIC、ACLINT、APLIC 与 IMSIC 支持，并建立物理 HART ID 到逻辑 CPU ID 的映射表；保留 T-Head 厂商覆盖分支。qemu-virt64-riscv 成为首个接入新公共层的 BSP（同一目录支持 RV32 与 RV64 S-mode），未选用 RT_USING_RISCV_NEW_COMMON 宏的既有 BSP 继续沿用 legacy_common / common64 路径。提交后自动流程复跑（格式通知、评审分配、membrowse 内存报告）；RISC-V 调整跟踪单 #11246 同步刷新（11:52）。提案维持开放。

1.2 网络栈修复批次合入：ping 统计除零与末包延时两案接连落地（10-14 ~ 10-15）

日期：2026-10-14 09:33 ~ 2026-10-15 09:10（合入时间）　来源：PR #11853、PR #11866

netdev 组件窗口内合入两笔 ping 相关修复：其一（#11853，10-14 合入），修复目标不可达时 ping 统计除零导致 shell 崩溃的问题，关联缺陷单 #11852 同日关闭；其二（#11866，10-15 上午合入），修正末包延时逻辑——原循环判断恒假导致最后一包后仍补时延、且延时为零时仍调用 rt_thread_delay(0) 返回非法参数，改为记录实际耗时、仅非末包且延时大于零时调用，关联缺陷单 #11865 同日关闭。同方向早期提案 #11862 已关闭未合入。

1.3 内核与 USB 修复批次合入：calloc 溢出与 USB host 接口数校验加固（10-14）

日期：2026-10-14 09:28 ~ 10:17（合入时间）　来源：PR #11848、PR #11822

内核侧修复 calloc 整数溢出问题（#11848），由社区贡献者提交并合入。USB 侧完成 legacy USB host 加固（#11822）：针对「host 直接信任设备上报接口数量、可触发越界访问」的缺陷单（#11288）补上接口数上界判断与接口枚举、清理路径的边界处理，两笔提交（接口数校验澄清、枚举与清理收口）同步合入，缺陷单同日关闭。

1.4 多厂商 BSP 与驱动批次合入：ra6w1、ESP32-C3、STM32H723、RISC-V 向量恢复等（10-14）

日期：2026-10-14 09:13 ~ 09:44（合入时间）　来源：PR #11814、PR #11847、PR #11851、PR #11861、PR #11855

维护者集中合入多笔厂商 BSP 与驱动更新：瑞萨 ra6w1 优化系统资源分配（主线程栈调整为 4096，RC 提交，#11814）；乐鑫 ESP32-C3 修复 Windows 路径下 IRAM 通配符匹配与蓝牙链接脚本误匹配问题（#11847）；STM32H723-DM-MC02 新增 SPI6 BDMA 支持（#11851）；RISC-V 向量单元修复配置后 vstart 状态恢复（#11861）；components/drivers reset 框架修复与 ulog 同时启用时的构建错误（#11855）。

1.5 在审提案集中获维护者评审：lwip 宏控制、ESP32-S3 BSP、rt_kprintf 修复、STM32 以太网 ops（10-14 ~ 10-15）
