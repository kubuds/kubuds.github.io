一、内核与版本动态

1.1 主线一晚集中合入三笔：ESP32-C6 与 CH32V003 BSP、IAR 模板修复（09-28）

日期：2026-09-28 22:19 ~ 22:22（北京时间，合入时间）　来源：PR #11836、PR #11838、PR #11843

维护者 Rbb666 在窗口内约三分钟内完成三笔合入。其一（#11836）乐鑫 ESP32-C6-DevKitC-1 板级支持（9 笔提交、40 个文件、+9598/-50）正式进入主线：含 bsp/ESP/ESP32_C6 完整板级工程（构建配置、IDF 适配层 idf_port、链接脚本与证书包）、ESP 共享驱动与 Kconfig 的适配更新及 CI 接线；该提案 09-25 凌晨提交、约四天后合入，本笔另并入一处 CH32V203 SConstruct 调整。其二（#11838）沁恒 CH32V003F4P6-EVT 板级支持（5 笔提交、47 个文件、+9258）合入：RISC-V 内核 RV32EC、48MHz、16KB Flash，默认 UART1 进 msh，此前已于 09-25 进入评审。其三（#11843）修正 5 个 BSP 的 IAR 工程模板：模板 ewp 的链接配置文件原先指向其他开发机的绝对路径，统一改为 $PROJ_DIR$ 相对路径（+7/-7，涉及 asm9260t、mm32f3270-100ask-pitaya、stm32f103-100ask-mini 等板卡）。

1.2 ESP32-S3-DevKitM-1 BSP 提案进入评审：需补齐软件包依赖（09-28 ~ 09-29）

日期：2026-09-28 19:04（创建）~ 09-29 10:18（最近更新）　来源：PR #11844、PR #11816

同一贡献者（cms19859230182-lang）在窗口内为乐鑫 ESP32-S3-DevKitM-1 提交全新 BSP 提案（#11844）：6 笔提交、44 个文件、+6862/-31，新增 bsp/ESP/ESP32_S3 与 libcpu/xtensa/esp32s3，单核镜像，UART0（GPIO43/44）进 msh，Flash 8MB DIO 80MHz；提案注明该板为 Xtensa LX7 架构、非 RISC-V，不能沿用 ESP32-C3 的工具链与中断接法，所配工具链为 xtensa-esp32s3-elf GCC 12.2.0。评审中维护者指出仍有编译与软件包依赖问题（09-28 22:18），提交者已在 09-29 上午回应并着手修订。另，ESP32-C3 的 Windows 构建修正提案（#11816，09-21 提交）在 09-29 上午有提交者跟进评论，仍处评审。

1.3 RT-Thread Env 工具修复 Unicode 与非法路径处理（09-28）

日期：2026-09-28 21:07 ~ 21:10（提交与合入时间）　来源：RT-Thread/env PR #298

env（Windows 侧开发工具）在窗口内合入修复 #298：移除仅允许 ASCII 的 BSP 路径校验，使 Env 命令可在中文等 Unicode 工作目录下正常使用；同时修正资源管理器右键菜单在磁盘根目录下的路径处理、选定路径不存在时直接终止启动，并补充回归测试（含 Unicode 路径用例）。由项目创始人 Bernard Xiong 提交并合入，为 env 仓库自 09-16 以来的首笔更新。

1.4 官方新闻接口连续第四十日无新增（09-29）

日期：2026-09-29（核查时间）　来源：RT-Thread 官方新闻接口

官方新闻接口（rt_org 分类）返回的存档稿最新条目日期仍为 2026-06-17，窗口内无新增，连续第四十日停更；产品与活动信息继续由微信公众号、社区论坛与 GitHub 渠道首发。
