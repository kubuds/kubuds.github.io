一、内核与版本动态

1.1 netdev：修复无网卡环境 ping 空指针崩溃

日期：2026-08-27（09:04 北京时间合入）　来源：RT-Thread/rt-thread commit 14ef29af

主仓库窗口内合入一笔组件稳定性修复：fix(netdev): 修复无网卡时 ping 命令空指针崩溃，由社区开发者 zhangyuyang 提交（author 时间 08-26 14:19）、核心维护者 Rbb666 于 08-27 09:04（UTC 01:04）合入。问题根因：netdev_cmd_ping 中 netdev 回退到 netdev_default 后未判空，QEMU 无网卡环境下执行 ping 直接解引用 NULL 触发 data abort；修复后在回退路径补充空指针检查，提示无可用网卡并返回错误。改动集中在 components/net/netdev/src/netdev.c 单文件。这是 v5.3.0-beta 分支建立（08-24）后主分支的又一批低风险稳定性修复，与此前 HW Stack Guard、finsh 清理形成”整理期”节奏的延续。

1.2 瑞萨 BSP：SPI 驱动两笔修复合入

日期：2026-08-27（09:01 北京时间合入）　来源：RT-Thread/rt-thread commits 69c26789 / fcc4d6c0

同一时间点（09:01 UTC 01:01）由 CYFS 提交并合入瑞萨 BSP 两笔 SPI 驱动修复：其一 [bsp/renesas][drivers] Fix SPI runtime configuration，修复 SPI 运行时配置问题；其二 [bsp/renesas][drivers] Skip invalid chip select writes in SCI SPI，跳过 SCI SPI 中无效片选（chip select）写入。两笔均属 bsp/renesas/ 驱动层打磨，与 08-25 合入的 RA6W1 BLE OTA 镜像生成优化同属瑞萨 BSP 持续迭代序列（RA6W1 BSP 08-05 首版、08-11 二期补外设后，SPI 驱动层继续收尾），”先合骨架、后补驱动”特征延续。

3.1 canopennode-rtt：新增 LSS 运行时波特率激活

日期：2026-08-27（11:00 北京时间合入）　来源：wdfk-prog/canopennode-rtt commit 11d7e9eb

面向 RT-Thread 的 CANopenNode 集成软件包（wdfk-prog/canopennode-rtt）于 11:00 合入新功能 feat[canopennode][lss]: support runtime bitrate activation，支持 CANopen 节点运行时波特率激活。继 08-25 合入 LSS Store 配置持久化（含 EEPROM 存储层与 AT24CXX 解耦、启动持久化）后，这是该包 LSS 能力的第二期扩展。近两周该包保持稳定迭代节奏：08-17 GFC 协议诊断、08-19 ASCII 网关 MSH 控制台桥、08-20 SDO 块传输校验、08-24 EEPROM 存储诊断、08-25 LSS 持久化、08-27 运行时波特率激活，每周 2-3 笔功能提交，是当前 RT-Thread 第三方工业协议软件包中最活跃者之一。

四、行业应用

4.1 2026 RTOS 性能榜单出炉：RT-Thread 纳入八大 RTOS 独立评测

日期：2026-08-26（媒体刊出）　来源：电子工程专辑（经 Google News） / Beningo 官方报告页 / PX5 官方解读页

电子工程专辑 08-26 刊出「2026 年 RTOS 性能榜单出炉！」：Beningo Embedded Group（Jacob Beningo）发布《2026 RTOS Performance Report》，基于 Eclipse Thread-Metric 测试套件在真实 Cortex-M 硬件上对 8 款 RTOS 做独立对比——PX5 5.3.1、ThreadX 6.5.1、FreeRTOS 11.3.0、Zephyr 4.4.1、Arm Keil RTX5 5.9.1、RT-Thread、NuttX、Micrium uC/OS-III，含 9 项 native API 测试（调度、内存分配、消息、同步、中断处理与中断延迟等）与 POSIX pthread 基准、跨架构（M4F vs M33）与编译器（IAR vs GCC）影响附录。结论：PX5 连续第二年全场最快（native API 下 ThreadX 最高慢 30.2%、FreeRTOS 慢 80.7%、Zephyr 慢 45.3%）；RT-Thread 在 native 测试中最高较 PX5 慢 86.3%，POSIX pthread 口径下最高慢 94.6%（PX5 官方口径，POSIX 场景其原生实现占优）。对本报告的意义：其一，RT-Thread 被第三方独立评测纳入 8 强对比阵容，侧面印证其全球市场地位；其二，性能数据不及第一梯队，且 Beningo 报告对除 RT-Thread 外全部参测系统均标注固定版本（RT-Thread 未标版本），横向比较口径存在局限，具体结论建议参照原报告方法论后解读。

五、总结与趋势观察

  1. 主分支小步加固延续：netdev ping 空指针修复与瑞萨 SPI 两笔修复于 08-27 上午同日合入，v5.3.0-beta 建立后主分支继续以低风险稳定性修复推进，未见大型特性合入。
  2. 睿擎 Workshop 今日落地：本周官方口径最重要的观察点，窗口内无会前新报道，会后报道预计明日出现，届时核查官方新闻 API 与媒体侧。
  3. 第三方软件包生态活跃：canopennode-rtt 保持每周 2-3 笔功能提交节奏，LSS 运行时波特率激活为二期能力扩展；CANopen 工业协议方向值得持续跟踪。
  4. 行业地位与性能口碑并存：RT-Thread 纳入 Beningo 2026 RTOS 性能榜单 8 强对比，市场地位获第三方认可；但性能数据排名靠后且参测版本未标注，需辩证看待。
  5. 新闻面持续平静：官方新闻 API 连续第七日无新增，媒体侧仅电子工程专辑榜单报道一条，其余 gnews 命中均为拆词噪音。

局限性说明：电子工程专辑原站（eet-china.com）本机直连超时，榜单报道细节以 Beningo 官方页与 PX5 官方解读页交叉核实；RT-Thread 参测版本在官方报告中未标注，性能对比口径存在不确定性。
