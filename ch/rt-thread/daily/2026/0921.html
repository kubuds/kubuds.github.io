一、内核与版本动态

1.1 主仓库周一集中合入九笔提案：SDIO 双内存泄漏修复与网络主机名校验收紧（09-21）

日期：2026-09-21 09:28 ~ 10:18（北京时间，合入时间）　来源：PR #11782、PR #11806

窗口末尾周一上午，主线集中合入九笔提案，全部为评审队列中的存量修复与整理，无新功能级改动。分量最重的是网络组件对 AT 通道主机名处理的收紧：原实现把形似数字的主机名字符串按自身长度拷入十六字节栈缓冲，超长输入可越界写入，合入版本改为直接拒绝超长数字主机名。存储侧两笔均为 SDIO 内存泄漏：其一在处理部分 CIS 元组分支时申请了临时内存却未释放（关联缺陷报告 #11724），反复初始化与反初始化 SDIO 设备即持续泄漏；其二驱动注册节点仅在找到匹配卡时才释放，无卡或未匹配场景反复注册注销同样泄漏。两笔由同一位贡献者提交，其中第二笔即上期收录的提案，本期完成合入闭环。

1.2 板级与工具链补丁同批落地：GD32 串口引脚、STM32H7 接收 DMA 与 Rust 目标选择修正（09-21）

日期：2026-09-21 09:28 ~ 10:18（北京时间，合入时间）　来源：PR #11808、PR #11804

同批还包含四笔板级与工具链修补。STM32H7 通用 DMA 配置文件补上 UART4 接收侧通道定义，修复板级启用该通道后串口接收无法工作的问题，该笔与块设备分区日志格式符修正同属上期评审的三笔小型修复，本期全部落地。兆易创新 GD32 系列的 USART 初始化修正：发送引脚改为复用推挽、接收引脚改为上拉输入，替换此前把两脚都配成普通输出的错误别名实现，覆盖 E50x 至 F30x 多个系列。Rust 工具链的芯片目标检测修正 Cortex-M33 分支：此前固定返回软浮点目标，硬浮点板卡会拿到错误的库，现按硬浮点判定与 M4/M7 分支一致。另有 QEMU Linux 快速开始指引与文档中移除高危卸载命令两笔文档修正。

三、生态与厂商适配

3.1 RT-Thread Studio 配套升级至内核 v5.3.0，J-Link 调试器更新至 V9.76a（09-20）

日期：2026-09-20 17:36 ~ 17:50（北京时间，合并时间）　来源：SDK 索引仓库、内核源码仓库

RT-Thread Studio 配套在同一天完成两项升级。其一，SDK 索引与内置内核源码仓库同步切换到 v5.3.0：索引侧更新内核条目并完成版本合并，源码侧把内置内核更新到新版本，用户在开发工具内新建工程与安装 SDK 将使用新内核。其二，调试器构件仓库把 J-Link 升级到 V9.76a，并在索引中补录对应条目——上一次升级为 2025 年 7 月的 V8.48，本次属跨年度的版本跟进，对依赖 J-Link 的量产验证与工业调试环境更为相关。v5.3.0 内核于 09-10 发布，Studio 侧在十天后完成跟随。

3.2 STM32H7 器件支持包与 HAL 驱动包双发布：v1.10.7 与 v1.11.6（09-18）

日期：2026-09-18 12:58 ~ 12:59（北京时间，推送时间）　来源：CMSIS 器件包、HAL 驱动包

STM32H7 系列的两个基础支持包在窗口内同日发布新版本。器件包 v1.10.7 补齐 TIM23 与 TIM24 定时器实例定义、修正 GPIO 模式寄存器位定义的笔误与链接脚本注释编码、条件化处理一类编译器告警。HAL 驱动包 v1.11.6 一次性并入约二十笔上游同步，覆盖 USB 零长包处理、以太网十兆速率切换与接收时间戳上下文、SDMMC 超高速卡时钟上限、I2C 事务死锁、加密外设 AES-GCM 与 CCM 非整字输出、FDCAN 过滤器溢出防护、DMA 回调触发位反转与智能卡配置序列等。两包是微控制器工程新建时的高频依赖，本次以历史节点补齐与上游对齐为主，延续器件包侧近期的版本对齐节奏。

3.3 英飞凌 PSoC6 评估板 BSP 修复 PWM/ADC 问题，瑞萨 RA8P1 新增 OpenMV 发布工程（09-18 ~ 09-21）

日期：2026-09-18 ~ 2026-09-21（推送时间）　来源：PSoC6 评估板 BSP、RA8P1 Titan Mini BSP

Studio BSP 组织下两个厂商板级仓库有更新。英飞凌 PSoC6 评估板 BSP 由外部贡献者提交 PWM 与 ADC 宏及驱动的跨工程修正，与主线评审中的英飞凌 PWM 宏错配提案（#11802）同源，属该板级支持包的收口整理。瑞萨 RA8P1 Titan Mini 新增 OpenMV 发布工程与持续集成配置，为这款高性能 Cortex-M85 板卡补齐机器视觉应用的发布链路，与上期收录的图形化开发动向相互衔接。

3.4 GD32 下游仓库提交驱动更新提案，界面库 AWTK 持续提交（09-18 ~ 09-20）

日期：2026-09-18 ~ 2026-09-20（推送时间）　来源：GD32 下游仓库 PR #71、AWTK 仓库

兆易创新侧的下游板级仓库在窗口内提交一笔整体性驱动更新提案（09-20 提交，仍在评审），延续该仓库近一个月的板级支持补齐节奏；其主分支最新提交亦为驱动更新类改动，厂商侧自维护分支保持稳定推进。通用界面工具包 AWTK（标签为 RT-Thread 生态）窗口内有三笔提交，涉及界面描述文件加载、动图处理与文档更新，均属工具包自身通用改进，按惯例记为非专项生态参考。

四、行业应用

4.1 社区在 RK3576 板卡上跑通异构 AMP 网络：RT-Thread 独占一颗 A53 独立收发（09-21）

日期：2026-09-21 09:39（北京时间，更新时间）　来源：论坛长文 63207209b0514465

社区发布一篇 RK3576（NanoPi M5 板卡）异构多核实践长文：从 Linux 手里剥离一颗 A53 核心交给 RT-Thread，并把 GMAC1 以太网控制器整体搬到 RT-Thread 侧，完成独立网络收发（ping 通）。作者先证否了同芯片上 Cortex-M0 协处理器路径（架构级访问控制隔离，不适用），再在应用核方案上定位并修复三个根因——MDIO 时钟频率计算错误、PHY 参考时钟使能时序过晚、持续 ping 触发堆崩溃；芯片厂商 SDK 中该型号的 GMAC 硬件抽象层为空壳，需自行补齐移植项。文章附完整复现路径与遗留问题说明，对 AMP 场景下实时侧独立联网与边缘网关方向有直接参考价值，属社区少见的深度实践记录。
