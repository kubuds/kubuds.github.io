一、内核与版本动态

1.1 评审队列单夜新增八条提案：存量缺陷加固系列七连发，WCH CH32V203 板级支持补位（09-22）

日期：2026-09-22 18:03 ~ 18:31（北京时间，提案时间）　来源：PR #11820、PR #11827

窗口内评审队列单夜新增八条提案（#11820 ~ #11827），为近期最集中的一批提交。其中七条来自同一贡献者，构成一组系统性的存量缺陷加固系列：两线串行总线控制器与传输互斥（#11820，修复 #11524）、电源管理按设备挂起模式成对恢复（#11821，修复 #11046）、USB 主机接口数量边界（#11822，修复 #11288）、IPC 消息队列路径终止符边界（#11823，修复 #11292）、块设备逻辑分区越界读写（#11824，关联 #11286）、STM32 OpenAMP 接收缓冲边界与环形回绕（#11825，修复 #11299）、virtio 输入偏移校验（#11826，修复 #10379、#10380）。七条均引用数月前的存量缺陷报告，并附 GCC 16.1 主机构建与边界用例的验证说明，属对历史遗留问题的集中清理。第八条为沁恒 WCH CH32V203C8T6-EVT-R0 板级支持（#11827）：该型号为青稞 V4B 内核的 RISC-V 微控制器（64KB 零等待 Flash、20KB SRAM），主线此前无对应 BSP，提案补齐工程骨架、D6 向量表、链接脚本与看门狗示例，并修补官方 SDK 包对 D6 型号直接退出构建的问题。

2.1 工博会 Workshop 详情公布：10 月 13 日专场，25 套智能小车教具（09-22）

日期：2026-09-22（报道时间）　来源：AI 云资讯报道

行业媒体发布工博会现场 Workshop 的详细信息，为上期收录的招募稿（09-20）补上场次与内容细节：第 26 届中国国际工业博览会定于 10 月 12 ~ 16 日在国家会展中心（上海）举行，RT-Thread 睿赛德的「AI 端侧智能小车实操 Workshop」设在 10 月 13 日（周二）13:00 ~ 17:00。课程以动手实操为核心，2 人一组、配备 25 套智能小车教具，由资深工程师全程带教，流程覆盖硬件检测、系统启动、外设调试、实时操控、SLAM 建图、自主导航、相机标定、多模态视觉跟随至 AR 综合演练，涉及激光雷达、IMU 与深度相机的现场调试；现场另集中展出基于同源底座的工控设备、移动机器人、具身智能与飞控单元等实物展品。场次与报名信息以主办方后续公告为准。

三、生态与厂商适配

3.1 瑞萨 RA8P1 Titan Mini 优化 OpenMV 工程：SDRAM 时钟与内存池调整，推理耗时显著下降（09-22）

日期：2026-09-22 16:09 / 16:36（北京时间，提交时间）　来源：性能优化提交、性能数据更新提交

Studio BSP 组织下瑞萨 RA8P1 Titan Mini 仓库在窗口内推送两笔 OpenMV 工程优化提交。其一调整外部 SDRAM 时序与时钟配置（刷新等待参数、BCLKA 分频），并以源码覆盖方式补全 SDCLK 选择器的初始化顺序，修复芯片配置工具的已知限制；其二把片内 SRAM 的主垃圾回收池由 1344 KiB 扩至 1472 KiB，改善大模型工作区的内存布局。随提交同步更新的实测性能显示：Tiny YOLOv2 INT8 416×416 单次推理由 156.10 ms 降至 58.49 ms（约 2.7 倍），YOLOv8n 256×256 由 186.54 ms 降至 38.33 ms（约 4.9 倍），320×320 由 310.29 ms 降至 287.49 ms。该工程 09-18 刚补齐 OpenMV 发布链路与持续集成，本期为发布后的性能收口；电子工程专辑同日发布跟进报道（《1 GHz MCU + NPU，Python 开玩！Titan Mini 的 OpenMV 更新来了》），原站访问受限，链接见附录。

3.2 GDR 2026.03 发布：RT-Thread 调试助手框架补对象命令与帮助体系（09-22）

日期：2026-09-22（发布时间）　来源：GDR 2026.03

第三方 GDB 调试助手框架 GDR 在窗口内发布 2026.03 版本。该框架运行于 GDB 的 Python 解释器内，为 RT-Thread 与 FreeRTOS 固件调试提供三层支持：各实时系统自有命令树（如查看线程、定时器、堆）、内核对象美化打印器与便捷函数（以原生 GDB 表达式访问对象字段）。新版本为 RT-Thread 侧新增 rtt objects 对象汇总命令，并把堆与对象输出统一到中性渲染器；帮助体系升级为 git 风格的结构化命令树，逐项说明字段、用法、配置依赖与实现限制；同时修复初始化策略校验失败会直接终止 GDB 会话的问题。框架当前支持 RT-Thread 3.1.x / 4.0.x / 4.1.x，Cortex-A9 与 RV64 目标均已通过闭环验证，属 RT-Thread 第三方调试工具链的活跃项目。

3.3 GD32 下游仓库驱动更新分支推进：PR #71 刷新并进入评审互动（09-22）

日期：2026-09-22 13:37（北京时间，推送时间）　来源：PR #71

兆易创新下游仓库 gd32_rt-thread 的 update_driver 分支在窗口内推送一笔驱动更新提交，同步刷新评审中的 PR #71，仓库侧出现评审评论互动。该提案围绕 USART、SPI 与两线串行总线驱动的 GPIO 初始化版本更新展开，对旧版驱动文件做替换整理，属厂商自维护分支的持续工作，尚未回流主线。同组织 Zephyr 方向的仓库亦有推送，非本主题。
