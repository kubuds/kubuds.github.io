一、内核与版本动态

1.1 主仓库窗口内合入 4 个 PR：MPU 权限修复、PWM utest、瑞萨 CAN FD、net/sal 资源释放

日期：2026-09-01（09:05-09:39 北京时间合并）　来源：PR #11760、PR #11751、PR #11754、PR #11769

昨日 RT-Smart POSIX 兼容批次（PR #11732/#11733，13 笔提交）之后，主仓库今日上午再合入 4 个 PR（另含 1 笔 clang-format style 提交），工作日合入节奏恢复：

  • PR #11760（09:05）[net][sal]：修复套接字创建失败时 DFS v2 vnode 未释放的问题，属资源泄漏修复；
  • PR #11751（09:16）[bsp/renesas][drivers]：瑞萨 BSP 驱动支持可配置 CAN FD 操作，外设能力继续演进；
  • PR #11754（09:33）[utest][pwm]：新增可配置 PWM matrix 测试，并修复矩阵测试清理与超时问题；
  • PR #11769（09:39）fix[arm][cortex-m4]：澄清 MPU 权限表达式，cortex-M4 内核 MPU 权限配置表述修正。

与前一日面向 RT-Smart POSIX 兼容层的大批量合入不同，本批集中于内核细节健壮性：ARM cortex-M4 MPU 权限、网络套接字失败路径的资源释放、驱动可配置化与测试覆盖，未见大特性合入。

三、生态与厂商适配

3.1 packages：optparse 补充 v1.0.0 / v1.0.1 版本条目，新旧接口并存可选

日期：2026-08-31（16:55 合并）　来源：RT-Thread/packages PR #2032

昨日 packages 曾为 optparse 软件包恢复 v1.0.0 版本条目以回滚破坏性接口变更（v1.0.0 为 2 参数接口）。今日 PR #2032 进一步补充 v1.0.1 版本条目：两个 tag 均指向 3 参数接口提交（07a365d），与 v1.0.0 的 2 参数接口区分，用户可按接口需求在软件包索引中选择对应版本。索引层对接口兼容的管理进入”双版本并存”阶段。

3.2 生态参考：canopennode-rtt 社区 CANopenNode 集成包连续开发

日期：2026-08-31 ~ 09-01　来源：github.com/wdfk-prog/canopennode-rtt（附文档站 wdfk-prog.space/canopennode-rtt/）

社区仓库（2026-06-30 创建，C 语言）面向 RT-Thread 集成国际知名开源 CANopen 协议栈 CANopenNode，近期提交活跃：新增事件驱动主线调度（09-01 08:54）、高分辨率时间支持与 kconfig 运行配置菜单整理、默认对象字典与 demo 模块解耦（08-31）、RX 规则编译为粗粒度 HDR 过滤器（08-30）、SRDO 生成 J09/B09S 对象字典及 MCU 诊断 fixture（08-29）。该包目前独立于官方 packages 索引（未见提交 PR），关注后续是否进入官方软件包体系；工业/车载 CANopen 通信场景值得留意。

3.3 生态参考：兆易创新 gd32_rt-thread 合入 F503 外设驱动与 F207i BSP 升级

日期：2026-08-31（19:17 / 19:31 合并）　来源：GD32-MCU-IOT/gd32_rt-thread PR #58、PR #63

GigaDevice 官方下游仓库（gd32_rt-thread）窗口内由原厂工程师合入两笔 BSP 适配：PR #58 为 gd32f503v-eval 增补 USART / I2C / SPI / DMA 驱动；PR #63 升级 gd32207i-eval BSP 并适配 F20x 系列驱动。芯片原厂主导的 BSP 覆盖继续扩展（近两周已连续合入 305R/407V/470Z/470i/L23x/F527 等多款型号相关适配）。
