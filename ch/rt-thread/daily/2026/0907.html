一、内核与版本动态

1.1 三日零合入终结：周一晨间批次合入 4 个 PR，覆盖 mmcsd AC5 兼容、MPU Kconfig、eclipse 工具链、hpmicro C++ 构建

日期：2026-09-07（合入窗口 10:19 ~ 11:18 北京时间，即 02:19:23Z ~ 03:18:42Z）　来源：RT-Thread/rt-thread commits（PR #11690、PR #11766、PR #11762、PR #11777）

主仓库 rt-thread 结束自 09-03 #11776 以来连续三个窗口（三日）的零合入，周一晨间一小时内连续合入 4 个 PR：

  • #11690 [device][mmcsd] Fix Arm Compiler 5 build compatibility（CYFS3 提交，08-10 创建，队列中最久约 4 周）：系统性修复 AC5 编译 MMC/SD 与块设备代码的兼容问题——通用 SWITCH 命令名与部分芯片寄存器宏冲突（改名 MMC_SWITCH 并同步修改飞腾 Phytium SDIF 调用点）；为 ARMCC5 提供具名 SD 状态字段访问方式（其他编译器继续用匿名字段接口）；以显式 rt_list_entry 替代依赖 typeof 的块设备链表遍历；DFS 关闭时补充分区结构定义；清理 void * 指针运算。
  • #11766 [mprotect][kconfig] Add safe defaults for MPU region count options（RogerNext 提交，08-28 创建）：为 NUM_MEM_REGIONS / NUM_CONFIGURABLE_REGIONS / NUM_EXCLUSIVE_REGIONS 补充 Kconfig 默认值。此前开启 RT_USING_HW_STACK_GUARD 但未显式配置时，rtconfig.h 生成空宏（#define NUM_CONFIGURABLE_REGIONS），展开成非法 C 表达式（(2 + )、for (i = 0U; i < ; i++)），导致 cortex-m4/m7/m33 的 MPU 代码编译失败。
  • #11762 [tools][eclipse] Sync assembler include paths（wdfk-prog 提交，08-28 创建）：同步 eclipse 插件工程的汇编器 include 路径，官方工具链（eclipse 插件）构建一致性修正。
  • #11777 [bsp][hpmicro] wire CXX/CXXFLAGS from rtconfig into scons Environment（kaidegit 提交，09-01 创建）：hpmicro BSP（先楫半导体 HPM 系列）开启 RT_USING_CPLUSPLUS 时，scons Environment 未接 rtconfig 的 CXX/CXXFLAGS 而回退宿主 g++，C++ 组编译参数被当作单个未加引号参数导致构建失败；修复后将 CXX/CXXFLAGS 注入 scons 环境。

该批次与维护者 Rbb666 同日晨间的密集评审（见 1.2）同段发生，主仓库从「蓄积期」转入「合入 + 评审双活跃」；release 仍为 v5.2.2（2025-10-31），尚无新版本发布动作。
