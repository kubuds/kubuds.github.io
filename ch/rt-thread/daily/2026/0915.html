一、内核与版本动态

1.1 RISC-V 惰性 FP/RVV 上下文切换提案获内核维护者正面回应（#11786）（09-15）

日期：2026-09-07 提案提交，2026-09-15 10:23 维护者回复（北京时间）　来源：Issue #11786

该议题以 OSPP 2026 选题形式提出，指出现有 RISC-V 移植层存在两处结构性缺口：一是每次上下文切换都无条件保存与恢复完整 FPU 状态，即使线程从未使用浮点单元；二是完全不支持向量扩展 RVV，向量寄存器未纳入线程上下文，任何使用向量指令的线程其状态都会被上下文切换静默破坏。两点在既有议题 #10722 中已有记录。提案建议把扩展状态改为惰性保存与恢复，即仅在真正使用时才落地状态。维护者 Rbb666 于窗口内回复，认可这是很好的性能优化提案并欢迎提交 PR。该议题标签为 enhancement、Kernel、Arch: RISC-V，是窗口内唯一一条架构级方向性表态。

1.2 评审队列观察（一）：STM32N657 Nucleo BSP 单日四次强制推送修 CI（#11799）（09-14）

日期：2026-09-14 13:21 / 13:24 / 15:06 / 16:44（北京时间）　来源：PR #11799

意法半导体 STM32N657 系列的 stm32n657-st-nucleo BSP（84 文件，新增约 15340 行）在窗口内被作者连续四次强制推送（09-14 13:21、13:24、15:06、16:44），直接回应维护者「CI 问题需要修复下」的评审意见。该 PR 于 09-11 送审，评审人已指派 Liang1795、hamburger-os、wdfk-prog，第三方内存比对工具出具的报告中该板卡暂未列入比对目标。单日高频重推说明 CI 与评审意见闭环仍在进行，尚未进入合入阶段。

1.3 评审队列观察（二）：国民技术 N32H 三系列驱动扩展回应评审后重推（#11800）（09-14）

日期：2026-09-14 16:48（北京时间，强制推送）　来源：PR #11800

该 PR 在 bsp/n32/n32hxxx 下扩展 N32H47x_48x、N32H49x、N32H7xx 三系列驱动，覆盖 n32h487zgl7-evb、n32h497zgl7-evb、n32h760zil7-stb 三块板卡：共用驱动层新增 ADC、DAC、I2C、SPI 配置头文件，并扩展 drv_adc、drv_dac、drv_eth、drv_gpio、drv_hard_i2c、drv_nand、drv_qspi、drv_sdram、drv_spi、drv_usart、drv_wdt 等 29 个文件；两块 evb 另增 FEMC 时序表、ETH PHY 复位与 CherryUSB 配置。窗口内作者再度强制推送，并在评审线程中逐条回复自动评审提出的问题，包括把 I2C DMA 超时处理描述为独立改动、扩展 N32H7xx 的传输中止逻辑等。国产 MCU 原厂驱动补齐仍是评审队列的主要构成。

1.4 评审队列观察（三）：lwip 2.2.1 支持分支再度重推，第三方内存比对无变化（#11797）（09-15）

日期：2026-09-15 11:19（北京时间，强制推送）　来源：PR #11797

该 PR 为修复 #11588 引入 lwip 2.2.1 支持，验证用 BSP 为 bsp/nxp/imx/imxrt/imxrt1180-nxp-evk/m7，并开启 BSP_USING_ETH、RT_USING_SAL、RT_USING_NETDEV、RT_USING_LWIP。窗口内作者再度强制推送（commit 04a4e19b）；同期第三方内存比对工具（MemBrowse）对该 PR 出具报告，判定未引入内存占用变化。评审标签为 components，评审人 Maihuanyi。协议栈版本升级是工业与网关场景的常用链路，本期处于评审迭代期，尚未合入主线。

日期：2026-09-15 08:00（北京时间，聚合时间）　来源：电子工程专辑（聚合）

RT-Thread 睿赛德联合兆易创新正式发售 Gino Pi 开发板，首发优惠 80 元，同期发布 Gino Pi 新品讲解。该板卡此前已在 09-11 进入 RT-Thread Studio SDK 索引（GD32H77D-Gino BSP v1.0.0，包体 138 MB），本期由「可下载 BSP」推进到「公开发售」，是兆易创新与睿赛德战略合作（覆盖 GD32 全系，重点深化 GD32F5、GD32VW553、GD32H7 三条产品线）在开发板层面落地的首款硬件。原文页面在网络访问受限，价格与优惠幅度以聚合摘要为准，未获官方页面二次确认。

3.2 Gino Pi 硬件规格与技术底细：Studio BSP SDK 仓库公开资料（09-10）

日期：2026-09-10（SDK 收尾提交）　来源：sdk-bsp-gd32h77d-realthread-ginopi

由 Studio BSP SDK 仓库可确认板卡的实际形态：核心为 GD32H77DIW（Arm Cortex-M7，最高 600 MHz），25 MHz 晶振，控制台 UART1（PA2/PA3，115200-8-N-1），运行指示灯 PC4 每 500 毫秒翻转。外扩 32 MiB SDRAM（映射于 0xC0000000）与板载 8 MiB GD25Q64E QSPI Flash；显示为 720×720 MIPI DSI 屏（FL7707N，RGB565），触摸 GT911 走 I2C3；摄像头 OV7670（QVGA RGB565，DCI 加 DMA）；以太网 ENET1 RMII；Wi-Fi 由 GD32VW553 AT 模块经 UART4 提供；下载调试走 SWD（Studio 侧 DAP-Link / PyOCD，MDK 侧 CMSIS-DAP）。SDK 基于 RT-Thread 5.3.0，含 16 个外设与应用示例工程，覆盖 UART、I2C、SPI、QSPI Flash、SD 卡、CAN、PWM、RTC、SDRAM、USB 设备与主机、LVGL 显示与触摸、Wi-Fi、以太网、摄像头、MQTT 以及出厂综合演示，同时提供 Studio 与 MDK5 两套工程。整体定位为 H7 级图形交互与联网评估平台，明显向人机界面与多媒体应用倾斜。

3.3 软件包索引：STM32N657xx FSBL 索引提交合入主索引（09-14）

日期：2026-09-14 12:35（北京时间，合入时间；作者提交日期 09-10）　来源：commit d9b53de7

上期送审的 hal_sdk 目录 STM32N657xx FSBL 软件包索引（对应软件包索引仓库 PR #2041）已于窗口内合入，提交新增 peripherals/hal-sdk/stm32/stm32n657xx_fsbl/Kconfig 与 package.json 两个文件，并同步更新 stm32 目录 Kconfig 以挂载新条目。该软件包与主仓库送审中的 stm32n657-st-nucleo BSP 配套，意味着 STM32N6 系列 FSBL（首级安全启动加载）环节的资源在软件包侧先行就位，开发者可在包管理器中直接获取。软件包索引与主仓库 BSP 送审的先后配合，是近期 STM32 新系列导入的固定节奏。
