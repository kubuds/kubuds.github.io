一、内核与版本动态

1.1 NXP i.MX RT1180 EVK BSP 功能大更新：I2C DMA/CAN/SPI/DWT/SDIO 与 EtherCAT 支持

日期：2026-08-21（17:45 北京时间合入，PR #11715）　来源：RT-Thread/rt-thread commit 6ea68279 / PR #11715

窗口内体量最大的一条合入，NXP 工程师（nxp-ran）主导，46 个文件、+3579/-769。[BSP][NXP] Add new features of I2C DMA, CAN, SPI, DWT and SDIO for RT1180：更新模板、配置文件与构建脚本以支持 HyperRAM、多核启动（multicore kickoff）、rpmsg-lite、NetC 以太网、CherryUSB 与 EtherCAT；为 GCC/IAR/KEIL 三种工具链更新链接脚本以支持多核 kick-off 与不同加载方式；更新 Keil 调试 ini 文件；新增 I2C DMA、CAN、SPI、DWT、SDIO 等外设特性支持。i.MX RT1180 为 NXP 跨界 MCU（Cortex-M33 平台、集成 NetC 以太网），本次为厂商主导的评估板 BSP 功能级增强。值得注意：EtherCAT 支持写入 NXP BSP 清单，与睿擎工业平台 EtherCAT 主线形成呼应，工控实时总线能力在 RT-Thread 生态内双线推进。

1.2 内核 IPC 超时唤醒归属竞态修复，配套回归测试

日期：2026-08-21（16:52 北京时间合入）　来源：RT-Thread/rt-thread commit ba79f694

[kernel][ipc] Fix timeout wakeup ownership race（ari.liu 提交，8 个文件、+721/-14）：修复 timer stop 与 in-flight 超时回调竞争时的线程 timer 归属问题——保持线程 timer 归属权直到超时回调确认不再进行，且仅在 waiter 成功恢复后才消费 IPC 资源；同时补齐通用与 RT-Smart channel 超时回调的归属清理。配套新增确定性调度器与 LWP 回归测试，覆盖 Event、Semaphore、Mailbox、Message Queue、sender、receiver 六类场景。IPC 超时路径的资源归属竞态是嵌入式 RTOS 经典难点，本次修复同时覆盖 rt-thread 内核与 rt-smart LWP 通道并固化回归测试，属内核健壮性的实质增强。

1.3 C906 内核仅保留玄铁 MMU 属性

日期：2026-08-21（16:51 北京时间合入）　来源：RT-Thread/rt-thread commit 5ae08713

Ensure that c906 uses only the Xuantie MMU properties（rcitach 提交，1 个文件、-56 行）：清理 libcpu/risc-v/t-head/c906/riscv_mmu.h，确保平头哥玄铁 C906（RISC-V）内核仅使用玄铁 MMU 属性，移除与通用 RISC-V MMU 属性混用带来的歧义。属 rt-smart RISC-V 内核侧适配的持续维护。

1.4 瑞萨 RA6W1 BSP 设备驱动缺陷修复

日期：2026-08-21（13:10 北京时间合入）　来源：RT-Thread/rt-thread commit 46d74447

fix ra6w1 device bug（rcitach 提交，6 个文件、+124/-23）：修复 RA6W1 EK 板级支持中的设备问题，涉及 ADC 驱动（drv_adc.c）、PWM 驱动（drv_pwm_w.c）、板级 Kconfig 与时钟配置（bsp_clock_cfg.h、hal_data.c）。延续瑞萨 RA6W1 BSP 的迭代节奏：08-05 首版、08-11 二期 45 文件补 ADC/SPI/I2C 等驱动，本次为三期缺陷修复，符合厂商 BSP”先合骨架、后补驱动、再修缺陷”的演进模式。

1.5 Nuvoton 四系列 CAN 驱动钳制接收 DLC

日期：2026-08-21（11:22 北京时间合入）　来源：RT-Thread/rt-thread commit 642040c4

[bsp][nuvoton] Clamp CAN receive DLC（hanzhijian 提交，4 个文件、+16）：在 m2354、m480、n9h30、nuc980 四个系列的 drv_can.c 中统一对 CAN 接收 DLC（数据长度码）做钳制处理，防止越界值传入，属 CAN 驱动的健壮性修补。

1.6 版本状态平稳

日期：2026-08-22　来源：rt-thread releases

最新正式版本仍为 v5.2.2（2025-10-31 发布），窗口内无新 release、无预发布。近期累积修复（Rust 构建、IPC 竞态、libc/dfs、各 BSP）预计随下个版本统一发布。

四、行业应用专章（工业 / 机器人 / 具身智能）

日期：2026-08-19 ~ 2026-08-21　来源：见各条目

行业应用侧窗口内无新的独立公开报道，但两条工控呼应值得注意：

  • EtherCAT 进入 NXP RT1180 BSP（今日 1.1）：工控实时总线能力在 NXP 平台落地，与睿擎平台形成双线；
  • 睿擎 Workshop 报名倒计时（今日 2.2）：8/27 上海 EtherCAT 实战进入临期推广。

近 3 天趋势（均已详报，此处回顾）：

  • Beningo 2026 RTOS 性能报告参测（08-19）：RT-Thread 作为唯一国产开源 RTOS 进入 8 款参测名单；
  • 8/27 睿擎 Workshop：预热（08-18）→ 报名倒计时（08-21）：EtherCAT 实时控制与工业方案实战。

趋势判断：EtherCAT 生态位在 NXP 与睿擎双平台同时出现，工控实时总线是当前最清晰的主线。

五、总结与趋势观察

  1. 内核 + BSP”修复日”：窗口内 5 条合入，体量最大为 NXP RT1180 BSP 功能更新（+3579 行，EtherCAT/HyperRAM/多核/rpmsg-lite 支持），其次为 IPC 超时唤醒归属竞态修复——同时覆盖内核与 rt-smart LWP 通道并配套六类场景回归测试，是近期内核侧最有分量的健壮性增强。
  2. RISC-V 侧持续维护：C906 玄铁 MMU 属性清理，rt-smart RISC-V 适配保持活跃。
  3. 厂商 BSP 演进节奏清晰：瑞萨 RA6W1 走完”首版 → 二期补驱动 → 三期修缺陷”；Nuvoton 四系列 CAN 驱动统一补 DLC 钳制。
  4. 工控主线双平台推进：EtherCAT 进入 NXP RT1180 BSP + 睿擎 8/27 Workshop 进入报名倒计时，本周四的活动为近期最值得跟踪的落地观察点。
  5. 官方信息出口持续滞后：rt_org 停滞 2 个月，news/activity 分类接口连续报错，社区与媒体动态仍快于官方渠道。
  6. 版本节奏：v5.2.2 已维持 9 个多月，近期修复（Rust 构建、IPC、libc/dfs、多厂商 BSP）持续累积，下个版本发布窗口值得关注。
