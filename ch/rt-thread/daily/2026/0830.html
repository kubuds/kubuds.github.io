一、内核与版本动态

1.1 ENV 工具 WebUI 化落地：新增 SDK 管理与本地工具链配置

日期：2026-08-29（20:21 北京时间合并）　来源：RT-Thread/env PR #290

窗口内最具价值的工程动态：RT-Thread 官方命令行工具 ENV 由创始人 Bernard Xiong（bernard）提交并合并 PR #290「Feature/sdk webui config」，为 ENV 的 WebUI 界面新增两项核心管理能力——本地工具链配置与 SDK 管理。改动规模可观：新增 sdk_manager.py（约 1100 行 SDK 管理器）与 toolchain_manager.py（工具链管理器），WebUI 前端 App.vue 扩展 600 余行并新增 file_context_menu.py 文件上下文菜单，配套 pytest 单测（test_sdk_webui、test_local_toolchain_webui）与 Playwright e2e 测试（webui.spec.js）。这是 ENV 自 08-17 起连续迭代（插件市场 WebUI 页面、插件后端服务生命周期、插件市场 Host API 代理等）的延续：ENV 正从纯命令行工具向 WebUI 图形化管理演进，本次落地标志着 SDK 与工具链的本地可视化管理能力成型，开发者可在浏览器界面完成工具链与 SDK 的配置管理。

1.2 主仓库窗口内无新合入，特性间歇期延续

日期：2026-08-30　来源：RT-Thread/rt-thread commits

主仓库 rt-thread 近 48 小时（committer 时间）无新合入，最后一笔仍为 08-28 12:25 的玄铁 C908 rt-smart BSP（已于昨日日报收录），特性间歇期延续。releases 无新版本（最新 v5.2.2 仍为 2025-10-31）。org 层面近 7 天活跃仓库仅 env（08-29）、rt-thread（08-28）、packages（08-28）三处，整体处于版本发布前的平静蓄力阶段。

二、官方与社区活动

2.1 elexcon 2026 预告：睿赛德”不止操作系统”，秀出 AI 硬件”全家桶”

日期：2026-08-30（刊出）　来源：电子工程专辑（经 Google News）

电子工程专辑 08-30 刊出活动预告「9月9-11日，不止操作系统：RT-Thread睿赛德elexcon秀出AI硬件’全家桶’」。展会为 elexcon 2026（第 23 届深圳国际电子展暨嵌入式展），2026-09-09 至 09-11 在深圳国际会展中心（宝安）举行，主题「All for AI, All for Green」，与 CIOE 中国光博会、IC 创新博览会（IICIE）同期。预告标题”不止操作系统”与”AI 硬件全家桶”暗示睿赛德参展重心从操作系统软件延伸至端侧 AI 硬件方案——与睿赛德近期战略脉络一致：WAIC 2026 提出 AIOS 理念（AI 推理放 Linux 侧、实时控制放 RT-Thread 侧混合部署，已在天车系统、六轴机器人验证）、AI KIT 一站式 AI 开发工具平台、作为首批核心成员加入”开源AIOS联盟”（均见科技日报 08-07 报道）。对照去年 elexcon 2025，睿赛德曾斩获”AloT 优秀方案奖”与”实时操作系统突破奖”两项行业大奖。原文站（eet-china.com）本机直连不可达，细节以标题与搜索索引摘要为准，展会现场看点待 9 月实地报道验证。

2.2 官方新闻 API 连续第十日无新增，睿擎 Workshop 会后报道仍缺位

日期：2026-08-30　来源：RT-Thread 官方新闻 API

三、生态与厂商适配

3.1 canopennode-rtt：RX 规则编译为粗粒度 HDR 过滤器

日期：2026-08-30（11:14 北京时间提交）　来源：wdfk-prog/canopennode-rtt

面向 RT-Thread 的 CANopenNode 集成软件包（社区开发者 wdfk-prog 维护）窗口终点前新增 1 笔提交：refactor[canopennode][filter]: compile RX rules into coarse HDR filters——将接收（RX）规则编译为粗粒度 HDR（硬件依赖接收）过滤器，属 CANopen 接收路径过滤逻辑的性能/架构层重构。该包自 08-25 起经历 LSS 配置持久化、运行时比特率激活、SRDO 安全对象字典（08-29 收录）等连续迭代，今日继续向接收路径优化推进。CANopenNode 为开源社区知名 CANopen 协议栈，此包属个人项目（1 star），尚未进入 RT-Thread packages 索引，标注生态参考。

四、行业应用

窗口内无新增行业应用条目。近三日趋势：08-27 兆易创新 GD32 下游仓库（GD32-MCU-IOT/gd32_rt-thread）合并 DMA 功能（PR #68，属厂商主导 BSP/驱动持续适配）；08-28 packages 索引新增 MRamTrace 轻量级 RAM 后端函数追踪软件包（调试/性能分析方向，PR #2027）；行业侧近期主线仍为睿擎工业平台（数据采集直播教学、Workshop）与端侧 AI 落地（AIOS 混合部署）。

五、总结与趋势观察

  1. elexcon 2026 参展预告成窗口内唯一媒体侧信号：睿赛德对外叙事从”操作系统”转向”不止操作系统”的 AI 硬件”全家桶”，与 AIOS 理念、AI KIT 平台、开源AIOS 联盟战略一脉相承，9 月 9-11 日深圳宝安展会将验证其端侧 AI 落地成果。
  2. ENV 工具 WebUI 化是窗口内最有价值的工程动态：SDK 管理与本地工具链配置落地（PR #290，创始人亲笔），配套单测与 e2e，官方开发工具链持续现代化，距 WebUI 插件市场、后端服务之后再次加码。
  3. 官方新闻面第十日平静：新闻 API 无新增，睿擎 Workshop 会后报道持续缺位；媒体侧仅电子工程专辑预告一条，官方公众号渠道可能存在未收录内容。
  4. 主仓库特性间歇期延续：窗口内无新合入（最后为 08-28 C908 rt-smart），无新 release；社区侧 canopennode-rtt 保持每日迭代节奏，CANopen 接收路径优化是本窗口生态看点。
  5. 软件包生态侧增调试新件：MRamTrace（RAM 后端函数追踪）08-28 进入 packages 索引，MCU 固件追踪调试方向有新工具。

局限性说明：电子工程专辑原站（eet-china.com）本机直连超时，elexcon 预告细节仅凭标题与搜索索引摘要，具体展品需待展会报道；睿擎 Workshop 会后报道可能仅发布于官方微信渠道，gnews 拆词噪音大无法覆盖；canopennode-rtt 为 1 星个人项目，收录仅供生态观察。
