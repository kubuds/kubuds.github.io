一、内核与版本动态

1.1 v5.3.0-beta 分支创建，v5.3.0 版本周期正式启动

日期：2026-08-24（10:38 北京时间）　来源：RT-Thread/rt-thread 分支列表 / 仓库事件

今日 10:38（UTC 02:38），RT-Thread 核心维护者 Rbb666 在 rt-thread 主仓库创建 v5.3.0-beta 分支，指向当前 master HEAD（08-21 的 NXP RT1180 BSP 大合入，6ea68279）。仓库此前已有 v5.2.0-beta / v5.2.1-beta / v5.2.2-beta 三个先例分支，beta 分支创建是 RT-Thread 版本发布流程的第一步：先切出稳定分支收拢修复、随后发布正式 tag。v5.2.2 正式版发布于 2025-10-31，此后主仓库进入 v5.3.0 开发积累期（期间合入 AF_UNIX 套接字、Device Model 重构、多厂商 BSP 等大量特性）；本次 beta 分支建立标志 v5.3.0 版本周期正式启动，距 v5.2.2 发布约 10 个月，与历史版本节奏（v5.1→v5.2 间隔约 11 个月）基本一致。分支当前与 master 同点，尚无独立提交，预计后续修复与特性收尾将在此分支上开展。

1.2 主仓库窗口内无新合入，master 停在 NXP RT1180 合入

日期：2026-08-24　来源：RT-Thread/rt-thread commits

主仓库 master 分支窗口内无新 commit，最后合入仍为 08-21 17:45（北京时间）的 NXP RT1180 BSP 功能更新（I2C DMA、CAN、SPI、DWT、SDIO，昨日已详报）。软件包索引仓库 packages 最后 push 亦停在 08-21 09:24，窗口内无新软件包合入。releases 无新增（v5.2.2 仍为最新正式版），v5.3.0-beta 为唯一新引用，开发主线进入版本收尾前的整理期。

三、生态与厂商适配

3.1 CANopenNode 集成包 canopennode-rtt 新增 EEPROM 存储诊断，一周五连更

日期：2026-08-24（11:09 北京时间）　来源：wdfk-prog/canopennode-rtt / commits

第三方开源项目 canopennode-rtt（面向 RT-Thread 的 CANopenNode V4 集成移植包）今日新增 feat[canopennode][storage]: add EEPROM storage diagnostic support 提交，为 AT24CXX EEPROM 存储后端增加诊断支持。该包不重实现协议栈，通过 git submodule 引用上游 CANopenNode 核心，由本仓库提供 RT-Thread 目标层：CAN 设备绑定、Kconfig/SCons 构建集成、接收/主循环/实时三线程运行模型、DFS 或 AT24CXX 存储后端、CiA 301/303/304/305/309 特性组开关与 demo 对象字典。近一周连续提交（08-17 NMT 心跳监督主站 demo、08-18 SDO 客户端验证、08-19 ASCII 网关 MSH 控制台桥、08-20 SDO 块传输验证、08-24 EEPROM 诊断），功能面从 NMT/SDO 向存储与诊断收敛，工控 CANopen 总线方向在 RT-Thread 生态的第三方落地持续加深。

3.2 生态参考：awtk / gd32_rt-thread / h120d-protocol 例行同步

topic:rt-thread 近一周活跃仓库其余三个均为例行动态，非 RT-Thread 专项：zlgopen/awtk（跨平台嵌入式 GUI 框架）今日 09:05 有 push，为通用 GUI 改进，与 RT-Thread 无直接关联；GD32-MCU-IOT/gd32_rt-thread（rt-thread 下游同步仓库）今日 09:58 push 为常规上游同步；h120d-protocol（大疆 H120D 无人机 WiFi 协议逆向文档，topic 标签关联）昨日 22:15 push 为协议逆向内容。三者标生态参考，不单列条目。

四、行业应用（工业 / 机器人 / 具身智能）

4.1 窗口内无新独立报道，近 3 天趋势回顾

日期：2026-08-22 ~ 2026-08-24　来源：见各条目

行业应用侧窗口内无新的独立公开报道。近 3 天趋势回顾：

  • v5.3.0 版本周期启动（08-24）：beta 分支创建标志 10 个月来首个新版本周期开启，工控/网络（AF_UNIX）等特性将随 v5.3.0 正式发布；

五、总结与趋势观察

  1. v5.3.0 版本周期正式启动是今日头条：核心维护者创建 v5.3.0-beta 分支（10:38），延续 v5.2.x 各版本”先 beta 分支、后正式 tag”的发布惯例；v5.2.2（2025-10-31）之后约 10 个月的特性积累（AF_UNIX、Device Model、多厂商 BSP）进入版本化收尾阶段。
  2. 主仓库代码侧平静：master 窗口内零合入，packages 索引亦无新增，开发处于分支建立后的整理期，与昨日判断一致。
  3. 工控主线多线并进：CANopenNode 集成包一周五连更（今日 EEPROM 存储诊断）叠加 8/27 睿擎 EtherCAT Workshop 临期，工业实时总线方向是生态侧最活跃主题。
  4. 官方信息出口持续滞后：rt_org 停滞 2 个月、news/activity 接口连续第四日报错，官方渠道节奏远慢于 GitHub 动态，版本周期启动这类信号目前只能从仓库事件观测。
  5. 局限说明：gnews 对 “RT-Thread” 检索噪音高（Rotten Tomatoes 拆词、吉利智擎混动等），本窗口新闻侧零新增已通过官方 API + GitHub + 多组 gnews 交叉核查确认；EET-China 原站不可达，相关条目仅引 gnews 链接。
