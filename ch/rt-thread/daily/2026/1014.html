一、内核与版本动态

主仓库窗口内无新提交与合入：master 最新一笔仍为 10-12 上午的 Eclipse 工程生成修复（#11787），此后约 45 小时无合入动作。评审与协作侧保持活跃：五笔在审提案与两条旧缺陷单窗口内均有更新，社区验证活动集中在 RISC-V 重构与内存安全方向。

1.1 Next RISC-V 大重构提案社区实测推进：QEMU 配置指引澄清、ESP32-C3 实板补丁验证（10-13）

日期：2026-10-13 10:54 ~ 23:52（评论与测试时间）　来源：PR #10320

RISC-V 大重构提案（#10320）窗口内完成四轮社区互动：其一，贡献者提交 QEMU 五组配置实测报告，其中「S-Mode 关闭设备模型」组合因缺少公共启动与多核调度符号而链接失败；其二，维护者给出平台适配口径——设备模型与无设备模型二选一（qemu-virt64-riscv 属前者，d1/d1s 与 smartl/e907 属后者），测试者据此调整用例分配；其三，当晚该贡献者在 ESP32-C3 实板验证两枚配套补丁（bsp/ESP 切换至新版公共 RISC-V 代码路径），报告 C3 与 C6 均编译通过、零告警。提案维持开放。

1.2 堆内存 ASan 提案增补提交：libc 访问检查与边界用例（10-13）

日期：2026-10-13 15:25（提交时间）　来源：PR #11772

堆内存运行时 AddressSanitizer 提案（#11772，8 月末开出）窗口内增补提交：在既有堆插桩运行时与 QEMU CI 覆盖的基础上，扩展对 libc 内存访问的检查并补齐边界用例。该案基于 GCC kernel-address 对内存访问插桩，运行时可检测堆缓冲区越界与释放后使用，并提供 FinSH 交互命令查看诊断信息。提案维持开放、待评审。

1.3 lwip/WLAN 控制提案扩展提交：DNS、DHCP、缓冲与 WLAN 生命周期四组更新（10-13）

日期：2026-10-13 14:27 ~ 16:08（提交时间）　来源：PR #11815

lwip 段宏控制提案（#11815）窗口内由宏控制主题扩展为四组提交并两度强制推送：其一，STA 模式下断开连接时清理 DNS 配置；其二，优化 DHCP 启动逻辑；其三，配置 lwip 缓冲选项并保留 PBUF 尾部空间；其四，同步 WLAN AP 生命周期与直收路径处理。提案覆盖面由编译宏整理扩展至网络栈行为修正，维持开放。

1.4 ESP32-S3 BSP 提案完成自动评审整改、请求人工复审（10-13）

日期：2026-10-13 12:02 ~ 12:42（评论时间）　来源：PR #11844

ESP32-S3 板级支持提案（#11844）窗口内完成自动评审整改：作者按 Copilot 评审意见修正互斥锁宏展开与 UART0 中断分配级别，并在说明中补充浮点与 AI 指令限制；剩余构建检查失败被判定为上游既有问题、与本案无关，作者点名请求人工复审，维护者回应当日稍后查看。该案自 09-28 开出并历经多次刷新，本次为窗口内实质推进。

1.5 Keil/IAR 目标选择提案：作者回应两处复审意见，维持开放（10-13）

日期：2026-10-13 16:34 ~ 17:38（评论时间）　来源：PR #11743

Keil/IAR 目标自动选择提案（#11743）窗口内就两处复审意见作出回应：针对「targets 初始化循环缺失」的疑问，作者指出相关路径与宏定义拼接代码已补齐、问题不存在；针对 IAR 链接配置字段混入 –config_def 无效符号的问题，作者提出该字段每条目由 IDE 自动加前缀、LINKFLAGS 不应再携带配置定义的讨论，寻求维护者确认。提案维持开放。

1.6 两条旧缺陷单获社区接手推进：串口 POSIX 控制参数与 DAC 文档示例（10-13）

日期：2026-10-13 22:13 ~ 22:17（评论时间）　来源：Issue #5073、Issue #6568

两条旧缺陷单窗口内获社区成员接手推进：串口 POSIX 接口 ioctl 无法设置底层参数（#5073）——贡献者核对后指出此前关联提案仅覆盖部分场景、问题在 dfs_v1 中仍存在，并表示希望接手该单；DAC 设备驱动文档示例问题（#6568）——修复已合入、文档中心参数描述亦更新，贡献者就文档呈现格式提出进一步修正方案。

1.7 官方新闻接口连续第五十五日无新增（10-14）

二、官方与社区活动

2.1 虚拟化混合部署教学平台稿刊出：RK3588 单芯片双域运行 Linux 与 RT-Thread（10-13）

日期：2026-10-13（媒体发布时间）　来源：电子工程专辑原文

电子工程专辑刊出 RT-Thread 虚拟化混合部署教学平台专题：Rockchip HyperCar 以 RK3588 单芯片同时运行 Linux/ROS 2 与 RT-Thread 双域，由 HyperBoot 负责启动、隔离与资源分配，双域经虚拟网络与 micro-ROS 协同——Linux 侧承载感知决策与应用编排，RT-Thread 侧承担底盘硬实时执行。平台配套基础控制、建图导航、视觉服务、机械臂四类模块共 16 个案例与三阶实训路径，并提供大模型本地部署与六轴机械臂抓取综合案例。

2.2 〖2026嵌入式大赛〗GD32H759IM 的 USB 副屏加 OV2640 摄像头二合一作品帖发布（10-13）

日期：2026-10-13 17:43（发布时间）　来源：论坛帖 76ffa34214c0eda4

2026 嵌入式大赛作品帖「GD32H759IM 的 USB 副屏加 OV2640 摄像头二合一」发布：以 GD32H759IMK6 为核心、运行 RT-Thread 4.1.1 与 LVGL 9.5，经 USB 高速口把 4.3 英寸 480×272 RGB 屏变为电脑第二显示器；固件整合 TLI 显示、EXMC SDRAM、DCI 摄像头与 USBHS0，提供 PC 监控仪表盘、屏幕镜像与摄像头推流三种模式，主机端为 Python 工具；-O0 构建下 Flash 约 354 KB、RAM 约 84 KB。

2.3 〖2026嵌入式大赛〗基于 GD32H7 的多功能环境监测与本地数据记录仪作品帖发布（10-13）

日期：2026-10-13 08:37（发布时间）　来源：论坛帖 248f9e54e367993d

2026 嵌入式大赛作品帖「基于 GD32H7 的多功能环境监测与本地数据记录仪系统」发布：以 GD32H759I-EVAL 为平台、RT-Thread 5.3.0 与 LVGL 8.3.11，经 SHT40、BH1750 与 SGP30 采集温湿度、光照、等效二氧化碳与 TVOC；中文触摸界面支持数值查看、阈值调整、趋势浏览与历史翻阅，数据按周期写入 SD 卡 CSV，配套电脑端离线解析工具；面向温室、机房与实验室等本地监测场景，当前版本不含联网上传。

三、生态与厂商适配

3.1 packages 索引新提案：hpm_sdk v1.13.0 软件包索引开出，上游标签同日发布（10-13）

日期：2026-10-13 17:07（创建时间）　来源：PR #2045（RT-Thread/packages）、rtt-pkg-hpm-sdk v1.13.0

软件包索引仓库（RT-Thread/packages）新开提案：为 HPMicro hpm_sdk 增加 v1.13.0 索引——新增 PKG_USING_HPM_SDK_V113 配置与对应下载条目，默认版本维持 v1.10.0、需显式选择；v1.13.0 新增 HPM5100 系列（HPM5151 / HPM5100EVK）支持并同步各系列外设驱动更新。对应包仓库 rtt-pkg-hpm-sdk 已于同日（16:05）发布 v1.13.0 标签。提案维持开放。

3.2 第三方 GDB 调试框架 GDR 发布 2026.04：新增适配器自动探测与自动初始化（10-13）

日期：2026-10-13 15:58（发布时间）　来源：GDR 2026.04 发布页、项目仓库

第三方 GDB 调试辅助框架 GDR 发布 2026.04：新增适配器自动探测——gdr probe 按匹配符号、版本来源与布局指纹给出 exact / range / undetected 置信度，gdr init auto 仅在唯一确定答案时自动选择；同步挂载 VS Code 扩展 2026.4.0 的 VSIX 产物。该框架在调试器内解读 RT-Thread 内核对象，支持 3.1.x / 4.0.x / 4.1.x，RV64 自 4.0.4 起、Cortex-A9 已实机验证，属第三方生态参考。

其余生态渠道窗口内延续静默：env 工具仓库（最近合入 10-09）、packages 索引（最近合入 09-24）、Studio SDK 索引（最近更新 10-10）均无窗口内推送；GD32 厂商下游 gd32_rt-thread 无新动作（最近 10-10），同组织 Zephyr 方向仓库的窗口内推送不属本期范围。
