一、内核与版本动态

1.1 STM32 SPI BDMA 支持合入主线，DMA / BDMA / GPDMA 配置统一（PR #11689）（09-14）

日期：2026-09-14 09:59（北京时间，合入时间；作者提交日期 09-11）　来源：PR #11689

主线在 v5.3.1 版本号推进之后恢复合入，本窗口内首笔功能性提交为 STM32 平台 SPI 的 BDMA 支持，并顺带统一了 DMA、BDMA、GPDMA 三类搬运通道的配置写法（随附 clang-format 格式化提交）。BDMA 是 STM32H7 / U5 等系列在低功耗域可用的独立 DMA 控制器，此前 SPI 驱动仅走通用 DMA 路径；本次合入补齐了 SPI 在 BDMA 通道上的收发能力，对需要在 STOP 低功耗模式下维持外设搬运的工业与传感器场景有直接价值。该 PR 自开启至合入历时数日，属社区驱动的外设驱动增强。

1.2 QEMU 入门文档两处修正合入（PR #11789 / #11794）（09-11）

日期：2026-09-11 13:23 与 13:26（北京时间）　来源：PR #11789、PR #11794

两笔文档修复同日合入：一是补齐 QEMU Linux 快速上手过程中缺失的 apt 依赖包，二是更新 qemu-vexpress-a9 README 中已失效的 GNU GCC 工具链下载链接。两笔提交的作者日期分别为 09-07 与 09-08，属长期搁置后的收尾合入。QEMU 模拟器是 RT-Thread 最常见的免硬件上手路径，文档可用性直接影响新开发者首次体验。

1.3 四项安全类 issue 集中于 09-13 关闭（tmpfs / 消息队列 / pread / finsh 补全）（09-13）

日期：2026-08-23 提交，2026-09-13 15:46 ~ 15:47 集中关闭　来源：#11735、#11736、#11737、#11738

同一日提交的四项安全类缺陷在 09-13 被集中标记为已完成关闭，覆盖：tmpfs 路径处理（_path_separate / _get_subdir）长路径分量导致的栈缓冲溢出、POSIX 消息队列名处理中 mq_unlink() 的无界栈溢出与 mq_open() 的差一错误、pread() 传入大负偏移绕过 rw_verify_area() 造成 tmpfs 越界堆读（信息泄露或崩溃）、finsh TAB 自动补全（msh_auto_complete_path）补全结果未裁剪到行缓冲导致的堆越界写。四项均由同一提交者认领并关闭，公开评论与提交历史中未见与之逐条对应的修复提交，修复的实际落地路径（可能并入 v5.3.0 的 dfs / posix 加固批次，或另行走内部流程）仍待核实。对以 RT-Smart 与文件系统、消息队列为卖点的工业与车载场景而言，该批缺陷的闭环进度值得持续跟踪。

1.4 评审队列观察（一）：新 BSP 与国产 MCU 驱动扩展密集送审（09-14）

日期：2026-09-11 ~ 2026-09-14　来源：#11799、#11800、#11798、#11764

窗口内新开与更新的 BSP / 驱动类 PR 集中：意法半导体 STM32N657 系列的 stm32n657-st-nucleo BSP（84 文件，+15340 行）、国民技术 N32H 系列驱动从单一板卡扩展到 n32h487zgl7-evb / n32h497zgl7-evb / n32h760zil7-stb 三块板（69 文件，+7561/-2754 行，覆盖 ADC、DAC、以太网、I2C、SPI、QSPI、NAND、SDRAM 等）、小华半导体 HC32 系列驱动扩展，以及 CherryUSB 组件对 N32H4x USBFS 设备侧的支持。整体呈现「国产 MCU 原厂与生态开发者密集补齐 BSP」的特征，与新版本发布后的适配窗口吻合。

1.5 评审队列观察（二）：lwip 2.2.1 协议栈支持入列，工具链与 USB 修复并存（09-14）

日期：2026-09-11 ~ 2026-09-14　来源：#11797、#11743、#11770、#11748

评审队列中的组件与工具类更新：新增 lwip 2.2.1 协议栈支持（改动 1875 文件，修复 #11588，验证平台为 NXP i.MX RT1180 EVK，配置 RT_USING_SAL + RT_USING_NETDEV + RT_USING_LWIP），这将把主线网络栈从既有 lwip 2.1.x 基线推进到 2.2.x；工具侧有「按 Kconfig 链接脚本自动选择 Keil / IAR 目标」的改进；缺陷修复侧包括 USB VCOM 中 rt_ringbuffer 与 rt_serial_rx_fifo 类型别名冲突的修正，以及内核新增栈指针对齐配置项。

1.6 评审队列观察（三）：达摩院玄铁 C908 的 QEMU rt-smart 支持持续推进（09-14）

日期：2026-08-31 开启，2026-09-14 10:16 更新　来源：PR #11775

针对达摩院玄铁 C908 的 QEMU 模拟平台（xiaohui c908）新增 rt-smart 支持，包含 MMU sv39 / sv48 页表模式与 SMP 多核启动，并补充 mmu_dem 相关能力，改动 31 文件、+2575/-565 行。该 PR 仍在评审中。对 RISC-V 侧而言，这是把 RT-Thread Smart（带 MMU 的混合部署形态）在玄铁高能效核上做模拟器级验证的关键一步，可用于在无硬件条件下验证进程隔离与用户态应用。

1.7 新增缺陷报告：SDIO 驱动注销失败与节点内存泄漏风险（#11801）（09-12）

日期：2026-09-12 14:56（北京时间）　来源：#11801

窗口内新增驱动类缺陷报告一则：SDIO 驱动在注销路径上存在失败与节点内存泄漏风险，已打上 bug 与 component: drivers 标签，尚未有人认领。SDIO 是 Wi-Fi 模组与存储卡的共用总线，该问题对长期运行设备的热插拔与资源回收场景有潜在影响。
