一、内核与版本动态

1.1 clang-format 自动提交不再跳过 CI：格式化流水线并入常态验证（09-23）

日期：2026-09-23 16:30 ~ 16:34（北京时间，创建与合入时间）　来源：PR #11830、合入提交

主线在窗口内合入一笔持续集成流程调整：clang-format 自动格式化提交的提交信息中去除「跳过 CI」标记，此后格式化提交与普通提交一样触发持续集成流水线。该标记原用于避免「自动格式化提交再触发一轮 CI」的循环，代价是格式化结果不经构建验证直接入库；调整后格式化动作纳入常态验证链路。对应工作流文件为此提案唯一变更文件，提案由社区贡献者提交，创建后约四分钟即完成合入。

1.2 评审队列窗口内新增两条提案：netdev 构建修复与 GD32H77D 外设系列（09-23）

日期：2026-09-23 11:05 / 15:41（北京时间，提案时间）　来源：PR #11828、PR #11829

评审队列在窗口内新开两条提案。其一为网络组件的小范围修复（#11828，netdev 的 AF_NETLINK 构建错误）：补上结构体前向声明，并把路由通知回调中的节点索引引用从临时变量改为直接取列表节点，修复开启相关配置组合后的编译报错，涉及两个文件。其二为大体量的厂商板级提案（#11829）——GD32H77D GinoPi 板卡外设系列，共 19 笔提交、142 个文件，详见第三章 3.1。

1.3 官方新闻接口连续第三十五日无新增（09-24）

日期：2026-09-24（核查时间）　来源：RT-Thread 官方新闻接口

官方新闻接口（rt_org 分类）仍为 5 条旧条目，最新仍为 2026-06-17 报道，连续第三十五日无新增；官网新闻列表页窗口内核查仍返回加载失败提示，无法直接核读。产品与活动信息继续由论坛、商城与行业媒体渠道首发。

二、官方与社区活动

2.1 RSOC26 夏令营教程体系化推进：窗口内更新《第一章 开发环境、BSP 配置与设备模型》（09-23）

日期：2026-09-23 15:22（北京时间，更新时间）　来源：论坛文章 5a5a1f34db847d92

社区论坛在窗口内更新一篇 RSOC26 系教程《第一章 开发环境、BSP 配置与 RT-Thread 设备模型》，给出从零到设备模型的完整主线：安装 RT-Thread Studio 并经 SDK 管理器部署内核源码与芯片支持包；以「基于芯片」方式新建工程（星火一号平台 STM32F407ZG，内核 4.1.1、USART1 控制台、ST-LINK 与 SWD 调试）；解析 BSP 工程目录结构与 board.c / board.h 职责（时钟树 168 MHz、系统滴答、堆边界）；讲解 I/O 设备模型三层架构与 GET_PIN 引脚编号机制；并以 GPIO 心跳灯与串口打印完成编译、烧录与 FinSH（MSH）命令行验证。该篇与此前散点发布的星火一号实践篇目形成章节化编排，属夏令营教程的体系化开篇。

三、生态与厂商适配

3.1 Gino Pi 主线 BSP 提案进入评审：GD32H77D 外设系列 19 笔提交、142 个文件（09-23）

日期：2026-09-23 15:41（北京时间，提案时间）　来源：PR #11829

兆易创新 GD32H77D 板卡 Gino Pi 的板级支持以系列提案形式提交主线评审：单分支 19 笔提交、142 个文件、净增约 2.6 万行。内容覆盖三层：板级骨架（工程、链接脚本、rtconfig）；外设全家桶——以太网、USB 主机与设备、SDRAM、硬件 I2C、SPI3、PWM、SDIO 与文件系统、RTC 与闹钟、看门狗、CAN 与 CAN FD、OSPI Flash、MIPI LCD、GT911 触摸、OV7670 摄像头与 LVGL；以及 GinoPi 外设演示工程与全 BSP 编译检查挂载。另含板载 GD32VW553 无线模块的 Wi-Fi 与 MQTT 支持，提交说明注明该模块的 UART4 AT 通信与 MAC 查询已验证、Wi-Fi 关联尚待完成，模块与示例默认关闭。该板卡此前已完成 Studio SDK 索引、发售与调试链路补完（见 3.2），本期是「从厂商 SDK 走向主线」的实质一步，目前处于评审中。

3.2 GD32 器件支持包与 Wi-Fi 组件三仓同步：H77x_78x 器件/外设库与 GD32VW553 联网支持（09-23）

日期：2026-09-23 16:01 ~ 16:10（北京时间，推送时间）　来源：gd32-arm-cmsis 提交、gd32-arm-series 提交、at_device 提交

与主线提案同日下午，RT-Thread 器件支持包组织的三个仓库先后完成铺垫性更新：CMSIS 器件支持包（gd32-arm-cmsis）与 GD32 外设库支持包（gd32-arm-series）分别新增 GD32H77x_78x 支持，为 H77 系列芯片提供 CMSIS 器件层与新外设库；AT 组件仓库（at_device）新增 GD32VW553 Wi-Fi 设备与 TCP socket 支持，使这款无线模块可经 AT 通道接入网络组件。三笔提交与主线 BSP 提案在同一时间窗内推送，构成 Gino Pi 软件栈的一次同步就位。

3.3 软件包索引三连合并：CanopenNode v1.2.0 配置重构、虚拟传感器新包、AI Agent 增加 MQTT 工具（09-24）

日期：2026-09-24 09:23 ~ 09:25（北京时间，合入时间）　来源：CanopenNode v1.2.0 合并、虚拟传感器包合并、AI Agent 配置合并

软件包索引仓库在窗口内集中合入三笔提案（均为 9 月 11 日 ~ 14 日提交、窗口内完成评审）：其一为 CanopenNode v1.2.0，9 个 Kconfig 文件重构，把原先的 CiA 401 设备 worker 开关整合为通用设备剖面体系——新增纯 C、无堆分配、与实时系统解耦的逻辑设备注册表，以及剖面控制器传输契约与 RT-Thread 主站传输选项，工业总线组件的配置结构向模块化前进。其二为新软件包「虚拟传感器」：提供模拟传感器数据生成，可选经 MQTT 上报（依赖 paho MQTT 与 cJSON 组件），面向无硬件条件的联调与教学场景，包源指向作者维护的独立仓库。其三为 AI Agent 软件包配置更新：新增 MQTT 工具及其 broker 地址等配置项，同时引入对 rt_vsnprintf 能力的自动检测机制——以「内核是否已定义该符号」为判据（而非套用版本号），自动决定是否启用完整版格式化软件包，避免 4.1.x 内核上重复定义导致链接失败，并保证浮点格式等完整能力可用。

3.4 瑞萨 RA8P1 Titan Mini OpenMV 新增 RGB LCD 显示与视觉示例（09-24）

日期：2026-09-24 09:42（北京时间，提交时间）　来源：提交 98076cf8、Titan Mini OpenMV 仓库

Studio BSP 组织下瑞萨 RA8P1 Titan Mini 仓库在窗口内推送一笔功能提交（17 个文件、约 1200 行新增）：为 OpenMV 工程接通板载 RGB 接口的 800×480 屏幕（RGB565），补齐 LCD 驱动与 MicroPython 的 lcd 模块，并同步调整显示适配、NPU 与运行时相关文件及 machine_pin / machine_pwm 等机器模块；示例侧新增 LCD 基础显示（色条、文字、图形、2 倍缩放与背光调节）、相机预览与红色色块追踪两个视觉示例，背光由 LCD 统一管理（占用 GPT7）。该工程此前完成 OpenMV 发布链路与性能优化（09-18、09-22 已收录），本期从性能收口转向显示与示例扩展，端侧视觉演示链路进一步完整。
