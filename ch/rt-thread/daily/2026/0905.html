一、内核与版本动态

1.1 官方 Env 工具链合入 WebUI 插件状态保持（keep_alive）机制

日期：2026-09-05（合入 09-05 00:08 北京时间）　来源：RT-Thread/env PR #294（合入提交）

RT-Thread 官方开发辅助工具 Env（仓库 RT-Thread/env）合入由创始人 BernardXiong（熊谱翔）提交的 PR #294「Add opt-in state retention for plugin WebUI pages」。核心变更：为插件 manifest.webui 增加可选 keep_alive 字段（默认 false），开启后插件 WebUI 的 iframe 在插件页、设置页与插件中心之间切换导航时保持挂载，不再每次重载（未开启插件维持原有重载行为）；同时移除 WebUI 顶部栏、把「退出 WebUI」操作移至侧栏底部，并按插件隔离静态资源、为沙箱化 WebUI 页面开放可选的后端 HTTP/WebSocket 上下文。该 PR 承接 09-02 起 env 分支上的一系列 WebUI 改造（按插件维护 iframe 生命周期、插件资源令牌与 CSP 边界、doctor 请求代次校验等，feature/ws 分支），本次合入标志 Env 的 WebUI 插件系统从「切换即重载」升级为「页面状态按需保持」，属官方工具链体验迭代，亦是本窗口 org 内唯一合入。

1.2 主仓库窗口内零合入零新 PR，蓄积期延续；CAN 重构 PR #11779 无新进展

日期：2026-09-05　来源：org:RT-Thread 仓库列表（commits / pulls 接口）

主仓库 rt-thread 连续第二个窗口无新提交合入（最近合入仍为 09-03 早间 #11776，昨日已收录），窗口内亦无新 PR 创建，release 仍为 v5.2.2（2025-10-31）。评审队列状态与昨日持平：CAN 框架重构 PR #11779（wdfk-prog，2 commits、+2902/-1308）最后一条评论仍为维护者 CYFS3 于 09-03 17:47（北京时间）的表态——不建议另行维护一套 CAN_V2 框架、希望开发者共同参与推动合入，窗口内无新增评论与提交；#11775（[bsp][c908] rt-smart 与 MMU Sv39/48 支持）、#11772（堆运行时 AddressSanitizer）、#11774（sal SIOCGIFCONF 溢出修复）、#11689（stm32 SPI BDMA）等均保持 open 未动。内核侧进入合入后的常规蓄积期。

三、生态与厂商适配

3.1 canopennode-rtt 新增 CiA402 周期同步模式 CSP/CSV/CST，运动控制模式面补齐

日期：2026-09-05（11:08 北京时间 push）　来源：wdfk-prog/canopennode-rtt

topic:rt-thread 生态仓库 canopennode-rtt 默认分支窗口内新提交「feat: support CiA 402 CSP CSV and CST modes」，为 CiA402（DS402 运动控制 profile）增加周期同步位置（CSP）、周期同步速度（CSV）、周期同步力矩（CST）三种周期同步模式。与 09-03/09-04 合入的多轴设备 profile 与 PP/PV/Homing 定位/速度/回零模式衔接，DS402 支持从非周期模式扩展到周期同步闭环模式，运动控制功能面补齐。结合该作者同时在主仓库推进 Generic CAN 框架重构（#11779），「应用层（CANopenNode 扩展）+ 框架层（CAN 重构）」双线并进态势延续，CAN/运动控制仍是当前社区最活跃的推进主线。

3.2 电子工程专辑专栏分享社区作品：FRDM-MCXN947 USB 监控副屏

日期：2026-09-04（17:30 北京时间）　来源：电子工程专辑 a522648（RT-Thread 论坛原作）

电子工程专辑「开源项目分享」专栏 09-04 发文介绍基于恩智浦 FRDM-MCXN947 开发板的 USB Monitor 项目实践：通过 RT-Thread 操作系统 + LVGL 图形库 + CherryUSB 协议栈，实现将 PC 端 CPU、GPU 等运行状态实时显示在副屏上。该作品源自 RT-Thread 论坛「24 嵌入式设计大赛」的「USB 一线通监控副屏」项目，属社区作品经行业媒体转载传播的典型案例，同时展示了 RT-Thread 在 NXP 新平台（MCXN947，双核 Cortex-M33）上配合 LVGL/CherryUSB 生态的开箱可用度。EET 原站正文不可直达，链接存证。

3.3 极海「极海芯得 EP.87」：RTT-Studio 环境下 APM32 外设驱动使用指南

日期：2026-09-03（11:30 北京时间；今日 3 天窗口复查补录，昨日 zh 查询未命中）　来源：电子工程专辑 a522255

极海半导体（Geehy）开发者社区「极海芯得」系列第 87 期（电子工程专辑 09-03 发布）：RTT-Studio 环境下的 APM32 外设驱动使用指南。文章讲解在 RT-Thread Studio 新建 APM32 工程后 adc、dac、hwtimer、uart 等外设驱动的使用方法，并指出 APM32 的 RT-Thread 外设驱动已将底层引脚初始化与外设时钟开启封装在驱动内部，开发者可直接以设备模型接口调用。属芯片原厂面向 RT-Thread 生态的持续教程输出（该系列此前已覆盖 APM32 系列 RT-Thread BSP 移植、LwIP、LVGL、CherryUSB 等主题），对 APM32 用户与 Studio 上手者有直接参考价值。

3.4 生态参考：H120D 无人机 RT-Thread 内部机制逆向文档项目更新

日期：2026-09-05（07:31 北京时间 push）　来源：H4ck3rTR/h120d-protocol

第三方逆向工程文档项目 h120d-protocol（stars 4）窗口内有更新：整理 Holy Stone H120D 航拍无人机 WiFi 协议逆向数据包、RT-Thread 内部机制说明及配套控制工具。该项目为独立爱好者的逆向文档工作（非官方），将消费级无人机固件中 RT-Thread 的内部机制（线程/消息等）与私有 WiFi 协议一并文档化，对研究 RT-Thread 在消费电子/无人机产品的实际落地形态有一定参考价值，收录作生态参考。
