一、内核与版本动态

1.1 主仓库零合入延续至第三窗口；新 PR #11780 修复 SDIO CIS 元数据内存泄漏

日期：2026-09-05（PR 创建 16:59 北京时间）　来源：RT-Thread/rt-thread PR #11780（关联 issue #11724）

主仓库 rt-thread 本窗口零合入、零新 issue，最近合入仍为 09-03 的 #11776（第三窗口延续），release 仍为 v5.2.2（2025-10-31）。窗口内唯一新增为社区开发者 Huoyanlifusu 提交的 PR #11780「[components][sdio] Fix CIS tuple memory leak」：修复 #11724 所指问题——sdio_read_cis() 处理 CISTPL_FUNCE 与 CISTPL_VERS_1 等部分 CIS tuple 时申请内存但处理完成后未释放，反复初始化/反初始化 SDIO 设备会导致内存泄漏；修复方案为上述两个分支处理完毕后释放临时 tuple，未知 tuple 仍交由 func->tuples 链表管理并由 sdio_free_cis() 统一释放。改动 1 个文件、净增 2 行，作者在 qemu-vexpress-a9 BSP 上完成验证。该 PR 是作者连续第三个组件级修复（#11756 netdev ping 空指针崩溃修复已于 08-26 合入；#11774 sal SIOCGIFCONF 越界修复仍在评审中），延续「组件级内存安全修复」的贡献主线。评审队列其余条目与昨日持平：#11779 CAN 框架重构自维护者 CYFS3 09-03 表态后无新评论，#11775（c908 rt-smart）、#11772（堆 ASan）、#11689（stm32 SPI BDMA）等均 open 未动。

三、生态与厂商适配

3.1 canopennode-rtt：CiA402 控制器侧与诊断/EMCY 补齐，CiA401 通用 I/O profile 分支启动

日期：2026-09-05 ~ 09-06（14:08 ~ 次日 10:06 北京时间，6 笔提交）　来源：wdfk-prog/canopennode-rtt（CIA401 分支）

自昨日 11:08 收录 CSP/CSV/CST 周期同步模式后，该仓库开发未停：默认分支新增「CiA402 device diagnostics and EMCY bridge」（设备诊断与 EMCY 应急报文桥接，09-05 14:08）、「添加 CiA402 控制器支持和相关测试」（16:13，CiA402 覆盖从设备侧扩展到控制器侧）与文档清理重构（16:36）；随后开出新分支 CIA401，09-05 21:53 起连续落地「generic I/O device profile core」「digital event and output fail-safe support」及 09-06 10:06 的「模拟量输入输出事件和故障安全功能支持」。至此该 CANopenNode 移植在 09-03 以来一周内完成双线扩展：运动控制 profile（CiA402：多轴、PP/PV/Homing、CSP/CSV/CST、诊断与 EMCY、控制器侧）与通用 I/O 设备 profile（CiA401：数字/模拟量事件与故障安全），CAN/工业现场总线方向的生态推进主线保持全社区最活跃。结合该作者同时在主仓库推进 Generic CAN 框架重构（#11779），「框架层 + 应用层」双线并进的态势不变。

3.2 生态参考：gdr GDB 调试框架收尾 FreeRTOS 适配，RT-Thread 保持首要支持

日期：2026-09-05（17:39 北京时间收尾提交）　来源：flespark/gdr

topic:rt-thread 仓库 flespark/gdr（GDB Python 环境下的 RTOS 调试辅助框架，提供 rtt threads/rtt timers 等 RTOS 命令树、内核对象 pretty-printer 与便利函数）窗口内提交「refactor(freertos): wrapup of new rtos support, code and docs quality enhance」，收尾 FreeRTOS 第二适配器。据其 README：RT-Thread（3.1.x / 4.0.x / 4.1.x，Cortex-A9 全系验证、RV64 自 4.0.4 起）仍是首要支持对象，窗口内完成的 FreeRTOS 通道（V10.3.0 ~ V11.3.x）在 QEMU 上补齐了 64 位 RISC-V lane 与 MPS2-AN521 双核 SMP 验证，属通用框架扩展、非 RT-Thread 专项提交，但对 RT-Thread 用户（含 RISC-V 目标）的 GDB 调试工具面是正向参照，收录作生态参考。

  • 内核侧：主仓库零合入进入第三窗口（最近合入 #11776，09-03），新 PR 仅 #11780 一件——SDIO CIS tuple 内存泄漏修复（1 文件 +2 行，qemu-vexpress-a9 验证），作者连续第三个组件级修复，评审队列无其他变化，release 仍 v5.2.2，蓄积期延续。
  • 生态侧：canopennode-rtt 一周内把 CANopenNode 移植从运动控制（CiA402 全模式）推进到通用 I/O profile（CiA401）与控制器侧支持，是当前社区最活跃的开发主线；GDB 调试辅助框架 gdr 完成 FreeRTOS 第二适配器收尾，RT-Thread 支持（含 RV64）保持为首要能力。
  • 官方/媒体侧：官方新闻 API 连续第 17 日静默；媒体侧 24h 窗口零新增报道（代理与源核查正常）；elexcon 2026（09-09~11 深圳）倒计时 3 天，会前静默属预期节奏。
