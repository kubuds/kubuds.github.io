RT-Thread周报（2026-09-30 ~ 2026-10-07）

2026-10-07 苦芽科技

报告周期：2026 年 9 月 30 日（周三）至 10 月 7 日（周三），共 8 天；国庆假期特别汇总期（10 月 1 日至 7 日为假期，日报暂停） 素材来源：本刊每日 RT-Thread 动态日报（2026-09-30 一期，窗口 09-29 11:00 ~ 09-30 11:00；10-01 ~ 10-07 假期无日报素材）；另含假期窗口组织核查（主仓库提交 / PR / Issue / Releases、env、软件包索引、Studio 与器件包组织、厂商下游、topic 检索）、官方新闻接口与社区论坛扫描、媒体与聚合渠道复核（覆盖至 10-08 晨） 编制说明：本周期横跨国庆假期——代码合入进入节内低产模式，评审验证、软件包筹备与社区运营保持运转；全部技术事实来自代码仓库、发布记录与社区渠道的实测核查

一、本周要闻

  • Next RISC-V 大重构假期持续多平台实测，创始人跟进推动（09-30 ~ 10-08）：5 月下旬创建、长期在审的主仓库 RISC-V 架构重构提案（#10320）在假期进入「实测驱动」阶段——社区测试者围绕玄铁 virt64/c906、qemu-virt64-riscv（RV64 四核）、玄铁 smartl/e907 与全志 D1/D1s 四类平台逐轮验证：先是 qemu-virt64 默认 AIA 配置卡在 PCI 且 NVMe 超时（10-02 反馈，当晚修复），10-03 复测默认配置连续三次进入 msh、NVMe 正常；随后修复 RV64 标准版未设 ABI 环境变量时的回退问题（按 FPU 自动取 lp64d，10-03）；e907 与 D1/D1s 适配补丁先后提供并完成打补丁与构建验证（D1/D1s 无开发板、未实机烧录，作者于 10-07 提请板卡协助）。创始人 Bernard Xiong 10-03 评论点赞并要求后续梳理状态清单；提案于 10-08 晨变基至含 lwIP 合并的最新主线（head e7b6e13f0），窗口内新增评论 42 条（含机器人检查），当前状态仍为开放评审。提案现为 164 个文件、+15164/-2611。

  • lwIP 2.2.1 合入主线（10-03）——假期唯一一笔合入：主仓库 PR #11797 由创始人合并：新增 lwIP 2.2.1 为可选版本（与 1.4.1 / 2.0.3 / 2.1.2 并存，不强制存量工程切换），4 个提交、402 个文件、+162255/-45；导入原始源码树、清理文档文件并修复 sio_write 签名冲突；验证平台为 NXP i.MXRT1180 评估板（m7 核）；对应需求 #11588（2026-07-08 提出）同日关闭。此前多周停留在评审队列的「网络协议栈升级」于本期完成落地。

  • RT-Thread Env 合入 WebUI 与插件开发工作流增强（10-03 ~ 10-04）：Env 工具完成一次面向开发体验的功能合入（PR #299，创始人提交、10-04 晚合并）——新增 WebUI 项目主页、构建、文档与网络设置界面；引入 epack 测试与市场发布工作流、插件图片图标与工作区启动要求、共享网络策略；配套命令失败退出码下发、venv 安装依赖说明与 VS Code 远程浏览器桥接。Env 从命令行工具向「可视化 + 插件化」演进。

  • 假期开发不中断：新开 4 条提案、多条评审刷新（10-01 ~ 10-07）：qemu-virt64-riscv 的 C-only Picolibc 构建选项（#11849，10-01）、blue-pill 的 STM32F103C6 支持（#11850，10-02）、STM32H723 板 SPI6 BDMA 支持（#11851，10-03）与 netdev ping 统计除零修复（#11853，10-06）相继开出；ESP32 系与 STM32 系多条在审提案（#11816 / #11847 / #11844 / #11819 / #11841）于 10-06 ~ 10-07 获刷新。

  • 软件包索引双提案：ESP32-C6 包版本与「ms-probe」诊断工具筹备入库（10-06 ~ 10-07）：索引仓库新增两条提案——乐鑫 ESP32-C6 相关包版本（#2043，10-07 凌晨）与官方诊断工具「ms-probe」（#2044，10-07；Microscope 嵌入式故障现场诊断 Probe，GPL-2.0 与商业双许可，设备端导出上下文、主机端解析现场与白名单内存）。两笔均待评审；索引主干假期无新合入。

  • 社区运营向「赛事与招募」汇聚：工博会 Workshop 招募、Edgi-X 挑战赛、嵌入式大赛作品（10-05 ~ 10-08）：工博会 RT-Thread Workshop（10 月 13 日上海专场）于 10-05 开启招募并预告多品类智能终端实物展示；RT-Thread 联合英飞凌与 FMT 发布「Edgi-X 全域载具适配挑战赛」（10-08 公告，基于英飞凌 PSoC-E83 异构双核的自驾仪平台，不限载具类型）；2026 嵌入式大赛作品帖节末密集出现（智能实验室管理终端、GD32H759 BLDC 电机控制、Edgi-Talk LVGL 指南等）。

  • 官方渠道静默延续至第 49 日（09-30 ~ 10-08）：官方新闻接口全期零新增（最新存档稿仍为 2026-06-17，连续停更自第三十二日延续至第四十九日）；官网新闻列表页仍不可直接核读。对外信息以论坛、媒体与商城渠道为主。
