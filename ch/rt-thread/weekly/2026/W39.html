RT-Thread周报（2026-09-21 ~ 2026-09-25）

2026-09-25 苦芽科技

报告周期：2026 年 9 月 21 日（周一）至 9 月 25 日（周五），共 5 个工作日、5 个发布日 素材来源：本刊每日 RT-Thread 动态日报（09-21、09-22、09-23、09-24、09-25，共 5 期）；另含 GitHub 组织窗口核查至 09-26 晨 编制说明：本周期覆盖 RT-Thread 内核与版本、工具链、生态厂商适配、社区活动与行业应用五个维度，条目均来自当期日报已核验信源

一、本周要闻

  • Gino Pi 生态全栈一周打通（09-21 ~ 09-23）：GD32H77D 开发板 Gino Pi 的主线 BSP 以系列提案形式进入评审（19 笔提交、142 个文件、净增约 2.6 万行，覆盖板级骨架、外设全家桶与演示工程）；同日器件支持包双仓新增 GD32H77x_78x 支持、AT 组件补上板载 GD32VW553 模块的 Wi-Fi 与 TCP socket 支持，此前 Studio SDK 侧已补齐 J-Link 依赖与链接脚本修正。板卡从「Studio 与厂商下游」走向「主线可维护」，是兆易创新与睿赛德合作线本周最实质的一步。
  • RISC-V 板级支持一日三连（09-24 ~ 09-25）：沁恒 CH32V203C8T6 BSP 完成主线合入（青稞 V4B 内核，提案到合入约两日）；乐鑫 ESP32-C6-DevKitC-1 BSP 提案进入评审，并同步提交 esp-idf 软件包 C6 构建源码；社区发布 RT-Thread Nano 免 IDF 移植工程（ESP32-S31 双核 RISC-V、320 MHz）。三款 RISC-V 芯片集中出现在板级链路上，RISC-V 在 RT-Thread 板级生态中的比重继续上升。
  • 主线全周合入 13 笔：周一晨间九笔集中批次（网络 AT 通道主机名校验收紧、SDIO 双内存泄漏修复、STM32H7 UART4 接收 DMA、GD32 USART 引脚修正、Rust 目标选择与 QEMU 文档等）、周一下午两笔（英飞凌 PWM 宏错配、CherryUSB N32H4x USBFS 支持）、周三 CI 流程调整（clang-format 提交不再跳过流水线）、周四 CH32V203 BSP，均已落地。
  • 评审队列单周 22 条新提案与 2 条缺陷报告（09-21 ~ 09-24）：含历史遗留缺陷七连加固系列（总线互斥、电源管理、USB 主机、IPC、块设备、OpenAMP、virtio）、国民技术 N32H 定时器补全（39 个文件、约四千行）、lwip-nat 端口分配与 lwip-dhcpd 头文件缺失、rt_vsnprintf 宽度语义缺陷修复等，质量向修复构成主体。
  • 软件包索引三连合并（09-24）：CanopenNode v1.2.0 完成九处 Kconfig 重构（CiA 401 设备开关整合为通用设备剖面体系）、「虚拟传感器」新包入列（模拟数据生成、可选 MQTT 上报）、AI Agent 包新增 MQTT 工具与 rt_vsnprintf 能力自动检测机制。
  • 瑞萨 Titan Mini 端侧视觉双推进（09-22、09-24）：OpenMV 工程先完成 SDRAM 时序与内存池优化（Tiny YOLOv2 INT8 单帧推理 156.10 ms 降至 58.49 ms，YOLOv8n 256×256 由 186.54 ms 降至 38.33 ms），再接通板载 800×480 RGB 屏幕，新增 LCD 显示与色块追踪示例；行业媒体同期跟进报道。
  • 工具链与配套生态多点更新（09-18 ~ 09-22）：RT-Thread Studio 配套切换至 v5.3.0 内核、J-Link 调试器升级至 V9.76a（跨年度更新）；STM32H7 器件包与 HAL 驱动包双发布（v1.10.7 / v1.11.6）；第三方 GDB 调试框架 GDR 发布 2026.03。
  • 官方渠道静默第三十二日至第三十六日；活动侧以工博会与产教为主：工博会 Workshop 详情公布（10 月 13 日上海专场、25 套智能小车教具）、临港「场景直通车」睿赛德闭门对接会补录、RSOC26 夏令营教程体系化开篇；官方新闻接口全周无新增。

二、内核与版本动态

版本与主线

  • 无新版本发布：最新正式版本仍为 09-10 发布的 v5.3.0；本周期为发布后的常态消化期，工作重心在评审队列与配套落地。
  • 合入节奏：全周 13 笔合入呈「一头集中、全程低频」分布——周一晨间九笔与下午两笔为峰值，周三、周四各一笔，其余时段主线静默。
  • 配套跟随（09-20）：RT-Thread Studio 的 SDK 索引与内置内核源码切换至 v5.3.0，调试器构件把 J-Link 升级至 V9.76a（上一版为 2025 年 7 月的 V8.48）；v5.3.0 内核发布十天后配套完成跟随。
  • 工具链现状：Env 工具链窗口内无新提交与发布（最新为 09-16 的 v2.0.2）；软件包索引仓库除 09-24 三笔合并外无其它动作。

本周合入主线的修复（按时间）

  • 网络 AT 通道主机名校验收紧，形似数字的超长主机名直接拒绝，消除栈缓冲越界写入隐患（09-21，#11782）
  • SDIO 两笔内存泄漏修复：CIS 元组分支临时内存未释放（09-21，#11780）、驱动注销节点泄漏闭环（09-21，#11806）
  • STM32H7 通用 DMA 补上 UART4 接收侧通道定义（09-21，#11808）
  • 块设备分区组件日志格式符与参数类型修正（09-21，#11809）
  • GD32 系列 USART 收发引脚初始化修正，发送改复用推挽、接收改上拉输入，覆盖 E50x 至 F30x（09-21，#11804）
  • Rust 工具链 Cortex-M33 硬浮点目标判定修正（09-21，#11811）
  • QEMU Linux 快速开始指引与文档高危命令清理两笔（09-21，#11790 / #11793）
  • 英飞凌 PWM 宏错配修复主线闭合，与评估板 BSP 修正同源（09-21，#11802）
  • CherryUSB 新增国民技术 N32H4x 系列 USBFS 设备侧支持（09-21，#11764）
  • clang-format 自动提交不再跳过持续集成，格式化结果纳入构建验证链路（09-23，#11830）
  • 沁恒 CH32V203C8T6-EVT-R0 BSP 合入，含 D6 向量表、64KB/20KB 链接脚本与两处共享驱动修复（09-24，#11827）

安全与缺陷

  • rt_vsnprintf 宽度语义缺陷与修复（09-24）：最小宽度被误作最大宽度截断（如 %3s 把 “abcdef” 截成 “abc”，左对齐与星号宽度变体同样受影响）；缺陷报告与修复提案同日提交，修复覆盖标准版与 tiny 版实现及单元测试（3 个文件），处于评审状态。
  • 历史遗留缺陷七连加固（09-22 提交，评审中）：同一贡献者一次性提交七条修复，覆盖两线串行总线控制与传输互斥、电源管理按挂起模式成对恢复、USB 主机接口数量边界、IPC 消息队列路径终止符边界、块设备逻辑分区越界读写、STM32 OpenAMP 接收边界与环形回绕、virtio 输入偏移校验；均引用数月前存量缺陷报告并附 GCC 16.1 构建与边界用例验证。
  • bluepill BSP 文档缺陷报告（#11818）：快速上手缺少重新生成 MDK 工程步骤，按文档操作无法编译。
  • 前周四项安全类 issue（tmpfs、消息队列、pread、finsh）公开记录中未见逐条对应修复提交，本周期无更新。

评审队列观察

  • 两批单夜集中提交构成新增主体：09-21 至 09-22 凌晨八条（N32H 定时器补全 39 个文件约四千行、STM32 以太网 ops 适配与 adcv2 日志等级、lwip 宏开关化、RA6W1 资源分配、ESP32-C3 Windows 构建、单元测试性能用例时钟依赖、bluepill 文档等）；09-22 夜间八条（缺陷加固系列七条＋CH32V203 BSP）。
  • 网络栈修复集中：lwip-nat 端口分配缺陷与 lwIP 2.1 适配（#11831）、lwip-dhcpd 补 string.h 头文件（#11835）、netdev AF_NETLINK 构建修复（#11828）。
  • 大提案持续待审：GD32H77D GinoPi 外设系列（#11829，142 个文件）、网络协议栈升级（lwip 2.2.1）长线等待、N32H 定时器补全。
  • 构建与整理类：ipc SConscript 冗余宏清理（#11832）、bluepill 文档修正（#11817）；另有 ESP32-C6 板级提案（#11836，见第三章）。
  • 旧提案恢复活动：#10689（2025 年 9 月创建）于窗口末恢复讨论。

三、生态与厂商适配

厂商 BSP

  • 兆易创新（GD32H77D / Gino Pi）：主线 BSP 系列提案进入评审——19 笔提交、142 个文件、净增约 2.6 万行，覆盖板级骨架（工程、链接脚本、rtconfig）、外设全家桶（以太网、USB 主机与设备、SDRAM、硬件 I2C、SPI3、PWM、SDIO 与文件系统、RTC 与闹钟、看门狗、CAN 与 CAN FD、OSPI Flash、MIPI LCD、GT911 触摸、OV7670 摄像头、LVGL）与演示工程；板载 GD32VW553 无线模块的 UART4 AT 通信与 MAC 查询已验证，Wi-Fi 关联尚待完成（默认关闭）。
  • 兆易创新（器件包与联网组件）：gd32-arm-cmsis 与 gd32-arm-series 双仓新增 GD32H77x_78x 支持（CMSIS 器件层与新外设库）；at_device 新增 GD32VW553 Wi-Fi 设备与 TCP socket 支持。
  • 瑞萨（RA8P1 Titan Mini）：OpenMV 工程完成外部 SDRAM 时序/时钟配置与片内 SRAM 主垃圾回收池扩容（1344 KiB 至 1472 KiB），三个模型推理耗时实测下降（最高约 4.9 倍）；随后新增 RGB 接口 800×480 屏幕驱动（RGB565）与 LCD 基础显示、相机预览、红色色块追踪示例（17 个文件、约 1200 行）。
  • 沁恒（CH32V203）：BSP 合入主线（见第二章），配套 drv_usbd 的 USBFS DMA 时序与 drv_iwdt 看门狗共享驱动修复；D6 型仅 64KB Flash / 20KB SRAM，USB 与其余外设需按容量取舍。
  • 乐鑫（ESP32-C6 / ESP32-S31）：ESP32-C6-DevKitC-1 BSP 提案（40 个文件、+9492 行）与 esp-idf 软件包 C6 构建源码提案同步送审（该贡献者与 CH32V203 提交者为同一人）；社区 ESP32-S31 免 IDF 移植工程已做可复现构建验证（89 个跟踪文件、逐字节一致镜像）。
  • 英飞凌（PSoC6）：PWM 宏错配修复在主线闭合；评估板 BSP 同步完成跨工程修正。
  • GD32 下游仓库：PR #71 驱动更新分支刷新并进入评审互动（USART、SPI 与两线串行总线驱动的 GPIO 初始化版本更新），尚未回流主线。

软件包与中间件

  • 软件包索引三连合并（09-24）：CanopenNode v1.2.0（九处 Kconfig 重构、通用设备剖面体系、逻辑设备注册表与传输契约）、「虚拟传感器」新包（模拟数据生成、可选 MQTT 上报）、AI Agent 包（MQTT 工具、按内核符号自动检测 rt_vsnprintf 能力，避免 4.1.x 内核重复定义）；三条积压约两周的提案同日合入。
  • STM32H7 器件包与 HAL 驱动包双发布（09-18）：器件包 v1.10.7（补齐 TIM23 / TIM24 实例、修正 GPIO 位定义笔误）、HAL 包 v1.11.6（并入约二十笔上游同步，覆盖 USB 零长包、以太网 10M 速率、SDMMC 时钟、I2C 死锁、AES-GCM/CCM、FDCAN 过滤、DMA 回调等）。
  • GDR 2026.03（09-22）：第三方 GDB 调试框架新增 RT-Thread 对象汇总命令与 git 风格结构化帮助体系，修复初始化策略校验失败终止会话的问题；支持 RT-Thread 3.1.x / 4.0.x / 4.1.x，Cortex-A9 与 RV64 目标已闭环验证。

核验说明

  • 上周期末已收录事项（媒体视角综述、工博会 Workshop 招募稿）本期不重复立条目，仅在信息更新时增量呈现。
  • Gino Pi 主线提案的合入形态（是否拆分、外设取舍）以评审结论为准；GD32VW553 的 Wi-Fi 关联与 TCP / MQTT 流量尚未完成验证（提交说明自述）。

  • RISC-V 成为板级增量主力：一周内沁恒 CH32V203 合入、乐鑫 ESP32-C6 送审与 ESP32-S31 免 IDF 移植接连出现，加上兆易创新 GD32VW553 无线模块支持，板级链路的新增动作几乎全部落在 RISC-V 芯片上。
