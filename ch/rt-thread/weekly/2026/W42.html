RT-Thread周报（2026-10-12 ~ 2026-10-16）

一、本周要闻

  • Next RISC-V 大重构合入主线，内核版本号同步升至 v5.4.0（10-17）：跟踪近五个月的主仓库 RISC-V 架构重构提案（#10320，作者 GuEe-GUI）由维护者 Rbb666 于 10-17 09:44 合入 master，4 个提交、165 个文件、+15134/-2617；合并前一分钟（09:43）另一笔提交（#11875）已将内核版本号 bump 至 v5.4.0（版本宏 5.4.0）。正式 Release 与标签尚未落地，发布页最新仍为 09-10 的 v5.3.0、ChangeLog 最新章节亦仍为 v5.3.0。该项发生在周五日报截点（10-16 08:00）之后，属发布日核查补录。

  • 本周合入 15 笔，10-14 上午 64 分钟内连落 8 笔（10-12 ~ 10-16）：周一 2 笔（#11863、#11787）、周二零合入（master 静默约 46 小时）、周三 8 笔（09:13 至 10:17）、周四 4 笔、周五 1 笔（#11846，在日报告截点之后）。合入主题集中在网络栈健壮性、内存与边界安全、厂商 BSP 三组，呈维护者批量收口形态。

  • 9PFS 文件系统连曝两枚缺陷，其一评级 CVSS 3.1 7.5（10-15）：新开缺陷单 #11868 指出接收路径的 64 位取值宏以普通指针解引用缓冲（结构体尺寸 292 与协议常量 42 使 rx_buffer+42 恒为 6 mod 8），ARMv7-A 下 GCC 生成的 LDRD 要求 8 字节对齐，任何合法 Tstat 应答都会在 dfs_9pfs_open 与 dfs_9pfs_stat 触发 data abort；报告定位到 2025-12 引入 9PFS 的提交，给出远程拒绝服务评级与 QEMU vexpress-a9 完整复现链，并附反汇编与 addr2line 佐证。另一枚 3 月开出的 #11289（getdents 路径越界读）获社区在 master（bsp/simulator 加 ASan）复现确认。两案均维持开放。

  • 网络栈健壮性闭环：ping 两案与 lwip 宏控制接连落定（10-14 ~ 10-15）：#11853 修复目标不可达时 ping 统计除零导致 shell 崩溃，缺陷单 #11852 同日关闭；#11866 修正末包延时逻辑（原循环判断恒假导致最后一包后仍补时延、且以 0 参调用延时接口），#11865 同日关闭；同方向早期提案 #11862 关闭未合入。#11815 的 lwip 段内容宏控制经多轮扩展后于 10-15 13:28 合入，6 文件 +188/-28。

  • 内存与边界加固成为并行主线（10-12 ~ 10-15）：内核 calloc 整数溢出修复（#11848）、legacy USB host 接口数上界与枚举清理（#11822，缺陷单 #11288 关闭）、设备树 ofw phandle 哈希表两处越界修正（#11845）、DHCP 服务器选项边界校验（#11858，期初承接）先后合入；堆内存 AddressSanitizer 提案（#11772）增补 rt_memcpy、rt_memset 与 rt_memmove 范围检查及边界用例，报告最新 CI 全部通过。

  • 评审队列高密度互动，新贡献者接手多条线（10-13 ~ 10-16）：ESP32-C6 SPI 提案（#11846）获维护者三条行级意见（关闭 DMA 后单次传输 64 字节上限需分段、C3 与 C6 共用 IDF 时构建互写、位宽校验需前移），作者逐条整改后于 10-16 11:31 合入；efm32 menuconfig 新手任务（#7530）由贡献者认领后 1 分钟开出提案（#11867，2 文件 +408）；DFS 层 F_GETFL 与 F_SETFL 同设备控制命令撞码的消歧提案（#11869）开出；aarch64 GIC 应答路径讨论给出数十万次推理级实测数据。

  • 生态与工具链：hpm_sdk v1.13.0 完成「标签、索引、BSP」闭环（10-13 ~ 10-17）：上游包仓库 10-13 发布 v1.13.0 标签（新增 HPM5100 系列），packages 索引提案 #2045 于 10-14 18:41 合入，为索引仓库半个月来首笔；主仓库 BSP 侧 10-17 升级至 v1.13.0 并新增 hpm5100evk 支持（#11871）。同期 Env 工具 10-17 合并 PR #302（WebUI 内建文档导航）并将版本号 bump 至 v2.0.3，Release 页最新仍为 09-16 的 v2.0.2。

  • 社区内容维持日均两帖，赛事与教学双线输出（10-12 ~ 10-15）：2026 嵌入式大赛作品帖本周 5 篇（便携式调试器、目语心声、GD32H759IM USB 副屏、环境监测记录仪、舒衡智养理疗机械臂），主控均为 GD32H7 系列；工博会 AI 小车 Workshop 复盘（10-15）与 RK3588 虚拟化混合部署教学平台（10-13）先后刊出；官方新闻接口静默延续至第五十七日。

安全与缺陷

日期：2026-10-12 ~ 2026-10-15　来源：Issue #11868

  • 新组件进入集中审计期：9PFS 本周两枚缺陷（远程拒绝服务 #11868、越界读 #11289）是本周最重的安全问题，前者自带复现链、反汇编与addr2line 佐证，后者获 master 上的 ASan 复现确认。
  • 边界类修复成组落地：calloc 整数溢出、USB host 接口数上界、ofw phandle 哈希表越界、DHCP 选项越界读取四处，覆盖内存分配、外设枚举、设备树与网络协议解析四个层面。
  • 旧单获社区接手：#5073（串口 POSIX ioctl 无法设置底层参数，核对确认问题在 dfs_v1 中仍存在）、#6568（DAC 文档示例，修复已合入、文档呈现格式待修正）、#5913（2022 年创建的 at_gethostbyname 溢出报告单，社区要求明确处置方向与负责人）。
  • 随修复关闭的缺陷单：本周 #11852、#11865、#11288、#11323、#11778、#11739 六单关闭（含期初承接两单长期挂起项）。

评审队列观察

日期：2026-10-13 ~ 2026-10-16　来源：PR #10320

  • RISC-V 方向最活跃：#10320 全周多轮迭代——10-13 提交 QEMU 五组配置实测报告（S-Mode 关闭设备模型组合因缺少公共启动与多核调度符号而链接失败），维护者给出「设备模型与无设备模型二选一」的适配口径，同日晚贡献者在 ESP32-C3 实板验证两枚配套补丁、C3 与 C6 均编译通过且零告警；10-15 11:51 推送 libcpu 级重构提交（6bf3686），跟踪单 #11246 同步刷新。
