RT-Thread周报（2026-09-14 ~ 2026-09-20）

2026-09-20 苦芽科技

报告周期：2026 年 9 月 14 日（周一）至 9 月 20 日（周日），共 7 个自然日、5 个发布日 素材来源：本刊每日 RT-Thread 动态日报（09-14、09-15、09-16、09-17、09-18，共 5 期）＋ RT-Thread 微信公众号本期推送（9 篇） 编制说明：本周期覆盖 RT-Thread 内核与版本、工具链、生态厂商适配、社区活动与行业应用五个维度，条目均来自当期日报与公众号推文已核验信源

一、本周要闻

  1. RT-Thread v5.3.0 重大版本更新，官方更新日志本周推送（公众号）：新增 Rust 语言支持（ARM / AArch64 / RISC-V），设备模型大幅增强并引入 DVFS 动态调压调频与 VirtIO 1.2，内核修复 IPC / LWP 超时唤醒竞争、新增 8 位与 16 位原子操作，BSP 侧新增树莓派 5、玄铁 C908X、GD32VW553 等平台。
  2. 玄铁 C908 平台 RISC-V 支持三连合入（09-15）：rt-smart、MMU 与 SMP 支持一并进入主线，合计 31 个文件、新增约 2575 行、删除 565 行，MMU 补齐 SV39 / SV48 / SV57 地址模式，验证平台为 QEMU 仿真的 xiaohui C908。该核由此从单核运行进入可做多核用户态验证的阶段。
  3. Gino Pi 开发板形成发售、适配、调试完整链路（09-15 ~ 09-16）：09-15 联合兆易创新正式发售（首发优惠 80 元）；09-16 补齐 JLink 调试链路（50 个示例工程）；同期睿擎工业开发平台首发适配 Gino Pi，提供 RuiChing Studio 一站式环境与 12 个开箱即用示例工程。
  4. env 工具链跃迁至 v2.0.0 并即时补发 v2.0.2（09-16）：版本号由 1.5.x 直达 2.0.0，为 2024 年 4 月以来首次发布；配置系统以 kconfiglib 重构、Windows 侧改为注册命令、新增 sdk 命令与 e-build 嵌入式构建系统、引入 env.json 作为单一信息来源、分发名调整为 rt-env。
  5. 媒体集体聚焦 elexcon：25 亿装机量与三重最高等级认证（公众号）：第 23 届深圳国际电子展期间，大公报、南方日报、广州日报、广东广电粤TV、深圳广电等密集报道 RT-Thread：累计装机量突破 25 亿台、开发者超 30 万；RT-Thread Safety OS 同时持有 IEC 61508 SIL3、EN 50128 SIL4 与 ISO 26262 ASIL-D 三重认证，国内仅此一家；展会期间获「边缘 AI 解决方案创新奖」。
  6. 高校产教融合与国际化布局提速（公众号＋09-17 官方稿）：国内已与约 200 所高校建立合作；海外以东南亚为支点，泰国多所院校（Thammasat、Mahidol、KMUT 系等）合作落地后，8 月初马来西亚之行与 Wawasan Open University 签署校企合作协议，并与 USM、UM、UNITEN 等多校就课程共建、联合实验室深入沟通。
  7. 高校赛事与社区内容密集产出（09-15 ~ 09-18）：第九届全国大学生嵌入式芯片与系统设计竞赛全国总决赛结果公布，深圳技术大学斩获特等奖 RT-Thread 杯及全国一等奖 3 项；社区论坛入门教程连载、竞赛开源工程与图形化配置工具讨论帖构成窗口内新增内容主体。

二、内核与版本动态

版本与主线

  • v5.3.0 重大版本更新（09-10 发布，官方更新日志本周推送）：这是 RT-Thread 近年最具分量的一次主版本更新，核心亮点在于新增 Rust 语言支持，并大幅增强 SoC 上基于设备树的设备模型（DM），引入动态电压与频率调节（DVFS）和 VirtIO 1.2 等关键特性。
  • 版本收尾后主线恢复常态合入（09-14 起）：本周期合入覆盖外设驱动增强、新系列 BSP 落地、架构后端补齐与链接脚本修复，主线版本号维持 v5.3.1，窗口内无新版本发布，最新正式版仍为 09-10 的 v5.3.0。
  • 工具链一周两度发版：期首日报收录 Env v1.5.3（09-10 发布，为该工具自 2024 年 4 月以来首个版本）；六天后 env 连发 v2.0.0 与 v2.0.2（09-16），版本号跃迁至 2.0.0。

v5.3.0 主要变化（据官方更新日志）

  • 内核：修复 IPC 与 LWP 等待流程中超时唤醒处理权的竞争问题；新增 8 位与 16 位原子操作支持；按采样窗口增量统计计算线程近期 CPU 使用率；禁止挂起空闲线程；线程被删除时释放其持有的互斥锁。
  • Rust 支持：新增 Rust 组件，支持 ARM、AArch64 和 RISC-V 目标检测，集成 SCons / Cargo；提供线程、互斥锁、信号量、消息队列、内存、时间和文件的 Rust 封装，以及应用、组件和动态模块示例；新增用于初始化和命令注册的过程宏。
  • 设备模型（DM）：扩展设备模型 API、设备探测、属性访问和 OFW 支持，并在 Cortex-M 目标上启用 OFW；时钟框架重构并新增 DVFS（含 CPU 与设备频率管理）、ARM SCMI 固件集成、通用机器电源接口；新增 UFS、DesignWare AHCI、通用 MTD、NVMEM 支持；新增 VirtIO 1.2（紧凑队列、MMIO / PCI 传输与 DMA 同步）及 9P、加密、RNG、SCMI、SCSI 驱动；新增 RPMSG 与 TEE 支持；新增 IEEE 1588 PTP 时钟支持。
  • RISC-V：为 QEMU virt64 和玄铁 C/R 系列处理器新增 SMP 支持；新增玄铁 C908X 处理器支持；新增 C908 Svpbmt 支持并修正 C906 / C908 可缓存属性与页表属性。
  • 文件系统与网络：DFS 新增 9PFS 支持（用于与 QEMU 等虚拟机共享文件），Elm FatFs 更新至 R0.16；网络新增可选 AF_UNIX 流式与数据报套接字（支持 SCM_RIGHTS 描述符传递），新增无需网络设备的 SAL 本地协议提供者。
  • BSP 新平台：树莓派 5（BCM2712 / RP1 设备模型）、玄铁 XiaoHui C908X、GD32VW553H-EVAL、NXP FRDM-i.MX91 与 i.MX RT1180 EVK、瑞萨 EK-RA6W1 与 RA8P1 Titan、瑞芯微 RK3528、STM32F407 MICU、HC32F4A2、N32H760 / 497 / 487、NS800RT7P65 等。
  • 工具与 CI：完善 VS Code 编译数据库处理；Keil 工程生成保留 SCons 头文件搜索路径优先顺序；Zig 构建脚本适配 Zig 0.14+；新增 ArmClang BSP 构建覆盖、SMP 自动化测试与 MemBrowse 内存使用报告；使用 clang-format 进行格式检查；新增 Issue 自动化。

安全与缺陷

  • 四项安全类 issue 集中关闭（09-13）：涉及 tmpfs 路径分量栈缓冲溢出、POSIX 消息队列名处理的无界栈溢出与差一错误、pread 大负偏移越界堆读、finsh 补全结果未裁剪导致的堆越界写（#11735 ~ #11738），四项于 09-13 下午集中标记关闭，公开记录未见与之逐条对应的修复提交。
  • SDIO 驱动注销失败与节点内存泄漏（09-12 报告，09-17 修复提案）：原逻辑仅在匹配到 SDIO 卡时才释放驱动注册节点，无卡或不匹配时节点不释放，反复注册与注销会造成内存泄漏；修复方案为不区分是否存在匹配卡都从驱动链表移除并释放节点，仅在匹配到卡时继续调用移除回调。
  • STM32 固件超容量缺陷关闭（09-17）：该报告自今年 1 月提交以来长期未闭，本次随链接脚本容量校验修复一并关闭。

评审队列观察

  • 窗口末尾三笔常态化修复进入评审（09-17）：STM32H7 通用 DMA 补充 UART4 接收侧定义（#11808）、块设备分区组件日志格式符与参数类型修正（#11809）、LLVM ARM 持续集成依赖补齐（#11807，已于当日合入）。

六、趋势观察

  • 主版本节奏确立：v5.3.0 以 Rust 支持、设备模型与虚拟化为核心卖点，半年一个主版本的发布节奏与工程化含量同步抬升；更新日志的公开粒度（内核、组件、BSP、CI、文档逐项列明）也体现出维护流程的成熟度。
  • RISC-V 主线适配加速：玄铁 C908 的 rt-smart、MMU 与 SMP 三连合入与 v5.3.0 中的 C908X、SMP 支持形成呼应，RISC-V 方向从单核裸跑走向多核用户态验证，与惰性 FP/RVV 提案属同一方向上的持续推进。
  • 工具链现代化落定：env 从 1.5.x 跃迁至 2.0.0，命令行化、配置系统重构与镜像地址单源化会直接影响开发者日常构建流程，建议升级前关注兼容性说明。
  • 商业闭环加速：Gino Pi 完成索引、发售、调试链路与平台适配的完整周期，芯片厂联合开发板模式（兆易创新）、工业平台（睿擎）与整车 OS（程翧）构成清晰的产品化路径。
  • 国际化与产教融合并行：泰国、马来西亚高校合作落地，配合国内约 200 所高校的产教融合网络，「五维模型」（课程、实验室、师资、认证、人才输送）正在成为生态扩张的标准打法。
  • 端侧 AI 是贯穿主线：从 AIOS 理念、AI KIT 工具平台、飞控与机器人案例到工博会 Workshop，端侧 AI 的落地叙事覆盖了技术、产品与市场三个层面，与「人工智能＋」政策方向形成共振。
