RT-Thread周报（2026-09-11 ~ 2026-09-18）

2026-09-18 苦芽科技

报告周期：2026 年 9 月 11 日（周五）至 9 月 18 日（周五），共 8 个自然日、6 个发布日 素材来源：本刊每日 RT-Thread 动态日报（09-11、09-14、09-15、09-16、09-17、09-18，共 6 期） 编制说明：本周期覆盖 RT-Thread 内核与版本、工具链、生态厂商适配、社区活动与行业应用五个维度，条目均来自当期日报已核验信源

一、本周要闻

  1. 玄铁 C908 平台 RISC-V 支持三连合入（09-15）：rt-smart、MMU 与 SMP 支持一并进入主线，合计 31 个文件、新增约 2575 行、删除 565 行，MMU 补齐 SV39 / SV48 / SV57 地址模式，验证平台为 QEMU 仿真的 xiaohui C908。该核由此从单核运行进入可做多核用户态验证的阶段。
  2. RISC-V 惰性 FP/RVV 上下文切换提案获内核维护者正面回应（09-15）：OSPP 2026 议题指出 RISC-V 移植层每次上下文切换都无条件保存与恢复完整 FPU 状态、且完全不支持向量扩展 RVV，维护者认可这是很好的性能优化提案并欢迎提交 PR。
  3. env 工具链跃迁至 v2.0.0 并即时补发 v2.0.2（09-16）：版本号由 1.5.x 直达 2.0.0，为 2024 年 4 月以来首次发布；配置系统以 kconfiglib 重构、Windows 侧改为注册命令、新增 sdk 命令与嵌入式构建系统、引入 env.json 作为单一信息来源、分发名调整为 rt-env。
  4. 两大 BSP 提案窗口内先后合入主线（09-16）：意法半导体 STM32N657 Nucleo BSP（83 文件、新增约 17884 行）与国民技术 N32H 三系列驱动扩展（70 文件、新增约 8096 行、删除 2778 行）先后落地，从送审到合入约五至六天；配套的 STM32N657xx FSBL 软件包索引已于 09-14 先行合入，该系列在 BSP 与软件包两侧至此齐备。
  5. Gino Pi 开发板形成索引、发售、适配完整链路（09-11 ~ 09-16）：09-11 进入 RT-Thread Studio SDK 索引（GD32H77D-Gino BSP v1.0.0，包体 138 MB），09-15 联合兆易创新正式发售（首发优惠 80 元），09-16 补齐 JLink 调试链路（50 个示例工程）并获睿擎平台首发适配。
  6. 存量缺陷集中收口（09-12 ~ 09-17）：STM32 各区链接脚本的容量校验缺陷完成修复并合入，覆盖 110 个链接脚本，同期关闭今年 1 月提交、挂起约八个月的缺陷报告；SDIO 驱动注销内存泄漏从缺陷报告（09-12）到修复提案（09-17）约两天，另有四项安全类 issue 于 09-13 集中关闭。
  7. 高校赛事与社区内容密集产出（09-15 ~ 09-18）：第九届全国大学生嵌入式芯片与系统设计竞赛全国总决赛结果公布，深圳技术大学斩获特等奖 RT-Thread 杯及全国一等奖 3 项；社区论坛入门教程连载、竞赛开源工程与图形化配置工具讨论帖构成窗口内新增内容主体。
  8. 官方新闻通道全周期零更新：官方新闻接口最新条目停留在 2026-06-17，连续第二十二日至第二十九日无新增，产品发售与活动预告均由公众号、官网商城与论坛渠道首发。

二、内核与版本动态

版本与主线

  • v5.3.0 发布收尾（期首日报 09-11 收录，事件日期 09-10）：v5.2.2 至 v5.3.0 变更日志合入 master，主线版本号推进至 v5.3.1；beta 阶段修复以 14 个提交、23 个文件回移主线，三者与 Release 发布在同一傍晚密集落地。
  • 版本收尾后主线恢复常态合入（09-14 起）：本周期合入覆盖外设驱动增强、新系列 BSP 落地、架构后端补齐与链接脚本修复，窗口内无新版本发布，最新正式版仍为 09-10 的 v5.3.0。
  • 工具链一周两度发版：期首日报收录 Env v1.5.3（09-10 发布，为该工具自 2024 年 4 月以来首个版本）；六天后 env 连发 v2.0.0 与 v2.0.2（09-16），版本号跃迁至 2.0.0。

本周合入主线的修复（按时间）

  • QEMU 入门文档两处修正合入，补齐 apt 依赖包并更新失效的工具链下载链接（09-11，#11789 / #11794）
  • STM32 SPI BDMA 支持合入，DMA / BDMA / GPDMA 三类搬运通道配置统一（09-14，#11689）
  • 玄铁 C908 平台 rt-smart、MMU 与 SMP 支持三连合入（09-15，#11775）
  • STM32 以太网驱动完成新版硬件抽象层接口迁移，已在 F4 与 H7 两个平台验证（09-15，#11781）
  • STM32N657 Nucleo BSP 合入主线，八十三文件、新增约 17884 行（09-16，#11799）
  • 国民技术 N32H 三系列驱动扩展合入主线，覆盖三块评估板（09-16，#11800）
  • 小华半导体 HC32 系列 BSP 配置同步合入主线，五十二文件（09-16，#11798）
  • STM32 直接存储器访问驱动类型名函数的链接问题修复（09-16，#11803）
  • STM32 GCC 链接脚本容量校验修复，覆盖 110 个链接脚本（09-17，#11805）
  • LLVM ARM 持续集成依赖修复合入，为该流水线补装终端信息库依赖（09-17，#11807）

安全与缺陷

  • 四项安全类 issue 集中关闭（09-13）：涉及 tmpfs 路径分量栈缓冲溢出、POSIX 消息队列名处理的无界栈溢出与差一错误、pread 大负偏移越界堆读、finsh 补全结果未裁剪导致的堆越界写（#11735 ~ #11738），四项于 09-13 下午集中标记关闭，公开记录未见与之逐条对应的修复提交。
  • SDIO 驱动注销失败与节点内存泄漏（09-12 报告，09-17 修复提案）：原逻辑仅在匹配到 SDIO 卡时才释放驱动注册节点，无卡或不匹配时节点不释放，反复注册与注销会造成内存泄漏；修复方案为不区分是否存在匹配卡都从驱动链表移除并释放节点，仅在匹配到卡时继续调用移除回调。
  • STM32 固件超容量缺陷关闭（09-17）：该报告自今年 1 月提交以来长期未闭，本次随链接脚本容量校验修复一并关闭。

评审队列观察

  • 网络协议栈升级长线：lwip 2.2.1 支持提案（#11797）窗口内多次重推迭代，规模 1874 个文件、新增约 34.6 万行，验证平台为恩智浦 i.MX RT1180 评估板，第三方内存比对判定未引入内存占用变化，是否合入仍待观察。
  • 新 BSP 与国产 MCU 驱动密集送审：STM32N657 Nucleo BSP 在 09-14 单日四次强制推送修复持续集成问题；国民技术 N32H 三系列在评审线程中逐条回应自动评审问题后重推；小华半导体 HC32 系列、意法半导体 STM32N657 系列等构成评审队列主体。
  • 窗口末尾三笔常态化修复进入评审（09-17）：STM32H7 通用 DMA 补充 UART4 接收侧定义（#11808）、块设备分区组件日志格式符与参数类型修正（#11809）、LLVM ARM 持续集成依赖补齐（#11807，已于当日合入）。
  • 架构后端由评审转入合入：达摩院玄铁 C908 的 QEMU rt-smart 支持（#11775，08-31 开启）于 09-15 完成合入，MMU 三种地址模式与 SMP 同时到位。

三、生态与厂商适配

厂商 BSP

  • 兆易创新（Gino Pi / GD32）：Gino Pi 进入 Studio SDK 索引（09-11）；联合睿赛德正式发售，首发优惠 80 元（09-15）；Studio BSP SDK 增加 JLink 调试链路，两笔提交合计 50 个文件（09-16）；GD32 下游板级仓库统一两线串行总线直接存储器访问开关命名并修复 207I 系列评估板构建（09-18）；GD32 串口收发引脚初始化修复提案进入评审，把发送脚配为复用推挽、接收脚配为上拉输入，影响 E50x / F10x / F20x / F30x 四系列（09-16，#11804）。
  • 意法半导体（STM32）：STM32N657 Nucleo BSP 合入主线，为该系列首次进入主线支持列表；STM32N657xx FSBL 软件包索引先行合入（09-14）；STM32 以太网驱动迁移新版硬件抽象层接口（09-15，8 文件、新增 755 行、删除 968 行）；STM32F4 器件支持包批量同步，默认向量表基址指向内部闪存基址并修正位定义（09-17）；STM32 GCC 链接脚本容量校验修复（09-17，110 个脚本）。
  • 国民技术：N32H47x / N32H48x、N32H49x、N32H7xx 三系列驱动扩展合入主线，共用驱动层新增 ADC、DAC、I2C、SPI 配置头文件并扩展以太网、GPIO、硬件 I2C、NAND、QSPI、SDRAM、串口与看门狗等驱动分支，三块评估板同步加入持续集成编译矩阵（09-16）。
  • 小华半导体：HC32 系列 BSP 配置同步合入，五十二文件、新增约 2844 行，含工程文件重生成、格式整理与串口中断驱动编译错误修复（09-16）。
  • 恩智浦：作为 lwip 2.2.1 提案的验证平台提供 i.MX RT1180 评估板支持；另有基于 N947 平台的遥控器技术直播预告（09-16）。
  • 英飞凌：PSoC6 评估板的 PWM 条件编译宏错配修复提案进入评审，宏名与板级配置不一致导致滑块示例的 PWM 初始化代码被整段编译掉，改动涉及 14 个文件（09-16，#11802）。
  • 版本级全景（v5.3.0 BSP 板块，期首日报收录）：覆盖瑞萨、兆易创新、恩智浦、意法半导体、瑞芯微、树莓派、达摩院玄铁、芯来等；其中达摩院玄铁新增 XuanTie XiaoHui C908X 平台支持，并为玄铁 C 系列 / R 系列处理器新增 SMP 支持，补齐 C908 的 Svpbmt 支持并修正 C906 / C908 的缓存属性与页表属性。

软件包与中间件

  • CANopen 双栈成形：Lely CANopen 包索引合入软件包索引仓库（09-11，PR #2038），提供 single-owner EV/IO2 运行时、RT-Thread CAN 集成与可选主站服务；CanopenNode 模块化 Kconfig 重构并把版本升级至 v1.2.0 提交待审；参数存储组件新增应用自定义 backend 选项。
  • 器件支持包对齐：STM32F4 器件支持包批量补齐历史版本节点并修正默认向量表基址，近期软件包动作以与上游对齐和补全为主（09-17）。
  • 其他索引更新：STM32N657xx FSBL 软件包索引合入（09-14）；虚拟传感器软件包并支持 MQTT 上传提交待审（09-11）。

六、趋势观察

  1. RISC-V 从「能跑」迈向「多核用户态验证」：玄铁 C908 的 rt-smart、MMU 与 SMP 三连合入，叠加惰性 FP/RVV 上下文切换提案获维护者正面回应，架构支持重点从基本可用转向实时性能、进程隔离与向量场景，是本期最具分量的方向性变化。
  2. 工具链结束长期停更：env 由 1.5.x 跃迁至 2.0.0 并即时补发 2.0.2，配置系统重构、命令行化与镜像地址单源化落地，将直接影响开发者日常构建流程，升级需关注兼容性说明。
  3. 国产微控制器原厂是合入主体：国民技术 N32H 三系列、小华半导体 HC32 系列、兆易创新 GD32 在近一周内密集送审与合入，原厂自维护分支与主线并行推进，主线的适配周期通常更长。
  4. 存量缺陷进入集中清理期：STM32 链接脚本容量校验缺陷挂起约八个月后关闭，SDIO 注销泄漏从缺陷报告到修复提案约两天，四项安全类 issue 于 09-13 集中关闭，评审与修复的闭环速度较前期明显加快。
  5. 开发板配套从「能跑」转向「好用」：Gino Pi 在正式发售后同一周内补齐 JLink 调试链路与睿擎平台适配，新产品导入的工作重心由硬件发布转向工具链与平台可用性。
  6. 官方渠道静默、社区内容上位：官方新闻接口连续二十余日零更新，窗口内新增内容以论坛教程连载、竞赛开源工程与社区讨论为主，内容产出与传播重心进一步向社区侧倾斜。
