RT-Thread周报（2026-08-12）

2026-08-12 苦芽科技

数据来源:本机每日日报(8/11、8/12)汇总 + GitHub 补采(8/6-8/10 窗口,rt-thread 主仓库 / RT-Thread/env / packages 索引)+ 跨窗口报道补录。 说明:本机日报系统 8 月 11 日由 K3 机器迁移而来,8/6-8/10 无逐日日报,该区间以 GitHub 提交(committer 时间)与 8/10-8/11 跨窗口报道为准,已尽量去重合并。官方新闻 API 最新条目仍为 6 月 17 日(滞后约 2 个月),官方动态以 GitHub 与第三方行业媒体佐证。

一、内核与版本动态

1.1 dm 设备模型框架一周密集合入(本周重点)

日期:2026-08-06 ~ 08-08　来源:rt-thread 主仓库

RT-Thread 新一代设备模型(dm)框架本周进入高频合入期,三天内落地十余笔实质性提交:

  • 网络侧(8/6):dm ethernet 基础框架 + MACB/DWMAC 控制器支持;phy 驱动改进(v2)并新增 RTL8211F 驱动;
  • 存储侧(8/6-8/7):nvme 改用 DMA 地址(修复 CPU 物理地址直用问题)、nvmem DT bits 解析修复、DW AHCI(ATA) 支持;
  • 其他子系统(8/6-8/8):thermal 冷却策略更新、dfs 文件系统操作类型检查(防类型不匹配异常)、RT_BITS_PER_LONG 可自定义、ivshmem 虚拟机间共享内存(虚拟化场景)、graphic 更新、ufs 修复、regulator 更新、phye 新增 Mode/State 与 MIPI D-PHY 时序助手(#11675)、clk 工作流修复(#11673)。

dm 框架覆盖从网络/存储到时钟/电源/显示的完整设备树驱动体系,本周合入节奏显示其已进入”大规模铺驱动”阶段,是 RT-Thread 面向高性能/虚拟化场景的重要底座。

1.2 NXP BSP 大特性合入:多核 / HyperRAM / CherryUSB / NETC / etherCAT

日期:2026-08-10　来源:rt-thread 主仓库 #11672

[BSP][NXP] Add new features of multicore, hyperram, cherryUSB, NETC and etherCAT:NXP 平台 BSP 一次性补齐多核、HyperRAM、CherryUSB、NETC 网络控制器、以太网与 EtherCAT 支持。对 i.MX 系列用户是实质性的平台能力扩展,多核与 NETC 与工业/边缘网关场景直接相关,EtherCAT 则与睿擎工业平台主线呼应。

1.3 瑞萨 RA6W1 BSP 二期”完善驱动”合入

日期:2026-08-11　来源:rt-thread 主仓库提交

“完善 ra6w1 的基础 BSP 驱动”(45 个文件)合入,补齐瑞萨 RA6W1(BLE MCU,Cortex-M33)的 ADC、SPI、I2C、PWM、Timer、DMAC、OSPI、QSPI-PSRAM 等外设驱动。厂商 BSP 两阶段合入模式又一实例:首版基础 BSP 于 8 月 5 日合入,二期把平台补成外设完备。

1.4 lwIP DHCPD pbuf 泄漏修复

日期:2026-08-12　来源:rt-thread 主仓库提交

[lwip-dhcpd] Fix pbuf leak for oversized requests:修复 lwIP 内置 DHCP 服务器在超大请求场景下的 pbuf 协议缓冲泄漏,提升 AP/热点模式(智能家居网关、车载热点)长时间运行的稳定性。

三、生态与工具链

3.1 Env 工具链插件体系:开发(8/7-8/8)→ 合并(8/12)

日期:2026-08-07 ~ 08-12　来源:RT-Thread/env PR #284

本周最值得关注的工具链事件:Env 插件体系从开发到合入完整走完。8 月 7-8 日 env 仓库密集提交(Env plugin lifecycle、CLI plugin 示例、WebUI host 与插件示例、WebUI assets 打包),8 月 12 日 PR #284(创始人 BernardXiong 主导,90 文件,+约 9600 行)正式合并:

  • env plugin 子命令:本地安装/卸载/查看插件,安装前展示包名、版本、签名状态与权限声明;
  • epack 插件打包格式:定义打包与构建流程,内置示例插件 build-insight-1.0.0,插件 API_VERSION=1 固化契约;
  • env webui 命令:启动本地 Env WebUI 服务器。

Env 从命令行工具升级为可扩展插件平台,为可视化界面、云构建、第三方工具接入预留标准接口,是开发者工具链的结构性升级。

3.2 packages 索引:端侧 AI 软件包两连进(8/10、8/11)

日期:2026-08-10/11　来源:RT-Thread/packages

  • 8 月 10 日:AIfES 入库(嵌入式机器学习库,支持 MCU 级训练与推理);
  • 8 月 11 日:轻量化 agent 框架入库([ai/agent]),同日修复 ch390 网卡包作者信息。

packages 索引在”端侧 AI”主线上连续进件,”MCU 级 Agent 运行能力 + 嵌入式 ML”的软件栈正在成形。

3.3 第三方生态:canopennode-rtt / gdr / h120d-protocol

日期:2026-08-11/12　来源:wdfk-prog/canopennode-rtt / flespark/gdr / H4ck3rTR/h120d-protocol

  • canopennode-rtt(8/11):社区 CANopenNode 集成包(CANopen 工业现场总线),尚未进入官方索引,第三方孵化项目;
  • gdr(8/11):GDB RTOS helper framework 连续 5 提交,新增 RT-Thread mbox/msgq/mempool 对象提取与 rtthread help 命令,让 GDB 具备 RT-Thread 线程感知调试能力;
  • h120d-protocol(8/12):Holy Stone H120D 无人机 WiFi 协议逆向文档更新,含 RT-Thread 内核结构分析——消费级无人机飞控大量采用 RT-Thread 的生态样本。

四、行业应用专章(工业 / 无人机)

4.1 工业线:EtherCAT 实时控制 + 睿擎平台推广

8 月 27 日上海 Workshop(EtherCAT 实时控制与工业方案实战)是工业线关键动作;叠加 NXP BSP 新增 EtherCAT 支持(1.2)、官方此前”睿擎工业平台赋能工控研发”与阿布扎比投资论坛亮相,工业场景是睿赛德当前明确的商业化主线。

4.2 无人机/飞行智能:Edgi-X 发布 + 生态双向呼应

Edgi-X 正式发布(2.1)标志”OS 厂商 → 行业硬件产品”路径落地;h120d-protocol 等无人机逆向项目持续活跃,侧面印证消费级无人机市场与 RT-Thread 绑定加深。飞行智能方向渗透值得持续跟踪。

五、总结与趋势观察

  1. dm 设备模型框架进入铺驱动阶段:一周十余笔合入覆盖网络/存储/时钟/电源/显示/虚拟化,是本周内核侧最显著的工程信号。
  2. 工具链平台化:Env 插件体系完成开发到合入闭环(env plugin / webui / epack),开发者工具开始可扩展。
  3. 端侧 AI 软件栈成形:AIfES + 轻量化 agent 框架先后入库,MCU 级 AI/Agent 能力下沉。
  4. 行业商业化双线推进:工业(EtherCAT/睿擎 Workshop)与无人机/飞行(Edgi-X 硬件产品)同步发力。
  5. 厂商 BSP 两阶段合入模式稳定:RA6W1 二期、NXP 大特性,NXP 一次到位含多核/网络/EtherCAT,适配质量与节奏俱佳。
  6. 局限性说明:8/6-8/10 区间无逐日日报,以 GitHub 提交为准;官方新闻 API 持续滞后(6/17);Google News 对 “RT-Thread” 噪音多(博彩/SEO),已剔除。
