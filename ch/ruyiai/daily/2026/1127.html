今日重点：triton-riscv 合入 PR #135，CPU lowering 与 matmul 统一走 VIR（11-26）

来源：PR #135。

11-26 17:41，PR #135 合入 triton-riscv 主线。标题为「Unify standard CPU lowering and matmul through VIR」。作者 WuXintong123，含 12 个提交。改动 2 个文件，加 255 行、删 124 行。

上期报告记录该 PR 仍在审，分支已含合入后的 #129，与主线的差异只剩 backend/compiler.py，本次这批差异全部落地。

改动集中在五处。RVV 向量宽度改从目标特性里最大的 +zvlNb 推导，缺省 128 位。同时接受显式的 target_vector_bits。标准流水线把 masked store 向量化，crop、transpose 与生产者融合的归约改写提前到 bufferization 之前。标准 matmul 在定宽与 RVV 目标上统一走 VIR，寄存器分块按目标向量宽度与寄存器数配置。新增 target_tune，把 -mtune 透传给 opt 与 llc。示例取值有 spacemit-x100、spacemit-a100 与 xt-c920v2。x86 侧顺带修了向量宽度。opt 之前给函数加上 prefer-vector-width，Emerald Rapids 这类目标可用满 512 位。

PR 说明 -mattr 继续定义 ISA，-mcpu 可以打开硬件未上报的扩展，二者分工不变。

依赖没有解除：仍需含 buddy-mlir#1068 的 Buddy 发行版，主线当前锁定的版本早于所需的 pass 与选项。编译内核的 CI 要等新发行版与 Buddy 版本更新。

今日重点：buddy-mlir 新增 XSAIAME 方言，RISC-V 矩阵扩展进入 IR 层（11-26）

来源：PR #1071。

11-26 17:18，PR #1071 合入，新增 xsai_ame 方言，改动 32 个文件，加 1541 行、删 1 行，作者 xyyy1420。

该方言为 XSAI 的 ZAMES 矩阵扩展与 ZMASYNC 同步扩展提供类型化 SSA IR。LLVM 后端支持已随 #1067 的 LLVM 升级进入主线，本次只加 IR 与 Python 绑定。降到 llvm.riscv.xsai.* intrinsic 与 Linalg 转换留待后续 PR，LLVM gitlink 未动。

类型有两种。!xsai_ame.tile<kind, MxN, element> 的 kind 取 a、b、c，对应 A 为 MxK、B 为 NxK、C 为 MxN。维度为正数或动态。元素类型共 15 种，整数侧有 i4、u4、i8、u8、i32，浮点侧有 fp8e4m3、fp8e5m2、fp16、bf16 与 tf32。其余为 fp32、nvfp4、mxfp4、fp2pack4 与 fp2pack5。!xsai_ame.sync 是矩阵同步寄存器的 SSA 句柄，物理寄存器编号不进接口。

操作含 load、store、mma、mzero，以及 msyncregreset、mfence、mrelease 与 macquire。load/store 在寄存器与秩 2 memref 视图之间搬 tile，可选转置，视图形状须与 tile 一致。mma 检查 a/b/c 种类与静态 K/M/N 维度，元素类型组合不做校验，支持哪些组合由硬件实现与 LLVM 后端决定。

四个同步操作都带内存效应，不会被删除，也不会跨内存访问重排。

方言已在 buddy-opt 与 InitAll 注册。Python 侧提供方言注册、TileType 与 SyncType，以及由 ODS 生成的算子构造器。

一、RuyiAI 栈进展（PyTorch / Triton / TileLang RISC-V 适配）

1.1 PR #135 的七组实测：matmul 收益最大，CPU 调优接近持平（11-26）

来源：PR #135。

PR 给出七组历史实测，都是相对基线的几何平均比值，小于 1 表示变快。样本来自各自的实验，不是同一次全量跑分。

RVV、VLEN 256、SpacemiT X100 上共三组。masked tile 拷贝消除 1726 例，CPU 时间 0.934，墙钟 0.941。masked 内存与归约改写 8643 例，CPU 时间 0.952，墙钟 0.959。VIR matmul 的改动对象 553 例，CPU 时间 0.810，墙钟 0.807。

x86-64、AVX-512、Emerald Rapids 上修向量宽度偏好 1712 例，CPU 时间 0.959，墙钟 0.956。

CPU 调优三组都在 1726 例上。VLEN 128 的 C920v2 为 0.995，VLEN 256 的 X100 为 0.989。VLEN 1024 的 A100 为 1.000。

PR 另称拷贝消除对照的 1726 例全部通过，matmul 对照的 856 例也全部通过。VLEN 修复恢复了 VLEN 256 与 1024 下的大规模欧氏距离对象检查。

6.1 后端统一完成后，瓶颈转向算子库存与 Buddy 版本锁定

判断：矩阵指令短期内不会进入端到端模型性能数据，midend 的合入先改变的是可表达性。
