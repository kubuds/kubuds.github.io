今日重点：FlagGems 五批 245 算子单日合入 triton-riscv（11-25）

来源：PR #136。其余四批为 #137 至 #140，链接见附录 [2] 至 [5]。

11-25 10:13 至 19:53，triton-riscv 合入五批 FlagGems 算子示例，合计 245 个算子。

五批分别是 B12 的 55 个、B13 的 51 个、B14 的 41 个、随机与 RNN 及 attention 的 50 个、稀疏与嵌套张量的 48 个。

每批按算子配一份 CPU 正确性测试，并从 examples 包的 __init__.py 统一导出。

五批合计新增 54,550 行、删除 315 行。B13 的验证记录为 riscv64 CPU 上 146 个测试全部通过，环境是 Python 3.12、PyTorch 2.10.0、CPU Triton 3.9.0。

B14 顺带修了 int4 打包器。此前输出列宽超过 128 个输入值时剩余字节不写入，非连续张量也被按连续内存读取。

上期报告记录 B12、B13、B14 三批仍在审，本期已全部落地。加上 11-24 合入的线性代数 59 个，本轮移植累计 304 个算子。

今日重点：triton-riscv 合入 RISC-V 后端调优，依赖 Buddy 近似数学（11-26）

来源：PR #129。Buddy 依赖项见附录 [24]。

11-26 00:24，PR #129 合入 triton-riscv 主线，改动 2 个文件，加 136 行、删 15 行。

改动全部位于 _ttsharedir_to_llir，只在目标为 RISC-V 时生效。

五项调整：数学函数改用多项式近似；改用可伸缩向量与 AVL 尾循环；matmul 向量宽度取 2·VLEN/32；buffer 在去分配前提升到栈上；跨步 memref 拷贝转 linalg 以便向量化。

PR 给出的精度是 f32 下 1 至 7 ULP，f16 与 bf16 下不超过 1 ULP，exp 与 erfc 的次正规结果除外。

该改动依赖 buddy-mlir#1068 提供的 polynomial-approximate-math pass 与 use-avl-loop 选项。buddy-opt 版本过旧时，RISC-V lowering 会因未知 pass 或选项终止。

调优基线是 VLEN-256 的 RISC-V 开发板，对照组为 triton-cpu。

1.2 后端调优 PR #129：近似数学、可伸缩向量与 matmul 向量化（11-26）

来源：PR #129。

多项式近似覆盖 exp、expm1、log、log2、log1p、tanh、erf、erfc、sin、cos、atan、atan2、asin、acos、cbrt 共 15 个函数。

此前 RVV 没有向量数学库，这些函数逐 lane 退化为 libm 调用，无法利用向量寄存器。

matmul 的向量宽度从固定 4 改为 2·VLEN/32，对应 8 行累加器、每行两个向量寄存器，LMUL 为 2。PR 说明 LMUL 4 会溢出。

--lower-vir-to-vector 增加 use-scalable=true 与 use-avl-loop=true。剩余段用一次活动长度迭代收尾，不再拆成减半段加标量循环。

跨步 memref.copy 改走 convert-strided-memref-copy-to-linalg，动态形状的拷贝降级到 SCF，FP8 拷贝保留原路径。
