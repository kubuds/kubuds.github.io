今日重点：Caffe 三笔 RVV 算子 PR 开出，MXNet 系列 15 笔在审——经典框架适配线进入实操

日期：2026-09-23 ~ 2026-09-28　来源：caffe PR #1、caffe PR #2、caffe PR #3、MXNet PR 列表

北京时间 09-28 14:56 至 14:59 之间（三分钟内），贡献者 Xlawy 在 caffe 仓（09-23 入库的两个经典框架仓库之一）连续开出三笔 RVV 算子 PR，为两仓自入库以来的首批实质代码动作：

  • #1 im2col（+113 / -9，2 文件）：把 im2col 的输出行收集拆分为标量助手与 RVV float 重载，每行按零填充与界内两段拆分，依 stride_w 选择单位步长或带步长向量载入，采用变长 e32,m4 分块；并顺带把 Protobuf 的 SetTotalBytesLimit 单参数 API 适配到 3.6.0 及以上版本。
  • #2 float CPU max pooling（+167 / -24，2 文件）：以 e32,m4 分块处理最大池化内部列，用带步长载入与严格大于比较更新最大值及胜出位置偏移，保留首次出现平局语义与 -1 哨兵，并对三列窗口做展开；边界仍走标量。
  • #3 float vPowx（+166 / -1，2 文件）：为非 MKL 的 vPowx<float> 增加 RVV 特化——在输入全为正规数且指数在 [-1, 1] 时启用向量 log/exp 近似（双精度中间量），指数 0 与 1 走直接向量运算，支持分块的在位调用；域检查不通过时整调用回退标量。

三笔均以 RVV 宏守卫新增特化、保留非 RVV 构建的标量回退，目前均处开放状态、无评审记录。同一路线的更早动作集中在 MXNet 仓：09-23 至 09-24 两天内，三名贡献者累计开出 15 笔 PR（ww8191201-coder 11 笔、Xlawy 2 笔、6eanut 2 笔），其中 11 笔为 RVV 算子向量化——GELU(erf) 反向、ReLU 反向、softmax、log-softmax、softmin、CTC log-softmax、im2col、col2im、batched cumsum、最近邻上采样、float32 最小值归约；另 4 笔为性能与构建基础（broadcast_reduce 与 reduce_with_axis 的索引走法强度削减、求和归约器 volatile 移除、非 MSVC 构建请求 -fno-math-errno）。多笔 PR 描述直接引用 SG2044（RVV 1.0、GCC 15.1）的测试语境。这一系列此前窗口未展开，本期与 Caffe 新动作合并记录。

截至窗口末，两仓合计 18 笔 PR 全部开放、无一合入。结合 09-24 期对两仓「归档、适配基线或新工作起点」的待观察记录，本批动作给出阶段性答案：两仓被用作经典框架 RVV 适配的实操基地，MXNet 系列覆盖推理主干算子面，Caffe 系列则聚焦卷积与激活基础设施。同日夜间，编译器侧的 RVV 动作由 tilelang-riscv PR #4 承接（见 1.1），RVV 成为当日组织内最集中的技术主题。

09-23 两仓入库时，其用途被记为待观察；一周之内，MXNet 以 15 笔 PR（三名贡献者）覆盖 11 个 RVV 算子与 4 项性能、构建基础，Caffe 于 09-28 以三笔 RVV 算子跟进——「适配」路线在经典框架维度正式落子。值得注意的细节：多条 PR 直接引用 SG2044（RVV 1.0、GCC 15.1）的测试语境，说明这批工作面向可运行的真机基线；与 PyTorch fork 侧 RVV 补丁（#46、#48）仍在队列等待形成对照——RVV 适配的当前推进，部分绕开了 PyTorch 主线。

5.2 中秋节前后的节奏：09-28 节后集中产出

09-25（农历八月十五，中秋节）及随后的周末，三组织提交近乎停摆；09-28 节后首个工作日出现集中产出：openRuyi 主仓库 5 笔、kiwi-image 3 笔、VS Code 插件 2 笔与 0.1.7 发布、ruyiai-daily 与论坛资讯帖同日恢复——假期带来的「低谷、反弹」在两个窗口内完整可见。

5.3 工具侧发布节奏稳定

窗口内三条工具线按各自节奏推进：VS Code 插件 0.1.7 转正（beta 后 8 天）、Ruyi Imager 夜间渠道更新、triton-riscv 每周夜间构建按期产出；对应地，ruyi-tuner 的 1.9 版本线保持「未发版但变更在途」状态已达两个窗口。

5.4 本窗口的空白与关注点

空白项：PyTorch riscv 分支与开放 PR 连续静默（自 09-21）；llvm-project PR #168（XTHeadVector 修复）评审停在 09-24；support-matrix 在审队列积压（09-21 至 09-24 无更新）；openRuyi 2026.09 月版公告未上线；外部新闻与 arXiv 零命中。关注点：一是 MXNet / Caffe 十八笔 PR 的评审与首批合入节奏；二是 ruyiai-daily 是否恢复每日推送；三是 ruyici macOS 构建与 riscv-gcc p 扩展补丁的推进；四是 6.18.54-1 内核标签是否进入 openRuyi 正式构建。
