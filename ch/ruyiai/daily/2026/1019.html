六、趋势观察

6.1 编译器栈版本联动收紧：Buddy MLIR 两日两版，下游当日跟版

Buddy MLIR 从 0.1.0 到 0.1.1 只隔约两日，且 0.1.1 的两笔变更都指向可交付性——服务端交叉编译让 buddy-server 能进 RISC-V 机器，模型发布工作流让模型制品能出 CI。下游响应同样按日计：triton-riscv 在 10-17 合入 #87 锁定 0.1.0，10-18 上午由自动跟版升到 0.1.1 夜间版；tilelang-riscv 在 10-16 把 Buddy MLIR 发布 CI 纳入自建流水线。三条仓库围绕同一 LLVM 后端的版本耦合在收紧，观察点在于是否形成统一的发布窗口与回归基线。

6.2 两条 fork 维护线继续分化：PyTorch 并入与重放并行，LLVM 六日静默

PyTorch 的 riscv 分支窗口内并入 143 笔（上游同步为主），并以整批重放维持本地补丁栈，同时出现近五周首笔 PR 合入（#51 riscv64 本地镜像）；LLVM 的 riscv 分支则自 10-12 起六日无提交，两笔 FPGA 后端 PR 停在 10-12。同是「上游 fork + 本地补丁栈」，一边是按日推进的流水线，一边是等待评审的静态分支，维护投入的差异比上一窗口更明显。观察点：LLVM 重放是否随新上游基线重启，以及 FPGA 后端 PR 是否进入评审。

6.3 RuyiSDK 三线并进：内核探测补齐、发行版扩面、工具链等版本窗口

内核侧把 RVA23 相关的原子性与取指原子性剖面扩展并入 cpufeature 与 hwprobe，私有扩展 ID 与上游对齐；发行版侧补入 Rust 嵌入式六包，把 Rust 裸机开发的基础依赖纳入软件源；工具链侧 0.54.0 定档 10 月底，ABI 兼容检测与 K1/K3 适配继续推进；固件线在三连发后暂停。整体呈现「内核探测补齐、发行版扩面、工具链等版本窗口」的节奏，下一步看 0.54.0 是否如期发版，以及峰会后的方案落地。
