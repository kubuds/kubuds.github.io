今日重点：LLVM fork 完成 riscv 分支基线重建——BOSC AME 指令更新合入、补丁栈重放到上游新基线

日期：2026-09-29 ~ 2026-09-30　来源：riscv 分支提交列表、PR #29、SyncBots 集成提交 697305d1

北京时间 09-29 14:07，llvm-project 仓（RuyiAI-Stack 组织）合入 PR #29「BOSC: bosc-ame-instruction-update」（Yranger，09-24 开出）——BOSC AME 指令系列的最新一笔更新。BOSC 为北京开源芯片研究院（Beijing Institute of Open Source Chip）的英文缩写；AME（Attached Matrix Extension）是面向 AI 计算的 RISC-V 矩阵扩展方向，其标准化在 RISC-V 国际基金会（RVI）框架内推进。

当夜 23:00 至 09-30 凌晨 01:47，该仓 riscv 分支（默认分支）完成一次整体重建：本地 RISC-V 补丁栈以新提交者时间整体重放，最早可追溯到 4 月的 MLIR-JIT 与向量语义修复（#1、#3、#4），其后依次为 IME/AME 迁移、BOSC AME 指令与内建函数系列（#14、#16、#18）、Buckyball 厂商扩展及与 Pebble 核 ISA 的对齐（#20、#23）、BOSCAME 后端设计更新（#24、#27），直至窗口内合入的 #29；CI 作业（riscv64 作业、OpenMP 检查）与 SyncBots 自动同步机器人的多次集成提交穿插其间。重建会话以集成提交「[SyncBots] Integrate LLVM at b3b5e33」收尾，同步点推进至 09-29 当日的 LLVM 上游提交。本次重建以重放为主，窗口内新增内容为 #29 一笔合入。

同步影响面：分支上三笔在审 PR 的更新时间一并刷新至当夜 01:47——#22「RVI AME（标准、预批准阶段）后端支持」（13 条讨论，7 月开出）、#25「BOSCAME FPGA 后端」与 #28「xboscame FPGA」。即标准 AME 后端与 FPGA 侧两条后续路径均在队列中，等待新基线下的评审推进。

要点归纳：该分支承接 RuyiAI 侧 RISC-V 编译器工作的全部内容（矩阵扩展、自定义指令、CI 与上游同步自动化）；本次重建使补丁栈与上游 LLVM 的同步点前移至当日提交，为后续矩阵扩展系列 PR 的评审确立新基线。
