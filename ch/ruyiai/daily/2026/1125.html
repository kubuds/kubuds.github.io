今日重点：FlagGems 线性代数 59 算子合入 triton-riscv（11-24）

来源：PR #134。

#134「Port/flaggems linalg」在 11-24 17:13 合入，改动 121 个文件，加 2457 行、删 35 行。

PR 一次加入 59 个 FlagGems 线性代数算子，每个算子配一个测试，并统一从示例包的导出表导出。LU、Cholesky、三角求解与 QR 各保留一个 kernel，同算法的算子共用。

测试不求 LAPACK。RISC-V 的 PyTorch 构建没有 LAPACK，因此不调用 torch.linalg，改用 matmul 恒等式重建结果来校验。

同批修了 CPU 后端的 affine_grid_generator。改为每个输出元素由一个 program 载入自己的 theta，kernel 停留在批次分配内。

这批代码此前以示例形式在审。11-23 期报告记录两笔示例 PR 未合入，本期已落地。

今日重点：openRuyi 打包 Triton 3.9.0，改用 Buddy 工具链并删除旧包（11-24）

来源：python-triton 升级提交。

openRuyi 打包仓在 11-24 15:14 一次性改了三处。python-triton 升到 3.9.0 并改用 Buddy 工具链，buddy-mlir 包升到 0.1.4，旧包 python-triton-ruyiai 被删除。

源码取三处：triton-lang 的 v3.9.0 发布包、RuyiAI-Stack 的 llvm-project 提交 f346011a。

第三处是 RuyiAI-Stack 的 triton-riscv 提交 9ded1d4c。三者版本在 spec 里固定。

构建依赖 buddy-mlir 0.1.4、buddy-mlir-llvm 0.1.4 与 clang 22 等。spec 写明 CPU 后端用 Buddy 的 LLVM 工具，AMD GPU 走同源 LLVM 自建。

这一改动把 RuyiAI 的 Triton 从单独包并入发行版主线。旧包名删除后，ruyi 装出的 triton 只有一个来源。

需要注意版本滞后。上游 buddy-mlir 已发到 0.1.8，发行版仍锁 0.1.4。

4.3 窗口内七笔提交，VIR 调度链成形（11-24 至 11-25）

来源：buddy-mlir 提交列表。

七笔提交集中在两段。11-24 上午是打包与前端：LLVM 与 Buddy 的 tar 包改用 zstd，DeepSeek 分词从聊天模板中拆出。

11-24 晚间至 11-25 凌晨是向量侧四笔。先给 VIR 的取值类操作标记 Pure，让 CSE 能合并、调度能跨访存移动。

随后新增 -vir-schedule，按 vir.set_vl 区间重排操作以降寄存器压力。再补 RVV 语义：广播仅作标量操作数时不占向量寄存器，MoE top-8 合并的最大活跃数由 10 修正为 4，所需分组由 9 修正为 3。

最后一笔把调度提前到 -lower-vir-to-vector 之前。

另有一笔近似数学 pass。RVV 上没有向量数学库，math.exp 等此前逐 lane 退化成 libm 调用。新 pass 改为多项式近似，并对 log、log2、sin、cos、atan2、cbrt 用自研模式，规避上游在次正规数与大幅值上的错误。

4.4 发行版锁 0.1.4，与上游差四个版本（11-24 状态）

来源：buddy-mlir 升级提交。

openRuyi 的 buddy-mlir 包仍是 0.1.4，源码取上游 release 标签。本期升级只把包从更早版本提到 0.1.4。

上游同期已到 0.1.8。打包侧落后四个小版本，Triton 的构建依赖也随之固定在 0.1.4。

六、趋势观察

6.1 FlagGems 移植转为日级批量

线性代数 59 个算子合入的同一天，B12、B13、B14 三批共 96 个以上算子开出。单笔 PR 上万行，节奏从周级压到日级。

移植口径也统一了：每算子一测试，包导出集中在初始化文件，测试绕开 LAPACK。这套做法可以直接复用到后续批次。

6.2 发行版开始接管 Triton 构建

openRuyi 把 triton 3.9.0 与 triton-riscv 固定提交写进 spec，构建改用 Buddy 工具链，并删除旧包。RuyiAI 的 Triton 从此由发行版主线交付。

这一步把「社区 fork 出轮子」变成「发行版出包」。后续版本节奏将由打包侧决定，而不是仓库标签。

6.3 上游发布节奏与打包版本脱节

Buddy 三天发了三版，发行版仍锁 0.1.4。zstd 打包与 VIR 调度这些新能力，短期进不了发行版。

若打包侧不跟进，Triton 的构建基线与上游会继续拉开。
