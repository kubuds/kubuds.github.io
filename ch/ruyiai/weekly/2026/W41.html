报告周期：2026 年 9 月 30 日（周三）至 10 月 7 日（周三），共 8 天；国庆假期特别汇总期（10 月 1 日至 7 日为假期，日报暂停） 素材来源：本刊每日 RuyiAI 动态报告（2026-09-30 一期，窗口 09-29 04:30 ~ 09-30 04:30；10-01 ~ 10-07 假期无日报素材）；另含组织仓库 216 小时窗口核查、社区双源复核与技术情报仓库全期扫描（覆盖至 10-08 晨） 编制说明：本周期横跨国庆假期——代码合入进入节内低产模式，评审队列、情报仓库与社区渠道保持运转；全部技术事实来自代码仓库、发布物与社区论坛的实测核查

一、本周要闻

  • openRuyi 2026.09 正式发布：RVA23 完善、云与存储软件栈扩充、仓库 GPG 校验启用（09-30）：发布公告于本周期首日上线（09-30 日报窗口内尚不可见，属本期核查新发现项）。要点：GCC 16 回移 BCLR 代码生成修复——消除 DPDK rte_softrss() 挂死与 Mesa ACO 调度器误编译；DPDK 25.07 在 RVA23 上启用 RVV 查找路径（lpm / fib / acl / node）；OpenJDK 合入 15 个 RISC-V 补丁（Zbs / Zfa 指令生成、RVV vset 优化、CRC32C intrinsic）；容器侧放行 riscv_hwprobe 后于进迭时空 V100 实测 OpenSSL 启用 Zvkned / Zvknhb 向量密码扩展、zlib-ng 启用 Zbc 加速 crc32；内核 7.2.6 / 6.18.54；新增 Cloudpods 4.0.3 多云平台、SPDK 25.09（io_uring / RBD bdev / SMA）与 Ceph 21.3.0 快照；安装链路默认启用 GPG 签名校验；安全更新批量落地（expat / jq / vim / pcre2 / runc 等）；提供 Server / Container / Desktop / Zero 四版本与实验性 RVA20 版本。来源：openRuyi 2026.09 发布

  • 《PyTorch RISC-V CI 实践》博文发布：如意社区联合玄铁与 RISE 公开实机 CI 体系（10-08 凌晨上线）：博文披露 PyTorch RISC-V 持续集成的全貌——RuyiAI（中科院软件所）与玄铁团队、RISE AI/ML 工作组共建：采用 Debian Trixie / Python 3.13 / GCC 14 / OpenBLAS 0.3.33 基线，「一次构建、多机测试」；Jenkins 并行分片（核心测试约 3 小时、全量约 5 小时）；按历史用时动态分片；统一 blocklist 经人工分类管理；失败日志集中归档（community-ci.openruyi.cn）；SyncBots 持续把上游 main 同步进 RISC-V 工作分支并自动触发核心测试——当前 RISC-V 核心测试套件持续稳定通过。工作起源于玄铁团队的 RFC（pytorch#171659）与 tracking issue（#180975）；软件所为 RISE 成员、RuyiAI 成员担任 RISE AI/ML WG 联席主席。来源：博文（中英双语）、RFC #171659、tracking #180975

  • 编译器侧的指令级正确性持续修正：BCLR 代码生成修复（openRuyi GCC 16 回移）、P 扩展 lowering、A100 与 Ztt——工具链在既有扩展的正确性与新扩展的支持两端同时收获。
