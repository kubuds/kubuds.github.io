一、核心项目进展

1.1 主仓：SM121（DGX Spark）点亮块缩放 MMA；CuTeDSL 栅栏选举与参数身份修复（10-10 ~ 10-11）

日期：2026-10-10、2026-10-11　来源：SM121 块缩放 MMA（#3430）／ CuTeDSL 栅栏选举（#3400）／ NVRTC / CuTeDSL 参数身份（#3414）

  • SM121 点亮（#3430，10-11 00:32 合入）：SM121（GB10、DGX Spark）实际支持 SM120 级 warp 块缩放 MMA，但 tl::sm120_mma_sync_blockscaled 只检查 CUTLASS_ARCH_MMA_SM120A_ENABLED（仅在 __CUDA_ARCH__ == 1200 时定义），导致 sm_121a 下所有块缩放 MMA 编译成 BPT.TRAP 而非 OMMA.SF；本笔改为按 arch 与家族同时接受 SM120 / SM121 目标，NVF4 测试按 SM12x 家族门控，CuTeDSL TMA 架构表放行 sm_121 / sm_121a。作者在 DGX Spark（驱动 580.178.04、CUDA 13.0）实测通过。
  • 栅栏选举（#3400，10-10 10:47 合入）：sync_grid() 此前选举所有 tid.x == 0 的线程，2D / 3D 线程块下多个线程重复发布同一块到达、栅栏可能提前放行；现只选举物理线程 (0, 0, 0)，计数器 / 世代协议与协作启动不变。回归覆盖 1D / 2D / 3D 网格与重复复用（RTX 5090、CuTeDSL 4.7.0）。
  • 参数身份（#3414，10-10 13:58 合入）：NVRTC 与 CuTeDSL 宿主包装器原先用原始 Var 名生成签名、按打印名匹配参数，重名（stream、device_id 等）与设备侧改名会串扰；现按 Var 身份分配包装器参数名并保留位置 ABI，CuTeDSL 允许同一内核以不同标量绑定重复调用，同名 shape / stride 符号得以区分。

1.2 主仓：GEMM dtype 白名单收官——不支持的组合在 CUDA codegen 前拒绝（10-12）

日期：2026-10-12　来源：GEMM dtype 白名单（#3245）

  • 部分 T.gemm 操作数 dtype 组合（如 bf16 x bf16 到 fp16）此前在前端被接受、直到 nvcc 内以不透明的 static_assert 失败（缺陷单 #3004）；本笔为 Ampere / Ada mma.sync 路径加显式 dtype 白名单，前端（tileop/gemm）与 C++ 指令选择双端强制，不支持组合在 CUDA codegen 前即被拒绝并给出明确信息。
  • 附 1 条负例与 3 条正例回归；受支持组合与非 Ampere 目标行为不变。本笔 10-12 01:21 合入，为窗口截点前最新一笔。

1.3 主仓：For 步长、JIT 输出索引、popcount、位归约与测试基建五笔落定（10-10 ~ 10-11）

日期：2026-10-10、2026-10-11　来源：For 循环步长（#3427）／ JIT 输出索引（#3318）／ popcount（#3300）／ 位归约（#3332）／ 测试基建（#3313）

  • For 步长（#3427，10-10 12:54 合入）：循环携带冲突分析此前把步长恒当作 1（与注释「默认 1、未指定时」相悖），非单位 / 符号步长下有效迭代对判定失真；现按显式步长收缩迭代对范围，CUDA 与 HIP codegen 均保留步长并委托 CodeGenC 发射，兼顾展开循环的词法分配作用域。
  • JIT 输出索引（#3318，10-10 12:02）：out_idx=[-1] 在参数个数不同的内核间复用时会被归一化污染（两参数内核把 [-1] 归一为 [1]、四参数内核随后误占输入槽）；现于归一化前拷贝调用方列表、拒绝等于参数个数的标量索引并给出合法区间。
  • popcount（#3300，10-10 12:02）：补齐有符号与 8 / 16 位窄整数的 CUDA 下沉——先按原宽度转无符号再扩展（int8(-1) 计 8 位而非 32 位），64 位走 __popcll，覆盖 8 种 dtype 回归；修复 #2984，H100（CUDA 13.0）16 项测试全过。
  • 位归约（#3332，10-11 14:13）：reduce_bitand / bitor / bitxor 原先只检查目标缓冲、放行浮点源（[1.0, 2.0, 4.5, 8.9] 被静默截断为 1 2 4 8 = 15 且无告警）；现源与目标统一按整数 / 布尔规则拒绝（refs #3301）。
  • 测试基建（#3313，10-11 18:25）：新增共享 IR 检查助手（节点收集、精确算子调用计数、按符号收集外部调用），issue 与 transform 测试从局部遍历代码迁移到助手；lower_ldgstg 测试补结构断言，选定 transform 测试固定 sm_90 目标并加可用性跳过。

日期：2026-10-10、2026-10-11　来源：MLA 解码 SM89（#2511）／ MLA 调优分裂扩展（#2524）／ MLA 候选剔除（#2525）／ WGMMA 描述符（#2523）

  • MLA 解码（#2511，10-10 22:31 合入）：SM89 上按批与头块数选择 2/4/8/16 KV 分裂（目标 128 CTA、上限 16），复用既有扫描与 FP32 分裂合并核——单请求 bf16 4k 默认延迟 0.158 至 0.034 ms（约 4.6 倍）、32k 1.170 至 0.162 ms（约 7.2 倍）。

  • 分页 GQA（#2512）：SM90 warp 特化 TMA 核（一个 TMA 生产者 warp + 两个消费者 warpgroup 重叠 QK 与 PV），持久 CTA 每 SM 一枚；缓存末端切瓦片的陈旧 V 行先清零再读；打包布局平均每请求至少一个 128 行瓦片时优先分派，H200 上被接管的四行用时降至原 0.44 至 0.88 倍。
