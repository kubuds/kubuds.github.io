一、核心與版本動態

1.1 RISC-V 惰性 FP/RVV 上下文切換提案獲核心維護者正面回應（#11786）（09-15）

日期：2026-09-07 提案提交，2026-09-15 10:23 維護者回復（北京時間）　來源：Issue #11786

該議題以 OSPP 2026 選題形式提出，指出現有 RISC-V 移植層存在兩處結構性缺口：一是每次上下文切換都無條件儲存與恢復完整 FPU 狀態，即使執行緒從未使用浮點單元；二是完全不支援向量擴充套件 RVV，向量暫存器未納入執行緒上下文，任何使用向量指令的執行緒其狀態都會被上下文切換靜默破壞。兩點在既有議題 #10722 中已有記錄。提案建議把擴充套件狀態改為惰性儲存與恢復，即僅在真正使用時才落地狀態。維護者 Rbb666 於視窗內回覆，認可這是很好的效能最佳化提案並歡迎提交 PR。該議題標籤為 enhancement、Kernel、Arch: RISC-V，是視窗內唯一一條架構級方向性表態。

1.2 評審佇列觀察（一）：STM32N657 Nucleo BSP 單日四次強制推送修 CI（#11799）（09-14）

日期：2026-09-14 13:21 / 13:24 / 15:06 / 16:44（北京時間）　來源：PR #11799

意法半導體 STM32N657 系列的 stm32n657-st-nucleo BSP（84 檔案，新增約 15340 行）在視窗內被作者連續四次強制推送（09-14 13:21、13:24、15:06、16:44），直接回應維護者「CI 問題需要修復下」的評審意見。該 PR 於 09-11 送審，評審人已指派 Liang1795、hamburger-os、wdfk-prog，第三方記憶體比對工具出具的報告中該板卡暫未列入比對目標。單日高頻重推說明 CI 與評審意見閉環仍在進行，尚未進入合入階段。

1.3 評審佇列觀察（二）：國民技術 N32H 三系列驅動擴充套件回應評審後重推（#11800）（09-14）

日期：2026-09-14 16:48（北京時間，強制推送）　來源：PR #11800

該 PR 在 bsp/n32/n32hxxx 下擴充套件 N32H47x_48x、N32H49x、N32H7xx 三系列驅動，覆蓋 n32h487zgl7-evb、n32h497zgl7-evb、n32h760zil7-stb 三塊板卡：共用驅動層新增 ADC、DAC、I2C、SPI 配置標頭檔案，並擴充套件 drv_adc、drv_dac、drv_eth、drv_gpio、drv_hard_i2c、drv_nand、drv_qspi、drv_sdram、drv_spi、drv_usart、drv_wdt 等 29 個檔案；兩塊 evb 另增 FEMC 時序表、ETH PHY 復位與 CherryUSB 配置。視窗內作者再度強制推送，並在評審執行緒中逐條回覆自動評審提出的問題，包括把 I2C DMA 超時處理描述為獨立改動、擴充套件 N32H7xx 的傳輸中止邏輯等。國產 MCU 原廠驅動補齊仍是評審佇列的主要構成。

1.4 評審佇列觀察（三）：lwip 2.2.1 支援分支再度重推，第三方記憶體比對無變化（#11797）（09-15）

日期：2026-09-15 11:19（北京時間，強制推送）　來源：PR #11797

該 PR 為修復 #11588 引入 lwip 2.2.1 支援，驗證用 BSP 為 bsp/nxp/imx/imxrt/imxrt1180-nxp-evk/m7，並開啟 BSP_USING_ETH、RT_USING_SAL、RT_USING_NETDEV、RT_USING_LWIP。視窗內作者再度強制推送（commit 04a4e19b）；同期第三方記憶體比對工具（MemBrowse）對該 PR 出具報告，判定未引入記憶體佔用變化。評審標籤為 components，評審人 Maihuanyi。協議棧版本升級是工業與閘道器場景的常用鏈路，本期處於評審迭代期，尚未合入主線。

3.1 RT-Thread 聯合兆易創新正式發售 Gino Pi 開發板，首發優惠 80 元（09-15）

日期：2026-09-15 08:00（北京時間，聚合時間）　來源：電子工程專輯（聚合）

RT-Thread 睿賽德聯合兆易創新正式發售 Gino Pi 開發板，首發優惠 80 元，同期釋出 Gino Pi 新品講解。該板卡此前已在 09-11 進入 RT-Thread Studio SDK 索引（GD32H77D-Gino BSP v1.0.0，包體 138 MB），本期由「可下載 BSP」推進到「公開發售」，是兆易創新與睿賽德戰略合作（覆蓋 GD32 全系，重點深化 GD32F5、GD32VW553、GD32H7 三條產品線）在開發板層面落地的首款硬體。原文頁面在網路訪問受限，價格與優惠幅度以聚合摘要為準，未獲官方頁面二次確認。

3.2 Gino Pi 硬體規格與技術底細：Studio BSP SDK 倉庫公開資料（09-10）

日期：2026-09-10（SDK 收尾提交）　來源：sdk-bsp-gd32h77d-realthread-ginopi

由 Studio BSP SDK 倉庫可確認板卡的實際形態：核心為 GD32H77DIW（Arm Cortex-M7，最高 600 MHz），25 MHz 晶振，控制檯 UART1（PA2/PA3，115200-8-N-1），執行指示燈 PC4 每 500 毫秒翻轉。外擴 32 MiB SDRAM（對映於 0xC0000000）與板載 8 MiB GD25Q64E QSPI Flash；顯示為 720×720 MIPI DSI 屏（FL7707N，RGB565），觸控 GT911 走 I2C3；攝像頭 OV7670（QVGA RGB565，DCI 加 DMA）；乙太網 ENET1 RMII；Wi-Fi 由 GD32VW553 AT 模組經 UART4 提供；下載除錯走 SWD（Studio 側 DAP-Link / PyOCD，MDK 側 CMSIS-DAP）。SDK 基於 RT-Thread 5.3.0，含 16 個外設與應用示例工程，覆蓋 UART、I2C、SPI、QSPI Flash、SD 卡、CAN、PWM、RTC、SDRAM、USB 裝置與主機、LVGL 顯示與觸控、Wi-Fi、乙太網、攝像頭、MQTT 以及出廠綜合演示，同時提供 Studio 與 MDK5 兩套工程。整體定位為 H7 級圖形互動與聯網評估平臺，明顯向人機介面與多媒體應用傾斜。

3.3 軟體包索引：STM32N657xx FSBL 索引提交合入主索引（09-14）

日期：2026-09-14 12:35（北京時間，合入時間；作者提交日期 09-10）　來源：commit d9b53de7

上期送審的 hal_sdk 目錄 STM32N657xx FSBL 軟體包索引（對應軟體包索引倉庫 PR #2041）已於視窗內合入，提交新增 peripherals/hal-sdk/stm32/stm32n657xx_fsbl/Kconfig 與 package.json 兩個檔案，並同步更新 stm32 目錄 Kconfig 以掛載新條目。該軟體包與主倉庫送審中的 stm32n657-st-nucleo BSP 配套，意味著 STM32N6 系列 FSBL（首級安全啟動載入）環節的資源在軟體包側先行就位，開發者可在包管理器中直接獲取。軟體包索引與主倉庫 BSP 送審的先後配合，是近期 STM32 新系列匯入的固定節奏。
