日期：2026-09-08 ~ 2026-09-09　來源：RT-Thread/rt-thread commits（commit 66648255、commit d7ea2bce）

3.1 canopennode-rtt 視窗內合入三筆 CiA401 功能：RT-Thread 裝置行規支援、多裝置節點邏輯裝置、MSH 測試控制

日期：2026-09-08（17:56 北京時間批次合入，即 09:56:22Z）　來源：wdfk-prog/canopennode-rtt commits

外部生態倉庫 canopennode-rtt（CANopen 移植，wdfk-prog 維護）視窗內批次合入三筆新功能提交（author 時間 09-07 ~ 09-08 上午，09-08 傍晚統一合入）：

  • feat[canopennode][cia401]: add RT-Thread device profile support：CiA401（I/O 裝置行規）增加面向 RT-Thread 的裝置行規支援層；
  • feat[CiA401][device]: support logical devices in multiple-device nodes：多裝置節點場景下邏輯裝置支援（一個節點內掛多個邏輯裝置）；
  • feat[CIA401][RTT]: add MSH bench controls for device testing：新增 MSH 命令列基準測試控制，便於裝置測試。

這是繼 09-06 兩筆 CiA401 模擬量事件與故障安全落地（已收錄）後的第二批 CiA401 功能，標誌著 CANopen CiA401 裝置行規在 RT-Thread 側的移植從「協議幀級」推進到「裝置行規 + 多邏輯裝置 + 測試工具鏈」層面，功能面持續擴大。wdfk-prog 同時在官方倉庫推進 CAN 驅動生命週期重構（#11779），「外部生態移植 + 官方框架」雙線並行，是當前 RT-Thread CAN/CANopen 方向最活躍的貢獻者。
