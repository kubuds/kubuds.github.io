一、核心與版本動態

1.1 三日零合入終結：週一晨間批次合入 4 個 PR，覆蓋 mmcsd AC5 相容、MPU Kconfig、eclipse 工具鏈、hpmicro C++ 構建

日期：2026-09-07（合入視窗 10:19 ~ 11:18 北京時間，即 02:19:23Z ~ 03:18:42Z）　來源：RT-Thread/rt-thread commits（PR #11690、PR #11766、PR #11762、PR #11777）

主倉庫 rt-thread 結束自 09-03 #11776 以來連續三個視窗（三日）的零合入，週一晨間一小時內連續合入 4 個 PR：

  • #11690 [device][mmcsd] Fix Arm Compiler 5 build compatibility（CYFS3 提交，08-10 建立，佇列中最久約 4 周）：系統性修復 AC5 編譯 MMC/SD 與塊裝置程式碼的相容問題——通用 SWITCH 命令名與部分晶片暫存器宏衝突（改名 MMC_SWITCH 並同步修改飛騰 Phytium SDIF 呼叫點）；為 ARMCC5 提供具名 SD 狀態欄位訪問方式（其他編譯器繼續用匿名欄位介面）；以顯式 rt_list_entry 替代依賴 typeof 的塊裝置連結串列遍歷；DFS 關閉時補充分割槽結構定義；清理 void * 指標運算。
  • #11766 [mprotect][kconfig] Add safe defaults for MPU region count options（RogerNext 提交，08-28 建立）：為 NUM_MEM_REGIONS / NUM_CONFIGURABLE_REGIONS / NUM_EXCLUSIVE_REGIONS 補充 Kconfig 預設值。此前開啟 RT_USING_HW_STACK_GUARD 但未顯式配置時，rtconfig.h 生成空宏（#define NUM_CONFIGURABLE_REGIONS），展開成非法 C 表示式（(2 + )、for (i = 0U; i < ; i++)），導致 cortex-m4/m7/m33 的 MPU 程式碼編譯失敗。
  • #11762 [tools][eclipse] Sync assembler include paths（wdfk-prog 提交，08-28 建立）：同步 eclipse 外掛工程的彙編器 include 路徑，官方工具鏈（eclipse 外掛）構建一致性修正。
  • #11777 [bsp][hpmicro] wire CXX/CXXFLAGS from rtconfig into scons Environment（kaidegit 提交，09-01 建立）：hpmicro BSP（先楫半導體 HPM 系列）開啟 RT_USING_CPLUSPLUS 時，scons Environment 未接 rtconfig 的 CXX/CXXFLAGS 而回退宿主 g++，C++ 組編譯引數被當作單個未加引號引數導致構建失敗；修復後將 CXX/CXXFLAGS 注入 scons 環境。

該批次與維護者 Rbb666 同日晨間的密集評審（見 1.2）同段發生，主倉庫從「蓄積期」轉入「合入 + 評審雙活躍」；release 仍為 v5.2.2（2025-10-31），尚無新版本釋出動作。
