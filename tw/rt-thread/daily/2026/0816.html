二、生態與工具鏈（本日重點）

2.1 smart-build 合入 Buildroot 包匯入：rt-smart 應用生態量級躍升（8 月 15 日）

日期：2026-08-15　來源：RT-Thread/smart-build PR #49

BernardXiong 主導的 PR #49「build: import Buildroot packages into smart-build」於 8 月 15 日 15:33-15:57（北京時間）分 8 筆提交合入，改動 267 個檔案，是本日最具生態意義的事件。核心內容：

  • Buildroot 包匯入器：從固定的 buildroot/ checkout 生成 smart-build 軟體包定義，匯入的包可在 menuconfig 中直接選中（用 select 語義而非 depends on），按類別分組、描述不超過 80 字元；
  • 相容性過濾：透過 packages/.imports/never-import.yaml 清單跳過 libc、Linux headers 及與 RT-Thread Smart 不相容的包，匯入源以倉庫相對路徑記錄（如 buildroot/package/iperf3）；
  • 新增 CLI 子命令：./smart-build buildroot {menuconfig, import}，並修復 libffi/ncurses/tmux 的 staging 問題、為構建過程增加進度顯示；
  • QEMU 虛擬平臺完善：qemu-virt-riscv64 獲得與 qemu-virt-aarch64 同等的 rootfs bootargs 處理，兩個架構均支援 full/mixed rootfs。

意義：smart-build 是 rt-smart 的構建系統（kernel/rootfs/bootloader），本次打通 Buildroot（數千個軟體包的嵌入式 Linux 構建生態）意味著 rt-smart 應用軟體的可複用面從官方軟體包索引一次性擴充套件到整個 Buildroot 生態，網路（iperf3 等）、工具類元件可快速納入；同時 QEMU aarch64/riscv64 虛擬平臺的就緒降低了無硬體環境下的開發與 CI 驗證門檻，與 RISC-V 生態形成聯動。

2.2 ENV 工具合入 PR #287：外掛命令支援多例項併發（8 月 16 日）

日期：2026-08-16　來源：RT-Thread/env PR #287

ENV 工具 8 月 16 日 01:11-01:22（北京時間）合入 BernardXiong 主導的 PR #287「Feature/plugin command multi instance」：同一 ENV 外掛命令允許在多個終端例項中併發執行；外掛生命週期操作保持互斥（如解除安裝會等待活躍命令結束）；新增原生 Windows 共享/排他檔案鎖與併發迴歸測試（13 個測試全部透過）。這是繼 8 月 14 日 PR #286（epack 互動式腳手架 + WebUI）之後 ENV 工具鏈的又一次體驗改進——多工並行開發場景下不再互相阻塞，Windows 使用者（ENV 主力平臺）受益直接。
