一、核心與版本動態

1.1 主線一晚集中合入三筆：ESP32-C6 與 CH32V003 BSP、IAR 模板修復（09-28）

日期：2026-09-28 22:19 ~ 22:22（北京時間，合入時間）　來源：PR #11836、PR #11838、PR #11843

維護者 Rbb666 在視窗內約三分鐘內完成三筆合入。其一（#11836）樂鑫 ESP32-C6-DevKitC-1 板級支援（9 筆提交、40 個檔案、+9598/-50）正式進入主線：含 bsp/ESP/ESP32_C6 完整板級工程（構建配置、IDF 適配層 idf_port、連結指令碼與證書包）、ESP 共享驅動與 Kconfig 的適配更新及 CI 接線；該提案 09-25 凌晨提交、約四天後合入，本筆另併入一處 CH32V203 SConstruct 調整。其二（#11838）沁恆 CH32V003F4P6-EVT 板級支援（5 筆提交、47 個檔案、+9258）合入：RISC-V 核心 RV32EC、48MHz、16KB Flash，預設 UART1 進 msh，此前已於 09-25 進入評審。其三（#11843）修正 5 個 BSP 的 IAR 工程模板：模板 ewp 的連結配置檔案原先指向其他開發機的絕對路徑，統一改為 $PROJ_DIR$ 相對路徑（+7/-7，涉及 asm9260t、mm32f3270-100ask-pitaya、stm32f103-100ask-mini 等板卡）。

1.2 ESP32-S3-DevKitM-1 BSP 提案進入評審：需補齊軟體包依賴（09-28 ~ 09-29）

日期：2026-09-28 19:04（建立）~ 09-29 10:18（最近更新）　來源：PR #11844、PR #11816

同一貢獻者（cms19859230182-lang）在視窗內為樂鑫 ESP32-S3-DevKitM-1 提交全新 BSP 提案（#11844）：6 筆提交、44 個檔案、+6862/-31，新增 bsp/ESP/ESP32_S3 與 libcpu/xtensa/esp32s3，單核映象，UART0（GPIO43/44）進 msh，Flash 8MB DIO 80MHz；提案註明該板為 Xtensa LX7 架構、非 RISC-V，不能沿用 ESP32-C3 的工具鏈與中斷接法，所配工具鏈為 xtensa-esp32s3-elf GCC 12.2.0。評審中維護者指出仍有編譯與軟體包依賴問題（09-28 22:18），提交者已在 09-29 上午回應並著手修訂。另，ESP32-C3 的 Windows 構建修正提案（#11816，09-21 提交）在 09-29 上午有提交者跟進評論，仍處評審。

1.3 RT-Thread Env 工具修復 Unicode 與非法路徑處理（09-28）

日期：2026-09-28 21:07 ~ 21:10（提交與合入時間）　來源：RT-Thread/env PR #298

env（Windows 側開發工具）在視窗內合入修復 #298：移除僅允許 ASCII 的 BSP 路徑校驗，使 Env 命令可在中文等 Unicode 工作目錄下正常使用；同時修正資源管理器右鍵選單在磁碟根目錄下的路徑處理、選定路徑不存在時直接終止啟動，並補充迴歸測試（含 Unicode 路徑用例）。由專案創始人 Bernard Xiong 提交併合入，為 env 倉庫自 09-16 以來的首筆更新。

3.1 GD32 下游倉合入驅動更新：USART/I2C/SPI 的 GPIO 初始化切換新版（09-28）

日期：2026-09-28 16:20（合入時間）　來源：GD32-MCU-IOT/gd32_rt-thread PR #71

兆易創新維護的 RT-Thread 下游倉庫在視窗內合入驅動更新（#71，提交說明為將 USART、I2C、SPI 驅動的 GPIO 初始化更新為新版本）：涉及 drv_hard_i2c、drv_spi、drv_usart 六個檔案，相對此前版本淨移除 797 行（以收回舊版實現為主，驅動檔案保留、實現收斂）。該倉庫的晶片適配與驅動維護節奏在本月持續（09-18 曾合入 F20x I2C DMA 更新）。
