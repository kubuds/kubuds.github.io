RT-Thread Env 工具 Windows 版倉庫（ConEmu shell 環境下的 Env 工具）今日上午釋出 v2.1.0：單筆提交 “Update Env to version 2.1.0”，涉及 packages 軟體包索引更新、tools/bin/env-init.bat 與 tools/scripts 調整。該版本距上一正式版本 v2.0.0（2024-07-10）已逾兩年，是 env-windows 倉庫 2024-07 之後的首次版本跳躍（其間僅 2025-06 補入 DTC 工具一筆功能提交）；GitHub Releases 頁尚未建立 v2.1.0 release 物件，目前僅 tag 落地，正式釋出說明預計隨公告/公眾號渠道放出。與 env 主倉庫 09-04 合入的 WebUI 外掛保活迭代（#294，已收錄）銜接，Env 工具鏈（選單配置/軟體包管理/WebUI 外掛）近期迭代節奏加快，或為 elexcon 2026 前後工具鏈整合動作的一部分。

1.4 OSPP 2026 議題提議：RISC-V Lazy FP/RVV 上下文切換（#11786）

日期：2026-09-07（23:49 北京時間建立，即 15:49:05Z）　來源：RT-Thread/rt-thread issue #11786

外部貢獻者 PiyushPatle26 在主倉庫提交 OSPP 2026 議題提議（issue #11786）：RISC-V 移植當前每次上下文切換都無條件儲存/恢復完整 FPU 狀態，即使執行緒從不使用浮點；同時核心完全不支援向量擴充套件（RVV）——向量暫存器不線上程上下文中，任何使用 V 指令的執行緒其狀態都會被上下文切換靜默破壞。提議利用硬體已提供的 mstatus.FS / mstatus.VS dirty 位，將擴充套件狀態儲存/恢復改為惰性（lazy）模式，而非無條件執行。該議題關聯早期 issue #10722（RISC-V 向量支援缺口）。此提議若入選，將成為核心 RISC-V 移植在浮點/向量擴充套件上下文管理上的結構性改進，與 #11775（C908 rt-smart/MMU）同屬核心側 RISC-V 主線推進。視窗內另有兩隻 pin_api_attach_irq legacy 路徑 IRQ 引數問題 issue（#11783 已關、#11784 跟蹤中，09-07 15:14/16:57 建立），屬同一驅動註冊問題的跟進報告。
