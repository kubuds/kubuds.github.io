一、核心與版本動態

1.1 官方 Env 工具鏈合入 WebUI 外掛狀態保持（keep_alive）機制

日期：2026-09-05（合入 09-05 00:08 北京時間）　來源：RT-Thread/env PR #294（合入提交）

RT-Thread 官方開發輔助工具 Env（倉庫 RT-Thread/env）合入由創始人 BernardXiong（熊譜翔）提交的 PR #294「Add opt-in state retention for plugin WebUI pages」。核心變更：為外掛 manifest.webui 增加可選 keep_alive 欄位（預設 false），開啟後外掛 WebUI 的 iframe 在外掛頁、設定頁與外掛中心之間切換導航時保持掛載，不再每次過載（未開啟外掛維持原有過載行為）；同時移除 WebUI 頂部欄、把「退出 WebUI」操作移至側欄底部，並按外掛隔離靜態資源、為沙箱化 WebUI 頁面開放可選的後端 HTTP/WebSocket 上下文。該 PR 承接 09-02 起 env 分支上的一系列 WebUI 改造（按外掛維護 iframe 生命週期、外掛資源令牌與 CSP 邊界、doctor 請求代次校驗等，feature/ws 分支），本次合入標誌 Env 的 WebUI 外掛系統從「切換即過載」升級為「頁面狀態按需保持」，屬官方工具鏈體驗迭代，亦是本視窗 org 內唯一合入。

1.2 主倉庫視窗內零合入零新 PR，蓄積期延續；CAN 重構 PR #11779 無新進展

日期：2026-09-05　來源：org:RT-Thread 倉庫列表（commits / pulls 介面）

主倉庫 rt-thread 連續第二個視窗無新提交合入（最近合入仍為 09-03 早間 #11776，昨日已收錄），視窗內亦無新 PR 建立，release 仍為 v5.2.2（2025-10-31）。評審佇列狀態與昨日持平：CAN 框架重構 PR #11779（wdfk-prog，2 commits、+2902/-1308）最後一條評論仍為維護者 CYFS3 於 09-03 17:47（北京時間）的表態——不建議另行維護一套 CAN_V2 框架、希望開發者共同參與推動合入，視窗內無新增評論與提交；#11775（[bsp][c908] rt-smart 與 MMU Sv39/48 支援）、#11772（堆執行時 AddressSanitizer）、#11774（sal SIOCGIFCONF 溢位修復）、#11689（stm32 SPI BDMA）等均保持 open 未動。核心側進入合入後的常規蓄積期。

三、生態與廠商適配

3.1 canopennode-rtt 新增 CiA402 週期同步模式 CSP/CSV/CST，運動控制模式面補齊

日期：2026-09-05（11:08 北京時間 push）　來源：wdfk-prog/canopennode-rtt

topic:rt-thread 生態倉庫 canopennode-rtt 預設分支視窗內新提交「feat: support CiA 402 CSP CSV and CST modes」，為 CiA402（DS402 運動控制 profile）增加週期同步位置（CSP）、週期同步速度（CSV）、週期同步力矩（CST）三種週期同步模式。與 09-03/09-04 合入的多軸裝置 profile 與 PP/PV/Homing 定位/速度/回零模式銜接，DS402 支援從非週期模式擴充套件到週期同步閉環模式，運動控制功能面補齊。結合該作者同時在主倉庫推進 Generic CAN 框架重構（#11779），「應用層（CANopenNode 擴充套件）+ 框架層（CAN 重構）」雙線並進態勢延續，CAN/運動控制仍是當前社群最活躍的推進主線。

3.2 電子工程專輯專欄分享社群作品：FRDM-MCXN947 USB 監控副屏

日期：2026-09-04（17:30 北京時間）　來源：電子工程專輯 a522648（RT-Thread 論壇原作）

電子工程專輯「開源專案分享」專欄 09-04 發文介紹基於恩智浦 FRDM-MCXN947 開發板的 USB Monitor 專案實踐：透過 RT-Thread 作業系統 + LVGL 圖形庫 + CherryUSB 協議棧，實現將 PC 端 CPU、GPU 等執行狀態實時顯示在副屏上。該作品源自 RT-Thread 論壇「24 嵌入式設計大賽」的「USB 一線通監控副屏」專案，屬社群作品經行業媒體轉載傳播的典型案例，同時展示了 RT-Thread 在 NXP 新平臺（MCXN947，雙核 Cortex-M33）上配合 LVGL/CherryUSB 生態的開箱可用度。EET 原站正文不可直達，連結存證。

3.3 極海「極海芯得 EP.87」：RTT-Studio 環境下 APM32 外設驅動使用指南

日期：2026-09-03（11:30 北京時間；今日 3 天視窗複查補錄，昨日 zh 查詢未命中）　來源：電子工程專輯 a522255

極海半導體（Geehy）開發者社群「極海芯得」系列第 87 期（電子工程專輯 09-03 釋出）：RTT-Studio 環境下的 APM32 外設驅動使用指南。文章講解在 RT-Thread Studio 新建 APM32 工程後 adc、dac、hwtimer、uart 等外設驅動的使用方法，並指出 APM32 的 RT-Thread 外設驅動已將底層引腳初始化與外設時鐘開啟封裝在驅動內部，開發者可直接以裝置模型介面呼叫。屬晶片原廠面向 RT-Thread 生態的持續教程輸出（該系列此前已覆蓋 APM32 系列 RT-Thread BSP 移植、LwIP、LVGL、CherryUSB 等主題），對 APM32 使用者與 Studio 上手者有直接參考價值。

3.4 生態參考：H120D 無人機 RT-Thread 內部機制逆向文件專案更新

日期：2026-09-05（07:31 北京時間 push）　來源：H4ck3rTR/h120d-protocol

第三方逆向工程文件專案 h120d-protocol（stars 4）視窗內有更新：整理 Holy Stone H120D 航拍無人機 WiFi 協議逆向資料包、RT-Thread 內部機制說明及配套控制工具。該專案為獨立愛好者的逆向文件工作（非官方），將消費級無人機韌體中 RT-Thread 的內部機制（執行緒/訊息等）與私有 WiFi 協議一併文件化，對研究 RT-Thread 在消費電子/無人機產品的實際落地形態有一定參考價值，收錄作生態參考。
