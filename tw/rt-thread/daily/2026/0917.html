一、核心與版本動態

1.1 小華半導體 HC32 系列 BSP 配置同步合入主線（09-16）

日期：2026-09-16 17:54（北京時間，合入時間）　來源：PR #11798

小華半導體 HC32 系列的配置同步提案在視窗內合入主線，規模 52 個檔案、新增約 2844 行、刪除 720 行，四個提交分別完成系列配置同步與工程檔案重生成、程式碼格式化、標頭檔案格式整理與串列埠中斷驅動編譯錯誤修復、rtconfig 回退與格式化忽略清單調整。具體改動包括刪除電源管理配置中的喚醒定時器使能掩碼、把名稱長度上限調整為 24 並同步核心名稱長度配置項。該提案 09-11 送審、09-14 完成最後一輪修訂，評審到合入約五天。HC32 系列在近一週內已有驅動擴充套件與配置同步兩批改動落地。

1.2 STM32 GCC 連結指令碼容量校驗修復合入，超容量韌體問題關閉（09-17）

日期：2026-09-17 09:31（北京時間，合入時間）　來源：PR #11805、Issue #11124

STM32 各區連結指令碼的容量校驗缺陷在視窗內完成修復併合入，改動覆蓋 110 個連結指令碼，新增與刪除各約 659 行。問題根因是部分指令碼用初始化資料段指定載入地址，但未把該段關聯到對應的只讀儲存區域，導致程式碼與常量本身沒有超限、疊加初始化資料映象後才超限時，連結仍會透過併產出超出配置容量的韌體。修復參照意法半導體官方連結指令碼的寫法補齊區域歸屬。同源缺陷報告自今年 1 月提交以來一直處於未閉狀態，本次隨修復一併關閉。

1.3 SDIO 驅動登出記憶體洩漏修復提案提交，承接上期缺陷報告（09-17）

日期：2026-09-17 10:01（北京時間，提交時間）　來源：PR #11806

上期報告記錄的 SDIO 驅動登出缺陷已收到修復提案，改動 1 個檔案、新增 6 行、刪除 4 行。原邏輯只有在找到匹配的 SDIO 卡時才釋放驅動註冊節點，裝置上無卡或卡不匹配時節點不釋放，反覆註冊與登出會造成記憶體洩漏。修復方案是確定待登出驅動後，無論當前是否存在匹配卡都從驅動連結串列移除並釋放節點，僅在匹配到卡時繼續呼叫驅動的移除回撥，保持原有裝置解綁流程不變。從缺陷報告到修復提案約兩天，處置節奏偏快。

1.4 三筆小型修復進入評審：UART4 接收 DMA、塊裝置日誌格式、持續整合依賴（09-17）

日期：2026-09-17 10:38 ~ 11:50（北京時間，提交時間）　來源：PR #11808、PR #11809、PR #11807

視窗末尾有三筆常態化修復進入評審。其一是為 STM32H7 通用 DMA 配置補充 UART4 接收側定義，包含例項、請求、中斷與時鐘宏，此前啟用 UART4 接收 DMA 會編譯失敗。其二是修正塊裝置分割槽元件的日誌格式符與引數型別不匹配問題，在部分 32 位工具鏈下無符號整型對應長整型、方用短整型格式符會觸發格式告警，改動只涉及輸出語句不觸及分割槽探測邏輯。其三是為 LLVM ARM 持續整合流程補裝終端資訊庫依賴，修復該流水線近期的構建失敗。

1.5 lwip 2.2.1 協議棧支援提案視窗內繼續迭代（09-16）

日期：2026-09-16 18:39（北京時間，最近更新）　來源：PR #11797

網路協議棧版本推進提案在視窗內再次更新，規模仍為 1874 個檔案、新增約 34.6 萬行、刪除 45 行，討論數增至 4 條。該提案修復既有議題並引入 lwip 2.2.1 支援，驗證平臺為恩智浦 i.MX RT1180 評估板，開啟乙太網、套接字抽象層、網路裝置與 lwip 元件。評審標籤為元件，此前第三方記憶體比對工具判定未引入記憶體佔用變化。若合入，主線網路棧基線將從 2.1.x 前進到 2.2.x，屬閘道器與工業聯網場景的常用鏈路，目前仍處評審迭代期。

三、生態與廠商適配

3.1 Gino Pi BSP SDK 增加 JLink 除錯鏈路，五十個工程一併補齊（09-16）

日期：2026-09-16 18:27 / 18:33（北京時間，提交時間）　來源：Studio BSP SDK 倉庫

Gino Pi 板卡的 Studio BSP SDK 在視窗內新增 JLink 除錯支援，兩筆提交合計 50 個檔案、新增約 2281 行、刪除 20 行。做法是為每個示例工程生成 JLink 除錯啟動配置與偵錯程式設定檔案，並同步更新中英文說明與工程指南文件。此前該 SDK 的下載與除錯鏈路只有 Studio 側的 DAP-Link 與 MDK 側的 CMSIS-DAP 兩條，本次補齊第三種偵錯程式，對使用 JLink 的工業與量產驗證團隊更友好。該 SDK 基於核心 5.3.0，含十六個外設與應用示例工程，板卡核心為 GD32H77D，屬高效能圖形互動與聯網評估定位。

3.2 睿擎平臺首發適配 Gino Pi：GD32H77D 開發板全鏈路開箱即用（09-16）

日期：2026-09-16 11:50（北京時間，釋出時間）　來源：電子工程專輯聚合條目

據聚合源條目，睿擎平臺首發適配 Gino Pi 開發板，強調 GD32H77D 平臺全鏈路開箱即用。睿擎平臺此前的板卡承載為瑞芯微 RK3506 與 RK3562 兩條線，本次向微控制器級的高效能圖形平臺延伸，與其工業控制與邊緣互動的定位互補；配套的板級支援包與示例工程已在 Studio 側就位，除錯鏈路也在同一視窗補齊 JLink。原文頁面受站方訪問限制未能取得，適配範圍與功能清單以聚合摘要與 SDK 倉庫公開資料交叉說明。
