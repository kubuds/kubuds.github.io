一、核心與版本動態

1.1 網路棧安全修復：DHCP 伺服器選項邊界檢查合入，#11323 關閉（10-10）

日期：2026-10-10 17:20（合入時間）　來源：PR #11858、Issue #11323

DHCP 伺服器選項解析的緩衝區邊界檢查提案（#11858，單檔案 +63/-33、兩筆提交——邊界檢查與 clang-format 整理）由維護者合入主線，缺陷單 #11323（解析選項時對資料包緩衝區越界讀取，由安全研究者上報）隨之關閉。修復在選項解析前增加邊界校驗，消除越界讀取路徑；該案 10-08 開出、經節後佇列消化後進入合入位，為視窗內網路側首筆安全類修復。

1.2 STM32 全系 BSP 棧 8 位元組對齊修正合入（10-10）

日期：2026-10-10 17:20（合入時間）　來源：PR #11841、Issue #7527

全系 STM32 BSP 棧對齊修正合入（#11841，作者 avm1234567，110 檔案 +220/-220）：各 BSP 連結指令碼與模板的 .stack 段由 ALIGN(4) 統一改為 ALIGN(8)，滿足 ARM AAPCS 對公共函式邊界處棧指標對齊的要求。修正援引 2023 年 5 月開出的缺陷單 #7527（全系 STM32 連結指令碼問題；該單目前仍為開放狀態，未隨本次合入自動關閉）。

1.3 C++ 全域性構造相容修復合入：cplusplus_system_init 補走 .init_array（10-11）

日期：2026-10-11 16:11（合入時間）　來源：PR #11856、Issue #11778

C++ 執行時相容修復合入（#11856，作者 cms19859230182-lang，4 檔案 +60/-6）：新版 GCC 將 C++ 全域性建構函式放入 .init_array 段，而既有初始化流程僅掃描 ctors_start/ctors_end 區間，導致未合併該段的部分 BSP 漏跑構造；修復補走 __init_array_start/__init_array_end（弱符號宣告），並跳過已落入 ctors 區間的重複條目。關聯缺陷單 #11778（多 BSP 的 C++ 自動構造支援異常）關閉。

1.4 USB CDC VCOM 環形緩衝別名缺陷修復合入，#11739 關閉（10-11）

日期：2026-10-11 17:37（合入時間）　來源：PR #11770、Issue #11739

USB CDC 虛擬串列埠修復合入（#11770，作者 Finder16，單檔案 +47/-6、兩筆提交）：舊實現將內嵌環形緩衝直接掛到 serial_rx，Serial V2 按串列埠 FIFO 結構解釋該指標——因環形緩衝恰為首成員而表面上可用，但 rx_cpt、rx_timeout 等欄位實際錯位；修復改為規範掛接並補充 VCOM 輪詢接收支援。該案 08-29 開出、經多輪評審後合入主線，缺陷單 #11739 關閉。

1.5 utest 效能測試時鐘依賴修復合入（10-11）

日期：2026-10-11 15:59（合入時間）　來源：PR #11813

測試框架修復合入（#11813，作者 CYFS3，2 檔案 +8/-1）：修復 utest 效能測試對固定時鐘計時的依賴，並加固測試構建守衛，降低不同板級與模擬環境下的誤報。

1.6 RISC-V 向量：vstart 恢復順序修正提案進入評審（10-10 ~ 10-11）

日期：2026-10-10 13:37 ~ 10-11 17:15（建立與更新）　來源：PR #11861、Issue #11786

RISC-V 向量上下文修正提案進入評審（#11861，作者 PiyushPatle26，4 檔案 +187/-5）：RESTORE_VECTOR 此前在 vsetvl 之前恢復 vstart，而向量配置指令會將其清零、導致重啟索引丟失；修復把恢復動作移到配置指令之後，並在 qemu-virt64-riscv 增加覆蓋零/非零 vstart 與 vl、vtype、vcsr 的迴歸用例（彙編探針 + C 用例）。維護者 10-11 評審確認修法正確、建議先解決測試併發問題並補驗證證據，作者當日已推送修正提交。同作者推動的 OSPP 2026 議題「RISC-V 惰性 FP/RVV 上下文切換」（#11786）視窗內同步更新實現計劃。

1.7 netdev ping 統計除零缺陷獲認領，修復提案新開（10-11）

日期：2026-10-11 22:10 ~ 23:05（認領與提案時間）　來源：Issue #11852、PR #11862、PR #11853

netdev ping 缺陷的修復脈絡在視窗內明顯推進：缺陷單 #11852（10-05 上報；目標不可達時 received 為 0，平均值除法觸發 x86 SIGFPE / Cortex-M 除零，殺死 shell 執行緒）於 10-11 晚間由貢獻者 ymj0440 評論認領、隨即開出提案 #11862（單檔案 +1/-1）；此前同類提案 #11853（作者 r3wretrhy，10-06 開出）已於 10-07 獲評審透過（LGTM）但尚未合入。兩案並行，待維護者擇一。

1.8 Next RISC-V 大重構提案視窗內再次重新整理（10-10）

日期：2026-10-10 19:18（最新提交時間）　來源：PR #10320

大重構提案「Next RISC-V」（#10320，作者 GuEe-GUI，166 檔案 +15175/-2614）視窗內再次重新整理：頭部提交更新為「[libcpu][risc-v] Refactor the RISC-V architecture port」，為 10-08 變基後的又一次推送。提案累計評論已滿百條，整合範圍覆蓋 S-mode RT-Thread / RT-Smart、Sv32~Sv64 MMU、AIA / CLIC / PLIC 中斷控制器與 T-Head 平臺合併等，仍在開放評審。

1.9 在審佇列兩處跟進：#11787 CI 排查、#11815 提交重新整理（10-10 ~ 10-11）

日期：2026-10-10 ~ 10-11（更新時間）　來源：PR #11787、PR #11815

在審佇列兩處跟進：其一，Eclipse 目標生成指令碼的隱藏目錄排除提案（#11787）經維護者 10-11 提示 CI 報錯後，作者當晚完成排查——失敗原因為流水線環境缺少 scons 命令、與排除邏輯本身無關；其二，lwip 段宏開關提案（#11815）作者 10-10 重新整理三筆提交，納入 PBUF_RAM 餘量可配置與租約移除、啟動錯誤處理修復。
