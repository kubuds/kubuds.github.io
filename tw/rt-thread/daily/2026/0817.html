RT-Thread 每日動態報告（2026-08-17）

2026-08-17 苦芽科技

調研視窗：過去 24 小時（2026-08-16 11:18 ~ 2026-08-17 11:18 北京時間） 信源：RT-Thread 官方新聞 API、GitHub（org: RT-Thread / topic: rt-thread）、Google News 聚合（zh-CN / en-US）、HN 等（詳見附錄）

一、核心與版本動態

1.1 WLAN 框架新增 WPA3/企業級/WAPI/OWE/DPP 安全模式標誌（8 月 17 日合入）

日期：2026-08-17（北京時間 11:00 合入；作者提交於 8 月 11 日，批次合入模式）　來源：rt-thread 主倉庫 commit 0823a4b

components/drivers/wlan/dev_wlan.h 安全標誌位一次性擴充五類：WPA3_SECURITY（WPA3）、ENTERPRISE_ENABLED（WPA2/WPA3 企業級認證）、WAPI_ENABLED（中國國標 WAPI）、OWE_ENABLED（開放網路增強，公共 Wi-Fi 免密加密）、DPP_ENABLED（Wi-Fi Easy Connect 裝置配網協議），此前僅有 WPA/WPA2/WEP/TKIP/AES 位。這是 WLAN 裝置框架層的 API 能力擴充——驅動可據此嚮應用暴露現代 Wi-Fi 安全協議能力，具體驅動適配有待後續跟進。作者 Kai（8 月 11 日提交），由維護者 Rbb666 於今日 11:00 合入主倉庫，屬典型的批次合入模式。

1.2 [bsp/raspberry-pi] 新增 Raspberry Pi 5 BSP 與 BCM2712 DMA 支援（8 月 16 日）

日期：2026-08-16 19:56（北京時間）　來源：rt-thread 主倉庫 commit f7258a6

GuEe-GUI 提交：樹莓派公共驅動重組至裝置框架（DM）之下；新增 Raspberry Pi 5 BSP（含配置與文件）；合入 BCM2712 與 DesignWare AXI DMA 控制器支援，按 channel mask 區分 BCM2712 的 DMA32/DMA40 通道；控制器復位後恢復 AXI DMA 使能位；支援跨 DMA 通道共享 AXI 最大突發長度。Pi 5（BCM2712）為 Raspberry Pi 系列在該 BSP 中首次落地，將 RT-Thread 對樹莓派硬體的支援推進到當前主力型號。

1.3 [bsp/rockchip] 擴充套件平臺與外設支援（8 月 16 日）

日期：2026-08-16 19:57（北京時間）　來源：rt-thread 主倉庫 commit d890866

同一作者同日提交：新增音訊、顯示、乙太網、PCIe、PHY、SDIO、UFS、硬體加密與多媒體加速器支援，並同步更新 RK3300 與 RK3500 平臺配置及驗證應用。瑞芯微平臺從基礎 BSP 向全外設覆蓋推進，其中 UFS/PCIe/硬體加密等面向中高階儲存與邊緣閘道器場景。

1.4 版本狀態無變化

日期：2026-08-17　來源：rt-thread releases

最新正式版本仍為 v5.2.2（2025-10-31 釋出），視窗內無新 release、無預釋出版本出現。

二、生態與工具鏈（本日重點）

2.1 smart-build 合入 ROS 2 交叉編譯支援：rt-smart 打通機器人中介軟體棧（8 月 17 日）

日期：2026-08-17 08:07（北京時間）　來源：RT-Thread/smart-build PR #50

BernardXiong 主導的 PR #50「Add ROS 2 cross-build and Smart package support」於今日 08:07 合入，改動 100+ 檔案（其中 packages/ros2 目錄 63 個）。核心內容：

  • ament_cmake 交叉編譯支援：ROS 2 軟體包與 host 工具包分組發現、host 依賴排程、原始碼補丁與 C++ 執行時 staging；
  • ROS 2 包棧：ROS 2 核心軟體包 + host SDK + 依賴配方（CycloneDDS、console-bridge、fmt、libyaml 等），固定版本源 + RT-Smart 適配補丁；
  • QEMU aarch64 傳輸層冒煙目標：新增 ros2-transport-smoke 應用/軟體包，掛在 boards/qemu-virt-aarch64 上，無硬體環境即可驗證 ROS 2 傳輸層；
  • 輕量 ipkg 包管理：啟用 ipkg 並禁用 BusyBox dpkg/rpm 功能，改進 BusyBox mount/rootfs 執行時整合；
  • 質量門：pytest 150 項全部透過；核心側 procfs 與系統相容性改動明確說明將另行提交。

意義：繼 8 月 15 日 Buildroot 包匯入後，smart-build 在四天內完成第二次生態量級躍升，方向從”通用應用生態”轉向”機器人中介軟體生態”。ROS 2 是現代機器人/具身智慧的事實標準中介軟體，rt-smart 獲得 ament 構建與 CycloneDDS 支援，意味著 RT-Thread 正式切入 ROS 2 嵌入式目標平臺行列；QEMU aarch64 冒煙目標延續了 8 月 15 日 QEMU virt 雙架構就緒的鋪墊，形成連續推進鏈路。

四、行業應用專章（機器人 / 具身智慧 / 工業）

  1. ROS 2 支援是機器人方向的標誌性事件：rt-smart + ROS 2（ament + CycloneDDS + QEMU 傳輸層冒煙）直接回應機器人/具身智慧對中介軟體的需求。此前「滴水智匯」臨港具身智慧生態佈局、Edgi-X AI 飛控為生態側動作，本次是工具鏈側真正把 ROS 2 構建與傳輸層跑起來的工程基礎；官方後續若提交核心 procfs 配套改動，將補齊執行時能力。預期接下來可見官方 ROS 2 示例與機器人廠商適配案例。
  2. 工業 EtherCAT 主線不變：睿擎工業平臺 Workshop 倒計時 10 天，26.08.06 版本與 3 核工控機預售餘溫仍在，視窗內無新增商業化動作。
  3. Wi-Fi 安全協議位補齊的行業價值：WPA3/企業級認證適配工業閘道器、零售終端等需安全接入的場景；WAPI 面向國內合規市場；OWE/DPP 面向公共網路體驗。框架層就緒後，待常用 Wi-Fi 驅動（Realtek/ESP 等）跟進實現。

五、總結與趨勢觀察

  1. 工具鏈連續三日加碼，方向明確轉向機器人：8/15 Buildroot 包匯入 → 8/16 ENV 外掛併發 → 8/17 ROS 2 交叉編譯。三連擊之後，rt-smart 應用生態同時覆蓋”通用 Linux 生態（Buildroot）”與”機器人中介軟體生態（ROS 2）”兩大面，官方下半年將機器人/具身智慧作為 rt-smart 主攻方向的意圖清晰。
  2. ROS 2 落地策略務實漸進：從 QEMU aarch64 冒煙目標起步、核心側改動另行提交，降低單次合入風險；後續跟蹤核心 procfs 配套提交與 ROS 2 真實裝置執行案例。
  3. 核心側 BSP 雙線推進：樹莓派 5（BCM2712）與瑞芯微（RK3300/RK3500 外設擴充套件）同日合入，DM 驅動框架在主流開發板平臺覆蓋擴大；RPi 5 入列對開發者基數有直接價值。
  4. WLAN 框架安全協議位補齊：WPA3/OWE/DPP/企業級/WAPI 標誌就位，為驅動實現留好介面；關注常用 Wi-Fi 驅動的跟進節奏。
  5. 版本面平穩，官方 API 滯後依舊，媒體側核查受限：v5.2.2 不變；官方新聞 API 滯後約 2 個月未見改善；本視窗 Google News（zh/en）經代理均超時不可達（詳見附錄），媒體側核查不完整，本日結論主要基於 GitHub 合入事實。
