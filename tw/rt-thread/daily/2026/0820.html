一、核心與版本動態

1.1 memheap 雙重釋放防護合入：release 構建下重複 free 不再破壞堆賬本

日期：2026-08-20（09:48 北京時間合入）　來源：RT-Thread/rt-thread commit 8234a36

主倉庫視窗內唯一新合入：[kernel/memheap] fix: stop invalid frees from corrupting heap（作者 Hui Su，維護者 Rbb666 合入，commit 8234a36）。提交說明指出：當 RT_DEBUGING_ASSERT 關閉時，RT_ASSERT() 不再中斷執行，release 構建中順序發生的重複 free 會繼續走到後續邏輯，從而破壞 memheap 的堆統計與空閒連結串列。修復在完成塊校驗後直接 return，使非法釋放無法再更新堆賬本。提交附帶的復現資料（double-free：used=64 / alloc=224 / free=64 → 釋放後 used 變為 4294959232，即 32 位溢位）直觀展示了漏洞後果；修復經 scons -C bsp/qemu-vexpress-a9 構建驗證。這是繼 08-17 AF_UNIX 大功能合入後核心側的防禦性加固，屬 release 構建健壯性修復。

日期：2026-08-19 ~ 2026-08-20　來源：wdfk-prog/canopennode-rtt commits

  • 08-19 14:42 北京時間：新增 ASCII gateway MSH 控制檯橋（CANopen ASCII 閘道器命令經 RT-Thread MSH shell 互動）；

結合 08-17/08-18 已合入的 heartbeat 監督 NMT 主站示例、GFC 協議診斷、MCU 側 SDO 客戶端校驗，該包正以”示例先行、逐功能補齊”節奏快速成型，覆蓋 NMT/SDO/GFC 等 CANopen 核心服務，面向工控現場匯流排場景。屬早期專案觀察物件，收錄為生態動態。

四、行業應用專章（工業 / 機器人 / 具身智慧）

4.1 睿擎平臺 DSMC+FPGA 通訊頻寬提升至 90MB/s

日期：2026-08-19（18:15 北京時間）　來源：電子工程專輯（經 Google News 收錄） / EET-China 原文

電子工程專輯刊發《睿擎平臺 DSMC+FPGA 通訊速度提升至 90MB/s》技術文（EET-China 原站不可達，正文經檢索摘要核實）：睿擎平臺（睿擎派 RK3506J 工業板 + 官方 FPGA 擴充套件板）DSMC 並行匯流排升級支援 16 位通訊後，FPGA 實測通訊頻寬提升至 90MB/s。文章對比了升級前後驅動機制：同步機制由”無（同步阻塞）”改為 rt_event 事件驅動，單次傳輸量由 4 位元組提升至 2KB（DMA 最大單次），並最佳化突發配置，CPU 佔用顯著下降。此為睿擎 26.08.06 版本特性（8 月 13 日版本釋出直播預告口徑為 89MB/s）的實測技術展開；硬體底座為 RK3506J（三核 Cortex-A7 + 單核 Cortex-M0，最高 1.5GHz）的 DSMC/Flexbus 並行匯流排（硬體頻寬 400MB/s，直連 FPGA 高速資料採集）。該進展與 8 月 27 日上海 EtherCAT 實時控制 Workshop 同屬睿擎工業平臺的工控通訊主線，方向為運動控制 + FPGA 資料採集的低延遲高頻寬路徑。

4.2 RT-Thread 入選 Beningo 2026 RTOS 效能報告參測名單

日期：2026-08-19（19:30 北京時間）　來源：電子工程專輯《2026年RTOS效能榜單出爐，PX5 RTOS拿下效能第一》 / Beningo 2026 RTOS Performance Report

電子工程專輯報道 Beningo（Embedded Group）2026 RTOS 效能報告發布：該報告為獨立基準，在真實 Cortex-M 硬體上以 Eclipse Thread-Metric 套件測試 8 款 RTOS——PX5 5.3.1、ThreadX 6.5.1、FreeRTOS 11.3.0、Zephyr 4.4.1、Arm Keil RTX5 5.9.1、RT-Thread、NuttX、Micrium µC/OS-III。測試含 9 項原生 API 測試（基礎處理、協作/搶佔排程、記憶體分配、訊息處理、同步、中斷處理、中斷搶佔、中斷延遲示波器實測等）及 POSIX API 對比。結果頭條為 PX5 奪魁：ThreadX 最高慢 30.2%、FreeRTOS 最高慢 80.7%、Zephyr 最高慢 45.3%。RT-Thread 作為 8 款參測物件中唯一來自中國的開源 RTOS 入選，具體名次與明細需郵箱訂閱免費下載報告；報告同比資料（2024 vs 2026）僅覆蓋 FreeRTOS/ThreadX/Zephyr/PX5，RT-Thread 系本屆新增參測物件。對社群而言，這是 RT-Thread 進入國際獨立基準視野的外部驗證訊號，效能定位以報告正式內容為準。

五、總結與趨勢觀察

  1. 核心側”消化期 + 防禦加固”：AF_UNIX 套接字（08-17）之後視窗內首個合入是 memheap 雙重釋放防護（08-20），修復 release 構建（關閉斷言）下重複 free 破壞堆賬本的問題；大功能預計隨下個版本釋出。
  2. 睿擎工業平臺成為本月媒體側主線：DSMC 16 位匯流排升級 + rt_event 事件驅動 DMA 實現 FPGA 通訊 90MB/s，緊接 8/27 EtherCAT Workshop 預熱，工控實時控制方向連續輸出。
  3. 國際基準曝光：RT-Thread 首次進入 Beningo 2026 RTOS 效能報告 8 款參測名單（唯一國產開源 RTOS），效能定位待報告全文公佈。
  4. 生態活躍度由 GitHub 與第三方媒體承擔：CANopenNode 整合包等第三方專案快速迭代，官方新聞 API 滯後約 2 個月的狀況持續（最新仍為 06-17），官方資訊出口亟待恢復。
  5. 侷限性說明：EET-China 原站不可達，DSMC 與 RTOS 榜單兩篇正文細節依賴檢索摘要與報告官方頁核實，RT-Thread 在效能報告中的具體名次未能取得。
