一、核心與版本動態

1.1 Cortex-M4 硬體棧保護（HW Stack Guard）支援合入核心

日期：2026-08-26（10:37 北京時間合入）　來源：RT-Thread/rt-thread commit e2e6245a

主倉庫視窗內合入一條核心級特性：[arm][cortex-m4] Add hardware stack guard support，由社群開發者 hanzhijian 提交（author 時間 08-25 09:19）、核心維護者 Rbb666 於 08-26 10:37（UTC 02:37）合入。該提交將基於硬體 MPU 的棧溢位保護（RT_USING_HW_STACK_GUARD）從原先僅支援的 Cortex-M7 / Cortex-M33 擴充套件到 Cortex-M4——後者是 M 系列中部署量最大的核心類，硬體棧保護落地意義顯著。核心改動集中在 libcpu/arm/cortex-m4/：新增與 M7 MPU 層對齊的 mpu.c / mpu.h / mputype.h（唯一差異是 M4 無 L1 快取，cacheability 位縮減為三個）；cpuport.c 新增 rt_hw_stack_guard_init()；context_gcc.S 補 #include <rtconfig.h> 並在 PendSV 上下文切換路徑呼叫 rt_hw_mpu_table_switch()；SConscript 在關閉記憶體保護時排除 mpu.c。參考 BSP 為 bsp/stm32/stm32f407-fk407m2-zgt6（正點原子 STM32F407 板）：board.h/board.c 定義 NUM_STATIC_REGIONS 與 static_regions[]，將 Flash 區標記為只讀，整體由 RT_USING_MEM_PROTECTION 開關控制、預設不啟用。這是 v5.3.0-beta 分支建立（08-24）後主分支合入的首個核心級功能提交，為 v5.3.0 的核心健壯性方向添了一筆。

1.2 finsh 清理：移除廢棄宏 FINSH_FUNCTION_EXPORT_ALIAS

日期：2026-08-26（10:53 北京時間）　來源：RT-Thread/rt-thread commit 0305faf8

創始人 Bernard Xiong 於 08-26 10:53（UTC 02:53）直接推送 [finsh] Remove deprecated FINSH_FUNCTION_EXPORT_ALIAS（對應 PR #11734），移除已廢棄的 FINSH_FUNCTION_EXPORT_ALIAS 宏在程式碼庫中的全部使用：共 19 個檔案、+124/-81 行，覆蓋 allwinner（sunxi-hal disp2 除錯與測試檔案）、apm32（drv_common.c）、at91（at91sam9260 reset.c）、fujitsu（mb9x nand.c）、simulator（board.c / module_win32.c）等 BSP，以及 dfs_v1 / dfs_v2 的 dfs_posix.c 元件程式碼。FINSH_FUNCTION_EXPORT_ALIAS 是 finsh 元件歷史上用於給命令匯出起別名的舊宏，本次清理屬程式碼現代化收尾，與昨日 RA8D1 合入同屬”整理期”節奏：合入通道恢復後，主分支正以低風險清理與特性兩類提交交替推進，為 v5.3.0 正式釋出做準備。

1.3 utest 控制檯緩衝約束與瑞薩 RA6W1 BLE OTA 生成最佳化

日期：2026-08-25 22:04 ~ 2026-08-26 10:42　來源：RT-Thread/rt-thread commits 45679c79 / 64f1fa4a

視窗內另有兩條合入（不單列）：其一，CYFS 提交、Rbb666 於 08-26 10:42 合入的 [utest] Enforce minimum console buffer size（src/Kconfig，為 utest 控制檯緩衝區設定最小長度約束，屬測試框架配置校驗加固）；其二，rcitach 提交、Rbb666 於 08-25 22:04 合入的瑞薩 RA6W1 BSP 改進——Improve BLE OTA image generation to avoid executing OPEN every time a flash erase and write operation occurs，修改 bsp/renesas/ra6w1-ek/ 下 ra6w1_ospi_flash.c 與 scripts/gen_rrq61_flash_image.py，最佳化 BLE OTA 映象生成流程，避免每次 Flash 擦寫都執行 OPEN 命令。RA6W1（瑞薩 BLE 單晶片）BSP 繼 08-05 首版、08-11 二期補外設後再度打磨，第三方/社群持續迭代特徵明顯。
