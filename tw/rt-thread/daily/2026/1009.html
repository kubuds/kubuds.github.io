一、核心與版本動態

1.1 節後開發恢復：主倉庫單日下午密集開出四條新提案（10-08）

日期：2026-10-08 12:51 ~ 17:23（北京時間，建立時間）　來源：PR #11855、PR #11856、PR #11857、PR #11858

節後首個開發日下午，社群在主倉庫集中開出四條修復提案，均附測試說明、處於評審：其一（#11855，12:51，單檔案 +3/-0）修復重置元件與日誌元件同時啟用時的構建錯誤——日誌相容宏將 assert 無條件下定義為 ASSERT，重置控制器結構體中的同名成員被宏展開導致編譯失敗，方案為在使用處取消該宏；其二（#11856，15:36，單檔案 +40/-4）修復 C++ 全域性構造缺失——新版 GCC 將 C++ 全域性建構函式移入 .init_array，而系統初始化僅遍歷舊構造區間，方案為補跑 .init_array 區間並做重疊去重，已在模擬器平臺完成構建驗證（關聯需求 #11778）；其三（#11857，16:32，兩提交，單檔案 +64/-41）調整帶顏色日誌的復位順序，避免顏色控制碼落到下一行、shell 提示符配色錯亂（關聯需求 #11296）；其四（#11858，17:23，單檔案 +63/-33）為 DHCP 伺服器選項解析補充緩衝區邊界檢查，修復畸形報文越界讀風險（關聯需求 #11323）。四條中三條出自同一位節前活躍貢獻者（近期有 ESP32-C6、CH32V003 等 BSP 合入記錄），當日均觸發格式化與記憶體對比流水線。

二、官方與社群活動

2.1 〖2026嵌入式大賽〗煙霧火災報警監測系統作品釋出（10-08）

日期：2026-10-08 17:21（釋出時間）　來源：論壇文章 0e815ddfc029ea9c

2026 嵌入式大賽視窗內再添一份完整作品：基於恩智浦 FRDM-MCXA346 與核心 5.2.2 的煙霧火災報警監測系統。系統以 MQ-2 採集煙霧濃度（ADC）、DHT22 採集溫溼度（單匯流排），實現 OLED 三頁顯示切換、蜂鳴器與繼電器聯動、長按消音、回差閾值防抖與自動恢復，並提供多條 MSH 除錯命令與電腦端儀表盤（實時曲線、CSV 記錄、遠端測試控制）。方案採用硬體抽象、業務與顯示三層結構及告警狀態機設計，開發環境為 Keil MDK-ARM。該帖延續節末以來大賽作品密集釋出的節奏——同期已有智慧實驗室管理終端、GD32H759 電機控制與 Edgi-Talk 顯示配置指南等作品（已由假期週報收錄）。

三、生態與廠商適配

3.1 env 工具合入 #300：離線 SDK 軟體包跳過 Git 更新（10-08）

日期：2026-10-08 20:10（合併時間）　來源：env PR #300

工具倉庫 env 視窗內合入一筆打包管理修復（#300，單檔案 +7/-0）：SDK 內手動管理的離線軟體包沒有獨立 .git 目錄，包更新時 Git 命令會在父倉庫誤執行；修復為在倉庫校驗前檢查軟體包目錄的 .git 並跳過離線原始碼，同時相容以 .git 檔案形式存在的 worktree 與子模組。該筆由社群貢獻者提交、創始人當晚合併，是工具鏈倉庫節後的首筆合入（上一筆為 10-04 合入的 #299，WebUI 與外掛工作流增強）。

3.2 RT-Thread Studio：Gino Pi SDK 提交五筆，補齊 LVGL 8/9 雙版本支援（10-08）

日期：2026-10-08 16:30 ~ 17:31（提交時間）　來源：Gino Pi 板級支援包倉庫

RT-Thread Studio 的 Gino Pi 板級支援包（兆易創新 GD32H77D，Cortex-M7 最高 600MHz，32MiB SDRAM、720×720 MIPI DSI 屏，基於核心 5.3.0，內建 17 個外設與應用工程）在視窗內集中提交五筆：顯示框架擴充套件為 LVGL 8/9 雙版本（按版本宏選擇包）、新增獨立 LVGL 8.3.11 示例、修正版本宏解析順序、將隨板 GD32 SDK 庫標記為非託管（避免被包管理器誤更新），並同步英文文件、補充 MDK 工程生成步驟。該板卡為 10-01 商城發售的聯合產品，SDK 側在發售視窗後快速補齊顯示與文件能力。

3.3 軟體包：esp-idf 適配倉庫恢復合入，補齊 ESP32-C6 scons 編譯原始碼（10-08）

日期：2026-10-08 17:28（合併時間）　來源：esp-idf PR #17

晶片適配包倉庫 esp-idf 視窗內完成一次實質合入（#17，4 提交、332 檔案、+48463/-5146）：補齊 ESP32-C6 所需的 scons 編譯原始碼，貢獻者在 ESP32-C6-DevKitC-1 實機編譯燒錄後進入 msh 驗證；該筆合入 rtt-dev 開發分支，為此倉庫自 2023 年末以來首度恢復合入。合入後維護者在評論中提議跟進更新 ESP-IDF 版本，貢獻者回應計劃升級至 6.1。樂鑫 C6 支援鏈路（BSP 合入、SPI 按需編譯提案在審、scons 編譯原始碼、包索引版本提案 #2043 在審）在節前節後連續推進，多個層面同時展開。

3.4 廠商下游：GD32 倉庫新開 GD32G553 DMA 支援提案 #72（10-08）

日期：2026-10-08 10:44（建立時間）　來源：GD32 下游倉庫 PR #72

兆易創新 GD32 板級支援倉庫視窗內開出新提案（#72，單提交、16 檔案、+2571/-50）：為 GD32G553 補齊 SPI、I2C 與 UART 的完整 DMA 支援，含 I2C2 的 DMAMUX 配置、UART0 ~ 5 全量通道、SPI G5x3 相容性與 Keil 編譯器相容修正；作者以 GCC 與 Keil 零告警編譯、I2C-AT24C02 EEPROM DMA 實測透過，測試板為 GD32G553Q-EVAL。提交當日編譯機器人報告有 BSP（gd32_arm）編譯失敗，待修復與評審；該倉庫此前一筆合入為 09-28（PR #71）。

4.1 「知手同行」手語教學機器人開源釋出：MaixCAM2 + Titan Mini + AmazingHand（10-09）

日期：2026-10-09 00:10（北京時間，專案材料釋出提交）　來源：開源倉庫 asungod/amazinghand

topic:rt-thread 生態新增一個手語入門教學機器人開源專案「知手同行」，教學應用與專案材料於視窗內釋出。系統由三部分組成：MaixCAM2 視覺節點完成手部關鍵點獲取與手型、課程步驟判定；Titan Mini 控制板（瑞薩 RA8P1 平臺，執行 RT-Thread 韌體）承擔通訊與機械動作執行，韌體含匯流排舵機驅動、動作安全門控與語音關鍵詞識別模組；AmazingHand 機械手執行實體示範。課程共 13 項（初級 3、中級 4、高階 6），配套瀏覽器練習介面、分步反饋、練習記錄與文字溝通卡，隨附技術報告、驗證材料與競賽講解材料；專案內部文件同時披露當前推進邊界（視覺節點串列埠鏈路已真機跑通、控制板韌體已完成編譯，兩板聯調與舵機閉環等仍在推進）。該板卡方向的同類社群專案此前有端側聲學事件檢測（09-30 日報收錄）。
