一、核心與版本動態

1.1 評審佇列單夜新增八條提案：存量缺陷加固系列七連發，WCH CH32V203 板級支援補位（09-22）

日期：2026-09-22 18:03 ~ 18:31（北京時間，提案時間）　來源：PR #11820、PR #11827

視窗內評審佇列單夜新增八條提案（#11820 ~ #11827），為近期最集中的一批提交。其中七條來自同一貢獻者，構成一組系統性的存量缺陷加固系列：兩線序列匯流排控制器與傳輸互斥（#11820，修復 #11524）、電源管理按裝置掛起模式成對恢復（#11821，修復 #11046）、USB 主機介面數量邊界（#11822，修復 #11288）、IPC 訊息佇列路徑終止符邊界（#11823，修復 #11292）、塊裝置邏輯分割槽越界讀寫（#11824，關聯 #11286）、STM32 OpenAMP 接收緩衝邊界與環形迴繞（#11825，修復 #11299）、virtio 輸入偏移校驗（#11826，修復 #10379、#10380）。七條均引用數月前的存量缺陷報告，並附 GCC 16.1 主機構建與邊界用例的驗證說明，屬對歷史遺留問題的集中清理。第八條為沁恆 WCH CH32V203C8T6-EVT-R0 板級支援（#11827）：該型號為青稞 V4B 核心的 RISC-V 微控制器（64KB 零等待 Flash、20KB SRAM），主線此前無對應 BSP，提案補齊工程骨架、D6 向量表、連結指令碼與看門狗示例，並修補官方 SDK 包對 D6 型號直接退出構建的問題。

三、生態與廠商適配

3.1 瑞薩 RA8P1 Titan Mini 最佳化 OpenMV 工程：SDRAM 時鐘與記憶體池調整，推理耗時顯著下降（09-22）

日期：2026-09-22 16:09 / 16:36（北京時間，提交時間）　來源：效能最佳化提交、效能資料更新提交

Studio BSP 組織下瑞薩 RA8P1 Titan Mini 倉庫在視窗內推送兩筆 OpenMV 工程最佳化提交。其一調整外部 SDRAM 時序與時鐘配置（重新整理等待引數、BCLKA 分頻），並以原始碼覆蓋方式補全 SDCLK 選擇器的初始化順序，修復晶片配置工具的已知限制；其二把片內 SRAM 的主垃圾回收池由 1344 KiB 擴至 1472 KiB，改善大模型工作區的記憶體佈局。隨提交同步更新的實測效能顯示：Tiny YOLOv2 INT8 416×416 單次推理由 156.10 ms 降至 58.49 ms（約 2.7 倍），YOLOv8n 256×256 由 186.54 ms 降至 38.33 ms（約 4.9 倍），320×320 由 310.29 ms 降至 287.49 ms。該工程 09-18 剛補齊 OpenMV 釋出鏈路與持續整合，本期為釋出後的效能收口；電子工程專輯同日釋出跟進報道（《1 GHz MCU + NPU，Python 開玩！Titan Mini 的 OpenMV 更新來了》），原站訪問受限，連結見附錄。

3.2 GDR 2026.03 釋出：RT-Thread 除錯助手框架補物件命令與幫助體系（09-22）

日期：2026-09-22（釋出時間）　來源：GDR 2026.03

第三方 GDB 除錯助手框架 GDR 在視窗內釋出 2026.03 版本。該框架執行於 GDB 的 Python 直譯器內，為 RT-Thread 與 FreeRTOS 韌體除錯提供三層支援：各實時系統自有命令樹（如檢視執行緒、定時器、堆）、核心物件美化列印器與便捷函式（以原生 GDB 表示式訪問物件欄位）。新版本為 RT-Thread 側新增 rtt objects 物件彙總命令，並把堆與物件輸出統一到中性渲染器；幫助體系升級為 git 風格的結構化命令樹，逐項說明欄位、用法、配置依賴與實現限制；同時修復初始化策略校驗失敗會直接終止 GDB 會話的問題。框架當前支援 RT-Thread 3.1.x / 4.0.x / 4.1.x，Cortex-A9 與 RV64 目標均已透過閉環驗證，屬 RT-Thread 第三方除錯工具鏈的活躍專案。

3.3 GD32 下游倉庫驅動更新分支推進：PR #71 重新整理並進入評審互動（09-22）

日期：2026-09-22 13:37（北京時間，推送時間）　來源：PR #71

兆易創新下游倉庫 gd32_rt-thread 的 update_driver 分支在視窗內推送一筆驅動更新提交，同步重新整理評審中的 PR #71，倉庫側出現評審評論互動。該提案圍繞 USART、SPI 與兩線序列匯流排驅動的 GPIO 初始化版本更新展開，對舊版驅動檔案做替換整理，屬廠商自維護分支的持續工作，尚未迴流主線。同組織 Zephyr 方向的倉庫亦有推送，非本主題。
