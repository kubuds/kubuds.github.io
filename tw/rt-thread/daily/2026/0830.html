一、核心與版本動態

1.1 ENV 工具 WebUI 化落地：新增 SDK 管理與本地工具鏈配置

日期：2026-08-29（20:21 北京時間合併）　來源：RT-Thread/env PR #290

視窗內最具價值的工程動態：RT-Thread 官方命令列工具 ENV 由創始人 Bernard Xiong（bernard）提交併合併 PR #290「Feature/sdk webui config」，為 ENV 的 WebUI 介面新增兩項核心管理能力——本地工具鏈配置與 SDK 管理。改動規模可觀：新增 sdk_manager.py（約 1100 行 SDK 管理器）與 toolchain_manager.py（工具鏈管理器），WebUI 前端 App.vue 擴充套件 600 餘行並新增 file_context_menu.py 檔案上下文選單，配套 pytest 單測（test_sdk_webui、test_local_toolchain_webui）與 Playwright e2e 測試（webui.spec.js）。這是 ENV 自 08-17 起連續迭代（外掛市場 WebUI 頁面、外掛後端服務生命週期、外掛市場 Host API 代理等）的延續：ENV 正從純命令列工具向 WebUI 圖形化管理演進，本次落地標誌著 SDK 與工具鏈的本地視覺化管理能力成型，開發者可在瀏覽器介面完成工具鏈與 SDK 的配置管理。

二、官方與社群活動

2.1 elexcon 2026 預告：睿賽德”不止作業系統”，秀出 AI 硬體”全家桶”

日期：2026-08-30（刊出）　來源：電子工程專輯（經 Google News）

電子工程專輯 08-30 刊出活動預告「9月9-11日，不止作業系統：RT-Thread睿賽德elexcon秀出AI硬體’全家桶’」。展會為 elexcon 2026（第 23 屆深圳國際電子展暨嵌入式展），2026-09-09 至 09-11 在深圳國際會展中心（寶安）舉行，主題「All for AI, All for Green」，與 CIOE 中國光博會、IC 創新博覽會（IICIE）同期。預告標題”不止作業系統”與”AI 硬體全家桶”暗示睿賽德參展重心從作業系統軟體延伸至端側 AI 硬體方案——與睿賽德近期戰略脈絡一致：WAIC 2026 提出 AIOS 理念（AI 推理放 Linux 側、實時控制放 RT-Thread 側混合部署，已在天車系統、六軸機器人驗證）、AI KIT 一站式 AI 開發工具平臺、作為首批核心成員加入”開源AIOS聯盟”（均見科技日報 08-07 報道）。對照去年 elexcon 2025，睿賽德曾斬獲”AloT 優秀方案獎”與”實時作業系統突破獎”兩項行業大獎。原文站（eet-china.com）本機直連不可達，細節以標題與搜尋索引摘要為準，展會現場看點待 9 月實地報道驗證。

三、生態與廠商適配

3.1 canopennode-rtt：RX 規則編譯為粗粒度 HDR 過濾器

日期：2026-08-30（11:14 北京時間提交）　來源：wdfk-prog/canopennode-rtt

面向 RT-Thread 的 CANopenNode 整合軟體包（社群開發者 wdfk-prog 維護）視窗終點前新增 1 筆提交：refactor[canopennode][filter]: compile RX rules into coarse HDR filters——將接收（RX）規則編譯為粗粒度 HDR（硬體依賴接收）過濾器，屬 CANopen 接收路徑過濾邏輯的效能/架構層重構。該包自 08-25 起經歷 LSS 配置持久化、執行時位元率啟用、SRDO 安全物件字典（08-29 收錄）等連續迭代，今日繼續向接收路徑最佳化推進。CANopenNode 為開源社群知名 CANopen 協議棧，此包屬個人專案（1 star），尚未進入 RT-Thread packages 索引，標註生態參考。

四、行業應用

視窗內無新增行業應用條目。近三日趨勢：08-27 兆易創新 GD32 下游倉庫（GD32-MCU-IOT/gd32_rt-thread）合併 DMA 功能（PR #68，屬廠商主導 BSP/驅動持續適配）；08-28 packages 索引新增 MRamTrace 輕量級 RAM 後端函式追蹤軟體包（除錯/效能分析方向，PR #2027）；行業側近期主線仍為睿擎工業平臺（資料採集直播教學、Workshop）與端側 AI 落地（AIOS 混合部署）。

五、總結與趨勢觀察

  1. elexcon 2026 參展預告成視窗內唯一媒體側訊號：睿賽德對外敘事從”作業系統”轉向”不止作業系統”的 AI 硬體”全家桶”，與 AIOS 理念、AI KIT 平臺、開源AIOS 聯盟戰略一脈相承，9 月 9-11 日深圳寶安展會將驗證其端側 AI 落地成果。
  2. ENV 工具 WebUI 化是視窗內最有價值的工程動態：SDK 管理與本地工具鏈配置落地（PR #290，創始人親筆），配套單測與 e2e，官方開發工具鏈持續現代化，距 WebUI 外掛市場、後端服務之後再次加碼。
  3. 官方新聞面第十日平靜：新聞 API 無新增，睿擎 Workshop 會後報道持續缺位；媒體側僅電子工程專輯預告一條，官方公眾號渠道可能存在未收錄內容。
  4. 主倉庫特性間歇期延續：視窗內無新合入（最後為 08-28 C908 rt-smart），無新 release；社群側 canopennode-rtt 保持每日迭代節奏，CANopen 接收路徑最佳化是本視窗生態看點。
  5. 軟體包生態側增除錯新件：MRamTrace（RAM 後端函式追蹤）08-28 進入 packages 索引，MCU 韌體追蹤除錯方向有新工具。

侷限性說明：電子工程專輯原站（eet-china.com）本機直連超時，elexcon 預告細節僅憑標題與搜尋索引摘要，具體展品需待展會報道；睿擎 Workshop 會後報道可能僅釋出於官方微信渠道，gnews 拆詞噪音大無法覆蓋；canopennode-rtt 為 1 星個人專案，收錄僅供生態觀察。
