一、核心與版本動態

1.1 主倉庫 RT-Smart POSIX 相容批次雙 PR 合入，共 13 筆提交

日期：2026-08-30（20:49-20:55 北京時間合併）　來源：PR #11732、PR #11733

昨日日報判斷主倉庫”特性間歇期延續”，當晚即被打破。創始人 BernardXiong 連續合入兩個 RT-Smart（RT-Thread Smart，POSIX/Linux 相容模式）相關 PR，共 13 筆提交：

  • PR #11732「Extend Smart POSIX filesystem and syscall compatibility」（20:49 合併，10 筆提交）：DFS POSIX 記錄鎖（record locks）與 utest 覆蓋、fchmod、tmpfs setattr 與後設資料修正、Linux 相容 procfs 程序/系統檔案欄位、libc epoll 在 OOM 時喚醒等待者、LWP 系統呼叫複製修復、EFAULT 與 tmpfs 屬性位修復、virtio 網絡卡改為依賴 LWIP、clang-format 對齊。
  • PR #11733「Harden RT-Smart serial ioctl arguments」（20:55 合併，3 筆提交）：RT-Smart 串列埠 ioctl 引數硬化，termios 宣告格式化並落實評審意見。

這是主倉庫自 08-28 玄鐵 C908 rt-smart BSP 之後最大的一筆合入，方向明確：RT-Smart 的 POSIX 檔案系統與系統呼叫相容層持續向 Linux 語義對齊（記錄鎖、多使用者 procfs、epoll），串列埠 ioctl 進入引數級硬化階段。

1.2 ENV WebUI TypeScript 化落地，並修復 BSP 同步失敗

日期：2026-08-31（00:56 合併 PR；11:00 追加修復提交）　來源：RT-Thread/env PR #291

ENV 工具 PR #291「feature/webui typescript」合併，三項改動：WebUI 前端由 JavaScript 遷移為 TypeScript；外掛啟動 WebUI 時自動跳轉到對應外掛的 WebUI 頁面；更新 RT-Thread Env logo。隨後 08-31 11:00 追加一筆修復提交「Fix WebUI module import error causing BSP package synchronization failure」，修復 WebUI 模組匯入錯誤導致 BSP 軟體包同步失敗的問題。

延續昨日 PR #290（SDK 管理與本地工具鏈配置）之後，ENV WebUI 化進入工程化階段，創始人連續第三日親筆迭代，官方開發工具鏈現代化節奏未停。

三、生態與廠商適配

3.1 packages：AI Agent 軟體包新增音訊框架

日期：2026-08-31（11:04 合併）　來源：RT-Thread/packages PR #2029

社群開發者 CXSforHPU 提交的 PR #2029 合併，ai/Agent/Kconfig 新增「Agent Driver」選單與 PKG_AGENT_DRIVER_AUDIO 開關，啟用後自動選擇 wavplayer（含錄音支援）與 BSP 音訊——AI Agent 軟體包由此獲得音訊驅動通路，為語音互動類智慧體應用提供硬體接入點。該包 08-24 剛加多模態支援與聊天記錄裁剪（PR #2022），本次補齊音訊側，端側 AI 能力拼圖繼續完善。改動為 Kconfig 配置層，實際驅動邏輯在 wavplayer/BSP 側，執行效果待實機驗證。

3.2 packages：optparse 恢復 v1.0.0 版本條目，修復破壞性介面變更

日期：2026-08-31（11:02 合併）　來源：RT-Thread/packages PR #2028

optparse 軟體包因介面破壞性變更（optparse_init 由 2 引數改為 3 引數、新增 argc）導致 wavplayer v0.2.0 等既有包編譯失敗（”too few arguments to function ‘optparse_init’“），而包索引此前僅收錄 latest 版本，使用者無法回退、只能手動改第三方包原始碼。PR #2028 由 Leeee-wx 提交，為 optparse 恢復 v1.0.0 版本條目（package.json + Kconfig），恢復回退能力，RT-Thread Studio 使用者可直接回滾。軟體包索引治理向”版本回退相容”方向演進。
