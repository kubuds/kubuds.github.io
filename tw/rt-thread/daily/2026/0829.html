一、核心與版本動態

1.1 玄鐵 C908 BSP 合入：QEMU virt64 平臺支援 RT-Thread Smart

日期：2026-08-28（12:25 北京時間合入）　來源：RT-Thread/rt-thread PR #11719

主倉庫視窗內最重要一筆合入：feat[bsp][xuantie]: c908 support rt-smart。由 BadmintonMaster 代為提交（原始 commit 來自 shuta.lst 的 rt-thread fork），核心維護者 Rbb666 於 08-28 12:25（UTC 04:25）合入，共 27 個檔案。內容：新增 bsp/xuantie/virt64/c908 板級支援包——基於 QEMU RISC-V64 VIRT 虛擬平臺的平頭哥玄鐵 C908 處理器移植，支援 RT-Thread Smart 微核心模式（核心/使用者態分離）與標準模式雙構建，並配套根檔案系統執行說明（link_smart.lds、run.sh）；同時為 SMP 適配對 libcpu/risc-v/common64/mmu.c 做了修改。工具鏈採用 Xuantie-900 GCC（musl 版，riscv64-unknown-linux-musl- 字首）+ Xuantie QEMU 模擬器。這是 xuantie virt64 BSP 家族繼 C910 等之後新增的 C908 支援，為 RISC-V 向量擴充套件核心在 RT-Thread Smart 高階應用場景下的開發驗證提供了 QEMU 虛擬化入口，也是 libcpu RISC-V 公共層 SMP/MMU 適配的持續補強。

1.2 qemu-vexpress-a9 回溯支援函式名

日期：2026-08-28（11:29 北京時間合入）　來源：RT-Thread/rt-thread commit 0ae80cc7

社群開發者 Hui Su 提交：Cortex-A9 QEMU BSP 在開啟 RT_BACKTRACE_FUNCTION_NAME 時，向編譯器與彙編器傳遞 -mpoke-function-name，使核心回溯（backtrace）輸出攜帶函式名，便於除錯。改動集中在 bsp/qemu-vexpress-a9/SConstruct 單檔案，屬除錯體驗小改進。

二、官方與社群活動

2.1 直播預告：從 ADC 到 DMA，資料採集元件怎麼設計？

日期：2026-08-28（刊出）　來源：電子工程專輯（原文 eet-china.com/mp/a520847.html）

電子工程專輯 08-28 刊出 RT-Thread 直播預告「從ADC到DMA，資料採集元件怎麼設計？」。話題大綱：其一，為什麼 ADC 不等於資料採集；其二，週期取樣與 DMA 取樣兩條路徑怎麼選；其三，多通道交織幀——資料怎麼組織才能兼顧吞吐與實時性。該直播是此前「睿擎平臺 RK3506 多通道資料採集元件的設計與實踐」（eet-china.com/mp/a520342）一文的延續，同一主題系列由工程實踐走向直播教學，對應睿擎工業平臺在工控資料採集方向的能力輸出。原文站本機直連不可達，細節以搜尋索引摘要與標題為準。

三、生態與廠商適配

3.1 canopennode-rtt 持續迭代：SRDO 物件字典與構建測試完善

日期：2026-08-29（11:10 北京時間提交）　來源：wdfk-prog/canopennode-rtt

面向 RT-Thread 的 CANopenNode 整合軟體包（社群開發者 wdfk-prog 維護）視窗內新增 3 筆提交：canopen[srdo] 生成 J09/B09S 物件字典（SRDO，Safety-Relevant Data Objects，CANopen 安全相關資料物件）、新增 MCU 診斷測試夾具（test fixture）、以及累計 B 階段構建配置（CI）。該包自 08-25 起進入 LSS（節點配置）持久化與執行時位元率啟用迭代，08-27 首次收錄於本日報（LSS 執行時位元率啟用），今日繼續向 CANopen 安全擴充套件（SRDO）與工程化（CI/測試）推進。CANopenNode 為開源社群知名 CANopen 協議棧，此包屬個人專案（1 star），尚未進入 RT-Thread packages 索引，標註生態參考。

五、總結與趨勢觀察

  1. 玄鐵 C908 補上 RT-Thread Smart 虛擬化驗證入口：QEMU virt64 平臺新增 C908 BSP，支援 RT-Thread Smart 微核心與根檔案系統執行，並伴隨 libcpu RISC-V 公共層 SMP/MMU 適配修改——RISC-V 應用處理器方向（rt-smart）在平頭哥核心覆蓋上再進一步，這是視窗內最具價值的主倉庫合入。
  2. 官方新聞面第九日平靜：新聞 API 無新增，睿擎 Workshop 會後報道缺位持續；媒體側僅電子工程專輯「ADC 到 DMA 資料採集」直播預告一條。
  3. 睿擎平臺內容輸出轉向直播教學：RK3506 多通道資料採集工程實踐（08-22 前後刊文）之後，官方以直播形式展開 ADC/DMA 資料採集元件設計系列，工控資料採集方向是當前睿擎生態的對外主線之一。
  4. 社群 CANopen 安全能力緩慢生長：canopennode-rtt 從 LSS 配置走向 SRDO 安全物件字典與 CI/測試完善，CANopen 工業匯流排生態在 RT-Thread 側以個人專案形式持續積累。
  5. 主倉庫視窗內僅 2 筆合入：C908 rt-smart（新 BSP）+ qemu-vexpress-a9 回溯改進，整體處於特性間歇期，與昨日瑞薩 BSP 收尾節奏一致。
