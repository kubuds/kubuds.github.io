RT-Thread週報（2026-09-21 ~ 2026-09-25）

2026-09-25 苦芽科技

報告週期：2026 年 9 月 21 日（週一）至 9 月 25 日（週五），共 5 個工作日、5 個釋出日 素材來源：本刊每日 RT-Thread 動態日報（09-21、09-22、09-23、09-24、09-25，共 5 期）；另含 GitHub 組織視窗核查至 09-26 晨 編制說明：本週期覆蓋 RT-Thread 核心與版本、工具鏈、生態廠商適配、社群活動與行業應用五個維度，條目均來自當期日報已核驗信源

一、本週要聞

  • Gino Pi 生態全棧一週打通（09-21 ~ 09-23）：GD32H77D 開發板 Gino Pi 的主線 BSP 以系列提案形式進入評審（19 筆提交、142 個檔案、淨增約 2.6 萬行，覆蓋板級骨架、外設全家桶與演示工程）；同日器件支援包雙倉新增 GD32H77x_78x 支援、AT 元件補上板載 GD32VW553 模組的 Wi-Fi 與 TCP socket 支援，此前 Studio SDK 側已補齊 J-Link 依賴與連結指令碼修正。板卡從「Studio 與廠商下游」走向「主線可維護」，是兆易創新與睿賽德合作線本週最實質的一步。
  • RISC-V 板級支援一日三連（09-24 ~ 09-25）：沁恆 CH32V203C8T6 BSP 完成主線合入（青稞 V4B 核心，提案到合入約兩日）；樂鑫 ESP32-C6-DevKitC-1 BSP 提案進入評審，並同步提交 esp-idf 軟體包 C6 構建原始碼；社群釋出 RT-Thread Nano 免 IDF 移植工程（ESP32-S31 雙核 RISC-V、320 MHz）。三款 RISC-V 晶片集中出現在板級鏈路上，RISC-V 在 RT-Thread 板級生態中的比重繼續上升。
  • 主線全周合入 13 筆：週一晨間九筆集中批次（網路 AT 通道主機名校驗收緊、SDIO 雙記憶體洩漏修復、STM32H7 UART4 接收 DMA、GD32 USART 引腳修正、Rust 目標選擇與 QEMU 文件等）、週一下午兩筆（英飛凌 PWM 宏錯配、CherryUSB N32H4x USBFS 支援）、週三 CI 流程調整（clang-format 提交不再跳過流水線）、週四 CH32V203 BSP，均已落地。
  • 評審佇列單週 22 條新提案與 2 條缺陷報告（09-21 ~ 09-24）：含歷史遺留缺陷七連加固系列（匯流排互斥、電源管理、USB 主機、IPC、塊裝置、OpenAMP、virtio）、國民技術 N32H 定時器補全（39 個檔案、約四千行）、lwip-nat 埠分配與 lwip-dhcpd 標頭檔案缺失、rt_vsnprintf 寬度語義缺陷修復等，質量向修復構成主體。
  • 軟體包索引三連合並（09-24）：CanopenNode v1.2.0 完成九處 Kconfig 重構（CiA 401 裝置開關整合為通用裝置剖面體系）、「虛擬感測器」新包入列（模擬資料生成、可選 MQTT 上報）、AI Agent 包新增 MQTT 工具與 rt_vsnprintf 能力自動檢測機制。
  • 瑞薩 Titan Mini 端側視覺雙推進（09-22、09-24）：OpenMV 工程先完成 SDRAM 時序與記憶體池最佳化（Tiny YOLOv2 INT8 單幀推理 156.10 ms 降至 58.49 ms，YOLOv8n 256×256 由 186.54 ms 降至 38.33 ms），再接通板載 800×480 RGB 螢幕，新增 LCD 顯示與色塊追蹤示例；行業媒體同期跟進報道。
  • 工具鏈與配套生態多點更新（09-18 ~ 09-22）：RT-Thread Studio 配套切換至 v5.3.0 核心、J-Link 偵錯程式升級至 V9.76a（跨年度更新）；STM32H7 器件包與 HAL 驅動包雙釋出（v1.10.7 / v1.11.6）；第三方 GDB 除錯框架 GDR 釋出 2026.03。
  • 官方渠道靜默第三十二日至第三十六日；活動側以工博會與產教為主：工博會 Workshop 詳情公佈（10 月 13 日上海專場、25 套智慧小車教具）、臨港「場景直通車」睿賽德閉門對接會補錄、RSOC26 夏令營教程體系化開篇；官方新聞介面全周無新增。

二、核心與版本動態

版本與主線

  • 無新版本釋出：最新正式版本仍為 09-10 釋出的 v5.3.0；本週期為釋出後的常態消化期，工作重心在評審佇列與配套落地。
  • 合入節奏：全周 13 筆合入呈「一頭集中、全程低頻」分佈——週一晨間九筆與下午兩筆為峰值，週三、週四各一筆，其餘時段主線靜默。
  • 配套跟隨（09-20）：RT-Thread Studio 的 SDK 索引與內建核心原始碼切換至 v5.3.0，偵錯程式構件把 J-Link 升級至 V9.76a（上一版為 2025 年 7 月的 V8.48）；v5.3.0 核心釋出十天後配套完成跟隨。
  • 工具鏈現狀：Env 工具鏈視窗內無新提交與釋出（最新為 09-16 的 v2.0.2）；軟體包索引倉庫除 09-24 三筆合併外無其它動作。

本週合入主線的修復（按時間）

  • 網路 AT 通道主機名校驗收緊，形似數字的超長主機名直接拒絕，消除棧緩衝越界寫入隱患（09-21，#11782）
  • SDIO 兩筆記憶體洩漏修復：CIS 元組分支臨時記憶體未釋放（09-21，#11780）、驅動登出節點洩漏閉環（09-21，#11806）
  • STM32H7 通用 DMA 補上 UART4 接收側通道定義（09-21，#11808）
  • 塊裝置分割槽元件日誌格式符與引數型別修正（09-21，#11809）
  • GD32 系列 USART 收發引腳初始化修正，傳送改複用推輓、接收改上拉輸入，覆蓋 E50x 至 F30x（09-21，#11804）
  • Rust 工具鏈 Cortex-M33 硬浮點目標判定修正（09-21，#11811）
  • QEMU Linux 快速開始指引與文件高危命令清理兩筆（09-21，#11790 / #11793）
  • 英飛凌 PWM 宏錯配修復主線閉合，與評估板 BSP 修正同源（09-21，#11802）
  • CherryUSB 新增國民技術 N32H4x 系列 USBFS 裝置側支援（09-21，#11764）
  • clang-format 自動提交不再跳過持續整合，格式化結果納入構建驗證鏈路（09-23，#11830）
  • 沁恆 CH32V203C8T6-EVT-R0 BSP 合入，含 D6 向量表、64KB/20KB 連結指令碼與兩處共享驅動修復（09-24，#11827）

安全與缺陷

  • rt_vsnprintf 寬度語義缺陷與修復（09-24）：最小寬度被誤作最大寬度截斷（如 %3s 把 “abcdef” 截成 “abc”，左對齊與星號寬度變體同樣受影響）；缺陷報告與修復提案同日提交，修復覆蓋標準版與 tiny 版實現及單元測試（3 個檔案），處於評審狀態。
  • 歷史遺留缺陷七連加固（09-22 提交，評審中）：同一貢獻者一次性提交七條修復，覆蓋兩線序列匯流排控制與傳輸互斥、電源管理按掛起模式成對恢復、USB 主機介面數量邊界、IPC 訊息佇列路徑終止符邊界、塊裝置邏輯分割槽越界讀寫、STM32 OpenAMP 接收邊界與環形迴繞、virtio 輸入偏移校驗；均引用數月前存量缺陷報告並附 GCC 16.1 構建與邊界用例驗證。
  • bluepill BSP 文件缺陷報告（#11818）：快速上手缺少重新生成 MDK 工程步驟，按文件操作無法編譯。
  • 前週四項安全類 issue（tmpfs、訊息佇列、pread、finsh）公開記錄中未見逐條對應修復提交，本週期無更新。

評審佇列觀察

  • 兩批單夜集中提交構成新增主體：09-21 至 09-22 凌晨八條（N32H 定時器補全 39 個檔案約四千行、STM32 乙太網 ops 適配與 adcv2 日誌等級、lwip 宏開關化、RA6W1 資源分配、ESP32-C3 Windows 構建、單元測試效能用例時鐘依賴、bluepill 文件等）；09-22 夜間八條（缺陷加固系列七條＋CH32V203 BSP）。
  • 網路棧修復集中：lwip-nat 埠分配缺陷與 lwIP 2.1 適配（#11831）、lwip-dhcpd 補 string.h 標頭檔案（#11835）、netdev AF_NETLINK 構建修復（#11828）。
  • 大提案持續待審：GD32H77D GinoPi 外設系列（#11829，142 個檔案）、網路協議棧升級（lwip 2.2.1）長線等待、N32H 定時器補全。
  • 構建與整理類：ipc SConscript 冗餘宏清理（#11832）、bluepill 文件修正（#11817）；另有 ESP32-C6 板級提案（#11836，見第三章）。
  • 舊提案恢復活動：#10689（2025 年 9 月建立）於視窗末恢復討論。

三、生態與廠商適配

廠商 BSP

  • 兆易創新（GD32H77D / Gino Pi）：主線 BSP 系列提案進入評審——19 筆提交、142 個檔案、淨增約 2.6 萬行，覆蓋板級骨架（工程、連結指令碼、rtconfig）、外設全家桶（乙太網、USB 主機與裝置、SDRAM、硬體 I2C、SPI3、PWM、SDIO 與檔案系統、RTC 與鬧鐘、看門狗、CAN 與 CAN FD、OSPI Flash、MIPI LCD、GT911 觸控、OV7670 攝像頭、LVGL）與演示工程；板載 GD32VW553 無線模組的 UART4 AT 通訊與 MAC 查詢已驗證，Wi-Fi 關聯尚待完成（預設關閉）。
  • 兆易創新（器件包與聯網元件）：gd32-arm-cmsis 與 gd32-arm-series 雙倉新增 GD32H77x_78x 支援（CMSIS 器件層與新外設庫）；at_device 新增 GD32VW553 Wi-Fi 裝置與 TCP socket 支援。
  • 瑞薩（RA8P1 Titan Mini）：OpenMV 工程完成外部 SDRAM 時序/時鐘配置與片內 SRAM 主垃圾回收池擴容（1344 KiB 至 1472 KiB），三個模型推理耗時實測下降（最高約 4.9 倍）；隨後新增 RGB 介面 800×480 螢幕驅動（RGB565）與 LCD 基礎顯示、相機預覽、紅色色塊追蹤示例（17 個檔案、約 1200 行）。
  • 沁恆（CH32V203）：BSP 合入主線（見第二章），配套 drv_usbd 的 USBFS DMA 時序與 drv_iwdt 看門狗共享驅動修復；D6 型僅 64KB Flash / 20KB SRAM，USB 與其餘外設需按容量取捨。
  • 樂鑫（ESP32-C6 / ESP32-S31）：ESP32-C6-DevKitC-1 BSP 提案（40 個檔案、+9492 行）與 esp-idf 軟體包 C6 構建原始碼提案同步送審（該貢獻者與 CH32V203 提交者為同一人）；社群 ESP32-S31 免 IDF 移植工程已做可復現構建驗證（89 個跟蹤檔案、逐位元組一致映象）。
  • 英飛凌（PSoC6）：PWM 宏錯配修復在主線閉合；評估板 BSP 同步完成跨工程修正。
  • GD32 下游倉庫：PR #71 驅動更新分支重新整理並進入評審互動（USART、SPI 與兩線序列匯流排驅動的 GPIO 初始化版本更新），尚未迴流主線。

軟體包與中介軟體

  • 軟體包索引三連合並（09-24）：CanopenNode v1.2.0（九處 Kconfig 重構、通用裝置剖面體系、邏輯裝置登錄檔與傳輸契約）、「虛擬感測器」新包（模擬資料生成、可選 MQTT 上報）、AI Agent 包（MQTT 工具、按核心符號自動檢測 rt_vsnprintf 能力，避免 4.1.x 核心重複定義）；三條積壓約兩週的提案同日合入。
  • STM32H7 器件包與 HAL 驅動包雙釋出（09-18）：器件包 v1.10.7（補齊 TIM23 / TIM24 例項、修正 GPIO 位定義筆誤）、HAL 包 v1.11.6（併入約二十筆上游同步，覆蓋 USB 零長包、乙太網 10M 速率、SDMMC 時鐘、I2C 死鎖、AES-GCM/CCM、FDCAN 過濾、DMA 回撥等）。
  • GDR 2026.03（09-22）：第三方 GDB 除錯框架新增 RT-Thread 物件彙總命令與 git 風格結構化幫助體系，修復初始化策略校驗失敗終止會話的問題；支援 RT-Thread 3.1.x / 4.0.x / 4.1.x，Cortex-A9 與 RV64 目標已閉環驗證。

六、趨勢觀察

  • RISC-V 成為板級增量主力：一週內沁恆 CH32V203 合入、樂鑫 ESP32-C6 送審與 ESP32-S31 免 IDF 移植接連出現，加上兆易創新 GD32VW553 無線模組支援，板級鏈路的新增動作幾乎全部落在 RISC-V 晶片上。
  • 「廠商釋出到主線」路徑成型：Gino Pi 從 Studio SDK 索引、除錯補鏈、器件包鋪墊到主線 BSP 提案一週內走完；晶片廠主導提交、Studio 與主線雙側並行，成為可複製的開發板落地節奏。
