RT-Thread週報（2026-08-12）

2026-08-12 苦芽科技

資料來源:本機每日日報(8/11、8/12)彙總 + GitHub 補採(8/6-8/10 視窗,rt-thread 主倉庫 / RT-Thread/env / packages 索引)+ 跨視窗報道補錄。 說明:本機日報系統 8 月 11 日由 K3 機器遷移而來,8/6-8/10 無逐日日報,該區間以 GitHub 提交(committer 時間)與 8/10-8/11 跨視窗報道為準,已儘量去重合並。官方新聞 API 最新條目仍為 6 月 17 日(滯後約 2 個月),官方動態以 GitHub 與第三方行業媒體佐證。

一、核心與版本動態

1.1 dm 裝置模型框架一週密集合入(本週重點)

日期:2026-08-06 ~ 08-08　來源:rt-thread 主倉庫

RT-Thread 新一代裝置模型(dm)框架本週進入高頻合入期,三天內落地十餘筆實質性提交:

  • 網路側(8/6):dm ethernet 基礎框架 + MACB/DWMAC 控制器支援;phy 驅動改進(v2)並新增 RTL8211F 驅動;
  • 儲存側(8/6-8/7):nvme 改用 DMA 地址(修復 CPU 實體地址直用問題)、nvmem DT bits 解析修復、DW AHCI(ATA) 支援;
  • 其他子系統(8/6-8/8):thermal 冷卻策略更新、dfs 檔案系統操作型別檢查(防型別不匹配異常)、RT_BITS_PER_LONG 可自定義、ivshmem 虛擬機器間共享記憶體(虛擬化場景)、graphic 更新、ufs 修復、regulator 更新、phye 新增 Mode/State 與 MIPI D-PHY 時序助手(#11675)、clk 工作流修復(#11673)。

dm 框架覆蓋從網路/儲存到時鐘/電源/顯示的完整裝置樹驅動體系,本週合入節奏顯示其已進入”大規模鋪驅動”階段,是 RT-Thread 面向高效能/虛擬化場景的重要底座。

1.2 NXP BSP 大特性合入:多核 / HyperRAM / CherryUSB / NETC / etherCAT

日期:2026-08-10　來源:rt-thread 主倉庫 #11672

[BSP][NXP] Add new features of multicore, hyperram, cherryUSB, NETC and etherCAT:NXP 平臺 BSP 一次性補齊多核、HyperRAM、CherryUSB、NETC 網路控制器、乙太網與 EtherCAT 支援。對 i.MX 系列使用者是實質性的平臺能力擴充套件,多核與 NETC 與工業/邊緣閘道器場景直接相關,EtherCAT 則與睿擎工業平臺主線呼應。

1.3 瑞薩 RA6W1 BSP 二期”完善驅動”合入

日期:2026-08-11　來源:rt-thread 主倉庫提交

“完善 ra6w1 的基礎 BSP 驅動”(45 個檔案)合入,補齊瑞薩 RA6W1(BLE MCU,Cortex-M33)的 ADC、SPI、I2C、PWM、Timer、DMAC、OSPI、QSPI-PSRAM 等外設驅動。廠商 BSP 兩階段合入模式又一例項:首版基礎 BSP 於 8 月 5 日合入,二期把平臺補成外設完備。

1.4 lwIP DHCPD pbuf 洩漏修復

日期:2026-08-12　來源:rt-thread 主倉庫提交

[lwip-dhcpd] Fix pbuf leak for oversized requests:修復 lwIP 內建 DHCP 伺服器在超大請求場景下的 pbuf 協議緩衝洩漏,提升 AP/熱點模式(智慧家居閘道器、車載熱點)長時間執行的穩定性。

二、官方與社群活動

2.1 首款 AI 飛控產品 Edgi-X 正式釋出並開啟預售

日期:2026-08-10(預售 8 月 6 日開啟)　來源:電子工程專輯

RT-Thread 首款 AI 飛控產品 Edgi-X 正式釋出並開啟預售,面向無人機/智慧飛行器場景,將 RTOS 實時性、軟體包生態與 AI 推理能力結合。這是睿賽德從”作業系統+生態”向”自有硬體產品”延伸的重要標誌,已進入商業化階段。

2.2 2026 RT-Thread 大學生夏令營入選名單釋出

2026 屆 RT-Thread 作業系統大學生夏令營入選名單落地,高校開發者培養通道進入實施階段。

2.3 睿擎工業平臺 Workshop 預告:8 月 27 日上海站

日期:2026-08-11(活動 8 月 27 日)　來源:電子工程專輯

睿賽德預告 8 月 27 日上海站”睿擎工業平臺 Workshop”:主題為 EtherCAT 實時控制與工業方案實戰,工業實時控制生態推廣進入線下落地階段。

三、生態與工具鏈

3.1 Env 工具鏈外掛體系:開發(8/7-8/8)→ 合併(8/12)

日期:2026-08-07 ~ 08-12　來源:RT-Thread/env PR #284

本週最值得關注的工具鏈事件:Env 外掛體系從開發到合入完整走完。8 月 7-8 日 env 倉庫密集提交(Env plugin lifecycle、CLI plugin 示例、WebUI host 與外掛示例、WebUI assets 打包),8 月 12 日 PR #284(創始人 BernardXiong 主導,90 檔案,+約 9600 行)正式合併:

  • env plugin 子命令:本地安裝/解除安裝/檢視外掛,安裝前展示包名、版本、簽名狀態與許可權宣告;
  • epack 外掛打包格式:定義打包與構建流程,內建示例外掛 build-insight-1.0.0,外掛 API_VERSION=1 固化契約;
  • env webui 命令:啟動本地 Env WebUI 伺服器。

Env 從命令列工具升級為可擴充套件外掛平臺,為視覺化介面、雲構建、第三方工具接入預留標準介面,是開發者工具鏈的結構性升級。

3.2 packages 索引:端側 AI 軟體包兩連進(8/10、8/11)

日期:2026-08-10/11　來源:RT-Thread/packages

  • 8 月 10 日:AIfES 入庫(嵌入式機器學習庫,支援 MCU 級訓練與推理);
  • 8 月 11 日:輕量化 agent 框架入庫([ai/agent]),同日修復 ch390 網絡卡包作者資訊。

packages 索引在”端側 AI”主線上連續進件,”MCU 級 Agent 執行能力 + 嵌入式 ML”的軟體棧正在成形。

3.3 第三方生態:canopennode-rtt / gdr / h120d-protocol

日期:2026-08-11/12　來源:wdfk-prog/canopennode-rtt / flespark/gdr / H4ck3rTR/h120d-protocol

  • canopennode-rtt(8/11):社群 CANopenNode 整合包(CANopen 工業現場匯流排),尚未進入官方索引,第三方孵化專案;
  • gdr(8/11):GDB RTOS helper framework 連續 5 提交,新增 RT-Thread mbox/msgq/mempool 物件提取與 rtthread help 命令,讓 GDB 具備 RT-Thread 執行緒感知除錯能力;
  • h120d-protocol(8/12):Holy Stone H120D 無人機 WiFi 協議逆向文件更新,含 RT-Thread 核心結構分析——消費級無人機飛控大量採用 RT-Thread 的生態樣本。

四、行業應用專章(工業 / 無人機)

4.1 工業線:EtherCAT 實時控制 + 睿擎平臺推廣

8 月 27 日上海 Workshop(EtherCAT 實時控制與工業方案實戰)是工業線關鍵動作;疊加 NXP BSP 新增 EtherCAT 支援(1.2)、官方此前”睿擎工業平臺賦能工控研發”與阿布扎比投資論壇亮相,工業場景是睿賽德當前明確的商業化主線。

4.2 無人機/飛行智慧:Edgi-X 釋出 + 生態雙向呼應

Edgi-X 正式釋出(2.1)標誌”OS 廠商 → 行業硬體產品”路徑落地;h120d-protocol 等無人機逆向專案持續活躍,側面印證消費級無人機市場與 RT-Thread 繫結加深。飛行智慧方向滲透值得持續跟蹤。

五、總結與趨勢觀察

  1. dm 裝置模型框架進入鋪驅動階段:一週十餘筆合入覆蓋網路/儲存/時鐘/電源/顯示/虛擬化,是本週核心側最顯著的工程訊號。
  2. 工具鏈平臺化:Env 外掛體系完成開發到合入閉環(env plugin / webui / epack),開發者工具開始可擴充套件。
  3. 端側 AI 軟體棧成形:AIfES + 輕量化 agent 框架先後入庫,MCU 級 AI/Agent 能力下沉。
  4. 行業商業化雙線推進:工業(EtherCAT/睿擎 Workshop)與無人機/飛行(Edgi-X 硬體產品)同步發力。
  5. 廠商 BSP 兩階段合入模式穩定:RA6W1 二期、NXP 大特性,NXP 一次到位含多核/網路/EtherCAT,適配質量與節奏俱佳。
  6. 侷限性說明:8/6-8/10 區間無逐日日報,以 GitHub 提交為準;官方新聞 API 持續滯後(6/17);Google News 對 “RT-Thread” 噪音多(博彩/SEO),已剔除。
