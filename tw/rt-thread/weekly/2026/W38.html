RT-Thread週報（2026-09-11 ~ 2026-09-18）

2026-09-18 苦芽科技

報告週期：2026 年 9 月 11 日（週五）至 9 月 18 日（週五），共 8 個自然日、6 個釋出日 素材來源：本刊每日 RT-Thread 動態日報（09-11、09-14、09-15、09-16、09-17、09-18，共 6 期） 編制說明：本週期覆蓋 RT-Thread 核心與版本、工具鏈、生態廠商適配、社群活動與行業應用五個維度，條目均來自當期日報已核驗信源

一、本週要聞

  1. 玄鐵 C908 平臺 RISC-V 支援三連合入（09-15）：rt-smart、MMU 與 SMP 支援一併進入主線，合計 31 個檔案、新增約 2575 行、刪除 565 行，MMU 補齊 SV39 / SV48 / SV57 地址模式，驗證平臺為 QEMU 模擬的 xiaohui C908。該核由此從單核執行進入可做多核使用者態驗證的階段。
  2. RISC-V 惰性 FP/RVV 上下文切換提案獲核心維護者正面回應（09-15）：OSPP 2026 議題指出 RISC-V 移植層每次上下文切換都無條件儲存與恢復完整 FPU 狀態、且完全不支援向量擴充套件 RVV，維護者認可這是很好的效能最佳化提案並歡迎提交 PR。
  3. env 工具鏈躍遷至 v2.0.0 並即時補發 v2.0.2（09-16）：版本號由 1.5.x 直達 2.0.0，為 2024 年 4 月以來首次釋出；配置系統以 kconfiglib 重構、Windows 側改為註冊命令、新增 sdk 命令與嵌入式構建系統、引入 env.json 作為單一資訊來源、分發名調整為 rt-env。
  4. 兩大 BSP 提案視窗內先後合入主線（09-16）：意法半導體 STM32N657 Nucleo BSP（83 檔案、新增約 17884 行）與國民技術 N32H 三系列驅動擴充套件（70 檔案、新增約 8096 行、刪除 2778 行）先後落地，從送審到合入約五至六天；配套的 STM32N657xx FSBL 軟體包索引已於 09-14 先行合入，該系列在 BSP 與軟體包兩側至此齊備。
  5. Gino Pi 開發板形成索引、發售、適配完整鏈路（09-11 ~ 09-16）：09-11 進入 RT-Thread Studio SDK 索引（GD32H77D-Gino BSP v1.0.0，包體 138 MB），09-15 聯合兆易創新正式發售（首發優惠 80 元），09-16 補齊 JLink 除錯鏈路（50 個示例工程）並獲睿擎平臺首發適配。
  6. 存量缺陷集中收口（09-12 ~ 09-17）：STM32 各區連結指令碼的容量校驗缺陷完成修復併合入，覆蓋 110 個連結指令碼，同期關閉今年 1 月提交、掛起約八個月的缺陷報告；SDIO 驅動登出記憶體洩漏從缺陷報告（09-12）到修復提案（09-17）約兩天，另有四項安全類 issue 於 09-13 集中關閉。
  7. 高校賽事與社群內容密集產出（09-15 ~ 09-18）：第九屆全國大學生嵌入式晶片與系統設計競賽全國總決賽結果公佈，深圳技術大學斬獲特等獎 RT-Thread 杯及全國一等獎 3 項；社群論壇入門教程連載、競賽開源工程與圖形化配置工具討論帖構成視窗內新增內容主體。
  8. 官方新聞通道全週期零更新：官方新聞介面最新條目停留在 2026-06-17，連續第二十二日至第二十九日無新增，產品發售與活動預告均由公眾號、官網商城與論壇渠道首發。

二、核心與版本動態

版本與主線

  • v5.3.0 釋出收尾（期首日報 09-11 收錄，事件日期 09-10）：v5.2.2 至 v5.3.0 變更日誌合入 master，主線版本號推進至 v5.3.1；beta 階段修復以 14 個提交、23 個檔案回移主線，三者與 Release 釋出在同一傍晚密集落地。
  • 版本收尾後主線恢復常態合入（09-14 起）：本週期合入覆蓋外設驅動增強、新系列 BSP 落地、架構後端補齊與連結指令碼修復，視窗內無新版本釋出，最新正式版仍為 09-10 的 v5.3.0。
  • 工具鏈一週兩度發版：期首日報收錄 Env v1.5.3（09-10 釋出，為該工具自 2024 年 4 月以來首個版本）；六天後 env 連發 v2.0.0 與 v2.0.2（09-16），版本號躍遷至 2.0.0。

本週合入主線的修復（按時間）

  • QEMU 入門文件兩處修正合入，補齊 apt 依賴包並更新失效的工具鏈下載連結（09-11，#11789 / #11794）
  • STM32 SPI BDMA 支援合入，DMA / BDMA / GPDMA 三類搬運通道配置統一（09-14，#11689）
  • 玄鐵 C908 平臺 rt-smart、MMU 與 SMP 支援三連合入（09-15，#11775）
  • STM32 乙太網驅動完成新版硬體抽象層介面遷移，已在 F4 與 H7 兩個平臺驗證（09-15，#11781）
  • STM32N657 Nucleo BSP 合入主線，八十三檔案、新增約 17884 行（09-16，#11799）
  • 國民技術 N32H 三系列驅動擴充套件合入主線，覆蓋三塊評估板（09-16，#11800）
  • 小華半導體 HC32 系列 BSP 配置同步合入主線，五十二檔案（09-16，#11798）
  • STM32 直接儲存器訪問驅動型別名函式的連結問題修復（09-16，#11803）

  • LLVM ARM 持續整合依賴修復合入，為該流水線補裝終端資訊庫依賴（09-17，#11807）

安全與缺陷

  • 四項安全類 issue 集中關閉（09-13）：涉及 tmpfs 路徑分量棧緩衝溢位、POSIX 訊息佇列名處理的無界棧溢位與差一錯誤、pread 大負偏移越界堆讀、finsh 補全結果未裁剪導致的堆越界寫（#11735 ~ #11738），四項於 09-13 下午集中標記關閉，公開記錄未見與之逐條對應的修復提交。
  • SDIO 驅動登出失敗與節點記憶體洩漏（09-12 報告，09-17 修復提案）：原邏輯僅在匹配到 SDIO 卡時才釋放驅動註冊節點，無卡或不匹配時節點不釋放，反覆註冊與登出會造成記憶體洩漏；修復方案為不區分是否存在匹配卡都從驅動連結串列移除並釋放節點，僅在匹配到卡時繼續呼叫移除回撥。
  • STM32 韌體超容量缺陷關閉（09-17）：該報告自今年 1 月提交以來長期未閉，本次隨連結指令碼容量校驗修復一併關閉。

評審佇列觀察

  • 網路協議棧升級長線：lwip 2.2.1 支援提案（#11797）視窗內多次重推迭代，規模 1874 個檔案、新增約 34.6 萬行，驗證平臺為恩智浦 i.MX RT1180 評估板，第三方記憶體比對判定未引入記憶體佔用變化，是否合入仍待觀察。
  • 新 BSP 與國產 MCU 驅動密集送審：STM32N657 Nucleo BSP 在 09-14 單日四次強制推送修復持續整合問題；國民技術 N32H 三系列在評審執行緒中逐條回應自動評審問題後重推；小華半導體 HC32 系列、意法半導體 STM32N657 系列等構成評審佇列主體。
  • 視窗末尾三筆常態化修復進入評審（09-17）：STM32H7 通用 DMA 補充 UART4 接收側定義（#11808）、塊裝置分割槽元件日誌格式符與引數型別修正（#11809）、LLVM ARM 持續整合依賴補齊（#11807，已於當日合入）。
  • 架構後端由評審轉入合入：達摩院玄鐵 C908 的 QEMU rt-smart 支援（#11775，08-31 開啟）於 09-15 完成合入，MMU 三種地址模式與 SMP 同時到位。

三、生態與廠商適配

廠商 BSP

  • 兆易創新（Gino Pi / GD32）：Gino Pi 進入 Studio SDK 索引（09-11）；聯合睿賽德正式發售，首發優惠 80 元（09-15）；Studio BSP SDK 增加 JLink 除錯鏈路，兩筆提交合計 50 個檔案（09-16）；GD32 下游板級倉庫統一兩線序列匯流排直接儲存器訪問開關命名並修復 207I 系列評估板構建（09-18）；GD32 串列埠收發引腳初始化修復提案進入評審，把傳送腳配為複用推輓、接收腳配為上拉輸入，影響 E50x / F10x / F20x / F30x 四系列（09-16，#11804）。
  • 意法半導體（STM32）：STM32N657 Nucleo BSP 合入主線，為該系列首次進入主線支援列表；STM32N657xx FSBL 軟體包索引先行合入（09-14）；STM32 乙太網驅動遷移新版硬體抽象層介面（09-15，8 檔案、新增 755 行、刪除 968 行）；STM32F4 器件支援包批次同步，預設向量表基址指向內部快閃記憶體基址並修正位定義（09-17）；STM32 GCC 連結指令碼容量校驗修復（09-17，110 個指令碼）。
  • 國民技術：N32H47x / N32H48x、N32H49x、N32H7xx 三系列驅動擴充套件合入主線，共用驅動層新增 ADC、DAC、I2C、SPI 配置標頭檔案並擴充套件乙太網、GPIO、硬體 I2C、NAND、QSPI、SDRAM、串列埠與看門狗等驅動分支，三塊評估板同步加入持續整合編譯矩陣（09-16）。
  • 小華半導體：HC32 系列 BSP 配置同步合入，五十二檔案、新增約 2844 行，含工程檔案重生成、格式整理與串列埠中斷驅動編譯錯誤修復（09-16）。
  • 恩智浦：作為 lwip 2.2.1 提案的驗證平臺提供 i.MX RT1180 評估板支援；另有基於 N947 平臺的遙控器技術直播預告（09-16）。
  • 英飛凌：PSoC6 評估板的 PWM 條件編譯宏錯配修復提案進入評審，宏名與板級配置不一致導致滑塊示例的 PWM 初始化程式碼被整段編譯掉，改動涉及 14 個檔案（09-16，#11802）。
  • 版本級全景（v5.3.0 BSP 板塊，期首日報收錄）：覆蓋瑞薩、兆易創新、恩智浦、意法半導體、瑞芯微、樹莓派、達摩院玄鐵、芯來等；其中達摩院玄鐵新增 XuanTie XiaoHui C908X 平臺支援，併為玄鐵 C 系列 / R 系列處理器新增 SMP 支援，補齊 C908 的 Svpbmt 支援並修正 C906 / C908 的快取屬性與頁表屬性。

軟體包與中介軟體

  • CANopen 雙棧成形：Lely CANopen 包索引合入軟體包索引倉庫（09-11，PR #2038），提供 single-owner EV/IO2 執行時、RT-Thread CAN 整合與可選主站服務；CanopenNode 模組化 Kconfig 重構並把版本升級至 v1.2.0 提交待審；引數儲存元件新增應用自定義 backend 選項。
  • 器件支援包對齊：STM32F4 器件支援包批次補齊歷史版本節點並修正預設向量表基址，近期軟體包動作以與上游對齊和補全為主（09-17）。
  • 其他索引更新：STM32N657xx FSBL 軟體包索引合入（09-14）；虛擬感測器軟體包並支援 MQTT 上傳提交待審（09-11）。

六、趨勢觀察

  1. RISC-V 從「能跑」邁向「多核使用者態驗證」：玄鐵 C908 的 rt-smart、MMU 與 SMP 三連合入，疊加惰性 FP/RVV 上下文切換提案獲維護者正面回應，架構支援重點從基本可用轉向實時效能、程序隔離與向量場景，是本期最具分量的方向性變化。
  2. 工具鏈結束長期停更：env 由 1.5.x 躍遷至 2.0.0 並即時補發 2.0.2，配置系統重構、命令列化與映象地址單源化落地，將直接影響開發者日常構建流程，升級需關注相容性說明。
  3. 國產微控制器原廠是合入主體：國民技術 N32H 三系列、小華半導體 HC32 系列、兆易創新 GD32 在近一週內密集送審與合入，原廠自維護分支與主線並行推進，主線的適配週期通常更長。
  4. 存量缺陷進入集中清理期：STM32 連結指令碼容量校驗缺陷掛起約八個月後關閉，SDIO 登出洩漏從缺陷報告到修復提案約兩天，四項安全類 issue 於 09-13 集中關閉，評審與修復的閉環速度較前期明顯加快。
  5. 開發板配套從「能跑」轉向「好用」：Gino Pi 在正式發售後同一周內補齊 JLink 除錯鏈路與睿擎平臺適配，新產品匯入的工作重心由硬體釋出轉向工具鏈與平臺可用性。
  6. 官方渠道靜默、社群內容上位：官方新聞介面連續二十餘日零更新，視窗內新增內容以論壇教程連載、競賽開源工程與社群討論為主，內容產出與傳播重心進一步向社群側傾斜。
