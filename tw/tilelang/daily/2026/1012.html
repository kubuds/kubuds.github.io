一、核心專案進展

1.1 主倉：SM121（DGX Spark）點亮塊縮放 MMA；CuTeDSL 柵欄選舉與引數身份修復（10-10 ~ 10-11）

日期：2026-10-10、2026-10-11　來源：SM121 塊縮放 MMA（#3430）／ CuTeDSL 柵欄選舉（#3400）／ NVRTC / CuTeDSL 引數身份（#3414）

  • SM121 點亮（#3430，10-11 00:32 合入）：SM121（GB10、DGX Spark）實際支援 SM120 級 warp 塊縮放 MMA，但 tl::sm120_mma_sync_blockscaled 只檢查 CUTLASS_ARCH_MMA_SM120A_ENABLED（僅在 __CUDA_ARCH__ == 1200 時定義），導致 sm_121a 下所有塊縮放 MMA 編譯成 BPT.TRAP 而非 OMMA.SF；本筆改為按 arch 與家族同時接受 SM120 / SM121 目標，NVF4 測試按 SM12x 家族門控，CuTeDSL TMA 架構表放行 sm_121 / sm_121a。作者在 DGX Spark（驅動 580.178.04、CUDA 13.0）實測透過。
  • 柵欄選舉（#3400，10-10 10:47 合入）：sync_grid() 此前選舉所有 tid.x == 0 的執行緒，2D / 3D 執行緒塊下多個執行緒重複釋出同一塊到達、柵欄可能提前放行；現只選舉物理執行緒 (0, 0, 0)，計數器 / 世代協議與協作啟動不變。迴歸覆蓋 1D / 2D / 3D 網格與重複複用（RTX 5090、CuTeDSL 4.7.0）。
  • 引數身份（#3414，10-10 13:58 合入）：NVRTC 與 CuTeDSL 宿主包裝器原先用原始 Var 名生成簽名、按列印名匹配引數，重名（stream、device_id 等）與裝置側改名會串擾；現按 Var 身份分配包裝器引數名並保留位置 ABI，CuTeDSL 允許同一核心以不同標量繫結重複呼叫，同名 shape / stride 符號得以區分。

1.2 主倉：GEMM dtype 白名單收官——不支援的組合在 CUDA codegen 前拒絕（10-12）

日期：2026-10-12　來源：GEMM dtype 白名單（#3245）

  • 部分 T.gemm 運算元 dtype 組合（如 bf16 x bf16 到 fp16）此前在前端被接受、直到 nvcc 內以不透明的 static_assert 失敗（缺陷單 #3004）；本筆為 Ampere / Ada mma.sync 路徑加顯式 dtype 白名單，前端（tileop/gemm）與 C++ 指令選擇雙端強制，不支援組合在 CUDA codegen 前即被拒絕並給出明確資訊。
  • 附 1 條負例與 3 條正例迴歸；受支援組合與非 Ampere 目標行為不變。本筆 10-12 01:21 合入，為視窗截點前最新一筆。

1.3 主倉：For 步長、JIT 輸出索引、popcount、位歸約與測試基建五筆落定（10-10 ~ 10-11）

日期：2026-10-10、2026-10-11　來源：For 迴圈步長（#3427）／ JIT 輸出索引（#3318）／ popcount（#3300）／ 位歸約（#3332）／ 測試基建（#3313）

  • For 步長（#3427，10-10 12:54 合入）：迴圈攜帶衝突分析此前把步長恆當作 1（與註釋「預設 1、未指定時」相悖），非單位 / 符號步長下有效迭代對判定失真；現按顯式步長收縮迭代對範圍，CUDA 與 HIP codegen 均保留步長並委託 CodeGenC 發射，兼顧展開迴圈的詞法分配作用域。
  • JIT 輸出索引（#3318，10-10 12:02）：out_idx=[-1] 在引數個數不同的核心間複用時會被歸一化汙染（兩引數核心把 [-1] 歸一為 [1]、四引數核心隨後誤佔輸入槽）；現於歸一化前複製呼叫方列表、拒絕等於引數個數的標量索引並給出合法區間。
  • popcount（#3300，10-10 12:02）：補齊有符號與 8 / 16 位窄整數的 CUDA 下沉——先按原寬度轉無符號再擴充套件（int8(-1) 計 8 位而非 32 位），64 位走 __popcll，覆蓋 8 種 dtype 迴歸；修復 #2984，H100（CUDA 13.0）16 項測試全過。
  • 位歸約（#3332，10-11 14:13）：reduce_bitand / bitor / bitxor 原先只檢查目標緩衝、放行浮點源（[1.0, 2.0, 4.5, 8.9] 被靜默截斷為 1 2 4 8 = 15 且無告警）；現源與目標統一按整數 / 布林規則拒絕（refs #3301）。
  • 測試基建（#3313，10-11 18:25）：新增共享 IR 檢查助手（節點收集、精確運算元呼叫計數、按符號收集外部呼叫），issue 與 transform 測試從區域性遍歷程式碼遷移到助手；lower_ldgstg 測試補結構斷言，選定 transform 測試固定 sm_90 目標並加可用性跳過。
