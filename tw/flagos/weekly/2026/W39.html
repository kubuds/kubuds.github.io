FlagOS週報（2026-09-21 ~ 2026-09-25）

2026-09-25 苦芽科技

報告週期：2026 年 9 月 21 日（週一）至 9 月 25 日（週五），共 5 個工作日 素材來源：本刊每日 FlagOS 動態報告（09-21、09-22、09-23、09-24、09-25 五期，視窗逐日銜接、無空檔）；全部條目來自當期已核驗信源，編制時另經 GitHub 複核補充 編制說明：本週為 FlagOS 2.2 GA（09-28）前的最後一個完整工作周，主線是釋出收口——「標籤、清單、範圍」三層校驗相繼完成；同時覆蓋元件與程式碼共建、新晶片夥伴接入、成員單位與生態四個維度。五期日報視窗提交命中合計 916 條（163 / 224 / 143 / 211 / 175），各期活躍倉庫 22 / 19 / 24 / 23 / 24 個，合計覆蓋 org 內約 30 個倉庫

  • 2.2 釋出物凍結：十元件正式版本標籤批次落庫（09-24）：09-24 凌晨 01:49 ~ 01:50，十個 L1 模組的正式版本標籤（裸版本號、無 rc / post 字尾）一次性打出——flaggems v5.4.0、flagfft v0.2.0、flagsparse v0.3.0、flagdnn v0.3.0、flagblas v0.3.0、flagtensor v0.3.0、flagaudio v0.3.0、flagattention v0.4.0、flaggems-vllm v0.2.0、flaggems-sglang v0.1.0；每個標籤打在對應模組 rc2 分支 HEAD 並逐條回讀核對，配套 PR（community #114）把「官方標籤 ← rc2 基線」對映補入官方清單，截至編制仍在審。

三、元件與程式碼共建

本週 org 內五期視窗提交數為 163 / 224 / 143 / 211 / 175 條，合計約 916 條，以下按模組聚合。

運算元與領域庫（FlagGems 及各領域庫）

  • FlagGems（主線，本週第一條線）：五期視窗提交 34 / 29 / 28 / 59 / 46 條。三條產能線並行：KernelGen 批次入庫（一週注入 Nvidia 長尾運算元約 60 枚，覆蓋 inverse、_gather_sparse_backward、msort、linalg_inv_ex、_ctc_loss 系、_cudnn 系、histogramdd、_scaled_grouped_mm_v2 等）；崑崙芯整備批（31 運算元最佳化批一次性入庫、27/31 達到 0.8x 效能線，另有近 20 筆 XPU 修復批覆蓋 FlashAttention 快路徑、scaled_mm 宿主快路徑、卷積系與特殊函式，測試機遷移至 klx-p800）；TLE 多後端鋪開（昇騰 glu 用 tle.dsa.extract_slice、天數 Iluvatar 在 vendor descriptor 啟用 TLE、海光 W8A8 管線因白名單限制改寫為分段 tl.range，48 小時內 TLE 進入四個後端）。
  • 量化與調優：海光 fused_inv_rope_fp8_quant（DeepSeek-V4 注意力路徑「逆 RoPE + FP8 組量化」融合）、海光 INT8 RMSNorm 註冊；沐曦 topk_w8a16_fp8；摩爾執行緒 index_add / polar 最佳化；六後端 FP8 測試補齊（NVIDIA / Ascend / Hygon / 玄鐵 / MetaX / Iluvatar）；FlagTune 成本模型擴至 Hopper、沐曦 MM 與達摩院玄鐵 ZW810E（v1.1.0 在審）、FP8 MM 本地調優啟用。
  • 平臺修復批：昇騰（apply_rotary_pos_emb cos/sin 重複、batched linalg_solve_triangular 錯誤結果、log_ 網格 padding）；天數（linalg_solve_triangular 關閉 TLE 路徑、index_reduce_）；海光（complex 標量乘）；沐曦（masked_fill 越界）；崑崙芯（special_bessel_y1 / softplus / weight_norm 批）。
  • 工程質量：運算元註冊路徑失效修復、基準 reference-only 基線校驗、候選前置預檢與程序內 profiling 鉤子、周度後端容器映象更新；SiliconFlow 持續貢獻（_scaled_grouped_mm 跨後端修復與調優、adaptive_avg_pool2d 最佳化、index_reduce_ 三平臺修復）。
  • FlagFFT：海光 HCU 介面卡（詳見要聞）；MACA 線「1d single」測量策略轉預設、FP64 暫存器交換實驗當日試落又撤回；打包三件套（Debian + RPM、Nexus 釋出、0.2.0-rc2 移植）；JIT 產物跨程序隔離與多程序迴歸測試。
  • FlagSparse：與 NCIC-AlphaSparse 協作進入高頻期（一週六批合併：MACA SpMV CSR 基線、DCU SpMM COO 最佳化、ASCEND 數值除錯、biv 演算法加入、MUSA 交付修復）；v0.3.0 正式標籤後 main 升 0.4.0；rpm 打包與 pip 相容修復。
  • FlagBLAS：昇騰 L2 效能最佳化兩批（SPR / SPR2 / HPR / HPR2、banded packed 與 triangular、SYMV 啟動路徑簡化）；摩爾執行緒 L2 支援合入；外部貢獻者打包線落地。
  • FlagDNN / FlagTensor / FlagAudio / FlagAttention：FlagDNN 重組天數與海光平臺實現架構、摩爾執行緒複用已編譯產物、打包合併；FlagTensor 0.3.0-rc2 打包線（deb / rpm、CMake 查詢 Torch、Nexus 上傳）；FlagAudio 首批三個 PR 合入後轉實（頻譜圖 Triton 運算元、增益恆等修復、openEuler 安裝回退）；FlagAttention v0.4.0 標籤、測試與基準更新。

推理與訓練框架（FlagGems-vllm / FlagGems-sglang / Torch-FL / 外掛線 / FlagScale / TE-FL / Megatron-LM-FL）

  • FlagGems-vllm（四平臺同窗）：昇騰 XCS 運算元批推進（slot_mapping 最佳化實測整輪服務 1050.9 → 81.2 ms、kpool 狀態壓縮、lightning indexer、kv_rmsnorm_rope_cache 等）；摩爾執行緒共享 INT4 / FP8 融合 Marlin MoE 與 W8A8 變長注意力；海光 INT8 塊狀 BMM 與 einsum 收縮；沐曦融合逆 RoPE FP8 量化與 persistent_topk MC550 後端；達摩院玄鐵 TLE 版 topk；Gemma RMSNorm 一次補齊三平臺；「同運算元多平臺對照實現」成為標準工作模式。
  • FlagGems-sglang：融合 MoE router 三路合併（崑崙芯與 MUSA 整合、昇騰兩版 tensorcore 變體、燧原 tensorcore dot-acc）；燧原 GCU vendor 註冊（裝置查詢、TLE 啟用、啟發式配置）。
