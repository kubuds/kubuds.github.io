今日重點：Xing4.1-Preview 八芯 Day0 適配，英偉達平臺每 Token 耗時最高降 20.9%（11-25）

日期：2026-11-25　來源：FlagOS 專欄。

  • 模型：中電信人工智慧科技有限公司開源星辰大模型 Xing4.1-Preview。
  • 規格：總引數 285B，每 Token 啟用約 17B，原生支援 1M 上下文。
  • 結構：45 層 Transformer 主幹，其中 42 層為 MoE。
  • 路由：每 Token 從 256 個專家中選 8 個，另有 1 個共享專家。
  • 注意力：MLA 壓縮 KV 表示，配合 DSA 稀疏注意力。
  • 適配範圍：平頭哥、英偉達、摩爾執行緒、昇騰、沐曦、海光、天數智芯、崑崙芯 8 家。
  • 交付物：W8A8 與 BF16 兩套版本，已上架魔搭與 Hugging Face。
  • 評測口徑：英偉達單機 8 卡、64 併發，基線為同精度原生方案。
  • 4K 輸入：輸出吞吐由 1862.10 升至 1988.23 tokens/s，提升 6.8%。
  • 4K 時延：平均每 Token 耗時由 30.23 降至 27.63 ms，降 8.6%。
  • 16K 輸入：吞吐提升 4.1%，每 Token 耗時降 18.7%。
  • 32K 輸入：吞吐提升 1.7%，每 Token 耗時降 20.9%。
  • 代價：三檔輸入的平均首 Token 時延分別增加 11.8%、21.5% 和 6.0%。
  • 精度：MATH-500、GPQA Diamond、MMLU 三項與英偉達原生對齊。
  • 國產平臺：部分場景單位算力吞吐達到英偉達原生的七成以上，最高 181.5%。
  • 運算元：4K 場景啟用 54 個 FlagGems 運算元。
  • 元件：部署鏈路使用 FlagGems、FlagTree 與 vLLM-plugin-FL。
  • 框架：英偉達、平頭哥、沐曦、海光、天數智芯、崑崙芯採用 vLLM 0.24.0。
  • 框架續：昇騰與摩爾執行緒採用 SGLang 0.5.18。
  • 觀察：這是 FlagOS 本週第一條帶完整效能資料的 Day0 適配。
  • 觀察續：國產平臺的對比指標是單位算力吞吐，不是絕對吞吐。
