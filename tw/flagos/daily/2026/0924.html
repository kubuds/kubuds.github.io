今日重點：距 2.2 GA（09-28）4 天——官方清單開始收錄 L1 運算元庫：十元件正式版本標籤批次落庫

日期：2026-09-24　來源：community #114、community #113、release-2.2-rc2.yaml、官方清單 release-2.2.yaml

rc2 穩定期進入最後一天（官方排期 09-24 截止、GA 定 09-28），釋出工程在 09-24 凌晨完成兩件事。

其一，官方釋出清單開始收錄 L1 運算元庫。09-24 01:49 ~ 01:50，十個 L1 模組的正式版本標籤（裸版本號、無 rc / post 字尾）批次打出：

  • flaggems v5.4.0、flagfft v0.2.0、flagsparse v0.3.0、flagdnn v0.3.0、flagblas v0.3.0、flagtensor v0.3.0、flagaudio v0.3.0、flagattention v0.4.0、flaggems-vllm v0.2.0、flaggems-sglang v0.1.0。

每個正式標籤都打在對應模組 rc2 分支 HEAD（即最新已驗證 post 標籤提交）上，且推送後已與遠端逐條回讀核對。配套 PR（community #114「add L1 operator libraries to the 2.2 official manifest」）於 01:51 開出：向官方清單 release-2.2/release-2.2.yaml 補入十條「官方標籤 ← rc2 基線」對映（flaggems v5.4.0 ← post4；flagattention v0.4.0 ← post1；flaggems-vllm v0.2.0 ← post1；flaggems-sglang v0.1.0 ← post1；其餘各條 ← post2），該 PR 仍在審（waiting merge）。官方清單此前僅有 sglang-plugin-fl v0.2.0 一條（09-22 落庫），本 PR 是 L1 層的首批批次收錄。

其二，rc2 通道以 13 模組 post 標籤收口（09-24 00:42，community #113）：把 release-2.2-rc2.yaml 中 13 個模組版本欄位統一 bump 到各自 rc2 分支 HEAD 的最新已驗證標籤——flaggems rc2.post4；flagfft / flagdnn / flagblas / flagtensor / flagaudio rc2.post2（內容為 Debian / RPM 打包與 Nexus 釋出鏈、flagaudio 增益恆等修復）；flagtree 三線 0.7.0rc2.post2；vllm-plugin-fl 雙線 post3；transformerengine-fl post2；flagscale post2。全部標籤推送前均與遠端核對。

同日範圍側另有一筆收縮記錄：community #112（FEP-0085）指出 rc2 測試在 FlagCX 0.14.0-rc2 與 FlagTree 0.7.0-rc2-triton3.6 中均未發現 GEMM+ReduceScatter 的實現（參 FlagCX#620），經與開發線商定將該運算元移出 2.2 範圍，FEP 文件、測試計劃與實現歷史同步修訂（該 PR 仍在審）。

判斷：正式標籤批次落庫 + rc2 清單收口 + 範圍收縮三件事在同一個視窗出現，說明 2.2 的釋出面已從「程式碼凍結」轉入「釋出物凍結」——清單、標籤、範圍三者開始互為校驗。接下來四天的觀察點是 #114 的合併與 L2 / L3 批次（vllm-plugin-FL、TE-FL、FlagScale、KernelGen 等）的收錄順序。
