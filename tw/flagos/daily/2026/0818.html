FlagOS 每日動態報告（2026-08-18）

2026-08-18 苦芽科技

調研視窗：2026-08-17 10:25 ~ 2026-08-18 10:19 北京時間 信源：GitHub（org: flagos-ai）、Google News 聚合（中英文）、HN、智源社群等（詳見附錄）

一、開源專案進展（GitHub 動態）

視窗總覽：org 內 53 個倉庫中 16 個在視窗內有推送；commit search 命中 81 條預設分支視窗內提交，為本月最活躍視窗之一，無正式 GitHub Release。本視窗三大主線：FlagGems KernelGen 運算元批次合入潮（約 25 條提交，多晶片後端全面鋪開）、Torch-FL 多晶片功能補全（海光 DCU AMP、燧原免 torch_gcu 整合，且由 Claude Code 智慧體輔助開發）、build-infra 多廠商驗證矩陣擴張（摩爾執行緒 MUSA 5.2.0/4.3.6、昇騰 CANN 9.0.0 相繼記檔）+ 海光 BW1000 進入 Megatron-LM-FL CI。

1.1 FlagGems：KernelGen 運算元批次合入潮，多晶片後端全面鋪開（約 25 條提交）

來源：FlagGems commits

  • 多後端運算元：linalg_det 單運算元一次覆蓋 NVIDIA/Ascend/Hygon/Thead/MetaX/Iluvatar 七後端（8/17 14:51）；conj_physical 增加 hygon runtime 與 ascend tune 配置（#5434）。
  • KernelGen NVIDIA 運算元批次新增（8/17 10:45-10:52 密集合入 16 個）：avg_pool1d、weight_int8pack_mm、special_bessel_y0、grid_sampler_3d_backward、upsample_bilinear2d_aa_backward、_native_batch_norm_legit、_fused_moving_avg_obs_fq_helper、special_shifted_chebyshev_polynomial_t、cdist、addr（inplace）、empty_permuted、batch_norm_impl_index、addbmm、_adaptive_avg_pool3d_backward、fake_quantize_per_channel_affine 等，另有 native_dropout_backward 重對映為 canonical wrapper（#5414）。
  • 晶片專屬批次：[KernelGen][Hygon] 海光運算元批次（#5557，8/18 10:21）；[KernelGen][Iluvatar] 天數智芯運算元批次（#5558，8/18 10:21）。

  • 摩爾執行緒最佳化：[MTHREADS] constant_pad_nd 專屬 kernel（#5395）；matmul_bias_activation 改用 SQMMA 指令最佳化（#5551）。

1.2 Torch-FL：多晶片功能補全，引入 Claude Code 智慧體輔助開發（10 條提交）

來源：Torch-FL pulls
