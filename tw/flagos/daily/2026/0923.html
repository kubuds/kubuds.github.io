今日重點：距 2.2 GA（09-28）5 天——釋出清單落庫、Release Info 門戶重建、Megatron 應用映象覆蓋 14 個後端行

日期：2026-09-22 ~ 2026-09-23　來源：community #111、release-2.2.yaml、Release Info 門戶、build-infra #1019 至 #1034

按社群 2.2 釋出追蹤（#47）的官方排期，rc2 穩定期 09-24 截止（之後僅接受 hotfix），GA Go/No-Go 定於 09-28。本視窗恰處收口期，釋出工程一日三線推進：

其一，官方釋出清單開始落庫。09-23 00:11 合入 community #111：新增 release/2.2/release-2.2.yaml——它是 FlagOS 2.2 的官方釋出源清單（vcstool 格式，供 vcs import 一次性拉取全部元件原始碼）。清單首條目為 sglang-plugin-fl v0.2.0（官方標籤打在該模組透過最終 rc2 驗證的提交上，分支 0.2.0-rc2，HEAD 1c84db7）。檔案頭註明了版本規範：官方標籤一律裸版本號（無 rc/post 字尾），FlagTree 例外、保留上游本地版本格式（如 0.7.0+triton3.6）；結構上按 L2「框架適配層」等分層組織，後續元件將逐批補入。

其二，應用映象登記推進到 14 個後端行。build-infra 本視窗 33 筆提交中，Megatron-LM-FL 應用映象標籤 2.2.0-0.2.3 在 14 個平臺行集中登記（nvidia-cuda12.8 / cuda13.3、ascend-cann8.5.0 / cann9.0.0、cambricon-neuware4.4.3 / 4.7.2、enflame-tops1.9.10 / 1.10.6、hygon-dtk26.04、iluvatar-corex4.4.0 / 4.5.0、metax-maca3.8.1.3、mthreads-musa4.3.6 / 5.2.0，對應 #1019 至 #1033）；配套修正兩筆：構建步驟直接讀取鎖定的 wheel 版本（#1018）、精確鎖定安裝版本並補齊兩個未構建行（#1017）。同期登記的還有 vLLM 崑崙芯應用映象 2.2.0-0.3.0rc2.post2（#1012 / #1013，配套授權重建 #1010）。

其三，Release Info 門戶重建。09-23 06:38 ~ 06:44，釋出資訊倉庫 gh-pages 分支連續 13 次推送、重建 Hugo 門戶（flagos-ai.github.io/release-info）。門戶按「廠商 / 基礎映象（base）/ 執行時映象（runtime）/ 應用映象（application）」四層組織，覆蓋 20 個平臺行的 base 與 runtime 映象，以及 vLLM（0.20.2 / 0.24.0 兩套矩陣）、Megatron（training / rl）、sglang 0.5.18 應用映象；以 Megatron 的 nvidia-cuda12.8 行頁面為例，已可見 harbor.baai.ac.cn/flagos-app/megatron_training0.17.1-nvidia-cuda12.8:2.2.0-0.2.3 與 flagos-runtime-nvidia-cuda12.8:2.2.0 的完整拉取說明。映象登記、門戶釋出、清單落庫三條線在本視窗首次同日對齊，2.2 釋出物開始對外可見。

版本分支側同步推進：FlagTree 0.7.0-rc2-triton3.6（09-23 09:36 推送）、vllm-plugin-FL 0.3.0-rc2（09-22 23:20，#549）、FlagScale 2.1.0-rc2（09-23 08:43，#1301 從 main 摘取）、sglang-plugin-FL 0.2.0-rc2（v0.2.0 已打標籤）。

2.1 AICC2026 在京舉行：FlagOS 兩場演講與「可靠AI」測評體系啟動（09-21/09-22）

日期：2026-09-21（會期）/ 2026-09-22（報道集中釋出）　來源：光明網、新京報、CBISMB、AICC 官網議程

第七屆人工智慧計算大會（AICC2026）於 09-21 在北京中關村國際創新中心舉行，09-22 起集中見報。與 FlagOS 直接相關的兩項：主論壇 09:50 檔，北京智源人工智慧研究院副院長兼總工程師林詠華作「從架構創新到可用算力：FlagOS 驅動 AI 計算的軟硬協同新正規化」報告，指出「AI 負載不會收斂，計算架構也不會只剩一種；硬體創新要轉化為可用算力，需要共享的軟體生態支撐——眾智 FlagOS 透過統一編譯器、運算元、通訊和訓推框架等能力，降低多元晶片的重複適配成本」；另據大會議程，智源研究院研究員趙帥在專題論壇作「眾智 FlagOS：以開放軟體棧釋放多元 AI 算力價值」報告。會上同步舉行「可靠AI」評測工作組啟動儀式（工信部電子五所，10:10 檔），並在產業成果環節正式釋出面向 Agent 時代的「可靠AI」測評體系——由工信部電子五所聯合北京智源研究院、浪潮資訊、摩爾執行緒、沐曦股份、北京開源晶片研究院、百度智慧雲、阿里雲等 20 多家產業鏈單位共同釋出，覆蓋晶片、整機與互聯、框架與系統、模型、資料、應用全環節，從可靠性、安全性、穩定性維度開展全鏈路評測。同期 IDC 與浪潮資訊聯合釋出《2026 年中國人工智慧計算力發展評估報告》：預計 2026 年中國智慧算力規模達 2576.5 EFLOPS、同比增長 87.9%。成員單位在議程上的密度（摩爾執行緒、清微智慧、智源 FlagOS 兩場）說明本棧已是國內開放算力生態的常駐議題。

2.2 雲棲大會：達摩院玄鐵釋出真武 V900——FlagOS 支援平臺 PPU 迎來新一代硬體（09-22）

日期：2026-09-22　來源：觀點網、每日經濟新聞、東方財富、阿里雲開發者社群

2026 雲棲大會（09-22，杭州）上，阿里巴巴旗下達摩院玄鐵（T-Head）釋出新一代訓推一體 AI 晶片真武 V900：216GB 視訊記憶體、片間互聯頻寬 1200GB/s，原生支援 FP8 / FP4 低精度計算，單晶片效能為上代真武 M890 的 3 倍，將於 2027 年第一季度量產；會上同時預告下一代真武 J900（2028 年 3 月）與倚天 720 / 730 兩代伺服器 CPU（2027 年），並披露真武 V900 超節點具備記憶體統一編址能力、可組成千卡全頻寬互聯。真武系列即阿里自研 PPU（Parallel Processing Unit），而 PPU 已是 FlagOS 統一外掛與編譯器的支援平臺之一（FlagGems-vllm PPU 運算元、FlagTree PPU CI、FlagDNN PPU 架構）——新一代硬體的釋出意味著本棧 PPU 後端有了明確的代際升級目標。

2.3 國產算力軟體棧動態：龍芯加速計算平臺首個版本釋出；數貿會今日開幕（09-22/09-23）

日期：2026-09-22 ~ 2026-09-23　來源：IT之家、快科技、數貿會 AI 展區預覽

  • 龍芯中科 09-22 釋出「龍芯加速計算平臺」首個軟體版本：基於龍芯 2K3000 / 9A1000 整合的 LG200 系列通用 GPU，覆蓋驅動、編譯器、執行時、運算元庫（BLAS / DNN）、推理引擎、除錯與效能分析工具，支援 OpenCL 3.0 與 CUDA 兩類程式設計模型，可低成本遷移 CUDA 應用，並規劃隨 9A2000 / 9A3000 演進實現代際軟體相容。國產算力「全棧軟體平臺」的又一例，與本棧「統一軟體棧降低適配成本」的路線互為參照。
  • 第五屆全球數字貿易博覽會 09-23 在杭州開幕（至 09-27）：首設「數貿·芯場景」積體電路應用生態板塊，沐曦等企業進入「晶片 + 材料 + 算力」協同展陳；算力企業參展 117 家。成員單位的產業露出由會議季承接。

四、總結與趨勢觀察

  • 2.2 進入 GA 前最後一週，釋出物開始「可見」：官方釋出清單首條目落庫（sglang-plugin-fl v0.2.0）、Release Info 門戶同日重建、Megatron 應用映象 2.2.0-0.2.3 覆蓋 14 行。rc2 穩定期 09-24 截止、GA 定 09-28——接下來一週的觀察點是清單逐批補齊與各元件 rc2/post 標籤的收口順序。
  • 分發形態繼續加寬：FlagCX wheel 從試點行擴到全部行 + 崑崙芯落地、deb/rpm 覆蓋到每個打包元件、FlagTree Iluvatar wheel 重建——與 FEP-0019（統一打包整合）的 Wave 1 驗收線吻合，「映象之外」的原生包通道成為 2.2 的標準交付面。
  • 量子棧是本日單倉吞吐之最：FlagQuantum 38 筆同時推進雲後端（Azure Quantum / Braket / CUDA-Q / Cirq 四線互通）、模擬融合加速與候選驗證門禁——從一個「跟隨元件」走向框架化開發節奏。
  • 三倉同時進入修復/調優節奏：FlagGems（15 枚 KernelGen + 六平臺修復）、FlagGems-vllm（三條在審轉合入）、Torch-FL（11 筆工程收口，含移除全域性補丁與退役程式碼）——特性凍結後的「驗收、修復、調優」視窗形態與排期一致。
  • 對外資訊面由會議季承接：元件級檢索第十八個平靜視窗 vs AICC2026 兩場 FlagOS 演講與「可靠AI」啟動、雲棲真武 V900 釋出、龍芯全棧 GPU 軟體平臺——產業側對「統一軟體棧 / 多元算力」的關注度在會議季集中釋放，與程式碼側收口互為印證。
  • 待觀察：2.2 清單後續條目（FlagTree 0.7.0+triton3.6、vllm-plugin-FL 0.3.0、FlagScale 2.1.0 等版本分支已在推進）；PPU 新硬體的軟體適配跟進（V900 量產在 2027 Q1）；FlagSparse / FlagAttention 打包線（FEP-0019 Wave 1）在 GA 前的落地。
