一、開源社群與軟體生態

1.1 Linux 7.3-rc1 釋出：RISC-V 中斷控制器程式碼重構入通用 ACPI IRQ 框架

日期：2026-08-31　來源：9to5Linux、LKML（Linus 釋出郵件）、Phoronix：Linux 7.3 新增多個新 RISC-V 擴充套件、Phoronix：KVM Chainsaw 清理合入

Linus Torvalds 於 08-30（北京時間 08-31 凌晨）釋出 Linux 7.3 首個候選版 7.3-rc1，為期兩週的合併視窗正式關閉。Linus 表示本次 rc1”提交數規模名列前茅”，主要驅動是 AMD DCN6 暫存器標頭檔案的大批次更新。與 RISC-V 直接相關的變化：irqchip/ACPI 程式碼重構將 RISC-V 中斷控制器管理程式碼抽取出通用部分併入公共 ACPI IRQ 程式碼，以支援 ARM 側 GICv5 IWB 的 ACPI 探測順序（該重構亦為 RISC-V 後續 ACPI 中斷支援鋪路）；合併視窗期間已合入對若干較新 RISC-V 擴充套件的支援（Phoronix 08-24 報道）。KVM 側本週期以修復與清理為主：”KVM Chainsaw”（拆分 kvm_mmu 巨型資料結構）合併落地，AMD SEV/SEV-ES 的 ENCRYPT/DECRYPT 改為整頁分配以修復 PSP 韌體頁指派導致的資料損壞問題，SEV-SNP population ioctl 加固。按每週日 rc 節奏，Linux 7.3 正式版預計 10 月 18 日或 25 日釋出。該條目為視窗內核心側最重要事件。

1.2 openKylin 3.0 正式釋出：四大架構同源，RISC-V 適配最廣、支援 RVA23 與 RVV 最佳化

日期：2026-08-28/29　來源：CSDN/開放原子、鳳凰網科技、新浪科技/IT之家

開放原子 openKylin 3.0 於 08-28 正式釋出。核心從 Linux 6.6 跨代升級至 7.0，GCC 15、glibc 2.42、LLVM 22、JDK 25 等 180 餘個核心元件同步迭代。與 RISC-V 生態最相關的三點：（1）同源支援 x86、ARM、RISC-V、LoongArch 四大架構，官方稱 openKylin 是”RISC-V 架構適配最廣、成熟度最高的作業系統之一”，已支援最新 RVA23 標準，各架構硬體相容清單在 Gitee 釋出；（2）RISC-V 平臺上 AI 推理經 RVV 指令最佳化，FP32 場景提速 2 至 5 倍、FP16 場景最高 36.5 倍；（3）場景覆蓋延伸至”靈龍”人形機器人、AI 無人小車、AI 機械臂等具身智慧適配與多架構工業硬體平臺。安全側整合 NIST 三大後量子密碼標準（ML-KEM/ML-DSA/SLH-DSA）並經 openHiTLS 提供系統級呼叫，支援 Rust For Linux 核心驅動開發。智慧體側構建開放底座：KylinBot 與 OpenClaw 等主流智慧體經 MCP 協議直調桌面能力。作為 RISC-V 軟體生態的國產 OS 關鍵一環，openKylin 3.0 的 RVA23/RVV 適配進度值得持續跟蹤。

1.3 開源專案兩則：ClickDOOM 用 ClickHouse SQL 模擬 RISC-V 跑 1993 DOOM；LabWired Core 韌體確定性模擬器

日期：2026-08-31　來源：MarcusKainth/ClickDOOM、w1ne/labwired-core

兩個新晉活躍開源專案（視窗內由 GitHub API 檢出）：ClickDOOM 將 1993 年 id Software 的 DOOM 引擎 C 原始碼經 doomgeneric 移植層原樣編譯為裸機 RV32IM 二進位制，再逐指令跑在”完全由 ClickHouse SQL 實現的 RISC-V CPU 模擬器”上（fetch/decode/execute、暫存器、RAM、MMIO 全在 SQL 內），demo3 第 220 幀在 2.2 億條指令後與參考模擬器輸出雜湊一致，驗證了模擬正確性；其前身為 Click-V（SQL 內 RISC-V CPU），Apache-2.0/GPL-2.0 雙許可，屬”把嚴肅 ISA 模擬玩成 SQL 極限挑戰”的趣味硬核專案。LabWired Core 是 Rust 編寫的韌體模擬器：載入韌體 ELF 後在建模的晶片（CPU、匯流排、外設、感測器）上確定性執行，同一 ELF + 板卡清單在任何機器產生相同 trace，可作 CI 門禁（pass/fail 退出碼），支援 ARM Cortex-M 與 RISC-V，61 stars。二者共同體現 RISC-V 工具鏈/模擬生態在”模擬即測試”方向上的活躍度。

二、產品與生態動態

2.1 XCENA MX1：Hot Chips 2026 詳解數千 RISC-V 核的 CXL 計算儲存器件

日期：2026-08-26（Hot Chips 演講）/08-28（報道）　來源：HPCwire、ServeTheHome、StorageNewsletter

XCENA 在 Hot Chips 2026 Memory 分會場（08-26，與三星聯合演講）詳解其 CXL Type 3 計算儲存器件 MX1 架構與實測效能：3072 顆定製 1.4GHz RISC-V 核組成 Memory Acceleration Unit 就近執行訪存密集型負載；四條 DDR5-8400 通道最高擴充套件 2TB 記憶體，SSD 經根埠以位元組定址 CXL 記憶體形態呈現；整合向量引擎提供約 3 TFLOPS FP32/FP16 點積吞吐（面向向量檢索、KV-cache 評分）。開發者以標準 C/C++ 或 Rust 程式設計，經 LLVM 工具鏈 + PXL 執行時（共享虛擬地址空間）排程數千核。實測相對宿主機 CPU 經 CXL 訪問：單 MX1 吞吐最高 4.7 倍、能效 18.7 倍；相對本地 DDR5：吞吐 2.0 倍、能效 6.2 倍。該器件是”RISC-V 大規模近存計算 + CXL 記憶體池化”路線的代表，與三星機架級 CXL 記憶體方案搭配，值得關注其對 AI 記憶體牆敘事的實際影響。

2.2 印度 Aheesa Vihaan 一版流片點亮：64 位 RISC-V 網路 SoC 透過首輪硬體驗證

日期：2026-08-30　來源：SDxCentral、The Hans India、Aheesa 官網

金奈初創 Aheesa Digital Innovations 宣佈其 Vihaan 系列一版流片（first-pass silicon）成功，首輪硬體驗證確認了效能指標。Vihaan 是 64 位 RISC-V 驅動的網路 SoC，面向寬頻接入場景：高效能路由器、託管交換機與統一威脅管理（UTM）裝置；另有邊緣版本面向 IoT 閘道器與工業自動化（本地低延遲處理）。該公司 2021 年成立，高管來自 Wipro、Microchip、AMI，CEO Sridharan Mani 曾任亞馬遜高階軟體開發經理；受印度電子與資訊科技部（MeitY）設計關聯激勵（DLI）計劃資助，融資約 419 萬美元（含泰米爾納德邦基礎設施基金 TNIFMC）。節奏：2026 年 1 月首輪流片，量產流片目標 2027 年。MeitY 宣告稱其進展”表明印度半導體設計正走出實驗室”。這是印度 RISC-V 主權晶片路線（繼 IIT Madras 系 Shakti 之後）在商用網路矽片方向上的標誌性進展。

2.3 Radxa Linkr 生態參考：U 盤大小 IP KVM，主控含 RISC-V 協處理器

日期：2026-08-30　來源：CNX Software、Radxa 產品頁

CNX Software 拆解評測 Radxa 新品 Linkr：U 盤大小的 IP KVM（70×22×12mm），經 HDMI 採集目標機畫面 + USB 模擬鍵鼠，支援 USB-C 直連、乙太網與 Wi-Fi 6（AIC8800）遠端控制，瀏覽器即可操作，免裝 App，支援 Tailscale VPN、雙因素認證及 OpenClaw/Hermes 等 AI agent 接管。主控為 Rockchip RV1106G3（Arm Cortex-A7 @1.2GHz + 整合 RISC-V 協處理器），1 TOPS NPU，256MB 片上記憶體 + 可選 16GB eMMC。與 RISC-V 的關聯點：RV1106 內嵌 RISC-V 協處理器（同類產品 JetKVM 亦採用），且 Radxa 本身是 RISC-V 單板主力廠商；但 Linkr 主算力側仍為 Arm，屬生態參考條目而非 RISC-V 原生產品。售價 59 美元起，四渠道暫缺貨。

三、國內團隊動態與深挖

3.1 國內團隊 GitHub 動態核查：視窗內整體平靜，僅算能/進迭有小步迭代

日期：2026-08-30/31　來源：sophgo/sophon-tools、spacemit-com/openocd、GitHub orgs API（XUANTIE-RV/sophgo/Nuclei-Software/spacemit-com/eswincomputing/revyos/sipeed）

對七家國內團隊的 GitHub 組織活躍度做視窗核查（orgs repos API pushed_at 過濾）：平頭哥（XUANTIE-RV，72 倉庫）、芯來（Nuclei-Software，42 倉庫）、奕斯偉計算（eswincomputing，16 倉庫）、矽速（sipeed）視窗內均無 push，整體處於釋出後平靜期；算能（sophgo）僅 sophon-tools 一筆 push（08-30 上午，即昨日已報發版前安全加固批次的合入落定）；進迭時空（spacemit-com）兩筆 push 分別為 docs-chip（昨日已報 P3 PMIC 文件）與 openocd 倉庫（上游映象只讀同步，無自主開發）；Revyos 組織 7 倉庫 push 均為 SG204x 韌體鏈同步（fsbl.bin/EDK2 交叉編譯器，昨日已報）。結論：國內團隊視窗內無架構級或產品級新動態，符合大版本釋出後的常規平靜期特徵；下一關注視窗為各團隊 9 月釋出節奏（算能 CV84X 量產配套、芯來掛牌後首輪動作、香山 KunminghuV2 後續）。

四、具身智慧與機器人專章

4.1 視窗內無 RISC-V 具身智慧硬體新品；軟體側 openKylin 3.0 完成人形機器人等適配

日期：2026-08-31　來源：本期各條目彙總（詳見附錄）

本視窗未發現新的 RISC-V 具身智慧硬體新品釋出，格局延續近一週判斷：RISC-V 在具身智慧側的進展集中於軟體與平臺適配層。本期最相關的訊號來自 openKylin 3.0（見 1.2）：其場景覆蓋明確納入”靈龍”人形機器人、AI 無人小車、AI 機械臂等具身智慧適配，並支援 RISC-V 等多架構工業硬體平臺——即國產 OS 陣營正把 RISC-V 具身智慧納入預設適配矩陣；同時 RISC-V 上 RVV 最佳化的 AI 推理效能（FP16 最高 36.5 倍提速）為端側模型部署提供了實測依據。此外 eeNews Europe 技術綜述（08-25，生態參考）指出歐洲 EPAC 1.0 加速器以 RISC-V 控制核 + 領域 AI tile 實現 12 TOPS/W，印證開放 ISA 在機器人與自主系統的功耗約束下的適用性。硬體新品視窗建議關注 9 月國內機器人展會季與各家 SoC 的機器人 SKU 釋出節奏。

五、總結與趨勢觀察

  1. 核心主線推進：Linux 7.3-rc1 釋出，合併視窗合入多個新 RISC-V 擴充套件，RISC-V 中斷控制器程式碼重構入通用 ACPI IRQ 框架，為 RISC-V ACPI 中斷支援鋪路；KVM 側以 SEV 修復與 kvm_mmu 巨型結構拆分為主。
  2. 國產 OS 的 RISC-V 適配加速：openKylin 3.0 四大架構同源釋出，自評”RISC-V 適配最廣、成熟度最高”，RVA23 支援 + RVV 推理最佳化（FP16 最高 36.5 倍）+ 具身智慧場景覆蓋，軟體棧就緒度持續提升。
  3. RISC-V 向資料中心縱深：XCENA MX1 以 3072 核 RISC-V 近存計算 + CXL 3.2 池化切入 AI 記憶體牆問題，實測吞吐/能效相對宿主 CPU 大幅領先（最高 4.7 倍/18.7 倍），與 SiFive BigSky 伺服器交付（08-29 已報）形成互補。
  4. 全球主權晶片路線多點開花：印度 Aheesa Vihaan（DLI 計劃資助）一版流片點亮，繼 Shakti 之後在商用網路矽片方向落子，2027 年量產流片目標明確。
  5. 國內團隊進入釋出後平靜期：七家主要組織 GitHub 視窗內無架構級動態，屬大版本釋出後常規節奏；下一觀察點為 9 月各家釋出視窗。
  6. 侷限說明：Google News 中文源對國內團隊直採有限（平頭哥/香山等詞條被同名噪音汙染），國內部分依賴 GitHub 提交核查；Radxa Linkr 主控為 Arm + RISC-V 協處理器，收錄為生態參考；gnews 跳轉頁不可直讀，正文均以原站為準。
