今日重點：藍芯算力完成近 20 億元 B 輪系列融資，RISC-V+AI 伺服器晶片衝刺量產

日期：2026-10-12（中文媒體首發）／2026-10-13（英文媒體跟進）　來源：鳳凰網·投資界：首發｜藍芯算力完成 B 輪系列近 20 億融資（10-12）、東方財富（財聯社）：藍芯算力完成近 20 億元 B 輪融資（10-12）、搜狐（大河財立方）：藍芯算力完成近 20 億元 B 輪融資（10-12）、DIGITIMES：China’s Blue Core Computing secures nearly US$300 million（10-13）

深圳 RISC-V 晶片公司藍芯算力（深圳）科技有限公司完成 B 輪系列融資，合計規模近 20 億元人民幣（約合 2.99 億美元）：深創投、華控基金、隆湫資本等老股東繼續追加，蘇國投、蘇創投、兆易創新、同創偉業、建銀國際、粵科金融、九坤創投等國資、產業資本與頭部創投進場。資金將用於 RISC-V CPU 晶片量產落地、AI 異構處理器迭代，以及面向電信運營商、金融機構和雲服務商的通用算力解決方案拓展。要點：

  • 產品：核心產品 LX500 為全球首款 RISC-V 通用計算與 AI 智算單晶片原生融合的伺服器 CPU——48 核異構設計（32 效能核＋16 能效核），片內整合 75 TOPS（INT8）AI 引擎，支援 RVV 1.0 向量擴充套件與 RVA23 標準，原生相容 PCIe 5.0 與 CXL 2.0 記憶體擴充套件。
  • 落地：2026 年 2 月流片點亮；7 月搭載 LX500 的聯想問天 WR5219 G5 伺服器在合肥聯寶工廠量產下線；已適配中國移動 BC-LINUX 作業系統，並完成 Kimi K2.6、Qwen3.6-35B 等大模型推理驗證。
  • 團隊：創始人兼 CEO 盧山為前位元組跳動伺服器晶片研發負責人（曾任職英特爾、高通），CTO 賈新霞擁有 21 年晶片設計經驗。

在 Agentic AI 算力需求與 RISC-V 伺服器化兩條敘事交匯下，這是 2026 年國內 RISC-V 領域規模最大的融資之一，也標誌國產 RISC-V 伺服器晶片從”點亮”進入”規模落地”階段。

一、開源社群與軟體生態

1.1 Asterinas 0.19.0：引入 X.Org／DRM 初支援並新增 AArch64 目標

日期：2026-10-13　來源：Phoronix：Asterinas 0.19.0 Brings Up X.Org & Other Improvements To This Rust-Written OS（10-13）

Rust 編寫的記憶體安全核心 Asterinas 釋出 0.19.0：首次引入初始 DRM 子系統，在 modesetting 驅動與 Mesa LLVMpipe 之上跑通 X.Org 圖形棧，替代此前的傳統幀緩衝體驗；新增 AArch64 架構支援，與既有的 x86_64、RISC-V、LoongArch64 目標並列；同時推進安全容器、Rust 原生裝置模型、自舉（self-hosting）與 AI 程式碼審查模式。該專案以 Linux 軟體相容與記憶體安全為賣點，是 RISC-V 平臺系統軟體多樣化的觀察樣本。

1.2 openRuyi：韌體線釋出「Ruyi Firmware 20261013」，K3 Pico-ITX 全套 UEFI 支援

日期：2026-10-13　來源：ruyifirmware Release 20261013（10-13）、edk2-ruyi 提交記錄（10-13）、openRuyi 提交記錄（10-13）

openRuyi 專案韌體線（ruyifirmware／edk2-ruyi）視窗內集中合入進迭時空 K3 Pico-ITX 平臺支援：GOP 圖形輸出與 EDID 模式、PCI 選項 ROM、RTL8127 有線網絡卡驅動、引導選擇與控制檯熱鍵策略、Fastboot 更新校驗等；併發布 「Ruyi Firmware 20261013」，提供含 x64 模擬（x64emu）與不含兩個韌體變體（x64emu 下已驗證 AMD Radeon RX 6400）。主倉同步進行 Go 生態軟體包（OpenTelemetry 採集器等）SPECS 更新；kiwi-image 新增 riscv64 映象的 GitHub Action 構建指令碼。openRuyi 官網新聞頁暫無新版本釋出（最新仍為 2026.09 版本）。

1.3 riscv.org 部落格：ISA Explorer 學員實踐——ISA 配置構建器與擴充套件沙盒

日期：2026-10-13　來源：RISC-V International：My RISC-V Mentorship: The Problems Nobody Assigned Me（10-13）

riscv.org 刊出 LFX 導師計劃學員 Rohit Sharma（印度 JECRC 大學）的實踐總結：在 RISC-V ISA Explorer 專案中，除完成既定里程碑外，自主設計並上線兩個工具——ISA Configuration Builder（按需勾選核心配置、自動解析依賴、生成工具鏈可用的配置串並校驗衝突）與 Extension Sandbox（新指令設計時即時檢查與既有編碼的衝突）；同步管線重寫為三遍路由，使 1,867 條指令按 83 個 ISA 子集自動歸類。工具用於降低自研核配置與自定義擴充套件的出錯成本，是社群教育與工具鏈建設的樣例。

香山主線（kunminghu-v3）合入儲存佇列前遞舊儲存資料修復（#6693）；驗證與模擬基礎設施多點開花：difftest 新增 MCSim 時序後端（與 DRAMSim3 並列）、mcsr/mcfg 的 delta 編碼、面向 FPGA 的 CRC-64 儲存佇列雜湊校驗及 PLDM 流程修復；NEMU 加速 AME 矩陣雜湊計算、引入 CRC-64 儲存佇列雜湊校驗與重複儲存日誌恢復修復；GEM5 增加 Zimop 指令支援（含 RV64 迴歸）與 TRACERTL/NEMU 軌跡格式支援。昆明湖平臺在正確性驗證基建上的推進本視窗較為顯著。

3.4 樂鑫：安全自檢庫 ESP-BIST 釋出 v1.1.0，工具鏈補齊 S31 支援

四、具身智慧與機器人專章

4.1 燕心科技：把「符號＋行為＋連線」融入 RISC-V 晶片，做即插即用機器人大腦

日期：2026-10-13　來源：36 氪：大模型能寫詩，卻走不出工廠圍欄——燕心科技把「符號＋行為＋連線」三條路線融進 RISC-V 晶片（10-13，Google News 連結）、英文版（36Kr Europe 同文）

4.2 視窗觀察：具身智慧側的三條線索

本視窗具身智慧與機器人側呈”兩端升溫、組合交付”側影：其一，國際新玩家以差異化架構入局——Ubitium 用可重配置 RISC-V 陣列統一感知、推理與實時控制，獲 1400 萬美元種子融資（見 2.1）；其二，國內早期創業把”機器人大腦”押注在 RISC-V 晶片化封裝（燕心科技，見 4.1）；其三，成熟廠商側，進迭時空 K3 持續向機器人與邊緣場景輸送”晶片—模組—軟體棧”完整鏈路（K3 COM-E 模組與 llama.cpp／模型庫軟體線，見 3.2），其機器人專項組織 spacemit-robotics 視窗內無新推送。三條線索共同指向：RISC-V 在具身智慧的競爭正從”單點晶片”轉向”晶片＋大腦軟體＋場景封裝”的組合交付。

五、總結與趨勢觀察

  • 資本與產品雙線共振：藍芯算力近 20 億元 B 輪與 Ubitium 1400 萬美元種子輪同期落地，高效能／物理 AI 方向的 RISC-V 晶片成為全球資本集中加註的賽道；國內 RISC-V 伺服器晶片進入”量產驗證”階段（LX500＋聯想整機量產＋運營商作業系統適配）。
  • 產業日程臨近：第六屆 RISC-V 中國峰會 10 月 18-20 日深圳舉行，達摩院玄鐵、奕斯偉、藍芯、進迭等集中亮相；疊加 Ubuntu 26.10（10 月 15 日釋出）首次提供官方 RISC-V 桌面映象，下週為觀察視窗。
  • 國內工程側高密度輸出：進迭時空 llama.cpp v0.2.2 與 Agent 軟體線集中建倉、K3 全國產化 COM-E 模組推出；香山驗證鏈（MCSim 時序後端、delta 編碼、CRC-64 儲存校驗）成體系推進；樂鑫安全自檢庫 v1.1.0 覆蓋全部 RISC-V SoC 產品線。
  • 開源系統軟體靜水深流：Asterinas 0.19（DRM／X.Org 初支援、AArch64 目標）與 openRuyi 韌體線（K3 Pico-ITX 支援釋出）顯示 RISC-V 平臺軟體在桌面與韌體兩端的持續補強。
  • 侷限說明：燕心科技資訊為單一媒體報道、公司仍處早期；藍芯融資規模以中文媒體與 DIGITIMES 口徑為準（近 20 億元人民幣／約 2.99 億美元）；本期會員官網巡檢 67 家抓取失敗（國內站點居多），相關站點動態可能存在遺漏。
