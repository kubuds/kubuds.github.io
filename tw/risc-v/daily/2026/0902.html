一、開源社群與軟體生態

1.1 NVIDIA 公佈 CUDA 移植 RISC-V 主機 CPU 的明確要求，SiFive 合作演示在即

日期：2026-08-23（Hot Chips 2026 教程演講）/ 09-01（ServeTheHome 與 Chips and Cheese 深度報道）　來源：ServeTheHome、Chips and Cheese（Chester Lam）、Hot Chips 2026 議程（NVIDIA 官方）

NVIDIA 在 Hot Chips 2026（斯坦福，08-23 至 08-25）週日的教程場次上，由 Frans Sijstermans 做了題為 “RISC-V Profile and Platform for Interoperability With NVIDIA GPUs” 的演講，系統公開了把 CUDA 擴充套件到 RISC-V 主機 CPU 的路線與要求清單。要點：

  • CUDA 現狀：自 2006 年以來的平行計算平臺，主機側目前僅支援 x86-64 與 aarch64；應用在 CPU 與 GPU 模組間切分，主機軟體棧複雜且異構。
  • 對 RISC-V 主機 CPU 的硬性要求：RVA23 profile；遵循 RISC-V server SoC 與 server platform 規範（含 RAS、專用安全處理器等基線）；ACPI（UEFI Forum 2025-05 在 ACPI 6.6 中加入 RISC-V，RISC-V BRS 引導與執行時服務規範 2025-08 落地）；PCIe 硬體級 I/O 一致性；PCIe peer-to-peer 通訊。NVIDIA 強調軟體二進位制相容是核心目標，避免”最低公分母”問題（以向量擴充套件的謂詞支援為例）。
  • NVLink Fusion 側：自定義 CPU（可以是 RISC-V）經 NVLink C2C（約 88 條 PCIe lane、CHI 一致性）接入 NVIDIA AI 平臺，額外要求 DOCA、NCCL 軟體棧與 NVIDIA 深度合作。SiFive 被點名是 RISC-V 側 NVLink Fusion CPU 合作伙伴，並計劃在 Hot Chips 現場演示一臺執行 CUDA 的高核數伺服器系統。
  • 點評：ServeTheHome 認為 RISC-V 正成為伺服器 CPU 市場 x86、Arm 之外真正的第三選項，但距大規模部署仍約兩代；Chips and Cheese 則提醒，現有 RISC-V 消費級硬體幾乎全部不滿足要求（ACPI 是最大短板），短期內 CUDA on RISC-V 只會出現在企業級伺服器平臺。這是視窗內對 RISC-V 軟體生態最具分量的商業背書訊號。

1.2 ab-riscv-interpreter 0.2：透過 RISC-V ACT 認證測試的 Rust 編譯期直譯器

日期：2026-08-31（部落格釋出）/ 09-01（Hacker News 熱帖）　來源：Project Abundance 部落格、Hacker News、crates.io

Project Abundance 釋出 ab-riscv-interpreter 與 ab-riscv-primitives 0.2 版本。特性：完全模組化與泛型化、panic-free、no_std 且零分配、可作 const fn 在編譯期執行、嚴格按 RISC-V 規範實現（面向區塊鏈用途）、透過 RISC-V Architectural Certification Tests（ACT）架構認證測試。解碼器獨立成 crate 可單獨使用；指令執行程式碼由宏生成（單個實現展開約 1900 行）；效能 CoreMark 約 1600（緊湊 match 迴圈）/ 2950（indirect threading）。代價是依賴約 30 個 nightly Rust 特性（const 泛型、保證尾呼叫等）。作者稱擴充套件可泛化到任意 RISC-V 類 ISA（如 Parity 的 PolkaVM）。面向區塊鏈/形式化驗證場景的 RISC-V 軟體棧又添一個嚴格實現選項。

1.3 Raven-RiscV：RV32IMF 彙編學習模擬器與 IDE 獲社群關注

日期：2026-09-02（視窗內 push）　來源：GitHub Gaok1/Raven-RiscV

Rust 編寫的 RISC-V 教學模擬器 Raven-RiscV 在視窗內更新（09-02 00:01 UTC）並保持社群熱度（111 stars）：支援 RV32IMF、逐步偵錯程式、快取與流水線視覺化，定位是”學彙編的模擬器 + IDE”。倉庫建立於 2025-03，近期因功能完善進入 RISC-V 主題倉庫熱門區間。教育類工具持續填補 RISC-V 彙編入門生態，與課程/競賽場景契合。

二、產品與生態動態

2.1 高通 Dragonwing Q-2390 / IQ-2390：ARM 主核 + RISC-V 實時核執行 Zephyr

日期：2026-09-01　來源：CNX Software、Qualcomm 新聞稿

高通釋出 Dragonwing Q2 系列 AIoT 處理器：Q-2390（商用/消費：零售、智慧家居、智慧顯示、企業邊緣裝置）與 IQ-2390（工業：工業自動化、機器視覺、樓宇管理、能源系統）。主計算核為四核 Cortex-A78/A55（ARM），支援 Android、Yocto Linux、Ubuntu；部分型號帶 RISC-V 實時核，該核支援 Zephyr RTOS。SoM 將在 IFA 2026 展示，評估套件預計 2027 年 Q1 提供。這是高通 AIoT 產品線延續”ARM 應用核 + RISC-V 實時/管理協核”組合的又一例項，RISC-V 在邊緣裝置中的角色繼續坐實；但需注意主計算仍由 ARM 承擔。

2.2 兆易創新與 Rutronik 簽約：GD32（含 RISC-V 架構 MCU）拓展 EMEA 與東南亞分銷

日期：2026-08-31（公告）/ 09-01（Evertiq、Bisinfotech 報道）　來源：GigaDevice 官網新聞、Evertiq、Bisinfotech

兆易創新（GigaDevice）與德國老牌分銷商 Rutronik Elektronische Bauelemente 達成戰略特許（franchise）合作，覆蓋 EMEA 與東南亞（含印度）。合作核心是 GD32 系列微控制器——官方明確該產品家族基於 Arm Cortex-M 與 RISC-V 雙架構，涵蓋入門級到高效能實時應用。目標市場：工業、汽車、能源、通訊、消費電子與 IoT。Rutronik 2025 財年營收約 10 億歐元、服務超 4 萬客戶、全球 80+ 辦公室，是兆易創新海外渠道的重要補充。國產 RISC-V MCU 藉助歐洲分銷體系出海的又一步。

三、國內團隊動態與深挖

3.1 進迭時空：K3 UEFI 韌體獲外部開發者修復，P3 資料手冊上線，AI 文件英文化

日期：2026-09-01　來源：spacemit-com/edk2-platforms commits、spacemit-com/docs-chip commits、spacemit-com/docs-ai

視窗內進迭時空（spacemit-com）三個倉庫有實質更新：

  • edk2-platforms（UEFI 韌體）：合併外部貢獻者 vhaudiquet 的兩個 K3 修復 PR——韌體網路問題與啟動進度碼（progress codes）問題。這是社群外部開發者直接參與 K3 UEFI 韌體開發的首批訊號之一，說明 K3 平臺韌體生態開始對外部貢獻開放。
  • docs-chip：新增 P3 晶片資料手冊（含 BUCK DVS 保留位修正），並持續推進資料手冊圖表英文翻譯，海外開發者可獲取的英文資料在補齊。
  • docs-ai：同步英文版解決方案文件。

結合昨日 RevyOS 為 K1/K3 新增核心配置（linuxboot、K3 DC/UFS），進迭 K3 平臺從韌體、文件到發行版核心的軟體棧正在整體推進。

3.2 算能：sophon-tools 收尾 CV84X6 memory_edit 修復

算能 sophon-tools 合併一筆修復（zetao.zhang）：CV84X6 -p 列印上限與校驗不一致（多報 2M）（#181），屬於 v26.08.31 發版批次的收尾工作。無釋出級新動態。

3.3 矽速：NanoKVM 最佳化 H264 影片流併發

日期：2026-09-01　來源：sipeed/NanoKVM commits

矽速 NanoKVM（RISC-V 架構 IP-KVM）合併兩筆提交：隔離 H264 訂閱者、共享 H264 採集幀，改善多客戶端併發觀看時的影片流效能與記憶體佔用。小型維護項。

五、總結與趨勢觀察

  1. CUDA 官方路線圖指向 RISC-V 主機 CPU：NVIDIA 在 Hot Chips 2026 首次公開移植要求清單（RVA23、伺服器 SoC/平臺規範、ACPI、PCIe 一致性、P2P），並點名 SiFive 為 NVLink Fusion 的 RISC-V 合作方、計劃現場演示跑 CUDA 的系統。這是 RISC-V 伺服器生態迄今最強的商業背書之一；但 ACPI 等硬門檻意味著達標硬體仍需數年，短期只會在企業級伺服器出現。
  2. RISC-V 實時核繼續滲透主流 AIoT SoC：高通 Dragonwing Q2 系列”ARM 應用核 + RISC-V 實時核（Zephyr）”再證這一組合已成為邊緣 AI 晶片主流做法。
  3. 國產 RISC-V MCU 出海渠道加碼：兆易創新 GD32（含 RISC-V 架構）借 Rutronik 渠道拓展 EMEA 與東南亞，覆蓋工業/汽車/能源等市場。
  4. 國內團隊處常規迭代期：進迭 K3 UEFI 韌體獲外部貢獻者修復、P3 資料手冊上線、AI 文件英文化是視窗內最實質進展；算能、矽速為維護性提交；七家核查組織中無釋出級新品。
  5. 開源工具鏈縱深拓寬：Rust 編譯期 RISC-V 直譯器透過 ACT 認證測試、RV32IMF 教學模擬器獲星，教育與驗證類軟體生態繼續補位。
  6. 侷限說明：Google News 中文源對國內團隊零命中，國內部分依賴 GitHub 提交核查；Qualcomm 型號級 RISC-V 實時核細節以 CNX 轉述為準；Hot Chips 演講於 08-23 舉行，本期為深度報道補錄（ServeTheHome 09-01 發文）。
