今日重點：達摩院玄鐵 C950 無獨立加速器跑通 27B 大模型，成果亮相 RISC-V 國際基金會官網

日期：2026-10-15　來源：riscv.org：V Questions with… DAMO Academy’s Dr. Jianyi Meng（10-15）

RISC-V 國際基金會官網「V Questions」專欄刊出對達摩院玄鐵（XuanTie）首席科學家、RISC-V 中國峰會 2026 副主席孟建熠的專訪，系統介紹玄鐵近期標誌性工作，併為 10-18 深圳峰會預熱。要點：

  • 里程碑資料：玄鐵團隊在 64 核 C950 目標配置上原生跑通 Qwen3.8-27B（270 億引數），無需獨立 GPU／NPU，解碼速度超過 30 tokens／秒（約合 20–22 詞／秒，達到自然實時對話水平）；該負載需要約 400 GB／s 的記憶體資料搬運能力，訪談強調「量化、矩陣指令、片上記憶體、頻寬與運算元最佳化必須作為單一系統協同設計」。
  • C950 與 AME：C950 為伺服器級 64 位超標量處理器，以 RVA23 檔案（含 RVV 1.0） 為通用計算基線；玄鐵自研矩陣擴充套件經矽驗證後，與 Qualcomm、IBM、VRULL、ISCAS、BOSC 等成員共同發起 AME（Attached Matrix Extension）任務組，正推動規範走向正式批准落地。
  • 設計取捨：AME 採用獨立 tile 暫存器而非複用向量暫存器——避免矩陣負載擠佔 RVV 暫存器堆、減少溢位與快取擾動，並原生支援混合精度累加（INT4／INT8→INT32，FP4／FP8／FP16／BF16→FP32）；矩陣狀態按需啟用，僅在必要時儲存／恢復。
  • 生態呼籲：孟建熠提出三方面期待——高效能資料中心軟體棧持續補齊（Java 執行時適配成果已回饋社群）、完整 AI 軟體鏈（最佳化運算元庫、更新編譯器、RISC-V 作為 xPU 的完整棧）、以及藉助 ISA 開放性探索新的擴充套件與計算正規化。

3.4 進迭時空：Agent 能力分發基建落地——APM、Agent Hub 與 Bianbu Skills 映象同日有實質內容

日期：2026-10-15　來源：spacemit-com/agent-power-manager、spacemit-com/bibit-agenthub-plugin、spacemit-com/bianbu-skill、model-zoo-vision 提交記錄（10-15）

10-13 集中建倉的「Agent 系統軟體」倉庫群在本視窗落地首批實質內容，指向端側 Agent 的能力分發基礎設施：

  • APM（agent-power-manager）：Go 編寫的命令列工具，把 Skill／Plugin／MCP／Expert 四類「Power」的檢索、安裝、升級、解除安裝與提交收斂到同一套命令；自 Agent Power Cloud（APC）同步後設資料、按版本安裝、事務可恢復，支援 bibit 等目標 Agent，Apache-2.0 開源。
  • Bibit Agent Hub（bibit-agenthub-plugin）：Bibit 內建「能力中心」——前端外掛（TypeScript／React）＋純標準庫 Go CLI Provider；提供已安裝清單、APC 全量市場瀏覽、一鍵升級與自定義資源上傳，支援 riscv64 構建。
  • Bianbu Skills（bianbu-skill）：APC 公開發布 Skill 的只讀映象倉庫，首期收錄 11 個 Skill（K3 媒體流水線、VPU／CoreMark 基準、RISC-V 移植助手、文件轉 Markdown、離線 HTML 應用生成等），按 APC 目錄快照原樣歸檔。
  • 配套更新：model-zoo-vision 兩筆修復（OC-SORT 卡爾曼跟蹤與記憶體安全 #100、視覺介面契約與數值安全 #101）；ai-sdk 二度更新 vision 子模組；llama.cpp（mtmd-backend）同步上游（PR #46）並修復 SMT 路徑；lxqt-schedule 引入 LXQt 日程管理與桌面提醒。

上期日報所述 Bianbu AgentOS 元件集中開源之後，進迭時空補齊的正是「能力分發與版本治理」這塊拼圖。

3.5 矽速：SLogic 增瀏覽器內韌體升級；MaixPy 合入三筆

日期：2026-10-15　來源：sipeed/SLogic 提交記錄（10-15）、sipeed/MaixPy 提交記錄（10-15）

矽速邏輯分析儀軟體 SLogic 繼續高頻迭代：視窗內新增 Web 韌體升級（瀏覽器內為 SLogic16U3／32U3 推送 OTA），底層庫改用 800 MHz 時鐘基準並修復 ngscope ADC 相關問題（ALL-LOGIC 同批落庫）。MaixPy 主線合入 3 筆（RVV 文件導航與示例完善等）。自 SLogic v2.3.0（10-14）釋出後，工具鏈與韌體升級體驗仍在快速打磨。

四、具身智慧與機器人專章

4.1 進迭時空 ROS2 模擬：人形機器人 humanoid_mujoco 增加 RGBD 模擬啟動命令

日期：2026-10-15　來源：ros2_simulation 提交記錄（10-15）

spacemit-robotics 組織視窗內唯一推送落在 ros2_simulation：為 humanoid_mujoco 包（人形機器人 RL 與 MuJoCo 同例項模擬，含「靈龍」LingLong 專用配置）新增 RGBD 模擬啟動命令 hmi_runtime（配合 3D LiDAR／RGBD 相機、點雲與 TF 釋出、RTAB-Map／Nav2 接入）。該倉庫的構建目標為 k3-com260-kit-humanoid-linglong——「人形機器人模擬訓練（MuJoCo＋RL）→ K3 機器人套件」的鏈路在軟體側進一步補齊。結合本視窗 Agent 能力分發基建的落地（3.4），進迭時空「晶片—AgentOS—模擬／RL 工具鏈」三層組合的輪廓更加清晰；機器人側目前仍以模擬與運控為主，視窗內無新硬體釋出。

五、總結與趨勢觀察

  • 玄鐵高效能敘事走向國際渠道：C950 單機跑 27B 大模型成果經 RISC-V 國際基金會官網專訪傳播（疊加 10-22 北京研討會與 10-20 峰會 AME 研討會），為峰會周預熱；AME 從「自研矩陣擴充套件」升級為「帶動 Qualcomm／IBM 等共同推進的標準提案」，是最值得跟蹤的線索。
  • 開源發行版與韌體「拼平臺覆蓋」：openRuyi 韌體連續日更（K3 線 8 筆＋UEFI 6 筆）、RevyOS 7.3 核心批次收攏 K3／EIC7700 等平臺配置——RISC-V 發行版的競爭焦點正從「能啟動」轉向「平臺廣度＋UEFI 體驗＋安全維護」。
  • 端側 Agent 基建從元件走向分發：進迭時空 APM／Agent Hub／Skills 映象形成「釋出—檢索—安裝—版本治理」閉環，RISC-V 端側 Agent 生態開始出現配套工程化工具鏈。
  • 三條細分產品線同視窗上新：先楫 HPM5100（混合訊號 MCU 量產）、香橙派 O1（邊緣 AI SBC）、樂鑫 ESP32-S31 Linux BSP 迭代＋社群 v0.3.1——MCU、AI 盒子、Linux-on-MCU 三個方向各有新供給。
  • 峰會周開幕在即：RVSC2026 週日（10-18）於深圳開幕，下期重點觀察開幕式、主論壇與各專題分論壇首日內容。
  • 侷限說明：openKylin 條目依據 10-15 報道（會議為 10-07~09），細節以官方後續材料為準；社群 ESP32-S31 Linux 專案屬愛好者專案，成熟度以其釋出說明為準；部分倉庫視窗內僅有分支級推送，已在信源核查表註明。
