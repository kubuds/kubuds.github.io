1.1 開放原子紫金專區 OPC 孵化行動計劃啟動，RISC-V 開源晶片產業創新中心落地蘇州試點

日期：2026-08-28　來源：人民網江蘇頻道、新華報業網、名城蘇州

8 月 28 日，以”開源聚勢·智慧共生”為主題的 2026 開源創新生態大會在蘇州舉辦，正式釋出開放原子紫金專區 OPC 孵化行動計劃：以 JSopen 為核心數字基座，依託”蘇州吳中+南京雨花”雙中心聯動，打造全國首個人工智慧 OPC 專業開源孵化社群。現場完成 OPC 專案孵化中心揭牌與 16 家首批入駐專案簽約（覆蓋 AI 大模型、具身智慧、醫療科技）；啟動紫金開源 OPC 創新投資者聯盟並揭牌江蘇雲途開元創業投資基金（規劃總規模不低於 10 億元的 OPC 產業基金矩陣，聯合南京雨花臺區設立 3000 萬元 AI 微種子基金）。與 RISC-V 直接相關的是：RISC-V 開源晶片產業創新中心作為五大省級開源生態創新平臺蘇州試點之一正式啟動，另有開源鴻蒙應用創新中心、紫金開源 AI 賦能中心等同步落地；科沃斯八界開源智創空間、博雲 BoHub 社群、三所高校開源創新實驗室揭牌，第八屆全球校園人工智慧演算法精英大賽（AI+開源）同步啟動。該事件為 08-28 當日落地、08-30 早間被多家媒體轉載，屬江蘇開源產業政策與 RISC-V 生態平臺建設的重要訊號。

1.2 OpenTitan 開源安全晶片獲西語科技媒體專題報道，生產部署背景回顧

日期：2026-08-29　來源：Desde Linux、lowRISC OpenTitan News、Google Open Source Blog

西語科技媒體 Desde Linux 於 08-29 發表 Google OpenTitan 專題文章，介紹這一全球最活躍的開源矽片專案（基於 RISC-V Ibex 核心的開源安全信任根 RoT 晶片）。該文屬科普向，但背景資訊值得記錄：OpenTitan 已於 2025-02 由 Nuvoton 量產並在 Chromebook 中首次生產部署，是首個支援後量子密碼（SLH-DSA PQC 安全啟動）的開源 RoT；2026 年內 Real Intent、Cadence 先後以工具合作伙伴身份加入，強化開源矽片籤核與驗證鏈路，社群總提交量超 3.3 萬筆。視窗內無 OpenTitan 新版本/新事件，作為開源矽片生態持續滲透的參考收錄。

2.1 賽昉昉·天樞-100 正式交付：國內率先達到可交付狀態的伺服器級 RISC-V CPU IP

日期：2026-08-27（補收錄）　來源：新浪科技/快科技、騰訊新聞、賽昉科技官網

快科技 8 月 27 日訊息：賽昉科技宣佈伺服器級 RISC-V HPC CPU 核心設計昉·天樞-100（Dubhe-100）正式交付——這是國內率先達到可交付狀態的伺服器級 RISC-V CPU IP，已獲客戶採用並進入伺服器晶片開發階段，填補國產 RISC-V 高效能運算 IP 空白。核心規格：效能對標 Arm Cortex-A78，整數 IPC 達 SPECint2006 15/GHz；深度亂序執行、15 級流水線、6 發射寬度、256 條指令亂序視窗；嚴格遵循 RVA23 規範，率先實現業界領先的亂序執行向量單元（RVV）；支援單核/雙核/四核叢集與 TileLink、AXI、ACE、CHI 互連，可對接自研 NoC IP 昉·星路-700（StarNoC-700）擴充套件至 256 核；已完成 Type 1/Type 2 Hypervisor 完整支援，Linux 與 KVM 虛擬化方案穩定執行；同步推出 AIA 高階中斷架構與 IOMMU 等伺服器級基礎設施 IP。商用落地方面，希奧端計算（LECARC）已確定採用天樞-100 開發面向智慧邊緣的新一代伺服器 CPU（雙方 06-29 官宣合作）。說明：天樞-100 首發（08-19）本報已收錄；”正式交付”為其後續里程碑，因前兩日 gnews 賽昉查詢被 301536.SZ 星宸科技半年報誤標汙染而漏檢，今日補收錄。

3.1 芯來科技新三板創新層掛牌（875127）：國內 RISC-V CPU IP 龍頭登陸資本市場

日期：2026-08-28　來源：同壁財經/新浪財經、同花順、億歐資料/網易

芯來智融半導體科技（上海）股份有限公司（證券簡稱：芯來科技，程式碼 875127）掛牌申請獲批，於 8 月 28 日在新三板創新層正式掛牌，主辦券商招商證券。該公司成立於 2018 年，創始人胡振波（國內第一顆開源 RISC-V 處理器核蜂鳥 E203 作者），是國內首批商用 RISC-V CPU IP 供應商：產品覆蓋 N 系列低功耗嵌入式、UX 系列高能效、NA 系列車規（全球首個 ISO 26262 ASIL-D 認證 RISC-V CPU IP）、NI 系列 AI 計算（全球較早支援 VLEN 1024 位元）；授權客戶超 300 家（含兆易創新、恆玄科技、晶晨、裕太微等上市公司），按 SHD Group 2026-03 報告以出貨量計居全球 RISC-V CPU IP 前四。財務與融資：2024/2025 營收 7,399.87 萬元/8,294.11 萬元，剔除股份支付影響後虧損逐期收窄（-1722.73 萬/-958.63 萬/-377.56 萬元），2025 經營性現金流轉正（792.03 萬元）；掛牌同時定向發行約 8.21 萬股、募資約 4,200 萬元（認購方為黑龍江振興先進製造產業基金、中芯熙誠北京數字科技基金），募資投向 RISC-V 晶片定製平臺研發。股東陣容含小米長江產業基金、君聯資本、中電科基金、芯原股份等（前十大股東合計持股 73.01%）。背景：2025-08 芯原股份曾籌劃收購芯來科技 97% 股權，同年 12 月宣佈終止（標的訴求與市場環境、政策要求存在偏差），芯來隨後轉向獨立掛牌；本次掛牌為公司從 IP 授權向晶片定製、Chiplet 及伺服器 CPU 四階段戰略升級提供資金通道。同日億歐資料將其歸入”製造領域投融資日報”上市類目（估算融資總額約 3 億元，含未披露口徑）。

3.2 算能 sophon-tools 發版前安全加固，SophLiteOS v2.2.6 等多項修復合入

日期：2026-08-29　來源：sophgo/sophon-tools 提交記錄

算能視窗內 5 筆提交（sophgo/sophon-tools，均為 08-29 晚間合入），主題為發版前安全檢查與加固：其一，/agent/ws 服務同源校驗與限流加固、CV84X2 裝置樹（dts）兜底查詢（#160）；其二，P1/P2 級安全加固批次——註冊流程拒絕臨時 token、防火牆保護埠守衛收緊、軟體包名/引號/退出碼/jwt/超時/指標 token 等細節修復（#161）；其三，SophLiteOS 的 agent 雙回覆問題修復——history 按 kind 歸一化去重，隨 v2.2.6 釋出（#157）；其四，OTA 預檢攔截殘缺刷機包、防止 OTA 死迴圈（#158）；其五，psocbak 備份排除外接資料盤掛載點並同步 ota_update md5（#159）。sophon-tools 是算能 SophOS/刷機與 OTA 工具鏈，本批提交屬釋出前夕的系統性安全與穩定性收斂，為 CV84X 系列（昨日已報官方規格落地）量產支撐工具的工程化補強。

3.3 香山：Ftq 預取效能調優、KunminghuV2 CI 選項與 Deterload 工具 H/V 擴充套件支援

日期：2026-08-29　來源：OpenXiangShan/XiangShan、OpenXiangShan/Deterload

OpenXiangShan 組織視窗內 4 筆提交：XiangShan 主倉庫兩筆——perf(Ftq) 將分支預取回退距離（BpRunAheadDistance）設為 icache way 查詢深度（#6425，08-29 17:23 北京時間），ci(perf) 為 KunminghuV2 配置新增效能迴歸觸發選項（#6437）；香山實驗室 Deterload 工具兩筆——新增帶 H/V 擴充套件的 hello 示例、builders 增加 enableV/enableH 引數（08-29 21:40 前後），使確定性負載生成工具鏈可覆蓋虛擬化與向量擴充套件驗證場景。整體屬例行效能調優與工具鏈能力擴充套件，規模不大但方向明確：KunminghuV2 配置的 CI 效能迴歸體系與 Deterload 的 H/V 支援，均服務於香山下一代核的驗證與調優閉環。

進迭時空 docs-chip 倉庫新增 P3 電源管理晶片（PMIC）資料手冊文件（中英雙語，08-29 19:44 北京時間），延續其硬體文件工程化沉澱（前日已報 AVL 文件化工作）。Revyos 組織 firmware-sg204x 倉庫兩筆提交：更新 SG2044 平臺的 fsbl.bin 引導韌體、EDK2 構建改用 Linux 交叉編譯器（08-30 凌晨），為 SG2044 平臺 UEFI 韌體鏈的常規迭代。兩團隊視窗內均為小步迭代，無架構級變化。

四、具身智慧與機器人專章

4.1 深開鴻釋出 M-Robots OS 3.0 Beta：開源鴻蒙機器人 OS 重心轉向群體智慧

日期：2026-08-29　來源：新浪科技/IT之家、深開鴻官網

在貴陽 2026 中國國際大資料產業博覽會上，深開鴻高階副總裁王皓正式釋出 M-Robots OS 3.0 Beta 版。M-Robots OS 是全國首個基於開源鴻蒙（OpenHarmony）的分散式異構多機協同機器人作業系統，3.0 Beta 將重心從”單機能力”轉向”群體智慧”，圍繞安全、實時、群體智慧、數字底座四大方向系統性升級：安全側構築”組網可信、接入可控、執行可防”立體防護。深開鴻 06-26 剛啟動 M-Robots 社群共建（首個開源鴻蒙機器人作業系統社群），並持續參與開源鴻蒙/RISC-V 生態賽事與硬體適配。本視窗 RISC-V 側無具身智慧硬體新品；該條作為開源鴻蒙機器人生態動態收錄——與昨日 Microduck（Hugging Face 生態雙足機器人）同屬”終端主控仍以 ARM/既有生態為主、RISC-V 在具身智慧領域以標準與治理層先行”格局的佐證，但開源鴻蒙機器人 OS 的硬體適配面已覆蓋 RISC-V 開發板，是值得跟蹤的潛在滲透通道。

4.2 全球具身智慧機器人產業博覽會落幕，3 天達成 39 億元成交意向

日期：2026-08-30　來源：搜狐轉載深圳特區報、觀察者

8 月 26-28 日在深圳舉辦的 2026 AGIC 深圳國際通用人工智慧產業博覽會暨 GERX 全球具身智慧機器人產業博覽會落幕，深圳特區報報道 3 天達成 39 億元成交意向，1200 件可直接訂貨的成熟展品、7000 餘名海外採購商參會；同期世界機器人大會（北京）後”機器人運動會”引發對具身智慧”加速度與剎車片”的討論（觀察者 08-29），行業關注點從技術演示轉向落地與可靠性。此類行業性進展為 RISC-V 具身智慧生態的外部環境指標：國內具身智慧產業正進入商業化放量階段，對端側晶片（含 RISC-V）的需求視窗持續開啟。

4.3 視窗內仍無 RISC-V 具身智慧硬體新品（格局延續）

日期：2026-08-29~08-30　來源：綜合 gnews/HN/GitHub 檢索

五、總結與趨勢觀察

  1. 資本市場里程碑：芯來科技（875127）8 月 28 日新三板創新層掛牌，成為國內首家登陸資本市場的商用 RISC-V CPU IP 企業（芯原 2025 年底終止併購後獨立掛牌），定向發行募資約 4,200 萬元投向 RISC-V 晶片定製平臺研發；疊加 8 月中旬傑理科技北交所上市，國產 RISC-V/晶片設計公司正加速對接多層次資本市場。

  3. 國內團隊工程化節奏：算能 sophon-tools 釋出前安全加固（SophLiteOS v2.2.6 等 5 筆）；香山推進 KunminghuV2 效能迴歸 CI 與 Deterload H/V 支援；進迭時空、Revyos 持續文件與韌體迭代——頭部團隊進入量產支撐與驗證工具鏈的深水區。
  4. 開源生態政策面：開放原子紫金專區 OPC 孵化行動計劃落地蘇州，RISC-V 開源晶片產業創新中心列入五大省級平臺試點，配套 10 億元級 OPC 產業基金矩陣與 3000 萬元 AI 微種子基金，開源晶片孵化獲得地方政策與資本雙重加持。
  5. 具身智慧：視窗內無 RISC-V 硬體新品；M-Robots OS 3.0 Beta（開源鴻蒙機器人 OS）轉向群體智慧，深圳具身智慧博覽會 3 天 39 億元成交意向——產業放量進行時，RISC-V 滲透仍以生態與中間層先行。
