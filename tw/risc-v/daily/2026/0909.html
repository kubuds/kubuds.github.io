1.1 香山：新向量後端合入 VIDiv 支援，儲存佇列修復與驗證倉庫批次推送（09-08）

日期：2026-09-08（15:47~19:30 北京時間批次）　來源：GitHub openxiangshan/XiangShan commits

香山開源高效能核（昆明湖）新向量後端功能補齊延續：09-08 批次合入 feat(VIDiv) “support VIDiv”，為向量執行通路新增整數除法指令支援；同批 fix(StoreQueue) 修復向量非活躍元素（vector inactive element）引發的意外 uncacheMove（#6474）。結合 09-06 整暫存器移動、09-07 vfma/vfmac 浮點乘加與 widen 指令批次，可判斷新向量後端正按”暫存器搬移—浮點乘加—整數除法—後續矩陣/規約運算”的順序快速鋪開指令面。同日 openxiangshan 組織下驗證與工具倉庫批次推送：NEMU（16:27）、XSAI（00:26 前後批次，16:26 UTC 推送）、difftest（15:27）、gsim、XSCache、XiangShan-Dashboard（23:42）、GEM5 等均有 pushed 訊號，屬配套驗證環境例行迭代，無版本釋出。香山工程側已進入向量子系統高頻開發期，建議持續跟蹤其新向量後端合入節奏。

1.2 開源硬體演示：Baochip-1x 無 FPU 片上完整訓練 GPT 登 HN（09-08）

日期：2026-09-08（HN 上榜 21:49 北京時間；原文 09-04）　來源：Hacker News、rvembedded 原文、GitHub AI-from-Scratch-in-C

嵌入式工程師 Armstrong Subero 釋出演示：在其 Rovari 教育平臺生態內，把自研”AI from Scratch in C”課程書稿中的 GPT 訓練程式完整移植到 bunnie Huang 設計的開源晶片 Baochip-1x（Dabao 評估板，Crowd Supply 出貨）上跑通。Baochip-1x 為 22nm”mostly open”RISC-V SoC：350 MHz RV32IMAC 核、無 FPU（無 F 擴充套件）、無 Flash、4 MB ReRAM 可執行程式碼 + 2 MB SRAM。演示模型為 27,680 引數的 decoder-only transformer（詞表 28、d_model 32、2 層、4 頭、context 64），含完整反向傳播、Adam 最佳化器與梯度檢查，整包連同軟浮點執行時程式碼僅 37 KB，訓練工作集約 1 MB（啟用快取佔 426 KB），片上從隨機權重訓練約 1 小時，權重最終寫入 ReRAM；每個浮點乘加均由軟體浮點模擬完成（每步約 460 萬次）。該文展示三點：無 FPU MCU 端側訓練”最小可行 GPT”可行、ReRAM 作為 22nm 上 Flash 替代品已實際商用、開源晶片配合開源教材可復現前沿概念。HN 09-08 晚間上榜（弱熱），內容教育價值較高，收錄為開源硬體與邊緣 AI 教學方向觀察。

二、產品與生態動態

2.1 美的聯合上海海思推”精衛 A²MCU”端側 AI 智慧冰箱：自研 RISC-V 核心落地白電（09-08）

日期：2026-09-08（快科技 18:48 披露）　來源：快科技、海思官網 Hi3066M 產品頁

海思 09-08 對外披露與美的聯合打造的端側 AI 智慧冰箱技術方案：搭載”精衛 A²MCU”系列晶片，以端側 AI 強化學習實現綜合節能 9.6%，按 6 月新實施的冰箱能效國標（500L 對開門 1 級能效日耗電從 0.92 度降至 0.55 度、准入門檻提升 30%~40%）測算，單臺一年可省約 19.3 度電。精衛 A²MCU 系海思圍繞空冰洗廚白電場景的系列化 MCU，基於自研 RISC-V 核心（海思官網在售 Hi3065H/Hi3066M 等型號：200 MHz 32 位 RISC-V + FPU、內建 eAI 引擎、512 KB Flash / 64 KB SRAM），eAI 引擎專為端側節能演算法運算元最佳化，使強化學習策略與冰箱主控同片實時執行；方案採用”端雲協同+純端側”雙軌（離線預訓練+線上自適應微調）與”AI 主控+PID 後備”雙軌保護。以 500 萬臺線上冰箱計，年減碳約 8.8 萬噸。意義：海思 RISC-V MCU+端側 AI 在頭部白電品牌旗艦能效場景規模化落地，是”RISC-V 進家電”從主控替換走向端側智慧化標杆案例，與 6 月新國標驅動的白電能效升級視窗形成共振。

三、國內團隊動態與深挖

3.1 上海交大 IPADS 主導 SPMP 記憶體保護擴充套件正式合入 RISC-V 國際標準，系國內首個完整主導的 ISA 特性（新聞 09-08，獲批 08-31）

日期：2026-09-08（文匯/上觀等集中報道；標準獲批 08-31）　來源：上觀新聞/文匯報、新浪財經轉載

國內主流媒體 09-08 集中報道一項標準里程碑：2026-08-31，由上海交通大學計算機學院 IPADS（並行與分散式系統研究所，陳海波教授團隊）主導推進的 SPMP（特權態實體記憶體保護）指令集標準正式透過 RISC-V 國際基金會董事會（BoD）審議，合入 RISC-V 指令集架構（ISA）標準。這是 RISC-V 國際基金會 2015 年成立以來首個由中國本土團隊從零起步、自主發起並完整主導的 ISA 標準特性：2019-09-23 團隊向社群提交架構初稿，歷經近 7 年（2500 余天）技術審查與方案修訂，獲批時工作組主席為 IPADS 博士楊璧丞。SPMP 為處理器提供特權態的實體記憶體保護與隔離能力，補齊 RISC-V 在安全體系架構上的短板。意義：這是國內機構首次在 RISC-V 擴充套件標準制定中掌握”從提案到定稿”的完整主導權，標誌中國團隊從被動跟隨規則轉向參與定義規則，為後續國產 RISC-V 安全特性（如各類隔離/機密計算擴充套件）進入國際標準積累正規化經驗。本報告此前未收錄該事件（獲批日 08-31 前後視窗遺漏），本次隨主流媒體報道補錄。

3.2 科技日報刊發西藏首個 RISC-V 千卡算力叢集報道：希姆計算 STCP950L 支撐 671B 級模型（報道 09-08，叢集 2026-04 交付）

日期：2026-09-08（科技日報刊發；叢集實際交付運營為 2026-04）　來源：科技日報/中國科技網、西藏自治區政府網（2026-04-08 首發）

科技日報 09-08 刊發：中國移動西藏公司攜手希姆計算在拉薩成功交付並正式運營西藏首個千卡 RISC-V 架構算力叢集，填補高原地區國產 RISC-V 高階算力空白，系中國移動西藏公司落實自治區”算力珠峰”戰略的實踐。叢集依託希姆計算自研 STCP950L NPU AI 算力卡搭建，從發貨、部署點亮到測試驗收僅 20 天，30 天試執行穩定，已支撐 70 億至 6710 億引數大模型的部署，全面適配批次推理、實時 AI 服務與大模型智慧體場景；重點服務智慧政務（提速”一網通辦”）、產業數字化（特色農業、文旅）與民生服務（遠端醫療、智慧教育）三大領域。需註明：經溯源，該叢集交付運營資訊最早由西藏日報於 2026-04-08 報道（本報告體系當時未收錄），本次系科技日報再刊發而進入視窗，屬於對已落地工程的權威媒體複述，核心增量是”超高原極端環境長期穩定執行”的驗證結論。意義：高海拔、低氣壓、大溫差環境對算力硬體穩定性要求嚴苛，千卡級國產 RISC-V AI 算力在此類特殊場景的規模化落地，為 RISC-V 進入智算基礎設施提供了極端環境實證。

3.3 綜合視窗觀察：達摩院玄鐵 sail CI 接入，sophgo/spacemit/sipeed 例行迭代（09-08）

國內團隊 GitHub 側週三前夜均為例行開發，無釋出級動態：達摩院玄鐵公開倉庫 damo-rv-priv-ats 於 09-08 11:29 合入 “add sail in github action”（#28），將 sail（RISC-V 形式化語義模擬器）接入 GitHub Actions，延續 09-07 新增 Hypervisor Za* 測試的驗證體系補強節奏，屬規範測試基建建設；算能（sophgo）zsbl 與 sophgo-edk2 分別於 14:19、20:20 前後推送，UEFI/引導工具鏈例行迭代；進迭時空（spacemit-com）docs-ai（19:13）、docs-chip（10:28）與 llama.cpp fork（11:14，上游同步性質）有推送，均為文件或同步更新；矽速（sipeed）maix_ax620e_sdk 及其 kernel/msp、MaixCDK 於 11:54~12:10 批次推送，圍繞 AX620E 的 SDK 例行演進。Nuclei-Software、eswincomputing、revyos 視窗內靜默。結論：國內團隊新聞側無新增量，實質動態以上述 GitHub 提交為主，明日進入 IICIE 展會視窗後預計轉熱。

四、具身智慧與機器人專章

4.1 視窗觀察：今日深圳 IICIE 開幕，RISC-V 產業生態創新大會與具身智慧產業大會今日下午開講（09-09）

日期：2026-09-09（今日開幕；本視窗截至 08:18 尚無開展首日即時報道）　來源：IICIE 會議一覽、IICIE 官方議程頁

昨日報告預告的深圳 IICIE（國際積體電路創新博覽會）於今日（09-09~11）在深圳國際會展中心（寶安）開幕，與 CIOE 中國光博會、elexcon 深圳國際電子展三展同期同地聯動，總展示面積 32 萬平方米、參展企業超 5000 家。RISC-V 相關議程集中今日下午：14 號館二樓 14C”2026 RISC-V 產業生態創新大會”與 15 號館館內會議室”2026 具身智慧產業大會——從算力到執行，構建具身智慧系統”同期開講；達摩院玄鐵、算能科技、進迭時空、中興微電子、北京君正等在官方參展名單，展區設”RISC-V 生態應用展示區”與 AI+特色展示區。昨日報告已預告”玄鐵/算能/進迭時空參展，今起進入國內 RISC-V x 具身動向兌現觀察視窗”；本視窗（截至今日 08:18）內尚無開展首日的現場報道與新品釋出資訊，大會成果將在明日報告重點跟進。

五、總結與趨勢觀察

本報告視窗為事件密度回暖前夜：新聞側出現一條國際標準里程碑與兩條算力落地報道，開源社群與國內團隊 GitHub 延續常規迭代，具身方向進入今日開幕的深圳展會兌現視窗。要點歸納如下：

其一，標準主導權實現”零的突破”。上海交大 IPADS 主導的 SPMP 記憶體保護擴充套件於 08-31 透過 RISC-V 國際基金會董事會審議合入 ISA 標準，是國內首個從提案到定稿完整主導的 ISA 特性（2019 年提交、近 7 年攻關），09-08 獲文匯/上觀等主流媒體集中報道。安全體系架構與”定義規則”話語權敘事同步升溫，預計將帶動更多國內安全/隔離類擴充套件提案加速走向國際標準。

其二，RISC-V 算力落地出現”高階算力+端側白電”兩極案例。希姆計算 STCP950L 千卡叢集在西藏超高原環境長期穩定執行（科技日報 09-08 再刊，支撐 671B 級模型），驗證 RISC-V 智算基礎設施的極端環境可靠性；海思精衛 A²MCU 以自研 RISC-V 核心+eAI 引擎進入美的冰箱端側節能場景（綜合節能 9.6%），借 6 月新國標視窗實現”RISC-V+端側 AI”在頭部白電的規模化落地。

其三，開源處理器工程節奏延續。香山新向量後端兩日連推 vfma/widen（09-07）與 VIDiv、StoreQueue 修復（09-08），向量子系統進入高頻功能補齊期；達摩院玄鐵 priv-ats 將 sail 形式化語義測試接入 CI，驗證體系持續強化；CVA6、OpenSBI 等海外開源核視窗內基本靜默，香山/玄鐵構成當前最活躍的開源側訊號源。

其四，事件視窗開啟。今日 IICIE 深圳開幕，RISC-V 產業生態創新大會與具身智慧產業大會今日下午舉行，達摩院玄鐵/算能/進迭時空集中參展，本週中段國內 RISC-V x 具身智慧動態進入密集釋出期，明日報告將重點跟進開展首日釋出與演講要點。
