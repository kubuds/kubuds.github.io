今日重點：進迭時空聯合香山釋出伺服器級 CPU V100，業內首顆完整符合 RISC-V 伺服器規範

日期：2026-10-19　來源：電子創新網：進迭時空釋出伺服器級 CPU V100（10-19）、深圳新聞網：進迭時空釋出伺服器級 CPU V100（10-19）、Phoronix：SpacemiT Announces The V100 Server-Class RISC-V Processor（10-19）、21 經濟網：首顆完整符合 RISC-V 伺服器規範的晶片釋出（10-19）

第六屆 RISC-V 中國峰會第二日（10-19），進迭時空（SpacemiT）與香山團隊聯合釋出伺服器級 CPU V100，並同步推出計算、智算、儲存三類伺服器整機。公司稱其為業內首顆完整符合 RISC-V 伺服器規範的通用計算晶片。

  • 規範覆蓋：把伺服器規範落到晶片、韌體與作業系統三層，覆蓋 RVA23、伺服器 SoC、伺服器平臺、啟動與執行時服務（BRS）、安全模型五項規範；其中 BRS 規範測試全項透過，支援 openEuler、openRuyi、openKylin、Debian、Ubuntu、Fedora、Red Hat、Rocky 等主流 Linux 發行版直接安裝、啟動與執行，不再需要為每顆晶片單獨定製系統。
  • 微架構：46 核混合設計——6 個香山昆明湖 V2R2 核 + 40 個自研 X100 核，最高主頻 2.4 GHz，雙路一致性互聯最高擴充套件至 92 核；單晶片 8 通道 DDR5-4800、52 條 PCIe 5.0 通道。工藝與功耗側（海外媒體口徑）為 12nm、120W TDP，並支援 UEFI、ACPI、SMBIOS。
  • 資料中心的必要件：支援 H 擴充套件、AIA 與 IOMMU，具備 CPU、記憶體、中斷與 I/O 的硬體虛擬化能力，虛擬化擴充套件已獲上游 Linux 原生支援、無需定製核心；片上整合硬體信任根並支援 RISC-V 原生 TEE；支援 RERI RAS 規範。面向雲端 Agent 應用提供輕量級虛擬機器方案，以接近容器的資源開銷取得虛擬機器級隔離。
  • 整機與生態：C2201 計算伺服器、G5201 智算伺服器、S5236 儲存伺服器；其中 G5201 支援 8 張全高全長雙寬加速卡，已驗證崑崙芯 M100 等國產加速卡，支援高速 RDMA 組網；配套主機板、韌體、BMC 管理與硬體參考設計對外開放。
  • 表態：創始人兼 CEO 陳志堅稱「V100 不僅是進迭時空從端到雲的重要一步，更代表 RISC-V 正在邁向真正可部署、可規模化應用的資料中心市場」。

一、開源社群與軟體生態

1.1 Linux 7.3 正式釋出：RISC-V 補齊 RVA23 識別、計數器委派與 KVM 擴充套件

日期：2026-10-18（媒體報道 10-19）　來源：Phoronix：Linux 7.3 Released（10-18）、Kernel Newbies：Linux 7.3 變更清單

Linux 7.3 於 10 月 18 日按期釋出。RISC-V 側本版落地的內容包括：hwprobe 暴露 RVA23U64 基礎行為，讓使用者態可以直接判斷機器是否符合 RVA23；新增計數器委派相關擴充套件支援（Smcdeleg／Ssccfg／Smcntrpmf）及 Ssqosid 與 CBQRI 的 resctrl 支援；KVM 增加 Svadu、Zicfiss、Zicfilp 的 FWFT 支援；改用 EFI 執行時服務完成關機與重啟；arm64 與 RISC-V 共同獲得 crashkernel CMA 預留支援；靜態計算 alternative 段邊界以修補相容 vDSO，並進一步移除 xip 支援。平臺側新增 StarFive JHB100 初始裝置樹與Canaan K230（64 位 RISC-V AI SoC）支援；此外補齊 Smcsrind／Sscsrind、Zicclsm、Ziccamoa、Ziccif、Ziccrse、Za64rs 等擴充套件的識別與列舉。對發行版而言，RVA23 的可探測性是從「靠 Kconfig 猜」轉向「執行時可判定」的關鍵一步。

1.2 香山：XSCache 合入耦合 L2 分 bank SRAM 與預取准入限流

日期：2026-10-19　來源：XSCache PR #36（10-19）、XiangShan PR #6738（10-19）、GEM5 PR #1241（10-19）

香山主倉（kunminghu-v3）視窗內 1 筆：#6738 提升 XSCache 子模組版本。快取側 XSCache #36 為實質性效能提交——把 CoupledL2 的 L2 SRAM 按 set 與 bank 拆分，並對預取准入（prefetch admission）做限流，指向末級快取頻寬爭用與預取汙染兩類問題。模擬側 GEM5（xs-dev）#1241 修正亂序模型：在 store 與 AMO 傳送失敗時跳過 load 流水線的 replay 標記，避免錯誤的重放記賬。參考模型 NEMU 與 difftest 主分支視窗內無新增（最近一次為 10-16 的 CRC 校驗開銷最佳化）。

1.3 openRuyi：dpdk 回移 RISC-V lpm 與 fib 查詢最佳化，spdk 升至 26.09

日期：2026-10-19　來源：openRuyi 主倉提交記錄（10-19）、openRuyi 官網新聞頁

openRuyi 主倉視窗內 15 筆提交，效能側兩筆最值得記錄：dpdk 回移 RISC-V 的 lpm 與 fib 查詢最佳化，直接作用於虛擬交換與路由轉發路徑；spdk 升至 26.09，跟進上游儲存棧版本。打包側繼續成組補 Rust 生態：新增 rust-brotli-7、brotli-decompressor-4、botan-0.10、alloc-stdlib-2、alloc-no-stdlib-2、winreg-0.52、sequoia-man-0.3、self-replace-1，並把 rust-regex 升至 1.13.1、regex-automata 升至 0.4.18、regex-syntax 升至 0.8.11；go-gopkg-h2non-gock 升級至 1.2.0 並清理重複提供者。同期組織內 lookout、kiwi-image、TakoPack 亦有推送。官網新聞頁最新版本仍為 2026.09（9 月 30 日釋出，本版改進 RVA23 支援、擴充雲與儲存軟體棧、升級 Go 1.27 構建環境），視窗內無新版本公告。

第六屆 RISC-V 中國峰會期間，中興微電子旗下礪睿微面向智算中心打造的高效能 RISC-V CPU 晶片珠峰200 首次對外展出。官方口徑稱其為行業首款面向智算中心場景的 RISC-V CPU 晶片，聚焦三類場景：Agent 叢集、推理超節點 Host、企業級智算混合推理；原生搭載 RISC-V AI 指令加速，並針對 KV Cache 與長上下文大模型推理做最佳化。硬體上整合 Matrix、Vector、壓縮、加密多類加速引擎，支援 DDR5、PCIe、CXL 高速互聯介面，可適配「RISC-V 原生 AI + GPU 加速卡」的 MoE 混合推理方案。詳細產品規格將於今年底正式釋出，本期僅確認方向與場景，效能資料尚未公佈。

2.3 超睿科技 UR-CP400 處理器核亮相：RVA23、8 發射亂序、SPECint 超 22 分每吉赫茲

日期：2026-10-19　來源：搜狐（90 說科技）：超睿科技亮相 2026 RISC-V 中國峰會（10-19）

超睿科技（UltraRISC）在峰會核心展區展示 UR 系列高效能 RISC-V 處理器核與基於 UR-DP1000 的多場景系統級方案。本代重點 UR-CP400：符合 RVA23 規範、支援 RVV 1.0，採用亂序 8 發射、14 級流水線微架構，在 FPGA 模擬配置下 SPECint_base2006 超過 22 分每吉赫茲；面向多層雲環境做了虛擬化增強，併為 Agentic AI 做針對性硬體最佳化，現場演示了 FPGA 原型系統。UR-CP400 的 IP 計劃於 2027 年第一季度交付。公司同時展示處理器核 IP、多核 CPU 晶片與 AI 邊緣、多節點叢集、虛擬化應用的分層產品佈局，CTO 蔣江在資料中心與高效能運算分論壇作技術演講。

4.1 Ubitium 完成 1400 萬美元種子輪：可重構 RISC-V 陣列面向物理 AI

日期：2026-10-13（中文媒體 10-19 報道）　來源：Ubitium 新聞稿（10-13）、Evertiq：Ubitium raises $14M（10-16）、至頂網：Ubitium 獲 1400 萬美元融資（10-19）

德國杜塞爾多夫初創公司 Ubitium 宣佈完成 1400 萬美元新種子輪，由 Ibex Investors 領投，OpenOcean 參與，老股東 KBC Focus Fund、Runa Capital、Inflection 跟投，累計種子輪融資 1800 萬美元。公司做的是可重構 RISC-V 陣列（CGRA 路線）：用一組可程式設計處理單元按軟體配置動態分配訊號處理、AI 推理與實時控制三類負載，以統一記憶體與標準 RISC-V 工具鏈替代「DSP + NPU + CPU」的多晶片堆疊，主打無人機、機器人、車輛與工業裝置的物理 AI 場景。首顆驗證晶片 UB108 採用三星 8nm、256 個處理單元，已演示三類計算在同一陣列上執行；首顆商用晶片 UB410 規劃 4096 個處理單元，評估樣片計劃 2027 年交付。該方向與國內「車規 + 具身」專用 SoC 路線互為對照：一方做專用化，一方做可重構通用化。

4.3 進迭時空機器人感知棧：平面重建在 VDEC 不可用時回退 CPU 影象解碼

日期：2026-10-19　來源：spacemit-robotics/perception PR #10（10-19）

spacemit-robotics 組織視窗內 1 筆推送：perception #10「planar 流程在 VDEC 不可用時回退到 CPU JPEG 解碼」。該倉庫承載機器人視覺的平面重建（planar）流程，此前數週連續調整特徵檢測引數作用域、ONNX Runtime 連結與模型下載健壯性，本期補上硬體影片解碼缺失時的降級路徑——對以 K3 等端側晶片為算力底座的機器人整機而言，屬於「沒有硬解碼也能跑起來」的可用性修補，而非效能最佳化。同組織其餘倉庫視窗內無推送。

五、總結與趨勢觀察

  • 伺服器規範從「文件」變成「產品」：V100 把 RVA23、伺服器 SoC、伺服器平臺、BRS 與安全模型五項規範一次性落到晶片、韌體與作業系統三層，且 BRS 測試全項透過、主流發行版可直接安裝。這意味著 RISC-V 伺服器開始擺脫「一芯一系統」的嵌入式慣性，向 x86 式的通用平臺模式靠攏——這是本期最具結構性的一步。
  • 開源核第一次進入商用伺服器晶片：V100 的 46 核裡有 6 個香山昆明湖 V2R2。開源高效能核不再只是學術與驗證物件，而是以 IP 形式進入可銷售的資料中心產品，香山「開源→產品」的路徑由此得到一次可核驗的樣本。
  • 智算中心成為新的競爭面：珠峰200 明確以 Agent 叢集、推理超節點 Host 與混合推理為場景，G5201 已驗證崑崙芯 M100 並支援 RDMA 組網，加上算能預告的 RISC-V 智算伺服器——三方都在把「CPU + 國產加速卡」的組合推向推理叢集，而不是單點對標通用伺服器。
  • 基礎軟體側同步補齊可判定性：Linux 7.3 讓 RVA23 可透過 hwprobe 在執行時判定，並把計數器委派、QoS 標識、KVM 的 Svadu 與影子棧擴充套件補齊；openRuyi 則把 RISC-V 的 lpm／fib 查詢最佳化回移進 dpdk。前者解決「怎麼知道自己是 RVA23」，後者解決「知道之後效能能否兌現」。
  • 資本冷熱仍分化：Tenstorrent 以 62 億美元估值完成 15 億美元 E 輪、明確拒絕出售，與國內芯際無限數千萬元 Pre-A 形成量級對照；但兩者共同點是資金都指向「量產與場景落地」，而非架構驗證。玄鐵 60 億顆出貨與 E908A 的車規雙 ASIL 認證，則提供了另一條以規模換生態的路徑。
  • 侷限說明：V100 的 12nm／120W 工藝與功耗資料來自海外媒體報道，官方中文稿未列該兩項；珠峰200 僅公佈場景與介面，規格與效能以年底釋出為準；算能與北京開源晶片研究院的峰會閃電演講內容為議程安排，具體產品規格未獲公開材料確認；Ubitium 融資釋出於 10-13，本期收錄依據為 10-19 中文媒體報道；會員官網巡檢的變化均為高校與機構首頁例行更新，未檢出實質產品、融資或架構釋出。
