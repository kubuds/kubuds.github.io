RISC-V 全球動態日報（2026-08-12）

2026-08-12 苦芽科技

調研視窗：過去 24 小時（2026-08-11 15:46 ~ 2026-08-12 08:50 北京時間） 信源：HN、Google News 聚合、CNX Software、Linuxiac、快科技、新京報、GitHub API 等（詳見附錄）

一、開源社群與核心/版本動態

1.1 QEMU 11.1 釋出：新增 RISC-V 大端支援與 K230 板級模擬

日期：2026-08-12（釋出 08-11 16:11 UTC）　來源：Linuxiac（經 vmvirtualmachine 映象核實） / Google News 聚合

QEMU 11.1 作為 11.x 系列首個維護版本釋出，頭號特性是 RISC-V 大端（big-endian）目標支援——對應 RISC-V 規範中執行時可控端序（runtime-controllable endianness）能力的落地，Codethink 此前即以此為主題開展”在小端架構上模擬大端”的研究並以 QEMU 為測試底座。RISC-V 側同步增強：新增勘智 K230 開發板支援（Canaan K230 為 RISC-V 雙核 AI 視覺 SoC，常用於端側視覺與機器人場景）、OpenSBI 升級至 1.8.1、新增 Tenstorrent mvendorid 支援，並修復大批 IOMMU、中斷處理、頁表遍歷與向量指令等底層問題。對 RISC-V 核心/發行版開發者而言，11.1 的大端支援意味著可在模擬器中先行驗證大端軟體棧。

1.2 RISC-V 官方規範倉庫自動化維護更新

日期：2026-08-12　來源：riscv-unified-db / riscv-arch-test

RISC-V 官方規範側基礎設施倉庫保持更新：riscv-unified-db（規範機器可讀資料庫）視窗內合入 4 筆依賴維護提交（prek、mise、jetty 版本升級與鎖檔案維護），riscv-arch-test（架構一致性測試 ACT）更新 Ubuntu 24.04 Docker 映象 digest。兩者均為自動化維護型提交，屬規範工程常規節奏；值得留意的訊號是 RVA23.1/RVB23.1 公開評審（昨日已報）正在推進，後續統一資料庫內容會隨之更新。

1.3 labwired-core：ESP32-C3（RISC-V）韌體模擬能力持續增強

日期：2026-08-12　來源：GitHub w1ne/labwired-core

Rust 編寫的確定性韌體模擬器 labwired-core（支援 ARM Cortex-M 與 RISC-V，提供 MCU 數字孿生與 MCP server 介面，59 stars）視窗內合入 15 筆提交：新增 ATmega328P Nano 孿生（CPU + Timer0/USART）、ESP32-C3（RISC-V 核心）側修復 DHT 單匯流排在 C3 孿生上的時序、為各 BLE Pong 實驗分配獨立通道以消除測試抖動，並新增資源度量（訪問計數 + PC 取樣）功能。其 ESP32-C3 相關工作量佔比提升，反映 RISC-V MCU 在”韌體級模擬/虛擬硬體”工具鏈中的覆蓋度在擴大。

二、產品與生態動態

2.1 尊界 V800 智慧座椅搭載奕斯偉 RISC-V 車規級 AI MCU（近 3 天趨勢）

日期：2026-08-10　來源：快科技 / 鳳凰網 / 新浪

鴻蒙智行尊界 V800 正式亮相，其全主動自適應智慧座椅成為亮點：透過精準的人體姿態識別與動態適配調整駕乘體驗，核心算力與 AI 演算法方案由奕斯偉計算提供的 RISC-V 車規級 AI MCU EAM2011 承載。EAM2011 是國內首顆支援輕量級 AI 應用的車規級 MCU，搭載自研 32 位 RISC-V 核心、採用國內成熟工藝製程，並完成從核心 IP、晶片設計到生產平臺的全鏈路本土化研發與量產體系搭建。該事件雖落在昨日視窗末端（08-10 報道，昨日報告未收錄），但作為國產 RISC-V 車規晶片規模化上車的標誌性案例，值得在今日報告中補錄。此前該系列晶片已見於智慧座艙輕量化 AI 部署場景。

三、國內團隊動態與深挖

3.1 開芯紅（香山 IP 商業化主體）：種子輪投資方陣容披露，國資+頭部產投共同加持

日期：2026-08-11/12　來源：新京報 / Google News 聚合（搜狐轉載，08-12 視窗內）

昨日已報開芯紅完成超億元種子輪融資（資金投向香山 IP 核架構升級），今日投資方陣容進一步披露：本輪匯聚國開科創、誠通科創、中科創星、中關村科學城、啟航基金及國泰創投等頭部產投機構（新京報 8 月 11 日報道，搜狐 8 月 12 日凌晨轉載進入本視窗）。國開科創與誠通科創均為國資背景創投平臺，加上中科創星（硬科技）、中關村科學城（北京屬地）的組合，表明香山 IP 商業化同時獲得國家級政策資本與屬地產業資本背書。GitHub 側香山生態倉庫組（XiangShan 主倉庫、difftest、NEMU、GEM5、env-scripts、XSAI 等 11 個倉庫）8 月 11 日批次更新，配套工具鏈保持同步演進，為”架構升級”路線提供工程側支撐。

3.2 奕斯偉計算：車規 MCU 上車 + 消費級 AI 私有云落地

日期：2026-08-10　來源：快科技 / Google News 聚合（網易） / Google News 聚合（湖北省經信廳）

奕斯偉計算本週多條動態疊加，形成”車規 + 消費電子”雙線落地圖景（均為近 3 天事件，昨日報告未收錄）：

  • 車規：EAM2011（自研 32 位 RISC-V 核心車規級 AI MCU）進入尊界 V800 智慧座椅，詳見 2.1；
  • 消費：極空間（ZSpace）即將上線的國產 AI 私有云 NAS 與奕斯偉合作打造，圖片素材 AI 處理全部本地執行、無需上傳雲端，隱私優先定位的端側 AI 場景；
  • 集團層面：奕斯偉材料（西安奕材）擬對武漢奕材增資，總募資 65 億元投向 12 英寸矽片擴產（湖北省經信廳披露），擬 2027 年首期產能投產——屬集團材料業務資本動作，與計算晶片業務相互獨立但印證集團整體擴產節奏。

3.3 算能（SOPHGO）：SophLiteOS 新增 AI Agent 功能

日期：2026-08-12（提交時間 08-11 21:03 / 08-12 07:15 北京時間）　來源：GitHub sophgo/sophon-tools

算能官方工具倉庫 sophon-tools 視窗內合入 5 筆提交，核心變更：SophLiteOS 新增 AI Agent 功能（含 pbmssm LLM 轉發），並將 picoclaw-web-chat 作為 AI Agent 頁內嵌實現（MYS-149 需求），另修復 SophLiteOS 概覽頁記憶體指標命名。SophLiteOS 是算能面向 RISC-V 端側晶片的輕量作業系統，本次合入把 LLM Agent 互動能力下沉到端側系統工具鏈中，配合其 K230/SG 系列 RISC-V SoC，屬於”RISC-V 端側 + LLM Agent”方向的直接工程進展。

四、具身智慧與機器人專章

視窗內無重大動態。 過去 24 小時英文檢索（”risc-v” robot when:3d）無視窗內命中，中文檢索（RISC-V 機器人/具身智慧 when:3d）僅命中車規與工業綜述類條目，未發現具身智慧/機器人方向的 RISC-V 強相關新聞。

近 3 天趨勢觀察：該方向與上週保持一致的漸進節奏。值得關注的鄰近訊號有二：一是奕斯偉 EAM2011 車規級 AI MCU 在尊界 V800 智慧座椅上的姿態識別應用（2.1），此類”感測器感知 + 動態適配”正是機器人控制與智慧座艙共用的技術棧，國產 RISC-V 車規晶片的落地路徑可作為具身智慧晶片的參照；二是算能 SophLiteOS AI Agent 功能落地（3.3），端側 LLM Agent 能力為 RISC-V 機器人大腦提供更輕的軟體基座。進迭時空（spacemit-robotics）、樂鑫（esp32-c 系列）機器人相關產品線未見新的公開里程碑。明日（8 月 13 日）第五屆滴水湖中國 RISC-V 產業論壇召開，10 款國產晶片集中亮相，具身智慧相關晶片新品值得會後跟蹤。

五、總結與趨勢觀察

  1. 模擬器層加速跟進 RISC-V 新特性：QEMU 11.1 落地 RISC-V 大端支援並新增 K230 板級模擬、OpenSBI 1.8.1，配合 Codethink 的端序研究，RISC-V 執行時可控端序從規範走向可驗證的工具鏈路徑正在閉環。
  2. 國產 RISC-V 車規晶片規模化上車：奕斯偉 EAM2011 進入尊界 V800 智慧座椅，疊加極空間 AI 私有云，奕斯偉系在車規與消費電子兩端同時兌現”RISC-V+AI”產品化。
  3. RISC-V 端側 OS 開始內建 LLM Agent：算能 SophLiteOS 合入 AI Agent 與 LLM 轉發功能，端側大模型應用棧向 RISC-V 生態滲透。
  4. 香山 IP 商業化獲政策資本背書：開芯紅種子輪投資方披露國開科創、誠通科創等國資機構，一級市場對國產高效能 RISC-V IP 的認可度持續提升。
  5. 侷限性說明：24 小時視窗內國際重磅新聞偏少（以 QEMU 11.1 為最顯著），國內動態多依賴 GitHub 提交與轉載媒體；極空間、武漢奕材等條目僅能引用 Google News 聚合連結（原站正文不可直接抓取），尊界 V800 細節以快科技/鳳凰網/新浪多源交叉核實。具身智慧專章視窗內無直接新聞，相關判斷基於鄰近方向推斷。
