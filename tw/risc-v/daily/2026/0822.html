一、開源社群與軟體生態

1.1 Ferrite Engineering 釋出 EDACrux：RISC-V 晶片驗證工具免費化（08-21）

日期：2026-08-21（riscv.org 官方部落格釋出，21:03 北京）　來源：RISC-V International Blog

RISC-V 老將 Martin Fink（前 HPE CTO，2017 年促成西部資料”每年十億核轉向 RISC-V”的關鍵人物）二次退休後再度出山，創辦新成員組織 Ferrite Engineering，併發布首個產品 EDACrux——一套四件免費 RISC-V 晶片設計驗證工具：WaveCrux（波形檢視器，內建 RVFI Commit Inspector）、NetCrux（RTL 原理圖瀏覽器）、LintCrux（lint 檢查儀表盤）、SimCrux（迴歸測試管理器），四者共享工作區並可交叉探查，幫助工程師定位”薛定諤指令”（被取指後究竟正常退役、被 squash 還是觸發 trap）。

核心亮點：

  • RVFI Commit Inspector：基於 RISC-V Formal Interface（源於 Clifford Wolf 的 riscv-formal，生態廣泛採用）把模擬中的退役指令流還原成可讀記錄，並自動跑六項一致性檢查、對照 RISC-V ISA 規範標記偏離——相容 Ibex、CVA6、PicoRV32、SERV、VeeR 家族及多數 riscv-formal 測試平臺；
  • 開源策略明確：”技術上已被開源解決、商業上未被充分服務的 EDA 環節，做精品化整合產品，核心開源、商業增強收費”——公測期（10 月初結束）全功能免費，公測結束後每件工具核心以 Apache 2.0 開源（含原始碼、測試、構建指令碼、波形引擎與 CXP 協議），Pro 版賣”深度與速度”（cycle-by-cycle 會計、分支預測分析、相容性儀表盤）；
  • 對生態的意義：Fink 直言”告訴你核心違反規範的工具不應該放在許可證後面”。目前多數 RISC-V 晶片仍用商業 EDA 工具設計，EDACrux 免費化降低了學術界與預算有限團隊的晶片驗證門檻，與 OpenHW CORE-V、CHIPS Alliance VeeR 等開源核形成”開源核 + 開源驗證工具”閉環。

2.1 印度卡納塔克邦釋出 KEO AI PC：RISC-V 處理器 + 邊緣 LLM（08-21）

日期：2026-08-21（釋出與集中報道，YourStory 23:38 / Moneycontrol 次日 00:22 北京）　來源：The Economic Times、YourStory、ETV Bharat、The Hindu

印度卡納塔克邦政府（IT-BT 部長 Priyank Kharge）與邦屬電子企業 KEONICS 正式釋出 KEO（Knowledge-driven, Economical and Open-source）AI PC：基於開源 RISC-V 處理器 + Linux 作業系統，面向公立學校與社群學習場景，主打彌合數字鴻溝。要點：

  • 硬體：RISC-V 處理器、內建 BUDDH AI agent；介面齊全（4G、Wi-Fi、乙太網、USB-A/USB-C、HDMI、音訊口）；配套演示的”Small AI PC”變體重不足 250 克、開放硬體設計；
  • 落地節奏：KEONICS 已收到 1,500 臺預訂單，首批部署目標為農村圖書館與學校；預裝學習、程式設計與辦公軟體；
  • 官方口徑：KEONICS 主席 Sharath Kumar Bache Gowda 稱這是”全球首個在邊緣裝置部署 LLM”的案例（注：該表述屬官方宣傳口徑，未披露所用處理器型號與模型規格，RISC-V 端側大模型已有平頭哥 C950 等更早先例）；
  • 背景意義：這是繼 IIT Madras 香提（Shakti）、印度 C2S 晶片計劃之後，印度邦政府級 RISC-V 終端規模化採購的又一落點，與國內”信創”邏輯同構——政府訂單驅動開源 CPU 生態落地，同時降低對 x86/ARM 的依賴。

2.2 LILYGO T-Display K230 Kit：K230 雙核 RISC-V 手持終端（08-21）

日期：2026-08-21（LinuxGizmos 報道 12:52 北京）　來源：LinuxGizmos

LILYGO 更新其 T-Display K230 手持開發平臺，裝入緊湊外殼並增加可拆卸物理鍵盤：基於嘉楠（Canaan）Kendryte K230 SoC（雙核 64 位 RISC-V，1.6GHz + 800MHz，整合 KPU/DPU/GPU/VPU，AI 加速 + 多媒體齊全），4.1 英寸 AMOLED 觸屏（568×1232）、2MP 旋轉攝像頭（1080p）、HDMI 輸出（1080p30）、LoRa（SX1262，868/915/923MHz）、2.4G Wi-Fi、乙太網、nRF52840 伴生 MCU、1GB LPDDR4。韌體側提供 CanMV / RT-Smart（RT-Thread 智慧作業系統）雙方案，LILYGO GitHub 倉庫 V1.3 增加 LR2021、電池、GPS、LTE-M、風扇、揚聲器支援。售價：LoRa CoreSet 約 150 美元、鍵盤 71~113 美元。這是 K230（國產 RISC-V 視覺 SoC）在”口袋級 Linux/AI 開發終端”形態上的又一產品化嘗試，LoRa+鍵盤組合指向應急通訊、離線教學等場景。
