一、開源社群與軟體生態

1.1 PoCL 7.2 釋出，OpenCL 3.0 官方一致性落地 RISC-V 與 x86_64

日期：2026-09-04　來源：Phoronix

可移植計算語言專案 PoCL 釋出 7.2 版，成為經 Khronos Group 認證的官方 OpenCL 3.0 一致性實現，覆蓋 RISC-V（RV64GC 與 RVA22 級硬體）與 x86_64（AVX-512 路徑，以 AMD Ryzen 9 9900X 驗證）兩類 CPU 平臺。新版本同時支援 LLVM 22（含 CUDA 與 Level Zero 裝置後端）及最高 LLVM 23 的 CPU 裝置目標，並跟進 cl_khr_extended_bit_ops、cl_khr_integer_dot_product、cl_khr_kernel_clock、cl_khr_spirv_linkonce_odr 等一批新 OpenCL 擴充套件。對 RISC-V 生態而言，這是開放平行計算標準首次在 RISC-V 通用處理器上獲得官方一致性背書，標誌著 RISC-V 在桌面與伺服器側異構計算軟體棧的成熟度再進一步。

1.2 回聲條目：ServeTheHome 補發 Hot Chips 2026 SiFive 標準與採納演講實錄

日期：2026-09-04　來源：ServeTheHome

ServeTheHome 補發其在 Hot Chips 2026 期間記錄的 SiFive《RISC-V 標準與採納》演講實錄。昨日（09-03）報告已收錄 SiFive 官方部落格的同主題補錄，本篇屬同源媒體回聲，實質內容無新增，按去重口徑不再單列詳述；僅補強一處訊號——演講收尾稱首批 RVA23 伺服器晶片將於今年落地，標準工作正轉化為真實硬體，與 SiFive 伺服器平臺規範（RVA23 + AIA 中斷 + UEFI/ACPI + MCTP/Redfish 管理）的推進相互印證。

二、產品與生態動態

2.1 XenoSpectrum 分析：中國伺服器市場仍 74% x86，北京緣何押注 RISC-V

日期：2026-09-04　來源：XenoSpectrum（譯自日文原創）

日媒 XenoSpectrum 刊髮長文，從市場資料與政策邏輯兩端分析中國 RISC-V 戰略：一方面伺服器市場約 74% 份額仍由 x86 把持，現實與”RISC-V 已鋪開”的觀感存在落差；另一方面北京透過信創名錄、國資雲與採購補貼等組合拳持續押注。文章批評業內流傳的”RISC-V 出貨佔比”數字常被剝離時間點與產品品類語境反覆引用，造成擴散性誇大；並以 RISC-V E203（0.145mW）較 Arm Cortex-M0（0.17mW）省電約 15% 的研究為例，指出此類孤例結論不宜泛化。該文對評估國內 RISC-V 伺服器敘事的”預期與現實的落差”具有參考價值，可視為近期”中國 RISC-V 政策熱”報道的祛魅式補充。

三、國內團隊動態與深挖

3.1 中科昊芯完成 B 輪融資，押注 AI 邊緣端 RISC-V DSP

日期：2026-09-03/04　來源：科創板日報（經東方財富轉載）、投資界

北京中科昊芯（中國科學院自動化研究所成果轉化企業，基於 RISC-V 架構的數字訊號處理器專業供應商）近日完成 B 輪融資，投資方為悅湖資本，資金重點投向 AI 邊緣端晶片產品與行業定製化解決方案研發。公司自研 Haawking HX2000 系列 DSP 已實現規模化應用，覆蓋 AI 智慧家電、工業控制、新能源汽車、光伏儲能及具身智慧等領域，主打高階 DSP 國產化替代；其團隊自 2016 年起投入 RISC-V 處理器研究，構建了從核心、架構到自主工具鏈（Haawking IDE）的全鏈條自研體系。值得關注的是賽道熱度：同賽道六嶽微電子 2026 年 7 月剛完成 5 億元 A 輪融資（粵科金融、廣州工控等十餘家機構參與），資本正加速湧入 RISC-V DSP 這一”國產替代 + 具身智慧”交叉賽道。

3.2 樂鑫 ESP32-S31 開發板上手：雙核 RISC-V 320MHz + Wi-Fi 6

日期：2026-09-04　來源：Geeky Gadgets（Google News 聚合）、Espressif 官方產品頁

Geeky Gadgets 釋出樂鑫 ESP32-S31 開發板（40-pin 排針 + 雙 USB-C）上手評測。ESP32-S31 是樂鑫 S 系列中採用 RISC-V 的雙核 32 位 SoC：主頻 320MHz、一核帶 128 位寬資料通路與 SIMD 指令，配 MMU、512KB SRAM 與 250MHz 8-bit DDR PSRAM（支援與 flash 併發訪問），最多 60 GPIO；無線側整合 2.4GHz Wi-Fi 6、藍芽 5.4（LE Audio/測向/Mesh 1.1）與 IEEE 802.15.4（Thread/Zigbee），對 Matter 協議提供 Wi-Fi 與 Thread 雙路徑支援。官方稱已進入量產並可購買，由 ESP-IDF、ESP-Matter、ESP-GMF 全棧支援，也可經 ESP-Hosted/ESP-AT 作連線協處理器，目標場景為智慧家居中樞、智慧音箱、邊緣 AI 與工業自動化。繼 C 系列（C2/C3/C5/C6/C61，RISC-V）與 P4 之後，樂鑫將 RISC-V 主控進一步引入 S 系列產品線；需注意 S31 與此前 Xtensa 核心的 S2/S3 架構不同，報道勿混為一談。

3.3 國內團隊 GitHub 綜合核查：整體平靜

日期：2026-09-04/05　來源：GitHub org 檢索（XUANTIE-RV、Nuclei-Software、sophgo、spacemit-com、eswincomputing、espressif、revyos、sipeed）

視窗內國內團隊開源側整體平靜，無重大新發布：

  • 達摩院玄鐵（XUANTIE-RV，72 倉庫）、奕斯偉計算（eswincomputing，16 倉庫）：視窗內無推送。
  • 芯來科技（Nuclei-Software）：nuclei-sdk、nuclei-linux-sdk 與 opensbi 倉庫有例行同步推送，提交內容為常規維護。
  • 算能（sophgo）：sophon-demo 修復 Qwen3.5 系列在 BM1684X2 上圖片輸入輸出異常，屬演示套件維護。
  • 進迭時空（spacemit-com）：ai-sdk 更新 RL 子模組引用，model_zoo_rl 新增”匯出原始策略動作以支援行為跟蹤”功能（#10），端側機器人強化學習工具鏈持續迭代。
  • 矽速（sipeed）：NanoKVM（RISC-V IP-KVM）改進終端啟動登入 shell 與 SSH 提示，體驗性更新。

四、具身智慧與機器人專章

4.1 視窗觀察：無重大機器人新品，RISC-V 具身敘事由融資與 RL 工具鏈承接

日期：2026-09-04/05

視窗內未見新的 RISC-V 機器人整機或具身專用晶片釋出。周邊關聯動態兩條：其一，中科昊芯 B 輪融資明確將”具身智慧”列為 HX2000 DSP 規模化應用場景之一（見 3.1），資金投向 AI 邊緣端晶片，說明工業控制類 RISC-V 處理器正藉助具身智慧擴大敘事半徑；其二，進迭時空 model_zoo_rl 新增原始策略動作匯出介面（見 3.3），延續其在機器人強化學習模型工具鏈上的投入。另注：CNX Software 報道的 Petoi Quaddle 迷你機器狗（眾籌）主控為 ESP32-S3（Xtensa 核心），非 RISC-V 平臺，按報道口徑剔除。行業主線仍延續昨日引述的”人形機器人計算走向中央與分散式混合架構”討論與”具身智慧量產元年”的產業敘事。

五、總結與趨勢觀察

  1. 軟體生態：PoCL 7.2 讓 RISC-V CPU 首次拿下 OpenCL 3.0 官方一致性認證，開放平行計算標準與 RISC-V 的結合再獲實質性背書，利好桌面/伺服器側異構計算棧。
  2. 資本面：中科昊芯 B 輪落地（悅湖資本），疊加六嶽微電子 7 月 5 億元 A 輪，RISC-V DSP 在”高階國產替代 + AI 邊緣 + 具身智慧”敘事下成為資本密集賽道。
  3. 產品面：樂鑫 ESP32-S31（雙核 RISC-V 320MHz + Wi-Fi 6 + 802.15.4）開發板開始鋪開上手評測，量產可用且 ESP-IDF/Matter/語音生態同步就緒，RISC-V 在消費級 AIoT 主控的滲透加深。
  4. 敘事面：XenoSpectrum 長文提示”RISC-V 伺服器佔比”類數字常被脫離時間與品類語境引用；”首批 RVA23 伺服器年內落地”的訊號與”伺服器市場仍 74% x86”的現實並存，高階市場放量仍需時間驗證。
  5. 平靜日說明：國內團隊 GitHub 側僅常規維護，機器人方向無視窗內新品；本期以軟體生態里程碑與融資事件為主。
