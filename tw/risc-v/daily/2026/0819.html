二、產品與生態動態

2.1 頭條：平頭哥官宣 XuanTie C950 原生執行 Qwen-3.8 27B——RISC-V 大模型推理的”Day 0”時刻

日期：2026-08-18（Wccftech 報道於 08-19 00:10 北京時間）　來源：Wccftech

阿里平頭哥（T-Head Xuantie RISC-V 團隊）官宣其旗艦 RISC-V 晶片 XuanTie C950 對最新開源模型 Qwen-3.8 27B 提供 Day 0（釋出即支援） 原生推理支援，具體指標：64 核 C950（帶 RVV 向量擴充套件）解碼速度 30 tokens/s，首 token 延遲（TTFT）僅 1.9 秒。要點：

  • 晶片背景：C950 於 2026 年 3 月釋出，定位”邊緣 AI 的伺服器級 RISC-V 處理器”——單晶片 64 個計算核、頻率最高 3.20 GHz，不依賴 GPU 執行 AI 負載；配標準 L1、靈活可配置 L2、可選共享 L3，帶硬體級智慧資料預取。TSMC 5nm 製造（據 Wccftech）。
  • 模型背景：Qwen-3.8 27B 為 270 億引數開源權重模型，官方稱編碼能力對標 Opus 4.5，可在單臺 MacBook（32GB 記憶體）上執行——屬”中尺寸高價效比”推理模型。
  • 戰略意義：這是阿里”類英偉達垂直整合”打法的又一落子——自研晶片對自研模型 Day 0 最佳化，形成”模型-晶片-雲”閉環；C950 可與其資料中心 AI 加速器組合，分攤推理負載。

這是 2026 年 RISC-V 陣營在”端側/邊緣大模型推理”方向最具標誌性的進展之一：此前的 RISC-V 大模型演示多停留在小模型或量化蒸餾，而 C950 在 64 核 RVV 上跑 27B 級模型達到可用吞吐，驗證了 RISC-V 多核+向量擴充套件路線在推理場景的可行性（詳見 3.1 平頭哥深挖）。

2.2 Xen 專案成立安全委員會（AMD/EPAM/Renesas 創始成員），推進 RISC-V 完整發布

日期：2026-08-18 10:59（北京時間）　來源：The Register

開源 Hypervisor Xen 專案成立 Safety Committee（安全委員會），創始貢獻成員為 AMD、EPAM、Renesas，目標推動 Xen 符合 IEC-61508 等功能安全正式標準——面向汽車、機器人等工作負載隔離場景（”分割槽機器人大腦”）。同時設立新的 Premier Plus 會員層級，服務尋求功能安全認證的組織。波音（Boeing）近期加入 Xen 專案，據 The Register 瞭解其興趣點正在於安全工作。與 RISC-V 的關聯：Xen 月初發布的更新”推進了面向 RISC-V 處理器完整功能釋出的工作”——Xen on RISC-V 距完整可用再進一步。虛擬化層的功能安全（隔離、分割槽、認證）與 RISC-V 在汽車/機器人的落地直接相關，值得跟蹤。

四、重點方向專章：具身智慧與機器人

4.1 安全虛擬化入場：Xen 安全委員會瞄準”機器人工作負載隔離”

Xen 專案成立安全委員會（AMD/EPAM/Renesas 創始成員）並推動 IEC-61508 合規，明確將”機器人”列為工作負載隔離的目標場景——”分割槽機器人大腦”意味著實時控制、導航、感知等混合關鍵性負載在同一硬體上的隔離執行成為可認證路徑。對 RISC-V 具身智慧的意義：Xen 的 RISC-V 支援正在推進”完整功能釋出”，汽車/機器人領域的安全認證虛擬化層若在 RISC-V 上落地，將補齊”實時核+應用核”雙核異構（滴水湖論壇路線）之外的第三種隔離形態——虛擬機器級分割槽。Renesas（車規 MCU 主力）+ AMD 的組合也暗示該委員會的多架構定位。

4.2 C950 跑 27B 模型：RISC-V 邊緣大模型推理的具身智慧潛力

C950（64 核 RVV、3.2 GHz、30 tok/s）驗證了 RISC-V 多核+向量路線在 27B 級模型推理上的可用性。對具身智慧而言，端側/邊緣大模型推理是”大腦上移”的關鍵環節——VLA（視覺-語言-動作）模型若能在 RISC-V 平臺達到可用吞吐，將降低整機對 GPU 的依賴。雖然 C950 目前定位邊緣伺服器而非嵌入式（功耗/體積與機器人本體部署仍有距離），但它是”RISC-V 跑大模型”從演示到產品的標誌性一步，為後續中尺寸晶片下放提供了基線資料（30 tok/s / 1.9s TTFT 可作為同類方案的參照系）。

4.3 進迭”感知-決策-運控”棧更新

model-zoo-vision 新增 DEIMv2 COCO 檢測器（實時檢測方向）、model_zoo_rl 的 Eigen 構建修復合入主分支——進迭時空的 K3 humanoid RL 執行時與視覺模型庫本週持續雙線推進，與其”感知（vision）-決策（RL）-運控（SPERT NPU）”三層佈局一致。節奏為”維護+增量”檔，無重大新發布。
