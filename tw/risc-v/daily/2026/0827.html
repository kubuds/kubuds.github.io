一、開源社群與軟體生態

1.1 GCC 補丁為 RISC-V 新增 -mcpu=native / -mtune=native 支援

日期：2026-08-26　來源：Phoronix / GCC 補丁列表

SiFive 工程師 Kito Cheng 向 GCC 提交補丁系列，為 RISC-V 後端新增 -mcpu=native 與 -mtune=native 支援，使編譯器能自動探測本機 CPU 核並據此選擇指令集擴充套件與調優引數，與其他架構對齊。該特性被寄望於併入明年的 GCC 17 釋出；當前侷限是不支援 RISC-V 混合/非對稱大小核設計。補丁同時改進 GCC 對 SiFive P550 / P870-D / U74 與進迭時空 Spacemit X60 / X100 / A100 等核心的識別。RISC-V 長期缺乏”本機原生調優”選項的短板正在補齊。

1.2 arXiv：CTTE 開源雙協議 RISC-V 追蹤編碼器

日期：2026-08-26　來源：arXiv:2608.18170 / Hacker News

論文釋出開源 RISC-V 處理器追蹤編碼器 CTTE（SystemVerilog 實現）：採用協議無關前端加可選後端設計，同時支援 RISC-V 兩種標準化追蹤格式 N-Trace（Nexus）與 E-Trace，實現 N-Trace 1.0 程式追蹤訊息集、引數化地址寬度，並遵循 RISC-V Trace Control Interface 規範。據作者稱，截至 2026 年 8 月尚無公開可綜合的 N-Trace 編碼器，也無單前端雙後端開源實現。CTTE 已與 5 家供應商的 6 款 RISC-V 核心完成整合驗證，為除錯與可觀測性工具鏈提供開放底座。

1.3 LLVM/Clang 23.1 釋出，通用編譯器棧更新

日期：2026-08-25　來源：Phoronix

LLVM 23.1 按計劃釋出，為 LLVM 23 系列首個穩定版（2026 下半年更新），本期主要亮點為 AMD Zen 6 與 NVIDIA Rigel 支援及部分 C++26 特性。作為 RISC-V 生態主流通用編譯器之一，LLVM 版本更新對依賴其後端的工具鏈與晶片廠商（含國內團隊）具有同步跟進意義，本期無 RISC-V 專項大改披露。

二、產品與生態動態

2.1 Armbian 26.8 釋出：重寫安裝器與 UEFI ISO

日期：2026-08-26　來源：Armbian 官方部落格 / 9to5Linux

面向 ARM 與 RISC-V 單板機的發行版 Armbian 26.8 釋出：全樹升級 Linux 7.1 核心，安裝器從獨立指令碼重寫為 armbian-config 模組（支援 SPI/MTD 目標、eMMC 與 NVMe 分離流程、獨立刷載入程式並上報失敗），Armbian Imager 升級至 2.0，新增可引導 UEFI ISO 映象構建（image-output-iso 擴充套件），便於 IPMI 虛擬光碟機與雲環境直接部署。對 RISC-V 單板使用者而言，UEFI ISO 與安裝器重寫降低入門門檻。

2.2 趨勢條目：SiFive BigSky 伺服器媒體持續發酵

日期：2026-08-26　來源：Electronics Weekly（gnews）、thestack.technology（gnews）、XenoSpectrum（gnews）

SiFive BigSky SF-2U870 企業級 RISC-V 伺服器釋出持續發酵：Electronics Weekly、thestack.technology、XenoSpectrum、Technetbook 等歐美媒體 8 月 26 日密集跟進，標題普遍強調”全球首款機架式 2U RISC-V 資料中心伺服器”與 32 核開發伺服器定位。主事件已於 8 月 25 日日報報道，本條為後續傳播觀察，不再展開。

2.3 Adafruit 實測 ESP32 深睡功耗：S3 vs C3 vs C6

日期：2026-08-26　來源：Adafruit Blog（gnews）

Adafruit 釋出 ESP32 三款 SoC 深度睡眠功耗實測對比（S3 vs C3 vs C6），其中 ESP32-C3 與 C6 均為 RISC-V 核心，實測資料顯示其低功耗表現與 Xtensa 核心的 S3 同臺競技，佐證 RISC-V MCU 在電池供電物聯網場景的競爭力。屬嵌入式社群內容，供低功耗選型參考。

三、國內團隊動態與深挖

3.1 進迭時空：K3 BSP v1.0.7 與 Bianbu V4.0.6 同日釋出

日期：2026-08-26　來源：docs-buildroot 釋出說明 / docs-bianbu 釋出說明 / esos org

進迭時空 8 月 26 日同日釋出 K3 晶片 Buildroot BSP v1.0.7 與 Bianbu V4.0.6 發行版更新。BSP 主要更新：支援 RISC-V64 加密加速、支援讀取 K3 chipid、最佳化 OPP 表（採用 efuse 校準值作熱溫參考），並修復 PCIe 喚醒鏈路訓練失敗、MIPI DSI 面板未切換、UFS 讀寫混合序列化、fastboot 大偏移截斷等一批底層缺陷。Bianbu V4.0.6 聚焦 LXQt 桌面與基礎元件修復（快照快門、背光外掛、wlroots 休眠黑屏、網路列表冗餘等）。配套 esos 倉庫同期批次合入 K3 掛起到磁碟（hibernation）支援、audio pmdomain 狀態修復等提交，文件側 MUSE Pi Pro 使用者指南新增 JTAG 除錯介面章節與 TF 卡除錯擴充套件板文件。版本節奏保持約月度更新。

3.2 算能：sophon-tools 大規模適配 CV84X2/SE13

日期：2026-08-26~27　來源：sophgo/sophon-tools

算能 sophon-tools 工具鏈視窗內合入約 25 筆提交，集中適配 CV84X2（疑似 CV 系列新一代晶片）與 SE13 單板：get_info 升級至 v1.5.0/1.5.1（補齊 CV84X2 剩餘 19 項空值指標、dts 探測跟隨符號連結、CHIP_SN 改按 BM1688 方案讀取）、bmssm 監控指標對齊 get_info、sophliteos 構建/部署三處坑修復（CV84X2 真機驗證）、psoph_phytool 硬體探測、pota_update 網路解析兜底等。提交資訊含 MYS-753/754 等內部缺陷跟蹤號並標註真機驗證，表明算能正為 CV84X2 新品鋪平工具鏈與運維配套。

3.3 香山：模擬器工具鏈密集更新，研究分析沉澱為主

日期：2026-08-26　來源：OpenXiangShan org 提交檢索

OpenXiangShan 組織視窗內約 40 筆提交，集中在一眾模擬/驗證工具鏈：gsim 重構 CI（新增 arm64 構建、clang 升級、jemalloc、dependabot 跟蹤、–threads 解析執行緒數引數）；XiangShanLab 新增 prefetch 指令 MMIO 非對齊分析報告（含波形）與指令生命週期分析（#4724 分析報告）；difftest 重寫 StoreRecorder 校驗邏輯、FPGA 差分除錯欄位過濾；GEM5 修復 arch-riscv MUL 符號溢位、禁用方向 TLB probe 跳過等；NEMU 支援向量 exp2 指令；XSAICache 同步 coupledL2 矩陣資料。延續”研究分析沉澱 + 基建維護”型活躍，未見新架構改動。

3.4 平頭哥：thead-extension-spec 修復 xtheadfmv 文件編碼錯誤

日期：2026-08-26　來源：XUANTIE-RV/thead-extension-spec PR #75

平頭哥玄鐵擴充套件規範倉庫合入 PR #75（外部貢獻者 majin2020）：修正 xtheadfmv 擴充套件文件中 th.fmv.hw.x 與 th.fmv.x.hw 兩條指令互換的 funct7 編碼（0x60/0x50），使其與硬體實際規格一致；同期修復 CI 的 wavedrom npm 引數問題。屬規範文件勘誤，動態量小，體現玄鐵擴充套件規範倉庫持續接受外部修訂。
