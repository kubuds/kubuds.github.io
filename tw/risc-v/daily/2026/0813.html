RISC-V 全球動態日報（2026-08-13）

2026-08-13 苦芽科技

調研視窗：過去 24 小時（2026-08-12 08:50 ~ 2026-08-13 08:24 北京時間） 信源：HN、Google News 聚合、CNX Software、Phoronix、The Register、電子工程專輯、新浪財經、IT之家、GitHub API 等（詳見附錄）

一、開源社群與核心/版本動態

1.1 USENIX 論文：商用亂序 RISC-V 晶片對全部 Spectre 變體易感，含國產玄鐵 C910/C920（今日頭條）

日期：2026-08-13（報道 08-12 20:42 UTC）　來源：The Register

比利時與德國高校學者完成論文《Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors》，已被第 35 屆 USENIX Security Symposium 錄用。研究結論直指此前”RISC-V 架構太簡單、不受 Spectre 影響”的流行假設是錯的：商用亂序執行 RISC-V 處理器（SiFive P550、平頭哥玄鐵 C910/C920）對所有主要 Spectre 變體均易感；而順序執行核心（SiFive U74、玄鐵 C906/C908）未見漏洞。研究者在兩塊晶片上實現了 Spectre-PHT/BTB/RSB/STL 四類 PoC 攻擊，召回率達 100%、精度超 97%，並在玄鐵 C910 上以 338 B/s 的速度洩露任意 Linux 核心記憶體。研究者強調：x86/ARM 的軟體緩解手段不能直接遷移（RISC-V 缺少微架構自省介面，且生態碎片化導致難以統一緩解），需從架構原語、硬體透明性與生態工具鏈層面系統性補課。相關補丁已合入主線上遊 Linux 3 個、另有 2 個在審；SiFive 已處理 P550 專項問題。對國產 RISC-V 伺服器與雲場景，這是安全基線的直接提示。

1.2 RISC-V 官方模擬器與測試套件維護更新

日期：2026-08-12（21:36/21:59 北京時間）　來源：riscv-isa-sim / riscv-tests / sail-riscv-tests

RISC-V 軟體生態基礎設施倉庫視窗內例行更新：官方 ISA 模擬器 Spike（riscv-isa-sim）合入構建系統清理（Boost 檢測上移至頂層 configure，修復重複連結告警與 C99 設計符告警，PR #2365/#2363/#2362）；riscv-tests 的 debug 測試新增”接受 GDB 主執行緒識別符號”相容修復（#657）；sail-riscv-tests 預編譯測試套件同步更新。均為低訊號維護型提交，屬規範工程常規節奏，與 RVA23 公開評審及統一資料庫更新（riscv-unified-db）保持同步。

二、產品與生態動態

2.1 Tenstorrent 提交 Ascalon XG GCC 補丁：疑為面向出口市場的去加密型號

日期：2026-08-13（08-12 16:14 EDT）　來源：Phoronix

Tenstorrent 工程師向 GCC 郵件列表提交補丁，首次公開新核心型號 Ascalon XG——這是高效能亂序 RISC-V RVA23 核心 Ascalon X 的新變體，目標是進入開源 GCC 上游支援。補丁中明確標註其為 “the global version of Ascalon X”：與 Ascalon X 的唯一差異是去掉 zvkng 向量密碼學擴充套件，其餘（rva23s64、zfbfmin、zfh、zvbc、zvfh、zvl256b、smaia、ssaia 等）保持完整，編譯器目標標識為 tt-ascalon-xg。去掉密碼學擴充套件、降低吞吐定位，業界普遍解讀為面向中國市場等出口管制場景的合規型號。這是 Tenstorrent Ascalon 系列在 RISC-V 高效能 CPU 路線上的又一佈局訊號，也側面印證出口管制正在影響 RISC-V 高效能核的型號分化。

2.2 Apollo 釋出 40 美元 ESPHome 官方入門套件，搭載 RISC-V 晶片 ESP32-C6

日期：2026-08-12（18:55 北京時間）　來源：CNX Software

Apollo Automation 與 Open Home Foundation 合作推出首款官方 ESPHome 入門套件，售價 40 美元。主控板為 ESPHome C6 Board，搭載 ESP32-C6-MINI-1 模組（樂鑫 RISC-V 核心 MCU，支援 2.4GHz Wi-Fi 6、BLE、Thread/Zigbee），透過兩條 14-pin FPC 介面連線四款模組：MH-SR602 PIR 人體感應、AHT20F 溫溼度、RGB LED+蜂鳴器通知模組與按鍵模組，USB-C 供電可選鋰電池。套件主打零門檻：配合 ESPHome Device Builder 桌面視覺化編輯器即可配置，無需寫 YAML，可獨立執行或接入 Home Assistant。ESP32-C6（RISC-V）成為智慧家居官方入門硬體的事實選擇之一，是 RISC-V MCU 在消費級生態滲透的又一例項。

（說明：QEMU 11.1 釋出及其 RISC-V 大端支援、K230 板級模擬已在昨日報告收錄，今日不重複。）

三、國內團隊動態與深挖

3.1 平頭哥：真武 AI 晶片累計出貨 56 萬片，阿里雲稱產能持續提升

日期：2026-08-12（19:30 北京時間）　來源：電子工程專輯

電子工程專輯報道，截至今年 4 月平頭哥真武 AI 晶片累計出貨 56 萬片。阿里雲全球資料中心總經理王朝陽在公開場合表示：平頭哥產能正在逐漸提升，”未來非常確定性的是，國產自有晶片的產能會持續提升、佔比越來越高，而產能提升時間大概不需要三年”。這是阿里雲側對國產自研晶片產能節奏的罕見量化表態。深挖：平頭哥為阿里全資半導體主體，產品線覆蓋資料中心 AI 晶片（含光/真武）、伺服器 CPU（倚天 710/730）與 RISC-V 處理器 IP（玄鐵系列），其中玄鐵 RISC-V 生態（XUANTIE-RV 組織）本週持續活躍——視窗內 zero_stage_boot 倉庫（C 語言零級啟動引導）更新（08-12 19:18）、damo-rv-priv-ats 與 opensbi 同步推進，顯示其 RISC-V 核心與生態工程與 AI 晶片業務並行投入。

3.2 希奧端計算：數億元 A 輪融資交割，總部遷至南京江北新區，兆易創新參投

日期：2026-08-12（18:01 北京時間）　來源：IT之家 / 投資界 / Google News 聚合（新浪財經）

伺服器 CPU 研發企業希奧端計算（成立於 2022 年 7 月）宣佈於 2026 年 7 月完成數億元人民幣 A 輪融資交割，並同步將總部遷至南京江北新區。本輪由銘哲資本、現象資本聯合一家頭部 VC 領投，中信建投資本、中銀國際、兆易創新、智宸資本、卓源亞洲、守正資本、鼎心資本等跟投——其中兆易創新是國內 RISC-V MCU（GD32V 系列）主力廠商，其參投印證產業資本對伺服器 CPU 國產化的押注。公司戰略為雙路線並行：一方面基於 ARM v9 指令集 Neoverse V3 核構建第一代產品 BlueDot V1（強化向量運算、亂序流水線與記憶體互聯頻寬，面向雲端與邊緣 AI 推理）；另一方面前瞻佈局 RISC-V CPU 架構。募資將投入 BlueDot V1 回片驗證與 2026 年底小批次試產。國產推理伺服器 CPU 賽道再添新玩家。

3.3 奕斯偉計算：三衝港交所，”RISC-V 第一股”連續減員引發關注

日期：2026-08-12（18:58 北京時間）　來源：Google News 聚合（新浪財經）

新浪財經刊髮長文分析奕斯偉計算（ESWIN Computing）第三次遞表港交所背後的經營細節：作為”RISC-V 架構第一股”候選，公司營收持續增長但三年累計虧損約 49 億元，客戶高度集中，且員工人數連續縮減成為市場關注點。結合此前已披露資訊（8 月 7-8 日啟動三衝港股、母公司西安奕材 65 億元增資武漢 12 英寸矽片基地），奕斯偉集團正以”材料擴產 + 計算晶片 IPO”雙線推進資本運作。員工規模變化與研發投入節奏的關係、以及 RISC-V 車規 MCU（EAM2011 上車尊界 V800）的放量進度，將是後續跟蹤重點。

3.4 進迭時空：AI SDK 集中更新，機器人學習框架 LeRobot 適配 K3 持續推進

日期：2026-08-12（20:32 北京時間）　來源：spacemit-com/ai-sdk / spacemit-robotics/lerobot / spacemit-com/docs-ros

進迭時空（SpacemiT）GitHub 組織視窗內多條倉庫集中更新：AI SDK（面向 K 系列晶片的 AI 能力集合，以 Git submodule 組織）更新計算機視覺、語音（VAD/ASR/TTS）、LLM 與多模態 VLM 元件（08-12 20:32），model-zoo-vision 視覺模型倉庫同步更新（19:49）；docs-chip/docs-buildroot 文件更新（15:41/16:23）。機器人側（spacemit-robotics）：LeRobot 倉庫 08-10 合入 “harden SmolVLA K3 runtime” ONNX 加固提交，此前已落地 ACT（Action Chunking with Transformers）FP16 部署示例與 ONNX 推理機器人測試；docs-ros（ROS 文件）與 Robot SDK IMU 驅動（peripherals-imu）同日更新。K3（RISC-V 8 核 AI SoC）在機器人學習框架與 ROS 生態上的適配面在擴大，詳情見第四章。

3.5 算能（SOPHGO）：引導鏈元件集中更新

日期：2026-08-12（14:41~14:47 北京時間）　來源：sophgo/zsbl / sophgo/sophgo-edk2 / sophgo/bootloader-riscv / sophgo/sophon-tools

算能 RISC-V 晶片引導鏈元件視窗內集中更新：zsbl（RISC-V Zero Stage BootLoader，08-12 14:47）、sophgo-edk2（UEFI 韌體，14:41）、bootloader-riscv（08-11 13:59）、linux_5.10 核心分支（08-11 16:40）相繼有提交；sophon-tools 今日（08-13 07:05）繼續更新（SophLiteOS AI Agent 功能昨日已報）。引導鏈（ZSBL→UEFI→核心）的成體系推進，通常對應新晶片平臺的韌體就緒階段，可視為算能新平臺量產準備的工程訊號。

3.6 芯來科技：申報新三板創新層，定向募資 4200 萬元（近 3 天趨勢）

日期：2026-08-10　來源：Google News 聚合（新浪財經）

國內 RISC-V CPU IP 龍頭芯來科技（Nuclei）申報新三板創新層，計劃定向募資 4200 萬元（新浪財經 8 月 10 日報道，落於本視窗之前，作近 3 天趨勢收錄）。資本側動態與研發側同步：GitHub 側 Nuclei-Software 組織近期更新 Lauterbach TRACE32 除錯指令碼倉庫（lauterbach-startup，08-11）、RV64GC Linux 能力核心 e603_hbird（08-07）與 nuclei-ai-models（08-07），顯示其從 IP 核到除錯工具鏈與 AI 模型庫的完整佈局仍在擴張。

四、具身智慧與機器人專章

視窗內最大看點：進迭時空（SpacemiT）在機器人學習框架上的持續落地。

  1. LeRobot 適配進展（spacemit-robotics/lerobot，08-10 16:20 提交）：合入 “fix(onnx): harden SmolVLA K3 runtime”（#17）——SmolVLA 是輕量視覺-語言-動作（VLA）模型，進迭時空在其 K3 RISC-V SoC 上以 ONNX 執行時部署並加固；此前已落地 ACT（Action Chunking with Transformers）的 SpineTorch FP16 部署示例（#16）與 ONNX 推理機器人測試（#14）。加上 6 月以來的 SmolVLA ONNX pipeline（#12/#13），K3 已形成”VLA + ACT 雙路線”的機器人學習模型端側部署矩陣。其組織內另有 humanoid_unitree_g1/go1（宇樹）、humanoid_tiangong（天工）、reachy_mini 等仿人機器人適配倉庫與 Robot SDK 電機/IMU 外設驅動，構成完整的機器人軟體棧。
  2. ROS 生態：docs-ros 文件倉庫更新（08-10），與 AI SDK 的 ROS 示例配套。
  3. 滴水湖論壇今日開幕：第五屆滴水湖中國 RISC-V 產業論壇於今日（8 月 13 日）召開，此前預告”10 款國產晶片新品集中亮相”（新浪財經 8 月 8 日報道），具身智慧相關晶片新品值得會後跟蹤；截至本報告採集時點（08:24）尚無開幕當日成果報道。
  4. 鄰近訊號：奕斯偉 EAM2011 車規級 AI MCU 在尊界 V800 智慧座椅的姿態識別應用（昨日已報），其”感知 + 動態適配”技術棧與機器人控制共用，可作為具身智慧晶片國產化路徑參照。

五、總結與趨勢觀察

  1. 安全基線敲響警鐘：USENIX 論文證實商用亂序 RISC-V 晶片（含國產玄鐵 C910/C920）對全部 Spectre 變體易感，且 x86/ARM 軟體緩解不可直接遷移。RISC-V 在高效能運算與雲場景的規模化程序中，微架構安全原語與生態級防禦工具鏈的建設將成關鍵競爭維度，國產亂序核（玄鐵、香山等）尤需重視。
  2. 出口管制重塑產品線：Tenstorrent Ascalon XG”去加密出口型號”公開亮相，疊加美國會推動收緊 AI 晶片流向管制，RISC-V 高效能核的”國內版/國際版”分化可能成為常態，國產替代視窗與合規壓力並存。
  3. 國產伺服器 CPU 融資活躍：希奧端 A 輪（兆易創新參投、BlueDot V1 年底試產）、芯來新三板募資、奕斯偉三衝港股，資本正密集湧入國產 CPU/RISC-V IP 賽道，ARM 與 RISC-V 雙路線成為新一代創業公司標配。
  4. 機器人方向穩步推進：進迭時空 LeRobot 的 SmolVLA/ACT 端側部署與 ROS 適配是本週最具體的 RISC-V 具身智慧進展；滴水湖論壇今日開幕，會後晶片新品資訊值得持續跟蹤。
  5. 生態基礎設施節奏正常：Spike/riscv-tests 維護更新、玄鐵 zero_stage_boot 等提交顯示規範工程與廠商工程均按常規節奏推進。
