二、產品與生態動態

2.1 微雪 Waveshare 推出 ESP32-C5 Pico 板卡：雙頻 Wi-Fi 6 RISC-V 微板卡採用樹莓派 Pico 外形（09-09）

日期：2026-09-09　來源：CNX Software、Open Source For You、Waveshare 文件站、GitHub waveshareteam/ESP32-C5-Pico

微雪（Waveshare）釋出 ESP32-C5 Pico 板卡，把樂鑫 ESP32-C5 雙頻 Wi-Fi 6 SoC 引入樹莓派 Pico 外形（約 51 至 56.85 x 21 mm）。核心規格：ESP32-C5-MINI-1/1U 模組（ESP32-C5HF4，單核 32 位 RISC-V 最高 240 MHz 加一顆 48 MHz 低功耗 RISC-V 核，384 KB SRAM、320 KB ROM、4 MB SPI flash），無線支援雙頻 2.4/5 GHz 802.11ax Wi-Fi 6 及 Wi-Fi 4 向下相容、藍芽 5.0 LE（含 Mesh）、802.15.4（Zigbee 3.0 / Thread 1.3 / Matter）。板載 USB-C（供電、燒錄、充電）、2x20 pin Pico 相容排針（最多 26 路 GPIO、20 路 PWM，另 6 路經 TCA9554PWR 擴充套件）、復位與 BOOT 按鍵、RGB LED 與鋰電充放電電路；提供四個版本（板載 PCB 天線或 IPEX 外接天線，排針預焊或未焊），軟體支援 Arduino IDE 與 ESP-IDF，示例程式碼自官網遷移至 GitHub（板卡資訊、RGB、I/O 擴充套件、雙頻 Wi-Fi、UART、1.83 英寸觸控式螢幕、MCP2515 SPI CAN 等）。意義：ESP32-C5 於 2025 年 4 月量產後，其”雙頻 Wi-Fi 6 + RISC-V”能力正沿 Pico 相容形態向下沉市場擴散，第三方板卡生態（微雪為深圳廠商）成為樂鑫 RISC-V 無線 MCU 落地的直接放大器。

2.2 兆易創新播客談 RISC-V、機器人與邊緣 AI：GD32 雙架構路線與 EtherCAT 分散式控制（09-09）

日期：2026-09-09　來源：Electropages、GigaDevice 人形機器人方案頁、GigaDevice GD32V 釋出公告

Electropages 播客（Robin Mitchell 對話兆易創新業務發展經理 Kevin Jones）系統談及該公司 MCU 路線：RISC-V 方面，兆易創新是較早的主流採用者，2019 年即推出 GD32VF103（核心由芯來科技提供，雙方公開合作），當前無線產品線亦採用 RISC-V，官方強調架構靈活性可讓晶片廠商圍繞特定應用與負載定製處理器；機器人方面，工業機器人多電機與複雜運動對控制器間通訊的確定性要求提高，GD32H7 系列支援 EtherCAT，可透過分散式 MCU 各自控制單個電機與區域性子系統，減少把全部決策回傳中央處理器的依賴；邊緣 AI 方面，電機異常檢測、人體檢測等本地推理任務不必依賴高階 AI 處理器，Cortex-M7/M33 在模型裁剪後已可承擔，有利於降低成本敏感場景對雲端的依賴。結合兆易創新人形機器人方案頁（”感知—決策—控制—執行”架構，MCU、儲存、模擬晶片組合覆蓋靈巧手、關節模組、IMU、電源管理等），可見其”Arm + RISC-V 雙架構 + 機器人/邊緣 AI”的國產 MCU 定位。本條為訪談類內容，無新品釋出，作為戰略觀察收錄。

3.1 進迭時空：新一代一致性互聯匯流排 N200 研發完成，形成通算+智算+互聯三大板塊（09-07 釋出，本次補錄）

日期：2026-09-07（公司釋出；此前兩個視窗遺漏，本次補錄）　來源：進迭時空官網新聞、GitHub spacemit-com/model_zoo_rl、spacemit-com/ai-sdk

進迭時空在官網披露，公司新一代自研高效能一致性互聯匯流排 N200 正式完成研發。繼佈局通用計算 CPU 核（X60/X100/X200）與智慧計算 AI 核（A60/A100/A200）後，N200 的收官標誌其完成”通用計算、智慧計算、計算互聯”三大核心技術板塊佈局；N200 將與通算核 X200、智算核 A200 一同用於下一代計算晶片，預計 2027 年正式量產。這是繼 K3（全球首顆符合 RVA23 規範量產的 RISC-V AI CPU，60 TOPS、支援 300 億至 800 億引數端側推理）之後的架構縱深動作：自研互聯匯流排意味著其下一代晶片將從”採用現成 NoC”轉向全棧自研，直接支撐多核一致性與 AI 核協同頻寬。視窗內 GitHub 側，進迭時空（spacemit-com）端側 AI 工具鏈持續迭代：ai-sdk 於 09-09 14:01 與 17:45、次日 00:22（北京時間）多次更新 rl/vision 子模組；model_zoo_rl 於 09-09 20:19 合入 feat(rl): support inference cancellation and YAML provider selection（#11）；model-zoo-vision、docs-ai、linux 亦有推送。RL 模型庫與推理取消、YAML provider 選擇等功能，對應機器人與具身場景對可中斷推理與多後端切換的實際需求。（注：公司新聞頁同批還列出 K3 跑通 DeepSeek Harness、GIS 2026 參展等條目，對應事件均在早前視窗，不重複收錄。）

3.2 芯來科技：英媒盤點 Quintauris RISC-V 生態合作，芯來車規 IP 對齊 RT-Europa（英文媒體 09-08~09 盤點，合作本體為 2026 上半年）

日期：2026-09-08（Electronics World 盤點文；New Electronics 09-09 同題報道）　來源：Electronics World、Automotive World、Quintauris 新聞室、芯來科技公告（2026-06-16）

英國媒體 Electronics World 於 09-08 刊出盤點稿，New Electronics 09-09 同題：Quintauris 透過持續合作擴充套件其 RISC-V 生態，2026 上半年新增四項合作——Elektrobit（04-21，汽車軟體，服務軟體定義汽車）、芯來科技 Nuclei（06-16，車規級 RISC-V 處理器 IP 對齊 Quintauris RT-Europa 實時平臺規範）、Ashling（除錯與開發工具）、以及 EM-Altair Profile 規範，覆蓋軟體、硬體與工具鏈。其中芯來部分的核心是：RT-Europa 為首個面向汽車實時 RISC-V 處理器的平臺規範（定義確定性記憶體訪問、中斷處理、特權模式、實體記憶體保護、除錯介面與 SoC 整合要求），芯來以量產驗證的 NA 系列與之對齊；芯來 NA 系列為全球首個透過 ISO 26262 ASIL-D 認證的 RISC-V 處理器 IP，覆蓋 ASIL-A 至 ASIL-D，客戶已超 300 家，應用於鐳射雷達、毫米波雷達、域控制器、車規 MCU、車載乙太網與 SoC 安全島。須明確：本條為英文媒體對既有合作的盤點式再報道，合作本體均發生於 2026 年上半年（非本視窗新事件），收錄價值在於其把”中國 RISC-V IP 進入國際車規參考平臺”的產業訊號再度放大；視窗內 Nuclei-Software 的 GitHub 組織 42 個倉庫無推送，無自主開發動態。

五、總結與趨勢觀察

本報告視窗新聞側偏弱、開源側活躍，國內進入到展會首日”議程落地、實況待釋放”的過渡狀態。要點歸納如下：
