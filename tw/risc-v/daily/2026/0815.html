一、開源社群與軟體生態動態

1.1 USENIX Security 26 論文：Spectre 在商業亂序 RISC-V 矽片上全線成立（今日頭條之一）

日期：2026-08-12（論文接收與部落格釋出，08-12~13 媒體擴散）　來源：Lukas Gerlach 部落格（論文短版） / The Register / SC Media

德國研究者 Lukas Gerlach 等的論文《Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors》被 USENIX Security 26 接收並公開。研究在可購得的商業亂序 RISC-V 處理器——平頭哥玄鐵 C910/C920 與 SiFive P550 上系統驗證：此前在 x86 上成立的 Spectre 各變體在 RISC-V 上同樣可行（部分需額外技巧）。關鍵發現：其一，Spectre-BTB（v2）是否可利用取決於韌體是否啟用間接分支預測器——C910/P550 出廠禁用、C920 啟用，啟用後攻擊成功但偶發機器崩潰，暗示存在硬體缺陷；其二，研究者構建了經 BPF 探針讀取任意檔案的實際利用鏈：RISC-V BPF JIT 對核心插入的 BPF_NOSPEC 屏障不生成任何指令，驗證器認為程式受保護而生成程式碼實際無屏障，形成”投機型別混淆”gadget；其三，被測核心將 BTB 在使用者態與核心態間分離，使傳統核心 Spectre 利用路徑變難。論文同時給出防禦建議。這是繼 2023 年 T-Head 安全公告後，對”RISC-V 免疫 Spectre”迷思的公開系統證偽，對 RISC-V 進入伺服器/雲基礎設施的信任建立構成重要提醒。

四、重點方向專章：具身智慧與機器人

滴水湖論壇多款新品指向具身智慧：格見半導體單晶片驅動 25 自由度、500 納秒電流環的機器人運動控制方案（見 3.3），是視窗內最具體的運控級產品訊號——電流環週期是運控實時性的核心指標，500 納秒級別對標高階伺服控制；進迭時空 K3 將機器人運控列為主打場景之一（見 3.1），延續 spacemit-robotics 在 LeRobot（SmolVLA/ACT 端側部署）、仿人機器人（humanoid_unitree_g1）方向的既有佈局；國際電子商情”從十顆晶片看 RISC-V 的主力之路”與新浪 8/14 綜述”伺服器、AI 和機器人：中國 RISC-V 的下一站”均將機器人列為 RISC-V 三大主力市場之一。運控（實時控制 DSP/MCU）與端側 AI（VLA 模型推理）構成 RISC-V 具身智慧的兩條並行主線，前者本週有實質新品落地。

4.2 生態側承接

香山/進迭等高效能核與運算元庫進展（見 1.2、3.1）繼續為機器人端側推理提供底座；格見 GS32 系列已獲 ASIL-B 認證（6 月），車規級實時控制晶片亦為機器人關節控制複用提供認證基礎。

五、總結與趨勢觀察

  1. 國產 RISC-V 進入”主力敘事”階段：滴水湖論壇”出貨 360 億顆、市佔超 30%、量產率超 90%”的產業資料與 10 款新品（伺服器 CPU、機器人運控、車規 CMS、視覺邊端、網絡卡、BMC）集中亮相，覆蓋 AI 伺服器、具身機器人、汽車電子三大戰場，國產 RISC-V 從”可用”向”主力”過渡的敘事在本週成型。這與昨日 SiFive SKL 開源（軟體核心庫軍備）共同指向：RISC-V 硬體生態已足夠豐富，競爭重心正在向軟體棧與行業落地遷移。
  2. RISC-V 伺服器之路出現量產級節點：藍芯 LX500（48 核 75 TOPS，宣稱全球首款 RISC-V 量產伺服器 CPU）與賽昉 JH-B100 BMC 同日聚焦，形成”主算力+帶外管理”雙線進入資料中心的態勢；前者若量產落地屬實，將與 Tenstorrent Ascalon、平頭哥玄鐵伺服器核（此前報道）同臺競技。
  3. 安全信任建設成為新議題：USENIX Security 26 論文公開驗證 Spectre 在商業亂序 RISC-V 矽片（含國產 C910/C920）成立，且指出 BPF JIT 缺屏障這一具體軟體缺陷。RISC-V 要進入伺服器/雲信任邊界，安全審計與加固（預測屏障、韌體預設配置、JIT 修復）需與效能敘事並行，相關防禦工作值得持續跟蹤。
  4. 具身智慧運控層迎來國產方案：格見半導體 500 納秒電流環/25 自由度運控晶片與進迭 K3 機器人運控定位，標誌 RISC-V 在機器人”運動控制基座”（此前多由 DSP/專用 MCU 佔據）開啟缺口，與端側 AI 推理（LeRobot 適配）構成完整落地路徑。
  5. 開源高效能核商業化提速：開芯紅超億元種子輪投向香山 IP 核架構升級，XiangShan 視窗內持續合入正確性修復（satp flush 取指錯誤），開源核”社群迭代+商業公司承接”的模式進一步清晰。
