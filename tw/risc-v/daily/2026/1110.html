今日重點：芯來發布 NI1000，首款支援 VME 矩陣擴充套件的 RISC-V 通用 AI 算力核（11-09）

芯來科技 11 月 9 日釋出 NI1000 RISC-V CPU IP，官方稱這是其第一款支援 Vector Matrix Extension（VME）的高效能通用 AI 處理器 IP。NI 系列是芯來面向 AI 應用的單列產品線，可配置為 900 或 1000 系列；RVV 1.0 向量單元（VPU）的 VLEN 可設為 512、1024、2048 或 4096 位，且叢集內每個核可以獨立配置自己的 VPU。核間透過 IOCP（IO Coherent Port）與 NPU 加速器緊耦合並保持快取一致性，NICE／VNICE 介面則允許使用者自定義標量與向量指令，NICE 還能用於與 NPU 的緊耦合互動。

技術要點在 VME 的實現方式。VME 與 CPU、RVV 在同一個核內緊耦合，源運算元直接複用 RVV 的向量暫存器組，運算單元也複用 RVV 的執行單元，只額外增加 Matrix Tiles 的面積；新增的原生矩陣指令把外積結果累加進專用的 N×N 累加器，四套獨立 Matrix Tiles 做乒乓並行以提升吞吐，並新增對 FP8 資料型別的原生支援。芯來給出的資料是：在 NI1020（VLEN 1024）上執行 32×32 的 FP32 矩陣乘法，整體面積只增加 15%（主要是 Matrix Tiles），矩陣乘法效能提升 2.5 倍。

定位講得比較剋制。官方明確寫著 NI 系列不打算取代 NPU、GPU 等加速器 IP，而是與之結合、更好地服務 AI SoC 上的加速器。這一點與 VME 的取捨一致：對比 IME 有獨立矩陣累加硬體、矩陣運算能效更高，對比 AME 省去完整獨立矩陣暫存器堆與硬體矩陣加速器；VME 站在中間，用可控的硬體開銷換矩陣算力，代價是峰值能效不如專用矩陣單元。芯來同時強調 VME 完全以 RVV 為基座，軟體生態可複用，並判斷 VME 會成為最早標準化的 RISC-V 矩陣擴充套件。

把這條放進本月的座標裡看，它補的是「通用算力核」這一層。此前一週的新聞集中在車規 MCU（英飛凌 AURIX RC1）、端側視覺 SoC（為旌 VS815V）與安全核（AMD 的 RISC-V TEE），都是把 RISC-V 放進特定功能單元；NI1000 面對的是 AI 晶片裡那顆「什麼都要幹一點」的通用核——要跑標量控制、要跑向量運算元、還要能承接一般規模的矩陣乘，然後與 NPU 分工。國內 AI 晶片公司長期在這層二選一：要麼外購高效能應用核，要麼自研但背軟體棧。VME 複用 RVV 的路子，實質是把這道選擇題的成本壓低，能不能被客戶接受，取決於工具鏈與運算元庫跟不跟得上。

一、開源社群與軟體生態

openRuyi 主倉單日 20 筆：wlroots 0.20.2、wget2 2.3.0 與 LLVM 22 至 24 的 Python 繫結修正（11-09／11-10）

openRuyi 主倉在視窗內落地 20 筆 SPECS 提交，節奏是典型的「滾動發行版日常」而非集中釋出：桌面棧把 wlroots 升到 0.20.2，網路工具把 wget2 升到 2.3.0，Python 側一口氣更新了 httpx2 與 httpcore2 到 2.13.0、idna 到 3.20、langgraph-sdk 到 0.4.11，並讓 python-pymongo 把 BSON 打進主包。另有幾筆是打包正確性修復：llvm22、llvm23、llvm24 三個包用 sed 把 clang 的 Python 繫結改為連結 libclang，openruyi-linux-build 修掉 devel 檔案衝突並安裝帶版本號的文件。

值得記一筆的是 llvm 那三筆。LLVM 各版本的 Python 繫結長期靠動態庫路徑推斷，發行版打包時若把 clang 的 Python 模組指向靜態庫或錯誤的 soname，使用者在 RISC-V 上裝 llvmlite、triton 這類依賴就會在匯入階段失敗。三個版本同步改成顯式連結 libclang，屬於「裝得上但用不了」這一類問題的根因修復，對做 RISC-V AI 棧的團隊比版本號本身更有意義。

CORE-V CVW 合併 11 筆：16550 UART 的 LSR 錯誤位、SPI 空 RX 歸零與鎖步非對齊豁免（11-09／11-10）

CORE-V CVW 在視窗內合併 11 筆，主線仍是「把外設與驗證環境做紮實」而不是改微架構：16550 UART 補上 LSR（線路狀態暫存器）的錯誤位行為，SPI 在接收 FIFO 為空時讀回零，分支預測重定向的覆蓋率統計加上排除項，鎖步（lockstep）模式對非對齊訪問給出豁免規則，另有一批示例與指令碼整理——刪除 SHA 的 Questa 指令碼、移除 Docker 構建與迴歸指令碼、統一 ruff 與 uv 的指令碼入口。

這組提交與上週「刪兩套區域性分支預測器、公開 RV32GC CoreMark/MHz 4.33」是同一輪收口的兩半。上週動的是效能與面積，這周動的是可驗證性：UART 的錯誤位與 SPI 的空讀語義都屬於「協議規定了、實現裡容易漏」的細節，漏了不會讓核跑不起來，但會讓驅動在錯誤路徑上掛死；鎖步豁免與覆蓋率排除則直接決定驗證報告能不能作為交付證據。對拿 CVW 做車規或工業評估的團隊，這類提交比多跑幾百 MHz 更值錢。

M9B 在 Tang Nano 9K 上搭出 RISC-V 電腦，五款 DOS 時代遊戲跑進 36MHz 軟核（11-09）

開發者 Mika Tammi 的 m9b 專案在 Hacker News 上出現：在一塊售價約二十美元的 Sipeed Tang Nano 9K（Gowin GW1NR-9）上，用 VexiiRiscv 軟核搭出一臺完整的小電腦——36MHz、帶快取、用板載 8MB PSRAM 作記憶體、720×480 HDMI 影片、48kHz 音訊、兩個 USB 口接鍵鼠、SD 卡存程式。開機進一個列出 SD 卡程式的介面，能跑五款 DOS 時代遊戲，且都帶音效與音樂：Doom（shareware，timedemo 約 22 fps）、Descent（約 10 fps）、Tyrian 2.1（滿速 35 fps）、System Shock（約 7 fps）、Ultima VII（兩套引擎，7 至 13 fps）。

這類專案的價值不在「能玩遊戲」，而在把「一臺電腦最少需要什麼」這條線畫出來。9K 的邏輯資源裝不下亂序核，也裝不下 Linux 級別的記憶體管理，於是取捨變得非常具體：要 HDMI 就得砍快取，要音效就得把音樂預先渲染成流從卡里讀。專案把 SoC、執行時、五套遊戲移植與 SD 卡映象拆成獨立倉庫並全部開源，每個倉庫都寫明改動了上游哪裡——對做 RISC-V 教學板與 FPGA 上手的團隊，這是一份可直接複用的工程分層樣本。

二、產品與生態動態

M5Stack Core Matrix 用 ESP32-C61 加 16×16 LED 矩陣，29.99 美元開賣（11-09）

M5Stack 推出 Core Matrix，一顆基於 ESP32-C61 的 IoT 控制器：SoC 為 ESP32-C61HR8，單核 32 位 RISC-V 最高 160MHz，320KB SRAM 加 8MB PSRAM、16MB QSPI flash，2.4GHz Wi-Fi 6 與藍芽 LE 5.0；正面是 16×16 白光 LED 矩陣（256 顆，TM1680 驅動），配 Bosch BMI270 六軸 IMU、microSD、無源蜂鳴器、三個使用者按鍵與電源鍵，擴充套件走 30 pin M5-Bus 與 Grove I2C，支援 USB 或 3.7V 外接電池供電，尺寸 54×54×11.6mm，售價 29.99 美元。軟體側支援 Arduino IDE 與 UIFlow2，提供 M5Unified、M5GFX 與電源管理晶片的驅動庫。

這塊板的意義是把「顯示」從螢幕換成點陣。ESP32-C61 是樂鑫面向低成本 Wi-Fi 6 的 RISC-V 型號，算力與記憶體都不足以驅動 LCD，但足以驅動 256 顆單色 LED 並跑狀態機與聯網邏輯；用點陣做圖示、動畫與通知，等於在「沒有螢幕」與「有螢幕」之間補了一檔。對做桌面狀態燈、機房指示器與低成本互動裝置的團隊，這是一個現成的參考形態，價格也落在可以批次鋪開的區間。

日期：2026-11-09　來源：CNX Software 報道

英飛凌 AURIX RC1 的 RISC-V 核被指來自 MIPS IP、由格芯代工（11-09）

Design And Reuse 11 月 9 日轉載 jonpeddie.com 的分析，指出英飛凌 AURIX RC1 採用的是 MIPS 的處理器 IP，由 GlobalFoundries 代工，並稱這是 MIPS 與格芯在 RISC-V 上的一筆重要設計勝利。文章同時提出一個問題：RISC-V 是否會最終取代英飛凌自有的 TriCore 架構。此前 11 月 4 日英飛凌釋出 RC1 時，官方口徑是「首條基於 RISC-V 的車規 MCU 平臺、TriCore 系列繼續供貨」，未展開 IP 來源。

這條補的是供應鏈層的空白。車規晶片公告通常只講平臺與生態，不講核從哪來；而對做國產車規 RISC-V 的團隊，核的來源直接決定兩件事——功能安全證據鏈由誰提供（ISO 26262 ASIL D 的 IP 級證據不是整機廠能自己補的），以及產能與製程落在哪家代工廠。MIPS 在被格芯收購後把路線整體轉到 RISC-V，這次若確為 RC1 的核供應商，等於「RISC-V 車規核」這個市場多了一個有代工廠背景的玩家；對國內 IP 廠商，這是一個需要正面對比的競爭者，而不是遠處的概念。

三、國內團隊深挖

平頭哥擬 2027 年赴港 IPO，募資 20 億至 30 億美元（11-09）

多家媒體 11 月 9 日援引路透社報道，阿里巴巴旗下晶片公司平頭哥半導體計劃於 2027 年在香港交易所上市，目標募資 20 億至 30 億美元（約 156 億至 234 億港元）。公開資訊顯示，平頭哥 2018 年 10 月由中天微與達摩院晶片團隊整合成立，產品覆蓋 AI 加速晶片（真武系列）、Arm 伺服器 CPU（倚天系列）、RISC-V 處理器 IP（玄鐵系列）與儲存主控等；2026 年 3 月阿里 CEO 吳泳銘在財報電話會上披露，平頭哥晶片累計出貨超過 47 萬片、年化營收超過百億元，8 月披露真武系列已服務超過 650 家客戶、外部付費客戶佔比超過六成。9 月雲棲大會發布的真武 V900 標稱 216GB 視訊記憶體、1200GB/s 片間頻寬，計劃 2027 年第一季度量產。

需要把口徑分清楚：報道把玄鐵系列 RISC-V 處理器 IP 計入平頭哥的產品線，而玄鐵團隊 2024 年已轉入達摩院、專做 RISC-V 處理器（C950 一類），平頭哥自身的產品重心是 PPU（AI 加速卡）與倚天（Arm CPU）；「玄鐵累計出貨 60 億顆」是集團層面的歷史累計口徑，不等於當前由平頭哥經營。上市主體最終如何切分資產、玄鐵 IP 歸屬是否隨之調整，目前沒有披露，這也是這條訊息最需要跟蹤的部分。

對 RISC-V 產業，IPO 本身不改變技術路線，但會改變資本對這條賽道的定價方式。過去兩年國內 RISC-V 公司的估值錨是「替代空間」，平頭哥若以百億元級年化營收、六成外部客戶的身份上市，錨就換成「已商業化的算力供應商」；這對正在融資的 RISC-V 伺服器、AI 晶片與 IP 公司是雙向影響——可比公司變清晰了，但資本市場也會用同一套營收與毛利標準來要求它們。

進迭時空：ggml-spacemit 單日四筆，門控 delta 網路用 RVV 與 TCM 重寫（11-09）

spacemit-com 的 llama.cpp fork（mtmd-backend 分支）在視窗內合併四筆 ggml-spacemit 後端提交：用 RVV 與 TCM 最佳化迴圈版門控 delta 網路（#54）、按 head size 對門控 delta 網路做展開特化（#59）、最佳化 MoE 矩陣乘並新增稠密 Q4_0 與 F16 的 GEMM（#53），以及修掉 softplus 缺少 log1p 項的實現錯誤（#57）。

四筆湊在一起，指向的是同一類模型結構。門控 delta 網路（GDN）是線性注意力一系的迴圈層，推理時每步只做小規模矩陣運算，瓶頸不在算力而在訪存與狀態駐留——這正是 TCM（緊耦合記憶體）該用的地方；把 head size 作為特化維度展開，則是為了消掉內層迴圈的分支與索引開銷。MoE 矩陣乘與 Q4_0／F16 GEMM 是另一條線：K3 的向量單元要同時伺候稀疏專家路由與低位元稠密層，缺一條都會讓整機吞吐掉到下一個檔。softplus 那筆最不起眼，但 log1p 缺失屬於數值穩定性問題，長序列推理會累積成可見偏差。

四、具身智慧與機器人專章

MIPS Actus 用雙顆 Atlas M8500 實時 RISC-V 核做機器人關節，帶 TSN 與後量子安全（11-09）

MIPS（已被格芯收購）11 月 9 日在 electronica 2026 前釋出 Actus 參考平臺的進展：一顆面向緊湊機器人關節的晶片，把確定性電機控制、機器人體內網路與邊緣推理放在同一顆 die 上，基於格芯的 FDX FD-SOI 工藝。核心是兩顆 MIPS Atlas M8500 實時 RISC-V 處理器，用硬體多執行緒消除中斷服務時的上下文切換開銷；專用三角函式加速在磁場定向控制（FOC）演算法上比標準三角函式庫快 16 倍以上；配 100 皮秒級高解析度 PWM 與 sigma-delta ADC 驅動大電流電機，另用 ARC VPX 512 位向量單元在同一顆晶片上跑感測器融合與預測性維護模型。

系統側同樣給足了：三埠時間敏感網路（TSN）千兆乙太網加 CAN-FD 與串列埠，讓各關節控制器與中央控制器交換位置與力矩資料；片內硬體安全模組支援後量子密碼，並對功能安全提供支援。Actus 與 Acies（推理原生平臺）、Aegis（安全原生 CPU 平臺）共同構成 MIPS 的物理 AI 產品線。

這條的分量在「關節」這個位置。人形機器人的算力敘事長期集中在大腦（誰家的 NPU、多少 TOPS），而真正卡量產的是從肘到指尖這一段：空間、功耗、散熱都極緊，卻要求平滑的人形運動與確定性時序。把雙實時核、電機控制外設、TSN 與安全模組塞進一顆關節晶片，等於把「大腦給指令、關節自己閉環」這套分散式架構做成可採購的器件。對國內做機器人關節與實時控制的團隊，這是與「MCU 加外接驅動」路線正面對比的一種方案，關鍵差異在硬實時與網路確定性，而不在算力。

日期：2026-11-09　來源：MIPS 新聞稿

spacemit-robotics：unitree-go2 支援 smallcore 電機通訊，perception 把推理執行時打包進 las2（11-09）

spacemit-robotics 的 unitree-go2 倉庫合併 #6，新增對 smallcore 電機通訊的支援（feat/smallcore-motor-tra… 分支）；perception 倉庫有兩筆圍繞 las2 的修正：把匹配的推理執行時打包進發布物（#14），並在此之前先把打包進原始碼倉庫的模型檔案移除（#13）。

兩件事都指向「交付形態」。unitree-go2 是宇樹 Go2 四足機器人在 K3 平臺上的移植工程，此前已經做完 IMU 快照讀取、地形行走策略與模型下載；補 smallcore 電機通訊，意味著控制鏈路要能對接不同批次的關節驅動板，這是把 demo 變成可復現工程必須過的一關。perception 的 #13 與 #14 是一對：先把大模型檔案從原始碼倉庫剝離（避免倉庫膨脹），再把推理執行時隨釋出物一起打包（避免使用者自己找依賴）——一減一加，說明這套感知棧開始按「可安裝的軟體包」而不是「一堆指令碼」來組織。

五、總結與趨勢觀察

一、AI 晶片的「通用核」這一層開始有專用產品。 芯來 NI1000 用 VME 把矩陣能力嫁接到 RVV 上，面積只加 15%、矩陣乘法快 2.5 倍，定位是與 NPU 分工而不是取代。這與過去兩年「誰的 NPU 峰值高」的敘事不同：AI SoC 裡那顆通用核長期靠外購應用核或自研大核解決，現在出現了第三條路——以向量為基座、按需加矩陣。真正的門檻不在 IP，而在運算元庫與編譯器能否把 VME 用起來。

二、機器人關節成了 RISC-V 實時核的新戰場，且路線開始分叉。 MIPS Actus 用雙顆 Atlas M8500 加 TSN 與後量子安全做關節級單晶片，國內 spacemit-robotics 則繼續在 K3 上做四足移植與控制鏈路適配。前者賣的是器件與實時性保證，後者攢的是可復現的工程與生態；兩條路都說明一件事：具身智慧的算力競爭正從「大腦」下沉到「小腦與關節」，而這一層的評價標準是確定性與功耗，不是 TOPS。

三、國內側的資本市場動作開始影響技術敘事。 平頭哥擬 2027 年赴港 IPO、募資 20 億至 30 億美元，若成行，RISC-V 與國產 AI 晶片公司第一次有了「已商業化、有外部客戶、有營收」的可比標的。需要留一分清醒：報道把玄鐵 IP 計入平頭哥產品線，而玄鐵團隊 2024 年已轉入達摩院，上市主體的資產邊界尚未披露；對產業觀察者，接下來要看的不是估值，而是招股材料裡外部客戶收入與關聯交易的切分方式。

四、軟體側的進展集中在「裝得上、用得了」這類細節。 openRuyi 單日 20 筆裡，llvm22 至 24 的 Python 繫結改為顯式連結 libclang 是最有代表性的一筆——它不提升任何指標，卻決定 RISC-V 上能不能正常裝 llvmlite 與 triton；CORE-V CVW 這一週合併的 UART LSR 錯誤位、SPI 空讀歸零與鎖步豁免，同屬「不影響跑分、影響能不能交付」的類別；算能把 bootloader 的兩代平臺構建鏈收斂、進迭把數字人管線收進 Bianbu 品牌，也都是從 demo 走向維護的動作。

五、平靜的新聞面與不平靜的倉庫面。 本期 Google News 側的有效新增只有芯來 NI1000、MIPS Actus、M5Stack Core Matrix 與英飛凌 AURIX 的 IP 來源四條，另有為旌 VS815V、AMD RISC-V TEE、Openchip BER10 三條屬舊聞二次傳播，已在此前報告收錄，本期不重複。這與上週的節奏一致：大廠釋出稀疏，但 GitHub 側的提交密度在上升——進迭、算能、芯來、openRuyi 與 CORE-V 在同一個 24 小時裡合計有 60 餘筆可核對的提交。

侷限性說明：本機匿名訪問 GitHub API 在採集時段觸發每小時 60 次的限流，組織與倉庫活躍度改由 GitHub 組織頁嵌入資料與各倉庫 Atom 提交流獲取，不消耗 API 額度；因此「視窗內有推送」的判定以預設分支提交時間為準，非預設分支的推送（如進迭的 wip 分支）可能被低估。達摩院玄鐵與奕斯偉的「零推送」結論同樣受此方法約束，僅表示預設分支在視窗內無提交。Google News 的中文查詢仍有博彩與股市稿噪音，已按標題語義剔除；RISC-V 會員官網巡檢的 108 項「變化」均為首頁營銷輪換或安全攔截頁，未發現實質產品與架構釋出。
