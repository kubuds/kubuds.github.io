今日重點：Qualcomm 收購 RISC-V 伺服器 IP 公司 Akeana，美系大廠加速收攏架構資產

日期：2026-10-21　來源：Dealroom：Qualcomm buys RISC-V startup Akeana to push into AI and data-center chips（10-21）、Sammy Fans：Qualcomm acquires Samsung foundry partner Akeana to expand AI chip business（10-21）

據 10-21 報道，Qualcomm 已完成對 RISC-V 處理器 IP 初創公司 Akeana 的收購，交易金額未披露。Akeana 創始人兼 CEO Rabin Sugumar 已在職業社交平臺確認，Akeana 的 IP 與團隊「已成為 Qualcomm 的一部分」，其本人加入 Qualcomm 出任工程副總裁。

  • 公司背景：Akeana 成立於 2021 年，核心團隊出自 Marvell／Cavium 的 ThunderX 伺服器處理器團隊；2024 年 8 月走出隱身狀態並披露融資超過 1 億美元（Kleiner Perkins、Mayfield、Fidelity 等參投），IP 覆蓋 Akeana 100／1000／5000 三檔（MCU 級 32 位核、帶 MMU 的 64 位核、面向筆記本與資料中心的超高效能核），並提供 AI 矩陣計算引擎與安全、除錯、RAS、遙測等系統 IP。
  • 產業側線索：Akeana 與三星代工合作推進 4nm 伺服器晶片，2025 年 12 月雙方完成代號 Alpine 的伺服器測試晶片設計，這是本條與「三星代工生態」直接相關的地方。
  • Qualcomm 的連續動作：2025 年 12 月 Qualcomm 收購 RISC-V 伺服器 CPU IP 公司 Ventana Micro Systems；此後完成對 Alphawave 的 24 億美元收購，並與 Amazon 公佈定製 AI 推理合作。加上本次 Akeana，Qualcomm 在 10 個月內收進兩家 RISC-V 伺服器 IP 團隊。
  • 解讀邊界：交易金額、客戶承諾與產品時間表均未公開，Akeana 的 IP 線是否併入 Qualcomm 自有 CPU 路線（Oryon）還是獨立產品線，目前沒有官方說明；本條只做事實層面的併購確認，商業回報尚待觀察。

與國內路線的對照：同一周內，進迭時空聯合香山釋出伺服器級 CPU V100（6 個香山昆明湖 V2R2 核 + 40 個自研 X100 核，46 核），走的是「開源核＋自研核混合」的產品化路徑。海外是 IP 團隊向大廠集中，國內是開源核向商用晶片滲透，兩條路徑都在回答同一個問題：伺服器級 RISC-V 的 IP 供給從哪裡來。

1.1 RISE 釋出首個基於 RVA23 的 Android 17 開源版本

日期：2026-10-20　來源：RISE：Android 17 Available on RVA23 with RISE（10-20）、RISE android_manifest：android-17-v1.0（10-20）

RISE 專案宣佈交付首個執行在 RVA23 硬體上的 Android 17 構建，以開源形式釋出，支援 SpacemiT K3 Pico-ITX 與阿里巴巴 A210 EVB 兩塊板卡。該專案編號 RP024，由 RISE 出資並牽頭，成員單位 進迭時空與阿里達摩院提供平臺經驗與硬體，BayLibre 承擔工程實現，建立在其此前 SpacemiT K1 的 Android 移植基礎上。

  • 釋出內容：android-17-v1.0 提供兩塊板卡的二進位制映象、鎖定版本的原始碼 manifest、校驗和、燒寫工具與重建說明，原始碼歷史與作者資訊完整保留，可復現、可擴充套件。
  • 開放程度：採用 U-Boot + OpenSBI 的開源啟動鏈，圖形棧基於上游 Imagination 核心驅動與 Mesa；官方明確這是面向開發者的開源版本，不是量產或認證版本。
  • 下一階段：RP024 第二階段將把構建、硬體測試與釋出流程自動化，先在 RISE Board Farm 已有的 A210 系統上跑測試，數週內加入 K3；RISE 還預告後續 RFP 將覆蓋 Bionic、BoringSSL、ART、V8、Chrome 與多媒體庫，並推動廠商把平臺支援回灌 Linux 核心、U-Boot 與 OpenSBI。

RVA23 是 RISC-V 應用處理器的規範分水嶺，Android 17 在其上跑通並開源，意味著「移動作業系統 + 應用處理器規範」這條最苛刻的組合第一次有了可復現的公共基線。

1.2 Linux 7.4 加密庫：RISC-V 與 x86 的 AES 最佳化實現併入 lib/crypto

日期：2026-10-21　來源：Phoronix：Linux 7.4 Kernel Crypto Library Enjoying Optimized AES Implementations On x86 & RISC-V（10-21）

Google 核心工程師 Eric Biggers 的加密子系統效能工作已合入 Linux 7.4：把 x86／x86_64 與 RISC-V 的 AES 各模式最佳化實現遷移進 lib/crypto 核心加密庫。

  • 覆蓋模式：ECB、CBC、CBC-CTS、CTR、XCTR、XTS 六種；遷移後庫 API 在這些架構上直接獲得加速，crypto_skcipher 一側的使用同樣繼續受益。
  • x86 側：走 AVX 最佳化程式碼與 AES-NI 指令；RISC-V 側為基於向量與加密擴充套件的加速實現。
  • 附帶收益：清理掉大量重複的膠水程式碼，減少維護面。同批更新還包括開發者 Stian Halseth 為 SPARC64 編寫的 AES-XTS 最佳化實現。

對 RISC-V 而言，這條的價值不在「又一個最佳化提交」，而在落點：加速實現從架構私有目錄搬進通用庫，核心內其它消費者（檔案系統加密、IPsec、dm-crypt 等）無需改動即可受益，屬於基礎設施層的可複用收益。

1.3 openRuyi：20 筆 SPECS 提交，uv 的 Rust 依賴成批入庫

日期：2026-10-22　來源：openRuyi 主倉提交記錄（10-22）、openRuyi 官網新聞頁

openRuyi 主倉在視窗內錄得 20 筆提交，集中在 10-22 凌晨的一批 SPECS 入庫，全部為 rust-uv-* 0.0.96 系列包：pep440、pep508、platform-tags、pypi-types、options-metadata、normalize、toml、version、small-str、globfilter、git-types、fs、errors、logging、macros、redacted、static、preview、warnings、windows。

這批包是 uv（Rust 編寫的 Python 包與專案管理器）的依賴元件。上一期日報記錄的 40 筆提交集中在 minio、Prometheus、sarama 等 Go 雲原生元件，本期轉向 Python 工具鏈，兩天連起來看，openRuyi 正在把「資料中心常用服務」與「Python 開發工具鏈」兩類軟體補齊到 RISC-V 發行版裡。官網新聞頁最新公告仍為 2026.09 版本，視窗內無新版本釋出。

2.1 樂鑫 ESP-Mosaico 開售：ESP32-S31 模組化 AI 硬體套件，59 美元起

日期：2026-10-21　來源：CNX Software：ESP-Mosaico — An ESP32-S31-based modular development platform for AI-assisted hardware creation（10-21）、Mosaico 商店

樂鑫推出 ESP-Mosaico：一塊以 ESP32-S31 為核心的模組化開發平臺，主打「AI 與硬體結合」，面向磁吸擴充套件玩具、運動感知、方形觸控 HMI 與邊緣語音／多媒體場景。

  • 核心板：ESP32-S31NRV16（320MHz RV32IMAFCP 高效能核＋低功耗 MCU 核，512KB SRAM＋32KB 低功耗 SRAM＋16MB PSRAM），Wi-Fi 6、藍芽 5.4（含 LE Audio、方向查詢、Mesh 1.1 與 Classic）、802.15.4；128MB SPI NAND＋16MB SPI NOR。
  • 人機與外設：2.16 英寸 480×480 QSPI 觸控式螢幕（CO5300＋CST9220）、NS4150B 功放與 ES8311 編解碼、雙 BMM150 磁力計、BMI270 六軸、振動馬達、USB-C 供電與燒寫；底板透過 60 針板對板聯結器擴充套件，含揚聲器與 3.7V／65mAh 電池。
  • 模組化：已推出攝像頭模組（OV3640 3.2MP 或 SC101IOT）與多功能互動模組（光敏、PIR、紅外 LED、6 顆 WS2812、機械鍵／電容觸控焊盤）。
  • 開發方式：官方給出兩條路徑——透過 ESP-Claw 的自然語言「對話式編碼」，以及透過 ESP-ZeroCode AI 的「氛圍程式設計」，由 AI 代理承擔實現、部署、真機測試與迭代。
  • 價格與狀態：含攝像頭與互動模組的完整套件 59 美元，電池模組 15 美元；此前已在淘寶與第三方渠道銷售數月，現由官方商店正式開售。

ESP32-S31 從「預覽器件」走向成品套件只用了約兩個月（10-14 才出現首款第三方開發板），而這一代產品把開發體驗本身當成賣點：自然語言生成韌體、AI 代理跑真機測試，這是 RISC-V MCU 在端側與 ARM 生態競爭時少見的差異化切口。

三、國內團隊深挖

3.1 達摩院玄鐵開出 CubeSandbox RISC-V 支援分支：CubeShim 對接 KVM／AIA VMM 後端

日期：2026-10-21　來源：XUANTIE-RV/CubeSandbox：add_riscv_support 分支（10-21）、TencentCloud/CubeSandbox 上游倉庫

達摩院玄鐵（XUANTIE-RV）在 GitHub 上維護的 CubeSandbox 分支 add_riscv_support 視窗內有新提交：註冊 riscv64-control-plane-demo.yml 工作流供手動觸發。CubeSandbox 是騰訊雲開源的 AI Agent 沙箱服務（Apache 2.0，硬體級隔離、毫秒級啟動、相容 E2B 介面，已進入 CNCF Landscape），玄鐵分支在做的正是把它移植到 RISC-V。

  • 構建路徑：make all-riscv64 可交叉編譯架構無關的控制面、guest 工具、Cubelet 與 CubeVS／eBPF，交叉構建映象自動生成；guest 核心用 make guest-kernel KERNEL_TARGET_ARCH=riscv64 單獨構建。
  • 冷啟動：CubeShim 已改為對接實驗性的 RISC-V KVM／AIA VMM 後端，支援直接核心冷啟動。
  • 現狀邊界：RISC-V 側快照／恢復仍關閉，需等 vAIA 狀態遷移實現；官方未提供釋出映象與受支援的部署路徑，屬開發者預覽階段。

AI Agent 的程式碼執行沙箱是今年增長最快的一類基礎設施，其底層依賴虛擬化與特權指令的完整度。玄鐵把這條棧搬上 RISC-V，指向的是「RISC-V 伺服器能不能承載 Agent 工作負載」這一具體命題，也是 RISC-V 在 AIA（高階中斷架構）落地後最直接的應用側驗證。

3.2 奕斯偉計算與 SiFive 簽署黃金合作伙伴聯盟 MOU，合作從邊緣 AI 擴充套件到 Agentic AI

日期：2026-10-21　來源：網易（華商韜略）：奕斯偉計算與 SiFive 簽署黃金合作伙伴聯盟 MOU（10-21）、觀點網：奕斯偉計算與 SiFive 簽署黃金合作伙伴聯盟 MOU 深化 RISC-V+AI 合作（10-21）

奕斯偉計算與 RISC-V 處理器 IP 企業 SiFive 正式簽署黃金合作伙伴聯盟備忘錄（Gold Partner Alliance MOU）。這是奕斯偉計算 10-09 在港交所上市後推進的一項國際產業合作。

  • 合作基礎：奕斯偉計算的 EIC7700 SoC 已用於 SiFive 旗艦開發板 HiFive Premier P550，面向全球開發者提供高效能 RISC-V 硬體平臺並已規模化上市，雙方技術協同已有可核驗的產品。
  • 升級方向：合作從邊緣 AI 擴充套件到 Agentic AI 等應用，共同挖掘低功耗、高效能 AI 方案需求，並按客戶整合訴求探索多層級 RISC-V 產品形態。
  • 雙方定位：SiFive 由 RISC-V 指令集創始團隊成員創立，強在架構與核心 IP；奕斯偉計算強在產品落地與商業化，公司口徑為國內領先的 RISC-V 主控晶片提供商之一。

值得注意的是合作的時間點：奕斯偉上市後第一筆公開的國際合作不是產能或代工，而是與 IP 供應商的聯盟升級。對照同期 Qualcomm 直接收購 IP 團隊的做法，國內廠商選擇了「自研核＋外部 IP 聯盟」的混合路線。

3.3 算能 sophon-demo 完成 CV84X6 適配：新增 MiniCPM4、InternVL3 與 MiniCPMV 樣例

日期：2026-10-21　來源：sophgo/sophon-demo 提交記錄（10-21）

算能（Sophgo）示例倉庫 sophon-demo 在 release 分支合入提交「CV84X6 適配：MiniCPM4 + InternVL3 + MiniCPMV」，為 CV84X6 平臺補上三個多模態／端側大模型樣例。

  • 模型覆蓋：MiniCPM4（端側小引數語言模型）、InternVL3（多模態視覺語言模型）、MiniCPMV（面壁智慧的多模態端側模型）——三者都屬端側部署取向，與算能 SoC 的邊緣推理定位一致。
  • 倉庫節奏：近期同倉還有 PaddleOCR-VL、SAM3、SAM2、BLIP、MP_SENet、YOLO_world 的 C++ 樣例新增，示例庫正從 Python 參考實現向 C++ 工程化樣例擴充套件。
  • 同視窗其他提交：zsbl 主分支 1 筆，把應用選擇上移到 SoC 級 Kconfig，屬啟動韌體的結構性整理。

端側晶片的競爭力越來越取決於「模型到了能不能跑、跑得動不動」——把當年最熱的多模態模型在自家平臺上補齊樣例，比賽道宣傳更實際。

4.1 峰會汽車電子、工業與機器人分論壇：紫荊 M100 量產上車，IAR 與芯來補齊工具鏈與 IP

第六屆 RISC-V 中國峰會七大平行分論壇（10-20）的回顧報道，把汽車電子、工業與機器人方向的具體進展攤開：

  • 紫荊半導體：長城汽車孵化的晶片公司，其 紫荊 M100 已成為量產上車的 RISC-V 車規晶片。整車廠內部孵化的 RISC-V 車規產品從樣片走到量產，是這一輪「上車」敘事裡最硬的證據。
  • IAR：從工具鏈視角提出 RISC-V 在汽車、工業與機器人領域的三大挑戰，並推出 RISC-V 開發工具，主打安全關鍵場景的合規開發。
  • 芯來科技：分享 RISC-V 在 AI 晶片中的 IP 方案，強調動態向量長度、可擴充套件指令集與統一軟體生態，覆蓋雲端到 MCU 的全場景 AI 算力。
  • 兆松科技：參與實時控制與車規 MCU 架構落地議題；同分論壇還有阿里達摩院介紹車規路線圖。

分論壇的整體口徑是「RISC-V 已從能不能用進入好用、商用階段」，但落到工程細節，討論的仍是安全認證、實時控制、工具鏈合規這三件難事——恰恰是機器人關節控制與車規底盤域控的共同門檻。

4.2 機器人算力側由融資敘事轉入量產驗證：關節控制晶片已量產，大腦晶片仍處流片階段

日期：2026-10-21　來源：人民網（北青網）：2026 RISC-V 中國峰會分論壇傳遞產業新訊號（10-21）、東方財富：智元機器人 47 次出手投了什麼（10-20）

24 小時視窗內，具身智慧方向沒有新的獨立融資或整機發布，可核驗的進展集中在產能與驗證環節：

  • 量產側：芯際無限的機器人關節控制晶片已量產，面向中端算力的 XC64AE 已啟動與頭部具身智慧企業的量產驗證，首款小腦晶片完成流片回片；車規側智慧電機控制 MCU 出貨突破 100 萬顆，2026 年新簽訂單 520 萬顆。
  • 未落地部分：定位大腦的 V1000（2.5D Chiplet，設計算力 1000 TOPS）仍處流片階段，第二代 XC64AE 全系列計劃 2027 年流片。
  • 資本側：智元機器人入股芯際無限（Pre-A 輪）後，其投資版圖已覆蓋本體、關鍵零部件與底層算力晶片；本體廠商以資本鎖定上游，使指令集選擇在早期就被繫結。

這條線索的意義在於節奏差：小腦與關節控制這類實時、低算力、強認證的環節已進入量產，而大算力的「大腦」晶片仍在流片與對標階段。RISC-V 在機器人上的第一波真實出貨，很可能來自關節與運動控制，而不是通用 AI 算力。

五、總結與趨勢觀察

  • 伺服器 IP 的歸屬正在集中：Qualcomm 十個月內收進 Ventana 與 Akeana 兩家 RISC-V 伺服器 IP 團隊，獨立 IP 供應商的數量在減少；國內則把開源核（香山昆明湖 V2R2）裝進商用伺服器晶片（V100）。同一周的兩件事，說明伺服器級 RISC-V 的 IP 供給正在分化為「大廠內部資產」與「開源核產品化」兩條路。
  • Android on RVA23 是平臺化節點，不是又一次移植：RISE 這次給的是鎖定 manifest、校驗和、燒寫工具與重建路徑，加第二階段的全自動構建與 Board Farm 測試。可復現、可迴歸，才是應用處理器生態真正的門檻。
  • 效能工作從架構私有走向通用複用：Linux 7.4 把 RISC-V 與 x86 的 AES 各模式實現搬進 lib/crypto，刪掉重複膠水程式碼。這類改動不顯眼，但讓加密、儲存、網路等上層消費者自動受益。
  • 發行版補齊的層次在上移：openRuyi 前一天批次入庫 Go 雲原生元件，這一天把 uv 的 20 個 Rust 依賴打包進 SPECS。從核心、工具鏈到 Python 開發工具，RISC-V 發行版的「可日常使用」正在被逐層填滿。
  • 端側競爭轉向開發體驗：ESP-Mosaico 以 59 美元套件、自然語言生成韌體、AI 代理跑真機測試作為賣點。當晶片規格趨同，誰能把「從想法到硬體」的路徑縮短，誰就更容易拿到開發者。
  • 車規與機器人仍是國內落地主線：紫荊 M100 量產上車、芯際無限關節控制晶片量產、奕斯偉與 SiFive 的 IP 聯盟，三條線分別對應整車、機器人與通用 IP 供給。峰會口徑樂觀，但認證、實時性與工具鏈仍是決定性變數。
  • 侷限說明：Qualcomm 收購 Akeana 的交易金額、客戶承諾與產品整合方案均未披露，現有資訊來自 Dealroom 與 Sammy Fans 的報道及當事人社交平臺確認，未見 Qualcomm 官方新聞稿；RISE 的 Android 17 屬開發者版本，明確不適用於量產；Linux 7.4 加密庫條目依據 Phoronix 報道，未逐條核對補丁；openRuyi 的 uv 依賴入庫僅從提交標題判斷用途，未見發行版公告；Radxa Linkr v1.6.0 未附變動清單；峰會分論壇內容來自媒體回顧報道，廠商口徑未必經第三方驗證；會員官網巡檢檢出的變化均為高校、機構與廠商官網的例行更新，未發現實質產品、融資或架構釋出；香山系與部分重點倉庫 pushed_at 顯示有推送，預設分支複核視窗內無新提交，判斷為非預設分支或 PR 頭分支活動。
