一、開源社群與軟體生態

1.1 香山：RVV 向量除法指令合入，Smmtt 擴充套件解碼重開，Bpu/FMA/CSR 多路修復

日期：2026-09-11 ~ 2026-09-13　來源：OpenXiangShan/XiangShan 提交記錄

視窗內香山主倉共 9 次提交，節奏延續”向量通路重構後轉收斂”的判斷。功能新增方面：zhaozukang 於 09-12 合入 feat(vector): support vector divide instruction，向量除法指令落地；Xuan Hu 於 09-11 提交 feat(decode): add back conditional Smmtt extension support，將被移除的 Smmtt（Supervisor 域與可信執行環境記憶體管理）擴充套件支援以條件 decode 方式重新加入，並同步重構 pass extensions to decode fields 的解碼引數傳遞；HuSipeng 於 09-11 新增分支預測單元 s2_override。缺陷修復集中在浮點與 CSR：Guanghui Cheng 於 09-11 修正 FMA 加數的 NaN-boxing 判斷（#6532），並修復 CSR 讀改寫過程中 LCOFIP 位丟失（#6522）；Zhihao Xu 於 09-11 修復 ICache 兩取指 replacer 的 touch 行為（#6416）。清理側，Xuan Hu 於 09-13 移除後端過時的 VL 非零狀態並清理向量無用類與方法。配套倉庫方面，XSAI（面向 AI 的香山分支）09-11 提交 difftest 子模組升級（#128）；XSCache（開源 L2/LLC 快取）與 YunSuan（功能單元庫）視窗內無新提交（最近分別為 08-31、09-10）。

1.2 CVA6：視窗內八次提交，PMP 與觸發器規則、Zcmp IDLE 門控、xRET 修復集中落地

日期：2026-09-11 ~ 2026-09-13　來源：openhwgroup/cva6 提交記錄

開源六發射應用級 RISC-V 核 CVA6 在視窗內共 8 次提交，以特權態與除錯正確性為主：Maanvi212006 於 09-13 要求 HLVX 訪問必須具備執行許可權（#3413，修正 PMP 與 Hypervisor 訪存許可權組合）；Flavien Solt 於 09-11 集中修復除錯觸發器語義，包括 NAPOT 地址匹配（#3488）、dmode 觸發器寫入規則（#3487）與 LoadAddr 觸發器動作保留（#3491）；Keerthivasan Palani 於 09-11 修復無 RVH 時 xRET 的 MPRV 處理（#3551）、單步執行下 WFI 停頓（#3525），並將 Zcmp 的 IDLE 狀態遷移改為以 issue 應答為門控（#3543）；Téo Biton 於 09-11 為分支預測結構補充有效位（#3550）。整體看，本週提交集中在”特權/除錯邊界條件正確性”，屬典型的功能驗證驅動推進；CVA6 亦被 riscv.org 列為效能模型驅動的超標量開源核案例。

2.1 2026 IICIE 國際積體電路創新博覽會在深圳落幕：設 RISC-V 產業生態創新大會與生態應用展示區

2.2 英飛凌在 Hot Chips 2026 講 RISC-V 汽車：新一代車規 MCU 走 RISC-V 路線，勝負手在車規工具鏈

日期：2026-09-13　來源：ServeTheHome

英飛凌在 Hot Chips 2026 的演講實錄於視窗內刊發，核心是車規 MCU 的計算需求與 RISC-V 的定位。英飛凌給出的需求畫像為：底盤、動力總成與 ADAS 合流要求實時低延遲、高能效與安全性共存，併疊加最高完整性等級與功能安全；其中電機控制一類快控制環需要 10 毫秒內截止、中斷延遲在數十納秒量級，而整車管理類策略功能可容忍數秒與 10 毫秒級中斷延遲。英飛凌強調，RISC-V 規定的是指令集架構而非實現細節，指令延遲、儲存層次、快取一致性與鎖步、錯誤追蹤等功能安全特性仍由晶片設計方決定，這正是汽車差異化的所在；在 MCU 場景，真正決定勝負的屬性是儲存器、連線性、專用硬體、供貨與最終 BOM 成本，而”是否有車規認證工具鏈”決定誰能勝出。結論層面，英飛凌把 RISC-V 與區域控制器（zonal controller）角色直接繫結：RISC-V 可加速區域控制單元落地，但應用適配與成本由 SoC 架構、生態推動與部署便利性共同決定，長期採用取決於標準化的軟硬體介面與工具鏈支援。該廠商此前已明確新一代 AURIX 車規 MCU 基於 RISC-V。

2.3 樂鑫 ESP32-P4 跑起《古墓麗影》：雙核 400 MHz RISC-V 軟渲染 30 FPS，25 美元級開發板

日期：2026-09-13　來源：Tom’s Hardware、GitHub openlara_esp32p4

開發者 alexkid77 將開源引擎 OpenLara（初代《古墓麗影》引擎重實現）移植到樂鑫 ESP32-P4：該 SoC 為雙核 400 MHz RISC-V（帶 AI 指令擴充套件），配 16 MB Flash、32 MB PSRAM，工程以 320x240 軟體渲染配合晶片內建畫素處理加速器（PPA）硬體放大到 1024x600 顯示，實現 30 FPS，並接入 I2S 加 ES8311 音訊、USB HID 鍵盤、GT911 觸控與 microSD 儲存，另支援 MP3/OGG 解碼與在屏 FPS 計數。硬體平臺為 ESP32-P4-Function-EV-Board，整板價位在 25 美元級、功耗約 1 瓦。技術意義不在遊戲本身，而在展示 RISC-V 應用級 MCU 的算力與顯示/音影片外設整合能力：以往需精細預算資源的微控制器，如今已能承載上世紀遊戲主機量級的實時軟渲染負載。該條為研發趣味型產品動態，可作為 RISC-V 端側算力上行的直觀註腳。

三、國內團隊動態與深挖

3.1 上海交大 SPMP 標準後續：交大官網刊發深度稿，確認已在香山與芯來晶片部署

日期：2026-09-11（標準獲批 08-31）　來源：上海交通大學新聞網、上海教育傳媒網

本條為標準事件的續報（2026-08-31 獲批、09-08 起主流媒體報道，本刊 09-09 期已收錄事件本體）。交大官網於 09-10 至 09-11 刊發深度稿，補充了國內首次”從零起步、完整主導”的具體分量與落地證據：一是技術定位，SPMP（特權態實體記憶體保護）面向 AI 晶片、車載晶片、智慧終端、工業控制器一類”固定佈局”場景，用特權態實體記憶體隔離替代多級頁表，避免層層查錶帶來的高延遲與頁表硬體面積/功耗開銷；二是落地情況，SPMP 已在香山（中科院開源高效能 RISC-V 處理器）與芯來（國產 RISC-V IP 廠商）等國產晶片上獲得部署與應用；三是社群履歷，SPMP 入選 RISC-V 國際基金會 2021 年度安全亮點特性，並被 Linux 基金會列為 2023 年度四大 RISC-V 安全進展、為當年我國唯一入選專案；四是評價，RISC-V 國際基金會董事會成員、中科院計算所副所長包雲崗致賀，稱這是中國機構首次從零起步、自主發起並完整主導 RISC-V 擴充套件標準的制定，既完善了 RISC-V 安全體系架構，也為國內機構參與國際標準制定樹立範例。團隊方面，工作由 IPADS（杜鼕鼕、楊璧丞、夏虞斌、陳海波等）主導，2019-09-23 提交架構初稿，歷時近七年，獲批時 SPMP 工作組主席為 IPADS 博士楊璧丞。對國內生態的直接含義是：香山與芯來已具備該隔離能力的可實現路徑，國產 RISC-V 安全特性的”標準—實現”閉環初步成形。

3.2 芯來科技 IPO 後續：九成營收來自 RISC-V IP 授權，招商證券輔導，上半年營收增 41% 未盈利

日期：2026-09-12 ~ 2026-09-13　來源：鳳凰網財經、東方財富

芯來科技北交所上市輔導備案的續報（輔導備案事件本刊 09-10 期已收錄）。視窗內媒體補充了三項財務與業務細節：一是收入結構，公司九成營收來自 RISC-V IP 授權，是國內少數以純 RISC-V CPU IP 授權為主業的廠商，與 ARM 模式下的 IP 授權業務可直接對照；二是輔導機構為招商證券；三是業績概況，上半年營收同比增長約 41%，但尚未盈利。結合此前資訊，芯來已於 09-10 前後啟動北交所上市輔導備案，若順利推進將成為國內 RISC-V IP 第一梯隊中率先進入資本市場的企業。對行業的觀察價值在於兩點：其一，純 IP 授權在 RISC-V 語境下的盈利模型仍未跑通（高增長、未盈利），與包雲崗此前”開源 IP 斬殺線”的論證互為印證；其二，若北交所路徑打通，可能為國內 RISC-V IP 與工具鏈企業提供新的融資正規化參考。

4.1 進迭時空 spacemit-robotics：MuJoCo 模擬新增無頭模式，機器人模擬走向 CI 化

日期：2026-09-11　來源：spacemit-robotics/simulation_mujoco

進迭時空機器人軟體棧（spacemit-robotics）在視窗內繼續推進：simulation_mujoco 於 09-11 合併 #8，新增 headless（無頭）模擬模式。該倉庫為其機器人 SDK 的 MuJoCo 模擬環境，無頭模式是模擬從”人工在圖形介面裡看”轉向”伺服器端批次/自動執行”的關鍵能力，通常用於迴歸測試、引數掃描與持續整合（CI）。結合該組織 09-08 至 09-09 在 IMU 與電機驅動（peripherals-imu、peripherals-motor）、整機控制（control_whole_body）、玲瓏人形（humanoid_linglong）、ROS 2 人形（ros2_humanoid）與感知（perception）等倉庫的成批推送，其機器人 SDK 已形成”外設驅動—整機控制—模擬—感知”的完整分層，且在持續補齊工程化能力而非僅做演示。這條線索與進迭時空在主晶片側推進自研推理後端、視覺模型庫的節奏一致，指向 RISC-V 平臺上的具身智慧軟體棧正在從”能跑”走向”可測、可交付”。

4.2 深開鴻 M-Robots OS 3.0 Beta：機器人作業系統數字底座適配 ARM/RISC-V/LoongArch/x86 四架構

日期：2026-08-28 釋出，2026-09-13 媒體轉載　來源：深開鴻官網、鳳凰網轉載快科技

深開鴻（深圳開鴻數字產業發展）在 2026 中國國際大資料產業博覽會（貴陽，8 月 28 日開幕）上釋出 M-Robots OS 3.0 Beta，媒體轉載落在本視窗內，故一併收錄並註明原始釋出時間。該系統以開源鴻蒙（OpenHarmony）為底座，是面向多形態機器人的分散式異構多機協同作業系統，1.0（2025-04）解決多硬體形態相容與低時延通訊，2.0（2026-05）補齊積木式框架、混合部署、M-DDS 低延時協同等六大能力，3.0 Beta 重心從單機能力轉向群體智慧，圍繞安全（VAA 統一數字身份、KGSI 安全啟動、群體安全狀態共享）、實時（自研單芯多核心混合部署，中斷響應與任務切換時延小於等於 1 微秒，關鍵業務 2 秒恢復、整機 4 秒恢復）、群體智慧（Agent Native 框架與 M-Claw 分散式自治叢集）、數字底座四條主線升級。與本刊主題直接相關的是數字底座一項：其明確適配 ARM、RISC-V、LoongArch、x86 四大架構，併相容 ROS、Dora-rs、OpenHarmony 三大生態，覆蓋 CPU/NPU/GPU/BPU 四類算力。 會上同時演示無人零售、園區巡檢、水質檢測三個群體協同場景，並聯合數字華夏釋出基於該系統的全國產人形機器人星行俠 P02。專案已於 2025 年 11 月捐贈開放原子開源基金會，2026 年 6 月社群啟動運營，設 13 個 SIG 技術組與獨立 PMC。對 RISC-V 生態的含義是：國內頭部機器人作業系統在架構層面把 RISC-V 與 ARM 並列為一級支援目標，為 RISC-V 晶片進入具身智慧整機提供了上層軟體入口。

五、總結與趨勢觀察

  • 國內 9 月進入 RISC-V 產業活動密集期。9 月 9 日至 11 日 IICIE 深圳落幕並設 RISC-V 產業生態創新大會與生態應用展示區，9 月 16 日至 18 日 IC WORLD 北京設”RISC-V 開放算力論壇：具身智慧·大模型·資料中心”專題，議程覆蓋 IP、運營商、智算儲存、行業資料、作業系統社群與晶片廠商，RISC-V 的議題重心明顯從”晶片/指令集”移向”AI 算力與端邊協同”。

  • 標準與資本的”雙線突破”進入續報階段。上海交大 SPMP 作為國內首個從零起步完整主導的 ISA 特性，其落地證據被補足到具體晶片（香山、芯來），”標準—實現”閉環初步成形；同期芯來科技衝刺北交所，九成營收來自 RISC-V IP 授權但尚未盈利，與包雲崗”開源 IP 斬殺線”的判斷形成現實對照，純 IP 授權的盈利模型仍是國內待解課題。

  • 開源核的功能驗證進入深水區。香山視窗內合入向量除法指令並重開 Smmtt（可信執行環境記憶體管理）條件支援，CVA6 八次提交集中在 PMP、除錯觸發器、Zcmp 與 xRET 等特權態邊界條件——兩家高效能開源核的推進重心都落在”安全與特權正確性”，與 SPMP 所代表的國產安全特性主線相互呼應。

  • 端側算力上行繼續被硬體事實佐證。樂鑫 ESP32-P4 以雙核 400 MHz RISC-V 加內建畫素處理加速器，在 25 美元級、約 1 瓦的開發板上實現《古墓麗影》引擎 30 FPS 軟渲染，說明 RISC-V 應用級 MCU 的能力邊界已越過傳統微控制器範疇，對機器人、工業與消費端側的本地化算力方案有直接提示。

  • 具身智慧軟體棧在向工程化收斂。進迭時空 spacemit-robotics 為 MuJoCo 模擬補上無頭模式，使其具備伺服器端批次回歸與 CI 能力；深開鴻 M-Robots OS 3.0 Beta 把 RISC-V 與 ARM 並列為數字底座四大支援架構之一。二者分別從”可測”與”可承載”兩個方向，為 RISC-V 進入具身智慧整機鋪路。
