一、開源社群與軟體生態

1.1 SpacemiT：Linux 7.4 裝置樹更新，K3 調頻、溫控與風扇控制啟用

日期：2026-10-08　來源：Phoronix《SpacemiT RISC-V SoCs To See More Improvements With Linux 7.4》（10-08）

上游核心針對 SpacemiT K3／K1 的裝置樹更新 pull request 於 10-08 發出（擬進入 Linux 7.4）：K3 的 CPU 調頻支援擴大到更多硬體、RFKILL 節點啟用，並新增溫控與風扇控制——針對 K3 CoM260 系統模組上的 CTF2301 感測器晶片；基於 K3 的 Muse Pi Pro、Orange Pi R2S、Orange Pi RV2 開發板均隨此批啟用 CPU 調頻。K1 側則啟用板載 EEPROM 支援，並支援從 EEPROM 資料設定 MAC 地址。K3 作為首批次產 RVA23 晶片之一，上游支援持續收口。

4.1 Upbeat：Bluemag Pi 無人機飛控釋出，SiFive E3／E2 雙核加持板載 AI

日期：2026-10-07　來源：Upbeat Technology：Bluemag Pi 釋出稿（10-07）、PR Newswire 英文稿

臺灣 Upbeat Technology 釋出 Bluemag Pi 感測器整合 AI 飛控板：基於其 UP301 SoC（SiFive E3 與 E2 雙核 RISC-V 架構），多核分工將飛行關鍵任務與通訊／導航／系統管理分離；執行 Apache NuttX RTOS，相容 PX4、ArduPilot、Betaflight 開源飛控棧。板載雙 IMU、氣壓計與雙 GNSS 接收器（感測器融合交叉校驗）、四合一電調與 MAVLink 遙測。面向長航時固定翼、商用多旋翼與水面無人艇；將於 CEATEC 2026（10 月 13 至 16 日，千葉）現場演示，並延伸展示其人形機器人手部等產品線。

4.2 進迭時空機器人：ros2_humanoid 控制鏈遷移至操作員 socket API

日期：2026-10-08　來源：ros2_humanoid 提交記錄（10-08）

進迭時空機器人組織 spacemit-robotics 的 ros2_humanoid 視窗內更新：將 ROS 控制遷移至操作員 socket API——承接此前 humanoid_linglong 增加操作員啟動與引導服務、humanoid_common 引入操作員服務與遠端客戶端的架構方向，人形機器人控制鏈的組織方式繼續向「操作員—執行器」解耦演進。

4.3 ZeroWire：Q8botOne 掌心四足機器人開啟眾籌預熱

日期：2026-10-08　來源：CNX Software：Q8botOne 報道（10-08）、Crowd Supply 眾籌頁

ZeroWire Robotics 的 Q8botOne 掌心級開源四足機器人進入眾籌上線前預熱（Crowd Supply）：ESP32-C3-MINI-N4（RISC-V）主控、8 個 DYNAMIXEL XL 系列智慧舵機、並聯腿結構與無排線一體化 PCB 設計，重約 250 克，可小跑、跳躍並承載約兩倍自重；硬體（Altium 原理圖、Gerber、BOM、3D CAD）與韌體、Python 控制軟體將全部開源，附預配對無線手柄。相較同尺寸 PWM 舵機方案，智慧舵機支援關節反饋與 PID 調參，面向創客與教研場景。

五、總結與趨勢觀察

  • 資本與量產雙里程碑同日到來：奕斯偉計算今日港交所掛牌（定價 1.55 港元、公開發售 9.09 倍認購），紫荊半導體車規 RISC-V 晶片出貨突破千萬顆——RISC-V 在資本市場與汽車量產兩端的可見度同步抬升。

  • 香山系模擬與修復雙線推進：FEX0 兩筆後端修復正式合入；NEMU 同日連開多筆 PR（檢查點機制、SIP／RVV 修復、difftest 引導式觀測），difftest 支援獨立加速器時鐘，為下一輪微架構迭代與多時鐘域驗證蓄力。
  • 生態向設計左右兩端擴充套件：左端 Tenstorrent 以虛擬平臺合作為 IP 開發提速、Chipyard 補齊 PMU 基礎設施；右端端側產品持續湧現（Upbeat 無人機飛控、Q8botOne 四足機器人），RISC-V 在安全關鍵實時系統與機器人場景不斷落子。
  • 待觀察：奕斯偉掛牌首日表現；香山 #6652／#6653 等評審佇列走向；矽速 AE350 Linux 倉庫後續提交；進迭時空 ai-gateway 0.2.0 的元件化落地節奏。
