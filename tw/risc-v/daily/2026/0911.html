今日重點:包雲崗談 RISC-V 與開源 IP——”開源 IP 斬殺線”正在形成

來源:開芯院公眾號《【大咖觀點】包雲崗:淺談北京市人民政府印發〈北京市”十五五”時期高精尖產業發展規劃〉》(https://mp.weixin.qq.com/s/tUq67S2OF_yor_jD60HSHw)

北京市人民政府印發《北京市”十五五”時期高精尖產業發展規劃》,提出加快第五代精簡指令集架構(RISC-V)、芯粒、光電融合等創新平臺建設,持續推進存算一體等新型架構產品迭代升級,聚力培育自主計算產業生態。中國科學院計算技術研究所副所長、北京開源晶片研究院(開芯院)首席科學家包雲崗就此分享了幾點認識:

一是”森林論”:RISC-V 生態好比一片森林,既需要參天大樹(高效能 RISC-V 晶片),也需要灌木草叢(海量嵌入式 MCU)。培育參天大樹,ARM 模式已不再適用,必須探索新模式,而開源 IP 將是成功機率最高的路徑;培育灌木草叢面向海量定製化長尾需求,猶如”義烏模式”——小商品、大市場,可借鑑嘉立創模式以低成本、敏捷開發體系應對。

二是 RISC-V+AI 將成為 AI 時代主流:不同 AI 場景、模型與部署形態對硬體提出高度差異化要求,RISC-V 的開放性與可擴充套件性比 x86 和 ARM 更易適配 AI 定製化需求,近期 Meta、OpenAI 自研 AI 晶片的背後都有 RISC-V 的身影。

三是軟體生態壁壘需要重新整理認知:跨指令集遷移軟體成本高,長期以來是 CPU 生態競爭的核心壁壘;但隨著 AI Agent 快速發展,程式碼遷移、適配、除錯與最佳化成本出現數量級下降,未來軟體生態將不再是壁壘。

四是”開源 IP 斬殺線”:全球 ARM 生態僅一家 IP 供應商、全年收入約 30 億美元,RISC-V IP 價格須低於 ARM 才有機會替代,市場總盤子很難超過 30 億美元;但指令集開放意味著多家 IP 供應方並存、單家營業額都做不大,難以維持高昂研發成本(近期 Andes 關閉 2023 年在美國德州成立的高效能 RISC-V IP 子公司即為例證)。破解思路是將高效能 RISC-V IP 作為產業公共品以開源模式提供,把授權費從幾千萬元、上億元降低 1-2 個數量級——正如 DeepSeek 等中國大模型透過開源將 AI 應用擴散到各行各業。開源模式存在可持續商業模式:當系統足夠複雜,就產生專業服務空間(“Linux + RedHat”“安卓 + 中科創達”)。

五是香山的六年實踐:香山於 2020 年 6 月啟動,2021 年 12 月開芯院成立支撐其持續發展;開芯院作為非營利機構(NPO)不需追求估值與利潤,只需每年籌集覆蓋運營成本的經費(約 1.5 億元/年)即可長期運轉。香山已基本解決資金籌集、工業級質量(充分驗證)與持續迭代演進(每年釋出一代)三大挑戰——“有信心、有底氣讓香山活 30 年”。由此形成一條冷酷的”開源 IP 斬殺線”:若價效比不能高於這條線,自研高效能 IP 的邏輯將難以成立(類比 1991 年 Linux 誕生後私有 Unix 的消亡)。積極擁抱開源 IP 的晶片企業將成為受益者——”香山”研發團隊已成為整個晶片產業的公共資產。

點評:這是繼 8 月滴水湖論壇、RISC-V 中國峰會之後,國內 RISC-V 政策與產業路線的又一重要表態:北京市”十五五”規劃把 RISC-V 列入高精尖產業重點平臺建設,包雲崗則從產業組織方式層面論證了”開源高效能 IP”路線的必要性與可持續性,對國內 RISC-V 晶片企業(自研 IP 與擁抱開源 IP)的路線選擇具有風向標意義。

二、產品與生態動態

2.1 NextSilicon 首次公開 Arbel：自研亂序超標量 RISC-V 核，雙核 2.4 GHz 一致性測試晶片跑通 Linux/Ubuntu（09-10）

日期：2026-09-10（公司部落格；HN 收錄 09-10 17:18 UTC）　來源：NextSilicon 部落格（Yiftach Gilad 署名）、Hacker News 討論

NextSilicon 公佈其自研高效能 RISC-V CPU 核 Arbel 的完整歷程。作者 Yiftach Gilad 自述在 Intel 做了 18 年處理器，最初認為”自建 CPU 核”近乎不可能。Arbel 的起點並非獨立產品，而是為該公司 Maverick 資料流加速器配套的序列執行單元：第一代是整合在加速器內的亂序、超標量、純整數 RISC-V 核，跑通 Linux 與 BusyBox 以驗證路線；其後逐步補齊向量能力、快取一致性、更強儲存結構與更寬的發射。關鍵節點是雙核、一致性、2.4 GHz 的測試晶片，整合 PCIe Gen5、CXL 與基於 CHI 的片上網路，外接通用 CXL DDR 與 PCIe 元件組成”迷你 PC”，可直接執行 Linux/Ubuntu 與開箱可用的 GCC/LLVM 並跑分。量產路線為 64 核、伺服器級、面向資料中心的 chiplet，覆蓋虛擬化、安全、可靠性、可除錯性與高頻寬 IO。架構上公司強調前端不依賴昂貴的 micro-op cache、虛擬 L1 快取結構降低 load-to-use 延遲並處理別名與標籤管理、原子化 L1 fill/evict 流水線等細節選擇。意義：在 HPC 與智慧體 AI 場景下，公司認為瓶頸正從數學引擎轉向編排、記憶體搬運、排程與軟體執行，因此”加速器旁的 CPU”重新變得關鍵；Arbel 是繼 SiFive、Ventana、Rivos 之後又一家公開伺服器級 RISC-V 核進展的創業公司，且以真實矽片而非路線圖對外發聲。

2.2 riscv.org 刊發 MIPS 執行長專稿：汽車行業的 RISC-V 意義在於選擇自由（09-10）

日期：2026-09-10　來源：riscv.org 部落格（Viewpoints）

RISC-V International 官網觀點欄目刊發 MIPS 執行長 Sameer Wasson 專稿（作者身份標註為 MIPS, by GF——即被 GlobalFoundries 收購後的 MIPS）。核心論點：汽車整車平臺的生命週期以十年計，軟體需維護到最後一輛車報廢，因此指令集架構（ISA）的選擇是戰略決策，OEM 與一級供應商需要的”經濟控制”不是自研一切，而是擁有供應商選擇權、議價能力、跨車型軟體複用能力，以及不必繫結某家廠商路線圖即可演進硬體。文章認為開放架構恰恰擴大競爭：半導體廠商仍可在實現層差異化，IP 廠商可在架構之上創新，軟體生態可跨系統複用，而 OEM 可保持架構一致性並自由評估方案。作者同時強調”開放不等於同質化”（openness should not mean commoditization），並指出隨著車輛內 AI 無處不在（感知、ADAS、安全、預測性維護、座艙），架構需要為尚不可預見的工作負載預留餘量，而 RISC-V 提供的價值在於”軟體底座保持一致、實現層隨負載演進”。意義：MIPS 轉向 RISC-V 並以”汽車經濟控制”為敘事主線，是繼 09-08 前後 GlobalFoundries 釋出 MIPS Acies 邊緣 AI 推理平臺報道之後，該陣營在行業話語層的延續動作，也反映 RISC-V 在汽車領域的推廣重心從”效能對標”轉向”長期成本與供應鏈自主”。

2.3 埃因霍溫理工大學 CONVOLVE 專案釋出 Chimera 晶片：RISC-V 處理核與記憶體中心/神經形態加速器跨層協同（09-08 釋出，09-10 英文媒體續報）

日期：2026-09-08（校方釋出）/ 09-10（Bits&Chips 等英文媒體續報進入本視窗）　來源：TU/e 官方新聞、Bits&Chips、CONVOLVE 專案站

歐盟資助、埃因霍溫理工大學（TU/e）主導的 CONVOLVE 專案公佈其流片驗證成果——代號 Chimera 的邊緣 AI 晶片原型，並在 ESSERC 會議（西班牙）向產業界宣講。方法論上的關鍵在於”跨層設計”：不再把 AI 演算法、處理器架構、儲存系統與電路設計分層獨立開發，而是聯合最佳化，從而在設計早期即平衡精度、可程式設計性、處理速度、矽面積與能耗。架構上，Chimera 把可程式設計 RISC-V 處理器與專用 AI 加速器組合使用，後者涵蓋記憶體中心（memory-centric）計算與神經形態計算技術，目標是從設計源頭壓低資料搬運帶來的能耗。專案組強調驗證基於已流片的原型晶片而非模擬，用真實 AI 工作負載實測能效、吞吐、延遲、面積與精度並與既有設計對比。團隊由 Manil Dev Gomony、Henk Corporaal、Sander Stuijk、Marc Geilen 等領銜，合作方分佈在魯汶、代爾夫特、蘇黎世。專案動因是 GenAI 負載推高資料中心能耗與用水，端側本地推理可同時降低能耗、延遲與對遠端基礎設施的依賴，作者定位為”歐洲在邊緣智慧處理器上的自主方案”。意義：本條補錄了歐洲學術陣營在 RISC-V + 新型 AI 加速（記憶體中心/神經形態）方向的具體矽片級進展，與產業側 RISC-V AI 晶片形成對照。

3.1 芯來科技啟動北交所上市輔導備案：RISC-V CPU IP 第一梯隊衝刺資本市場（09-10）

日期：2026-09-10（公司公告披露日）　來源：同壁財經（新浪財經轉載）、撲克財經

芯來智融半導體科技（上海）股份有限公司（證券簡稱”芯來科技”，證券程式碼 875127）於 09-10 披露《申請公開發行股票並在北交所上市輔導備案及其進展公告》：公司已於 09-08 與招商證券簽署北交所上市輔導協議，09-09 向上海證監局提交輔導備案申請材料，北交所上市程序正式啟動。公司成立於 2018 年 9 月，總部位於上海浦東，主營 RISC-V CPU IP 授權、SoC 子系統平臺授權及晶片定製，系國家級重點專精特新”小巨人”企業、中國 RISC-V 產業聯盟副理事長單位，創始人胡振波合計控制 42.50% 表決權。產品體系為 N/U/NX/UX 四大通用 CPU IP 產品線加 NS（安全）、NA（車規）、NI（智慧計算）三個專用線，其中 UX1030H 為全球較早支援 RVA23 規範的高效能 RISC-V CPU IP，NA900 為全球首個透過 ISO 26262 ASIL-D 車規認證的 RISC-V CPU IP；累計取得境內授權專利 93 項（發明專利 92 項）。按 The SHD Group 2026 年 3 月報告的核心出貨量口徑，芯來位列全球 RISC-V CPU IP 市場前四的第一梯隊，國內外正式授權客戶超 300 家，覆蓋兆易創新、芯原股份、恆玄科技、晶晨半導體等上市公司及央國企。財務方面：2024/2025 年營收 7399.87 萬元 / 8294.11 萬元，2026 年上半年 3687.45 萬元；2024/2025 年歸母淨利潤分別為 -8646.73 萬元 / -9593.78 萬元，剔除股份支付影響後虧損由 2023 年的 -1722.73 萬元收窄至 2025 年的 -958.63 萬元；最近兩年研發投入累計佔營收比例達 124.48%。公司已於 2026-08-28 掛牌新三板創新層，同步定向發行募資約 4200 萬元用於 RISC-V 晶片定製平臺研發專案，認購方含黑龍江振興先進製造產業私募股權基金、中芯熙誠（北京）數字科技基金等產業資本，並按規劃擬於掛牌後 12 個月內向北交所提交發行上市申請檔案。行業資料方面，公告援引 SHD Group：2025 年全球 RISC-V SoC 出貨量約 69 億顆，預計 2031 年增至約 360 億顆，複合年增長率 31.7%。深挖視角：芯來是國內少數以純 CPU IP 授權為主業並衝刺公開資本市場的 RISC-V 企業，其”車規 ASIL-D 認證 + RVA23 高效能核 + 300 家授權客戶”的組合，是觀察國內 RISC-V IP 商業化成熟度的關鍵樣本；此前日報持續跟蹤的芯來 GitHub 組織（Nuclei-Software，42 倉庫）在視窗內無專項 push，本次動態為資本市場而非程式碼側。（財務與市場資料來源自公司公告與第三方報告轉述，以正式披露檔案為準。）

五、總結與趨勢觀察

  1. 高效能 RISC-V 核的”真實矽片”敘事升溫：NextSilicon 公開 Arbel（雙核 2.4 GHz、CXL/PCIe Gen5/CHI NoC、跑通 Linux/Ubuntu 與 GCC/LLVM，路線圖為 64 核伺服器級 chiplet），且明確以”智慧體 AI 時代 CPU 重新關鍵”為立論基石。與既有 SiFive、Ventana、Rivos 路線相比，Arbel 的特殊性在於它是從加速器配套需求”長出來”的 CPU，說明資料中心 RISC-V 的驅動力正從”替代通用 CPU”擴充套件到”主機-加速器協同的系統完整性”。
  2. 開源核陣營進入結構收斂期：香山在連續一週的向量指令功能合入（整暫存器移動、vfmac/widen、VIDiv）之後，09-09 至 09-10 連續做包裝層移除（VFAlu/VFMA）與控制訊號清理（VPUCtrlSignals）並修復 vxsat 寫使能傳播，屬典型的”功能鋪開後結構整理”，通常是下一階段（矩陣/規約運算或效能調優）的前置動作。
  3. 國內 RISC-V IP 商業化進入資本驗證階段：芯來科技啟動北交所上市輔導備案，是繼奕斯偉計算衝擊港股後國內 RISC-V 企業資本化的又一動作，且兩者商業模式不同（芯來為 CPU IP 授權、奕斯偉為晶片產品），可互為對照；芯來”車規 ASIL-D + RVA23 高效能核 + 300 家授權客戶”是其差異化基礎，但兩年研發投入佔營收 124.48%、剔除股份支付後仍虧損，說明 IP 授權模式的盈利拐點尚未到來。
  4. RISC-V 在汽車的推廣重心轉向”長期經濟性”：riscv.org 刊發 MIPS 執行長專稿，把汽車 RISC-V 的賣點從效能對標轉向”平臺生命週期十年以上的選擇自由與軟體複用”，與前一天 GlobalFoundries/MIPS 釋出 Acies 邊緣 AI 推理平臺的產業動作呼應，顯示該陣營正以”經濟控制”敘事進攻車規市場。
  5. 端側 AI 加速與 RISC-V 的學術側合流：TU/e 的 CONVOLVE/Chimera 用 RISC-V 可程式設計核 + 記憶體中心/神經形態加速器的跨層設計，把”降低資料搬運能耗”作為首要目標並完成了原型晶片實測；玄鐵同步在開源側補齊 RVV 量化運算元微核心庫（torq-tile），一端是體系結構創新、一端是運算元工程落地，共同支撐 RISC-V 在端側 AI 的實際可用性。
  6. 當日國內廠商程式碼側以收斂性維護為主：算能 SG2044 韌體補 4GB 以下地址分配相容性、進迭時空合併 K1 引導分支並更新 ROS 機器人文件，均為穩定性與文件質量類工作，無釋出級新動態；玄鐵 torq-tile 的 RVV 量化運算元批次（09-07 合入）為本視窗發現的新增內容。

侷限性說明：NextSilicon Arbel 的效能描述（2.4 GHz 雙核測試晶片、64 核量產規劃、微架構選擇）均來自公司部落格自述，尚無第三方評測或 SPEC 級資料佐證，其”伺服器級”定位需以實際量產矽片為準；MIPS 專稿為觀點文章（Viewpoints），觀點歸屬作者與 MIPS 公司，不代表 RISC-V International 立場；TU/e Chimera 的具體能效數字需以 ESSERC 論文與專案公開材料為準，本條依據校方新聞與專案站描述；芯來科技財務與市場資料來源自公司公告及 The SHD Group 報告轉述，投資相關內容不構成建議；香山、玄鐵、算能、進迭時空的程式碼動態以 commit message 與倉庫 pushed 時間為準，未做微架構級驗證；torq-tile 的視窗內推送未見新提交（疑為分支/後設資料操作），其表述以 09-07 合入批次為準。
