一、開源社群與軟體生態

1.1 樂鑫 esp-nn 1.3.1 釋出，RISC-V 核心全連線層向量化最佳化

日期：2026-08-28　來源：espressif/esp-nn 提交記錄

樂鑫神經網路庫 esp-nn 釋出 1.3.1（合入時間 08-28 23:44 北京時間）。本次核心效能改進為全連線層（fully_connected）per-channel offset 校正的向量化：RISC-V 路徑（riscv_pie 最佳化核心變體，面向 ESP32-C 系列）與 Xtensa S3 路徑同步最佳化，S3 側在短行場景優先使用匯編；README 效能數字同步重新整理。esp-nn 的 riscv_pie 核心族覆蓋啟用函式、基礎數學、全連線等運算元，是樂鑫持續為 RISC-V MCU 提供 DSP 級最佳化運算元的例行迭代，無架構級變化。

二、產品與生態動態

2.1 SiFive BigSky 進入交付階段：首批系統已在領先客戶執行負載，Futurum 分析師解讀

日期：2026-08-28　來源：The Futurum Group 分析稿（釋出日 2026-08-28）

Futurum Group 分析師 Brendan Burke 於 08-28 發表 BigSky 專題解讀，標題直言”SiFive BigSky 出貨首款 RISC-V 伺服器”。新增事實要點：（1）BigSky SF-2U870 完整符合 RVA23 profile，開箱即用支援 Ubuntu 26.04 LTS 與 RHEL 10；（2）CUDA 可在其 P870-D 核心上執行，作為 NVIDIA GPU 的 LLM 工作負載 head node（控制節點）；（3）SiFive 稱領先客戶（含超大規模雲廠商、軟體與主要 SoC 廠商）已在已部署的 BigSky 系統上執行工作負載。分析師判斷：BigSky 本質是”出售時間”的移植載體——壓縮超大規模廠商定製 SoC 專案多年代軟體階段；RISC-V 伺服器當前所處位置相當於 Arm 約 2018 年（RVA23 與伺服器平臺規範已定稿、企業級 Linux 就緒、首批可執行該軟體棧的矽片到達客戶），制約 RISC-V 資料中心落地的已從矽片轉為軟體，BigSky 正是為按期彌合該缺口而生。同時指出 SiFive 未隨平臺公佈 SPEC/效能、功耗與定價資料，商務競爭力驗證留待後續。本視窗為該事件自 08-24 釋出、08-25 至 08-27 媒體發酵後的”交付/部署進展 + 分析師定調”階段，屬實質性新資訊。

三、國內團隊動態與深挖

3.1 香山：68+ 筆提交，跨月開發成果大規模合入（ZICBO、Zvknha/Zvbb、向量單元重構、AMOCAS）

日期：2026-08-28　來源：OpenXiangShan/XiangShan 提交檢索、XiangShanLab

OpenXiangShan 組織視窗內約 84 筆提交（XiangShan 主倉庫 68 筆），核心事件是 08-28 16:44 一批跨月開發成果的大規模合入（author 日期跨度 2025-11 至 2026-08-26，屬批次合入收尾而非當日新開發）。要點：（1）ZICBO 擴充套件：新增 ZICBO 支援並將快取塊操作（cbo）opcode 經 LSUOpType 統一（author 08-26）；（2）密碼學向量擴充套件：Zvknha（NIST AES 向量密碼學）initial version（author 2026-02）、Zvbb（向量位操作）初始化支援（author 2026-02）；（3）向量單元重構：vector 新初始提交（author 08-06）、vstart 傳入 VectorDecodeChannel、immType 加入 vector fu config、vl value wakeup 禁用、VTypeGen 時序斷鏈等一批重構與時序最佳化；（4）AMOCAS d/w/q 支援（author 08-19）與 AMOCAS src select 邏輯修正；（5）指令集側從 riscv_opcodes 倉庫匯入生成指令列表（author 2025-11）、load event 差異化 opcode（formLoadEventOpcode，author 08-20）。同期 XiangShanLab 活躍：4636 號分析程式落地、difftest-tracer skill、chisel 教學程式基礎庫與 issue 工作流改造，教學與實驗工具建設持續推進。本次合入使香山在向量擴充套件覆蓋、原子指令與快取塊操作指令支援上明顯補強。

3.2 進迭時空：模型庫文件工具新倉庫 model-zoo-file2md 釋出 0.1.1

日期：2026-08-28　來源：spacemit-com/model-zoo-file2md

進迭時空視窗內 3 筆提交（新倉庫 model-zoo-file2md）：新增 document to markdown 元件（feat(file2md)）、恢復可讀的 0.1.1 釋出說明、移除本地 benchmark 報告指令碼。該倉庫定位為模型庫文件轉 Markdown 工具鏈，服務進迭 model zoo 系列倉庫（model_zoo_rl 等）的文件標準化。結合前日 docs-chip 倉庫 AVL 文件化工作，進迭時空正持續強化模型庫與硬體文件的工程化沉澱，當日動態量小，屬工具鏈打磨。

四、具身智慧與機器人專章

4.1 視窗內無 RISC-V 具身智慧新品；Hugging Face 生態 Microduck 雙足機器人釋出（RK3566/ARM，生態參考）

日期：2026-08-28　來源：CNX Software、pollen-robotics/microduck

Pollen Robotics 與 Hugging Face 釋出 Microduck：25 cm 高雙足機器人，15 個電機（腿/頭/頸自由度）、相機 + 深度感測器 + 雙 IMU + 8×8 ToF LiDAR、可抓取物件的鉸接喙，399 美元預售，2026 年聖誕前發貨，限北美與歐洲。其主控為 Rockchip RK3566（四核 Cortex-A55，非 RISC-V），軟體棧（Rust 編寫的 50 Hz 伺服控制守護程序、Python 強化學習訓練工具、Hugging Face 線上模擬器）全開源。本視窗 RISC-V 側無具身智慧硬體新品；該條作為生態參考收錄——物理 AI 硬體浪潮（Hugging Face 開源機器人生態）仍在加速，但終端主控主流仍選 ARM 平臺，RISC-V 在具身智慧領域的滲透依舊呈現”標準與治理層先行（MIPS 晉升頂級會員，昨日已報）、終端落地待觀察”的格局。

五、總結與趨勢觀察

  1. 本視窗核心事件是 SiFive BigSky 從”釋出”走向”交付”：Futurum 分析師確認首批系統已在超大規模雲廠商等領先客戶部署執行負載，RVA23 完整合規 + Ubuntu 26.04 LTS/RHEL 10 開箱即用，CUDA 在 P870-D 上承擔 NVIDIA GPU head node 角色；分析對標”RISC-V 伺服器處於 Arm 2018 年位置”，軟體就緒度已成資料中心落地的主要矛盾。未公佈效能與定價資料，商務驗證仍待觀察。
  2. 香山完成一批跨月開發成果的大規模合入：向量單元重構 + Zvknha/Zvbb 密碼學向量擴充套件 + ZICBO 快取塊操作擴充套件 + AMOCAS 原子指令支援，指令覆蓋與安全特性顯著補強；XiangShanLab 教學實驗工具（4636 程式、difftest-tracer）同步推進，研究向工程轉化節奏穩定。
  3. 國內團隊動態分化：進迭時空釋出文件工具新倉庫 model-zoo-file2md 0.1.1；算能、平頭哥（XUANTIE-RV）、芯來、奕斯偉計算視窗內均無提交——算能昨日剛完成 CV84X6 官方規格落地，屬正常節奏輪換。
  4. 具身智慧：視窗內無 RISC-V 硬體新品；Hugging Face 生態 Microduck 雙足機器人選用 RK3566（ARM），物理 AI 終端主控仍以 ARM 為主，RISC-V 在該領域的落地節奏慢於治理層訊號。
  5. 侷限性說明：gnews 中文團隊查詢（平頭哥/香山/算能/進迭/芯來/奕斯偉）為空或噪音（香山命中均為北京香山論壇同名新聞）；”Milk-V” 查詢被 gnews 分詞拆解為牛奶類內容嚴重汙染；StarFive 命中 301536.SZ（星宸科技，非賽昉）半年報誤標；國內團隊資訊以 GitHub 提交為準。
