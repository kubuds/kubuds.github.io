1.1 Sedna：純 Java RISC-V 模擬器重啟開發，向多架構框架演進（08-23）

日期：2026-08-23（README 更新 23:11 北京；開發活躍自 08-21 起）　來源：github.com/fnuecke/sedna

2020 年誕生的純 Java RISC-V 模擬器 Sedna（rv64imacfd + Zifencei，支援 S 態、可引導 Linux、透過 riscv-tests 全部用例、支援機器狀態序列化，釋出在 Maven Central）於本視窗重啟活躍開發：作者將舊 Z80 模擬器遷移進 Sedna 框架（指令解碼器生成器泛化、磁碟裝置遷移、Z80 板級接入），README 於 08-23 23:11（北京時間）更新。專案定位正從”單架構 RISC-V 模擬器”向”多架構模擬框架”演進——解碼器生成器已同時服務於 Z80 作概念驗證，JVM 生態的 RISC-V 模擬器選項（QEMU 之外）由此獲得一個活躍維護的補充。

1.2 Arduino ESP32 核心新增 OTA 韌體 SHA-256 可選校驗（08-24）

日期：2026-08-24（03:38 北京，committer 時間）　來源：espressif/arduino-esp32 PR #12824

樂鑫 arduino-esp32 核心合入 feat(update): add optional SHA-256 checksum for incoming firmware (#12824)：為 OTA 更新流程新增可選韌體 SHA-256 校驗，強化韌體完整性驗證（防下載損壞/篡改）。ESP32-C 系列（C3/C5/C6/C61 等 RISC-V 核心）與 Xtensa 系列均受益，屬樂鑫軟體生態例行加固，無破壞性變更。

3.1 香山：COVE 機密計算 MMU 路徑兩筆修復合入（08-24）

日期：2026-08-24（00:02 北京，committer 時間）　來源：OpenXiangShan/XiangShan PR #6299、PR #6300

視窗內香山主倉庫 2 筆提交，均指向 COVE（機密虛擬機器擴充套件，Confidential VM Extension）的 MMU 實現：

  • #6299 fix(MMU, COVE): reject out-of-range Smmpt addresses：此前超出 43 位地址範圍的 Smmpt43 請求未被 MPTCache 拒絕，會被當作 cache miss 送入 miss queue/table walker，而非返回 access fault。修復定義 Smmpt43 / Smmpt52 的 PA 寬度與各模式最大合法 PPN（43 位：0x007fffffff；52 位：0xffffffffff），在 stageCheck 流水級校驗請求 PPN，越界請求經 respHit 返回 accessFault、抑制 respMiss 防止表遍歷，並在 range fault 時清除 permission / NAPOT / 連續許可權 / MPT 級後設資料、cache flush 時清除 range-fault 暫存器；
  • #6300 fix(MMU, COVE): fix bug for mpt miss queue：MPT miss queue 當前實現違反 Decoupled 協議（twReq.valid 未按 ready 門控），雖未觀察到功能丟請求，仍按協議修復。

意義：香山是 RISC-V 開源高效能處理器中少數推進 CoVE/MPT（記憶體保護表）機密計算路線的專案。兩筆修復均為”協議合規性打磨”性質，說明其 COVE 實現已越過功能打通、進入細節收斂階段——與近期”效能收尾期”的整體節奏一致（分支預測/AIA 等大項收斂後的細活階段）。

日期：2026-08-23（交匯點報道 18:50 北京）　來源：中國江蘇網/交匯點

以”AI 賦能，智創芯未來”為主題的第六屆積體電路設計創新會議暨應用展首次落地南京江北新區：2 場主會議、8 場專題會議、5 大主題展區、超百場專家與企業報告，約兩千名專業觀眾，紫光展銳、華大九天、阿里巴巴、英特爾研究院等參與。RISC-V 相關要點：

  • RISC-V 協同創新聯盟同步啟動，與 Chiplet 協同創新中心揭牌一道，為開源晶片與先進封裝搭建技術交流與產業合作平臺；
  • 專題覆蓋 IC 設計創新、汽車晶片國產化（國內首個車規晶片健康度量化標準”艾思齊 AsaChi”完成解讀）、先進封裝、RISC-V 開源生態、家電晶片創新（海爾/海信/TCL）、具身智慧、產教融合、投融資對接；
  • “2026 強芯榜單”釋出、2026 中國研究生創芯大賽·EDA 精英挑戰賽啟動（後備人才培養）。

背景：會議落地地江北新區已集聚超 600 家積體電路全鏈條企業。行業正轉向”AI 賦能 + 架構革新 + 先進封裝 + 開源生態協同”的系統級創新；RISC-V 協同創新聯盟啟動是開源處理器產業組織化的又一訊號（近兩週已有滴水湖 RISC-V 產業論壇、HICOOL 2026 RISC-V+AI 協同創新挑戰賽複賽等密集動作）。
