一、開源社群與軟體生態

1.1 香山：昆明湖 V3 將 ROB 擴大至 160 項；GEM5 增加兩執行緒 SpMT 資源劃分

日期：2026-10-16　來源：XiangShan PR #6730（10-16）、GEM5 xs-dev #1231（10-16）、NEMU PR #1246（10-16）、NEMU PR #1252（10-16）

香山主倉（kunminghu-v3）合入 #6730：將重排序緩衝（ROB）容量擴大至 160 項，屬亂序執行視窗的引數級效能調整，直接擴大可同時在飛的指令數量。模擬側 GEM5（xs-dev 分支）合入 #1231：為兩執行緒 SpMT 增加中間端（middle end）資源劃分，指向多執行緒共享前端／重新命名資源時的隔離與配額。驗證側同視窗兩筆：NEMU #1246 新增昆明湖 V2（kmhv2）配置並對齊 V2 與 V3 的公共修復，使參考模型同時覆蓋兩代微架構；#1252 降低 DiffTest 儲存 CRC 校驗開銷。視窗內 difftest、XSCache 主分支無新增。

1.2 openRuyi：主倉一次合入 6 個 Rust 生態軟體包，補齊裸機與驅動開發元件

日期：2026-10-16　來源：openRuyi 主倉提交記錄（10-16）

openRuyi 主倉由維護者 luojia65 一次性提交 6 個 SPECS 包：rust-riscv 0.16、rust-riscv-macros 0.4、rust-riscv-types 0.1、rust-embedded-hal 1、rust-volatile-register 0.2、rust-vcell 0.1。該組軟體包覆蓋 RISC-V 裸機執行時、嵌入式 HAL 抽象與底層暫存器訪問，是 Rust 在 RISC-V 裸機與驅動場景落地的底層依賴；對發行版而言，意味著 Rust 的支援範圍從編譯器本身擴充套件到執行期元件成組進入打包體系。官網新聞頁本期無新版本公告（最新仍為 2026.09）。

1.3 meta-riscv：linux-mainline 升至 7.2.11，riscv-common 改為優先主線核心與 U-Boot

日期：2026-10-16~10-19　來源：riscv/meta-riscv 提交記錄（10-16~10-19）

Yocto 層 meta-riscv 視窗內 14 筆提交：linux-mainline 由 7.2.10 升至 7.2.11；riscv-common 調整為首選主線 Linux 與 U-Boot，減少對廠商 BSP 分支的依賴；文件側補齊進迭時空 K3 Pico-ITX、K3 COM260 與 LicheePi-4A 的啟動與 UART 說明，併為 freedom-u540 設定 KERNEL_IMAGETYPE=Image。發行版構建層向主線收斂，與 openRuyi、RevyOS 近期的平臺收攏動作同向。

二、產品與生態動態

2.1 Tenstorrent 據報同時與 Intel、Qualcomm 洽談出售，估值或超 50 億美元

日期：2026-10-17　來源：Startup Fortune：Intel and Qualcomm Both Court Jim Keller’s AI Chip Startup Tenstorrent（10-17）

據 Bloomberg 報道（Startup Fortune 轉述），RISC-V AI 晶片公司 Tenstorrent 正分別與 Intel、Qualcomm 就潛在出售進行談判，並已聘請投行評估，交易估值可能超過 50 億美元；訊息傳出後 Intel 股價盤中一度上漲 6.4%。Intel、Qualcomm 與 Tenstorrent 均拒絕置評。Tenstorrent 由 Jim Keller 執掌，是 RISC-V 高效能 AI 加速與 IP 的代表性公司；今年 6 月曾傳出 Qualcomm 以 80–100 億美元洽購，Keller 當時予以否認。該事項仍處媒體報道階段，未獲任何一方確認。

2.2 AI 智慧體完成 RISC-V 加密 SoC 全流程設計：算力成本約 2000 美元、功耗 20 mW

日期：2026-10-16（原始報道 10-15）　來源：騰訊新聞（快科技）：門檻崩塌！AI 耗資 1.4 萬就能設計出 RISC-V 晶片（10-16）

半導體博主 @bubbleboi 使用 Meta 的 Muse AI 智慧體，完成一款 RISC-V 加密專用 SoC 從邏輯設計到佈局佈線的全流程：消耗約 1 億 token、算力成本約 2000 美元；藉助 OpenROAD 完成佈局佈線並生成可送廠的 GDSII 版圖。設計含約 61590 個邏輯單元、100 MHz、功耗 20 mW、時序餘量 4.5 ns，透過 DRC 檢查與 150 萬條 Berkeley TestFloat 向量校驗。作者正尋找多專案晶圓（MPW）共享流片機會。該結果尚未經矽驗證，屬個人實驗，但為「AI 參與晶片設計」的成本曲線提供了可複核樣本。

三、國內團隊深挖

3.1 睿思芯科完成戰略融資：任君資本、水木基金入股，繼續加碼 RISC-V 伺服器 CPU

日期：2026-10-16　來源：搜狐（大河財立方）：睿思芯科完成戰略融資（10-16）

睿思芯科（深圳）完成新一輪戰略融資，投資方包括任君資本、水木基金，金額未披露。公司由譚章熹創立，團隊出自加州大學伯克利分校 RISC-V 原創專案組，曾推出國內首款全自研 RISC-V 伺服器處理器「靈羽」，此前完成由深重投國資領投的 B 輪。本輪資金將用於 RISC-V 伺服器級高效能處理器與雲原生 CPU 研發。譚章熹同時擔任 RISC-V 國際開源實驗室（RIOS）聯合主任，今日峰會開幕式亦由其致辭。

3.2 奕斯偉計算上市後首周：市值 338 億港元，人機互動仍佔收入 76%

日期：2026-10-17　來源：新浪財經（中國經營報）：奕斯偉計算上市即破發 RISC-V 仍待規模化商用（10-17）

10-09 在港交所掛牌的奕斯偉計算（01256.HK）首份上市後市場評估出爐：首日收報 1.535 港元、跌 0.97%，市值約 338 億港元；2023–2025 年營收 17.52／20.25／24.31 億元，經調整淨利潤分別為 −17.05／−14.40／−11.61 億元，毛利率在 14%–18% 區間；人機互動晶片仍佔收入基本盤 76%，單價由 20.9 元降至 11.6 元。按 2025 年營收計，其在中國 RISC-V 主控晶片市場排名第五、國產廠商第三，份額 1.2%（前五合計 22.5%）。

3.3 進迭時空 llama.cpp 分支釋出 v0.2.3：合入 K3 decode 狀態最佳化並同步上游

日期：2026-10-16　來源：llama.cpp v0.2.3 Release（10-16）、PR #48：perf/k3-decode-state（10-16）

spacemit-com/llama.cpp 的 mtmd-backend 分支釋出 v0.2.3：合入 #48（K3 decode 階段狀態複用最佳化）與 #47（同步上游 20261014 版本），並更新版本號。該分支維持約 1–3 週一版的節奏（v0.2.2 於 10-13 釋出），持續收斂 K1／K3 端側推理的可用性與效能。

3.4 算能 zsbl：將各 cpusys 拆分為獨立應用子目錄

日期：2026-10-16　來源：sophgo/zsbl 提交記錄（10-16）

算能 zsbl（ZScale Boot Loader）視窗內 1 筆結構調整：將每個 cpusys 拆分為獨立的應用子目錄，便於不同晶片平臺分別維護引導程式碼。屬引導韌體側的工程重構，未涉及功能變更；同期 sophon-tools 亦有推送。

四、具身智慧與機器人專章

4.1 智元機器人戰略入股芯際無限：RISC-V 人形機器人算力走向專用底座

日期：2026-10-18　來源：搜狐（半導體產業縱橫）：智元戰略投資芯際無限！加碼清華系 RISC-V 具身智慧算力賽道（10-18）

智元機器人戰略入股清華系 RISC-V AI 晶片公司芯際無限。芯際無限是清華大學唯一技術轉化並持股的 RISC-V AI 晶片企業，團隊自 2016 年起從事 RISC-V 研究；2026 年清華華控技術轉移以核心 RISC-V 智慧財產權作價入股。產品側：

  • XC64AE（小腦晶片）：12 核 RISC-V 核心＋自研 NPU，兼顧運動控制與中端環境感知，首款已流片回片並推出標準化開發方案；V1000（大腦晶片）基於 2.5D Chiplet，標稱 1000 TOPS；關節控制晶片已量產，2027 年第二代 XC64AE 全系列計劃流片。
  • 車規 XC32 系列：XC32MC 車身電機控制 MCU 已批次上車，累計訂單超 500 萬顆；XC32LS 符合 ASIL-D，已流片點亮、計劃 2027 年量產；XC32DC 中央域控預計 2028 年定點量產。
  • 意義：在特斯拉自研 FSD 與英偉達 Jetson 通用平臺之外，芯際無限選擇「全棧自研 RISC-V＋可裁剪指令擴充套件＋Chiplet」的第三條路線；智元帶來整機場景與實測資料，加速晶片從樣品走向量產驗證。

4.2 峰會機器人議題：10-20 設汽車電子、工業與機器人分論壇，具身智慧滲透率預期升至 28.2%

日期：2026-10-17~10-19　來源：第六屆 RISC-V 中國峰會官網議程、證券時報：RISC-V 重磅峰會將舉辦，產業空間有望超 2000 億元（10-17）

峰會 10-20 設「汽車電子、工業與機器人」分論壇（聯合主席：賽昉科技徐滔、沁恆微楊勇），主論壇亦安排零次方機器人分享 RISC-V 架構在具身智慧領域的應用。市場側，弗若斯特沙利文資料顯示：RISC-V 在中國具身智慧晶片的滲透率預計由 2025 年 10.7% 升至 2030 年 28.2%，智慧終端由 6.9% 升至 26.7%；中國 RISC-V 主控晶片市場由 2025 年約 377 億元增至 2030 年約 2194 億元。

五、總結與趨勢觀察

  • 峰會進入「議程兌現」階段：會前兩週的議程、參展商與講者預熱已結束，10-19 主論壇與 10-20 七場分論壇是檢驗「生態成熟度」敘事的第一手材料；AI 與資料中心兩條主線（達摩院 AME、奕斯偉 RISC-V＋AI、藍芯 LX500）集中在主論壇下午場。
  • 資本冷熱分化明顯：一級市場持續加註（智元入股芯際無限、睿思芯科完成戰投），二級市場則給出「理性偏冷」定價（奕斯偉上市首日破發、A 股 RISC-V 概念股年內平均回撤）。產業長期空間（2030 年 2194 億元）與短期盈利兌現之間的錯位，仍是估值主線。
  • 軟體棧三條推進線：微架構側香山以 ROB 擴容與 NEMU 雙版本配置提升效能與驗證覆蓋面；發行版側 openRuyi 補 Rust 執行期元件、meta-riscv 向主線核心／U-Boot 收斂；端側推理側進迭時空 llama.cpp 保持 1–3 週一版迭代。
  • 具身智慧成為 RISC-V 差異化戰場：從芯際無限的專用 SoC＋Chiplet，到峰會機器人分論壇與 28.2% 滲透率預期，RISC-V 在機器人算力上的敘事已從「可用」轉向「專用底座＋場景資料閉環」。
  • 侷限說明：峰會主論壇講者與順序依據會前公佈材料，官網對 10-19 仍標註「詳細議程即將公佈」，以現場為準；Tenstorrent 出售事項為媒體報道、三方未確認；AI 設計 RISC-V SoC 為個人實驗、尚未流片，資料以作者公開描述為準；會員官網巡檢的變化多為營銷頁重新整理，未檢出實質產品釋出。
