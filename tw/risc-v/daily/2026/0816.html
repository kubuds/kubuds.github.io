一、開源社群與軟體生態動態

1.1 RISC-V 官方高保證密碼學（HAC）規範密集更新：ML-KEM/ML-DSA 後量子密碼描述細化（今日頭條之一）

日期：2026-08-15（11:34~23:25 UTC 約 20 筆提交）　來源：riscv/riscv-high-assurance-cryptography GitHub

RISC-V 國際基金會高保證密碼學（HAC）規範倉庫視窗內密集提交約 20 筆，主要圍繞後量子密碼與高保證實現：ML-KEM（Kyber 後量子金鑰封裝）與 ML-DSA（Dilithium 後量子簽名）的指令集描述修訂、ACE-ISA-unpriv 規範措辭統一（”must” 改 “shall”）、OCB3 結構精簡、CR 表示與容量上限澄清等，並處理評審意見（review1.md）與 AsciiDoc 排版修正。HAC 是 RISC-V 面向 FIPS 140-3 級高保證密碼實現（恆定時間、側通道防護）的擴充套件規範，其 ML-KEM/ML-DSA 等後量子指令集描述進入密集修訂階段，標誌 RISC-V 密碼擴充套件向實用化、標準化收斂——對 RISC-V 進入金融/政務/雲信任邊界有直接意義，與本週 Spectre 論文引發的安全信任討論形成呼應。

日期：2026-08-15（06:00/16:08 UTC 提交，北京 14:00/08-16 00:08）　來源：OpenXiangShan/difftest GitHub

四、重點方向專章：具身智慧與機器人

4.1 雙核 RISC-V RT-MCU：運控基座的”異構分工”敘事成形

本視窗最具方向性訊號是電子工程專輯的專題《雙核 RISC-V RT-MCU 如何撐起具身機器人的運動控制基座？》（08-15）：雙核架構（實時核跑電機/關節控制環路 + 應用核跑通訊/感知/邊緣 AI）成為具身機器人運動控制基座的主流設計思路，代表性產品峰岹 FU75XX 系列（32 位 RISC-V 雙核、雙電機驅動）自 2025-11 起即以”為未來機器人而生”定位。這與滴水湖論壇（08-13）的運控訊號完全同頻：格見半導體 500 納秒電流環/單晶片 25 自由度（昨日報告 3.3）、先楫 HPM53M1 人形機器人關節控制、進迭時空 K3 機器人運控定位——國產 RISC-V 運控方案正從”單核實時 DSP/MCU”向”雙核異構（實時+智慧）”演進，運控層國產替代路徑進一步具體化。

4.2 端側 AI 推理 NPU 化：SPERT 整圖核心路徑

進迭時空 llama.cpp 分支的 SPERT 整圖核心路徑（3.1）與算能 YOLOv8-pose 實戰級修復（3.2）共同指向具身智慧軟體棧的成熟化：前者將 LLM/VLA 推理下沉至端側 NPU 引擎（低功耗實時性），後者持續修補視覺感知示例的工程缺陷。結合昨日 LeRobot（SmolVLA/ACT）端側部署與仿人機器人適配，RISC-V 具身智慧”感知（視覺）— 決策（端側 LLM/VLA）— 運動（雙核 RT-MCU 運控）”三層國產化路徑逐步清晰。

五、總結與趨勢觀察

  1. 後量子密碼成為 RISC-V 規範熱點：RISC-V 官方 HAC 規範視窗內約 20 筆提交細化 ML-KEM/ML-DSA 等後量子密碼指令描述，密碼擴充套件向 FIPS 級高保證實現收斂——與本週 Spectre-on-RISC-V 論文引發的安全信任討論同向，安全/密碼正成為 RISC-V 生態的官方優先順序議題。
  2. 運控層”雙核異構”敘事成形：電子工程專輯專題（雙核 RISC-V RT-MCU）+ 峰岹 FU75XX + 滴水湖論壇運控新品（格見/先楫/K3）同頻，具身機器人運動控制基座的國產 RISC-V 方案從”單核實時”走向”實時核+應用核”雙核分工。
  3. 端側 LLM 推理加速下沉 NPU：進迭時空 llama.cpp 合入 SPERT 整圖核心路徑，端側大模型推理從”CPU 跑通”邁向”NPU 整圖加速”，與運算元庫（FlagGems-RACE）、推理文件（docs-ai）構成完整鏈條。
  4. 奕斯偉 IPO 進入”上市前夜”：港股”RISC-V 架構第一股”敘事推進至臨近掛牌，雖三年累虧 49 億，但車規 MCU/CMS 產品線與國產 RISC-V 主力敘事為其背書。
  5. 驗證基礎設施持續加碼：香山 difftest 增加驗證器背壓控制與批次驗證（提升吞吐）、新增 macOS arm64 主機支援，開源高效能核的驗證效率成為競爭力焦點。
