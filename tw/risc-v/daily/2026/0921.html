今日重點：奕行智慧完成近 20 億元新一輪融資，投後估值近 150 億元

日期：2026-09-18　來源：獵雲網 via 騰訊新聞《奕行智慧完成新一輪近20億元融資，投後估值接近150億元》、36Kr 英文《Yixing Intelligence Secures 2 Billion Yuan New Financing》

RISC-V 雲端 AI 算力晶片企業奕行智慧（EVAS Intelligence）於 09-18 經多家媒體確認完成新一輪融資：金額近 20 億元（約合 2.95 億美元），投後估值接近 150 億元。本輪投資方超過 20 家，包括華泰創新、鐘鼎資本、中芯聚源、九安醫療、通富微電、賽意產業基金、和利資本、芯鑫租賃等，其中芯鑫租賃為國家積體電路產業投資基金一期（大基金一期）子基金。這是繼今年上半年 15 億元 B 輪融資與中國移動戰略投資後，公司在數月內再度獲得的大額資金，也是目前國內 RISC-V 方向披露的最大單筆融資。

產品與商業側資訊一併釋出：第一代 Epoch 雲端算力晶片已實現規模化量產交付，原生支援分塊量化 FP8；今年 7 月 WAIC 期間釋出的業界首個 RISC-V AI 算力超節點（64 節點正交無背板、E200-L 液冷 OAM 模組、晶片間百納秒級互聯）已在河北石家莊運營商資料中心完成叢集部署，驗證了萬卡級部署路徑；新一代雲端晶片已完成流片，公司給出的迭代節奏為”一年一代”。生態側，公司推進 VISA 虛擬指令集開源，軟體棧原生相容 PyTorch、TensorFlow、JAX、ONNX，並與 vLLM、Triton 及 FlagOS 等社群聯動。

政策背景值得對照：工信部與國家發展改革委近期聯合印發《電子資訊製造業發展”十五五”規劃》，在軟硬協同部分提出”推進第五代精簡指令集（RISC-V）研發與產業化，支援 RISC-V 晶片在人工智慧、嵌入式系統等領域應用”。資本市場在本輪給出的估值，與政策指向、以及公司”首個量產級 RISC-V 雲端算力”的定位直接相關。需要保留的邊界是：估值接近 150 億元不等於業績兌現，公司成立四年、首代晶片剛進入規模交付，後續訂單與營收兌現節奏是更硬的檢驗。

一、開源社群與軟體生態

1.1 香山 NEMU/difftest：AME 矩陣擴充套件一批修復與適配

日期：2026-09-18 ~ 09-20　來源：NEMU PR #1224、NEMU PR #1217、difftest PR #962

NEMU 在視窗內合入 5 項提交，AME（矩陣擴充套件）方向兩項：檢測對未定義 tile 暫存器區域的讀取（#1224，09-20）、把矩陣 load 的比較範圍限定在活躍區域（#1217，09-18）；差分測試方向兩項：為 SHARE REF 場景標記 CSR 髒位（#1220，09-20）、改用 memmove 匯出 GCC 暫存器提升匯出效能（#1219，09-18）；虛擬化方向一項：riscv64 保留 RVH 最終 TLB refill 路徑、不再強制故障（#1218，09-18）。difftest 側配套兩項：#962 讓 AME 打包事件適配 NEMU ABI（09-18），#971 關閉 elfloader 除錯列印（09-20）。

這組提交由同一開發者連續推進，主線是讓矩陣擴充套件在 NEMU、difftest 與 RTL 之間行為一致——包括”未定義暫存器區域的讀取行為”這類邊界語義的明確化。AME 相關支援在香山驗證鏈中的密集落地，說明矩陣計算是其當前指令集擴充套件工作的重點方向之一。

1.2 香山倉庫群：store prefetch 與 CHI 整合等分支級開發活躍，主幹無新合併

日期：2026-09-18 ~ 09-20 核查　來源：XiangShan 分支活動、GEM5 分支活動、XSCache 分支活動

視窗內香山主倉、GEM5、XSCache 的 master 均無新合併提交，但分支級推送密集，主要動向可歸納為四條：一是 store prefetch 最佳化系列在 XSCache 與 XiangShan 同步推進（size8、size4-shadow-dedup 等多個變體分支，屬訪存預取策略的探索）；二是 GEM5 側建立 CHI 整合 rebase 分支（feature/chi-dev-v2-rebase-xs-dev-20260920）、cacheline 置換拆分（split-store-perm）與 I-prefetch 對齊分支，對應一致性匯流排整合與取指最佳化；三是 XiangShan 主倉出現 TAGE 分支衝突修復（fix-tage-bank-conflict）、RAS 測試（test-ras-1）、快速中斷（fast-interrupt）與昆明湖 V3（kunminghu-v3）分支更新；四是部分批次效能實驗分支（codex/perf-128-*）。分支活躍、主幹待合，屬並行開發期的正常形態，本期記錄里程碑、待合併後跟蹤。

1.3 openRuyi：SPECS 包提交約 20 項，雲原生與工具鏈更新密集；9 月版本未釋出

日期：2026-09-19 ~ 09-21　來源：openRuyi 提交記錄、openRuyi 官網新聞頁

openRuyi 滾動發行版倉庫視窗內落地約 20 項 SPECS 提交：新增 cloudpods 與 cloudpods-operator（多雲管理平臺）、vkmark、assimp、glm、kes 等軟體包；更新 go 1.27.1、jemalloc 5.4.0、iptables 1.8.13、flashrom 1.8.0、libjaylink 0.5.0。容器棧方向跟進上游倉庫遷移（podman、buildah、composefs、containers-common 的地址更新），並在預設 seccomp profile 中放行 riscv_hwprobe 系統呼叫——該改動允許容器內程式探測 RISC-V 硬體特性，對雲原生負載的可移植性有實際意義。整體看，發行版正在”伺服器與雲原生”方向持續堆包：雲平臺、容器、韌體工具三類元件同時推進。

官網新聞頁核查：最新條目仍為”openRuyi 2026.08 釋出”（08-27），2026.09 版本尚未釋出。按該發行版月度節奏（每月下旬釋出），9 月版本已進入釋出視窗，下一期需重點跟蹤。

1.4 openRuyi ceph-ci：Ceph RISC-V 移植持續推進，precommit-hooks 新倉落地

日期：2026-09-18　來源：ceph-ci 提交記錄、openruyi-precommit-hooks 提交記錄

openRuyi 的 Ceph 移植 CI 倉庫視窗內落地 8 項提交：為從 GitHub 拉取原始碼引入 token 認證，解決 CI 拉取失敗；對 rocksdb v9.11.2 打 GCC 16 相容補丁（強制包含 cstdint 頭）；rgw 側 lancedb 升級至 0.39.0，並在 riscv64 上預設關閉 lancedb；CI 流程改為用 dnf 把構建出的 rpm 安裝進乾淨基礎映象做驗證，替代此前的手工檢查。另有 openruyi-precommit-hooks 新倉庫建立，首個鉤子為 SPDX 許可證頭檢查，用於統一軟體包提交的許可宣告規範。

Ceph 是分散式儲存的主力元件，其 RISC-V 移植與 CI 化意味著該發行版在”儲存底座可復現構建”上又進一步。GCC 16 相容補丁這類提交也提示：openRuyi 已開始跟隨下一代工具鏈的預適配節奏。

2.1 2026 半導體生態發展大會：RISC-V 國際標準時間表與藍芯 LX500 商業進展

日期：會議 2026-09-17 ~ 09-19（上海）；報道 09-20 進入視窗　來源：財聯社／科創板日報 via 東方財富《聚焦2026半導體生態發展大會：產業轉向多元技術突圍 天基計算、三維封裝與RISC-V多點開花》

在上海舉行的 2026 半導體生態發展大會（主題”AI 驅動新質創芯”）上，RISC-V 成為獨立議題板塊，兩條產業資訊值得記錄。

標準時間表：超睿科技（上海）執行總裁兼技術長蔣江指出，AI 產業運算元庫重複投入、生態割裂的痛點，根源在於晶片底層指令集與微架構不統一；RISC-V 的開放標準、軟硬體解耦、開源生態是其成為 AI 晶片創新底層正規化的三大優勢。就 RISC-V 成為國際標準的時間表，他給出”最樂觀預計 2027 年底獲批，客觀來看可能需要 2 至 3 年甚至更長時間”的判斷，同時強調這是”不可逆轉的大趨勢”。

商業進展：藍芯算力（深圳）技術長賈新霞披露，公司今年 2 月點亮首款基於 RISC-V 的”智通融合”一體 CPU 藍芯 LX500，並基於該晶片推出面向 AI 原生場景的智慧體一體機；產品已完成 Qwen 3.5 35B（BF16 精度）與 Kimi K2.6 萬億引數大模型的適配，Kimi K3 128K 超長上下文版本適配推進中。客戶側已落地頭部運營商、央國企集團、雲服務廠商、金融機構、高校及工業領域，2026 年以來收穫國內外批次訂單並啟動交付，部分國際叢集專案在建。

2.2 SEMICON India 2026 閉幕：DIR-V 大賽揭曉，C-DAC 釋出 AI 與量子平臺

日期：2026-09-19 ~ 09-20　來源：thepublicworld《SEMICON India 2026 Wraps up with 15 New Announcements on Chips, AI and Quantum Tech》、fintechbiznews《Digital India RISC-V Grand Challenge Won By 3 Teams》（Google News 聚合）

SEMICON India 2026 閉幕，15 項新公告中 RISC-V 相關內容佔據重要位置：Digital India RISC-V（DIR-V）Grand Challenge 結果揭曉——賽事由 Maker Village 在 MeitY 的 Chips to Startup（C2S）計劃下組織，共吸引 1,236 支團隊、5,000 餘名參與者，三支團隊的方案分享 60 萬盧比獎金：第一名 SASTRA 大學基於 IIT Madras SHAKTI 處理器的自主水面清潔機器人，第二名來自特里凡得琅的數字聽診器（執行於 C-DAC VEGA 處理器），第三名 IISc 班加羅爾的森林監測系統。參賽作品均基於印度自主 RISC-V 處理器（SHAKTI、VEGA），顯示其國產處理器生態開始支撐實際應用創新。

2.3 Openchip：歐洲主權 RISC-V 晶片 BER10 的兩年流片路徑

日期：2026-09-17（視窗首日）　來源：RISC-V International《V Questions with… Openchip’s Cesc Guim and Marc Fernández》

RISC-V 國際基金會刊發對巴塞羅那 Openchip 兩位負責人的訪談。BER10 是歐洲基於開放標準自研的高效能 RISC-V 應用處理器：團隊 2024 年初從零組建，350 餘名員工分佈西班牙、義大利、波蘭、比利時、法國、德國、愛爾蘭，不到兩年時間完成流片，且一次成功、無需重流片。晶片為 64 位、可執行 Linux，整合向量單元、一致性 fabric、儲存與互連子系統以及獨立管理 tile。資金方面依託歐盟 NextGenerationEU 計劃下 IPCEI 微電子專案的 1.11 億歐元支援。

訪談中的三個要點：其一，晶片回片約三週後成功啟動作業系統，團隊稱下一個”傳統節目”是跑 DOOM；其二，公司定位強調”交付系統”而非只交付晶片——整合、認證、支援與生產級軟體棧是商業化前提；其三，正與歐洲多方討論基於 seL4 的主權系統棧，把”每一層都可驗證”作為歐洲主權計算的目標形態。該案例是歐洲 Chips Act 框架下 RISC-V 路線最具代表性的樣本之一。

2.4 Nordic 釋出 nRF54LC10A：Cortex-M33 加 RISC-V 協處理器的多協議 SoC

日期：2026-09-17 釋出，09-18 進入視窗　來源：LinuxGizmos《nRF54LC10A SoC features Cortex-M33, RISC-V coprocessor, Bluetooth LE, Thread and Zigbee》

Nordic Semiconductor 擴充套件 nRF54L 系列，新增入門級多協議 SoC nRF54LC10A：128MHz Arm Cortex-M33 主核（帶 FPU、DSP、MPU 與 TrustZone）+ 128MHz RISC-V 協處理器，後者用於軟體定義外設與時間關鍵任務的解除安裝；1MB NVM、192KB RAM；2.4GHz 無線電支援藍芽 LE（含 Channel Sounding）、Thread、Zigbee、Matter 與專有模式（最高 4Mbps）；提供 CSP29、CSP39（約 1.93 × 2.29mm）與 QFN48 三種封裝。當前為專案制早期送樣，量產預計 2027 年二季度。

這是 RISC-V 作為”內部控制核/協處理器”進入國際大廠主流 IoT 產品線的又一例項：跟隨主核存在、不對外暴露程式設計模型，但出貨規模可觀——與 NVIDIA GPU 內建 RISC-V 控制器屬同一滲透路徑的不同環節。

3.1 達摩院玄鐵：zero_stage_boot 釋出 XuanTie_V1.4.0 穩定版

日期：2026-09-18　來源：zero_stage_boot 釋出頁、damo-rv-priv-ats PR #32

達摩院玄鐵開源的零階段引導專案 zero_stage_boot 在 09-18 晚釋出 XuanTie_V1.4.0 穩定版（此前經過 rc1、rc2、rc3 三輪預釋出）。釋出產物為成套預編譯包：zsb 韌體本身、OpenSBI 0.9 與 1.7、Linux 5.10 與 6.6 核心，覆蓋 32ilp32、64ilp32、64lp64 三種 ABI 組合（6.6 附 debug 變體）——面向下游 SoC 廠商與板卡夥伴的啟動鏈整合，開箱即可在對應玄鐵 CPU 上跑通”零階段引導—OpenSBI—Linux”鏈路。opensbi 倉庫在同一批次同步推送。

同組織其它動靜：特權態測試倉庫 damo-rv-priv-ats 在 09-18 更新測試計劃、把測試項與規範條款建立連結（PR #32），延續其”測試對齊規範”的工作方式；其餘 70 餘個公開倉庫視窗內無推送，符合其近期以啟動鏈與安全測試為主線的節奏。

進迭時空 spacemit-com 組織視窗內 29 個倉庫有推送，其中 09-18 傍晚近 30 個倉庫在一分鐘內完成批次推送（抽查 linux-6.18 分支為 k3-br-v1.0.y 產品分支更新），覆蓋 buildroot、U-Boot、OpenSBI、Linux 6.18、Mesa、MPP 及 VPU/GPU 測試工具等 K3 產品線全棧元件——屬典型的產品分支批次同步，為下游 K3 平臺整合商提供統一基線。視窗內該組織無新版本號釋出。

3.3 算能：ZSBL 釋出 v3.2.0；sophon-tools 連發 2.1.x 並支援 f2fs

日期：2026-09-18 ~ 09-20　來源：sophgo/zsbl 提交記錄、sophgo/sophon-tools 提交記錄

ZSBL（零階段引導）在 v3.1.0 釋出次日再發 v3.2.0（09-18），納入兩項裝置模型改進：平臺裝置改為按裝置樹路徑命名、無驅動的裝置不再例項化，對下游發行版列舉與識別外設更友好。此前一天還調整了版本邏輯、移除平臺版本欄位，顯示引導韌體在為一輪面向多平臺的釋出做準備。

燒寫工具 sophon-tools 的 psewriter 元件視窗內連發 2.1.0 至 2.1.3 四個版本：新增”只格式化 TF 卡”模式並調整為第一順位、內建中文字型修復現場亂碼、修復 LVM_SETCOLUMNWIDTH 導致的啟動失敗。09-20 繼續加入 f2fs 支援（ota_update、socbak、bmssm 可按分割槽配置），併為 BOOT、recovery 分割槽增加檔案系統型別防護——配錯分割槽型別會靜默破壞啟動鏈，這類”護欄”提交體現工具正從”能燒寫”走向”現場交付可靠性”。

3.4 矽速：SLogic 邏輯分析儀軟體棧重構，驅動共享核心與三平臺 CI

日期：2026-09-18 ~ 09-20　來源：sipeed/SLogic 提交記錄、sipeed/slogic16u3-tools 提交記錄

矽速 SLogic 邏輯分析儀軟體棧視窗內完成一波架構級重構：把 libsigrok 驅動移植進共享核心、去重裝置表、為 Combo 8 型號拆分獨立驅動檔案（slogic8u2.c）、為訊號模式增加顯示名稱的標準化匯出，並移除共享核心中的 Windows 限速邏輯；CI 側建立三平臺（Windows/Linux/macOS，含 Wine 預算控制）全產品構建。工具鏈側：slogic16u3-tools 新增 Config 標籤頁（WinUSB/udev 環境一鍵配置）、中英文國際化與操作介面重構、標籤觸發的便攜版自動釋出工作流，並修復 GBK 區域設定下捕獲崩潰與凍結版 Windows 構建的模組路徑問題。

此前（09-17 期已收錄）該工具鏈剛完成燒寫 CLI 共享與 libusb 內建；本期是”資料採集側核心重構”與”應用側交付打磨”的同步推進，工具鏈正在向跨平臺、可釋出的工程形態收斂。

3.5 Radxa Linkr：v1.5.0 釋出，外掛中心與網路外掛上線

日期：2026-09-18　來源：radxa-linkr/linkr Releases

Radxa 的瀏覽器遠端管理產品 Linkr 釋出 v1.5.0（距 v1.4.2 約兩週）。新功能：外掛中心——外掛上傳、安裝、啟用、停用與解除安裝的統一入口；ZeroTier 與 EasyTier 網路外掛——支援加入網路、檢視網路資訊、退出網路；截圖水印按截圖尺寸自適應；OCR 文字識別——識別結果可編輯、複製，並支援透過外掛離線執行；實驗性 IPv6 支援；Agent API 支援切換解析度與影片質量。改進與修復：鍵盤相容性與輸入延遲、音訊播放被攔截時的提示與手動恢復、Tailscale 改用 REST API 並提示與 ZeroTier 的衝突。

Linkr 面向開發板與 NAS 的遠端管理場景。本次版本以”可擴充套件外掛體系”為主線，是其從單機工具走向平臺化產品的重要訊號——外掛化的網路通道（ZeroTier/EasyTier/Tailscale）尤其適合遠端運維場景。

4.1 蘇州睿芯×啟元機器人：高光 D35 資料流物理 AI 晶片進入人形機器人生態

日期：2026-09-20（量產訊息 09-14）　來源：上海證券報 via 新浪財經《睿芯RISC-V資料流物理AI晶片牽手啟元機器人》、極客公園《啟元機器人釋出 Q1/T1 雙新品 官宣蘇州睿芯為算力生態合作伙伴》、蘇州工業園區《RISC-V資料流物理AI晶片量產！》

上緯新材（688585）旗下消費級具身智慧品牌啟元機器人 09-20 在上海釋出 Q1、T1 兩款個人機器人（19999 元起），並官宣蘇州睿芯積體電路為算力生態合作伙伴：雙方將圍繞具身智慧端側算力需求展開技術合作，推進資料流架構 AI 晶片在人形機器人場景的落地。

蘇州睿芯成立於 2020 年，走”RISC-V 指令集 + 資料流架構”的差異化路線：擁有 80 餘項資料流專利，核心團隊來自中科院計算所、中科院自動化所、IBM、Intel 等機構，研究成果獲 ISCA 2026 最佳論文提名；其全自研 RISC-V CPU 核心 IP 已透過國際半導體巨頭技術認證並進入全球採購體系。旗艦產品高光 D35 定位”全球首款 RISC-V 資料流物理 AI 晶片”——以資料到達觸發計算，減少資料搬運的能耗與延遲，主打邊緣端推理，單晶片最高支援 128GB 高速視訊記憶體，採用 Chiplet 先進封裝與全棧軟體工具鏈，已於 9 月中旬由蘇州工業園區宣佈量產。釋出會在生態展區展示了 D35 晶片實物與控制器模組。

意義與邊界：這是國產 RISC-V 晶片首次以”算力生態夥伴”身份進入消費級人形機器人釋出會的舞臺；但合作目前處於”技術合作與落地探索”階段，D35 在啟元產品中的實際裝機形態與量產節奏仍待後續披露，報道中的晶片引數均引自廠商口徑。

4.2 進迭時空 spacemit-robotics：ORB-SLAM3 執行倉庫與使用指南落地

spacemit-robotics 在 09-20 匯入 ORB-SLAM3 執行倉庫（ros2_orbslam3_run）：首次提交即包含從 CameraInfo 與 TF 載入相機標定的能力；配套的 manifest 倉庫把該執行倉庫加入工作區清單，docs-ros 文件倉庫同步合入 ORB-SLAM3 使用指南（PR #208）。ORB-SLAM3 是視覺 SLAM 的經典開源實現，支援單目/雙目/慣性多模態。本次以”倉庫 + 清單 + 文件”三件套的標準形態整合，意味著視覺建圖與定位能力正被規範地納入 K3 機器人軟體棧，是空間計算平臺補齊感知鏈路的一步。

4.4 算能 sophon-demo：π0.5 VLA 移植例程與 CV84X6 批次適配

日期：2026-09-19　來源：sophon-demo release 分支提交記錄

算能 sophon-demo 在 release 分支合入 π0.5 VLA 移植例程（面向 BM1684X SoC，09-19）：把 Physical Intelligence 的 π0.5 視覺-語言-動作模型移植到自家邊緣推理平臺，這是其示例庫繼大語言模型（LLM-TPU）之後向具身智慧模型側的關鍵落子，為機器人客戶提供開箱可跑的 VLA 參考實現。同批提交完成 CV84X6（SE13-64）形態的批次適配：11 個檢測/跟蹤樣例，以及 FLUX.1、Stable Diffusion XL/1.5、Seamless、ChatTTS 等生成類樣例外。至此該示例庫在”感知-生成-動作”三類負載上均有 CV84X6 支援，反映出算能為新一代封裝形態所做的軟體配套已基本成型。

五、總結與趨勢觀察

  • 資本側出現國內 RISC-V 最大單筆融資：奕行智慧近 20 億元、投後估值近 150 億元，疊加蘇州睿芯高光 D35 量產並牽手啟元機器人、藍芯算力 LX500 客戶落地——雲端算力與具身智慧兩條高價值賽道同時拿到”商業化證據”。與半年前”技術驗證”敘事相比，接下來的關鍵變數是交付與訂單兌現，估值給出的信任票需要用營收來還。
  • 標準與生態節奏並行：超睿科技給出 RISC-V 國際標準”2027 年底最樂觀”的時間表，與前幾期國內汽車 QC/T 標準啟動編制互為呼應；標準週期以年計，而產品釋出以月計，兩條線的節奏差是理解產業預期的關鍵。
  • 開源軟體側的”伺服器化”穩步推進：openRuyi 的 cloudpods、容器棧 seccomp 放行 riscv_hwprobe、Ceph 移植 CI 等提交，都是把伺服器級工作負載搬上 RISC-V 的基礎工作；openRuyi 9 月版本已進入釋出視窗，下期重點跟蹤。
  • 香山生態本週技術含量集中在 AME 矩陣擴充套件：NEMU/difftest 連續落地矩陣擴充套件邊界行為與差分適配，配合分支級的 store prefetch 最佳化佇列，矩陣計算與訪存最佳化是其近期主軸。
  • 國內廠商工程主線各有側重：達摩院玄鐵釋出 ZSB 成套韌體（啟動鏈）；算能快速迭代 ZSBL 與燒寫工具（交付可靠性）；矽速重構 SLogic 軟體棧（工具平臺化）；進迭時空批次同步 K3 分支並深耕機器人軟體棧（ORB-SLAM3、人機介面）；Radxa Linkr 以外掛體系轉向平臺產品。
  • 侷限性說明：本期資料來自公開網頁與 GitHub 公開提交，未使用任何非公開渠道。GitHub 未認證 API 在採集期內接近速率上限，部分倉庫的提交明細經 Atom 源與事件介面交叉核驗；RISC-V 國際基金會會員官網巡檢有 70 家抓取失敗（以國內站點與反爬站點為主）；會議類資訊（半導體生態發展大會、SEMICON India）來自聚合渠道，已標註會議日期。
  • 下一期關注點：openRuyi 2026.09 版本是否釋出（含容器與雲原生棧更新）；奕行智慧新一代晶片與超節點的交付節奏；蘇州睿芯與啟元機器人合作的具體落地形態；香山各最佳化分支的合併動向；達摩院玄鐵工具鏈與核心倉庫是否恢復推送。
