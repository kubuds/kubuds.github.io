一、開源社群與軟體生態

1.1 CPython 官方支援 RISC-V（Tier 3 平臺）：軟體生態里程碑

日期：2026-08-24（Python Insider 公告）/ 08-31（Adafruit 轉載、HN 熱帖）　來源：Python Insider（官方公告）、RISE Project 部落格、Adafruit 報道（gnews 連結）

CPython 維護者 Stan Ulbrych 在 Python Insider 官方部落格宣佈：RISC-V 正式成為 CPython 的 Tier 3 受支援平臺（PEP 11）。達成條件的關鍵是真實硬體上的持續測試——RISE Project 提供了多臺物理 RISC-V 機器用於 CPython buildbot 與架構相關問題除錯；主要貢獻者還包括 RISE 的 Ludovic Henry、Furkan Onder 與 Emma Smith，Ulbrych 本人的工作獲 Sovereign Tech Agency 獎學金資助。下一步：藉助 RISE RISC-V Runners 計劃把 RISC-V 直接接入 CPython 官方 CI（合併前即可獲得反饋），並長期爭取升級至 Tier 2；同時探索利用 RISC-V 特性的架構級效能最佳化。公告同時呼籲社群在真實 RISC-V 硬體上構建並反饋問題。該公告 08-24 釋出，昨日報告未覆蓋，本期補錄；08-31 Adafruit 轉載與 Hacker News 熱帖使其在視窗內獲得高關注，是近一週 RISC-V 軟體生態最重要的里程碑。

1.2 Arduboy CHGame Rev0：39 美元開源 RISC-V 彩色掌機

日期：2026-08-31　來源：Hackster.io、Arduboy 商店

經典開源掌機 Arduboy 推出新平臺 CHGame Rev0：39 美元裸板開發套件，主控為沁恆（WCH）CH32X035G8U6——32 位 RISC-V 微控制器，48 MHz，64 KB Flash、20 KB RAM，帶 DMA 與可程式設計 I/O（PIO）；配 1.44 英寸 ST7735 彩色 LCD（128x128、16 位色）、八顆按鍵、壓電揚聲器、microSD 槽與 200 mAh 電池。Arduino 相容免驅動，板面絲印標註 GPIO/功能分割槽並開放 GPIO、I2C、UART 擴充套件口，官方定位是”自帶螢幕按鍵的 RISC-V 開發板”。當前為資助開發的前期套件，量產成本預計進一步下探。這是國產 RISC-V MCU（沁恆）在海外開源硬體社群的一次典型落地，延續 CH32V003 系”白菜價 RISC-V 掌機”熱度。

二、產品與生態動態

2.1 Micro Magic MagicV 處理器宣佈立即供貨，宣稱世界最快/最低功耗 64 位 RISC-V

日期：2026-08-31　來源：PR-Inside（ACCESS Newswire 通稿）、Middletown Life 轉載

美國矽谷私有公司 Micro Magic 宣佈其 MagicV 處理器系列即日供貨，提供 1/2/4 核配置，現場演示多核 MagicV 執行 Linux、Zephyr 與 FreeRTOS。通稿重申歷年宣稱的指標：單核 1.1V 下 5 GHz、13,000 CoreMarks；0.8V 下 4.25 GHz 僅 200 mW（11,000 CoreMarks）；能效 110,000 CoreMarks/Watt；超低功耗核 1 GHz 僅 10 mW；資料基於 16nm 工藝，更先進節點可用。CEO Mark Santoro 稱客戶對效能印象深刻、低功耗表現”令人震驚”。需注意：全部效能數字均為廠商自宣，未見第三方基準或流片公開證據，公司長期尋求戰略合作或併購，建議作為”宣稱待驗證”條目跟蹤（Micro Magic 自 2021 年即釋出類似宣稱，本次為首次宣佈可購貨）。

2.2 西班牙 Indra-UPM 首批四晶片流片交付，含 RISC-V 架構晶片

日期：2026-08-31　來源：Demócrata

西班牙 Indra 集團與馬德里理工大學（UPM）聯合教席”改變未來的微電子”完成首批四款晶片設計並送製造，現已產出交付、進入評估表徵階段。具體為三顆 65nm 矽晶片（TSMC 流片）與一顆磷化銦（InP）光子整合晶片（研究波束成形架構）。其中一顆矽晶片採用 RISC-V 架構，另兩顆用於 3D 異構整合測試，目標是推進射頻模組小型化與整合度。專案為預競爭環境，學生與工業博士參與，服務於歐洲技術自主戰略；Indra 同時是專注 III-V 族光子製造的 Sparc Foundry 大股東（維哥工廠預計 2027 年投產）。該動向與西班牙 OpenChip（RISC-V International 董事會成員）等佈局同頻，屬歐洲主權晶片路線在 RISC-V 側的中型落地。

三、國內團隊動態與深挖

3.1 國內團隊 GitHub 動態：RevyOS 新增 K1/K3 核心配置，算能 sophon-tools 發版批次落地

日期：2026-08-31　來源：revyos/linux commits、sophgo/sophon-tools commits、sophgo/mcu PR#84、spacemit-com/docs-buildroot、sipeed/maix_ax620e_sdk

視窗核心查七家國內團隊 GitHub 組織：平頭哥（XUANTIE-RV）、芯來（Nuclei-Software）、奕斯偉計算（eswincomputing）、樂鑫（espressif）無相關 push，延續釋出後平靜期。有實質動態的三家：

進迭時空生態 RevyOS（revyos/linux，Han Gao 08-31 批次提交）為最值得關注項：新增 spacemit K1/K3 核心配置檔案、linuxboot 啟動配置，啟用 CONFIG_ERRATA_PICOHEART 與 Banana Pi F3（K1）USB2 支援，並啟用 K3 平臺 DC（顯示控制器）與 UFS 支援，同時把 TH1520 的 USB 相關選項改為模組化、串列埠數量配置調整。這是 RevyOS 發行版面向 K1/K3 雙平臺的核心配置增強批次，表明進迭時空生態正在為 K3 新平臺的顯示/儲存能力鋪軟體底。spacemit-com/docs-buildroot 同日移除 K1 secure boot 文件章節（文件清理）。

算能：sophon-tools 08-31 共 15 筆提交（zetao.zhang），為 v26.08.31 發版前置批次——修復 BMSSM（單板管理系統）OTA 升級/回滾首條 workflow 被自身 handler 鎖誤殺（MYS-451 競態）、sophliteos 升級語義改為系統級並加二次確認碼、deb 打包補齊控制成員與空 preinst（根治 overlayfs 下 dpkg obsolete-info 報錯）等，屬系統管理棧穩定性加固；sophgo/mcu 同步修復 SM5MINI(v20) 的 i2c_slave_reset 錯誤清除 IP 資訊問題。

矽速：maix_ax620e_sdk 修復 UVC 端點生命週期問題（相機流穩定性），小幅維護。

總體看國內團隊仍處常規迭代期，無架構級/產品級釋出；K3 平臺軟體棧推進是視窗內最值得跟蹤的訊號。

四、具身智慧與機器人專章

4.1 MicroDuck：Hugging Face 與 Pollen Robotics 的開源雙足機器人（生態參照，主控非 RISC-V）

日期：2026-08-27（釋出）/ 08-31（OSChina 報道）　來源：OSChina、Pollen Robotics 官網、Interesting Engineering

Hugging Face 機器人團隊（2025-04 併入的法國 Pollen Robotics）推出 MicroDuck：25 cm、不足 800 g 的開源雙足機器人，15 個電機、相機、深度感測器、雙 IMU 與可抓取喙，399 美元預購（08-27 開放），能行走、下蹲、跌倒爬起甚至輪滑；軟體棧全開源（Microduck 與 Microduck RL 兩倉庫），覆蓋控制、模擬、強化學習與 sim-to-real，支援用遊戲手柄”玩著”訓練新技能。預購首日銷售額超 250 萬美元、高峰每 4 秒售出一臺，交付目標 2026 聖誕前。與 RISC-V 的關聯：主控為瑞芯微 RK3566（ARM 平臺），非 RISC-V 硬體，收錄為開源具身智慧生態參照——其”開源硬體 + 開源 RL 軟體棧 + 低價普及”模式與 RISC-V 機器人生態路線同構，軟體棧（50 Hz 控制環、策略部署、OTA 更新機制）的可移植性值得 RISC-V 平臺借鑑；也為”開源硬體走向消費級具身智慧”提供市場驗證樣本。

五、總結與趨勢觀察

  1. 軟體生態里程碑：CPython 將 RISC-V 列為 Tier 3 受支援平臺（PEP 11），RISE Project 提供真實硬體 buildbot 是達成關鍵；下一步接入官方 CI 並衝擊 Tier 2。Python 是 AI 與科學計算主語言，此事件對 RISC-V 開發者生態的長期價值顯著。
  2. 開源硬體持續平民化：Arduboy CHGame Rev0 以 39 美元把沁恆 CH32X035 RISC-V 掌機帶進主流開源硬體社群，國產 RISC-V MCU 海外滲透再添一例。
  3. 高階宣稱與主權晶片並行：Micro Magic 宣佈 MagicV 可購貨（效能數字均為廠商自宣、待驗證）；西班牙 Indra-UPM 四晶片流片含 RISC-V 設計，歐洲主權晶片路線在射頻/光子方向延伸。
  4. 國內團隊進入常規迭代期：七家組織無釋出級動態；RevyOS 新增 K1/K3 核心配置（含 linuxboot、K3 DC/UFS）是視窗內最實質進展，算能 sophon-tools v26.08.31 發版批次以系統棧穩定性加固為主。
  5. 具身智慧生態參照：MicroDuck 首日 250 萬美元預購驗證”低價開源機器人 + RL 軟體棧”需求強勁，但其主控為 ARM；RISC-V 側機會視窗仍在 9 月國內機器人展會季與各家 SoC 機器人 SKU。
  6. 侷限說明：Google News 中文源對國內團隊直採仍受限（同名噪音汙染），國內部分依賴 GitHub 提交核查；Micro Magic 指標未經獨立驗證；MicroDuck 與 Indra 條目部分資訊來自廠商/學院通稿，已儘量交叉核對。
