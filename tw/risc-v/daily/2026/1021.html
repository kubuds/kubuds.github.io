今日重點：藍芯算力釋出智通融合超節點，RISC-V AI 算力從單晶片走向叢集

日期：2026-10-19 釋出（10-20 集中報道）　來源：經濟參考網：藍芯算力釋出智通融合超節點（10-20）、證券日報網：藍芯算力釋出智通融合超節點（10-20）、36 氪：藍芯算力釋出智通融合超節點 RISC-V 加速拓展 AI 推理新場景（10-20）、投資界：藍芯算力釋出智通融合超節點（10-20）

第六屆 RISC-V 中國峰會第三日（10-19），藍芯算力（深圳） 釋出智通融合超節點，把基於 RISC-V 的 AI 計算能力從單晶片、伺服器推進到叢集化算力基礎設施。當日 CTO 賈新霞以「LX500：解鎖 AI 推理新路徑」為題發表演講。

  • 架構主張：傳統「CPU + 獨立加速卡」方案要靠 PCIe 在不同記憶體空間之間搬資料，大模型推理的長上下文與首 Token 延遲被頻寬和功耗放大。智通融合把通用計算與 AI 計算整合在同一晶片，並以統一記憶體架構減少搬運，超節點是這條路線向更大規模系統的延伸。
  • 晶片規格：LX500 整合 48 個 RISC-V 核（32 效能核 + 16 能效核），同時整合 AI Vector 與 Matrix 計算引擎，AI 算力 75 TOPS INT8，支援 INT4 至 FP32 多種精度；共享 DDR5 記憶體資源，支援 CXL 擴充套件。
  • 產品節奏：2026 年 2 月晶片點亮，4 月首次公開亮相，5 月釋出一體機原型，7 月搭載 LX500 的聯想問天 WR5219 G5 伺服器亮相，8 月起向多家行業客戶送樣並進入小批次部署測試。至此形成 LX500 晶片、WR5219 G5 伺服器、LX5000 智通融合一體機、智通融合超節點四級產品矩陣。
  • 軟體與場景：已圍繞 Qwen、DeepSeek、Kimi 等大模型開展適配，覆蓋不同引數規模、不同精度與長上下文場景；落地方向為企業私有知識庫 RAG、Agent 辦公助手、金融合規推理、政府離線問答與工業現場檢測。

3.3 樂鑫 esp-emu 0.50.0：P4／S31 融合乘加提速約 3 倍，P4 視訊記憶體視窗跟隨 MMU

日期：2026-10-20　來源：espressif/esp-emulator: esp-emu 0.50.0（10-20）

樂鑫開源模擬器 esp-emu 0.50.0 於 10-20 釋出，RISC-V 側改動集中在 ESP32-P4／S31／C3：

  • 效能：P4 與 S31 的單精度融合乘加改走宿主直通路徑，約 3 倍加速，sinf、expf、powf 等數學函式隨之受益，結果與標誌位保持一致。
  • 記憶體模型：P4 的 PSRAM 視窗改為跟隨 PSRAM MMU，執行時重對映外部記憶體視窗的韌體不再讀到全零，也不會在非法指令處 trap。
  • 缺陷修復：C3 與 S3 的 BLE 發射功率 API 在控制器使能後不再觸發 Load access fault；P4 針對 rev 0.x／1.x 韌體的啟動在模擬器側提前拒絕，並給出改用對應 ROM 或重新編譯的兩種修法。

模擬器與矽片行為對齊得越細，RISC-V 端側韌體的 CI 才越有替代真機的可能——這也是樂鑫持續投入這條工具鏈的實際價值。

4.2 智元機器人兩年投資 47 家企業，A 計劃三年孵化 50 餘個早期專案

日期：2026-10-20　來源：大河財立方：智元機器人兩年投 47 家企業｜名單（10-20）、新浪財經：智元機器人的投資版圖（10-20）

據財聯社創投通—執中資料，智元機器人兩年內已投資 47 家企業，並透過合資方式設立至少 17 家新公司，與 40 餘家上市公司達成含資本在內的合作；今年啟動的「智元 A 計劃」計劃三年內孵化 50 餘個早期專案。投資主線清晰：一端直投本體與大模型公司（數字華夏、首形科技、靈初智慧、星源智機器人），另一端鎖定關鍵零部件（千覺機器人、靈猴機器人、富興電機）。出貨節奏上，公司預計今年數千臺、明年數萬臺。

與 RISC-V 的關聯：智元是 10-19 芯際無限 Pre-A 輪的聯合投資方，而芯際無限主攻的正是具身智慧全棧 RISC-V 晶片。本體廠商以資本繫結上游晶片，使具身智慧的指令集選擇在早期就被產業資本鎖定——這是今年值得持續跟蹤的一條暗線。

4.3 峰會 10-21 香港日：Demo Talk 場地落定，議程與講者持續更新

日期：2026-10-20 ~ 10-21　來源：第六屆 RISC-V 中國峰會官網議程（10-21）、峰會官網原始碼倉庫提交記錄（10-20）

第六屆 RISC-V 中國峰會主會期（10-18 ~ 10-20，深圳會展中心福田）已收官，10-21 為 RISC-V 香港日，地點在香港城市大學 ICP B-101 室，時間 9:00 ~ 17:10。峰會官網與原始碼倉庫在視窗內仍有兩處更新：10-20 的 Demo Talk 場地補入向日葵廳 5F，機密計算講者資訊更新；原始碼倉庫視窗內 3 筆提交（HEAD 10-20 22:06），議程頁文字由 15316 增至 15343 字元。

五、總結與趨勢觀察

  • RISC-V 的 AI 敘事從「晶片」升級為「系統」：藍芯算力把智通融合從單晶片推到超節點，睿芯用資料流架構吃 35B 模型的本地推理，中科通量直接給出工作站 + 一體機 + 加速卡的三件套。三家不約而同繞開「對標通用 CPU」，轉而按推理場景組織算力——這是本期最清晰的產業訊號。
  • 國產團隊的差異化在架構層，不在製程層：資料流（睿芯、中科通量）、統一記憶體與 CXL（藍芯）、SMT 與 AME 矩陣擴充套件（達摩院）——在先進製程受限的前提下，這些是能靠設計拿回來的效能。達摩院給出的 C950A 五倍目標，本質也是同一邏輯的延伸。
  • 軟體棧的補齊從工具鏈轉向服務端中介軟體：openRuyi 單日 40 筆提交裡，minio、Prometheus、sarama、uwsgi 這類雲原生元件佔了大頭；樂鑫則把模擬器的矽片一致性做到單條指令級。前者決定 RISC-V 伺服器能不能承接真實業務，後者決定端側韌體的迭代速度。
  • 資本與產品開始同頻：進迭時空 10-19 釋出 V100、10-20 完成 B+ 輪，間隔一天；智元以 47 筆投資把本體與上游晶片綁在一起。相比前兩年「先融資再找場景」，今年的順序更像「先出產品再補彈藥」。
  • 具身智慧的政策底座正在成型：工信部給出全年 10 萬臺的量級預期，並明確要釋出 2026 版標準體系建設指南、建設人形機器人開源社群。對 RISC-V 而言，這是把晶片、中介軟體與場景介面一併寫進規範的時間視窗。
  • 侷限說明：藍芯算力超節點的節點內晶片數量、互聯方式與交付時間未公開，現有報道只有方向性表述；睿芯「全球首款量產 RISC-V 資料流物理 AI 晶片」與「Intel 全球採購認可」均為公司口徑，未見 Intel 側公開確認；中科通量產品規格來自廠商在峰會現場的公開介紹，缺少第三方實測；工信部資料釋出於 10-19，本期收錄依據為其釋出會實錄與 10-20 的集中報道；會員官網巡檢檢出的變化均為高校與機構首頁例行更新，未發現實質產品、融資或架構釋出；香山系倉庫組織側 pushed_at 顯示有推送，但預設分支 atom 複核視窗內無新提交，判斷為非預設分支活動。
