一、開源社群與軟體生態

1.1 Canonical 詳解企業級開源 RISC-V 軟體就緒度：Ubuntu riscv64 包透過率 55.1%（09-07）

日期：2026-09-07（ServeTheHome 週一釋出，入窗時間 09-08 01:00 北京時間）　來源：ServeTheHome

ServeTheHome 補錄 Hot Chips 2026 演講實錄：Canonical 矽谷合作總監 Gordan Markus 系統講解 Ubuntu 的多架構構建機制與 RISC-V 企業級就緒路徑，並給出量化缺口資料——Ubuntu 26.10 測試快照中 riscv64 共 3,443 個軟體包接受測試、1,898 個透過，透過率約 55.1%，遠低於 amd64 的約 92%。Canonical 將差距部分歸因於模擬構建與測試目標（執行時間從數小時被拉長到數天），並已引入原生 RISC-V 構建機，夥伴提供伺服器級 RVA23 平臺支援。開源協作側：Canonical 參與 RISC-V International 的 RISE 專案（面向移動、消費電子、資料中心與汽車的商業軟體就緒），其 Ubuntu 24.04 原生 RISC-V runner 支撐託管於 Scaleway Elastic Metal 的構建與板卡農場，使用阿里與進迭時空（SpacemiT）硬體，已累計 116 個組織、24,000 個任務與 70 萬分鍾構建量。Canonical 的核心判斷是：RVA23 風格 profile 讓軟體目標可預測，配合大規模上游協作可跨越拖慢新 ISA 開源採用的歷史性”軟體就緒差距”；未來兩年伺服器級 RVA23 硬體陸續到位後，軟體棧有了固定收斂目標。這是視窗內對企業級 RISC-V 軟體生態最有資料價值的一條。

1.2 香山：新向量後端 vfma 通路重構與寬指令支援批次落地（09-07）

日期：2026-09-07（16:19~17:33 北京時間批次）　來源：GitHub openxiangshan/XiangShan commits

香山開源高效能核（昆明湖）向量後端重構持續推進：09-07 下午批次合入 feat(vfma) “support vfma in new vector backend”、feat(vector, vfmac) 重構 pipeline 暫存器並支援 widen 指令、fix(vector) 初始化 vfma pipe metadata，標誌新向量後端執行通路從整暫存器移動（昨日批次）延伸到浮點乘加（vfma/vfmac）與加寬運算；同批還包含 bypass 就緒與非暫存器源修復、LoadQueueReplay 非對齊 head 延遲喚醒處理、ROD 編碼對齊修復（#6509）與 FFlagsWen 表補入 VFREC7_V/VFRSQRT7_V。結合前幾日 vialu/mgu 連線與向量寬窄指令支援，可判斷香山向量執行子系統重構正按”指令功能補齊—通路資料流修復—浮點矩陣運算接入”的順序推進，工程成熟度持續提升，本視窗無版本釋出。

1.3 CVA6：修復面擴充套件至 RV32/64 指令合法性，虛擬化與記憶體保護繼續打磨（09-07~08）

日期：2026-09-07 20:18 ~ 09-08 05:36（北京時間，9 個提交）　來源：GitHub openhwgroup/cva6 commits

OpenHW Group 應用級開源核 CVA6 在視窗內繼續批次合入修復，覆蓋面較昨日進一步擴充套件：新增指令語義合法性維度——zip/unzip 僅 RV32 合法、RV64 應解碼為非法（#3527），拒絕 RV64-only FCVT 在 RV32 上的非法使用（#3540），mstatus.MPP 在 RVH=1 時對保留值 2’b10 的合法化；虛擬化與記憶體保護路徑延續昨日主題——ptw 修正 HLVX 規則不適用於 VS-stage PTE 讀的 G-stage 檢查、PMPADDR63 越界訪問修復（#3485）；另補禁用 C 擴充套件時的 misaligned branch 迴歸測試（#3424）、假 4 KiB 別名迴歸測試（#3453）與 debug 迴圈共享指標越界修復。連續兩日合計逾 15 個提交，虛擬化兩階段地址轉換與 PMP 安全路徑的打磨進入高頻期，可作為 RISC-V 開源應用核質量維護節奏的觀察訊號。

二、產品與生態動態

2.1 YuzukiHD 開源 YuzukiNeko：Allwinner F101（達摩院玄鐵 C907）Pico 尺寸 Linux 板卡（09-08）

日期：2026-09-08　來源：CNX Software、YuzukiHD/YuzukiNeko GitHub

開源硬體團隊 YuzukiHD 釋出新板 YuzukiNeko：Raspberry Pi Pico 尺寸（約 51 x 21 mm）的 Linux 單板機，搭載全志新款 SoC Allwinner F101”智慧控制與顯示處理器”。F101 採用單核達摩院玄鐵 C907 RISC-V 核（1.008 GHz，32 KB I-cache + 16 KB D-cache），QFN-68 封裝，SiP 整合 8 MB（F101S2）或 16 MB（F101S3）PSRAM（252 MHz），整合顯示引擎（RGB888 720p、單鏈路 LVDS 1366x768、4 通道 MIPI DSI 1280x800）、大尺寸 JPEG/PNG 解碼、USB 2.0 DRD 與 512 bit eFuse。板載 128 Mbit SPI NOR + microSD、USB-C（資料/供電/燒錄）、雙 20-pin GPIO 擴充套件排針與 FEL 按鍵。軟體側 YuzukiHD 已在 GitHub 開源原理圖、EasyEDA 工程、Gerber、3D STEP 與 BOM，並提供基於 mainline Linux 7.2 的 sun252i_f101 分支、Buildroot 外部樹及 Zephyr RTOS 支援（Linux 與 Zephyr 雙系統）。Whycan 論壇訊息稱 F101 SoC 單價約 18 元人民幣（約 2.7 美元），社群預期整板售價可低於 10 美元。板卡尚未開售。意義：達摩院玄鐵 C907 繼 D1 系（C906）後再獲本土 SoC 大規模低成本採用，超低價”Linux/Zephyr 雙系統”RISC-V 微板卡生態有望進一步擴張。
