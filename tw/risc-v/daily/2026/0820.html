1.2 社群辯論：Dmitry Grinberg 批評 RISC-V 嵌入式 ISA，多方回應（08-19）

日期：2026-08-19（Adafruit 轉載 02:37 北京時間）　來源：Adafruit Blog、dmitry.gr 原文

嵌入式開發者 Dmitry Grinberg 撰長文《RISC-V: They Should Have Known Better》，批評 RISC-V 嵌入式核心的指令集取捨，Adafruit Blog 於 08-19 轉載引發社群熱議。核心論點：RISC-V 嵌入式指令集（以 RV32E 為參照）缺少 aarch64 式的位域指令（BFC/BFI），他統計同一核心映象中位域插入/提取指令出現 6,284/8,881 次，認為”唯一的目的——嵌入式核心——RISC-V 反而比現有競品更差”，並批評程式碼密度與上下文切換設計。社群回應亦迅速：

  • rvembedded.com《A Third World Embedded Engineer Responds》以實機案例反駁：CH32V003 十美分的 RV32EC 核心（16 暫存器、無乘除、僅 M 模式）即可支撐其兩款量產產品，工具鏈數小時可上手，”有 ISA 手冊和 C 編譯器就夠”；
  • Reddit r/RISCV 討論多持正面立場：”RISC-V 設計良好、將是未來主導 ISA、無效能天花板，向量擴充套件優於 ARM”；
  • HN 同步發酵（回應帖 5 分 2 評）。

這是一場”嵌入式 ISA 設計取捨”的公開辯論，雙方圍繞位域指令、程式碼密度、成本與工具鏈成熟度交鋒——標誌著 RISC-V 已進入”可以被嚴肅批評、也有實機證據回應”的生態成熟期。

1.3 開源專案觀察：labwired-core——ARM/RISC-V 確定性韌體模擬器（08-20）

日期：2026-08-20（08:13 北京時間）　來源：github.com/w1ne/labwired-core（59 stars）

w1ne 釋出 labwired-core：面向 ARM Cortex-M 與 RISC-V 的確定性韌體模擬器，主打”經硬體驗證的並行外設模擬”（hardware-validated parallel peripherals），用於韌體在環測試。屬嵌入式/韌體測試方向的新工具，RISC-V 側覆蓋值得關注（當日新建、星級尚低，僅作生態觀察）。

二、產品與生態動態

2.1 頭條：賽昉科技釋出 Dubhe-100——RVA23 合規的伺服器/HPC RISC-V CPU IP（08-19）

日期：2026-08-19（官方 X 官宣 13:19 北京；CNX 報道 08-20 08:00 北京）　來源：CNX Software、StarFive 產品頁

賽昉科技（StarFive）官方釋出 Dubhe 家族新旗艦 Dubhe-100——面向伺服器與 HPC 的 64 位 RVA23 合規商用級 RISC-V CPU IP，官方 X 稱其為”commercial-grade RISC-V CPU IP for servers and HPC”。核心規格：

  • ISA/微架構：RV64GCBVH（含 B/V/H 擴充套件）、15 級流水線、6 發射超標量、深度亂序執行、支援指令融合與多核快取一致性、AIA 1.0 中斷架構；
  • 效能：SPECint2006 15/GHz、Dhrystone v2.2 10.0 DMIPS/MHz（官方宣稱值）；
  • 向量與密碼：支援 RISC-V Vector（RVV）與 Vector Crypto 全套擴充套件；
  • 安全與除錯：PMP/PMA（可配 16/32/64 區域、最小 4096 位元組粒度）、Svpbmt、符合 RISC-V Debug/Trace 規範的除錯與跟蹤介面、HPM 硬體效能計數器；
  • 目標應用：伺服器/HPC、LLM 推理、AI agent、視覺分析（計算機視覺）、基礎設施晶片（Smart NIC 控制器、分散式儲存控制器）；
  • 首個客戶：LECARC（希奧端計算，2026-06-29 官宣合作）正基於 Dubhe-100 設計智慧邊緣伺服器 SoC；
  • 軟體生態：開發走 StarFive StarStudio IDE，Dubhe SDK 尚未開放下載（預計商用 SoC 落地後放出到 starfive-tech GitHub）。

定位評述：Dubhe-100 使賽昉進入”RVA23 高階核心”競爭圈，與平頭哥 C950（64 核、RVA23、矩陣加速）正面同場；RISC-V International CEO Andrea Gallo 同期評價”2026 年就是高效能 RISC-V 應用處理器之年”，Dubhe-100 官宣是最新註腳（詳見 3.1 深挖與第四章）。

2.2 Pine64 暫停 Linux 裝置生產：DRAM/eMMC 缺貨漲價（08-19）

日期：2026-08-19（CNX 報道 18:29 北京時間）　來源：CNX Software、Hackster.io

Pine64 官方（社群 Mastodon）宣佈：因 DRAM 與 eMMC 缺貨且價格高企，即日起暫停 Linux 裝置生產，”生產是否恢復取決於 2027 年年中之後的儲存價格走勢”。要點：

  • 斷貨時間表：PineNote 與 PineTab2 預計約 3 個月內售罄；RISC-V 相關的 Star64（JH7110，StarFive 雙 A55 類核心）同屬受影響 Linux 產品線；
  • MCU 產品不受影響：PineTime 手錶、Pinecil 烙鐵、PinePower 電源等 MCU 產品線繼續生產並擴張（儲存成本佔比低）；
  • 行業訊號：AI 需求擠壓 DRAM/eMMC 產能導致價格暴漲，低成本 Linux/RISC-V 單板機廠商首當其衝——對”平價 RISC-V 入門硬體”供給是負面擾動，社群入門平臺（Star64 等）短期供應承壓。

三、國內團隊動態與深挖

3.1 平頭哥：C950 效能數字的批判性覆盤——SHL 軟體棧與測量侷限（08-19）

日期：2026-08-19（13:36 北京時間）　來源：XenoSpectrum

昨日頭條（C950 原生執行 Qwen-3.8 27B）今日迎來行業媒體的批判性覆盤：XenoSpectrum 刊髮長文拆解”30 tok/s / TTFT 1.9s”數字背後的軟體棧與測量邊界：

  • 數字來源：出自 08-18 技術觀察者 tphuang 轉發的 XUANTIE 標籤幻燈片，非獨立複測結果；幻燈片另列出 Qwen3.8-2.4T-A95B 在 C950 上的 decode 7.2 tok/s / TTFT 8.5s；
  • 效能來源：核心是平頭哥 SHL（Heterogeneous Neural Network Library）異構神經網路庫——按精度與計算形狀選擇 MatMul/Linear 矩陣運算元、Softmax/RMSNorm 專用實現，配合運算元融合、緩衝區複用、格式轉換削減；官方倉庫公開支援 8/16/f16 位、對稱/非對稱量化與異構排程；
  • C950 定位：伺服器級 RISC-V 處理器 IP（雲/資料中心、AI agent 伺服器、高效能機器人），8 指令解碼、亂序執行、向量計算、Matrix AI 加速、RVA23 Profile 與 CoVE；Qwen3.8-27B 權重 08-12~14 上傳，C950 材料 08-18 即出，Day 0 適配屬實；
  • 測量侷限（原文重點）：精度、量化、批大小、提示長度、記憶體頻寬、功耗均未披露，無法與 GPU/Mac 同口徑對比；C950 是 IP，64 核 target configuration 不等於量產晶片出貨；TSMC 5nm 工藝（Nikkei 報道”5nm 驗證”）未經阿里證實。
  • 另：XUANTIE-RV/opensbi 倉庫 08-19 07:56 UTC 有推送（預設分支無新提交，疑為 tag/分支級更新；此前 08-07 已打 XuanTie_V1.4.0-rc2-c9502 標籤，C950 啟動韌體迭代持續）。

評述：這篇覆盤把敘事從”官宣里程碑”拉回”可復現基準”層面——RISC-V 跑 27B 大模型的方向性驗證成立，但距離可對標的效率資料仍需廠商披露測量條件。這與昨日報告”以媒體口徑為準”的侷限說明互相印證。

四、重點方向專章：具身智慧與機器人

4.1 RISC-V 高階算力敘事集體轉向 AI agent 與機器人（08-19）

本週兩條國內重磅（C950 與 Dubhe-100）在產品定位上高度同向——都把”AI agent 伺服器 / 高效能機器人 / 具身智慧”寫進核心應用場景：

  • 平頭哥 C950：官方口徑明確覆蓋”AI agent 伺服器與高效能機器人”，SHL 軟體棧 + 64 核 RVV 跑通 27B 級模型（30 tok/s），為端側/邊緣大模型推理提供基線資料；
  • 賽昉 Dubhe-100：目標應用含 LLM 推理、AI agent 與視覺分析，首客戶 LECARC 做”智慧邊緣伺服器”，官方宣傳語即”Agentic AI 時代”；
  • 香山 XSAI：矩陣加速器（CUTE）持續迭代，RISC-V 開源側的高效能 AI 計算底座同步推進。

對具身智慧的意義：VLA（視覺-語言-動作）模型上機依賴”端側可負擔的大模型推理”，C950 的 30 tok/s 基線說明 RISC-V 多核+向量路線在該方向已越過”演示”門檻；而 Dubhe-100 的 15/GHz 整數效能與 Vector Crypto 則指向”機器人算力底座 + 安全”的更高一檔定位。風險面同步出現：DRAM/eMMC 漲價使低成本機器人/邊緣硬體的整機成本承壓（見 2.2），供應鏈波動可能延緩平價具身平臺的鋪開。

五、總結與趨勢觀察

  1. 賽昉 Dubhe-100 官宣：中國伺服器級 RISC-V IP 再添一員——RVA23 合規、SPECint2006 15/GHz、Vector Crypto，與平頭哥 C950 正面同場，RISC-V 高階核心競賽進入”中國雙雄”階段；
  2. C950 效能數字迎來批判性覆盤：XenoSpectrum 拆解出 SHL 軟體棧是關鍵（運算元融合/量化/緩衝區複用），同時指出測量條件未披露、”IP ≠ 量產晶片”——”RISC-V 跑大模型”敘事進入理性討論期；
  3. 香山連續第三日高強度迭代（12 倉庫）：前端 IBuffer 時序、訪存亂序正確性、矩陣加速器 CUTE 三線並進，開源高效能核研發節奏不減；
  4. 社群辯論升溫：Dmitry Grinberg 對嵌入式 ISA 的批評與實機回應（CH32V003 案例）同屏出現，RISC-V 生態進入”可批評、有反駁”的成熟期；
  5. 供應鏈陰雲：Pine64 因 DRAM/eMMC 缺貨暫停 Linux 裝置生產（Star64 等 RISC-V SBC 受影響），AI 需求擠壓儲存產能的傳導開始波及平價 RISC-V 硬體。

侷限性說明：Dubhe-100 規格以 CNX 轉述與 StarFive 官方產品頁為準，SPECint2006 15/GHz 為 IP 級廠商宣稱值、未經獨立第三方複測；C950 效能數字為廠商幻燈片口徑（XenoSpectrum 亦強調非獨立複測）；XUANTIE-RV/opensbi 08-19 推送未核實到具體提交內容（預設分支無新提交）；gnews 中文查詢（zh-CN 區域）視窗內為空、英文正常，國內廠商中文報道可能存在漏報；本週廠商英文查詢（SiFive/Milk-V 等）空命中，未見海外頭部廠商新品。
