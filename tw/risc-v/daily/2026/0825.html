一、開源社群與軟體生態

1.1 CPython 官方支援 RISC-V：成為官方 tier 3 平臺（08-25）

日期：2026-08-25（部落格釋出同期；HN 收錄 08-24 20:12 UTC = 08-25 04:12 北京）　來源：blog.python.org、HN

CPython 正式宣佈 RISC-V 成為官方支援平臺，按 PEP 11 列入 tier 3。支撐路徑：RISE Project 提供多臺真實 RISC-V 硬體作為 buildbot 測試與架構問題除錯環境（Ludovic Henry、Furkan Onder、Emma Smith 等社群貢獻者），Sovereign Tech Agency 獎學金資助了本輪架構支援工作。下一步計劃：借 RISE RISC-V Runners 將 RISC-V 直接接入 CPython 官方 CI（比 buildbot 更快反饋）、長期推動升級 tier 2 並做架構特定效能最佳化。意義：Python 是 AI/機器人軟體棧的骨幹語言，官方 tier 3 支援為 RISC-V 端側與伺服器場景的軟體可用性補齊關鍵一環（配 2.1 的伺服器進展）。

1.2 Linux 7.3 新增多款 RISC-V 擴充套件支援（08-24）

日期：2026-08-24（Phoronix 10:12 UTC = 18:12 北京）　來源：Phoronix

開發中的 Linux 7.3 合入多款較新 RISC-V ISA 擴充套件的發現與列舉支援：間接 CSR 訪問（Smcsrind/Sscsrind）、計數器特權過濾（Smcntrpmf）、S 態計數器配置（Ssccfg）、計數器委派（Smcdeleg，覆蓋所有特權級）、記憶體原子性/一致性類（Zicclsm 非對齊訪存、Ziccamoa 原子操作、Ziccif 指令取指原子性、Ziccrse LR/SC 前向進度、Za64rs 保留集）、QoS 標識（Ssqosid，記憶體/快取頻寬監控）。另有 CFI Shadow Stack 處理改進、QoS 標籤上下文切換、UEFI Runtime 服務用於重啟/關機等。這批擴充套件以伺服器與效能監控導向為主，與 RVA23 伺服器平臺推進（見 2.1）在特性上直接呼應。

1.3 Hot Chips 2026：NVIDIA 詳解 CUDA 移植 RISC-V 的技術要求（08-24）

日期：2026-08-24（Chips and Cheese 釋出；HN 68 分、9 評論）　來源：Chips and Cheese、HN

Hot Chips 2026 上 NVIDIA 演講介紹將 CUDA 支援擴充套件到 RISC-V：要求 RVA23 profile 與 RISC-V server SoC / server platform 規範（含 RAS、專用安全處理器等基線特性）；額外要求 PCIe 一致性（否則 DMA 與 CPU 快取間需軟體顯式失效，CUDA 棧難以處理）、裝置間 P2P PCIe、向量擴充套件謂詞支援等，避免”最低公分母”導致無法用效能增強指令；ACPI 問題此前阻礙移植，已由 2025 年 UEFI 論壇的 RISC-V ACPI 支援與去年批准的 BRS（Boot and Runtime Services）規範解決。韓媒《每日經濟》（韓國）同期報道 NVIDIA 計劃將 AI 伺服器 CPU 支援從 Arm/x86 擴至 RISC-V。結合 SiFive 確認 CUDA 已在其 BigSky 平臺實際執行（見 2.1），”CUDA 上 RISC-V”從 2025 年表態進入技術要求落地階段。

1.4 RISC-V 指令集手冊進入 ISO/IEC DIS 26791-1 國際標準草案階段（08-24）

日期：2026-08-24（HN 12:54 UTC = 20:54 北京）　來源：HN、iso.org/standard/94578

RISC-V 指令集手冊以 ISO/IEC DIS 26791-1 編號進入國際標準草案（DIS）階段——ISO/IEC JTC 1 標準流程中 DIS 面向成員國投票，是正式國際標準化的關鍵節點。作為開放 ISA 走向 ISO 標準的標誌性動作，與 RISC-V International 在 JTC 1 的標準化推進一致。注：ISO 官網頁面反爬無法直接抓取正文，技術範圍以官網與 DIS 文字為準。

二、產品與生態動態

2.1 SiFive BigSky SF-2U870：全球首款機架式 2U RISC-V 企業伺服器釋出（08-24）

日期：2026-08-24（SiFive 新聞稿；HotHardware 12:23 EDT = 08-25 00:23 北京）　來源：SiFive 新聞稿、HotHardware、HPCwire

SiFive 在 Hot Chips 2026 同期釋出 BigSky SF-2U870 資料中心開發平臺，宣稱全球首臺企業級、可機架部署的 2U RISC-V 伺服器：32 核 P870-D @2GHz、256GB DDR5-5600、3.84TB U.2 NVMe、10/25Gbps OCP 3.0 網路、64 條 PCIe Gen5 擴充套件（可容納雙寬 GPU 與專用加速器）、RVA23 合規；開箱支援 Ubuntu 26.04 LTS 與 RHEL 10；面向超大規模雲廠商、晶片廠商與軟體商，用於企業軟體移植、負載調優與自研晶片流片前驗證。已限量現貨發售（官方稱”需求超供給”，CEO Patrick Little：”RISC-V 進入資料中心不再是遙遠願景”）。關鍵細節：SiFive 與 NVIDIA 合作移植 CUDA 並計劃把 NVLink Fusion 整合進未來平臺，CUDA 已實際執行於 BigSky，作為 NVIDIA GPU 上現代 LLM 工作負載的頭節點——RISC-V 硬體首次具備該能力。

五、總結與趨勢觀察

  1. RISC-V 伺服器化進入”實物交付”階段：BigSky 2U 機架伺服器限量現貨 + CUDA 實際執行（作 NVIDIA GPU LLM 負載頭節點）+ NVLink Fusion 路線圖，疊加 Linux 7.3 伺服器特性擴充套件（QoS 標識/計數器委派/CFI）與 ISO 標準化推進——資料中心”最後一公里”軟體棧正在密集補齊；
  2. NVIDIA CUDA 支援從 2025 表態到 2026 Hot Chips 技術要求細化（RVA23、PCIe 一致性、P2P），”伺服器級 CPU + 平臺”是硬門檻，直接利好 P870-D 類高效能核與 RVA23 伺服器規範生態；
