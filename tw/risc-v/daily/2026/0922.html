今日重點：奕斯偉計算透過港交所上市聆訊，有望成為港股「RISC-V 第一股」

日期：2026-09-21　來源：第一財經《奕斯偉計算透過港交所上市聆訊》、新浪財經／觀點網《奕斯偉計算透過港交所上市聆訊 2025年營收24.31億元》、網易號《奕斯偉計算透過港交所聆訊，RISC-V賽道有望迎來「第一股」》

據港交所檔案，北京奕斯偉計算技術股份有限公司於 09-21 透過港交所主機板上市聆訊，聯席保薦人為中信證券與中信建投國際（公司於 2026-07-31 第三次遞交招股書）。若後續發行順利，將成為港股「RISC-V 第一股」，填補 RISC-V 晶片賽道的上市標的空白。

經營資料方面：公司採用 Fabless 模式，以 RISC-V 為技術底座，產品覆蓋人機互動及多媒體處理晶片、互連及計算晶片，聚焦智慧終端與具身智慧兩大場景；2023 至 2025 年營收分別為 17.52 億元、20.25 億元、24.31 億元，2025 年淨虧損 15.16 億元；2026 年一季度營收 4.94 億元（同比增長 18.4%）、淨虧損 3.75 億元、毛利率 14.8%。截至 2026 年 3 月 31 日，已推出超 150 款軟硬體協同產品、服務全球 220 餘家客戶；計算產品收入從 2023 年的 37.5 萬元增至 2025 年的 3.20 億元，2026 年一季度達 2.23 億元，產品切入汽車、工業等核心賽道。以 2025 年營收口徑統計，公司為國內最大的智慧終端人機互動晶片提供商。

行業面資料一併釋出：據弗若斯特沙利文統計，中國 RISC-V 主控晶片市場規模由 2021 年的 11 億元增長至 2025 年的 377 億元（年複合增長率 139.5%），預計 2030 年擴大至 2194 億元。需要保留的邊界是：聆訊透過距正式發行與定價仍有流程要走，公司的淨虧損與計算產品線的放量節奏將是上市後最直接的檢驗指標。同日，公司 GitHub 側有配套釋出動作（見 3.1）。

一、開源社群與軟體生態

1.1 openRuyi：核心雙線升級至 7.2.6 與 6.18.52，安全修復批次落地

日期：2026-09-21　來源：openRuyi 提交：linux 升級 7.2.6、kernel-team-tools：TAG 升至 v7.2.6-1、openRuyi 官網新聞頁

openRuyi 滾動發行版視窗內提交 20 項以上，主線是核心雙線升級與上游跟進：linux 升級至 7.2.6、linux-lts 升級至 6.18.52（均含 patchset 與 config 重新整理）；kernel-team-tools 同步更新四個核心系列的構建標籤（6.18.52-1／7.0.14-5／7.1.13-1／7.2.6-1），並在核心配置中啟用 ULTRARISC、VFIO_IOMMU_TYPE1、ARCH_ANLOGIC 等選項；openRuyi-Project/linux 的 ruyi/6.18.y、7.0.y、7.1.y、7.2.y 四個維護分支當日同步推送。

構建體系側：新增 openruyi-linux-build 元件（為各風味變體提供統一的 linux 包），linux／linux-lts／linux-lts-kmhv2 三份 spec 改用 rpm 宏統一維護；glibc 2.44 跟上上游快照。安全與包更新批次落地：python-pytorch-lightning 2.6.6、python-datasets 5.0.1、python-ujson 6.0.0、ImageMagick 7.1.2.31、pcre2 10.48（提交均標註 security-fixes）；雲原生側新增 k8s konnectivity-client 與 kms、Datadog dd-trace-go、VictoriaMetrics 等 Go 包。官網新聞頁視窗內無新公告，9 月版本尚未釋出（最新為 2026.08，08-27 釋出）。

1.2 香山：昆明湖 V3 分支修復 CBO 與預取路徑，NEMU 將 mseccfg 改為可配置

日期：2026-09-21　來源：XiangShan 提交：LoadUnit 保留 prefetch.i 退休路徑（#6230）、NEMU 提交：mseccfg 改為 Kconfig 可選項（#1221）

香山主倉庫視窗內 5 項提交落在 kunminghu-v3 分支：LoadUnit 對 prefetch.i 改為正常退休而非在 S1 階段清除（#6230）；CBO（Cache Block Operation）指令兩項修復——decode 階段 numWb 改為 2、Load-Store Queue 的 StoreQueue credits 在跨 CBO lane 時正確保持；docker 基礎映象切換為 xs-env:stable（#6577）；CI 側改進 ckpt_select.py 並加入 nightly fuzz（#6604）。NEMU 側兩項：把 mseccfg 改為 Kconfig 可配置項（#1221）、虛擬化 supervisor 計時器僅在 nemu_timer 啟用時關閉。

GEM5 分支級開發同樣活躍：feat-ywl-pfbuffer 分支新增 PDB（預取資料緩衝）模型，並修復其重放清理與預取准入邏輯；視窗內另新開 Hybrid_CROB、calibrate-rvv-iq 等開發分支（分別指向混合 CROB 與 RVV 指令佇列校準）。difftest 與 XSCache 主分支視窗內無新提交；主幹合併動向仍待觀察。

1.3 Bluespec 開源硬體 IP 庫 Tape-Out（FukuzSoC）批次新開倉庫

日期：2026-09-21　來源：GitHub 組織 Tape-Out（FukuzSoC）

一個名為 FukuzSoC 的開源硬體 IP 庫 09-21 批次新開倉庫，包括三套參考 SoC（soc-mcu／soc-linux／soc-smp）與 PLIC 中斷控制器等。其組織自述為「用 Bluespec 構建、由 XiRang 包管理器裝配的開源硬體 IP 庫」：每個 IP 倉庫包含 ip.yaml（配置項、契約與實測面積）、regmap.yaml（暫存器對映）、Bluespec 原始碼與覆蓋全配置矩陣的行為測試；自研工具鏈 xirang 負責解析、生成、測試與「定價」，spec 定義檔案語義。

IP 譜系涵蓋 hart 處理器核、cache、NPU／GPGPU／YOLO 加速器，ACLINT／PLIC／IMSIC 等 RISC-V 中斷體系部件，UART／SPI／I2C 等外設與乙太網交換／路由模組；成熟度分 planned／simulated／fpga-proven／asic-ready／silicon-proven 五級，並在每個倉庫以徽章展示。參考 SoC 明確「不含自有 RTL」，全部由 IP 組合裝配——這種「包管理器 + IP 庫」的組織方式與國內常見的 RTL 單倉模式不同，其成熟度推進值得跟蹤。（注：為新近公開專案，尚未見公開的流片記錄與社群討論。）

1.4 simdjson 出現 RVV 向量後端實驗倉庫

日期：2026-09-21　來源：MA-Gustave/Simdjson-rvv-vla

開發者開源 simdjson 的 RISC-V 向量（RVV 1.0）實驗後端，採用向量長度無關（VLA）寫法，配套 GCC／Clang 驗證、執行時分發、上游驗收測試與可復現效能基準，倉庫 09-21 建立並當日連續推送提交。simdjson 是應用廣泛的高效能 JSON 解析庫，RVV 後端若被上游接納，將補齊 RISC-V 平臺在該庫上的向量加速路徑。注：目前為個人實驗倉庫，尚處早期階段，效能與上游接納進度待驗證。

1.5 開源生態短波：GNOME Flatpak riscv64 構建、Exercism 賽道與 AG32 開源工具鏈

日期：2026-09-21　來源：nico359/gnome-flatpak-riscv64、Exercism RISC-V 賽道、bbenchoff/AGaMEMnon

三條輕量動態：其一，開發者維護 GNOME Flatpak Platform／SDK 的 riscv64 非官方構建倉庫（09-11 建倉，視窗內持續更新），若成型將改善 RISC-V 桌面端容器化應用的分發條件；其二，Exercism 程式設計學習平臺開設 RISC-V 賽道（含獨立 test-runner，09-21 推送），RISC-V 進入該平臺的語言列表；其三，AG32（AGM 半導體 RISC-V MCU，內嵌 AGRV2K FPGA 邏輯）的開源 SDK 與工具鏈專案 AGaMEMnon（48 星，基於 yosys／nextpnr 的開源流程）視窗內活躍，繼續推進對這顆「MCU + FPGA」混合晶片的開源工具支援。

1.6 北京開源創新賽設開源智慧硬體賽道，11 月與 GOTC 2026 同期舉辦

日期：2026-09-21　來源：OSChina《從具身智慧到桌面小裝置，北京開源創新賽硬體賽道面向全國創客開放》

第四屆開放原子大賽·2026 開源行業解決方案創新賽（北京開源創新賽）開放報名：特設「開源智慧硬體解決方案」賽道，徵集智慧終端、嵌入式系統、物聯網裝置、具身智慧硬體等軟硬一體方案，覆蓋工業手持終端、醫療終端、機器人、可穿戴等形態；要求控制程式開放原始碼、結構件公開三維模型圖紙，可供他人復現。報名與材料提交截止 10 月 31 日，總決賽 11 月 13 至 14 日在北京亦莊舉行，30 支隊伍角逐 100 萬元總獎池，作品有機會在 11 月 14 日的 GOTC 2026 全球開源技術峰會（預計 3000 人次、100 個市集攤位）展出。RISC-V 在賽事導語中與 Arduino、3D 列印並列，被列為開源硬體生態的基礎性力量。

二、產品與生態動態

2.1 印度 Aheesa 釋出 VIHAAN-I：本土自研 RISC-V 寬頻網路 SoC 完成流片

日期：2026-09-21　來源：EE Times《Fabless Startup Aheesa Tapes Out First Indian RISC-V Network SoC》、Machine Maker《Aheesa Advances India’s Semiconductor Ambitions with Indigenous VIHAAN Broadband Networking Chip》

印度金奈的 Fabless 初創 Aheesa Digital Innovations 在 SEMICON India 2026 期間展示其自研 RISC-V 寬頻網路 SoC VIHAAN-I（廠商稱其為印度首款本土設計的 RISC-V 寬頻網路晶片）。該晶片為 28nm 工藝，單晶片整合計算、寬頻接入與系統控制，面向 GPON／EPON 光纖接入與電信基礎設施，目標是替代印度電信與網路領域的進口半導體。公司已完成 VIHAAN-I 流片，計劃進入多專案晶圓（MPW）製造，商用時間目標 2027 年一季度；專案獲印度 MeitY 設計連結激勵（DLI）計劃認可，並獲泰米爾納德邦新興行業種子基金投資。意義與邊界：這是印度「國產晶片」議程在電信基礎設施方向落下的第一個 RISC-V SoC 載體，但產品尚未量產，工藝與效能細節均來自廠商及展會報道口徑。

2.2 智慧汽車晶片生態大會續報：DF30 計劃 2026 年規模量產，英飛凌下一代車規 MCU 全面轉向 RISC-V

日期：2026-09-21（會議 09-16）　來源：鳳凰網轉網通社《2026第六屆智慧汽車晶片生態大會召開，東風、長安、上汽及英飛凌等企業討論RISC-V架構應用》、鳳凰網轉網通社《英飛凌宣佈下一代汽車MCU全面轉向RISC-V架構》

網通社 09-21 就 2026 第六屆智慧汽車晶片生態大會發布兩項後續報道，補足了此前未覆蓋的細節。其一，東風汽車披露其 RISC-V 車規晶片進度的量化座標：與中國信科聯合研發、武漢二進位制半導體參與的 DF30 基於 RISC-V 多核架構、國產 40nm 車規工藝、功能安全達 ASIL-D，2024 年 11 月釋出後已在東風奕派 007、猛士 M817、風神皓瀚等車型完成驗證，首搭發動機 ECU，計劃 2026 年規模量產、年底首批搭載量產車下線；為其提供 CPU 核心的芯來科技團隊從二十餘人擴至約五百人，晶片先後完成六百多項測試。

其二，英飛凌汽車業務高管在大會上闡述「下一代汽車 MCU 全面轉向 RISC-V」的佈局：新品納入 AURIX 家族（與 TriCore、Arm 產品線並存），其汽車 MCU 份額已從 2025 年的 32.1% 提升至 36%；2026 年 3 月釋出 DRIVECORE 虛擬原型評估包，國內部分主機廠與 Tier1 已用於前期評估；AUTOSAR 側聯合 Vector、東軟睿馳、普華適配，開源側推進 FreeRTOS／Zephyr／NuttX；並作為核心成員加入中國汽車晶片標準檢測認證聯盟（CACC）的汽車 RISC-V 工作組。行業口徑：RISC-V 在汽車領域的滲透率預計從 2025 至 2026 年的約 10% 升至 2031 年的 31%；Mobileye EyeQ Ultra 已整合 12 顆 RISC-V 核進入量產視窗，地平線征程 6 亦部分採用 RISC-V 核心量產。

2.3 IC WORLD 大會 RISC-V 開放算力論壇：電信「北海」平臺、算能伺服器 CPU 與 openKylin 適配進展

日期：2026-09-21 報道（會議 09-16 至 09-18）　來源：中國科技網（科技日報）《2026北京微電子國際研討會暨IC WORLD大會在亦莊舉辦》、賽迪網《助推RISC-V從「可用」走向「好用」，RISC-V開放算力論壇在京成功舉辦》、OSChina《openKylin亮相2026 IC WORLD大會，共探RISC-V算力生態建設》

2026 北京微電子國際研討會暨 IC WORLD 大會（09-16 至 09-18，亦莊）的「RISC-V 開放算力論壇：具身智慧·大模型·資料中心」細節在視窗內進一步披露（OSChina 09-21 刊出 openKylin 參會稿）。論壇由北京積體電路學會與 RDI 聚力聯盟主辦、北京 RDI 創新中心承辦：奕斯偉計算副總裁劉帥稱 RISC-V 出貨增速已超過 x86 和 Arm，公司持續打造 RISC-V 核心部件與方案；中國電信研究院介紹「北海」RISC-V 智算平臺建設成果，同時點出軟體生態適配難、大規模叢集驗證不足兩個瓶頸；武漢元石智算提出優先從儲存、管理場景切入、實現跨架構算力統一排程；openKylin 社群介紹其在硬體適配、AI 能力融合、雲原生支援及具身智慧場景的進展；北京算能展示量產 RISC-V 伺服器 CPU 在智算中心、政務雲等場景的落地案例；青島國實資訊分享 RISC-V 支撐海洋可信資料空間的建設方案；北京 RDI 創新中心表示下一步將打造 RISC-V 智算底座驗證體系，並佈局具身智慧端邊控制器。

3.2 算能：sophon-tools 修復批次與 Qwen3 系列 CV84X6 bmodel

日期：2026-09-21　來源：sophon-tools #200：VPSS 使用率抓取（v1.6.0）、LLM-TPU：Qwen3 系列 CV84X6 bmodel、sophon-demo：Qwen3.5 prefix cache 修復

3.3 進迭時空：model-zoo-vision 的 RVV 預處理融合最佳化與 mpp 更新

日期：2026-09-21　來源：model-zoo-vision #86：RVV 加速融合 CPU pack、mpp：流包按 VB 引用傳遞、ai-sdk 子模組更新

進迭時空視覺模型庫 model-zoo-vision 一天內合入 4 個最佳化 PR，主線是用 RISC-V 向量擴充套件（RVV）加速影象預處理：先以 RVV 加速融合 CPU pack（#86），再把 face／clip 模型遷移到融合 pack（#87），隨後把 tracking pack 與 RVV OCR 識別融合（#88），最後抽出共享的 RVV u8c3 pack 輔助函式完成重構（#89）。同視窗 mpp（多媒體處理平臺）在 feat 分支新增「流包按 VB 引用傳遞」並補齊測試與 cpplint 風格修正；ai-sdk 兩次更新 vision 子模組。預處理是 CV 流水線中典型的 CPU 密集段，這一組提交延續了其「把運算元從 CPU 通用路徑遷到 RVV」的最佳化慣性。

日期：2026-09-21　來源：芯東西《想看AI晶片下一步往哪裡走？沒來上海峰會的人，看這篇就夠了》

據芯東西 09-21 報道，2026 全球 AI 晶片峰會（上海，為期兩天）落幕，超 60 位嘉賓、逾百家 AI 晶片生態企業參會。RISC-V 相關看點集中在進迭時空：其晶片產品總監陳儉東介紹基於 RISC-V 推進「同構融合計算」——以統一架構、統一記憶體與統一軟體系統，實現 CPU 算力、AI 算力與實時算力的按需分配；兩代晶片已量產，K1 為第一代（AI 算力 2T），K3 為八核 CPU（主頻 2.4GHz、AI 算力 60T、支援部署 30B 模型），後續將開發更高算力平臺的「大小腦融合晶片」。展會側，芯來科技、Imagination、進迭時空等企業展出產品方案；具身智慧晶片論壇上，維泛智慧提出面向具身場景的 BiGPU 仿生類腦架構。峰會以「從 TOPS 到 Token」為主線，反映行業關注點正從峰值算力轉向推理場景的軟硬協同。
