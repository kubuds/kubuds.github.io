一、開源社群與軟體生態動態

1.1 RISC-V 架構大辯論持續升溫：Grinberg 批評長文引發多方回應（今日頭條）

日期：2026-08-14 原文首發（HN 376 分），本視窗內 08-16 兩篇重磅回應　來源：Grinberg 原文（dmitry.gr） / rvembedded 回應文 / The Chip Letter 綜述

獨立嵌入式開發者 Dmitry Grinberg 的長文《RISC-V: They Should Have Known Better》08-14 登上 HN 首頁（376 分，250+ 評論），成為近期對 RISC-V 架構最系統的一次批評。其核心觀點：一、單一 ISA 無法同時通吃廉價 MCU 與高效能運算兩端，”高階 CPU 的需求與低成本 MCU 的需求本質上對立”；二、壓縮指令編碼”荒謬”（如 S 型儲存指令 16 位編碼偏移量僅 0-3）、立即數在指令中散亂分佈（對比 MIPS/ARM）、Zicsr 等擴充套件本應內建；三、結論是”我 100% 確定 RISC-V 終將拿下廉價一次性 MCU 市場——但不是因為 ISA 設計得好，而是儘管它設計得一般”，靠的是免費與低價；高階桌面/手機市場則”不看好”。

本視窗內的新進展是兩篇高熱度回應（08-16）：

  • rvembedded.com《A Third World Embedded Engineer Responds》（HN 353 分，170+ 評論）：千里達及托巴哥的嵌入式工程師（已把整套 STM32/ARM 棧遷移到 RISC-V，代表作 CH32V003 教材）從”全球南方”視角反駁——對發展中國家的工程師與學生，10 美分與 1 美元的晶片差價、運費與海關壁壘遠比 ISA 優雅性重要；他桌上恰好擺著三個證據：10 美分 RV32EC 的 CH32V003（正是 Grinberg 親手推匯出的那類核）與 400 MHz 雙核 CH32H417 同屬一個 ISA 家族，直接反駁”單一 ISA 不能通吃”；同時誠實承認 Grinberg 部分批評合理（壓縮儲存偏移、Zicsr 獨立成擴充套件）。
  • The Chip Letter《RISC-V: What Really Matters》（08-16）：綜合評述認為 RISC-V 因”免費、主流工具鏈支援、可擴充套件”而註定成功——引 Raspberry Pi Pico 2 的 Hazard3 開源核設計者 Luke Wren：”滿足我對 ISA 的兩個要求：主流 LLVM/GCC 支援、不需要律師”；Meta MTIA 加速器團隊成員：”我們在 AI 加速器上用 RISC-V 大獲成功”；但高效能桌面/手機市場地位仍存疑，廠商或更傾向 ARM 授權路線。

意義：這是繼本週 Spectre-on-RISC-V 論文後第二個生態級話題，標誌 RISC-V 輿論從”技術新星”敘事進入”被嚴肅審視與反思”階段；爭論雙方反而在一點上高度一致——廉價嵌入式/端側市場 RISC-V 勢在必得（靠價格與開放，而非架構完美）。

1.2 RISC-V 官方高保證密碼學（HAC）規範連續第二日密集修訂（約 12 筆提交）

日期：2026-08-16（00:48~23:37 UTC）　來源：riscv/riscv-high-assurance-cryptography GitHub

HAC 規範倉庫視窗內再合入約 12 筆提交，延續昨日 ML-KEM/ML-DSA 後量子主線：Allow ace.restrict instructions in any state（允許 ace.restrictl/h/v 在任何 CR 狀態下執行，替代原先的異常路徑）、SCProtection 層級與 ace.restrictv 保留值範圍（3-5、6-7）明確化、CSK 術語統一（清理遺留的 RCSK 引用）、異常行為與零化（zeroization）規則澄清、ace.setst 使用控制修復、刪除 ace-examples.adoc 並持續處理評審意見（review1.md）。連續兩日密集修訂表明該面向 FIPS 140-3 級高保證密碼實現的擴充套件規範進入評審收斂衝刺期，與本週安全信任議題（Spectre 論文、密碼擴充套件）構成同一條主線：RISC-V 正系統性補課安全與密碼基礎設施。

四、重點方向專章：具身智慧與機器人

4.1 本視窗具身智慧方向平靜：運控主線仍是”雙核異構 + 成本敏感”

本視窗內具身智慧/機器人方向無新發布，回看近三日趨勢（08-15 滴水湖論壇與電子工程專輯專題）：國產 RISC-V 運控方案正從”單核實時”走向”實時核+應用核”雙核異構（峰岹 FU75XX、格見 500 納秒電流環、先楫 HPM53M1、進迭 K3 運控定位），端側感知—決策—運控三層國產化路徑成形（進迭 SPERT NPU 推理、算能視覺示例庫修補）。

4.2 架構之爭與具身智慧的交點：爭論雙方都承認”廉價嵌入式 RISC-V 勢在必得”

今日頭條的架構大辯論（1.1）與具身智慧方向形成有趣呼應：Grinberg 批評長文的結論恰恰是”RISC-V 將 100% 拿下廉價一次性 MCU 市場，靠的是價格與開放而非架構完美”——而具身機器人運動控制基座（關節電機控制、感測器融合）正是典型的成本敏感、實時性優先場景。爭論雙方（批評者與辯護者）在這一點上罕見一致，從側面印證：在機器人運控這一國產 RISC-V 的核心增量市場，RISC-V 的生態位不因架構爭議而動搖。運控晶片的國產替代路徑與”全球南方”嵌入式工程師的生態敘事（10 美分部件改變教育與實踐的邊界）同構：開放 + 低價是 RISC-V 在嵌入式/端側取勝的根本邏輯。

  1. 架構之爭成為本週生態第二熱點：Grinberg 長文（08-14，HN 376 分）引發”全球南方”工程師回應（rvembedded，08-16，HN 353 分）與 The Chip Letter 綜述（08-16）——RISC-V 輿論從”技術新星”進入”被嚴肅審視”階段；爭論雙方一致認同廉價嵌入式/端側市場 RISC-V 靠”開放+低價”勝出。

  3. 安全/密碼仍是 RISC-V 官方優先順序：HAC 規範連續兩日密集修訂（ace.restrict 任意狀態、SCProtection 層級、CSK 術語、零化規則），與本週 Spectre 論文議題同向；SPMP 凍結後首次維護。
  4. 國內團隊視窗內平靜：香山主分支無新合入（周邊例行），平頭哥/進迭/算能/芯來/奕斯偉無新增，深度動態集中在 08-15；樂鑫安全供應鏈基礎設施（NVD 映象/SBOM/安全看板）持續加碼。
  5. 開源桌面/OS 生態活躍：AROS riscv64 平臺定時器落地、felix86 x86 遊戲翻譯層活躍——與”高階市場存疑”的辯論形成張力，生態補位正在發生。
