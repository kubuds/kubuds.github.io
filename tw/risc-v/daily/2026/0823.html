一、開源社群與軟體生態

1.1 樂鑫釋出 ESP32-S31 Linux BSP 開發者預覽版：帶 MMU 的 RISC-V 微處理器正式支援 Linux（08-22）

日期：2026-08-22（CNX Software 報道 12:26 北京；HN 討論 20:50 北京）　來源：CNX Software、HN 討論帖、espressif/esp-linux-bsp

樂鑫正式釋出 ESP32-S31 官方 Linux BSP 開發者預覽版，這是 ESP32 家族首個官方支援 Linux 的 RISC-V 產品線：ESP32-S31 為雙核 RISC-V 微處理器（整合 MMU 記憶體管理單元），3 月首次亮相、5 月推出兩款開發板、數週前剛宣佈量產；開發板帶 16MB PSRAM，可承載最小 Linux 映象。要點：

  • 官方 BSP 構成（三倉庫分工）：esp-linux-bsp（映象佈局與打包工具，integration/v1.0-esp32s31 分支）＋ esp-buildroot-external（Buildroot 2025.02 的 NOR 啟動棧與根檔案系統，含構建燒錄指引）＋ espressif/linux（Linux 6.18 核心 fork，integration/v6.18-esp32s31 分支）；Buildroot 打包把 U-Boot SPL、FIT、裝置樹、XIP 核心與 cramfs rootfs 合併為單檔案 s31_full_flash.bin，esptool >= 5.3.0 直刷即可啟動 Linux console（115200 波特）；
  • 釋出狀態：開發者預覽、不推薦生產使用——官方明示”無固定更新節奏、可能隨時破壞性變更、功能接受有限、bug 按盡力而為修復”，僅面向早期採用者做技術驗證與反饋收集；已實現功能邊界（如 WiFi 是否可用）尚未完全明確；
  • 社群移植同步活躍：GrieferPig 的 esp32-s31-linux 把 MMU RV32 Linux 6.12 原生跑在 ESP32-S31 上（Buildroot rootfs 與 reboot 穩定，poweroff 未實現，WiFi/藍芽雙模/雙核尚為實驗性）；Marco（annoyedmilk）的移植則帶來 Linux 7.1 + OpenSBI 1.9（LCD/微 SD/USB host/WLAN 之外的外設未啟用）。

意義：樂鑫此前以 ESP-IDF/RTOS 生態著稱，Linux BSP 使”帶 MMU 的 RISC-V 微處理器”以官方渠道進入 Linux 世界，疊加量產後價格優勢，有望把完整 Linux 開發體驗下放到數十美元級嵌入式器件——與香山/進迭等高效能路線互補，構成”RISC-V 向低端滲透 Linux”的另一極。

4.1 無新增專項新聞：Linux 下放到低功耗 RISC-V MCU 強化邊緣算力底座（08-22）

日期：2026-08-22　來源：gnews 機器人專項查詢（”risc-v” robot when:3d、具身智慧 RISC-V when:3d）、GitHub 組織檢索

視窗內機器人專項查詢僅命中已報道舊條目（Alibaba 27B、Dubhe-100），中文”具身智慧 RISC-V”查詢為空，判定為無新增專項新聞日。但本日主新聞與機器人/邊緣算力直接相關：ESP32-S31 官方 Linux BSP（1.1）——帶 MMU 的雙核 RISC-V 微處理器跑完整 Linux，意味著一類低成本、低功耗器件可承載機器人主控與邊緣推理任務，配合 16MB PSRAM 與 XIP 核心，為”小器件跑完整 Linux 控制棧”提供官方通道；GrieferPig 的 Linux 6.12 移植已在 Korvo-1 開發板上穩定執行 rootfs。

觀察結論：機器人專項新聞密度繼續處於週期性低位（連續三日無獨立新新聞），趨勢線仍是”端側/邊緣算力持續下放”——前日 K1 視覺模型矩陣擴充套件（深度/分割）、KEO 邊緣 LLM，今日 ESP32-S31 Linux 化，共同指向 RISC-V 器件承載 AI/機器人負載的能力邊界不斷外擴。硬體與核心動作仍是最可靠的觀察錨點。

五、總結與趨勢觀察

  1. “Linux 下放到 MCU 級 RISC-V”官方化：樂鑫 ESP32-S31 釋出 Linux BSP 開發者預覽（Linux 6.18 fork + Buildroot 2025.02 整合），帶 MMU 的 RISC-V 微處理器以官方渠道進入 Linux 生態，疊加量產與價格優勢，與高效能路線（香山/進迭/賽昉）互補，構成 RISC-V 生態”高階追效能、低端擴應用”的雙向滲透；
  2. 社群移植與官方並行：官方 BSP 之外，GrieferPig（Linux 6.12 MMU RV32）與 Marco（Linux 7.1 + OpenSBI 1.9）兩個社群移植已在 Korvo-1 板上跑通——樂鑫器件的社群活躍度是 ESP32 生態傳統優勢，Linux 化後延續；
  3. 國內團隊節奏繼續分化：樂鑫（Linux BSP 三倉庫、活躍）、香山（5 筆例行）、算能（agent 工具鏈發版）有動作；進迭時空 0 筆（昨日 YOLO26 後休整）、平頭哥/芯來/奕斯偉/賽昉靜默；
  4. 產品線平靜：視窗內無新產品釋出，KEO / K230 為昨日事件轉載；ESP32-S31 量產節奏與 Linux 側 WiFi/藍芽支援進度是後續觀察點；
  5. 平靜日說明：gnews 英文視窗內新增僅 ESP32-S31 一條；廠商英文查詢（SiFive/Milk-V/SpacemiT/SOPHGO/StarFive/Andes）全部命中舊聞或噪音；中文區域查詢視窗內為空，國內動態以 GitHub 組織檢索捕捉（見附錄核查表）。

侷限性說明：ESP32-S31 Linux BSP 處於開發者預覽階段，已實現功能邊界（WiFi/藍芽在 Linux 側的狀態）官方未完整披露，本文以 CNX Software 實測與倉庫 README 為準；社群移植專案（GrieferPig/Marco）狀態以各自 GitHub 倉庫宣告為準，屬非官方支援；香山/算能提交按 committer 時間歸類，個別提交的 author 日期可能早於視窗。
