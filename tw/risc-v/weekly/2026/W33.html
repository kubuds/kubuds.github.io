RISC-V週報（2026-08-12）

2026-08-12 苦芽科技

資料來源:本機每日日報(8/11、8/12)彙總 + GitHub 組織提交補採(8/6-8/10 視窗,XUANTIE-RV / OpenXiangShan / Nuclei-Software / sophgo / spacemit-com 等)+ 跨視窗報道補錄。 說明:本機日報系統 8 月 11 日由 K3 機器遷移而來,8/6-8/10 無逐日日報,該區間以 GitHub 提交與 8/10-8/11 的跨視窗報道為準,已儘量去重合並。

一、開源社群與核心/規範動態

1.1 RVA23.1 與 RVB23.1 Profile 公開評審正式啟動

日期:2026-08-11　來源:HN / RISC-V isa-dev 郵件組

RISC-V 國際基金會啟動 RVA23.1 與 RVB23.1 Profile 公開評審,面向全社群徵集反饋。這是 RVA23/RVB23 系列規範釋出後的首個維護性迭代版本,涉及 A 類應用與 B 類基準 Profile 的細則修訂與勘誤更新,對工具鏈、核心與編譯器生態的適配節奏有直接指引意義。

1.2 QEMU 11.1 釋出:新增 RISC-V 大端支援與 K230 板級模擬

日期:2026-08-12(釋出 08-11 16:11 UTC)　來源:Linuxiac 經映象核實

QEMU 11.1 的頭號特性是 RISC-V 大端(big-endian)目標支援,對應 RISC-V 執行時可控端序能力的落地(Codethink 此前以此為主題開展研究)。RISC-V 側同步增強:新增勘智 K230 開發板支援、OpenSBI 升級至 1.8.1、新增 Tenstorrent mvendorid 支援,並修復大批 IOMMU、中斷處理、頁表遍歷與向量指令問題。RISC-V 核心/發行版開發者可在模擬器中先行驗證大端軟體棧。

1.3 香山 XiangShan:一週時序與正確性修復系列

日期:2026-08-06 ~ 08-10　來源:GitHub OpenXiangShan/XiangShan

香山本週合入多筆修復:FTQ/ICache meta 讀埠時序(#6281)、Phr 在 s1/s3 期間的更新時序(#6263)、vbop 握手邏輯整理(#6163)、WriteBuffer 同條目讀寫衝突(#6315)、IFU 異常時 s1_instrCount 計算(#6301)、StoreUnit 僅雙 TLB 命中時向 UnalignQueue 傳送 paddr(#6332)。另 XiangShanLab 倉庫新增 RISC-V spec/gap 技能工具(8/10)。工程側持續推進,為架構升級(見 3.2 開芯紅)提供支撐。

1.4 RISC-V 規範基礎設施倉庫活躍

日期:2026-08-11/12　來源:riscv-unified-db / riscv-arch-test

riscv-unified-db(規範機器可讀資料庫)合入多筆依賴維護提交,riscv-arch-test 更新 Ubuntu 24.04 Docker 映象。屬規範工程常規節奏,與 RVA23.1 評審配套推進。

1.5 社群反思文章《RISC-V: They Should Have Known Better》引熱議

日期:2026-08 上旬　來源:HN / dmitry.gr

資深嵌入式開發者 Dmitry.GR 釋出長文,批評 RISC-V 在中斷延遲、指令密度、定址模式等底層設計上的缺陷,稱部分嵌入式指標不如幾十年前架構。文章在 HN/Reddit 引發廣泛討論,新浪等中文媒體亦有轉載,是本週社群層面最重要的觀點性事件(屬觀點文,非官方立場)。

1.6 labwired-core:ESP32-C3(RISC-V)韌體模擬能力增強

日期:2026-08-12　來源:GitHub w1ne/labwired-core

Rust 編寫的確定性韌體模擬器 labwired-core(59 stars)合入 15 筆提交:新增 ATmega328P Nano 孿生、修復 ESP32-C3(RISC-V)上 DHT 單匯流排時序、新增資源度量功能。RISC-V MCU 在”韌體級模擬/虛擬硬體”工具鏈中的覆蓋度在擴大。

二、產品與生態動態

2.1 Comu:6 美元 USB 口 RISC-V 開發板

日期:2026-08-10　來源:CNX Software

基於沁恆 CH32V203(RISC-V 核心 MCU)的微型開發板 Comu,整板可嵌入 USB 介面內(U 盤形態),售價約 6 美元,顯著降低 RISC-V MCU 入門門檻,在 HN 上獲討論。

2.2 Dabao(Baochip-1x,DEF CON 34 徽章晶片)生態快速成形

日期:2026-08-10　來源:Adafruit Blog

DEF CON 34 徽章搭載的 Baochip-1x RISC-V SoC 獲得 MicroPython 實驗性移植;GitHub 上已出現 mainline Linux 啟動嘗試(baochip-linux)、裸機 DOOM 移植(baochip-doom)與裸機 C SDK(dabao-sdk)。一週內聚集”移植 Linux + 跑 DOOM + 出 SDK”,是 RISC-V 開源硬體社群活躍度的典型樣本。

2.3 尊界 V800 智慧座椅搭載奕斯偉 RISC-V 車規級 AI MCU

日期:2026-08-10　來源:快科技 / 鳳凰網

鴻蒙智行尊界 V800 亮相,其全主動自適應智慧座椅核心算力由奕斯偉計算 EAM2011 承載——國內首顆支援輕量級 AI 應用的車規級 MCU,搭載自研 32 位 RISC-V 核心,完成全鏈路本土化研發與量產。這是國產 RISC-V 車規晶片規模化上車的標誌性案例。

2.4 第五屆滴水湖中國 RISC-V 產業論壇預告(8 月 13 日舉行)

日期:2026-08-07(公告)　來源:新浪財經

第五屆滴水湖中國 RISC-V 產業論壇定於 8 月 13 日舉行,10 款國產先進晶片集中亮相(具體成果見下期週報)。

三、國內團隊動態

3.1 芯來科技:資本化推進 + 除錯工具鏈生態 + 蜂鳥 FPGA 修復

日期:2026-08-06 ~ 08-11　來源:新浪財經 / Nuclei-Software GitHub

三條線並進:8 月 10 日向全國股轉系統申報新三板創新層並定向募資 4200 萬元;8 月 11 日新增 lauterbach-startup 倉庫(Lauterbach TRACE32 偵錯程式啟動指令碼,國際除錯工具鏈適配);e603_hbird(蜂鳥 E203 相關)合入 DDR 時鐘層次與 bitstream 等 FPGA 修復(8/6-8/7)。”IP 龍頭資本化”與”生態工具鏈”雙線同步。

3.2 開芯紅(香山 IP 商業化主體):超億元種子輪,國資+頭部產投共同加持

日期:2026-08-11/12　來源:觀點網 / 新京報

開芯紅完成超億元種子輪融資,資金投向香山 IP 核架構升級;投資方陣容隨後披露:國開科創、誠通科創、中科創星、中關村科學城、啟航基金、國泰創投等國資與頭部產投機構。香山 IP 商業化同時獲得國家級政策資本與屬地產業資本背書(本週兩日連續報道,合併為一條)。

3.3 奕斯偉計算:車規上車 + 消費級 AI 私有云雙線落地

日期:2026-08-10　來源:快科技 / 網易(聚合) / 湖北經信廳(聚合)

奕斯偉本週多條動態疊加:車規側 EAM2011 進入尊界 V800 智慧座椅(2.3);消費側與極空間(ZSpace)合作國產 AI 私有云 NAS,圖片素材 AI 處理全部本地執行;集團材料業務(奕斯偉材料)擬募資 65 億元投向 12 英寸矽片擴產(2027 年首期投產)。”RISC-V+AI”在車規與消費兩端同時兌現。

3.4 算能(SOPHGO):SophLiteOS 新增 AI Agent + 工具鏈密集修復

日期:2026-08-09 ~ 08-12　來源:GitHub sophgo/sophon-tools / zsbl

sophon-tools 視窗內多筆合入:SophLiteOS 新增 AI Agent 功能(含 pbmssm LLM 轉發、picoclaw-web-chat 內嵌),把 LLM Agent 互動能力下沉到端側系統工具鏈——配合 K230/SG 系列 RISC-V SoC,屬”RISC-V 端側 + LLM Agent”直接工程進展;另有 pota_update/pmemory_edit 安全修復、Docker 三映象合併為單映象(體積約 10GB)等。zsbl 構建系統最佳化:剝離 Linux-kernel 依賴、修復內建 dtb 增量重建。

3.5 進迭時空(SpaceMiT):K3 生態文件與端側 AI 加速推進

日期:2026-08-06 ~ 08-10　來源:GitHub spacemit-com

docs-ros 更新 K3 機器人機械臂 ONNX 部署指南(#200);docs-buildroot 新增 K3 Secure Boot 指南;model-zoo-vision 用 eigen-spacemit + OpenBLAS 加速 YOLOv8-Seg mask GEMM(#64)。K3 的機器人/安全啟動/端側 AI 文件棧在 8 月第一週密集補全(注:K3 旗艦 SoC 將於 8/13 滴水湖論壇正式釋出)。

3.6 平頭哥(XUANTIE-RV):damo-rv-priv-ats 更新

日期:2026-08-06　來源:GitHub XUANTIE-RV/damo-rv-priv-ats

玄鐵 DAMO(動態記憶體分配與保護?)RV Priv ATS 倉庫更新:調整 config 目錄結構(#21)、更新測試以使用 CSR 編碼(#22,8/11)。屬玄鐵生態的許可權與地址翻譯側持續迭代。

四、具身智慧與機器人

視窗內無重大獨立新聞。 鄰近訊號:奕斯偉 EAM2011 在尊界 V800 上的人體姿態識別應用(感測器感知+動態適配技術棧與機器人控制共用);算能 SophLiteOS AI Agent 為 RISC-V 機器人大腦提供更輕的軟體基座;進迭時空 K3 機器人機械臂 ONNX 部署文件更新。8/13 滴水湖論壇預計有具身智慧相關晶片新品釋出,值得會後跟蹤。

五、總結與趨勢觀察

  1. 規範側進入評審視窗:RVA23.1/RVB23.1 公開評審啟動,QEMU 11.1 落地 RISC-V 大端支援,規範到工具鏈的適配路徑正在閉環。
  2. 國產 RISC-V 資本化加速:芯來申報新三板創新層(募資 4200 萬)、開芯紅超億元種子輪獲國資加持、奕斯偉集團 65 億擴產——IP/晶片廠商密集對接一級與二級市場。
  3. RISC-V 車規與端側 AI 規模化落地:EAM2011 上車尊界 V800、SophLiteOS 內建 AI Agent、奕斯偉 AI 私有云,國產 RISC-V 在”AI 落地”方向多點開花。
  4. 社群生態活躍度不減:6 美元 USB 開發板、DEF CON 徽章晶片的 Linux/DOOM/SDK 生態、Dmitry.GR 的 RISC-V 反思長文引發行業討論——既有低門檻硬體帶來的新鮮血液,也有對架構底層的嚴肅審視。
  5. 前瞻:8/13 第五屆滴水湖論壇(10 款國產晶片集中亮相,含進迭 K3、藍芯 LX500 伺服器 CPU、特普斯 EA6530 等)是下週期最重要的產業觀察視窗。
