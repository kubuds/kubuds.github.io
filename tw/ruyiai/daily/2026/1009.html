harness 以獨立倉庫承接 Triton-RISCV agent 後端與工作臺；triton-riscv 收到社群貢獻的 softmax / matmul 最佳化 PR（#85）。兩條線共同指向：RuyiAI 工具鏈的「agent 化 / 自動化」敘事與社群參與度並行上升——觀察 agent 工作臺與運算元貢獻的後續迭代節奏。

5.4 openRuyi 生態擴充套件與月版節奏

openRuyi 單視窗 61 筆（Go 生態 31、Python 3.14 升級批、AI 資料棧 17、ceph / moby / dotnet 等修復），為 2026.09 釋出後的持續性打包擴張，雲原生與 AI / 資料科學棧兩條生態線同步加厚。觀察點：下一月版週期開啟時，本批 Python 3.14 與 Go 依賴是否會進入版本構建基線。
