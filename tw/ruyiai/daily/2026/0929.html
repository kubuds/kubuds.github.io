今日重點：Caffe 三筆 RVV 運算元 PR 開出，MXNet 系列 15 筆在審——經典框架適配線進入實操

日期：2026-09-23 ~ 2026-09-28　來源：caffe PR #1、caffe PR #2、caffe PR #3、MXNet PR 列表

北京時間 09-28 14:56 至 14:59 之間（三分鐘內），貢獻者 Xlawy 在 caffe 倉（09-23 入庫的兩個經典框架倉庫之一）連續開出三筆 RVV 運算元 PR，為兩倉自入庫以來的首批實質程式碼動作：

  • #1 im2col（+113 / -9，2 檔案）：把 im2col 的輸出行收集拆分為標量助手與 RVV float 過載，每行按零填充與界內兩段拆分，依 stride_w 選擇單位步長或帶步長向量載入，採用變長 e32,m4 分塊；並順帶把 Protobuf 的 SetTotalBytesLimit 單引數 API 適配到 3.6.0 及以上版本。
  • #2 float CPU max pooling（+167 / -24，2 檔案）：以 e32,m4 分塊處理最大池化內部列，用帶步長載入與嚴格大於比較更新最大值及勝出位置偏移，保留首次出現平局語義與 -1 哨兵，並對三列視窗做展開；邊界仍走標量。
  • #3 float vPowx（+166 / -1，2 檔案）：為非 MKL 的 vPowx<float> 增加 RVV 特化——在輸入全為正規數且指數在 [-1, 1] 時啟用向量 log/exp 近似（雙精度中間量），指數 0 與 1 走直接向量運算，支援分塊的在位呼叫；域檢查不透過時整呼叫回退標量。

三筆均以 RVV 宏守衛新增特化、保留非 RVV 構建的標量回退，目前均處開放狀態、無評審記錄。同一路線的更早動作集中在 MXNet 倉：09-23 至 09-24 兩天內，三名貢獻者累計開出 15 筆 PR（ww8191201-coder 11 筆、Xlawy 2 筆、6eanut 2 筆），其中 11 筆為 RVV 運算元向量化——GELU(erf) 反向、ReLU 反向、softmax、log-softmax、softmin、CTC log-softmax、im2col、col2im、batched cumsum、最近鄰上取樣、float32 最小值歸約；另 4 筆為效能與構建基礎（broadcast_reduce 與 reduce_with_axis 的索引走法強度削減、求和歸約器 volatile 移除、非 MSVC 構建請求 -fno-math-errno）。多筆 PR 描述直接引用 SG2044（RVV 1.0、GCC 15.1）的測試語境。這一系列此前視窗未展開，本期與 Caffe 新動作合併記錄。

截至視窗末，兩倉合計 18 筆 PR 全部開放、無一合入。結合 09-24 期對兩倉「歸檔、適配基線或新工作起點」的待觀察記錄，本批動作給出階段性答案：兩倉被用作經典框架 RVV 適配的實操基地，MXNet 系列覆蓋推理主幹運算元面，Caffe 系列則聚焦卷積與啟用基礎設施。同日夜間，編譯器側的 RVV 動作由 tilelang-riscv PR #4 承接（見 1.1），RVV 成為當日組織內最集中的技術主題。

五、趨勢觀察

5.1 經典框架 RVV 雙線成形：從「入庫」到「堆 PR」

09-23 兩倉入庫時，其用途被記為待觀察；一週之內，MXNet 以 15 筆 PR（三名貢獻者）覆蓋 11 個 RVV 運算元與 4 項效能、構建基礎，Caffe 於 09-28 以三筆 RVV 運算元跟進——「適配」路線在經典框架維度正式落子。值得注意的細節：多條 PR 直接引用 SG2044（RVV 1.0、GCC 15.1）的測試語境，說明這批工作面向可執行的真機基線；與 PyTorch fork 側 RVV 補丁（#46、#48）仍在佇列等待形成對照——RVV 適配的當前推進，部分繞開了 PyTorch 主線。

5.2 中秋節前後的節奏：09-28 節後集中產出

09-25（農曆八月十五，中秋節）及隨後的週末，三組織提交近乎停擺；09-28 節後首個工作日出現集中產出：openRuyi 主倉庫 5 筆、kiwi-image 3 筆、VS Code 外掛 2 筆與 0.1.7 釋出、ruyiai-daily 與論壇資訊帖同日恢復——假期帶來的「低谷、反彈」在兩個視窗內完整可見。

5.3 工具側釋出節奏穩定

視窗內三條工具線按各自節奏推進：VS Code 外掛 0.1.7 轉正（beta 後 8 天）、Ruyi Imager 夜間渠道更新、triton-riscv 每週夜間構建按期產出；對應地，ruyi-tuner 的 1.9 版本線保持「未發版但變更在途」狀態已達兩個視窗。

5.4 本視窗的空白與關注點
