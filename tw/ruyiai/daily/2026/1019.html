第六屆 RISC-V 中國峰會於 10-18 在深圳會展中心（福田）開幕，會期至 10-20。按社群 10-13 公告，RuyiSDK 帶來主題演講、海報展示與 D15 展位的多方案演示，覆蓋 RuyiSDK 包管理器、IDE 與開發板支援矩陣等方向。視窗內論壇未出現峰會相關新帖或覆盤，最後一帖仍是 10-15 的每日資訊；演講材料與展位演示內容尚待會期後釋出。觀察點：會後是否補充演講幻燈片、演示方案與現場反饋。

六、趨勢觀察

6.1 編譯器棧版本聯動收緊：Buddy MLIR 兩日兩版，下游當日跟版

Buddy MLIR 從 0.1.0 到 0.1.1 只隔約兩日，且 0.1.1 的兩筆變更都指向可交付性——服務端交叉編譯讓 buddy-server 能進 RISC-V 機器，模型釋出工作流讓模型製品能出 CI。下游響應同樣按日計：triton-riscv 在 10-17 合入 #87 鎖定 0.1.0，10-18 上午由自動跟版升到 0.1.1 夜間版；tilelang-riscv 在 10-16 把 Buddy MLIR 釋出 CI 納入自建流水線。三條倉庫圍繞同一 LLVM 後端的版本耦合在收緊，觀察點在於是否形成統一的釋出視窗與迴歸基線。

6.2 兩條 fork 維護線繼續分化：PyTorch 併入與重放並行，LLVM 六日靜默

PyTorch 的 riscv 分支視窗內併入 143 筆（上游同步為主），並以整批重放維持本地補丁棧，同時出現近五週首筆 PR 合入（#51 riscv64 本地映象）；LLVM 的 riscv 分支則自 10-12 起六日無提交，兩筆 FPGA 後端 PR 停在 10-12。同是「上游 fork + 本地補丁棧」，一邊是按日推進的流水線，一邊是等待評審的靜態分支，維護投入的差異比上一視窗更明顯。觀察點：LLVM 重放是否隨新上游基線重啟，以及 FPGA 後端 PR 是否進入評審。

6.3 RuyiSDK 三線並進：核心探測補齊、發行版擴面、工具鏈等版本視窗

核心側把 RVA23 相關的原子性與取指原子性剖面擴充套件併入 cpufeature 與 hwprobe，私有擴充套件 ID 與上游對齊；發行版側補入 Rust 嵌入式六包，把 Rust 裸機開發的基礎依賴納入軟體源；工具鏈側 0.54.0 定檔 10 月底，ABI 相容檢測與 K1/K3 適配繼續推進；韌體線在三連發後暫停。整體呈現「核心探測補齊、發行版擴面、工具鏈等版本視窗」的節奏，下一步看 0.54.0 是否如期發版，以及峰會後的方案落地。
