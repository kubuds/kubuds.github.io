今日重點：進迭時空 X100/A100 核心支援合入 RuyiSDK GCC 16.2 分支

日期：2026-09-21　來源：spacemit-x100 提交、Spacemit-A100 提交

北京時間 09-21 15:04 與 15:10，RuyiSDK 的 GCC 多版本維護倉庫 riscv-gcc 的 16.2 分支先後合入兩筆進迭時空核心支援補丁：RISC-V: Add basic spacemit-x100 core support 與 RISC-V: Add basic Spacemit-A100 core support，把兩顆核心正式加入編譯器的 -mcpu/-mtune 選項。

X100 一筆將排程對映到現有的 generic_ooo 模型，改動覆蓋 riscv-cores.def 的核心與調優條目、riscv.cc 中新增的 spacemit_x100_tune_info、mcpu/mtune 文件再生成，並附新增用例測試 mcpu-spacemit-x100.c。A100 一筆的說明更詳細：該核心為順序雙發射、微架構接近 X60，因此暫複用 Spacemit X60 的成本模型；ISA 上最接近 X100，主要差異是不實現 H（虛擬化）擴充套件、向量長度 VLEN=1024（zvl1024b），並帶有 xsmtvdotii 擴充套件——該擴充套件定義一併寫入 riscv-ext-spacemit.def 與擴充套件文件，測試與核心條目同步補齊。

兩筆補丁的作者均為進迭時空的 Mark Zhuang（補丁署名日期為 6 月底），09-21 由倉庫方完成合入。對採用 K3 平臺的開發板（如 CoM260 Kit 的 8 顆 X100 加 8 顆 A100 核組合）而言，這意味著 RuyiSDK 工具鏈可以直接以 -mcpu 選擇這兩顆核心並獲得對應的擴充套件定義與排程設定，而非僅使用通用配置。考慮到兩筆均為 basic support（X100 用通用亂序模型、A100 複用 X60 成本），後續的排程細化與測試覆蓋值得在日報中繼續跟蹤。

RuyiSDK 雙週進展彙報最新一期仍為 076 期（09-15，內容為 ruyi 0.52 與 VS Code 外掛 0.1.6 釋出），077 期視窗內未釋出；openRuyi 新聞頁最新文章仍為 2026.08 版本公告，2026.09 月度版本尚無預告。

五、趨勢觀察

5.1 工具鏈開始認核心：X100/A100 進入 -mcpu/-mtune，與 RVV 實測數字形成兩條支撐線

本視窗最具體的技術進展是 riscv-gcc 16.2 分支為進迭時空兩顆核心補齊 -mcpu/-mtune 與擴充套件定義（含 VLEN=1024 與 xsmtvdotii）。結合 09-17 的 ONNX Runtime MLAS RVV 核心最佳化（K3/X100 實測提速 3.01 倍），針對 K3 平臺的兩條支撐線同時推進：效能側有可復現的運算元級數字，工具鏈側有核心級識別與排程入口。下一步值得跟蹤的是排程模型細化——X100 暫用通用亂序模型、A100 複用 X60 成本模型均屬過渡方案——以及這些核心支援後續的維護路徑。

5.2 openRuyi 的滾動更新進入核心雙線與構建規範化階段

單日 56 次提交中，核心 7.2.6 與 LTS 6.18.52 雙線升級、openruyi-linux-build 新包與 RPM 宏重構是本輪最重的兩塊，其餘為安全更新與雲原生、桌面包補齊。結合新聞頁尚無 09 月版本公告的現狀，月度版本的內容仍在快速累積；下一個觀察點是 2026.09 月度版本公告及其隨版的核心與安全基線。

5.3 K3/CoM260 平臺一週內完成驗證、示例與課程的內容閉環

從 09-18 的 K3 Pico-ITX ROS2 課程入口，到 09-20 的 CoM260 Buildroot 報告、09-21 的 CoM260 Kit 三系統批次報告與 board-docs 示例補齊，再到同期 GCC 側的核心識別支援，K3 平臺在一週內完成了「多系統驗證—示例程式碼—課程材料—工具鏈」的連續覆蓋。對以 K3 為目標的開發者和產品團隊，工具鏈、系統映象與學習材料的就緒度明顯提升。

5.4 本視窗的空白與關注點

需要如實記錄的空白：新聞側對 RuyiAI、RuyiSDK、如意社群、openRuyi 的 Google News 中英文多組查詢連續零命中；arXiv 視窗內無新收錄；ruyi 與 packages-index 靜默（無提交與釋出）；向量與運算元三個專專案標倉庫全部靜默；PyTorch fork 只有自動化同步動作，無新的功能提交。關注點：一是 ruyi 0.54 預釋出線的後續動態與 0.53 正式版打號；二是雙週進展第 077 期（上期 09-15）；三是 openRuyi 2026.09 月度版本；四是 riscv-gcc 16.2 分支的後續合入節奏。
