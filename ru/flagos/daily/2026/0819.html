Ежедневный отчёт FlagOS (2026-08-19)

2026-08-19 Kubuds

Окно мониторинга: 2026-08-18 10:19 ~ 2026-08-19 10:19 пекинское время Источники: GitHub (org: flagos-ai), агрегация Google News (китайский и английский), HN, HuggingFace, сообщество Zhiyuan и др. (подробности в приложении)

1. Прогресс открытых проектов (динамика GitHub)

Обзор окна: из 53 репозиториев внутри org в окне было 15 с пушами; поиск по коммитам дал 145 коммитов внутри окна (из них 80 в FlagGems-Experimental — рекорд для одного репозитория org в одном окне), официальных GitHub Release нет. Главная тема окна: FlagGems-Experimental KernelGen — массовый выпуск операторов для всех производителей (80 коммитов, NVIDIA/Hygon/Iluvatar/Moore Threads/T-Head/MetaX/Kunlunxin/Cambricon/Enflame — слияние по нескольким бэкендам в один день, а также добавлена поддержка Cambricon MLU C++ Runtime и массовое добавление лицензии Apache 2.0); кроме того, FlagTree добавляет бэкенд SpaceMiT (Jindie Shikong) (14-й бэкенд), sglang-plugin-FL впервые подключает Iluvatar от Iluvatar CoreX и MUSA от Moore Threads, vllm-plugin-FL вводит Enflame S60 в CI.

1.1 FlagGems-Experimental: массовый выпуск операторов KernelGen для всех производителей (80 коммитов, главная тема окна)

Источник: FlagGems-Experimental commits

8/18 во второй половине дня и вечером прошло двумя волнами:

  • Первая волна (18.08, 17:04–17:15 по пекинскому времени, около 50 коммитов):
    • Сторона NVIDIA: массовое добавление семейства специальных функций (special_i0, special_softmax, special_logsumexp, special_legendre_polynomial_p, special_shifted_chebyshev_polynomial_t, special_xlog1py, special_log1p, special_spherical_bessel_j0), а также базовых операторов slice, split_with_sizes и других.
    • Сторона производителей чипов: Hygon за один раз добавил 10 специализированных операторов (cudnn_convolution, broadcast_to, adaptive_max_pool3d_backward, diff, broadcast_tensors, amp_foreach_non_finite_check_and_unscale, tile, repeat, softplus_backward, avg_pool3d_backward, nll_loss_backward); крупный пакет от MetaX (lgamma/lgamma_, adaptive_max_pool3d_backward, special_chebyshev_polynomial_u, alpha_dropout, linalg_cholesky, log_normal_, erfinv/erfinv_, gcd_, special_gammaln и другие); Iluvatar (addmm_, nonzero_numpy с двухпроходным гибридным kernel); MThreads (linalg_cholesky); thead (lcm/lcm_); Kunlunxin (digamma, kernel минимума arctan на полиномах, bernoulli); обновление ENFLAME 20260709.
    • Инженерное управление: добавление заголовков копирайта Apache 2.0 во все исходники (#4873), массовое исправление проблем CI с тайм-аутами/ошибками/OOM/точностью (#4829), конфигурация FlagTune topk lens, обновление op-monitor.
  • Вторая волна (18.08, 18:21–22:31 по пекинскому времени, около 30 коммитов): продолжение режима «выделенных пакетов для чипов» из основного репозитория утром 18.08 — последовательно влиты [KernelGen][Hygon] (#5557), [KernelGen][Iluvatar] (#5558), [KernelGen][MThreads] с 20 операторами (#5556), [KernelGen][T-Head] (#5560), [KernelGen][MetaX] (#5559); поддержка операторов Cambricon MLU C++ Runtime (#5535); 13 новых операторов NVIDIA (compute_linear_combination, _convolution_mode, _add_relu, blackman_window, bilinear, value_selecting_reduction_backward, addmv_, resize_output, as_strided_scatter, cholesky_solve_helper, unflatten, _scaled_dot_product_efficient_attention, acos); регистрация fused_rms_norm_backward (#5074); оптимизация обобщённого kernel index_copy/index_copy в KMCompiler (#5496), log_sigmoid_backward (#5012).

Толкование: конвейер операторов KernelGen вступил в новую фазу «параллельного массового выпуска для множества производителей» — в одном окне коммиты появились у всех 9 бэкендов (NVIDIA, Hygon, Iluvatar, MThreads, T-Head, MetaX, Kunlunxin, ENFLAME, MLU), причём пакеты производителей (последовательные номера #5556–#5560) показывают, что все производители чипов уже подают сгенерированные артефакты по единому процессу. Поддержка MLU на уровне C++ Runtime и добавление лицензии Apache 2.0 свидетельствуют о том, что проект, расширяя покрытие операторов, одновременно продвигает глубокую адаптацию среды исполнения и управление соответствием требованиям открытого исходного кода.

1.2 Основной репозиторий FlagGems: массовое вливание операторов KernelGen NVIDIA сегодня утром + исправления CI для множества чипов (14 коммитов)

Источники: FlagGems commits

  • 19.08, 09:42–09:49, пекинское время, KernelGen NVIDIA: плотное слияние 9 операторов: binary_cross_entropy (#4091), expand_copy (#4324), cumsum_ (#4365), frexp (#4433), linalg_svd (#4817), upsample_bilinear2d (#5167), _scaled_dot_product_cudnn_attention (#5182), cummin_helper (#5538, включая реализацию + тесты + бенчмарки).
  • 18.08: [KMCompiler][Nvidia][Ascend] linalg_lu для двух бэкендов (#5518); [metax] исправление регистрации операторов + обновление конфигураций heuristics/tune (#5576); Try fix Iluvatar CI job (#5441); исправление ключа autotune upsample_linear1d разблокирует metax CI (#5591); исправление sum для пустого тензора (#5567); исправление ошибки импорта в CI (#5573).

Разбор: основной репозиторий и экспериментальная площадка расширяются синхронно — сначала пакетное слияние в экспериментальной площадке (Experimental), затем перевод в основной репозиторий; массовые исправления CI для Iluvatar/metax показывают, что матрица CI для множества чипов реально работает и непрерывно отлаживается.

2. Новости и экосистема

2.1 Общая оценка новостного блока

Google News по ключевым словам компонентов FlagGems/FlagScale/FlagTree/FlagPerf/FlagCX/KernelGen не дал ни одного прямого попадания в окне; запрос к HN выявил лишь 1 ложное совпадение（«Clinch – Warp fork», не связано с FlagOS, исключено). Запрос «BAAI открытый исходный код» по-прежнему в основном даёт букмекерский/SEO-шум и обобщённые статьи агрегатора сообщества BAAI по AI（исключено целым пакетом). На уровне компонентов новости спокойны, эффективные экосистемные записи сосредоточены на деловой активности организаций-участников, подробности в 2.3 и главе 3.

Оценка тренда: характерная черта чипового ландшафта в этом окне — «полномасштабное вовлечение всех производителей в производственную линию KernelGen + расширение бэкенд-экосистемы вовне». С одной стороны, 9 бэкендов выпускаются одновременно в одном окне, и на стороне производителей произошёл переход от «адаптации под них» к «самостоятельной отправке по единому процессу» (что подтверждается последовательными партиями от производителей #5556-#5560); с другой стороны, FlagTree пополнился новым участником RISC-V — SpacemiT, линейка инференс-плагинов (sglang/vllm) начала охватывать несколько чипов, а Ascend демонстрирует активность сразу по четырём направлениям — Torch-FL/FlagDNN/FlagGems/build-infra — «единый программный стек» FlagOS проникает во всё более широкий спектр чипов и фреймворков.

4. Итоги

  1. FlagGems-Experimental — 80 коммитов в одном окне, массовый выпуск KernelGen у всех производителей (главная новость окна): 9 бэкендов влиты в один день или на следующий, включая эксклюзивные партии от производителей (#5556-#5560), поддержку Cambricon MLU C++ Runtime, семейство специальных функций NVIDIA и 13 новых операторов, а также полное дополнительное проставление лицензии Apache 2.0 — производственная линия операторов вступила в стадию «параллельной работы множества производителей и глубокой адаптации».
  2. Матрица бэкендов FlagTree расширилась до 14 участников: бэкенд SpacemiT официально выведен в upstream по спецификации с добавлением CI/CD; лагерь RISC-V после Pingtouge Zhenwu PPU получил ещё одного участника; синхронно обновлён бэкенд SUNRISE от Xiwang Xinke.
  3. Ускорение мультичиповости инференс/тренинг-плагинов: sglang-plugin-FL впервые подключил бэкенд Iluvatar от Iluvatar CoreX и завершил e2e для MUSA от Moore Threads; vllm-plugin-FL Enflame S60 от Enflame вошёл в CI; Torch-FL получил новый профилировщик MSPTI для Ascend и универсальный autocast PrivateUse1.
  4. Обновление механизмов build-infra: унифицирована трёхсегментная линия vllm wheel/plugin/app-image (#431); после исправления первопричины index op у Cambricon чёрный список vllm-repack переведён в переходное состояние; зафиксирован E2E с двумя компиляторами для Ascend hw26.
  5. Активность членских организаций на коммерческом фронте: Moore Threads планирует листинг в Гонконге, серия Haiguang Tianxi масштабно выходит в публичные облака, анализ выхода Iluvatar CoreX из убытков, разблокировка опционов Cambricon — адаптация программного стека и динамика рынка капитала продвигаются синхронно.
  6. Новостной фон спокоен: нулевые попадания по ключевым словам компонентов, нет значимых результатов на HN, официальных релизов на GitHub нет; тег FlagTensor v0.2.0-rc2.post1 и ветка Megatron-LM-FL 0.2.0-rc2 указывают на то, что новый раунд релизов, возможно, уже близок.

Пояснение об ограничениях: количество коммитов и время вливания FlagGems-Experimental взяты из commit search (поисковый индекс может немного отставать от фактического вливания, время отдельных коммитов определяется по repos API pushed_at); вывод «poor perf» для бэкенда FlagDNN Ascend взят из комментария к коммиту, независимых бенчмарк-данных не обнаружено; по ссылкам-редиректам gnews не удалось получить основной текст, суждения по новостной части опираются на заголовки и перекрёстное подтверждение из нескольких источников; SUNRISE (Xiwang Xinke) и SpacemiT — это обобщение новых участников матрицы бэкендов FlagTree, и оба ещё не фигурируют в официальном списке членских организаций org.
