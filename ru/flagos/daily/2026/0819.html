四、总结

  1. FlagGems-Experimental 单窗口 80 条提交，KernelGen 全厂商批量出货（本窗口头条）：9 个后端同日/隔日合入，含厂商专属批次（#5556-#5560）、寒武纪 MLU C++ Runtime 支持、NVIDIA 特殊函数族与 13 个新算子，并完成 Apache 2.0 许可全量补注——算子产线进入”多厂商并行、深度适配”阶段。
  2. FlagTree 后端矩阵扩至 14 家：SpaceMiT（进迭时空）后端按规范正式上游化并加 CI/CD，RISC-V 阵营继平头哥真武 PPU 后再添成员；曦望芯科 SUNRISE 后端同步更新。
  3. 推理/训练插件多芯片化加速：sglang-plugin-FL 首次接入天数智芯 Iluvatar 后端并完成摩尔线程 MUSA e2e；vllm-plugin-FL 燧原 Enflame S60 进 CI；Torch-FL 新增昇腾 MSPTI profiler 与 PrivateUse1 通用 autocast。
  4. build-infra 机制升级：vllm wheel/plugin/app-image 三段流水线统一整合（#431）；寒武纪 index op 根因修复后 vllm-repack 黑名单转过渡态；昇腾 hw26 双编译器 E2E 记录。
  5. 成员单位商业面活跃：摩尔线程筹划港股上市、海光天曦系列公有云规模化上线、天数智芯扭亏分析、寒武纪股权激励解禁——软件栈适配与资本市场动态同步推进。
  6. 新闻侧平静：组件关键词零命中、HN 无有效结果，无正式 GitHub Release；FlagTensor v0.2.0-rc2.post1 标签与 Megatron-LM-FL 0.2.0-rc2 分支显示新一轮版本发布或已临近。
