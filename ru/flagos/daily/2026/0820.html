1. Прогресс open-source проектов (динамика GitHub)

Обзор окна: из 53 репозиториев в org 14 имели пуши в окне; поиск по коммитам выявил 65 коммитов в окне (build-infra — 24, FlagBLAS — 19, лидируют), официальных GitHub Release нет. Главная тема окна: build-infra замкнул сквозной инференс-конвейер бэкенда Sunrise Semiconductor SUNRISE — производственная линия FlagTree sunrise wheel стала официальной и завершена сквозная валидация двух версий vllm (0.24.0/0.20.2) с исправлением онлайн decode hang; также vllm-plugin-FL впервые поддерживает бэкенд Kunlunxin, Torch-FL дополнил функциональность трёх чипов в один день, FlagScale добавил CI для Ascend/MetaX.

1.1 build-infra: сквозной инференс-конвейер Sunrise Semiconductor SUNRISE запущен (главная тема окна, 12 коммитов)

Источник: build-infra commits

  • Формализация производственной линии wheel (19.08 15:26 #442): добавлен механизм сборки packaging/flagtree/sunrise — база ubuntu 22.04 old-glibc (аналогично режиму metax builder), предустановленные зависимости sunrise (LLVM 22 / sunriseTritonPlugin_v0.6.0.4 / triton toolkits), сборка FlagTree wheel из исходников с FLAGTREE_BACKEND=sunrise и версионным гейтингом; дополнительно добавлена цель CI. В тот же день в #441 завершена сквозная проверка vllm-sunrise 0.24.0 на TANGRT 1.2.0 (включая DOCKER_RUN_FLAGS сборки ptpu).
  • Серия отладки сборки (19.08 17:16-20:25 #445-#450): сборка с заменой gcc на clang/lld, проверка инструментария ld.lld, сборка cp310 wheel с системным python3.10, переключение pip на зеркало Alibaba Cloud (runner не может напрямую подключиться к pypi.org), восстановление $ORIGIN RUNPATH с добавлением алиаса tang.
  • Исправление онлайн-проблем и повторная проверка двух версий (20.08 07:39-09:01 #451/#459/#461): пересборка sunrise FlagTree wheel для исправления decode hang (записи в vllm 0.20.2 §2.9 и 0.24.0 §11.5); затем завершены сквозная проверка sunrise 0.24.0 vllm-repack (#459) и повторная проверка 0.20.2(F) (#461).
  • Другие коммиты в том же репозитории: метки изменений использования metax flagtree для обучения E2E и merged-wheel (#435), фиксация TORCHINDUCTOR_COMPILE_THREADS=1 в окружении приложения megatron-rl (#443), workflow сборки NVIDIA flash-attn из исходников (#454), записи о проверке NVIDIA cuda13.3 в четырёх сценариях с двумя компиляторами (#455), унификация префикса образов приложений на flagos-app и стандартизация именования tag (#457/#462/#463).

Толкование: после завершения обновления зависимостей бэкенда FlagTree компанией Xiwang Xinke SUNRISE 18.08 (#999) данное окно мониторинга непосредственно вступило в фазу глубокой поставки «производственная линия wheel + E2E инференса + исправление онлайн-проблем» — от выбора базы сборки до адаптации к зеркалам и исправления зависания decode; полнота инженерной проработки сквозной цепочки является наиболее полным примером недавнего подключения отечественных бэкендов (ранее подобной глубины достигал только Pingtouge PPU). Одновременно на стороне NVIDIA синхронно совершенствуется механизм образов приложений megatron (сборка flash-attn из исходников, матрица cuda13.3 с двумя компиляторами, стандарт именования tag), а система образов для обучения/инференса движется к унификации.

1.2 vllm-plugin-FL: добавлен бэкенд Kunlunxin (#268)

Источник: PR #268 (объединён 19.08 15:16)

На основе vLLM 0.20.2 (адаптация пустой библиотеки) в vllm-plugin-FL добавлена поддержка бэкенда Kunlunxin, проверочными моделями выбраны Qwen3.6-35B-A3B и Qwen3.6-27B, тестирование охватывает высококонкурентные текстовые и графические входы (TP=4, max-model-len 16384, интеграция FLAGCX_PATH и USE_RESHAPE_AND_CACHE_FLASH). Kunlunxin 18.08 только что включил первую партию операторов в производственную линию KernelGen (digamma, arctan minimax, bernoulli), а на следующий день вышел на линию плагинов инференса — матрица отечественных бэкендов на стороне инференса расширилась ещё на одну позицию (ранее уже охвачены Enflame, Iluvatar, Moore Threads, Ascend и другие).

1.3 Torch-FL: функциональность трёх чипов дополнена в один день (6 коммитов)

Источник: Torch-FL commits

  • #140 (19.08 13:38) завершена интеграция Pingtouge Zhenwu PPU AMP — цепочка автоматического смешанного машинного представления для бэкенда PPU полностью укомплектована.
  • #136 (19.08 13:13) интеграция профайлера Moore Threads MUSA MUPTI — после профайлера Ascend MSPTI 18.08 это подключение профайлера второго чипа.
  • #135 (19.08 14:05) расширение поддержки Ascend AMP и dtype.
  • #132 (19.08 13:41) исправлена компиляция torch.compile fullgraph на flagos; #133 (14:45) полный маршрутизирующий бокс FlagGems index_select; #138 (12:51) добавлен документ руководства по интеграции FlagGems.

Интерпретация: продолжение основной линии от 18.08 «дополнение функциональности для нескольких чипов»; в текущем окне три чипа (T-Head/Moore Threads/Ascend) в один день получили поддержку AMP и profiler, покрытие слоя тренировочных плагинов продолжает углубляться.

Интерпретация: семейство операций разреженных/ленточных матриц Level-2 в FlagBLAS систематически дополнено в течение одного дня, продолжая ритм управления эталонами L2 от 18.08 (#68/#70); покрытие операторов библиотеки быстро сходится к спецификации BLAS.

Оценка тенденции: отличительная черта чиповой картины этого окна — «глубокая отладка цепочки инференса + непрерывное расширение матрицы бэкендов». С одной стороны, Xiwang Xinke SUNRISE завершила наиболее полную цепочку подключения отечественного бэкенда к FlagOS (производственная линия wheel → E2E → исправление проблем), KunlunXin следом за ней вышел на линию плагинов инференса, охват бэкендов на стороне инференса достиг более 6 компаний; с другой стороны, на стороне обучения (FlagScale/FlagBLAS/Torch-FL) параллельно продвигаются три направления: «матрица CI для множества чипов + пополнение семейств операторов + возможности AMP/profiler». В коммерческом плане основные точки внимания — контракт Horizon Journey 6B на десятки миллионов комплектов, два подряд экосистемных партнёрства Hygon и прогресс Moore Threads на гонконгской бирже — адаптация программного стека и темпы коммерческого внедрения синхронизируются.

4. Итоги

  1. SUNRISE компании Xiwang Xinke: сквозной инференс-конвейер запущен (главная новость окна мониторинга): в build-infra 12 коммитов завершили производственную линию sunrise FlagTree wheel (#442, база ubuntu 22.04 old-glibc + LLVM 22 + sunriseTritonPlugin v0.6.0.4), vllm-sunrise 0.24.0 E2E (TANGRT 1.2.0, #441), исправление зависания decode и двойная проверка версий 0.20.2/0.24.0 (#451/#459/#461) — наиболее полный инженерный пример подключения отечественного бэкенда к FlagOS.
  2. Kunlunxin вышел на линию инференс-плагинов: vllm-plugin-FL #268 на базе vLLM 0.20.2 поддерживает бэкенд Kunlunxin, высоконагруженная проверка изображений и текста Qwen3.6-35B-A3B/27B пройдена; с момента включения его операторов KernelGen прошёл всего один день.
  3. Три направления на стороне обучения идут параллельно: Torch-FL в один день дополнил поддержку трёх чипов (завершён PPU AMP Pingtouge, профилировщик MUSA MUPTI Moore Threads, расширение AMP Ascend); FlagScale добавил CI сборки и тестирования Ascend/Muxi; FlagBLAS за один день дополнил семейство операторов Level-2 разреженных/ленточных (SYMV/SPMV/GER/SYR/HER/SPR/HPR/SYR2/HER2/GBMV/HBMV/SBMV).
  4. Совершенствование образов и инженерных механизмов: build-infra унифицировал префикс app image до flagos-app и стандартизировал именование tag (#457/#462/#463); добавлена сборка NVIDIA flash-attn из исходников (#454) и записи проверки cuda13.3 для четырёх сценариев с двумя компиляторами (#455); TransformerEngine-FL открыл backend ops, необходимые для TP comm overlap (#95).
  5. Коммерческая активность членских организаций: MPC4 от Bosch на базе Journey 6B получил заказ масштаба десятков миллионов комплектов (Horizon, совокупный объём заказов Journey 6B превысил 20 млн комплектов); Hygon достиг двух экосистемных соглашений с Tianji Data и компанией Geer Software; Moore Threads штурмует гонконгскую биржу; вознаграждение Cambricon после разблокировки поступило на счёт.
  6. Новостной фон спокойный: по ключевым словам компонентов ноль совпадений, на HN нет значимых результатов, официальных GitHub Release нет; серии FlagTensor 0.2.x и Megatron-LM-FL 0.2.0 всё ещё в подготовке, сигналов о релизах версий не появилось.

Пояснение об ограничениях: количество коммитов и время включения взяты из commit search (индекс поиска может немного отставать от фактического включения, для отдельных коммитов время определяется по repos API pushed_at); серия коммитов FlagBLAS в основном представляет собой объединённое включение пакетов от контрибьюторов AriesMTR; по ссылкам-редиректам gnews невозможно получить основной текст, поэтому суждения по новостной части опираются на заголовки и перекрёстное подтверждение из нескольких источников; Xiwang Xinke (SUNRISE) и Kunlunxin не входят в официальный список членских организаций org, поэтому они обобщены по факту экосистемы бэкендов; пункт «Tianji Intelligent Computing» — это углублённый репортаж от 8/19 о запуске 7/24, а не новый запуск внутри окна мониторинга.
