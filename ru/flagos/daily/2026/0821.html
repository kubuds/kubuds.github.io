1. Открытые проекты (динамика GitHub)

Обзор окна: из 52 репозиториев организации 14 имели пуши в окне; поиск по коммитам выявил 55 коммитов в окне (FlagGems — 27, FlagBLAS — 12, лидируют), официальных GitHub Release нет. Два главных события окна: высокоплотное расширение матрицы операторов FlagGems (массовые операторы KernelGen + глубокая оптимизация SQMMA для Moore Threads) и завершение фиксации двухкомпиляторной E2E-проверки Hygon hygon vllm 0.24.0 в build-infra; также объединение бэкендов CUDA/DCU в FlagSparse, поддержка отладки Iluvatar в FlagPrism, дополнение семейства треугольных решателей в FlagBLAS.

1.1 FlagGems: 27 коммитов лидируют, массовые операторы KernelGen + оптимизация матричного умножения SQMMA для Moore Threads (главное событие окна)

Источник: FlagGems commits

  • Массовое добавление операторов KernelGen Nvidia (8/20 10:33-10:53, 12 операторов): special_expit (#4263), linalg_householder_product (#5179), adaptive_max_pool2d (#5077), rshift (#5075), amp_update_scale (#5503), _list_to_tensor (#5273), fake_quantize_per_channel_affine_cachemask (#5455), _convolution_double_backward (#5505), view_as_complex (zero-copy view, #5373), _batch_norm_impl_index_backward (#5504), adaptive_avg_pool1d (#5550), float_power (#5517).
  • Расширение и исправления KMCompiler для множества чипов (16:23-17:50): linalg_matrix_norm (Nvidia #5595, Iluvatar/Hygon #5648), операторы dist (Nvidia/MetaX #5406), masked_scatter_backend (#4954), index_fill/index_fill_ (Nvidia/Ascend #5643), исправление импорта tle для Ascend (#5616) и исправления багов (#5641/#5654), исправление багов Iluvatar (#5644), исключение fp64 benchmark (iluvatar/ascend, #5658).
  • MTHREADS (Moore Threads), глубокая оптимизация матричного умножения: addmm_out оптимизирован через override SQMMA/FMA (#5604, 18:19), baddbmm оптимизирован через SQMMA (#5666, 19:42).
  • Прочее: обновление версии flagtree для бэкенда Enflame enflame 1.10.6 (#5649, 14:04), откат реализации erfc для Ascend (#5380, 14:20), исправление тестов операторов upsample/quant для T-Head PPU (#5655, 15:36).

Комментарий: В соответствии с сообщением от 8/18 «KernelGen — массовые поставки для всех производителей», в данном окне мониторинга производственная линия KernelGen на стороне Nvidia пополнилась 12 операторами за один день, на стороне KMCompiler выполнены кросс-чиповые (Nvidia/Ascend/Hygon/Iluvatar/Moore Threads) исправления и расширения, покрытие операторов продолжает сходиться к высокоуровневым и квантизационным/обратным API PyTorch; на стороне Moore Threads выполнена оптимизация SQMMA на уровне аппаратных инструкций для addmm_out/baddbmm, что знаменует переход библиотеки операторов от «покрытия» к «глубокой оптимизации под отдельный чип».

1.2 build-infra: запись E2E-верификации двух компиляторов для hygon vllm 0.24.0 (#466), app image отложен до FlagTree #1020

Источники: PR #466, PR #464, PR #465

  • #466 (слит 8/20 20:19): зафиксирована верификация двух компиляторов для hygon (Hygon, DTK 26.04) vllm 0.24.0 на узле hygon25 — путь F (flagtree 0.6.1+hcu3.6, временно обойдён через значение по умолчанию cluster_dims внутри контейнера, исправление в upstream — FlagTree PR #1020) и путь T (vendor triton 3.5.1) оба достигли Application startup complete и согласованного вывода; hygon app image отложен: компилятор по умолчанию пути F заблокирован FlagTree #1020, а packaging/flagtree/hygon wheel требует пересборки вместе с новым релизом flagtree; юниты T/F для hygon 0.24.0 в матрице верификации vllm стали зелёными.
  • #464 (8/20 11:00): запись сборки app image megatron-training + верификация двух компиляторов на h20.
  • #465 (8/20 12:21): документ handoff app-image sunrise 0.20.2.
  • FlagTree #1020 (создан 8/20 17:23, ожидает слияния): default cluster_dims=(1,1,1) for backends that omit it — исправление AttributeError при прогреве KV-cache vllm 0.24.0 на бэкендах без поддержки cluster-launch, таких как hcu/mthreads (воспроизведено во время выполнения на hygon DTK 26.04).

Комментарий: Вслед за полной цепочкой поставки SUNRISE от Xiwang Xinke, Hygon становится следующим бэкендом вывода, глубоко верифицируемым build-infra. Исправление cluster_dims, от которого зависит путь F Hygon (компилятор FlagTree), уже подано как #1020; после слияния будет пересобран hygon flagtree wheel и обновлён app image — ритм «сначала запись верификации, затем механизм релиза» совпадает с путём SUNRISE.

2. Новостные публикации и экосистема

2.1 Общая оценка новостной стороны

Google News по ключевым словам компонентов FlagOS/FlagGems/FlagScale/FlagTree/FlagPerf/FlagCX/KernelGen в пределах окна не дал ни одного прямого попадания (совпадает с 20.08); HN дал лишь 3 нерелевантных попадания (обсуждение HN ban, альтернатива Stripe, редакторы macOS — все исключены). Запрос “Zhiyuan Research Institute открытый исходный код” в основном дал общие статьи об AI (обзоры Kimi K3 и др., не имеющие содержательной связи с FlagOS); запросы по Enflame/Tianshu Zhixin/Qingwei дали исключительно шумовые попадания (отчёт Hongxin Electronics, страница котировок Biren Technology, отгрузка оборудования Huahai Qingke, развлекательные и бытовые материалы — весь пакет исключён). Новости на уровне компонентов продолжают оставаться спокойными, содержательные пункты сосредоточены в коммерческой активности членских организаций и экосистемном сотрудничестве (подробнее см. 2.2 и главу 3).

На стороне операторов 27 коммитов в одном репозитории FlagGems (массовые операторы производственной линии KernelGen, многопчиповая матрица KMCompiler, глубокая оптимизация SQMMA от Moore Threads) свидетельствуют о том, что унифицированная библиотека операторов вступила в параллельную фазу «широкого покрытия + точной настройки под отдельные чипы»; на стороне инференса build-infra после SUNRISE запустил E2E-верификацию двух компиляторов hygon 0.24.0 от Hygon (двойной путь F/T), записи верификации и механизм релиза (app image, пересборка wheel) продвигаются синхронно, Hygon становится следующим глубоко интегрируемым инференс-бэкендом. С момента FlagOS 2.1 (6/24) прошло более 8 недель, в текущем окне по-прежнему нет сигналов о формальном релизе, однако пересборка hygon flagtree wheel и обновление app image будут ближайшими точками наблюдения.

Оценка тенденций: ключевое слово ландшафта чипов в этом окне — “параллельное расширение охвата операторов и углубление инференса”. На стороне инференса Hygon, сменив Xiwang Xinke, стал объектом глубокой верификации build-infra (узлы hygon25, DTK 26.04, двойные компиляторы F/T, решение по app image); исправление FlagTree #1020 — ключевая точка блокировки формализации инференс-конвейера Hygon; на стороне операторов Moore Threads (матричное умножение SQMMA), Iluvatar CoreX (отладка FlagPrism + включение FlagTensor + исправления FlagGems), MetaX (dist-операторы + TLE) имеют существенный прогресс, участие членских организаций переходит от “подключения” к “оптимизации”. В коммерческом плане рост выручки Moore Threads за H1, значительный рост Hygon за H1 и отраслевое внедрение, удвоение чистой прибыли Cambricon за полугодие составляют ключевые моменты; преодоление ценой акций Cambricon тысячи юаней и связанные колебания потоков капитала относятся к рутинным рыночным явлениям и приводятся лишь для справки.

4. Итоги

  1. FlagGems лидирует с 27 коммитами в одном репозитории (один из главных пунктов окна): KernelGen Nvidia за один день пакетно добавил 12 операторов, KMCompiler выполнил кросс-чиповые (Ascend/Hygon/Iluvatar CoreX/MetaX) перекрёстные исправления и расширения, Moore Threads провёл глубокую оптимизацию матричного умножения addmm_out/baddbmm SQMMA — библиотека операторов вступила в фазу параллельного “широкого охвата + тонкой настройки под отдельные чипы”.
  2. Углубление верификации инференс-конвейера Hygon hygon (второй главный пункт окна): build-infra #466 фиксирует E2E с двойными компиляторами vllm 0.24.0 (hygon25, DTK 26.04; путь F: flagtree 0.6.1+hcu3.6, путь T: vendor triton 3.5.1 — оба достигли завершения запуска); app image отложен до включения FlagTree #1020 (исправление значения по умолчанию cluster_dims, предложено 20/08) и пересборки hygon wheel.
  3. Расширение инструментальной цепочки разреженности и отладки: FlagSparse завершил объединение кода бэкендов CUDA/DCU; FlagPrism Debugger добавил поддержку Tianshu/CoreX от Iluvatar CoreX; FlagTensor включил ветку iluvatar — Iluvatar CoreX в этом окне продвигается по нескольким направлениям.
  4. Завершение семейства решателей треугольных систем FlagBLAS: TPSV/TRSV/TBSV последовательно включены (серия PR #82-#87 от AriesMTR), покрытие Level-2 продвинулось ещё на ступень; CI Ascend включён, матрица кросс-чипового CI расширена до библиотеки BLAS.
  5. Активность членских организаций в коммерческой сфере: выручка Moore Threads за H1 — 1,736 млрд юаней, +147%; выручка Hygon за H1 выросла более чем на 60% и охватила производство кино и ТВ/GIS/экосистему токен-экономики Хэфэя; чистая прибыль Cambricon за H1 — 2,311 млрд юаней, +122%; дистрибьюторская система MetaX “Отраслевой ковчег” расширяется.
  6. Новостной фон спокойный: нулевые совпадения по компонентным ключевым словам, официальных GitHub Release нет; пересборка flagtree wheel для Hygon и обновление app image — точки наблюдения за ближайшими сигналами о релизах.

Пояснение ограничений: количество коммитов и время включения получены из commit search (поисковый индекс может немного отставать от фактического включения, время отдельных коммитов определяется по repos API pushed_at); серия коммитов FlagBLAS в основном представляет собой пакетное объединение вкладов участников AriesMTR; переходные ссылки gnews не позволяют извлечь основной текст, суждения по новостной стороне опираются на заголовки и перекрёстную проверку по нескольким источникам; данные финансовых отчётов Hygon/Moore Threads/Cambricon за H1 основаны на сообщениях СМИ и не сверены построчно с оригиналами официальных объявлений компаний.
