Еженедельный отчёт RuyiAI (2026-10-12 ~ 2026-10-16)

2026-10-16 Kubuds

Отчётный период: с 12 октября 2026 г. (понедельник) по 16 октября 2026 г. (пятница), всего 5 рабочих дней

Источники материалов: 5 выпусков ежедневного отчёта о динамике RuyiAI (с 2026-10-12 по 2026-10-16, окно каждого выпуска — с 04:30 предыдущего дня до 04:30 текущего дня); дополнительно включены 168-часовая проверка репозиториев трёх организаций RuyiAI-Stack, ruyisdk, buddy-compiler, дополнительная проверка ключевых репозиториев openRuyi-Project, а также двойная перепроверка по сообществу разработчиков RuyiSDK и странице новостей openRuyi (охват до утра 10-17)

Пояснение к составлению: главной технической линией недели стали линейка платформы прошивок K3 проекта openRuyi (три выпуска за три дня подряд, с 10-13 по 10-15) и реализация двух бэкендов GCC + LLVM для инструментальной цепочки расширения матриц Ztt. Помимо материалов ежедневных отчётов, в еженедельный отчёт добавлены две новые находки проверки: во-первых, утром 10-15 в ветке ztt-dev проекта riscv-gcc одним пакетом прошли 20 коммитов Ztt (в ежедневный отчёт того дня не вошли); во-вторых, оживление tilelang-riscv 10-16 и выпуск Buddy MLIR 0.1.0 (произошли после окна ежедневного отчёта).

1. Главные новости недели

  • openRuyi открыл линейку платформы прошивок K3, три выпуска прошивок за три дня подряд с 10-13 по 10-15: 10-13 созданы edk2-ruyi (35 коммитов единым пакетом — первая публикация кода платформы EDK2 для SpacemiT K3 Pico ITX) и ruyifirmware (5 коммитов — построение цепочки упаковки и выпуска), в тот же день в 18:46 выпущена первая версия «Ruyi Firmware 20261013»; 10-14 во второй версии добавлен выбор режима CPU внутри UEFI (только X100 / смешанный X100+A100 / только A100, включая переключатели расширений RVV и H) с постоянным сохранением; 10-15 в третью версию добавлены страница System Information только для чтения, эмуляция UEFI-драйверов x64 и ARM64 (по умолчанию отключена, включается через Platform Settings) и экспериментальный пилот AMD ARM64 GOP 1.68. Источники: edk2-ruyi, Ruyi Firmware 20261013, 20261014, 20261015

  • Инструментальная цепочка расширения матриц Ztt дополнена стороной LLVM, сформированы два бэкенда GCC + LLVM (10-12): ruyisdk/llvm-project утром 10-12 создал ветку ztt-dev и выполнил первую публикацию полного стека из 26 патчей LLVM / Clang (автор LukeZhuang, охватывают базовую поддержку расширения Ztt, профилирование на уровне функций, CSR и группы матричных регистров, ассемблирование и дизассемблирование инструкций, типы IR и intrinsic, матричные типы регистров Clang, разворачивание псевдоинструкций после распределения регистров, обработку переполнения регистров M и ACC; последний коммит приводит тесты в соответствие с системой диагностики AME); на стороне GCC ветка ztt-dev проекта riscv-gcc после создания 09-30 уже последовательно приняла 36 коммитов 10-08, 51 коммит 10-11 и 20 коммитов 10-15 (последний пакет обнаружен при проверке на этой неделе). В сочетании с PR V0.6 документации intrinsic Ztt проекта attached-matrix-extension цепочка «спецификация — документация — две инструментальные цепочки» синхронно активна. Источники: llvm-project ztt-dev, головной aeb52e1a, riscv-gcc ztt-dev

  • Официальный релиз Buddy MLIR 0.1.0, кросс-компиляция для RISC-V и CI развёрнуты повсеместно (10-16): в репозитории buddy-compiler/buddy-mlir на этой неделе 16 коммитов и 4 релиза, среди которых 0.1.0 выпущен в ночь на 10-16 по пекинскому времени (тег release/v0.1.0), после чего ночная ветка перешла на серию 0.1.1.dev (dev20261016, dev20261017). По линии RISC-V работа шла интенсивно: добавлена кросс-компиляция для плат RISC-V в buddy-cli (#987), исправлена цель RISC-V в Makefile (#986), упрощён процесс кросс-компиляции (#975), добавлена кросс-компиляция серверной части RISC-V для buddy-server (#989), а в сборке manylinux riscv64 установлены torch для riscv64 из индекса пакетов Ruyi и добавлен libsndfile (#990, #937, #988). Источники: buddy-mlir, BUDDY MLIR 0.1.0, PR #989

  • tilelang-riscv от RuyiAI прервал почти месячное молчание: 5 коммитов по RISC-V подключены к цепочке релизов Buddy (10-16): последний коммит в этом репозитории был 09-20, а на этой неделе подряд прошли 5 — форматирование кода, поддержка семантики времени выполнения вышестоящих операторов (lane-local состояние, ragged copy, динамическое управление потоком, исправления преобразований FP8/FP4), обновление адаптации рантайма TileOps (подмодуль поднят до 67250e81, успешно пройдены ядра paged-cache gather и varlen GQA sinks), добавлен Buddy MLIR release CI и сборка Python-расширения в Buddy CI. Это означает, что бэкенд RISC-V для TileLang начал непрерывную интеграцию на основе версионных артефактов Buddy MLIR. Источники: список коммитов tilelang-riscv, первый из 5 коммитов 32fce5ed

  • Масштабное обслуживание дистрибутива openRuyi за неделю: около 90 коммитов по модулям Go, KDE Plasma 6.7.5 в 39 пакетах, LLVM 24, mesa 26.2.4 и обратный перенос PowerVR (10-12 ~ 10-14): 10-12 в основном репозитории 40 коммитов, из которых 39 поднимают весь стек рабочего стола KDE Plasma до 6.7.5 (plasma-workspace / kwin / systemsettings / powerdevil / breeze и др.); 10-13 за один день 103 коммита — около 90 из них массовые обновления модулей экосистемы Go (серия k8s 0.37.1, gRPC 1.84, OpenTelemetry Collector 1.67, SDK облачных провайдеров и др.), также llvm-snapshot поднят до LLVM 24, audit 4.2.1 с включённой поддержкой RISC-V, целый пакет обновлений стека GnuPG; 10-14 три коммита переключились на графический стек: mesa 26.2.4 и первый раунд обратного переноса оптимизаций PowerVR. 10-16 добавлены SPEC ещё для 6 крейтов Rust, связанных с RISC-V, включая rust-riscv-0.16. Источники: список коммитов openRuyi, PR #1410, PR #1347, PR #1399

  • ruyisdk/llvm-project: влито исправление смешанной разрядности индексного доступа XTHeadVector (13.10, PR #168): исправлена обработка th.vlxe / th.vxse в сценариях несовпадения разрядности элементов данных и индексов (сохранены знаковые смещения, размер элементов памяти, passthrough маски и семантика нулевой длины), понижение intrinsic расширено на смешанную разрядность целочисленных и плавающих векторов, а для RV32 / RV64 добавлено покрытие codegen для случаев с маской, нулевой длиной, отрицательными смещениями и большими индексами. Последний содержательный коммит в ветке rebase-17.0.6 был в июне; это событие знаменует переход линейки векторного инструментария Xuantie от долгосрочного сопровождения к точечным исправлениям. Источники: PR #168, issue #136

  • Продвижение ядра по двум линиям: в openRuyi linux открыта ветка ruyi/7.3.y с первыми 31 коммитом; в linux-xuantie-kernel вендорские ключи унифицированы как XUANTIE и дополнен hwprobe (15.10 ~ 16.10): ветка ruyi/7.3.y создана 13.10, а 15.10 в неё легли первые 31 коммит (GPU-узлы K3 и домены питания дисплея, Type-C Port A / USB3 PHY / FUSB301, привязка Ethernet MAC к EEPROM, серия исправлений spacemit DP, отключение динамического переключения скорости PCIe для amdgpu на K3, UFS FASTAUTO, поддержка платы SG2044 SRD3-12 и др.); в linux-xuantie-kernel 15.10 вендорские ключи расширений T-Head целиком переименованы в форму XUANTIE (XTHEADVDOT → XUANTIE_VDOT и т. п.), а 16.10 добавлены ещё 4 коммита — Ziccamoa / Ziccif / Ziccrse / Za64rs / Zicclsm включены в cpufeature и hwprobe, в пространстве id расширений ISA выделен приватный диапазон, а id расширений выровнены с upstream. Источники: ruyi/7.3.y, linux-xuantie-kernel

  • Выпущен двухнедельный отчёт 078 с темой «RuyiSDK будет представлен на саммите RISC-V China Summit»; саммит пройдёт 18–20 октября в Шэньчжэне (13.10): выпуск 078 финализирован через конвейер редактирования из 8 коммитов (#371 ~ #378) и синхронизирован с форумом; ключевые пункты включают ожидаемый к концу месяца релиз пакетного менеджера 0.54.0 (проверка совместимости ABI, официальный пакет для macOS, адаптация инструментальных цепочек SpacemiT K1/K3 в разработке), очередной цикл шлифовки IDE, портирование по 6 векторных математических функций для glibc и newlib, доработку бэкенда ZTT в GCC и схему верификации GEMM/GEMV (снижение времени компиляции примерно на 5,05 % ~ 6,97 %), intrinsics расширения RISC-V P в LLVM, первые испытания RVV Wasm SIMD в V8 на реальном оборудовании с влитым патчем отката hwprobe, портирование JEP 483 / 515 AOT в OpenJDK, исправление атомарных операций riscv64 в Go. Программа саммита включает keynote-доклады, стендовые презентации и демонстрации на стенде D15. Источники: файл выпуска 078, форум #2891

Обзор окна: действия организации RuyiAI-Stack (18 ~ 19 репозиториев) на этой неделе сосредоточены в pytorch (четыре утра — по одному полному пересбору стека), llvm-project (после ночного перезапуска 12.10 активность приостановлена), triton-riscv (новый выпуск ночной сборки), tilelang-riscv (16.10 — оживление, пять коммитов), ruyiai-daily (непрерывные обновления выпусков с 12.10 по 16.10) и репозитории сайта (рутинные коммиты данных о контрибьюторах); harness, mxnet, caffe, FBGEMM, IntrinTrans, VecIntrinBench, cpuinfo, torq-tile, dsh-osc, pytorch-ci, SyncBots-DeepAgents в окне не получали пушей.

tilelang-riscv: пять коммитов оживления в пятницу, подключение к цепочке релизов Buddy

  • 10-16 подряд 5 коммитов RISC-V (с интервалами в несколько десятков минут, представляют собой одно групповое продвижение): сначала отдельно выполнен clang-format, чтобы последующие изменения были читаемыми; затем добавлена поддержка семантики времени выполнения upstream-операторов (lane-local состояние между фазами сериализации, безопасное ragged copy, динамический поток управления, дополнены общие IEEE и битовые операции, исправления преобразования FP8/FP4, хранение unsigned memref и настраиваемое повторное использование разделяемой памяти, а также явный отказ для неподдерживаемых кооперативных циклов while); после этого подмодуль TileOps обновлён до 67250e81 и успешно прогнаны ядра paged-cache gather и varlen GQA sinks; в конце добавлены Buddy MLIR release CI и «сборка Python-расширения в Buddy CI».
  • Значение: этот репозиторий молчал почти месяц после 09-20; групповые коммиты этой недели продвинули бэкенд TileLang RISC-V от «покрытия операторов» к «непрерывной интеграции на основе артефактов версии Buddy MLIR», что совпадает с ритмом выпуска Buddy MLIR 0.1.0. Источники: список коммитов tilelang-riscv

7. Наблюдения за трендами

  • K3 стал единственной системной главной линией недели: прошивка (три версии за три дня), ядро (первая партия из 31 коммита в ruyi/7.3.y) и образы (автоматизация kiwi-image) — все три слоя пришли в движение в одну и ту же неделю, причём прошивка прошла путь от «налаживания цепочки» до «выбираемого режима CPU + моделируемых драйверов». Точка наблюдения — смогут ли эти возможности к неделе саммита 18.10 сложиться в демонстрируемый законченный образец устройства, а также фактические данные трёх режимов CPU.
  • Расширение матрицы перешло от «продвижения одного бэкенда» к параллельной работе «два бэкенда + спецификация + проверка операторов»: тематика трёх партий GCC ztt-dev (36 → 51 → 20 коммитов) сместилась от развёртывания функциональности к корректности взаимодействия с другими расширениями (сохранение состояния при пересечении RVV / Zfa / атомарных операций), первый push ztt-dev на стороне LLVM закрывает вторую половину, документация V0.6 и руководство AME-operator подтягиваются; при этом рабочая группа upstream AME под руководством XuanTie продвигает стандартизацию — внутренние черновики репозитория и линия спецификации начинают звучать в унисон.
  • Разрыв в ритме двух линий поддержки fork продолжает расти: ветка PyTorch riscv сохраняет пересборку из 23 коммитов каждое утро и обновление 8 PR; ветка LLVM riscv после 12.10 три ночи подряд не перезапускалась. Первое говорит о высокой степени автоматизации механизма следования за upstream, второе может означать смещение фокуса работ на стороне LLVM к линии поддержки ruyisdk/llvm-project (исправление XTHeadVector — как раз результат этой линии).
  • Buddy Compiler становится одним из фактических upstream для RuyiAI: buddy-mlir за неделю выполнил выпуск 0.1.0 и починку цепочки кросс-компиляции riscv64 / CI / публикации manylinux, а обновление зависимостей triton-riscv и новый CI tilelang-riscv привязаны к версионным артефактам Buddy — цепочка «фреймворк компиляции MLIR → фронтенд операторов → ночные артефакты» на этой неделе впервые на riscv64 замкнулась в публикуемый wheel.
  • Поддержка дистрибутива вошла в двойной ритм «пакетная обработка + пакет безопасности»: за один день openRuyi обработал 90 модулей Go, 39 пакетов KDE, полный стек GnuPG, пять пакетов безопасности подряд, что говорит о том, что следование зависимостям стало инженерно отработанным; скрытое ограничение — связка стоимости полной пересборки и ритма выпуска образов, стоит понаблюдать за сроками 0.54.0 и образа 2026.10.
  • Список для наблюдения: релиз 0.54.0 в конце месяца и проверка совместимости ABI; когда ruyi/7.3.y войдёт в канал образов; ревью triton-riscv #85; два PR по LLVM FPGA (#25 / #28); PyTorch #46 / #48 (RVV) и #51 (локальный образ уже в ветке); PR документации attached-matrix-extension #1; будут ли в период саммита (18.10 ~ 20.10) выпуски версий или анонсы результатов.
