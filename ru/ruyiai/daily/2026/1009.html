Главное за сегодня: расширение матрицы идёт двумя параллельными линиями — 36 коммитов бэкенда GCC по черновику Ztt за один день, стек LLVM riscv завершил ночную пересборку

Дата: 2026-10-08 ~ 2026-10-09　Источник: список коммитов riscv-gcc ztt-dev, список коммитов llvm-project riscv, головной коммит 44b1cf2, PR #25, PR #28

Самый крупный единичный результат этого окна появился в ветке ztt-dev репозитория riscv-gcc: контрибьютор pz9115 8 октября утром (08:40–11:27) подряд отправил 36 коммитов бэкенда Ztt. Ztt — это черновой набор инструкций матричного расширения RISC-V, представляющий собой направление раскладки инструментальной цепочки GCC со стороны RuyiAI вне линий BOSC AME / A100 на стороне LLVM. Этот набор изменений охватывает от низкого до высокого уровня: упрощение построения выборки нуля и трансляции нуля (повторное использование x0 и очистка типов данных), свёртку структур (проекция / восстановление / обратные операции / извлечение конкатенацией / zip и unzip) и обработку свидетелей, сквозное сопровождение состояния Md (дескриптор матрицы) через скалярные, матричные, строчные/столбцовые и групповые классы операций, повторное использование регистров дескрипторов, добавление intrinsics для вещественных строчных/столбцовых операций, исправление псевдонима округления по умолчанию для большого ACC, кэширование входных атрибутов встроенных функций, очистку неиспользуемых рабочих областей, а также тесты и документацию семантики значений M; это самый плотный набор с момента открытия этой ветки 30 сентября.

На стороне LLVM ветка riscv проекта llvm-project (ветка по умолчанию) завершила новый цикл ночной пересборки: локальный стек патчей из 26 штук целиком воспроизведён с временем новых коммиттеров (поздно вечером 8 октября), отправка завершена 9 октября в 00:51 — головной коммит 44b1cf2 «[RISCV] Add A100 HP/SP and pack/unpack lowering with calibrated scheduling» (#31; совпадает с головным патчем предыдущего цикла пересборки, является рутинным воспроизведением); интеграционный коммит внутри стека остаётся «[SyncBots] Integrate LLVM at b3b5e33», точка привязки воспроизведения продвинута до снапшота upstream за 8 октября (базовая линия upstream включает коммиты того дня, такие как [RISCV] исправление векторного ISD #228215). После завершения пересборки время обновления двух PR бэкенда FPGA (#25 «BOSCAME FPGA бэкенд», #28 «xboscame FPGA») сразу же обновилось до 9 октября 00:51, ожидается продвижение рецензирования на новой базовой линии. Кроме того: внутри fork 8 октября в 18:38 создана ветка buckyball (указывает на старый головной коммит до пересборки), одноимённая по направлению с расширением производителя Buckyball внутри стека (#20 / #23).

Ключевые выводы: матричное расширение параллельно продвигается в одном окне по двум инструментальным цепочкам — LLVM (BOSC AME / A100) и GCC (Ztt); пересборочная синхронизация, ожидающие рецензирования PR на стороне FPGA и раскладка новой ветки формируют область наблюдения следующего этапа.

5. Наблюдения за тенденциями

5.1 Двухстековый ритм расширения матрицы и точки наблюдения

В данном окне два стека инструментальных цепочек продемонстрировали содержательное продвижение в один день: на стороне GCC бэкенд черновика Ztt — 36 коммитов за день (масштаб, максимальный для этой линии), на стороне LLVM стек патчей при рутинном воспроизведении удерживает передний край (патчи A100 HP/SP на вершине). Точки наблюдения: синхронизация линии Ztt на стороне riscv-binutils и путь к upstream (в binutils ветка ztt-dev в данном окне не имеет коммитов); прогресс ревью двух PR бэкенда FPGA (#25, #28) на новой базовой линии.

5.2 Ночные пересборки, отправка базовых линий и взаимодействие с PR

Механизмы «ночной пересборки / ежедневной отправки базовой линии» для двух форков llvm-project и pytorch в данном окне работали в заданном ритме: после завершения пересборки записи базовых линий открытых PR обновлялись соответственно (llvm #25, #28; pytorch — 8 записей). Этот механизм стал штатной формой эксплуатации форков на стороне RuyiAI — наблюдать за эффективностью продвижения точек синхронизации с upstream (линия SyncBots b3b5e33), а также за согласованием ритма пересборок и очерёдности ревью PR.

5.3 Интеллектуальная инфраструктура и вклад сообщества в операторы

harness в отдельном репозитории принимает бэкенд и рабочий стол агента Triton-RISCV; triton-riscv получил PR от сообщества по оптимизации softmax / matmul (#85). Обе линии указывают на одно: нарратив «агентизации / автоматизации» инструментальной цепочки RuyiAI и участие сообщества растут параллельно — наблюдать за последующим ритмом итераций рабочего стола агента и вклада в операторы.

5.4 Расширение экосистемы openRuyi и ритм месячных версий

openRuyi — 61 коммит за одно окно (экосистема Go — 31, пакет обновления Python 3.14, стек данных AI — 17, исправления ceph / moby / dotnet и др.), что представляет собой продолжение пакетного расширения после релиза 2026.09; две экосистемные линии — облачно-нативная и AI / data science — утолщаются синхронно. Точки наблюдения: при открытии цикла следующей месячной версии войдут ли данный пакет Python 3.14 и зависимости Go в базовую линию сборки версии.
