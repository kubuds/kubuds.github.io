1.1 Выпущен Linux 7.3-rc1: код контроллера прерываний RISC-V переработан и включён в общую структуру ACPI IRQ

Дата: 2026-08-31　Источник: 9to5Linux, LKML (письмо Линуса о выпуске), Phoronix: в Linux 7.3 добавлены несколько новых расширений RISC-V, Phoronix: принята очистка KVM Chainsaw

Linus Torvalds 30 августа (31 августа по пекинскому времени, раннее утро) выпустил первый кандидатный релиз Linux 7.3 — 7.3-rc1, двухнедельное окно слияния официально закрыто. Линус отметил, что по количеству коммитов этот rc1 «находится среди лидеров», главным драйвером стали массовые обновления заголовочных файлов регистров AMD DCN6. Изменения, напрямую связанные с RISC-V: рефакторинг кода irqchip/ACPI выделил общую часть кода управления контроллером прерываний RISC-V и включил её в общий код ACPI IRQ для поддержки порядка ACPI-обнаружения GICv5 IWB на стороне ARM (этот рефакторинг также прокладывает путь для последующей поддержки прерываний ACPI в RISC-V); в течение окна слияния уже была принята поддержка ряда более новых расширений RISC-V (репортаж Phoronix от 08-24). На стороне KVM в этом цикле преобладали исправления и очистка: «KVM Chainsaw» (разделение гигантской структуры данных kvm_mmu) принят и включён, ENCRYPT/DECRYPT для AMD SEV/SEV-ES переведены на выделение целыми страницами для исправления повреждения данных, вызванного назначением страниц прошивки PSP, усилена защита SEV-SNP population ioctl. Согласно ритму rc каждое воскресенье, официальный релиз Linux 7.3 ожидается 18 или 25 октября. Этот пункт — важнейшее событие на стороне ядра в окне мониторинга.

1.2 Официально выпущен openKylin 3.0: единая кодовая база для четырёх архитектур, наиболее широкая адаптация RISC-V, поддержка RVA23 и оптимизаций RVV

Дата: 2026-08-28/29　Источник: CSDN/OpenAtom, Phoenix Tech, Sina Tech/ITHome

Открытая атомная openKylin 3.0 официально выпущена 08-28. Ядро скачкообразно обновлено с Linux 6.6 до 7.0, более 180 ключевых компонентов, включая GCC 15, glibc 2.42, LLVM 22, JDK 25, обновлены синхронно. Три наиболее значимых для экосистемы RISC-V момента: (1) Унифицированная поддержка четырёх основных архитектур x86, ARM, RISC-V, LoongArch; официально заявлено, что openKylin — «одна из операционных систем с 가장 широкой адаптацией и наивысшей зрелостью для архитектуры RISC-V», уже поддерживает новейший стандарт RVA23, списки совместимости оборудования для каждой архитектуры опубликованы на Gitee; (2) На платформе RISC-V AI-инференс оптимизирован с помощью инструкций RVV: в сценариях FP32 ускорение в 2–5 раз, в сценариях FP16 — до 36,5 раз; (3) Охват сценариев расширен до гуманоидного робота «Linglong», AI-беспилотных тележек, AI-роботизированных манипуляторов и других задач адаптации воплощённого интеллекта и мультиархитектурных промышленных аппаратных платформ. В области безопасности интегрированы три стандарта постквантовой криптографии NIST (ML-KEM/ML-DSA/SLH-DSA) с системными вызовами через openHiTLS, поддерживается разработка драйверов ядра Rust For Linux. В области агентов создана открытая база: KylinBot и OpenClaw и другие массовые агенты напрямую вызывают возможности рабочего стола через протокол MCP. Являясь ключевым звеном отечественной ОС в программной экосистеме RISC-V, прогресс адаптации RVA23/RVV в openKylin 3.0 заслуживает постоянного отслеживания.

1.3 Два открытых проекта: ClickDOOM симулирует RISC-V через ClickHouse SQL для запуска DOOM 1993 года; LabWired Core — детерминированный симулятор прошивок

Дата: 2026-08-31　Источник: MarcusKainth/ClickDOOM, w1ne/labwired-core

Два новых активных открытых проекта (выявлены через GitHub API в окне мониторинга): ClickDOOM компилирует C-исходники движка DOOM 1993 года от id Software через порт-слой doomgeneric как есть в бинарник bare-metal RV32IM, затем по инструкциям исполняет их на «симуляторе CPU RISC-V, полностью реализованном на ClickHouse SQL» (fetch/decode/execute, регистры, RAM, MMIO — всё внутри SQL); кадр 220 demo3 после 220 миллионов инструкций совпадает по хешу вывода с эталонным симулятором, что подтверждает корректность симуляции; предшественник — Click-V (CPU RISC-V внутри SQL), двойная лицензия Apache-2.0/GPL-2.0, относится к категории «серьёзная симуляция ISA, превращённая в SQL-экстремальный вызов» — занимательный хардкорный проект. LabWired Core — написанный на Rust симулятор прошивок: после загрузки ELF прошивки детерминированно исполняет её на смоделированном чипе (CPU, шина, периферия, датчики); один и тот же ELF + список плат дают одинаковый trace на любой машине, может использоваться как CI-гейт (pass/fail по коду возврата), поддерживает ARM Cortex-M и RISC-V, 61 stars. Оба вместе отражают активность экосистемы инструментов/симуляции RISC-V в направлении «эмуляция как тестирование».

2. Продукты и динамика экосистемы

2.1 XCENA MX1: Hot Chips 2026 — подробный разбор CXL-устройства вычислительной памяти с тысячами ядер RISC-V

Дата: 2026-08-26 (доклад на Hot Chips)/08-28 (репортаж)　Источник: HPCwire, ServeTheHome, StorageNewsletter

XCENA на сессии Memory конференции Hot Chips 2026 (08-26, совместный доклад с Samsung) подробно разобрала архитектуру и измеренную производительность своего вычислительного устройства хранения MX1 класса CXL Type 3: 3072 кастомных ядра RISC-V с частотой 1,4 ГГц образуют Memory Acceleration Unit и выполняют ресурсоёмкие по доступу к памяти нагрузки поблизости; четыре канала DDR5-8400 поддерживают расширение до 2 ТБ памяти, SSD через корневой порт представлен в форме CXL-памяти с байтовой адресацией; встроенный векторный движок обеспечивает пропускную способность скалярного произведения около 3 TFLOPS FP32/FP16 (ориентирован на векторный поиск, оценку KV-cache). Разработчики программируют на стандартных C/C++ или Rust, планируя тысячи ядер через инструментальную цепочку LLVM + среду выполнения PXL (разделяемое виртуальное адресное пространство). Измерено относительно CPU хост-машины при доступе через CXL: пропускная способность одного MX1 до 4,7 раза выше, энергоэффективность в 18,7 раза выше; относительно локальной DDR5: пропускная способность в 2,0 раза выше, энергоэффективность в 6,2 раза выше. Это устройство представляет направление “крупномасштабные вычисления вблизи памяти на RISC-V + пулирование памяти CXL”, сочетается с стоечным решением CXL-памяти Samsung и заслуживает внимания с точки зрения его фактического влияния на нарратив о стене памяти для AI.

2.2 Индийская Aheesa Vihaan: первый проход кремния запущен — 64-битный RISC-V сетевой SoC прошёл первый раунд аппаратной валидации

Дата: 2026-08-30　Источники: SDxCentral, The Hans India, официальный сайт Aheesa

Ченнайский стартап Aheesa Digital Innovations объявил об успешном первом проходе кремния (first-pass silicon) серии Vihaan, первый раунд аппаратной валидации подтвердил характеристики производительности. Vihaan — это управляемый 64-битным RISC-V сетевой SoC, ориентированный на сценарии широкополосного доступа: высокопроизводительные маршрутизаторы, управляемые коммутаторы и устройства унифицированного управления угрозами (UTM); также есть edge-версия для IoT-шлюзов и промышленной автоматизации (локальная обработка с низкой задержкой). Компания основана в 2021 году, руководители выходцы из Wipro, Microchip, AMI, CEO Sridharan Mani ранее был старшим менеджером по разработке ПО в Amazon; финансируется по программе Design Linked Incentive (DLI) Министерства электроники и информационных технологий Индии (MeitY), привлекла около 4,19 млн долларов (включая инфраструктурный фонд Тамилнада TNIFMC). График: первый проход кремния в январе 2026 года, целевой серийный проход кремния — 2027 год. В заявлении MeitY говорится, что его прогресс “показывает, что индийский полупроводниковый дизайн выходит из лабораторий”. Это знаковый прогресс индийского курса на суверенные чипы RISC-V (после линейки Shakti от IIT Madras) в направлении коммерческого сетевого кремния.

2.3 Экосистемный референс Radxa Linkr: IP KVM размером с флешку, в главном контроллере есть сопроцессор RISC-V

Дата: 2026-08-30　Источники: CNX Software, страница продукта Radxa

CNX Software разобрал и протестировал новинку Radxa Linkr: IP KVM размером с флешку (70×22×12 мм), захватывает экран целевой машины через HDMI + эмулирует клавиатуру и мышь через USB, поддерживает прямое подключение USB-C, удалённое управление через Ethernet и Wi-Fi 6 (AIC8800), работает прямо в браузере, без установки приложения, поддерживает Tailscale VPN, двухфакторную аутентификацию и перехват управления AI-агентами вроде OpenClaw/Hermes. Главный контроллер — Rockchip RV1106G3 (Arm Cortex-A7 @1.2GHz + встроенный сопроцессор RISC-V), NPU 1 TOPS, 256 МБ встроенной памяти + опционально 16 ГБ eMMC. Связь с RISC-V: RV1106 содержит встроенный сопроцессор RISC-V (аналогичный продукт JetKVM также его использует), к тому же сама Radxa — ведущий производитель одноплатных компьютеров на RISC-V; но основная вычислительная часть Linkr по-прежнему на Arm, это статья категории экосистемный референс, а не нативный продукт RISC-V. Цена от 59 долларов, в четырёх каналах продаж пока нет в наличии.

Дата: 2026-08-30/31　Источники: sophgo/sophon-tools, spacemit-com/openocd, GitHub orgs API (XUANTIE-RV/sophgo/Nuclei-Software/spacemit-com/eswincomputing/revyos/sipeed)

Проведена проверка активности в окне по GitHub-организациям семи китайских команд (фильтрация orgs repos API по pushed_at): T-Head (XUANTIE-RV, 72 репозитория), Nuclei (Nuclei-Software, 42 репозитория), ESWIN Computing (eswincomputing, 16 репозиториев), Sipeed (sipeed) в пределах окна не имели push, в целом находятся в спокойном периоде после релиза; SOPHGO (sophgo) имеет лишь один push в sophon-tools (утро 08-30, то есть подтверждено слияние вчера уже доложенного пакета усиления безопасности перед выпуском версии); SpacemiT (spacemit-com) имеет два push — соответственно в docs-chip (вчера уже доложенная документация P3 PMIC) и в репозитории openocd (только read-only синхронизация зеркала upstream, без собственной разработки); 7 push в организации Revyos — все синхронизация цепочки прошивок SG204x (fsbl.bin/кросс-компилятор EDK2, вчера уже доложено). Вывод: у китайских команд в пределах окна нет новых динамик архитектурного или продуктового уровня, что соответствует обычному спокойному периоду после выпуска крупной версии; следующее окно внимания — сентябрьский ритм релизов каждой команды (сопровождение серийного производства CV84X у SOPHGO, первый раунд действий Nuclei после листинга, продолжение XiangShan KunminghuV2).

4. Специальная глава об embodiment AI и робототехнике

4.1 В окне нет новых RISC-V аппаратных продуктов для embodiment AI; на программной стороне openKylin 3.0 завершил адаптацию человекоподобных роботов и др.

Дата: 2026-08-31　Источники: сводка пунктов данного выпуска (подробности см. в приложении)

В данном окне не обнаружено новых выпусков RISC-V аппаратных продуктов для embodiment AI, конфигурация продолжает суждение последней недели: прогресс RISC-V на стороне embodiment AI сосредоточен в программном и платформенно-адаптационном слое. Наиболее релевантный сигнал этого выпуска исходит от openKylin 3.0 (см. 1.2): в охват его сценариев явно включена адаптация embodiment AI, такая как человекоподобный робот “Linglong”, AI-беспилотная тележка, AI-манипулятор, и поддерживаются многоархитектурные промышленные аппаратные платформы, включая RISC-V, — то есть лагерь отечественных ОС включает RISC-V embodiment AI в матрицу адаптации по умолчанию; в то же время оптимизированная по RVV производительность AI-инференса на RISC-V (ускорение FP16 до 36,5 раз) предоставляет измеренное обоснование для развёртывания моделей на периферийных устройствах. Кроме того, технический обзор eeNews Europe (08-25, ссылка по экосистеме) указывает, что европейский ускоритель EPAC 1.0 реализует 12 TOPS/W на базе управляющего ядра RISC-V + доменного AI tile, подтверждая применимость открытой ISA при ограничениях энергопотребления в роботах и автономных системах. По окну новых аппаратных продуктов рекомендуется следить за сентябрьским сезоном выставок робототехники в Китае и ритмом выпуска роботизированных SKU SoC каждой компании.

5. Итоги и наблюдения за трендами

  1. Продвижение основной линии ядра: выпущен Linux 7.3-rc1, в окно слияния включены несколько новых расширений RISC-V, рефакторинг кода контроллера прерываний RISC-V вошёл в общую структуру ACPI IRQ, прокладывая путь для поддержки прерываний RISC-V ACPI; на стороне KVM преобладают исправления SEV и разбиение крупной структуры kvm_mmu.
  2. Ускорение адаптации RISC-V в отечественных ОС: openKylin 3.0 выпущен из одного источника для четырёх архитектур, самооценка — “самая широкая адаптация RISC-V, наивысшая зрелость”, поддержка RVA23 + оптимизация инференса RVV (FP16 до 36,5 раз) + охват сценариев embodiment AI, готовность программного стека продолжает повышаться.
  3. RISC-V углубляется в центры обработки данных: XCENA MX1 с 3072-ядерными RISC-V вычислениями вблизи памяти + пулинг CXL 3.2 входит в проблему стены памяти AI, измеренная пропускная способность/энергоэффективность значительно опережают хост-процессор (до 4,7 раз/18,7 раз), что дополняет поставку серверов SiFive BigSky (доложено 08-29).
  4. Глобальный курс на суверенные чипы расцветает в нескольких точках: индийский Aheesa Vihaan (финансируется программой DLI) с первой версией tape-out и зажжением, после Shakti делает ход в направлении коммерческого сетевого кремния, цель серийного tape-out в 2027 году ясна.
  5. Китайские команды входят в спокойный период после релиза: у семи основных организаций в окне GitHub нет динамик архитектурного уровня, это обычный ритм после выпуска крупной версии; следующая точка наблюдения — сентябрьские окна релизов каждой компании.
  6. Пояснение об ограничениях: китайские источники Google News ограниченно напрямую охватывают китайские команды (статьи вроде T-Head/XiangShan загрязнены одноимённым шумом), отечественная часть зависит от проверки коммитов GitHub; основной контроллер Radxa Linkr — Arm + сопроцессор RISC-V, включён как ссылка по экосистеме; страницы перехода gnews не читаются напрямую, основной текст основан на оригинальных сайтах.
