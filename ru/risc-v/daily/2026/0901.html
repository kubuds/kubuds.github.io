一、开源社区与软件生态

1.1 CPython 官方支持 RISC-V（Tier 3 平台）：软件生态里程碑

日期：2026-08-24（Python Insider 公告）/ 08-31（Adafruit 转载、HN 热帖）　来源：Python Insider（官方公告）、RISE Project 博客、Adafruit 报道（gnews 链接）

CPython 维护者 Stan Ulbrych 在 Python Insider 官方博客宣布：RISC-V 正式成为 CPython 的 Tier 3 受支持平台（PEP 11）。达成条件的关键是真实硬件上的持续测试——RISE Project 提供了多台物理 RISC-V 机器用于 CPython buildbot 与架构相关问题调试；主要贡献者还包括 RISE 的 Ludovic Henry、Furkan Onder 与 Emma Smith，Ulbrych 本人的工作获 Sovereign Tech Agency 奖学金资助。下一步：借助 RISE RISC-V Runners 计划把 RISC-V 直接接入 CPython 官方 CI（合并前即可获得反馈），并长期争取升级至 Tier 2；同时探索利用 RISC-V 特性的架构级性能优化。公告同时呼吁社区在真实 RISC-V 硬件上构建并反馈问题。该公告 08-24 发布，昨日报告未覆盖，本期补录；08-31 Adafruit 转载与 Hacker News 热帖使其在窗口内获得高关注，是近一周 RISC-V 软件生态最重要的里程碑。

1.2 Arduboy CHGame Rev0：39 美元开源 RISC-V 彩色掌机

日期：2026-08-31　来源：Hackster.io、Arduboy 商店

经典开源掌机 Arduboy 推出新平台 CHGame Rev0：39 美元裸板开发套件，主控为沁恒（WCH）CH32X035G8U6——32 位 RISC-V 微控制器，48 MHz，64 KB Flash、20 KB RAM，带 DMA 与可编程 I/O（PIO）；配 1.44 英寸 ST7735 彩色 LCD（128x128、16 位色）、八颗按键、压电扬声器、microSD 槽与 200 mAh 电池。Arduino 兼容免驱动，板面丝印标注 GPIO/功能分区并开放 GPIO、I2C、UART 扩展口，官方定位是”自带屏幕按键的 RISC-V 开发板”。当前为资助开发的前期套件，量产成本预计进一步下探。这是国产 RISC-V MCU（沁恒）在海外开源硬件社区的一次典型落地，延续 CH32V003 系”白菜价 RISC-V 掌机”热度。

二、产品与生态动态

2.1 Micro Magic MagicV 处理器宣布立即供货，宣称世界最快/最低功耗 64 位 RISC-V

日期：2026-08-31　来源：PR-Inside（ACCESS Newswire 通稿）、Middletown Life 转载

美国硅谷私有公司 Micro Magic 宣布其 MagicV 处理器系列即日供货，提供 1/2/4 核配置，现场演示多核 MagicV 运行 Linux、Zephyr 与 FreeRTOS。通稿重申历年宣称的指标：单核 1.1V 下 5 GHz、13,000 CoreMarks；0.8V 下 4.25 GHz 仅 200 mW（11,000 CoreMarks）；能效 110,000 CoreMarks/Watt；超低功耗核 1 GHz 仅 10 mW；数据基于 16nm 工艺，更先进节点可用。CEO Mark Santoro 称客户对性能印象深刻、低功耗表现”令人震惊”。需注意：全部性能数字均为厂商自宣，未见第三方基准或流片公开证据，公司长期寻求战略合作或并购，建议作为”宣称待验证”条目跟踪（Micro Magic 自 2021 年即发布类似宣称，本次为首次宣布可购货）。

2.2 西班牙 Indra-UPM 首批四芯片流片交付，含 RISC-V 架构芯片

日期：2026-08-31　来源：Demócrata

西班牙 Indra 集团与马德里理工大学（UPM）联合教席”改变未来的微电子”完成首批四款芯片设计并送制造，现已产出交付、进入评估表征阶段。具体为三颗 65nm 硅芯片（TSMC 流片）与一颗磷化铟（InP）光子集成芯片（研究波束成形架构）。其中一颗硅芯片采用 RISC-V 架构，另两颗用于 3D 异构集成测试，目标是推进射频模块小型化与集成度。项目为预竞争环境，学生与工业博士参与，服务于欧洲技术自主战略；Indra 同时是专注 III-V 族光子制造的 Sparc Foundry 大股东（维哥工厂预计 2027 年投产）。该动向与西班牙 OpenChip（RISC-V International 董事会成员）等布局同频，属欧洲主权芯片路线在 RISC-V 侧的中型落地。

三、国内团队动态与深挖

3.1 国内团队 GitHub 动态：RevyOS 新增 K1/K3 内核配置，算能 sophon-tools 发版批次落地

日期：2026-08-31　来源：revyos/linux commits、sophgo/sophon-tools commits、sophgo/mcu PR#84、spacemit-com/docs-buildroot、sipeed/maix_ax620e_sdk

窗口内核查七家国内团队 GitHub 组织：平头哥（XUANTIE-RV）、芯来（Nuclei-Software）、奕斯伟计算（eswincomputing）、乐鑫（espressif）无相关 push，延续发布后平静期。有实质动态的三家：

进迭时空生态 RevyOS（revyos/linux，Han Gao 08-31 批量提交）为最值得关注项：新增 spacemit K1/K3 内核配置文件、linuxboot 启动配置，启用 CONFIG_ERRATA_PICOHEART 与 Banana Pi F3（K1）USB2 支持，并启用 K3 平台 DC（显示控制器）与 UFS 支持，同时把 TH1520 的 USB 相关选项改为模块化、串口数量配置调整。这是 RevyOS 发行版面向 K1/K3 双平台的内核配置增强批次，表明进迭时空生态正在为 K3 新平台的显示/存储能力铺软件底。spacemit-com/docs-buildroot 同日移除 K1 secure boot 文档章节（文档清理）。

算能：sophon-tools 08-31 共 15 笔提交（zetao.zhang），为 v26.08.31 发版前置批次——修复 BMSSM（单板管理系统）OTA 升级/回滚首条 workflow 被自身 handler 锁误杀（MYS-451 竞态）、sophliteos 升级语义改为系统级并加二次确认码、deb 打包补齐控制成员与空 preinst（根治 overlayfs 下 dpkg obsolete-info 报错）等，属系统管理栈稳定性加固；sophgo/mcu 同步修复 SM5MINI(v20) 的 i2c_slave_reset 错误清除 IP 信息问题。

矽速：maix_ax620e_sdk 修复 UVC 端点生命周期问题（相机流稳定性），小幅维护。

总体看国内团队仍处常规迭代期，无架构级/产品级发布；K3 平台软件栈推进是窗口内最值得跟踪的信号。

四、具身智能与机器人专章

4.1 MicroDuck：Hugging Face 与 Pollen Robotics 的开源双足机器人（生态参照，主控非 RISC-V）

日期：2026-08-27（发布）/ 08-31（OSChina 报道）　来源：OSChina、Pollen Robotics 官网、Interesting Engineering

Hugging Face 机器人团队（2025-04 并入的法国 Pollen Robotics）推出 MicroDuck：25 cm、不足 800 g 的开源双足机器人，15 个电机、相机、深度传感器、双 IMU 与可抓取喙，399 美元预购（08-27 开放），能行走、下蹲、跌倒爬起甚至轮滑；软件栈全开源（Microduck 与 Microduck RL 两仓库），覆盖控制、仿真、强化学习与 sim-to-real，支持用游戏手柄”玩着”训练新技能。预购首日销售额超 250 万美元、高峰每 4 秒售出一台，交付目标 2026 圣诞前。与 RISC-V 的关联：主控为瑞芯微 RK3566（ARM 平台），非 RISC-V 硬件，收录为开源具身智能生态参照——其”开源硬件 + 开源 RL 软件栈 + 低价普及”模式与 RISC-V 机器人生态路线同构，软件栈（50 Hz 控制环、策略部署、OTA 更新机制）的可移植性值得 RISC-V 平台借鉴；也为”开源硬件走向消费级具身智能”提供市场验证样本。

五、总结与趋势观察

  1. 软件生态里程碑：CPython 将 RISC-V 列为 Tier 3 受支持平台（PEP 11），RISE Project 提供真实硬件 buildbot 是达成关键；下一步接入官方 CI 并冲击 Tier 2。Python 是 AI 与科学计算主语言，此事件对 RISC-V 开发者生态的长期价值显著。
  2. 开源硬件持续平民化：Arduboy CHGame Rev0 以 39 美元把沁恒 CH32X035 RISC-V 掌机带进主流开源硬件社区，国产 RISC-V MCU 海外渗透再添一例。
  3. 高端宣称与主权芯片并行：Micro Magic 宣布 MagicV 可购货（性能数字均为厂商自宣、待验证）；西班牙 Indra-UPM 四芯片流片含 RISC-V 设计，欧洲主权芯片路线在射频/光子方向延伸。
  4. 国内团队进入常规迭代期：七家组织无发布级动态；RevyOS 新增 K1/K3 内核配置（含 linuxboot、K3 DC/UFS）是窗口内最实质进展，算能 sophon-tools v26.08.31 发版批次以系统栈稳定性加固为主。
  5. 具身智能生态参照：MicroDuck 首日 250 万美元预购验证”低价开源机器人 + RL 软件栈”需求强劲，但其主控为 ARM；RISC-V 侧机会窗口仍在 9 月国内机器人展会季与各家 SoC 机器人 SKU。
  6. 局限说明：Google News 中文源对国内团队直采仍受限（同名噪音污染），国内部分依赖 GitHub 提交核查；Micro Magic 指标未经独立验证；MicroDuck 与 Indra 条目部分信息来自厂商/学院通稿，已尽量交叉核对。
