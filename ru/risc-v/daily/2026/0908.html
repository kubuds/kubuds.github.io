一、开源社区与软件生态

1.1 Canonical 详解企业级开源 RISC-V 软件就绪度：Ubuntu riscv64 包通过率 55.1%（09-07）

日期：2026-09-07（ServeTheHome 周一发布，入窗时间 09-08 01:00 北京时间）　来源：ServeTheHome

ServeTheHome 补录 Hot Chips 2026 演讲实录：Canonical 硅谷合作总监 Gordan Markus 系统讲解 Ubuntu 的多架构构建机制与 RISC-V 企业级就绪路径，并给出量化缺口数据——Ubuntu 26.10 测试快照中 riscv64 共 3,443 个软件包接受测试、1,898 个通过，通过率约 55.1%，远低于 amd64 的约 92%。Canonical 将差距部分归因于模拟构建与测试目标（执行时间从数小时被拉长到数天），并已引入原生 RISC-V 构建机，伙伴提供服务器级 RVA23 平台支持。开源协作侧：Canonical 参与 RISC-V International 的 RISE 项目（面向移动、消费电子、数据中心与汽车的商业软件就绪），其 Ubuntu 24.04 原生 RISC-V runner 支撑托管于 Scaleway Elastic Metal 的构建与板卡农场，使用阿里与进迭时空（SpacemiT）硬件，已累计 116 个组织、24,000 个任务与 70 万分钟构建量。Canonical 的核心判断是：RVA23 风格 profile 让软件目标可预测，配合大规模上游协作可跨越拖慢新 ISA 开源采用的历史性”软件就绪差距”；未来两年服务器级 RVA23 硬件陆续到位后，软件栈有了固定收敛目标。这是窗口内对企业级 RISC-V 软件生态最有数据价值的一条。

1.2 香山：新向量后端 vfma 通路重构与宽指令支持批次落地（09-07）

日期：2026-09-07（16:19~17:33 北京时间批次）　来源：GitHub openxiangshan/XiangShan commits

香山开源高性能核（昆明湖）向量后端重构持续推进：09-07 下午批次合入 feat(vfma) “support vfma in new vector backend”、feat(vector, vfmac) 重构 pipeline 寄存器并支持 widen 指令、fix(vector) 初始化 vfma pipe metadata，标志新向量后端执行通路从整寄存器移动（昨日批次）延伸到浮点乘加（vfma/vfmac）与加宽运算；同批还包含 bypass 就绪与非寄存器源修复、LoadQueueReplay 非对齐 head 延迟唤醒处理、ROD 编码对齐修复（#6509）与 FFlagsWen 表补入 VFREC7_V/VFRSQRT7_V。结合前几日 vialu/mgu 连接与向量宽窄指令支持，可判断香山向量执行子系统重构正按”指令功能补齐—通路数据流修复—浮点矩阵运算接入”的顺序推进，工程成熟度持续提升，本窗口无版本发布。

1.3 CVA6：修复面扩展至 RV32/64 指令合法性，虚拟化与内存保护继续打磨（09-07~08）

日期：2026-09-07 20:18 ~ 09-08 05:36（北京时间，9 个提交）　来源：GitHub openhwgroup/cva6 commits

OpenHW Group 应用级开源核 CVA6 在窗口内继续批量合入修复，覆盖面较昨日进一步扩展：新增指令语义合法性维度——zip/unzip 仅 RV32 合法、RV64 应解码为非法（#3527），拒绝 RV64-only FCVT 在 RV32 上的非法使用（#3540），mstatus.MPP 在 RVH=1 时对保留值 2’b10 的合法化；虚拟化与内存保护路径延续昨日主题——ptw 修正 HLVX 规则不适用于 VS-stage PTE 读的 G-stage 检查、PMPADDR63 越界访问修复（#3485）；另补禁用 C 扩展时的 misaligned branch 回归测试（#3424）、假 4 KiB 别名回归测试（#3453）与 debug 循环共享指针越界修复。连续两日合计逾 15 个提交，虚拟化两阶段地址转换与 PMP 安全路径的打磨进入高频期，可作为 RISC-V 开源应用核质量维护节奏的观察信号。

二、产品与生态动态

2.1 YuzukiHD 开源 YuzukiNeko：Allwinner F101（达摩院玄铁 C907）Pico 尺寸 Linux 板卡（09-08）

日期：2026-09-08　来源：CNX Software、YuzukiHD/YuzukiNeko GitHub

开源硬件团队 YuzukiHD 发布新板 YuzukiNeko：Raspberry Pi Pico 尺寸（约 51 x 21 mm）的 Linux 单板机，搭载全志新款 SoC Allwinner F101”智能控制与显示处理器”。F101 采用单核达摩院玄铁 C907 RISC-V 核（1.008 GHz，32 KB I-cache + 16 KB D-cache），QFN-68 封装，SiP 集成 8 MB（F101S2）或 16 MB（F101S3）PSRAM（252 MHz），集成显示引擎（RGB888 720p、单链路 LVDS 1366x768、4 通道 MIPI DSI 1280x800）、大尺寸 JPEG/PNG 解码、USB 2.0 DRD 与 512 bit eFuse。板载 128 Mbit SPI NOR + microSD、USB-C（数据/供电/烧录）、双 20-pin GPIO 扩展排针与 FEL 按键。软件侧 YuzukiHD 已在 GitHub 开源原理图、EasyEDA 工程、Gerber、3D STEP 与 BOM，并提供基于 mainline Linux 7.2 的 sun252i_f101 分支、Buildroot 外部树及 Zephyr RTOS 支持（Linux 与 Zephyr 双系统）。Whycan 论坛消息称 F101 SoC 单价约 18 元人民币（约 2.7 美元），社区预期整板售价可低于 10 美元。板卡尚未开售。意义：达摩院玄铁 C907 继 D1 系（C906）后再获本土 SoC 大规模低成本采用，超低价”Linux/Zephyr 双系统”RISC-V 微板卡生态有望进一步扩张。
