1. Сообщество открытого исходного кода и программная экосистема

1.1 Espressif выпустила esp-nn 1.3.1: векторизованная оптимизация полносвязного слоя в ядрах RISC-V

Дата: 2026-08-28　Источник: журнал коммитов espressif/esp-nn

Нейросетевая библиотека Espressif esp-nn выпустила 1.3.1 (слияние 08-28 23:44 пекинское время). Ключевое улучшение производительности в этом выпуске — векторизация коррекции per-channel offset в полносвязном слое (fully_connected): путь RISC-V (вариант оптимизированных ядер riscv_pie, ориентированный на серию ESP32-C) и путь Xtensa S3 оптимизированы синхронно, на стороне S3 в сценариях коротких строк приоритетно используется ассемблер; показатели производительности в README также обновлены. Семейство ядер riscv_pie в esp-nn охватывает операторы активации, базовой математики, полносвязного слоя и др.; это регулярная итерация Espressif по предоставлению оптимизированных на уровне DSP операторов для RISC-V MCU, без архитектурных изменений.

2. Продукты и динамика экосистемы

2.1 SiFive BigSky переходит в фазу поставок: первые системы уже выполняют рабочие нагрузки у ведущих клиентов, комментарий аналитика Futurum

Дата: 2026-08-28　Источник: аналитическая статья The Futurum Group (дата публикации 2026-08-28)

Аналитик Futurum Group Брендан Бёрк 08-28 опубликовал тематический разбор BigSky, в заголовке прямо заявив «SiFive BigSky поставляет первый RISC-V сервер». Новые фактические тезисы: (1) BigSky SF-2U870 полностью соответствует профилю RVA23, из коробки поддерживает Ubuntu 26.04 LTS и RHEL 10; (2) CUDA может работать на его ядрах P870-D в качестве head node (управляющего узла) для рабочих нагрузок LLM на GPU NVIDIA; (3) SiFive заявляет, что ведущие клиенты (включая гиперскейлеров, производителей ПО и крупных производителей SoC) уже выполняют рабочие нагрузки на развёрнутых системах BigSky. Вывод аналитика: BigSky по сути — «продающий время» носитель для портирования — сокращает многолетнюю фазу ПО в проектах заказных SoC гиперскейлеров; текущее положение RISC-V серверов эквивалентно положению Arm примерно в 2018 году (RVA23 и спецификация серверной платформы уже финализированы, корпоративный Linux готов, первые чипы, способные запускать этот программный стек, доставлены клиентам), ограничивающим фактором развёртывания RISC-V в дата-центрах стали не чипы, а ПО, и BigSky рождён, чтобы своевременно закрыть этот разрыв. Одновременно отмечено, что SiFive не опубликовала вместе с платформой данные SPEC/производительности, энергопотребления и цен, а проверка коммерческой конкурентоспособности отложена на потом. Данное окно — этап «прогресса поставок/развёртывания + определения тона аналитиками» для этого события после публикации 08-24 и медийного разогрева с 08-25 по 08-27, относится к существенно новой информации.

3. Динамика китайских команд и углублённый анализ

3.1 XiangShan: 68+ коммитов, масштабное слияние результатов разработки за месяц (ZICBO, Zvknha/Zvbb, рефакторинг векторного блока, AMOCAS)

Дата: 2026-08-28　Источник: поиск коммитов OpenXiangShan/XiangShan, XiangShanLab

Организация OpenXiangShan за окно мониторинга — около 84 коммитов (в основном репозитории XiangShan — 68 коммитов); ключевое событие — массовое слияние 08-28 в 16:44 пакета межмесячных результатов разработки (диапазон author-дат с 2025-11 по 2026-08-26; это завершение пакетного слияния, а не новая разработка текущего дня). Ключевые пункты: (1) расширение ZICBO: добавлена поддержка ZICBO и унификация opcode операций над блоками кэша (cbo) через LSUOpType (author 08-26); (2) векторные криптографические расширения: Zvknha (векторная криптография NIST AES) — начальная версия Версия (author 2026-02), Zvbb (векторные битовые операции) — инициализация поддержки (author 2026-02); (3) рефакторинг векторного блока: новый начальный коммит vector (author 08-06), передача vstart в VectorDecodeChannel, добавление immType в vector fu config, отключение vl value wakeup, разрыв временных цепочек VTypeGen и ряд других рефакторингов и оптимизаций таймингов; (4) поддержка AMOCAS d/w/q (author 08-19) и исправление логики AMOCAS src select; (5) импорт генерируемого списка инструкций со стороны набора инструкций из репозитория riscv_opcodes (author 2025-11), дифференцированные opcode load event (formLoadEventOpcode, author 08-20). В тот же период активен XiangShanLab: внедрена аналитическая программа № 4636, skill difftest-tracer, базовая библиотека учебных программ chisel и переработка issue-процесса; развитие учебных и экспериментальных инструментов продолжается. Это слияние заметно усилило XiangShan в покрытии векторных расширений и поддержке атомарных инструкций и инструкций операций над блоками кэша.

3.2 SpacemiT: новый репозиторий инструмента документации модельной библиотеки model-zoo-file2md, релиз 0.1.1

Дата: 2026-08-28　Источник: spacemit-com/model-zoo-file2md

SpacemiT за окно мониторинга — 3 коммита (новый репозиторий model-zoo-file2md): добавлен компонент document to markdown (feat(file2md)), восстановлены читаемые примечания к релизу 0.1.1, удалён локальный скрипт benchmark-отчёта. Этот репозиторий позиционируется как инструментальная цепочка преобразования документации модельной библиотеки в Markdown, обслуживающая стандартизацию документации серии репозиториев model zoo SpacemiT (model_zoo_rl и др.). В сочетании с работой по документированию AVL в репозитории docs-chip предыдущего дня SpacemiT последовательно усиливает инженерное накопление в модельной библиотеке и аппаратной документации; объём динамики текущего дня невелик — это шлифовка инструментальной цепочки.

4. Специальная глава: embodied AI и робототехника

4.1 В окне нет новых RISC-V изделий embodied AI; в экосистеме Hugging Face выпущен двуногий робот Microduck (RK3566/ARM, экосистемный ориентир)

Дата: 2026-08-28　Источник: CNX Software, pollen-robotics/microduck

Pollen Robotics и Hugging Face выпустили Microduck: двуногий робот высотой 25 см, 15 двигателей (степени свободы ног/головы/шеи), камера + датчик глубины + два IMU + 8×8 ToF LiDAR, шарнирный клюв, способный захватывать предметы; цена предзаказа 399 долларов, поставки до Рождества 2026 года, ограничено Северной Америкой и Европой. Его главный контроллер — Rockchip RK3566 (четырёхъядерный Cortex-A55, не RISC-V), программный стек (написанный на Rust демон управления сервоприводами с частотой 50 Гц, инструменты обучения с подкреплением на Python, онлайн-симулятор Hugging Face) полностью открыт. В этом окне на стороне RISC-V новых аппаратных изделий embodied AI нет; эта запись включена как экосистемный ориентир — волна аппаратного обеспечения физического AI (открытая робототехническая экосистема Hugging Face) продолжает ускоряться, но в качестве основного терминального главного контроллера по-прежнему чаще выбирают платформу ARM; проникновение RISC-V в область embodied AI всё ещё демонстрирует картину «стандарты и уровень управления идут впереди (MIPS повышен до высшего членства, сообщалось вчера), терминальное внедрение — предмет наблюдения».

5. Итоги и наблюдения за тенденциями

  1. Ключевым событием данного окна мониторинга стал переход SiFive BigSky от «анонса» к «поставкам»: аналитик Futurum подтвердил, что первые системы уже развёрнуты и выполняют рабочие нагрузки у ведущих заказчиков, включая гиперскейлеров; полное соответствие RVA23 + поддержка Ubuntu 26.04 LTS/RHEL 10 «из коробки», CUDA на P870-D выполняет роль NVIDIA GPU head node; в аналитике проводится параллель «серверы RISC-V находятся там, где Arm был в 2018 году», а готовность программного обеспечения стала основным противоречием для развёртывания в центрах обработки данных. Данные о производительности и ценах не опубликованы, коммерческая валидация всё ещё требует наблюдения.
  2. XiangShan завершил крупномасштабное слияние результатов разработки за несколько месяцев: рефакторинг векторного блока + криптографические векторные расширения Zvknha/Zvbb + расширения операций с блоками кэша ZICBO + поддержка атомарных инструкций AMOCAS — покрытие инструкций и характеристики безопасности значительно усилены; учебно-экспериментальный инструментарий XiangShanLab (4636 программ, difftest-tracer) продвигается синхронно, темп трансформации исследований в инженерию стабилен.
  3. Динамика отечественных команд разнородна: SpacemiT выпустила новый репозиторий документационного инструмента model-zoo-file2md 0.1.1; Sophon, T-Head (XUANTIE-RV), Nuclei и ESWIN Computing в окне мониторинга не имеют коммитов — Sophon лишь вчера завершила внедрение официальных спецификаций CV84X6, что является нормальной ротацией ритма.
  4. Embodied AI: в окне мониторинга нет новых RISC-V аппаратных продуктов; двуногий робот Microduck из экосистемы Hugging Face использует RK3566 (ARM), в качестве основного контроллера физических AI-терминалов по-прежнему доминирует ARM, темп внедрения RISC-V в этой области отстаёт от сигналов на уровне управления.
  5. Ограничения: запросы gnews по китайским командам (T-Head/XiangShan/Sophon/SpacemiT/Nuclei/ESWIN) пусты или представляют собой шум (попадания по XiangShan — всё одноимённые новости Пекинского форума Сяншань); запрос «Milk-V» разбит токенизатором gnews на молочные категории и сильно загрязнён; попадание StarFive по 301536.SZ (SigmaStar, не StarFive) — ошибочная маркировка полугодового отчёта; информация о китайских командах основывается на коммитах в GitHub.
