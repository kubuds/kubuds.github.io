1.1 Sedna: возобновление разработки чистого Java-эмулятора RISC-V, эволюция в многоархитектурный фреймворк (08-23)

Дата: 2026-08-23 (обновление README в 23:11 по пекинскому времени; активная разработка с 08-21)　Источник: github.com/fnuecke/sedna

Чистый Java-эмулятор RISC-V Sedna, появившийся в 2020 году (rv64imacfd + Zifencei, поддержка S-режима, возможность загрузки Linux, прохождение всех тестов riscv-tests, поддержка сериализации состояния машины, публикация в Maven Central), в данном окне возобновил активную разработку: автор перенёс старый эмулятор Z80 в фреймворк Sedna (обобщение генератора декодера инструкций, перенос дискового устройства, подключение платформы Z80), README обновлён 08-23 в 23:11 (пекинское время). Позиционирование проекта эволюционирует от «одноархитектурного эмулятора RISC-V» к «многоархитектурному фреймворку эмуляции» — генератор декодера уже обслуживает Z80 в качестве доказательства концепции, благодаря чему варианты эмуляторов RISC-V в экосистеме JVM (помимо QEMU) получают активно поддерживаемое дополнение.

1.2 Ядро Arduino ESP32: добавлена опциональная проверка SHA-256 для OTA-прошивок (08-24)

Дата: 2026-08-24 (03:38 по пекинскому времени, время коммиттера)　Источник: espressif/arduino-esp32 PR #12824

В ядро arduino-esp32 от Espressif влит feat(update): add optional SHA-256 checksum for incoming firmware (#12824): для процесса OTA-обновления добавлена опциональная проверка SHA-256 прошивки, усиливающая верификацию целостности прошивки (защита от повреждения при загрузке / подмены). Выигрывают как серия ESP32-C (C3/C5/C6/C61 и другие с ядром RISC-V), так и серия Xtensa; это плановое укрепление программной экосистемы Espressif без ломающих изменений.

3.1 XiangShan: два исправления пути MMU для конфиденциальных вычислений COVE вошли в основную ветку (08-24)

Дата: 2026-08-24 (00:02 пекинское время, время коммиттера)　Источники: OpenXiangShan/XiangShan PR #6299, PR #6300

В окне мониторинга — 2 коммита в основном репозитории XiangShan, оба касаются реализации MMU для COVE (Confidential VM Extension, расширение для конфиденциальных виртуальных машин):

  • #6299 fix(MMU, COVE): reject out-of-range Smmpt addresses: ранее запросы Smmpt43, выходящие за пределы 43-битного диапазона адресов, не отклонялись MPTCache, а воспринимались как cache miss и направлялись в miss queue / table walker вместо возврата access fault. Исправление определяет ширину PA для Smmpt43 / Smmpt52 и максимальный допустимый PPN для каждого режима (43 бита: 0x007fffffff; 52 бита: 0xffffffffff), проверяет PPN запроса на стадии конвейера stageCheck, для выходящих за диапазон запросов возвращает accessFault через respHit, подавляет respMiss для предотвращения обхода таблицы, а при range fault очищает permission / NAPOT / последовательные права / метаданные уровня MPT, а при cache flush очищает регистр range-fault;
  • #6300 fix(MMU, COVE): fix bug for mpt miss queue: текущая реализация MPT miss queue нарушает протокол Decoupled (twReq.valid не стробируется сигналом ready); хотя функциональная потеря запросов не наблюдалась, исправление выполнено в соответствии с протоколом.

Значение: XiangShan — один из немногих проектов открытых высокопроизводительных процессоров RISC-V, продвигающих конфиденциальные вычисления по пути CoVE/MPT (таблица защиты памяти). Оба исправления носят характер «шлифовки на соответствие протоколу», что говорит о том, что реализация COVE прошла этап функциональной отладки и вошла в стадию уточнения деталей — что согласуется с общим ритмом недавнего «этапа завершения производительности» (мелкая работа после сходимости крупных пунктов, таких как предсказание переходов/AIA).

3.2 Шестая конференция по инновациям в проектировании интегральных схем прошла в Нанкине: запущен альянс инновационного сотрудничества RISC-V (08-23)

Дата: 2026-08-23 (репортаж Jiaohuidian 18:50 пекинское время)　Источники: China Jiangsu Net/Jiaohuidian

Шестая конференция по инновациям в проектировании интегральных схем и выставка прикладных решений на тему «AI даёт импульс, разум создаёт будущее чипов» впервые прошла в районе Цзянбэй Нового района Нанкина: 2 пленарных заседания, 8 тематических секций, 5 крупных тематических выставочных зон, более ста докладов экспертов и компаний, около двух тысяч профессиональных посетителей; участвовали Unisoc, Huada Empyrean, Alibaba, исследовательский институт Intel и другие. Ключевые моменты, связанные с RISC-V:

  • Одновременно запущен альянс инновационного сотрудничества RISC-V, вместе с открытием центра совместных инноваций Chiplet, создающий платформу технического обмена и промышленной кооперации для открытых чипов и передовой упаковки;
  • Тематика охватывает инновации в проектировании IC, локализацию автомобильных чипов (завершена интерпретация первого отечественного количественного стандарта здоровья автомобильных чипов «AsaChi»), передовую упаковку, открытую экосистему RISC-V, инновации в чипах для бытовой техники (Haier/Hisense/TCL), воплощённый интеллект, интеграцию производства и образования, взаимодействие с инвестициями и финансированием;
  • Опубликован «Список 2026 Qiangxin», запущен конкурс EDA Elite Challenge в рамках Всекитайского конкурса студентов по проектированию чипов 2026 (подготовка кадрового резерва).

Контекст: район Цзянбэй, где прошла конференция, уже объединяет более 600 предприятий полной цепочки интегральных схем. Отрасль переходит к системным инновациям «AI-импульс + архитектурные инновации + передовая упаковка + сотрудничество открытой экосистемы»; запуск альянса инновационного сотрудничества RISC-V — ещё один сигнал организованности индустрии открытых процессоров (за последние две недели уже прошли форум индустрии RISC-V в Дихуайху, полуфинал конкурса инновационного сотрудничества RISC-V+AI HICOOL 2026 и другие интенсивные мероприятия).
