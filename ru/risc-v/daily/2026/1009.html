Ежедневный отчёт RISC-V (2026-10-09)

2026-10-09 Kubuds

1. Открытое сообщество и программная экосистема

1.1 SpacemiT: обновление device tree для Linux 7.4, включены частотное регулирование K3, термоконтроль и управление вентилятором

Дата: 2026-10-08　Источник: Phoronix «SpacemiT RISC-V SoCs To See More Improvements With Linux 7.4» (10-08)

Pull request с обновлениями device tree для SpacemiT K3/K1 в upstream-ядре был отправлен 10-08 (планируется к включению в Linux 7.4): поддержка частотного регулирования CPU для K3 расширена на большее число аппаратных конфигураций, включён узел RFKILL, а также добавлены термоконтроль и управление вентилятором — для чипа датчика CTF2301 на системном модуле K3 CoM260; на отладочных платах Muse Pi Pro, Orange Pi R2S, Orange Pi RV2 на базе K3 вместе с этим пакетом включается частотное регулирование CPU. На стороне K1 включена поддержка встроенного EEPROM, а также поддержка установки MAC-адреса из данных EEPROM. K3, будучи одним из первых серийных чипов RVA23, продолжает получать всё более полную поддержку в upstream.

1.2 RevyOS: массовое применение конфигураций ядра, продвижение платформ K1/K3 и EIC7700

Дата: 2026-10-08　Источник: История коммитов revyOS/linux (ветка revyos/7.3.y, 10-08)

В репозитории ядра RevyOS (revyos/linux) в течение окна мониторинга одним пушем добавлено более 20 конфигурационных коммитов: добавлены dp1000 и специализированные конфигурации K1/K3 (дисплей DC для K3, UFS для K3, K1 USB2 для Banana F3); включены архитектура ESWIN EIC7700 и драйверы DWMAC, PINCTRL, последовательность питания GPU TH1520, RTC/RESET_GPIO и ряд других часто используемых драйверов; на стороне USB-C включены переключение ролей Type-C, TCPM, UCSI, FUSB301 и режим альтернативного DP. На стороне CI добавлены задачи кросс- и нативной сборки, а также конфигурация linuxboot. Конфигурации ядра дистрибутива для множества платформ (TH1520/K1/K3/EIC7700) были массово развёрнуты в первом окне после праздников.

1.3 openRuyi: массовое расширение пакетов SPECS, более 20 позиций серии go-github добавлены за один раз

Дата: 2026-10-08　Источник: История коммитов openRuyi (10-08), Коммит openRuyi: cgctl поддерживает текущий API cilium-ebpf

В основной репозиторий openRuyi в течение окна мониторинга за один раз влито более 20 коммитов SPECS: массово добавлены определения пакетов серии go-github-* (gopsutil, gokrb5, nats.go, cassandra-gocql, aliyun-credentials-go, google-cel-go и другие), а также выполнена адаптация cgctl к текущему API cilium-ebpf и исправлена сборка Go для jcmturner-gokrb5-v8. С учётом проверки новостной страницы официального сайта — после версии 2026.09 новых анонсов релизов нет; данный пакет расширений следует отнести к повседневному пополнению репозитория пакетов после релиза, охватывающему зависимости экосистемы Go, связанные с cloud native и observability.

1.4 XiangShan: два бэкенд-исправления FEX0 закрыты и влиты в основную ветку

Дата: 2026-10-08　Источник: XiangShan PR #6649: сохранение выходного слота FEX0 для преобразования x0 (открыт 09-29, влит 10-08), XiangShan PR #6651: очистка неиспользуемого F2vCfg в FEX0 (открыт 09-29, влит 10-08)

Исправления бэкенда XiangShan, зафиксированные в ежедневном отчёте от 09-29, в течение окна мониторинга были официально закрыты: #6649 (сохранение выходного слота FEX0 для преобразования x0) и #6651 (удаление неиспользуемой конфигурации F2vCfg в FEX0) последовательно влиты в основную ветку; оба коммита находятся в пути выдачи и управления ресурсами блока исполнения с плавающей точкой FEX0. Ранее открытые в том же пакете #6652 и #6653 (исправления выдачи и упорядочивания векторных операций) в записях о вливании данного окна не обнаружены; ход рассмотрения ожидает отслеживания.

1.5 Цепочка симуляции XiangShan: NEMU открывает несколько PR подряд, difftest поддерживает независимые тактовые сигналы ускорителя

Дата: 2026-10-08　Источники: difftest PR #977: поддержка независимых тактовых сигналов ускорителя (10-08), NEMU PR #1242: предотвращение защёлкивания прерывания таймера при записи в SIP, NEMU PR #1243: управляемое difftest наблюдение за памятью, NEMU PR #1244: режим контрольных точек CHECKPOINT_HERE, NEMU PR #1245: обработка ошибок формата контрольных точек ZSTD

В окне мониторинга цепочка симуляции продвигалась по нескольким направлениям: difftest #977 влит — поддержка независимых тактовых сигналов ускорителя, что прокладывает путь к сравнительной симуляции с несколькими тактовыми доменами; NEMU открыл несколько PR подряд — #1241 (сохранение записи на первой странице при страничной ошибке на границе страниц RVV, край окна), #1242 (предотвращение защёлкивания прерывания таймера при записи в SIP), #1243 (управляемое difftest наблюдение за памятью), #1244 (введение режима контрольных точек CHECKPOINT_HERE на основе nemu_trap 0x105), #1245 (доработка обработки ошибок формата контрольных точек ZSTD), а также отправлена ветка feat-matrix-mem-profiling. Механизм контрольных точек и исправления поведения CPU развиваются параллельно, инфраструктура симуляции накапливает силы для следующей итерации микроархитектуры.

1.6 Краткие новости экосистемы: Chipyard влил библиотеку PMU, riscv-unified-db добавил записи Zkr／Sdext

Дата: 2026-10-08　Источники: Chipyard PR #2387: влитие библиотеки PMU и добавление конфигурации PMU для BOOM v3 (10-08), история коммитов riscv-unified-db (10-08)

Открытый фреймворк для SoC Chipyard (UC Berkeley) в окне мониторинга влил #2387: библиотека PMU (блок мониторинга производительности) добавлена как подмодуль генератора, для BOOM v3 добавлена конфигурация PMU, синхронно обновлены указатели подмодулей — инфраструктура аппаратного профилирования неупорядоченных ядер дополнена. riscv-unified-db (машиночитаемая база данных спецификаций) добавила записи о семенных CSR Zkr (включая поддержку источника энтропии на бэкенде C++), описания расширения Sdext и обработки нелегальных инструкций — охват расширений в базе данных спецификаций продолжает расширяться.

2. Продукты и динамика экосистемы

2.1 Vayavya Labs и Tenstorrent: виртуальные платформы SystemC ускоряют разработку программного и аппаратного обеспечения RISC-V

Дата: 2026-10-07　Источники: Новостная комната Tenstorrent: объявление о партнёрстве с Vayavya Labs (10-08), материал PR Newswire (10-07)

Vayavya Labs объявила о партнёрстве с Tenstorrent в области виртуальных платформ: на базе своей платформы TvastaaVP для IP безопасности и системного управления Tenstorrent создаётся виртуальная платформа SystemC, позволяющая раньше начинать разработку и верификацию программного обеспечения до выхода кристалла и снижать риски интеграции. Стороны называют это сотрудничество переходом от однократного моделирования к многолетнему партнёрству и представят его совместно на мероприятии экосистемы RISC-V «The Open Frontier» (10-08), проводимом Tenstorrent в Бангалоре. Сдвиг влево (shift-left) в проектировании становится конкурентным фактором для высокопроизводительных чипов RISC-V.

2.2 Sophgo: SG2044 влит в коммит о релизе SDK v20261008, кодовое имя платы изменено на SRM31

Дата: 2026-10-08　Источники: история коммитов bootloader-riscv (10-08)

Shenzhen bootloader-riscv завершил в окне мониторинга три коммита по серии SG2044: переименование платформенного кодового имени SRM3-C0 в SRM31, добавление скрипта релиза (release script) и включение коммита релиза SDK v20261008 — прошивка и SDK 64-ядерной серверной платформы RISC-V SG2044 вступают в новый раунд версионированной поставки. В тот же период в репозиториях sophgo-edk2, edk2-platforms и других также были поддерживающие пуши (линия поддержки UEFI серий SRM/cv).

2.3 Релиз Radxa Linkr v1.5.2: двойное нажатие FN для переключения точки доступа, исправлено переключение разрешения Q8B

Дата: 2026-10-08　Источники: Релиз Radxa Linkr v1.5.2 (10-08)

Продуктовая линейка браузерного удалённого управления Linkr от Radxa выпустила v1.5.2 (предыдущая версия v1.5.0 вышла 09-24): новая функция — быстрое двойное нажатие пользовательской кнопки FN для включения/выключения точки доступа Wi-Fi; улучшен выбор диапазона точки доступа с учётом ограничений модуля Wi-Fi (при отсутствии подключения к сети или при подключении к 5GHz используется 5GHz, при подключении к 2.4GHz используется 2.4GHz); исправлена проблема переключения разрешения при использовании Radxa Dragon Q8B в качестве источника видеовхода. Сценарии внешнего управления отладочными платами/NAS продолжают оттачиваться.

2.4 Sipeed: создан репозиторий Tang Mega 138K/AE350 Linux, продвигается поддержка платформы NanoKVM Go

Дата: 2026-10-08　Источники: Репозиторий sipeed/Tang-Mega-138K-Linux (создан), История коммитов maix_ax620e_sdk (10-08)

Sipeed в окне мониторинга создал репозиторий Tang-Mega-138K-Linux, описанный как «репозиторий жёсткого ядра AE350 Linux для Tang Mega 138K» — на этой отладочной плате FPGA установлено 32-битное жёсткое ядро RISC-V AE350 (800MHz), и данный репозиторий указывает на запуск проекта по портированию Linux для жёсткого ядра (репозиторий пока пуст, что является ранним сигналом). В тот же период в maix_ax620e_sdk в U-Boot добавлена проверка идентичности платы NanoKVM Go и отображение логотипа режима восстановления; в инструментальной цепочке SLogic/scopehal и в 6 репозиториях, включая sipeed_wiki, также были пуши.

Дата: 2026-10-08　Источники: Sina Finance (Gelonghui): публичное размещение получило переподписку в 9,09 раза (10-08), Hstong: закрытие тёмной торговли с ростом на 1,6% (10-08), 21 Economic Net: репортаж о начале IPO (10-03)

В связи с сегодняшним листингом Eswin Computing (01256.HK) раскрыла окончательные результаты распределения (подробности в разделе «Главное за сегодня»): цена размещения 1,55 гонконгского доллара, чистая выручка 2,386 млрд гонконгских долларов, публичное размещение в Гонконге получило переподписку в 9,09 раза. 3.2 Zijing Semiconductor: поставки автомобильных чипов RISC-V превысили десять миллионов штук, управляющий чип «малого мозга» E100 в разработке

Дата: 2026-10-08　Источники: Phoenix Net (экспресс Wangtong News Agency): поставки автомобильных чипов Zijing Semiconductor превысили десять миллионов штук (10-08)

Разработанный Great Wall Motor Hunan Zijing Semiconductor в рамках окна мониторинга раскрыл: объём поставок автомобильных чипов превысил десять миллионов штук. Его M100 (первый в стране автомобильный MCU на базе открытого ядра RISC-V) в декабре 2025 года был запущен в серийное производство и установлен на автомобили, применяется в комбинированных фарах, атмосферной подсветке, комбинированных переключателях и других системах управления кузовом; IP, производство, сборка и тестирование полностью локализованы, число сотрудничающих клиентов превышает 15. По квалификации уже пройдены сертификации ISO 26262 ASIL-D процесс, ASIL-B продукт, AEC-Q100 и ASPICE. Продуктовая линейка: M200 планируется к запуску в производство в четвёртом квартале 2026 года (40 нм, комбинированная приборная панель / T-BOX / шлюз / BCM), M300 позиционируется как зональный контроллер, серия A100 — чипы питания и драйверов; перспективное направление воплощённого интеллекта — первый чип «управления мозжечком» E100 (архитектура RISC-V) находится в разработке, ещё не запущен в серийное производство. В мае 2026 года Zijing совместно с Great Wall Motor и другими создали центр инноваций индустрии RISC-V.

3.4 Espressif: esp-nn исправил проблему невыровненного доступа в ядрах RISC-V PIE

Дата: 2026-10-08　Источники: записи коммитов esp-nn (10-08)

Espressif esp-nn (библиотека операторов нейронных сетей) в рамках окна мониторинга влила пакет исправлений, связанных с RISC-V: ядра RISC-V PIE для max_pool включают невыровненное сохранение, на каждом входе в ядро устанавливается бит невыровненного доступа PIE (данное исправление направлено на проблемы, вызванные невыровненным сохранением на ESP32-P4), а также добавлены шесть тестов форм CONV_2D из GitHub issue #36, CI переключён на эмулятор esp-emu 0.46. На стороне esp-idf в рамках окна мониторинга 14 вливаний в основном касаются исправлений SPI / USB Host / энергопотребления (регулярное обслуживание); всего в организации Espressif в рамках окна мониторинга было выполнено push в 30 репозиториев.

Q8botOne от ZeroWire Robotics — открытый четвероногий робот размером с ладонь — вышел на этап предзапусковой подготовки краудфандинга (Crowd Supply): главный контроллер ESP32-C3-MINI-N4 (RISC-V), 8 интеллектуальных сервоприводов серии DYNAMIXEL XL, параллельная конструкция ног и беспроводная интегральная конструкция PCB без шлейфов, вес около 250 граммов, способен бегать рысью, прыгать и нести примерно вдвое больше собственного веса; аппаратное обеспечение (схемы Altium, Gerber, BOM, 3D CAD), прошивка и программное обеспечение управления на Python будут полностью открыты, в комплекте — предварительно спаренный беспроводной геймпад. По сравнению с решениями на PWM-сервоприводах того же размера, интеллектуальные сервоприводы поддерживают обратную связь по положению суставов и настройку PID, ориентированы на сценарии мейкеров и учебно-исследовательских задач.

5. Итоги и обзор тенденций

  • Двойная веха капитала и массового производства наступила в один день: SpacemiT (ESWIN Computing) сегодня провела листинг на Гонконгской бирже (цена размещения 1,55 гонконгского доллара, переподписка публичного предложения в 9,09 раза), а поставки автомобильных RISC-V чипов Zijing Semiconductor превысили десять миллионов штук — видимость RISC-V одновременно растёт как на рынке капитала, так и в серийном автомобильном производстве.
  • После праздников ядро и дистрибутивы восстановили полную скорость: поддержка устройств в upstream для SpacemiT K3/K1 завершается (планируется включение в Linux 7.4), RevyOS одним разом развернула более 20 коммитов конфигурации ядра (включая ESWIN EIC7700, linuxboot), openRuyi массово расширяет пакеты экосистемы Go.
  • Семейство XiangShan продвигается по двум линиям — симуляция и исправления: два бэкенд-исправления FEX0 официально приняты; NEMU в тот же день открыл сразу несколько PR (механизм контрольных точек, исправления SIP/RVV, управляемое наблюдение difftest), difftest поддерживает независимые тактовые сигналы ускорителя, накапливая силы для следующего раунда итераций микроархитектуры и верификации многодоменных тактовых сигналов.
  • Экосистема расширяется в обе стороны от проектирования: на левом конце Tenstorrent ускоряет разработку IP через сотрудничество по виртуальным платформам, Chipyard дополняет инфраструктуру PMU; на правом конце продолжают появляться end-side продукты (полётный контроллер дрона Upbeat, четвероногий робот Q8botOne), RISC-V последовательно закрепляется в системах реального времени, критичных для безопасности, и в робототехнических сценариях.
  • Требует наблюдения: показатели первого дня торгов SpacemiT; направление очереди ревью XiangShan #6652/#6653 и других; последующие коммиты репозитория Sipeed AE350 Linux; темпы компонентизации SpacemiT ai-gateway 0.2.0.
