一、内核与版本动态

1.1 玄铁 C908 BSP 合入：QEMU virt64 平台支持 RT-Thread Smart

日期：2026-08-28（12:25 北京时间合入）　来源：RT-Thread/rt-thread PR #11719

主仓库窗口内最重要一笔合入：feat[bsp][xuantie]: c908 support rt-smart。由 BadmintonMaster 代为提交（原始 commit 来自 shuta.lst 的 rt-thread fork），核心维护者 Rbb666 于 08-28 12:25（UTC 04:25）合入，共 27 个文件。内容：新增 bsp/xuantie/virt64/c908 板级支持包——基于 QEMU RISC-V64 VIRT 虚拟平台的平头哥玄铁 C908 处理器移植，支持 RT-Thread Smart 微内核模式（内核/用户态分离）与标准模式双构建，并配套根文件系统运行说明（link_smart.lds、run.sh）；同时为 SMP 适配对 libcpu/risc-v/common64/mmu.c 做了修改。工具链采用 Xuantie-900 GCC（musl 版，riscv64-unknown-linux-musl- 前缀）+ Xuantie QEMU 模拟器。这是 xuantie virt64 BSP 家族继 C910 等之后新增的 C908 支持，为 RISC-V 向量扩展内核在 RT-Thread Smart 高端应用场景下的开发验证提供了 QEMU 虚拟化入口，也是 libcpu RISC-V 公共层 SMP/MMU 适配的持续补强。

1.2 qemu-vexpress-a9 回溯支持函数名

日期：2026-08-28（11:29 北京时间合入）　来源：RT-Thread/rt-thread commit 0ae80cc7

社区开发者 Hui Su 提交：Cortex-A9 QEMU BSP 在开启 RT_BACKTRACE_FUNCTION_NAME 时，向编译器与汇编器传递 -mpoke-function-name，使内核回溯（backtrace）输出携带函数名，便于调试。改动集中在 bsp/qemu-vexpress-a9/SConstruct 单文件，属调试体验小改进。

二、官方与社区活动

2.1 直播预告：从 ADC 到 DMA，数据采集组件怎么设计？

日期：2026-08-28（刊出）　来源：电子工程专辑（原文 eet-china.com/mp/a520847.html）

电子工程专辑 08-28 刊出 RT-Thread 直播预告「从ADC到DMA，数据采集组件怎么设计？」。话题大纲：其一，为什么 ADC 不等于数据采集；其二，周期采样与 DMA 采样两条路径怎么选；其三，多通道交织帧——数据怎么组织才能兼顾吞吐与实时性。该直播是此前「睿擎平台 RK3506 多通道数据采集组件的设计与实践」（eet-china.com/mp/a520342）一文的延续，同一主题系列由工程实践走向直播教学，对应睿擎工业平台在工控数据采集方向的能力输出。原文站本机直连不可达，细节以搜索索引摘要与标题为准。

五、总结与趋势观察

  1. 玄铁 C908 补上 RT-Thread Smart 虚拟化验证入口：QEMU virt64 平台新增 C908 BSP，支持 RT-Thread Smart 微内核与根文件系统运行，并伴随 libcpu RISC-V 公共层 SMP/MMU 适配修改——RISC-V 应用处理器方向（rt-smart）在平头哥内核覆盖上再进一步，这是窗口内最具价值的主仓库合入。
  2. 官方新闻面第九日平静：新闻 API 无新增，睿擎 Workshop 会后报道缺位持续；媒体侧仅电子工程专辑「ADC 到 DMA 数据采集」直播预告一条。
  3. 睿擎平台内容输出转向直播教学：RK3506 多通道数据采集工程实践（08-22 前后刊文）之后，官方以直播形式展开 ADC/DMA 数据采集组件设计系列，工控数据采集方向是当前睿擎生态的对外主线之一。
  4. 社区 CANopen 安全能力缓慢生长：canopennode-rtt 从 LSS 配置走向 SRDO 安全对象字典与 CI/测试完善，CANopen 工业总线生态在 RT-Thread 侧以个人项目形式持续积累。
  5. 主仓库窗口内仅 2 笔合入：C908 rt-smart（新 BSP）+ qemu-vexpress-a9 回溯改进，整体处于特性间歇期，与昨日瑞萨 BSP 收尾节奏一致。
