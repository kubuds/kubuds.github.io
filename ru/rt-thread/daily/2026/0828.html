1.1 瑞萨 BSP：R7FA8M85 SDHI 卡检测触发合入

日期：2026-08-27（11:48 北京时间合入）　来源：RT-Thread/rt-thread commit 5abbbec4

主仓库窗口内唯一一笔新合入：[BSP][Renesas] Trigger SDHI card detection on R7FA8M85。由 CYFS 提交（author 时间 08-26 15:28 北京时间）、核心维护者 Rbb666 于 08-27 11:48（UTC 03:48）合入，改动集中在 bsp/renesas/libraries/HAL_Drivers/drivers/drv_sdhi.c 单文件。R7FA8M85 属瑞萨 RA8 系列，SDHI 即 SD 卡主机接口，本次修改在驱动层触发卡检测流程。这是继 08-27 上午瑞萨 SPI 两笔修复（09:01 合入）后当日第二批次瑞萨 BSP 动作，RA6W1 BSP 08-05 首版、08-11 二期补外设之后的”先合骨架、后补驱动”迭代序列延续至 RA8 系列外设收尾。

三、生态与厂商适配

3.1 packages 新增 MRamTrace 软件包：RAM 后端函数追踪与离线可视化

日期：2026-08-28（10:59 北京时间合入）　来源：RT-Thread/packages PR #2027 / Zepp-Hanzj/MRamTrace

软件包索引仓库今日 10:59 合入新包 MRamTrace（社区开发者 Zepp-Hanzj 提交，MIT 协议）：一款轻量级基于 RAM 的 MCU 函数追踪与离线可视化工具。原理：借 GCC/Clang -finstrument-functions 将函数进入/退出事件写入环形缓冲区，冻结后导出并结合 ELF 生成火焰图、调用图、Perfetto、Speedscope 等离线分析数据。特性：16 字节定长事件低开销、纯软件插桩不依赖 ETM/SWO、支持任务/中断/空闲多上下文，RT-Thread 移植利用 rt_thread_self() 免任务切换 hook。已在 STM32F407（lxb407zgt6）实测验证。这是 packages 生态在”嵌入式可观测性/性能分析”方向的新增能力，与此前 08-24 合入的 bmi270 六轴 IMU 驱动（含 Mahony AHRS 融合）同属近期社区软件包供给扩张序列。

3.2 ENV 工具合入插件后端服务与包更新安全加固

日期：2026-08-27（20:40 北京时间合入）　来源：RT-Thread/env PR #289

RT-Thread 命令行构建与包管理工具 ENV 合入 PR #289「Add plugin backend services and harden package update handling」，由创始人 BernardXiong 亲自提交并于 08-27 20:40 合入。内容分两条主线：其一，新增插件后端服务（plugin backend service）生命周期与服务运行器支持，扩展插件 manifest 校验与服务元数据，并经 WebUI host 暴露插件服务状态与控制；其二，包更新安全加固——保护 ENV 仓库在包更新过程中免受非预期 Git 配置改动、保留 Gitee 镜像预取与规范远端恢复、Git 命令改用显式工作目录，并新增 ENV 仓库保护与普通 Gitee 包远端回归测试（7 项测试通过）。ENV 工具走向”插件服务化 + 包管理安全加固”的信号明确，对国内开发者常用的 Gitee 镜像流程做了兼容性保护。

3.3 GD32 下游 BSP：DMA 相关修改合入

日期：2026-08-27（11:49 北京时间合入）　来源：GD32-MCU-IOT/gd32_rt-thread PR #68

兆易创新官方组织 GD32-MCU-IOT 维护的 RT-Thread 下游 BSP 仓库（gd32_rt-thread）合入 PR #68「Add DMA-related modifications」（junying2025 提交，5 个文件、+385/-358），对 GD32 系列 DMA 驱动做集中修改。该仓库以高频合入著称（本月已并入 F527_LVGL、L23x、470i-eval、305r-start 等多个系列/板卡支持），本次 DMA 修改属 GD32 BSP 驱动层打磨，为生态参考性质，标注”芯片原厂主导”。

4.1 客户成功案例：RT-Thread 赋能马来西亚本土 IoT 方案破解空气污染与洪涝难题

日期：2026-08-27（11:50 北京时间刊出）　来源：电子工程专辑（经 Google News） / 原文 eet-china.com/mp/a520546.html

电子工程专辑 08-27 刊出「客户成功案例丨RT-Thread赋能马来西亚本土IoT方案，破解城市空气污染与洪涝难题」：基于 RT-Thread 的马来西亚本土 IoT 方案通过实时监测与智能预警，帮助市政部门将洪涝应对从”事后抢险”转变为”事前数分钟预警”，并为污染源排查提供了精准的数据依据。该案例同时覆盖城市空气污染监测与洪涝预警两个市政场景，是 RT-Thread 面向东南亚城市级 IoT 部署的公开客户成功案例，佐证其在海外市政/环境监测领域形成真实落地。原文站（eet-china.com）本机不可达，正文细节以搜索摘要与标题为准。
