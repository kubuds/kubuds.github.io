一、内核与版本动态

1.1 memheap 双重释放防护合入：release 构建下重复 free 不再破坏堆账本

日期：2026-08-20（09:48 北京时间合入）　来源：RT-Thread/rt-thread commit 8234a36

主仓库窗口内唯一新合入：[kernel/memheap] fix: stop invalid frees from corrupting heap（作者 Hui Su，维护者 Rbb666 合入，commit 8234a36）。提交说明指出：当 RT_DEBUGING_ASSERT 关闭时，RT_ASSERT() 不再中断执行，release 构建中顺序发生的重复 free 会继续走到后续逻辑，从而破坏 memheap 的堆统计与空闲链表。修复在完成块校验后直接 return，使非法释放无法再更新堆账本。提交附带的复现数据（double-free：used=64 / alloc=224 / free=64 → 释放后 used 变为 4294959232，即 32 位溢出）直观展示了漏洞后果；修复经 scons -C bsp/qemu-vexpress-a9 构建验证。这是继 08-17 AF_UNIX 大功能合入后内核侧的防御性加固，属 release 构建健壮性修复。

四、行业应用专章（工业 / 机器人 / 具身智能）

4.1 睿擎平台 DSMC+FPGA 通信带宽提升至 90MB/s

日期：2026-08-19（18:15 北京时间）　来源：电子工程专辑（经 Google News 收录） / EET-China 原文

电子工程专辑刊发《睿擎平台 DSMC+FPGA 通信速度提升至 90MB/s》技术文（EET-China 原站不可达，正文经检索摘要核实）：睿擎平台（睿擎派 RK3506J 工业板 + 官方 FPGA 扩展板）DSMC 并行总线升级支持 16 位通信后，FPGA 实测通信带宽提升至 90MB/s。文章对比了升级前后驱动机制：同步机制由”无（同步阻塞）”改为 rt_event 事件驱动，单次传输量由 4 字节提升至 2KB（DMA 最大单次），并优化突发配置，CPU 占用显著下降。此为睿擎 26.08.06 版本特性（8 月 13 日版本发布直播预告口径为 89MB/s）的实测技术展开；硬件底座为 RK3506J（三核 Cortex-A7 + 单核 Cortex-M0，最高 1.5GHz）的 DSMC/Flexbus 并行总线（硬件带宽 400MB/s，直连 FPGA 高速数据采集）。该进展与 8 月 27 日上海 EtherCAT 实时控制 Workshop 同属睿擎工业平台的工控通信主线，方向为运动控制 + FPGA 数据采集的低延迟高带宽路径。

4.2 RT-Thread 入选 Beningo 2026 RTOS 性能报告参测名单

日期：2026-08-19（19:30 北京时间）　来源：电子工程专辑《2026年RTOS性能榜单出炉，PX5 RTOS拿下性能第一》 / Beningo 2026 RTOS Performance Report

电子工程专辑报道 Beningo（Embedded Group）2026 RTOS 性能报告发布：该报告为独立基准，在真实 Cortex-M 硬件上以 Eclipse Thread-Metric 套件测试 8 款 RTOS——PX5 5.3.1、ThreadX 6.5.1、FreeRTOS 11.3.0、Zephyr 4.4.1、Arm Keil RTX5 5.9.1、RT-Thread、NuttX、Micrium µC/OS-III。测试含 9 项原生 API 测试（基础处理、协作/抢占调度、内存分配、消息处理、同步、中断处理、中断抢占、中断延迟示波器实测等）及 POSIX API 对比。结果头条为 PX5 夺魁：ThreadX 最高慢 30.2%、FreeRTOS 最高慢 80.7%、Zephyr 最高慢 45.3%。RT-Thread 作为 8 款参测对象中唯一来自中国的开源 RTOS 入选，具体名次与明细需邮箱订阅免费下载报告；报告同比数据（2024 vs 2026）仅覆盖 FreeRTOS/ThreadX/Zephyr/PX5，RT-Thread 系本届新增参测对象。对社区而言，这是 RT-Thread 进入国际独立基准视野的外部验证信号，性能定位以报告正式内容为准。

五、总结与趋势观察

  1. 内核侧”消化期 + 防御加固”：AF_UNIX 套接字（08-17）之后窗口内首个合入是 memheap 双重释放防护（08-20），修复 release 构建（关闭断言）下重复 free 破坏堆账本的问题；大功能预计随下个版本发布。
  2. 睿擎工业平台成为本月媒体侧主线：DSMC 16 位总线升级 + rt_event 事件驱动 DMA 实现 FPGA 通信 90MB/s，紧接 8/27 EtherCAT Workshop 预热，工控实时控制方向连续输出。
  3. 国际基准曝光：RT-Thread 首次进入 Beningo 2026 RTOS 性能报告 8 款参测名单（唯一国产开源 RTOS），性能定位待报告全文公布。
  4. 生态活跃度由 GitHub 与第三方媒体承担：CANopenNode 集成包等第三方项目快速迭代，官方新闻 API 滞后约 2 个月的状况持续（最新仍为 06-17），官方信息出口亟待恢复。
  5. 局限性说明：EET-China 原站不可达，DSMC 与 RTOS 榜单两篇正文细节依赖检索摘要与报告官方页核实，RT-Thread 在性能报告中的具体名次未能取得。
