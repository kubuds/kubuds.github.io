一、内核与版本动态

1.1 玄铁 C908 平台 RISC-V 支持三连合入：rt-smart、MMU 与 SMP（09-15）

日期：2026-09-15 22:57（北京时间，合入时间）　来源：PR #11775

玄铁 C908 平台的三个提交在窗口内一并合入主线，合计 31 个文件、新增约 2575 行、删除 565 行。三项内容分别是：libcpu 的 MMU 框架补齐 SV39 / SV48 / SV57 地址模式支持并附带测试用例；参照 K230 与 Virt / C906 的既有实现，为 C908 增加 rt-smart 支持；为 C908 增加 SMP 支持，并针对副核拉起时机、TLB 刷新与 IPI 初始化做优化。验证平台为 BSP 目录下的 xiaohui C908（QEMU 仿真）。rt-smart 与 SMP 同时到位，意味着该核从能跑进入可做多核用户态验证的阶段。

1.2 env 工具链连发 v2.0.0 与 v2.0.2，命令行化重构落定（09-16）

日期：2026-09-16 09:48 / 09:51（北京时间，发布时间）　来源：env v2.0.0、env v2.0.2

RT-Thread env 工具链在窗口内连发两个版本，版本号从 1.5.x 直接跃迁至 2.0.0，两分钟后再补发 2.0.2 修正。这是自 2024 年 4 月 v1.5.2 以来的首次发布。主要变化包括：以 kconfiglib 重构配置系统并统一命令行入口，Windows 侧改为注册命令而不再依赖脚本；新增 sdk 命令与 e-build 嵌入式构建系统；引入 env.json 作为版本号、仓库地址与镜像信息的单一来源，代码中的硬编码地址改由访问层读取；默认安装不再捆绑 arm-none-eabi、gdb 与 qemu 工具链；安装脚本按网络位置自动选择镜像源。分发名调整为 rt-env。

1.3 SDIO 驱动注销与节点内存泄漏缺陷报告进入处理队列（09-15）

日期：2026-09-15 17:53（北京时间，最近更新）　来源：Issue #11801

窗口内一条设备驱动缺陷报告的讨论更新。报告指出 SDIO 驱动框架存在两处隐患：加载多个 SDIO 驱动后卸载其中一个时，链表遍历未在匹配成功后退出，局部指针可能被下一轮循环覆盖为空；已分配节点指针的释放被绑定在已匹配到卡的分支内，未匹配到卡时不会释放，存在内存泄漏风险。报告另建议用更安全的链表遍历宏替代现有写法。该议题标记为缺陷与驱动组件，状态为处理中，窗口内有三条讨论。

二、官方与社区活动

2.1 第九届全国大学生嵌入式芯片与系统设计竞赛：深技大斩获特等奖 RT-Thread杯（09-15）

日期：2026-09-15 14:34（北京时间，发布时间）　来源：南方都市报报道

第九届全国大学生嵌入式芯片与系统设计竞赛全国总决赛结果公布，深圳技术大学团队斩获特等奖 RT-Thread杯及全国一等奖 3 项、二等奖 4 项、三等奖 2 项。赛事由中国电子教育学会主办，15 家芯片企业联合命题，共 908 所院校、4.45 万名学生、1.7 万支队伍参赛，1227 支队伍晋级全国总决赛。获特等奖的作品为《基于 RT-Thread 的手势交互桌面氛围灯与植物养护一体化终端》，另有《基于 OpenHarmony 与 RISC-V 的智慧会议室系统》获全国一等奖。企业冠名奖项的出现，说明 RT-Thread 在高校赛道的投入已从提供开发板延伸到命题与评审环节。

2.2 社区论坛新增技术文章《MCU C 运行时库启动流程》（09-15）

日期：2026-09-15 17:04（北京时间，更新时间）　来源：社区论坛文章接口

社区论坛新增一篇技术文章，从 ARMv7-M 的复位行为讲起，逐层拆解向量表与 VTOR 的关系、.data 段从 Flash 到 RAM 的拷贝与 .bss 段清零，并讨论如何用嵌入式 C 运行时库标准化接管初始化流程。文章附有配套视频，属面向初学者的体系性讲解。论坛文章接口此前一期返回异常，本期恢复正常，后续重新纳入日常核查。

三、生态与厂商适配

3.1 STM32N657 Nucleo BSP 合入主线，八十三文件规模（09-16）

日期：2026-09-16 09:05（北京时间，合入时间）　来源：PR #11799

上期处于评审队列的 STM32N657 Nucleo BSP 提案于窗口内合入主线，规模 83 个文件、新增约 17884 行，评审人为 supperthomas 与 kurisaW。该提案 09-11 送审，09-14 曾单日四次强制推送修复持续集成问题，随后通过评审并合入。与之配套的 STM32N657xx FSBL 软件包索引已于 09-14 先行合入，STM32N6 系列在 BSP 与软件包两侧至此齐备。STM32N6 面向带神经处理单元的图形与视觉应用，这是该系列首次进入主线支持列表。

3.2 国民技术 N32H 三系列驱动扩展合入主线（09-16）

日期：2026-09-16 09:06（北京时间，合入时间）　来源：PR #11800

上期评审队列中的 N32H 三系列驱动扩展同样在窗口内合入主线，70 个文件、新增约 8096 行、删除 2778 行，覆盖 N32H47x 与 N32H48x、N32H49x、N32H7xx 三个系列及三块评估板。共用驱动层新增 ADC、DAC、I2C、SPI 配置头文件，并扩展 ADC、DAC、以太网、GPIO、硬件 I2C、NAND、QSPI、SDRAM、SPI、串口与看门狗等驱动分支；两块评估板另增 FEMC 时序表、以太网物理层复位与 USB 配置。三款新板卡同步加入持续集成编译矩阵。国产 MCU 原厂的驱动补齐仍是本季度主线合入的主要来源。

3.3 STM32 以太网驱动完成新版 HAL 接口迁移（09-15）

日期：2026-09-15 22:59（北京时间，合入时间）　来源：PR #11781

STM32 以太网驱动完成向新版硬件抽象层接口的迁移，8 个文件、新增 755 行、删除 968 行，已在 F4 与 H7 两个平台上验证。改动把分散的收发逻辑收敛到统一接口，为后续各 BSP 复用同一份以太网驱动打底。提交者为长期维护 STM32 移植层的开发者，属主线维护性改动。

3.4 驱动侧修复动态：GD32 串口引脚、Infineon PWM 宏与 STM32 链接问题（09-15 ~ 09-16）

日期：2026-09-15 21:50 ~ 2026-09-16 10:19（北京时间，提交与合入时间）　来源：PR #11802、PR #11803、PR #11804

窗口内有三条驱动修复类改动。已合入的一条（#11803）修正 STM32 直接存储器访问驱动中一个类型名函数的链接问题，改动仅一行，用于消除未启用日志组件时的编译告警。两条进入评审的改动分别是：GD32 各系列的串口收发引脚初始化修复，把发送脚配置为复用推挽、接收脚配置为上拉输入，并移除把两个引脚都配成通用推挽输出的错误别名，影响 GD32E50x、F10x、F20x、F30x 四个系列；以及 Infineon PSoC6 评估板的 PWM 宏错配修复，条件编译宏名与板级配置不一致，导致滑块示例中的 PWM 初始化代码被整段编译掉、示例始终找不到 PWM 设备，共 14 个文件。三条均为生态开发者提交的常态化修复。

五、总结与趋势观察

5.1 近三日趋势（09-13 ~ 09-16）

  • 内核侧架构能力补齐：玄铁 C908 的 rt-smart、MMU 与 SMP 三连合入是近期最具分量的内核改动，RISC-V 方向从单核裸跑走向多核用户态验证，与上周 RISC-V 惰性浮点与向量上下文切换议题属同一方向上的持续推进。
  • 工具链大版本落定：env 从 1.5.x 跃迁至 2.0.0 并即时补发 2.0.2，是 2024 年以来首次发布。命令行化、配置系统重构与镜像地址单源化会直接影响开发者的日常构建流程，升级前需关注兼容性说明。
  • 评审队列快速清空：上期报告列出的两个 BSP 提案在窗口内先后合入主线，从送审到合入约五至六天，说明持续集成与评审意见闭环效率稳定。
  • 厂商适配持续为合入主体：STMicroelectronics 与国民技术两家相关改动占据本期合入条目多数，国际大厂新系列与国产 MCU 并行推进。
  • 传播侧渠道迁移延续：官方新闻接口停更已满二十七日，与此同时高校竞赛与论坛技术文章成为品牌与技术的对外窗口，外部观察宜把竞赛信息与论坛接口纳入常规核查。
