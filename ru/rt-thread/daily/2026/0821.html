一、内核与版本动态

1.1 Rust 构建集成体系完善：跨组件构建配置修复并新增 STM32 CI 覆盖

日期：2026-08-21（11:17 北京时间合入）　来源：RT-Thread/rt-thread commit 30af7388

窗口内最值得关注的一条合入：[rust][tools] Fix Rust build example configuration handling。提交说明显示这是一次对 Rust 构建集成的系统性修复，覆盖 core、applications、components 与 module 示例四个层次：修复构建失败传播、target 与 feature 处理、链接标志传递、示例配置语义等问题，并为 STM32（stm32f407-rt-spark）新增 CI attach 覆盖。涉及 components/rust/ 下 Cargo.toml、SConscript、core 源码与中英文 README 等多个文件。结合 8 月中旬以来 rust 相关合入节奏，Rust 支持仍是 RT-Thread 工具链方向上的活跃投入点，本次提交把 Rust 示例的构建正确性纳入了 CI 保护。

1.2 libc timegm 月份溢出计算修复

日期：2026-08-21（09:44 北京时间合入）　来源：RT-Thread/rt-thread commit 339bffb7

[fix][libc] fix timegm month overflow calculation：修复 libc timegm 实现中月份溢出计算错误。timegm 用于将 struct tm 直接转换为 time_t（不经过本地时区），月份（tm_mon）出现越界值时计算结果错误，此修复修正溢出换算逻辑。属 libc 侧的时间处理健壮性修复。

1.3 dfs utimensat 路径缓冲区泄漏修复

日期：2026-08-20（18:30 北京时间合入）　来源：RT-Thread/rt-thread commit 7d1e5515

[dfs] Fix path buffer leaks in utimensat：修复 utimensat（设置文件时间戳的系统调用）实现中的路径缓冲区泄漏。dfs 层在路径解析路径上对已分配缓冲区缺少释放路径，本次补上。延续昨日 memheap 双重释放防护的”缺陷修复”主线，内核侧近两日以资源管理与时间处理的小型健壮性修复为主。

1.4 国民技术 N32H 系列 BSP 三期扩展：H47X/H49X/H7XX 驱动支持合入

日期：2026-08-20（17:32 北京时间合入，PR #11711）　来源：RT-Thread/rt-thread commit 9fce24b6 / PR #11711

[bsp][n32] add H47X/H49X/H7XX driver support（社区贡献者 OnlyoutzZ 提交），60 个文件变更，全部位于 bsp/n32/n32hxxx/libraries/N32_Drivers/drivers/config/ 下：新增 h47x_48x 与 h49x 的 CAN/UART 驱动配置，扩展 h7xx 的 ADC、CAN、DAC、I2C 硬件、LPTIM、脉冲编码器、PWM、SPI、TIM、UART 等外设配置。这是 N32H 系列 BSP 的第三期合入：07-22 首版（n32h760zil7-stb 修复完善 + 新增 n32h497zgl7-evb、n32h487zgl7-evb 板级支持）、08-12 二期（Nsing LCDC 与 SDRAM 驱动）、本次三期补齐 H47X/H49X/H7XX 外设驱动配置，符合厂商 BSP”先合骨架、后补驱动”的迭代模式，国民技术 H 系列（Cortex-M 高算力型号）在 RT-Thread 生态中的适配持续深化。

1.5 版本状态平稳

日期：2026-08-21　来源：rt-thread releases

最新正式版本仍为 v5.2.2（2025-10-31 发布），窗口内无新 release、无预发布。AF_UNIX（08-17）、memheap 加固（08-20）及今日多项修复预计随下个版本统一发布。

五、总结与趋势观察

  1. 内核侧”消化期”延续，Rust 方向最活跃：AF_UNIX（08-17）、memheap 加固（08-20）之后，窗口内 3 条合入中有 2 条为 libc/dfs 缺陷修复；最大动作是 Rust 构建集成系统化修复并纳入 STM32 CI 覆盖，Rust 支持投入节奏清晰。
  2. N32H 系列 BSP 三期扩展：国民技术生态由社区贡献者持续推动，H47X/H49X/H7XX 外设驱动配置补齐（60 文件），”先骨架后驱动”模式完整走完三期。
  3. 软件包质量基建升级：packages CI 新增 PR 阶段 Kconfig 校验，入库质量门槛前移；LiME-TM 新包快速打磨。
  4. 官方信息出口状态变化需关注：news/activity 分类接口由”空”变为”分类数据不存在”，rt_org 仍滞后 2 个月，8/27 Workshop 无官方渠道预热信息，官方公开信息能力持续偏弱。
  5. 版本节奏：v5.2.2 已维持 9 个多月，近期多项修复（AF_UNIX、memheap、libc、dfs、Rust 构建）累积，下个版本发布窗口值得关注。
