1. Динамика ядра и версий

1.1 В основном репозитории в окне влиты 4 PR: исправление прав MPU, utest PWM, CAN FD Renesas, освобождение ресурсов net/sal

Дата: 2026-09-01 (слияние 09:05-09:39 пекинское время)　Источник: PR #11760, PR #11751, PR #11754, PR #11769

После вчерашней партии совместимости с RT-Smart POSIX (PR #11732/#11733, 13 коммитов) сегодня утром в основной репозиторий влиты ещё 4 PR (плюс 1 коммит clang-format style), темп слияний в рабочий день восстановлен:

  • PR #11760 (09:05) [net][sal]: исправлена проблема неосвобождённого vnode DFS v2 при неудачном создании сокета, исправление утечки ресурсов;
  • PR #11751 (09:16) [bsp/renesas][drivers]: драйверы BSP Renesas поддерживают настраиваемую работу CAN FD, возможности периферии продолжают развиваться;
  • PR #11754 (09:33) [utest][pwm]: добавлен настраиваемый тест PWM matrix, а также исправлены проблемы очистки и тайм-аута матричного теста;
  • PR #11769 (09:39) fix[arm][cortex-m4]: уточнено выражение прав MPU, исправлена формулировка конфигурации прав MPU ядра cortex-M4.

В отличие от вчерашнего массового вливания, ориентированного на слой совместимости RT-Smart POSIX, эта партия сосредоточена на деталях надёжности ядра: права MPU ARM cortex-M4, освобождение ресурсов на пути отказа сетевого сокета, настраиваемость драйверов и покрытие тестами; крупных новых функций не вливалось.

2. Официальные и общественные мероприятия

2.1 Официальный новостной API двенадцатый день подряд без пополнений, на медиастороне в окне ноль новых записей

Дата: 2026-09-01　Источник: официальный новостной API RT-Thread

Официальный новостной API (категория rt_org) по-прежнему содержит 5 старых записей, самая свежая — всё ещё репортаж об инвестиционном форуме в Абу-Даби от 2026-06-17, двенадцатый день подряд без пополнений. Дополнительные проверки через gnews по нескольким группам (RT-Thread when:3d, RT-Thread 睿赛德 when:3d, 睿擎派 OR 睿擎 when:3d): англоязычные запросы дали только шум от разбиения “RT” вроде SCALR AI; китайскоязычные запросы дали анонс участия в выставке elexcon 2026, уже учтённый вчера (опубликован EE Times China 08-30); запрос по Ruiqing — пусто. На медиастороне в окне ноль новых записей, единственный недавний внешний сигнал — по-прежнему участие в шэньчжэньской выставке elexcon 2026 с 9 по 11 сентября (RT-Thread Ruiside покажет “полный набор” AI-аппаратного обеспечения).

3. Экосистема и адаптация производителей

3.1 packages: optparse дополнен записями версий v1.0.0 / v1.0.1, старый и новый интерфейсы сосуществуют по выбору

Дата: 2026-08-31 (слияние в 16:55)　Источник: RT-Thread/packages PR #2032

Вчера packages восстановил для пакета optparse запись версии v1.0.0, чтобы откатить ломающее изменение интерфейса (v1.0.0 — интерфейс с 2 параметрами). Сегодня PR #2032 дополнительно добавляет запись версии v1.0.1: оба тега указывают на коммит с интерфейсом из 3 параметров (07a365d), что отличает его от интерфейса v1.0.0 с 2 параметрами; пользователи могут выбирать соответствующую версию в индексе пакетов в зависимости от требований к интерфейсу. Управление совместимостью интерфейсов на уровне индекса вступает в стадию «сосуществования двух версий».

3.2 Экосистемная справка: непрерывная разработка интеграционного пакета CANopenNode от сообщества canopennode-rtt

Дата: 2026-08-31 ~ 09-01　Источник: github.com/wdfk-prog/canopennode-rtt (с сайтом документации wdfk-prog.space/canopennode-rtt/)

Репозиторий сообщества (создан 2026-06-30, язык C) нацелен на интеграцию в RT-Thread международно признанного открытого стека протоколов CANopen — CANopenNode; в последнее время коммиты активны: добавлена событийно-ориентированная диспетчеризация основной линии (09-01 08:54), поддержка времени высокого разрешения и приведение в порядок меню конфигурации kconfig во время выполнения, развязка словаря объектов по умолчанию и демонстрационного модуля (08-31), компиляция правил RX в грубый HDR-фильтр (08-30), генерация словаря объектов J09/B09S для SRDO и фикстуры диагностики MCU (08-29). Этот пакет в настоящее время независим от официального индекса packages (PR не отправлялся); стоит следить за тем, войдёт ли он впоследствии в официальную систему пакетов; сценарии промышленной/автомобильной связи CANopen заслуживают внимания.

3.3 Экосистемная справка: GigaDevice gd32_rt-thread включает драйверы периферии F503 и обновление BSP F207i

Дата: 2026-08-31 (слияние в 19:17 / 19:31)　Источник: GD32-MCU-IOT/gd32_rt-thread PR #58, PR #63

В официальном нижестоящем репозитории GigaDevice (gd32_rt-thread) в рамках окна инженерами производителя было включено два изменения адаптации BSP: PR #58 добавляет драйверы USART / I2C / SPI / DMA для gd32f503v-eval; PR #63 обновляет BSP gd32207i-eval и адаптирует драйверы серии F20x. Покрытие BSP, ведомое производителем чипов, продолжает расширяться (за последние две недели непрерывно включались адаптации, связанные с такими моделями, как 305R/407V/470Z/470i/L23x/F527 и другими).

4. Отраслевые применения

В рамках окна новых записей нет; тренды за последние три дня см. в резюме.

5. Резюме и наблюдения за трендами

  • Сторона ядра: ритм включений в основной репозиторий в рабочие дни восстановился; данный пакет в основном содержит исправления надёжности (права MPU cortex-M4, освобождение vnode в путях отказа сокетов net/sal, матричное тестирование PWM utest), конфигурируемость CAN FD в BSP Renesas продолжает эволюцию периферии.
  • Сторона экосистемы: управление сосуществованием двух версий — нового и старого интерфейсов optparse — в индексе пакетов реализовано; GigaDevice непрерывно адаптирует BSP; интеграционный пакет CANopenNode от сообщества (canopennode-rtt) активно разрабатывается, направление промышленной связи заслуживает отслеживания.
  • Официальная сторона: официальные медиа молчат 12 дней подряд; следующее внешнее окно — 9–11 сентября, Shenzhen elexcon 2026.
  • Тренд за последние три дня (08-30 ~ 09-01): пакет включений совместимости RT-Smart POSIX (08-30) → перевод ENV WebUI на TypeScript и исправления, аудиофреймворк agent (08-31) → пакет исправлений надёжности ядра (09-01). Основная линия — совершенствование слоя совместимости RT-Smart + модернизация официального инструментария + шлифовка деталей ядра; в дни с низким новостным потоком преобладает динамика репозиториев на GitHub.
