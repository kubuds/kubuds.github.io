一、内核与版本动态

1.1 小华半导体 HC32 系列 BSP 配置同步合入主线（09-16）

日期：2026-09-16 17:54（北京时间，合入时间）　来源：PR #11798

小华半导体 HC32 系列的配置同步提案在窗口内合入主线，规模 52 个文件、新增约 2844 行、删除 720 行，四个提交分别完成系列配置同步与工程文件重生成、代码格式化、头文件格式整理与串口中断驱动编译错误修复、rtconfig 回退与格式化忽略清单调整。具体改动包括删除电源管理配置中的唤醒定时器使能掩码、把名称长度上限调整为 24 并同步内核名称长度配置项。该提案 09-11 送审、09-14 完成最后一轮修订，评审到合入约五天。HC32 系列在近一周内已有驱动扩展与配置同步两批改动落地。

1.2 STM32 GCC 链接脚本容量校验修复合入，超容量固件问题关闭（09-17）

日期：2026-09-17 09:31（北京时间，合入时间）　来源：PR #11805、Issue #11124

STM32 各区链接脚本的容量校验缺陷在窗口内完成修复并合入，改动覆盖 110 个链接脚本，新增与删除各约 659 行。问题根因是部分脚本用初始化数据段指定加载地址，但未把该段关联到对应的只读存储区域，导致代码与常量本身没有超限、叠加初始化数据镜像后才超限时，链接仍会通过并产出超出配置容量的固件。修复参照意法半导体官方链接脚本的写法补齐区域归属。同源缺陷报告自今年 1 月提交以来一直处于未闭状态，本次随修复一并关闭。

1.3 SDIO 驱动注销内存泄漏修复提案提交，承接上期缺陷报告（09-17）

日期：2026-09-17 10:01（北京时间，提交时间）　来源：PR #11806

上期报告记录的 SDIO 驱动注销缺陷已收到修复提案，改动 1 个文件、新增 6 行、删除 4 行。原逻辑只有在找到匹配的 SDIO 卡时才释放驱动注册节点，设备上无卡或卡不匹配时节点不释放，反复注册与注销会造成内存泄漏。修复方案是确定待注销驱动后，无论当前是否存在匹配卡都从驱动链表移除并释放节点，仅在匹配到卡时继续调用驱动的移除回调，保持原有设备解绑流程不变。从缺陷报告到修复提案约两天，处置节奏偏快。

1.4 三笔小型修复进入评审：UART4 接收 DMA、块设备日志格式、持续集成依赖（09-17）

日期：2026-09-17 10:38 ~ 11:50（北京时间，提交时间）　来源：PR #11808、PR #11809、PR #11807

窗口末尾有三笔常态化修复进入评审。其一是为 STM32H7 通用 DMA 配置补充 UART4 接收侧定义，包含实例、请求、中断与时钟宏，此前启用 UART4 接收 DMA 会编译失败。其二是修正块设备分区组件的日志格式符与参数类型不匹配问题，在部分 32 位工具链下无符号整型对应长整型、方用短整型格式符会触发格式告警，改动只涉及输出语句不触及分区探测逻辑。其三是为 LLVM ARM 持续集成流程补装终端信息库依赖，修复该流水线近期的构建失败。

1.5 lwip 2.2.1 协议栈支持提案窗口内继续迭代（09-16）

日期：2026-09-16 18:39（北京时间，最近更新）　来源：PR #11797

网络协议栈版本推进提案在窗口内再次更新，规模仍为 1874 个文件、新增约 34.6 万行、删除 45 行，讨论数增至 4 条。该提案修复既有议题并引入 lwip 2.2.1 支持，验证平台为恩智浦 i.MX RT1180 评估板，开启以太网、套接字抽象层、网络设备与 lwip 组件。评审标签为组件，此前第三方内存比对工具判定未引入内存占用变化。若合入，主线网络栈基线将从 2.1.x 前进到 2.2.x，属网关与工业联网场景的常用链路，目前仍处评审迭代期。

社区论坛文章接口恢复后本期收录两篇当日技术文章。第一篇讲用子模块加稀疏检出管理固件仓库，把内核、厂商库、板级适配与业务代码的版本边界、工作区边界与构建边界分离开，主张只有具备独立生命周期与发布节奏的公共模块才值得拆成子模块。第二篇为一则实机缺陷分析：设备在每秒五到十千字节的并发吞吐下彻底掉线，定位为服务端压小接收窗口并发送结束报文时，套接字关闭返回进行中错误，而抽象层与上层组件仍按成功处理并释放句柄，最终导致底层套接字不可达、堆内存降至千字节级。作者用已有发送锁包裹关闭调用来规避，回归三十轮后资源回到基线。两篇均属社区自发产出，对长期运行设备有参考价值。

三、生态与厂商适配

3.1 Gino Pi BSP SDK 增加 JLink 调试链路，五十个工程一并补齐（09-16）

日期：2026-09-16 18:27 / 18:33（北京时间，提交时间）　来源：Studio BSP SDK 仓库

Gino Pi 板卡的 Studio BSP SDK 在窗口内新增 JLink 调试支持，两笔提交合计 50 个文件、新增约 2281 行、删除 20 行。做法是为每个示例工程生成 JLink 调试启动配置与调试器设置文件，并同步更新中英文说明与工程指南文档。此前该 SDK 的下载与调试链路只有 Studio 侧的 DAP-Link 与 MDK 侧的 CMSIS-DAP 两条，本次补齐第三种调试器，对使用 JLink 的工业与量产验证团队更友好。该 SDK 基于内核 5.3.0，含十六个外设与应用示例工程，板卡核心为 GD32H77D，属高性能图形交互与联网评估定位。

3.2 睿擎平台首发适配 Gino Pi：GD32H77D 开发板全链路开箱即用（09-16）

日期：2026-09-16 11:50（北京时间，发布时间）　来源：电子工程专辑聚合条目

据聚合源条目，睿擎平台首发适配 Gino Pi 开发板，强调 GD32H77D 平台全链路开箱即用。睿擎平台此前的板卡承载为瑞芯微 RK3506 与 RK3562 两条线，本次向微控制器级的高性能图形平台延伸，与其工业控制与边缘交互的定位互补；配套的板级支持包与示例工程已在 Studio 侧就位，调试链路也在同一窗口补齐 JLink。原文页面受站方访问限制未能取得，适配范围与功能清单以聚合摘要与 SDK 仓库公开资料交叉说明。
