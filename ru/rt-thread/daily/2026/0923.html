1. Динамика ядра и версий

1.1 В очереди рецензирования за одну ночь добавлено восемь предложений: серия усиления существующих дефектов из семи подряд, дополнение поддержки платы WCH CH32V203 (09-22)

Дата: 2026-09-22 18:03 ~ 18:31 (пекинское время, время предложений)　Источник: PR #11820, PR #11827

В окне мониторинга в очереди рецензирования за одну ночь добавлено восемь предложений (#11820 ~ #11827), это самая концентрированная партия коммитов за последнее время. Семь из них принадлежат одному и тому же контрибьютору и образуют группу системного усиления существующих дефектов: взаимное исключение двухлинейного последовательного контроллера шины и передачи (#11820, исправляет #11524), парное восстановление управления питанием по режиму приостановки устройства (#11821, исправляет #11046), граница количества интерфейсов USB-хоста (#11822, исправляет #11288), граница терминатора пути очереди сообщений IPC (#11823, исправляет #11292), чтение-запись за границами логического раздела блочного устройства (#11824, связано с #11286), граница приёмного буфера и кольцевой обход STM32 OpenAMP (#11825, исправляет #11299), проверка смещения ввода virtio (#11826, исправляет #10379, #10380). Все семь ссылаются на отчёты о существующих дефектах многомесячной давности и сопровождаются пояснениями по проверке сборки на хосте GCC 16.1 и граничных случаев, представляя собой концентрированную расчистку исторически накопленных проблем. Восьмое — поддержка платы QENHENG WCH CH32V203C8T6-EVT-R0 (#11827): эта модель представляет собой RISC-V микроконтроллер с ядром Qingke V4B (64KB Flash с нулевым ожиданием, 20KB SRAM), в основной ветке ранее не было соответствующего BSP; предложение дополняет каркас проекта, таблицу векторов D6, скрипт компоновки и пример сторожевого таймера, а также исправляет проблему официального пакета SDK, связанную с прямым выходом сборки для модели D6.

1.2 Официальный новостной API тридцать четвёртый день подряд без пополнений (09-23)

Дата: 2026-09-23 (время проверки)　Источник: официальный новостной API RT-Thread

Официальный новостной API (категория rt_org) по-прежнему содержит 5 старых записей, самая свежая — по-прежнему репортаж об инвестиционном форуме в Абу-Даби от 2026-06-17, тридцать четвёртый день подряд без пополнений; страница списка новостей официального сайта в окне мониторинга при проверке по-прежнему возвращает сообщение об ошибке загрузки, прямой просмотр невозможен. Основная ветка после концентрированной партии во второй половине дня понедельника (09-21) не имеет новых слияний, в окне также нет записей о закрытии или слиянии предложений; вся текущая активность сосредоточена в очереди рецензирования и репозиториях на стороне производителей.

3. Экосистема и адаптация производителей

3.1 Renesas RA8P1 Titan Mini оптимизирует проект OpenMV: настройка тактовой частоты SDRAM и пула памяти, время инференса значительно снижено (09-22)

Дата: 2026-09-22 16:09 / 16:36 (пекинское время, время коммитов)　Источники: коммит оптимизации производительности, коммит обновления данных о производительности

В организации Studio BSP репозиторий Renesas RA8P1 Titan Mini в течение окна мониторинга отправил два коммита по оптимизации проекта OpenMV. Первый корректирует тайминги и конфигурацию тактовой частоты внешней SDRAM (параметры ожидания обновления, делитель BCLKA), а также дополняет последовательность инициализации селектора SDCLK путём переопределения исходного кода, устраняя известные ограничения конфигурационного инструмента чипа; второй расширяет основной пул сборки мусора во внутренней SRAM с 1344 KiB до 1472 KiB, улучшая размещение памяти для рабочих областей больших моделей. Синхронно обновлённые с коммитами измеренные показатели производительности: одиночный инференс Tiny YOLOv2 INT8 416×416 снизился с 156,10 мс до 58,49 мс (примерно в 2,7 раза), YOLOv8n 256×256 — с 186,54 мс до 38,33 мс (примерно в 4,9 раза), 320×320 — с 310,29 мс до 287,49 мс. Данный проект лишь 09-18 дополнил цепочку релизов OpenMV и непрерывную интеграцию, а текущий выпуск является финальной оптимизацией производительности после релиза; EE Times China в тот же день опубликовало последующий репортаж («1 GHz MCU + NPU, играем на Python! Обновление OpenMV для Titan Mini»), доступ к оригинальному сайту ограничен, ссылка — в приложении.

3.2 Выпуск GDR 2026.03: фреймворк ассистента отладки RT-Thread дополнен объектными командами и справочной системой (09-22)

Дата: 2026-09-22 (время релиза)　Источник: GDR 2026.03

Сторонний фреймворк ассистента отладки GDB — GDR — в течение окна мониторинга выпустил версию 2026.03. Фреймворк работает внутри интерпретатора Python в GDB и обеспечивает трёхуровневую поддержку отладки прошивок RT-Thread и FreeRTOS: собственные деревья команд каждой RTOS (например, просмотр потоков, таймеров, кучи), средства красивого вывода объектов ядра и вспомогательные функции (доступ к полям объектов через нативные выражения GDB). Новая версия добавляет для стороны RT-Thread сводную команду объектов rtt objects и унифицирует вывод кучи и объектов в нейтральном рендерере; справочная система обновлена до структурированного дерева команд в стиле git с пояснениями по каждому пункту полей, использования, зависимостей конфигурации и ограничений реализации; также исправлена проблема, когда сбой проверки стратегии инициализации напрямую завершал сессию GDB. Фреймворк в настоящее время поддерживает RT-Thread 3.1.x / 4.0.x / 4.1.x, цели Cortex-A9 и RV64 уже прошли замкнутую проверку, и он является активным проектом в сторонней цепочке инструментов отладки RT-Thread.

3.3 Ветка обновления драйверов нижестоящего репозитория GD32 продвигается: PR #71 обновлён и вступает в рецензионное взаимодействие (09-22)

Дата: 2026-09-22 13:37 (пекинское время, время отправки)　Источник: PR #71

В нижестоящем репозитории gd32_rt-thread компании GigaDevice ветка update_driver в течение окна мониторинга отправила коммит обновления драйверов, синхронно обновив находящийся на рецензии PR #71, на стороне репозитория появилось взаимодействие в виде комментариев рецензии. Данное предложение касается обновления версий инициализации GPIO для драйверов USART, SPI и двухпроводной последовательной шины, выполняет замену и упорядочивание старых файлов драйверов и относится к непрерывной работе поддерживаемой производителем ветки, ещё не вернувшейся в основную линию. В репозитории того же направления Zephyr также были отправки, но это не тема данного раздела.

  • Основная линия молчит, рецензирование сконцентрировано за одну ночь: после концентрированного пакета во второй половине дня понедельника (09-21) основная линия два дня подряд не принимала коммитов, а очередь рецензирования за одну ночь пополнилась восемью предложениями, что редкость в последнее время; семь из них образуют системное усиление границ для унаследованных проблем (все с пояснениями по верификации и ссылками на отчёты о существующих дефектах), одно добавляет поддержку платы Qinheng CH32V203 (RISC-V).
