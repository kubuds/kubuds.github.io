一、内核与版本动态

1.1 进行中：CAN 框架重构 PR #11779 进入评审讨论，维护者表态不另建 CAN_V2

日期：2026-09-03（评审讨论集中日；线程自 09-02 延续）　来源：PR #11779

昨日收录的 Generic CAN 框架结构性重构 PR（wdfk-prog 提交，2 commits、+2902/-1308）窗口内进入实质评审：维护者 CYFS3 于 09-02 22:10 提问”其他 BSP 是否也需要重新适配 can”，作者 09-03 08:26 回应称无需——STM32 bxCAN 改动仅为支持 RT_CAN_CMD_ABORT_TX，其余属 CI 格式化与优化，框架设计已做兼容处理；09-03 16:39 评审给出 “Request changes” 意见，要点是当前实现改变了 Generic CAN 与全部 BSP 间的运行时契约，却只迁移了 STM32 bxCAN，暂不满足”其他 BSP 无需适配”的兼容性承诺；随后 17:47 CYFS3 明确表态：不建议另行维护一套 CAN_V2 框架（维护成本过高），希望感兴趣的开发者共同参与推动本 PR 合入。当前评论 8 条、PR 仍 open，合入策略尚在协商，但重构方向本身未受质疑，获得维护者背书。

日期：2026-09-04　来源：org:RT-Thread 仓库列表（commits / pulls 接口）

二、官方与社区活动

2.1 睿赛德公布 2026 上海开源软件应用创新大赛命题：面向工业质检 AI 的睿擎平台工具链

日期：2026-09-03　来源：OSChina 资讯（报名入口 oschina.net/os2026）

睿赛德在「2026 上海开源软件应用创新大赛」AI+工业软件赛道提出命题《基于睿擎工业开发平台的预训练视觉模型轻量化适配与低代码部署优化》。命题切中工业质检部署”最后一公里”：睿擎工业平台自带高实时性工业内核与 NCNN 推理框架（原生支持 YOLOv3 通用目标检测），但缺现场数据采集与样本标注能力、不支持导入自定义工业预训练模型、部署依赖手写代码。赛题要求在不改造平台实时内核前提下，轻量化补齐四段工具链——数据采集与规整、缺陷样本在线标注、自定义模型量化与算子兼容适配、低代码一键部署，交付可运行 Demo，按工具完整性/平台适配性/模型优化效果/易用性四维评审。报名截止 10 月 11 日，总决赛 10 月 24 日在上海举办，获奖项目瓜分 100 万元奖池（现金、Token、大模型 API 等），并有机会入选上海市开源项目培优工程。这是官方新闻静默期内少有的实质对外动作，反映睿赛德借区域开源大赛推动睿擎工业平台生态与开发者招募。

topic:rt-thread 生态仓库 canopennode-rtt 默认分支窗口内新增两笔 CiA402（DS402 运动控制 profile）提交：09-03 11:25「add multi-axis device profile support」（多轴设备 profile 支持，9c8da59）、09-04 09:41「add PP PV and homing mode support」（Profile Position / Profile Velocity 定位与速度模式及回零模式，7f143ec）。与此前事件驱动主线调度（09-01）、LSS 运行时波特率激活（08-27）衔接，昨日观测的 ds402/A04 特性分支演进已汇入主线，运动控制功能面从单轴扩展至多轴与典型定位/速度/回零模式。该仓库作者同时在主仓库推进 CAN 框架重构（见 1.1），”应用层（CANopenNode 软件包扩展）→ 框架层（Generic CAN 重构）”双线并进，CAN 仍是当前社区最活跃的推进主线。
