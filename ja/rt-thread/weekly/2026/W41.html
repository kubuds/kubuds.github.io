2026-10-07 Kubuds

報告期間：2026 年 9 月 30 日（水）から 10 月 7 日（水）までの計 8 日間；国慶節休暇特別集計期間（10 月 1 日から 7 日は休暇のため、デイリーレポートは休止） 素材ソース：本誌の毎日 RT-Thread 動向デイリーレポート（2026-09-30 の 1 回分、調査期間 09-29 11:00 ~ 09-30 11:00；10-01 ~ 10-07 は休暇中のためデイリーレポート素材なし）；ほかに休暇期間中の組織的調査（メインリポジトリのコミット / PR / Issue / Releases、env、ソフトウェアパッケージインデックス、Studio とデバイスパッケージ組織、ベンダーダウンストリーム、topic 検索）、公式ニュースインターフェースとコミュニティフォーラムのスキャン、メディアおよびアグリゲーションチャネルの再確認（10-08 朝までをカバー）を含む 編集説明：本期間は国慶節休暇をまたぐ――コードのマージは休暇中の低生産モードに入り、レビュー検証、ソフトウェアパッケージの準備、コミュニティ運営は稼働を維持した；すべての技術的事実はコードリポジトリ、リリース記録、コミュニティチャネルの実測確認による

1. 今週の主要ニュース

  • Next RISC-V 大規模リファクタリング、休暇中も複数プラットフォームで実測継続、創設者がフォローアップを推進（09-30 ~ 10-08）：5 月下旬に作成され、長期にわたり審査中のメインリポジトリの RISC-V アーキテクチャリファクタリング提案（#10320）が、休暇中に「実測駆動」段階へ――コミュニティのテスターは玄鉄 virt64/c906、qemu-virt64-riscv（RV64 クアッドコア）、玄鉄 smartl/e907、全志 D1/D1s の 4 種類のプラットフォームを巡って段階的に検証した：まず qemu-virt64 のデフォルト AIA 設定が PCI で停止し NVMe がタイムアウト（10-02 にフィードバック、同日夜に修正）、10-03 の再テストではデフォルト設定で連続 3 回 msh に進入し、NVMe も正常だった；その後、RV64 標準版で ABI 環境変数が未設定時のフォールバック問題を修正（FPU に応じて lp64d を自動選択、10-03）；e907 と D1/D1s の適応パッチが相次いで提供され、パッチ適用とビルド検証を完了（D1/D1s は開発ボードがなく、実機書き込みは未実施。作者は 10-07 にボード提供の協力を要請）。創設者の Bernard Xiong は 10-03 にコメントでいいねし、今後ステータスリストを整理するよう求めた；提案は 10-08 朝に lwIP マージを含む最新メインライン（head e7b6e13f0）へリベースされ、期間内に新規コメント 42 件（ボットチェックを含む）が追加され、現在のステータスは依然としてオープンなレビュー中。提案は現在 164 ファイル、+15164/-2611。

  • lwIP 2.2.1 がメインラインにマージ（10-03）――休暇中唯一のマージ：メインリポジトリの PR #11797 が創設者によりマージされた：lwIP 2.2.1 をオプション版として追加（1.4.1 / 2.0.3 / 2.1.2 と共存、既存プロジェクトの切り替えを強制しない）、4 コミット、402 ファイル、+162255/-45；元のソースツリーをインポートし、ドキュメントファイルを整理して sio_write のシグネチャ競合を修正；検証プラットフォームは NXP i.MXRT1180 評価ボード（m7 コア）；対応する要件 #11588（2026-07-08 提出）は同日クローズ。これまで複数週にわたりレビュー待ち行列に滞留していた「ネットワークプロトコルスタックのアップグレード」が本期間に完了した。

  • コミュニティ運営は「イベントと募集」へ集約：工博会 Workshop 募集、Edgi-X チャレンジ、組込みコンテスト作品（10-05 ~ 10-08）：工博会 RT-Thread Workshop（10 月 13 日上海特別会場）は 10-05 に募集を開始し、多品種のスマート端末実機展示を予告；RT-Thread は英飛凌および FMT と共同で「Edgi-X 全域載具適配挑戰賽」を発表（10-08 公告、英飛凌 PSoC-E83 異構デュアルコアをベースとした自動運転計器プラットフォーム、載具タイプ不問）；2026 組込みコンテスト作品スレッドが期間末に密集して出現（スマートラボ管理端末、GD32H759 BLDC モーター制御、Edgi-Talk LVGL ガイドなど）。

2. カーネルとバージョン動向

バージョンとメインライン

  • 新バージョンリリースなし：最新正式版は依然 09-10 リリースの v5.3.0；全期間で新規 Release とタグなし、リリース後の消化期間中。
  • マージペース：休日期間のマージは 10-03 の 1 件のみ（4 コミット、いずれも lwIP 2.2.1）；09-30 ~ 10-02 および 10-04 ~ 10-07 はメインラインが完全に静黙、ここ数ヶ月で最も緩やかなペース。
  • ツールチェーンと付帯（Env）：10-03 ~ 10-04 に WebUI とプラグイン開発ワークフロー強化のマージを完了（PR #299、11 コミット、10-04 21:25 マージ）——WebUI 4 種界面（プロジェクトホーム、ビルド、ドキュメント、ネットワーク設定）、epack テストとマーケットプレイス公開フロー、プラグインアイコンとネットワークポリシー、コマンド終了コード配信と venv 依存説明、VS Code ブリッジ；開発ツールは可視化とプラグイン化のイテレーションへ。

3. エコシステムとベンダー適配

ベンダー BSP

  • ST 系小容量とボードレベル外設の推進：blue-pill の STM32F103C6（32KB Flash / 10KB RAM）サポート提案（#11850）と付随需要（#11854、10-07）が起票；STM32H723-DM-MC02 の SPI6 BDMA サポート提案（#11851、10-03）は WS2812 BDMA バッファの SRAM4 配置と GCC / IAR / MDK5 リンクスクリプトの同期を含む。
  • 楽鑫系の継続的打磨：ESP32-C3 と ESP32-S3-DevKitM-1 提案が休暇中にリフレッシュ（#11816 / #11847 / #11844）；ソフトウェアパッケージ側では別途 C6 パッケージバージョン提案あり（下記参照）。
  • RISC-V ボードレベルとアーキテクチャ適配：玄鉄 C906 / C907 / E907 と全志 D1 / D1s の適配検証が休暇を通じて実施（#10320 関連）；qemu-virt64-riscv の C-only Picolibc ビルドオプション提案（#11849）が起票——RISC-V プラットフォームは「ボードレベルサポート」と「ビルドシステム」の二層で同時に推進。
  • ベンダーダウンストリームとデバイスパッケージ：GD32 ダウンストリームリポジトリ（gd32_rt-thread）の最新マージは依然として 09-28（PR #71）；デバイスサポートパッケージ組織は調査期間内にプッシュなし（最新は 09-23 の gd32-arm-series）。

ソフトウェアパッケージとミドルウェア

  • ms-probe 入库準備（公式ツール）：ツールリポジトリ（Real-Thread/ms-probe）は 10-07 に「独立パッケージング」準備を完了——Microscope 組み込み診断の導入、独立 RT-Thread パッケージメタデータとチェックの追加、インデックス統合準備と VExpress A9 テストの完了、standalone パッケージング PR #1 のマージ；インデックス側は feature/ms-probe-package ブランチと PR #2044 で推進。位置づけは故障現場診断 Probe：デバイス側でコンテキストをエクスポート、ホスト側で現場とホワイトリストメモリを解析；GPL-2.0 と商業のデュアルライセンス。

  • インデックス幹にマージなし：ソフトウェアパッケージインデックスメインブランチは休暇中平静（最近のマージは 09-24）；キューには他に複数の審査待ち提案あり（litetype、CmBacktrace バージョンと設定、DS1307 RTC、ADS1146、HSM 状態機械、am2320 など）。
  • ミドルウェア：lwIP 2.2.1（第 2 章参照）；他コンポーネントのマージなし。

4. 公式とコミュニティ活動

  • Edgi-X 全領域ビークル適配チャレンジが正式に開始（10-08）：RT-Thread が英飛凌と FMT と共同で発起——Edgi-X は三者共同で作り上げたプロフェッショナル級の自動運転用ハードウェア（英飛凌 PSoC-E83、Cortex-M55 + M33 異種混在デュアルコア）であり、ビークルの種類を問わない（マルチローター、固定翼、無人船、ホイール式小型車、車輪付き脚型ロボットなど）。開発者が自らのビークルで適配と実際の機能の動作完了に挑戦することを歓迎する。賞金が用意され、完走者にはハードウェアが贈呈される。エンジニア、ロボット開発者、大学ラボ、メイカーチームを対象とする。
  • 工博会展 RT-Thread Workshop の募集開始（10-05）：第 26 回中国国際工業博覧会（10 月 12 日～16 日、国家会展中心（上海））にて RT-Thread Workshop の募集を開始（10 月 13 日専用回）。募集告知では、現場でロボット、ドローン、産業制御機器、ボードなどの多品種スマート端末の実物を集中的に展示することを予告している。
  • 2026 RT-Thread 組込みコンテストの作品投稿が密集（10-06 ～ 10-08）：スマートラボ管理端末（ArtInChip D12x + RT-Thread 4.1.1 + LVGL v9、PC 中継および Bluetooth ドアロック制御を含む）。GD32H759I-EVAL + RT-Thread Nano による BLDC モーター制御（ホール六步換相、六路相補 PWM、上位機による波形モニタリング）。Edgi-Talk LVGL 横画面表示設定ガイド。
  • フォーラムとコミュニティの内容：技術スレッド「MCU リンカスクリプト『アップグレード』」が 10-08 未明に更新。FH8626V300L 開発ボード試用レポート（双路常電モードとサーボ PWM テスト、10-05）。Gino Pi 販売スレッドは休暇中も更新を維持（10-01）。
  • メディアチャネル：電子工程専輯が「クラウドから端末まで、自ら AI カーを一台作ろう！工博会展 RT-Thread Workshop 募集開始」を発表（10-05）。またコミュニティ技術分享「睿擎 RC3506 ベースの多チャネル ADC 収集装置」を掲載（09-30、収集拡張ボード、表示とネットワーク接続の移植要点を含む）。
  • 公式チャネル：公式ニュースインターフェースと公式サイトの確認状態は要聞第 7 条を参照。公開アグリゲーションチャネルでは休暇中に他に有効な報道は見られなかった。

5. 業界応用と商業動向

  • K230 と RT-Thread Smart の消防プロトタイプが継続的に反復（09-30 ～ 10-01）：厨房火炎検出、マルチセンサフュージョン、適応型連動の研究プロトタイプ（SRTP-K230-Fire-Guardian）が休暇中に連続 6 件のコミットを実施し、KEY1 / KEY2 パネルの順序デバッグとボード側の検収記録を推進。
  • RV1103 シングルチップドローンプロトタイプのハードウェア設計が密集的に反復（10-01 ～ 10-06）：Linux と RISC-V MCU フライトコントロールループプロトタイプ（Luckfox Pico Mini B）に LTE + GNSS スタックボード（LFX_LTE_R1）、50×50 シングルボードフライトコントロール（LFX_FC_R2）、機体適合ボード（LFX_MOUNT_R1）、1503 モーター機体（LFX_FRAME_R1）を追加し、GPS ポート（ATGM336H クラスモジュール）とリモートコントロール / グラウンドステーションの章を補足。
  • 産業ロボット通信ゲートウェイの工程カーネルが公開（10-02 ～ 10-03）：コミュニティが Modbus RTU/TCP インターフェース、CANopen メッセージ処理、固定長メモリプール、キューと優先度継承などの RT-Thread 統合要点を含むゲートウェイ開発記録を公開（CI リリース検証を含む）。
  • 商用着地：本期間（休暇）に新規の量産、商用または提携着地の報道はなし。産業側の直近の節点は連休後 10 月 13 日の工博会展 Workshop と Edgi-X チャレンジ。

6. トレンド観察

  • 休暇中は「低マージ、高検証」の形態：全期間でマージはわずか 1 件だが、#10320 のマルチプラットフォーム実測、2 箇所の修正と CI リフレッシュが全期を通じて続き、コード側は「検証とレビュー」を主軸に運転。
  • RISC-V アーキテクチャ再構築が実測駆動段階へ：検証マトリックスは玄鉄 C906/C907、QEMU virt64 から E907 と全志 D1/D1s へ拡張され、「コードレビュー」から「マルチプラットフォームでの動作完了」へ推進。実機ボードが次のボトルネックに（D1/D1s は既にボード支援による検証を要請）。
  • ネットワークコンポーネントと開発ツールの二本柱が着地：lwIP 2.2.1 が「オプション項目として並存」する形でマージされ、Env は WebUI とプラグインワークフローで開発体験を強化——それぞれ「コンポーネントの現代化」と「ツールの可視化」という二つの進化ラインを指し、いずれも既存プロジェクトを破壊しないことを前提とする。
  • ソフトウェアパッケージエコシステムは「公式ツールの参入」と「無線チップサポート」が準備の重点：ms-probe がインデックス登録前の最後の一里の準備を完了、ESP32-C6 パッケージバージョン提案が再登場——休暇はインデックス側の準備期間。
  • コミュニティ運営が 10 月中旬の節点へ収束：工博会展 Workshop（10-13）、Edgi-X チャレンジ、組込みコンテスト作品の密集公開、連休後 2 週間が運営と展示のピーク。
  • 公式チャネルの沈黙が深化：ニュースインターフェースの停止が第 49 日に入り（全期間ゼロ更新）、対外情報はさらにフォーラム、メディア、商城チャネルに依存し、コード側の継続的運転と対照をなす。
