モータ制御と端末側 AI

日付：2026-10-30 ~ 2026-11-04　情報源：リポジトリ：NS800RT7P65D FOC と CANopen

  • デュアル Cortex-M7 の 20 kHz センサレス FOC：納芯微 NS800RT7P65D を2つの論理 CPU に分割している。一方は 20 kHz の ADC サンプリングと PWM を実行し、センサレス FOC、滑模観測器、PLL 推定を行い、ハードウェアシャットオフを備える。もう一方は UART と FinSH、CANopenNode v4.1 と CiA 402 ブリッジ、CAN 送受信を実行する。コア間は非同期コマンドメールボックスと6フィールド・24バイトの一貫性スナップショットのみを経由し、共有メモリの無秩序な読み取りは行わない。基盤は RT-Thread 5.3.1 の SMP 設定である。これは今週最も量産形態に近いコンテスト作品である。
