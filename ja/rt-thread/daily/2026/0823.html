1. カーネルとバージョン動向

1.1 メインリポジトリは期間内に新規マージなし、v5.2.2 は安定

日付：2026-08-23　出典：RT-Thread/rt-thread commits / releases

rt-thread メインリポジトリの最後のマージは 08-21 17:45 の NXP RT1180 BSP 機能更新（昨日詳細報告済み）で、本期間終了時点まで新規 commit はなし。ソフトウェアパッケージインデックスリポジトリ packages の最後の push も 08-21 09:24 で停止している。最新の正式バージョンは依然 v5.2.2（2025-10-31 リリース）で、期間内に新規 release もプレリリースもなし。開発は昨日の大型マージ後の静かな整理期間に入っており、直近に蓄積された修正（Rust ビルド、IPC 競合、libc/dfs、複数ベンダー BSP）は次期バージョンで一括リリースされる見込み。

3. エコシステムとベンダー対応

3.1 GDR デバッグフレームワークが 2026.02 をリリース、qemu テストスクリプトを強化

日付：2026-08-22（12:10 ~ 17:03 北京時間）　出典：flespark/gdr release 2026.02 / commits

サードパーティ製 RT-Thread GDB デバッグ補助フレームワーク flespark/gdr が 2026.02 マイルストーンバージョンをリリース（release tag 2026.02、08-22 17:03 リリース、前バージョン 2026.01 は 07-29）。さらに qemu 自動テスト基盤を継続的に整備：デフォルト fixture キャッシュディレクトリを更新（12:10）、バージョン番号を 2026.2 に bump（16:33）、qemu テストスクリプトに fixture キャッシュ再利用とエクスポートオプションを追加（17:00）および <rtos>/<target>/<version> 進捗ログ（17:02）。このフレームワークは 08-19 に rtthread heap detail コマンドを追加、08-21 に三連続更新（オブジェクトコンテナ互換、heap 情報のメモリ走査への fallback、出力フォーマット更新）。今回は初の月内バージョン化リリース＋テスト基盤整備であり、RT-Thread/rt-smart GDB デバッグシーン向けツールチェーンがバージョン管理段階に入ったことを示す。
