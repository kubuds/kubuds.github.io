1. カーネルとバージョン動向

1.1 休暇後の開発再開：メインリポジトリで同日午後に集中的に4件の新規提案が提出される（10-08）

日付：2026-10-08 12:51 ~ 17:23（北京時間、作成時間）　出典：PR #11855、PR #11856、PR #11857、PR #11858

休暇後初の開発日の午後、コミュニティはメインリポジトリに集中的に4件の修正提案を提出し、いずれもテスト説明が付属しレビュー中：其一（#11855、12:51、単一ファイル +3/-0）はリセットコンポーネントとログコンポーネントの同時有効化時のビルドエラーを修正——ログ互換マクロがassertを無条件にASSERTと定義し、リセットコントローラ構造体内の同名メンバがマクロ展開されてコンパイル失敗となる問題で、対策は使用箇所で当該マクロを無効化する；其二（#11856、15:36、単一ファイル +40/-4）はC++グローバルコンストラクタの欠落を修正——新版GCCはC++グローバルコンストラクタを.init_arrayに移動させるが、システム初期化は旧構築区間のみを走査するため、対策は.init_array区間を追加実行し重複排除を行い、シミュレータプラットフォームでビルド検証済み（関連要望 #11778）；其三（#11857、16:32、2コミット、単一ファイル +64/-41）は色付きログのリセット順序を調整し、色制御コードが次の行に落ちてshellプロンプトの配色が乱れるのを回避（関連要望 #11296）；其四（#11858、17:23、単一ファイル +63/-33）はDHCPサーバオプション解析にバッファ境界チェックを追加し、不正パケットの境界外読み取りリスクを修正（関連要望 #11323）。4件のうち3件は同一の休暇前活発コントリビュータ（最近ESP32-C6、CH32V003などのBSPマージ記録あり）によるもので、当日はすべてフォーマットとメモリ比較パイプラインがトリガーされた。

1.2 レビューキュー観察：古い提案の再確認によりメインラインに同種の修正が既に含まれることが確認される（10-08）

日付：2026-10-08 14:22（北京時間、再確認コメント）　出典：PR #11499

メインリポジトリは期間内に新規マージなし（メインラインの最終マージは依然として10-03 12:59のネットワークプロトコルスタック）。既存提案には2点の動き：6月に提出されたカーネル同期リンクリストログ保護提案（#11499）について著者が再確認し、競合は上流コミット（タイムアウト起床帰属修正）が同一箇所に空ポインタ判断を既に補完していることに起因し、メインラインに当該修正が既に含まれていると指摘、提案の今後の処置はメンテナの評価待ち；DHCPパケットヘッダファイル補完提案（#11835）は自動メモリ比較再チェックを1回トリガーしたが、実質的な進展なし。また、RISC-V大規模リファクタリング提案（#10320）は期間内に新規コメントなし、最近の動きは依然として10-08午前のリベース更新（休暇ウィークリーレポートに既出）。

2. 公式・コミュニティ活動

2.1 〖2026組込みコンテスト〗煙火災警報監視システム作品公開（10-08）

日付：2026-10-08 17:21（公開時間）　情報源：フォーラム記事 0e815ddfc029ea9c

2026組込みコンテストの調査期間内に、さらに完全な作品が一つ追加された。NXP FRDM-MCXA346 とカーネル 5.2.2 をベースとした煙火災警報監視システムである。システムは MQ-2 で煙濃度（ADC）、DHT22 で温湿度（シングルバス）を収集し、OLED 三ページ表示切替、ブザーとリレーの連動、長押し消音、ヒステリシス閾値によるチャタリング防止と自動復帰を実現し、複数の MSH デバッグコマンドと PC 側ダッシュボード（リアルタイム曲線、CSV 記録、リモートテスト制御）を提供する。方案はハードウェア抽象化、業務、表示の三層構造とアラーム状態機械設計を採用し、開発環境は Keil MDK-ARM である。本スレッドは連休終盤以降のコンテスト作品の集中的な公開のリズムを継続している——同期間には既にスマートラボ管理端末、GD32H759 モーター制御、Edgi-Talk 表示設定ガイドなどの作品がある（休暇ウィークリーレポートに収録済み）。

3. エコシステムとメーカー対応

3.1 env ツール #300 をマージ：オフライン SDK ソフトウェアパッケージが Git 更新をスキップ（10-08）

日付：2026-10-08 20:10（マージ時間）　情報源：env PR #300

ツールリポジトリ env の調査期間内にパッケージ管理修正が一つマージされた（#300、単一ファイル +7/-0）。SDK 内で手動管理されるオフラインソフトウェアパッケージには独立した .git ディレクトリがなく、パッケージ更新時に Git コマンドが親リポジトリで誤実行される問題を、リポジトリ検証前にソフトウェアパッケージディレクトリの .git をチェックしてオフラインソースをスキップするよう修正し、同時に .git ファイル形式で存在する worktree とサブモジュールにも対応した。本件はコミュニティ貢献者により提出され、創業者が当晚マージしたもので、ツールチェーンリポジトリの連休後の初マージである（前回は 10-04 にマージされた #299、WebUI とプラグインワークフロー強化）。

3.2 RT-Thread Studio：Gino Pi SDK に5件コミット、LVGL 8/9 デュアルバージョン対応を補完（10-08）

日付：2026-10-08 16:30 ~ 17:31（コミット時間）　情報源：Gino Pi ボードサポートパッケージリポジトリ

RT-Thread Studio の Gino Pi ボードサポートパッケージ（兆易創新 GD32H77D、Cortex-M7 最高 600MHz、32MiB SDRAM、720×720 MIPI DSI スクリーン、カーネル 5.3.0 ベース、17 のペリフェラルとアプリケーション工程を内蔵）は、調査期間内に5件を集中コミットした。表示フレームワークを LVGL 8/9 デュアルバージョンに拡張（バージョンマクロによりパッケージを選択）、独立した LVGL 8.3.11 サンプルを新規追加、バージョンマクロ解析順序を修正、随板 GD32 SDK ライブラリを非管理対象としてマーク（パッケージマネージャによる誤更新を回避）、併せて英語ドキュメントを同期し、MDK 工程生成手順を補完した。本ボードは 10-01 に商城で発売された共同製品であり、SDK 側は発売期間後に表示とドキュメント機能を迅速に補完した。

3.3 ソフトウェアパッケージ：esp-idf 対応リポジトリがマージを再開、ESP32-C6 scons コンパイルソースを補完（10-08）

日付：2026-10-08 17:28（マージ時間）　情報源：esp-idf PR #17

チップ対応パッケージリポジトリ esp-idf の調査期間内に実質的なマージが一回完了した（#17、4 コミット、332 ファイル、+48463/-5146）。ESP32-C6 に必要な scons コンパイルソースを補完し、貢献者は ESP32-C6-DevKitC-1 実機でコンパイル・書き込み後に msh で検証した。本件は rtt-dev 開発ブランチにマージされ、本リポジトリとしては 2023 年末以来初めてマージを再開したものである。マージ後、メンテナはコメントで ESP-IDF バージョンの更新をフォローアップすることを提案し、貢献者は 6.1 へのアップグレードを計画していると回答した。楽鑫 C6 サポートチェーン（BSP マージ、SPI オンデマンドコンパイル提案が審査中、scons コンパイルソース、パッケージインデックスバージョン提案 #2043 が審査中）は連休前後を通じて継続的に推進され、複数の層で同時に展開している。

3.4 メーカーダウンストリーム：GD32 リポジトリに GD32G553 DMA サポート提案 #72 が新規オープン（10-08）

日付：2026-10-08 10:44（作成時間）　出典：GD32 下流リポジトリ PR #72

兆易創新 GD32 ボードサポートリポジトリの調査期間内に新提案（#72、単一コミット、16 ファイル、+2571/-50）が作成された。GD32G553 向けに SPI、I2C、UART の完全な DMA サポートを補完するもので、I2C2 の DMAMUX 設定、UART0 ～ 5 の全チャネル、SPI G5x3 互換性と Keil コンパイラ互換修正を含む。作者は GCC と Keil でゼロ警告コンパイル、I2C-AT24C02 EEPROM の DMA 実測通過を報告し、テストボードは GD32G553Q-EVAL。コミット当日にコンパイルボットが BSP（gd32_arm）のコンパイル失敗を報告しており、修正とレビュー待ち。このリポジトリの直前のマージは 09-28（PR #71）。

4. 業界応用

4.1 「知手同行」手話教学ロボットがオープンソース公開：MaixCAM2 + Titan Mini + AmazingHand（10-09）

日付：2026-10-09 00:10（北京時間、プロジェクト資料公開コミット）　出典：オープンソースリポジトリ asungod/amazinghand

topic:rt-thread エコシステムに手話入門教学ロボットのオープンソースプロジェクト「知手同行」が新たに追加され、教学アプリケーションとプロジェクト資料が調査期間内に公開された。システムは三部分から構成される。MaixCAM2 視覚ノードが手部キーポイントの取得と手型・課程ステップの判定を担当。Titan Mini 制御ボード（ルネサス RA8P1 プラットフォーム、RT-Thread ファームウェアを実行）が通信と機械動作の実行を担い、ファームウェアにはバスサーボドライバ、動作安全ゲーティング、音声キーワード認識モジュールを含む。AmazingHand ロボットハンドが実体の模範演示を実行する。課程は全 13 項目（初級 3、中級 4、上級 6）で、ブラウザ練習インターフェース、ステップごとのフィードバック、練習記録、文字コミュニケーションカードを備え、技術報告書、検証資料、競技解説資料を添付。プロジェクト内部ドキュメントは同時に現在の推進境界も開示している（視覚ノードのシリアルリンクは実機で動作確認済み、制御ボードファームウェアはコンパイル完了、両ボードの連調とサーボ閉ループなどはなお推進中）。このボード方向の同類コミュニティプロジェクトとしては、以前に端側音響イベント検出がある（09-30 デイリーレポート収録）。
