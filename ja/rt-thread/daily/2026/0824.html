1. カーネルとバージョン動向

1.1 v5.3.0-beta ブランチ作成、v5.3.0 バージョンサイクルが正式始動

日付：2026-08-24（10:38 北京時間）　出典：RT-Thread/rt-thread ブランチ一覧 / リポジトリイベント

本日 10:38（UTC 02:38）、RT-Thread コアメンテナ Rbb666 が rt-thread メインリポジトリに v5.3.0-beta ブランチを作成し、現在の master HEAD（08-21 の NXP RT1180 BSP 大口マージ、6ea68279）を指している。リポジトリには以前から v5.2.0-beta / v5.2.1-beta / v5.2.2-beta の3つの先例ブランチがあり、beta ブランチの作成は RT-Thread のリリースプロセスの最初のステップである。まず安定ブランチを切り出して修正を集約し、その後正式 tag をリリースする。v5.2.2 正式版は 2025-10-31 にリリースされ、その後メインリポジトリは v5.3.0 開発蓄積期に入った（期間中に AF_UNIX ソケット、Device Model 再構成、複数ベンダー BSP など大量の機能をマージ）。今回の beta ブランチ確立は v5.3.0 バージョンサイクルの正式始動を意味し、v5.2.2 リリースから約 10 か月で、歴史的なバージョンリズム（v5.1→v5.2 の間隔は約 11 か月）とほぼ一致する。ブランチは現在 master と同一点にあり、独立したコミットはまだなく、今後の修正と機能の最終調整はこのブランチ上で行われる見込みである。

1.2 メインリポジトリは期間内に新規マージなし、master は NXP RT1180 マージで停止

日付：2026-08-24　出典：RT-Thread/rt-thread commits

メインリポジトリの master ブランチには期間内に新規 commit がなく、最後のマージは依然として 08-21 17:45（北京時間）の NXP RT1180 BSP 機能更新（I2C DMA、CAN、SPI、DWT、SDIO、昨日詳報済み）。ソフトウェアパッケージインデックスリポジトリ packages の最終 push も 08-21 09:24 で停止しており、期間内に新規ソフトウェアパッケージのマージはない。releases に新規追加はなく（v5.2.2 が依然として最新正式版）、v5.3.0-beta が唯一の新規参照であり、開発主線はバージョン収尾前の整理期に入っている。

8月27日上海「睿擎工業プラットフォーム Workshop：EtherCAT リアルタイム制御と工業ソリューション実戦」まで残り3日。調査期間内にメディア側の新規予熱報道はなし（gnewsの睿擎検索では08-18/08-19の旧記事と吉利智擎ハイブリッドなど無関係なノイズのみヒット）、申込カウントダウン稿は依然として08-21の旧文。本イベントは今週最も追跡に値する実装観察点であり、会後には実践振り返り系のコンテンツが登場すると予想される。

3. エコシステムとベンダー対応

3.1 CANopenNode 統合パッケージ canopennode-rtt に EEPROM ストレージ診断を追加、1週間で5連続更新

日付：2026-08-24（11:09 北京時間）　出典：wdfk-prog/canopennode-rtt / commits

サードパーティ製オープンソースプロジェクト canopennode-rtt（RT-Thread 向け CANopenNode V4 統合移植パッケージ）は本日、feat[canopennode][storage]: add EEPROM storage diagnostic support コミットを追加し、AT24CXX EEPROM ストレージバックエンドに診断サポートを加えた。本パッケージはプロトコルスタックを再実装せず、git submodule で上流 CANopenNode コアを参照し、本リポジトリが RT-Thread ターゲット層を提供する：CAN デバイスバインディング、Kconfig/SCons ビルド統合、受信/メインループ/リアルタイムの3スレッド実行モデル、DFS または AT24CXX ストレージバックエンド、CiA 301/303/304/305/309 機能群スイッチと demo オブジェクトディクショナリ。直近1週間の連続コミット（08-17 NMT ハートビート監視マスタ demo、08-18 SDO クライアント検証、08-19 ASCII ゲートウェイ MSH コンソールブリッジ、08-20 SDO ブロック転送検証、08-24 EEPROM 診断）により、機能面は NMT/SDO からストレージと診断へと収束し、産業制御 CANopen バス方向における RT-Thread エコシステムのサードパーティ実装が持続的に深化している。

3.2 エコシステム参考：awtk / gd32_rt-thread / h120d-protocol の定例同期

日付：2026-08-24　出典：zlgopen/awtk / GD32-MCU-IOT/gd32_rt-thread / H4ck3rTR/h120d-protocol

topic:rt-thread の直近1週間の活発なリポジトリのうち残り3つはいずれも定例的な動きであり、RT-Thread 専項ではない：zlgopen/awtk（クロスプラットフォーム組み込み GUI フレームワーク）は本日09:05に push、汎用 GUI 改善であり RT-Thread とは直接関係なし；GD32-MCU-IOT/gd32_rt-thread（rt-thread 下流同期リポジトリ）は本日09:58の push が通常の上流同期；h120d-protocol（DJI H120D ドローン WiFi プロトコルリバースエンジニアリング文書、topic タグ関連）は昨日22:15の push がプロトコルリバースエンジニアリング内容。三者はエコシステム参考として標記し、個別条目にはしない。

4. 業界応用（工業 / ロボティクス / 具身知能）

4.1 調査期間内に新規独立報道なし、直近3日間の傾向振り返り

日付：2026-08-22 ~ 2026-08-24　出典：各条目参照

業界応用側では調査期間内に新たな独立公開報道はなし。直近3日間の傾向振り返り：

  • v5.3.0 バージョンサイクルの始動（08-24）：beta ブランチの作成により 10 か月ぶりとなる新バージョンサイクルの開始を標識、産業制御/ネットワーク（AF_UNIX）などの特性は v5.3.0 正式リリースに伴い提供予定；
  • NXP i.MX RT1180 BSP の大型更新に EtherCAT を含む（08-21）：産業制御リアルタイムバス能力が NXP クロスオーバー MCU プラットフォームで実現（+3579 行、HyperRAM/マルチコア/rpmsg-lite/NetC サポート）、睿擎産業プラットフォームと二本柱を形成；
  • 睿擎産業プラットフォーム Workshop が間近に迫る：8 月 27 日上海「EtherCAT リアルタイム制御と産業ソリューション実戦」まで残り 3 日（08-24 確認）、今週最も注視に値する実装観察ポイント；
  • CANopen エコシステムのサードパーティ実装が深化（08-17 → 08-24）：canopennode-rtt が一週間で五連続更新、NMT/SDO/ストレージ診断をカバー、産業フィールドバス方向は引き続き活発。

5. 総括とトレンド観察

  1. v5.3.0 バージョンサイクルの正式始動が本日のトップニュース：コアメンテナが v5.3.0-beta ブランチを作成（10:38）、v5.2.x 各バージョンの「先に beta ブランチ、後に正式 tag」というリリース慣例を継続；v5.2.2（2025-10-31）以降約 10 か月分の特性蓄積（AF_UNIX、Device Model、マルチベンダー BSP）がバージョン化の最終段階に入る。
  2. メインリポジトリのコード側は平静：master の調査期間内は合流ゼロ、packages インデックスにも新規追加なし、開発はブランチ作成後の整理期間にあり、昨日の判断と一致。
  3. 産業制御の主線が多線並行で前進：CANopenNode 統合パッケージが一週間で五連続更新（本日 EEPROM ストレージ診断）に加え、8/27 睿擎 EtherCAT Workshop が間近に迫り、産業リアルタイムバス方向はエコシステム側で最も活発なテーマ。
  4. 公式情報の出口は引き続き遅延：rt_org は 2 か月停滞、news/activity インターフェースは連続四日目にエラー報告、公式チャネルのペースは GitHub の動きよりはるかに遅く、バージョンサイクル始動のようなシグナルは現在リポジトリイベントからのみ観測可能。
  5. 限界の説明：gnews は “RT-Thread” 検索でノイズが高い（Rotten Tomatoes の語分割、吉利智擎ハイブリッド等）、本調査期間のニュース側ゼロ新規は公式 API + GitHub + 複数組の gnews クロスチェックで確認済み；EET-China 原サイトは到達不可、関連項目は gnews リンクのみ引用。
