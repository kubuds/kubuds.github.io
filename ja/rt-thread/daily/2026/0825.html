1. カーネルとバージョン動向

1.1 master マージ再開：ルネサス RA8D1 Vision Board の Keil 書き込み設定を修正

日付：2026-08-24（17:10 北京時間）　出典：RT-Thread/rt-thread commit 5d19f815

主リポジトリの master に期間内で1件のマージが追加された：[renesas][ra8d1] Fix Keil flash download configuration。コミュニティ開発者の CYFS 氏がコミットし、コアメンテナーの Rbb666 氏が 08-24 17:10（UTC 09:10）にマージした。変更範囲は bsp/renesas/ra8d1-vision-board/ 配下の template.uvoptx（2か所）と template.uvprojx（4か所）、すなわち RA8D1 Vision Board プロジェクトテンプレートにおける Keil（MDK）の Flash ダウンロードアルゴリズム設定の修正であり、BSP テンプレートの可用性修正に属し、カーネルには影響しない。このコミットは 08-21 の NXP RT1180 BSP 大型マージ（+3579 行）以降、master への最初の新規マージであり、ブランチ樹立後の整理期間が終わりマージ経路が回復したことを示す。v5.3.0-beta ブランチ（08-24 作成）は現在も master と同一地点で独立したコミットはない。

2. 公式・コミュニティイベント

2.1 RISC-V 技術サロン@長沙駅：熊譜翔氏が講演「程翧」車載規格と AI 新パラダイム

日付：2026-08-24（記事掲載 11:26 北京時間；イベントは 08-18 14:00-17:00 に開催）　出典：電子工程専輯（RT-Thread 公式コラム）

2026 RISC-V 城市行・技術サロン@長沙駅（湖南省半導体行業協会、芯来科技、湖南融創微が主催、長沙岳麓区福朋喜来登酒店）の会后報道が 08-24 に掲載され、テーマは RISC-V の AI、産業制御、航空宇宙分野での実装に焦点を当てた。RT-Thread 創業者兼 CEO の熊譜翔氏が招待され、《RISC-V に根ざし、智行は遠くへ――RT-Thread のエコシステム実践、車載規格「程翧」と AI 新パラダイム》と題する講演を行い、核心的な情報量は多かった：第一に、エコシステム規模のデータ――世界累計搭載台数は25億台超、アクティブ開発者コミュニティは30万人超、サービス企業は1万社超。RISC-V 側では 2018 年からいち早く対応を開始し、芯来、兆易創新、嘉楠、玄鉄、先楫、沁恒など数十社の原廠の100余款の製品に深く対応済みで、公式とコミュニティが共同で30余款の BSP を維持している。第二に、商業化と機能安全――RT-Safety オペレーティングシステムは既に IEC61508 SIL3、EN50128 SIL4 認証を取得し、その上に構築された程翧車載制御システムは ISO26262 ASIL D 認証を取得、AUTOSAR CP と互換、BSW 設定、コード生成ツールと仮想 ECU 開発環境を付属。第三に、AI 戦略――RT-Thread AI Kit というワンストップ MCU 端 AI デプロイメントプラットフォーム（モデル接続、最適化、バックエンド変換からプロジェクト統合までの全工程、プルーニング/量子化/キャリブレーション）を発表し、Env + Agent インテリジェント開発パラダイムを予告、将来は自律的な知覚・意思決定能力を持つ AI Agent へと進化する。この報道は期間内で唯一のニュース側の新規追加であり、かつ公式対外口径の集中的な更新である。

3. エコシステムとベンダー対応

3.1 packages インデックスが1日で3連続更新：BMI270 IMU ドライバ / LiteType フォントエンジン / AI Agent マルチモーダル

日付：2026-08-24（13:29 ~ 17:35 北京時間）　情報源：RT-Thread/packages commits

ソフトウェアパッケージインデックスリポジトリ packages のウィンドウ内に 3 つの PR がマージされ、これまでの1週間余りの静寂（前回合流 08-21 09:24）を破った：

  • bmi270（#2026、17:35 マージ）：BMI270 六軸 IMU ドライバソフトウェアパッケージを新規追加、Mahony AHRS 姿勢融合を内蔵、I2C（デバイスアドレス 0x68/0x69 選択可）をサポート、RT-Thread sensor デバイス（/dev/acce_bmi）として登録し sensor フレームワークに接続可能。Bosch BMI270 は TWS/ウェアラブル/ロボットなどの低消費電力シーンで一般的で、センサー外設パッケージの補充に属する；
  • LiteType（#2020、13:42 マージ）：multimedia カテゴリの軽量組み込みフォントエンジンパッケージを新規追加、同時にパッケージリポジトリを Gitee から GitHub に移行し、国際的な開発者が取得しやすくした；
  • ai/Agent（#2022、13:29 マージ）：ai/Agent パッケージ（08-11 に新規追加された軽量化 agent フレームワーク）を更新、今回のマージでマルチモーダルサポートとチャット履歴トリミング機能を追加、端側 agent フレームワークがマルチモーダル入力へ進化。

3 つのマージ方向（センサー、マルチメディアレンダリング、端側 AI agent）はいずれもエコシステム側の増分補完であり、公式の「リアルタイム+インテリジェント」AI OS の方向性と呼応している。

3.2 canopennode-rtt ブランチで LSS 起動永続化を開発、ストレージバックエンドと AT24CXX を分離

日付：2026-08-24 18:34 ~ 2026-08-25 09:43　情報源：wdfk-prog/canopennode-rtt ブランチ feat/lss-precan-persistence

昨日詳報した CANopenNode 統合パッケージ（08-24 11:09 main に EEPROM ストレージ診断をマージ）は本日ブランチ開発に転向：feat/lss-precan-persistence ブランチ上で連続コミット feat[canopennode][lss]: add backend-neutral startup persistence（08-24 18:34）、ストレージエントリ簡素化リファクタリング（08-24 19:10）、EEPROM provider と AT24CXX の分離リファクタリング（08-25 09:43 ブランチ tip）。方向性は CANopen ノード層設定サービス（LSS、CiA 305）の起動永続化：EEPROM ストレージバックエンドを provider として抽象化し、AT24CXX 具体的なデバイスへのバインドから脱却、LSS パラメータプリスキャンと電源投入時復元への道を鋪装。機能はまだ main にマージされておらず、進行中の開発に属する；08-17 以来の NMT ハートビート監視マスター、SDO ブロック転送、ASCII ゲートウェイなど一連のコミットと併せて、この第三者パッケージの産業制御 CANopen 方向への深耕はなお継続中。
