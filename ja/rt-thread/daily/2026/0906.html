1. カーネルとバージョン動向

1.1 メインリポジトリのゼロマージが第 3 ウィンドウまで継続；新規 PR #11780 が SDIO CIS メタデータのメモリリークを修正

日付：2026-09-05（PR 作成 16:59 北京時間）　出典：RT-Thread/rt-thread PR #11780（関連 issue #11724）

メインリポジトリ rt-thread は本期間ゼロマージ、ゼロ新規 issue、直近のマージは依然として 09-03 の #11776（第 3 ウィンドウ継続）、release は依然として v5.2.2（2025-10-31）。期間内で唯一の新規はコミュニティ開発者 Huoyanlifusu が提出した PR #11780「[components][sdio] Fix CIS tuple memory leak」：#11724 が指摘する問題を修正——sdio_read_cis() が CISTPL_FUNCE や CISTPL_VERS_1 などの一部 CIS tuple を処理する際にメモリを申請するが処理完了後に解放せず、SDIO デバイスの初期化/逆初期化を繰り返すとメモリリークが発生する；修正方案は上記 2 分岐の処理完了後に一時 tuple を解放し、未知の tuple は依然として func->tuples リンクリストで管理し sdio_free_cis() により一括解放する。変更は 1 ファイル、純増 2 行、作者は qemu-vexpress-a9 BSP 上で検証を完了。同 PR は作者の連続 3 件目のコンポーネント級修正（#11756 netdev ping ヌルポインタクラッシュ修正は 08-26 にマージ済み；#11774 sal SIOCGIFCONF 境界外修正は依然レビュー中）であり、「コンポーネント級メモリ安全修正」の貢献主軸を継続。レビューキューのその他の項目は昨日と横ばい：#11779 CAN フレームワーク再構築はメンテナ CYFS3 が 09-03 に表明して以降新規コメントなし、#11775（c908 rt-smart）、#11772（ヒープ ASan）、#11689（stm32 SPI BDMA）などはいずれも open で未動。

2. 公式・コミュニティイベント

2.1 公式ニュース API が連続 17 日間新規なし、elexcon 2026 まであと 3 日

日付：2026-09-06　出典：RT-Thread 公式ニュース API

公式ニュース API（rt_org カテゴリ）は依然として 5 件の旧項目、最新は依然として 2026-06-17 アブダビ投資フォーラム報道、連続 17 日間新規なし。次の対外ウィンドウは 9 月 9-11 日の深圳 elexcon 2026（睿賽德出展、「AI ハードウェア全家桶」予告は 08-30 に収録済み）、本日は開幕前最後の週末、カウントダウン 3 日。中国語・英語メディア側（Google News をプロキシ経由で 1d/2d/3d ウィンドウを検証）はいずれも期間内の新規 RT-Thread 報道なし、最新メディア内容は依然として 09-04 電子工程専輯のコミュニティ作品共有（昨日収録済み）、公式チャンネル静黙期間中もコミュニティとメディアのコンテンツ産出リズムは影響を受けず。

3. エコシステムとベンダー対応

3.1 canopennode-rtt：CiA402 コントローラ側と診断/EMCY を補完、CiA401 汎用 I/O profile ブランチを起動

日付：2026-09-05 ~ 09-06（14:08 ~ 翌日 10:06 北京時間、6 コミット）　情報源：wdfk-prog/canopennode-rtt（CIA401 ブランチ）

昨日 11:08 に CSP/CSV/CST 周期同期モードを収録した後も、当該リポジトリの開発は止まらなかった。デフォルトブランチに「CiA402 device diagnostics and EMCY bridge」（デバイス診断と EMCY 緊急メッセージブリッジ、09-05 14:08）、「CiA402 コントローラサポートと関連テストの追加」（16:13、CiA402 のカバレッジをスレーブ側からコントローラ側へ拡張）とドキュメント整理・リファクタリング（16:36）を新規追加。その後、新ブランチ CIA401 を開き、09-05 21:53 から「generic I/O device profile core」「digital event and output fail-safe support」、そして 09-06 10:06 の「アナログ入出力イベントとフェイルセーフ機能サポート」を連続して着地させた。これにより当該 CANopenNode 移植は 09-03 以降の一週間で二線拡張を完了した。モーション制御 profile（CiA402：マルチ軸、PP/PV/Homing、CSP/CSV/CST、診断と EMCY、コントローラ側）と汎用 I/O デバイス profile（CiA401：デジタル/アナログイベントとフェイルセーフ）である。CAN/産業フィールドバス方向のエコシステム推進主線は全コミュニティで最も活発な状態を維持している。当該作者が同時にメインリポジトリで Generic CAN フレームワークのリファクタリング（#11779）を進めていることと合わせ、「フレームワーク層 + アプリケーション層」の二線並行の態勢は変わらない。

3.2 エコシステム参考：gdr GDB デバッグフレームワークが FreeRTOS 対応を收尾、RT-Thread は首要サポートを維持

日付：2026-09-05（17:39 北京時間 收尾コミット）　情報源：flespark/gdr

topic:rt-thread リポジトリ flespark/gdr（GDB Python 環境下の RTOS デバッグ補助フレームワーク。rtt threads/rtt timers などの RTOS コマンドツリー、カーネルオブジェクトの pretty-printer と便利関数を提供）は、調査期間内に「refactor(freertos): wrapup of new rtos support, code and docs quality enhance」をコミットし、FreeRTOS 第二対応器を收尾した。その README によれば、RT-Thread（3.1.x / 4.0.x / 4.1.x、Cortex-A9 全系で検証済み、RV64 は 4.0.4 以降）は引き続き首要サポート対象である。調査期間内に完成した FreeRTOS チャネル（V10.3.0 ~ V11.3.x）は QEMU 上で 64 ビット RISC-V lane と MPS2-AN521 デュアルコア SMP 検証を補完した。汎用フレームワークの拡張であり RT-Thread 専項コミットではないが、RT-Thread ユーザー（RISC-V ターゲットを含む）の GDB デバッグツール面に対しては正向参照となり、エコシステム参考として収録する。

4. 業界応用

新規項目なし。調査期間内に新たな業界応用/落地事例の報道はなし。直近三日間（09-04 ~ 09-06）も業界側は静穏を保持している。最近収録済みの業界コンテンツは 08-27 マレーシア都市 IoT 事例と 08-24 RISC-V+AI 二線サミット報道（電子工程専輯）である。睿賽德の具身智能（臨港滴水智匯）、工業（睿擎工業プラットフォーム）などの方向における最新の対外動向は、09-09 開幕の elexcon 2026 に伴い集中的にリリースされる見込みである。

5. 総括とトレンド観察

  • カーネル側：メインリポジトリはゼロ合流で第3ウィンドウに突入（直近合流は #11776、09-03）。新規 PR は #11780 の1件のみ——SDIO CIS tuple のメモリリーク修正（1ファイル +2行、qemu-vexpress-a9 で検証）。作者は3連続となるコンポーネントレベルの修正で、レビュー待ち行列に他の変化はなく、release は依然 v5.2.2 のままで、蓄積期が継続。
  • エコシステム側：canopennode-rtt は1週間で CANopenNode のポーティングを運動制御（CiA402 全モード）から汎用 I/O profile（CiA401）およびコントローラ側サポートへと推進し、現在のコミュニティで最も活発な開発主線となっている。GDB デバッグ補助フレームワーク gdr は FreeRTOS 第2アダプタの仕上げを完了し、RT-Thread サポート（RV64 含む）を最重要機能として維持。
  • 公式/メディア側：公式ニュース API は連続17日目で沈黙。メディア側は24hウィンドウで新規報道ゼロ（代理とソースの核查は正常）。elexcon 2026（09-09~11 深圳）までカウントダウン3日、会前の沈黙は想定内のペース。
  • 直近3日のトレンド（09-04 ~ 09-06）：CiA402 多軸と PP/PV/Homing、EET がコミュニティの USB モニタサブスクリーン作品を転載、公式沈黙15日目（09-04）→ env が WebUI keep_alive を合流（#294）、CiA402 周期同期 CSP/CSV/CST が着地、公式沈黙16日目（09-05）→ sdio CIS リーク修正 PR #11780、CiA402 診断/EMCY/コントローラ側と CiA401 I/O profile ブランチが始動、公式沈黙17日目（09-06）。現在の推進主線は「公式ツールチェーン WebUI 体験のイテレーション + CANopenNode デュアル profile エコシステム拡張」であり、対外活動は elexcon 2026 まで充電中。
