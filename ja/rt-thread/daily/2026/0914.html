1. カーネルとバージョン動向

1.1 STM32 SPI BDMA サポートがメインラインにマージ、DMA / BDMA / GPDMA 設定を統一（PR #11689）（09-14）

日付：2026-09-14 09:59（北京時間、マージ時間；作者コミット日 09-11）　出所：PR #11689

メインラインは v5.3.1 バージョン番号の推進後にマージを再開し、本期間内の最初の機能性コミットは STM32 プラットフォーム SPI の BDMA サポートであり、併せて DMA、BDMA、GPDMA の 3 種類の転送チャネルの設定記述を統一した（clang-format フォーマットコミットを同梱）。BDMA は STM32H7 / U5 などのシリーズで低消費電力ドメインで利用可能な独立 DMA コントローラであり、これまで SPI ドライバは汎用 DMA 経路のみを使用していた；今回のマージで SPI の BDMA チャネル上での送受信能力が補完され、STOP 低消費電力モードでペリフェラル転送を維持する必要がある工業およびセンサシーンに直接的な価値がある。この PR は開始からマージまで数日を要し、コミュニティ駆動のペリフェラルドライバ強化に属する。

1.2 QEMU 入門ドキュメントの 2 箇所修正がマージ（PR #11789 / #11794）（09-11）

日付：2026-09-11 13:23 と 13:26（北京時間）　出所：PR #11789、PR #11794

2 件のドキュメント修正が同日マージされた：1 つは QEMU Linux クイックスタート過程で欠落していた apt 依存パッケージの補完、もう 1 つは qemu-vexpress-a9 README 内で既に無効となった GNU GCC ツールチェーンのダウンロードリンクの更新である。2 件のコミットの作者日はそれぞれ 09-07 と 09-08 であり、長期間放置された後の収尾マージに属する。QEMU シミュレータは RT-Thread で最も一般的なハードウェア不要の入門経路であり、ドキュメントの可用性は新規開発者の初回体験に直接影響する。

1.3 四件の安全系 issue が 09-13 に集中クローズ（tmpfs / メッセージキュー / pread / finsh 補完）（09-13）

日付：2026-08-23 コミット、2026-09-13 15:46 ~ 15:47 に集中クローズ　情報源：#11735、#11736、#11737、#11738

同日にコミットされた四件の安全系欠陥が 09-13 に完了クローズとして集中的にマークされた。対象は以下の通り：tmpfs のパス処理（_path_separate / _get_subdir）において長いパスコンポーネントが引き起こすスタックバッファオーバーフロー、POSIX メッセージキュー名処理における mq_unlink() の無制限スタックオーバーフローと mq_open() のオフバイワンエラー、pread() に大きな負のオフセットを渡すことで rw_verify_area() を迂回し tmpfs の範囲外ヒープ読み取りを引き起こす問題（情報漏洩またはクラッシュ）、finsh の TAB 自動補完（msh_auto_complete_path）で補完結果が行バッファにトリミングされずヒープ範囲外書き込みを引き起こす問題。四件はいずれも同一のコミッターが引き受けクローズしており、公開コメントおよびコミット履歴にはこれらに一件ずつ対応する修正コミットは見当たらない。修正の実際の着地経路（v5.3.0 の dfs / posix 強化バッチに統合された可能性、あるいは別途内部プロセスを経た可能性）は依然として確認待ちである。RT-Smart とファイルシステム、メッセージキューをセールスポイントとする産業・車載シーンにとって、本欠陥群のクローズ進捗は継続的に追跡する価値がある。

1.4 レビューキューの観察（1）：新規 BSP と国産 MCU ドライバ拡張が集中的に審査提出（09-14）

日付：2026-09-11 ~ 2026-09-14　情報源：#11799、#11800、#11798、#11764

1.5 レビューキューの観察（2）：lwip 2.2.1 プロトコルスタックサポートが列に加わり、ツールチェーンと USB 修正が併存（09-14）

1.6 レビューキューの観察（3）：達摩院玄鉄 C908 の QEMU rt-smart サポートが持続的に推進（09-14）

日付：2026-08-31 開始、2026-09-14 10:16 更新　出所：PR #11775

達摩院玄鉄 C908 向けの QEMU 模擬プラットフォーム（xiaohui c908）に rt-smart サポートを新規追加。MMU sv39 / sv48 ページテーブルモードと SMP マルチコア起動を含み、mmu_dem 関連の機能も補充。変更は31ファイル、+2575/-565 行。本 PR は依然としてレビュー中。RISC-V 側にとってこれは、RT-Thread Smart（MMU を備えたハイブリッドデプロイ形態）を玄鉄の高エネルギー効率コア上でシミュレータレベルで検証する重要な一歩であり、ハードウェアなしの条件でプロセス分離とユーザー空間アプリケーションを検証するために利用できる。

1.7 新規欠陥報告：SDIO ドライバの登録解除失敗とノードメモリリークのリスク（#11801）（09-12）

日付：2026-09-12 14:56（北京時間）　出所：#11801

調査期間内に、工業、車載、ロボット/具身知能方向の新規業界実装事例の報道は検索されなかった。業界側の既存アクションは二つ継続している。第一に、睿賽徳が程翧車両基礎ソフトウェア操作システムで 2026 第八回金輯賞最優秀技術実践応用賞に申告したこと（09-11 収録済み、調査期間内に後続進展なし）。第二に、2026 上海オープンソースソフトウェア応用イノベーションコンテスト「AI + 工業ソフトウェアトラック」の『睿擎工業開発プラットフォームに基づく事前訓練視覚モデルの軽量化対応とローコード配置最適化』という命題が引き続き作品を募集しており、申込締切は 10 月 11 日である。なお、電子工程専輯が 09-11 に「すべての開発者ができる工業品質検査 AI、RT-Thread 命題公布」というタイトルで改めてこの命題を配信したが、内容はそれ以前の 09-03 公布、09-09 ライブ解説のコンテスト課題と一致しており、二次転載に属するため、本期では新規項目として重複計上しない。工業品質検査と工業データ収集は依然として対外的に最も活発なシーンストーリーであり、実装事例側の公開増分はやや少ない。

5. 総括とトレンド観察

5.1 直近三日間のトレンド（09-11 ~ 09-14）

  • 主線は通常のマージリズムに回帰：v5.3.0 / v5.3.1 リリース後、調査期間内は BSP ドライバ強化（STM32 SPI BDMA）とドキュメント修正が中心で、別に四件の国産 MCU ドライバ系 PR が集中的にレビュー提出され、新バージョン後の対応ウィンドウにある。
  • セキュリティ系欠陥が一度集中的にクローズ：08-23 コミットの tmpfs / メッセージキュー / pread / finsh 補完欠陥の四項目が 09-13 に集中的にクローズされたが、公開コミット履歴には逐条の修正記録が見当たらず、修正の着地方法は依然として確認が必要であり、継続追跡を推奨する。
  • エコシステム側で本期最も実質的な着地アクションが出現：Gino Pi（GD32H77D）BSP v1.0.0 が RT-Thread Studio SDK インデックスに登録され、展示会の新製品からダウンロード可能なデリバリ段階へ移行、兆易創新 GD32H7 ラインのソフトハード協同が引き続き推進されている。
  • 公式対外ニュースは引き続き沈黙（第二十五日）、情報増分は GitHub と開発者コミュニティへ移行；コミュニティ側では CANopen（Lely / CanopenNode）を巡り、パッケージインデックス、下流リポジトリ、技術記事の三本柱連動が形成されている。
  • 業界側に新規実装事例なし、主に地域オープンソースコンテスト命題（申込 10-11 締切）と金輯賞申告で熱度を維持、工業品質検査と工業データ収集が最も活発なシーンストーリー。
  • RISC-V 側に注目すべき長線が一本：達摩院玄鉄 C908 の QEMU rt-smart（MMU sv39/48 + SMP）サポートは依然としてレビュー推進中であり、玄鉄コア上での RT-Thread Smart のエミュレータレベルの検証に属する。

5.2 限界と重複排除の説明

  • 本期は月曜定例の拡張ウィンドウ（過去 3 日間）で、土日をカバーする；平日内の公開増分自体がやや少ないため、項目は GitHub の事実を主、ニュースを従としている。
  • 電子工程専輯の原サイトは本機ネットワークから到達不可（HTTP/2 プロトコルエラーとタイムアウト）、その 8 月回顧月報とライブ予告項目は集約リンクと公開摘要から取得しており、月報本文の詳細（ワークショップ来場者数、展示物資等を含む）は原文を逐字照合していない；月報中の大学訪問情報は公式英語チャネル内容とクロスチェックして一致している。
  • 公式ニュース API と公式サイトニュースセンターは依然として 2026-06-17 で更新停止、睿賽徳公式サイト商業站は 403 を返すため、公式口径の増分は業界メディア転載と公式英語チャネルに準拠する。
  • 四項のセキュリティ系 issue のクローズには公開説明や関連 PR が付されておらず、本レポートは「集中クローズ」という事実のみを述べ、修正の完全性について結論を下さない。
  • Google News 中国語側の「RT-Thread」クエリには依然として体壇加等のギャンブル系 SEO コンテンツと低空経済無関係稿が混入しており、タイトル意味に基づき排除済み；英語側の「RT-Thread」クエリは継続的に Rotten Tomatoes 映像評分類ノイズにヒットしており、いずれも計上していない。
