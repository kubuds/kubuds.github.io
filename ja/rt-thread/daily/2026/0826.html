一、内核与版本动态

1.1 Cortex-M4 硬件栈保护（HW Stack Guard）支持合入内核

日期：2026-08-26（10:37 北京时间合入）　来源：RT-Thread/rt-thread commit e2e6245a

主仓库窗口内合入一条内核级特性：[arm][cortex-m4] Add hardware stack guard support，由社区开发者 hanzhijian 提交（author 时间 08-25 09:19）、核心维护者 Rbb666 于 08-26 10:37（UTC 02:37）合入。该提交将基于硬件 MPU 的栈溢出保护（RT_USING_HW_STACK_GUARD）从原先仅支持的 Cortex-M7 / Cortex-M33 扩展到 Cortex-M4——后者是 M 系列中部署量最大的内核类，硬件栈保护落地意义显著。核心改动集中在 libcpu/arm/cortex-m4/：新增与 M7 MPU 层对齐的 mpu.c / mpu.h / mputype.h（唯一差异是 M4 无 L1 缓存，cacheability 位缩减为三个）；cpuport.c 新增 rt_hw_stack_guard_init()；context_gcc.S 补 #include <rtconfig.h> 并在 PendSV 上下文切换路径调用 rt_hw_mpu_table_switch()；SConscript 在关闭内存保护时排除 mpu.c。参考 BSP 为 bsp/stm32/stm32f407-fk407m2-zgt6（正点原子 STM32F407 板）：board.h/board.c 定义 NUM_STATIC_REGIONS 与 static_regions[]，将 Flash 区标记为只读，整体由 RT_USING_MEM_PROTECTION 开关控制、默认不启用。这是 v5.3.0-beta 分支建立（08-24）后主分支合入的首个内核级功能提交，为 v5.3.0 的内核健壮性方向添了一笔。

1.2 finsh 清理：移除废弃宏 FINSH_FUNCTION_EXPORT_ALIAS

日期：2026-08-26（10:53 北京时间）　来源：RT-Thread/rt-thread commit 0305faf8

创始人 Bernard Xiong 于 08-26 10:53（UTC 02:53）直接推送 [finsh] Remove deprecated FINSH_FUNCTION_EXPORT_ALIAS（对应 PR #11734），移除已废弃的 FINSH_FUNCTION_EXPORT_ALIAS 宏在代码库中的全部使用：共 19 个文件、+124/-81 行，覆盖 allwinner（sunxi-hal disp2 调试与测试文件）、apm32（drv_common.c）、at91（at91sam9260 reset.c）、fujitsu（mb9x nand.c）、simulator（board.c / module_win32.c）等 BSP，以及 dfs_v1 / dfs_v2 的 dfs_posix.c 组件代码。FINSH_FUNCTION_EXPORT_ALIAS 是 finsh 组件历史上用于给命令导出起别名的旧宏，本次清理属代码现代化收尾，与昨日 RA8D1 合入同属”整理期”节奏：合入通道恢复后，主分支正以低风险清理与特性两类提交交替推进，为 v5.3.0 正式发布做准备。

1.3 utest 控制台缓冲约束与瑞萨 RA6W1 BLE OTA 生成优化

日期：2026-08-25 22:04 ~ 2026-08-26 10:42　来源：RT-Thread/rt-thread commits 45679c79 / 64f1fa4a

窗口内另有两条合入（不单列）：其一，CYFS 提交、Rbb666 于 08-26 10:42 合入的 [utest] Enforce minimum console buffer size（src/Kconfig，为 utest 控制台缓冲区设置最小长度约束，属测试框架配置校验加固）；其二，rcitach 提交、Rbb666 于 08-25 22:04 合入的瑞萨 RA6W1 BSP 改进——Improve BLE OTA image generation to avoid executing OPEN every time a flash erase and write operation occurs，修改 bsp/renesas/ra6w1-ek/ 下 ra6w1_ospi_flash.c 与 scripts/gen_rrq61_flash_image.py，优化 BLE OTA 镜像生成流程，避免每次 Flash 擦写都执行 OPEN 命令。RA6W1（瑞萨 BLE 单芯片）BSP 继 08-05 首版、08-11 二期补外设后再度打磨，第三方/社区持续迭代特征明显。
