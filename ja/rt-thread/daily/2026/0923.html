1. カーネルとバージョン動向

1.1 レビューキューが一夜で新たに八件の提案を追加：既存欠陥強化シリーズ七連発、WCH CH32V203 ボードサポートが補位（09-22）

日付：2026-09-22 18:03 ~ 18:31（北京時間、提案時間）　出典：PR #11820、PR #11827

期間内のレビューキューに一夜で新たに八件の提案（#11820 ~ #11827）が追加され、最近で最も集中的な一批のコミットとなった。うち七件は同一貢献者によるもので、体系的な既存欠陥強化シリーズを構成している：二線シリアルバスコントローラと伝送ミューテックス（#11820、#11524 を修正）、電源管理のデバイス別サスペンドモードのペア復元（#11821、#11046 を修正）、USB ホストインターフェース数の境界（#11822、#11288 を修正）、IPC メッセージキューパスの終端記号境界（#11823、#11292 を修正）、ブロックデバイス論理パーティションの範囲外読み書き（#11824、#11286 に関連）、STM32 OpenAMP 受信バッファ境界とリングラップアラウンド（#11825、#11299 を修正）、virtio 入力オフセット検証（#11826、#10379、#10380 を修正）。七件はいずれも数ヶ月前の既存欠陥報告を引用し、GCC 16.1 ホストビルドと境界ケースの検証説明を添えており、歴史的遺留問題の集中的な清理に属する。第八件は沁恒 WCH CH32V203C8T6-EVT-R0 ボードサポート（#11827）：この型番は青稞 V4B コアの RISC-V マイクロコントローラ（64KB ゼロウェイト Flash、20KB SRAM）であり、メインラインには従来対応する BSP が存在しなかった。提案はプロジェクト骨格、D6 ベクタテーブル、リンクスクリプトとウォッチドッグサンプルを補完し、公式 SDK パッケージが D6 型番で直接ビルドを終了する問題を修正している。

1.2 公式ニュースインターフェースが連続三十四日目に新規追加なし（09-23）

日付：2026-09-23（確認時間）　出典：RT-Thread 公式ニュースインターフェース

公式ニュースインターフェース（rt_org カテゴリ）は依然として 5 件の旧エントリのままで、最新も依然として 2026-06-17 のアブダビ投資フォーラム報道であり、連続三十四日目に新規追加なし；公式サイトのニュース一覧ページは期間内の確認でも読み込み失敗のプロンプトを返し、直接確認できない。メインラインは月曜日（09-21）午後の集中批次以降に新たなマージはなく、期間内に提案のクローズやマージ記録もなく、現在の活性面はすべてレビューキューとベンダー側リポジトリに集中している。

2. 公式・コミュニティ活動

2.1 工博会展 Workshop 詳細公布：10月13日専用開催、スマートカー教材25セット（09-22）

日付：2026-09-22（報道時間）　出典：AI 雲資訊報道

業界メディアが工博会展現場 Workshop の詳細情報を公開し、前号で収録した募集原稿（09-20）に会場と内容の詳細を補完した：第 26 回中国国際工業博覧会は 10 月 12 日〜16 日に国家会展中心（上海）で開催され、RT-Thread 睿赛徳の「AI 端側智能小车実践 Workshop」は 10 月 13 日（火曜日）13:00〜17:00 に設定されている。コースはハンズオン実践を核心とし、2 人 1 組、25 セットのスマートカー教材を配备し、ベテランエンジニアが全程指導し、流れはハードウェア検測、システム起動、周辺機器デバッグ、リアルタイム操作、SLAM マッピング、自律ナビゲーション、カメラキャリブレーション、マルチモーダル視覚フォローから AR 総合演練までをカバーし、レーザーレーダー、IMU、深度カメラの現場デバッグを含む。現場ではさらに同一ベース由来の産業制御機器、移動ロボット、具身知能、飛控ユニットなどの実物展示品を集中的に展示する。会場と申し込み情報は主催者の後続公告を基準とする。

3. エコシステムとベンダー適合

3.1 ルネサス RA8P1 Titan Mini が OpenMV プロジェクトを最適化：SDRAM クロックとメモリプール調整で、推論時間が大幅短縮（09-22）

日付：2026-09-22 16:09 / 16:36（北京時間、コミット時間）　情報源：性能最適化コミット、性能データ更新コミット

Studio BSP 組織下のルネサス RA8P1 Titan Mini リポジトリは、調査期間内に 2 件の OpenMV プロジェクト最適化コミットをプッシュした。1 件目は外部 SDRAM のタイミングとクロック設定（リフレッシュ待機パラメータ、BCLKA 分周）を調整し、ソースコード上書き方式で SDCLK セレクタの初期化順序を補完し、チップ設定ツールの既知の制限を修正した。2 件目はチップ内 SRAM のメインガベージコレクションプールを 1344 KiB から 1472 KiB に拡張し、大規模モデルワークスペースのメモリ配置を改善した。コミットと同時に更新された実測性能によると、Tiny YOLOv2 INT8 416×416 の単回推論は 156.10 ms から 58.49 ms に短縮（約 2.7 倍）、YOLOv8n 256×256 は 186.54 ms から 38.33 ms に短縮（約 4.9 倍）、320×320 は 310.29 ms から 287.49 ms に短縮された。このプロジェクトは 09-18 に OpenMV リリースチェーンと継続的インテグレーションを補完したばかりで、今回はリリース後の性能収束である。電子工程専輯は同日にフォローアップ報道を発表した（「1 GHz MCU + NPU、Python で遊ぼう！Titan Mini の OpenMV 更新が来た」）。原サイトへのアクセスは制限されており、リンクは付録を参照。

3.2 GDR 2026.03 リリース：RT-Thread デバッグアシスタントフレームワークがオブジェクトコマンドとヘルプ体系を補完（09-22）

日付：2026-09-22（リリース時間）　情報源：GDR 2026.03

サードパーティ GDB デバッグアシスタントフレームワーク GDR は、調査期間内に 2026.03 バージョンをリリースした。このフレームワークは GDB の Python インタプリタ内で動作し、RT-Thread と FreeRTOS ファームウェアのデバッグに 3 層のサポートを提供する：各リアルタイムシステム固有のコマンドツリー（スレッド、タイマー、ヒープの表示など）、カーネルオブジェクトの美化プリンタと便利関数（ネイティブ GDB 式でオブジェクトフィールドにアクセス）。新バージョンでは RT-Thread 側に rtt objects オブジェクト集約コマンドを追加し、ヒープとオブジェクトの出力を中性レンダラーに統一した。ヘルプ体系は git スタイルの構造化コマンドツリーにアップグレードされ、各項目のフィールド、使い方、設定依存、実装制限を説明する。同時に、初期化戦略検証の失敗が GDB セッションを直接終了させる問題を修正した。フレームワークは現在 RT-Thread 3.1.x / 4.0.x / 4.1.x をサポートし、Cortex-A9 と RV64 ターゲットの両方でクローズドループ検証を通過しており、RT-Thread サードパーティデバッグツールチェーンの活発なプロジェクトである。

3.3 GD32 下流リポジトリのドライバ更新ブランチが進行：PR #71 がリフレッシュされレビュー互動に入る（09-22）

日付：2026-09-22 13:37（北京時間、プッシュ時間）　情報源：PR #71

兆易創新の下流リポジトリ gd32_rt-thread の update_driver ブランチは、調査期間内に 1 件のドライバ更新コミットをプッシュし、レビュー中の PR #71 を同期リフレッシュし、リポジトリ側でレビューコメントの互動が発生した。この提案は USART、SPI、2 線シリアルバスドライバの GPIO 初期化バージョン更新を中心に展開され、旧版ドライバファイルを置換整理するもので、ベンダー自維護ブランチの継続的な作業であり、まだメインラインには還流していない。同組織の Zephyr 方向のリポジトリにもプッシュがあるが、本主題とは関係ない。

4. 業界応用

4.1 調査期間内に新規落地事例なし；工博会展展示品の構成が産業側の最近の動き（09-23）

期間内に新たな量産または商用化の事例はない。産業側の直近の動きは工博会展から来ている。睿赛德は会場で産業制御機器、移動ロボット、具身智能、飛控ユニットなどの実物展示品を集中的に展示し、端側 AI スマートカーの実習ワークショップを開催し（詳細は 2.1）、「下層システムから AI アプリケーションまで」の完全な体験チェーンをカバーしている。ロボットおよび具身智能の方向では、期間内に新たな提携や導入のニュースはなく、前週と同じペースである。

5. まとめとトレンド観察

5.1 直近1日のトレンド（09-22 ~ 09-23）

  • メインラインは静默、レビュー側は一夜に集中：メインラインは月曜日（09-21）午後の集中バッチ以降、2日連続でマージがなく、レビューキューは一夜で8件の提案が新規追加され、最近では珍しい。うち7件は歴史的な遺留問題に対する系統的な境界強化を構成し（いずれも検証説明を添付し、既存の欠陥レポートを引用）、1件は沁恒 CH32V203（RISC-V）ボード級サポートを補完するものである。
  • ベンダーのボード級は性能収束期へ移行：Titan Mini の OpenMV プロジェクトはリリースチェーンが整備された後、速やかに最適化段階に入り、ハードウェアクロックとメモリプールの調整により推論所要時間が倍単位で短縮され、業界メディアのフォローも得て、端側ビジョンというラインのエンジニアリング成熟度は着実に向上している。
  • サードパーティ製デバッグエコシステムにバージョン産出：GDR 2026.03 は RT-Thread オブジェクトコマンドとヘルプ体系を完善し、コミュニティ自発のデバッグツールチェーンは引き続き活発である。
  • 公式チャネルは静默三十四日目：製品とイベント情報は引き続き商城、フォーラム、業界メディアが首发している。公式サイトのニュース一覧ページは依然として直接確認できない。
  • コミュニティコンテンツはメンテナンス更新が中心：チュートリアル連載、コンテスト、アプリケーション系の旧スレッドは期間内にいずれも編集リフレッシュがあり、新規テーマはない。深層コンテンツの産出ペースは安定している。

5.2 限界と重複排除の説明

  • 重複排除の説明：工博会 Workshop（09-20 募集は既に収録済み、本期は開催回と内容詳細の補充）、RA8P1 OpenMV プロジェクト（09-18 既に収録済み、本期は性能最適化の増分）、GD32 PR #71（09-21 既に収録済み、本期はブランチ推進の増分）はいずれも増分報道である。チュートリアル連載第二章、RK3576 長スレッド、電賽プロジェクト（09-18、09-21 既に収録済み）は旧スレッドの編集更新であり、重複収録はしない。
  • 電子工程専輯の原サイトは直接アクセスできないため、Titan Mini 報道の要点は集約タイトルと公開時間に基づく。工博会展の会期は公式公開報道に基づき、Workshop の開催回詳細は 09-22 の稿件に基づき、最終的には主催者公告を基準とする。
  • 公式ニュースインターフェースと公式サイトニュース一覧ページの状態は前期と同じ（更新停止三十四日目、ページは直接確認できない）。
