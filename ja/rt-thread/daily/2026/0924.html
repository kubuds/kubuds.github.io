1. カーネルとバージョン動向

1.1 clang-format 自動コミットが CI をスキップしなくなる：フォーマットパイプラインを通常検証に統合（09-23）

日付：2026-09-23 16:30 ~ 16:34（北京時間、作成とマージの時刻）　出典：PR #11830、マージコミット

メインラインは期間内に継続的インテグレーションのフロー調整を1件マージした。clang-format 自動フォーマットコミットのコミットメッセージから「CI をスキップ」マークを除去し、以後はフォーマットコミットも通常のコミットと同様に継続的インテグレーションパイプラインをトリガーする。このマークは元々「自動フォーマットコミットがさらに CI を1ラウンドトリガーする」ループを避けるためのもので、その代償としてフォーマット結果がビルド検証を経ずに直接リポジトリに入っていた。調整後はフォーマット動作も通常の検証経路に組み込まれる。対応するワークフローファイルがこの提案の唯一の変更ファイルであり、提案はコミュニティ貢献者によって提出され、作成から約4分でマージが完了した。

1.2 レビューキューの期間内に新たな提案2件：netdev ビルド修正と GD32H77D ペリフェラルシリーズ（09-23）

日付：2026-09-23 11:05 / 15:41（北京時間、提案時刻）　出典：PR #11828、PR #11829

レビューキューは期間内に新たに2件の提案を開いた。1件目はネットワークコンポーネントの小規模な修正（#11828、netdev の AF_NETLINK ビルドエラー）：構造体の前方宣言を補い、ルート通知コールバック内のノードインデックス参照を一時変数から直接リストノードを取得する方式に変更し、関連設定の組み合わせを有効化した際のコンパイルエラーを修正する。2ファイルに関わる。2件目は大規模なベンダーボード級提案（#11829）——GD32H77D GinoPi ボードペリフェラルシリーズで、計19コミット、142ファイルに及ぶ。詳細は第3章 3.1 を参照。

1.3 公式ニュースインターフェースは連続35日間新規なし（09-24）

日付：2026-09-24（確認時刻）　出典：RT-Thread 公式ニュースインターフェース

公式ニュースインターフェース（rt_org カテゴリ）は依然として古いエントリ5件のままで、最新も依然として 2026-06-17 の報道であり、連続35日間新規なし。公式サイトのニュース一覧ページは期間内の確認でも読み込み失敗のプロンプトを返し、直接確認することができない。製品とイベントの情報は引き続きフォーラム、ストア、業界メディアのチャネルから先行発信されている。

2. 公式・コミュニティ活動

2.1 RSOC26 サマーキャンプチュートリアルの体系化を推進：期間内に「第1章 開発環境、BSP 設定とデバイスモデル」を更新（09-23）

日付：2026-09-23 15:22（北京時間、更新時間）　情報源：フォーラム記事 5a5a1f34db847d92

コミュニティフォーラムは調査期間内に RSOC26 系チュートリアル「第1章 開発環境、BSP 設定と RT-Thread デバイスモデル」を更新し、ゼロからデバイスモデルまでの完全な主线を示した：RT-Thread Studio をインストールし、SDK マネージャ経由でカーネルソースコードとチップサポートパッケージをデプロイ；「チップベース」方式で新規プロジェクトを作成（星火一号プラットフォーム STM32F407ZG、カーネル 4.1.1、USART1 コンソール、ST-LINK と SWD デバッグ）；BSP プロジェクトディレクトリ構造と board.c / board.h の役割を解析（クロックツリー 168 MHz、システムティック、ヒープ境界）；I/O デバイスモデルの三層アーキテクチャと GET_PIN ピン番号メカニズムを解説；そして GPIO ハートビート LED とシリアルプリントによりコンパイル、書き込み、FinSH（MSH）コマンドライン検証を完了した。本稿はこれまで散発的に公開された星火一号実践篇目と章立て化された編成を形成し、サマーキャンプチュートリアルの体系的な開篇に属する。

3. エコシステムとベンダー適配

3.1 Gino Pi メインライン BSP 提案がレビュー入り：GD32H77D ペリフェラルシリーズ 19 コミット、142 ファイル（09-23）

日付：2026-09-23 15:41（北京時間、提案時間）　情報源：PR #11829

兆易創新 GD32H77D ボード Gino Pi のボードサポートがシリーズ提案形式でメインラインレビューに提出された：単一ブランチ 19 コミット、142 ファイル、純増約 2.6 万行。内容は三層をカバーする：ボードレベル骨格（プロジェクト、リンクスクリプト、rtconfig）；ペリフェラルフルセット——イーサネット、USB ホストとデバイス、SDRAM、ハードウェア I2C、SPI3、PWM、SDIO とファイルシステム、RTC とアラーム、ウォッチドッグ、CAN と CAN FD、OSPI Flash、MIPI LCD、GT911 タッチ、OV7670 カメラと LVGL；そして GinoPi ペリフェラルデモプロジェクトと全 BSP コンパイルチェックのマウント。さらにオンボード GD32VW553 無線モジュールの Wi-Fi と MQTT サポートを含み、コミット説明には同モジュールの UART4 AT 通信と MAC クエリが検証済み、Wi-Fi アソシエーションは未完了であることが注記され、モジュールとサンプルはデフォルトで無効。本ボードはこれまでに Studio SDK インデックス、販売、デバッグチェーン補完を完了しており（3.2 参照）、本期は「ベンダー SDK からメインラインへ」の実質的な一歩であり、現在レビュー中である。

3.2 GD32 デバイスサポートパッケージと Wi-Fi コンポーネントの三リポジトリ同期：H77x_78x デバイス/ペリフェラルライブラリと GD32VW553 ネットワーク接続サポート（09-23）

日付：2026-09-23 16:01 ~ 16:10（北京時間、プッシュ時間）　情報源：gd32-arm-cmsis コミット、gd32-arm-series コミット、at_device コミット

メインライン提案と同じ日の午後、RT-Thread デバイスサポートパッケージ組織の三つのリポジトリが相次いで基盤的更新を完了した：CMSIS デバイスサポートパッケージ（gd32-arm-cmsis）と GD32 ペリフェラルライブラリサポートパッケージ（gd32-arm-series）はそれぞれ GD32H77x_78x サポートを追加し、H77 シリーズチップに CMSIS デバイス層と新ペリフェラルライブラリを提供；AT コンポーネントリポジトリ（at_device）は GD32VW553 Wi-Fi デバイスと TCP socket サポートを追加し、この無線モジュールが AT チャネル経由でネットワークコンポーネントに接続可能とした。三つのコミットはメインライン BSP 提案と同じ時間窓内にプッシュされ、Gino Pi ソフトウェアスタックの一度の同期整備を構成する。

3.3 ソフトウェアパッケージインデックス三連マージ：CanopenNode v1.2.0 設定リファクタリング、仮想センサー新パッケージ、AI Agent に MQTT ツール追加（09-24）

日付：2026-09-24 09:23 ~ 09:25（北京時間、マージ時間）　情報源：CanopenNode v1.2.0 マージ、仮想センサーパッケージマージ、AI Agent 設定マージ

ソフトウェアパッケージ索引リポジトリは調査期間内に三件の提案を集中的にマージした（いずれも 9 月 11 日 ~ 14 日提出、調査期間内にレビュー完了）。一つ目は CanopenNode v1.2.0 で、9 個の Kconfig ファイルを再構成し、従来の CiA 401 デバイス worker スイッチを汎用デバイスプロファイル体系に統合した——純粋な C、ヒープ割り当てなし、リアルタイムシステムと疎結合の論理デバイスレジストリを新設し、さらにプロファイルコントローラの転送契約と RT-Thread マスター転送オプションを追加、産業バスコンポーネントの設定構造がモジュール化へ前進した。二つ目は新ソフトウェアパッケージ「仮想センサー」：模擬センサーデータ生成を提供し、オプションで MQTT 経由の報告が可能（paho MQTT と cJSON コンポーネントに依存）、ハードウェア条件のない統合テストや教育シナリオ向けで、パッケージソースは作者が維持する独立リポジトリを指す。三つ目は AI Agent ソフトウェアパッケージの設定更新：MQTT ツールおよびその broker アドレスなどの設定項目を新設し、同時に rt_vsnprintf 能力の自動検出機構を導入した——「カーネルが当該シンボルを定義済みか」を判定基準とし（バージョン番号の適用ではなく）、完全版フォーマットソフトウェアパッケージを有効化するか自動決定し、4.1.x カーネルでの重複定義によるリンク失敗を回避し、浮動小数点フォーマットなどの完全な能力が利用可能であることを保証する。

3.4 瑞薩 RA8P1 Titan Mini OpenMV に RGB LCD 表示とビジョン例を新規追加（09-24）

日付：2026-09-24 09:42（北京時間、コミット時間）　情報源：コミット 98076cf8、Titan Mini OpenMV リポジトリ

Studio BSP 組織下の瑞薩 RA8P1 Titan Mini リポジトリは調査期間内に一笔の機能コミットをプッシュした（17 ファイル、約 1200 行追加）：OpenMV プロジェクトにオンボード RGB インターフェースの 800×480 スクリーン（RGB565）を接続し、LCD ドライバと MicroPython の lcd モジュールを補完し、併せて表示アダプテーション、NPU とランタイム関連ファイルおよび machine_pin / machine_pwm などのマシンモジュールを調整した。サンプル側では LCD 基本表示（カラーバー、文字、図形、2 倍拡大とバックライト調整）、カメラプレビューと赤色ブロック追跡の二つのビジョン例を新規追加し、バックライトは LCD が統一的に管理する（GPT7 を占有）。当該プロジェクトは以前に OpenMV リリースチェーンと性能最適化を完了しており（09-18、09-22 収録済み）、今期は性能収束から表示とサンプル拡張へ転換し、エンド側ビジョンデモチェーンがさらに完全になった。

調査期間内に新規の量産、商用または提携実装事例はない。産業側の最近の動きは前の調査期間に集中している：工博会展エンド側 AI スマートカーワークショップ（10 月 13 日専場）と Gino Pi 発売後のエコシステム推進（第 3 章参照）。教育側では、RSOC26 サマーキャンプ教程が引き続き体系的な出力を継続（2.1 参照）。ロボティクスおよび具身智能方向では調査期間内に新規展開情報はなく、前週のリズムと一致している。

5. まとめとトレンド観察

5.1 直近一日のトレンド（09-23 ~ 09-24）

  • Gino Pi 全スタックが同日開通：メインライン BSP 提案（19 笔コミット、142 ファイル）、デバイスサポートパッケージ両リポジトリ（H77x_78x）とネットワークコンポーネント（GD32VW553）が一つの午後に同期プッシュされ、ボードは「Studio SDK とベンダーダウンストリーム」から「メインライン保守可能」へと移行した。これは兆易創新と睿賽徳の提携ラインにおける最近で最も実質的な一歩である。メインライン提案は依然レビュー期間中にある。
  • ソフトウェアパッケージ索引の集中マージ：約二週間滞留した三件の提案（CanopenNode モジュール化設定、仮想センサー新パッケージ、AI Agent の MQTT ツールとフォーマット能力自動検出）が同日マージされ、産業バス、教育統合テスト、エンド側 AI の三方向でコミュニティパッケージが持続的に厚みを増している。
