1.1 sal 層 SIOCGIFCONF バッファオーバーフロー修正がメインリポジトリにマージ（#11774）

日付：2026-09-07（14:53 北京時間マージ、すなわち 06:53:10Z）　出所：RT-Thread/rt-thread commits（PR #11774）

昨日のレポートでレビューキューに掲載された #11774 [components][sal] Fix SIOCGIFCONF buffer overflow（Huoyanlifusu コミット）が、09-07 午後に正式に master へマージされた。この PR は 09-07 朝に Rbb666 から CHANGES_REQUESTED の差し戻し意見を受けていたが、著者は同日中に修正版を再プッシュし（昨日収録済み）、今回のマージをもって「差し戻し—再プッシュ—マージ」のラウンドが完了した。修正は sal 層 SIOCGIFCONF（インターフェースアドレスリスト取得）ioctl 処理におけるバッファオーバーフローリスクに対応するもので、ネットワークコンポーネントのメモリ安全性に分類される修正である；マージ時刻は昨日朝の4 PRバッチの後で、期間内で唯一の新規マージとなった。release は依然として v5.2.2（2025-10-31）であり、新バージョンリリースの動きはない。

1.3 レビューとキューの動向：新規 PR #11785 FRDM-MCXC162 BSP、#11782 AT 数値型ホスト名境界修正；#11775 C908 に2件のコミットを追加；旧 NXP BSP PR を集中的に整理

調査期間内に新規 PR が2件オープンされ、レビューキューには継続的な動きがある：

  • #11785 [bsp][nxp] Add FRDM-MCXC162 BSP support（yandld、09-07 17:52 作成、今朝 10:53 時点でも更新あり）：NXP FRDM-MCXC162 開発ボード BSP を追加。yandld は NXP BSP の長期貢献者であり、これまでにも NXP シリーズ BSP を複数回コミットしている；MCXC1xx は NXP のエントリーレベル MCU シリーズ（Cortex-M0+）であり、本 PR は NXP エコシステムのボードカバレッジの恒常的な拡充を継続するもの。現在もレビュー中。
  • #11782 [net][at] Reject overlong numeric hostnames（wyf-777、09-07 12:08 作成）：_gethostbyname_by_device() は数値型ホスト名を strncpy(ipstr, name, strlen(name)) で 16 バイトのスタックバッファにコピーしていた——16 バイトの入力は終端文字を飲み込み、17 バイト以上の入力は範囲外書き込みとなる；修正により超過長の数値型ホスト名を拒否する。ネットワークコンポーネントのメモリ安全性パッチであり、#11774 と同じく最近の安全性/堅牢性修正の方向性に属する。

1.4 OSPP 2026 議題提案：RISC-V Lazy FP/RVV コンテキストスイッチ（#11786）

日付：2026-09-07（23:49 北京時間作成、すなわち 15:49:05Z）　情報源：RT-Thread/rt-thread issue #11786

外部貢献者 PiyushPatle26 がメインリポジトリに OSPP 2026 議題提案（issue #11786）を提出：RISC-V 移植は現在、コンテキストスイッチのたびに無条件で完全な FPU 状態を保存/復元しており、スレッドが浮動小数点を全く使用しなくても実行される；同時にカーネルはベクトル拡張（RVV）を完全にサポートしていない——ベクトルレジスタはスレッドコンテキストに含まれず、V 命令を使用するスレッドの状態はコンテキストスイッチによって静かに破壊される。提案では、ハードウェアが既に提供している mstatus.FS / mstatus.VS ダーティビットを活用し、拡張状態の保存/復元を無条件実行ではなく遅延（lazy）モードに変更する。本議題は初期の issue #10722（RISC-V ベクトルサポートのギャップ）に関連する。この提案が採用されれば、カーネル RISC-V 移植における浮動小数点/ベクトル拡張コンテキスト管理の構造的改善となり、#11775（C908 rt-smart/MMU）と同じくカーネル側 RISC-V メインラインの推進に属する。調査期間内には他に2件の pin_api_attach_irq legacy パス IRQ パラメータ問題の issue（#11783 はクローズ済み、#11784 は追跡中、09-07 15:14/16:57 作成）があり、同一のドライバ登録問題のフォローアップ報告に属する。
