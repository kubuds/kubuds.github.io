1. カーネルとバージョン動向

1.1 3日間ゼロマージの終結：月曜朝のバッチで4件のPRをマージ、mmcsd AC5互換、MPU Kconfig、eclipseツールチェーン、hpmicro C++ビルドをカバー

日付：2026-09-07（マージ期間 10:19 ~ 11:18 北京時間、すなわち 02:19:23Z ~ 03:18:42Z）　出典：RT-Thread/rt-thread commits（PR #11690、PR #11766、PR #11762、PR #11777）

メインリポジトリ rt-thread は 09-03 #11776 以来、連続3期間（3日間）のゼロマージを終了し、月曜朝の1時間以内に連続して4件のPRをマージした：

  • #11690 [device][mmcsd] Fix Arm Compiler 5 build compatibility（CYFS3 コミット、08-10 作成、キュー内で最長約4週間）：AC5 で MMC/SD およびブロックデバイスコードをコンパイルする際の互換性問題を系統的に修正——汎用 SWITCH コマンド名が一部チップのレジスタマクロと衝突（MMC_SWITCH に改名し、飛騰 Phytium SDIF の呼び出し箇所も同期修正）；ARMCC5 に名前付き SD ステータスフィールドアクセス方法を提供（他のコンパイラは引き続き匿名フィールドインターフェースを使用）；typeof に依存するブロックデバイスリンクリスト走査を明示的な rt_list_entry に置き換え；DFS 無効時にパーティション構造体定義を補完；void * ポインタ演算を整理。
  • #11766 [mprotect][kconfig] Add safe defaults for MPU region count options（RogerNext コミット、08-28 作成）：NUM_MEM_REGIONS / NUM_CONFIGURABLE_REGIONS / NUM_EXCLUSIVE_REGIONS に Kconfig デフォルト値を追加。従来は RT_USING_HW_STACK_GUARD を有効にしても明示的に設定しない場合、rtconfig.h が空のマクロ（#define NUM_CONFIGURABLE_REGIONS）を生成し、不正な C 式（(2 + )、for (i = 0U; i < ; i++)）に展開されて、cortex-m4/m7/m33 の MPU コードのコンパイルが失敗していた。
  • #11762 [tools][eclipse] Sync assembler include paths（wdfk-prog コミット、08-28 作成）：eclipse プラグインプロジェクトのアセンブラ include パスを同期、公式ツールチェーン（eclipse プラグイン）ビルドの一貫性修正。
  • #11777 [bsp][hpmicro] wire CXX/CXXFLAGS from rtconfig into scons Environment（kaidegit コミット、09-01 作成）：hpmicro BSP（先楫半導体 HPM シリーズ）で RT_USING_CPLUSPLUS を有効にすると、scons Environment が rtconfig の CXX/CXXFLAGS を接続せずホストの g++ にフォールバックし、C++ グループのコンパイルパラメータが単一のクォートされていない引数として扱われてビルドが失敗；修正後は CXX/CXXFLAGS を scons 環境に注入。

当該バッチはメンテナ Rbb666 の同日朝の集中的なレビュー（1.2 参照）と同じ時間帯に発生し、メインリポジトリは「蓄積期」から「マージ＋レビュー双方活発」へ移行；release は依然 v5.2.2（2025-10-31）で、新バージョンのリリース動作はまだない。

1.2 レビューキューが集中的に活発化：#11774 が差し戻された後、当日再プッシュ、#11775 が再レビューに回付、#11770 が行内提案を受領；新 PR #11781 が着地

日付：2026-09-07（北京時間 10:16 ~ 11:18）　情報源：RT-Thread/rt-thread pulls

マージバッチと同じ時間帯に、メンテナ Rbb666 がレビューキューを集中的に処理：

  • #11774 [components][sal] Fix SIOCGIFCONF buffer overflow（Huoyanlifusu）：02:30:45Z に Rbb666 の CHANGES_REQUESTED レビュー意見を受領、著者は当日 03:04:48Z に早くも新規コミット（[components][sal] Fix SIOCGIFCONF buffer overflow）をプッシュして応答、ラウンドのテンポは速い。
  • #11775 [bsp][c908] rt-smart と MMU Sv39/48 サポート（QEMU xiaohui c908、OpenSBI SMP 含む）（BadmintonMaster）：Rbb666 が 02:18:28Z に「@rcitach レビューをお願いします」とコメントし、別のメンテナに再レビューを委譲；本 PR は達摩院玄鉄 C908 の QEMU xiaohui プラットフォームにおける rt-smart と OpenSBI SMP のサポートで、RISC-V 関連。
  • #11770 fix[usb]: stop aliasing rt_ringbuffer as rt_serial_rx_fifo in VCOM（Finder16）：Rbb666 が 03:17:12Z に components/legacy/usb/usbdevice/class/cdc_vcom.c:358 へインライン提案を残した——rx_bufsz == 0 のポーリング受信パス（Serial V2 がデバイスを開く前に config.rx_bufsz を 0 に設定し RT_SERIAL_RX_BLOCKING を採用する場合にポーリングモードへ入り、serial_rx を割り当てない）を補足し、サンプルパッチを提示。
  • #11772 [components][asan] Add runtime AddressSanitizer for heap（RogerNext）：02:16:58Z に Rbb666 のレビューコメント（COMMENTED）を受領。

新規 PR について：#11781 [BSP][STM32] Adapt Ethernet driver to new HAL API（CYFS3、09-06 15:17 北京時間作成）が調査期間内に着地、STM32 イーサネットドライバを新版 HAL API に適応、キュー内の #11689（stm32 SPI BDMA、moment-NEW）と同様に STM32 ドライバ近代化の主線に属する。期間内に新規 issue はなし。
