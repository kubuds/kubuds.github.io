1. カーネルとバージョン動向

1.1 玄鉄 C908 BSP マージ：QEMU virt64 プラットフォームが RT-Thread Smart をサポート

日付：2026-08-28（12:25 北京時間マージ）　出典：RT-Thread/rt-thread PR #11719

メインリポジトリの期間内で最も重要なマージ：feat[bsp][xuantie]: c908 support rt-smart。BadmintonMaster が代理コミット（元の commit は shuta.lst の rt-thread fork から）、コアメンテナ Rbb666 が 08-28 12:25（UTC 04:25）にマージ、計27ファイル。内容：bsp/xuantie/virt64/c908 ボードサポートパッケージを新規追加——QEMU RISC-V64 VIRT 仮想プラットフォームをベースとした達摩院玄鉄玄鉄 C908 プロセッサ移植で、RT-Thread Smart マイクロカーネルモード（カーネル/ユーザー空間分離）と標準モードのデュアルビルドをサポートし、ルートファイルシステム実行説明（link_smart.lds、run.sh）を併設。同時に SMP 適応のため libcpu/risc-v/common64/mmu.c を修正。ツールチェーンは Xuantie-900 GCC（musl 版、riscv64-unknown-linux-musl- プレフィックス）+ Xuantie QEMU エミュレータを採用。これは xuantie virt64 BSP ファミリーにおいて C910 などに続いて追加された C908 サポートであり、RISC-V ベクトル拡張コアの RT-Thread Smart ハイエンド応用シナリオにおける開発検証に QEMU 仮想化エントリを提供するもので、libcpu RISC-V 共通層の SMP/MMU 適応の継続的補強でもある。

1.2 qemu-vexpress-a9 バックトレースが関数名をサポート

日付：2026-08-28（11:29 北京時間マージ）　出典：RT-Thread/rt-thread commit 0ae80cc7

コミュニティ開発者 Hui Su がコミット：Cortex-A9 QEMU BSP で RT_BACKTRACE_FUNCTION_NAME を有効にした際、コンパイラとアセンブラに -mpoke-function-name を渡すことで、カーネルバックトレース出力に関数名を含め、デバッグを容易にする。変更は bsp/qemu-vexpress-a9/SConstruct 単一ファイルに集中しており、デバッグ体験の小規模な改善に属する。

2. 公式・コミュニティイベント

2.1 ライブ配信予告：ADC から DMA まで、データ収集コンポーネントをどう設計するか？

日付：2026-08-28（掲載）　出典：電子工程専輯（原文 eet-china.com/mp/a520847.html）

電子工程専輯は 08-28 に RT-Thread ライブ配信予告「ADC から DMA まで、データ収集コンポーネントをどう設計するか？」を掲載。トピック概要：第一に、なぜ ADC はデータ収集とイコールではないのか；第二に、周期サンプリングと DMA サンプリングの2つの経路をどう選ぶか；第三に、マルチチャネルインターリーブフレーム——スループットとリアルタイム性を両立させるためにデータをどう組織するか。このライブ配信は以前の「睿擎プラットフォーム RK3506 マルチチャネルデータ収集コンポーネントの設計と実践」（eet-china.com/mp/a520342）という記事の続編であり、同一テーマシリーズがエンジニアリング実践からライブ配信教学へと発展するもので、睿擎工業プラットフォームの産業制御データ収集方向における能力出力に対応する。原文サイトは本機からの直接接続が不可のため、詳細は検索インデックスの要約とタイトルに依拠する。

2.2 公式ニュース API、9日連続で新規追加なし、睿擎 Workshop 事後レポートも依然不在

日付：2026-08-29　情報源：RT-Thread 公式ニュース API

公式ニュース API（rt_org カテゴリ）は依然として 5 件の旧エントリのみで、最新は 2026-06-17 のアブダビ投資フォーラム報道、連続 9 日間新規追加なし；news / activity カテゴリのインターフェースは引き続き「分類データが存在しません」を返す。昨日のレポートで確認を予告した「睿擎工業プラットフォーム Workshop」（08-27 上海開催）の会後報道は、ウィンドウ内に依然現れていない：gnews の「睿擎 when:3d」は 10 件ヒットするが、そのすべてがフォード領睿、博越L i-HEV、吉利帝豪智擎などの語分割ノイズであり、「睿擎派」の完全一致検索はわずか 1 件で、しかも同じく領睿の動画である。公式発表のニュース面は引き続き平静で、メディア側は電子工程専輯のライブ予告 1 件のみ。睿擎 Workshop の後続報道は引き続き明日の観察ポイントとする。

3. エコシステムとベンダー対応

3.1 canopennode-rtt の継続的イテレーション：SRDO オブジェクト辞書とビルドテストの完善

日付：2026-08-29（11:10 北京時間コミット）　情報源：wdfk-prog/canopennode-rtt

RT-Thread 向け CANopenNode 統合ソフトウェアパッケージ（コミュニティ開発者 wdfk-prog メンテナンス）はウィンドウ内に 3 筆のコミットを追加：canopen[srdo] で J09/B09S オブジェクト辞書（SRDO、Safety-Relevant Data Objects、CANopen 安全関連データオブジェクト）を生成、MCU 診断テストフィクスチャ（test fixture）を追加、そして累積 B 段階ビルド設定（CI）。本パッケージは 08-25 より LSS（ノード設定）永続化とランタイムビットレート有効化のイテレーションに入り、08-27 に本デイリーレポートへ初収録（LSS ランタイムビットレート有効化）、本日も引き続き CANopen 安全拡張（SRDO）と工程化（CI/テスト）へと推進している。CANopenNode はオープンソースコミュニティで著名な CANopen プロトコルスタックであり、本パッケージは個人プロジェクト（1 star）で、まだ RT-Thread packages インデックスには入っておらず、エコシステム参考として注記する。

4. 業界応用

ウィンドウ内に新規の業界応用エントリはない。直近 3 日のトレンド：08-27 に電子工程専輯がマレーシア都市 IoT 顧客成功事例（洪水警報 + 大気汚染モニタリング、08-28 のデイリーレポートに収録済み）を掲載；睿擎工業プラットフォーム Workshop は 08-27 に上海で開催され、会後報道は引き続き欠落；本ウィンドウの業界側は睿擎プラットフォームのデータ収集ライブ教学が継続シグナルとなっている。

5. 総括とトレンド観察

  1. 玄鉄 C908 が RT-Thread Smart 仮想化検証入口を補完：QEMU virt64 プラットフォームに C908 BSP を新規追加し、RT-Thread Smart マイクロカーネルとルートファイルシステムの実行をサポート、あわせて libcpu RISC-V 共通層の SMP/MMU 対応変更を伴う——RISC-V アプリケーションプロセッサ方向（rt-smart）は達摩院玄鉄カーネルカバレッジにおいてさらに前進、これはウィンドウ内で最も価値のあるメインリポジトリへのマージである。
  2. 公式ニュース面は 9 日目も平静：ニュース API に新規追加なし、睿擎 Workshop 会後報道の欠落が継続；メディア側は電子工程専輯「ADC から DMA データ収集」のライブ予告 1 件のみ。
  3. 睿擎プラットフォームのコンテンツ出力はライブ教学へ転換：RK3506 マルチチャネルデータ収集工程実践（08-22 前後掲載）の後、公式はライブ形式で ADC/DMA データ収集コンポーネント設計シリーズを展開、工控データ収集方向は現在の睿擎エコシステムの対外メインラインの一つである。
  4. コミュニティ CANopen 安全能力は緩やかに成長：canopennode-rtt は LSS 設定から SRDO 安全オブジェクト辞書と CI/テスト完善へと進み、CANopen 産業バスエコシステムは RT-Thread 側で個人プロジェクトの形式により蓄積を続けている。
  5. メインリポジトリはウィンドウ内わずか 2 筆のマージ：C908 rt-smart（新規 BSP）+ qemu-vexpress-a9 回帰改善、全体は機能の間歇期にあり、昨日のルネサス BSP 収尾のリズムと一致している。

制限事項説明：電子工程専輯の原サイト（eet-china.com）はローカル直連がタイムアウトし、ライブ予告の詳細は検索インデックスの摘要とタイトルのみに依拠；睿擎 Workshop の会後報道は公式 WeChat チャネルのみに掲載された可能性があり、gnews は語分割ノイズが大きくカバーできない；canopennode-rtt は 1 星の個人プロジェクトで影響力は限定的であり、収録はエコシステム観察用に供するのみ。
