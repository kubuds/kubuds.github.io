1. カーネルとバージョン動向

1.1 メインリポジトリへの 2 件のマージ：Infineon PWM マクロ不整合修正のクローズ、国民技術 N32H4x USBFS デバイス側サポートの統合（09-21）

日付：2026-09-21 15:43 ~ 15:44（北京時間、マージ時間）　出典：PR #11802、PR #11764

期間内にメインリポジトリへ 2 件の提案がマージされ、いずれもレビューキューの既存項目のクローズである。其一つ目は Infineon ボードレベルの PWM マクロ不整合修正：チャネルポートのリネーム後に残ったマクロ定義の不一致が複数箇所で収束し、前期に収録した PSoC6 評価ボード BSP 修正と同源で、今回はメインラインでマージが完了しクローズした。二つ目は CherryUSB コンポーネントによる国民技術 N32H4x シリーズ USBFS デバイス側サポートの統合：この提案は今月中旬にすでにレビューキューに入っており、今回レビューを経て着地し、このシリーズチップの USB デバイス機能にコンポーネントレベルのサポートを補完した。いずれも修正と適配の類の変更であり、期間内に新機能レベルのマージはなし；メインラインは今週月曜午前の集中バッチ以降、新規プッシュはない。

1.2 レビューキューに 1 日で 8 件追加：N32H タイマー補完、STM32 イーサネット適配と lwip マクロ制御など（09-21 ~ 09-22）

日付：2026-09-21 16:11 ~ 09-22 03:25（北京時間、提案時間）　出典：PR #11812、PR #11819

期間内にレビューキューへ 7 件の提案と 1 件の欠陥報告が追加され、1 日あたりの密度は近年まれに見るものである。最も規模が大きいのは国民技術 N32H シリーズのタイマー補完（39 ファイル、約 4 千行）：N32H47x_48x と N32H49x と H7xx はドライバファイルを共用しており、従来は H7xx ブランチのみ実装されていたため、2 枚の評価ボードでクロックタイマー、低電力タイマー、PWM、パルスエンコーダがいずれもコンパイルで空になっていた；今回は両シリーズのブランチを補完し、実際のクロックツリーに基づいて周波数を読み戻し、継続的インテグレーションのカバレッジも整備し、前期のドライバ拡張作業を引き継いだ。その他の提案は以下をカバー：STM32 新イーサネットドライバの ops 層適配と PHY 型番の追記、adcv2 ドライバのデフォルトログレベルの同期引き下げ；lwip コンポーネントの一部内容のマクロスイッチ化；Renesas RA6W1 BSP のシステムリソース割り当て最適化；単体テストの性能ケースのクロック依存とビルド保護の修正；ESP32-C3 の Windows 下でのビルドパスマッチング修正；bluepill BSP ドキュメント修正（LED ピン表記と空リスト項目）および付随する欠陥報告（クイックスタートに MDK プロジェクト再生成手順が欠けており、ドキュメント通りに操作してもコンパイルできない）。レビューキューは国産マイクロコントローラ適配とビルド類の修正が中心という構造が継続している。

日付：2026-09-22（確認時間）　出典：RT-Thread 公式ニュースインターフェース

官方ニュースインターフェースが今回返したアーカイブ稿の最新条目の日付は依然として 2026-06-17 で、調査期間内に新規追加はなく、33 日連続で更新停止となっている。公式サイトのニュース一覧ページは引き続き読み込み失敗の状態を返しており、直接確認することができない。製品販売とイベント情報は引き続き公式アカウント、公式サイト商城、フォーラムのチャネルから先に発信されており、今回の商城稿の更新（3.2 参照）もこのチャネルからのものである。

2. 公式・コミュニティイベント

2.1 臨港「シーン直通車」第 2 期開催：睿赛德がニーズ非公開マッチング専場を開設（09-20 報道、追記）

日付：2026-09-18（イベント）/ 2026-09-20（報道）　情報源：解放日報・上観新聞

「臨港科創城・シーン直通車」第 2 期——AI 大規模モデルとエージェントの工場進出専場イベントが 09-18 に臨港で開催され、臨港新片区管理委員会が主催した。「政府が場を設け、チェーンリーダーが出題し、企業が解答する」という需給マッチングモデルを採用し、ベンチマーク事例の共有、チェーンリーダーのニーズ発表、スタートアップ企業のクイックピッチを集めた。イベントでは 4 つの分科非公開サロンが設けられ、うち「睿赛德ニーズ非公開マッチング会」は RT-Thread 睿赛德の専場として、その専門ニーズと AI 技術供給側との間で的を絞った商談を行った。残りの 3 つはそれぞれ大規模モデルとエージェントの工場進出、中微のシーンニーズと航発通航動力のニーズに焦点を当てた。この報道は 09-20 に公開され、前号では収録できなかったため今回追記したもので、睿赛德が臨港の工業・スマート製造エコシステムのシーンマッチングに継続的に参加していることを示している。

2.2 フォーラム MCU シリーズが GNU リンカスクリプト長文を更新（09-22）

日付：2026-09-22 08:35（北京時間、更新時間）　情報源：フォーラム記事 bcc6d010c550766f

コミュニティ作者「大目熊」の MCU 低層シリーズが調査期間内に GNU リンカスクリプトの長文を 1 本更新した（このシリーズではこれまで probe-rs 書き込みデバッグ、C ランタイムライブラリの起動フローの各篇を収録済み）。記事は STM32F103 プロジェクトを例に、まずオブジェクトファイル内のセクション構造（.text/.data/.bss/.rodata）とリンカによる一貫した統合を説明し、次に MCU にメモリ管理ユニットがない下でアドレス計画をなぜリンカスクリプトで明示的に配置しなければならないかを解説し、さらにベアメタルプログラム向けの GNU ld スクリプトの書き方を示して、実行アドレスとロードアドレス、.data のコピー、.bss のゼロクリア、割り込みベクタテーブルなどの概念を完全なチェーンとしてつなぎ、B 站の配套動画も添えている。体系的な連載であり、前 2 篇とともに「デバッグ—起動—リンク」という低層のピースを構成している。

3. エコシステムとメーカー適配

3.1 Gino Pi BSP SDK の一括補鏈：J-Link 依存が全プロジェクトをカバー、リンカスクリプトとテストフレームワークを修正（09-21）

日付：2026-09-21 11:38（北京時間、プッシュ時間）　情報源：Gino Pi BSP SDK リポジトリ

Gino Pi（GD32H77D）ボードの Studio BSP SDK は調査期間内に 3 件のコミットをプッシュし、19 ファイルに関係して、エンジニアリングの細部を中心に一括補鏈を行った。第一に、SDK マニフェストが約 110 行追加され、すべてのサンプルプロジェクトに J-Link デバッガ依存を補完し、前号で収録した J-Link サポートがプロジェクト作成と依存インストールの段階で正式に有効になるようにした。第二に、ユニットテストのパフォーマンスケースの依存宣言（設定項目とビルドスクリプト）を修正し、その依存設定を正した。第三に、16 のサンプルプロジェクトの GCC リンカスクリプトを統一的に修正し、ユニットテスト関連セクションを保持処理し、初期化配列を読み取り専用としてマークした。この SDK はボード販売の前後からデバッグとテストのチェーン上で細部を補完し続けており、今回はこのペースを継続している。

3.2 公式サイト商城 Gino Pi 販売稿更新：購入チャネルと初回レビューイベントを明確化（09-22）

日付：2026-09-22 07:51（北京時間、更新時間）　情報源：商城販売稿 05086f4d786c7a0b

Gino Pi 販売稿が調査期間内に更新され、以前に収録した販売消息（09-15、当時は集約要約に準拠）の際に欠けていた公式の要素を補った。稿件は現在、公式淘宝商品リンク、80 元初回優待クーポンの受け取り方法（「Gino Pi 興趣小組」への参加）、および初回レビューイベントの予告——初回購入ユーザーが後日周辺機器タスクを完了するとキャッシュバックに参加できる——を提示している。ボード仕様表、サンプルプロジェクト一覧、SDK リポジトリ、開発ボード文書センターの入口はすでに明記されている。ボードと SDK の情報は以前の収録と一致しており、今回は販売運営とコミュニティインタラクションの要素の補完に属する。

日付：2026-09-21 ~ 2026-09-22（確認時間）

調査期間内に新規の量産または商用落地ケースはない。前期に収録した 2 つのコミュニティ手がかり——RK3576 ボードの異種 AMP ネットワーク長文（09-21 収録）と 2026 電賽 H 題バランスローリングボールプロジェクト（09-18 収録）——は、調査期間内はいずれも既存スレッドのメンテナンス更新であり、重複報道は行わない。ロボットおよび具身智能の方向では調査期間内に新規の動きはなく、前週のペースと一致している。

5. まとめとトレンド観察

5.1 直近1日の動向（09-21 ~ 09-22）

  • メインラインは月曜午後に収束、活発さはレビュー側へ移行：2件のマージはいずれも既存項目のクローズ；1日で新規8件の提案と欠陥は最近では珍しく、うちN32Hタイマー補完の1件は約4000行、レビューキューは国産マイクロコントローラのボード級およびビルド系パッチが主体。

  • 公式チャネルは33日目に沈黙：製品とイベント情報は引き続き商城、フォーラム、メディアチャネルが初出、本期の商城稿更新と臨港イベント報道はいずれも非公式ニュースインターフェースチャネル発。

  • 臨港イベント報道（09-20発表）は前期窗口の範囲内にあり、前期に収録できなかったため、本期に補録し、タイトルおよび本文に日付を明記。
