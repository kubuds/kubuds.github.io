1. カーネルとバージョン動向

1.1 公式 Env ツールチェーンに WebUI プラグイン状態保持（keep_alive）機構をマージ

日付：2026-09-05（09-05 00:08 北京時間にマージ）　出典：RT-Thread/env PR #294（マージコミット）

RT-Thread 公式開発補助ツール Env（リポジトリ RT-Thread/env）に、創業者 BernardXiong（熊譜翔）が提出した PR #294「Add opt-in state retention for plugin WebUI pages」がマージされた。中核となる変更：プラグイン manifest.webui にオプションの keep_alive フィールド（デフォルト false）を追加し、有効化するとプラグイン WebUI の iframe がプラグインページ、設定ページ、プラグインセンター間のナビゲーション切り替え時にマウントを保持し、毎回リロードされなくなる（未有効化のプラグインは従来のリロード動作を維持）；同時に WebUI 上部バーを削除し、「WebUI 終了」操作をサイドバー下部へ移動、プラグインごとに静的リソースを分離、サンドボックス化された WebUI ページにオプションのバックエンド HTTP/WebSocket コンテキストを開放した。本 PR は 09-02 以降の env ブランチにおける一連の WebUI 改修（プラグインごとの iframe ライフサイクル管理、プラグインリソーストークンと CSP 境界、doctor リクエスト世代検証など、feature/ws ブランチ）を引き継ぐもので、今回のマージは Env の WebUI プラグインシステムが「切り替え即リロード」から「ページ状態をオンデマンドで保持」へアップグレードしたことを示す。公式ツールチェーンの体験イテレーションであり、本期間内で org 内唯一のマージでもある。

1.2 メインリポジトリは期間内マージゼロ・新規 PR ゼロ、蓄積期が継続；CAN リファクタリング PR #11779 に新たな進展なし

日付：2026-09-05　出典：org:RT-Thread リポジトリ一覧（commits / pulls インターフェース）

メインリポジトリ rt-thread は2期連続で新規コミットのマージなし（直近のマージは依然として 09-03 早朝の #11776、昨日収録済み）、期間内に新規 PR 作成もなく、release は依然として v5.2.2（2025-10-31）。レビューキューの状態は昨日と横ばい：CAN フレームワークリファクタリング PR #11779（wdfk-prog、2 commits、+2902/-1308）の最後のコメントは依然としてメンテナ CYFS3 の 09-03 17:47（北京時間）の発言——別途 CAN_V2 フレームワークを維持することは推奨せず、開発者に共同でマージを推進してほしいという内容で、期間内に新規コメント・コミットなし；#11775（[bsp][c908] rt-smart と MMU Sv39/48 サポート）、#11772（ヒープ実行時 AddressSanitizer）、#11774（sal SIOCGIFCONF オーバーフロー修正）、#11689（stm32 SPI BDMA）などはいずれも open のまま動きなし。カーネル側はマージ後の通常の蓄積期に入っている。

2. 公式・コミュニティイベント

2.1 公式ニュース API は16日連続で新規追加なし、elexcon 2026 まであと4日

日付：2026-09-05　出典：RT-Thread 公式ニュース API

公式ニュース API（rt_org カテゴリ）は依然として 5 件の旧エントリのままで、最新も 2026-06-17 のアブダビ投資フォーラム報道のまま、連続 16 日間新規追加なし。次の対外ウィンドウは 9 月 9-11 日の深圳 elexcon 2026（睿賽德出展、8-30 予告は既に収録済み）で、カウントダウン 4 日。中国語情報源側の gnews 3 日間ウィンドウ再確認：OSChina の既収録の命題報道（09-03）を除き、新たに電子工程専輯のコンテンツ 2 件がヒット（3.2、3.3 参照）。コミュニティとメーカー側のコンテンツ産出は依然継続しており、静黙は公式ニュースチャンネル自体に限られていることを示している。

3. エコシステムとメーカー対応

3.1 canopennode-rtt に CiA402 周期同期モード CSP/CSV/CST を新規追加、モーション制御モード面を補完

日付：2026-09-05（11:08 北京時間 push）　情報源：wdfk-prog/canopennode-rtt

topic:rt-thread エコシステムリポジトリ canopennode-rtt のデフォルトブランチウィンドウ内に新規コミット「feat: support CiA 402 CSP CSV and CST modes」があり、CiA402（DS402 モーション制御プロファイル）に周期同期位置（CSP）、周期同期速度（CSV）、周期同期トルク（CST）の 3 種の周期同期モードを追加。09-03/09-04 にマージされた多軸デバイスプロファイルおよび PP/PV/Homing の位置決め/速度/原点復帰モードと連携し、DS402 サポートが非周期モードから周期同期クローズドループモードへ拡張され、モーション制御機能面が補完された。同作者がメインリポジトリで Generic CAN フレームワーク再構築（#11779）を同時に進めていることと合わせ、「アプリケーション層（CANopenNode 拡張）+ フレームワーク層（CAN 再構築）」の二本立て並行の態勢が継続しており、CAN/モーション制御は依然として現在のコミュニティで最も活発な推進主線である。

3.2 電子工程専輯コラムがコミュニティ作品を紹介：FRDM-MCXN947 USB モニタサブディスプレイ

日付：2026-09-04（17:30 北京時間）　情報源：電子工程専輯 a522648（RT-Thread フォーラム原作）

電子工程専輯「オープンソースプロジェクト共有」コラムが 09-04 に記事を掲載し、NXP FRDM-MCXN947 開発ボードベースの USB Monitor プロジェクト実践を紹介：RT-Thread オペレーティングシステム + LVGL グラフィックライブラリ + CherryUSB プロトコルスタックを通じて、PC 側の CPU、GPU などの稼働状態をリアルタイムでサブディスプレイに表示することを実現。本作品は RT-Thread フォーラム「24 組み込み設計コンテスト」の「USB 一本通モニタサブディスプレイ」プロジェクトに由来し、コミュニティ作品が業界メディアに転載・拡散される典型例であると同時に、RT-Thread が NXP 新プラットフォーム（MCXN947、デュアルコア Cortex-M33）上で LVGL/CherryUSB エコシステムと連携した際の開箱即用度を示している。EET 原サイト本文は直接アクセス不可、リンクを証跡として保存。

3.3 極海「極海芯得 EP.87」：RTT-Studio 環境下での APM32 ペリフェラルドライバ使用ガイド

日付：2026-09-03（11:30 北京時間；本日 3 日間ウィンドウ再確認で追加収録、昨日の zh クエリではヒットせず）　情報源：電子工程専輯 a522255

極海半導体（Geehy）開発者コミュニティ「極海芯得」シリーズ第 87 回（電子工程専輯 09-03 公開）：RTT-Studio 環境下での APM32 ペリフェラルドライバ使用ガイド。記事では RT-Thread Studio で APM32 プロジェクトを新規作成した後、adc、dac、hwtimer、uart などのペリフェラルドライバの使用方法を解説し、APM32 の RT-Thread ペリフェラルドライバは下層のピン初期化とペリフェラルクロック開啟を既にドライバ内部にカプセル化しており、開発者はデバイスモデルインターフェースで直接呼び出せることを指摘している。チップ原廠による RT-Thread エコシステム向けの継続的なチュートリアル産出に属する（本シリーズはこれまでに APM32 シリーズの RT-Thread BSP 移植、LwIP、LVGL、CherryUSB などのテーマを既にカバー）。APM32 ユーザーと Studio 入門者にとって直接的な参考価値がある。

3.4 エコシステム参考：H120D ドローン RT-Thread 内部機構リバースドキュメントプロジェクト更新

日付：2026-09-05（07:31 北京時間 push）　情報源：H4ck3rTR/h120d-protocol

サードパーティ製リバースエンジニアリング文書プロジェクト h120d-protocol（stars 4）が調査期間内に更新：Holy Stone H120D 航撮ドローンの WiFi プロトコルリバースデータパケット、RT-Thread 内部機構の説明および付属制御ツールを整理。本プロジェクトは独立愛好家によるリバース文書化作業（非公式）であり、コンシューマ向けドローン向けファームウェアにおける RT-Thread の内部機構（スレッド／メッセージ等）と私有 WiFi プロトコルを併せて文書化しており、RT-Thread がコンシューマエレクトロニクス／ドローン製品で実際にどのように実装されるかの形態を研究する上で一定の参考価値があり、エコシステム参考として収録。

4. 総括とトレンド観察

  • ツールチェーン側：公式 Env ツールが PR #294 をマージ——WebUI プラグインシステムに opt-in 状態保持（keep_alive）、プラグイン単位のリソース隔離とサンドボックスコンテキストを導入、創業者 BernardXiong が自らマージし、公式開発者ツールの体験イテレーションが加速。
  • カーネル側：メインリポジトリは2調査期間連続でゼロマージ、ゼロ新規 PR（直近 #11776 は 09-03）、CAN フレームワーク再構築 #11779 のレビューは新たな進展なし（CYFS3 が 09-03 に表明後、コミュニティの反応待ち）、蓄積期間が継続；release は依然 v5.2.2。
  • エコシステム側：canopennode-rtt が2日以内に CiA402 を多軸 + PP/PV/Homing から周期同期 CSP/CSV/CST 全面カバーへと推進、モーション制御の主線が活発；中国語エコシステムのコンテンツ側では、電子工程専輯が RT-Thread 関連作品の共有（FRDM-MCXN947 USB モニタ副画面）とチップ原廠チュートリアル（極海 EP.87）を継続的に制作。
  • 公式側：公式ニュース API は16日連続で沈黙、elexcon 2026（9/9-11 深圳）まで残り4日、会前の沈黙は想定内のリズム。
  • 直近3日のトレンド（09-03 ~ 09-05）：メインリポジトリ #11776 マージ、CiA402 多軸と PP/PV/Homing、CAN 再構築レビューで意見の相違が生じ、メンテナから「CAN_V2 は作らない」との表明（09-03）→ env WebUI 改修推進、EET がコミュニティ作品を転載、公式沈黙15日目（09-04）→ env PR #294 マージ、CiA402 周期同期モード実装、公式沈黙16日目（09-05）。現在の推進主線は「公式ツールチェーン WebUI 体験イテレーション + CAN／モーション制御エコシステムの二本柱」であり、公式の対外活動は elexcon まで沈黙して力を蓄えている。
