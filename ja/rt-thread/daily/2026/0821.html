1. カーネルとバージョン動向

1.1 Rust ビルド統合体系の完善：コンポーネント横断のビルド設定修正と STM32 CI カバレッジの追加

日付：2026-08-21（11:17 北京時間マージ）　出典：RT-Thread/rt-thread commit 30af7388

期間内で最も注目すべきマージ：[rust][tools] Fix Rust build example configuration handling。コミット説明によれば、これは Rust ビルド統合に対する体系的な修正であり、core、applications、components、module サンプルの4階層をカバーする。ビルド失敗の伝播、target と feature の処理、リンクフラグの伝達、サンプル設定の意味論などの問題を修正し、STM32（stm32f407-rt-spark）向けに新たに CI attach カバレッジを追加した。components/rust/ 配下の Cargo.toml、SConscript、core ソースコード、中文・英文 README など複数ファイルに及ぶ。8月中旬以降の rust 関連マージのペースと合わせると、Rust サポートは依然として RT-Thread ツールチェーン方向における活発な投資点であり、本コミットは Rust サンプルのビルド正確性を CI 保護の対象に組み込んだ。

1.2 libc timegm の月オーバーフロー計算修正

日付：2026-08-21（09:44 北京時間マージ）　出典：RT-Thread/rt-thread commit 339bffb7

[fix][libc] fix timegm month overflow calculation：libc の timegm 実装における月オーバーフロー計算エラーを修正。timegm は struct tm を直接 time_t に変換する（ローカルタイムゾーンを経由しない）ために用いられ、月（tm_mon）に範囲外の値が生じた場合に計算結果が誤る。本修正はオーバーフロー換算ロジックを修正する。libc 側の時間処理の堅牢性修正に属する。

1.3 dfs utimensat のパスバッファリーク修正

日付：2026-08-20（18:30 北京時間マージ）　出典：RT-Thread/rt-thread commit 7d1e5515

[dfs] Fix path buffer leaks in utimensat：utimensat（ファイルタイムスタンプを設定するシステムコール）実装におけるパスバッファリークを修正。dfs 層のパス解析経路において、割り当て済みバッファの解放経路が欠落しており、今回それを補った。昨日の memheap 二重解放防止の「欠陥修正」主線を引き継ぎ、カーネル側はこの2日間、リソース管理と時間処理の小規模な堅牢性修正が中心となっている。

1.4 国民技術 N32H シリーズ BSP 第三期拡張：H47X/H49X/H7XX ドライバサポートのマージ

日付：2026-08-20（17:32 北京時間にマージ、PR #11711）　ソース：RT-Thread/rt-thread commit 9fce24b6 / PR #11711

[bsp][n32] add H47X/H49X/H7XX driver support（コミュニティ貢献者 OnlyoutzZ がコミット）、60 ファイル変更、すべて bsp/n32/n32hxxx/libraries/N32_Drivers/drivers/config/ 配下：h47x_48x と h49x の CAN/UART ドライバ設定を新規追加、h7xx の ADC、CAN、DAC、I2C ハードウェア、LPTIM、パルスエンコーダ、PWM、SPI、TIM、UART などのペリフェラル設定を拡張。これは N32H シリーズ BSP の第三期マージ：07-22 初版（n32h760zil7-stb 修復完善 + n32h497zgl7-evb、n32h487zgl7-evb ボードサポート新規追加）、08-12 二期（Nsing LCDC と SDRAM ドライバ）、今回の三期で H47X/H49X/H7XX ペリフェラルドライバ設定を補完、ベンダー BSP の「まず骨格をマージ、後でドライバを補完」という反復モデルに合致し、国民技術 H シリーズ（Cortex-M 高演算モデル）の RT-Thread エコシステムにおける対応が持続的に深化している。

1.5 バージョン状態は安定

日付：2026-08-21　ソース：rt-thread releases

最新正式バージョンは依然 v5.2.2（2025-10-31 リリース）、調査期間内に新規 release なし、プレリリースなし。AF_UNIX（08-17）、memheap 加固（08-20）および本日の複数の修復は次期バージョンで統一的にリリースされる見込み。

5. 総括と趨勢観察

  1. カーネル側「消化期」継続、Rust 方向が最も活発：AF_UNIX（08-17）、memheap 強化（08-20）の後、調査期間内の3件のマージのうち2件は libc/dfs の欠陥修正；最大の動きは Rust ビルド統合の系統的修正と STM32 CI カバレッジへの組み入れであり、Rust サポートへの投入ペースは明確。

  5. リリースペース：v5.2.2 は既に9か月以上維持されており、直近の多数の修正（AF_UNIX、memheap、libc、dfs、Rust ビルド）が蓄積、次回リリースの窓が注目に値する。
