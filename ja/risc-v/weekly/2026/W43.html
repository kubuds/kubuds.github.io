RISC-V ウィークリーレポート (2026-10-19 ~ 2026-10-23)

2026-10-23 Kubuds

レポート期間：2026年10月19日（月）から10月23日（金）まで、計5営業日、5期分のデイリーレポート素材。うち10-19期は72時間ウィンドウ（10-16から10-19をカバー、前回デイリーレポートの締め切り時点から継続）、残り4期は24時間ウィンドウである。したがって本文中に少数ながら日付が10-16から10-18に属する項目があるが、これは当該期デイリーレポートの正常なカバー範囲に属する。

素材の情報源：毎日のRISC-Vグローバル動向デイリーレポート（10-19、10-20、10-21、10-22、10-23の5期分）。さらにGitHubのフォロー組織と重点リポジトリの168時間ウィンドウ再検査（Atomによるバックアップを含む）、openRuyiの二重情報源照合（メインリポジトリのコミットと公式サイトのニュースページ）、RISC-V国際基金会の会員公式サイト巡回点検（391社）とriscv.orgブログによる補強を実施し、10-23 05:00以降のコミットとリリースについては別途Atomと公式ページにより逐条照合した。

編成説明：5期分のデイリーレポートの核心項目を「命令セットとアーキテクチャエコシステム／オペレーティングシステムとディストリビューション／チップとハードウェア／コミュニティと産業活動」の4次元で集約し、同一の线索に属する複数日にわたる進展は統合して叙述しつつ元の日付を保持した。事実、バージョン番号、日付はいずれも当該期に検証済みの情報源または本周期の実測照合から取得しており、単一メディアの報道やベンダー自身の説明は本文中に注記した。今週の主線は第6回RISC-V中国サミット（10-18から10-20まで深セン、10-21は香港デー）であり、サミットはニュース密度のピークであると同時に、今週の大半の製品・ロードマップ情報の原出所でもある。

2. 命令セットとアーキテクチャエコシステム

RVA23：「仕様—カーネル—ディストリビューション—チップ—オペレーティングシステム」の閉ループを一週間で完成

  • 判定可能性：Linux 7.3 は hwprobe で RVA23U64 の基本動作を公開し、ユーザー空間からマシンが RVA23 に適合するかを直接判断できる。これは「コンパイル時の推測」から「実行時の照会」への重要な一歩である。同版ではカウンタ委譲、QoS 識別子、KVM の Svadu、シャドウスタック（Zicfiss／Zicfilp）サポートも補完された。
  • 製品への展開：進畳時空 V100 は RVA23／サーバ SoC／サーバプラットフォーム／BRS／セキュリティモデルの5項目規範に基づいて設計され、BRS 全項目テストに合格した。超睿科技 UR-CP400 は RVA23 に適合し RVV 1.0 をサポートする。K3 は世界初の RVA23 規範に適合し量産出荷された RISC-V AI CPU と表現されている。
  • オペレーティングシステムへの展開：RISE の Android 17 ビルドは明確に RVA23 ハードウェアをターゲットとし、ロックされた manifest とチェックサムを提供しており、「モバイル OS + アプリケーションプロセッサ規範」という最も厳しい組み合わせの最初の公開ベースラインとなった。
  • 判断：3つの流れが同じ週に互いに整合したことは、RVA23 が規範テキストから調達可能・インストール可能・再現可能なエンジニアリング的事実へと転換したことを示す。次の観察点は、ディストリビューション側の profile 階層ビットと glibc の段階的フォールバックがカーネルの進展に伴い実装されるかどうかである。
  • 情報源：Kernel Newbies（Linux 7.3）、RISE（Android 17 on RVA23）、Phoronix（SpacemiT V100）、搜狐（超睿 UR-CP400）

香山：性能パラメータ以外に、今週の重心は明らかに特権态、検証、CI へ移行

  • 10-19 号（10-16 から 10-18 のカバレッジを含む）：メインリポジトリ #6730 はリオーダーバッファ（ROB）を160項目に拡大、アウトオブオーダー実行ウィンドウのパラメータレベルの性能調整である。GEM5（xs-dev）#1231 は2スレッド SpMT に中間端リソース分割を追加。NEMU #1246 は昆明湖 V2（kmhv2）設定を追加し V2／V3 共通修正に整合、#1252 は DiffTest ストレージ CRC 検証のオーバーヘッドを低減。
  • 10-20：XSCache #36 は CoupledL2 の L2 SRAM を set と bank で分割し、プリフェッチの准入を制限、ラストレベルキャッシュの帯域競合とプリフェッチ汚染を示唆。メインリポジトリ #6738 は XSCache サブモジュールのバージョンを更新。GEM5 #1241 は store／AMO 送信失敗時に load パイプラインの replay マークをスキップ。
  • 10-22：メインリポジトリ #6692 は mnret と dret の2つの特権戻り命令のデコードを補完、#6729 は ROB リダイレクト開始インデックスを修正、#6696 は README に Dashboard と star 履歴リンクを追加。
  • 10-23（前回デイリーレポートの締切以降、Atom で再確認）：メインリポジトリ #6742 は StoreUnit が tval でポインタマスク後のアドレスを報告するようにし、#6756 は checkpoint を更新、#6701 は CI の PERF_HOME と WAVE_HOME を統一しビルド済み emu をキャッシュ。NEMU #1260 は Copilot review ワークフローを削除。
  • シミュレーションと検証：GEM5 は 10-23 に #1189 Hybrid CROB サポートと #1257 SMT LSQ DynamicBorrowing ドナー検出修正および統計をマージ、10-22 に #1214 をマージし遅延翻訳前にアクセスサイズを初期化。difftest は 10-23 の一日で #991 並発レジスタ書き込みハッシュ、#996 コピーバック成功した CUDA 結果の回避、#995 BOOM DiffTest 統合ドキュメントの補完および CUDA 検証スループット最適化をマージ。
  • 判断：今週の香山は新しい性能数値を発表しておらず、コミットは特権态デコード、リダイレクトインデックス、tval 報告、CI と DiffTest 基盤に集中している。これはオープンソースコアが「ベンチマーク」から「デリバリー可能」段階へ移行する典型的な形態である。情報源：XiangShan、XSCache、NEMU、difftest

CORE-V：CVA6 メインストリーム収束、CVW 検証面拡大

  • ガバナンス層の変化（10-23）：openhwfoundation/cva6 コミット #3664「master made read-only」、README に master ブランチは新規 PR を受け付けないことが明記され、旧バージョンの統合を継続するユーザー向けにのみ保持され、新規コントリビューションは一律でデフォルトブランチとなった main に移行する。これはブランチガバナンスの収束であり、下流の統合側（特に依然として master を追跡しているプロジェクト）に対して明確な移行シグナルとなる。
  • 検証プラットフォーム：CVW（CORE-V Wally）は今週 3 件をマージ——新規に QM Tech K7 開発ボードサポートを追加（PR #1601、FPGA ボードレベル適配の拡充が継続）、hptwReservedAD 回帰テストを追加（PR #1993）し、予約リーフ PTE の A/D ビット更新動作をカバー；10-22 に jalr の Table I.1 における正誤表項目をマージ（PR #1996）；10-23 に Sail 0.16 アップグレードをマージ（PR #1995）、これに先立ち riscv-arch-test を act4 2b0415eef に整合済み。
  • 判断：形式検証と回帰スイートを得意とする CORE-V にとって、今週の動きは「メインブランチの切り替え + 境界ケースの補完 + 形式モデルのアップグレード」であり、機能追加よりも検証成熟度をよく反映している。出典：cva6 #3664、cvw

ツールチェーンとシミュレーション：達摩院のコミュニティ貢献と楽鑫のシミュレータ整合性

  • 達摩院玄鉄（サミットでの発信）：GCC コミュニティにおける RISC-V 関連の貢献量は世界第 2 位であり、プロセッサに 10% 以上の典型的な性能向上をもたらす；OpenJDK コミュニティの RISC-V コードの過半数は達摩院由来；RISC-V 国際財団の CSC 認証ベースライン構築に参加し 2796 個のテストケースをオープンソース化；C950 は RISC-V とサーバー Java の深い適配を初めて実現し、性能が 30% 向上。

  • メインフォーラムの注目点：午前は Andrea Gallo（インテリジェントのアーキテクチャ）、David Patterson（AI 時代の RISC-V）、容志誠（RISC-I から RISC-V へ）、孟建熠（玄鉄 IP の技術革新とオープンエコシステム）、陳志堅（エッジからクラウドへ）；午後は Krste Asanović（RISC-V State of the Union）、Aniket Saha（Tenstorrent）、周萌（規模化の転換点と標準化）、何寧（奕斯偉 RISC-V＋AI）、賈新霞（藍芯 LX500）。ライトニングトークには中興微、SiFive、新思科技、超睿科技、算能、MIPS、北京開芯院、Cadence などが含まれる。
  • 分科会の全体方針とエンジニアリング詳細のギャップ：汽車エレクトロニクス、工業とロボティクス分科会の全体方針は「RISC-V はすでに使えるかどうかから、使いやすく商用段階に入った」というものだが、エンジニアリングの詳細に落とし込むと、議論されているのは依然として安全認証、リアルタイム制御、ツールチェーンコンプライアンスという3 つの難題——まさにロボット関節制御と車載シャシードメインコントローラに共通するハードルである。IAR はツールチェーンの視点から3 つの課題を提起し RISC-V 開発ツールを発表、芯来は AI チップ IP ソリューション（動的ベクトル長、拡張可能な命令セット、統一ソフトウェアエコシステム）を共有した。
  • 会後の最初の動き：科華データと進迭時空が戦略的協力契約を締結（10-22）、技術、製品、市場、エコシステムの4 次元での協力を巡り、AI チップ層と計算力インフラ層の適合リンクを打通する。科華側は電力エレクトロニクスに約 40 年深耕し、10 年以上のデータセンター建設・運営経験を持ち、『国産チップと計算力ハードウェアインフラ協調技術規範（CCHS）』団体標準の主編も務める。海外メディアは同時期に、サーバー CPU の競争は単一チップの性能にとどまらず、適合とメンテナンスコストが受け入れられるかどうかが顧客移行の鍵であると指摘した。出典：サミット公式サイト、人民網（分科会振り返り）、観点網（科華契約）

政策と産業データ

  • 工信部（10-19 発表会）：今年上半期、我が国のヒューマノイドロボット完成品は 400 機種を突破、生産量は 4 万台超、年間では 10 万台突破が見込まれ、関連製品は倉庫物流、飲食小売、家庭サービスなど300 以上の重点シーンで検証と展開が進んでいる。次に揭榜挂帥による重要共通技術の攻略、実景実訓、国家ヒューマノイドロボット産業標準体系建設ガイド 2026 版の発表、ヒューマノイドロボットオープンソースコミュニティの高水平建設、産業モニタリング体系の構築と品質・データセキュリティ検測の強化を推進する。
  • 市場予測：弗若斯特沙利文のデータによると、RISC-V の中国具身知能チップにおける浸透率は 2025 年の 10.7% から 2030 年には 28.2% に上昇、スマート端末は 6.9% から 26.7% に上昇すると予測；中国の RISC-V 主控チップ市場は 2025 年の約 377 億元から 2030 年には約 2194 億元に拡大する。
  • 智元の資本版図：2 年間で 47 社に投資、合弁方式で少なくとも 17 社の新会社を設立、40 社余りの上場企業と資本を含む協力に合意、「智元 A 計画」は 3 年内に 50 余りの初期プロジェクトを孵化する計画；出荷ペースは今年数千台、来年数万台と予測される。本体メーカーが資本で上流チップを結びつけることで、具身知能の命令セット選択は早期に産業資本によってロックされる。
  • 判断：政策の2 つの抓手（標準体系、オープンソースコミュニティ）は、RISC-V 側で長期的に欠けているソフトウェアとインターフェース規範にまさに対応する；具身知能は今週唯一、政策・資本・出荷の3 層の証拠を同時に備える方向である。出典：新浪科技（工信部）、証券時報、大河財立方（智元）

国際コミュニティ

  • riscv.org：CERNチーム（Benoît Denkinger 氏ら）によるサミットポスター論文を掲載。SOCRATES（System-on-Chip Radiation-Tolerant Ecosystem）プロジェクトの下で開発されたSoCMakeを紹介し、高エネルギー物理学向けの放射線耐性 RISC-V SoC をモジュール式に構築するために用いられる。併設のプロトタイプチップTriglaVは完全耐放射線 ASIC であり、LHC 検出器のフロントエンド読み出しなど強放射線環境向けである。技術構成は三重モジュール冗長、強化相互接続、メモリ保護であり、自動車や産業制御の安全クリティカルな場面にも同様に適用できる。
  • 境界：国際メディアによる今週のサーバー製品に関する集中報道は、多くがサミット後の総括であり、国内で既報の事項と重複する。「適配コストが真の閾値である」との判断は取材を受けた業界アナリストによるものであり、見解は産業界の共通認識を代表するものではない。出典：riscv.org ブログ、Global Times

6. トレンド観察

  • サーバー RISC-V の重心は「リリース」から「適配」へ移行：今週は V100、LX500、珠峰200、UR-CP400 が集中的に登場し、ハードウェア形態がすでに整っていることを証明した。しかしサミット後の最初の動きは科華データと進迭時空によるインフラ協調契約であり、海外メディアの分析も適配・保守コストを顧客移行の決定的変数として挙げている。クラウドの次なる勝負所は発表会ではなく、機房とソフトウェアスタックにある。
  • オープンソースコアが初めて販売可能な商用サーバーチップに進出：V100 の 46 コアのうち 6 個は香山昆明湖 V2R2 であり、オープンソース高性能コアはもはや学術・検証の対象ではなく、IP の形でデータセンター製品に組み込まれている。同じ週に OpenHW は CVA6 の master を読み取り専用化し、main をデフォルトブランチとした。オープンソースコアプロジェクトのガバナンスと製品化が同時に収束しつつあり、一進一退が「オープンソースコア供給能力」の両面を構成している。
  • サーバー IP 供給は三つの経路に分化しつつある：Qualcomm は 10 か月以内に Ventana と Akeana を吸収し（大手内部資産）、国内はオープンソースコアを商用チップに搭載し（V100）、奕斯偉は「自研コア + 外部 IP アライアンス」（SiFive との MOU 升級）を選択した。三つの経路はいずれも同じ問いに答えている。サーバー級 RISC-V の IP はどこから来るのか。
  • 性能路線は制程を迂回し、アーキテクチャとシステムへ転換：データフロー（睿芯、中科通量）、統一メモリと CXL（藍芯）、SMT と AME マトリックス拡張（達摩院）、再構成可能アレイ（Ubitium）——先端制程が制限される前提の下で、これらは設計によって性能を取り戻す手段である。達摩院が C950A に定めた「5 倍」目標は、本質的に同じ論理の延長である。
  • ディストリビューションの補完階層は一週間で二段階上昇：openRuyi はツールチェーンとカーネルパッケージから、クラウドネイティブミドルウェア（minio、Prometheus、sarama）へ、さらに Python／Node／Java ランタイムと Go エコシステムへと進んだ。セキュリティ修正は security-fixes マーク付きでバッチ処理のフローに乗り始めた。RISC-V ディストリビューションは「インストールできる」から「本番環境で使える」へ向かっているが、公式サイトのバージョンは依然 2026.09 のままで、リリースのペースとコミットのペースは同期していない。
  • 具身智能の最初の実出荷は汎用 AI 算力ではなくリアルタイム制御から：工信部は年間 10 万台のオーダーを示し、智元は 47 件の投資で上流チップを囲い込んだ。一方、検証可能な製品進捗を見ると、関節制御チップと小脳チップは量産済み、車載モータ制御 MCU は出荷 100 万個超であるのに対し、「大脳」を位置づける V1000（2.5D Chiplet、1000 TOPS）は依然として流片段階にある。このテンポの差は、どのロードマップよりも産業の現在地をよく示している。

限界と基準の説明

  • Omdia データの2箇所で基準が不一致：10-19 デイリーレポートでは孟建熠氏の表述を引用し「2030年まで年間出荷台数が年約30%増、世界のプロセッサ出荷台数シェア約25%を占める」とし、10-23 デイリーレポートでは孫彦邦氏の表述を引用し「年間出荷台数の成長率は50%、2030年の世界市場シェアは25%近く」としている。シェアの基準は一致するが、成長率の基準は異なるため、本レポートは共通部分（2030年に約25%）のみを採信し、成長率の差異は保留して要確認とする。
  • ベンダー(ファウンドリ/メーカー)の自己申告は第三者検証なし：V100 の「業界初のサーバー仕様に完全準拠」、睿芯 D35 の「世界初の量産 RISC-V データフロー物理 AI チップ」と「カーネル IP が Intel の世界調達検証を通過」、中科通量ワークステーションの仕様、珠峰200 のシナリオ位置づけは、いずれも企業の表述またはサミット会場での紹介であり、第三者の実測再現を欠く。
  • プロセスと消費電力データの情報源が単一：V100 の 12nm／120 W は海外メディア報道のみに見られ、公式中国語稿にはこの2項目は記載されていない。
  • 未公開の部分：珠峰200 の詳細仕様（年末発表）、蓝芯スーパーノードのノード内チップ数と相互接続方式および納期、Qualcomm による Akeana 買収の取引金額と製品統合方案、科华数据と進迭時空の提携金額とスケジュール。
  • ベンダー(ファウンドリ/メーカー)のテストデータ：加特兰 Kunlun-Pro の 3668 DMIPS とクラスタリング／トラッキング所要時間はベンダー(ファウンドリ/メーカー)テストによる。玄鉄 60億個出荷、GCC 世界2位、OpenJDK の半分超の貢献はサミットでの表述。
  • 形態の境界：RISE の Android 17 は明確に開発者バージョンであり量産には適用不可。esp32-s31-linux はコミュニティプロジェクトに属し製品化経路を構成しない。CubeSandbox の RISC-V サポートは依然として開発者プレビューで、公式はリリースイメージを提供していない。V1000 ブレインチップは依然としてテープアウト段階。
  • 重複報道の扱い：今週の V100、E908A、UR-CP400、珠峰200、Tenstorrent、玄鉄 60億個などの項目は、後続の日付で二次転載が複数回出現しており、初回報道日で収録し重複計上はしていない。付録の情報源には元の出典を保持する。
