1. オープンソースコミュニティとソフトウェアエコシステム

1.1 CPython が RISC-V を公式サポート：公式 tier 3 プラットフォームに（08-25）

日付：2026-08-25（ブログ公開と同時期；HN 収録 08-24 20:12 UTC = 08-25 04:12 北京）　出典：blog.python.org、HN

CPython は RISC-V が公式サポートプラットフォームとなり、PEP 11 に基づき tier 3 に分類されることを正式に発表した。サポート体制：RISE Project が複数の実 RISC-V ハードウェアを buildbot テストおよびアーキテクチャ問題のデバッグ環境として提供（Ludovic Henry、Furkan Onder、Emma Smith などのコミュニティ貢献者）、Sovereign Tech Agency の奨学金が今回のアーキテクチャサポート作業を資金援助した。今後の計画：RISE RISC-V Runners を活用して RISC-V を CPython 公式 CI に直接接続（buildbot より高速なフィードバック）、長期的には tier 2 への昇格を推進し、アーキテクチャ固有の性能最適化を行う。意義：Python は AI/ロボティクスソフトウェアスタックの骨干言語であり、公式 tier 3 サポートは RISC-V の端側およびサーバーシーンにおけるソフトウェア可用性の重要な一环を補完する（2.1 のサーバー進展と合わせて）。

1.2 Linux 7.3 に複数の RISC-V 拡張サポートを追加（08-24）

日付：2026-08-24（Phoronix 10:12 UTC = 18:12 北京）　出典：Phoronix

開発中の Linux 7.3 に、比較的新しい RISC-V ISA 拡張の検出と列挙サポートが複数マージされた：間接 CSR アクセス（Smcsrind/Sscsrind）、カウンタ特権フィルタリング（Smcntrpmf）、S 態カウンタ設定（Ssccfg）、カウンタ委譲（Smcdeleg、全特権レベルをカバー）、メモリ原子性/一貫性クラス（Zicclsm 非アラインドメモリアクセス、Ziccamoa 原子操作、Ziccif 命令フェッチ原子性、Ziccrse LR/SC 前方進捗、Za64rs 予約セット）、QoS 識別子（Ssqosid、メモリ/キャッシュ帯域幅モニタリング）。他に CFI Shadow Stack 処理の改善、QoS タグのコンテキストスイッチ、再起動/シャットダウン用の UEFI Runtime サービスなど。これらの拡張はサーバーと性能モニタリング指向が中心で、RVA23 サーバープラットフォームの推進（2.1 参照）と機能的に直接呼応している。

1.3 Hot Chips 2026：NVIDIA が CUDA の RISC-V 移植に向けた技術要件を詳説（08-24）

日付：2026-08-24（Chips and Cheese 発表；HN 68 ポイント、9 コメント）　情報源：Chips and Cheese、HN

Hot Chips 2026 での NVIDIA の講演は、CUDA サポートを RISC-V に拡張することを紹介：RVA23 profile と RISC-V server SoC / server platform 仕様（RAS、専用セキュリティプロセッサなどのベースライン機能を含む）を要求；さらに PCIe コヒーレンシ（そうでなければ DMA と CPU キャッシュ間でソフトウェアによる明示的な無効化が必要となり、CUDA スタックでは処理が難しい）、デバイス間 P2P PCIe、ベクトル拡張プレディケートのサポートなどを要求し、「最小公分母」によって性能強化命令が使えなくなる事態を回避；ACPI の問題は以前に移植を妨げていたが、2025 年の UEFI フォーラムにおける RISC-V ACPI サポートと昨年承認された BRS（Boot and Runtime Services）仕様によって解決された。韓国メディア《毎日経済》（韓国）は同時期に、NVIDIA が AI サーバー CPU のサポートを Arm/x86 から RISC-V へ拡大する計画を報道した。SiFive が CUDA を既に自社の BigSky プラットフォームで実際に動作させていることを確認したこと（2.1 参照）と合わせ、「CUDA on RISC-V」は 2025 年の表明から技術要件の実装段階へと移行した。

1.4 RISC-V 命令セットマニュアルが ISO/IEC DIS 26791-1 国際標準草案段階へ（08-24）

日付：2026-08-24（HN 12:54 UTC = 20:54 北京時間）　情報源：HN、iso.org/standard/94578

RISC-V 命令セットマニュアルが ISO/IEC DIS 26791-1 の番号で国際標準草案（DIS）段階に入った——ISO/IEC JTC 1 標準プロセスにおいて DIS は加盟国投票に付されるもので、正式な国際標準化の重要な節目である。オープン ISA が ISO 標準へ向かう象徴的な動きであり、RISC-V International による JTC 1 での標準化推進と一致している。注：ISO 公式サイトのページはアンチクロールにより本文を直接取得できないため、技術範囲は公式サイトと DIS テキストに準拠する。

2. 製品とエコシステムの動向

2.1 SiFive BigSky SF-2U870：世界初のラックマウント型 2U RISC-V エンタープライズサーバーを発表（08-24）

日付：2026-08-24（SiFive プレスリリース；HotHardware 12:23 EDT = 08-25 00:23 北京時間）　情報源：SiFive プレスリリース、HotHardware、HPCwire

SiFive は Hot Chips 2026 と同時期に BigSky SF-2U870 データセンター開発プラットフォームを発表し、世界初のエンタープライズ向けでラック搭載可能な 2U RISC-V サーバーを謳った：32 コア P870-D @2GHz、256GB DDR5-5600、3.84TB U.2 NVMe、10/25Gbps OCP 3.0 ネットワーク、64 レーンの PCIe Gen5 拡張（デュアル幅 GPU と専用アクセラレータを収容可能）、RVA23 準拠；開梱で Ubuntu 26.04 LTS と RHEL 10 をサポート；ハイパースケールクラウド事業者、チップメーカー、ソフトウェアベンダー向けで、エンタープライズソフトウェアの移植、負荷チューニング、自社チップのテープアウト前検証に用いられる。既に限定数で即納販売中（公式は「需要が供給を上回る」と述べ、CEO の Patrick Little は「データセンターへの RISC-V の進出はもはや遠いビジョンではない」と語った）。重要な詳細：SiFive は NVIDIA と協力して CUDA を移植し、将来のプラットフォームに NVLink Fusion を統合する計画で、CUDA は既に BigSky 上で実際に動作しており、NVIDIA GPU 上の現代的な LLM ワークロードのヘッドノードとして機能する——RISC-V ハードウェアが初めてこの能力を備えた。

2.2 IAR と東軟睿驰が戦略提携に合意：RISC-V 車載ツールチェーンを補完（08-24/25 報道）

日付：2026-08-24/25 報道（EET-China 08-25 00:17 北京時間；両社は 08-20 に上海で調印）　情報源：BigGo Finance、EET-China（電子工程専輯）

組込みツールチェーン廠商 IAR と 東軟睿驰（Neusoft Reach） が戦略提携を締結：NeuSAR OS と IAR 開発ツールの深層統合に焦点を当て、国内開発シナリオ向けにソフトウェアとツールチェーンの一体型ソリューションを提供し、AUTOSAR ソフトウェアエコシステムと RISC-V 車載チップの融合を推進する；両社は「チップ—基礎ソフトウェア—アプリケーション開発」をカバーする完全なツールチェーンを共同構築し、RISC-V 車載グレード開発におけるツールチェーンのギャップを埋め、自動車業界での規模展開を加速させる。注：調印は 08-20、報道は 08-24/25 に本調査期間入り、初収録となる；東軟睿驰は国産車載基礎ソフトウェア NeuSAR の主要廠商であり、IAR は以前から SiFive の車載 E7A/S7A コアをサポートしている。

2.3 Andes D23-SE が ISO 26262 ASIL-B/ASIL-D 機能安全認証を取得（08-24 報道）

日付：2026-08-24 報道（New Electronics 18:42 北京時間；原廠公告 08-18）　情報源：New Electronics、andestech.com

AndesCore D23-SE プロセッサが ISO 26262 ASIL-B および ASIL-D の二重グレード機能安全認証を取得（開発プロセスは第 2/4/5/7/8 部に適合）。D23-SE は 3 段パイプライン、部分的デュアルイシューの高能効指向安全コアであり、アンチロックブレーキ、タイヤ空気圧監視、エアバッグ、モータ駆動制御などの ECU/DCU シナリオをカバーする；認証取得により N25F-SE/D25F-SE/D45-SE とともに Andes の完全な車載安全コアラインナップを構成する。注：原廠公告は 08-18（調査期間外）、本調査期間では New Electronics の報道として収録、初収録となる。

2.4 LilyGo T-Display K230 Kit：Tech Times が現行 Ubuntu は動作不可と報道（08-24/25）

日付：2026-08-24/25（Tech Times 08-25 03:48 北京時間）　情報源：Tech Times（gnews）

Tech Timesは「RISC-V AI ポケットコンピュータが現行の Ubuntu から締め出される」と題して LilyGo T-Display K230 Kit（CoreSet 約150ドル、Kendryte K230 デュアルコア RISC-V + ESP32-S3-R8 コプロセッサ、キーボードと LoRa はオプション）を報道。08-21 発表イベントの二次拡散に属し、新たな詳細は、現行の Ubuntu ディストリビューションではその上で動作できない（専用の Linux/RTOS イメージが必要）ことであり、エッジ側 RISC-V 端末のディストリビューション対応がいまだ短板であることを裏付け、当該製品ラインの今後の観察ポイントとなる（2.1 のサーバー側「すぐに使える Ubuntu/RHEL」と対照をなす）。

3.3 奕斯偉計算：香港 IPO 開示で累積損失が 52 億元超（08-25）

搜狐財経が招股説明書を引用して報じたところによると、奕斯偉計算は累計損失が52億元を超え、上位5大顧客の売上高占比は8割超（2022/2023/2024年でそれぞれ88.7%/90.7%/88.5%）で、主力製品の単価は下落している。同社は現在香港株式市場でのIPOを進めている。奕斯偉計算は国内大手のRISC-Vチップ設計企業（RISC-Vアーキテクチャをベースに、事業はスマート端末と相互接続コンピューティングの2大ラインをカバーし、後者は自動車、ロボット、産業シーンを対象とする）であり、その商業化の進捗と顧客集中度は、国内RISC-V大手企業の収益モデルを観察する上で重要なサンプルである。注：データはメディア報道と招股説明書の要約に由来し、正式な開示文書を基準とする。報道時期は本調査期間の終盤に位置するため、期間内のイベントとして収録する。

期間内のロボット専項検索は08-18～21の旧聞（端側RISC-Vの突破口論、ルネサスの身体性知能への布陣、進迭K3の量産とハーフマラソン走破）のみがヒットし、新規専項ニュースなしの日と判定。関連する手がかり：

  • ICDIA 2026閉幕報道（観察者 08-24）：大会には身体性知能の専場とAIロボット展示エリアが設けられ、多方面で「認知知能から物理的実行の実装へ」の経路を議論——08-23で既報イベントのフォローアップであり、身体性知能はすでに国産IC大会の定番議題となっている；
  • 端側コンピューティングの下方展開トレンドが継続：進迭K1/K3ビジョンマトリクス、K230 Kit、ESP32-S31のLinux化などが、RISC-VデバイスがAI/ロボット負荷を担う境界を引き続き拡大。奕斯偉計算の公式サイトは、その相互接続およびコンピューティングチップが「主に自動車、ロボット及び産業シーンに応用され、智能体に知覚、処理、執行の能力を持たせる」と位置づけており、そのIPO開示（3.3）は当該事業ラインの顧客集中度が極めて高いことを示している；
  • サーバー側の新たな変数：BigSky + CUDA（2.1）は身体性知能のクラウド訓練/推論基盤にRISC-Vの新たな選択肢を提供し、今後の追跡ポイントとして価値がある。

5. まとめとトレンド観察

  1. RISC-V のサーバー化が「実物納入」段階へ：BigSky 2U ラックサーバーの限定実機在庫 + CUDA の実稼働（NVIDIA GPU LLM 負荷のヘッドノードとして）+ NVLink Fusion ロードマップ、さらに Linux 7.3 のサーバー機能拡張（QoS 識別子/カウンタ委譲/CFI）と ISO 標準化の推進——データセンターの「ラストワンマイル」ソフトウェアスタックが集中的に整備されつつある；
  2. NVIDIA CUDA のサポートは 2025 年の表明から 2026 年 Hot Chips の技術要件細分化へ（RVA23、PCIe コヒーレンス、P2P）、「サーバー級 CPU + プラットフォーム」がハードルの条件であり、P870-D 級の高性能コアと RVA23 サーバー仕様エコシステムに直接追い風；
  3. 国内の分化が継続：香山は二本柱で推進（COVE 収束 + 性能/ストレージの調整、19 件のコミット、調査期間内で最も活発）；進迭時空はドライバ/ドキュメントを定例的に；奕斯偉計算は香港株 IPO で累計赤字 52 億元超を開示、顧客集中度が高い——国内大手 RISC-V 設計企業の商業化プレッシャーが顕在化しており、継続的な追跡が必要；
  4. 車載エコシステムの補強：IAR×東軟睿馳のツールチェーン協業、Andes D23-SE の ASIL-B/D 認証、さらに奕斯偉 EAI8800（7 月に二重認証）——RISC-V 車載の「IP—ツールチェーン—基礎ソフトウェア—チップ」のチェーンが徐々に閉じつつあり、AUTOSAR エコシステムの RISC-V 移行が加速；
  5. オープンソース側の活発度が回復：CPython tier 3、Linux 7.3 の複数拡張のマージ、HN における CUDA-on-RISC-V の議論が加熱（68 点）、ここ数日の平穏と対照的；Python の公式サポートが AI ソフトウェアスタックの重要な一环を補完。

限界に関する説明：BigSky の性能データと CUDA 稼働の詳細はベンダーのプレスリリースに基づくもので、独立した評価はまだない；奕斯偉計算の財務データはメディア報道と招股書摘要に由来し、正式な開示資料に基づくものとする；ISO/IEC DIS 26791-1 のページはアンチクロールのため直接取得できず、具体的な技術範囲は ISO 公式サイトに基づくものとする；香山のコミット内容はコミットメッセージに基づくもので、マイクロアーキテクチャ級の検証詳細には触れていない；IAR×東軟の契約は 08-20 の出来事であり、報道が調査期間に入ったもので、出来事自体は調査期間内に発生したものではない。
