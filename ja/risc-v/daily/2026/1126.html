今日の重点：奕斯偉集成电路産業基地が北京亦庄に立地（11-25）

11 月 25 日、北京経済技術開発区管理委員会と北京奕斯偉科技グループは経済発展協力協定を締結し、奕斯偉グループ集成电路産業基地プロジェクトが北京亦庄に立地した。

プロジェクトはチップ設計を核心とし、演算インフラ建設、シリコンベースと新材料研究開発、半導体設備などの板塊が協同する。計画の表現は「チップ—ボード—サーバ—演算クラスタ」を縦に打通し、クラウドエッジ智能、具身智能、端側智能の三類シナリオをカバーするというものである。

署名両者の位置づけは RISC-V フルスタック演算産業クラスタである。奕斯偉グループ董事長の王東升氏は、研究開発投入を拡大し、RISC-V 計算アーキテクチャチップと演算システムの規模化落地を推進すると述べた。

奕斯偉計算は RISC-V+AI を基盤とし、製品は端側智能、具身智能、クラウドエッジ智能の三ラインに分かれる。11 月 19 日の ICCAD-Expo 2026 で、同社は既に 620+ 項目の IP、20+ シリーズの RISC-V コアを蓄積したと披露した。

北京経済開発区には現在、集成电路関連企業が 400 社超あり、設計、製造、封止・テスト、設備、材料、部品をカバーしている。今年前三四半期、同区の集成电路産値は 1600 億元超であった。

日付：2026-11-25 出典：https://www.ncsti.gov.cn/kjdt/scyq/bjjjjskfq/jkdt/202611/t20261125_265445.html。別途：https://www.eswin.com/news/newsinfo/179.html。

RISC-V 100 ランキング動向

進畳 V100 が初めて RISC-V SPEC CPU2006 榜に進入（11-24）

11 月 24 日、riscv100.top の What’s New に一条の記録が上线した：SpacemiT V100 XSCC 1.1 SPEC CPU2006 Speed。

公告が示した絶対スコアは int 17.879、fp 15.297。モードは Speed/Base、入力は ref、29 項目の整数と浮動小数点テストが全て完了した。ランキング記録の日付は 2026-10-10 で、今回の巡検日より前であり、補録による上榜であって当日の新規測定ではない。

ランキングは Ratio/GHz で表示され、対応する記録は int 8.127、fp 6.953である。

V100 は進迭時空の RISC-V サーバプロセッサで、RVA23 をサポートする。公式製品ページには各チップ 46 コア：6 個の香山昆明湖 V2R2 コア、40 個の進迭 X100 コアが記載されている。

テストはデュアルソケット V100 ノード上で実行され、OS は openRuyi Creek、X100 コアのみを使用した。

対照となるランキングの現状を見ると、RISC-V チャンネル SPEC CPU2006 の首位は依然として香山 KMHv3 と XSCC 2.0 の組み合わせである。この記録の日付は 2026-10-17、int 22.802、fp 25.649、いずれも Ratio/GHz。

日付：2026-11-24 情報源：https://riscv100.top/whats-new/2026-11-24-v100-xscc11-spec06-speed。関連：https://riscv100.top/riscv/spec06/。

1. オープンソースコミュニティとソフトウェアエコシステム

openRuyi 20 件：17 個の rust-* パッケージと eza を登録、clamav を 1.5.5 に更新（11-25）

11 月 25 日、openRuyi メインリポジトリに 20 件の SPECS 変更がマージされた。うち 17 件は Rust パッケージである。

いくつかを挙げる：eza、git2 0.21、criterion 0.8、trycmd、proc-mounts、timeago、serde-norway と unsafe-libyaml-norway。rust-libgit2-sys は 0.18.4 に更新。

ほかに node-exporter の新規追加、clamav の 1.5.5 への更新がある。当日はリリースはなく、作業はパッケージング面に集中した。

日付：2026-11-25 情報源：https://github.com/openRuyi-Project/openRuyi/commits/main。

カーネルタグ推進：manifest に 7.3.6-2、7.0.14-21、6.18.65-2 を追加（11-25）

openRuyi の kernel-team-tools は当日 3 件。夜間の 1 件は manifest に 7.3.6-2、7.0.14-21、6.18.65-2 の 3 つのカーネルタグを追加した。

残り 2 件は linux と linux-lts の設定を内蔵 MOTORCOMM_PHY に変更した。同一リポジトリは 25 日未明に linux 設定を v7.3.6-1、linux-lts を v6.18.65-1 に更新しており、これらの数件は今回の調査期間より前である。

日付：2026-11-25 情報源：https://github.com/openRuyi-Project/kernel-team-tools/commits/master。

RevyOS カーネル 20 件の設定を一括マージ、6 社の SoC をカバー（11-25）

RevyOS の linux リポジトリ（revyos/7.3.y）は当日 20 件をマージし、コミット時刻は 19:41 に集中した。

追加された SoC 設定には知合 A210、奕斯偉 EIC7700、UltraRISC DP1000、進迭 K1 と K3、玄鉄 TH1520、算能 SG2042 と SG2044 が含まれる。

同日 ARM SCMI を有効化し、EFI framebuffer を efidrm に置き換えて drm_panic を有効化した。さらに linuxboot 設定と debian_defconfig を追加した。

別に K3 の errata が 1 件：WRS.NTO の代わりに WRS.STO を使用する。もう 1 件は奕斯偉 starpro64 のファン制御を有効化する。

これらコミットの作者日付は 2025-12 から 2026-11-20 にわたり、長期設定ブランチの一括マージであり、当日新規に書かれたものではない。

日付：2026-11-25 情報源：https://github.com/revyos/linux/commits/revyos/7.3.y。

香山 GEM5 2 件：キャリブレーションスキルと低メモリホスト回避（11-25）

香山 GEM5（xs-dev ブランチ）は当日 2 件。1 件は Calibration Skills を追加（#1385）、1 件は分散シミュレーションが低メモリホストを回避するようにした（#1348）。前日にマージされたオプションのスカラ浮動小数点除算と平方根のパイプライン化は依然ブランチ上にあり、ロールバックは見られない。

日付：2026-11-25 情報源：https://github.com/OpenXiangShan/GEM5/commits/xs-dev。

3. 国内チームの深掘り

香山 3 コミット：フロントエンド TopDown 帰属、ICache 有効ビットと NEMU の MRET フラッシュ（11-25）

香山メインリポジトリ（kunminghu-v3）は当日 2 コミット。1 件はフロントエンド TopDown 帰属を修正（#6808）、1 件は ICache が corrupt/deniedReg に対して ValidHold を使用するように（#6948）。

いずれもパフォーマンスカウンタとキャッシュ一貫性の側面であり、新機能はない。併せて NEMU に 1 コミット：非 RVH ビルドが MRET 時に tcache をフラッシュ（#1313）。

日付：2026-11-25 情報源：https://github.com/OpenXiangShan/XiangShan/commits/kunminghu-v3。関連：https://github.com/OpenXiangShan/NEMU/commits/master。

算能 LLM-TPU 2 コミット：Qwen3.5 サンプリングと MiniCPM-V-4.7 の GGUF ビルド（11-25）

算能 LLM-TPU は当日 2 コミット。1 件は Qwen3.5 デモに penalty sampling を追加、1 件は MiniCPM-V-4.7 35B-A3B の性能データと GGUF ビルド手順を更新。

このリポジトリは算能 TPU 上で大規模モデルを動かすリファレンス実装であり、変更はモデル適応層に集中している。

日付：2026-11-25 情報源：https://github.com/sophgo/LLM-TPU/commits/main。

奕斯偉：ICCAD で 620+ 項目の IP と 20+ シリーズの RISC-V コアを提示（11-19）

背景の補足。11 月 19 日から 20 日の ICCAD-Expo 2026 で、奕斯偉計算董事長の米鵬氏が「RISC-V+AI によるデジタルインフラの再構築」と題する基調講演を行った。

同社は 620+ 項目の IP、20+ シリーズの RISC-V コアを蓄積し、智能感知、智能交互、智慧連接、多媒体処理、認知決策、智能制御の 6 分類の能力をカバーするとしている。技術基盤は RISACon と呼ばれ、ソフトウェアは RISEA、RISAA、RISCA の 3 層に分かれる。3 つの成長曲線は端末側、具身、雲辺に対応する。

日付：2026-11-19 情報源：https://www.eswin.com/news/newsinfo/179.html。

玄鉄と芯来：調査期間内に新規コミットなし（11-25）

XUANTIE-RV 組織は調査期間内に torq-tile の pushed_at の変化のみ。当該リポジトリのメインブランチに新規コミットはなく、HEAD は v1.0.0 タグと同じコミットで、リリースもない。

Nuclei-Software の最新プッシュは 11-19 で、調査期間内に更新はない。楽鑫は当日 38 のリポジトリにプッシュがあり、内容は SDK、ツールチェーン、ドキュメントの定例更新で、RISC-V コアに関連する新規リリースは見られない。

日付：2026-11-25 情報源：https://github.com/XUANTIE-RV/torq-tile。関連：https://github.com/Nuclei-Software。

進畳ロボティクススタック 11 コミット：G1 の RGB-D SLAM とオンデマンド RTSP エンコード（11-25）

日付：2026-11-25 情報源：https://github.com/spacemit-robotics/ros2_humanoid/commits/main。関連：https://github.com/spacemit-robotics/humanoid_common/commits/main。

5. 総括とトレンド観察

  • 産業契約：当日唯一の実契約は亦庄。奕斯偉は拠点を北京経済開発区に置き、方向性は RISC-V チップ設計とフルスタック算力クラスタ。契約当事者が示したチェーンはチップ、ボード、サーバーから算力クラスタまで。
  • ランキング新プラットフォーム：進畳 V100 が初めて RISC-V SPEC CPU2006 に登場。マシンの構成は注目に値する。各 46 コアのうち、6 個が香山昆明湖 V2R2、40 個が進畳 X100。今回は X100 コアのみで測定し、ランキングスコアは Ratio/GHz 8.127（int）。
  • ディストリビューションがサーバー検証を引き継ぐ：今回のテストは openRuyi Creek で実行。同日 openRuyi メインリポジトリに 20 件のパッケージ変更をマージ、kernel-team-tools がカーネルタグを推進。ソフトウェアスタックとハードウェア検証が噛み合い始めた。
  • 設定の一括マージ：RevyOS が一度に 20 件をマージし、知合、奕斯偉、UltraRISC、進畳、玄鉄、算能の 6 社の SoC をカバー。作者日付は約 1 年にわたり、これは長期設定ブランチの収束であり、新規開発ではないことを示す。
  • 動くことから調整できることへ：ロボットスタックの 11 件は SLAM 分散、オンデマンドエンコード、シリアルポートのロールマッピング、コリジョンボディに集中。こうした変更はリリースノートには現れないが、実機が安定して動くかどうかを決める。
  • 直近 1 日のトレンド：産業側は土地を契約し、ソフトウェア側はパッケージングし、ハードウェア側はランキングに登場。3 本の線がそれぞれ進み、交差点は openRuyi と進畳の V100 ノード。
