今日の重点：RevyOS が知合計算 A210（Melon Pi）カーネルサポートを公開、一連のパッチが整備

日付：2026-09-29　出典：revyos/linux コミット：MAINTAINERS に知合 A210 サポートを追加（09-29）、コミット：A210 温控とウォッチドッグデバイスツリー（09-29）、コミット：PWM が TH1520 ドライバを再利用して A210 をサポート（09-29）、コミット：Melon Pi V2 オーディオ配線（09-29）

9月29日午前、RevyOSカーネルリポジトリ（revyos/linux）が rv/a210-upstream-local ブランチに一連のパッチを一括プッシュし（調査期間内に14件を確認）、知合計算（Zhihe Computing）「阿基米德」A210 SoC およびその Melon Pi V2 開発ボード向けのカーネルサポートを补齐した。A210 は達摩院玄鉄 C920 と C908 を搭載した8コア RISC-V の「通推一体」チップ（12 TOPS@INT8）であり、エッジサーバや具身智能などのシーンに向けられている。今回のパッチ群がカバーする範囲は以下の通り：MAINTAINERS と defconfig のエントリ；デバイスツリー（温度制御とウォッチドッグ、PWM、ADC、Melon Pi V2 のオーディオ配線）；ドライバ側には PWM が TH1520 ドライバを复用するもの、IIO ADC 単次変換、ASoC の A210 I2S コントローラと Everest ES8156 ステレオコーデックを含む；さらに [NOT-FOR-UPSTREAM] の deb-pkg DTB インストール調整が1件。ほとんどが dt-bindings とドライバ、デバイスツリーの正規化された形態でコミットされ、RevyOS の新ハードウェアへの迅速な追従リズムを継続している。

digitimes 09-29 報道：GlobalFoundries傘下のMIPSは、SynopsysのARCプロセッサIP事業の統合を完了したと述べている。RISC-Vを基盤としてフィジカルAIをアンカーとし、AIoTから自動車とデータセンターアプリケーションへと拡大する。同社は、この合併によりGFとMIPSが世界第2位のプロセッサIPサプライヤーになったと述べている。同日のBusiness Wireのニュース：MIPSとXcelsa Labsが戦略的協業に合意——XcelsaのApex設計最適化プラットフォーム（形式的等価保証）により、MIPS IPをベースとしたカスタムチップ開発を加速し、AI、自動車、産業、ロボティクス、エッジのシナリオをカバーする。これに先立つ9月初旬、MIPSはAcies／Actus／Aegisの3つのワークロードネイティブプラットフォームを発表済みである。

2.2 Nuvacore：「Core First」開発モデルを公表、ISA選択はオープンなまま維持

日付：2026-09-29　情報源：Notebookcheck「Apple SiliconとNuviaのベテランが、ISAオプションを開いたままにする異例のCPUコアを公開」（09-29）、Tom’s Hardware「伝説的なQualcomm、Apple、Nuviaの卒業生が新CPUスタートアップを設立」（背景）

Gerard Williams III、John Bruno、Ram Srinivasan（Apple／Nuvia／Qualcommのバックグラウンド）によって設立されたCPU新興企業Nuvacoreは、初の汎用コアWarpCoreの「Core First」モデルを公開した：まずISAと切り離されたマイクロアーキテクチャ基盤を構築し、その後ターゲットシステムに応じて命令セットを選択する。同社の採用資料ではRISC-V、Arm64、x86が並記されており、ISAの選択肢がオープンに維持されていると解釈されている——メディアは、RISC-VはArm式のアーキテクチャライセンスが不要なため最も直接的な経路であると指摘する一方、デコード、特権レベル、メモリオーダリング、ソフトウェア互換性が依然として最終的なISAを決定する制約となるとしている。同社はまだISAの選択、プロセス、テープアウト計画を開示していない。

2.3 SignOff：RISC-V「Kaveri」ソフトIPでカスタムチップの全工程能力を展示

日付：2026-09-29　情報源：Electronics For You「SignOff Builds Toward a Bigger Role in Custom Silicon」（09-28／29）

インドの設計サービス企業 SignOff Semiconductor は、VLSI 設計サービスからターンキー型カスタムチップへと事業を拡大しつつある。同社は自社開発の RISC-V「Kaveri」プラットフォーム上で、カスタマイズ可能な RTL とアプリケーション周辺のペリフェラル機能をソフト IP 形式で示し、それを製品ラインではなく「能力の証明」と位置付けている。アーキテクチャからシリコン実装までを単一のパートナーに任せたい顧客層を対象とする。同社はこのプラットフォームを用いて複数のアプリケーションデモを完了したと述べており、ファウンドリおよび OSAT エコシステム、EDA への投資と組み合わせてエンドツーエンドのプロジェクトを受注している。

4.1 進迭時空ロボティクス：ros2_humanoid に ASR 動作音声提示を追加

日付：2026-09-29　情報源：ros2_humanoid コミット：ASR 動作音声提示と堅牢な再生（09-29）

進迭時空ロボティクスリポジトリ ros2_humanoid は調査期間内に1件追加：ASR 動作に音声提示とより堅牢な再生メカニズムを追加——09-28号で収録した Qwen3-ASR 音声動作制御を基礎に、音声対話リンクのフィードバックとフォールトトレランスを引き続き完善。その他のロボティクス側：本調査期間内に国内関連チームの他の実質的動向はなし（会員公式サイト巡検でロボティクス方向の更新は見られず）。

五、まとめとトレンド観察

  • 新ハードウェアとディストリビューション追随の好循環：知合計算 A210 が RevyOS カーネルサポートバッチを取得（複数の dt-bindings とドライバの標準化コミットを含む）；openRuyi が K3 ファームウェア 20260929 をリリースし、linux-lts を 6.18.54 へローリングアップグレード。
  • RISC-V のプロセッサ IP 層における商業的地位の上昇：GF と MIPS は ARC 統合完了後、世界第2位のプロセッサ IP サプライヤーになったと述べ、Xcelsa との協業で「ワークロードからカスタムシリコンまで」のチェーンを補完；自動車とデータセンターが明確な拡張方向。
  • 「ISA の開放性」が再びトップチームの注目を集める：Nuvacore の Core First モデルは ISA 選択を後置し、RISC-V はライセンスコストの面で直接的な受益選択肢に。
  • 国内ベンダーのツールチェーンがバージョン化と教学化の段階へ：矽速 SLogic 2.0.0 と slogic16u3-tools の同時リリース、進迭時空 K3 Triton チュートリアルの成形、楽鑫の多言語音声モデル——「使える」から「学べる、リリースできる」へ。
  • 香山系は高頻度のブランチレベル開発を維持：メインリポジトリの4件のバックエンド修正 PR は発射と定序パスに集中、difftest は CROB 対比ラインを敷設、仿真チェーンと実装チェーンを同期推進。
  • 要観察：奕斯偉の価格設定と上場（10月9日）、openRuyi 2026.09 バージョン、香山4件の PR のレビュー動向；達摩院玄鉄、芯来、Radxa Linkr などは調査期間内に沈黙。
