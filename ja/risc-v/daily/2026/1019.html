1. オープンソースコミュニティとソフトウェアエコシステム

1.1 香山：昆明湖 V3 が ROB を 160 項目に拡大；GEM5 が 2 スレッド SpMT のリソース分割を追加

日付：2026-10-16　情報源：XiangShan PR #6730（10-16）、GEM5 xs-dev #1231（10-16）、NEMU PR #1246（10-16）、NEMU PR #1252（10-16）

香山メインリポジトリ（kunminghu-v3）に #6730：リオーダーバッファ（ROB）容量を 160 項目に拡大がマージされた。アウトオブオーダー実行ウィンドウのパラメータレベルの性能調整に属し、同時にインフライト可能な命令数を直接拡大する。シミュレーション側では GEM5（xs-dev ブランチ）に #1231：2 スレッド SpMT のためのミドルエンドリソース分割の追加がマージされ、マルチスレッドでフロントエンド／リネームリソースを共有する際の分離とクォータを指向する。検証側では同一期間に 2 件：NEMU #1246 は昆明湖 V2（kmhv2）設定を新規追加し、V2 と V3 の共通修正を整合させることで、参照モデルが両世代のマイクロアーキテクチャを同時にカバーできるようにした；#1252 は DiffTest のストレージ CRC 検証オーバーヘッドを低減する。期間内に difftest、XSCache のメインブランチには新規追加なし。

1.2 openRuyi：メインリポジトリに Rust エコシステムのソフトウェアパッケージ 6 件を一括マージ、ベアメタルとドライバ開発コンポーネントを補完

日付：2026-10-16　情報源：openRuyi メインリポジトリのコミット記録（10-16）

openRuyi メインリポジトリにメンテナの luojia65 が 6 件の SPECS パッケージを一括コミットした：rust-riscv 0.16、rust-riscv-macros 0.4、rust-riscv-types 0.1、rust-embedded-hal 1、rust-volatile-register 0.2、rust-vcell 0.1。このパッケージ群は RISC-V ベアメタルランタイム、組込み HAL 抽象化、低レベルレジスタアクセスをカバーし、Rust が RISC-V ベアメタルおよびドライバのシナリオで実装されるための低レベル依存群である；ディストリビューションにとっては、Rust のサポート範囲がコンパイラ自体からランタイムコンポーネントへとグループ単位でパッケージ体系に進出することを意味する。公式サイトのニュースページには当期の新バージョン公告なし（最新は依然として 2026.09）。

1.3 meta-riscv：linux-mainline を 7.2.11 に更新、riscv-common をメインラインカーネルと U-Boot 優先に変更

日付：2026-10-16~10-19　情報源：riscv/meta-riscv コミット記録（10-16~10-19）

Yocto レイヤー meta-riscv の調査期間内の14 コミット：linux-mainline が 7.2.10 から 7.2.11 へアップグレード。riscv-common はメインライン Linux と U-Boot を優先するよう調整され、ベンダー BSP ブランチへの依存を削減。ドキュメント側では進畳時空 K3 Pico-ITX、K3 COM260、LicheePi-4A の起動と UART の説明を補完し、freedom-u540 に KERNEL_IMAGETYPE=Image を設定。ディストリビューションビルドレイヤーはメインラインへ収束し、openRuyi、RevyOS の最近のプラットフォーム集約の動きと同方向である。

2. 製品・エコシステム動向

2.1 Tenstorrent、Intel と Qualcomm の両社と売却交渉中と報道、評価額は 50 億ドル超の可能性

日付：2026-10-17　情報源：Startup Fortune：Intel and Qualcomm Both Court Jim Keller’s AI Chip Startup Tenstorrent（10-17）

Bloomberg の報道によると（Startup Fortune が転載）、RISC-V AI チップ企業 Tenstorrent が Intel、Qualcomm とそれぞれ潜在的な売却について交渉中であり、すでに投資銀行を招聘して評価を進めており、取引評価額は50 億ドルを超える可能性がある。報道を受けて Intel 株価は一時 6.4% 上昇した。Intel、Qualcomm、Tenstorrent はいずれもコメントを拒否している。Tenstorrent は Jim Keller が率いる、RISC-V 高性能 AI アクセラレーションと IP の代表的な企業である。今年 6 月には Qualcomm が 80〜100 億ドルで買収交渉中との噂が流れ、Keller は当時これを否定していた。本件は依然としてメディア報道の段階にあり、いずれの当事者からも確認されていない。

2.2 AI エージェントが RISC-V 暗号 SoC の全工程設計を完了：計算コスト約 2000 ドル、消費電力 20 mW

日付：2026-10-16（原報道 10-15）　情報源：騰訊新聞（快科技）：門檻崩塌！AI 耗資 1.4 万就能設計出 RISC-V 芯片（10-16）

半導体ブロガー @bubbleboi は Meta の Muse AI エージェントを使用し、RISC-V 暗号専用 SoC の論理設計から配置配線までの全工程を完了した。消費は約 1 億トークン、計算コストは約 2000 ドル。OpenROAD を用いて配置配線を完了し、ファウンドリに送付可能な GDSII レイアウトを生成した。設計は約 61590 個の論理セル、100 MHz、消費電力 20 mW、タイミング余裕 4.5 ns を含み、DRC チェックと 150 万本の Berkeley TestFloat ベクタ検証を通過した。作者はマルチプロジェクトウェハ（MPW）のシャトル流片機会を探している。この結果はまだシリコン検証されておらず、個人実験であるが、「AI によるチップ設計」のコスト曲線に対して再検証可能なサンプルを提供するものである。

3. 国内チーム深掘り

3.1 睿思芯科が戦略融資を完了：任君資本、水木基金が出資、RISC-V サーバー CPU を引き続き強化

日付：2026-10-16　情報源：搜狐（大河財立方）：睿思芯科完成戦略融資（10-16）

睿思芯科（深圳）が新たな戦略融資を完了した。投資家には任君資本、水木基金が含まれ、金額は非公開。同社は譚章熹が創設し、チームはカリフォルニア大学バークレー校の RISC-V オリジナルプロジェクトグループ出身。国内初の完全自社開発 RISC-V サーバープロセッサ「霊羽」を発表した。これに先立ち、深重投国資がリードする B ラウンドを完了している。今回の資金は RISC-V サーバー級高性能プロセッサとクラウドネイティブ CPU の研究開発に充てられる。譚章熹は同時に RISC-V 国際オープンソースラボラトリ（RIOS）の共同主任を務めており、本日のサミット開幕式でも挨拶を行った。

3.2 奕斯偉計算の上場後初週：時価総額 338 億香港ドル、ヒューマンインタラクションが依然として収入の 76% を占める

日付：2026-10-17　情報源：新浪財経（中国経営報）：奕斯偉計算上市即破発 RISC-V 仍待規模化商用（10-17）

10-09 香港証券取引所に上場した奕斯偉計算（01256.HK）の上場後初の市場評価が発表された。初日終値は1.535 香港ドル、0.97% 下落、時価総額は約 338 億香港ドル。2023～2025 年の売上高は 17.52／20.25／24.31 億元、調整後純利益はそれぞれ −17.05／−14.40／−11.61 億元、粗利益率は 14%～18% の範囲。人間機械交互チップが依然として収入の基本盤の 76% を占め、単価は 20.9 元から 11.6 元に低下した。2025 年の売上高ベースで、中国の RISC-V 主制御チップ市場において第 5 位、国産メーカーでは第 3 位、シェア 1.2%（上位 5 社合計 22.5%）。

3.3 進畳時空 llama.cpp ブランチが v0.2.3 をリリース：K3 デコード状態最適化をマージし上流を同期

日付：2026-10-16　情報源：llama.cpp v0.2.3 Release（10-16）、PR #48：perf/k3-decode-state（10-16）

spacemit-com/llama.cpp の mtmd-backend ブランチが v0.2.3 をリリース：#48（K3 デコード段階の状態再利用最適化）と #47（上流 20261014 バージョンの同期）をマージし、バージョン番号を更新した。このブランチは約 1～3 週に 1 版のペースを維持しており（v0.2.2 は 10-13 にリリース）、K1／K3 のエッジ推論の可用性と性能を継続的に収束させている。

3.4 算能 zsbl：各 cpusys を独立したアプリケーションサブディレクトリに分割

日付：2026-10-16　情報源：sophgo/zsbl コミット記録（10-16）

算能 zsbl（ZScale Boot Loader）の調査期間内の構造調整 1 件：各 cpusys を独立したアプリケーションサブディレクトリに分割し、異なるチッププラットフォームごとにブートコードを保守しやすくした。ブートファームウェア側のエンジニアリングリファクタリングであり、機能変更は含まない。同期間に sophon-tools にもプッシュがあった。

4. エンボディドインテリジェンスとロボット特章

4.1 智元機器が芯際無限に戦略的出資：RISC-V ヒューマノイドロボットの算力が専用基盤へ

日付：2026-10-18　情報源：搜狐（半導体産業縦横）：智元戦略投資芯際無限！清華系 RISC-V エンボディドインテリジェンス算力赛道を強化（10-18）

智元機器が清華系 RISC-V AI チップ企業芯際無限に戦略的出資。芯際無限は清華大学が唯一技術移転し株式を保有する RISC-V AI チップ企業であり、チームは 2016 年から RISC-V 研究に従事している。2026 年には清華華控技術移転がコア RISC-V 知的財産権を現物出資として持株に組み入れた。製品側：

  • XC64AE（小脳チップ）：12 コア RISC-V コア＋自社開発 NPU、運動制御と中級環境知覚を両立。初号品はすでにテープアウト・回片を経て標準化開発方案を打ち出した。V1000（大脳チップ）は 2.5D Chiplet をベースに、公称 1000 TOPS。関節制御チップは量産済み、2027 年には第 2 世代 XC64AE 全シリーズのテープアウトを計画。
  • 車載 XC32 シリーズ：XC32MC 車体モータ制御 MCU はすでに大量に車載され、累計受注は 500 万個超。XC32LS は ASIL-D に適合し、テープアウト・点灯済みで 2027 年の量産を計画。XC32DC 中央ドメイン制御は 2028 年の定点量産を見込む。
  • 意義：テスラの自社開発 FSD やエヌビディア Jetson の汎用プラットフォームとは異なり、芯際無限は「フルスタック自社開発 RISC-V＋トリミング可能な命令拡張＋Chiplet」という第 3 の路線を選択。智元は実機シーンと実測データをもたらし、チップがサンプルから量産検証へ移行するのを加速させる。

4.2 サミットのロボット議題：10-20 に汽車電子・工業・ロボット分科会を設置、エンボディドインテリジェンス浸透率は 28.2% へ上昇見込み

日付：2026-10-17～10-19　情報源：第 6 回 RISC-V 中国サミット公式サイト議程、証券時報：RISC-V 重要サミット開催へ、産業空間は 2000 億元超の見込み（10-17）

サミットは 10-20 に「汽車電子・工業・ロボット」分科会を設置（共同議長：賽昉科技徐滔、沁恒微楊勇）。メインフォーラムでも零次方機器が RISC-V アーキテクチャのエンボディドインテリジェンス分野での応用を共有する予定。市場側では、Frost & Sullivan のデータにより、RISC-V の中国エンボディドインテリジェンスチップにおける浸透率は 2025 年の 10.7% から 2030 年には 28.2% へ、スマート端末は 6.9% から 26.7% へ上昇すると予測。中国の RISC-V 主制御チップ市場は 2025 年の約 377 億元から 2030 年には約 2194 億元へ増加する。

5. まとめとトレンド観察

  • サミットは「アジェンダ実現」段階へ：会議2週間前のアジェンダ、出展社、講演者の事前告知は終了し、10-19のメインフォーラムと10-20の7つのサブフォーラムが「エコシステム成熟度」の語りを検証する一次資料となる。AIとデータセンターの2つの主軸（達摩院 AME、奕斯偉 RISC-V＋AI、藍芯 LX500）はメインフォーラム午後の部に集中している。
  • 資本の冷熱分化が顕著：プライマリ市場は継続的に出資を強化（智元が芯際無限に出資、睿思芯科が戦略投資を完了）する一方、セカンダリ市場は「理性的にやや冷めた」価格付けを示している（奕斯偉は上場初日に公開価格割れ、A株の RISC-V 関連銘柄は年間平均で下落）。産業の長期的な成長余地（2030年に2194億元）と短期的な利益実現との間のミスマッチが、依然としてバリュエーションの主軸である。
  • ソフトウェアスタックの3つの推進ライン：マイクロアーキテクチャ側では香山が ROB 拡張と NEMU のデュアルバージョン構成により性能と検証範囲を向上。ディストリビューション側では openRuyi が Rust ランタイムコンポーネントを補完し、meta-riscv がメインラインカーネル／U-Boot へ収束。エッジ推論側では進迭時空の llama.cpp が1〜3週間に1版のイテレーションを維持している。
  • Embodied AI が RISC-V の差別化戦場に：芯際無限の専用 SoC＋Chiplet から、サミットのロボットサブフォーラムや28.2%の普及率予測まで、ロボティクス演算における RISC-V の語りは「利用可能」から「専用基盤＋シーンデータのクローズドループ」へと転換している。
  • 限界の説明：サミットメインフォーラムの講演者と順序は会議前に公表された資料に基づく。公式サイトは10-19について依然として「詳細アジェンダは近日公開」と表記しており、現場の情報を優先する。Tenstorrent の売却案件はメディア報道であり、三者は未確認。AI による RISC-V SoC 設計は個人の実験であり、まだテープアウトしていないため、データは作者の公開説明に基づく。会員公式サイトの巡回で確認された変化は主にマーケティングページの更新であり、実質的な製品リリースは検出されなかった。
