今日の重点：進畳時空が香山と共同でサーバー級 CPU V100 を発表、業界初の RISC-V サーバー規範に完全準拠

日付：2026-10-19　出典：電子創新網：進畳時空がサーバー級 CPU V100 を発表（10-19）、深圳新聞網：進畳時空がサーバー級 CPU V100 を発表（10-19）、Phoronix：SpacemiT Announces The V100 Server-Class RISC-V Processor（10-19）、21 経済網：RISC-V サーバー規範に完全準拠した初のチップが発表（10-19）

第6回 RISC-V 中国サミット2日目（10-19）、進畳時空（SpacemiT）と香山チームが共同でサーバー級 CPU V100 を発表し、同時に計算・智算・ストレージの3種類のサーバー整機を投入した。同社はこれを業界初の RISC-V サーバー規範に完全準拠した汎用計算チップと称している。

  • 仕様カバレッジ：サーバー仕様をチップ、ファームウェア、オペレーティングシステムの3層に落とし込み、RVA23、サーバー SoC、サーバープラットフォーム、起動・ランタイムサービス（BRS）、セキュリティモデルの5項目の仕様をカバーする。うちBRS 仕様テストは全項目合格し、openEuler、openRuyi、openKylin、Debian、Ubuntu、Fedora、Red Hat、Rocky など主要 Linux ディストリビューションの直接インストール、起動、実行をサポートし、チップごとに個別にシステムをカスタマイズする必要がなくなった。
  • マイクロアーキテクチャ：46コアのハイブリッド設計——6個の香山昆明湖 V2R2コア + 40個の自研 X100コア、最高動作周波数2.4 GHz、デュアルソケット・コヒーレント相互接続で最大92コアまで拡張可能。単チップ8チャネル DDR5-4800、52レーン PCIe 5.0。プロセスと消費電力側（海外メディアの報道による）は12nm、120W TDPで、UEFI、ACPI、SMBIOS をサポートする。
  • データセンターに必須の要素：H 拡張、AIA、IOMMU をサポートし、CPU、メモリ、割り込み、I/O のハードウェア仮想化機能を備える。仮想化拡張はアップストリーム Linux でネイティブサポート済みで、カスタムカーネルは不要。オンチップにハードウェア信任ルートを統合し、RISC-V ネイティブ TEE をサポート。RERI RAS 仕様をサポートする。クラウド向け Agent アプリケーション向けに軽量仮想マシンソリューションを提供し、コンテナに近いリソースオーバーヘッドで仮想マシン級の分離を実現する。
  • システム製品とエコシステム：C2201 計算サーバー、G5201 智算サーバー、S5236 ストレージサーバー。うち G5201 はフルハイト・フルレングス・デュアル幅のアクセラレータカード8枚をサポートし、昆仑芯 M100などの国産アクセラレータカードを検証済みで、高速 RDMA ネットワーキングをサポートする。付属のマザーボード、ファームウェア、BMC 管理、ハードウェアリファレンスデザインは外部に公開されている。
  • コメント：創業者兼 CEO の陳志堅氏は「V100 は進迭時空がエッジからクラウドへ進む重要な一歩であるだけでなく、RISC-V が真に展開可能で大規模応用可能なデータセンター市場へ向かっていることを表している」と述べた。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 Linux 7.3 正式リリース：RISC-V が RVA23 識別、カウンタ委譲、KVM 拡張を補完

日付：2026-10-18（メディア報道 10-19）　情報源：Phoronix：Linux 7.3 Released（10-18）、Kernel Newbies：Linux 7.3 変更リスト

Linux 7.3 が10月18日に予定通りリリースされた。RISC-V 側で本バージョンに盛り込まれた内容は以下の通り：hwprobe が RVA23U64 の基本動作を公開し、ユーザー空間からマシンが RVA23 に準拠しているかを直接判断できるようにした。カウンタ委譲関連拡張（Smcdeleg／Ssccfg／Smcntrpmf）のサポートおよび Ssqosid と CBQRI の resctrl サポートを追加。KVM に Svadu、Zicfiss、Zicfilp の FWFT サポートを追加。EFI ランタイムサービスを用いたシャットダウンと再起動に変更。arm64 と RISC-V が共同で crashkernel CMA 予約サポートを獲得。静的計算 alternative セグメント境界を修正して vDSO との互換性を修復し、さらに xip サポートを削除。プラットフォーム側では StarFive JHB100 の初期デバイスツリーと Canaan K230（64ビット RISC-V AI SoC）のサポートを追加。さらに Smcsrind／Sscsrind、Zicclsm、Ziccamoa、Ziccif、Ziccrse、Za64rs などの拡張の識別と列挙を補完した。ディストリビューションにとって、RVA23 の検出可能性は「Kconfig で推測する」から「実行時に判定する」への鍵となる一歩である。

1.2 香山：XSCache が結合 L2 バンク別 SRAM とプリフェッチ准入スロットリングをマージ

日付：2026-10-19　情報源：XSCache PR #36（10-19）、XiangShan PR #6738（10-19）、GEM5 PR #1241（10-19）

香山主リポジトリ（kunminghu-v3）の調査期間内に1件：#6738 XSCache サブモジュールのバージョンを向上。キャッシュ側の XSCache #36 は実質的な性能コミットであり、CoupledL2 の L2 SRAM を set と bank ごとに分割し、さらにプリフェッチ准入（prefetch admission）にレート制限を实施しており、ラストレベルキャッシュの帯域競合とプリフェッチ汚染という2種類の問題を指向している。シミュレーション側の GEM5（xs-dev）#1241 はアウトオブオーダーモデルを修正し、store と AMO の送信失敗時にload パイプラインの replay マークをスキップして、誤ったリプレイ計上の回避を図っている。参照モデル NEMU と difftest のメインブランチには調査期間内の新規追加はない（直近は 10-16 の CRC チェックオーバーヘッド最適化）。

1.3 openRuyi：dpdk が RISC-V の lpm と fib 検索最適化をバックポート、spdk が 26.09 にアップグレード

日付：2026-10-19　情報源：openRuyi メインリポジトリのコミット記録（10-19）、openRuyi 公式サイトニュースページ

openRuyi メインリポジトリの調査期間内に15件のコミット、性能側で最も記録に値するのは2件：dpdk が RISC-V の lpm と fib 検索最適化をバックポートし、仮想スイッチとルーティング転送パスに直接作用する；spdk が 26.09 にアップグレードされ、上流のストレージスタックバージョンに追随した。パッケージ側では引き続き Rust エコシステムをグループ単位で補充：rust-brotli-7、brotli-decompressor-4、botan-0.10、alloc-stdlib-2、alloc-no-stdlib-2、winreg-0.52、sequoia-man-0.3、self-replace-1 を新規追加し、rust-regex を 1.13.1 に、regex-automata を 0.4.18 に、regex-syntax を 0.8.11 にアップグレード；go-gopkg-h2non-gock を 1.2.0 にアップグレードし重複プロバイダを整理した。同期間中に組織内の lookout、kiwi-image、TakoPack にもプッシュがあった。公式サイトのニュースページの最新バージョンは依然として 2026.09（9月30日リリース、本版は RVA23 サポートの改善、クラウドとストレージソフトウェアスタックの拡充、Go 1.27 ビルド環境へのアップグレード）であり、調査期間内に新バージョンの告知はない。

2. 製品とエコシステムの動向

2.1 中興微電子傘下の砺睿微が智算センター向け RISC-V CPU「珠峰200」を初公開

日付：2026-10-19　情報源：21経済網（科創板日報）：中興微傘下の砺睿微が智算センター向け高性能 RISC-V チップを初展示（10-19）、網易：砺睿微の RISC-V チップを初展示（10-19）

第6回 RISC-V 中国サミット期間中、中興微電子傘下の砺睿微が智算センター向けに開発した高性能 RISC-V CPU チップ珠峰200 を初めて対外展示した。公式の説明では業界初の智算センターシーン向け RISC-V CPU チップとされ、3つのシーンに焦点を当てる：Agent クラスタ、推論スーパーノード Host、エンタープライズ向け智算ハイブリッド推論；ネイティブに RISC-V AI 命令加速を搭載し、KV Cache と長コンテキスト大規模モデル推論向けに最適化を行っている。ハードウェアには Matrix、Vector、圧縮、暗号化の各種加速エンジンを統合し、DDR5、PCIe、CXL の高速相互接続インターフェースをサポート、「RISC-V ネイティブ AI + GPU アクセラレータカード」の MoE ハイブリッド推論方案に適合可能。詳細な製品仕様は今年末に正式発表予定であり、今回は方向性とシーンのみを確認、性能データは未公表。

2.2 Tenstorrent が15億ドルのシリーズ E 資金調達を完了、投資後評価額62億ドル

日付：2026-10-19　情報源：Tenstorrent プレスリリース：Tenstorrent Announces a $1.5B Series E at a $6.2B valuation（10-19）、Dealroom：Tenstorrent raises $1.5B Series E（10-19）、Quartz：Tenstorrent raised $1.5 billion（10-19）

Tenstorrent は 10 月 19 日、15 億ドルのシリーズ E 資金調達を完了したと発表した。投資後評価額は 62 億ドルで、2024 年の約 26 億ドルから倍以上となり、米国半導体企業のシリーズ E としては最大規模の一つとなる。今回のラウンドは新設の Trace Capital（創業者 Ben Mahdavi）と Innovation X が共同でリードし、Fidelity、T. Rowe Price、Morgan Stanley、Sandisk、Tether Investments、Cadence Ventures、ARK Invest、Agostinelli Group などが参加した。資金は量産とグローバル商用展開の拡大に充てられ、Galaxy サーバの規模化された展開を推進する。この結果は二日前の「Intel、Qualcomm が同時に買収交渉」との報道と対照をなす——メディアは同社が売却を拒否し、独立での資金調達を選択したと伝えている。Tenstorrent は Jim Keller が率いる、RISC-V 高性能 AI アクセラレーションと IP の代表的な企業である。

2.3 超睿科技 UR-CP400 プロセッサコアが登場：RVA23、8 発行アウトオブオーダー、SPECint 22 ポイント毎ギガヘルツ超

日付：2026-10-19　情報源：搜狐（90 説科技）：超睿科技 2026 RISC-V 中国サミットに登場（10-19）

超睿科技（UltraRISC）はサミットのコア展示エリアで UR シリーズ高性能 RISC-V プロセッサコアと、UR-DP1000 ベースの多シナリオ・システムレベルソリューションを展示した。今回の世代の重点 UR-CP400 は、RVA23 仕様に準拠し、RVV 1.0 をサポートし、アウトオブオーダー 8 発行、14 段パイプラインのマイクロアーキテクチャを採用、FPGA シミュレーション構成において SPECint_base2006 が 22 ポイント毎ギガヘルツを超える；マルチレイヤクラウド環境向けに仮想化を強化し、Agentic AI 向けに特化したハードウェア最適化を行い、会場では FPGA プロトタイプシステムを実演した。UR-CP400 の IP は 2027 年第 1 四半期に提供予定である。同社は同時に、プロセッサコア IP、マルチコア CPU チップ、AI エッジ、マルチノードクラスタ、仮想化アプリケーションの階層型製品布局を展示し、CTO の蒋江氏はデータセンター・高性能計算分科会で技術講演を行った。

3. 国内チームの深掘り

3.1 達摩院玄鉄：出荷 60 億個超、初のデュアル ASIL 認証車載 CPU IP E908A を発表

日付：2026-10-19　情報源：東方財富（上海証券報）：孟建熠氏、玄鉄チップは安定出荷 60 億個超と発言（10-19）、搜狐（钛媒体）：達摩院、車載強化プロセッサ玄鉄 E908A を発表（10-19）、IT 之家：玄鉄チップ出荷 60 億個超（10-19）、聯合新聞網：RISC-V が端末への浸透を加速（10-19）

達摩院首席科学者の孟建熠氏はサミットで、玄鉄チップは累計で安定出荷 60 億個を超えた（2024 年に初めて 40 億個を突破）と述べ、Omdia の予測を引用した：2030 年までに世界の RISC-V プロセッサ年間出荷量は年率約 30% 増加し、世界のプロセッサ出荷シェアの約 25% を占める見通し。

同日発表された車載強化プロセッサ玄鉄 E908A：公式はこれをASIL-B と ASIL-D の基準を同時に達成した初の RISC-V CPU IPと称し、シングルポイント安全指標（SPFM）が業界で初めて 90% を超えたとし、セーフティアイランド、ドメインコントローラ、車載ゲートウェイなどのシーン向けにリアルタイム計算基盤を提供する。達摩院は同時に自動運転と具現化知能（エンボディドインテリジェンス）製品のロードマップを初公開し、次世代 C950A の目標性能は既存の RISC-V 車載製品の 5 倍とした。ハードウェア側では本期新規のオープンソースリポジトリへのコミットはなく（XUANTIE-RV 組織の調査期間内は 0 プッシュ、直近は 10-15 の ATS／拡張仕様リポジトリの更新）、本期の玄鉄動向は IP 製品とロードマップに集中しており、商業化側の進展に属する。

3.2 芯際無限が Pre-A ラウンドの資金調達を完了：智元が安徽国資と共同出資、具現化知能フルスタック RISC-V チップを主軸に

日付：2026-10-19　情報源：東方財富（界面新聞）：芯際無限が Pre-A ラウンドの資金調達を完了（10-19）、新浪科技（投中網）：芯際無限が Pre-A ラウンドの資金調達を完了（10-19）、網易（問芯）：清華系 RISC-V チップ企業が数千万規模の資金調達、智元機器が戦略投資（10-19）

上海芯際無限智能科技は 10 月 19 日、Pre-A ラウンドの資金調達を完了したと発表した。智元機器が安徽省汽車創新中心、国元股権、合肥包河創投と共同出資し、総額は数千万人民元、万創投行が財務アドバイザーを務める。資金は主に具現化知能フルスタック RISC-V チップの研究開発と産業化に充てられる。本ラウンドは前回のデイリーレポートにおける「智元の戦略出資」事項の正式な成約開示であり、投資家構成、金額、アドバイザー情報が新たに追加された。

企業側の補足事実：2023 年設立（旧名「芯車無限」）、2026 年に社名変更し、清華華控技術移転を通じて核心 RISC-V 知的財産権を現物出資として組み入れ、清華が唯一技術転化し株式を保有する RISC-V AI チップ企業である。核心チームは 2016 年から RISC-V の研究開発に従事。製品は二つのライン：

  • 車載 XC32 シリーズ：XC32MC 車体モータ制御 MCU はすでに量産車に搭載され、出荷は 100 万個超、2026 年の新規受注は 520 万個、顧客には江淮、奇瑞が含まれる。XC32LS（ASIL-D デュアルコアロックステップ）はすでにテープアウト・点灯を完了し、自動車メーカーと一次サプライヤーのテストに入っており、2027 年に量産。XC32DC 中央ドメインコントローラは 2028 年の指名量産を計画。
  • 具現化知能 XC64AE シリーズ：小脳チップ XC64AE（12 コア RISC-V + 自社開発 NPU）の初号品はすでにテープアウト・回収を完了し標準化開発方案を発表。大脳チップ V1000 は 2.5D Chiplet ベースで、計画演算性能 1000 TOPS。関節制御チップはすでに量産済み。2027 年に第二世代 XC64AE 全シリーズのテープアウトを計画。

3.3 算能：一括デプロイツールを Go と Fyne で書き換え、sophon-demo は各種 C++ サンプルを补齐

日付：2026-10-19　情報源：sophgo/sophon-tools コミット記録（10-19）、sophgo/sophon-demo コミット記録（10-19）

算能は調査期間内に二つの製品ラインを集中的に更新し、いずれも実装効率に焦点を当てており、チップ仕様ではない：

  • sophon-tools は 1 日で 7 コミット：一括デプロイツール pqt_batch_deployment を Go + Fyne で書き換え、Linux／Windows 両プラットフォームの単一バイナリを出力。その後バージョンごとに 2.1.0 で Web UI とグラフィックスタックなしの headless ビルドを追加、2.2.0 でデスクトップ GUI と Web UI のビジュアルを刷新、2.3.0 で LAN スキャン、MAC プレフィックスによるデバイスの一括検出と追加をサポート、2.4.0 で MAC なしのフォールバックモード（Ping のみ）を追加。また seskill はパッケージ生成時にベクトルインデックスを事前構築し、インデックスとドキュメント内容をバインドする（bmssm 2.3.18／se-rag-core 1.4.0）。

4.1 Ubitium が 1400 万ドルのシードラウンドを完了：再構成可能 RISC-V アレイがフィジカル AI に向ける

日付：2026-10-13（中国語メディア 10-19 報道）　情報源：Ubitium プレスリリース（10-13）、Evertiq：Ubitium raises $14M（10-16）、至頂網：Ubitium が 1400 万ドルを調達（10-19）

ドイツ・デュッセルドルフのスタートアップ Ubitium は、Ibex Investors がリードし OpenOcean が参加、既存株主の KBC Focus Fund、Runa Capital、Inflection がフォローオンした1400 万ドルの新シードラウンドを完了したと発表した。シードラウンドの累計調達額は1800 万ドル。同社が取り組むのは再構成可能 RISC-V アレイ（CGRA 路線）である。一群のプログラマブル処理ユニットをソフトウェア設定に応じてシグナル処理、AI 推論、リアルタイム制御の三種類の負荷に動的に配分し、統一メモリと標準 RISC-V ツールチェーンによって「DSP + NPU + CPU」のマルチチップスタックを置き換える。ドローン、ロボット、車両、産業機器のフィジカル AI シーンを主眼とする。初号検証チップ UB108 はサムスン 8nm を採用し 256 個の処理ユニットを搭載、三種類の計算を同一アレイ上で実行するデモを実演済み。初号商用チップ UB410 は 4096 個の処理ユニットを計画し、評価サンプルは 2027 年納品予定。この方向性は国内の「車載規格 + エンボディド」専用 SoC 路線と相互に対照をなす。一方は専用化を、一方は再構成可能な汎用化を志向する。

4.3 進畳時空のロボティクス知覚スタック：平面再構成が VDEC 不可用時に CPU 画像デコードへフォールバック

日付：2026-10-19　情報源：spacemit-robotics/perception PR #10（10-19）

spacemit-robotics 組織の調査期間内のプッシュは 1 件：perception #10「planar フローが VDEC 不可用時に CPU JPEG デコードへフォールバック」。このリポジトリはロボットビジョンの平面再構成（planar）フローを担い、これまでの数週間にわたり特徴検出パラメータのスコープ、ONNX Runtime のリンク、モデルダウンロードの堅牢性を継続的に調整してきた。今回はハードウェアビデオデコード欠如時のデグレードパスを補完した。K3 などの端側チップを算力基盤とするロボット整機にとって、性能最適化ではなく「ハードデコードがなくても動作する」ための可用性修正である。同組織の他のリポジトリには調査期間内のプッシュはない。

5. 総括とトレンド観察

  • サーバー規範が「ドキュメント」から「製品」へ：V100 は RVA23、サーバー SoC、サーバープラットフォーム、BRS、セキュリティモデルの5項目の規範を一度にチップ、ファームウェア、オペレーティングシステムの3層に落とし込み、しかも BRS テストは全項目合格、主要ディストリビューションは直接インストール可能である。これは RISC-V サーバーが「1チップ1システム」という組み込みの慣性から脱却し、x86 型の汎用プラットフォームモデルに近づき始めたことを意味する——これは今号で最も構造的な一歩である。
  • オープンソースコアが初めて商用サーバーチップに進出：V100 の46コアのうち6個が香山昆明湖 V2R2 である。オープンソースの高性能コアはもはや学術・検証の対象にとどまらず、IP の形で販売可能なデータセンタ製品に進出しており、香山の「オープンソース→製品」という経路はこれにより検証可能なサンプルを一度得たことになる。
  • 智算センターが新たな競争軸に：珠峰200 は Agent クラスタ、推論スーパーノード Host、ハイブリッド推論を明確にシーンとして掲げ、G5201 は昆仑芯 M100 を検証済みで RDMA ネットワーキングをサポートし、さらに算能が予告した RISC-V 智算サーバー——三者はいずれも「CPU + 国産アクセラレータカード」の組み合わせを推論クラスタへと押し出しており、汎用サーバーへの単点対標ではない。
  • 基盤ソフトウェア側も判定可能性を同時に補完：Linux 7.3 は RVA23 を hwprobe 経由で実行時に判定可能にし、カウンタ委譲、QoS 識別子、KVM の Svadu とシャドウスタック拡張を補完した。openRuyi は RISC-V の lpm／fib 検索最適化を dpdk にバックポートした。前者は「自分が RVA23 であることをどう知るか」を解決し、後者は「知った後に性能を実現できるか」を解決する。
  • 資本の冷熱は依然として分化：Tenstorrent は62億ドル評価で15億ドルのシリーズ E を完了し、売却を明確に拒否した。国内の芯际無限の数千万元の Pre-A とは桁違いの対照をなす。しかし両者に共通するのは、資金がいずれも「量産とシーン実装」に向かっており、アーキテクチャ検証ではないという点である。玄鉄の60億個出荷と E908A の車載向けデュアル ASIL 認証は、規模でエコシステムを獲得するもう一つの経路を提示している。
  • 限界の説明：V100 の12nm／120W プロセスと消費電力データは海外メディアの報道によるもので、公式中国語稿にはこの2項目が記載されていない。珠峰200 はシーンとインターフェースのみを公表しており、仕様と性能は年末のリリースを基準とする。算能と北京オープンソースチップ研究院のサミットでのライトニングトーク内容はアジェンダの予定であり、具体的な製品仕様は公開資料で確認されていない。Ubitium の資金調達発表は10-13で、今号の収録根拠は10-19の中国語メディア報道である。会員公式サイトの巡回で見られた変化はいずれも大学・機関トップページの定例更新であり、実質的な製品、資金調達、アーキテクチャの発表は検出されていない。
