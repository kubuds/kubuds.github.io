1. オープンソースコミュニティとソフトウェアエコシステム

1.1 eeNews 特集：RISC-V 高性能組み込み拡張の全体像

日付：2026-08-25　出典：eeNews Europe

eeNews Europe が総説長文を掲載し、組み込み RISC-V 拡張の現状を整理した。NIST 軽量暗号標準（Ascon シリーズ）が複数のアクセラレーション拡張を生み出した。CHERI は RV64Y 拡張として標準化を推進中で、英国の SCI Semiconductor が3月に初の商用テープアウトを完了し、Codasip は主力事業を売却して CHERI 実装へ転換した。Antmicro がオープンソースの Caliptra 信頼のルートプロジェクト向けに保守する VeeR EL2 コアに、User モードとデュアルコアロックステップ（DCLS）を追加した。欧州 PULP 体系の CV-X-IF コプロセッサインターフェースは OpenHW が普及を進め、カスタム拡張の統一を目指す。スペイン BSC の PQCUARK 拡張は NTT+Keccak のデュアルユニットにより後量子アルゴリズムを約10倍高速化し、ASIC 面積オーバーヘッドはわずか8%である。Quintauris は EM-Altair 組み込み実行環境 profile を発表し、MCU レベルのバイナリ互換性を保証するとともに、CEO 交代を完了した（Kocher 退任、Lopez 就任）。

1.2 riscv.org：RISER マイクロサーバープラットフォーム——システムプロトタイプ統合の課題

日付：2026-08-25　出典：RISC-V International Blog

RISC-V International ブログが、EU の Horizon Europe が資金提供する RISER プロジェクトの進捗を掲載した。プロジェクトは2023年1月から全欧州の RISC-V クラウドサーバーとアクセラレータのプロトタイプを開発しており、今回は EPAC1.5 RISC-V ベクトルプロセッサのテストチップに基づく FPGA 支援マイクロサーバープラットフォームを公開した。自社開発の起動ファームウェア、NVMe ストレージ、100 Gbps イーサネットを統合し、チップのブリングアップとユースケース検証で遭遇した統合課題を詳述している。プロジェクトはギリシャ FORTH の Manolis Marazakis 氏のチームが主導し、欧州クラウドインフラの「開かれた戦略的自律」目標に貢献する。

1.3 コミュニティブログ：Dawn Processor がアウトオブオーダー実行を実現

日付：2026-08-24　出典：outercloud.dev / Hacker News

個人開発者ブログ連載第三回：自研 RISC-V プロセッサ「黎明プロセッサ」（Dawn Processor）がアウトオブオーダー実行（OoO）対応を完了。命令ディスパッチキューと依存長テーブルでレジスタ依存を追跡し、シングルイシュー幅、レジスタリネーミングなし。主な利点はメモリアクセスレイテンシの隠蔽。現在の弱点は分岐による全パイプライン・フラッシュ（約 7 サイクル）とメモリ命令のボトルネックで、次版では分岐予測、キャッシュ、より広いイシュー幅の追加を計画。著者の目標は最速のオープンソース RISC-V プロセッサの実現であり、まず BOOM と香山を超える必要があると自己評価している。

2. 製品・エコシステム動向

2.1 Hot Chips 2026：XCENA MX1 CXL コンピューテーショナルメモリデバイス

日付：2026-08-25　情報源：ServeTheHome

Hot Chips 2026 において、韓国 XCENA と Samsung が共同で MX1 CXL コンピューテーショナルメモリデバイスを展示：Type 3 CXL デバイスは 1 枚のカード上に CXL メモリ拡張（4 チャネル DDR5-8400、最大 2 TB）、CXL メモリとして公開される SSD バックエンドストレージ、そして 3,072 個の 1.4 GHz カスタム RISC-V コアで構成される近メモリ計算アレイを融合している。その核心的な主張は、AI ワークロードはまず演算能力ではなくメモリ容量、帯域幅、消費電力によって制約されるというものである。Samsung のラック級 CXL メモリ計画に関する共同セッションと同場で発表された。

3. 国内チーム動向と深掘り

3.1 奕斯偉計算：IPO 目論見書の詳細、報告期間の累計損失が 52 億元超

日付：2026-08-25　情報源：新浪財経（gnews）

香港株 IPO のフォローアップ：目論見書は報告期間（2023 年から 2025 年および 2026 年第 1 四半期）の累計純損失が約 52.75 億元、売上高がそれぞれ 17.52 / 20.25 / 24.31 / 4.94 億元であることを開示している。上位 5 社の顧客の売上高占比は 83% から 91%、最大顧客（市場では一般に京東方を指すと見られる）の売上高占比は 82.1% から 39.3% に低下し、単一顧客への依存は著しく緩和された。同社は「価格を下げて量を取る」戦略で売上高を押し上げており、中核製品の単価は下落している。研究開発費は年々縮小（14.45 億元から 2.52 億元へ）。8 月 25 日に既報の IPO 開示に関する深掘りフォローアップである。

3.2 香山（OpenXiangShan）：調査期間内に 33 件のコミット、研究分析の蓄積が中心

日付：2026-08-25　情報源：GitHub commit 検索

OpenXiangShan 組織の調査期間内の 33 件のコミット：中核プロセッサリポジトリは平静で、主な動きは XiangShanLab がメモリサブシステムの実験分析ドキュメント（LFST、MDP、SSIT、折り畳み PC 生成器、ページテーブルキャッシュ、CBO-zero と CBO-inval のシナリオ分析）を新規追加し、香山関連論文を整理したこと。xs-env は定例の依存関係アップグレード（nixpkgs、gsim）。「研究分析の蓄積」型の活性であり、新しいアーキテクチャの変更は見られない。

3.3 進迭時空：K3 ドキュメント改訂と端側 TTS エコシステム更新

日付：2026-08-25　情報源：spacemit-com org

spacemit-com 組織の調査期間内 4 件のコミット：K3-CoM260 モジュールデータシート仕様改訂、K3 チップ DPU0/DPU1 ディスプレイインターフェース対応の明確化（ドキュメント）、model-zoo-tts で Kokoro TTS フロントエンドと Misaki のアラインメント完了（#23）、ai-sdk サブモジュールの同期更新。ドキュメント保守と端側モデルエコシステムの推進が中心で、K3 の実装配套を継続的に強化。

3.4 芯来科技：UX シリーズ IP で PicoClaw/OpenClaw を実行、国際メディアが伝達

日付：2026-08-25（公式初出 2026-04-24）　情報源：eeNews Europe / nucleisys.com

eeNews 特集の引用：芯来科技は自社開発の UX シリーズプロセッサ IP プラットフォーム上で PicoClaw と OpenClaw という二大エッジ AI Agent フレームワークのデプロイと全機能検証を完了——UX1000H（仮想化と RVA23 対応、アウトオブオーダー実行）が Agent スケジューリングを担当し、NI900 シリーズ（AI 推論アクセラレーション、RVV 1.0）が端側推論を担当；UX900 開発ボードは RV64GCV ベースで Ubuntu 24.04 を実行し軽量デプロイを完了、複雑なシナリオでは OpenClaw 3.9 が月之暗面 Kimi 大モデルを統合。公式ニュースは 4 月 24 日に初出、今回は国際メディアによる伝達であり、そのエッジ AI Agent 能力が海外で注目を集めたことを示す。

4. 具現化知能とロボット専門章

4.1 ヒューマノイドロボット産業レポート：上半期出荷 4 万台超、世界シェア 97%

日付：2026-08-25（レポートは 8-20 に世界ロボット大会で発表）　情報源：人民日報/人民網

中国人形ロボット・具現化知能百人会が 2026 世界ロボット大会で「2026 人形ロボット産業発展レポート」を発表：2026 年上半期の中国人形ロボット出荷量は 4 万台超、世界シェアは 97% に上昇；レポートは技術革新が「クラスター創出」の新段階に入ったとし、重要チップ、部品から完成機までの全産業チェーン製造能力を形成済みで、業界応用が小ロット試用から常態化デプロイと規模化応用へ加快していると述べた。第 2 回世界人形ロボット運動会は 8 月 22 日に国家速滑館で開幕、六大州 16 カ国から 666 チーム、2,056 台のロボットが参加。

4.2 天工 Omni、世界人形ロボット運動会 400 メートルで優勝

日付：2026-08-25（OSChina 転載；大会は 8-22 から 8-24）　情報源：OSChina / IT之家

第 2 回世界人形ロボット運動会 400 メートル小型クラス決勝で、北京人形ロボットイノベーションセンターの天工 Omni が 45.66 秒で優勝、その「顔を覆って走る」走法が会場の焦点に；研究開発チームはこの姿勢は人為的設定や遠隔操作ではなく、ロボットがシミュレーションで不断に反復し自ら選択した最適走法だと応答；8 月 24 日、天工 Omni は 400 メートル障害物競走でも優勝。このロボットは身長 1.35 メートル、機体 39 キロ、狭い空間、応急救助、家庭サービスシナリオ向けで、関節、センサー、システム、運動制御 API の二次開発体系を開放。
