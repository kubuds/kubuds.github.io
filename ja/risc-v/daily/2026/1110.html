今日の重点：芯來が NI1000 をリリース、VME 行列拡張を初サポートする RISC-V 汎用 AI 演算コア（11-09）

芯來科技は 11 月 9 日、NI1000 RISC-V CPU IP を発表した。公式によれば、Vector Matrix Extension（VME）をサポートする初の高性能汎用 AI プロセッサ IP である。NI シリーズは芯來の AI アプリケーション向け単列製品ラインで、900 または 1000 シリーズとして構成可能。RVV 1.0 ベクトルユニット（VPU）の VLEN は 512、1024、2048、4096 ビットに設定でき、クラスタ内の各コアが独自の VPU を独立して構成できる。コア間は IOCP（IO Coherent Port）を介して NPU アクセラレータと緊密に結合され、キャッシュコヒーレンシを維持する。NICE／VNICE インターフェースによりユーザーはスカラーおよびベクトル命令をカスタマイズでき、NICE は NPU との緊密結合インタラクションにも使用できる。

技術的な要点は VME の実装方式にある。VME は CPU、RVV と同一コア内で緊密に結合され、ソースオペランドは RVV のベクトルレジスタ群を直接再利用し、演算ユニットも RVV の実行ユニットを再利用するため、追加されるのは Matrix Tiles の面積のみである。新たに追加されたネイティブ行列命令は外積結果を専用の N×N アキュムレータに累積し、4 組の独立した Matrix Tiles がピンポン並列でスループットを向上させ、さらに FP8 データ型のネイティブサポートを追加した。芯來が示したデータによれば、NI1020（VLEN 1024）上で 32×32 の FP32 行列乗算を実行した場合、全体の面積増加はわずか 15%（主に Matrix Tiles）で、行列乗算性能は 2.5 倍向上する。

位置づけの説明はかなり控えめだ。公式には、NI シリーズは NPU や GPU などのアクセラレータ IP を置き換えるものではなく、それらと組み合わせて AI SoC 上のアクセラレータにより良く貢献すると明記されている。この点は VME の取捨選択と一致する。IME と比較すると独立した行列累加ハードウェアを持ち、行列演算のエネルギー効率がより高い。AME と比較すると完全な独立行列レジスタファイルとハードウェア行列アクセラレータを省いている。VME はその中間に立ち、制御可能なハードウェアコストで行列演算能力を獲得するが、その代償としてピークエネルギー効率は専用行列ユニットに劣る。芯来は同時に、VME が完全に RVV を基盤としており、ソフトウェアエコシステムを再利用できると強調し、VME が最も早く標準化される RISC-V 行列拡張になると判断している。

この記事を今月の座標に置いて見ると、補っているのは「汎用演算コア」という層だ。前の週のニュースは車載グレード MCU（インフィニオン AURIX RC1）、端末側ビジョン SoC（為旌 VS815V）、セキュリティコア（AMD の RISC-V TEE）に集中しており、いずれも RISC-V を特定の機能ユニットに組み込むものだった。NI1000 が向き合うのは、AI チップの中の「何でも少しずつこなす」汎用コアである。スカラー制御を実行し、ベクトルオペレータを実行し、さらに一般的な規模の行列積を引き受け、そして NPU と分業する。国内の AI チップ企業は長らくこの層で二択を迫られてきた。高性能アプリケーションコアを外購するか、自社開発するがソフトウェアスタックを背負うか。VME が RVV を再利用する道筋は、実質的にこの選択問題のコストを引き下げるものであり、顧客に受け入れられるかどうかは、ツールチェーンとオペレータライブラリが追随できるかどうかにかかっている。

openRuyi メインリポジトリで1日20件：wlroots 0.20.2、wget2 2.3.0、LLVM 22〜24 の Python バインディング修正（11-09／11-10）

openRuyi メインリポジトリは調査期間内に20件の SPECS コミットを着地させた。そのペースは典型的な「ローリングディストリビューションの日常」であり、集中リリースではない。デスクトップスタックは wlroots を 0.20.2 に、ネットワークツールは wget2 を 2.3.0 に更新し、Python 側では httpx2 と httpcore2 を一気に 2.13.0 へ、idna を 3.20 へ、langgraph-sdk を 0.4.11 へ更新し、さらに python-pymongo で BSON をメインパッケージに取り込んだ。他にもパッケージングの正確性修正が数件ある。llvm22、llvm23、llvm24 の3パッケージでは sed を使って clang の Python バインディングを libclang へのリンクに変更し、openruyi-linux-build は devel ファイルの競合を修正し、バージョン番号付きのドキュメントをインストールするようにした。

特筆すべきは llvm の3件だ。LLVM 各バージョンの Python バインディングは長らく動的ライブラリのパス推論に依存しており、ディストリビューションのパッケージング時に clang の Python モジュールを静的ライブラリや誤った soname に指し示すと、ユーザーが RISC-V 上で llvmlite や triton といった依存関係をインストールした際にインポート段階で失敗する。3バージョンを同期して明示的に libclang へリンクするよう変更したのは、「インストールはできるが使えない」という類の問題の根本原因修正であり、RISC-V AI スタックに取り組むチームにとってはバージョン番号そのものよりも意義が大きい。

CORE-V CVW が11件をマージ：16550 UART の LSR エラービット、SPI の空 RX ゼロ戻し、ロックステップの非整列アクセス免除（11-09／11-10）

CORE-V CVW は調査期間内に11件をマージした。主线は依然として「ペリフェラルと検証環境をしっかり作る」ことであり、マイクロアーキテクチャの変更ではない。16550 UART は LSR（ラインステータスレジスタ）のエラービット動作を補い、SPI は受信 FIFO が空のときにゼロを読み戻し、分岐予測リダイレクトのカバレッジ統計に除外項目を加え、ロックステップモードでは非整列アクセスに対する免除規則を与え、さらに一連のサンプルとスクリプトの整理——SHA の Questa スクリプトの削除、Docker ビルドと回帰スクリプトの削除、ruff と uv のスクリプトエントリの統一——を行った。

このコミット群は、先週の「局所分岐予測器2セットの削除、RV32GC CoreMark/MHz 4.33 の公開」と同じ収束の半分である。先週動いたのは性能と面積、今週動いたのは検証可能性だ。UART のエラービットと SPI の空読みセマンティクスはいずれも「プロトコルが規定しているが実装で漏れやすい」細部であり、漏れてもコアが動かなくなるわけではないが、ドライバがエラーパスでハングする。ロックステップ免除とカバレッジ除外は、検証レポートを納品証拠として使えるかどうかを直接左右する。CVW を車載グレードや産業向け評価に使うチームにとって、こうしたコミットは数百 MHz 多く動かすことよりも価値がある。

M9BがTang Nano 9K上にRISC-Vパソコンを構築、5本のDOS時代ゲームが36MHzソフトコアで動作（11-09）

開発者Mika Tammiのm9bプロジェクトがHacker Newsに登場した：約20ドルのSipeed Tang Nano 9K（Gowin GW1NR-9）上で、VexiiRiscvソフトコアを用いて完全な小型パソコンを構築——36MHz、キャッシュ付き、オンボード8MB PSRAMをメモリとして使用、720×480 HDMI映像、48kHzオーディオ、2つのUSBポートでキーボードとマウスを接続、SDカードにプログラムを保存。起動するとSDカード内のプログラムを一覧表示する画面に入り、5本のDOS時代ゲームが動作し、いずれも効果音と音楽付き：Doom（シェアウェア、timedemo約22 fps）、Descent（約10 fps）、Tyrian 2.1（フルスピード35 fps）、System Shock（約7 fps）、Ultima VII（2種類のエンジン、7～13 fps）。

この種のプロジェクトの価値は「ゲームが動く」ことではなく、「1台のパソコンに最低限何が必要か」という線を引くことにある。9Kのロジックリソースではアウトオブオーダーコアも、Linuxレベルのメモリ管理も収まらないため、取捨選択が非常に具体的になる：HDMIを得るにはキャッシュを削り、効果音を得るには音楽を事前レンダリングしてストリームとしてカードから読み込む必要がある。プロジェクトはSoC、ランタイム、5セットのゲーム移植、SDカードイメージを独立したリポジトリに分割し、すべてオープンソース化しており、各リポジトリには上流のどこを変更したかが明記されている——RISC-V教育ボードやFPGA入門に取り組むチームにとって、これは直接再利用可能なエンジニアリング階層のサンプルである。

M5StackはCore Matrixを発表した。ESP32-C61ベースのIoTコントローラ：SoCはESP32-C61HR8、シングルコア32ビットRISC-V最大160MHz、320KB SRAMと8MB PSRAM、16MB QSPI flash、2.4GHz Wi-Fi 6とBluetooth LE 5.0；前面は16×16白光LEDマトリクス（256個、TM1680ドライブ）、Bosch BMI270 6軸IMU、microSD、パッシブブザー、3つのユーザーボタンと電源ボタンを搭載し、拡張は30 pin M5-BusとGrove I2C、USBまたは3.7V外部バッテリー給電に対応、サイズ54×54×11.6mm、価格29.99ドル。ソフトウェア側はArduino IDEとUIFlow2に対応し、M5Unified、M5GFX、電源管理チップのドライバライブラリを提供する。

インフィニオン AURIX RC1 の RISC-V コアは MIPS IP 由来、GlobalFoundries が製造と指摘（11-09）

Design And Reuse は 11 月 9 日、jonpeddie.com の分析を転載し、インフィニオンの AURIX RC1 が MIPS のプロセッサ IP を採用し、GlobalFoundries が製造を担当していると指摘し、これは MIPS と GlobalFoundries にとって RISC-V における重要な設計上の勝利だと述べた。記事は同時に、RISC-V が最終的にインフィニオン自有の TriCore アーキテクチャを置き換えるのかという問題を提起している。先に 11 月 4 日にインフィニオンが RC1 を発表した際、公式の説明は「RISC-V ベースの車載グレード MCU プラットフォームとして初、TriCore シリーズは供給を継続」であり、IP の出所については触れていなかった。

この報道はサプライチェーン層の空白を補うものである。車載グレードチップの発表は通常、プラットフォームとエコシステムのみを語り、コアの出所には言及しない。国産車載グレード RISC-V に取り組むチームにとって、コアの出所は直接的に二つのことを決める——機能安全の証拠チェーンを誰が提供するのか（ISO 26262 ASIL D の IP レベルの証拠は完成車メーカーが自ら補えるものではない）、そして生産能力とプロセスがどのファウンドリに落ちるのかである。MIPS は GlobalFoundries に買収された後、路線を全面的に RISC-V へ転換しており、今回もし本当に RC1 のコアサプライヤーであれば、「RISC-V 車載グレードコア」市場にファウンドリの背景を持つプレイヤーが加わったことになる。国内 IP ベンダーにとっては、遠い概念ではなく、正面から比較すべき競合である。

平頭哥、2027 年に香港 IPO を計画、20 億〜30 億ドルの調達を目指す（11-09）

複数メディアが 11 月 9 日、ロイター通信の報道を引用し、アリババ傘下のチップ会社である平頭哥半導体が 2027 年に香港証券取引所への上場を計画しており、20 億〜30 億ドル（約 156 億〜234 億香港ドル）の調達を目標としていると伝えた。公開情報によると、平頭哥は 2018 年 10 月に中天微と達摩院のチップチームが統合されて設立され、製品は AI アクセラレータチップ（真武シリーズ）、Arm サーバー CPU（倚天シリーズ）、RISC-V プロセッサ IP（玄鉄シリーズ）、ストレージコントローラなどに及ぶ。2026 年 3 月、アリババ CEO の呉泳銘氏は決算電話会議で、平頭哥のチップ累計出荷が 47 万枚を超え、年換算売上高が百億元を超えたと明らかにし、8 月には真武シリーズが 650 社以上の顧客にサービスを提供し、外部有料顧客の割合が六割を超えたと明らかにした。9 月の雲栖大会で発表された真武 V900 は 216GB のビデオメモリ、1200GB/s のチップ間帯域を公称し、2027 年第 1 四半期の量産を計画している。

MIPS Actus が2基の Atlas M8500 リアルタイム RISC-V コアでロボット関節を実現、TSN とポスト量子セキュリティを搭載（11-09）

MIPS（格芯に買収済み）は11月9日、electronica 2026 に先立ち Actus リファレンスプラットフォームの進展を発表した。コンパクトなロボット関節向けチップで、決定論的モーター制御、ロボット体内ネットワーク、エッジ推論を同一ダイ上に配置し、格芯の FDX FD-SOI プロセスに基づく。中核は2基の MIPS Atlas M8500 リアルタイム RISC-V プロセッサで、ハードウェアマルチスレッディングにより割り込みサービス時のコンテキストスイッチングオーバーヘッドを排除する。専用三角関数アクセラレーションは磁界方向制御（FOC）アルゴリズムにおいて標準三角関数ライブラリの16倍以上高速。100ピコ秒級の高分解能 PWM と sigma-delta ADC を備え大電流モーターを駆動し、さらに ARC VPX 512ビットベクトルユニットで同一チップ上にセンサーフュージョンと予知保全モデルを実行する。

システム側も十分に備わっている。3ポートの時間敏感ネットワーキング（TSN）ギガビットイーサネットに CAN-FD とシリアルポートを加え、各関節コントローラと中央コントローラが位置とトルクのデータを交換できる。オンチップのハードウェアセキュリティモジュールはポスト量子暗号をサポートし、機能安全にも対応する。Actus は Acies（推論ネイティブプラットフォーム）、Aegis（セキュリティネイティブ CPU プラットフォーム）とともに MIPS のフィジカル AI 製品ラインを構成する。

この項目の重みは「関節」という位置にある。ヒューマノイドロボットの演算力の語りは長らく頭脳（どの社の NPU、どれだけの TOPS）に集中してきたが、量産を真に阻むのは肘から指先までの区間である。空間、消費電力、放熱はいずれも極めて厳しく、しかも滑らかなヒューマノイド運動と決定論的タイミングが要求される。デュアルリアルタイムコア、モーター制御ペリフェラル、TSN、セキュリティモジュールを1つの関節チップに詰め込むことは、「頭脳が指令を出し、関節が自ら閉ループを形成する」という分散アーキテクチャを調達可能なデバイスにすることに等しい。国内でロボット関節とリアルタイム制御に取り組むチームにとって、これは「MCU プラス外付けドライバ」路線と正面から比較される一つの方案であり、重要な差異はハードリアルタイムとネットワーク決定性にあり、演算力にはない。

5. 総括とトレンド観察

1. AI チップの「汎用コア」という層に専用製品が登場し始めた。 芯来 NI1000 は VME を用いて行列演算能力を RVV に接ぎ木し、面積増加はわずか 15%、行列乗算は 2.5 倍高速で、その位置づけは NPU を置き換えるのではなく分業するものだ。これは過去 2 年間の「どの NPU のピーク性能が高いか」という物語とは異なる。AI SoC における汎用コアは長らくアプリケーションコアの外販や自社開発の大型コアで解決されてきたが、今や第三の道が現れた——ベクトルを基盤とし、必要に応じて行列を追加する。真のハードルは IP ではなく、オペレータライブラリとコンパイラが VME を活用できるかどうかにある。

2. ロボット関節が RISC-V リアルタイムコアの新たな戦場となり、その路線が分岐し始めた。 MIPS Actus は 2 基の Atlas M8500 に TSN とポスト量子セキュリティを組み合わせて関節レベルのシングルチップを実現し、国内の spacemit-robotics は引き続き K3 上で四足歩行の移植と制御リンクの適応を進めている。前者が売るのはデバイスとリアルタイム性の保証であり、後者が積み上げるのは再現可能なエンジニアリングとエコシステムである。両方の道が示すのは一つのことだ——エンボディドインテリジェンスの計算競争は「大脳」から「小脳と関節」へと下沉しつつあり、この層の評価基準は確定性と消費電力であり、TOPS ではない。

3. 国内側の資本市場の動きが技術の物語に影響を与え始めた。 平頭哥は 2027 年に香港上場を予定し、20 億から 30 億米ドルを調達する計画で、実現すれば RISC-V と国産 AI チップ企業にとって初めて「商業化済み、外部顧客あり、売上あり」の比較可能な対象が生まれる。ただし冷静さも一分必要だ。報道は玄鉄 IP を平頭哥の製品ラインに算入しているが、玄鉄チームは 2024 年に達摩院へ移管済みであり、上場主体の資産境界はまだ開示されていない。産業観察者にとって次に見るべきは評価額ではなく、招股資料における外部顧客収入と関連取引の切り分け方である。

4. ソフトウェア側の進展は「インストールでき、使える」といった細部に集中している。 openRuyi の 1 日 20 件のコミットのうち、llvm22 から 24 の Python バインディングを明示的な libclang リンクに変更したものが最も代表的な一件だ——何らかの指標を向上させるものではないが、RISC-V 上で llvmlite と triton を正常にインストールできるかどうかを左右する。CORE-V CVW が今週マージした UART LSR エラービット、SPI 空読みゼロ帰、ロックステップ免除も同様に「ベンチマークには影響しないが納品できるかどうかに影響する」カテゴリに属する。算能が bootloader の 2 世代プラットフォーム構築チェーンを収束させたこと、進畳がデジタルヒューマンパイプラインを Bianbu ブランドに収めたことも、いずれもデモからメンテナンスへ向かう動きである。

5. 静かなニュース面と静かでないリポジトリ面。 本期の Google News 側の有効な新規は芯来 NI1000、MIPS Actus、M5Stack Core Matrix、英飛凌 AURIX の IP 出所の 4 件のみで、他に為旌 VS815V、AMD RISC-V TEE、Openchip BER10 の 3 件は旧聞の二次伝播であり、既に過去のレポートで収録済みのため本期は重複しない。これは先週のリズムと一致する。大手の発表は疎らだが、GitHub 側のコミット密度は上昇している——進畳、算能、芯来、openRuyi、CORE-V が同じ 24 時間で合計 60 件余りの照合可能なコミットを行った。

限界に関する説明：本機の匿名による GitHub API アクセスは収集時間帯に毎時 60 回のレート制限に達したため、組織とリポジトリのアクティビティは GitHub 組織ページの埋め込みデータと各リポジトリの Atom コミットフィードから取得し、API クォータを消費していない。したがって「期間内にプッシュあり」の判定はデフォルトブランチのコミット日時を基準とし、非デフォルトブランチへのプッシュ（例えば進畳の wip ブランチ）は過小評価されている可能性がある。達摩院玄鉄と奕斯偉の「ゼロプッシュ」という結論も同じ方法論の制約を受け、デフォルトブランチに期間内コミットがなかったことのみを意味する。Google News の中国語クエリには依然としてギャンブルや株式記事のノイズがあり、タイトルの意味に基づいて排除した。RISC-V 会員公式サイトの巡回で見つかった 108 件の「変化」はすべてトップページのマーケティングローテーションまたはセキュリティブロックページであり、実質的な製品・アーキテクチャの発表は発見されなかった。
