今日の重点：奕斯偉計算が香港株式市場での公募を正式に開始、10 月 9 日上場予定

日付：2026-09-28　出典：RTHK「奕斯偉計算上市集資最多約25億元　或成「RISC-V」第一股」（09-28）、経済参考網「奕斯伟计算启动港股招股」（09-28）、香港商報「RSIC-V晶片商奕斯偉計算(01256)今日招股　計劃全球發售約15.7億股」（09-28）

9 月 28 日、北京奕斯偉計算（01256.HK）は香港株式市場でのグローバル公募を正式に開始した。約 15.7 億株の H 株を募集予定（うち約 10% が香港公募分）、発行価格帯は 1 株あたり 1.48〜1.59 香港ドル、1 ロット 2000 株、参加費は約 3212 香港ドル、上限価格ベースでの調達総額は最大約 24.97 億香港ドル（約 25 億香港ドル、約 3.2 億米ドル）。公募は 10 月 6 日に申込締切、10 月 9 日に香港証券取引所メインボードに上場予定で、共同スポンサーは中信証券と中信建投国際。

同社は中信資管香港、日本 Orix、合肥建投、GBAHIL（大湾区共同家園投資）などの基幹投資家を導入し、合計約 11.61 億香港ドルを引き受ける。調達資金は主に人機交互およびマルチメディア処理チップ、インターコネクトおよびコンピューティングチップの製品開発とソフトウェア・ハードウェア技術プラットフォーム構築、潜在的な戦略的 M&A などに充てられる。目論見書のデータによると、2026 年 3 月末時点で同社は 150 以上のソフトウェア・ハードウェア協調製品を投入し、世界 220 社以上の顧客にサービスを提供、620 以上の IP モジュールと 20 以上のシリーズ化された RISC-V コアを蓄積している。発行が順調に進めば、香港市場初の RISC-V を主力事業とするチップ上場企業となる（香港は既に 2026-27 年度財政予算案で RISC-V を重点発展する 7 大新興産業の一つに位置づけている）。本誌は価格決定と上場の節目を引き続き追跡する。

2. 製品とエコシステムの動向

2.1 Efinix が Sapphire RV64 をリリース：64 ビット RISC-V FPGA ソフトコア SoC

日付：2026-09-28　出典：Business Wire「Efinix Brings 64-Bit RISC-V Performance to Embedded FPGA Designs With New Sapphire RV64 SoC」（09-28）、Efinix Sapphire RV64 ユーザーガイド（公式ドキュメント）

FPGA ベンダー Efinix が Sapphire RV64 SoC をリリース：Sapphire ソフトコアシリーズを 32 ビットから 64 ビット RISC-V に拡張——7 段パイプライン、オプションの A／F／D／C および Zba／Zbb／Zbs／Zicbom 拡張をサポート；オンチップ 4 ～ 512KB RAM、マルチウェイ L1 命令／データキャッシュ、オプションの L2 キャッシュ（64 ～ 512KB、8 ウェイ）、分岐予測器とハードウェア／ソフトウェアプリフェッチ；DDR／LPDDR4 メモリコントローラと組み合わせ、1 ～ 4 個の 64 ビットコアを構成可能、主周波数 20 ～ 400MHz。製品は「アプリケーションが 32 ビットコアのアドレッシング、キャッシュ、I/O の上限を超えた」エッジ AI および組み込み Linux シーンを対象とし、同社の全 Titanium／Topaz FPGA と Trion（T20 以上）デバイスに使用可能で、Efinity IP Manager によるグラフィカル設定に対応。公式ドキュメントによると、このコアはオープンソースの VexiiRiscv に類似し、自社デバイス向けに最適化されている。

2.2 Xcena MX1 が EE Times で詳細解説：CXL メモリに 1000 以上の RISC-V コアを統合

日付：2026-09-28　情報源：EE Times「Xcena Cuts Data Movement to Address Memory Bottlenecks」（09-28）、IndexBox「Xcena MX1: CXL Near-Memory Processing with 2TB DDR5 and 1,000+ RISC-V Cores」（09-28）

EE Times と IndexBox は 09-28 に記事を掲載し、韓国の半導体企業 Xcena の MX1 コンピューティング型 CXL メモリデバイス（今夏の Hot Chips 2026 で発表）を詳細に解説した：単卡で最大 2TB DDR5（4 チャネル、CXL 3.2 ／ PCIe 6.0）を統合、SSD は InfiniteMemory を介してバイトアドレッシング可能なメモリとして公開され、1000 以上の中自研 1.4GHz RISC-V コアからなる近存コンピューティングユニット（技術メディアの報道では 3072 個、24 サブシステムが 128MB L3 を共有）と約 3 TFLOPS FP32/FP16 ベクトルエンジンを統合；公式の説明ではデータ分析負荷において CXL 経由でアクセスするホスト CPU と比較して最大 4.7 倍のスループット、18.7 倍のエネルギー効率を実現。開発者は LLVM ツールチェーンを通じて C／C++／Rust でプログラミング可能で、2026 年末の量産、2027 年からの収益計上を計画。RISC-V コアの「メモリウォール」シーンにおけるスケール展開が、これら一連の報道の注目点となっている。

3. 国内チームの深耕

3.1 RevyOS：5 つのカーネルブランチを一括更新、ESWIN EIC7700 サポートを追加

日付：2026-09-29 未明　情報源：revyos/linux コミット：ARCH_ESWIN/DWMAC_EIC7700/PINCTRL_EIC7700 を有効化（09-29 未明）、revyos/linux コミット：K1/K3 プラットフォーム設定（09-29 未明）、revyos/linux コミット：drm powervr を有効化（09-29 未明）

RevyOS カーネルリポジトリ（revyos/linux）は調査期間の末尾に、5つのブランチ（revyos/6.18.y と 7.0.y から 7.3.y）に対して各約 20 件の設定更新を一括プッシュした。核心はESWIN（奕斯偉）EIC7700 プラットフォームサポートの新規追加（ARCH_ESWIN、DWMAC_EIC7700 イーサネット、PINCTRL_EIC7700）であり、あわせて進迭時空 K1／K3 シリーズの設定（K3 ディスプレイコントローラ、K3 UFS、Banana F3 の K1 USB2 など）を補完した。同時に PowerVR GPU DRM と TH1520 GPU 電源シーケンス、RESET/PHY 関連ドライバと linuxboot 設定を有効化し、CI 側ではクロス／ネイティブビルドを追加した。これはカーネルバージョンをまたぐ設定ベースラインの同期であり、6.18 と 7.x の二系統カーネルに新ハードウェアサポートを補完するものである。

日付：2026-09-28　情報源：model-zoo-vision コミット：RTMPose 姿勢推定を追加（#96）（09-28）、spacemit-com/ai-sdk リポジトリ（vision サブモジュール同期）

進迭時空 model-zoo-vision は RTMPose 人体姿勢推定モデルを追加した（#96）——このリポジトリが最近進めている SuperPoint、セグメンテーション、OCR、顔／CLIP などのモデルに対する K1/K3 プラットフォーム上の RVV 前処理・後処理アクセラレーションの流れを継続するものであり、ai-sdk も vision サブモジュールを同期更新した。ロボット側の動向は第4章を参照。

楽鑫側は調査期間内にメンテナンス的なマージが中心であった。esp-idf の release/v5.4 メンテナンスブランチは NimBLE の「ACL 接続確立後の Read Remote 失敗」の処理と未サポート機能のチェック強化をマージした。esp-hosted-linux は 09-25 に続き 3 件を追加——ホスト側ファームウェアバージョンヘッダを 1.0.6.0.8 に同期、OTA コマンドを 30 秒タイムアウトに変更、SPI 上の TX-aggr アライメントチェックをスキップ。関連する投入は ESP32-C／S シリーズ RISC-V 製品ラインを含む全系チップをカバーする。

3.4 矽速：SLogic ロジックアナライザ ngscope ネイティブドライバのフェーズ1が完了

日付：2026-09-28　情報源：SLogic コミット：ngscope ネイティブ SLogic ドライバ フェーズ1（09-28）、SLogic コミット：グループ単位のアナログ／デジタルチャネル切替（09-28）、slogic16u3-tools コミット：SLogic32U3 に独立した DFU PID を割り当て（09-28）

Sipeed の SLogic ロジックアナライザ ソフトウェアスタックは対象期間内に 7 件のコミットを推進：ngscope クライアントが「ネイティブ SLogic ドライバ（フェーズ 1）」を実装し、sigrok-bridge への依存を排除、実行時のキャプチャ幅選択、グループ単位のアナログ／デジタルチャネル切替と自動並べ替え表示をサポート、ビルド成果物は scopehal-apps による統一命名に変更；ツール側では SLogic32U3 に独立した DFU PID（0x30F2、16U3 の 0x30F1 とは別）を割り当て、eFuse 書き込みフローを簡素化した。RISC-V エコシステムのオープンソーステスト・計測ツールチェーンは引き続き整備が進んでいる。

3.5 算能：CV84x6 ソフトウェア適配を継続推進

日付：2026-09-28　情報源：sophon-demo コミット：SE13-64（CV84X6）メイン CPU 仕様を修正（09-28）、sophgo/build リポジトリ（edge_dev ブランチ継続プッシュ）、sophgo/osdrv リポジトリ（edge_dev ブランチ継続プッシュ）

前号で CV84x6（84x6）プラットフォームが 16 リポジトリに大規模展開したのに続き、算能は対象期間内にさらに 3 リポジトリをプッシュ：build と osdrv の edge_dev ブランチが更新を継続（09-28）、sophon-demo のドキュメントは SE13-64（CV84X6 プラットフォーム）のメイン CPU 仕様を 8 コア Cortex-A55@2.0GHz に修正した。新プラットフォームのソフトウェアスタックは依然としてイテレーション期にあり、ハードウェア仕様の細部が徐々に校正されている。

4. 具身知能とロボティクス専章

4.1 進畳時空ロボティクス：ros2_humanoid に Qwen3-ASR 音声動作制御を追加

日付：2026-09-28　情報源：ros2_humanoid コミット：Qwen3-ASR 音声動作制御バックエンドを追加（09-28）

進畳時空ロボティクスのリポジトリ ros2_humanoid に Qwen3-ASR バックエンドが追加され、音声認識によってヒューマノイドロボットの動作制御を駆動——09-23 号で収録した RGB-D SLAM と Nav2 サポート、さらに以前の ZMQ ポリシー切替と音声立位制御のラインにつながり、そのヒューマノイドロボットソフトウェアスタックは「音声／マルチモーダルインタラクション＋ROS2 ナビゲーション」の重ね合わせで推進されている。

その他のロボティクス側：対象期間内に国内関連チームのその他の実質的動向はなし（会員企業公式サイトの巡回ではロボティクス方向の更新は見られなかった）。

5. まとめとトレンド観察

  • 資本化が発行・上場段階へ：奕斯偉計算が 09-28 に正式に招股を開始（価格 1.48〜1.59 香港ドル、最大調達額約 25 億香港ドル、10 月 9 日上場予定）。香港市場「RISC-V 第一株」の価格設定と申込熱は、この分野のバリュエーションに公開の参照点を形成するだろう。
  • ディストリビューション側も新ハードウェアサポートを同時にカーネルへ投入：RevyOS は一晩で 6.18 と 7.x の 5 本のカーネルブランチで設定を一括更新——ESWIN EIC7700、K1/K3 の表示とストレージ、PowerVR GPU——「ボードと SoC の準備が整えばディストリビューションが迅速に追随する」リズムが加速している；openRuyi も SPECS 層で活発さを維持。
  • 香山系 IOMMU とプリフェッチの二本柱で推進：メインリポジトリが bosc IOMMU と DMAC／IOPMP のシミュレーション統合をマージ、GEM5 側では BDP ストリーム深度制御がパラメータ化の最終段階へ——昆明湖 v3 のシステム統合と性能実験はなお二つのラインで深化中。
  • RISC-V が「非 MCU 型計算力ポジション」へ拡張：Efinix は FPGA ソフトコアを 64 ビットへ推進、Xcena は千を超える RISC-V コアで CXL 近存計算を実現——同日に現れたハードとソフトの二つの製品動向は同じトレンドを指し示す：RISC-V コアは制御系シーンからデータプレーンとメモリ側の計算力へと向かっている。
  • 検証、翻訳、ツールチェーンが継続的に厚みを増す：rv32emu システムシミュレーション JIT バッチ、felix86 互換層の研磨、Sipeed ロジックアナライザと openRuyi パッケージング層——インフラ系プロジェクトは高頻度の小さな歩みを維持。
  • 要観察：達摩院玄鉄、奕斯偉計算（GitHub）、芯来などは対象期間内に静か；次号では奕斯偉の価格設定と申込進捗、香山 IOMMU／プリフェッチのマージ動向、openRuyi 2026.09 バージョンのリリース有無に注目。
