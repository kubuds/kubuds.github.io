日付：2026-08-17 18:00 ~ 2026-08-18 07:45（北京時間）　出典：riscv/riscv-high-assurance-cryptography GitHub

高保証暗号（HAC）仕様リポジトリは調査期間内にさらに15件以上のコミットをマージし、前々日・前日からの ML-KEM/ML-DSA ポスト量子主線の追い込みを継続した：Resolved ace.size returning a PI's size in a suitable status（ace.size がどの CR 状態で PI サイズを返すかを明確化）、Clarify padding and key derivation behavior（パディングと鍵導出の挙動を明確化）、Marked issue of ace.load/ace.store in wrong extension as a non-issue（拡張をまたいだ ace.load/store の使用問題を非問題と位置づけ）、ace-ISA-algorithms.adoc の3件連続更新、ace-introduction/acronyms の改訂、docs-resources 依存関係のアップグレード（#146）など。3日連続の集中的改訂（前々日・前日は約12件/日）は、FIPS 140-3 級の高保証暗号実装に向けたこの拡張仕様が依然としてレビュー収束期にあることを示しており、今週のセキュリティ/暗号主線（Spectre 論文、SPMP メンテナンス）と同じ方向性にある：RISC-V 公式はセキュリティと暗号基盤を体系的に補強しつつある。

1.3 riscv-unified-db が3件の命令セマンティクス修正をマージ：zalrsc 符号拡張、sstateen 固定長、c.sdsp インデックス

日付：2026-08-18 05:22 ~ 05:36（北京時間）　出典：riscv/riscv-unified-db GitHub

RISC-V 公式統合命令データベース（unified-db、UDB プロジェクト）の調査期間内に三件の命令セマンティクスレベルの修正がマージされた：

  • fix(zalrsc): sign-extend the lr.w result on RV64 (#2460)——Zalrsc 拡張の lr.w は RV64 上で結果を符号拡張する必要がある；
  • fix(csr): sstateen0-3 take the stateen family's fixed length of 64 (#2395)——sstateen0-3 CSR は固定 64 ビット長とする；
  • fix(isa): c.sdsp must use its full 5-bit register index (#2419)——圧縮命令 c.sdsp は完全な 5 ビットレジスタインデックスを使用しなければならない。

UDB は RISC-V 公式 spec／ソフトウェアツールチェーンの機械可読な命令セマンティクスの単一情報源であり（riscv-arch-test、Sail などが同ライブラリを消費する）、この種の低レベルセマンティクス修正はテストとシミュレーションツールの正確性に直接影響し、「規範インフラ」級のメンテナンスに属する。

4. 重点方向専門章：身体性知能とロボティクス

4.1 進畳 K3 humanoid RL ランタイム（model_zoo_rl）のブランチレベル保守

本調査期間、身体性知能方向に重大な新リリースはなく、最も注目すべきは依然として進畳時空の K3 ヒューマノイドロボット強化学習スタックである：model_zoo_rl は調査期間内に fix/eigen-cmake-target ブランチ（ビルド統合修正）をプッシュし、デフォルトブランチは 07-23 に宣言的モデル I/O と型付きテンソルサポートをマージ済み——RL 推論スタック（以前に報道した SPERT NPU 全体グラフ推論、robot-test CI、per-policy kp/kd 設定を含む）は依然として継続的に進化しているが、ペースは「新機能段階」ではなく「保守段階」である。

4.2 端側ビジョンハードウェアの可用性：ESP32-P4X-EYE が販売開始

身体性知能の「知覚層」の視点から見ると、楽鑫 ESP32-P4X-EYE ビジョン開発キット（デュアルコア RISC-V 400MHz + AI 命令拡張 + カメラ/ディスプレイインターフェース）が販売開始され、端側ビジョン知覚（SLAM 前処理、物体検出フロントエンド、HMI インタラクション）に新たな低コスト RISC-V ハードウェア選択肢を提供した。進畳 SPERT（端側 NPU 推論）、算能ビジョンサンプルライブラリ（YOLO シリーズ）とともに、国産 RISC-V「知覚—意思決定—運動制御」三層の国産化経路における知覚層の持続的な補強を構成している。

4.3 直近三日間のトレンド回顧

08-15 ～ 08-17 を振り返ると：滴水湖フォーラムは「リアルタイムコア＋アプリケーションコア」のデュアルコア異種運動制御路線を確立（峰岹 FU75XX、先楫 HPM53M1、進畳 K3 の運動制御ポジショニング）；アーキテクチャ大討論（Grinberg の長文 vs グローバルサウスのエンジニアの応答）は「安価な組み込み RISC-V は必ず獲得する」という点で稀に見る一致を見せた；今週の身体性知能方向は全体としてリリースの端境期にあり、主線は依然として「コスト敏感＋リアルタイム性優先」の運動制御国産化と端側知覚スタックの研鑽である。
