1. オープンソースコミュニティとソフトウェアエコシステムの動向

1.1 RISC-V アーキテクチャ大論争がヒートアップ：Grinberg の批判長文が多方面からの反応を引き起こす（今日のトップニュース）

日付：2026-08-14 原文初公開（HN 376 ポイント）、本調査期間内の 08-16 に二本の重要反論文書　出典：Grinberg 原文（dmitry.gr） / rvembedded 反論文 / The Chip Letter 概説

独立系組み込み開発者 Dmitry Grinberg の長文『RISC-V: They Should Have Known Better』は 08-14 に HN のトップページに登場し（376 ポイント、250+ コメント）、最近で最も体系的な RISC-V アーキテクチャへの批判となった。その核心的な主張は以下の通り：1. 単一の ISA では安価な MCU とハイパフォーマンスコンピューティングの両端を同時にカバーすることはできない、「ハイエンド CPU の要求と低コスト MCU の要求は本質的に対立する」；2. 圧縮命令エンコーディングは「荒唐無稽」（例えば S 型ストア命令の 16 ビットエンコーディングのオフセットはわずか 0-3）、即値が命令内で散在している（MIPS/ARM と比較）、Zicsr などの拡張は本来内蔵されるべき；3. 結論は「RISC-V が最終的に安価な使い捨て MCU 市場を制することを 100% 確信している——しかしそれは ISA の設計が優れているからではなく、設計が平凡であるにもかかわらずだ」、無料と低価格によってである；ハイエンドデスクトップ/スマートフォン市場については「楽観視していない」。

本調査期間内の新たな進展は二本の高反響な反論文（08-16）である：

  • rvembedded.com『A Third World Embedded Engineer Responds』（HN 353 ポイント、170+ コメント）：トリニダード・トバゴの組み込みエンジニア（STM32/ARM スタック全体を既に RISC-V に移行済み、代表作は CH32V003 教材）が「グローバルサウス」の視点から反論——発展途上国のエンジニアと学生にとって、10 セントと 1 ドルのチップ価格差、送料と税関の壁は ISA の優雅さよりもはるかに重要である；彼の机の上にはちょうど三つの証拠が置かれている：10 セントの RV32EC の CH32V003（まさに Grinberg が自ら導き出したタイプのコア）と 400 MHz デュアルコア CH32H417 が同じ ISA ファミリーに属し、「単一 ISA では両端をカバーできない」という主張に直接反論する；同時に Grinberg の批判の一部が妥当であることも誠実に認めている（圧縮ストアのオフセット、Zicsr の独立拡張化）。
  • The Chip Letter『RISC-V: What Really Matters』（08-16）：総合評述として RISC-V は「無料、メインストリームツールチェーンのサポート、拡張可能」であるがゆえに成功する運命にあると考える——Raspberry Pi Pico 2 の Hazard3 オープンソースコア設計者 Luke Wren を引用：「私の ISA に対する二つの要求を満たしている：メインストリームの LLVM/GCC サポート、弁護士が不要」；Meta MTIA アクセラレータチームメンバー：「我々は AI アクセラレータで RISC-V を大いに活用し成功している」；しかしハイパフォーマンスデスクトップ/スマートフォン市場での地位は依然として疑問視され、ベンダーは ARM ライセンス路線をより好む可能性がある。

意義：これは今週の Spectre-on-RISC-V 論文に続く第二のエコシステム級の話題であり、RISC-V の世論が「技術の新星」という物語から「真剣に検証され反省される」段階に入ったことを示す；論争の双方はむしろ一点で高度に一致している——安価な組み込み/端末側市場では RISC-V は必ず取る（アーキテクチャの完璧さではなく、価格と開放性によって）。

1.2 RISC-V 公式高保証暗号（HAC）仕様が二日連続で集中的に改訂（約 12 件のコミット）

日付：2026-08-16（00:48~23:37 UTC）　出典：riscv/riscv-high-assurance-cryptography GitHub

HAC 仕様リポジトリの調査期間内にさらに約 12 件のコミットがマージされ、昨日の ML-KEM/ML-DSA ポスト量子の主線を継続した：Allow ace.restrict instructions in any state（ace.restrictl/h/v を任意の CR 状態で実行可能とし、従来の例外パスを置き換え）、SCProtection 階層と ace.restrictv 予約値範囲（3-5、6-7）の明確化、CSK 用語の統一（遺留の RCSK 参照を整理）、例外動作とゼロ化（zeroization）ルールの明確化、ace.setst 使用制御の修正、ace-examples.adoc の削除とレビュー意見（review1.md）の継続処理。2 日連続の集中的な改訂は、FIPS 140-3 級の高保証暗号実装を志向するこの拡張仕様がレビュー収束のスプリント期に入ったことを示しており、今週のセキュリティ信頼テーマ（Spectre 論文、暗号拡張）と同じ主線を構成する：RISC-V はセキュリティと暗号基盤を体系的に補強しつつある。

4. 重点方向専章：具身知能とロボティクス

4.1 本調査期間の具身知能方向は平静：運動制御の主線は依然として「デュアルコア異種 + コスト敏感」

本調査期間内に具身知能/ロボティクス方向の新規リリースはなく、直近3日間の傾向を振り返ると（08-15 滴水湖フォーラムと電子工程専輯の特集）：国産 RISC-V 運動制御ソリューションは「シングルコアリアルタイム」から「リアルタイムコア+アプリケーションコア」のデュアルコア異種構成へ移行しつつある（峰岹 FU75XX、格見 500 ナノ秒電流ループ、先楫 HPM53M1、進迭 K3 運動制御ポジショニング）。端側知覚—意思決定—運動制御の三層国産化パスが形成されつつある（進迭 SPERT NPU 推論、算能ビジュアルサンプルライブラリの修正）。

4.2 アーキテクチャ論争と具身知能の交点：論争双方とも「安価な組み込み RISC-V は必ず取る」ことを認める

今日頭条のアーキテクチャ大討論（1.1）と具身知能方向は興味深い呼応を形成している：Grinberg が長文を批判した結論まさに「RISC-V は 100% 安価な使い捨て MCU 市場を獲得する、それは価格と開放性によるものでアーキテクチャの完璧さによるものではない」——そして具身ロボットの運動制御基盤（関節モータ制御、センサーフュージョン）はまさに典型的なコスト敏感、リアルタイム性優先のシナリオである。論争双方（批判者と擁護者）はこの点でまれに一致しており、側面から裏付けられる：ロボット運動制御という国産 RISC-V の核心的增量市場において、RISC-V の生態的地位はアーキテクチャ論争によって揺らぐことはない。運動制御チップの国産代替パスは「グローバルサウス」の組み込みエンジニアの生態ナラティブ（10 セント部品が教育と実践の境界を変える）と同構である：開放 + 低価格が RISC-V が組み込み/端側で勝利する根本ロジックである。
