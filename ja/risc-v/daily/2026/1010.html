今日の重点：奕斯偉計算が上場初日に公開価格割れ、終値は0.97%安、総時価総額は約338億香港ドル

日付：2026-10-09　出典：新浪財経（澎湃新聞）：奕斯偉計算の上場初日は0.97%の微安（10-09）、21経済網：「RISC-V 第一股」の初登場、公開価格割れ後に回復（10-09）、TechNode：RISC-V chipmaker ESWIN Computing lists in Hong Kong（10-09）

「RISC-V 第一股」の奕斯偉計算（01256.HK）は10-09に香港証券取引所メインボードに上場し、初日の値動きは乱高下となった：寄付値は1.54香港ドルで公開価格割れ（公開価格は1.55香港ドル）、取引時間中に一時回復し（昼間の最高値は約3%高）、安値は1.365香港ドル、終値は1.535香港ドルで0.97%安、総時価総額は約338.3億香港ドル。今回のグローバル募集は約16.17億株の H 株で、調達総額は25億香港ドル、純額は約23.86億香港ドル；調達資金の約35%はチップ製品の開発・イテレーションに、30%は RISAA（RISC-V と AI）ソフトウェア・ハードウェアプラットフォームに充てられる。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 Canonical：Ubuntu 26.10 が公式 RISC-V デスクトップイメージを初リリース

日付：2026-10-09　出典：9to5Linux：Canonical Announces Official Ubuntu Desktop Images for RISC-V（10-09）、Phoronix：Ubuntu 26.10 To Include Desktop Images For RISC-V（10-09）

Canonical は Ubuntu Desktop が正式に RISC-V イメージを提供すると発表した。10 月 15 日リリースの Ubuntu 26.10（Stonking Stingray）と同時に導入される。さらに実験的な Xubuntu Minimal イメージもある（現時点では公式サポート外、仮想マシンでの試用を推奨）。公式は SpacemiT K3（Pico-ITX）でのテストを推奨しており、26.10 からこのプラットフォームに公式サポートを提供する。完全なデスクトップ体験は RVA23 級ハードウェア向けで、Milk-V Jupiter 2、DeepComputing DC-ROMA、SiFive HiFive Unmatched を含む。実機起動には、一次ブートローダ（例：U-Boot）とデバイスツリーを自身で配置する必要がある。

1.2 LLVM／RISC-V：分岐なしコードが RV32 で依然として分岐にコンパイルされ、Zicond が解決策に

日付：2026-10-09　出典：Frank Denis：Branches in branch-free code（10-09）、Hacker News ディスカッション

実測により判明：clang 23 は RISC-V 上で意図的に分岐なしで書かれた定数時間コード（128 ビット加算のキャリー伝播、マスク選択など）を条件分岐（beq／beqz）にコンパイルする。RV32 と RV64 のいずれにも存在し、潜在的なサイドチャネルを構成する。Zig、Rust も同様に影響を受ける。Zicond 拡張（RVA23 構成の一部で、czero.eqz／nez を提供）を有効にすると、すべてのケースで分岐なしに戻るが、タイミング特性は依然として Zkt 拡張の併用があって初めて保証される。GCC 16.1 は一部の書き方では分岐なしだが、比較マスクの書き方では依然として分岐を導入する。結論：コンパイラのバージョンやパラメータが変更された後は、定数時間コードのマシンコードを再監査する必要がある。

1.3 riscv-unified-db：RVA23.1／RVB23.1 プロファイルを新規追加

日付：2026-10-09　出典：riscv-unified-db コミット記録（10-09）

仕様の機械可読データベース riscv-unified-db は調査期間内に 7 件のコミット：RVA23.1 と RVB23.1 プロファイルを新規追加（#2721）、Zabha 拡張に 8／16 ビットアトミック RMW パスを補充（#2566）、Sspmp／Sspmpen／Smpmpdeleg 拡張定義を新規追加（#1817）、Smcdeleg と Ssccfg の依存関係を補完（#2718）、さらに fcvt 浮動小数点変換メタデータを修正し、VSEI／VSSI 割り込みパラメータを整理。仕様データベースは最新の ratified 構成を継続的に追跡している。

1.4 openRuyi：Go エコシステムのソフトウェアパッケージをさらに 13 項登録

日付：2026-10-09　出典：openRuyi コミット記録：SPECS 第二批（10-09）、lookout コミット記録（10-09）

初回の 20 余項に続き、openRuyi メインリポジトリは調査期間内にさらに 13 件の SPECS コミットをマージ：franz-go、OpenTelemetry profiling、Jaeger IDL、Datadog シリーズ、ghinstallation、阿里雲 OpenAPI、chroma など Go エコシステムコンポーネントのパッケージ定義を新規追加し、buf-protovalidate と cloudfoundry-clock も補入。同一組織のバージョン巡回ツール lookout は同日 20 余件をマージ（リリースバージョンのドロップダウン選択、依存関係の一括アップグレードと CI キャッシュ最適化）。公式サイトのニュースページを確認したところ、2026.09 バージョン以降に新たなリリース告知はない。

1.5 香山：FMA 提前唤醒、MMU ptehelper 支持など 6 件をマージ

日付：2026-10-09　ソース：XiangShan コミット記録（kunminghu-v3 ブランチ、10-09）、PR #6679、PR #6687

香山メインリポジトリの調査期間内に 6 件のマージ：#6679 は FMA に対して FMA と load からの早期ウェイクアップ（src2 パス）を追加、#6687 は aes64ks1i が rnum>10 の際に不正命令例外をトリガーしない問題を修正、#6580 は割り込み関連のコメントを修正、#6636 は workload_list のパフォーマンスレポートを有効化、他に MMU コミット 2 件（ptehelper サポートの新規追加とスペル修正）。フロントエンドデコード、浮動小数点発行、MMU パスが同時に収束。

1.6 香山シミュレーションチェーン：difftest が 2 スロット ROB アーキテクチャイベントをサポート、GEM5 が V3 RTL に整合

日付：2026-10-09　ソース：difftest PR #979：2 スロット ROB 項アーキテクチャイベント（10-09）、difftest PR #954：UVHS GBus ホストインターフェイス、GEM5 コミット記録（10-09）、NEMU コミット記録（10-09）

シミュレーションチェーンが多方面で前進：difftest は #979（crob が 2 スロット ROB 項の archEvent と storeEvent をサポート）と #954（FPGA 検証方向に UVHS GBus ホストインターフェイスを新規追加）をマージ；GEM5 は UARTLite の迅速ビルドを修正し Clang カバレッジを追加（#1209）、SBuffer store miss 処理を昆明湖 V3 RTL に整合；NEMU の ZSTD チェックポイント形式エラー処理がメインブランチにマージ。

2. 製品とエコシステムの動向

2.1 算能：sophon-demo に YOLO26 深度推定と姿勢推定のサンプルを新規追加

日付：2026-10-09　ソース：sophon-demo コミット記録（10-09）、sophon-tools コミット記録（10-09）

算能 sophon-demo に YOLO26 単眼深度推定と姿勢推定の 2 サンプル（YOLO26_depth／YOLO26_pose）を新規追加し、新世代検出モデルの算能 TPU プラットフォームにおけるサンプルマトリクスを補完；sophon-tools は EC20 モジュールの自己復旧 timer を udev がモジュールを検出した際にトリガーするよう変更（周期を 60s から 90s に調整）、さらに psewriter の 32 ビットプラットフォームにおけるテストコンパイルを修正。sophgo 組織の調査期間内に 8 リポジトリの一括プッシュ（libsophon、LLM-TPU、osdrv などを含む）。

2.2 矽速：SLogic に sigrok-cli 転送プラグインを新規追加

日付：2026-10-09　ソース：SLogic コミット記録（10-09）、slogic16u3-tools コミット記録（10-09）

矽速ロジックアナライザエコシステムの更新：SLogic リポジトリに sigrok-cli-slogic-plugin を新規追加——sigrok コマンドラインツールチェーン向けのクロスプラットフォーム薄型ラッパー転送器で、wiki ドキュメント（中英）も同時に整合；slogic16u3-tools は OTA アプリケーションイメージ書き込みの調整パラメータを product.toml（[ota] 設定セクション）に公開し、ツールチェーンの設定可能性を強化。

3. 国内チームの深掘り

3.1 奕斯偉計算：上場初日の値動きは乱高下、調達純額 23.86 億香港ドル

日付：2026-10-09　情報源：搜狐（芯智訊）：RISC-V 第一股！奕斯偉計算が上場初日に公募割れ（10-09）、電子工程専輯：奕斯偉計算が香港取引所に上場、王東升氏が3つ目のIPOを獲得（10-09）

上場初日（詳細は「今日の重点」参照）を巡る補足：場中高値は約1.60香港ドル、安値は1.365香港ドル。発行費用は約1.21億香港ドル。同社は元京東方会長の王東升氏が創業に関与し、累計4ラウンドの資金調達額は90億元超（IDG資本が最大の外部機関株主）。2023年から2025年の売上高は17.52／20.25／24.31億元、純損失は18.37／15.47／15.16億元。目論見書は競争への対応策として「価格を下げて数量を取る」戦略を開示しており、今後も損失が続く可能性がある。

3.2 奕斯偉グループ：武漢シリコン材料基地の初回設備が今月搬入

日付：2026-10-09　情報源：湖北省経済和情報化庁：奕斯偉武漢シリコン材料基地の初回設備が今月搬入（10-09）

同じく奕斯偉グループに属するシリコン材料部門（西安奕材、科創板上場）の武漢基地建設が加速：敷地面積約310畝、総投資額約125億元、初回設備は今月搬入、来年第2四半期に生産開始、全面稼働後の年間生産額は35億元超を見込む。今年6月末時点で西安奕材の総生産能力は100万枚／月を突破、出荷量の世界シェアは約7.7%（12インチシリコンウェハは国内首位、世界6位）。同基地は武漢における12インチシリコンウェハ工程の空白を埋め、地元のストレージおよびウェハ製造クラスターと連携を形成する。

3.3 進畳時空：spine-triton がビルド・リリース経路を整備

日付：2026-10-09　情報源：spine-triton コミット記録（10-09）、docs-buildroot コミット記録（10-09）

進畳時空の spine-triton（K3のTritonコンパイルスタック）は調査期間内に10件余りのコミットが集中してリリース経路を整備：smt_rvisa モジュールのリネームを行い、GitHub CIを新設して各Pythonバージョン向けに riscv64 wheel をビルド；vendoringロジックを共有スクリプト（scripts/common.sh）に抽出し、定例でバージョン番号とビルドワークフローを更新。ドキュメント側では、docs-buildroot にK3 Secure Bootガイドの英語翻訳とv1.0.8／v1.0.9リリースノートを追加、docs-rosはK3ドキュメントの数箇所を修正。

3.4 楽鑫：esp-sr が wakenet10 ウェイクモデルをサポート、esp-idf のマルチチップ修正がマージ

日付：2026-10-09　情報源：esp-sr コミット記録（10-09）、esp-idf コミット記録（10-09）

楽鑫は調査期間内に継続的に推進：esp-sr 音声フレームワークに wakenet10 ウェイクモデルのサポートを追加（PTモデルファイルを含む）、音声対話スタックをアップグレード；esp-idf は一連の修正をマージ——C61 の監視クロックをPVT関数による設定に変更、SDMMC msyncタイムアウトマスク、TEEのロールバック防止、S31 DAC準備とBLE Audioアドレス署名など。楽鑫組織は調査期間内に30以上のリポジトリへプッシュし、端側（RISC-Vチップラインを含む）のメンテナンスが高頻度で行われている。

4. 具身智能とロボット専章

4.1 進畳時空ロボット：ros2_humanoid が WebSocket 直結 ASR 動作制御を追加

日付：2026-10-09　情報源：ros2_humanoid コミット記録（10-09）

進畳時空ロボット組織の ros2_humanoid は調査期間内に WebSocket直結のASR（音声認識）動作制御をマージ：認識結果がWebSocketを経由して直接ヒューマノイドロボットの動作をトリガーできる。これに先立ち同リポジトリはROS制御をオペレーターsocket APIへ移行し、音声プロンプト期間中もASR収集を維持していた——制御チェーンは「音声—オペレーター—アクチュエータ」の直結と疎結合の方向へ継続的に進化している。

5. 総括とトレンド観察

  • ディストリビューションのデスクトップ側がマイルストーンを迎える：Ubuntu 26.10 が公式 RISC-V デスクトップイメージを初出荷（SpacemiT K3 を推奨、RVA23 級ハードウェア向け）。RISC-V デスクトップの可用性は「実験的イメージ」から「公式サポート」へと移行。

  • ツールチェーンと仕様層の細部収束：LLVM が RISC-V 上で分岐なしコードを分岐付きにコンパイル（Zicond／RVA23 が解決策）、riscv-unified-db に RVA23.1／RVB23.1 プロファイルを追加。ソフトウェアと仕様層は細部でなお継続的に研磨中。
