RISC-V 全球动态日报（2026-08-11）

2026-08-11 苦芽科技

调研窗口：过去 24 小时（2026-08-10 15:46 ~ 2026-08-11 15:46 北京时间） 信源：HN、Google News 聚合、CNX Software、Phoronix、RISC-V 官方、GitHub API 等（详见附录）

一、开源社区与内核/版本动态

1.1 RVA23.1 与 RVB23.1 Profile 公开评审正式启动

日期：2026-08-11　来源：HN / RISC-V isa-dev 邮件组

RISC-V 国际基金会就 RVA23.1 与 RVB23.1 Profile 启动公开评审（public review），面向全社区征集反馈。这是 RVA23/RVB23 系列规范发布后的首个维护性迭代版本，涉及 A 类应用与 B 类基准 Profile 的细则修订与勘误更新。评审链接发布在 RISC-V ISA 开发邮件组（groups.riscv.org isa-dev），社区可通过该渠道提交意见。作为 RVA23 系列的新一轮公开评审，其对工具链、操作系统（内核/发行版）与编译器生态的适配节奏有直接指引意义。

1.2 社区活动预告：第五届滴水湖中国 RISC-V 产业论坛 8 月 13 日举行

日期：2026-08-07（公告）　来源：新浪财经 / 电子工程专辑

第五届滴水湖中国 RISC-V 产业论坛将于 8 月 13 日举行，届时将有 10 款国产先进芯片集中亮相，是观察国产 RISC-V 处理器产业化进度的近期重要节点。本届论坛在国产芯片”产业化新高地”方向上继续推进，值得在会后跟踪各厂商新品细节。

1.3 规范基础设施仓库活跃

日期：2026-08-11　来源：riscv/riscv-unified-db

RISC-V 官方规范数据库仓库（riscv-unified-db，208 stars）保持更新。该仓库是”RISC-V 规范唯一来源”工程的一部分，以机器可读方式维护规范与制品信息，近期 RVA23.1 等评审文档的配套数据也在此维护。

二、产品与生态动态

2.1 Comu：6 美元 USB 口 RISC-V 开发板

日期：2026-08-10　来源：CNX Software / Hackster.io

Comu 是一款基于 CH32V203（沁恒，RISC-V 内核 MCU）的微型开发板，整个板卡可完全嵌入 USB 接口内，售价约 6 美元。该设计把开发板做成 U 盘形态，降低了 RISC-V MCU 入门门槛，在 HN 上获得讨论（4 分）。此类”极低价 + 新形态”开发板持续为 RISC-V 社区带来新鲜血液。

2.2 Dabao（Baochip-1x，DEF CON 34 徽章芯片）获 MicroPython 实验移植

日期：2026-08-10　来源：Adafruit Blog

Adafruit 报道了 Dabao（即 DEF CON 34 徽章搭载的 Baochip-1x RISC-V SoC）的 MicroPython 实验性移植。该芯片周边社区生态正在快速成形：GitHub 上已出现 mainline Linux 启动尝试（pkoscik/baochip-linux）、裸机 DOOM 移植（ace42588/baochip-doom）与裸机 C SDK（ArmstrongSubero/dabao-sdk）。一款会议徽章芯片能在一周内聚集”移植 Linux + 跑 DOOM + 出 SDK”的社区动作，说明其文档与工具链对极客友好，是 RISC-V 开源硬件社区活跃度的典型样本。

三、国内团队动态与深挖

3.1 芯来科技：申报新三板创新层 + Lauterbach TRACE32 支持仓库上线

日期：2026-08-10/11　来源：新浪财经 / GitHub Nuclei-Software

芯来科技（Nuclei，国产 RISC-V CPU IP 头部厂商）8 月 10 日向全国股转系统申报新三板创新层，并定向募资 4200 万元（新浪财经）。同日（8 月 11 日），其官方 GitHub 组织新增仓库 lauterbach-startup，提供 Lauterbach TRACE32 调试器针对芯来 RISC-V 处理器的启动脚本。从”IP 龙头资本化”到”国际调试工具链适配”，芯来在商业与生态两条线同步推进；TRACE32 脚本仓库的建立也说明其客户群体的调试工具链需求正在标准化。

3.2 香山（XiangShan）：开芯红超亿元种子轮投向香山 IP 核架构升级

日期：2026-08-11　来源：观点网

开芯红完成超亿元种子轮融资，资金投向香山 IP 核架构升级（观点网）。香山是开放高性能 RISC-V 处理器标杆项目（GitHub 7186 stars），该轮融资表明其商业化路径获得一级市场认可。仓库侧同样活跃：8 月 11 日 XiangShan 合入 feat(topdown)：OoO 窗口瓶颈归因（#6173，新增 OoO-window bottleneck attribution 功能）与 loadPipe 延迟标志写入修复（#6339），性能分析能力在持续增强，为”架构升级”提供了工程侧佐证。

3.3 奕斯伟（ESWIN）：”RISC-V 第一股”上市后盈利争议受关注

日期：2026-08-10　来源：凤凰网

凤凰网刊发分析文章《三年亏 49 亿，RISC-V 第一股奕斯伟的繁荣谁买单？》，聚焦奕斯伟计算（ESWIN Computing，EIC7700 SoC 平台）上市后的盈利与估值问题。该文为媒体观点类报道，未获公司官方回应，本报告仅作资本市场动态记录；其芯片工程侧动态仍以 GitHub 组织 eswincomputing 的 linux-stable/opensbi 等仓库活跃度为准。

四、具身智能与机器人专章

窗口内无重大动态。 过去 24 小时未检索到与具身智能/机器人方向直接相关的 RISC-V 强相关新闻（gnews “具身智能 when:2d” 与 “RISC-V 机器人” 查询均无窗口内命中）。

近 3 天趋势观察：该方向仍以生态渐进为主——此前跟踪的进迭时空（SpaceMiT，spacemit-robotics 组织）、乐鑫（esp32-c 系列）等国内团队的机器人相关产品线未见新的公开里程碑，行业侧的机器人动态多集中在通用人工智能与整机层面，与 RISC-V 指令集直接相关的公开进展保持低频。若需深挖该方向，可重点关注 8 月 13 日滴水湖论坛上具身智能相关芯片新品发布。

五、总结与趋势观察

  1. 规范侧进入评审窗口：RVA23.1/RVB23.1 公开评审启动，是未来数月工具链与 OS 适配的重要输入，社区可积极参与反馈。
  2. 国内团队资本化加速：芯来申报新三板创新层（募资 4200 万）、开芯红超亿元种子轮投向香山 IP——RISC-V IP 厂商正密集对接一级/二级市场；奕斯伟上市后的盈利讨论则是资本化的另一面。
  3. 生态事件前瞻：8 月 13 日第五届滴水湖中国 RISC-V 产业论坛，10 款国产芯片集中亮相，是本周最重要的国内产业观察窗口。
  4. 开源硬件社区活跃度不减：6 美元 USB 开发板 Comu、DEF CON 34 徽章芯片 Dabao 的 MicroPython/Linux/DOOM 生态，显示低门槛硬件持续吸引开发者。
  5. 局限性说明：本窗口内新浪财经、观点网、凤凰网原站与 Adafruit（Cloudflare）正文不可直接抓取，相关条目引用 Google News 聚合链接；新闻总量中等偏少，判断为”平静日”向常规日的过渡状态。
