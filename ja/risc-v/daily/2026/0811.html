RISC-V デイリーレポート (2026-08-11)

2026-08-11 Kubuds

調査期間：過去 24 時間（2026-08-10 15:46 ~ 2026-08-11 15:46 北京時間） 情報源：HN、Google News アグリゲーション、CNX Software、Phoronix、RISC-V 公式、GitHub API など（詳細は付録）

1. オープンソースコミュニティとカーネル/リリース動向

1.1 RVA23.1 と RVB23.1 Profile の公開レビューが正式に開始

日付：2026-08-11　出典：HN / RISC-V isa-dev メーリングリスト

RISC-V 国際基金会は RVA23.1 と RVB23.1 Profile に関する公開レビュー（public review）を開始し、コミュニティ全体からフィードバックを募集している。これは RVA23/RVB23 シリーズ仕様のリリース後、最初のメンテナンスイテレーションであり、A クラスアプリケーションと B クラスベースライン Profile の細則改訂およびエラッタ更新を含む。レビューのリンクは RISC-V ISA 開発メーリングリスト（groups.riscv.org isa-dev）に掲載され、コミュニティはこのチャネルを通じて意見を提出できる。RVA23 シリーズの新たな公開レビューとして、ツールチェーン、オペレーティングシステム（カーネル/ディストリビューション）、コンパイラエコシステムの対応ペースに対する直接的な指針としての意義がある。

1.2 コミュニティイベント予告：第5回滴水湖中国 RISC-V 産業フォーラムが 8 月 13 日に開催

日付：2026-08-07（告知）　出典：新浪財経 / 電子工程専輯

第5回滴水湖中国 RISC-V 産業フォーラムが 8 月 13 日に開催され、10 種類の国産先端チップが一堂に公開される予定であり、国産 RISC-V プロセッサの産業化進捗を観察する上で直近の重要な節目となる。今回のフォーラムは国産チップの「産業化の新たな高地」という方向性で引き続き推進され、会後に各社の新製品の詳細を追跡する価値がある。

1.3 仕様インフラストラクチャのリポジトリが活発

日付：2026-08-11　出典：riscv/riscv-unified-db

RISC-V 公式仕様データベースリポジトリ（riscv-unified-db、208 stars）が更新を維持している。このリポジトリは「RISC-V 仕様の唯一の情報源」プロジェクトの一部であり、機械可読な形で仕様と成果物情報を維持しており、最近では RVA23.1 などのレビュー文書に対応するデータもここで管理されている。

2. 製品とエコシステムの動向

2.1 Comu：6 ドルの USB 端子 RISC-V 開発ボード

日付：2026-08-10　出典：CNX Software / Hackster.io

Comu は CH32V203（沁恒、RISC-V コア MCU）をベースにした超小型開発ボードで、ボード全体が USB 端子内に完全に収まるサイズで、価格は約 6 ドル。開発ボードを USB メモリ形態にすることで RISC-V MCU の参入障壁を下げており、HN で議論を呼んだ（4 ポイント）。このような「超低価格＋新しい形態」の開発ボードは、RISC-V コミュニティに新鮮な血を継続的に供給している。

2.2 Dabao（Baochip-1x、DEF CON 34 バッジチップ）が MicroPython の実験的移植を獲得

日付：2026-08-10　出典：Adafruit Blog

Adafruit が Dabao（すなわち DEF CON 34 バッジに搭載された Baochip-1x RISC-V SoC）の MicroPython 実験的移植を報道した。このチップの周辺コミュニティエコシステムは急速に形を成しつつある。GitHub 上では既に mainline Linux 起動の試み（pkoscik/baochip-linux）、ベアメタル DOOM 移植（ace42588/baochip-doom）、ベアメタル C SDK（ArmstrongSubero/dabao-sdk）が登場している。あるカンファレンスバッジ用チップが一週間で「Linux 移植 + DOOM 動作 + SDK 公開」というコミュニティの動きを集めたことは、そのドキュメントとツールチェーンがギークに優しいことを示しており、RISC-V オープンソースハードウェアコミュニティの活発さの典型的なサンプルである。

3. 国内チーム動向と深掘り

3.1 芯来科技：新三板イノベーション層への申請 + Lauterbach TRACE32 対応リポジトリ公開

日付：2026-08-10/11　情報源：新浪財経 / GitHub Nuclei-Software

芯来科技（Nuclei、国産 RISC-V CPU IP のトップメーカー）は 8 月 10 日、全国股転システムに対し新三板イノベーション層への申請を行い、あわせて 4200 万元の定向増資を実施した（新浪財経）。同日（8 月 11 日）、その公式 GitHub 組織に新規リポジトリ lauterbach-startup が追加され、Lauterbach TRACE32 デバッガの芯来 RISC-V プロセッサ向け起動スクリプトを提供している。「IP トップ企業の資本化」から「国際的デバッグツールチェーンの対応」まで、芯来は商業とエコシステムの二本の線で同時に前進している。TRACE32 スクリプトリポジトリの設立は、その顧客層のデバッグツールチェーン需要が標準化しつつあることも示している。

3.2 香山（XiangShan）：開芯紅が1億元超のシードラウンドを香山 IP コアアーキテクチャアップグレードに投入

日付：2026-08-11　情報源：観点網

開芯紅が1億元超のシードラウンド調達を完了し、資金は香山 IP コアアーキテクチャアップグレードに投入される（観点網）。香山はオープンな高性能 RISC-V プロセッサの標杆プロジェクト（GitHub 7186 stars）であり、今回の調達はその商業化パスがプライマリー市場で認められたことを示している。リポジトリ側も同様に活発である。8 月 11 日、XiangShan は feat(topdown)：OoO ウィンドウボトルネック帰属（#6173、OoO-window bottleneck attribution 機能を新規追加）と loadPipe 遅延フラグ書き込みの修正（#6339）をマージし、性能分析能力が持続的に強化されており、「アーキテクチャアップグレード」にエンジニアリング側の裏付けを提供している。

3.3 奕斯偉（ESWIN）：「RISC-V 第一股」上場後の盈利をめぐる議論が注目を集める

日付：2026-08-10　情報源：鳳凰網

鳳凰網は分析記事『三年で 49 億の損失、RISC-V 第一股奕斯偉の繁栄は誰が支払うのか？』を掲載し、奕斯偉計算（ESWIN Computing、EIC7700 SoC プラットフォーム）上場後の盈利とバリュエーションの問題に焦点を当てた。本稿はメディアの観点類の報道であり、会社側の公式回應は得られていない。本レポートは資本市場の動向記録としてのみ扱う。そのチップエンジニアリング側の動向は、引き続き GitHub 組織 eswincomputing の linux-stable/opensbi などのリポジトリの活発度を基準とする。

4. 具身知能とロボティクス専章

調査期間内に重大な動向なし。 過去 24 時間、具身知能／ロボティクス方向に直接関連する RISC-V 強関連ニュースは検索されなかった（gnews 「具身知能 when:2d」と「RISC-V ロボット」のクエリはいずれも期間内のヒットなし）。

直近 3 日間の傾向観察：この方向は依然としてエコシステムの漸進が主体である。以前追跡した進畳時空（SpaceMiT、spacemit-robotics 組織）、楽鑫（esp32-c シリーズ）など国内チームのロボティクス関連製品ラインに新たな公開マイルストーンは見られず、業界側のロボティクス動向は汎用人工知能と完成機レベルに集中しており、RISC-V 命令セットに直接関連する公開進展は低頻度を保っている。この方向を深掘りする必要がある場合は、8 月 13 日の滴水湖フォーラムにおける具身知能関連チップ新製品発表に注目するとよい。

5. 総括と傾向観察

  1. 規範側がレビュー期間に入る：RVA23.1/RVB23.1 の公開レビューが開始。今後数カ月のツールチェーンと OS 適応にとって重要な入力であり、コミュニティは積極的にフィードバックに参加できる。
  2. 国内チームの資本化が加速：芯来が新三板イノベーション層への申請（調達額 4200 万）、開芯红が超億元のシードラウンドを香山 IP に投入——RISC-V IP ベンダーは一次/二次市場への接続を密集させている。奕斯偉上場後の収益性をめぐる議論は資本化のもう一つの側面である。
  3. エコシステムイベントの前瞻：8 月 13 日の第 5 回滴水湖中国 RISC-V 産業フォーラムでは、10 種類の国産チップが集中的に披露され、今週最も重要な国内産業観察の窓口となる。
  4. オープンソースハードウェアコミュニティの活発さは衰えず：6 ドルの USB 開発ボード Comu、DEF CON 34 バッジチップ Dabao の MicroPython/Linux/DOOM エコシステムは、低ハードルなハードウェアが継続的に開発者を惹きつけていることを示している。
  5. 限界の説明：本調査期間内、新浪財経、観点網、鳳凰網の原サイトと Adafruit（Cloudflare）の本文は直接クロールできず、関連項目は Google News のアグリゲーションリンクを引用している。ニュース総量は中程度やや少なめであり、「平穏な日」から通常日への移行状態と判断される。
