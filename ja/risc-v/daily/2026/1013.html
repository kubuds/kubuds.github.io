今日の重点：進畳時空 llama.cpp ブランチが独立した ggml-spacemit バックエンドを導入、v0.2.1 をリリース

日付：2026-10-12　出典：spacemit-com/llama.cpp PR #43：Add standalone ggml-spacemit backend（10-12）、llama.cpp ブランチ Release v0.2.1（10-12）

進畳時空の llama.cpp ブランチリポジトリが PR #43 をマージし、独立した ggml-spacemit バックエンドを導入、既存の CPU パスとのデュアルバックエンド共存を実現：

  • 独立バックエンドは明示的に有効化：有効化しない場合、デバイスレジストリはゼロデバイスを報告し、デフォルト動作は変わらない（従来の CPU パスを維持）；有効化には環境変数
    GGML_SPACEMIT_BACKEND を 1 に設定する必要があり、利用者は --device SPACEMIT0 でこのバックエンドを選択する。
  • ビルド修正：libggml-cpu と libggml-spacemit の 2 つのライブラリのビルド方法を調整し、両者間のシンボル挿入（symbol interposition）衝突を修正。
  • 同日 v0.2.1 をリリース（前版 v0.2.0 は 09-24 にリリース）——ブランチのバージョン番号は約 2~3 週間のイテレーションリズムを維持。

本期間の他の進畳時空更新（xslim の静的量子化がオペレータ無視をサポート、モデルライブラリに RT-DETR と MNN バックエンドを追加、3.6 参照）および Ubuntu 26.10 の K3 公式サポートが近づく中（1.1 参照）、K3／K1 のエッジ AI 推論とデスクトップ上位エコシステムの経路が社内外で同時に整備されつつある。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 Ubuntu：26.10 RISC-V デスクトップイメージがリリース前テスト週間に入る

日付：2026-10-12　出典：NeoTeo：Ubuntu 26.10 RISC-V desktop images: what to test（10-12）、新浪財経：Ubuntu 計画が RISC-V 命令セットに適合した公式 26.10 デスクトップイメージをリリースへ（10-12）、Canonical Discourse：Announcing Ubuntu Desktop Images for RISC-V（10-09、背景）

Ubuntu 26.10（Stonking Stingray）は 10 月 15 日のリリースが予定されており、riscv64 デスクトップイメージはリリース前最後の一週間の集中的なテスト期間に入っている。本調査期間のテスト側の動き：NeoTeo が「何をテストすべきか」のテストガイドを公開（10-12）、新浪財経など中国語メディアが追随報道（10-12）。既報の要点：Ubuntu Desktop が初めて RISC-V 公式イメージを提供、さらに実験的な Xubuntu Minimal イメージもあり（仮想マシンでの試用を推奨）；公式は SpacemiT K3（Pico-ITX）でのテストを推奨（26.10 から同プラットフォームに公式サポートを提供）；完全なデスクトップ体験は RVA23 級ハードウェア（Milk-V Jupiter 2、DeepComputing DC-ROMA、SiFive HiFive Unmatched）向け；実機起動には一次ブートローダー（U-Boot）とデバイスツリーを自身で配置する必要がある；不具合報告は Launchpad 経由。

1.2 RevyOS：カーネル設定を一括拡充——奕斯偉 EIC7700 と linuxboot、Type-C スタックのサポートを追加

日付：2026-10-12　出典：revyos/linux コミット記録（10-12）

RevyOS カーネルリポジトリは調査期間内に 20 コミット、設定に対して第二弾の一括拡充を実施（これに先立つ 10-11 の一回はベースライン同期）：奕斯偉（ESWIN）EIC7700 プラットフォームのサポートを新規追加（ARCH_ESWIN、DWMAC_EIC7700 ネットワークカード、PINCTRL_EIC7700、さらに DRM_AST ディスプレイを有効化）と DP1000 プラットフォーム設定；K3 向けにディスプレイコントローラと UFS を有効化；K1（Banana F3） 向けに USB2 を有効化；Type-C プロトコルスタック（TYPEC／TCPM／UCSI／FUSB301／DP_ALTMODE／PHY_SPACEMIT）と RTC_DRV_EFI、PWM ファンセンサーなどを有効化；linuxboot 設定を新規追加；CI にクロスビルドとネイティブビルドを追加。ディストリビューション側では国産 SoC（K1／K3／EIC7700）と TH1520 のプラットフォーム化サポートが引き続き深化している。

1.4 技術コミュニティ：RVBNA（バルク正規化アルゴリズム）解析記事の公開

日付：2026-10-11（10-12 に Hacker News 経由で拡散）　情報源：FProx：RISC-V Bulk Normalization Algorithm (RVBNA)（10-11）、Hacker News ディスカッション（10-12）

コミュニティの著者 FProx が RVBNA（RISC-V Bulk Normalization Algorithm）——スケーラブルなドット積（dot product）近似計算手法——を解析する記事を執筆：固定小数点アキュムレータを核心とし、積と累加の 2 段階のいずれも round-to-odd 丸めを採用、わずかな精度を犠牲にして実装コストと遅延のスケーラビリティを獲得（アキュムレータの guard ビット数は累加項数に応じて拡張）。RVBNA はすでに RISC-V ISA マニュアル草案に記載され（5 月に統合）、現在 2 つの拡張プロジェクトに統合されている：ベクトル行列拡張 VME の Zvt ファミリ（riscv-isa-manual PR #2997）と大バルクドット積拡張 Zvdota／Zvbdota（PR #2618）。記事は FP MUL+ADD、FMA、Kulisch 精密累加などの手法の精度—コストのトレードオフを系統的に比較し、誤差評価器（rvbna-explorer）をオープンソース化した。

日付：2026-10-12　情報源：CNX Software：Facebook releases Muse Gadgets SDK for ESP32 and Raspberry Pi/Linux-based devices（10-12）、facebookincubator/muse-gadget-sdk（GitHub）

Meta はオープンソースの Muse Gadgets SDK（Apache-2.0）をリリースし、自作ハードウェアを同社のパーソナル AI アシスタント Muse に接続可能にした：ESP32 デバイス SDK（画像表示、音声入出力、センサー／アクチュエータインターフェース、複数の ESP32 開発ボードをサポートし、ESP32-C5／C6 など RISC-V チップモデルをカバー）と Linux デバイス SDK（Raspberry Pi など、system.run、file.read/write などの命令を提供）を含む；さらにサードパーティデバイススキルカタログ（スマートホーム、プリンター、3D プリンターなど）も含む。Meta は自作の 5000 台の Muse Home Link を米国のサブスクライバー向けに無償配布し、ハードウェアは ESP32-C5（デュアルバンド Wi-Fi 6、BLE、802.15.4）ベース。これは RISC-V ワイヤレス MCU が大手企業のコンシューマー向けハードウェアに採用された最新事例であり、ESP32 エコシステムがパーソナル AI エージェントのハードウェア基盤として使われ始めていることを示す。

2.2 業界分析：AI ワークロードが RISC-V 採用を加速、SHD は 2031 年に SoC 出荷 359 億個を予測

日付：2026-10-12　情報源：Bisinfotech：Why AI workloads are accelerating RISC-V adoption（10-12）

業界メディア Bisinfotech は、AI とエッジコンピューティングがいかに SoC 設計の志向を再形成するかを分析する記事を掲載した。性能のボトルネックは動作周波数からデータ移動、メモリ階層、相互接続効率へと移り、ヘテロジニアス SoC において RISC-V は制御とシステム管理の役割を担うのに適しており、行列／テンソル演算などのカスタム拡張の余地を残している。記事は SHD Group『2026 RISC-V 市場レポート』を引用し、2031 年に RISC-V SoC の出荷量が 359 億個に達し、CAGR は約 31.7% になると予測し、ソフトウェアとハードウェアの協調（コンパイラ／ランタイムによるカスタム命令のサポート）と pre-silicon 検証（FPGA プロトタイプ）がカスタム RISC-V SoC の実用化にとって重要であると強調している。

3.1 香山：MBTB 全連想 vBTB がメインブランチにマージ；NEMU が v2026.10.r3 をリリース

日付：2026-10-12　情報源：XiangShan PR #6587：implement a fully associative vbtb（10-12）、NEMU コミット記録（10-12）、NEMU Release v2026.10.r3（10-12）

香山メインブランチ（kunminghu-v3）の調査期間内に PR #6587：MBTB（メインブランチターゲットバッファ）向けに全連想 vBTB（仮想分岐ターゲットバッファ）を実装 がマージされた。シミュレーション基盤も同時に推進：NEMU は AME 行列拡張の命令ディスパッチと物理メモリ（PMEM）アクセスを分離して重构（#1249）し、v2026.10.r3 バージョンをリリースした。difftest／GEM5／XSCache の調査期間内のプッシュはフィーチャーブランチに集中（メインブランチには調査期間内のコミットなし）。これは前号の圧縮 ROB（crob）のマージに続き、香山がアウトオブオーダーフロントエンド構造と行列拡張シミュレーションの2つのラインで継続的に投入していることを示している。

3.2 達摩院玄鉄：コンプライアンステストフレームワークに T-SBI を導入、テストスイートを S モード実行へ移行

日付：2026-10-12　情報源：damo-rv-priv-ats PR #37（10-12）、damo-rv-priv-ats リポジトリ

達摩院玄鉄（XUANTIE-RV）組織下の damo-rv-priv-ats コンプライアンステストフレームワーク（RISC-V 特権レベル仕様の 90 余りの拡張をカバーし、ベアメタルプログラムとして QEMU／Sail／Spike／FPGA 上で直接実行）は PR #37 をマージした：T-SBI（Test Supervisor Binary Interface）プロトコル層を導入し、すべてのテストスイートを S モードの通常実行モデルへ移行——起動段階で M モードのみの初期化を完了した後、main() の前に S(HS) モードへ降格して実行する。動機は、元々テスト本体を M モードで実行していたため S/HS 視点でのレジスタの挙動（例えば Smstateen でゲートされた CSR を HS モードで読み取る際にトラップすべきケース）をモデリングできなかったことにある；移行後はテストの実行位置が仕様の判定シナリオと一致する。当該組織の調査期間内では 73 のリポジトリのうちこの 1 リポジトリのみがプッシュされた。

3.3 算能：SG2042 プラットフォームソフトウェアパッケージを集中リリース——SDK v20261012 と EDK2 v1.5.0

日付：2026-10-12　情報源：bootloader-riscv コミット記録（10-12）、edk2-platforms Releases（10-12）、LLM-TPU コミット記録（10-12）

算能（SOPHGO）SG2042（64 コア RISC-V サーバーチップ）プラットフォームソフトウェアパッケージを調査期間内に集中リリース：bootloader-riscv は SG2042 SDK v20261012 をリリース（新規リリーススクリプトを含む）、edk2-platforms は SG2042 EDK2 v1.5.0 をリリース、edk2／edk2-non-osi／sophgo-edk2 などのリポジトリも同時にプッシュされた。AI 側：LLM-TPU は MiniCPM5-2B（20 億パラメータ）の Python デモを追加（BM1684X／CV84X6 プラットフォーム向け）し、bge-reranker-v2-m3 の再ランキング、MinerU2.5-Pro のドキュメント解析の適配コミットを完了しマージした。SG2042 のファームウェアと SDK 側は継続的に反復を続けている。

3.4 楽鑫：ESP-GMF マルチメディアフレームワークが v1.1 をリリース、esp-vision が LCD タッチサポートを追加

日付：2026-10-12　情報源：esp-gmf Release v1.1（10-12）、esp-vision コミット記録（10-12）、esp-idf コミット記録（10-12）

楽鑫のマルチメディアフレームワーク ESP-GMF が v1.1 をリリース（前版 v1.0 は 6 月にリリース）：Reverb と Delay オーディオエフェクト、ALC 遷移時間制御、設定読み取りインターフェースと bypass サポートを新規追加し、Bluetooth オーディオ、再生とマルチシンクキャプチャを改善し、マルチメディアパイプラインのランタイム制御能力を拡張。デバイス側：esp-vision が LCD タッチドライバサポートをマージ；esp-idf メインブランチが RISC-V トレース（trace）スナップショットのリファクタリング、BLE ログコンソールドキュメントと CI ターゲットテストなどの変更をマージ。楽鑫組織は調査期間内に 38 のリポジトリをプッシュし、当日最も活発な注目組織となった。

3.5 矽速：SLogic が SLogic16U3 モデル対応と USB リンク速度セルフチェックを新規追加

日付：2026-10-12　情報源：SLogic コミット記録（10-12）、ALL-LOGIC コミット記録（10-12）

矽速のロジックアナライザソフトウェア SLogic（v2.1.0 は 10-10 にリリース）は調査期間内も修正を継続：回帰セルフチェックでモデルを自動識別し SLogic16U3 サポートを新規追加；Windows 下での USB リンク速度検出（10G／5G）を新規追加；スループット測定を先頭バイトから起算に変更（コールドスタートの干渉を排除）；「最初の 32 ビットを破棄」を型番ごとの独立した quirk に変更し全コードコピーに同期；段階的回帰チェックリストドキュメントを補充。ALL-LOGIC リポジトリは libslogic の変更を同期。矽速組織は調査期間内に 6 のリポジトリをプッシュ。

3.6 進迭時空：xslim／mpp／モデルライブラリの複数ソフトウェアラインを更新

日付：2026-10-12　情報源：xslim コミット記録（10-12）、mpp コミット記録（10-12）、model-zoo-vision コミット記録（10-12）、model_zoo_rl コミット記録（10-12）

llama.cpp バックエンドの独立化（本日の重点を参照）のほか、進迭時空は複数のソフトウェアラインを同時に更新：xslim 静的量子化ツールが ignore_op_types／ignore_op_names をサポート（オペレータタイプまたは名称で量子化をスキップ）；mpp がビデオデコーダのキャプチャバッファレイアウトとペイロードの報告を修正；視覚モデルライブラリが RT-DETR 物体検出をマージ（#97）；強化学習モデルライブラリが MNN 推論バックエンドを新規追加（#12）；docs-*、ai-sdk など 10 余りのドキュメントと SDK リポジトリを一括更新（docs-events、docs-courses、docs-ros などを含む）。K3／K1 エッジ AI とマルチメディアスタックおよびドキュメント体系を同時に推進。

4. 具身知能とロボット専門章

4.1 進迭時空ロボット：知覚ライブラリが SuperPoint＋LightGlue 特徴マッチャをマージ、IMU／モータ特性をメインブランチに統合

日付：2026-10-12　情報源：perception PR #9：superpoint-lightglue-matcher（10-12）、peripherals-imu コミット記録（10-12）、peripherals-motor コミット記録（10-12）

spacemit-robotics の3リポジトリが進行：知覚ライブラリ perception に SuperPoint＋LightGlue 特徴マッチャをマージ（PR #9、視覚測位と画像レジストレーションに利用可能）、平面再構築モジュールをリファクタリング（依存リンクを実行可能ターゲットに調整、モデル検査と作業ディレクトリの説明を補足）；IMU ライブラリは BMI270 カーネル IIO 読み取り特性をメインブランチに統合（前回報道の feat/bmi270-iio ブランチの開発完了・収束）；モータライブラリは M8010-A 0.0.1.202610121419 バージョンパッケージをリリース。ロボット知覚と周辺デバイススタックはブランチ開発からメインブランチへのマージ・収束を完了し、引き続きカーネル態とイベント駆動方向へ収束している。

5. まとめとトレンド観察

  • デスクトップ生態系は検収週へ：Ubuntu 26.10 は 10-15 にリリース予定で、RISC-V デスクトップイメージ（SpacemiT K3 の公式サポートを含む）はリリース前の集中テスト期間にある；テストガイドと中国語メディアの報道が密集しており、イメージ品質のフィードバックは初回リリースの実インストール体験に直接影響する。
  • RISC-V AI 推論スタックの補強が加速：進迭時空 llama.cpp 独立 ggml-spacemit バックエンド（v0.2.1）（本日の重点参照）、xslim 量子化ツールとモデルライブラリの拡張（RT-DETR／MNN）；業界レポートは AI 負荷を RISC-V 採用の加速要因と見ている（SHD は 2031 年に 359 億個出荷と予測）。
  • 国内チームの高密度なアウトプット：今期は香山（全連想 vBTB）、達磨院玄鉄（T-SBI コンプライアンスフレームワーク）、算能（SG2042 プラットフォームソフトウェアパッケージ）、楽鑫（ESP-GMF v1.1）、矽速（SLogic16U3）、進迭時空（AI ソフトウェアスタックとロボット）がいずれも実質的なコミットを実施；GitHub 組織の活発度は espressif 38＞spacemit-com 15＞sophgo 7。
  • 生態系のファンダメンタル：Muse Gadgets SDK により RISC-V 無線 MCU（ESP32-C5）が Meta 公式のコンシューマ向け AI ハードウェアに進出；RevyOS は奕斯偉 EIC7700 プラットフォーム設定を追加し、国産 SoC のディストリビューションサポート面が引き続き拡大。
  • 要観察：Ubuntu 26.10 正式版 RISC-V イメージのインストールフィードバック；香山全連想 vBTB の今後の性能検証；spacemit llama.cpp 独立バックエンドが上流にフィードバックされるか；openRuyi 次期バージョンリリース（公式サイトは現在も 2026.09）。
