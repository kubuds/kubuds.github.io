今日の重点：香山マトリクス拡張検証チェーンが FP8 精度を補完、NEMU と difftest が同時に実装（10-27）

香山チームは期間内に、マトリクス拡張（AME／MMA）のサポートを命令セマンティクスからデータ型と検証手法の 2 層へと推進した：参照モデル NEMU に FP8 マトリクス積和を追加し、差分検証フレームワーク difftest に同期検証ビルドオプションを追加し、さらに MMA の整数飽和セマンティクスを CPU と CUDA の両側で一致するよう修正した。

この線索はすでに 3 日連続で現れており、明確な技術進化の曲線を構成している。10-26 の進展は difftest が Tensor Cores を使って INT8 マトリクス比較を実行し、「比較が遅い」を解決したこと；10-27 の進展は MMA イベントの型エンコーディングを mcfg レジスタセマンティクスに基づくデコードに変更し、「比較が正しくない」を解決したこと；今日追加されたのは FP8 データ型と同期検証スイッチで、「比較が網羅的でない」を解決する。3 日間で 3 つのアクションは、同じ事実を指し示している：検証対象のコアはすでにサイクル単位のソフトウェアシミュレーションでは実行不可能なほど複雑になり、検証インフラ自体がハードウェア化・並列化されなければならない。

産業上の意義は香山の 1 コアにとどまらない。マトリクス拡張は RISC-V が AI 推論負荷に進出するための必須課題であり、規範レベルではまだ推進中である——サミット期間中に、あるメーカーは「マトリクス拡張規範が成型し製品に搭載されるにはさらに 1〜2 年かかる」と判断した。香山がこの時点で FP8 と整数飽和セマンティクスを参照モデルと差分検証に組み込むことは、「規範実装後にどう検証するか」という工程を前もって準備しておくことに等しい。国産 AI アクセラレータが本当に詰まるのは算力ピークではなく、浮動小数点と整数の境界挙動が実装間で不一致になることであることが多い；差分検証がこの層までカバーしてこそ、マルチプラットフォーム比較可能性を語る資格が生まれる。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 香山 NEMU が FP8 MMA をサポート、difftest に同期検証ビルドオプションを追加

日付：2026-10-27　出典：GitHub：OpenXiangShan/NEMU コミット記録、GitHub：OpenXiangShan/difftest コミット記録

NEMU は調査期間内に 4 件のコミットをマージした。中核は feat(ame): support FP8 MMA with FP32 accumulation（#1266）で、行列拡張が FP8 入力・FP32 累加の積和演算をサポートし始めた。これは大規模モデル推論で最もよく使われる精度の組み合わせの一つである。同じバッチには、階層化 BOOM リファレンス設定（#1262）、共有 FAST リファレンス時に HostTLB を再利用する性能最適化（#1270）、および diff-spike の NEMU ゲストメモリを 32 GiB に調整する変更（#1267）も含まれる。

difftest は同期間に 3 件で、MMA 検証手法に集中している。MMA 経路の決定論的比較に用いる同期検証ビルドオプションを新設し（#1009）、CPU と CUDA 両側の整数飽和処理を修正し（#1008）、FPGA シナリオにおける DiffTest チェーンとリファレンスモデル検査を分離した（#1006）。

  • 観察：FP8 が入ると、リファレンスモデルと実チップの間の数値差が拡大する。飽和、丸め、NaN 伝播のいずれか一箇所でも不一致があれば、差分比較は無効になる。このバッチのコミットは「精度セマンティクスの一貫性」を検証範囲に組み込むものであり、単に比較スループットを増やすよりも重要である。

1.2 香山昆明湖 V3、7 件の修正をマージ：PC ガードビットと StoreQueue プレフィックス出隊

日付：2026-10-27　情報源：GitHub：OpenXiangShan/XiangShan コミット記録

昆明湖 V3 ブランチの調査期間内に 7 件のコミットがあり、すべて機能修正である。コア側は「実 PC を伴うガードビット」（#6751）、浮動小数点領域の不要コード整理（#6765）。ストアキューの側では同じバッチの 2 件の修正が最も重要で、物理アドレスマッチングと仮想アドレスマッチングを分離し（#6769）、完了済みのストアキュープレフィックスのみを出隊させる（#6768）。後者はアウトオブオーダーコアで典型的な順序化の誤りに対処するもので、部分的に完了したキューの項目が早期に解放されると、メモリアクセスの順序がアーキテクチャのセマンティクスと一致しなくなる。

  • 観察：この種の修正は性能ランキングには現れないが、アウトオブオーダーコアを量産に投入できるかどうかを左右する。ストアキューのプレフィックス出隊は RISC-V の弱いメモリモデルの下で最も誤りやすい箇所の一つであり、2 件が同じバッチで連続してマージされたことは、チームがストアサブシステムの正当性収束に取り組んでいることを示す。

1.3 openRuyi、1 日で 20 件：Samba ファミリーを 4.25.1 に上げ Waf ビルドへ移行

日付：2026-10-27　情報源：GitHub：openRuyi-Project/openRuyi コミット記録

openRuyi メインリポジトリの調査期間内に 20 件のコミットがあり、3 つの領域に集中している。第一は Samba エコシステムの全体アップグレードとビルド体系の統一である。samba を 4.25.1 に上げ、併せて tdb 1.4.15、talloc 2.5.0、tevent 0.17.2 を同期アップグレードし、統一して Waf ビルドマクロに切り替え、rpm-config-openruyi に Waf サポートを追加した。第二はオーディオスタックの修正で、jack2 のクライアント接続を修正し、リサンプリングを有効化した。第三はインフラとセキュリティで、cmocka を 2.0.2 に上げて単体テストを有効化し、ceph は ceph-volume、mgr、cephfs-mirror、rgw の修正をバックポートし、rust-aws-lc-sys 0.46 を新設して rust-aws-lc-rs を 1.18.2 に上げた。

  • 観察：Samba の 4 点セットのビルド方式を Waf に統一し、ディストリビューションのメタ設定レベルでマクロサポートを提供するのは、典型的な「上流がビルドシステムを変えたら、ディストリビューションもそれに合わせて作り直す」作業である。こうした縁の下の作業が、SMB ファイルサービスが RISC-V サーバー上で上流のペースに合わせてセキュリティ更新を追随できるかどうかを決める。

1.4 Pharo 14 リリース：仮想マシンに RISC-V JIT を追加

日付：2026-10-26　情報源：Pharo 公式：Pharo 14 Released、オープンソース中国：Pharo 14 リリース

Smalltalk 開発環境 Pharo がバージョン 14 をリリースした。仮想マシン側の 3 つの構造的改造のうち、RISC-V コミュニティに最も直接的なのは RISC-V JIT サポートの新設である。残る 2 つはフレームとスタック管理の統一（インタプリタと実行エンジンの大幅な整理）、メモリ管理の拡張（直接老年代割り当てとガベージコレクションの改善）である。さらに Slang／C 翻訳層の大量の修正、コマンドラインテストとデバッグツールの拡充、そしてリリースサイクルを秋季に変更することを含む。

  • 観察：Pharo の RISC-V JIT は「ニッチな言語スタックがメインストリームのバックエンドを补齐する」という類のシグナルに属する。言語仮想マシンは ISA エコシステムの中で最も見落とされやすい層である。ニュースにはならないが、JIT バックエンドが欠けているということは、その種の開発者全体が RISC-V 上で実用的な性能を得られないことを意味する。

1.5 矽速 SLogic、USB バルク転送を补齐、Radxa Linkr は linkrd リポジトリを新設

日付：2026-10-27　情報源：GitHub：sipeed/SLogic コミット記録、GitHub：radxa-linkr/linkrd

矽速 SLogic ロジックアナライザの調査期間内に4件のコミットがあり、いずれも USB 転送層に関するもの：SLogic8U2 に新 PID（0x3000）を割り当て、各アプリケーションのデバイステーブルと命名を統一し、単一 USB 転送を約5ミリ秒に短縮するとともに少なくとも4つの転送を常時処理中とし、処理中の転送が4つ未満の場合はセルフチェックを直接失敗させる。同時に libsigrok、all-logic、scopehal-apps、slogicview も一括して進めた。Radxa Linkr 組織の linkrd リポジトリは同日 init proj の初回コミットを完了し、新規リポジトリの立ち上げとなった。

  • 観察：SLogic のこれらのコミットが露呈したのはサンプリング系外設の古くからの問題である——スループットのボトルネックはサンプリングレートではなく USB 転送のスケジューリングにある。「少なくとも4つの転送を処理中」をセルフチェックのアサーションに書き込むことは、性能制約をテストに埋め込むことであり、国内で計測器系 RISC-V 外設を手掛けるチームにとって参考に値する手法である。

2. 製品・エコシステム動向

2.1 物奇微がサミットで全シリーズの RISC-V チップを展示：WQ9301 は量産出荷済み

日付：2026-10-26　情報源：物奇微電子：物奇微が全シリーズ RISC-V チップを携え第6回 RISC-V 中国サミットに登場、新浪財経：国産ルータ Wi-Fi6 チップの突破口（10-27）

重慶物奇微電子は第6回 RISC-V 中国サミットでネットワーク通信とエッジ側インテリジェンスの2つの製品ラインを展示した。公式の説明によれば、同社の全シリーズ製品はオープンソースの RISC-V アーキテクチャに基づいており、累計で6億個を超える RISC-V コアを使用している。重点製品は Wi-Fi 6 AP チップ WQ9301：RISC-V マルチコアアーキテクチャで、802.11 a/b/g/n/ac/ax、上下りンク MU-MIMO と OFDMA、160MHz 帯域幅と 1024QAM をサポートし、デュアルバンド同時接続の物理層は最高 3Gbps、ベースバンドと RF を単一チップに集積している。公式はこれを国内でごく少数、量産出荷を実現した RISC-V Wi-Fi 6 AP チップであるとし、ルータ、スマートゲートウェイ、FTTR の国産化代替に向けたものだとしている。

  • 観察：ルータ AP チップは Wi-Fi 産業チェーンの中で研究開発投入と認証のハードルが最も高い環であり、過去には長らく海外メーカーが握っていた。WQ9301 の量産の意義はパラメータではなく、「AP 側の RISC-V がテープアウトから大量出荷までの全工程を走り切った」ことにある——これは STA 側より一桁難しい。

2.2 Keybytes がオープンソースのモジュラーキーボードを公開：キー1つにつき RISC-V マイクロコントローラ1個

日付：2026-10-26　情報源：The Register：Open source keyboard lets you swap parts like magnetic Lego bricks、Tom’s Hardware（10-27）

オープンソースハードウェアプロジェクト Keybytes はモジュール化を1キー単位まで徹底した：各キーは独立した 1u の回路基板（Keybit と呼ばれる）で、それぞれに CH32V003 シリーズの RISC-V マイクロコントローラを搭載し、四辺に電源供給と I2C を伝送する pogo pin を配置、キー同士は磁石で吸着し、任意に並べ替えて異なる配列にできる。キーボード全体には追加で1つのコントローラモジュール（Keyword と呼ばれる）だけが必要で、キーを集約してホストと通信する役割を担い、このモジュールは同じ外形ながら内部に2層の回路基板を隠している。設計とファームウェアは GitHub でオープンソース化され、Keybit 基板1枚のコストは約2ドル、Keyword は約30ドル、フルサイズ筐体全体の材料と受託組立コストは約900ドルである。

  • 観察：通常のキーボードは1つのチップでマトリクス全体をスキャンするが、Keybytes は逆にスキャン能力を各キーに分散させている。コスト面では全く優位性はないが、「配列の並べ替え」をはんだ付け工程から抜き差し動作へと変えた——レイアウトを頻繁に変更する必要がある特殊な入力デバイス（片手キーボード、アクセシビリティ入力、分割型エルゴノミクス）にとっては現実的な実行可能な道筋である。CH32V003 のような数セントの RISC-V MCU がこの方式の成立の前提となっている。

2.3 米家デスク型浄水飲料機 3 が RISC-V チップを搭載、ミネラル徐放とフィルター寿命管理に使用

日付：2026-10-27　情報源：IT之家：小米が米家デスク型浄水飲料機 3 を発表

Xiaomiはミーハウス据置型浄水器3を発売、価格は1499元。製品はRISC-Vチップを搭載し、特許取得済みの緩放技術により水中へストロンチウム、亜鉛、カルシウムなど6種類の天然ミネラル元素を安定的に放出し（実測ストロンチウム含有量は0.2mg/L以上）、これに基づいてROフィルターの寿命を動的に3年に延長する。その他の仕様：2100W厚膜加熱で3秒即湯、最大流量786mL/min、40〜99℃の範囲を1℃刻みで調整可能、デュアルコア9段階ろ過にデュポンRO膜（精度0.0001マイクロメートル）を組み合わせ、6L原水・廃水分離タンクに2L外部純水ポットを付属し、NFCカップタグによる専用水温・水量の記憶に対応する。

  • 観察：これはRISC-Vが家電において「単なるスイッチではなく制御アルゴリズムを担う」稀な事例である——ミネラルの緩放とフィルター寿命の動的計算はいずれもセンサーの閉ループとモデル演算を必要とし、制御系の負荷に属する。国産家電がこうしたアルゴリズムをRISC-V MCUへ移行させることは、ARM Cortex-Mを代替する地味だが現実的な代替経路である。

2.4 36krがRVA23普及の年を振り返る：三つのハードルと三つの時間点

日付：2026-10-27　情報源：36kr：PPTからデータセンターへ——RISC-VがRVA23普及の年を迎え、AIとフィジカルAIの二路線で突破

36krはサミットの振り返り長文を掲載した（プラットフォーム上ではユーザー自主投稿・AI支援生成と表示され、主要データは公式メディアの表現と照合済み）。記事はRISC-V国際財団CEOのAndrea Galloの判断を引用している：2026年はRVA23アプリケーションプロセッサの普及の年であり、過去1年間に同時発生した三つの転換点——RVA23プロファイルの確定、サーバープラットフォーム仕様1.0のリリース、高性能チップの相次ぐ登場——が現れた。

規模化以前の障害について、藍芯算力生態マーケティング責任者の許慶偉氏は「最後の1%から5%」という表現を示した：業界ソリューションの基盤の90%以上は汎用的であり、本当に足を引っ張るのは、金融がどのデータベースとミドルウェアに適合すべきか、工業がどの専用ツールチェーンに適合すべきかという点で、実際の顧客による牽引に頼るしかない。同氏は三つの時間点を挙げた：2028年に市場に同種のプレイヤーが四五社現れ、2030年にRISC-VとAIサーバーのエコシステムが初步的に構築され、2035年にエコシステムが基本的に使いやすい水準に達する。深圳計算科学研究院崖山データベースCEOの陳志標氏のフィードバックはより直接的である：今年RISC-V上でコードレベルの適合を完了し、機能は使用可能だが、中核性能の場面では依然として大きな隔たりがある。

  • 観察：この振り返りの価値は、議論を「何がリリースされたか」から「どこで詰まっているか」へ引き寄せた点にある。三つの時間点のうち最も記録に値するのは2028年——多くのベンダーが規模の転換点を2年後に賭けており、2027年が生産能力、認証、ソフトウェア適合への集中的投資の年になることを意味する。

3. 国内チーム深掘り

3.1 物奇微：累計6億個のRISC-Vコアを使用、AIメガネ向けメイン制御が十余りのブランドに採用

日付：2026-10-15〜10-26　情報源：物奇微電子：世界初のブレイン・コンピュータ・インターフェースAIメガネを発表、物奇微電子：全シリーズRISC-Vチップがサミットに登場

物奇微電子（重慶）は国内で最も早くRISC-Vに基づく研究開発と量産を行った設計会社の一つであり、製品ラインは「接続」と「端側AI」の二本柱に分かれる：前者の代表はWi-Fi 6 APチップWQ9301とSTAシリーズ、後者はスマートオーディオメイン制御とマシンビジョンチップである。同社はサミット期間中に累計6億個超のRISC-Vコアを使用したことを明らかにした。そのWi-Fi APチップは以前に工信部の自主制御可能認証を取得し、STAチップはAEC-Q100車載規格認証を通過している。

端側AIの路線の着地点はAIメガネである。そのWQ7036シリーズスマートオーディオメイン制御はVADとKWSアルゴリズム、通話ノイズリダクション、低消費電力Bluetooth制御を統合し、公式によれば影目、極米、NIMO、加南、Looktech、LOHO、VITUREなど十余りのブランドのAIオーディオメガネ、AI撮影メガネ、ARメガネに採用されている。10-15にパリのSILMO光学展で発表されたLooktechの新世代製品はこの方案を採用し、EEG脳波センサーと6軸IMUを内蔵し、筐体重量は30グラム以内、テンプルの肉厚は0.4ミリメートルに抑えられている。

  • 観察：国内AIメガネのメイン制御は長らく「BluetoothオーディオSoC＋外付けISP」の組み合わせであったが、物奇の経路は音声フロントエンドアルゴリズム（ウェイクアップ、ノイズリダクション）と無線接続を一つのRISC-V SoCに押し込むことにある。AIメガネ本体の開発を計画するチームにとって、これは汎用アプリケーションプロセッサを回避できる低コストの方案だが、代償として演算能力の上限はメイン制御の位置づけに制約され、画像と表示には依然として外付けが必要となる。

4. エンボディドインテリジェンスとロボット特集章

4.1 エンボディドインテリジェンスチップ市場：RISC-V浸透率は2025年10.7%、2030年には28.2%と予測

日付：2026-10-27　情報源：36kr：PPTからデータセンターへ

サミットレビューでFrost & Sullivanのデータを引用：中国の具身知能チップ市場は2021年の341億元から2025年の1297億元へ増加（年平均成長率39.6%）、2030年には3877億元に達すると予測。同期間中、RISC-Vの当該市場における浸透率は1.7%から10.7%へ上昇し、2030年には28.2%に達する見込みである一方、x86とArmのシェアはそれぞれ40%、49%から31%、41%へ低下した。もう一组のデータは、中国のRISC-V主控チップ市場が2021年の11億元から2025年の377億元へ増加し、2030年には2194億元に達すると予測される（年平均成長率139.5%）。

  • 観察：二つの数字を並べて見るとより意味がある——主控チップ市場は4年間で約34倍に成長したが、具身知能チップにおけるRISC-Vの絶対シェアは依然として1割程度にとどまる。これは増分が主に汎用主控とコンシューマー側から来ていることを示しており、ロボット本体の大算力チップは依然としてArmとx86の地盤である。これは国内メーカーが「小脳」側では切り込めるが、「大脳」側では依然として検証段階にある理由でもある。

4.2 零次方机器人：端側で複数の計算リズムが併存、RISC-Vは通信と制御から切入

日付：2026-10-27　情報源：36氪：PPTから机房まで

零次方机器人の共同創業者兼CTOである程頤氏は、整機メーカーの視点から路線判断を示した：ロボットの端側では複数の計算リズムが併存する必要がある——タスクの分割は数百ミリ秒から秒級、VLA動作ポリシーは数十から数百ミリ秒、接触発生後の高頻度知覚調整はまた別のリズムであり、これらを同一システム内で協調させなければならない。氏は、近期の合理的な経路は成熟したアプリケーションホストを保持し、まず通信と制御などの环节にRISC-Vを導入することだと考える。これらの位置は職責とインターフェースが明確で、収益を迅速に証明できるからだ。

  • 観察：これは今期最も現実的な具身知能に関する判断である。RISC-Vを通信と制御の环节に置き、最初から主控を置き換えるのではないということは、国内ロボットメーカーのRISC-V導入期が「コプロセッサ／リアルタイム領域」の形態で現れることを意味する。これはRISC-V MCUとリアルタイムOSを手がけるチームにとって実行可能なウィンドウであり、高算力SoCを手がけるチームにとってはより長い検証サイクルとなる。

4.3 进迭时空机器人リポジトリの一括同期、調査期間内に実質的な新規コミットなし

日付：2026-10-27　情報源：GitHub：spacemit-robotics 組織

spacemit-robotics組織では調査期間内に8つのリポジトリがプッシュを示したが、同一秒内に完了しており（humanoid_common、humanoid_unitree_g1、control_whole_body、target、peripherals-motor、peripherals-imuなど）、主ブランチはコミットログを核查した結果、調査期間内に新規コミットはなく、ブランチまたはミラー同期であり新規開発ではないと判定された。同期間中、revyosの4つのリポジトリ（opensbi、ruyiedk2、edk2、coreboot）、sipeedの6つのリポジトリも同様の秒級一括プッシュの特徴を示した。

  • 観察：この種の一括プッシュを開発成果と見なすのはよくある誤判である。ロボットスタックの実際の開発活動は主ブランチのコミット内容を見る必要があり、今期の進迭時空はロボット方向で収録可能な新たな進展はなかった。

5. まとめとトレンド観察

1. 検証インフラがオープンソースコア競争の見えざる戦場に。 香山のこの線は3日連続で進展した：difftestがTensor Coresを借用して比較スループットを向上させ、MMAイベントタイプがmcfgセマンティクスに従ってデコードされ、今日はNEMUがFP8乗加算をサポートし、difftestが同期検証スイッチと整数飽和修正を追加した。三つの動きを合わせると一つの判断になる——検証されるコアは既に純粋なソフトウェアシミュレーションでは追いつけないほど複雑になっており、検証自体をハードウェア化する必要がある。そしてFP8が入ってきた後は、精度セマンティクスの一貫性がスループットよりも成否を決める。この経験は国内のAI拡張に取り組むすべてのチームに当てはまる。

2. 端側はRISC-Vにとって当日唯一、実際の新製品が落地した方向である。 物奇のWi-Fi 6 APチップが量産出荷を実現し、AIグラス主控が10以上のブランドに採用され、小米はミネラル緩徐放出とフィルター寿命アルゴリズムを家電内のRISC-Vチップに組み込み、KeybytesはCH32V003でキーごとに1つのMCUを搭載するキーボードを作った。三つの共通点は、チップが安価で、アルゴリズムが閉ループし、量がコンシューマー側にあること——サーバー側で依然として性能を論証中のシーンと対照的である。

3. サミット後のレビュー期、議論の焦点は「何を発表したか」から「どこで詰まっているか」へ移行。 今期の中国語報道の主体はサミット後の解読であり、ハードウェア発表と玄鉄60億個、芯際無限の資金調達、Tenstorrentの15億ドルEラウンドなどの内容はすでに10-19から10-20期に収録済みであり、重複排除ルールに従い再掲しない。新たに現れた有効な増分は産業判断である：RVA23落地の年、規模化前の「最後の1%から5%」、2028／2030／2035の3つの時点、そして崖山データベースの「機能は利用可能だがコア性能には依然として差がある」という実測フィードバック。

4. 平穏なウィンドウの判定と根拠。 今期の中国語と英語のGoogle Newsで合計57件の調査期間内の重複排除ヒットがあり、ギャンブルとゲームのノイズ、株式市況記事、サミットの重複報道を除外した後、実質的な新規は約5件である；GitHub側の重点組織の多くは調査期間内に主ブランチのコミットがなかった。ニュース量の少ない日に属し、レポートは平穏日プロトコルに従って納品され、内容の主体はオープンソース側の進展と端側製品の落地に置かれた。
