今日の重点：藍芯算力が約 20 億元の B ラウンドシリーズ資金調達を完了、RISC-V+AI サーバーチップが量産へ突入

日付：2026-10-12（中国語メディア初報）／2026-10-13（英語メディア追随）　出典：鳳凰網・投資界：独占｜藍芯算力が B ラウンドシリーズで約 20 億元の資金調達を完了（10-12）、東方財富（財聯社）：藍芯算力が約 20 億元の B ラウンド資金調達を完了（10-12）、搜狐（大河財立方）：藍芯算力が約 20 億元の B ラウンド資金調達を完了（10-12）、DIGITIMES：China’s Blue Core Computing secures nearly US$300 million（10-13）

深圳の RISC-V チップ企業藍芯算力（深圳）科技有限公司が B ラウンドシリーズ資金調達、合計規模約 20 億元人民幣（約 2.99 億ドル相当）を完了：深創投、華控基金、隆湫資本などの既存株主が引き続き追加出資し、蘇国投、蘇創投、兆易創新、同創偉業、建銀国際、粤科金融、九坤創投などの国有資本、産業資本、トップティアのベンチャーキャピタルが参入。資金は RISC-V CPU チップの量産落地、AI ヘテロジニアスプロセッサのイテレーション、および通信事業者、金融機関、クラウドサービスプロバイダー向けの汎用コンピューティングソリューションの展開に充てられる。要点：

  • 製品：中核製品 LX500 は世界初の RISC-V 汎用計算と AI 智算を単一チップでネイティブ融合したサーバー CPU——48 コアヘテロジニアス設計（高性能コア 32＋高効率コア 16）、オンチップに 75 TOPS（INT8）AI エンジンを統合、RVV 1.0 ベクトル拡張と RVA23 標準をサポート、PCIe 5.0 と CXL 2.0 メモリ拡張にネイティブ対応。
  • 実装：2026 年 2 月にテープアウト・点灯；7 月に LX500 を搭載した聯想問天 WR5219 G5 サーバーが合肥聯宝工場で量産ラインオフ；中国移動 BC-LINUX オペレーティングシステムに適合済みで、Kimi K2.6、Qwen3.6-35B などの大規模モデル推論検証を完了。
  • チーム：創業者兼 CEO の盧山は元字節跳動サーバーチップ研究開発責任者（インテル、クアルコムに在籍経験あり）、CTO の賈新霞は 21 年のチップ設計経験を持つ。

Agentic AI の算力需要と RISC-V のサーバー化という二つの叙事が交差する中、これは 2026 年国内 RISC-V 領域で最大規模の資金調達の一つであり、国産 RISC-V サーバーチップが「点灯」から「規模実装」段階へ入ったことを示すものでもある。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 Asterinas 0.19.0：X.Org／DRM の初期的サポートを導入し AArch64 ターゲットを追加

日付：2026-10-13　情報源：Phoronix：Asterinas 0.19.0 Brings Up X.Org & Other Improvements To This Rust-Written OS（10-13）

Rust で書かれたメモリ安全カーネル Asterinas が 0.19.0 をリリース：初めて初期 DRM サブシステムを導入し、modesetting ドライバと Mesa LLVMpipe 上で X.Org グラフィックススタックを動作させ、従来の伝統的なフレームバッファ体験に取って代わった；AArch64 アーキテクチャサポートを新規追加し、既存の x86_64、RISC-V、LoongArch64 ターゲットと並列に位置付けた；同時にセキュアコンテナ、Rust ネイティブデバイスモデル、セルフホスティング（self-hosting）と AI コードレビューモードを推進。このプロジェクトは Linux ソフトウェア互換性とメモリ安全を売りとし、RISC-V プラットフォームのシステムソフトウェア多様化の観察サンプルである。

1.2 openRuyi：ファームウェアラインが「Ruyi Firmware 20261013」をリリース、K3 Pico-ITX の全套 UEFI サポート

日付：2026-10-13　情報源：ruyifirmware Release 20261013（10-13）、edk2-ruyi コミット記録（10-13）、openRuyi コミット記録（10-13）

openRuyi プロジェクトのファームウェアライン（ruyifirmware／edk2-ruyi）では、調査期間内に進迭時空 K3 Pico-ITX プラットフォームサポートを集中的にマージ：GOP グラフィックス出力と EDID モード、PCI オプション ROM、RTL8127 有線 NIC ドライバ、ブート選択とコンソールホットキー戦略、Fastboot 更新検証など；併せて 「Ruyi Firmware 20261013」をリリースし、x64 エミュレーション（x64emu）を含む版と含まない版の二つのファームウェアバリアントを提供（x64emu では AMD Radeon RX 6400 を検証済み）。メインリポジトリでは同時に Go エコシステムソフトウェアパッケージ（OpenTelemetry コレクターなど）の SPECS 更新を実施；kiwi-image に riscv64 イメージの GitHub Action ビルドスクリプトを新規追加。openRuyi 公式サイトのニュースページには新バージョンリリースはまだない（最新は依然として 2026.09 バージョン）。

1.3 riscv.org ブログ：ISA Explorer 受講生の実践——ISA コンフィグビルダーと拡張サンドボックス

日付：2026-10-13　情報源：RISC-V International：My RISC-V Mentorship: The Problems Nobody Assigned Me（10-13）

riscv.org は LFX メンターシッププログラムの受講生である Rohit Sharma（インド・JECRC大学）の実践総括を掲載した。RISC-V ISA Explorer プロジェクトにおいて、既定のマイルストーンを完了する以外に、自ら2つのツールを設計・公開した——ISA Configuration Builder（必要に応じてコア設定を選択し、依存関係を自動解析し、ツールチェーンで利用可能な設定文字列を生成し、競合を検証する）と Extension Sandbox（新命令の設計時に既存エンコーディングとの競合を即時チェックする）。同時にパイプラインを3パスのルーティングへ書き直し、1,867 条の命令を 83 個の ISA サブセットへ自動分類できるようにした。ツールは自研コアの設定とカスタム拡張のエラーコストを低減するために用いられ、コミュニティ教育とツールチェーン構築の好事例である。

2. 製品とエコシステムの動向

2.1 Ubitium：1,400万ドルのシード調達、再構成可能な RISC-V「汎用プロセッサ」をフィジカル AI に向けて

日付：2026-10-13　情報源：Ubitium 公式サイトプレスリリース：UBITIUM RAISES $14 MILLION TO BUILD THE FIRST UNIVERSAL PROCESSOR FOR PHYSICAL AI（10-13）、EE Times：Ubitium Tapes Out First ‘Universal’ RISC-V Chip（背景）

ドイツ・デュッセルドルフの半導体スタートアップ Ubitium（RISC-V International 会員）は 1,400万ドルの新シードラウンドを発表した。Ibex Investors がリードし、OpenOcean、KBC Focus Fund、Runa Capital、Inflection などが参加、累計調達額は 1,800万ドルに達した。同社は1 つの再構成可能な RISC-V 処理アレイで「DSP＋NPU＋CPU」の寄せ集めスタックを置き換えることを主張している——アレイは実行時の要求に応じて信号処理、AI 推論、リアルタイム制御の3種類の負荷間でリソースを配分する。初号チップ UB108（256 個の処理ユニット、サムスン 8nm）はすでにテープアウトし、同一アレイ上で3種類の負荷を検証済み。初の商用チップ UB410（4,096 個の処理ユニット）は 2027 年に評価ユニットを納入する計画で、初期顧客はレーダーやオーディオなど「知覚層」アプリケーションに注力する。

3. 国内チームの深掘り

3.1 進畳時空：llama.cpp ブランチが v0.2.2 をリリース、K1 端末での Qwen3.5 出力問題を修正

日付：2026-10-13　情報源：llama.cpp Release v0.2.2（10-13）、llama.cpp PR #44：Fix ggml-spacemit op kernels garbling Qwen3.5-2B output on K1（10-13）

前回（独立系 ggml-spacemit バックエンドの導入と v0.2.1）の続きとして、进迭時空 llama.cpp ブランチは調査期間内にさらに v0.2.2 をリリースした：Qwen3.5-2B が K1 上で文字化けを出力するオペレータカーネル修正（#44）をマージし、新バックエンドの有効化方法を完全に文書化した——環境変数 GGML_SPACEMIT_BACKEND とパラメータ –device SPACEMIT0 を同時に設定しなければ有効にならない（環境変数のみの設定では効果がない）；マルチモーダルモデルは –media-backend smt パスを使用し、ベンチマークテストは llama-bench –dev SPACEMIT0 を使用する。ブランチは約1〜3週間のリリースサイクルを維持しており、端側推論の可用性は継続的に収束している。

3.2 进迭時空エコシステム：K3 全国産化 mini COM-E モジュールが登場；Agent ソフトウェアラインが集中的にリポジトリを建立

日付：2026-10-12／2026-10-13　情報源：CSDN：衆達科技が SMSM_K3_A 进迭時空 K3 全国産化 mini COM-E モジュールを発表（10-12）、GitHub：spacemit-com 組織の新規リポジトリ（10-13）、model-zoo-vision コミット記録（10-13）

エコシステムの2つの動向：第一に、衆達科技が进迭時空 K3 をベースに SMSM_K3_A 全国産化 mini COM-E（Type 10）モジュールを発表した——16コア同構融合アーキテクチャ、60 TOPS AI 演算性能、32GB LPDDR5 メモリ、16MB NOR＋128GB UFS ストレージ、部品は100%国産；Bianbu／Buildroot／銀河麒麟 V10 をサポートし、産業グレード -40〜70℃、典型的消費電力 13W；AI 側では llama.cpp（GGUF/GGML、Qwen3-30B などを実行可能）と YOLO、VLM、ASR/TTS をサポートし、AI エッジゲートウェイ、産業サーバー、具身ロボットなどのシーンに向けられている。第二に、GitHub 側では、进迭時空が 10-13 の夕方に一批の新規リポジトリを集中的に建立した（bibit シリーズ、bianbu-agent シリーズ、agent-power-manager、bianbu-agenic、bianbu-skill など、現在はいずれも空のリポジトリ）——端側 AI Agent システムソフトウェア方向への布石を示している；ソフトウェア側では model-zoo-vision が CosPlace 視覚位置認識モデルを追加し、mpp が vdec/venc/RTSP の複数の修正をマージし、docs-buildroot が K1/K3 スクリーン適合ドキュメントを更新した。

3.3 香山：ストアキューの修正がメインブランチにマージ；仿真検証チェーンが集中的にイテレーション

日付：2026-10-13　情報源：XiangShan PR #6693：fix forward older store data（10-13）、NEMU コミット記録（10-13）、difftest コミット記録（10-13）、GEM5 コミット記録（10-13）

香山メインライン（kunminghu-v3）がストアキューの古いストアデータ前方伝播修正（#6693）をマージ；検証と仿真インフラは多方面で成果を上げている：difftest は MCSim タイミングバックエンド（DRAMSim3 と並列）を追加し、mcsr/mcfg の delta エンコーディング、FPGA 向けの CRC-64 ストアキューハッシュ検証および PLDM フローの修正を行った；NEMU は AME マトリックスハッシュ計算を加速し、CRC-64 ストアキューハッシュ検証と重複ストアログ回復修正を導入した；GEM5 は Zimop 命令サポート（RV64 回帰を含む）と TRACERTL/NEMU トレースフォーマットサポートを追加した。昆明湖プラットフォームの正確性検証基盤への推進は本調査期間において比較的顕著である。

3.4 楽鑫：安全自己診断ライブラリ ESP-BIST が v1.1.0 をリリース、ツールチェーンが S31 サポートを補完

日付：2026-10-13　情報源：esp-bist Release v1.1.0（10-13）、esptool コミット記録（10-13）、esp-video-components コミット記録（10-13）

Espressif組み込み自己テスト（BIST）ライブラリ esp-bist が v1.1.0 をリリース——このライブラリは CPU レジスタ、CSR、割り込み処理、揮発性／不揮発性メモリ、スタックとクロック源などのハードウェアに対して完全性自己テストを行い、IEC 60730 Class B などの安全クリティカルなシナリオ向けであり、サポートリストは ESP32-C3／C5／C6／C61 と H2／H4／P4（いずれも RISC-V コア）をカバー；esptool は ESP32-S31 の ADC ウェイト eFuse フィールドと ESP32-H2 チップバリアント識別をマージ；esp-video-components は OV5647 センサの非連続クロックモードを修正。Espressif 組織の調査期間内に 46 のリポジトリがプッシュされ、端側（RISC-V チップラインを含む）のメンテナンスペースは密集している。

3.5 Sipeed：ロジックアナライザソフトウェア SLogic が v2.2.0 をリリース

日付：2026-10-13　情報源：SLogic Release release-2.2.0（10-13）、SLogic コミット記録（10-13）、sipeed_wiki コミット記録（10-13）

Sipeedロジックアナライザソフトウェア SLogic は v2.1.0 に続き v2.2.0 をリリース：arm64（macOS）下でのキャプチャ長問題と ngscopeclient の深メモリ再整形がもはやフリーズしないことに焦点；同時に ALL-LOGIC の arm64 下でのサンプリング深度変数の未初期化問題を修正；sipeed_wiki は NanoKVM マルチスクリーンイメージのドキュメントを更新し、ドキュメントリンクを修正し、サイト上部の案内を SLogic32U3 の Kickstarter クラウドファンディング入口に切り替えた。

4.1 燕心科技：「記号＋行動＋接続」を RISC-V チップに融合し、プラグアンドプレイのロボットブレインを実現

日付：2026-10-13　情報源：36 氪：大模型能写诗，却走不出工厂围栏——燕心科技把「符号＋行为＋连接」三条路线融进 RISC-V 芯片（10-13、Google News リンク）、英語版（36Kr Europe 同一記事）

36 氪が北京のスタートアップ燕心科技（2025 年 1 月設立）を報道：大規模モデルが「工場のフェンスを越えられない」シーン泛化の課題に対し、記号主義、行動主義、コネクショニズムの三つの技術路線を一つの「汎用エンボディドインテリジェンスブレイン」システムに融合し、事前パッケージ化して RISC-V チップに固化、ロボットメーカー向けにプラグアンドプレイの「業界向けエンボディドインテリジェンスブレイン」を提供し、出荷後の継続学習と人間と機械の対話によるティーチング、純端側デプロイを支持すると主張。留意すべき点：同社は依然として早期検証段階にある——公開情報によれば登録資本金は 100 万元、まだ資金調達ロードショー期間中であり、報道も具体的な技術実装の詳細、性能指標、量産進捗はいずれも非公開であると指摘している。RISC-V×エンボディドインテリジェンスの交差領域が引き続き早期創業を惹きつけるもう一つの例証と見ることができる。

4.2 調査期間観察：エンボディドインテリジェンス側の三つの手がかり

本調査期間のエンボディドインテリジェンスとロボット側は「両端で温度上昇、組み合わせデリバリ」の様相を呈している：第一に、国際的な新規プレイヤーが差別化されたアーキテクチャで参入——Ubitium は再構成可能な RISC-V アレイで知覚、推論、リアルタイム制御を統合し、1400 万ドルのシード資金を調達（2.1 参照）；第二に、国内の早期スタートアップが「ロボットブレイン」を RISC-V チップ化パッケージに賭けている（燕心科技、4.1 参照）；第三に、成熟メーカー側では、進迭時空 K3 が引き続きロボットとエッジシーンに向けて「チップ—モジュール—ソフトウェアスタック」の完全なチェーンを供給している（K3 COM-E モジュールと llama.cpp／モデルライブラリソフトウェアライン、3.2 参照）。そのロボット専門組織 spacemit-robotics は調査期間内に新しいプッシュはなかった。三つの手がかりが共に指し示すのは：RISC-V のエンボディドインテリジェンスにおける競争は、まさに「単点チップ」から「チップ＋ブレインソフトウェア＋シーンパッケージ」の組み合わせデリバリへと転換しつつあるということである。

5. まとめとトレンド観察

  • 資本と製品の二軸共鳴：藍芯算力（蓝芯算力）の約 20 億元 B ラウンドと Ubitium の 1400 万ドルシードラウンドが同時期に成立し、高性能／フィジカル AI 方向の RISC-V チップが世界の資本が集中的に注ぎ込む赛道となった；国内の RISC-V サーバーチップは「量産検証」段階に入っている（LX500＋Lenovo 完成機量産＋通信事業者オペレーティングシステム適配）。
  • 産業日程が迫る：第 6 回 RISC-V 中国サミットが 10 月 18〜20 日に深圳で開催され、達摩院玄鉄、奕斯偉、藍芯、進畳などが集中して亮相する；これに Ubuntu 26.10（10 月 15 日リリース）が初めて公式 RISC-V デスクトップイメージを提供することが重なり、来週が観察ウィンドウとなる。
  • 国内エンジニアリング側の高密度出力：進畳時空の llama.cpp v0.2.2 と Agent ソフトウェアラインが集中的にリポジトリ構築、K3 全国産化 COM-E モジュールを推出；香山検証チェーン（MCSim タイミングバックエンド、delta 符号化、CRC-64 ストレージ検査）が体系的に推進；楽鑫の安全自検ライブラリ v1.1.0 がすべての RISC-V SoC 製品ラインをカバー。
  • オープンソースシステムソフトウェアの静水深流：Asterinas 0.19（DRM／X.Org 初サポート、AArch64 ターゲット）と openRuyi ファームウェアライン（K3 Pico-ITX サポートリリース）は、RISC-V プラットフォームソフトウェアがデスクトップとファームウェアの両端で継続的に補強されていることを示す。
  • 制限事項の説明：燕心科技の情報は単一メディア報道であり、会社は依然としてアーリー段階にある；藍芯の調達規模は中国語メディアと DIGITIMES の口径に準拠（約 20 億元人民元／約 2.99 億ドル）；今期の会員公式サイト巡回は 67 社がクロール失敗（国内サイトが多数）、関連サイトの動態には漏れが存在する可能性がある。
