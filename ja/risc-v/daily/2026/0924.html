今日の重点：riscv.org ブログが Monte Cimone v3 を公開：算能 SG2044 ベースの RISC-V HPC テストベッドが第3世代評価を完了

日付：2026-09-23　出典：RISC-V International ブログ《Monte Cimone v3: Where RISC-V Stands in High-Performance Computing》

9月23日、RISC-V 国際財団公式サイトブログはボローニャ大学、イタリア Cineca スーパーコンピュータセンターと E4 Computer Engineering が共同で完成した Monte Cimone v3（MCv3）評価を公開した：この RISC-V HPC テストベッドの第3世代は算能（SOPHGO）Sophon SG2044 プロセッサでクラスタを構築し、HPL と STREAM ベンチマークを使用して消費電力を同時測定し、Intel Xeon Platinum 8480+（Sapphire Rapids）および NVIDIA Grace CPU Superchip プラットフォームと比較した。記事中のデータ：SG2044 のシングルコア性能は前世代 SG2042 の2倍以上に向上し、クラスタ拡張性も同時に改善；MCv3 のエネルギー効率は 3.08 GFLOPs/W に達し（第1世代 MCv1 の約10倍）、ピークエネルギー効率点での性能は Sapphire Rapids の 46%、Grace CPU Superchip の 91% に達した。著者チームにはボローニャ大学の Luca Benini、Andrea Bartolini らエネルギー効率計算研究に長年従事する学者が含まれ、MCv3 は同テストベッドの「実際の HPC 負荷に対する定量的評価」という位置づけを継続している。

意義と境界：これは第三者学術チームが初めて国産 RISC-V サーバーチップ（SG2044）を Intel、NVIDIA サーバープラットフォームと同じベンチマーク枠組みに置きエネルギー効率点の対照を示したもので、RISC-V の HPC におけるナラティブは「動作可能」から「対照可能なエネルギー効率優位区間を持つ」へとアップグレードされた；同時に比較の口径に注意が必要——性能総量にはまだ差があり（46%）、比較もエネルギー効率点（ピーク効率）を主要な観察窗口としていることは、RISC-V サーバーの現実的な切入ポイントが依然としてエネルギー効率敏感かつオープンでカスタマイズ可能なシーンであり、全面的な性能代替ではないことを示している。SG2044 は算能が2025年に発表し（64コア、同時期に複数の HPC テスト環境に進出）、本評価は公開学術チャネルにおけるさらなる定量的裏付けである。

中国科学院ソフトウェア研究所が主導する openRuyi プロジェクトでは、調査期間内に 6 つのリポジトリが活発だった。最も注目すべきは kvm-unit-tests の RISC-V 側に新たに追加された BRS（Boot and Runtime Services）SBI 要求テストである。BRS は RISC-V ブートフローの新世代仕様であり、このコミットはディストリビューションが「BRS に準拠したファームウェア／ブートチェーン」を検証するためのテストの足がかりを補い、さらに SBI コンソール初期化を UART から分離した（従来のシリアルポートがない環境でのテスト実行を容易にするため）。ディストリビューションのメインリポジトリは引き続き SPECS をメンテナンスし、vkmark が lavapipe ソフトウェア Vulkan 上でクラッシュするパッチをバックポートして修正し、SPDX ヘッダチェックを導入した。ツールチェーン側では clang-wrap がリンカオプションと静的ライブラリメンバ選択を整備し、llvmir-converter が保護されたターゲット特性を保持してバージョン管理されたネイティブテンプレートをキャッシュする。公式サイトリポジトリは openRuyi デスクトップユーザードキュメントを補充し、ceph-ci はビルド並列上限を調整した。公式サイトのニュースページには今回の調査期間内で新しい告知はない（2026.09 リリースは未だ発行されていない）。

2.1 蓋世汽車が RISC-V 車載チップ三部作の終篇を掲載：「車載後、何で競うのか」

日付：2026-09-23　情報源：Gasgoo「RISC-V, After Entering Vehicles, What Does It Compete On?」

蓋世汽車英文サイトは09-23に、その RISC-V 車載チップシリーズの第3弾を掲載した（前2弾はそれぞれ「なぜ突然注目が高まったのか」と「いかに断片化を克服するか」を論じており、今回は最終回）。要点：量産の着地点はすでに車体制御などのエッジシーンに現れている——長城汽車技術センターが孵化させた紫荊半導体 M100 はコンビネーションヘッドライト、アンビエントライト、スイッチなどの車体制御に用いられる。東風 DF30 は多車種での検証を完了し、2026年に規模量産を計画（09-21／09-22 期に収録済み）。業界の口径では、2024年8月以来すでに複数の国産 RISC-V 車規 MCU が量産され、2026年にはさらに一批が登場するとされる。知能運転と座艙の大型チップは現在もなお補助コア／専用加速ユニットの形態で現れている（地平線征程 6 の一部は RISC-V コアを採用、Mobileye EyeQ Ultra など）。主制御 CPU は依然として Arm／x86 である。コスト計算：Arm コアのライセンス料はグレード別に数百万円から1千万円超、量産後にさらにロイヤルティを計上する。商用 RISC-V コアのライセンス料はその約10分の1だが、「無料」とは命令セット層のみを指し、商用 IP、ツール、検証環境はいずれも有料であり、エコシステムへの投入が主要なハードルとなる（英飛凌は2～3年前からエコシステムに投入。達摩院の李偉立氏は車規の全工程認証には3～5年が必要と述べる）。エコシステムとペース：アライアンス Quintauris（Bosch、英飛凌、NXP、高通などが発起）はすでに芯来科技と協力を展開している。浸透率は2025～2026年の約10％から2031年の約31％へ上昇すると予測される。発展経路は「エッジから中心へ」（車体／動力制御が先行し、その後大型チップの汎用コア／制御コアの形態で切り込む）。結論は、Arm とは短期的には補完関係、長期的には共存するというもの。本記事はメディア業界分析（全新の事件ではない）であり、本期はその要点を補記して当該シリーズの追跡を完了する。

算能（SOPHGO）の大規模モデルデプロイリポジトリLLM-TPUは調査期間内に「feat: add multi-image input and ViT output caching to Qwen3.5 demos」をコミットした。Qwen3.5シリーズのデモにマルチ画像入力サポートとViT出力キャッシュ（視覚エンコーダの重複計算を削減）を追加し、09-15号の「テキストのみのQwen3.5サポート」に続いてマルチモーダル能力への推進を継続している。同日、riscv.orgブログが公開したMonte Cimone v3 HPC評価（本日の重点参照）で使用されたのはまさに算能のSophon SG2044プロセッサであり、算能が「クラウド側TPU推論」と「RISC-VサーバーCPU」の2つの製品ラインでエコシステム活動を同時展開していることが見て取れる。

3.3 進迭時空：spine-runtime v0.6.3リリース、ソフトウェアスタックとドキュメント基盤を多面的に更新

日付：2026-09-23　情報源：spine-runtime v0.6.3リリース（09-23）、model-zoo-vision #92コミット（09-23）、mppコミット：vdecチャネルライフサイクル簡素化（09-23）、ai-sdkコミット（09-23）

進迭時空（SpacemiT）は調査期間内に7つのリポジトリでプッシュがあった。spine-runtimeはv0.6.3をリリース（同社のRISC-V SoC向けAIマルチコア実行ランタイムで、汎用コアとAI計算コア間のタスクスケジューリングと同期を担当）。model-zoo-visionはベンチマークシナリオとより明確な推論タイミングを追加（#92）。mppマルチメディアミドルウェアは3件の修正（vdecチャネルライフサイクル簡素化、MJPEG MP4サンプリングバッファ拡張、テストアセットをNexusからのダウンロードに変更）。ai-sdkはビジョンサブモジュールポインタを更新。docs-chipとdocs-productは用語・記述lintと知識同期フロー（ドキュメント基盤）を導入。K3プラットフォームのソフトウェアスタックとツールチェーンの継続的反復であり、バージョンレベルの重大なリリースはない。

4. 具身知能とロボット専章

4.1 進迭時空 spacemit-robotics：人形ロボットにRGB-D SLAMとNav2サポートを追加、モータ駆動と知覚モジュールを更新

日付：2026-09-23　出典：ros2_humanoid コミット（09-23）、peripherals-motor コミット（09-23）、perception コミット（09-23）

進迭時空ロボットライン（spacemit-robotics）は調査期間内に 4 つのリポジトリをプッシュ：ros2_humanoid に RGB-D SLAM と Nav2 ナビゲーションサポートを追加——同社の人型ロボット ROS 2 スタック（従来より Nav2 速度指令を RL 運動制御チェーンへ接続するブリッジノードと頭部 TF 発行を提供）は「運動制御」から「知覚—測位—ナビゲーション」の閉ループへと推進を継続；peripherals-motor に M8010-A モータの RS485 共有ライブラリドライバを追加（新アクチュエータ型番のサポートを補完）；perception 知覚ライブラリは平面タイリングレンダリングのターゲットを固定 1080p に修正し使用ドキュメントを更新；IMU ペリフェラルリポジトリも同期メンテナンス。09-22 号の「玲珑人形ロボットの姿勢と動力学ポリシー修正」と合わせ、進迭時空はここ二日間、人型ロボットソフトウェアスタック（制御、知覚、ナビゲーション、ペリフェラルドライバ）を継続的に補強している。

5. 総括とトレンド観察

  • HPC 側が第三者による定量座標を獲得：Monte Cimone v3 は算能 SG2044 を Intel Xeon および NVIDIA Grace と対置し、「ピーク電力効率点 91% Grace／46% Sapphire Rapids、3.08 GFLOPs/W」という対照データを提示——RISC-V HPC の語りは「動作可能」から「対照可能な電力効率優位の区間がある」へとアップグレード；性能総量の差は依然存在し、現実的な切入点はなお電力効率敏感かつオープンでカスタマイズ可能なシナリオである。
  • 車載 RISC-V が「量産とエコシステム投資」段階へ：蓋世汽車の最終編は議論を標準からデリバリーへ転換——ボディコントロールはすでにバッチ展開、パワートレインとスマートドライビングは「エッジからセンターへ」推進；真のハードルはライセンス料以外のエコシステム投資（ツールチェーン、認証、アライアンス協力）であり、10% から 31%（2031 年）という浸透率座標と 2026 年から 2030 年のウィンドウ期を提示。
  • 資本側の熱気は衰えず：奥維領芯が 2 億元超の Pre-A+ を着地（深圳国資＋産業資本の組み合わせ）、これに先立つ奕行智能の約 20 億元調達、奕斯偉の聴聞が重なり、RISC-V プロセッサ赛道の「研究開発—流片—資本」循環が国内で持続的に運転；次の鍵となる変数はなお製品デリバリーと受注の実現である。
  • オープンソース基盤が集中的な練り込み期へ：香山キャッシュサブシステム「Oceanus」とベクトルパスの並行修正、openRuyi が BRS ブート規範向けにテストを補充、SLogic／felix86 などのツールチェーン更新——いずれも次段階の製品化に向けた布石となる動きであり、openRuyi 公式サイトの 2026.09 リリースは依然として近期の観察点である。
  • 具現化知能ソフトウェアスタックの継続的補強：進迭時空の人型ロボットが SLAM とナビゲーション能力を補完し、蘇州睿芯のデータフローアーキテクチャとロボットシナリオを結びつける動きと呼応し、「端側演算力＋ロボットソフトウェアスタック」の組み合わせが持続的に形成されつつある。

限界の説明：本期の国際ニュース側は riscv.org ブログと業界分析記事が中心であり、中国語メディアの多くはすでに収録済みイベントの後続報道（睿芯数貿会、奕斯偉聴聞の英文転載など）；会員公式サイト巡回 92 社の変化はいずれもマーケティング層の更新；奕斯偉計算リポジトリにはプッシュのタイムスタンプがあるが各ブランチとタグに調査期間内の新規コミットは見られない（詳細は情報源検証表を参照）；「12nm が NVIDIA 7nm を超える」などの表現はメディアの見出し上の口径であり、第三者による実測検証は経ていない。
