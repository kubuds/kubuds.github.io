RISC-V デイリーレポート (2026-08-15)

2026-08-15 Kubuds

調査期間：過去 24 時間（2026-08-14 08:20 ~ 2026-08-15 08:20 北京時間） 情報源：HN、Google News アグリゲーション（英語＋中国語）、滴水湖フォーラムシリーズ報道（eet-china/EDN/集微網/芯智訊/新浪財経/国際電子商情）、The Register/SC Media、USENIX Security 26 論文著者ブログ、GitHub API（香山/達摩院玄鉄/進迭時空/算能/楽鑫/芯来/奕斯偉）、LinuxGizmos、Phoronix アグリゲーション等（詳細は付録参照）

1. オープンソースコミュニティとソフトウェアエコシステムの動向

1.1 USENIX Security 26 論文：Spectre が商用アウトオブオーダー RISC-V シリコン上で全系統成立（本日のトップニュースの一つ）

日付：2026-08-12（論文採択とブログ公開、08-12~13 メディア拡散）　出典：Lukas Gerlach ブログ（論文短縮版） / The Register / SC Media

ドイツの研究者 Lukas Gerlach らの論文「Spectre on RISC-V Silicon: Attacks and Defenses on Commercial Out-of-Order Processors」が USENIX Security 26 に採択され公開された。研究は入手可能な商用アウトオブオーダー RISC-V プロセッサ——達摩院玄鉄玄鉄 C910/C920 と SiFive P550 上で体系的に検証：これまで x86 上で成立していた Spectre の各変種が RISC-V 上でも同様に可能であることを示した（一部は追加の技巧を要する）。主要な発見：第一に、Spectre-BTB（v2）が利用可能かどうかはファームウェアが間接分岐予測器を有効化しているかに依存する——C910/P550 は出荷時に無効、C920 は有効であり、有効化後は攻撃が成功するが偶発的にマシンがクラッシュし、ハードウェア欠陥の存在を示唆する；第二に、研究者は BPF プローブを経由して任意のファイルを読み取る実際のエクスプロイトチェーンを構築した：RISC-V BPF JIT はカーネルが挿入した BPF_NOSPEC バリアに対して何の命令も生成せず、バリデータはプログラムが保護されていると見なすが生成コードには実際にはバリアがなく、「投機的型混同」gadget を形成する；第三に、被検コアは BTB をユーザーモードとカーネルモード間で分離しており、従来のカーネル Spectre エクスプロイト経路を困難にしている。論文は同時に防御策も提示している。これは 2023 年の T-Head セキュリティ勧告に続き、「RISC-V は Spectre に免疫がある」という迷信に対する公開の体系的反証であり、RISC-V がサーバー/クラウドインフラへ進出する上での信頼構築にとって重要な注意喚起となる。

1.2 香山 XiangShan：satp フラッシュ後の初回命令フェッチエラーを修正（#6014）

日付：2026-08-14（07:02 UTC コミット、北京 15:02）　出典：OpenXiangShan/XiangShan GitHub

香山オープンソース高性能 RISC-V プロセッサ（7191 スター）は期間内に fix(csr): fix first fetch fault after satp flush (#6014) をマージし、satp（ページテーブルベースアドレスレジスタ）フラッシュ後の初回命令フェッチエラーを修正した——アドレス翻訳/ページテーブル切り替え経路の境界条件欠陥の修正であり、仮想メモリ切り替えの正確性に直接関連する。期間内に difftest/XSCache/GEM5/NEMU など周辺リポジトリが継続的にプッシュされたこと（15 時間以内にいずれも更新あり）と合わせ、香山プロジェクトチームはフルスタックで高頻度のイテレーションリズムを維持している。以前の 08-13 の BERTi 性能強化、elaboration パラメータキャッシュ高速化は昨日のレポートに収録済みである。

1.4 Tenstorrent Ascalon XG コアの GCC パッチ + オープンソースプロジェクト観察

日付：2026-08-12（Phoronix 報道）　情報源：Phoronix アグリゲーション

2. 製品とエコシステムの動向

2.1 第5回滴水湖中国 RISC-V 産業フォーラム：40 余りの紹介、量産率 90% 超、出荷 360 億個（今日のトップニュース）

日付：2026-08-13 開幕、08-13~14 集中報道　情報源：国際電子商情 / eet-china / 新浪財経 / 集微網

昨日予告された第5回滴水湖中国 RISC-V 産業フォーラム（上海臨港、8 月 13 日開幕）の成果が集中的に明らかになり、本日の産業側で最大の出来事となった。芯原の戴偉民氏が披露したところによると、過去 4 回のフォーラムで累計 40 款の国産 RISC-V チップを紹介し、量産率は 90% 超に達した。本届フォーラムは産業シグナルを発信した——RISC-V チップの累計出荷は 360 億個、市場シェアは 30% を突破、浸透率は 25% に達した。フォーラムでは 10 款のローカル RISC-V チップ新製品が発表され、AI サーバー、ロボット運動制御、車載エレクトロニクス、インテリジェントビジョン、ネットワークインターフェースなどの方向をカバーしている（詳細は 2.2~2.4 と第 3 章を参照）。上海当局は世界の RISC-V 産業高地の構築を加速すると表明した。国際電子商情は「十のチップから見る RISC-V の主力への道」と総括した：具身ロボット、AI サーバー、車載エレクトロニクスという三大戦場を全面的にカバーし、国産 RISC-V が「可用」から「主力」へと移行する産業ナラティブの形成を象徴している。

2.2 藍芯算力 LX500：世界初の RISC-V 量産サーバー CPU（48 コア 75 TOPS）

日付：2026-08-13（滴水湖フォーラムで登場）　情報源：eet-china / EDN China / 芯智訊

藍芯算力は滴水湖フォーラムで LX500 を発表し、「世界初の RISC-V 量産サーバー CPU」と主張した。48 コア、75 TOPS の AI 算力を持ち、「智通融合」（CPU と AI アクセラレーションの融合）アーキテクチャを採用、算力利用率を主軸とし、「CPU+アクセラレータカード」分離アーキテクチャの物語を終わらせる。同社は以前に聯想と RISC-V+AI 智通融合 CPU 共同革新ラボラトリーを設立しており、聯想は世界初のオープンソースアーキテクチャ AI サーバーも発表している（7 月報道）；藍芯算力は Pre-B ラウンドで隆湫キャピタルから 3 億元超の独占投資を獲得した（7 月 1 日）。もし「量産サーバー CPU」が事実であれば、これは RISC-V がデータセンターのメイン算力ノードに挑む象徴的な節目であり、昨日の賽昉 BMC がデータセンター管理側に切り込んだことと合わせて「計算+管理」の二軸の呼応を形成する。

2.3 賽昉科技 JH-B100 シリーズ：RISC-V BMC チップが国産代替を加速（昨日報道のフォローアップ、型番が具体化）

日付：2026-08-13/14　情報源：EDN China / eet-china / Sohu

昨日の「賽昉が AI データセンター BMC に賭ける」という産業ニュースは、本日具体的な製品として実現した。賽昉科技 JH-B100 シリーズ RISC-V BMC チップ（以前「昉·驚鴻-B100」が 2026 中国 IC 設計成就賞に参評していた）は、複数の中国メディアが「智算センターの見えない生命線、世界的独占を打破」というタイトルで報道し、智算センターの BMC 需要爆発に対して国産代替を加速させると指摘している。BMC 市場は長らく Aspeed が支配しており、RISC-V ソリューションがサーバーの帯外管理に切り込むことは、エコシステムがデータセンターに入るための低コスト高価値な経路である。

日付：2026-08-13　情報源：eet-china V861 / eet-china 時擎 / Sohu PT153S

3.2 奕斯偉計算（ESWIN Computing）EAI8800：RISC-V 車載グレード電子ルームミラー（CMS）専用チップ

日付：2026-08-13　情報源：SEMI 大半導体産業網 / eet-china / EDN China

4. 重点方向専章：具身智能とロボット

4.1 滴水湖フォーラムがロボット関連シグナルを集中的に発信：運動制御チップが国産 RISC-V の新戦場に

滴水湖フォーラムの複数の新製品が具身智能を指向：格見半導体の単一チップで25自由度を駆動、500ナノ秒電流ループのロボット運動制御ソリューション（3.3参照）は、調査期間内で最も具体的な運動制御レベルの製品シグナルである——電流ループ周期は運動制御のリアルタイム性の核心指標であり、500ナノ秒レベルはハイエンドサーボ制御に対標する；進迭時空 K3 はロボット運動制御を主力シーンの一つと位置づけ（3.1参照）、spacemit-robotics の LeRobot（SmolVLA/ACT エッジ側デプロイ）、ヒューマノイドロボット（humanoid_unitree_g1）方向における既存の布陣を継続；国際電子商情「10のチップから見る RISC-V の主力への道」と新浪 8/14 総説「サーバー、AI、ロボット：中国 RISC-V の次の駅」はいずれもロボットを RISC-V の三大主力市場の一つに位置づけている。運動制御（リアルタイム制御 DSP/MCU）とエッジ側 AI（VLA モデル推論）が RISC-V 具身智能の二つの並行主線を構成し、前者は今週実質的な新製品が落地した。

4.2 エコシステム側の受け皿

香山/進迭などの高性能コアとオペレータライブラリの進展（1.2、3.1参照）は引き続きロボットのエッジ側推論に基盤を提供；格見 GS32 シリーズは既に ASIL-B 認証を取得しており（6月）、車載グレードのリアルタイム制御チップはロボット関節制御の再利用にも認証基盤を提供する。

5. まとめとトレンド観察

  1. 国産 RISC-V が「主力叙事」段階へ：滴水湖フォーラムの「出荷 360 億個、市場シェア 30% 超、量産率 90% 超」という産業データと 10 款の新製品（サーバー CPU、ロボット運動制御、車載 CMS、ビジュアルエッジ、ネットワークカード、BMC）が集中的に登場し、AI サーバー、具身ロボット、車載エレクトロニクスという三大戦場をカバーしており、国産 RISC-V が「使える」から「主力」へ移行するという叙事が今週形を成した。これは昨日の SiFive SKL オープンソース（ソフトウェアカーネルライブラリの軍備）と共に、次のことを示している：RISC-V ハードウェアエコシステムは既に十分に豊かであり、競争の重心はソフトウェアスタックと業界実装へ移行しつつある。
  2. RISC-V サーバーの道に量産級の節目が出現：藍芯 LX500（48 コア 75 TOPS、世界初の RISC-V 量産サーバー CPU と宣称）と賽昉 JH-B100 BMC が同日に焦点を集め、「主算力＋帯外管理」の二路線でデータセンターへ参入する態勢を形成；前者の量産実装が事実であれば、Tenstorrent Ascalon、達摩院玄鉄玄鉄サーバーコア（既報）と同舞台で競うことになる。
  3. セキュリティ信頼の構築が新たな議題に：USENIX Security 26 論文が、Spectre が商用アウトオブオーダー RISC-V シリコン（国産 C910/C920 を含む）で成立することを公開検証し、 moreover BPF JIT にバリアが欠けているという具体的なソフトウェア欠陥を指摘した。RISC-V がサーバー/クラウドの信頼境界へ入るには、セキュリティ監査と強化（予測バリア、ファームウェアのデフォルト設定、JIT 修復）を性能叙事と並行して進める必要があり、関連する防御作業は継続的に追跡する価値がある。
  4. 具身知能の運動制御層に国産方案が登場：格見半導体の 500 ナノ秒電流ループ/25 自由度運動制御チップと進迭 K3 ロボット運動制御のポジショニングは、RISC-V がロボットの「運動制御基座」（従来は主に DSP/専用 MCU が占めていた）に切り口を開いたことを示し、エッジ AI 推論（LeRobot 対応）と共に完全な実装経路を構成している。
  5. オープンソース高性能コアの商業化が加速：開芯紅の超 1 億元シードラウンドが香山 IP コアアーキテクチャのアップグレードに投向され、XiangShan の調査期間内に正確性修正（satp flush 命令フェッチエラー）が継続的にマージされ、オープンソースコアの「コミュニティ反復＋商業会社が承接」というモデルがさらに明確になった。

局限性説明：滴水湖フォーラムの新製品は多くが発表口径であり、具体的なパラメータはメーカー公式データに準拠する（LX500 の「量産」タイムテーブル、K3 の「四項第一」の具体的次元は公式ホワイトペーパー待ち）；eet-china/EDN などの原サイトはアンチクロールのため、本文の詳細は主にタイトルと複数ソースのクロスチェックに基づく；網易が孵化した北京チップ創企業が 20 億元超の B ラウンド調達を完了（36氪/智東西、8/14）は命令セット方向を確認できないため、産業資本動向の備考のみとし、本文には含めていない；本レポートの GitHub データは未認証 API（60 req/h の制限内で完了）に基づく。
