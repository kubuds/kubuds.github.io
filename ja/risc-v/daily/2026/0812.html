RISC-V デイリーレポート (2026-08-12)

2026-08-12 Kubuds

調査期間：過去 24 時間（2026-08-11 15:46 ~ 2026-08-12 08:50 北京時間） 情報源：HN、Google News アグリゲーション、CNX Software、Linuxiac、快科技、新京報、GitHub API など（詳細は付録参照）

1. オープンソースコミュニティとカーネル/リリース動向

1.1 QEMU 11.1 リリース：RISC-V ビッグエンディアン対応と K230 ボードエミュレーションを追加

日付：2026-08-12（リリース 08-11 16:11 UTC）　出典：Linuxiac（vmvirtualmachine ミラーにて検証） / Google News アグリゲーション

QEMU 11.1 は 11.x シリーズ初のメンテナンスリリースとして公開され、最大の特徴は RISC-V ビッグエンディアン（big-endian）ターゲット対応である——これは RISC-V 仕様における実行時制御可能なエンディアン（runtime-controllable endianness）能力の実装に対応するもので、Codethink は以前からこれをテーマに「リトルエンディアンアーキテクチャ上でビッグエンディアンをエミュレートする」研究を進め、QEMU をテスト基盤としてきた。RISC-V 側も同時に強化：勘智 K230 開発ボード対応を追加（Canaan K230 は RISC-V デュアルコア AI ビジョン SoC で、エッジ側ビジョンやロボティクスシーンでよく使われる）、OpenSBI を 1.8.1 にアップグレード、Tenstorrent mvendorid 対応を追加し、さらに大量の IOMMU、割り込み処理、ページテーブル走査、ベクトル命令などの低レイヤ問題を修正した。RISC-V カーネル/ディストリビューション開発者にとって、11.1 のビッグエンディアン対応は、エミュレータ上でいち早くビッグエンディアンソフトウェアスタックを検証できることを意味する。

1.2 RISC-V 公式仕様リポジトリの自動メンテナンス更新

日付：2026-08-12　出典：riscv-unified-db / riscv-arch-test

RISC-V 公式仕様側のインフラリポジトリは更新を継続：riscv-unified-db（仕様の機械可読データベース）は当調査期間内に依存関係メンテナンスのコミット 4 件（prek、mise、jetty のバージョンアップとロックファイルのメンテナンス）をマージし、riscv-arch-test（アーキテクチャ適合性テスト ACT）は Ubuntu 24.04 Docker イメージの digest を更新した。いずれも自動メンテナンス型のコミットであり、仕様エンジニアリングの通常のペースに属する。注目すべきシグナルは、RVA23.1/RVB23.1 の公開レビュー（昨日既報）が進行中であり、今後統一データベースの内容もそれに伴い更新されることである。

1.3 labwired-core：ESP32-C3（RISC-V）ファームウェアエミュレーション能力が持続的に強化

日付：2026-08-12　出典：GitHub w1ne/labwired-core

Rust で書かれた決定論的ファームウェアエミュレータ labwired-core（ARM Cortex-M と RISC-V をサポート、MCU デジタルツインと MCP server インターフェースを提供、59 stars）は当調査期間内にコミット 15 件をマージ：ATmega328P Nano ツイン（CPU + Timer0/USART）を追加、ESP32-C3（RISC-V コア）側で DHT シングルバスの C3 ツイン上でのタイミングを修正、各 BLE Pong 実験に独立チャネルを割り当ててテストのジッタを解消し、さらにリソース計測（アクセスカウント + PC サンプリング）機能を追加した。ESP32-C3 関連の作業量の比率が高まっており、RISC-V MCU が「ファームウェアレベルエミュレーション/仮想ハードウェア」ツールチェーンにおけるカバレッジを拡大していることを反映している。

2. 製品とエコシステム動向

2.1 尊界 V800 スマートシートに奕斯偉の RISC-V 車載グレード AI MCU を搭載（直近 3 日のトレンド）

日付：2026-08-10　出典：快科技 / 鳳凰網 / 新浪

鴻蒙智行尊界 V800 が正式に登場、その全主動適応智能座椅がハイライトに：精密な人体姿勢認識と動的適応調整により駕乗体験を最適化し、中核算力と AI アルゴリズム方案は奕斯偉計算が提供する RISC-V 車載グレード AI MCU EAM2011が担う。EAM2011 は国内初の軽量級 AI アプリケーションをサポートする車載グレード MCU であり、自研の 32 ビット RISC-V コアを搭載、国内の成熟したプロセス製造を採用し、コア IP、チップ設計から生産プラットフォームまでの全チェーン国産化研究開発と量産体系構築を完了している。本件は昨日の調査期間末端に位置するが（08-10 報道、昨日のレポートでは未収録）、国産 RISC-V 車載チップの規模化搭載の象徴的事例として、本日のレポートで補録する価値がある。これまでに同シリーズのチップは智能座艙の軽量化 AI デプロイシーンで見られている。

3. 国内チーム動向と深掘り

3.1 開芯紅（香山 IP 商業化主体）：シードラウンド投資家陣容が披露、国有資本＋大手産業投資が共同支援

日付：2026-08-11/12　情報源：新京報 / Google News アグリゲーション（搜狐転載、08-12 期間内）

昨日既報の開芯紅の超億元シードラウンド調達完了（資金は香山 IP コアアーキテクチャアップグレードに投入）に続き、本日投資家陣容がさらに披露された：本ラウンドは国開科創、誠通科創、中科創星、中関村科学城、啓航基金及び国泰創投等の大手産業投資機構を集めた（新京報 8 月 11 日報道、搜狐 8 月 12 日未明転載が本期間内に進入）。国開科創と誠通科創はいずれも国有資本背景のベンチャー投資プラットフォームであり、中科創星（ハードテック）、中関村科学城（北京属地）の組み合わせを加えると、香山 IP 商業化が国家級政策資本と属地産業資本の両方から支援を得ていることを示す。GitHub 側では香山エコシステムリポジトリ群（XiangShan メインリポジトリ、difftest、NEMU、GEM5、env-scripts、XSAI 等 11 リポジトリ）が 8 月 11 日に一括更新され、付随ツールチェーンも同期進化を維持し、「アーキテクチャアップグレード」路線にエンジニアリング側の支えを提供している。

3.2 奕斯偉計算：車載グレード MCU 搭載＋コンシューマ向け AI プライベートクラウド着地

日付：2026-08-10　情報源：快科技 / Google News アグリゲーション（網易） / Google News アグリゲーション（湖北省経信庁）

奕斯偉計算は今週複数の動向が重なり、「車載グレード＋コンシューマ電子」の二路線着地図景を形成している（いずれも直近 3 日の事象、昨日のレポートでは未収録）：

  • 車載グレード：EAM2011（自研 32 ビット RISC-V コア車載グレード AI MCU）が尊界 V800 智能座椅に採用、詳細は 2.1 参照；
  • コンシューマ：極空間（ZSpace）がまもなく上線する国産 AI プライベートクラウド NAS と奕斯偉が協力して構築、画像素材 AI 処理はすべてローカルで実行、クラウドへのアップロード不要、プライバシー優先定位の端側 AI シーン；
  • グループレベル：奕斯偉材料（西安奕材）が武漢奕材へ増資を計画、総調達額65 億元を 12 インチシリコンウェハ拡産に投入（湖北省経信庁披露）、2027 年に第一期生産能力の稼働を予定——グループの材料事業の資本動作に属し、計算チップ事業とは相互に独立だが、グループ全体の拡産ペースを裏付けている。

3.3 算能（SOPHGO）：SophLiteOS に AI Agent 機能を追加

日付：2026-08-12（コミット時間 08-11 21:03 / 08-12 07:15 北京時間）　情報源：GitHub sophgo/sophon-tools

算能公式ツールリポジトリ sophon-tools の調査期間内に5件のコミットがマージされた。中核となる変更点：SophLiteOS に AI Agent 機能を新規追加（pbmssm LLM 転送を含む）、および picoclaw-web-chat を AI Agent ページ内に組み込み実装（MYS-149 要件）。さらに SophLiteOS 概要ページのメモリ指標の命名を修正。SophLiteOS は算能が RISC-V 端側チップ向けに提供する軽量オペレーティングシステムであり、今回のマージにより LLM Agent 対話能力を端側システムツールチェーンに下沉させた。同社の K230/SG シリーズ RISC-V SoC と組み合わせることで、「RISC-V 端側 + LLM Agent」方向の直接的なエンジニアリング進展に位置づけられる。

4. 具身智能とロボティクス専章

調査期間内に重大な動向なし。 過去24時間の英語検索（"risc-v" robot when:3d）で調査期間内のヒットはなく、中国語検索（RISC-V 机器人/具身智能 when:3d）では車規格・産業综述系の項目のみがヒットし、具身智能/ロボティクス方向の RISC-V 強関連ニュースは発見されなかった。

直近3日間の傾向観察：この方向は先週と一致した漸進的リズムを維持している。注目すべき隣接シグナルは二つ：一つ目は奕斯偉 EAM2011 車規格 AI MCU の尊界 V800 智能座席における姿勢認識応用（2.1）。この種の「センサー知覚 + 動的対応」はロボティクス制御と智能座艙が共有する技術スタックであり、国産 RISC-V 車規格チップの落地経路は具身智能チップの参照となり得る。二つ目は算能 SophLiteOS の AI Agent 機能落地（3.3）。端側 LLM Agent 能力は RISC-V ロボットの頭脳に対してより軽量なソフトウェア基盤を提供する。進迭時空（spacemit-robotics）、楽鑫（esp32-c シリーズ）のロボティクス関連製品ラインには新たな公開マイルストーンは見られない。明日（8月13日）に第5回滴水湖中国 RISC-V 産業フォーラムが開催され、10款の国産チップが集中亮相する。具身智能関連チップの新製品は会後の追跡に値する。

5. 総括と趨勢観察

  1. シミュレータ層が RISC-V 新特性への追随を加速：QEMU 11.1 が RISC-V ビッグエンディアンサポートを落地させ、K230 ボード級模拟を新規追加、OpenSBI 1.8.1、Codethink のエンディアン研究と配合し、RISC-V ランタイムの制御可能エンディアンが規範から検証可能なツールチェーン経路へと向かう閉環が進行中。
  2. 国産 RISC-V 車規格チップの規模化搭載：奕斯偉 EAM2011 が尊界 V800 智能座席に進出、極空間 AI プライベートクラウドとの叠加により、奕斯偉系は車規格と消費電子の両端で同時に「RISC-V+AI」の製品化を実現。
  3. RISC-V 端側 OS が LLM Agent を内蔵開始：算能 SophLiteOS が AI Agent と LLM 転送機能をマージ、端側大規模モデルアプリケーションスタックが RISC-V エコシステムへ浸透。
  4. 香山 IP の商業化が政策資本の裏付けを獲得：開芯紅シードラウンドの投資家として国開科創、誠通科創などの国資機構が披露され、一次市場における国産高性能 RISC-V IP への認可度が持続的に向上。
  5. 制限事項の説明：24時間の調査期間内は国際的な重報ニュースがやや少なく（QEMU 11.1 が最も顕著）、国内動向は GitHub コミットと転載メディアに多く依存。極空間、武漢奕材などの項目は Google News アグリゲーションリンクのみ引用可能（原サイト本文は直接クロール不可）。尊界 V800 の詳細は快科技/鳳凰網/新浪のマルチソースでクロスチェック。具身智能専章は調査期間内に直接ニュースなし、関連判断は隣接方向からの推論に基づく。
