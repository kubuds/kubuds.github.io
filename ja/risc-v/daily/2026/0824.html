1.1 Sedna：純 Java RISC-V シミュレータが開発再開、マルチアーキテクチャフレームワークへ進化（08-23）

日付：2026-08-23（README 更新 23:11 北京；開発は 08-21 から活発化）　出典：github.com/fnuecke/sedna

2020 年に誕生した純 Java RISC-V シミュレータ Sedna（rv64imacfd + Zifencei、S 態をサポート、Linux をブート可能、riscv-tests の全ケースを通過、マシン状態のシリアライズをサポート、Maven Central で公開）が本期間に活発な開発を再開：作者は旧 Z80 シミュレータを Sedna フレームワークへ移行（命令デコーダジェネレータの汎用化、ディスクデバイスの移行、Z80 ボードの接続）し、README を 08-23 23:11（北京時間）に更新。プロジェクトの位置づけは「単一アーキテクチャの RISC-V シミュレータ」から「マルチアーキテクチャシミュレーションフレームワーク」へと進化しつつある——デコーダジェネレータはすでに Z80 の概念実証にも同時に提供されており、JVM エコシステムにおける RISC-V シミュレータの選択肢（QEMU 以外）はこれにより活発にメンテナンスされる補完を得た。

1.2 Arduino ESP32 コアに OTA ファームウェア SHA-256 オプション検証を追加（08-24）

日付：2026-08-24（03:38 北京、committer 時間）　出典：espressif/arduino-esp32 PR #12824

楽鑫の arduino-esp32 コアに feat(update): add optional SHA-256 checksum for incoming firmware (#12824) がマージ：OTA 更新フローにオプションのファームウェア SHA-256 検証を追加し、ファームウェアの完全性検証を強化（ダウンロード破損/改ざんの防止）。ESP32-C シリーズ（C3/C5/C6/C61 などの RISC-V コア）と Xtensa シリーズのいずれも恩恵を受け、楽鑫ソフトウェアエコシステムの定例的な堅牢化に属し、破壊的変更はない。

3. 国内チーム動向と深掘り

3.1 香山：COVE 機密計算 MMU パスの2件の修正がマージ（08-24）

日付：2026-08-24（00:02 北京時間、committer 時間）　情報源：OpenXiangShan/XiangShan PR #6299、PR #6300

調査期間内に香山メインリポジトリで2件のコミットがあり、いずれも COVE（機密仮想マシン拡張、Confidential VM Extension）の MMU 実装を対象としている：

  • #6299 fix(MMU, COVE): reject out-of-range Smmpt addresses：従来、43ビットアドレス範囲を超える Smmpt43 リクエストが MPTCache に拒否されず、cache miss として miss queue/table walker に送られ、access fault を返さなかった。修正では Smmpt43 / Smmpt52 の PA 幅と各モードの最大合法 PPN（43ビット：0x007fffffff；52ビット：0xffffffffff）を定義し、stageCheck パイプライン段でリクエスト PPN を検証、範囲外リクエストは respHit 経由で accessFault を返し、respMiss を抑制してテーブルウォークを防止、さらに range fault 時に permission / NAPOT / 連続権限 / MPT レベルメタデータをクリアし、cache flush 時に range-fault レジスタをクリアする；
  • #6300 fix(MMU, COVE): fix bug for mpt miss queue：MPT miss queue の現行実装が Decoupled プロトコルに違反している（twReq.valid が ready でゲートされていない）。機能的なリクエスト損失は観測されていないが、プロトコルに従い修正。

意義：香山は RISC-V オープンソース高性能プロセッサの中で、CoVE/MPT（メモリ保護テーブル）機密計算路線を推進する数少ないプロジェクトである。2件の修正はいずれも「プロトコル準拠性の作り込み」の性質を持ち、その COVE 実装が機能開通を越えて詳細収束段階に入ったことを示す——最近の「性能収尾期」の全体的なリズム（分岐予測/AIA などの大項目収束後の細かい作業段階）と一致している。
