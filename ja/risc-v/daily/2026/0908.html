1. オープンソースコミュニティとソフトウェアエコシステム

1.1 Canonical が企業向けオープンソース RISC-V ソフトウェア就緒度を詳解：Ubuntu riscv64 パッケージ通過率 55.1%（09-07）

日付：2026-09-07（ServeTheHome 月曜公開、ウィンドウ入り時間 09-08 01:00 北京時間）　出典：ServeTheHome

ServeTheHome が Hot Chips 2026 講演録を追記：Canonical シリコンバレー提携ディレクター Gordan Markus 氏が Ubuntu のマルチアーキテクチャビルド機構と RISC-V 企業向け就緒への道筋を体系的に解説し、定量化されたギャップデータを示した——Ubuntu 26.10 テストスナップショットでは riscv64 の全 3,443 パッケージがテストを受け、1,898 が通過、通過率は約 55.1% で、amd64 の約 92% を大きく下回る。Canonical はこの差をエミュレーションビルドとテスト対象に一部帰因させ（実行時間が数時間から数日に延伸）、ネイティブ RISC-V ビルドマシンを導入済みで、パートナーがサーバー級 RVA23 プラットフォームを提供している。オープンソース協業側：Canonical は RISC-V International の RISE プロジェクト（モバイル、コンシューマエレクトロニクス、データセンター、自動車向け商用ソフトウェア就緒）に参画し、その Ubuntu 24.04 ネイティブ RISC-V runner が Scaleway Elastic Metal でホストされるビルドとボードファームを支え、Alibaba と進迭時空（SpacemiT）のハードウェアを使用、累計 116 組織、24,000 タスク、70 万分のビルド量を達成している。Canonical の中核的判断は：RVA23 スタイルのプロファイルによりソフトウェアターゲットが予測可能になり、大規模なアップストリーム協業と組み合わせることで、新 ISA のオープンソース採用を遅らせてきた歴史的な「ソフトウェア就緒ギャップ」を乗り越えられる；今後2年でサーバー級 RVA23 ハードウェアが順次登場すれば、ソフトウェアスタックに固定された収束ターゲットができる。これはウィンドウ内で企業向け RISC-V ソフトウェアエコシステムに関して最もデータ価値の高い一條である。

1.2 香山：新ベクトルバックエンド vfma パス再構築とワイド命令サポートをバッチで着地（09-07）

日付：2026-09-07（16:19~17:33 北京時間バッチ）　出典：GitHub openxiangshan/XiangShan commits

香山オープンソース高性能コア（昆明湖）ベクトルバックエンド再構築が継続的に推進中：09-07 午後バッチで feat(vfma)「support vfma in new vector backend」、feat(vector, vfmac) の pipeline レジスタ再構築と widen 命令サポート、fix(vector) の vfma pipe metadata 初期化がマージされ、新ベクトルバックエンドの実行経路がレジスタ全体移動（昨日のバッチ）から浮動小数点積和演算（vfma/vfmac）と加寬演算へと延伸したことを示す。同バッチには bypass レディと非レジスタソース修正、LoadQueueReplay の非整列 head 遅延ウェイクアップ処理、ROD エンコーディング整列修正（#6509）と FFlagsWen テーブルへの VFREC7_V/VFRSQRT7_V 追加も含まれる。前日の vialu/mgu 接続とベクトル寬窄命令サポートと合わせて判断すると、香山ベクトル実行サブシステムの再構築は「命令機能補完—経路データフロー修正—浮動小数点行列演算接続」の順序で推進されており、エンジニアリング成熟度は持続的に向上している。本調査期間にリリースはない。

1.3 CVA6：修正範囲が RV32/64 命令合法性に拡大、仮想化とメモリ保護は研磨を継続（09-07~08）

日付：2026-09-07 20:18 ~ 09-08 05:36（北京時間、9 コミット）　情報源：GitHub openhwgroup/cva6 commits

OpenHW Group のアプリケーション級オープンソースコア CVA6 は、調査期間内にバッチ修正のマージを継続し、対象範囲は昨日からさらに拡大した。新たに命令意味論の合法性の次元を追加——zip/unzip は RV32 のみ合法で、RV64 は不正としてデコードすべき（#3527）、RV64-only の FCVT を RV32 上で不正使用することを拒否（#3540)、mstatus.MPP が RVH=1 時に予約値 2’b10 を合法化する；仮想化とメモリ保護経路は昨日のテーマを継続——ptw は HLVX 規則が VS-stage PTE 読み取りの G-stage チェックに適用されないことを修正、PMPADDR63 の範囲外アクセス修正（#3485）；さらに C 拡張無効時の misaligned branch 回帰テスト（#3424）、偽 4 KiB エイリアス回帰テスト（#3453）と debug ループ共有ポインタの範囲外修正を追加。連続二日で合計 15 を超えるコミットとなり、仮想化の二段階アドレス変換と PMP セキュリティ経路の研磨は高頻度期に入っており、RISC-V オープンソースアプリケーションコアの品質保守リズムを観察するシグナルとなり得る。

2. 製品とエコシステムの動向

2.1 YuzukiHD が YuzukiNeko をオープンソース化：Allwinner F101（達磨院玄鉄 C907）Pico サイズの Linux ボード（09-08）

日付：2026-09-08　情報源：CNX Software、YuzukiHD/YuzukiNeko GitHub

オープンソースハードウェアチーム YuzukiHD が新ボード YuzukiNeko を発表：Raspberry Pi Pico サイズ（約 51 x 21 mm）の Linux シングルボードコンピュータで、全志の新型 SoC Allwinner F101「スマートコントロール・ディスプレイプロセッサ」を搭載。F101 はシングルコアの達磨院玄鉄 C907 RISC-V コア（1.008 GHz、32 KB I-cache + 16 KB D-cache）を採用し、QFN-68 パッケージ、SiP で 8 MB（F101S2）または 16 MB（F101S3）の PSRAM（252 MHz）を統合、ディスプレイエンジン（RGB888 720p、シングルリンク LVDS 1366x768、4 チャネル MIPI DSI 1280x800）、大サイズ JPEG/PNG デコード、USB 2.0 DRD と 512 bit eFuse を統合。オンボードには 128 Mbit SPI NOR + microSD、USB-C（データ/電源/書き込み）、デュアル 20-pin GPIO 拡張ヘッダと FEL ボタンを搭載。ソフトウェア側では YuzukiHD が GitHub で回路図、EasyEDA プロジェクト、Gerber、3D STEP と BOM をオープンソース化し、mainline Linux 7.2 ベースの sun252i_f101 ブランチ、Buildroot 外部ツリーおよび Zephyr RTOS サポート（Linux と Zephyr のデュアルシステム）を提供。Whycan フォーラムの情報によると F101 SoC の単価は約 18 元人民幣（約 2.7 ドル）で、コミュニティはボード全体の販売価格が 10 ドル未満になることを期待している。ボードはまだ販売開始されていない。意義：達磨院玄鉄 C907 は D1 系（C906）に続き、再び中国本土 SoC に大規模かつ低コストで採用され、超低価格「Linux/Zephyr デュアルシステム」RISC-V マイクロボードエコシステムのさらなる拡大が見込まれる。

3. 国内チームの動向と深掘り

日付：2026-09-07（14:29~22:55 北京時間）　情報源：XUANTIE-RV/damo-rv-priv-ats commits、XUANTIE-RV/thead-extension-spec commits

達摩院玄鉄の公開リポジトリは月曜日の静寂の後、反復を再開した。調査期間内の 2 リポジトリで合計 4 コミット：特権アーキテクチャリポジトリ damo-rv-priv-ats は 09-07 22:55 に「add Hypervisor_Za* tests」（#27）をマージし、hypervisor モード下のアトミック系命令（Za* シリーズ）にテストを新規追加した；拡張仕様リポジトリ thead-extension-spec は 14:29~14:48 に PR #77（XTheadCmo 拡張）をマージ：clean set/way 操作と th.dcache.isw 命令の範囲を L1 D-cache に厳格化し、このキャッシュ管理操作拡張があくまで L1 セマンティクスにのみ作用することを明確化した。いずれの動向も仕様の細分化とテスト補強の性質であり、「拡張定義—テスト検証」という通常のリズムに属し、新たな製品級のシグナルはない。なお付記：海外メディアは 09-07 時点でも Geeky Gadgets などが「C950 無 GPU で Qwen 3.8 を動作」（タイトルに Reportedly 付き）を転載しているが、照合の結果これは 08-18 Day 0 適合の公式発表（本レポート 08-19/20 で詳報済み）の遅れての反響であり、新事件ではないため項目として別掲しない。

3.2 総合期間観察：算能/進畳/矽速は定例反復、ニュース側は国内チーム全体的に静寂（09-07/08）

4. 具身智能とロボティクス専章

4.1 期間観察：新規動向なし、09-09 深圳 IICIE 具身智能産業大会が明日開幕（09-07/08）

日付：2026-09-07/08

本期間、RISC-V 具身智能/ロボティクス方向には新製品発表と重大イベントはない。補足クエリ「具身智能 RISC-V when:7d」のヒットはいずれも期間外の予熱と業界横断的コンテンツ（09-02 電子工程専輯深圳三展連動予熱、09-05 復旦 MBA 張江ロボット谷視察など）であり、実質的な新項目はない。観察点は不変：09-09 から深圳 IICIE 国際集成電路創新博覧会（14 号館 RISC-V 産業生態創新大会、15 号館 2026 具身智能産業大会）が開幕し、智能汽車 x 具身ロボットの三展連動（09-09~11）が重なり、達摩院玄鉄/算能/進畳時空などが出展する。明日から国内 RISC-V x 具身動向の実現を観察する窓口に入る。

5. 総括とトレンド観察

本レポートの調査期間は通常活発日（平穏日ではない）：オープンソースコミュニティ側では企業級準備度を定量化した報道1件と2つのオープンソースコアの継続的コミット、製品側では玄鉄コアの低コスト採用に関するハードウェア項目1件、国内チームの GitHub は反復を再開したがニュース側は静かであった。要点は以下の通り：

1つ目に、企業級ソフトウェア準備度が「定量化可能な検収」段階に入った。Canonical は Hot Chips の追加講演で riscv64 パッケージ通過率 55.1% 対 amd64 92% という定量的差距を公開し、原因を明確にシミュレーションビルドのボトルネックに帰し、解決策はネイティブビルドマシンと RVA23 profile の収束である——RISC-V サーバーソフトウェアの物語は「動く」から「検収可能」へと転換しつつあり、RISE プロジェクトと 24,000 タスク級ビルドファームの存在は上流の投入がすでに規模を持っていることを示している。

2つ目に、オープンソースコア再構築の主旋律が継続。香山の新ベクトルバックエンドは全レジスタ移動（09-06）から vfma/vfmac 浮動小数点積和と widen 命令（09-07）へと進み、実行パスの機能補完のリズムは明確である；CVA6 は2日連続で 15+ の修正を行い、カバー範囲は仮想化/PMP から RV32/64 命令合法性へと拡大し、マルチアーキテクチャの意味的正しさの研磨が新たな注目点となっている。

3つ目に、達磨院玄鉄エコシステムの「上探・下沉」双方向拡張。上探側では C950 が GPU なしで Qwen 3.8 を動かす 8 月の公式発表が依然として海外メディアで遅れて反響を呼んでおり、物語の伝播周期が終わっていないことを示している；下沉側では C907 が 18 元人民元級の Allwinner F101 SoC に採用され、YuzukiHD のオープンソースボードと Linux/Zephyr デュアルシステム対応を伴い、玄鉄コアのライセンスは超低コストマイクロボード市場でのカバー範囲を拡大し続けている。

4つ目に、前瞻ウィンドウ：09-09 に深圳 IICIE が開幕し、同時期に RISC-V 産業生態革新大会と具身智能産業大会（14/15 号館）が開催され、三展連動のスマートカーとロボットテーマが重なり、今週中盤の国内 RISC-V 動向は明らかに回暖すると予想され、明日のレポートで重点的にフォローする。

局限性の説明：GitHub 非認証 API のレート制限（60 req/h）下では、org 核查は pushed_at 順で最近活発なリポジトリを抽出確認し、spacemit-com の非デフォルトブランチへのプッシュ、低活発リポジトリのコミットは漏れる可能性がある；香山/CVA6/各ベンダーのコミット内容は commit message のタイトルのみで判断し、コードの詳細を逐一照合していない；Canonical の通過率とビルドファームのデータは ServeTheHome の講演実録からの転載であり、Ubuntu 公式の独立データによる相互検証は経ていない。
