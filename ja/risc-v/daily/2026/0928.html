今日の重点：奕斯偉計算が香港IPOの公募を開始、約3億ドルの調達を予定、10月8日上場見込み

日付：2026-09-25　出典：南華早報「Chinese RISC-V chipmaker Eswin seeks US$300m in Hong Kong IPO ahead of October debut」（09-25）、The Standard「ESWIN Computing Technology eyes US$300m HK IPO」（09-23）、ChipNews「Eswin edges toward the first RISC-V listing in Hong Kong」（09-25）

南華早報の09-25報道によると、北京奕斯偉計算は今週月曜日（09-28、すなわち今号の発行日）から機関投資家および一般投資家向けの公募を開始し、約3億ドル（約23.4億香港ドル）の調達を目標とし、10月8日に香港証券取引所での上場取引を予定している。共同主幹事は中信証券（香港）と中信建投国際。同社はすでに香港証券取引所の上場ヒアリングを通過しており（本誌09-21号で既報）、上場前の最終プロセスが正式に始動した。

財務面では、招股説明書によると2025年の売上高は24.31億元人民元（前年比約20%増）、通年の純損失は15億元——「増収が続き、損失は縮小中」という曲線は、国際投資家による価格決定の検証を受けることになり、これも RISC-V チップのビジネスモデルの成色を観察する重要なサンプルとなる。

発行が順調に進めば、奕斯偉計算は香港市場で初の RISC-V を主業とするチップ上場企業となり、この分野の上場銘柄の空白を埋め、「RISC-V エコシステム企業のバリュエーションアンカー」に公開市場の参照を提供することになる。発行規模、価格設定、応募熱は市況により調整される可能性があり、最終的には正式な公告による。本誌は10月上旬に上場結果を追跡する。

1.1 香山：feat-pdb プリフェッチデータバッファ昇格のゲート付きマージ、XSCache「Oceanus」L2 をさらに 4 件修正

キャッシュサブシステム XSCache「Oceanus」（L2 開発ブランチ）はさらに 4 件を修正、いずれも CHI コヒーレンスパイプラインの境界修正である：EvictBack フィールド代入の補完、データ分離応答段階になってから CompAck を待機、L2VPipeSNP が全ライトバック種別とリトライをサポート、リトライパスのリーク状態クリア。このブランチは 09-23 号で 20 件のコミットを収録しており、今号は修正収束の継続である。

日付：2026-09-26 から 09-27　情報源：GEM5 コミット：予測式ストリーム深度コントローラの選択（09-27）、GEM5 コミット：BDP 昇格ヒステリシスの強化（09-27）、GEM5 コミット：H2P 有効准入率の統計（09-27）、GEM5 コミット：H2P バッファメタデータライフサイクルの厳格化（09-26）、GEM5 コミット：ベクトルレジスタリネーム panic の修正（#1185）、NEMU Release v2026.09.r18（09-25）

GEM5 の 2 つの開発ブランチは週末に合計 31 件の実験コミットを推進した：feat-ywl-pfbuffer は 1 日で 20 件、BDP（帯域遅延積）ストリーム深度適応コントローラ群を構築——予測式ストリーム深度コントローラの選型から、トレンド予測の拡張・厳格化・ダンピング、さらに昇格ヒステリシス（hysteresis）と位相変化適応フィルタまで；apf-align は 11 件、H2P プリフェッチバッファの准入とライフサイクルモデリングを中心に：エントリはコミット時に保持し resolve 時に解放、TAGE の弱信頼度でゲート付きに候補を割り当て、さらにアイドル周期統計、有効准入率、弱信頼 A/B スイッチを補完した。デフォルトブランチ（xs-dev）はベクトルレジスタリネームの panic を 1 件同時修正した（#1185）。

NEMU は 09-25 に v2026.09.r18 をリリースした。それ以前にマージ済みの share-ctrl CUTE AMU コールバックの完善をカプセル化し（#1225、本紙前号ですでに当該コミットを収録済み）、あわせて xs／xs-dual と ref／ref-debug の組み合わせの事前ビルド成果物を定例提供した。9 月のローリングリリースのペースは第 18 版まで維持されている。

2. 製品とエコシステムの動向

2.1 ESP-Mosaico：Espressif ESP32-S31 モジュラ開発キットがメディアで詳解

日付：2026-09-27　情報源：LinuxGizmos「ESP-Mosaico centers dual-core RISC-V ESP32-S31 around a 2.16-inch square AMOLED」（09-27）、Espressif 公式発表稿（08-19）、ESP-Mosaico 公式ドキュメント

LinuxGizmos が記事を掲載し、楽鑫 ESP-Mosaico——AI Coding（コード知能エージェント）向けの拡張可能な知能インタラクション開発キット（公式 08-19 リリース、今回は外媒による詳細の補足）を詳解：メインコントローラ ESP32-S31NRV16（デュアルコア 32 ビット RISC-V @320MHz、16MB オンチップ PSRAM）を搭載し、2.16 インチ 480×480 方形 AMOLED タッチスクリーン、オーディオコーデックとパワーアンプ、六軸 IMU、デュアル磁力計、SPI NAND と触覚フィードバックを備え、左右 2 つの 2×10P モジュールインターフェースが磁吸式の拼接拡張をサポートする。ソフトウェア側は Chat Coding／Vibe Coding の 2 つのパス（内蔵 ESP-Claw デバイス側 Agent）で BSP と esp-mosaico サンプルプロジェクトを組み合わせる。前号で収録した ESP32-S31 Linux 移植の進展と呼応し、楽鑫は S31 をチップから「キット＋フレームワーク」の製品化段階へと推し進めている。

2.2 LILYGO T-Dongle-C5：ESP32-C5 デュアルバンド Wi-Fi 6 USB ドングルが全面報道を獲得

日付：2026-09-27　情報源：CNX Software「LILYGO T-Dongle-C5 – An ESP32-C5 USB dongle with microSD card slot, optional 0.96-inch OLED」（09-27）

CNX Software が記事を掲載し、すでに全面発売されている LILYGO T-Dongle-C5（ESP32-S3 版 T-Dongle-S3 を承接）を概観：メインコントローラ ESP32-C5HR8（シングルコア RISC-V @240MHz に 40MHz 低消費電力コアを加算）、デュアルバンド Wi-Fi 6、BLE 5.0 と 802.15.4（Zigbee／Thread）をサポート、16MB flash／8MB PSRAM、USB-A 直挿し形態、オプションで 0.96 インチ IPS スクリーン、microSD カードスロットと Qwiic 拡張；公式ストアは 13.02 ドルから。コミュニティではすでに ESP32 Marauder ペネトレーションテストファームウェアなどの移植が登場し、エコシステムの活発度が上昇している。ESP32-C5 は楽鑫の RISC-V 製品ラインに属し（前世代 S3 は Xtensa）、今回の反復は体験と形態の両面で意義を持つ。

2.3 ロシア K1921VG10Ya：デュアルコア RISC-V MCU が 13×13mm BGA パッケージに換装

日付：2026-09-25　情報源：kit-e.ru「Микроконтроллер К1921ВГ10Я в корпусе BGA」（09-25）、mforum.ru：К1921ВГ1Т 新パッケージ報道（09-24）

ロシアの GS Nanotech と НИИЭТ（電子技術研究所）が、デュアルコア RISC-V マイクロコントローラ K1921VG1T の小型パッケージ版（K1921VG10Ya）のパイロットバッチパッケージングを完了：LQFP-208（28×28mm）から BGA216（13×13mm） に変更し、PCB 占有面積を最大で約 5 分の 1 に縮減、チップ仕様は不変——デュアルコア RISC-V @204MHz、lockstep をサポート、4MB Flash、1MB SRAM、内蔵ギガビットイーサネット PHY とハードウェア暗号化（AES およびロシア標準「Кузнечик／Магма」）、産業オートメーションと組み込み向け。報道によればパイロットの歩留まりは良好で、両社はすでに量産パッケージング能力を備えている。国際 RISC-V MCU のパッケージ形態は引き続き豐富化している。

3. 国内チームの深耕

3.1 算能：16 のリポジトリを集中プッシュ、84x6（CV84x6）新プラットフォームと 88a2 プラットフォームサポートが実現

日付：2026-09-26 から 09-27　情報源：sophgo/build コミット：84x6 と 88a2 設定を追加（09-26）、sophgo/osdrv コミット：84x6 サポートを追加（09-26）、sophgo/osdrv コミット：2D エンジン更新（09-27）、sophgo/bootloader-arm64 コミット：84x6 サポート（09-26）、sophgo/sophon_media コミット：84x6 サポート（09-26）、sophgo/libsophav コミット：libsophav 更新（09-26）

算能 GitHub 組織の調査期間内に 16 のリポジトリが集中的にプッシュされ（edge_dev 開発ブランチが中心）、核心はコードネーム 84x6（CV84x6）の新プラットフォーム向けにソフトウェアスタックを展開することにある：build リポジトリには一式のボードレベル設定が追加された——FPGA ターゲット（edge_84x6_fpga）、Palladium ハードウェアエミュレーションターゲット（edge_84x6_palladium_c906、RISC-V 側デバイスツリー soph_base_riscv.dtsi、cv84x6_palladium_c906.dts と hart1–4 メモリマッピングスクリプトを含む）、および EVB 量産ボードターゲット（edge_84x6_wevb_emmc、se13v1 シリーズデバイスツリーと BGA ボードレベル初期化を含む）；osdrv には 84x6 ドライバサポート（interdrv シーケンス、ISP／監視 HAL、spacc、uapi 定義）が追加され、2D エンジンも更新された；bootloader-arm64、sophon_media、libsophav（vglite ライブラリを新規追加）も同時に適応した。同バッチではさらに 88a2 プラットフォーム（BM1688／CV186AH 系）向けに buildroot／fastboot とエミュレーション設定が補完された。

FPGA、Palladium エミュレーション、EVB ボードの 3 種類のターゲットが並存しており、新プラットフォームがソフトウェア適応と検証段階にあることを示している（リリースのペースは公式の開示による）。前期の算能の定常的なプッシュと OrangePi O1 シングルボードのニュースを合わせると、その「新チップ—SDK 先行」というエンジニアリングのリズムは明確である。算能は RISC-V エコシステムの重要なメンバーである（BM1688 などの SoC に RISC-V コプロセッサを内蔵）。

3.2 達摩院玄鉄：DAMO-RV-ATS テストスイートにベクトル固定小数点とメモリアクセステストを追加

日付：2026-09-25 から 09-27　情報源：DAMO-RV-ATS コミット：ベクトル固定小数点命令テスト（#4）（09-25）、DAMO-RV-ATS コミット：ベクトルメモリアクセステスト（#5）（09-27）、DAMO-RV-ATS コミット：README リソースリンク（#3）（09-25）

達磨院玄鉄がオープンソース化した RISC-V 命令互換性検証フレームワーク DAMO-RV-ATS は、調査期間内に 3 件の PR をマージした。ベクトル固定小数点命令テスト(平均加減算系 vaadd／vaaddu／vasub／vasubu など、固定小数点テスト共通ライブラリを併設)とベクトルメモリアクセステストスイート(メモリアクセスディレクトリを新設し、vle シリーズのロード、fault-only-first、セグメント型メモリアクセス、ストライドおよびインデックスアドレッシングなど数十のテストケースをカバー)を追加し、さらに中英語 README とアーキテクチャ関連リソースを補足した。このスイートは RVV 1.0、Zvbb、Zvbc 向けの計 200 命令テストケース(README 記載)に対応し、互換性リグレッションと自動ランダムテストに用いられる。本誌 09-15 号では玄鉄の「仕様とテスト」投入ラインにおいて同リポジトリに言及した。今回はベクトルカバレッジの実質的な拡充であり、その「拡張定義—テスト補強」という段階的パターンを継続するものである。

3.3 楽鑫：esp-idf は調査期間内に 7 件をマージ、esp-hosted-linux リポジトリは継続的に推進

日付：2026-09-25　情報源：esp-idf コミット：mbedTLS 分割ハンドシェイクオーバーフロー修正(09-25)、esp-idf コミット：NimBLE バインディング超過時の LFU 淘汰(09-25)、esp-idf コミット：WPS registrar ヒープリーク修正(09-25)、esp-idf コミット：lwIP NAPT IPv6 範囲外アクセス修正(09-25)、esp-hosted-linux コミット：Linux 6.12+ ビルド互換(09-25)、esp-hosted-linux リポジトリ

esp-idf は調査期間内に 7 件をマージし、セキュリティと安定性を中心とした：mbedTLS 動的バッファの分割ハンドシェイクシナリオにおけるバッファオーバーフロー、lwIP NAPT の IPv6 範囲外アクセス、softAP 下の WPS registrar の反復ヒープリークを修正した。NimBLE はバインディング数が上限を超えた際に LFU(最長時間未使用かつ最少使用)デバイス淘汰戦略を新設した。ほかに HTTP server の errno 処理と CI 期待値の調整がある。エンジニアリング側では、09-02 に新設された esp-hosted-linux リポジトリが 3 日間で 3 件を推進した：Linux 6.12+ ビルド互換と警告整理、統合と復旧パスの堅牢化、MR ガバナンスの厳格化。上述の投入は ESP32-C／S シリーズ RISC-V 製品ラインを含む全シリーズチップをカバーする。

4.1 睿芯高光 D35：数貿会で正式量産発表、多分野企業と集中契約

日付：2026-09-25　情報源：搜狐・中関村在線「全球首款RISC-V数据流物理AI芯片高光D35正式量产 数贸会首发首秀引关注」(09-26)、京報網「第五届数贸会今日开幕 全栈自研物理AI芯片全场景亮相杭州」(09-23)

9 月 25 日、蘇州睿芯は第 5 回全球数字貿易博覧会の「初公開初上演」ステージにおいて 高光 D35 の正式量産発表を行った。同チップは「データフロー＋RISC-V」のデュアル自主路線(メーカー説明：世界初の RISC-V アーキテクチャデータフロー物理 AI チップ)に位置づけられ、会場では智慧園区、智慧交通、医療健康、具身知能、デジタル科技など多分野の企業とエコシステム協力枠組み協定を締結し、業界ソリューションを共同開発する。チップの要点(メーカー説明)：全自研高性能 RISC-V CPU コア(IP は Intel 全球調達体系の認証を取得済み)、単チップ最大 128GB 高速ビデオメモリ、Chiplet 柔軟構成、ソフトウェアスタックは CUDA 互換コンパイラ、Triton および vLLM／SGLang などをサポートする。本誌 09-21 から 09-24 号では同社の数貿会出展と啓元ロボット算力協力の動向を継続的に追跡してきたが、今回は量産発表とエコシステム契約の着地ノードである。

その他のロボット側：進迭時空 spacemit-robotics などのリポジトリは調査期間内にプッシュなし；会員企業公式サイトの巡回では具身知能関連の実質的更新は見られなかった。

5. 総括とトレンド観察

  • 資本化の最終段階へ：奕斯伟計算が 09-28 から公開募集を開始し、10 月 8 日の上場を目指す——「RISC-V 第一株」が公聴のナラティブから発行の実務へ移行；価格設定と申込の熱気は、この分野の評価額に公開市場の参照点を提供し、その「増収と損失縮小」の曲線を直接検証するものとなる。
  • 国産新ハードウェアプラットフォームのソフトウェアスタックが先行：算能 CV84x6 が 16 のリポジトリで集中的に展開（FPGA／Palladium シミュレーションと RISC-V C906 側の設定を含む）、乐鑫 S31 はキット（ESP-Mosaico）から Linux ホスト側（esp-hosted-linux、buildroot）へと二本立てで推進——「新プラットフォームのソフトウェアスタックを先に整備する」ことは、すでに国内メーカー共通のリズムとなっている。
  • 香山系のキャッシュとプリフェッチが週末開発の重心：GEM5 の 2 日間で 31 件の実験（BDP ストリーム深度制御、H2P 准入とライフサイクル）に、香山 feat-pdb のゲーティングと XSCache Oceanus の修正が加わり、キャッシュ／プリフェッチサブシステムは依然として昆明湖 v3 の性能攻略の方向性である。
  • エコシステム基盤の厚みが増す：达摩院玄铁 DAMO-RV-ATS がベクトル固定小数点とメモリアクセスのテストを拡充、felix86 は 1 週間で十余件の互換レイヤーを打磨、rv32emu は Linux イメージビルドを改善——「検証」と「互換」の両端で継続的に投資が行われている。
  • 要注意：openRuyi 2026.09 バージョンは依然として未リリース；芯来、进迭时空、矽速、revyos、Radxa Linkr、奕斯伟計算などは GitHub 側の調査期間内にプッシュなし；会員公式サイトの巡回では実質的な動きなし。次号の注目点：奕斯伟の価格設定と 10 月 8 日の上場、算能 84x6 の公式発表、openRuyi 月次版、香山プリフェッチラインのマージ動向。
