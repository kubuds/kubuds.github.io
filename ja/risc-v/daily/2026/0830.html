1. オープンソースコミュニティとソフトウェアエコシステム

1.1 開放原子紫金専区 OPC インキュベーション行動計画が始動、RISC-V オープンソースチップ産業イノベーションセンターが蘇州で試験展開

日付：2026-08-28　出所：人民網江蘇チャンネル、新華報業網、名城蘇州

8 月 28 日、「オープンソースで勢いを集め・知能で共生する」をテーマとした 2026 オープンソース創新生態大会が蘇州で開催され、開放原子紫金専区 OPC インキュベーション行動計画が正式に発表された：JSopen を中核デジタル基盤とし、「蘇州呉中＋南京雨花」の双センター連動に依拠して、全国初の人工知能 OPC 専門オープンソースインキュベーションコミュニティを構築する。会場では OPC プロジェクトインキュベーションセンターの除幕と 16 社の初回入居プロジェクトの調印（AI 大規模モデル、具身知能、医療テクノロジーをカバー）が完了し；紫金オープンソース OPC 創新投資者聯盟が始動し江蘇雲途開元創業投資基金が除幕された（計画総規模 10 億元以上を下回らない OPC 産業ファンドマトリクス、南京雨花台区と共同で 3000 万元の AI マイクロシード基金を設立）。RISC-V と直接関連するのは：RISC-V オープンソースチップ産業イノベーションセンターが五つの省級オープンソースエコシステム創新プラットフォームの蘇州試験展開の一つとして正式に始動し、他にオープンソース OpenHarmony 応用創新センター、紫金オープンソース AI 賦能センターなどが同時に着地；科沃斯八界オープンソース智創空間、博雲 BoHub コミュニティ、三大学のオープンソース創新実験室が除幕され、第 8 回世界キャンパス人工知能アルゴリズム精英大賞（AI＋オープンソース）も同時に始動した。この出来事は 08-28 当日に着地し、08-30 早朝に複数のメディアで転載され、江蘇のオープンソース産業政策と RISC-V エコシステムプラットフォーム構築の重要なシグナルである。

1.2 OpenTitan オープンソースセキュリティチップがスペイン語テックメディアで特集報道、量産展開の背景を振り返る

日付：2026-08-29　情報源：Desde Linux、lowRISC OpenTitan News、Google Open Source Blog

スペイン語テックメディア Desde Linux は 08-29、Google OpenTitan の特集記事を掲載し、世界で最も活発なオープンソースシリコンプロジェクト（RISC-V Ibex コアをベースとするオープンソースのセキュリティ信頼のルート RoT チップ）を紹介した。同記事は科学解説寄りだが、背景情報は記録に値する。OpenTitan は 2025-02 に Nuvoton により量産され、Chromebook で初の量産展開を果たしており、ポスト量子暗号（SLH-DSA PQC セキュアブート）をサポートする初のオープンソース RoT である。2026 年中に Real Intent、Cadence が相次いでツールパートナーとして参加し、オープンソースシリコンのサインオフと検証のチェーンを強化しており、コミュニティの総コミット数は 3.3 万件を超える。調査期間内に OpenTitan の新バージョン／新イベントはなく、オープンソースシリコンエコシステムの継続的な浸透の参考として収録する。

2. 製品とエコシステムの動向

2.1 賽昉昉・天枢-100 が正式に納入：国内でいち早く納入可能な状態に達したサーバー級 RISC-V CPU IP

日付：2026-08-27（追加収録）　情報源：新浪科技/快科技、騰訊新聞、賽昉科技公式サイト

快科技 8 月 27 日の報道：賽昉科技はサーバー級 RISC-V HPC CPU コア設計昉・天枢-100（Dubhe-100）の正式納入を発表した——これは国内でいち早く納入可能な状態に達したサーバー級 RISC-V CPU IP であり、すでに顧客に採用されサーバーチップ開発段階に入っており、国産 RISC-V 高性能計算 IP の空白を埋めるものである。主要仕様：性能は Arm Cortex-A78 に対抗し、整数 IPC は SPECint2006 で 15/GHz に達する。深いアウトオブオーダー実行、15 段パイプライン、6 発行幅、256 命令のアウトオブオーダーウィンドウ。RVA23 仕様を厳格に遵守し、業界をリードするアウトオブオーダーのベクトルユニット（RVV）をいち早く実装。シングル／デュアル／クアッドコアクラスタと TileLink、AXI、ACE、CHI 相互接続をサポートし、自社開発 NoC IP 昉・星路-700（StarNoC-700）と接続して 256 コアまで拡張可能。Type 1/Type 2 Hypervisor の完全サポートを完了し、Linux と KVM 仮想化ソリューションが安定稼働。同時に AIA 高度割り込みアーキテクチャや IOMMU などのサーバー級インフラ IP も打ち出した。商用展開では、希奥端計算（LECARC）が天枢-100 を採用してインテリジェントエッジ向けの次世代サーバー CPU を開発することが決定している（両社は 06-29 に提携を公式発表）。説明：天枢-100 の初回発表（08-19）は本レポートですでに収録済み。「正式納入」はその後続のマイルストーンであり、直前 2 日間に gnews の賽昉検索が 301536.SZ 星宸科技の半期報告書により誤ってタグ付けされ汚染されたため検出漏れとなったもので、本日追加収録する。

3. 国内チームの動向と深掘り

3.1 芯来科技が新三板創新層に上場（875127）：国内 RISC-V CPU IP のトップが資本市場に参入

日付：2026-08-28　情報源：同壁財経/新浪財経、同花順、億欧データ/網易

芯来智融半導体科技（上海）股份有限公司（証券略称：芯来科技、コード 875127）の上場申請が承認され、8 月 28 日に新三板革新層へ正式に上場した。主幹事証券は招商証券。同社は 2018 年設立、創業者は胡振波（国内初のオープンソース RISC-V プロセッサコア蜂鳥 E203 の作者）で、国内初の商用 RISC-V CPU IP サプライヤー：製品は N シリーズ低消費電力組み込み、UX シリーズ高電力効率、NA シリーズ車載規格（世界初の ISO 26262 ASIL-D 認証 RISC-V CPU IP）、NI シリーズ AI 計算（世界で早くから VLEN 1024 ビットをサポート）をカバー。ライセンス先は 300 社超（兆易創新、恒玄科技、晶晨、裕太微など上場企業を含む）。SHD Group 2026-03 レポートによると出荷量ベースで世界の RISC-V CPU IP 上位 4 位。財務と資金調達：2024/2025 年売上高は 7,399.87 万元/8,294.11 万元、株式報酬費用の影響を除いた損失は各期で縮小（-1722.73 万/-958.63 万/-377.56 万元）、2025 年は営業キャッシュフローがプラスに転換（792.03 万元）。上場と同時に約 8.21 万株を私募発行し、約 4,200 万元を調達（引受先は黒龍江振興先進製造産業基金、中芯熙誠北京数字科技基金）、調達資金は RISC-V チップカスタムプラットフォームの研究開発に投入。株主構成には小米長江産業基金、君聯資本、中電科基金、芯原股份などが含まれる（上位 10 大株主合計持株比率 73.01%）。背景：2025-08 に芯原股份が芯来科技の 97% 株式取得を計画したが、同年 12 月に中止を発表（標的の要求と市場環境、政策要件に乖離があった）。その後芯来は独立上場へ方針転換。今回の上場は、同社が IP ライセンスからチップカスタム、Chiplet、サーバー CPU への 4 段階の戦略的アップグレードを行うための資金チャネルを提供する。同日、億欧データはこれを「製造分野投融資デイリーレポート」の上場カテゴリに分類した（推定調達総額は約 3 億元、未開示分を含む）。

3.2 算能 sophon-tools がリリース前のセキュリティ強化、SophLiteOS v2.2.6 など複数の修正をマージ

日付：2026-08-29　情報源：sophgo/sophon-tools コミット記録

算能の調査期間内の 5 件のコミット（sophgo/sophon-tools、いずれも 08-29 夜にマージ）。テーマはリリース前のセキュリティチェックと強化：第一に、/agent/ws サービスの同一オリジン検証とレート制限強化、CV84X2 デバイスツリー（dts）のフォールバック検索（#160）。第二に、P1/P2 級セキュリティ強化バッチ——登録フローで一時 token を拒否、ファイアウォール保護ポートガードの厳格化、ソフトウェアパッケージ名/引用符/終了コード/jwt/タイムアウト/メトリクス token などの細部修正（#161）。第三に、SophLiteOS の agent 二重返信問題の修正——history を kind ごとに正規化して重複排除、v2.2.6 としてリリース（#157）。第四に、OTA 事前チェックで不完全な書き込みパッケージをブロックし、OTA の無限ループを防止（#158）。第五に、psocbak バックアップで外付けデータディスクのマウントポイントを除外し、ota_update md5 を同期（#159）。sophon-tools は算能の SophOS/書き込みと OTA ツールチェーンであり、本バッチのコミットはリリース直前の系統的なセキュリティと安定性の収束であり、CV84X シリーズ（昨日既に公式仕様の確定を報告済み）の量産支援ツールのエンジニアリング的補強である。

3.3 香山：Ftq プリフェッチ性能チューニング、KunminghuV2 CI オプションと Deterload ツールの H/V 拡張サポート

日付：2026-08-29　情報源：OpenXiangShan/XiangShan、OpenXiangShan/Deterload

OpenXiangShan 組織の調査期間内の 4 件のコミット：XiangShan メインリポジトリが 2 件——perf(Ftq) で分岐プリフェッチの後退距離（BpRunAheadDistance）を icache way 検索深度に設定（#6425、08-29 17:23 北京時間）、ci(perf) で KunminghuV2 設定に性能回帰トリガーオプションを追加（#6437）。香山ラボの Deterload ツールが 2 件——H/V 拡張付きの hello サンプルを追加、builders に enableV/enableH パラメータを追加（08-29 21:40 前後）。これにより決定論的負荷生成ツールチェーンが仮想化とベクトル拡張の検証シナリオをカバーできるようになった。全体としては定例の性能チューニングとツールチェーン機能拡張であり、規模は小さいが方向性は明確：KunminghuV2 設定の CI 性能回帰体系と Deterload の H/V サポートは、いずれも香山次世代コアの検証とチューニングの閉ループに資するものである。

3.4 進迭時空 P3 PMIC データシート文書が公開；Revyos が SG2044 ファームウェアを更新（简報）

日付：2026-08-29/08-30　情報源：spacemit-com/docs-chip、revyos/firmware-sg204x

進迭時空の docs-chip リポジトリに P3 電源管理チップ（PMIC）データシート文書が新規追加された（中英バイリンガル、08-29 19:44 北京時間）。ハードウェア文書のエンジニアリング化の蓄積を継続するもの（前日に AVL 文書化作業を既報）。Revyos 組織の firmware-sg204x リポジトリでは 2 件のコミット：SG2044 プラットフォームの fsbl.bin ブートファームウェアを更新、EDK2 ビルドを Linux クロスコンパイラに変更（08-30 未明）。SG2044 プラットフォーム UEFI ファームウェアチェーンの定常的な反復である。両チームとも調査期間内は小刻みな反復のみで、アーキテクチャレベルの変化はない。

4. 具身知能とロボット専章

4.1 深開鴻が M-Robots OS 3.0 Beta を発表：オープンソース鴻蒙ロボット OS の重心が群知能へ

日付：2026-08-29　情報源：新浪科技/IT之家、深開鴻公式サイト

贵阳で開催された 2026 中国国際ビッグデータ産業博覧会で、深開鴻上級副総裁の王皓氏が M-Robots OS 3.0 Beta 版を正式に発表した。M-Robots OS は全国初のオープンソース鴻蒙（OpenHarmony）をベースとした分散型ヘテロジニアス多機協調ロボットオペレーティングシステムであり、3.0 Beta は重心を「単機能力」から「群知能」へ移し、安全、リアルタイム、群知能、デジタル基盤の 4 大方向を軸に体系的にアップグレードした。安全面では「組網可信、接続可控、運用可防」の立体的な防御を構築する。深開鴻は 06-26 に M-Robots コミュニティの共同構築を始めたばかりであり（初のオープンソース鴻蒙ロボット OS コミュニティ）、継続的にオープンソース鴻蒙/RISC-V エコシステムのコンテストやハードウェア対応に参加している。当調査期間、RISC-V 側に具身知能ハードウェアの新製品はない。本項はオープンソース鴻蒙ロボットエコシステムの動向として収録する——昨日の Microduck（Hugging Face エコシステムの二足歩行ロボット）と同様に、「端末のメイン制御は依然として ARM/既存エコシステムが主体であり、RISC-V は具身知能分野において標準とガバナンス層で先行する」という構図の裏付けである。ただし、オープンソース鴻蒙ロボット OS のハードウェア対応範囲はすでに RISC-V 開発ボードをカバーしており、追跡に値する潜在的な浸透チャネルである。

4.2 世界具身知能ロボット産業博覧会が閉幕、3 日間で 39 億元の成約意向

日付：2026-08-30　情報源：搜狐転載深圳特区報、観察者

8 月 26-28 日に深圳で開催された 2026 AGIC 深圳国際汎用人工知能産業博覧会兼 GERX 世界具身知能ロボット産業博覧会が閉幕した。深圳特区報は 3 日間で 39 億元の成約意向を達成、直接注文可能な成熟展示品 1200 点、海外バイヤー 7000 名余りが参加したと報道。同時期に世界ロボット大会（北京）後の「ロボット運動会」が具身知能の「加速度とブレーキパッド」に関する議論を引き起こした（観察者 08-29）。業界の関心は技術デモから実装と信頼性へ移っている。このような業界横断的な進展は RISC-V 具身知能エコシステムの外部環境指標である：国内の具身知能産業は商業化の放量段階に入りつつあり、端側チップ（RISC-V を含む）への需要ウィンドウは持続的に開いている。

4.3 調査期間内に依然として RISC-V 具身知能ハードウェアの新製品なし（構図継続）

日付：2026-08-29~08-30　情報源：gnews/HN/GitHub 検索を統合

本ウィンドウの gnews ロボット関連クエリ（具身智能、risc-v robot など）のヒットは業界トレンドとオープンソース鴻蒙エコシステムのニュースが中心で、RISC-V 具身智能ハードウェアの新製品発表はなかった；GitHub 側でも各 RISC-V チームのコミットに具身関連の新規リポジトリはない。昨日の結論と一致：RISC-V は具身智能分野で依然として「標準とガバナンス層が先行（MIPS が RISC-V 国際基金会のトップレベル会員に昇格）、端末での実装は様子見」の段階にあり、オープンソース鴻蒙ロボット OS（M-Robots OS）など中間層エコシステムが潜在的な浸透チャネルとなっている。

5. 総括とトレンド観察
