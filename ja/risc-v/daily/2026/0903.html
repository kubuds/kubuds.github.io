1. オープンソースコミュニティとソフトウェアエコシステム

1.1 香山昆明湖オープンソースコア、ハイペースで反復：XiangShan メインリポジトリ1日10+コミット、ベクトル命令例外処理を集中的に修正

日付：2026-09-02（北京時間 09-02 09:57 から 09-03 01:47 まで連続コミット）　出典：GitHub openxiangshan/XiangShan commits、openxiangshan 組織リポジトリ

中国科学院計算技術研究所が主導するオープンソース高性能 RISC-V プロセッサコア XiangShan（昆明湖アーキテクチャ）は、調査期間内にハイペースな開発を維持し、メインリポジトリに1日で10+コミットをマージ、ベクトル命令と例外処理の正確性修正に集中している：

  • 命令デコード側：VMSGTU.VI などのベクトル比較命令の即値符号拡張問題（SelImmField/ImmIsUnsign5b）を修正、VSetFuncUnit に vill オペランドチェックを追加、VsetDecoder が VS（ベクトル状態）無効時に正しく不正命令例外をトリガー——ベクトル拡張機能とステートマシンセマンティクスを継続的に厳格化；
  • 実行ユニット側：AtomicsUnit のアトミック操作例外生成ロジックを修正、LoadUnit の非アラインドリプレイ時にヘッド TLB メタデータを保持；
  • マイクロアーキテクチャと検証基盤：DecodeStage にレジスタレベルのレジスタ切り替えタイミングパスを追加、dramsim3 がクロックエッジで Verilator DPI をサンプリング、新たに「学生カバレッジ学習器」（feat(BOP)）実験特性を追加。

関連リポジトリも同期更新：ready-to-run（NEMU 参照を bump、16:44 UTC）、NEMU、XSCache、workload-builder、GEM5 がいずれも調査期間内に push され、「プロセッサ+シミュレータ+イメージ」の開発クローズドループが全線で活発であることを示している。昆明湖（Kunminghu）後続版のベクトルと信頼性の打磨は進行中であり、これは RVA23/RVV エコシステムソフトウェア（昨日の NVIDIA CUDA による RISC-V ホスト CPU への RVA23 要求）と呼応している。

半導体業界通信 The Chip Letter は 2023 年 8 月と 2026 年 8 月に読者へ同一の投票を行った：「20 年後（2043 年）に RISC-V は標準または最も普及した命令セットになるか？」結果の対比は明瞭である：2023 年は多数の読者が「なる」と答えたが、2026 年にはその割合が半数を下回り、約 22 ポイント下落した。著者 Babbage は二つの解釈を示している：第一に、AI への大規模投資が本来 RISC-V に向けられたはずの資源と注目を吸い上げ、RISC-V は多くのアクセラレータで脇役に過ぎなくなっている；第二に、RISC-V の発展は競合の强弱に高度に依存しており、過去三年でインテルが力強く復活し、Arm の自社開発サーバ SoC や NVIDIA などの高性能コアも進歩しており、両者が相まって RISC-V の「マインドシェア」が流失している。コメント欄の意見は分かれている：RISC-V には一定の面積／性能優位がなく、最良の場合でも愛好家市場に広がる程度だとする読者もいれば、Espressif の ESP32-C3/C6 を例に挙げ、その「安価で十分」という特性がコスト敏感な市場での価値を持つと強調する読者もいる。この調査はコミュニティの意見であり事実データではないが、「AI 時代のナラティブとマインドシェア」が RISC-V のハイエンド化プロセスに与える潜在的影響は継続的に追跡する価値がある。

1.3 ship-your-interpreter：Lean 4 + Sail RV64D モデルで RISC-V バイナリに対して CompCert 式の精化証明を実施

日付：2026-09-02/03（新規リポジトリ、調査期間内に更新）　情報源：GitHub BasisResearch/ship-your-interpreter

新規オープンソースプロジェクト ship-your-interpreter は形式検証の新たな発想を代表している：「インタプリタのソースコードを検証するのではなく、インタプリタのバイナリを直接検証する」。本プロジェクトは WHILE 言語のインタプリタをベアメタル RV64 ELF にコンパイルし（I/O は HTIF 経由）、さらに Lean 4 に組み込んだ Sail 生成の RISC-V RV64D 命令セットモデルを用いて、CompCert 式の前方シミュレーション証明「帰納的大ステップ意味論がマシン動作を抽象化する」を行う：中核定理は、導出可能なすべての挙動がマシン上で停止すること（かつ終了コード 0）を保証し、導出不能なプログラムは決してクリーンに停止しない。リポジトリの自述によれば、すべてのビルドはsorry ゼロ、公理ゼロ（古典的選択補題のみ）であり、未完了の義務は Prop 型定義として正直に記録され、sorry で覆い隠されることはない；付随して fuzzer/SMT/census 検証スタックと関数ごとのシミュレーション補題（約 500 個のデコードテーブルモジュール）がある。これは「バイナリレベルの RISC-V ソフトウェア正しさ」に対して Lean エコシステムでは稀なエンドツーエンド参照実装を提供するもので、RISC-V 形式化（ACT、Sail）ツールチェーンと相補的である。リポジトリはまだ新しく（star 数が少ない）、注目に値する初期プロジェクトである。

2. 製品とエコシステム動向

2.1 晶心 Andes が agentic AI プラットフォーム ChipAgents を導入：カスタムプロセッサ設計時間を約 30% 短縮、検証サイクルを約 3 週間に圧縮

日付：2026-09-02（晶心公式サイトニュース）　情報源：晶心科技 Andes 公式サイト、Dealroom 転載

RISC-V 国際財団の創設プレミア会員であり、世界有数の RISC-V CPU IP サプライヤーの一つである晶心科技（Andes Technology、台湾証券取引所 6533）は、カスタムプロセッサ設計フローに agentic AI プラットフォーム ChipAgents を採用し、顕著な成果を上げたと発表した：カスタムプロセッサ設計時間を約 30% 短縮し、従来数か月に及んだ検証ワークフローを約 3 週間に圧縮した。これは、ある大手 CPU IP ベンダーが「AI エージェント支援によるチップ設計／検証」を公式フローに組み込んださらに一例であり、これまで複数の EDA／設計サービス企業が推進してきた AI-for-chip-design の趨勢と一致する；晶心にとって、そのビジネスモデルは顧客向けの AndesCore カスタマイズ（命令拡張、SoC 統合）に高度に依存しており、検証の自動化は納期競争力に直結する。ChipAgents はサードパーティの agentic AI プラットフォーム（チップ設計向けエージェントプラットフォーム）である。現在の公開情報はベンダー側の説明が主であり、具体的な方法論の詳細は今後の開示を待つ必要がある。

3. 国内チーム動向と深掘り

3.1 霊睿智芯：P100 国産サーバ級 RISC-V コアの技術詳細を公開、国内初の動的 SMT4 を実装、テストチップがまもなくテープアウト

日付：2026-09-02（観察者網深度独占インタビュー）　情報源：観察者網、新浪財経転載、老杳吧/愛集微、中国日報網 2026-07 資金調達報道

設立から2年未満の国産チップスタートアップ霊睿智芯は、観察者網の独占インタビューを通じて、フルスタック自社開発のサーバー級 RISC-V CPU コア P100（2026年初に v1 をリリース、テストチップは間もなくテープアウト予定）を初めて体系的に公開した。中核的なセールスポイントは、エージェント（Agent）負荷向けの動的 SMT4である。シングルコア最大4スレッドで、ワークロードに応じて SMT1～SMT4 の間をリアルタイムに動的切り替えでき、システムの再起動は不要——同社はこれを国内初の成熟した実用化に至った動的 SMT 技術と称している（文中では「国産 SMT 技術路線で唯一のベンチマーク製品」と記述されているが、これは同社の説明である）。その他の仕様：20段以上のアウトオブオーダー・スーパースカラパイプライン、8デコード10発行、TAGE 分岐予測、シングルコア性能は 20/GHz 超を主張（SPEC CPU2006）。エージェントの長チェーン無人運用シーン向けにエンタープライズ級 RAS を強化（エンドツーエンドのエラー検出、ハードウェアレベルでのエラー隔離、エラー命令を自動再実行するコア自動復旧）。RISC-V オープン命令セットをベースにカスタム拡張インターフェースを予約し、顧客がパイプライン内に専用アクセラレータユニットを統合できるよう支援する。

同社のストーリー背景：エージェント実行における CPU の価値の再評価（タスク分解、ツール呼び出し、サンドボックスのライフサイクルなどの制御フロー負荷。インテル/ジョージア工科大学の研究を引用し、CPU 側の実行時間占比を 50%～90.6% と主張）、サーバー CPU/GPU の比率は約 1:4 から 1:1 へ傾斜。モルガン・スタンレーは 2031 年にエージェント駆動の CPU 増分市場が 325億～600億ドルに達すると予測。市場戦略：長期的には CPU 製品販売を主とし、短期的には選択的に IP ライセンスを実施（DPU、自動運転、embodied intelligence の頭脳、AI アクセラレータチップ向けで、汎用 CPU 競合製品にはライセンスしない）。国産プロセスに深く連携。壁仞科技などの国産 GPU メーカーが同社の数億元 Pre-A ラウンドの資金調達に参加（2026-07 に正式発表）。両社は「CPU+GPU」スケジューリングを共同最適化し、国産エージェント算力一体機を構築する。ロードマップ：P100 ベースの 128コア サーバー級 CPU は 2027年にテープアウト、2028年に量産を予定。embodied intelligence と端側推論向けのドメイン特化プロセッサも並行して推進中。注記：霊睿智芯はこれまで本シリーズのデイリーレポートに収録されておらず、本期が同チームの初収録である。技術指標の多くは同社の自述であり、量産検証前は留保して見るべきだが、その「エージェントネイティブ CPU + SMT」という位置づけは、国産 RISC-V サーバーのストーリーに新たなサンプルを提供するものである。

3.2 算能：LLM-TPU にマイクロソフト Mage-VL のストリーミング・マルチモーダル展開を追加、プリコンパイル済み bmodel を添付

日付：2026-09-02　情報源：GitHub sophgo/LLM-TPU、Mage-VL プロジェクトページ（マイクロソフト）、arXiv:2607.24904

算能（SOPHGO）のオープンソースモデル展開スタック LLM-TPU（BM1684X/BM1688/CV186X シリーズ TPU 向け）は、調査期間内に Mage-VL の展開サポートをマージした。コミットによれば、Mage-VL ストリーミング（streaming）推論 demo を新規追加し、プリコンパイル済み bmodel のダウンロードリンクを添付している（07:38 UTC に README を更新）。Mage-VL はマイクロソフトが 2026年7月にオープンソース化した「codec-native」ストリーミング・マルチモーダル基盤モデル（arXiv:2607.24904）であり、リアルタイム動画/イベントストリーム向けの低遅延マルチモーダル推論を主打とする。これは、算能 TPU 側の VLM カバレッジが静的画像・テキストからストリーミング動画理解シーンへさらに拡張されたことを意味し、かつプリコンパイル済みモデルによりユーザーの展開ハードルを下げている。算能が最近 CV84X6 の仕様を正式化し sophon-tools をメンテナンスしていること（昨日既報）と合わせると、その AI ソフトウェアスタックは依然として高頻度のイテレーション期にある。

3.3 国内チーム GitHub 総合核查：達摩院玄鉄が hypervisor テストスイートを追加提出、その他は大半がドキュメントと同期

日付：2026-09-02/03　出典：XUANTIE-RV/damo-rv-priv-ats、Nuclei-Software、spacemit-com、sipeed、eswincomputing などの組織 repos API

10 社の国内 RISC-V チームの GitHub 組織に対して調査期間チェック（pushed_at ≥ 09-02 08:18 北京時間）を実施：

  • 達摩院玄鉄（XUANTIE-RV、72 リポジトリ）：唯一の実質的コミットは damo-rv-priv-ats（2026-06 リポジトリ作成、C 言語、公開 star 数は少ない）——「Added more Hyprevisor test suites (#26)」（09-02 09:45 CST）。このリポジトリは達摩院/達摩院玄鉄側の RISC-V 特権アーキテクチャ（hypervisor/アドレス変換）テストスイートの公開化プロジェクトと見られ、内部ツールの外部流出に属し、情報量は限定的；
  • 香山（openxiangshan）：1.1 を参照、調査期間内で最も活発；
  • 芯来（Nuclei-Software、42 リポジトリ）：lauterbach-startup（Lauterbach デバッガ起動設定）のみ 1 件 push、通常のメンテナンス；
  • 進迭時空（spacemit-com）：docs-bianbu / docs-chip / docs-ros の 3 箇所のドキュメントリポジトリを更新（Bianbu システム、チップマニュアル、ROS ドキュメント）および edk2-platforms の同期、ドキュメント補完のペースを継続（昨日すでに K3 UEFI/P3 マニュアルを報告）；
  • 算能（sophgo）：3.2 を参照；矽速（sipeed）：maix_ax620e_sdk_kernel カーネル SDK 更新；賽昉（starfive-tech）：u-boot リポジトリ push（デフォルトブランチ以外/上流同期の疑い）；RevyOS：linux fork カーネル同期；奕斯偉計算（eswincomputing）：push なし。

結論：香山と算能を除き、国内チームは調査期間内にアーキテクチャレベルまたは製品レベルの新動向はなく、大型バージョンリリース後の通常の平穏期が継続している。

4. 身体性知能とロボティクス専門章

4.1 MIPS（by GF）が Acies / Actus / Aegis の三大 Physical AI プラットフォームを発表、RISC-V ハイレベルエコシステムが後押し

日付：2026-09-02（米西、北京時間 09-03 未明）　出典：Business Wire 通稿、Yahoo Finance 転載

GlobalFoundries 傘下の MIPS（すでに全面的に RISC-V アーキテクチャへ転換、8 月に RISC-V 国際基金会のトップレベル会員に昇格し董事会副主席に就任、本シリーズ 08-29 で既報）が Physical AI 向けの三つの「ワークロードネイティブ（workload-native）」開発者プラットフォームを発表し、AI 能力を産業機械、交通手段、組み込みシステムへと下沉させた：

  • MIPS Acies：推論ネイティブ（Inference-Native）——現代のエッジワークロード向け AI 推論開発者プラットフォーム、オープンで標準ベースの NPU とオープンソフトウェアスタックを含む；
  • MIPS Actus：イベントネイティブ（Event-Native）——モーションコントロール、センサーフュージョン、予知保全などイベント駆動型組み込みアプリケーション向けのリアルタイム開発者プラットフォーム；
  • MIPS Aegis：セーフティネイティブ（Safety-Native）——低遅延とエージェント型（agentic）処理を必要とするミッションクリティカルな Physical AI システム向け。

MIPS CEO Sameer Wasson 氏は、コンピューティングプラットフォームはワークロードに応じて変化する必要があると述べ、MIPS は「オープンでソフトウェアファースト」のプラットフォームで統一された基盤を提供し、「効率と tokens-per-watt」を技術的基盤としている。プラットフォームは RISC-V のオープンな特性 + GF のプロセス/パッケージング/製造能力に依拠し、AI とプロセッサ IP、ワークロードモデリング、カスタムチップ（software-to-silicon）の一体型パスを提供する。注目すべきエンドースメントの陣容：AMD 組み込みシリコンマーケティングディレクターの Manuel Uhm 氏と MediaTek 共同 COO/CFO の David Ku 氏がいずれも RISC-V エコシステムと MIPS のコミットメントへの歓迎姿勢を表明——昨日報道の NVIDIA CUDA-on-RISC-V 要求リスト、MediaTek-NVIDIA NVLink Fusion 提携（08-31）と相互に裏付け合う：Physical AI/具身知能は RISC-V のハイエンド化において最も重要なナラティブと戦場になりつつある。プラットフォームの具体的な顧客とタイムテーブルはまだ開示されていない。

本調査期間中、RISC-V 側に他の具身知能ハードウェア新製品はない。MIPS のプラットフォーム化リリースと国内の「エージェント CPU」ナラティブ（3.1 参照）は共に次のことを指し示す：RISC-V は「物理世界とエージェント向けの専用演算力」という立場でロボティクス/具身知能に参入しつつあり、単に汎用コアのコストパフォーマンスに頼るものではない。

5. まとめとトレンド観察

  1. 二つの主線が並行して進む：Physical AI のプラットフォーム化（西洋）とエージェント CPU（中国）。MIPS の三プラットフォーム（Acies/Actus/Aegis）は「推論+リアルタイム+セキュリティ」をパッケージ化して RISC-V Physical AI 開発基盤とした；国内の霊睿智芯は「動的 SMT4 エージェントネイティブ CPU」ナラティブで参入した。昨日の NVIDIA による CUDA の RISC-V ホスト CPU への移植に関する必須要件（RVA23/ACPI/一貫性）の公表も重なり、ハイエンド RISC-V の商業ナラティブは AI データセンターと具身知能を中心に急速に形成されつつある。
  2. 「マインドシェア」回落のシグナルに警戒。The Chip Letter の三年間に二度の読者投票は、RISC-V が二十年後に主流になるという自信が 22 パーセントポイント下落したことを示し、著者は AI 投資への分流と x86/Arm の反撃に帰因している——意見調査は事実を代表するものではないが、エコシステムは技術推進以外にもナラティブを争う必要があることを喚起する。
  3. オープンソースコアの反復は止まらない：香山昆明湖は調査期間中に 10+ コミットがベクトル命令例外の正確性と信頼性に集中；形式検証（ship-your-interpreter のバイナリレベル精化証明）と AI 支援設計（晶心×ChipAgents）がソフトウェアと設計効率の新たなテコとなる。
  4. 国内チームは全体としてリリース後の静穏期にあり、マークすべき次のノード：霊睿智芯 P100 テストチップのテープアウト、賽昉天枢-100 の顧客チップ進展、香山の後続バージョン、算能 CV84X の量産配套。
