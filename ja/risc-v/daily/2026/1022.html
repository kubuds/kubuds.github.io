今日の重点：Qualcomm が RISC-V サーバー IP 企業 Akeana を買収、米系大手がアーキテクチャ資産の集約を加速

日付：2026-10-21　出典：Dealroom：Qualcomm buys RISC-V startup Akeana to push into AI and data-center chips（10-21）、Sammy Fans：Qualcomm acquires Samsung foundry partner Akeana to expand AI chip business（10-21）

10-21 の報道によると、Qualcomm は RISC-V プロセッサ IP スタートアップ Akeana の買収を完了した。取引金額は非公開。Akeana の創業者兼 CEO Rabin Sugumar はビジネス向けソーシャルプラットフォームで、Akeana の IP とチームが「すでに Qualcomm の一部となった」ことを確認し、自身は Qualcomm に入社してエンジニアリング担当バイスプレジデントに就任した。

  • 企業背景：Akeana は 2021 年に設立され、中核チームは Marvell／Cavium の ThunderX サーバプロセッサチーム出身である。2024 年 8 月にステルス状態から脱し、1 億ドル超の資金調達（Kleiner Perkins、Mayfield、Fidelity などが参加）を明らかにした。IP は Akeana 100／1000／5000 の 3 グレード（MCU 級 32 ビットコア、MMU 付き 64 ビットコア、ノート PC とデータセンター向けの超高性能コア）をカバーし、AI マトリクス演算エンジンならびにセキュリティ、デバッグ、RAS、テレメトリなどのシステム IP も提供する。
  • 産業側の手がかり：Akeana は三星代工と協力して 4nm サーバチップを推進しており、2025 年 12 月に両社はコード名 Alpine のサーバテストチップ設計を完了した。これが本項と「三星代工エコシステム」が直接関連する点である。
  • Qualcomm の連続的な動き：2025 年 12 月に Qualcomm は RISC-V サーバ CPU IP 企業 Ventana Micro Systems を買収した。その後、Alphawave の 24 億ドルでの買収を完了し、Amazon とカスタム AI 推論の協力も発表した。今回の Akeana を加えると、Qualcomm は 10 か月以内に RISC-V サーバ IP チームを 2 社取り込んだことになる。
  • 解釈の限界：取引金額、顧客コミットメント、製品スケジュールはいずれも非公開であり、Akeana の IP ラインが Qualcomm 自有の CPU ロードマップ（Oryon）に統合されるのか、独立した製品ラインとなるのかについては、現時点で公式説明はない。本項は事実レベルの M&A 確認にとどまり、商業的リターンはなお觀察を要する。

国内路線との対照：同じ週に、進迭時空は香山と共同でサーバ級 CPU V100（香山昆明湖 V2R2 コア 6 個＋自研 X100 コア 40 個、計 46 コア）を発表し、「オープンソースコア＋自研コアのハイブリッド」という製品化パスを歩んでいる。海外では IP チームが大手へ集中し、国内ではオープンソースコアが商用チップへ浸透している。両方のパスが同じ問いに答えようとしている。すなわち、サーバ級 RISC-V の IP 供給はどこから来るのか、という問いである。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 RISE、RVA23 ベースの初の Android 17 オープンソース版をリリース

日付：2026-10-20　情報源：RISE：Android 17 Available on RVA23 with RISE（10-20）、RISE android_manifest：android-17-v1.0（10-20）

RISE プロジェクトは、RVA23 ハードウェア上で動作する初の Android 17 ビルドをオープンソース形式で提供すると発表した。SpacemiT K3 Pico-ITX と阿里巴巴 A210 EVB の 2 枚のボードをサポートする。本プロジェクトは番号 RP024 で、RISE が出資し主導し、メンバー企業の進迭時空と阿里達摩院がプラットフォームの経験とハードウェアを提供し、BayLibre がエンジニアリング実装を担当した。同社の以前の SpacemiT K1 向け Android 移植をベースにしている。

  • リリース内容：android-17-v1.0 は 2 枚のボード向けバイナリイメージ、バージョン固定されたソース manifest、チェックサム、書き込みツール、再ビルド手順を提供する。ソース履歴と作者情報は完全に保持され、再現可能かつ拡張可能である。
  • オープン度：U-Boot + OpenSBI によるオープンソース起動チェーンを採用し、グラフィックススタックは上流 Imagination カーネルドライバと Mesa に基づく。公式には、これは開発者向けのオープンソース版であり、量産版や認証版ではないと明言されている。
  • 次段階：RP024 の第 2 フェーズでは、ビルド、ハードウェアテスト、リリースプロセスの自動化を進め、まず RISE Board Farm に既存の A210 システム上でテストを実行し、數週間内に K3 を追加する。RISE はまた、後続の RFP が Bionic、BoringSSL、ART、V8、Chrome、マルチメディアライブラリをカバーすることを予告し、ベンダーに対しプラットフォームサポートを Linux カーネル、U-Boot、OpenSBI へ還元するよう促している。

RVA23 は RISC-V アプリケーションプロセッサの規範上の分水嶺であり、Android 17 がその上で動作しオープンソース化されたことは、「モバイル OS＋アプリケーションプロセッサ規範」という最も厳しい組み合わせに初めて再現可能な公共ベースラインが生まれたことを意味する。

1.2 Linux 7.4 暗号ライブラリ：RISC-V と x86 の AES 最適化実装が lib/crypto に統合

日付：2026-10-21　情報源：Phoronix：Linux 7.4 Kernel Crypto Library Enjoying Optimized AES Implementations On x86 & RISC-V（10-21）

Google カーネルエンジニア Eric Biggers による暗号サブシステムの性能作業が Linux 7.4 にマージされた。x86／x86_64 および RISC-V の AES 各モードの最適化実装を lib/crypto カーネル暗号ライブラリへ移行したもの。

  • 対象モード：ECB、CBC、CBC-CTS、CTR、XCTR、XTS の6種類。移行後、ライブラリ API はこれらのアーキテクチャ上で直接高速化の恩恵を受け、crypto_skcipher 側の利用も引き続き受益する。
  • x86 側：AVX 最適化コードと AES-NI 命令を使用。RISC-V 側はベクトル拡張と暗号拡張に基づく高速化実装。
  • 副次的な利点：重複する多数のグルーコードを整理し、メンテナンス対象を削減。同じ更新には開発者 Stian Halseth による SPARC64 向け AES-XTS 最適化実装も含まれる。

RISC-V にとって、この項目の価値は「また一つの最適化コミット」にあるのではなく、その着地点にある。高速化実装がアーキテクチャ固有ディレクトリから汎用ライブラリへ移され、カーネル内の他の利用者（ファイルシステム暗号化、IPsec、dm-crypt など）が変更なしで恩恵を受けられる。インフラストラクチャ層の再利用可能な收益に属する。

1.3 openRuyi：SPECS コミット20件、uv の Rust 依存がまとめて登録

日付：2026-10-22　情報源：openRuyi メインリポジトリのコミット記録（10-22）、openRuyi 公式サイトニュースページ

openRuyi メインリポジトリは調査期間内に 20件のコミット を記録し、10-22 未明の SPECS 一括登録に集中していた。すべて rust-uv-* 0.0.96 シリーズパッケージ：pep440、pep508、platform-tags、pypi-types、options-metadata、normalize、toml、version、small-str、globfilter、git-types、fs、errors、logging、macros、redacted、static、preview、warnings、windows。

これらのパッケージは uv（Rust で書かれた Python パッケージ・プロジェクトマネージャー）の依存コンポーネントである。前回のデイリーレポートで記録した40件のコミットは minio、Prometheus、sarama などの Go クラウドネイティブコンポーネントに集中していたが、今回は Python ツールチェーンへと転換している。二日間を連続して見ると、openRuyi は「データセンターでよく使われるサービス」と「Python 開発ツールチェーン」の二種類のソフトウェアを RISC-V ディストリビューションへ补齐しつつある。公式サイトニュースページの最新告知は依然として 2026.09 バージョンであり、調査期間内に新バージョンのリリースはない。

2. 製品とエコシステムの動向

2.1 楽鑫 ESP-Mosaico 販売開始：ESP32-S31 モジュラー AI ハードウェアキット、59ドルから

日付：2026-10-21　情報源：CNX Software：ESP-Mosaico — An ESP32-S31-based modular development platform for AI-assisted hardware creation（10-21）、Mosaico ストア

楽鑫は ESP-Mosaico を発表した。ESP32-S31 を中核とするモジュラ開發プラットフォームで、「AI とハードウェアの融合」を主軸とし、マグネット式拡張玩具、モーションセンシング、方形タッチ HMI、エッジ音声／マルチメディアシーンに向けたもの。

  • コアボード：ESP32-S31NRV16（320MHz RV32IMAFCP 高性能コア＋低消費電力 MCU コア、512KB SRAM＋32KB 低消費電力 SRAM＋16MB PSRAM）、Wi-Fi 6、Bluetooth 5.4（LE Audio、方向検索、Mesh 1.1 と Classic を含む）、802.15.4；128MB SPI NAND＋16MB SPI NOR。
  • ヒューマンマシンインターフェースと周辺機器：2.16 インチ 480×480 QSPI タッチスクリーン（CO5300＋CST9220）、NS4150B アンプと ES8311 コーデック、デュアル BMM150 磁力計、BMI270 6 軸、振動モーター、USB-C 給電と書き込み；ベースボードは 60 ピンのボード・トゥ・ボードコネクタで拡張、スピーカーと 3.7V／65mAh バッテリーを含む。
  • モジュール化：カメラモジュール（OV3640 3.2MP または SC101IOT）と多機能インタラクションモジュール（光センサー、PIR、赤外線 LED、WS2812 6 個、メカニカルキー／静電容量タッチパッド）を既に発表。
  • 開発方法：公式が 2 つの経路を提示——ESP-Claw による自然言語の「対話型コーディング」、および ESP-ZeroCode AI による「バイブコーディング」。AI エージェントが実装、デプロイ、実機テスト、イテレーションを担う。
  • 価格と状況：カメラとインタラクションモジュールを含む完全キット 59 ドル、バッテリーモジュール 15 ドル；此前は淘宝とサードパーティチャネルで数か月販売されており、現在は公式ストアで正式に販売開始。

ESP32-S31 は「プレビュー部品」から完成品キットへと約 2 か月で移行した（10-14 に初のサードパーティ開発ボードが登場したばかり）。そしてこの世代の製品は開発体験そのものをセールスポイントにしている：自然言語によるファームウェア生成、AI エージェントによる実機テスト。これは RISC-V MCU がエッジ側で ARM エコシステムと競争する際の珍しい差別化ポイントである。

Radxa Linkr が v1.6.0 をリリース、メインブランチにも同日同バージョンのコミットが現れた。本プロジェクトは瑞莎（Radxa）が開発ボードと NAS 向けに展開するブラウザベースのリモート管理製品ラインであり、メインリポジトリ linkr および plugins、linkr-skills、linkr-docs、linkr-docs-en、docs の 6 つのリポジトリで維持されている；調査期間内にドキュメントサイトの 3 リポジトリとメインリポジトリのいずれにもプッシュがあった。

3. 国内チームの深掘り

3.1 達摩院玄鉄が CubeSandbox の RISC-V サポートブランチを開設：CubeShim が KVM／AIA VMM バックエンドに対応

日付：2026-10-21　情報源：XUANTIE-RV/CubeSandbox：add_riscv_support ブランチ（10-21）、TencentCloud/CubeSandbox アップストリームリポジトリ

達摩院玄鉄（XUANTIE-RV）が GitHub 上で維持する CubeSandbox ブランチ add_riscv_support に調査期間内の新規コミットがあった：riscv64-control-plane-demo.yml ワークフローを手動トリガー用に登録。CubeSandbox はテンセントクラウドがオープンソース化した AI Agent サンドボックスサービス（Apache 2.0、ハードウェアレベル分離、ミリ秒級起動、E2B インターフェース互換、CNCF Landscape に参入済み）であり、玄鉄ブランチが取り組んでいるのはまさにこれを RISC-V に移植することである。

  • ビルド経路：make all-riscv64 でアーキテクチャ非依存のコントロールプレーン、guest ツール、Cubelet、CubeVS／eBPF をクロスコンパイルでき、クロスビルドイメージが自動生成される；guest カーネルは make guest-kernel KERNEL_TARGET_ARCH=riscv64 で個別にビルドする。
  • コールドスタート：CubeShim は実験的な RISC-V KVM／AIA VMM バックエンドに対応するよう変更され、直接カーネルコールドスタートをサポートする。
  • 現状の境界：RISC-V 側ではスナップショット／リストアが依然として無効であり、vAIA 状態移行の実装を待つ必要がある；公式はリリースイメージとサポート対象のデプロイ経路を提供しておらず、開発者プレビュー段階に属する。

AI Agent のコード実行サンドボックスは今年最も成長の速いインフラの一種であり、その基盤は仮想化と特権命令の完全性に依存している。玄鉄がこのスタックを RISC-V に載せたのは、「RISC-V サーバーは Agent ワークロードを支えられるか」という具体的な命題を指しており、RISC-V が AIA（先進割り込みアーキテクチャ）の実装後に迎える最も直接的なアプリケーション側の検証でもある。

3.2 奕斯偉計算と SiFive がゴールドパートナーアライアンス MOU を締結、協力はエッジ AI から Agentic AI へ拡大

日付：2026-10-21　情報源：網易（華商韜略）：奕斯偉計算と SiFive がゴールドパートナーアライアンス MOU を締結（10-21）、観点網：奕斯偉計算と SiFive がゴールドパートナーアライアンス MOU を締結、RISC-V+AI 協力を深化（10-21）

奕斯偉計算と RISC-V プロセッサ IP 企業 SiFive が正式にゴールドパートナーアライアンス覚書（Gold Partner Alliance MOU）を締結した。これは奕斯偉計算が 10-09 に香港証券取引所へ上場した後に推進する国際産業協力の一つである。

  • 協力の基盤：奕斯偉計算の EIC7700 SoC は SiFive のフラッグシップ開発ボード HiFive Premier P550 に既に採用されており、世界中の開発者に高性能 RISC-V ハードウェアプラットフォームを提供し、すでに規模化して上市している。両社の技術協調には検証可能な製品が存在する。
  • アップグレードの方向：協力はエッジ AIから Agentic AI などのアプリケーションへ拡大し、低消費電力・高性能 AI ソリューションの需要を共同で開拓し、顧客の統合要望に応じて多層的な RISC-V 製品形態を探求する。
  • 両社の位置づけ：SiFive は RISC-V 命令セット創設チームのメンバーによって設立され、アーキテクチャとコア IP に強みを持つ。奕斯偉計算は製品の実装と商業化に強みを持ち、同社の説明では国内をリードする RISC-V 主控チップサプライヤーの一つである。

注目すべきは協力のタイミングである。奕斯偉の上場後初の公開された国際協力は生産能力やファウンドリではなく、IP サプライヤーとのアライアンス強化であった。同時期に Qualcomm が IP チームを直接買収した手法と対照的に、国内メーカーは「自社開発コア＋外部 IP アライアンス」の混合路線を選択した。

3.3 算能 sophon-demo が CV84X6 適配を完了：MiniCPM4、InternVL3、MiniCPMV のサンプルを追加

日付：2026-10-21　情報源：sophgo/sophon-demo コミット記録（10-21）

算能（Sophgo）のサンプルリポジトリ sophon-demo は release ブランチに「CV84X6 適配：MiniCPM4 + InternVL3 + MiniCPMV」というコミットをマージし、CV84X6 プラットフォームに三つのマルチモーダル／端末側大規模モデルのサンプルを追加した。

  • モデルカバレッジ：MiniCPM4（端末側小パラメータ言語モデル）、InternVL3（マルチモーダル視覚言語モデル）、MiniCPMV（面壁智能のマルチモーダル端末側モデル）——いずれも端末側デプロイ志向であり、算能 SoC のエッジ推論の位置づけと一致する。
  • リポジトリのリズム：最近同じリポジトリには PaddleOCR-VL、SAM3、SAM2、BLIP、MP_SENet、YOLO_world の C++ サンプルも追加されており、サンプルライブラリは Python リファレンス実装から C++ エンジニアリングサンプルへ拡張しつつある。
  • 同一期間の他のコミット：zsbl メインブランチに 1 件、アプリケーション選択を SoC レベルの Kconfig へ移行するもので、起動ファームウェアの構造的整理に属する。

端末側チップの競争力は「モデルが来たら動くか、動かせるか」にますます依存している——その年最もホットなマルチモーダルモデルのサンプルを自社プラットフォームで整備することは、トラックの宣伝よりも現実的である。

4. 具身智能とロボット専門章

4.1 サミットの自動車エレクトロニクス、工業、ロボット分科会：紫荊 M100 が量産車載、IAR と芯来がツールチェーンと IP を補完

日付：2026-10-21　情報源：人民網（北青網）：オープンアーキテクチャの黄金の瞬間——2026 RISC-V 中国サミット分科会が産業の新信号を伝える（10-21）

第六回 RISC-V 中国サミットの七大並行分科会（10-20）の回顧報道が、自動車エレクトロニクス、工業、ロボット方向の具体的な進展を明らかにしている：

  • 紫荊半導体：長城汽車が孵化させた半導体企業で、その 紫荊 M100 はすでに量産搭載を果たした RISC-V 車載チップとなっている。自動車メーカー内部で孵化した RISC-V 車載製品がサンプルから量産へと移行したことは、今回の「搭載」の物語の中で最も確固たる証拠である。
  • IAR：ツールチェーンの観点から、自動車・産業・ロボット分野における RISC-V の三大課題を提起し、RISC-V 開発ツールを発表した。安全重要シナリオにおけるコンプライアンス準拠の開発を主眼とする。
  • 芯来科技：AI チップにおける RISC-V の IP ソリューションを共有し、動的可変ベクトル長、拡張可能な命令セット、統一ソフトウェアエコシステムを強調。クラウドから MCU までの全シナリオ AI 演算力をカバーする。
  • 兆松科技：リアルタイム制御と車載 MCU アーキテクチャの実装議題に参加。同分科会ではアリババ達摩院が車載ロードマップを紹介した。

分科会全体の基調は「RISC-V は使えるかどうかの段階から、使いやすく商用可能な段階へと移行した」というものだが、エンジニアリングの細部に落とし込むと、議論されているのは依然として安全認証、リアルタイム制御、ツールチェーンのコンプライアンスという三つの難題である。まさにこれこそが、ロボット関節制御と車載シャシードメインコントローラに共通するハードルである。

4.2 ロボット演算力側は融資の物語から量産検証へ移行：関節制御チップは量産済み、ブレインチップは依然テープアウト段階

日付：2026-10-21　情報源：人民網（北青網）：2026 RISC-V 中国峰会分科会が産業の新信号を発信（10-21）、東方財富：智元ロボット 47 回の投資で何を投じたか（10-20）

24 時間の調査期間内に、具現化知能の方向で新たな独立融資や完成機発表はなく、検証可能な進展は生産能力と検証の段階に集中している：

  • 量産側：芯際無限のロボット関節制御チップは量産済み。中端演算力向けの XC64AE はすでに大手具現化知能企業との量産検証を開始し、初の小脳チップはテープアウトとリターンを完了した。車載側ではスマートモータ制御 MCU の出荷が 100 万個を突破し、2026 年の新規受注は 520 万個。
  • 未実現部分：ブレインに位置づけられる V1000（2.5D Chiplet、設計演算力 1000 TOPS）は依然としてテープアウト段階にあり、第二世代 XC64AE 全シリーズは 2027 年のテープアウトを計画している。
  • 資本側：智元ロボットが芯際無限（Pre-A ラウンド）に出資して以降、その投資ポートフォリオは本体、基幹部品、基盤演算力チップをカバーしている。本体メーカーが資本で上流を固定することで、命令セットの選択が早期に縛られることになる。

この手がかりの意義はテンポの差にある。小脳や関節制御といったリアルタイム、低演算力、強認証の領域はすでに量産に入っている一方、大演算力の「ブレイン」チップは依然としてテープアウトとベンチマークの段階にある。ロボットにおける RISC-V の最初の実出荷は、汎用 AI 演算力ではなく、関節とモーション制御から来る可能性が高い。

5. まとめとトレンド観察

  • サーバー IP の帰属が集中しつつある：Qualcomm は 10 か月以内に Ventana と Akeana の RISC-V サーバー IP チームを相次いで取り込み、独立系 IP サプライヤーの数は減少している。国内ではオープンソースコア（香山昆明湖 V2R2）を商用サーバーチップ（V100）に搭載している。同じ週のこの二つの出来事は、サーバー級 RISC-V の IP 供給が「大手企業の内部資産」と「オープンソースコアの製品化」という二つの道に分化しつつあることを示している。
  • Android on RVA23 はプラットフォーム化の節目であり、もう一つの移植ではない：今回 RISE が提供したのは、固定された manifest、チェックサム、書き込みツールと再構築パス、さらに第 2 段階の全自動ビルドと Board Farm テストである。再現可能でリグレッション可能であることが、アプリケーションプロセッサエコシステムの真のハードルである。
  • 性能作業はアーキテクチャ固有から汎用再利用へ：Linux 7.4 は RISC-V と x86 の AES 各モード実装を lib/crypto に移し、重複するグルーコードを削除した。こうした変更は目立たないが、暗号化、ストレージ、ネットワークなど上層のコンシューマーが自動的に恩恵を受ける。
  • ディストリビューションが補完する層が上へ移行：openRuyi は前日に Go クラウドネイティブコンポーネントを一括でリポジトリに取り込み、この日は uv の 20 個の Rust 依存関係を SPECS にパッケージ化した。カーネル、ツールチェーンから Python 開発ツールまで、RISC-V ディストリビューションの「日常的に使える」状態が層ごとに埋められつつある。
  • エッジ側の競争は開発体験へ転換：ESP-Mosaico は 59 ドルのキット、自然言語によるファームウェア生成、AI エージェントによる実機テストを売り文句としている。チップ仕様が収斂する中で、「アイデアからハードウェアまで」の経路を短縮できる者が開発者を獲得しやすくなる。
  • 車載グレードとロボットは引き続き国内実装の主軸：紫荊 M100 の量産車載搭載、芯際無限の関節制御チップ量産、奕斯偉と SiFive の IP アライアンスという三つの線は、それぞれ整車、ロボット、汎用 IP 供給に対応する。サミットの見通しは楽観的だが、認証、リアルタイム性とツールチェーンは依然として決定的な変数である。
  • 限界の説明：Qualcomm による Akeana 買収の取引金額、顧客コミットメント、製品統合方案はいずれも未開示であり、現存する情報は Dealroom と Sammy Fans の報道および当事者のソーシャルプラットフォームでの確認によるもので、Qualcomm 公式プレスリリースは見られない。RISE の Android 17 は開発者版本であり、量産には適用されないことが明記されている。Linux 7.4 の暗号ライブラリの項目は Phoronix の報道に基づくもので、パッチを逐条確認したものではない。openRuyi の uv 依存関係の取り込みはコミットタイトルのみから用途を判断したもので、ディストリビューションの告知は見られない。Radxa Linkr v1.6.0 には変更リストが添付されていない。サミット分科会の内容はメディアの回顧報道によるもので、ベンダーの表現が第三者により検証されたとは限らない。会員公式サイトの巡回で検出された変化はいずれも大学、機関、ベンダー公式サイトの定例更新であり、実質的な製品、資金調達、アーキテクチャのリリースは発見されていない。香山系と一部の重点リポジトリの pushed_at はプッシュを示しているが、デフォルトブランチの再確認期間内に新規コミットはなく、非デフォルトブランチまたは PR ヘッドブランチの活動と判断される。
