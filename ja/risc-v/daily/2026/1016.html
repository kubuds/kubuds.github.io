今日の重点：達摩院玄鉄 C950 が独立アクセラレータなしで 27B 大モデルを動作、成果が RISC-V 国際財団公式サイトに掲載

日付：2026-10-15　出典：riscv.org：V Questions with… DAMO Academy’s Dr. Jianyi Meng（10-15）

RISC-V 国際財団公式サイトの「V Questions」コラムに、達摩院玄鉄（XuanTie）首席科学者、RISC-V 中国サミット 2026 副議長の孟建熠へのインタビューが掲載され、玄鉄の最近の象徴的な取り組みを系统的に紹介するとともに、10-18 の深圳サミットを予熱している。要点：

  • マイルストーンデータ：玄鉄チームは 64 コア C950 ターゲット構成上で Qwen3.8-27B（270 億パラメータ）をネイティブに動作させ、独立した GPU／NPU を必要とせず、デコード速度は毎秒 30 トークン超（約 20–22 語／秒、自然なリアルタイム対話レベルに到達）；この負荷には約 400 GB／s のメモリデータ転送能力が必要であり、インタビューでは「量子化、行列命令、オンチップメモリ、帯域幅とオペレータ最適化は単一システムとして協調設計されなければならない」と強調された。
  • C950 と AME：C950 はサーバー級 64 ビットスーパースカラプロセッサであり、RVA23 プロファイル（RVV 1.0 を含む）を汎用計算のベースラインとする；玄鉄が自社開発した行列拡張はシリコン検証後、Qualcomm、IBM、VRULL、ISCAS、BOSC などのメンバーと共同で AME（Attached Matrix Extension）タスクグループを発起し、仕様の正式承認・実装に向けて推進している。
  • 設計上のトレードオフ：AME はベクトルレジスタを再利用せず独立した tile レジスタを採用——行列負荷が RVV レジスタファイルを圧迫するのを避け、スピルとキャッシュ撹乱を低減し、混合精度累算（INT4／INT8→INT32、FP4／FP8／FP16／BF16→FP32）をネイティブにサポートする；行列状態はオンデマンドで有効化され、必要な時のみ保存／復元される。
  • エコシステムへの呼びかけ：孟建熠は三つの期待を提示した——高性能データセンターソフトウェアスタックの継続的な補完（Java ランタイム適配の成果はすでにコミュニティに還元済み）、完全な AI ソフトウェアチェーン（最適化オペレータライブラリ、コンパイラの更新、xPU としての RISC-V の完全なスタック）、そして ISA の開放性を活かした新たな拡張と計算パラダイムの探索。

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 openRuyi：Ruyi Firmware が 20261015 を連続リリース；K3 ファームウェアと UEFI ラインは調査期間内に複数件を推進

日付：2026-10-15　情報源：Ruyi Firmware 20261015 Release（10-15）、ruyifirmware コミット記録（10-15）、edk2-ruyi コミット記録（10-15）、openRuyi メインリポジトリ コミット記録（10-15）

openRuyi ファームウェアラインは3 日連続で新バージョン「Ruyi Firmware 20261015」をリリースし、K3 プラットフォームが引き続き反復の中心である。ファームウェア側は調査期間内に 8 件のコミット：raw SPI 焼き込みインストールドキュメント、A100-only モードの割り込みルーティング修正、System Information ページと DRAM リスト、グラフィックスコンソールの初期化、IMG GPU クロックのデバイスツリー修正、「選択可能な UEFI ドライバエミュレーション」のパッケージング；付随して edk2-ruyi 6 件——K3 システム情報ページ、SMBIOS による DRAM 構成の報告、GOP 初期化後のグラフィックスコンソール接続、プラットフォーム設定のグループ化と SPI-backed エミュレーションオプション。メインリポジトリ側は 8 件の SPECS 更新でセキュリティ保守が中心（cups、python-nltk（CVE-2026-81726）、capstone 5.0.9、llama-cpp 0.4.1、multipath-tools 0.15.1 のバックポートとアップグレード、spdk への bdevperf インストールなど）。openRuyi 公式サイトのニュースページには今期新バージョンの告知はない（最新は依然として 2026.09）。

1.2 RevyOS：7.3 カーネルブランチで K3／奕斯偉 EIC7700 などのプラットフォーム構成を一括有効化

日付：2026-10-15　情報源：revyos/linux revyos/7.3.y コミット記録（10-15）

RevyOS は 7.3 カーネルブランチ（revyos/7.3.y）の調査期間内に 20 件の一括構成コミットをマージした：起動チェーン側では linuxboot 構成とクロス／ネイティブビルド CIを新規追加；プラットフォーム側では一度に有効化——進迭時空 K3（UFS／DC）と K1（Banana F3 USB2）、奕斯偉 EIC7700（ARCH_ESWIN／DWMAC／PINCTRL）、TH1520 USB モジュール（RESET_GPIO を含む）、USB Type-C と表示リンク（TCPM／UCSI／DP_ALTMODE／PHY_SPACEMIT）、DRM_AST、ERRATA_PICOHEART など数十項目、さらに 8250 シリアルの実行ポート数を 6 に調整。このバッチは RevyOS がその 7.3 カーネルライン向けにマルチベンダーのプラットフォームサポート面を統一的に集約しつつあることを示している。

1.3 openKylin が OSS EU 2026 に登場：RVV 最適化により ONNX Runtime の FP32 推論が 2–5 倍高速化

日付：2026-10-15（会議 10-07~09）　情報源：MarkTechPost：openKylin Outlines Its Vision for Reimagining Linux in the AI Era at OSS EU 2026（10-15）、openKylin 公式サイト

MarkTechPost が Open Source Summit Europe 2026（プラハ）における openKylin の参加総括記事を掲載：執行董事の Min Liu 氏は基調講演で統合 AI ランタイム KART とシステムレベルの Agent 実行環境（「リソース管理」から「インテント管理」へ向かう三層アーキテクチャ：KART ランタイム層／Agent 実行層／能力層）を紹介；技術委員会メンバーの Jianfeng Li 氏は《Building an AI-Ready Linux Desktop on RISC-V》のライトニングトークを行った。RISC-V 側の要点：RVV カーネル最適化により ONNX Runtime FP32 推論が 2–5 倍高速化、関連するカーネル最適化と推論フレームワーク適合作業はアップストリームへの還元を計画；AI スタックは進畳時空 K3 上で vLLM による CPU 推論をサポートし、提供形態には .deb、Python wheel、Conda、Docker が含まれる。サミット会場では、進畳時空がopenKylin 3.0 をプリインストールした K3 ノート PCを展示した。

2. 製品とエコシステムの動向

2.1 先楫半導体 HPM5100 シリーズ RISC-V 混合信号 MCU が量産入り：アナログとモーター制御に注力

日付：2026-10-15　情報源：CNX Software：HPMicro HPM5100 RISC-V MCU integrates four 16-bit ADCs, four op-amps（10-15）

上海先楫半導体（HPMicro）のHPM5100 シリーズ 32 ビット RISC-V 混合信号 MCU が海外メディアで報じられた：初回 HPM5151 部品は 400 MHz RISC-V コア、416 KB SRAM＋1 MB Flash を搭載し、4 チャネル 16 ビット ADC、4 チャネルオペアンプ、4 チャネルアナログコンパレータを集積、アナログセンシングとモーター制御向け；インターフェースには USB 2.0 OTG（PHY 内蔵）、CAN FD、複数チャネルの UART／SPI／I2C と 32 チャネル PWM を含み、ハードウェア浮動小数点と DSP 命令をサポート。シリーズは量産済み：QFN48／QFN68／LQFP100 パッケージの価格は 15.60／16.90／19.50 元、EVK 開発ボードは 258 元；SDK 1.13.0（9 月）がサポートを追加済みで、SEGGER Embedded Studio for RISC-V も付属する。

2.2 香橙派 O1 が上市：算能 BM1688（RISC-V コプロセッサ含む）搭載、16 TOPS エッジ AI に注力

日付：2026-10-15　情報源：CNX Software：Orange Pi O1 SBC features 16 TOPS SOPHGO BM1688 AI SoC（10-15）、OrangePi O1 製品ページ

香橙派が OrangePi O1 シングルボードコンピュータを発表。算能 SOPHGO BM1688 SoC をベースとする：8コア Arm Cortex-A53 @1.65 GHz＋RISC-V C906 コプロセッサ @1.2 GHz、16 TOPS@INT8 ニューラルネットワーク加速エンジンを内蔵し、16路 1080p ビデオデコード／10路エンコードに対応；8／16 GB LPDDR4X、M.2 NVMe、デュアルギガビットイーサネットポート、Wi-Fi 6E／BT 5.3、2×USB 3.0 と 4G／5G モジュール拡張を提供。価格は 195ドル（8 GB）／325ドル（16 GB）（別途7.9ドルの冷却ファン）；Ubuntu イメージと Linux ソースコードは後日提供予定。算能 BM1688 エコシステム（従来は主にモジュールとサーバ形態）が汎用 SBC チャネルへと浸透し始めている。

2.3 楽鑫 ESP32-S31 Linux BSP に「フラッシュレイアウト設定可能」を追加；コミュニティ移植版が v0.3.1 をリリース

日付：2026-10-15　情報源：espressif/esp-linux-bsp（10-15 更新）、esp32-s31-linux：v0.3.1 Release（10-15）

「Linux on ESP32-S31」をめぐる2つの新たな進展：第一に、楽鑫 ESP32-S31 Linux BSP（esp-linux-bsp） の調査期間内に「esp32s31：フラッシュレイアウトを設定可能化」コミットがマージされた——このリポジトリは Buildroot イメージレイアウトとパッケージングツール（post-image フックが U-Boot SPL を Espressif イメージフォーマットにカプセル化し、SPL、U-Boot FIT、Linux デバイスツリー、XIP カーネルと cramfs ルートファイルシステムを s31_full_flash.bin に統合する）を担い、現在は開発者プレビューブランチでメンテナンスされている。第二に、コミュニティプロジェクト esp32-s31-linux が v0.3.1 をリリース（Linux 7.2＋OpenSBI 1.9 が ESP32-S31-Korvo-1 上で動作し、16 MiB PSRAM をメモリとして使用）、Bluetooth と 802.15.4 RCP サポートを新たに追加しリリースノートを整備した。ESP32-S31（デュアル RV32 コア @320 MHz）は「Linux のために生まれたわけではない」MCU から、公式とコミュニティの2つのオープンソースシステムパスを持つ実験プラットフォームへと変貌した。

2.4 RVSC2026 カウントダウン：会直前の最終ラウンドのアジェンダと講演者更新；サミット公式サイトのソースコードに13コミット

日付：2026-10-15　情報源：第六回 RISC-V 中国サミット公式サイトアジェンダページ（10-15 更新）、summit-website リポジトリのコミット記録（10-15）

第六回 RISC-V 中国サミット（10-18 開幕、深圳会展中心（福田））は会前の最終調整段階に入った：公式サイトの大會議題ページが調査期間内に更新——10-20 の RAG セッションの講題が《クラウドコンピューティング AI のアンロック：RISC-V CPU を使用した RAG ワークロードの加速》（アリババ達摩院 周云飛、呂一哲）に確定、香山 HPC セッションに共同講演者が追加され、DiffTest-H の講題が「30 MHz」に更新、ホームページの中国語・英語のヒーロー画像が差し替えられた；サミット公式サイトのソースコードリポジトリは調査期間内に 13 コミット（英語出展者まとめページの新規追加を含む）。会前の資料は開幕に向けてほぼ準備完了となっている。

2.5 The Next Platform が zeroRISC インタビューを掲載：オープンシリコンの10年

日付：2026-10-15　情報源：The Next Platform：A Decade In, zeroRISC Sees A Bright Future For Open Silicon（10-15）

The Next Platform が zeroRISC 創業者 Dominic Rizzo（OpenTitan 初期責任者）への長編インタビューを掲載し、オープンシリコンの10年とビジネスパスを振り返った。核心的論点の一つはRISC-V のオープン性が「オープンソース実装」にライセンスを発行したこと——「オープンソース ISA があるのなら、なぜ実装をオープンにしないのか」；zeroRISC は現在 OpenTitan セキュリティルート（RISC-V ベース） を基盤とし、データセンター、ICS／OT、IoT 向けにシリコン＋ソフトウェア＋クラウド管理の完全なソリューションを提供しており、サプライチェーンにおける信頼の中でのオープンシリコンの位置づけについても論じている。本記事はオープンハードウェアとセキュリティルート市場の進化を観察する一つの視点である。

3.3 算能：SG2042 SDK が v20261015 をリリース；tpu-mlir／sophon-sail 更新

日付：2026-10-15　情報源：sophgo/bootloader-riscv コミット履歴（10-15）、sophgo/tpu-mlir コミット履歴（10-15）、sophgo/sophon-sail コミット履歴（10-15）

算能は3ラインで推進：bootloader-riscv は SG2042 SDK v20261015 のリリースノートを公開（サーバープラットフォーム起動ファームウェアのバージョンごとの定例更新を継続）；tpu-mlir（TPU コンパイラ、998 スター）は「バックエンド更新」コミットをマージ；sophon-sail（推論インターフェース層）は rawstream モジュールの一時 FBC bm_image のライフサイクル問題を修正（PR #17）。新製品側（2.2 香橙派 O1 が BM1688 を採用を参照）と合わせ、算能の「チップ＋コンパイラ＋推論ランタイム＋本体チャネル」という端側 AI の組み合わせは調査期間内に多点的に展開している。

3.4 進迭時空：Agent 能力分散基盤が着地——APM、Agent Hub と Bianbu Skills ミラーが同日に実質的コンテンツ

日付：2026-10-15　出典：spacemit-com/agent-power-manager、spacemit-com/bibit-agenthub-plugin、spacemit-com/bianbu-skill、model-zoo-vision コミット記録（10-15）

10-13 に集中的にリポジトリを立ち上げた「Agent システムソフトウェア」リポジトリ群は、本調査期間で最初の実質的な内容を着地させ、端末側 Agent の能力配布インフラを指し示している：

  • APM（agent-power-manager）：Go で書かれたコマンドラインツールで、Skill／Plugin／MCP／Expert の四種類の「Power」の検索、インストール、アップグレード、アンインストール、コミットを同一のコマンドセットに集約する。Agent Power Cloud（APC）からメタデータを同期し、バージョン別インストール、トランザクションの復元が可能で、bibit などの対象 Agent をサポートし、Apache-2.0 でオープンソース化。
  • Bibit Agent Hub（bibit-agenthub-plugin）：Bibit 内蔵の「能力センター」——フロントエンドプラグイン（TypeScript／React）＋純標準ライブラリの Go CLI Provider。インストール済みリスト、APC 全量マーケットの閲覧、ワンクリックアップグレード、カスタムリソースのアップロードを提供し、riscv64 ビルドをサポート。
  • Bianbu Skills（bianbu-skill）：APC が公開する Skill の読み取り専用ミラーリポジトリで、第一期は 11 個の Skill（K3 メディアパイプライン、VPU／CoreMark ベンチマーク、RISC-V 移植アシスタント、ドキュメントから Markdown への変換、オフライン HTML アプリ生成など）を収録し、APC ディレクトリのスナップショットのままアーカイブ。
  • 付随更新：model-zoo-vision の 2 件の修正（OC-SORT カルマン追跡とメモリ安全 #100、視覚インターフェース契約と数値安全 #101）、ai-sdk の vision サブモジュール二度目の更新、llama.cpp（mtmd-backend）の上流同期（PR #46）と SMT パスの修正、lxqt-schedule への LXQt スケジュール管理とデスクトップリマインダーの導入。

前期デイリーレポートで述べた Bianbu AgentOS コンポーネントの集中的なオープンソース化の後、進迭時空が補ったのはまさに「能力配布とバージョンガバナンス」というこのピースである。

3.5 矽速：SLogic にブラウザ内ファームウェアアップグレードを追加、MaixPy に 3 件をマージ

日付：2026-10-15　出典：sipeed/SLogic コミット記録（10-15）、sipeed/MaixPy コミット記録（10-15）

矽速のロジックアナライザソフトウェア SLogic は引き続き高頻度でイテレーションを重ねている。本調査期間で Web ファームウェアアップグレード（ブラウザ内で SLogic16U3／32U3 に OTA を配信）を新たに追加し、基盤ライブラリは 800 MHz クロック基準に切り替え、ngscope ADC 関連問題を修正（ALL-LOGIC も同時期にコミット）。MaixPy のメインブランチには 3 件をマージ（RVV ドキュメントのナビゲーションとサンプルの整備など）。SLogic v2.3.0（10-14）のリリース後も、ツールチェーンとファームウェアアップグレード体験はなお急速に磨き込まれている。

4. 身体性知能とロボット専門章

4.1 進迭時空 ROS2 シミュレーション：ヒューマノイドロボット humanoid_mujoco に RGBD シミュレーション起動コマンドを追加

日付：2026-10-15　出典：ros2_simulation コミット記録（10-15）

spacemit-robotics 組織において本調査期間で唯一のプッシュは ros2_simulation に着地した。humanoid_mujoco パッケージ（ヒューマノイドロボットの RL と MuJoCo 同一インスタンスシミュレーション、専用構成「霊龍」LingLong を含む）に RGBD シミュレーション起動コマンド hmi_runtime を新規追加（3D LiDAR／RGBD カメラ、ポイントクラウドと TF 配信、RTAB-Map／Nav2 連携に対応）。このリポジトリのビルドターゲットは k3-com260-kit-humanoid-linglong であり、「ヒューマノイドロボットシミュレーション訓練（MuJoCo＋RL）→ K3 ロボットキット」というチェーンがソフトウェア側でさらに補完された。本調査期間の Agent 能力配布インフラの着地（3.4）と合わせて、進迭時空の「チップ—AgentOS—シミュレーション／RL ツールチェーン」という三層の組み合わせの輪郭がより鮮明になっている。ロボット側は現在もシミュレーションと運動制御が中心で、本調査期間に新ハードウェアの発表はない。

5. 総括とトレンド観察

  • 玄鉄ハイパフォーマンス叙事が国際チャネルへ展開：C950 シングルマシンで 27B 大規模モデルを実行した成果が RISC-V 国際基金会公式サイトのインタビューを通じて広まった（さらに 10-22 北京セミナーと 10-20 サミット AME セミナーを重ねて）、サミット週のウォームアップとなり、AME は「自社開発マトリクス拡張」から「Qualcomm／IBM などを巻き込んで共同推進する標準提案」へと格上げされ、最も追跡に値する手がかりとなった。
  • オープンソースディストリビューションとファームウェアの「プラットフォームカバレッジ競争」：openRuyi ファームウェアは連日更新（K3 ライン 8 コミット＋UEFI 6 コミット）、RevyOS 7.3 カーネルは K3／EIC7700 などのプラットフォーム設定を一括で取り込んだ——RISC-V ディストリビューションの競争焦点は「起動できるか」から「プラットフォームの広さ＋UEFI 体験＋セキュリティ保守」へと移りつつある。
  • 端末側 Agent 基盤がコンポーネントから配布へ：進畳時空の APM／Agent Hub／Skills イメージが「公開—検索—インストール—バージョンガバナンス」のクローズドループを形成し、RISC-V 端末側 Agent エコシステムに付随するエンジニアリングツールチェーンが現れ始めた。
  • 三つの細分化製品ラインが同一期間に新登場：先楫 HPM5100（混合信号 MCU 量産）、香橙派 O1（エッジ AI SBC）、楽鑫 ESP32-S31 Linux BSP の反復＋コミュニティ v0.3.1——MCU、AI ボックス、Linux-on-MCU の三方向でそれぞれ新たな供給がある。
  • サミット週開幕間近：RVSC2026 は日曜日（10-18）に深圳で開幕し、次号では開幕式、メインフォーラム、各テーマ別分科会の初日の内容を重点的に観察する。
  • 制限事項の説明：openKylin の項目は 10-15 の報道に基づく（会議は 10-07～09）、詳細は公式の後続資料を基準とする。コミュニティの ESP32-S31 Linux プロジェクトは愛好家プロジェクトであり、成熟度はそのリリースノートを基準とする。一部のリポジトリは調査期間内にブランチレベルのプッシュのみであり、情報源検証表に注記済みである。
