1. オープンソースコミュニティとソフトウェアエコシステムの動向

1.1 RISC-V 公式高保証暗号（HAC）仕様が集中的に更新：ML-KEM/ML-DSA ポスト量子暗号の記述を細分化（本日のトップニュースの一つ）

日付：2026-08-15（11:34~23:25 UTC 約 20 コミット）　出典：riscv/riscv-high-assurance-cryptography GitHub

RISC-V 国際財団の高保証暗号（HAC）仕様リポジトリは、調査期間内に約 20 コミットを集中的に行い、主にポスト量子暗号と高保証実装を巡るものとなった：ML-KEM（Kyber ポスト量子鍵カプセル化）と ML-DSA（Dilithium ポスト量子署名）の命令セット記述改訂、ACE-ISA-unpriv 仕様の文言統一（”must” を “shall” に変更）、OCB3 構造の簡素化、CR 表現と容量上限の明確化などで、レビュー意見（review1.md）への対応や AsciiDoc の組版修正も含まれる。HAC は RISC-V の FIPS 140-3 級高保証暗号実装（定数時間、サイドチャネル防護）向けの拡張仕様であり、その ML-KEM/ML-DSA などのポスト量子命令セット記述が集中的な改訂段階に入ったことは、RISC-V 暗号拡張が実用化・標準化へ収斂しつつあることを示す——RISC-V が金融/行政/クラウドの信頼境界に入ることに直接的な意味を持ち、今週の Spectre 論文が引き起こしたセキュリティ信頼の議論と呼応している。

日付：2026-08-15（06:00/16:08 UTC コミット、北京 14:00/08-16 00:08）　出典：OpenXiangShan/difftest GitHub

香山に付随する difftest（差分協調検証フレームワーク）は、調査期間内に三项の改善をマージした：feat(mma): add configurable verifier backpressure (#923)（mma 検証器の背圧を設定可能に）、feat(mma): batch contiguous verification requests (#920)（連続検証リクエストを一括統合し、検証スループットを向上）、fix(runtime): support Darwin arm64 hosts (#930)（macOS Apple Silicon ホスト対応を新規追加）。うち Darwin arm64 対応はローカル開発検証フローに有利である。調査期間内に XiangShan メインリポジトリは 08-15 18:07 UTC にプッシュされ（メインブランチの最近のマージは依然として 08-14 の satp 修正 #6014、当日はブランチ/CI の動向）、XSCache（08-15 18:55 UTC）、difftest、NEMU、CoupledL2、GEM5、env-scripts、circt などの周辺リポジトリも同時に活発で、香山フルスタックは引き続き高頻度で反復している。

4. 重点方向専章：具身智能とロボティクス

4.1 デュアルコア RISC-V RT-MCU：運動制御基盤の「異種分担」ナラティブが形成

本調査期間で最も方向性を示すシグナルは電子工程専輯の特集『デュアルコア RISC-V RT-MCU はいかにして具身ロボットの運動制御基盤を支えるのか？』（08-15）：デュアルコアアーキテクチャ（リアルタイムコアがモータ/関節制御ループを実行＋アプリケーションコアが通信/知覚/エッジ AI を実行）が具身ロボット運動制御基盤の主流設計思想となり、代表製品である峰岹 FU75XX シリーズ（32 ビット RISC-V デュアルコア、デュアルモータ駆動）は 2025-11 以降「未来のロボットのために生まれた」という位置づけを掲げている。これは滴水湖フォーラム（08-13）の運動制御シグナルと完全に同頻である：格見半導体 500 ナノ秒電流ループ/単チップ 25 自由度（昨日のレポート 3.3）、先楫 HPM53M1 ヒューマノイドロボット関節制御、進迭時空 K3 ロボット運動制御ポジショニング——国産 RISC-V 運動制御ソリューションは「シングルコアリアルタイム DSP/MCU」から「デュアルコア異種（リアルタイム＋インテリジェント）」へと進化しつつあり、運動制御層の国産代替パスがさらに具体化している。

4.2 端側 AI 推論の NPU 化：SPERT 全体グラフカーネルパス

進迭時空 llama.cpp ブランチの SPERT 全体グラフカーネルパス（3.1）と算能 YOLOv8-pose の実戦級修正（3.2）は、ともに具身智能ソフトウェアスタックの成熟化を指し示す：前者は LLM/VLA 推論を端側 NPU エンジンへと下沉させ（低消費電力リアルタイム性）、後者は視覚知覚サンプルのエンジニアリング欠陥を継続的に修正している。昨日の LeRobot（SmolVLA/ACT）端側デプロイとヒューマノイドロボット対応を踏まえると、RISC-V 具身智能の「知覚（視覚）— 意思決定（端側 LLM/VLA）— 運動（デュアルコア RT-MCU 運動制御）」という三層の国産化パスが次第に明確になりつつある。

5. まとめとトレンド観察

  1. ポスト量子暗号が RISC-V 規範のホットスポットに：RISC-V 公式 HAC 規範は調査期間内に約 20 件のコミットで ML-KEM/ML-DSA などのポスト量子暗号命令記述を細分化し、暗号拡張は FIPS 級の高保証実装へと収束——今週の Spectre-on-RISC-V 論文が引き起こしたセキュリティ信頼の議論と同方向であり、セキュリティ/暗号は RISC-V エコシステムの公式優先議題となりつつある。
  2. 運動制御層の「デュアルコア異種」ナラティブが形成：電子工程専輯の特集（デュアルコア RISC-V RT-MCU）＋峰岹 FU75XX＋滴水湖フォーラムの運動制御新製品（格見/先楫/K3）が同頻し、具身ロボット運動制御基盤の国産 RISC-V ソリューションは「シングルコアリアルタイム」から「リアルタイムコア＋アプリケーションコア」のデュアルコア分担へと移行。
  3. 端側 LLM 推論加速が NPU へ下沉：進迭時空 llama.cpp が SPERT 全体グラフカーネルパスをマージし、端側大規模モデル推論は「CPU で動かす」から「NPU 全体グラフ加速」へと邁進、オペレータライブラリ（FlagGems-RACE）、推論文書（docs-ai）と完全なチェーンを構成。
  4. 奕斯偉 IPO が「上場前夜」に：香港市場「RISC-V アーキテクチャ第一株」のナラティブが上場間近まで前進、3年間で累計49億の赤字ながら、車規 MCU/CMS 製品ラインと国産 RISC-V 主力ナラティブがこれを裏付ける。
  5. 検証インフラが持続的に強化：香山 difftest が検証器のバックプレッシャ制御とバッチ検証（スループット向上）を追加、macOS arm64 ホストサポートを新規追加、オープンソース高性能コアの検証効率が競争力の焦点に。
