香山オープンソース高性能コア（昆明湖）ベクトルサブシステムが「機能展開」から「構造再構築」へ移行：09-09 22:06 の隣接する 2 つのコミットでそれぞれベクトル浮動小数点演算の VFAlu と VFMA のラッパー層を削除（refactor(vector): remove VFAlu wrapper and set fuGen to null in VfaluCfg、remove VFMA wrapper and set fuGen to null in VfmaCfg）し、機能ユニット設定による直接生成に切り替えた。これは 09-06 から 09-08 に連続してマージされたもの（レジスタ全体移動、vfma/vfmac と widen 命令、VIDiv ベクトル整数除算）に続くパス整理であり、通常はこの命令群が安定化とその後の行列／縮約演算拡張の前置段階に入ったことを意味する。同じ調査期間のその他のコミットはフロントエンドと実行の詳細をカバー：09-09 23:36 fix(decode,rename): handle JAL/JALR link and jump uops（著者日付 05-08、長期ブランチバッチの最終マージ）、09-09 09:26 fix(I2F): pipeline move op's fflags result signal（#6519）、09-09 15:17 ci(emu): determine emu-mc threads with verilator version（#6517）。関連側：XiangShan-Dashboard は 09-10 03:10 に release: 1.0.0 をリリースし、バージョンとビルド時間のバッジを追加；difftest は fix(fpga): recover specified name of XMR probe（#959）をマージ；XiangShanLab は Zicfilp（landing pad ジャンプ先検証拡張）テンプレートを追加；GEM5 はリポジトリの code owner を追加。openxiangshan 組織では調査期間内に 16 のリポジトリ（XiangShan、difftest、GEM5、CoupledL2、XSCache、gsim、rocket-chip、ZhuJiang など）にプッシュがあり、依然として現在最も活発なオープンソースコアチームであり、検証とツールチェーンの関連も同期して進化している。

2. 製品とエコシステムの動向

2.1 微雪 Waveshare が ESP32-C5 Pico ボードを発表：デュアルバンド Wi-Fi 6 RISC-V マイクロボードがラズベリーパイ Pico のフォームファクタを採用（09-09）

日付：2026-09-09　情報源：CNX Software、Open Source For You、Waveshare ドキュメントサイト、GitHub waveshareteam/ESP32-C5-Pico

Waveshare（微雪）が ESP32-C5 Pico ボードを発表し、Espressif ESP32-C5 デュアルバンド Wi-Fi 6 SoC をラズベリーパイ Pico フォームファクタ（約 51～56.85 x 21 mm）に導入した。主要仕様：ESP32-C5-MINI-1/1U モジュール（ESP32-C5HF4、シングルコア 32 ビット RISC-V 最大 240 MHz に加え 48 MHz 低消費電力 RISC-V コア、384 KB SRAM、320 KB ROM、4 MB SPI flash）、無線はデュアルバンド 2.4/5 GHz 802.11ax Wi-Fi 6 および Wi-Fi 4 下位互換、Bluetooth 5.0 LE（Mesh 含む）、802.15.4（Zigbee 3.0 / Thread 1.3 / Matter）をサポート。オンボード USB-C（給電、書き込み、充電）、2x20 pin Pico 互換ピンヘッダ（最大 26 路 GPIO、20 路 PWM、他 6 路は TCA9554PWR 経由で拡張）、リセットと BOOT ボタン、RGB LED とリチウム電池充放電回路を搭載；4 バージョンを提供（オンボード PCB アンテナまたは IPEX 外付けアンテナ、ピンヘッダ実装済みまたは未実装）、ソフトウェアは Arduino IDE と ESP-IDF をサポート、サンプルコードは公式サイトから GitHub へ移行（ボード情報、RGB、I/O 拡張、デュアルバンド Wi-Fi、UART、1.83 インチタッチスクリーン、MCP2515 SPI CAN など）。意義：ESP32-C5 が 2025 年 4 月に量産されて以降、その「デュアルバンド Wi-Fi 6 + RISC-V」能力は Pico 互換形態に沿ってダウンストリーム市場へ拡散しており、サードパーティ製ボードエコシステム（Waveshare は深圳のメーカー）が Espressif の RISC-V ワイヤレス MCU の実装を直接増幅する存在となっている。

2.2 兆易創新、ポッドキャストで RISC-V、ロボティクス、エッジ AI を語る：GD32 デュアルアーキテクチャ路線と EtherCAT 分散制御（09-09）

日付：2026-09-09　情報源：Electropages、GigaDevice ヒューマノイドロボットソリューションページ、GigaDevice GD32V リリース発表

Electropages ポッドキャスト（Robin Mitchell と兆易創新の事業開発マネージャー Kevin Jones の対話）は、同社の MCU 路線を系統的に取り上げた：RISC-V に関しては、兆易創新は比較的早い段階での主流採用者であり、2019 年には GD32VF103（コアは芯来科技が提供、両社は公開で協力）を発表、現在のワイヤレス製品ラインも RISC-V を採用しており、公式はアーキテクチャの柔軟性によりチップメーカーが特定のアプリケーションと負荷に合わせてプロセッサをカスタマイズできると強調；ロボティクスに関しては、産業用ロボットの多モーターと複雑な運動によりコントローラ間通信の決定性への要求が高まっており、GD32H7 シリーズは EtherCAT をサポートし、分散 MCU がそれぞれ単一モーターとローカルサブシステムを制御することで、すべての意思決定を中央プロセッサに戻す依存を減らすことが可能；エッジ AI に関しては、モーター異常検知、人体検知などのローカル推論タスクはハイエンド AI プロセッサに依存する必要がなく、Cortex-M7/M33 はモデルを圧縮すればすでに担うことができ、コスト敏感なシーンでのクラウド依存を減らすのに有利。兆易創新のヒューマノイドロボットソリューションページ（「知覚—意思決定—制御—実行」アーキテクチャ、MCU、メモリ、アナログチップの組み合わせで器用な手、関節モジュール、IMU、電源管理などをカバー）と合わせて見ると、その「Arm + RISC-V デュアルアーキテクチャ + ロボティクス/エッジ AI」という国産 MCU のポジショニングがうかがえる。本条はインタビュー類の内容であり、新製品発表はなく、戦略観察として収録する。

3. 国内チームの動向と深掘り

3.1 進迭時空：新世代コヒーレント相互接続バス N200 の研究開発完了、汎用計算＋知能計算＋相互接続の三大板塊を形成（09-07 発表、今回補録）

日付：2026-09-07（会社発表；以前の 2 回の調査期間で漏れ、今回補録）　情報源：進迭時空公式サイトニュース、GitHub spacemit-com/model_zoo_rl、spacemit-com/ai-sdk

進畳時空が公式サイトで明らかにしたところによると、同社の新一代自研高性能コヒーレント相互接続バス N200 が正式に開発を完了した。汎用計算 CPU コア（X60/X100/X200）と智能計算 AI コア（A60/A100/A200）の布局に続き、N200 の完成は「汎用計算、智能計算、計算相互接続」という三大核心技術板塊の布局が完了したことを示す。N200 は通算コア X200、智算コア A200 とともに次世代計算チップに用いられ、2027 年の正式量産が予定されている。これは K3（世界初の RVA23 規範に準拠した量産 RISC-V AI CPU、60 TOPS、300 億から 800 億パラメータの端側推論をサポート）に続くアーキテクチャの縦深的な動きである。自研相互接続バスは、その次世代チップが「既製 NoC の採用」からフルスタック自研へ転換することを意味し、マルチコアコヒーレンスと AI コア連携帯域幅を直接支える。調査期間内の GitHub 側では、進畳時空（spacemit-com）の端側 AI ツールチェーンが継続的に迭代している。ai-sdk は 09-09 14:01 と 17:45、翌日 00:22（北京時間）に rl/vision サブモジュールを複数回更新した。model_zoo_rl は 09-09 20:19 に feat(rl): support inference cancellation and YAML provider selection（#11）をマージした。model-zoo-vision、docs-ai、linux にもプッシュがある。RL モデルライブラリと推論キャンセル、YAML provider 選択などの機能は、ロボットと具身シーンにおける中断可能な推論とマルチバックエンド切替の実際の需要に対応している。（注：同社ニュースページには同一バッチで K3 の DeepSeek Harness 実行成功、GIS 2026 出展などの項目も掲載されているが、対応する事件はいずれも以前の調査期間に属するため重複収録しない。）

3.2 芯来科技：英媒が Quintauris RISC-V エコシステム協業を総括、芯来の車規 IP が RT-Europa に整合（英文メディア 09-08~09 総括、協業本体は 2026 上半期）

日付：2026-09-08（Electronics World 総括記事、New Electronics 09-09 同題報道）　情報源：Electronics World、Automotive World、Quintauris ニュースルーム、芯来科技公告（2026-06-16）

英メディア Electronics World は 09-08 に総括記事を掲載し、New Electronics は 09-09 に同題で報じた。Quintauris は継続的な協業を通じて RISC-V エコシステムを拡大しており、2026 上半期に四つの協業を新たに追加した——Elektrobit（04-21、自動車ソフトウェア、ソフトウェア定義車両に対応）、芯来科技 Nuclei（06-16、車規級 RISC-V プロセッサ IP を Quintauris RT-Europa リアルタイムプラットフォーム規範に整合）、Ashling（デバッグと開発ツール）、そして EM-Altair Profile 規範であり、ソフトウェア、ハードウェア、ツールチェーンをカバーする。うち芯来部分の核心は以下である。RT-Europa は自動車リアルタイム RISC-V プロセッサ向けの初のプラットフォーム規範（決定論的メモリアクセス、割り込み処理、特権モード、物理メモリ保護、デバッグインタフェース、SoC 統合要件を定義）であり、芯来は量産検証済みの NA シリーズをこれに整合させる。芯来 NA シリーズは世界初の ISO 26262 ASIL-D 認証を取得した RISC-V プロセッサ IP であり、ASIL-A から ASIL-D をカバーし、顧客は既に 300 社を超え、レーザーレーダー、ミリ波レーダー、ドメインコントローラ、車規 MCU、車載イーサネット、SoC セーフティアイランドに応用されている。明確にすべき点として、本項目は英文メディアによる既存協業の総括的な再報道であり、協業本体はいずれも 2026 年上半期に発生しており（本調査期間の新規事件ではない）、収録価値は「中国の RISC-V IP が国際車規参照プラットフォームに参入する」という産業シグナルを再び増幅させる点にある。調査期間内に Nuclei-Software の GitHub 組織 42 リポジトリにはプッシュがなく、自主開発の動きはない。

3.3 総合調査期間観察：玄鉄 Hypervisor Za* テストを統計スクリプトに統合、算能 SG2044 UEFI、矽速 NanoKVM の定例迭代（09-09）

5. 総括と趨勢観察

本レポートの調査期間はニュース側がやや弱く、オープンソース側が活発で、国内は展覧会初日「議程が落地し、実況の放出を待つ」移行状態に入っている。要点は以下の通り。

其一、オープンソースコアは構造再構築期に入っている。香山は三日連続で新ベクトル後端命令面（整レジスタ移動、vfma/widen、VIDiv）を展開した後、09-09 に VFAlu/VFMA 包装層を削除し配置による直接生成に切り替え、XiangShan-Dashboard 1.0.0 リリース、difftest FPGA プローブ修復、XiangShanLab への Zicfilp テンプレート追加と相まって、検証とツールチェーンの配套が同期して推進されている。達摩院玄鉄は Hypervisor 原子類命令テストを統計スクリプトに統合し、テストベースラインを継続的に固めている。オープンソース側のシグナル品質はニュース側を上回っている。

其二、RISC-V 端側は「無線接続 + ロボット制御」の二線製品叙事を形成している。ESP32-C5（デュアルバンド Wi-Fi 6 RISC-V SoC）は微雪ボードを通じて Pico 互換形態へ拡散し、開発者の参入障壁を下げている。兆易創新は GD32 の Arm+RISC-V デュアルアーキテクチャに EtherCAT 確定性制御と Cortex-M7/M33 エッジ推論を重ね、RISC-V をロボット/産業制御製品マトリクスに組み込んでいる。

其三、国内チームのアーキテクチャ縦深が推進されている。進迭時空 N200 の自研一貫性相互接続バスが研究開発を完了し、「汎用演算コア + 知能演算コア + 相互接続バス」の三大板塊を補完、2027 年量産の次世代チップ全スタック自研を指向している。その GitHub 側の RL モデルライブラリと割り込み可能推論、マルチバックエンド選択などの機能反復は、具身智能シーンのニーズに直接対応している。芯来科技の車規 IP は再び国際メディアの盘点で言及され、中国の RISC-V IP が国際車規参考プラットフォームに継続的に組み込まれていることを反映している（協力本体は 2026 年上半期であり、新規事件ではない）。

其四、展覧会ウィンドウは開いたが実況は未到着。深圳 IICIE 初日、RISC-V 産業エコシステム創新大会の議程（清芯智研、国芯科技、算能、隼瞻、進迭時空、芯際無限、中徳工業の七講演）と「具身智能産業大会」が同期して落地し、達摩院玄鉄、算能、進迭時空などが集中的に出展している。初日の現場報道と発表内容は本調査期間内では依然として検索チャネルにインデックスされておらず、後続の追跡価値は高い。
