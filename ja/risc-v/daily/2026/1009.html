日付：2026-10-08　出典：新浪財経（格隆匯）：奕斯偉計算の香港公開発売が9.09倍の応募、10月9日上場（10-08）、華盛通：暗盤引け、奕斯偉計算は1.6%高（10-08）、鳳凰網（瑞恩資本）：「RISC-V 第一股」は10月9日に香港上場予定（10-08）

1. オープンソースコミュニティとソフトウェアエコシステム

1.1 SpacemiT：Linux 7.4 デバイスツリー更新、K3 の周波数調整・温度制御・ファン制御を有効化

日付：2026-10-08　情報源：Phoronix「SpacemiT RISC-V SoCs To See More Improvements With Linux 7.4」（10-08）

上流カーネルの SpacemiT K3／K1 向けデバイスツリー更新 pull request が 10-08 に発出された（Linux 7.4 への投入を予定）：K3 の CPU 周波数調整サポートをより多くのハードウェアに拡大し、RFKILL ノードを有効化、さらに温度制御とファン制御を新規追加——K3 CoM260 システムモジュール上の CTF2301 センサーチップ向け；K3 ベースの Muse Pi Pro、Orange Pi R2S、Orange Pi RV2 開発ボードはいずれもこのバッチで CPU 周波数調整が有効化される。K1 側ではオンボード EEPROM サポートを有効化し、EEPROM データからの MAC アドレス設定をサポートする。K3 は初の量産 RVA23 チップの一つとして、上流サポートの収束が続いている。

1.2 RevyOS：カーネル設定を一括投入、K1／K3 と EIC7700 プラットフォームを推進

日付：2026-10-08　情報源：revyos/linux コミット記録（revyos/7.3.y ブランチ、10-08）

RevyOS カーネルリポジトリ（revyos/linux）は調査期間内に一度のプッシュで 20 余りの設定コミットを投入：dp1000 と K1／K3 専用設定（K3 ディスプレイ DC、K3 UFS、Banana F3 の K1 USB2）を新規追加；ESWIN EIC7700 アーキテクチャと DWMAC、PINCTRL ドライバ、TH1520 GPU 電源シーケンス、RTC／RESET_GPIO など一連の常用ドライバを有効化；USB-C 側では Type-C ロールスイッチ、TCPM、UCSI、FUSB301 と DP オルタネートモードを有効化。CI 側ではクロス／ネイティブビルドタスクと linuxboot 設定を新規追加。マルチプラットフォーム（TH1520／K1／K3／EIC7700）向けのディストリビューションカーネル設定が、連休後最初の調査期間に集中的に展開された。

1.3 openRuyi：SPECS を一括拡充、go-github シリーズ 20 余りを一度に取り込み

日付：2026-10-08　情報源：openRuyi コミット記録（10-08）、openRuyi コミット：cgctl が現在の cilium-ebpf API をサポート

openRuyi メインリポジトリは調査期間内に一度に 20 余りの SPECS コミットをマージ：go-github-* シリーズのパッケージ定義（gopsutil、gokrb5、nats.go、cassandra-gocql、aliyun-credentials-go、google-cel-go など）を一括追加し、cgctl を現在の cilium-ebpf API に適合させ、jcmturner-gokrb5-v8 の Go ビルドを修正。その公式サイトのニュースページと照合したところ——2026.09 バージョン以降新規リリース告知はなし；本バッチの拡充はリリース後のソフトウェアソース日常補包に属し、クラウドネイティブと可観測性関連の Go エコシステム依存をカバーしている。

1.4 香山：FEX0 のバックエンド修正 2 件が完了、メインブランチにマージ

日付：2026-10-08　情報源：XiangShan PR #6649：x0 変換のために FEX0 出力スロットを保持（09-29 起票、10-08 マージ）、XiangShan PR #6651：FEX0 内の未使用 F2vCfg を整理（09-29 起票、10-08 マージ）

1.5 香山シミュレーションチェーン：NEMU が複数の PR を連続起票、difftest が独立アクセラレータクロックをサポート

1.6 エコシステム短波：Chipyard が PMU ライブラリをマージ、riscv-unified-db に Zkr／Sdext エントリを追加

日付：2026-10-08　出典：Chipyard PR #2387：PMU ライブラリのマージと BOOM v3 への PMU 設定追加（10-08）、riscv-unified-db コミット記録（10-08）

オープンソース SoC フレームワーク Chipyard（UC Berkeley）は調査期間内に #2387 をマージ：PMU（性能監視ユニット）ライブラリをジェネレータサブモジュールとして導入し、BOOM v3 に PMU 設定を追加、サブモジュールポインタも同期更新——アウトオブオーダーコアのハードウェア性能分析のための基盤を補完した。riscv-unified-db（仕様の機械可読データベース）は Zkr シード CSR（C++ バックエンドのエントロピー源サポートを含む）、Sdext 拡張の記述と不正命令処理などのエントリを新規追加し、仕様データベースの拡張カバレッジは引き続き拡大している。

2. 製品とエコシステムの動向

2.1 Vayavya Labs が Tenstorrent と提携：SystemC 仮想プラットフォームで RISC-V ソフトウェア・ハードウェア開発を加速

日付：2026-10-07　出典：Tenstorrent ニュースルーム：Vayavya Labs 提携発表（10-08）、PR Newswire リリース（10-07）

Vayavya Labs は Tenstorrent の仮想プラットフォームパートナーとなることを発表：同社の TvastaaVP プラットフォームを基盤に、Tenstorrent のセキュリティおよびシステム管理 IP 向けの SystemC 仮想プラットフォームを構築し、ソフトウェアがテープアウト前に早期に開発・検証できるようにして統合リスクを低減する。両社はこの提携が単発のモデリングから複数年にわたるパートナーシップへと格上げされると述べ、Tenstorrent がバンガロールで開催する RISC-V エコシステムイベント「The Open Frontier」（10-08）で同席して共有する予定。デザインシフト左（shift-left）は RISC-V 高性能チップの競争要素となりつつある。

2.2 算能：SG2044 が SDK v20261008 リリースコミットをマージ、ボードレベルコードネームを SRM31 に改名

日付：2026-10-08　出典：bootloader-riscv コミット記録（10-08）

算能 bootloader-riscv はウィンドウ内で SG2044 シリーズの3件のコミットを完了：ボード級コード名 SRM3-C0 を SRM31 に改名、リリーススクリプトを新規追加（release script）、そして SDK v20261008 リリースのコミットをマージ——64コア RISC-V サーバープラットフォーム SG2044 のファームウェアと SDK が新たなバージョン化デリバリの段階に入った。同期間に sophgo-edk2、edk2-platforms などのリポジトリにも保守的なプッシュがあった（SRM/cv シリーズの UEFI サポートライン）。

2.3 Radxa Linkr v1.5.2 リリース：FN ダブルクリックでホットスポット切替、Q8B 解像度切替を修正

日付：2026-10-08　情報源：Radxa Linkr v1.5.2 リリース（10-08）

Radxa のブラウザリモート管理製品ライン Linkr が v1.5.2 をリリース（前バージョン v1.5.0 は 09-24 にリリース）：新機能はFN ユーザーキーの素早いダブルクリックによる Wi-Fi ホットスポットのオン／オフ切替；Wi-Fi モジュールの制限に適応するためホットスポット帯域選択を改善（未接続または 5GHz 接続時は 5GHz を使用、2.4GHz 接続時は 2.4GHz を使用）；Radxa Dragon Q8B を映像入力源として使用する際の解像度切替問題を修正。開発ボード／NAS のアウトオブバンド管理シナリオを継続的に打磨。

2.4 矽速：Tang Mega 138K／AE350 Linux リポジトリを新規作成、NanoKVM Go ボード級サポートを推進

日付：2026-10-08　情報源：sipeed/Tang-Mega-138K-Linux リポジトリ（新規作成）、maix_ax620e_sdk コミット記録（10-08）

矽速（Sipeed）はウィンドウ内で Tang-Mega-138K-Linux リポジトリを新規作成、説明は「Tang Mega 138K のハードコア AE350 Linux リポジトリ」——この FPGA 開発ボードには 32 ビット RISC-V AE350 ハードコア（800MHz）が搭載されており、このリポジトリはハードコアへの Linux 移植の立ち上げを指し示す（リポジトリは暫定空、早期シグナルに属する）。同期間に maix_ax620e_sdk の U-Boot に NanoKVM Go ボードカード身分検証と復旧モード Logo 表示を追加；SLogic／scopehal ツールチェーンと sipeed_wiki など 6 つのリポジトリにもプッシュがあった。

3. 国内チーム深掘り

3.1 奕斯偉計算：H 株価格 1.55 香港ドル、純調達 23.86 億香港ドル、暗盤終値 1.6% 上昇

日付：2026-10-08　情報源：新浪財経（格隆匯）：公開販売で 9.09 倍の応募（10-08）、華盛通：暗盤終値 1.6% 上昇（10-08）、21 経済網：招股開始報道（10-03）

本日の上場に関して、奕斯偉計算（01256.HK）は最終配分結果を開示（詳細は「今日の重点」参照）：価格 1.55 香港ドル、純調達 23.86 億香港ドル、香港公開販売で 9.09 倍の応募。背景データ（招股期間報道）：中国 RISC-V 主控チップ市場規模は 2021 年の 11 億元から 2025 年の 377 億元へ増加、年平均複合成長率約 139.5%；同社は 2025 年収入ベースで中国最大の国産スマート端末人機対話チッププロバイダー、第 3 位の国産 RISC-V 主控チッププロバイダー；今回 9 社の基石（通富微電、頎中科技傘下主体を含む）を導入し合計 11.61 億香港ドルを応募。

3.2 紫荊半導体：車載規格 RISC-V チップ出荷が 1000 万個を突破、「小脳」制御チップ E100 を開発中

日付：2026-10-08　情報源：鳳凰網（網通社速報）：紫荊半導体車載チップ出荷量が 1000 万個を突破（10-08）

長城汽車が孵化した湖南紫荊半導体は調査期間内に、車載グレードチップの出荷数がすでに1000万個を突破したと開示した。その M100（国内初のオープンソース RISC-V コア車載グレード MCU）は 2025-12-18 に量産・車載搭載され、組み合わせヘッドランプ、アンビエントライト、コンビネーションスイッチなどの車体制御に応用されている。IP、製造、封止・テストはすべて国産化され、提携顧客は15社超。認証面では ISO 26262 ASIL-D プロセス、ASIL-B 製品、AEC-Q100、ASPICE などの認証を取得済み。製品ロードマップ：M200 は 2026年第4四半期にテープアウト予定（40nm、コンビネーションメータ／T-BOX／ゲートウェイ／BCM）、M300 はゾーンコントローラに位置づけ、A100 シリーズは電源と駆動チップ。具身智能方向では初の「小脳制御」チップ E100（RISC-V アーキテクチャ）を研究中で、まだ量産には至っていない。2026年5月に紫荊は長城汽車などと共同で RISC-V 産業創新センターを設立した。

3.3 進畳時空：spine-triton バックエンド修正がマージ、ai-gateway が 0.2.0 にアップ

日付：2026-10-08　情報源：spine-triton コミット記録（10-08）、ai-gateway PR #44：ゲートウェイが 0.2.0 にアップ（10-08）、mpp コミット記録（10-08）

3.4 楽鑫：esp-nn が RISC-V PIE カーネルの非アラインドアクセス問題を修正

日付：2026-10-08　情報源：esp-nn コミット記録（10-08）

楽鑫 esp-nn（ニューラルネットワークオペレータライブラリ）は調査期間内に RISC-V 関連の修正を一括マージした：max_pool の RISC-V PIE カーネルで非アラインドストアを有効化、各カーネル入口で PIE 非アラインドアクセスビットを設定（今回の修正は ESP32-P4 上の非アラインドストアによる問題に対応）、さらに GitHub issue #36 由来の6つの CONV_2D 形状テストを追加、CI を esp-emu 0.46 シミュレータに切り替え。esp-idf 側は調査期間内に14件のマージがあり、SPI／USB Host／低消費電力修正が中心（例行メンテナンス）；楽鑫組織の調査期間内合计30のリポジトリがプッシュされた。
