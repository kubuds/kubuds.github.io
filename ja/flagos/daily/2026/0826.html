  • FlagScale（訓練）：#1272 は訓練ツールチェーンに Hygon BW1000 CI サポートを追加（8/25 11:48 マージ）——海光 DCU が FlagScale 公式 CI マトリクスに参入。
  • FlagCX（通信ライブラリ）：#541 が Hygon DCU 対応と CI workflow を完了（8/25 12:32 マージ）——チップ横断通信ライブラリに海光バックエンドを補完。

1.3 build-infra：検証駆動エンジニアリング硬化の締めくくり——並列、隔離、長タイムアウト（08-25）

情報源：#531、#536、#540、#552、#556、#557、#563、#564

  • vllm と megatron の 2 系統の verify-driver を並行実行（#536）。バックエンドごとの検証実行を相互に分離し、並行競合を回避（#540）。
  • 検証成果物を run_id で命名してアップロード（#531）。失敗セルの詳細を実行ログにエコー（#540）。megatron 側は NullTokenizer で wget ダウンロードを回避し、model-size パラメータを追加（#527/#529）。
  • verify-driver の自動再トリガーループを停止（#557）、PSUTIL_PREINSTALL のデッドコードを削除（#556）、serve レディポーリングのタイムアウトを 300s から 900s に引き上げ（#563）、completion リクエストのタイムアウトを 120s から 600s に引き上げ（#564）——長時間タスクの検証がタイムアウトによる誤判定で失敗しなくなる。

解読：昨日の「検証ドライバのハードニング」を引き継ぎ、本調査期間では E2E 検証を「単機シリアル+固定タイムアウト」から「並行+分離+長タイムアウト+監査可能な成果物」というエンジニアリング形態へと進めた。マルチバックエンドマトリクスの規模拡大に伴い、検証インフラ自体がボトルネックとなっており、今回のハードニングは次批次の新規ベンダー（海光など）の参入に向けたエンジニアリング上の準備である。

1.4 FlagGems：KernelGen オペレータ拡充とマルチバックエンド最適化（08-25/08-26）

情報源：FlagGems commits（調査期間内 19 件のコミット）

  • KMCompiler 昇騰側：log_sigmoid_backward の性能最適化（#5718）、exponential オペレータ（#5682）、linalg_lstsq エントリに stages を追加（#5700）、linalg_det テスト修正（#5701）。
  • 摩尔線程（MThreads）：AddMM layouts と bias epilogue の最適化（#5384）。
  • 寒武紀：tensor mask を elementwise ビット演算に変更し Python の and/or/not を置き換え（#5745、5.3.5 の再検証と併せて）。

3.2 摩尔線程が MTT S5000 Prefill-as-a-Service 白書を発表（08-24 発表/08-25 報道）

情報源：IT之家/新浪科技（8/24）、鳳凰網（8/25）

  • 摩尔線程が『MTT S5000 Prefill-as-a-Service 技術白書』を発表し、Prefill-Decode ヘテロジニアス解耦方案を提起：Prefill（計算集約型）と Decode（メモリアクセス集約型）を別プールに分離配備し、長コンテキスト推論（数百 K から 1M token）における構造的な演算リソースのミスマッチを解消する。
  • 実測データ：64K コンテキストのシングルマシン Prefill スループット 95,920 tok/s；400K の極限長シーケンスで TPM が 2.6M tokens に到達。AI Agent、コード生成、超長文ドキュメント分析のシナリオ向けに、「単位 Token あたりのインフラコスト削減」を主軸とする。
  • 摩尔線程は FlagOS メンバー単位の中で検証マトリクスが最も完全なバックエンドの一つである（8/24 レポート：musa4.3.6/5.2.0 デュアルバックエンドで F/T デュアルパス全通過）；その長コンテキスト推論側のハードウェア戦略は FlagOS の推論側検証の主線と同調している。

3.3 沐曦：GPU 智算ペイロードの宇宙軌道検証が外媒の注目を集める（08-25）

情報源：DIGITIMES（8/25）、騰訊新聞（事象ソース、7/25）

  • DIGITIMES は 8/25 に「中国 GPU の応用が宇宙へ延伸」と報道：沐曦 GPU 智算ペイロードを搭載した「雲尖沐曦号」衛星（吉天星 A-04 星、三体計算星座）は 7/24 に力箭一号遥十五で軌道投入され、現在、国産商用 GPU が宇宙の高エネルギー粒子放射線、真空熱サイクルの下で動作する信頼性を軌道上で検証中——国産智算チップが「地上検証」から「軌道上実戦」への鍵となる飛躍。事象は 7 月末に発生し、当期間内に国際産業メディアが再度注目した。

4. まとめ
