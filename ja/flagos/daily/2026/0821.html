1. オープンソースプロジェクトの進展（GitHub 動向）

期間総覧：org 内の 52 リポジトリのうち 14 が期間内にプッシュあり；commit search で期間内のコミット 55 件がヒット（FlagGems 27 件、FlagBLAS 12 件が上位）、正式な GitHub Release はなし。本期間の二大トピック：FlagGems のオペレータマトリクスの高密度拡充（KernelGen 一括オペレータ + 摩尔線程 SQMMA の深層最適化） と build-infra による海光 hygon vllm 0.24.0 デュアルコンパイラ E2E 検証記録の完了；他に FlagSparse の CUDA/DCU バックエンド統合、FlagPrism の天数智芯デバッグサポート、FlagBLAS の三角ソルバー系補完。

1.1 FlagGems：27 件のコミットで首位、KernelGen 一括オペレータ + 摩尔線程 SQMMA 行列積最適化（期間トップ）

出典：FlagGems commits

  • KernelGen Nvidia オペレータの一括投入（8/20 10:33-10:53、12 オペレータ）：special_expit（#4263）、linalg_householder_product（#5179）、adaptive_max_pool2d（#5077）、rshift（#5075）、amp_update_scale（#5503）、_list_to_tensor（#5273）、fake_quantize_per_channel_affine_cachemask（#5455）、_convolution_double_backward（#5505）、view_as_complex（ゼロコピー view、#5373）、_batch_norm_impl_index_backward（#5504）、adaptive_avg_pool1d（#5550）、float_power（#5517）。
  • KMCompiler のマルチチップ拡張と修正（16:23-17:50）：linalg_matrix_norm（Nvidia #5595、Iluvatar/Hygon #5648）、dist オペレータ（Nvidia/MetaX #5406）、masked_scatter_backend（#4954）、index_fill/index_fill_（Nvidia/Ascend #5643）、昇騰 tle import 修正（#5616）とバグ修正（#5641/#5654）、天数智芯のバグ修正（#5644）、fp64 benchmark 除外（iluvatar/ascend、#5658）。
  • MTHREADS（摩尔線程）の行列積深層最適化：addmm_out を SQMMA/FMA override で最適化（#5604、18:19）、baddbmm を SQMMA で最適化（#5666、19:42）。
  • その他：燧原 enflame 1.10.6 バックエンドの flagtree バージョン更新（#5649、14:04）、昇騰 erfc のフォールバック実装（#5380、14:20）、達摩院玄鉄 PPU upsample/quant オペレータテスト修正（#5655、15:36）。

解説：8/18の「KernelGen 全ベンダー一括出荷」と呼応する形で、本調査期間では KernelGen ラインが Nvidia 側で1日12オペレータをスタックに投入し、KMCompiler 側ではマルチチップ（Nvidia/昇騰/海光/天数智芯/沐曦）のクロス修正と拡張を実施、オペレータカバレッジは引き続き PyTorch 高階および量子化/逆伝播 API へと収束している。摩尔線程側では addmm_out/baddbmm の SQMMA ハードウェア命令レベルの最適化により、オペレータライブラリが「カバレッジ」から「単一チップ深度チューニング」へと進んでいることを示している。

1.2 build-infra：海光 hygon vllm 0.24.0 デュアルコンパイラ E2E 検証記録（#466）、app image は FlagTree #1020 待ちで延期

情報源：PR #466、PR #464、PR #465

  • #466（8/20 20:19 マージ）：hygon（海光、DTK 26.04）vllm 0.24.0 の hygon25 ノード上でのデュアルコンパイラ検証を記録——F パス（flagtree 0.6.1+hcu3.6、一時的にコンテナ内の cluster_dims デフォルト値で回避、FlagTree PR #1020 が上流修正）と T パス（vendor triton 3.5.1）はいずれも Application startup complete に到達し推論も一致；hygon app image は延期：F パスのデフォルトコンパイラが FlagTree #1020 にブロックされ、かつ packaging/flagtree/hygon wheel は新 flagtree release に合わせて再ビルドが必要；vllm 検証マトリクスの hygon 0.24.0 T/F ユニットはグリーンに。
  • #464（8/20 11:00）：megatron-training app image ビルド記録 + h20 デュアルコンパイラ検証。
  • #465（8/20 12:21）：sunrise 0.20.2 app-image handoff ドキュメント。
  • FlagTree #1020（8/20 17:23 作成、マージ待ち）：default cluster_dims=(1,1,1) for backends that omit it——hcu/mthreads など cluster-launch サポートのないバックエンドで vllm 0.24.0 の KV-cache warmup 時に発生する AttributeError を修正（hygon DTK 26.04 ランタイムで再現）。

解説：昨日の曦望芯科 SUNRISE 全リンクデリバリに続き、海光が次に build-infra で深く検証される推論バックエンドとなった。海光 F パス（FlagTree コンパイラ）が依存する cluster_dims 修正はすでに #1020 として提出され、マージ後には hygon flagtree wheel を再ビルドし app image を更新する——「検証記録が先行、リリース機構が追随」というリズムは SUNRISE パスと一致している。

趨勢判断：本調査期間のチップ業界地図のキーワードは「オペレータの広度と推論の深度が並行」である。推論側では、海光が曦望芯科からバトンを受け継ぎ、build-infra の深度検証対象となった（hygon25 ノード、DTK 26.04、F/T デュアルコンパイラ、app image の決定）。FlagTree #1020 の修正は、海光推論生産ライン正式化の鍵となる卡点である。オペレータ側では、摩尔線程（SQMMA 行列積）、天数智芯（FlagPrism デバッグ + FlagTensor マージ + FlagGems 修正）、沐曦（dist オペレータ + TLE）がいずれも実質的な進展を見せており、メンバー単位の参加は「接続」から「最適化」へと向かっている。ビジネス面では、摩尔線程の H1 売上高の高成長、海光の H1 大幅増と多業種での展開、寒武紀の中間報告における純利益倍増が注目点となる。寒武紀の株価が 1000 元を突破したことおよび関連資金流の変動は市場面の例行事項であり、参考にとどめる。

4. 総括

  1. FlagGems 単一リポジトリ 27 件のコミットで首位（本調査期間のトップニュースの一つ）：KernelGen Nvidia の単日 12 オペレータ一括投入、KMCompiler のマルチチップ（昇騰/海光/天数智芯/沐曦）横断修正と拡張、摩尔線程の addmm_out/baddbmm SQMMA 行列積の深度最適化——オペレータライブラリは「広度カバレッジ + 単一チップ精密調整」の並行段階に入った。
  2. 海光 hygon 推論チェーンの検証深化（本調査期間のトップニュースの二つ目）：build-infra #466 は vllm 0.24.0 のデュアルコンパイラ E2E を記録（hygon25、DTK 26.04；F パス flagtree 0.6.1+hcu3.6、T パス vendor triton 3.5.1 はいずれも起動完了に到達）；app image は FlagTree #1020（cluster_dims デフォルト値修正、8/20 に提出済み）のマージと hygon wheel 再ビルドを待って延期。
  3. スパースおよびデバッグツールチェーンの拡張：FlagSparse が CUDA/DCU バックエンドのコードマージを完了；FlagPrism Debugger が天数智芯 Tianshu/CoreX サポートを追加；FlagTensor が iluvatar ブランチをマージ——天数智芯は本調査期間に多線で推進。
  4. FlagBLAS 三角ソルバー族の補完：TPSV/TRSV/TBSV が相次いでマージ（AriesMTR シリーズ PR #82-#87）、Level-2 カバレッジがさらに一歩前進；昇騰 CI をマージ、マルチチップ CI マトリクスが BLAS ライブラリまで拡張。
  5. メンバー単位のビジネス面が活発：摩尔線程 H1 売上高 17.36 億 +147%；海光 H1 売上高は 6 割超増で映像制作/GIS/合肥詞元経済エコシステムに展開；寒武紀 H1 純利益 23.11 億 +122%；沐曦「行業方舟」販売体系を拡張。
  6. ニュース側は平静：コンポーネントキーワードのヒットゼロ、正式な GitHub Release なし；海光 flagtree wheel の再ビルドと app image の更新は、近期のリリースシグナルの観察ポイントである。
