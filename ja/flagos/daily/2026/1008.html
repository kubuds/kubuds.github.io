今日の重点：FlagQuantum 期間内23件のマージ——分散MPS訓練がリリース認証へ昇格（10-07 ~ 10-08）

日付：2026-10-07 ~ 2026-10-08　出典：FlagQuantum #587、#590、#591、#595

連休後初回の期間において、FlagQuantum（FlagOS の量子シミュレーションと訓練コンポーネント）が組織内で最大の増分となった：期間内76件のコミット、23件のPRマージ、10-07午前から10-08午前まで連続的に推進し、リリース認証、性能ディスパッチ、勾配と幾何量、誤り訂正デコード、ネイティブエントロピー導出の五つのラインをカバー：

  • リリース認証の落地（#587、10-08 07:16 マージ）：分散 MPS リリース戦役が終結——two_node_mps_training 能力行が production_supported から release_certified へ昇格（本調査期間で唯一昇格した能力行）。認証はリリースゲートを通過した 2 件の署名済み実測生産実行ペイロードに基づく。同時に、実測理由によりテンソルネットワーク（TN）容量前提が現在のリビジョン上で満たせないことを記録し、検査フローで発見されたすべての産出側欠陥を修正（セルフマージ基準 c7bba053 以降、28 筆の非マージコミットを含む）。本戦役は #535 で開始された分散 MPS / テンソルネットワークリリース作業を引き継ぐものである。
  • 性能ディスパッチ批次（#576 / #581 / #582 / #583）：statevector 公開ディスパッチを SV-014（SWAP）、SV-010（対角）、有界 SV-011（Pauli 回転）へ拡張し、有界 Pauli 回転ディスパッチの再認証を完了——SV 系列の項目ごとの「実装 + 証拠」という推進方式を継続。
  • 勾配と幾何量（#562 / #568 / #575 / #585 / #564 / #565）：fq.jacobian / fq.jvp / fq.vjp（多出力プログラム）を新規追加。二階導関数（Hessian）はパラメータシフトで一階規則を再利用。Fubini-Study 計量テンソルを新規追加（中心差分実装、演算子シフト規則を再利用しない理由を反証表で説明）。N3-9 では「勾配手法 × 実行モード」の 30 対マトリクスを契約として確定し、ゲートで再テスト。
  • QEC とエントロピー導出（#590 / #591 / #592 / #589）：スライディングウィンドウデコーダを新規追加（flagquantum/qec/sliding_window.py、772 行追加、ウィンドウごとに検出器エラーモデルを読み込み逐次デコード）。fq.vn_entropy により von Neumann エントロピーをネイティブ Stable Core 導出へ昇格（ルート導出予算 37 → 38）。4 行の QEC 整合項目が収束。Quafu リモートコミットは資格情報が欠如する場合に fail-closed へ変更。
  • 品質収束（#595 / #597）：#595 で未申告のディスパッチリビジョン 16 筆を追記。#597（オープン）で CI 並行グループの欠陥を修正——2 回連続のマージで前回の検証が一括キャンセルされる（#590 の 23/23 チェックがキャンセルされたのはこのメカニズムによる）。

判断：FlagQuantum の「リリース認証 + 契約化ガバナンス」の二軸が形成されつつある——能力は契約ファイルとして記録され、ゲートと実測ペイロードで再検証される。そのエンジニアリング規律は FlagOS 主线リリース体系と同構である。調査期間はちょうど連休の末尾と連休明け初日にまたがり、本リポジトリは長期休暇中も高い強度を維持した開発ラインである。

1.1 FlagQuantum：分散 MPS リリース認証の落地——2 ノード訓練が release_certified へ昇格（10-08）

日付：2026-10-08　情報源：FlagQuantum #587、#535

  • 認証内容：two_node_mps_training が production_supported から release_certified へ昇格。能力表で唯一変動した行。認証はリリースゲート（release gate）に受け入れられた 2 件の署名済み measured_production_run 実測生産実行ペイロードに基づく。
  • 容量記録：テンソルネットワーク容量前提は実測理由により「現在のリビジョン上で満たせない」と記録——容量境界を明示的に記録し、暗黙の制約として残さない。
  • エンジニアリング範囲：セルフマージ基準 c7bba053 以降、28 筆の非マージコミットと 2 筆の主线マージを含む。同時に本リポジトリのセルフチェックフローで発見されたすべての産出側欠陥を修正。
  • 承接関係：戦役は #535（10-06 マージ）で開始され、今回完了してリポジトリのリリース認証体系（release_certified 档）へ初の分散能力行を提供した。

  • ゲートバッチ（#566 / #571）：有界可逆 3 量子ビットゲートディスパッチ（#566）、稠密局所 2 量子ビット行列ディスパッチ（#571）——局所ゲートディスパッチのカバレッジが引き続き稠密化。

  • 意味：パフォーマンスバッチが「カーネル内最適化」から「ディスパッチ層セマンティクス」へと前進——同一操作を行列形態と有界性に応じて専用カーネルへ分流し、項目ごとに証拠を残す。
