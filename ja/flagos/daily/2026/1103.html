3.3 昇騰と海光：W8A8 INT8 の GEMM と BMM の二つの実装（11-02）

3.4 摩尔線程：Conv1D 真の一次元 GEMM が 26 個のベンチマーク例すべてを 0.8 倍ライン超えに（11-02）

日付：2026-11-02　情報源：FlagGems PR #6754 · FlagGems PR #7428 · FlagGems PR #6903 · FlagBLAS PR #157 · FlagTree PR #1314

  • Conv1D の結果：#6754 は MTT S5000 に conv1d バックエンドカバレッジを追加し、公式 conv1d_padding ベンチマークを 18/26 例達成から 26/26 例が 0.80 倍 torch 以上に引き上げた。以前はすべての FP32 K3/K5 padding 例が 0.41 から 0.53 倍にとどまっていた。
  • 三層の改法：第一に、conv1d は元々 MTHREADS カバレッジがなく全て汎用 conv2d を通り、小グループ形状では padding が実体化され、W=1 形状では単一の有効 OW チャネルしかヒットしなかった。ルーティング変更後は冗長な padding と bias 割り当てを除去し、退化した幅のディスパッチを修正した。第二に、専用の Triton-MUSA Conv1D カーネルを新設し、M が N 掛ける Lout に等しいとして三次元グリッド分割を行い、出力チャネルは除算剰余を行わなくなった。第三に、重みをカーネル幅、入力チャネル、出力チャネル順に事前パッケージし、精度補償付きの SQMMA と組み合わせた。
  • 付随対応：#7428 は S5000 上の one_hot の検証と推論を最適化し、#6903 は空インデックスを index_add の空操作とみなし、#157 は MUSA の L1 BLAS を補い、#1314 は二回の非同期 TME コピー間で membar をスキップする。
  • 判断：これは本調査期間で珍しい「ベンチマークをすべてライン超えさせた」完全な事例である——ルーティング、専用カーネル、重みレイアウト、命令級精度補償の四層を同時に改め、前後の対照を示した。他のバックエンドにとって複製可能なテンプレートとなる。
