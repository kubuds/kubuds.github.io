3.1 摩尔線程：RLinf 公式 CI が MTT S5000 に接入——「単方向適配」から「双方向共建」へ（09-22/09-23 報道）

日付：2026-09-19（サロン）～ 2026-09-23（報道）　出典：証券時報・人民財訊、与非網、PChome

摩尔線程主催の「MUSA オープンソース技術サロン：RLinf × MUSA Meetup」（09-19、北京）は、身体性知能強化学習の実測データを一組公開した。RLinf 公式 CI はバージョン 0.3 以降 MTT S5000 を接続し、すべてのコードをメインブランチにマージする前に国産算力で自動検証を完了しなければならない。RLinf は MUSA バックエンドでの実行を正式にサポートした。重要なデータ：248 個の並列環境、同一レシピと同一乱数シードの下で、S5000 と国際主流 GPU の訓練曲線の逐次相関係数は r = 0.976（191 ステップの共通ウィンドウ）。実機 LIBERO-Spatial 評価では、両ハードウェアの策略成功率が一致した。工程側では 1 ステップ全体の所要時間が 2549 秒から 1888 秒に短縮（-26%）、GPU 空転率は 18.5% から 3.1% に圧縮された。オペレータ級ベンチマークでは、S5000 の GEMM とアテンション性能が国際主流 GPU の 1.6～2 倍に達した。両者はさらに端雲協同フレームワーク（雲 S5000／端 MTT E300）を共同構築する。「一方向適配から双方向共建へ」が本項目を定位づける核心である――オープンソースフレームワークが国産算力を CI ディレクトリに書き込むことは、エコシステム上の位置の転換に属する。

  • 2.2リリース面は「リリース物凍結」段階へ：10コンポーネントの正式版タグが一括登録（01:49 ~ 01:50）、rc2マニフェスト13モジュールのpostタグ収束（00:42）、FEP-0085のスコープ縮小（17:52）——3本のラインが同一ウィンドウ内で「タグ、マニフェスト、スコープ」の整合を完了。GA（09-28）まで4日、rc2安定期間は本日締切、観察点はマニフェストL2 / L3バッチ収録とGo/No-Goに移行。
  • プラットフォーム面は拡張を継続、しかも経路はそれぞれ異なる：thead-ppu2.1.0アプリケーションページは「手動登録、後から管轄化」の過渡形態；FlagTreeの5プラットフォームタグは「ベンダー特化」を正式にバージョン体系に組み込み；vllm-plugin-FLの壁仞SUPAバックエンドPRは「新ベンダーがプラグインリポジトリから参入」の又一例。多元チップ図景はGA前も拡列を続けている。
  • オペレータライブラリは全面的に「検収とチューニング」のリズムへ移行：KernelGen単一ウィンドウ16枚（ロングテール補充継続）+ 昆侖芯31オペレータ最適化バッチ（27/31達成）+ mv / GEMM / アテンションのマルチプラットフォーム修復——特性凍結後のスケジュール形態と完全に一致、GA前最終週のパフォーマンスアクションが集中的に放出。
  • 量子とスパースという2つの「非主線」コンポーネントは独自のリズム：FlagQuantumは2ウィンドウ連続30+件かつCirq / Qiskit Aerデュアルブリッジを完了；FlagSparseとNCIC-AlphaSparseは6件の双方向同期。それらの工程化程度はGA前に顕著に上昇、2.2以外の長期観察項を構成。
  • 对外情報面：会議シーズン終盤 + オープンソフトウェアスタックのナラティブが同頻：AICC2026会後総括でFlagOSのポジショニングを再述、Open3D-PIMC続報、達磨院玄鉄SAIL「GitHub研究開発主線」——国内AIチップの「ソフトウェアスタック開放」とFlagOSの「多元統一スタック」という2つのナラティブが同一週に集中放出、一方でコンポーネントレベルの検索は依然として第19の平穏なウィンドウにあり、情報増分は依然としてリリースリズムによって駆動されメディア側ではないことを示している。
  • 要観察：① community #114のマージとL2 / L3バッチ収録；② FlagTree 0.7.0シリーズタグに対応する正式Releaseとドキュメント（wikiは整備を開始）；③ 達磨院玄鉄PPUのランタイム / コンパイラ / オペレータ層における後続の管轄化（TE-FL PPU CI、FlagGems-vllm TLEオペレータは既に先行シグナル）；④ 壁仞SUPA、Sunriseなど新ベンダーバックエンドのマージ進捗。
