今日の重点：FlagOS 2.3ベースレイヤーが1日で3社入れ替え、沐曦はmaca3.10.1.11へ、燧原はtops 2ラインが初納品、摩尔線程musa4.3.6は全チェーンで撤去（11-18）

日付：2026-11-18　出典：#1894 · metax-maca3.10.1.11 · enflame-tops1.9.29

  • 沐曦ライン切り替え：#1894 で base 層の maca3.7.2.1 を maca3.10.1.11 に置き換え、MetaX C550 チップ向け、ドライバ 3.100.1 付き、ベースイメージは ubuntu:24.04。変更記録の原文には本ラインが maca3.7.2.1 に取って代わることが明記されている。ドライバはユーザー空間のみでインストールされ、イメージはカードなしでもビルド可能で、カーネルドライバはホスト側に残る。#1895 で runtime 層の同日変更記録を補完し、#1896 で SDK 付属の ompi ライブラリを LD_LIBRARY_PATH に追加した。
  • 燧原の初回納品：tops1.9.29 は紫霄 C200（S60）向け、tops4.1.6 は L600 向けで、両ラインとも初回納品となる。納品範囲は同一：driver、runtime、CC、PTI、TOPSTX、TOPS ATen、EFML、ECCL、Triton GCU 1.0.20261116 と gculare-perftest、いずれも ubuntu:24.04 ベース。/opt/triton_gcu はベンダー製 triton のインストール位置を指すシンボリックリンクとして作成され、FlagTree の toolkit.py はこのパスで検索を行う。
  • 摩尔線程の撤収：#1902 で base 層から musa4.3.6 ビルド層を退役させ、#1904 でアプリ層から同一ラインを削除した。flagcx 行に対応する #1905 はなお審査中。musa5.2.0 と musa5.3.0 の両ラインは維持される。
  • バージョンの基準：configs.yaml の stack version は 2.3.0、flaggems は 5.4.0 に固定。2.3 の日程は community #176 に準拠：FEP マージ締切 11-13、機能凍結と rc0 が 11-30、rc1 が 12-07、rc2 が 12-14、封板 12-25、GA が 12-30。
  • 所感：同じ日に 2 社が世代交代、1 社が撤収となり、動きはすべて変更記録と Containerfile に落とされており、リリース告知はない。基盤層のリズムは、まずイメージがビルドでき検収できるようにし、その後でバージョン番号を語るというもので、この時点で rc0 までまだ 12 日ある。

日付：2026-11-17 ~ 2026-11-18　情報源：雷峰網 · 環球網科技 · 投資家網

  • 出来事：11月17日、「国芯国模 自主生態」2026清昴AIパートナー大会兼Token工場年次総会において、北京智源人工智能研究院と清昴智能が共同で「国産Token工場エンドツーエンド推論最適化方案」を発表し、衆智FlagOSに基づく商用Token工場を上线した。雷峰網が11-18 13:31に報道を掲載し、環球網と投資家網が同日に続報。
  • エコシステムの見解：報道によれば、FlagOSエコシステムは既に21社のチップ企業、86社のエコシステムパートナーを集め、35種類のAIチップをカバーしている。9大オペレータライブラリには累計1454以上のオープンソースTritonオペレータが蓄積され、そのうち約800個が少なくとも5種類の国産チップ上でネイティブオペレータの80%以上の性能に達している。単一のコードリポジトリが20社のベンダーバックエンドをカバーし、過去半年間に何度も新モデル公開当日に12種類のチップで動作させることに成功した。
  • 昇騰910Cの勘定：智譜GLM-5.3とGLM-5.3-Flashに対し、Prefill側では81920入力、16並列でバッチスループットが3.41%向上し、256K入力でTTFT p50が4.94%低下。Decode側ではLI量子化書き戻しにより動的量子化、スケール変換、HBMキャッシュ書き戻しを同一カーネルに統合し、910Cマイクロベンチマークが18.03マイクロ秒から2.04マイクロ秒に短縮。エンドツーエンドITLは10%以上低下、TPOTは8%以上低減。
  • 既存910B：BAAI Token Hubは48枚の910BをPrefillとDecodeを分離したクラスタに構成し、32枚のカードを4つのPrefillドメインに、16枚のカードを8つのDecodeドメインに分割し、1MコンテキストのGLM-5.3-Flashサービスを稼働させ、既に2週間連続で安定稼働、TTFT P50は約2.3秒、TPOT P50は22ミリ秒。Prefillドメイン間のPrefix Cache再利用によりヒット率が82.65%から94.15%に向上し、再利用段階の初字遅延中央値が16.63秒から3.10秒に短縮。
  • 横断比較：平頭哥810E上でFlagOS 2.2によりDeepSeek-V4.1-Flashが77%から82%向上し、16路並列で利用可能、最大80並列、単一リクエストデコード136.2 tok/s。海光BW1100上でGLM-5.3-Flashが25%以上向上し、多並列下で単路スループットが80 TPSを突破。
  • 見解の注意点：環球網版ではさらに910C上でGLM-5.3-Flashの全体出力が二十数TPSから五十数TPSに上昇し、論理サービススループットが最適化前の2.04倍、単位算力コストが商業API課金より19.4%から27.6%低いとし、自動チューナーが検索効率を298倍に高めたと述べている。これらの数字はベンダーとメディアの見解であり、第三者による再現は見られない。
