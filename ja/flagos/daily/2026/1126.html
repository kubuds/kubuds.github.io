今日の重点：Xing4.1-Preview 八芯Day0適配、NVIDIAプラットフォームでトークンあたり所要時間が最大20.9%短縮（11-25）

日付：2026-11-25　出典：FlagOSコラム。

  • モデル：中電信人工智能科技有限公司が星辰大規模モデル Xing4.1-Preview をオープンソース化。
  • 仕様：総パラメータ 285B、各 Token あたり約 17B をアクティブ化、1M コンテキストをネイティブサポート。
  • 構造：45 層の Transformer バックボーン、うち 42 層が MoE。
  • ルーティング：各 Token は 256 個のエキスパートから 8 個を選択、別に共有エキスパート 1 個。
  • アテンション：MLA が KV 表現を圧縮、DSA スパースアテンションと組み合わせ。
  • 適合範囲：平頭哥、NVIDIA、摩尔線程、昇騰、沐曦、海光、天数智芯、崑崙芯の 8 社。
  • 成果物：W8A8 と BF16 の 2 バージョン、すでに魔搭と Hugging Face に公開済み。
  • 評価口径：NVIDIA シングルマシン 8 カード、64 同時実行、ベースラインは同精度のネイティブ方案。
  • 4K 入力：出力スループットが 1862.10 から 1988.23 tokens/s に上昇、6.8% 向上。
  • 4K レイテンシ：Token あたり平均所要時間が 30.23 から 27.63 ms に低下、8.6% 削減。
  • 16K 入力：スループット 4.1% 向上、Token あたり所要時間 18.7% 削減。
  • 32K 入力：スループット 1.7% 向上、Token あたり所要時間 20.9% 削減。
  • コスト：3 段階入力の平均初回 Token レイテンシがそれぞれ 11.8%、21.5%、6.0% 増加。
  • 精度：MATH-500、GPQA Diamond、MMLU の 3 項目で NVIDIA ネイティブと同等。
  • 国産プラットフォーム：一部シーンで単位算力スループットが NVIDIA ネイティブの 7 割以上に到達、最高 181.5%。
  • オペレータ：4K シーンで 54 個の FlagGems オペレータを有効化。
  • コンポーネント：デプロイ経路で FlagGems、FlagTree、vLLM-plugin-FL を使用。
  • フレームワーク：NVIDIA、平頭哥、沐曦、海光、天数智芯、崑崙芯は vLLM 0.24.0 を採用。
  • フレームワーク続き：昇騰と摩尔線程は SGLang 0.5.18 を採用。
  • 所見：これは FlagOS 今週最初の完全な性能データを伴う Day0 適合。
  • 所見続き：国産プラットフォームの比較指標は単位算力スループットであり、絶対スループットではない。
