今日の重点：Torch-FLがFlagGemsのPythonコミット経路をネイティブhostにコンパイル、Qwen3-0.6BのウォームスタートオーバーヘッドをベンダーPyTorchの1.17倍に低減（11-14~11-16）

日付：2026-11-14 ~ 2026-11-16　出典：Torch-FL #824 · Torch-FL #839 · Torch-FL #822（要件票） · Project 14

  • 結果：#824 は FlagGems の Python 側 host ロジック——メタデータ、メモリ割り当て、ヒューリスティック、Triton 発射準備——をガード付きのネイティブ host プログラムにコンパイルし、既存のデバイスカーネルを維持する。完全な Qwen3-0.6B 推論において、prefill/decode のホットスタート CPU コミット所要時間は 211.51/203.92 ミリ秒から 28.46/27.15 ミリ秒に短縮された。ベンダー PyTorch は 24.43/22.96 ミリ秒であり、換算遅延比は 1.17 と 1.18 である。
  • 受け入れ基準：#822 は国産アクセラレータ上でベンダー PyTorch と同一物理カード、同一作業量での比較を行い、スループット比が 0.80 以上または遅延比が 1.25 以下となることを要求する。NVIDIA 側は既に基準を満たしているが、国産カード側には公開データがまだない。#824 は実験的な NVIDIA 推論実装であると自述しており、デフォルトモードの切り替えではなく、全オペレータカバレッジの宣言でもない。
  • 連続性：11-15 から 11-16 未明にかけて六つのコミットを連続して統合——#826 は FlagGems ソースコードとモデル host をコンパイルし、#835 はネイティブ host レジストリを全量登録し、#836 は schema 型付きの eager エントリを生成し、#837 はソースコード呼び出しブリッジを生成し、#838 はスカラーセマンティクスを保持し、#839 は共有 host オーバーヘッドを低減した（+2388/-55、15 ファイル）。このラインは「単一モデルの動作確認、レジストリの補完、オーバーヘッドの削減」の順序で進められており、散発的な性能パッチではない。
  • 設計方針：#823 の設計稿は実装前に路線を定め、結論として上限を決めるのはカーネル発射ではなくメモリ割り当てであるため、第一段階ではアロケータから直接メモリを取得する。#824 と #826 のマージ後、計画はメンテナの承認を得て、#829 と #830 が後続を引き継ぐ。
  • 意味：FlagGems の eager パスは常に「Python 税」の層を抱えていた——呼び出しごとに Python でメタデータ、割り当て、発射準備を行う必要がある。この層をコンパイル除去した後、クロスチップ推論のギャップは「カーネルの書き方の良し悪し」から「host パスの組織方法」に拡大し、2.3 の推論性能受け入れ基準には host 側のベースラインを併記する必要がある。

4. まとめとトレンド観察

  • 2.3 rc前夜に到達：11-13のFEPマージ締め切りはすでに過ぎ、次の関門は11-30の機能凍結とrc0である。調査期間内にbuild-infraは910C、ROCm 7.2.4、PPU 2.1.0、MUSA 5.3.0の4バックエンドの2.3.0バージョンデータを補完し、取りまとめ単位は依然として「1バックエンド1 PR」である。
  • 性能の語りが「オペレータ数」から「hostパス」へ転換：Torch-FLはFlagGemsのPythonコミットオーバーヘッドをベンダーPyTorchの1.17～1.18倍まで压低し、#822の80%しきい値をクリアした。国産カード側で再現する場合、異種チップ推論の比較にはhostベースラインも併記しなければ、数値は比較可能にならない。
  • 融合オペレータは推論側の主戦場：海光MegaMoE、英偉達MegaPreAttention、昇騰A5のKDAと因果畳み込みは、いずれも通信、投影、正規化、KV更新を1回の永続カーネルに束ねるものである。こうした作業が変えるのはマルチカードの可用性であり、単点の演算力ではない。
  • テストとCIの比重が上昇：FlagGemsの62件のアラインメント、82個のプラットフォームpytestパッケージ（#9118）、FlagGems-vllmのCI自己完結（#1202）、gendocの5件の強化は、いずれも同じことを指し示している——2.3のボトルネックは「コードを書く」ことから「受け入れと追跡可能性」へ移りつつある。
  • 週末も停工ではない：11-13の1日で180件のマージ、125件のコミット、11-14と11-15はそれぞれ15件と27件のマージ。平日に溜まったレビューは週末に片付けられ、実際の新規開発は依然として11-13の日中に集中している。
  • ニュース面とコード面の乖離が続く：gnewsのコンポーネント検索は連続してゼロヒットで、本期で唯一情報量のある外部報道は地平線旭日チップのエンボディドツール適配と燧原の人事異動であり、いずれも背景情報に属する。デイリーレポートの判断基準は依然としてコミット、PR、パッケージングマトリクスの一次データである。
