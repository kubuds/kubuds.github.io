2. ニュース報道とエコシステム

2.1 トップニュース：FlagOS 四日間で三度の Day0——Qwen3.8-Flash-Next、GLM-5.3-Flash 当日適応、Hy4 preview マルチチップリリース、10 款のチップをカバー（09-01）

情報源：智源研究院公式発表（hub.baai.ac.cn/view/57616）（2026-09-01 20:10）、vLLM アップストリーム PR 53909、vLLM アップストリーム PR 53877

  • 8/26 夜にアリババが Qwen3.8-Flash-Next を、智譜が GLM-5.3-Flash をオープンソース化、8/27 午後にテンセントが Hy4 preview をオープンソース化。衆智 FlagOS コミュニティは三度にわたるマルチチップ対応を連続で完了：Qwen3.8-Flash-Next と GLM-5.3-Flash はいずれもリリース当日 Day0、Hy4 preview はその後マルチチップ版リリースを完了；達摩院玄鉄、英偉達、摩尔線程、華為昇騰、沐曦、崑崙芯、海光、天数智芯、清微智能、曦望など 10 款のチップをカバーし、ハードウェア能力に応じて BF16/FP8/INT8 版を提供、すでに魔搭と Hugging Face に順次リリース済み。
  • Qwen3.8-Flash-Next（Qwen4 アーキテクチャの早期プレビュー）：QSA スパースアテンション、Gated Residual、N-gram Embedding の三種類の新構造を導入、FlagOS は Triton ベースの新規オペレータを 8 個追加（3 個の Hyper-Connection、3 個の QSA、2 個の PLE state）し、FlagTree を通じてマルチチップにコンパイル；オペレータ融合の重畳により每步約 8.66ms を節約（HC 融合の寄与が 6.3ms で七割以上を占める）；鍵となるのは metadata 構築を CUDA Graph に組み込むことで、部分的なグラフ化から完全なグラフ化へ移行することで +7.46% のエンドツーエンド收益をもたらす（単独オペレータレベルではわずか +0.93%）。8 個の融合オペレータはすでに vLLM アップストリームに提出済み（PR 53909）、さらにアップストリームに対して GDN Packed Decode 経路の FP32 精度欠陥を一件修正（PR 53877）。
  • GLM-5.3-Flash（GLM-5 シリーズ初のネイティブマルチモーダル、AA 総合智能指数 57 点）：線形＋スパースのハイブリッドアテンションにおけるチップ間の並列分割差異は推論プラグイン層が受け持つ；vLLM-plugin-FL と SGLang-plugin-FL の二経路は同一の FlagGems オペレータと BF16 重みを共用し、チップを切り替えてもモデルファイルを差し替える必要がない。
  • Hy4 preview（770B パラメータ、Hy3 の 2.6 倍、激活 49B、1M コンテキスト）：FlagOS-Compressor 量子化ツールチェーンを通じて FP8/BF16 ネイティブ重みから INT8 への圧縮経路を実現し、量子化推論オペレータのマルチチップ対応を完了；量子化＋クロスチップ移行後、英偉達 CUDA FP8 原版と比較して、誤差はアラインメント区間内に収まる。
  • リリース体系データ更新：2026 年 8 月時点で、FlagRelease は 10 社余りのチップメーカー、12 款以上のハードウェア、80 個余りのオープンソースモデルインスタンスをカバーするクロスチップ版をリリース済み。

解読：これは 8/13 の Qwen3.8-2.4T 九チップ Day0、4 月の DeepSeek-V4 八チップ Day0 に続き、FlagOS が初めて「連続三回の Day0」という密度でフロンティアモデルのマルチチップ対応を完了したものである——公式はこれを公共オペレータライブラリ、統一コンパイラ（FlagTree）、圧縮ツール（FlagOS-Compressor）、標準化リリースチェーン（FlagRelease）の四層複利に明確に帰因させており、クロスチップ対応がプロジェクト制からインフラ能力へと移行したことを示す；vLLM アップストリームへの双方向貢献（オペレータ＋精度修正）は、FlagOS の対応成果が国際主流推論フレームワークへと還流しつつあることを示している。

2.2 智源コミュニティ：2026 年具身智能人材流動観察（09-01）

4. まとめ

本調査期間（09-01 10:18 ~ 09-02 10:18）の FlagOS エコシステムの主線：

  1. 智源公式発表「FlagOS 四日間で三度の Day0」は今調査期間の最大イベントである。Qwen3.8-Flash-Next、GLM-5.3-Flash は発表当日に対応、Hy4 preview はマルチチップで発表され、10 種類のチップをカバーした。Qwen3.8-Flash-Next の 8 つの融合オペレータと 1 つの精度修正はすでに vLLM 上流へ還流済みである。Hy4 preview の INT8 実装は FlagOS-Compressor 量子化ツールチェーンに依存する——「連続 Day0」は公式に公共ソフトウェアスタックの複利効果と定義された。
  2. 2.2 RC0 検証が推進：FlagOS-Compressor は v0.1.0-rc0.post1 を打った（2.2 で新規追加されたモジュールの最初の検証 tag であり、マニフェストと完全に整合）。community #105 は vllm-plugin-FL 0.2 メンテナンスラインを 2.2 マニフェストに組み込み、リリース管理の粒度をメンテナンスブランチまで細分化した。
  3. build-infra 検証マトリクスのエンジニアリング化：sglang 検証マトリクス Phase 0 が立項されクローズした（vLLM/megatron に続く三本目のマトリクス）。昇騰（ascend-cann8.5.0）vLLM アプリケーションイメージが初めて統一管理に登録され、沐曦/摩尔線程のイメージ tag がバッチでデータベースに格納され、PR ステータス列のリアルタイムレンダリングがオンライン化された。
  4. sglang-plugin-FL が FlagCX KV 伝送バックエンドを導入し PD 分離デプロイを支援、海光バックエンドの命名を規範化（hcu → hygon）。FlagCX は訓練通信ライブラリから推論デカップリングデプロイシナリオへ拡張した。
  5. メンバー企業の動向が密集：燧原は本日（9/2）にネット申し込みを開始し、「四小龍」が A 株に集結（董事長は遅くとも 2027 年に黒字化と発言）。地平線は H1 売上高 +32.9%、報告上は黒字転換したが調整後は依然赤字、ライセンスモデルが半分以上を占め、征程 7 は 2027Q2 のテープアウトを予定。沐曦と優必選が合弁で曦選創智を設立。海光は光大銀行から 1.33 億元の調達を獲得。
  6. ニュース側のコンポーネント単位クエリは依然として散発的なヒットが中心（今調査期間で唯一の直接ヒットは智源公式の Day0 記事）。GitHub コミットとメンバー企業の財務動向は依然として信頼できる動向源であり、コンポーネントバージョンのリズム（rc0.postN 検証 tag）は集中的な実装期に入っている。
