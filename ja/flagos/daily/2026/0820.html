1. オープンソースプロジェクトの進展（GitHub 動向）

期間総覧：org 内の 53 リポジトリのうち 14 が期間内にプッシュあり；commit search は期間内コミット 65 件をヒット（build-infra 24 件、FlagBLAS 19 件が上位）、正式な GitHub Release はなし。本期間のトップニュース：build-infra が曦望芯科 SUNRISE バックエンド推論の全チェーンを開通——FlagTree sunrise wheel 生産ラインを正式化し、vllm 両バージョン（0.24.0/0.20.2）のエンドツーエンド検証とオンライン decode hang 修正を完了；ほかに vllm-plugin-FL が初めて昆侖芯バックエンドをサポート、Torch-FL 三チップ機能を同日補完、FlagScale に昇騰/沐曦 CI を新規追加。

1.1 build-infra：曦望芯科 SUNRISE 推論全チェーン開通（期間トップニュース、12 件のコミット）

出典：build-infra commits

  • wheel 生産ラインの正式化（8/19 15:26 #442）：新たに packaging/flagtree/sunrise ビルド機構を追加——ubuntu 22.04 old-glibc ベース（metax builder モードと同一）、sunrise 依存関係をプリセット（LLVM 22 / sunriseTritonPlugin_v0.6.0.4 / triton toolkits）、FLAGTREE_BACKEND=sunrise でソースから FlagTree wheel をビルドしバージョンゲートを実施、併せて CI target を新規追加。同日 #441 で vllm-sunrise 0.24.0 の TANGRT 1.2.0 上でのエンドツーエンド検証を完了（ptpu ビルドの DOCKER_RUN_FLAGS を含む）。
  • ビルドトラブルシューティングシリーズ（8/19 17:16-20:25 #445-#450）：clang/lld による gcc 代替ビルド、ld.lld ツールチェーン検査、システム python3.10 での cp310 wheel ビルド、pip を阿里雲ミラーに変更（runner が pypi.org に直接接続不可）、$ORIGIN RUNPATH の復元と tang エイリアスの付与。
  • オンライン問題の修正とデュアルバージョン再確認（8/20 07:39-09:01 #451/#459/#461）：sunrise FlagTree wheel を再ビルドし decode hang を修正（vllm 0.20.2 §2.9 と 0.24.0 §11.5 の2箇所に記録）；続いて sunrise 0.24.0 vllm-repack エンドツーエンド（#459）と 0.20.2(F) 再確認（#461）を完了。
  • 同リポジトリのその他コミット：metax flagtree 学習 E2E と merged-wheel 用法変更記録（#435）、megatron-rl app 環境で TORCHINDUCTOR_COMPILE_THREADS=1 を固定（#443）、NVIDIA flash-attn ソースビルド workflow（#454）、NVIDIA cuda13.3 四情景デュアルコンパイラ検証記録（#455）、app image プレフィックスを flagos-app に統一し tag 命名を規範化（#457/#462/#463）。

解読：曦望芯科 SUNRISE は 8/18 に FlagTree バックエンド依存関係の更新（#999）を完了後、本調査期間で直接「wheel 生産ライン + 推論 E2E + オンライン問題修正」の深層デリバリ段階に突入——ビルドベース選定からイメージソース対応、さらに decode ハング修正まで、全チェーンのエンジニアリング完成度は最近の国産バックエンド接続の中で最も完全な一例（これまでは達摩院玄鉄 PPU のみが同程度の深度に達していた）。同時に NVIDIA 側の megatron app image 機構（flash-attn ソースビルド、cuda13.3 デュアルコンパイラマトリクス、tag 命名規範）も同時に整備され、学習/推論イメージ体系は統一に向かっている。

1.2 vllm-plugin-FL：昆侖芯バックエンドを新規追加（#268）

情報源：PR #268（8/19 15:16 マージ）

vLLM 0.20.2（空ライブラリ対応）をベースに vllm-plugin-FL へ Kunlunxin 昆侖芯バックエンドサポートを追加。検証モデルは Qwen3.6-35B-A3B と Qwen3.6-27B、テストは高並列テキストおよび画像入力（TP=4、max-model-len 16384、FLAGCX_PATH と USE_RESHAPE_AND_CACHE_FLASH を統合）をカバー。昆侖芯は 8/18 に KernelGen 生産ラインで首批オペレータ（digamma、arctan minimax、bernoulli）をマージしたばかりで、翌日には推論プラグインラインに進出——推論側の国産バックエンドマトリクスがさらに一席拡大（これまでに燧原、天数智芯、摩尔線程、昇騰などをカバー済み）。

トレンド判断：本調査期間のチップ版図の特徴は「推論チェーンの深層的な疎通 + バックエンドマトリックスの持続的な外拡」である。一方で、曦望芯科 SUNRISE は国産バックエンドを FlagOS に接続する最も完全なチェーン（wheel 生産ライン→E2E→問題修正）を完成させ、崑崙芯がそれに続いて推論プラグインラインに入り、推論側のバックエンドカバレッジは既に6社以上に達している；もう一方で、学習側（FlagScale/FlagBLAS/Torch-FL）は「マルチチップ CI マトリックス + オペレータファミリの補完 + AMP/profiler 能力」の三本柱で並行して前進している。ビジネス面では、地平線征程6B の千万セット指名、海光のエコシステム提携2連発、摩尔線程の香港上場進展が主な注目点を構成しており——ソフトウェアスタックの対応とビジネス実装のリズムは同期している。

4. まとめ

  1. 曦望芯科 SUNRISE 推論全チェーン開通（本調査期間のトップニュース）：build-infra の12件のコミットで sunrise FlagTree wheel 生産ライン（#442、ubuntu 22.04 old-glibc ベース + LLVM 22 + sunriseTritonPlugin v0.6.0.4）、vllm-sunrise 0.24.0 E2E（TANGRT 1.2.0、#441）、decode hang 修正と 0.20.2/0.24.0 両バージョンの再検証（#451/#459/#461）を完了——国産バックエンドを FlagOS に接続する最も完全なエンジニアリング事例。
  2. 昆仑芯が推論プラグインラインに参入：vllm-plugin-FL #268 が vLLM 0.20.2 をベースに昆仑芯バックエンドをサポート、Qwen3.6-35B-A3B/27B の高並列テキスト・画像検証に合格；その KernelGen オペレータのマージからわずか1日後。
  3. 学習側は三線並行：Torch-FL が同一日に3チップを補完（達摩院玄鉄 PPU AMP 完了、摩尔線程 MUSA MUPTI profiler、昇騰 AMP 拡張）；FlagScale に昇騰/沐曦のビルドテスト CI を新規追加；FlagBLAS が1日で Level-2 疎/帯オペレータファミリー（SYMV/SPMV/GER/SYR/HER/SPR/HPR/SYR2/HER2/GBMV/HBMV/SBMV）を補完。
  4. イメージとエンジニアリング機制の整備：build-infra が app image プレフィックスを flagos-app に統一し tag 命名を規範化（#457/#462/#463）；NVIDIA flash-attn ソースビルド（#454）と cuda13.3 の4シナリオ・デュアルコンパイラ検証記録（#455）を新規追加；TransformerEngine-FL が TP comm overlap に必要な backend ops を公開（#95）。
  5. 会員単位の商業面が活発：博世の征途6B ベース MPC4 が千万セット級の定点を獲得（地平線、征途6B 累計定点量が2000万セット突破）；海光が天璣データ、格尔軟件と2件のエコシステム協力を達成；摩尔線程が香港株式市場への上場を冲刺；寒武紀のインセンティブ解除が着金。
  6. ニュース側は平静：コンポーネントキーワードはゼロヒット、HN に有効な結果なし、正式な GitHub Release なし；FlagTensor 0.2.x と Megatron-LM-FL 0.2.0 シリーズは依然として準備中で、リリースのシグナルは現れず。

限界説明：コミット数とマージ時間は commit search に由来（検索インデックスは実際のマージよりやや遅れる可能性があり、個別コミットの時間は repos API の pushed_at を基準とする）；FlagBLAS シリーズのコミットは主に AriesMTR 貢献者バッチの一括マージ；gnews のジャンプリンクは本文を取得できないため、ニュース側の判断はタイトルと複数ソースのクロスチェックに依存；曦望芯科（SUNRISE）と昆仑芯は org 会員単位の公式リストに含まれていないため、バックエンドエコシステムの事実に基づき帰纳；「天基智算」の項目は 7/24 打ち上げイベントに関する 8/19 の深度報道であり、調査期間内の新規打ち上げではない。
