FlagOS デイリーレポート (2026-08-19)

2026-08-19 Kubuds

調査期間：2026-08-18 10:19 ~ 2026-08-19 10:19 北京時間 情報源：GitHub（org: flagos-ai）、Google News アグリゲーション（中国語・英語）、HN、HuggingFace、智源コミュニティ等（詳細は付録参照）

1. オープンソースプロジェクトの進展（GitHub 動向）

期間総覧：org 内 53 リポジトリのうち 15 が期間内にプッシュあり；commit search で期間内コミット 145 件がヒット（うち FlagGems-Experimental が 80 件で、org 内の単一リポジトリ・単一期間としては最高記録）、正式な GitHub Release はなし。本期間のトップニュース：FlagGems-Experimental KernelGen 全ベンダーオペレータ一括出荷（80 コミット、NVIDIA/海光/天数智芯/摩尔線程/達摩院玄鉄/沐曦/崑崙芯/寒武紀/燧原のマルチバックエンドが同日マージ、さらに寒武紀 MLU C++ Runtime サポートの新規追加と Apache 2.0 ライセンスの全量補記）；ほかに FlagTree に SpaceMiT（進迭時空）バックエンドを新規追加（第 14 のバックエンド）、sglang-plugin-FL が初めて天数智芯 Iluvatar と摩尔線程 MUSA に接続、vllm-plugin-FL 燧原 Enflame S60 が CI に参入。

1.1 FlagGems-Experimental：KernelGen 全ベンダーオペレータ一括出荷（80 コミット、期間トップニュース）

出典：FlagGems-Experimental commits

8/18 午後から夜にかけて 2 波に分けてマージ：

  • 第1波（8/18 17:04-17:15 北京時間、約50件）：
    • NVIDIA側：特殊関数ファミリーの一括追加（special_i0、special_softmax、special_logsumexp、special_legendre_polynomial_p、special_shifted_chebyshev_polynomial_t、special_xlog1py、special_log1p、special_spherical_bessel_j0）、ほかに slice、split_with_sizes などの基本オペレータ。
    • チップメーカー側：海光 Hygon が一度に10個の専用オペレータ（cudnn_convolution、broadcast_to、adaptive_max_pool3d_backward、diff、broadcast_tensors、amp_foreach_non_finite_check_and_unscale、tile、repeat、softplus_backward、avg_pool3d_backward、nll_loss_backward）；沐曦 MetaX の大量バッチ（lgamma/lgamma_、adaptive_max_pool3d_backward、special_chebyshev_polynomial_u、alpha_dropout、linalg_cholesky、log_normal_、erfinv/erfinv_、gcd_、special_gammaln など）；天数智芯 Iluvatar（addmm_、nonzero_numpy の2パス混合 kernel）；摩尔線程 MThreads（linalg_cholesky）；達摩院玄鉄 thead（lcm/lcm_）；崑崙芯 Kunlunxin（digamma、arctan minimax 多項式 kernel、bernoulli）；燧原 ENFLAME 20260709 更新。
    • エンジニアリングガバナンス：全ソースコードへの Apache 2.0 著作権ヘッダー一括付与（#4873）、CI のタイムアウト/失敗/OOM/精度問題の一括修正（#4829）、FlagTune topk lens 設定、op-monitor 更新。
  • 第2波（8/18 18:21-22:31 北京時間、約30件）：8/18 午前のメインリポジトリの「チップ専用バッチ」モードを継続——[KernelGen][Hygon]（#5557）、[KernelGen][Iluvatar]（#5558）、[KernelGen][MThreads] 20オペレータ（#5556）、[KernelGen][T-Head]（#5560）、[KernelGen][MetaX]（#5559）が相次いでマージ；寒武紀 MLU C++ Runtime オペレータサポート（#5535）；NVIDIA の13個の新オペレータ（compute_linear_combination、_convolution_mode、_add_relu、blackman_window、bilinear、value_selecting_reduction_backward、addmv_、resize_output、as_strided_scatter、cholesky_solve_helper、unflatten、_scaled_dot_product_efficient_attention、acos）；fused_rms_norm_backward 登録（#5074)；KMCompiler index_copy/index_copy 汎用 kernel 最適化（#5496）、log_sigmoid_backward（#5012）。

解読：KernelGen オペレータ生産ラインは「マルチベンダー並列一括出荷」の新段階に入った——単一調査期間内に9つのバックエンド（NVIDIA、Hygon、Iluvatar、MThreads、T-Head、MetaX、Kunlunxin、ENFLAME、MLU）すべてでマージがあり、かつベンダーバッチ（#5556-#5560 の連続番号）は各チップメーカーが統一プロセスで生成物をコミットしていることを示している。C++ Runtime 層の MLU サポートと Apache 2.0 ライセンス補注は、プロジェクトがオペレータカバレッジを拡大しつつ、ランタイムの深層対応とオープンソースコンプライアンスガバナンスを同時に推進していることを示している。

トレンド判断：本調査期間のチップ版図の特徴は「KernelGen 生産ラインの全ベンダー化＋バックエンド生態系の外延拡大」である。一方で、9 つのバックエンドが単一調査期間で同時に出荷され、ベンダー側は「対応される側」から「統一手順に従って自らコミットする側」へと転換した（#5556-#5560 の連続ベンダーバッチが証左）。他方で、FlagTree に RISC-V の新メンバーである進迭時空が加わり、推論プラグインライン（sglang/vllm）がマルチチップ化を開始し、さらに昇騰が Torch-FL/FlagDNN/FlagGems/build-infra の四方面で展開——FlagOS の「統一ソフトウェアスタック」は、より広範なチップとフレームワークへ浸透しつつある。

4. まとめ

  1. FlagGems-Experimental は単一調査期間で 80 件のコミット、KernelGen は全ベンダー一括出荷（本調査期間のトップニュース）：9 つのバックエンドが同日／翌日にマージされ、ベンダー専用バッチ（#5556-#5560）、寒武紀 MLU C++ Runtime サポート、NVIDIA 特殊関数群と 13 の新規オペレータを含み、さらに Apache 2.0 ライセンスの全量補注を完了——オペレータ生産ラインは「マルチベンダー並行、深層対応」段階に入った。
  2. FlagTree バックエンドマトリクスが 14 社に拡大：SpaceMiT（進迭時空）バックエンドが仕様に従い正式にアップストリーム化され CI/CD を追加、RISC-V 陣営は達摩院玄鉄真武 PPU に続くメンバー追加となった。曦望芯科 SUNRISE バックエンドも同時に更新。
  3. 推論／訓練プラグインのマルチチップ化が加速：sglang-plugin-FL が初めて天数智芯 Iluvatar バックエンドに接続し、摩尔線程 MUSA e2e を完了。vllm-plugin-FL は燧原 Enflame S60 が CI に参加。Torch-FL は昇騰 MSPTI profiler と PrivateUse1 汎用 autocast を新規追加。
  4. build-infra の仕組みをアップグレード：vllm wheel/plugin/app-image の三段パイプラインを統合整理（#431）。寒武紀 index op の根本原因修復後、vllm-repack ブラックリストは過渡状態へ移行。昇騰 hw26 デュアルコンパイラの E2E 記録。
  5. メンバー企業の商業面が活発：摩尔線程は香港株上場を計画、海光天曦シリーズはパブリッククラウドで規模化して上線、天数智芯は赤字脱却の分析、寒武紀は株式インセンティブの解除——ソフトウェアスタック対応と資本市場の動向が同時に進行。
  6. ニュース面は平穏：コンポーネントキーワードはゼロヒット、HN に有効な結果なし、正式な GitHub Release もなし。FlagTensor v0.2.0-rc2.post1 タグと Megatron-LM-FL 0.2.0-rc2 ブランチは、新たなリリースが間近である可能性を示唆。

限界に関する説明：FlagGems-Experimental のコミット数とマージ時間は commit search に由来する（検索インデックスは実際のマージよりやや遅れる可能性があり、個別コミットの時間は repos API pushed_at を基準とする）。FlagDNN Ascend バックエンドの「poor perf」結論はコミットコメントに由来し、独立したベンチマークデータは見られない。gnews のリダイレクトリンクは本文を取得できず、ニュース側の判断はタイトルと複数ソースのクロスチェックに依存する。SUNRISE（曦望芯科）と SpaceMiT（進迭時空）は FlagTree バックエンドマトリクスの新規メンバーとしての整理であり、両者はまだ org メンバー企業の公式リストには現れていない。
