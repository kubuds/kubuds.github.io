今日の重点：2.2 GA（09-28）まで 3 日——デリバリー範囲監査が始動：18 項目の FEP を保持、6 項目を 2.3 に延期

日付：2026-09-24　出典：community #115、community #114

rc2 安定化期間は公式スケジュール通り 09-24 に締め切られ、GA は 09-28 に予定されている。調査期間内におけるリリースエンジニアリングの主体動作は「リリース物の凍結」から「範囲と声明の凍結」へ移行した——09-24 14:29（北京時間）、community リポジトリで PR #115「docs: define delivered FlagOS 2.2 FEP scope and defer remaining work to 2.3」（ブランチ docs/fep-2.2-rc2-audit-20260924、当日二回プッシュされ 16:12 に至る）が開かれた：

  • 範囲二分：2.2 索引には 18 項の Implemented FEP を含む（保留）；FEP 0019、0069、0081、0084、0093、0100 の六項は目標バージョンを 2.3 に変更し、状態を Deferred とマーク。
  • 保留項の厳格化：各保留 FEP は「実装済みのインターフェース + 検証済みの設定」に限定し、その他の目標は明示的な 2.3 節と関連する deferred-work インデックスに移す。
  • RC2 对照の更新元：source revisions、API、パッケージング詳細、テストコマンド、関連 PR を項目ごとに更新し、検証のトレーサビリティ、プラットフォーム障害、既知の制限を保持する。
  • 口径の明確化：Tree primitive QA と NVSHMEM 融合 / FlagCX-backed 融合、および Compressor 成果物テストと全モデル推論受け入れを明確に区別する——「コンポーネントレベルの検証」を「エンドツーエンドの受け入れ」と言い換えないようにする。
  • 文体制約：簡潔な英語を要求し、テンプレート文言と「未サポートの完了 / 性能宣言」を削除する。

同期間、L1 オペレータライブラリ十组件の正式タグ一覧（community #114：flaggems v5.4.0、flagfft v0.2.0、flagsparse v0.3.0、flagdnn v0.3.0、flagblas v0.3.0、flagtensor v0.3.0、flagaudio v0.3.0、flagattention v0.4.0、flaggems-vllm v0.2.0、flaggems-sglang v0.1.0）は依然として審査中（waiting merge）。

判断：昨日観察されたのは「一覧、タグ、範囲の三者が相互検証する」ことであり、本日 #115 は検証を第三層——対外宣言そのもの——へと推進した。GA 前の 3 日間は新機能を追わず、「実装済み / 検証済み / 延期」を分けて記述し、逐条証拠を紐付ける。これはリリース規律の動作である：2.2 の公開紹介はこの版の FEP ドキュメントを事実の底本とし、その後の 2.3 の開発ナラティブ（3D 算力、量子などの新方向を含む）も 2.2 のデリバリー境界と正式に切り分けられる。

3. メンバー単位の深掘り

3.1 摩尔線程：Protenix-v2 全链路推論サポート——AI4S 三場景クローズドループ（09-24）

日付：2026-09-24　情報源：IT之家（鳳凰網転載）、第一財経

摩尔線程は、自主 MUSA ソフトウェアスタックに基づき、訓推一体智算カード MTT S5000 上でオープンソース生体分子構造予測モデル Protenix-v2 の全链路推論サポートを完了したと発表した。Protenix-v2 は字節跳動 Seed チームが開発（2026-04 リリース）したもので、タンパク質、DNA、RNA 及び小分子リガンド複合体に対して高精度なエンドツーエンド予測を行える世界でも数少ない完全オープンソース基盤である。実測：S5000 のエンドツーエンド推論性能は国際主流 GPU 比で平均約 26% 高速化、三次元コンフォメーション予測精度は高度に整合。今回の適配により、摩尔線程は大分子構造予測、全ゲノム配列モデリング、臨床医学影像の三大 AI4S 核心場景におけるエンドツーエンド工程検証を完了した。昨日レポートの RLinf × S5000 訓練側の動向と相接し——訓練側（具身 RL）と推論側（AI4S）が同一週にそれぞれ一石を落とした、「国産算力が科研ワークフローを承接する」という場景叙事は引き続き拡面している。

3.2 昇騰：910C NPU 可視性修復と RL 訓練チェーン就緒（09-24）

日付：2026-09-24 ~ 2026-09-25　情報源：build-infra #1105、#1107、#1103、FlagGems #6654
