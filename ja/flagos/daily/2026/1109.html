1.9 配布と基盤：TE-FL 純 Python wheel がワンラインで複数ベンダーに対応、vLLM 0.32 適応の波（11-08）

日付：2026-11-08　情報源：build-infra #1687（TE-FL 配布層リリースライン） · build-infra #1690（TE ディレクトリ項目） · build-infra #1683（vLLM 0.32 下限評価） · vllm-plugin-FL #706（平頭哥 PPU 上の 0.32） · sglang-plugin-FL #155（昆仑芯 0.5.18）

  • 配布層：#1687 で TransformerEngine-FL の純 Python wheel リリースラインを追加。TE_FL_SKIP_CUDA=1 で py3-none-any パッケージを構築し、1 回のビルドで全非 NVIDIA ベンダーの PyPI と日次インデックスにプッシュする。バージョンは 2.17.0+fl.0.3.0 の形式で、上流セグメントはバージョンゲーティングに使用し、FL バージョンはローカルタグで管理する。NVIDIA は除外される。そのネイティブパスが上流 TE そのものであるためだ。
  • 付随対応：#1690 で transformer_engine のディレクトリ項目と説明を追加。#1689 で te-fl-release の wheel リリースを記録。#1688 で runner 上の不安定な GitHub HTTPS に対するクローン強化を実施。
  • フレームワーク適応：vLLM 0.32.0 と SGLang 0.5.18 の集中適応が発生——平頭哥 PPU（#706）、天数（#674）、MUSA（#715）、昆仑芯 P800 は 0.28 経由（#585）、昇騰は FlagOS-Compressor の動的 W8A8 量子化に対応（#643）、いずれもレビュー中。昆仑芯と PPU の SGLang 0.5.18 の 2 件もいずれもレビュー中。
  • バージョン下限：#1683 で vLLM 0.32.0 の torch と Python 下限に対する評価結論を記録し、後続のマトリクスの布石とする。

4. まとめとトレンド観察

  • プラットフォーム面は「キーあり」から「デリバラブル」へ：平頭哥 ZW810E PPU は二日間でバックエンドキー、base イメージ、runtime changelog、状態マトリクスの四箇所を整列し、2.3.0 はこのバックエンドにとって初の runtime デリバリーとなった。デバイスは阿里雲 PAI-DSW イメージ内でのみ取得可能、runner に GitHub 出口なしという二つの制約がそのデリバリー形態を他のバックエンドと異なるものにしており、短期的に app 層は依然空白である。
  • オペレータ生産はすでにバッチリズムに突入：単日で FlagGems 123 件がマージされ、うち 87 個の昇騰オペレータは一人が一時間以内に登録、さらに 20 個の海光専用オペレータが審査待ちで列をなす。KernelGen は「オペレータを書く」ことを「生成結果を審査する」ことに変え、ボトルネックは実装からレビューと受け入れへ移った——これが審査中 PR 数（269 件）がマージ数を継続的に上回る理由を説明する。
  • 配布層は収束しつつある：TransformerEngine-FL は純 Python wheel 一份で全非 NVIDIA ベンダーに供給し、FlagTree の deb は一バックエンド一パッケージへ、rpm は公開済み wheel を直接取得する形へ変更、二つの動きは同一目標を指す——チップごとの重複ビルドを減らし、差異を設定に留める。
  • フレームワーク適配は波状：vLLM 0.32.0 と SGLang 0.5.18 の適配が調査期間内に集中して現れ、平頭哥、天数、MUSA、昆侖芯、昇騰の五社をカバーするが、绝大多数は依然審査中である。11-30 の rc0 前にマージできるかが、2.3 がマトリクス通りにデリバリーできるかの鍵となる変数である。
  • 2.3 は収口カウントダウンに入る：コミュニティ 2.3 タイムテーブルは FEP マージ締切 11-13、フィーチャーフリーズと rc0 11-30、rc1 12-07、rc2 12-14、コードロック 12-25、GA 12-30。本期は新規 FEP 提出なし、11-06 の那批六份（0164 から 0168、0170）は依然 Provisional Draft で自述に GPU 受け入れ未実施とあり、収口圧力は来週に集中する。
  • リスクと観察点：平頭哥 app 層未接続、海光 20 オペレータ全件審査中、天数四条 CI のうち三箇所審査中、競賽提出は登録のみで成績未出——四項目はいずれも「動作あり、受け入れ未到」に属し、来週は新規量ではなくマージ率に注目すべきである。

本版の訂正について

本号に掲載した PPU バックエンド（thead-ppu* バックエンドキー、ZW810E、PAI-DSW イメージ、PPU_SDK）は平頭哥（T-Head）に属し、玄鉄ではありません。従来版はこのバックエンド系列を「玄鉄」と表記し、2024 年に平頭哥から分社化して達摩院へ移管され、RISC-V プロセッサのみを手がける玄鉄（XuanTie）と混同していました。thead は平頭哥が現在も使用しているオープン向けブランド名です。本版はすべて平頭哥に訂正しています。
