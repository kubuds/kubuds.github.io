  • 09-02 機関格付動向：壹評級が沐曦股份（688802.SH）に対する初回格付レポートを発表（東方財富、第一財経が同時掲載）、沐曦上場後にセルサイドのカバレッジ体系が構築され始めた。

  • 09-02 メディア観察：寒武紀（688256.SH）がソフトウェア人材を大規模採用、チップハードウェアの物語から「ソフトウェアスタック/エコシステム」への投資シグナルと解読されている（寒武紀はFlagOS側でDay0十芯片の一つであり、build-infra本調査期間でneuware4.7.2/4.4.3デュアルバックエンドのvLLMアプリケーションイメージを登録）。

3.5 地平線と業界の視点：ソリューション販売から基盤販売へ；国産 GPU は規模納入の大試練へ（09-02/09-03）

出典：新浪（従卖方案到卖底座）、搜狐（芯片出貨 221.8 万套）、極客公園（規模交付大考）、鳳凰網財経（次の一手は何か）

  • 地平線（09660.HK）中報続読（09-03 朝の2本）：新浪財経《従卖方案到卖底座》はその収入構造（ライセンス及びサービス収入が過半を占める）の背後にあるアイデンティティ転換——智駕ソリューション事業者から「基盤/プラットフォーム」型企業への転換——を分解；搜狐は「チップは221.8万セット販売（+12.1%）、しかし過半の収入はチップ販売ではない」という衝突感のあるタイトルで中報の話題を引き続き醸成。いずれも昨日の中報の解読の延長であり、新データはなし。

解読：地平線は FlagOS メンバー（D-Robotics BPU）としての「基盤化」転換ナラティブが FlagOS オープンソースソフトウェアスタックのプラットフォーム位置づけと同じ方向を向く；業界評論が集団で「規模納入」へ転換することは、FlagOS のような統一ソフトウェアスタックの価値提案（一度の対応で複数チップに納入）が産業需要の上昇期にあることを意味する。

4. まとめ

当調査期間（09-02 10:18 ~ 09-03 10:18）の FlagOS エコシステム主線：

  1. GitHub 側は高活性、リリース側は安定：16 リポジトリでプッシュ、調査期間内に48件のコミット；tags/releases API の検証では調査期間内に新規 tag/release なし——昨日以前の 2.2 rc0.post1 検証 tag の集中期が終わり、バージョン安定期に入った（次のシグナルは community リストリポジトリの動きに注目）。
  2. build-infra 推論イメージマトリクスの拡大：vLLM 0.24.0 アプリケーションイメージラインが同日に寒武紀（neuware4.7.2/4.4.3 デュアルバックエンド）、天数智芯（corex4.4.0）、燧原（tops1.9.10）の3社メンバーを接続、昨日の昇騰/沐曦/摩尔線程に加え、マルチベンダー推論イメージ登録は6社以上をカバー；sglang 検証マトリクスは2日間で Phase 0 から Phase 5 へ進行（0.5.18 アプリケーションイメージ + import-face shim wheel）。
  3. FlagGems マルチベンダーバックエンドの整備が高頻度：海光 HCU オペレータ性能最適化、天数智芯 Iluvatar の Triton 3.6 リグレッション修正、KernelGen/KMCompiler の新規オペレータ5件登録；メンバーチップバックエンドの「修正と最適化」が調査期間内のオペレータライブラリの主旋律に。
