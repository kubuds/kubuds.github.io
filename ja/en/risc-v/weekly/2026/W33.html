RISC-V Weekly Report (2026-08-12)

2026-08-12 Kubuds

Data sources: Aggregated from local daily briefings (8/11, 8/12) + supplementary GitHub organization commit collection (8/6-8/10 window, XUANTIE-RV / OpenXiangShan / Nuclei-Software / sophgo / spacemit-com, etc.) + cross-window report backfill. Note: The local daily briefing system was migrated from the K3 machine on August 11. There are no per-day briefings for 8/6-8/10; that interval is based on GitHub commits and cross-window reports from 8/10-8/11, with deduplication and merging applied as much as possible.

I. Open-Source Community and Kernel/Specification Updates

1.1 Public review of RVA23.1 and RVB23.1 Profiles officially launched

Date: 2026-08-11　Source: HN / RISC-V isa-dev mailing list

The RISC-V International Foundation has launched a public review of the RVA23.1 and RVB23.1 Profiles, soliciting feedback from the entire community. This is the first maintenance iteration following the release of the RVA23/RVB23 specification series, covering detailed revisions and errata updates to the Class A application and Class B baseline Profiles, and it provides direct guidance on the adaptation cadence for toolchains, kernels, and the compiler ecosystem.

1.2 QEMU 11.1 released: adds RISC-V big-endian support and K230 board emulation

Date: 2026-08-12 (released 08-11 16:11 UTC)　Source: Linuxiac, verified via mirror

The headline feature of QEMU 11.1 is RISC-V big-endian target support, corresponding to the realization of runtime-controllable endianness on RISC-V (the subject of prior research by Codethink). On the RISC-V side, enhancements include: added support for the Canaan K230 development board, an OpenSBI upgrade to 1.8.1, added Tenstorrent mvendorid support, and fixes for a large batch of IOMMU, interrupt handling, page table walk, and vector instruction issues. RISC-V kernel/distribution developers can now validate big-endian software stacks in the emulator ahead of time.

1.3 XiangShan: a week of timing and correctness fixes

Date: 2026-08-06 ~ 08-10　Source: GitHub OpenXiangShan/XiangShan

XiangShan merged several fixes this week: FTQ/ICache meta read port timing (#6281), Phr update timing during s1/s3 (#6263), cleanup of vbop handshake logic (#6163), WriteBuffer read-write conflicts on the same entry (#6315), s1_instrCount computation on IFU exceptions (#6301), and StoreUnit sending paddr to UnalignQueue only on dual TLB hits (#6332). In addition, the XiangShanLab repository added RISC-V spec/gap skill tooling (8/10). Engineering work continues apace, providing support for the architectural upgrade (see 3.2 KaixinHong).

1.4 RISC-V specification infrastructure repositories active

Date: 2026-08-11/12　Source: riscv-unified-db / riscv-arch-test

riscv-unified-db (the machine-readable specification database) merged several dependency maintenance commits, and riscv-arch-test updated its Ubuntu 24.04 Docker image. This is the routine cadence of specification engineering, advancing in tandem with the RVA23.1 review.

1.5 Community reflection piece “RISC-V: They Should Have Known Better” sparks discussion

Date: early 2026-08　Source: HN / dmitry.gr

Veteran embedded developer Dmitry.GR published a long-form article criticizing RISC-V’s shortcomings in low-level design areas such as interrupt latency, instruction density, and addressing modes, arguing that some embedded metrics fall short of architectures designed decades ago. The article triggered extensive discussion on HN/Reddit and was also reposted by Chinese media outlets such as Sina. It is the most important opinion piece at the community level this week (an opinion piece, not an official position).

1.6 labwired-core: enhanced ESP32-C3 (RISC-V) firmware emulation capability

Date: 2026-08-12　Source: GitHub w1ne/labwired-core

labwired-core (59 stars), a deterministic firmware emulator written in Rust, merged 15 commits: added an ATmega328P Nano twin, fixed DHT one-wire timing on ESP32-C3 (RISC-V), and added resource metrics functionality. Coverage of RISC-V MCUs in “firmware-level emulation/virtual hardware” toolchains is expanding.

II. Product and Ecosystem Updates

2.1 Comu: $6 USB-port RISC-V Development Board

Date: 2026-08-10　Source: CNX Software

The tiny development board Comu, based on the WCH CH32V203 (RISC-V core MCU), fits entirely inside a USB port (in the form of a USB flash drive) and sells for about $6, significantly lowering the barrier to entry for RISC-V MCUs. It drew discussion on HN.

2.2 Dabao (Baochip-1x, DEF CON 34 Badge Chip) Ecosystem Takes Shape Rapidly

Date: 2026-08-10　Source: Adafruit Blog

The Baochip-1x RISC-V SoC powering the DEF CON 34 badge has received an experimental MicroPython port; on GitHub, attempts to boot mainline Linux (baochip-linux), a bare-metal DOOM port (baochip-doom), and a bare-metal C SDK (dabao-sdk) have already appeared. Within a single week, the community has come together to “port Linux + run DOOM + ship an SDK” — a textbook example of the RISC-V open-source hardware community’s vitality.

2.3 Zunjie V800 Smart Seats Feature ESWIN RISC-V Automotive-Grade AI MCU

Date: 2026-08-10　Source: MyDrivers / ifeng

The HIMA Zunjie V800 made its debut, with the core compute for its fully active adaptive smart seats handled by the ESWIN EAM2011 — China’s first automotive-grade MCU supporting lightweight AI applications, built on a self-developed 32-bit RISC-V core and completing full-chain localized R&D and mass production. This is a landmark case of domestically developed RISC-V automotive-grade chips entering volume production vehicles.

2.4 Preview of the 5th Dishui Lake China RISC-V Industry Forum (to be held on August 13)

Date: 2026-08-07 (announcement)　Source: Sina Finance

The 5th Dishui Lake China RISC-V Industry Forum is scheduled for August 13, with 10 advanced domestic chips to be unveiled together (specific results will be covered in the next weekly report).

III. Domestic Team Updates

3.1 Nuclei: Capitalization Push + Debug Toolchain Ecosystem + Hummingbird FPGA Fixes

Date: 2026-08-06 ~ 08-11　Source: Sina Finance / Nuclei-Software GitHub

Three tracks advancing in parallel: on August 10, filed with the National Equities Exchange and Quotations (NEEQ) for the Innovation Tier and raised 42 million yuan in a targeted offering; on August 11, added the lauterbach-startup repository (Lauterbach TRACE32 debugger startup scripts, adapting to international debug toolchains); e603_hbird (Hummingbird E203-related) merged DDR clock hierarchy and bitstream FPGA fixes (8/6-8/7). “IP leader capitalization” and “ecosystem toolchain” advancing on dual tracks simultaneously.

3.2 OpenCore Red (XiangShan IP commercialization entity): Over 100 million yuan seed round, backed jointly by state capital and leading industrial investors

Date: 2026-08-11/12　Source: Guandian / The Beijing News

OpenCore Red completed a seed round of over 100 million yuan, with funds directed toward XiangShan IP core architecture upgrades; the investor lineup was subsequently disclosed: Guokai Venture Capital, Chengtong Venture Capital, CAS Star, Zhongguancun Science City, Qihang Fund, Guotai Venture Capital and other state-owned and leading industrial investment institutions. XiangShan IP commercialization has secured backing from both national-level policy capital and local industrial capital (reported over two consecutive days this week, merged into one item).

3.3 ESWIN Computing: Dual-track deployment in automotive-grade and consumer AI private cloud

Date: 2026-08-10　Source: MyDrivers / NetEase (aggregated) / Hubei Economy and Information Technology Department (aggregated)

Multiple ESWIN developments stacked this week: on the automotive-grade side, EAM2011 entered the Zunjie V800 smart seat (2.3); on the consumer side, partnered with ZSpace on a domestic AI private cloud NAS, with all AI processing of image assets running locally; the group’s materials business (ESWIN Materials) plans to raise 6.5 billion yuan for 12-inch wafer expansion (first phase production in 2027). “RISC-V + AI” is being delivered simultaneously at both the automotive-grade and consumer ends.

3.4 SOPHGO: SophLiteOS adds AI Agent + intensive toolchain fixes

Date: 2026-08-09 ~ 08-12　Source: GitHub sophgo/sophon-tools / zsbl

Multiple merges within the sophon-tools window: SophLiteOS adds AI Agent functionality (including pbmssm LLM forwarding, picoclaw-web-chat embedding), pushing LLM Agent interaction capabilities down into the edge-side system toolchain — combined with K230/SG series RISC-V SoCs, this represents direct engineering progress on “RISC-V edge-side + LLM Agent”; additionally, pota_update/pmemory_edit security fixes, and consolidation of three Docker images into a single image (~10GB). zsbl build system optimization: stripping Linux-kernel dependencies, fixing incremental rebuild of built-in dtb.

3.5 SpaceMiT: K3 ecosystem documentation and edge-side AI acceleration advancing

Date: 2026-08-06 ~ 08-10　Source: GitHub spacemit-com

docs-ros updated the K3 robotic arm ONNX deployment guide (#200); docs-buildroot added the K3 Secure Boot guide; model-zoo-vision accelerated YOLOv8-Seg mask GEMM with eigen-spacemit + OpenBLAS (#64). K3’s robotics/secure boot/edge-side AI documentation stack was densely completed in the first week of August (note: the K3 flagship SoC will be officially released on 8/13 at the Dishui Lake Forum).

3.6 T-Head (XUANTIE-RV): damo-rv-priv-ats update

Date: 2026-08-06　Source: GitHub XUANTIE-RV/damo-rv-priv-ats

XuanTie DAMO (Dynamic Allocation and Memory Optimization?) RV Priv ATS repository update: adjusted config directory structure (#21), updated tests to use CSR encoding (#22, 8/11). Continuous iteration on the privilege and address translation side of the XuanTie ecosystem.

IV. Embodied Intelligence and Robotics

No major standalone news within the window. Adjacent signals: ESWIN EAM2011’s human pose recognition application on the Zunjie V800 (sensor perception + dynamic adaptation technology stack shared with robot control); SOPHGO SophLiteOS AI Agent provides a lighter software foundation for RISC-V robot brains; SpaceMiT K3 robotic arm ONNX deployment documentation update. The 8/13 Dishui Lake Forum is expected to feature embodied intelligence-related chip launches, worth tracking post-event.

V. Summary and Trend Observations

  1. Specifications side enters review window: RVA23.1/RVB23.1 public review launched, QEMU 11.1 lands RISC-V big-endian support, the adaptation path from specification to toolchain is closing the loop.
  2. Domestic RISC-V capitalization accelerating: Nuclei files for NEEQ Innovation Tier (raising 42 million yuan), OpenCore Red’s over 100 million yuan seed round backed by state capital, ESWIN Group’s 6.5 billion yuan expansion — IP/chip vendors are densely engaging both primary and secondary markets.
  3. RISC-V automotive-grade and edge-side AI scaling up: EAM2011 onboard the Zunjie V800, SophLiteOS with built-in AI Agent, ESWIN AI private cloud — domestic RISC-V is blossoming across multiple points in the “AI deployment” direction.
  4. Community ecosystem activity undiminished: $6 USB development boards, DEF CON badge chip Linux/DOOM/SDK ecosystem, Dmitry.GR’s reflective long-form piece on RISC-V sparking industry discussion — both fresh blood from low-barrier hardware and serious scrutiny of the architecture’s foundations.
  5. Looking ahead: The 8/13 Fifth Dishui Lake Forum (10 domestic chips showcased together, including SpaceMiT K3, BlueCore LX500 server CPU, Tops EA6530, etc.) is the most important industry observation window for the coming period.
