日付：2026-09-24　出典：v0.1.6 リリース PR（#68）／v0.1.5.post3 リリース PR（#63）／TileRT リリースページ

  • 09-24 夜（北京時間 20:22 と 23:33）、TileRT は2件のリリース PR を連続でマージした：v0.1.5.post3（#63、09-07 作成、調査期間内にマージ）と v0.1.6（#68、当日作成・当日マージ、プロジェクトメンバー Lingxiao Ma がマージ）。いずれもメインブランチに入っている。
  • v0.1.6 のリリースノートは：AMD Instinct MI350X/MI355X 上で GLM-5.2/5.3 サポート（ROCm パス）を追加し、PD 分離（プリフィル/デコード分離）関連の更新を含む。同日 #66（PD 側デコード KV 注入コピーのクロスデバイス対オーバーラップに関する性能単）がクローズされ、内容は今回のリリースの文脈に統合された。
  • なお、本レポートの確認時点（09-25 早朝）において、TileRT の GitHub Releases ページとタグは依然として v0.1.5.post2（2026-08-06） のままである——リリース PR はマージ済みだが、公開リリースページは追随していない。本デイリーレポートは「リリースプロセスは開始済み、ページは更新待ち」として記録し、次号で引き続き確認する。

判読：これは TileRT の月次大型バージョン（v0.1.5 シリーズ、08-06 リリース）以降の最初の新規増分である：パッチライン（post3）とマイナーバージョンライン（v0.1.6）が同日に推進され、ROCm / AMD Instinct MI350 シリーズをリリースノートの最も目立つ位置に置いている。「超低遅延推論ランタイム」という位置づけにとって、マルチハードウェアプラットフォームのモデルカバレッジが NVIDIA ラインと並行して強化され始めたことを意味する。

1. コアプロジェクトの進展

1.1 メインリポジトリ：NaN 伝播修正を2ラインでマージ、2件の欠陥単をクローズ（09-24）

日付：2026-09-24　情報源：#3273／#3270／#3205／#3024

  • #3273（北京時間 17:03 マージ）：サポートされていないリダクション NaN 伝播 dtype に対してコンパイル時エラーを追加——診断情報は操作名、サポートされる出力型、実引数 dtype を提示する。検証はネイティブ ReduceOp コンストラクタ内に配置され、ローカルリダクション、フラグメントリダクション、書き戻し累加を跨いでアキュムレータ dtype 契約を統一的に保持する。対応する欠陥単 #3270（reduce_max/min/absmax の nan_propagate=True が float32/float64 で暗黙的に無視される）はマージに伴いクローズ——09-23 の報告から修正マージまで、全行程で約1日半。
  • #3205（北京時間 13:44 マージ）：T.clamp の NaN 伝播セマンティクス修正——NaN 伝播する clamp をデバイステンプレートへ正しく降下させる。対応する欠陥単 #3024 がクローズ。この単はファジングテストで発見された「clamp が NaN を暗黙的に破棄し下限を返す」という誤ったコードクラスの問題に由来する。
  • 2つのラインが同日に着地したことは、前号で浮上した「NaN 伝播」セマンティクスのギャップが閉環したことを意味する：一方はサポートされていない構成をコンパイル時失敗へ前倒しし、他方は暗黙の誤った動作を期待される伝播セマンティクスへ修正した。

1.2 メインリポジトリ：SIMT im2col と非同期ステージング——性能欠陥単と二段階リファクタ PR が同日に成立（09-24）

日付：2026-09-24　情報源：#3274／#3275／#3279／#3278

  • 北京時間12:48、性能欠陥票#3274が起票：SIMT im2colの低減タイミングが遅すぎ、スケジューリングとベクトル化の機会を逃していた。3分後、#3275（CUDA/Transform、SIMT im2colのロードをスケジューリング前に前倒しして露出）が即座に起票——「当日報告、当日対策」のリズムが再現。
  • 当日23:22、#3278（Transform/CUDA：パーティションレイアウト下の非同期コピー低減を修正）がマージ完了——非同期コピーのパーティションレイアウト（partitioned layouts）下でのバグ修正がメインラインにマージ。
  • 09-25 未明00:30、#3279が起票：「非同期データ一時保持と転送認識低減の統一」——著者自身が#3275の抜本的なリファクタリングと述べ、畳み込み、mHC前置、Bounded GEMMなどのシナリオで「実質的な性能向上」があるとし、現在も実験的とマークされている。要点（PR要約による）：論理レベルのtileオペレータ展開と物理低減を分離し、CUDA/CPU/Metal/ROCm/WebGPUの各パイプラインがスケジューリングとレイアウト推論の前に論理アクセスを露出する。共有の転送分析（メモリアクセス効果、値変換、実行ガード、TMA使用を記述）を導入し、パイプライン計画がプリフェッチ段階と非同期候補を識別し、warp特化分析がSIMTプロデューサを識別し、CUDAとROCmの非同期コピー注入器が変換可能な転送を識別できるようにする。パイプライン待機計画が複数の非同期プロデューサ段階に依存するコンシューマをサポート開始。ベクトル化がベクトル化されたcp.asyncのためにアクセス区間を拡幅開始。スレッド同期分析がインデックスとポインタアクセスの物理バイトフットプリントを追跡。プロデューサプレフィックスが共有メモリに書き込む場合、TMA発行前に共有メモリ同期エッジを補う。別途開発者ドキュメントを添付し、im2colフォールバックテストを設定可能なパイプライン段階数に更新。
  • #3276（CUDA：FP8ベクトルコピーのパッキング状態を保持）が同日起票、レビュー中。

判読：「欠陥票 → アクセスの前倒し露出 → 一時保持と転送認識の統一」という三段階の漸進が同一日に成形され、しかも畳み込みとGEMM系負荷の性能骨格を直接狙っている。「論理アクセス」と「物理低減」の分離は、これまでの「乱数、レイアウト証明、NaNセマンティクス」などの手がかりと一脈相通じる——コンパイラは暗黙の動作をシステマティックに明示化し、合成可能性と診断可能性を獲得しようとしている。

日付：2026-09-24　情報源：tilelang-softhier リポジトリ

  • 個人コミュニティリポジトリ tilelang-softhier が北京時間 17:15~17:19 に README を更新し、リポジトリファイルを調整。リポジトリの自述によれば：これは TileLang をタイル型マルチ PE（many-PE）アクセラレータへ拡張する作業——カーネルは計算以外にタイルの帰属、タイルの NoC（オンチップネットワーク）上での移動と同期位置を決定する必要がある。ターゲットプラットフォーム SoftHier は GVSoC でモデリングされた、設定可能なマルチクラスタ RISC-V アクセラレータ（チューリッヒ工科大学統合システム研究室、Luca Benini 教授指導の学期プロジェクト、リポジトリは TileLang の fork）。
  • 核心設計原則：カーネル作者は「何を計算するか、データがどこにあるか」のみを宣言し、コンパイラがクラスタ配置、集合通信ルーティング、同期を導出する。結果表：4×4 クラスタ構成、BM=BN=BK=128 の 2D SUMMA GEMM、N=7168、K=2048（DeepSeek-V3 ルーティングエキスパートの次元削減投影サイズに対応）、M=512 時でコンパイラ生成コード 1.01 ms vs 手書き C 0.96 ms（差 5.14%）。
  • 傍証：コミュニティには他に TVM/TileLang Cookbook（30 スター）等の中国語学習資料があり、本期間のプッシュはスター推移グラフ自動化（chart ブランチ）で、メインブランチに新規内容なし。他にいくつかの散発的な個人実験リポジトリがあるが、実質的内容なし。

5. トレンド観察

5.1 リリースリズム：パッチラインとマイナー版本ラインが並行する TileRT

TileRT は 09-24 の 1 日で v0.1.5.post3 と v0.1.6 の 2 件のリリース PR をマージした。前者は v0.1.5 ラインの 3 番目のパッチ、後者は GLM-5.2/5.3 の ROCm（AMD Instinct MI350X/MI355X）サポートと PD 分離更新を統合したもの。8 月がわずか 1 件のリリースであったリズムと比較すると、これはリリースパイプラインが稠密化しているシグナルである；しかしリリースページとタグはリリース PR に遅れており、公開チャネルでの情報ギャップは次期も引き続きフォローする必要がある。

5.2 顕示化運動の第二波：意味検証からスケジューリングと一時保存へ

前ウィンドウの「NaN 伝播」はコンパイル期検証＋意味修復の二本立てでマージされ、2 件の欠陥チケットがクローズして締めくくられた；同一原則は直ちにコンパイラスケジューリング層へと転換している：SIMT im2col のロード早期露出（#3275）、論理アクセスと物理降低の分離による非同期一時保存の統一（#3279）、パーティションレイアウト下の非同期コピー修復（#3278）。「先に宣言、後に導出、暗黙を顕示へ」は言語意味から性能クリティカルパスへと延伸し、畳み込み、GEMM、mHC などのシナリオに直接寄与している。

5.3 LinearAttention ファミリーが整編期に入る

DeltaNet 推論オペレータ（09-23）から GLA 推論＋SM90 DeltaNet デコード（09-24）、さらに同日の 4 件の「レガシーパス削除／改名」ドラフトまで、線形注意力ファミリーのイテレーションモードが完全に現れている：拡張（学習側→推論側）→プラットフォーム化（SM90/H200）→整編（旧削除と収束）。ページング GQA の統一オペレータへの移行（#2202）は同一主線の注意力側の配套に属する。

5.4 空白とリスクポイント

第一に、大型案件のレビューバンド幅：メインリポジトリの TileIR バックエンド実行 PR と魔法除算などの大型変更は調査期間内に新規マージなし、加えてリリースが 23 日間停滞しており、「小口は速くマージ、大口は審査が遅い」という構図が継続している；第二に、昇騰ドキュメントの検証キューはバッチで進行しているものの、主体は 8 月中旬から保留されたままで依然としてオープン状態にあり、検収とマージのパスについて説明が見当たらない；第三に、TileRT のリリースページがリリース PR に遅れており、本テーマのバージョン追跡に短期的な盲点を構成している；第四に、摩尔線程が 2 週連続で沈黙、国産適配の 4 社は熱度が不均一である。
