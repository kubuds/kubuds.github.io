出典：バイウィークリーレポート第081期。qemu-user-riscv-ame コミット。qemu-system-riscv-rvp コミット。

11-19 10:33から14:42にかけて、packages-indexに13件のコミットが連続して落ちた。最初の4件は4つのエミュレータソフトウェアパッケージを追加した。qemu-systemとqemu-userがそれぞれ1セットずつで、それぞれAMEとRVPサポートを備える。

ウィークリーレポート081には、AMEサポートは達摩院が貢献したと明記されている。これは行列拡張が初めてインストール可能なソフトウェアパッケージの形でRuyiSDKソフトウェアソースに入ったことを意味する。

同じ号のウィークリーレポートは11-19に確定した。wechat-articlesリポジトリの調査期間内に9件のコミットが落ち、骨組み、本文から巻頭言まで順に補完された（#411から#418）。

今日の重点：buddy-mlirがZTT v0.6とLLVM行列拡張をマージ、triton-riscvバックエンドのチューニングが追随（11-19）

情報源：buddy-mlir PR #1066。PR #1067。triton-riscv PR #129。

11-19 19:20から19:21にかけて、buddy-mlirが2つのPRを連続してマージした。#1067はLLVMサブモジュールを542365c9cd38から163d6a753b58へ進めた。

新しいポインタはllvm-project forkの#33マージ点を指す。このマージはXSAIのZAMES行列命令とZMASYNC同期命令を加える。対象範囲には行列と同期のintrinsic、サイズなしターゲット拡張型、アセンブルと逆アセンブル、およびRV64 SelectionDAGの降級が含まれる。

サポート範囲には境界がある。行列のコピー、オーバーフローとリロード、および関数間ABIはまだカバーされていない。PRの説明ではサブモジュールポインタのみを変更し、行数は+1 −1である。

#1066は退役したAME方言を全面的にZTT v0.6へ置き換え、依然としてame名前空間を踏襲する。型付き命令opを138個定義し、カスタムアセンブリ構文とintrinsicブリッジを備える。

降級パスは一律でlower-ameを通り、llvm.riscv.ztt.*呼び出しに落ちる。PRには8×8と4×4の2組のサンプル、および2つのfreestanding負荷のgem5上での検証が付属する。変更は30ファイル、+8349 −1277。

下流は当日中に追随した。triton-riscvは18:20に#129を開き、RISC-Vターゲットのbuddy-opt降級パラメータを調整した。変更はターゲットがRISC-Vの場合にのみ有効で、計2ファイル、+137 −12。

チューニングは3つある。数学関数は多項式近似に変更し、exp、log、tanh、erf、sin、cos、atanなど13個のオペレータをカバーする。ベクトルはターゲットの最小VLENの可変長ベクトルに変更し、avlループで締めくくる。行列積のベクトル幅は2·VLEN/32に変更した。

VLENはターゲットの+zvlNbから読み取る。+vのみの場合は128と計算する。作者はVLEN-256のRISC-Vボード上でtriton-cpu調整のパラメータと比較した。

このPRはまだマージされていないbuddy-mlir #1068に依存する。PRの説明には、旧版のbuddy-optを使うと未知のpassまたはオプションの箇所で直接失敗すると明記されている。

1.2 FlagGems サンプル三点連：63 + 43 + 40 個のオペレータが 3 ブランチに分かれてマージ待ち（11-19）

情報源：PR #126。PR #127。PR #130。

FlagGems サンプルは 1 日のうちに 3 ブランチに積み重なった。#126 は 63 個の aten オペレータをカバーし、#127 はさらに 43 個の torch.special オペレータを追加し、さらに #130 が 40 個の活性化、dropout、損失オペレータを追加する。

3 ブランチは直列に積み重ねられている。#127 は #126 の上に、#126 は #120 の上に、#130 はさらに #127 の上に載っている。PR 説明はいずれも、先行分が未マージの場合 diff には先行コミットも含まれると注記している。

それぞれの説明によると、main に対する規模はそれぞれ 239、325、405 ファイルである。#130 自身の部分は 4 コミット、81 ファイルで、残りは先行 PR に属する。

テスト数は層ごとに増加する。#126 は 6416 項目の通過を記録し、+#127 は 6782 項目、#130 は 7091 項目を記録した。新規追加ケースはそれぞれ 309 項目と 366 項目である。

#127 の内容は特殊関数である。ベッセル関数ファミリー、4 種類の Chebyshev とシフト版、2 種類の Hermite、Laguerre と Legendre を含み、さらに log_softmax と logsumexp もある。

ツールチェーンで降格できない intrinsic は閉形式に置き換えた。erfcx は 3 段混合で、fp32 段、fp64 段、漸近級数がそれぞれ一部を担う。log_ndtr の裾は −t² + log(erfcx(t)/2) の計算に変更し、ndtr のアンダーフローを回避する。

#130 の内容はニューラルネットワーク系オペレータ寄りである。GELU、GLU の逆伝播式、融合された conv/addmm/prelu、dropout と randomized-ReLU の変種、および CTC 順伝播と逆伝播を含む損失グループがある。

CTC の格子動的計画法は fp64 の Triton カーネルを用いる。逆伝播は beta スキャンをホスト側に残し、同時に渡された alpha をクリーンアップする。著者は、aten の CPU 実装では到達不能な格子点が未初期化のまま残ると注記している。

畳み込みの cudnn エピローグは aten 経由に変更された。Triton は bias、Z 加算、ReLU のみを保持する。triplet margin は pairwise_distance のセマンティクスに従って処理し、eps は差分ベクトルにブロードキャストされる。

3 ブランチはいずれも範囲を python/examples/flaggems に限定している。PR 説明には、バックエンド、CI、その他 PR のファイルを変更しないと明記されている。

1.3 RISC-V バックエンドチューニング PR #129 が起票、Buddy の未マージ pass に依存（11-19）

情報源：PR #129。PR #128。buddy-mlir PR #1068。

#129 は 18:20 に起票され、タイトルは #128 と同じである。#128 は 10:19 に起票され、10:20 にクローズされ、その後 #129 として再オープンされた。内容は同一である。

変更は Triton から LLIR へのある関数 1 箇所に集中している。ターゲットが RISC-V の場合のみパラメータを追加し、他のターゲットには影響しない。著者は特定の VLEN にバインドしていないと説明している。

パラメータは三つに分類する。数学関数は多項式近似を展開し、exp、expm1、log、log2、log1p、tanh、erf、erfc、sin、cos、atan、atan2、asin、acos、cbrt を含む。

ベクトル化は伸縮可能ベクトルに切り替え、ターゲットの最小 VLEN に応じて幅を取り、avl ループを展開する。行列積のベクトル幅は 2·VLEN/32 に変更し、従来は定数 4 であった。

精度の根拠は Buddy 側にある。#1068 の説明では f32 で 1 から 7 ULP、f16 と bf16 で最大 1 ULP としている。例外は exp と erfc の非正規化結果である。

依存関係はハード制約である。#1068 はまだマージされておらず、buddy もこれら二つの機能を備えたリリースはまだない。PR の説明には、旧版の buddy-opt は未知の pass やオプションの箇所で停止すると明記されている。

4.4 GPT-2 デコード修正が公開、多項式近似数学 pass は審査待ち（11-19）

情報源：buddy-mlir PR #1069。PR #1068。PR #1065。

#1069 は 23:57 に公開され、GPT-2 デコードの数値エラーを修正する。問題は転置 B のバッチ行列積が、デコードのベクトル化によって非転置レイアウトとして処理されていた点にある。

linalg 層には転置 B 専用のオペレータが存在しない。両者は linalg.batch_matmul を共有し、indexing_maps のみで区別される。デコードパイプラインでは 2 つの pass が前後に隣接し、前者がすべての batch_matmul をデフォルトレイアウトでベクトル化していた。

修正はガードを追加するもの。デフォルトの indexing_maps のみがベクトル化に進み、転置 B は後続の専用 pass に委ね、こうしたオペレータを動的に合法とマークする。変更は 2 ファイル、+127。

#1068 は数学近似の本体であり、依然として審査中。新しい pass は exp、tanh、log などのベクトル数学を多項式に置き換え、計算をベクトルレジスタ内に留め、lane ごとに libm を呼び出さなくする。

上流 MLIR の近似には 6 つのオペレータで境界問題がある。log と log2 は非正規化入力を FLT_MIN にクランプし、sin と cos の単一定数帰約は大きな引数で歪み、atan2 の象限判定にも偏差がある。この pass はそれらのために別のパターンを記述する。

sin と cos は 3 段の Cody-Waite 帰約を用い、1e5 を超える引数は 192 ビットの Payne-Hanek を通す。ベクトル内にこうした lane が現れた場合のみ分岐に入る。

ループ末尾も変更した。avl ループは剰余を有効長の 1 回のイテレーションのみで実行し、半分に分割してスカラーループを加えることをしなくなった。

#1065 は同日 1:10 にクローズされ、マージされず。これは linalg.transpose のキャッシュフレンドリーなブロッキングを行うもので、11-18 に作成された。

これら二種類の作業は機能一覧には現れないが、上位ソフトウェアが新しいベースラインでビルドできるかどうかを決める。ディストリビューション側の重点はパッケージ追加から基盤交換へと移りつつある。
