今日の重点：Caffe に 3 件の RVV オペレータ PR が出され、MXNet シリーズ 15 件が審査中——古典フレームワーク適応ラインが実作業段階へ

日付：2026-09-23 ~ 2026-09-28　出典：caffe PR #1、caffe PR #2、caffe PR #3、MXNet PR リスト

北京時間 09-28 14:56 から 14:59 の間（3 分以内）に、貢献者 Xlawy が caffe リポジトリ（09-23 にマージされた 2 つの古典フレームワークリポジトリの一つ）で 3 件の RVV オペレータ PR を連続して出しました。両リポジトリのマージ以来、初の実質的なコードアクションとなります：

  • #1 im2col（+113 / -9、2ファイル）：im2col の出力行収集をスカラー補助と RVV float オーバーロードに分割し、各行をゼロパディングと境界内の2区間に分け、stride_w に応じて単位ステップまたはストライド付きベクトルロードを選択し、可変長 e32,m4 ブロックを採用。あわせて Protobuf の SetTotalBytesLimit 単一引数 API を 3.6.0 以降に適合させた。
  • #2 float CPU max pooling（+167 / -24、2ファイル）：e32,m4 ブロックで最大プーリングの内部列を処理し、ストライド付きロードと厳密大なり比較で最大値および勝出位置オフセットを更新し、初出タイの意味論と -1 センチネルを保持し、3列ウィンドウを展開。境界は引き続きスカラーで処理。
  • #3 float vPowx（+166 / -1、2ファイル）：非 MKL の vPowx<float> に RVV 特殊化を追加——入力がすべて正規数かつ指数が [-1, 1] のときにベクトル log/exp 近似（倍精度中間量）を有効化し、指数 0 と 1 は直接ベクトル演算、ブロック単位のインプレース呼び出しをサポート。ドメイン検査を通過しない場合は呼び出し全体をスカラーにフォールバック。

3件はいずれも RVV マクロガードで新規定特化を追加し、非 RVV ビルドのスカラーフォールバックを保持しており、現在すべてオープン状態でレビュー記録なし。同一路線のより早い動きは MXNet リポジトリに集中：09-23 から 09-24 の2日間に、3名のコントリビュータが累計15件の PR を開いた（ww8191201-coder 11件、Xlawy 2件、6eanut 2件）。うち11件が RVV オペレータのベクトル化——GELU(erf) 逆伝播、ReLU 逆伝播、softmax、log-softmax、softmin、CTC log-softmax、im2col、col2im、バッチ cumsum、最近傍アップサンプリング、float32 最小値リダクション。残り4件は性能とビルド基盤（broadcast_reduce と reduce_with_axis のインデックス走査強度削減、総和リデューサの volatile 除去、非 MSVC ビルドでの -fno-math-errno 要求）。多くの PR 説明が SG2044（RVV 1.0、GCC 15.1）のテスト文脈を直接引用している。この一連は以前の調査期間では展開されておらず、本期は Caffe の新規動作と統合して記録する。

調査期間末時点で、両リポジトリ合計18件の PR はすべてオープン、マージ済みはゼロ。09-24 期の両リポジトリに対する「アーカイブ、適合ベースラインまたは新規作業起点」という要観察記録と合わせると、本批次の動作は段階的な答えを示している：両リポジトリは古典的フレームワークの RVV 適配の実践基地として用いられ、MXNet 系列は推論バックボーンのオペレータ面をカバーし、Caffe 系列は畳み込みと活性化の基盤に焦点を当てている。同日夜間、コンパイラ側の RVV 動作は tilelang-riscv PR #4 が引き受け（1.1 参照）、RVV は当日組織内で最も集中した技術テーマとなった。

5.1 古典的フレームワーク RVV の二路線が成形：『マージ』から『PR の積み上げ』へ

5.2 中秋前後のリズム：09-28 は連休後の集中的な産出

09-25（旧暦八月十五、中秋節）およびその後の週末、三組織のコミットはほぼ停止した；09-28 の連休後最初の営業日に集中的な産出が現れた：openRuyi メインリポジトリ 5 件、kiwi-image 3 件、VS Code 拡張 2 件と 0.1.7 リリース、ruyiai-daily とフォーラム情報スレが同日に再開——休暇による「低谷、反発」が二つの調査期間内で完全に可視化された。

5.3 ツール側のリリースリズムは安定

調査期間内に三つのツールラインがそれぞれのリズムで推進した：VS Code 拡張 0.1.7 が正式化（beta 後 8 日）、Ruyi Imager のナイトリーチャネル更新、triton-riscv の毎週のナイトリービルドが予定通り産出；対応して、ruyi-tuner の 1.9 バージョンラインは「未リリースだが変更は途中」の状態を二つの調査期間にわたって維持している。

5.4 本調査期間の空白と注目点

空白項目：PyTorch riscv ブランチとオープン PR が連続して沈黙（09-21 以降）；llvm-project PR #168（XTHeadVector 修正）のレビューが 09-24 で停止；support-matrix のレビュー待ちキューが滞留（09-21 から 09-24 まで更新なし）；openRuyi 2026.09 月版の告知が未公開；外部ニュースと arXiv はゼロヒット。注目点：第一に MXNet / Caffe の 18 件の PR のレビューと初回マージのリズム；第二に ruyiai-daily が毎日のプッシュを再開するか；第三に ruyici の macOS ビルドと riscv-gcc p 拡張パッチの推進；第四に 6.18.54-1 カーネルタグが openRuyi の正式ビルドに入るかどうか。
