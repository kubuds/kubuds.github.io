今日の重点：マトリクス拡張の二本柱が同時進行——Ztt ドラフト GCC バックエンドが1日で36コミット、LLVM riscv スタックが夜間リビルド完了

日付：2026-10-08 ~ 2026-10-09　出典：riscv-gcc ztt-dev コミットリスト、llvm-project riscv コミットリスト、ヘッドコミット 44b1cf2、PR #25、PR #28

本ウィンドウ最大の単一成果は riscv-gcc の ztt-dev ブランチに現れた：貢献者 pz9115 が 10-08 午前（08:40 ~ 11:27）に 36 件の Ztt バックエンドコミットを連続プッシュした。Ztt は RISC-V マトリクス拡張方向のドラフト命令セットであり、RuyiAI が LLVM 側の BOSC AME / A100 ライン以外に展開する GCC ツールチェーン布局である。当該バッチの内容は下層から上層までをカバーする：ゼロ取得とゼロブロードキャストの構築簡略化（x0 再利用とデータ型クリア）、構造折り畳み（射影 / 再構築 / 逆操作 / 拼接抽出 / zip と unzip）と証人処理、Md（マトリクス記述子状態）トラッキングがスカラー、マトリクス、行列出とグループ化の各演算クラスを貫通、記述子レジスタ再利用、浮動小数点行列出 intrinsics の新規追加、大 ACC デフォルト丸めエイリアス修正、組込み関数入力属性キャッシュ、未使用ワークスペース清理、および M 値セマンティクスのテストとドキュメント；このブランチが 09-30 に新規開設されて以来、最も密集したバッチである。

LLVM 側では、llvm-project の riscv ブランチ（デフォルトブランチ）が新たな夜間再構築を完了した：ローカルパッチスタック 26 件を新しいコミッタ時間で全体リプレイ（10-08 深夜）、10-09 00:51 にプッシュ完了——ヘッドは 44b1cf2「[RISCV] Add A100 HP/SP and pack/unpack lowering with calibrated scheduling」（#31；前回の再構築のヘッドパッチと同じで、定例リプレイに属する）；スタック内統合コミットは「[SyncBots] Integrate LLVM at b3b5e33」を維持し、リプレイアンカーは 10-08 当日の上流スナップショットまで進んだ（上流ベースラインには当日の [RISCV] ベクトル ISD 修正 #228215 などのコミットを含む）。再構築完了後、2 件の FPGA バックエンド PR（#25「BOSCAME FPGA バックエンド」、#28「xboscame FPGA」）の更新時間は直ちに 10-09 00:51 に更新され、新ベースライン下でのレビュー進展を待っている。另外：fork 内で 10-08 18:38 に buckyball ブランチを新規作成（再構築前の旧ヘッドを指す）、スタック内の Buckyball ベンダー拡張（#20 / #23）方向と同名である。

要点まとめ：マトリクス拡張は LLVM（BOSC AME / A100）と GCC（Ztt）の 2 つのツールチェーン上で同一ウィンドウに並行して推進されている；再構築式同期、FPGA 側の審査待ち PR と新ブランチ布局が次段階の観察面を構成する。

Google News は RuyiSDK、RuyiAI、openRuyi および如意 RISC-V の中国語・英語の複数クエリの調査期間内でゼロヒット（チャネルは正常、同期間内の他の情報源はすべて正常に返却）。arXiv（RISC-V とコンパイル、ベクトル、推論方向）は調査期間内に新規収録なし（最近のエントリは 10-07 コミット）。openRuyi ディストリビューションのニュースページに新規記事なし（2026.09 リリース告知が依然として最新）；RuyiAI 公式サイトとブログに新規記事なし（ブログは依然として Triton 適配と PyTorch RISC-V CI の 2 本）。

5. トレンド観察

5.1 マトリクス拡張のデュアルスタック・リズムと観察ポイント

本調査期間、2 つのツールチェーンスタックが同日に実質的な進展を見せた：GCC 側は Ztt ドラフトバックエンドが単日 36 コミット（規模は同ライン最大）、LLVM 側はパッチスタックの定例リプレイで前線を維持（A100 HP/SP パッチがトップ）。観察ポイント：Ztt ラインの riscv-binutils 側での同期とアップストリーム化の経路（binutils の ztt-dev は本調査期間コミットなし）；FPGA バックエンドの 2 件の PR（#25、#28）の新ベースライン下でのレビュー進捗。

5.2 夜間リビルド、ベースライン・プッシュと PR 連動

llvm-project と pytorch の 2 つの fork の「夜間リビルド / 毎日ベースライン・プッシュ」メカニズムは本調査期間もリズム通りに稼働：リビルド完了後にオープン PR のベースライン記録が随時更新（llvm #25、#28；pytorch 8 件）。このメカニズムは既に RuyiAI 側 fork の常態的な運用形態となっている——アップストリームとの同期ポイント（SyncBots b3b5e33 ライン）の推進効率、およびリビルドのリズムと PR レビューのバッチの連携を観察する。

5.3 インテリジェント基建とコミュニティのオペレータ貢献

harness は独立リポジトリで Triton-RISCV agent バックエンドとワークベンチを引き受ける；triton-riscv はコミュニティ貢献の softmax / matmul 最適化 PR（#85）を受信。2 つのラインは共に以下を指し示す：RuyiAI ツールチェーンの「agent 化 / 自動化」ナラティブとコミュニティ参加度が並行して上昇——agent ワークベンチとオペレータ貢献の今後のイテレーション・リズムを観察する。

5.4 openRuyi エコシステム拡張と月次版リズム

openRuyi は単一調査期間で 61 コミット（Go エコシステム 31、Python 3.14 アップグレードバッチ、AI データスタック 17、ceph / moby / dotnet などの修正）、2026.09 リリース後の持続的なパッケージング拡張であり、クラウドネイティブと AI / データサイエンススタックの 2 つのエコシステムラインが同時に厚みを増している。観察ポイント：次の月次版サイクル開始時に、本バッチの Python 3.14 と Go 依存がバージョンビルドベースラインに入るかどうか。
