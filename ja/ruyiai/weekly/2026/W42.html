RuyiAI ウィークリーレポート (2026-10-12 ~ 2026-10-16)

2026-10-16 Kubuds

レポート期間：2026年10月12日（月）から10月16日（金）まで、計5営業日

素材ソース：本誌のデイリーレポート RuyiAI 動向レポート5号（2026-10-12から2026-10-16まで、各号の調査期間は前日04:30から当日04:30まで）；加えて RuyiAI-Stack、ruyisdk、buddy-compiler の3組織における168時間のリポジトリ調査、openRuyi-Project 重点リポジトリの補足調査、および RuyiSDK 開発者コミュニティと openRuyi ニュースページのデュアルソース再確認（10-17朝までをカバー）

編纂説明：今週の技術的主線は、openRuyi の K3 ファームウェアプラットフォームライン（10-13から10-15の3日間に3版連続リリース）と、Ztt マトリクス拡張ツールチェーンの GCC + LLVM デュアルバックエンドの実装である。ウィークリーレポートではデイリーレポートの素材に加えて2件の調査上の新発見を補足した：第一に、10-15午前の riscv-gcc の ztt-dev ブランチにおける Ztt コミット20件の一括投入（当日のデイリーレポートには未収録）；第二に、10-16の tilelang-riscv の復活と Buddy MLIR 0.1.0 のリリース（デイリーレポートの調査期間後に発生）。

1. 今週の主なニュース

  • openRuyi が K3 ファームウェアプラットフォームラインを開設、10-13から10-15の3日間に3版のファームウェアを連続リリース：10-13に edk2-ruyi を新規作成（35件の一括初回投入で SpacemiT K3 Pico ITX の EDK2 プラットフォームコード）し、ruyifirmware（5件でパッケージリリースチェーンを構築）を新設、当日18:46に最初のバージョン「Ruyi Firmware 20261013」をリリース；10-14の第2版では UEFI 内の CPU モード選択（X100 のみ / X100+A100 混在 / A100 のみ、RVV および H 拡張のスイッチを含む）を導入し永続保存を実装；10-15の第3版では読み取り専用の System Information ページ、x64 および ARM64 UEFI ドライバエミュレーション（デフォルト無効、Platform Settings 経由で有効化）と実験的な AMD ARM64 GOP 1.68 パイロットを追加。出典：edk2-ruyi、Ruyi Firmware 20261013、20261014、20261015

  • Ztt マトリクス拡張ツールチェーンが LLVM 側を補完し、GCC + LLVM デュアルバックエンドを形成（10-12）：ruyisdk/llvm-project は10-12午前に ztt-dev ブランチを新規作成し、26件の LLVM / Clang パッチのフルスタック初回投入を完了（作者 LukeZhuang、Ztt 拡張の基本サポート、関数レベルプロファイル、CSR とマトリクスレジスタグループ、命令アセンブルとディスアセンブル、IR 型と intrinsic、Clang マトリクスレジスタ型、レジスタ割り当て後の疑似命令展開、M レジスタと ACC オーバーフロー処理をカバー、最終コミットでテストを AME 診断体系に整合）；GCC 側の riscv-gcc の ztt-dev ブランチは09-30の作成後、10-08の36件、10-11の51件、10-15の20件を連続投入済み（最終バッチは今週の調査で発見）。さらに attached-matrix-extension の Ztt intrinsic ドキュメント V0.6 PR が加わり、「仕様—ドキュメント—デュアルツールチェーン」の連鎖が同時に活発化。出典：llvm-project ztt-dev、先頭 aeb52e1a、riscv-gcc ztt-dev

  • Buddy MLIR 0.1.0 正式リリース、RISC-V クロスコンパイルと CI を全面展開（10-16）：buddy-compiler/buddy-mlir は今週 16 コミット、4 リリース、うち 0.1.0 は北京時間 10-16 未明にリリース（タグ release/v0.1.0）、その後ナイトリーチャネルは 0.1.1.dev 系列（dev20261016、dev20261017）に移行した。RISC-V 関連の動きが集中：buddy-cli に RISC-V ボード向けクロスコンパイルを追加（#987）、Makefile の RISC-V ターゲットを修正（#986）、クロスコンパイルフローを簡素化（#975）、buddy-server に RISC-V サーバー側クロスコンパイルを追加（#989）、さらに manylinux riscv64 ビルドで Ruyi パッケージインデックスを用いて riscv64 版 torch をインストールし、libsndfile を補完（#990、#937、#988）。出典：buddy-mlir、BUDDY MLIR 0.1.0、PR #989

  • RuyiAI の tilelang-riscv、約 1 か月の沈黙を破る：5 件の RISC-V コミットで Buddy リリースチェーンに接続（10-16）：同リポジトリの前回コミットは 09-20 だったが、今週金曜に 5 件を連続コミット——コードフォーマット、上流オペレータのランタイムセマンティクス対応（lane-local 状態、ragged copy、動的制御フロー、FP8/FP4 変換修正）、TileOps ランタイム適応のアップグレード（サブモジュールを 67250e81 に更新、paged-cache gather と varlen GQA sinks カーネルを動作確認）、Buddy MLIR release CI の追加と Buddy CI での Python 拡張ビルド。これは TileLang の RISC-V バックエンドが Buddy MLIR のリリース成果物を基準として継続的インテグレーションを開始したことを意味する。出典：tilelang-riscv コミット一覧、5 件の初回 32fce5ed

3. RuyiSDK ツールチェーンとディストリビューション（ファームウェア、コンパイラ、カーネル、openRuyi）

K3 ファームウェアプラットフォームライン：3日で3版、リンク開通から設定可能・シミュレーション可能へ

  • 外部情報源：Google News による RuyiSDK / RuyiAI / openRuyi /「如意コミュニティ」の中国語・英語の複数クエリは全週で関連ヒットゼロ（同期間に RISC-V 汎用クエリは正常に返答しており、チャネルに異常はない）；arXiv の RISC-V コンパイル、ベクトル、エッジ AI 方向に新規収録なし；openRuyi ディストリビューションのニュースページは依然として 2026.09 リリース告知が最新（2026.10 リリースページは未公開）；RuyiAI 公式サイトとブログに新規記事なし。

7. トレンド観察

  • K3 が今週唯一の体系的な主線となった：ファームウェア（3日で3版）、カーネル（ruyi/7.3.y 初回 31 コミット）、イメージ（kiwi-image 自動化）の3層が同一週に同時に動き、ファームウェアは「リンク開通」から「CPU モード選択可能 + ドライバ模拟可能」へと進んだ。観察点は、これらの機能が 10-18 サミット週にデモ可能な実機形態を形成できるか、および3段階 CPU モードの実測データにある。
  • マトリクス拡張は「単一バックエンド推進」から「デュアルバックエンド + 規範 + オペレータ検証」の並行へ：GCC ztt-dev の3バッチ（36 → 51 → 20 コミット）はテーマが機能敷設から他の拡張との協調の正確性（RVV / Zfa / アトミック操作を跨ぐ状態保持）へと移行し、LLVM 側の ztt-dev 初回プッシュが残りの半分を補完、ドキュメント V0.6 と AME-operator チュートリアルも追随；同時に upstream AME タスクグループが玄鉄の主導で標準化を推進——リポジトリ内ドラフトと規範ラインが同頻化し始めた。
  • 2本の fork 保守ラインのリズム分化が拡大中：PyTorch riscv ブランチは毎朝1回の 23 コミット再構築、8 件の PR 同期更新を維持；LLVM riscv ブランチは 10-12 以降3夜連続で再適用なし。前者は上流追随メカニズムの自動化度が高いことを示し、後者は LLVM 側の作業重心が ruyisdk/llvm-project の保守ライン（XTHeadVector 修正がその成果）へ移行した可能性を示す。
  • Buddy Compiler が RuyiAI の事実上の上流の一つに：buddy-mlir は1週間で 0.1.0 リリースと riscv64 クロスコンパイル / CI / manylinux リリースチェーン修正を完了し、triton-riscv の依存更新と tilelang-riscv の新 CI はいずれも Buddy のバージョン成果物をアンカーとする——「MLIR コンパイルフレームワーク → オペレータフロントエンド → ナイトリービルド成果物」のチェーンが今週初めて riscv64 上でリリース可能な wheel まで閉ループ化した。
  • ディストリビューション保守は「バッチ処理 + セキュリティバッチ」の二重リズムへ：openRuyi の単日 90 コミットの Go モジュール、39 パッケージの KDE、GnuPG スタック全体、5パッケージのセキュリティ連続リリースは、依存追随がエンジニアリング化されたことを示す；暗黙の制約は全量再構築コストとイメージリリースリズムの結合であり、0.54.0 と 2026.10 イメージのタイミングを観察する価値がある。
  • 観察待ちリスト：0.54.0 月末リリースと ABI 互換性検出；ruyi/7.3.y がいつイメージチャネルに入るか；triton-riscv #85 レビュー；LLVM FPGA の2件の PR（#25 / #28）；PyTorch #46 / #48（RVV）と #51（ローカルイメージはブランチにマージ済み）；attached-matrix-extension ドキュメント PR #1；サミット（10-18 ~ 10-20）期間中にバージョンや成果のリリースがあるか。
